**安全红线（本会话已发生过整章丢失事故）**
1. 禁止对该文件使用 Write 整文件覆盖。只用 Edit，一次一节，`old_string` 覆盖从 `## ` 标题到下一节标题之前的全部内容；单次 `new_string` 不超过约 120 行。
2. 每改完一节，跑 `python3 tools/check_loss.py`（工作目录 `cpp-rust`）。它对比 git HEAD，H2 减少或汉字倒退超 8% 即失败；失败先修，别继续写。
3. 每改完一节，跑 `grep -c "^## " <<文件路径>>`，必须仍是 11。
4. 语义盒要配平：`::: ex` 套 `::: sol` 需要两个 `:::` 收尾；`::: method 即时自测` 要在最后一题之后闭合。
5. 盒子标题那一行不能出现尖括号（`Vec<u64>` 会被当成 HTML 标签）；泛型只写在正文反引号里。
6. **把本章第一个 `<pre class="layout">` 升级成内联图**（其余可暂时保留）。写法： `<figure><svg role="img" …><title>…<desc>…</svg><figcaption>图 N-M · 句</figcaption></figure>`，图内不许有空行，`id` 加本章前缀（如 `c11-`），并保留图后的「读图：」句子。

**图示写法**：`<figure aria-labelledby="cN-fig-x-caption">` 起一行，内部**不许空行**，`<svg role="img" width="900" height="…" viewBox="0 0 900 …">` 里先 `<title id="cN-fig-x-title">` 再 `<desc id="cN-fig-x-desc">`（desc 用一整句话讲清图里每个元素指什么，读屏软件只念得到它），然后才是 `<defs>`/`<g>`/`<rect>`/`<text>`；结尾 `</svg><figcaption id="cN-fig-x-caption">图 N-M · 一句话图题</figcaption></figure>`，图后保留一句「读图：…」。**所有 `id` 加本章前缀**（如 `c9-`），否则与全书其他 `id` 冲突、门禁会报重复锚点。配色只用主题变量：`var(--fig-blue)`、`var(--fig-gold)`、`var(--fig-green)`、`var(--fig-red)`、`var(--fig-purple)`、`var(--fig-neutral)`、`var(--muted)`、`var(--line-strong)`；**没有** `--fig-ink` 这个变量。

**每节骨架**：本节回答一个问题 → `::: preview 先抓住一件事` → `### N.M.k` 小节（术语首现即用一句大白话定义）→ `::: def 定义 N.M.k · 名 英文 {#def-N.M.k}` → `::: ex 例 N.M.k · … {#ex-N.M.k}` 内套 `::: sol 解答` → `::: think 思考 · …` → 有判定的给 `::: method 判定流程` → `### N.M.k 小结与常见错误`（`**小结。**① …（[@def-…]）` + `::: errata 常见错误清单（N.M 节）` 列 E-a…E-f）→ `::: method 即时自测 · N.M`（记忆/辨析/应用/迁移四题，各折进 `::: sol 第 k 题答案`）。

**末三节改写**：N.9 → 延伸阅读与来源（审计台账留在 `src/appendix/coverage.md`）；N.10 → 常见错误索引（各节清单索引表 + 3–4 条跨节错误，不重述 E-x）；N.11 → 本章小结与章末件（`::: note 本章小结` + `### 本章速查` + `### 本章导航`）。章末件页面尚不存在，不要链接 `chNN_exercises.md` 之类。

**证据纪律**：不许编造任何数字、IR、汇编或输出。文件里已有的实测值、文件名、命令、版本原样保留；缺数据的结论写成「本节没有采集」。

**交叉引用顺序**：先写盒子（带 `{#def-N.M.k}`），再在别处引用它。`check_book.py` 会逐条核对 `[@id]`，
引用一个还没写出来的锚点就是报错，预处理器也会因此中止构建。**交叉引用**：`[@def-N.M.k]`/`[@ex-N.M.k]` 全书解析，可引用第 1 章已有 id（`def-1.1.1`…`def-1.8.2`、`ex-1.1.1`…`ex-1.8.1`）与你自己新建的 id；引用不存在的 id 会让预处理器报错。全章至少 60 处。
