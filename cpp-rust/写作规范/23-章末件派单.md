**硬规则**

1. **数字只能来自正文。**不许出现正文里没有的实测值、单位或趋势；要引用数字就照抄正文并给出处链接。
2. **链接必须可达。**只链正文里真实存在的锚点：H2 的 `sec-cpp-rust.<<篇>>.<<章>>.k`、盒子的 `{#def-…}`/`{#ex-…}`。
   写完跑 `python3 tools/check_book.py`，它逐条核对 `](文件#锚点)` 与 `[@id]`。
3. **盒子要配平。**`::: ex` 套 `::: sol` 需要两个 `:::` 收尾；`::: hint` 要先自己闭合再开 `::: sol`。
4. **盒子标题里不要写尖括号**（`Vec<u64>` 会被当成 HTML 标签），泛型只写在正文反引号里。
5. 五页之间不许互相重复：总结讲结论、回忆卡管提取、习题集管做、自测卷管限时验收、自检表管达标判定。
6. 五页的 H1 标题格式固定：`# 第N章 · 全章总结` / `· 闭卷回忆卡` / `· 习题集` / `· 综合自测卷` / `· 学习目标自检表`。
7. 文风与正文一致：一段平均 80 字以内，一句 35 字以内，术语首次出现给一句白话解释，不写「显然」。

都能跑通。不要跑 `mdbook build`，不要改 `SUMMARY.md`（由集成者统一挂目录）。
