# 15 分钟入学诊断自测

这本书默认你会三件事：写 Rust、知道操作系统大概在做什么、能读懂均值和标准差。诊断的作用是告诉你**先补哪一格**，不是给你打分。

规则：闭卷，15 分钟，答案写在纸上。每题 1 分。做完先看[分数怎么读](#entry-score)，再逐题展开核对。不要边做边查——查到的不算。

<a id="entry-qs"></a>

## 一、Rust 与所有权（1–4）

1. 下面两段代码，哪个版本每次调用可能触发堆分配？为什么？<br>
   (a) `fn sum(v: &Vec<u64>) -> u64 { v.iter().copied().fold(0, u64::wrapping_add) }`<br>
   (b) `fn sum(v: Vec<u64>) -> u64 { v.iter().copied().fold(0, u64::wrapping_add) }`

2. `let a = b.clone();` 和 `let a = b;` 对 `Vec<u64>` 的差别是什么？对 `u64` 的差别又是什么？

3. 一个结构体里放下 `Option<&'static u8>` 常常不需要额外字节。这是什么机制？

4. `drop(v)` 之后再用 `v` 会怎样？编译器是靠什么拦住它的？

## 二、操作系统与硬件（5–7）

5. 一次内存访问从 L1 到主存，量级上大概差多少倍？（给个数量级即可）

6. 「缓存行」是什么？为什么它会影响你遍历二维数组的写法？

7. 进程被抢占、页面缺页、频率回降——这三件事分别发生在硬件、操作系统还是编译器层面？

## 三、统计与测量（8–10）

8. 21 个数的样本标准差用 N−1 而不是 N 作分母，为什么？

9. p50 和均值有什么区别？什么情况下两者会明显分开？

10. 「测了 1000 次，所以我的结论很可靠」——这句话缺了什么？

## 四、推理方式（11–12）

11. 有人说：「我把循环展开后快了 30%，所以展开循环能提速 30%。」写出你要问的第一个问题。

12. 一个求和函数返回 0，测试却通过了。给出两种「测试其实什么都没验证」的可能原因。

## 核对

1. **(b) 会。**按值接收 `Vec<u64>` 意味着调用方必须把所有权交出来；如果调用点上没有可移动的值，就需要自己构造一份——通常即一次堆分配与拷贝。(a) 只借用，不分配。

2. 对 `Vec<u64>`：`clone` 分配新缓冲区并逐元素复制；`let a = b` 只移动所有权，不复制数据。对 `u64`：两者都只是复制 8 字节（`u64` 是 `Copy`），差别可以忽略——这也是为什么「clone 贵不贵」必须先问类型。

3. **niche 优化**：`Option<&T>` 借用引用「非空」这个不变量，用全零指针表示 `None`，因此不需要额外判别字段。第 2 章展开。

4. 编译错误（use-after-drop 属于借用检查层面的 move 错误）。编译器跟踪每个绑定的**初始化状态**：`drop(v)` 使 `v` 进入 moved-out 状态，之后的使用不被允许。第 3 章把它当成「证明边界」来讨论。

5. 数量级差几十到一百倍（L1 约 1 ns 级、主存约 100 ns 级）。**这本书不引用具体周期数**——本机没有采集硬件计数器，你只需要记住「差一两个数量级」。

6. CPU 与内存之间一次搬运的最小单位（多数平台 64 字节，Apple 平台上 `sysctl` 记录 128 字节）。按行遍历会连续命中同一条缓存行，按列遍历会把许多无关数据一起拖进来——第 2 章的热字段讨论从这里开始。

7. 抢占=操作系统；缺页=操作系统（硬件配合触发）；频率回降=硬件/电源管理。三者的持续时间和可复现性完全不同，第 1 章 1.4 的时间漂移讨论把它们放在一起处理。

8. 用 N 会把方差系统性低估：样本均值本身已经是从这批数据里估出来的，它「贴住」了数据，剩余离差比真实总体的离差小。N−1 是无偏估计的必要修正。第 1 章 1.5 明确按 N−1 计算。

9. p50 是排序后中间那个值，均值是算术平均。分布有长尾时两者明显分开：少数极慢的批次会把均值抬高，却几乎不影响 p50。这是「均值 0.058、p99 0.059」这类数字要一起报的原因。

10. 缺了**独立性条件**。1000 次如果来自同一次运行、同一套热状态和同一后台负载，它只是把同一个环境测得更精确，不能代表跨时段、跨机器的差异。第 1 章 1.7 用「独立重跑」而不是「同一运行加样本」。

11. 该问的是：**这 30% 是在什么条件下测的，基线有没有可能根本就没执行？** 展开循环同时改变了代码生成可见性，收益也可能来自被删掉的工作。第 1 章 1.1、1.5。

12. ① 期望值由被测实现自己算出，两者同源，一起错；② 断言发生在计时/执行之外，或 `sum` 被优化器整段删除后返回常量仍然匹配了一个恰好为 0 的期望。第 1 章 [@def-1.1.1] 与例 1.1.1。
