# 速查背记卡

这一页是复习四层里的压缩层。正文负责证明，章末的回忆卡负责提取，这一页只负责一件事：把一个核心观点压成一句能背出来的话，再附一句「它凭什么成立」。

背下来不是为了跳过正文。是为了回正文时，知道自己在核对哪一条。

::: note 三页的分工

| 页 | 管什么 | 什么时候翻 |
|:--|:--|:--|
| [符号表](preface-notation.md) | 记号指什么、在哪儿第一次出现 | 读表格时卡在一个字母上 |
| [术语表](appendix/glossary.md) | 一个词的一句话定义 | 不确定一个术语的边界 |
| [速查卡](appendix/cheatsheet.md) | 遇到症状先查哪一项 | 手上有一个具体问题要处理 |
| 这一页 | 一句结论加它的前提 | 合上正文，试着把它说出来 |

:::

::: note 按主线四步挑卡

时间只够翻一遍时，按你要补的那一步取卡，不必按章顺序：

| 步 | 先翻这些章的卡 | 这一格要保证说得出什么 |
|:--|:--|:--|
| ① 工作真的发生 | [1](#card-ch01)、[3](#card-ch03)、[4](#card-ch04)、[6](#card-ch06)、[8](#card-ch08) | 我怎么证明这段计算没被删、这个副作用真的落了 |
| ② 这个数是什么 | [1](#card-ch01)、[2](#card-ch02)、[5](#card-ch05)、[9](#card-ch09)、[12](#card-ch12) | 单位、分母、口径，以及这个数不回答什么 |
| ③ 差异不是噪声 | [1](#card-ch01)、[13](#card-ch13) | 同轮交替、配对差值、区间与方向 |
| ④ 守得住、可复核 | [7](#card-ch07)、[10](#card-ch10)、[11](#card-ch11)、[14](#card-ch14)、[15](#card-ch15)、[16](#card-ch16)、[17](#card-ch17) | 预算、门禁三态、证据包与不覆盖范围 |

:::

**写法约定。**「背什么」是要出口的那一句；「为什么成立」只给一根钩子，不给完整论证；「依据」指向真正做证明的那一节。背不出提示句，就回那一节，不要在这一页硬记。

全页不写实测数值：数值绑定机器与版本，记法不绑。

## 怎么用这些卡 {#card-how}

### 先配对，再复习

回忆卡管提取，这一页管压缩，两者按章配对。用法固定两步：先在这里把「背什么」那句念熟，合上页面，去[第一章 · 闭卷回忆卡](part1/ch01_recall.md)那一侧从空白纸上把完整陈述叫出来。

能叫出来，这一对才算过。十七章都各自有一页闭卷回忆卡（在各章章末件里，从[第一章那一页](part1/ch01_recall.md)可以看到格式），这一页和它配对使用；卡壳时再退回每节的即时自测。

::: note 别背数字

卡片里一个实测值都不写。纳秒数、字节数、批次条数都绑定一台机器、一个版本、一组参数，换环境就变。要背的是口径、前提和边界；数值留在该节表格里，用时去查。

:::

### 节奏与记号

| 时点 | 做什么 | 判定 |
|:--|:--|:--|
| 学完当天 | 过这一章的卡片，只背「背什么」那一句 | 关键词齐全才算 ✓ |
| 第 1 天 | 合上页面复述「为什么成立」 | 说得出前提才算 ✓ |
| 第 3 天 | 从卡片反查依据那一节，讲清它挡住了哪种错法 | 讲不清就记 △ |
| 第 7 天 | 只重做标成 △ 和 × 的卡 | 全对才进入下一章 |

每张卡一个记号：✓ 一次说对；△ 说对一半或者要提示；× 想不起来。只重做 △ 和 ×。把整叠卡从头再读一遍，是在读，不是在提取，收益差很多。

### 做成间隔复习卡组

一页卡片天然对应一副卡。正面放「背什么」，背面放「为什么成立」加依据链接，标签用章号。具体做法：

1. 每个表格行导出成一条记录，第一列当卡片编号，第四列的链接原文写进备注字段。
2. 新建一种「双向」卡片类型：正向从「背什么」推到「为什么成立」；反向从机制推到结论，防止只练半边。
3. 依据链接放进背面末尾。答不出时先点链接回正文，读完再重答，别把卡片文案改成答案。
4. 每天控制新卡数量。宁少，别让一天的复习变成一次通读。
5. 标 × 的卡单独建一个临时牌组，过完再并回主牌组；连续答对的卡会自动拉长间隔。

### 卡背不住的时候

背不住通常不是记性差，是这一句被压掉了前提。回到依据那一节，找三个东西：它针对的错误写法、它成立要的条件、它不覆盖的范围。

把这三样补进卡片，句子自然就记住了。一直补不出来的卡，说明正文那一节还需要重写——这本身就是有价值的反馈。
