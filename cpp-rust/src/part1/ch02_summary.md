# 第二章 · 全章总结

这一页只回答一件事：**九节各留下了什么可复用的结论。**探针表、计时数据与展开解释都在正文，这里把每条结论压缩成一句可以带走的句子。合上正文再读这页，读不下去的那一行就是断点。

## 九节一览

| 节 | 留下的结论 | 破坏它的最快方式 |
|:--|:--|:--|
| [2.1](ch02.md#sec-cpp-rust.1.2.1) | 布局是 size / align / 偏移三元组，size 决定数组步长；每句布局话都要落层 | 只报一个 size 就谈性能，或把本轮 `RustOrder` 的 16 字节写成语言定理 |
| [2.2](ch02.md#sec-cpp-rust.1.2.2) | 标签能不能省，取决于载荷的有效值集合是否排除了某些位模式；niche 省空间不必然省判断 | 把一次 `Option` 观察推广成所有 `T` 的通例，或用 `transmute` 绕过构造器 |

| [2.4](ch02.md#sec-cpp-rust.1.2.4) | 本章的 SoA 只是热列投影；差距里步长与执行形态同时在变，归因要一条对一条产物 | 把 8.74 倍贴成「数据层应整体改列式」的重构决议 |
| [2.5](ch02.md#sec-cpp-rust.1.2.5) | 0.519 对 0.059 带着四件东西：对象、计时边界、单位、样本协议；数据全部在计时外构造 | 把批均值读成一次访问的耗时，或拿区间不跨零就宣布可发布 |
| [2.6](ch02.md#sec-cpp-rust.1.2.6) | 能力边界写进签名：`Option` 表达容量失败，`&mut self` 独占借用，生命周期绑住 `reset` | 假设 `take` 得到的切片是零，或在失败分支里先推进游标 |
| [2.7](ch02.md#sec-cpp-rust.1.2.7) | 8.25 对 2.81 的单位是 ns/逻辑块操作；收益来自接口语义换了，不是同一算法跑得快 | 把 2.81 报成一次 `malloc` 延迟，或只看时间不给 262144 字节预留 |
| [2.8](ch02.md#sec-cpp-rust.1.2.8) | 类型化放置要两份互不替代的证明：布局证明与来源证明；先证明基地址，再算偏移 | 只把相对游标上取整到 align 的倍数，就宣称地址已对齐 |
| [2.9](ch02.md#sec-cpp-rust.1.2.9) | 母本给的是有条件的保证；AoS/热列数字与 `ByteRegion` 是本章本机实验与有限组件 | 把本机实验数字冒充成母本结论，或抹掉文档年代差 |

## 一条主线

**先把布局记全账 → 再分清三类证据 → 然后问实测差距能叫什么 → 最后把能力写进签名、把缺的证明列成清单。**

2.1–2.2 走完第一句：size 要配上 align 与偏移，描述符与元素区是两笔账，每句话落到语言约束、标准库保证还是本机观测。2.3–2.4 走完第二、三句：跨度可算、miss 未采、代码形态同时在变，所以 2.5 的实测差距只能写成「候选场景」。2.6–2.7 把镜头从读换成存储：复用组件先把容量失败、借用边界与「不擦除」写进接口，计时才站得住。2.8 收尾于「还想推广什么」：任意 `T` 的放置缺哪八项要素，一条不少地列在清单上。

任何一环没走完，后面的数字要么建在错的分母上，要么建在没有承诺的表示上。

## 能否讲出这几句话

不看书，用自己的话回答。答不上来的，回到对应小节只看那一段。

1. 布局三元组是哪三个量？哪一个直接决定数组步长？为什么只报 size 会漏边界？
2. 为什么 `Option<NonZeroU64>` 能把 `None` 藏进被排除的位模式，`Option<u64>` 却要多付 8 字节？
3. 布局事实、机制证据、性能结果各是什么？2.3 节里本章各有没有？
4. 「热列投影」与完整 SoA 差在哪三点？这条差别限制了哪一句结论？
5. `take` 的签名里写了哪三条约束？为什么 `reset` 的合法性由借用区间决定、不由变量名决定？
6. 「相对偏移已是 align 的倍数」为什么仍可能是无效地址？用正文里的基地址例子说出反例。
