# 第三章 · 学习目标自检表

每条目标给出**达标检验**（合上书写得出什么算达标）与**依据**（正文小节 + 习题编号）。逐条打勾：✓ 达标 / △ 部分 / × 未达标。△ 和 × 的条目按「依据」回看对应小节，不要整章重读。

**这张表按「能力类型」分组（K 知识 / S 技能 / A 应用），不按主线分组**——同一件事在主线上的哪一步，卷子里已经逐题标好了，见[综合自测卷](ch03_exam.md)末尾的「每题落在主线哪一步」。两处都打勾时，以卷子的归堆为准：它告诉你缺的是哪一步的习惯。

本章的六条学习目标（见[3.11 本章导航](ch03.md#sec-cpp-rust.1.3.11)）在本表里拆成 K 知识、S 技能、A 应用三组：责任与字节、访问范围与阶段、初始化前缀、失败清理、两张实测表的读法、十维证明表。

## 未达标时怎么办

| 情况 | 动作 |
|:--|:--|
| K 组有 × | 只看对应小节的定义盒与「小结与常见错误」，再重做该节的即时自测 |
| S 组有 × | 回到[习题集](ch03_exercises.md#ch03-ex-pack)的最小练习包，做该节那道实操题；S3、S7 要真的跑一次命令 |
| A 组有 × | 重做[综合自测卷](ch03_exam.md)第三部分，然后按[回忆卡](ch03_recall.md)第三组练「只写第一行」 |
| 只想练闭卷提取 | 按[回忆卡](ch03_recall.md)的节奏走：当天第一组、第 1 天第二组、第 3 天第三组、第 7 天只重做 △ 和 × |
| 全部 ✓ | 进入[第四章](ch04.md)；7 天后回来只重做标过 △ 的卡，并顺手清空[第一章](ch01_checklist.md)与[第二章](ch02_checklist.md)里尚未 ✓ 的条目——本章两张实测表完全沿用它们的协议 |
