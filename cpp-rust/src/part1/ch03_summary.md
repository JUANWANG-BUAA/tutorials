## 一条主线

**先问谁负责，再问能访问什么、有没有合法的值，最后才问要不要把证明担到自己身上。**

3.1 回答第一件事：责任归谁。移动只转移「谁使用、谁释放」，物理搬运由具体调用边界决定（[定义 3.1.1](ch03.md#def-3.1.1)）。3.2 回答第二件事：谁能在此刻访问哪段范围，以及这条编译期事实向后端交代了什么（[定义 3.2.1](ch03.md#def-3.2.1)、[定义 3.2.2](ch03.md#def-3.2.2)）。3.3 与 3.4 回答第三件事：这段存储里有没有合法的值，失败时谁清理它——前者定义边界，后者把边界跑成计数测试与 MIR 清理边。3.5 与 3.6 是这本账的计量部分：把责任差异与结构差异换成两组实测数字。3.7 与 3.8 回答最后一件事：标准库不再替我们说话时要补哪十行证明，以及 `Pin` 只覆盖其中一条轴。

任何一环跳过去，后面的结论就在替另一条轴说话。本章的四张判定流程反复检查的只有这件事：**结论所在的轴，与依据所在的轴，是不是同一条。**

## 能否讲出这几句话

不看书，用自己的话回答。答不上来的，回到对应小节只看那一段。

1. 一次 move 里，「谁负责释放」和「搬了多少字节」为什么是两个问题？各自的依据从哪儿来？
2. 排他访问按什么维度描述？为什么变量名不同、指针个数不同都不能证明不重叠？
3. `with_capacity(n)`、`vec![0u64; n]`、提前 `set_len(n)` 三者的长度行为分别是什么？哪一个越界，越的是哪条界？
4. `Err` 与 panic 两条失败路径的清理为什么都由「已初始化前缀」决定？字段与局部变量的析构顺序各是什么？
5. 3.5 的 0.100168563 与 3.6 的 −0.952518123 各自描述的是什么口径？哪一个能换算成一次调用的时间，两者都不能说什么？
6. 证明表的十个维度里，哪两条是「一行解引用」最少要补的？为什么 `Send` 和 `Pin` 都替不了它们？

配套的检测：[即时自测](ch03.md#sec-cpp-rust.1.3.1)分散在各节末尾，跨节的闭卷提取用[回忆卡](ch03_recall.md)，成套做题用[习题集](ch03_exercises.md)，限时验收用[综合自测卷](ch03_exam.md)，逐条达标判定用[自检表](ch03_checklist.md)。
