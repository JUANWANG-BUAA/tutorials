# 第12章 · 全章总结

这一页只回答一件事：**十一节各留下了什么可复用的结论。**推导、汇编与两次 21 批实测都在正文，这里把每条压成一句能带走的句子。合上正文再读，读不下去的那一行就是断点。

五个词先对上：向量化（把一条指令同时用于多个数据）、零拷贝（只传指针与长度，不复制字节）、生命周期（编译器追踪一个引用能活多久的标记）、系统调用（用户程序请内核代做一步操作）、寄存器（CPU 里直接存取的那几个槽位）。

## 一条主线

**先问运算能不能并行 → 再问编译器肯不肯证明 → 证不出来才手写 → 再看数据能不能不复制 → 用布局与汇编划清证据层 → 最后把所有权推到内核边界。**

- 12.1 给硬件底座：一边是发射墙，一边是车道数。
- 12.2 把「没向量化」拆成四类证不出的性质，不是玄学。
- 12.3 处理编译器证不了的场景，账单是凭证、回退与尾部清理。
- 12.4 换赛道：从寄存器转向内存通路，胖指针加 `'a` 取代逐帧拷贝。
- 12.5 立规矩：布局表、编译产物、计时三层证据不互相顶替。
- 12.6–12.7 上秤：一次量运算路径，一次量分配账单。
- 12.8 推到内核：缓冲区交出去之后，谁保证它没被释放。
- 12.9–12.11 收尾：来源、陷阱、出口，留下可复验的句子。

任何一环没走完，后面那个倍数都只是修辞。
