# 第11章 · 学习目标自检表

每条目标给出**达标检验**（合上书写得出什么算达标）与**依据**（正文小节 + 习题编号）。逐条打勾：✓ 达标 / △ 部分 / × 未达标。△ 与 × 按「依据」回看对应小节，不要整章重读。

**这张表按「能力类型」分组（K 知识 / S 技能 / A 应用），不按主线分组**——同一件事在主线上的哪一步，卷子里已经逐题标好了，见[综合自测卷](ch11_exam.md)末尾的「每题落在主线哪一步」。两处都打勾时，以卷子的归堆为准：它告诉你缺的是哪一步的习惯。

术语按正文定义。缓存行（核之间搬运数据的最小单位）。伪共享（两个独立变量挤在同一行）。线性化点（调用真正生效的那一瞬间）。位模式（内存里那串二进制值）。分配器（发放与回收堆地址的组件）。

## 未达标时怎么办

| 情况 | 动作 |
|:--|:--|
| K 组有 × | 只看对应小节的定义盒与「小结与常见错误」，再重做该节的即时自测 |
| S 组有 × | 回到[习题集](ch11_exercises.md#ch11-ex-pack)的最小练习包，做该节那道题 |
| A 组有 × | 重做[综合自测卷](ch11_exam.md#ch11-exam-p3)第三部分；再按[回忆卡](ch11_recall.md#ch11-recall-first)第三组练「只写第一行」 |
| 数字题反复错 | 先把[全章总结](ch11_summary.md)的十一节一览读一遍，确认每个数属于哪一节、什么口径 |
| 全部 ✓ | 进入[第十二章](ch12.md)；7 天后回来只重做标过 △ 的卡 |
