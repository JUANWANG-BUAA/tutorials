# 第11章 · 全章总结

这一页只回答一件事：**十一节各留下了什么可复用的结论。**推导、表格与实测都在正文，这里把每条压成一句能带走的句子。合上正文再读，读不下去的那一行就是断点。

三个词先对上：线性化点（一次调用真正生效的那一瞬间）、位模式（内存单元里那串二进制值）、代际（全体读者共用的年代编号）。

## 一条主线

**先定进度等级 → 再钉线性化点 → 再拆 ABA 的两根因果 → 再选回收机制 → 再量代价 → 最后守住驻留期。**

- 11.1 先划界：挂起测试决定一个实现够不够格叫无锁。
- 11.2 再定正确性：把每次调用收缩到一条原子指令上。
- 11.3 打开第一个危机：指针值相等，内存却可能已经换命。
- 11.4 给出两条回收流派：保护指针，还是保护一段时间。
- 11.5 下到地基：这些原子变量在缓存行上怎么摆。
- 11.6–11.7 上秤：同一份 21 批协议量吞吐与方差，再量一张旧门票的滞留账。
- 11.8–11.11 收尾：把同一原理放进内核与异步运行时检查边界，交代来源，留下可复验的出口。

这条线从「谁能前进」走到「谁占着闸门」。任何一环没走完，后面的数字都只是修辞。

## 能否讲出这几句话

不看书，用自己的话回答。答不上来的，回到对应小节只看那一段。

1. 有锁与无锁的分水岭落在哪一个测试上？为什么自旋锁连最弱一级都不满足？
2. 一个并发队列的入队线性化点在哪条指令上？为什么不是更新 `tail` 的那条？
3. ABA 的两问检验是什么？逻辑 ABA 与破坏性 ABA 的分界在哪一格？

5. 为什么 4096 个对象在停顿期间一个都释放不了？`drop(guard)` 之后为什么是集中爆发？
6. 一个 `.await` 撕掉了读者的哪三张承诺？为什么「版本号比对」替代不了驻留期？
