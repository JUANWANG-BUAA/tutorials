## 一条主线

**画访问图 → 立三层证明 → 钉进类型与布局 → 用产物核对指令 → 单变量对照测吞吐 → 交接路径看接口 → 归因停在证据层 → 换边界就重证。**

7.1–7.3 回答「谁能合法碰这块内存」。7.4 把语义承诺与指令选择分开。7.5 与 7.6 用两套对照，分别测共享写与交接路径。7.7 决定一条归因能推进到哪句。7.8 划出本章结论的边界。

任何一环跳过，后面的纳秒数都只是修辞。正确性没有证明，计时可能只是在测未定义行为。
