# 第十六章 · 学习目标自检表

每条目标给出**达标检验**（合上书写得出什么算达标）与**依据**（正文小节 + 习题编号）。逐条打勾：✓ 达标 / △ 部分 / × 未达标。△ 和 × 的条目按「依据」回看对应小节，不要整章重读。

**这张表按「能力类型」分组（K 知识 / S 技能 / A 应用），不按主线分组**——逐题的归堆已经在卷子里标好了，见[综合自测卷](ch16_exam.md)末尾的「每题落在主线哪一步」。两处都填时以卷子的表为准：它告诉你缺的是哪一步的习惯，本表告诉你哪一条目标没达标。

## 未达标时怎么办

| 情况 | 动作 |
|:--|:--|
| K 组有 × | 只看对应小节的定义盒与「小结与常见错误」，再重做该节的即时自测 |
| S 组有 × | 回到[习题集](ch16_exercises.md#ch16-ex-pack)的最小练习包，做该节那道题；S3、S6 要真的跑一遍命令 |
| A 组有 × | 重做[综合自测卷](ch16_exam.md)第三部分，然后按[回忆卡](ch16_recall.md)第三组练「只写第一行」 |
| 全部 ✓ | 7 天后回来只重做标过 △ 的卡，并用[全章总结](ch16_summary.md)核对十一节结论是否还能复述 |
