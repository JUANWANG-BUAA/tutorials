# 第17章 · 学习目标自检表

每条目标给出**达标检验**（合上书写得出什么算达标）与**依据**（正文小节或定义盒链接 + 习题集/自测卷题号）。逐条打勾：✓ 达标 / △ 部分 / × 未达标。△ 和 × 的条目按「依据」回看对应小节，不要整章重读。K 组管「说得出」，S 组管「做得出」，A 组管「换个场景还在」。

**这张表按「能力类型」分组（K 知识 / S 技能 / A 应用），不按主线分组**——逐题的归堆已经在卷子里标好了，见[综合自测卷](ch17_exam.md)末尾的「每题落在主线哪一步」。两处都填时以卷子的表为准：这一章四步都要交，卷子的归堆直接告诉你哪一步还缺证据。

## 未达标时怎么办

| 情况 | 动作 |
|:--|:--|
| K 组有 × | 只看对应小节的定义盒与「小结与常见错误」，再重做该节即时自测；K1–K2 的 × 优先，边界没写死时后面全白做 |
| S 组有 × | 回[习题集最小练习包](ch17_exercises.md#ch17-ex-pack)做该节那道实操题；S1 与 S4 是最常被面试追问的两项 |
| A 组有 × | 重做[综合自测卷](ch17_exam.md#ch17-exam-p3)第三部分，然后按[回忆卡第三组](ch17_recall.md)练「只写第一行」 |
| 全部 ✓ | 按[主干线与终极目标](../mainline.md)的十二问自查一遍，全部能指到证据位置，再把证据包骨架套到自己仓库的真实议题上 |
