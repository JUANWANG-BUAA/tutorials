# 第十三章 · 学习目标自检表

每条目标给出**达标检验**（合上书写得出什么算达标）与**依据**（正文小节 + 习题编号）。逐条打勾：✓ 达标 / △ 部分 / × 未达标。△ 与 × 按「依据」回看对应小节，不要整章重读。

**这张表按「能力类型」分组（K 知识 / S 技能 / A 应用），不按主线分组**——逐题的归堆已经在卷子里标好了，见[综合自测卷](ch13_exam.md)末尾的「每题落在主线哪一步」。两处都填时以卷子的表为准：它告诉你缺的是哪一步的习惯，本表告诉你哪一条目标没达标。

## 未达标时怎么办

| 情况 | 动作 |
|:--|:--|
| K 组有 × | 只看对应小节的定义盒与「小结与常见错误」，再重做该节的即时自测 |
| S 组有 × | 回到[习题集](ch13_exercises.md#ch13-ex-pack)的最小练习包，做该节那道实操题 |

| 全部 ✓ | 进入[第十四章](ch14.md)；7 天后回来只重做标过 △ 的卡 |
