# 学习目标（K / S / A）

按知识（K）、技能（S）、态度（A）三层列出。每条都能在正文中找到对应小节，学完相应章节后回到本页逐条自查；每章章末的自检表是本页的分章细化。

## 知识（K）：概念与结构，能闭卷复述

- **K1 处理器构成与两类指令集**：CISC 与 RISC 的取舍；ARM 的 Load/Store 结构、固定指令长度、条件执行（§2.1、§3.1）。
- **K2 Cortex-A9 微架构要素**：八级乱序超标量流水线、SCU 与 ACP 的分工、多级 Cache 与 VMSA（§2.3）。
- **K3 状态与模式**：ARM/Thumb 两种执行状态的切换条件；七种处理器模式按特权/异常的分层（§2.5、§2.6）。
- **K4 寄存器组织**：37 个寄存器的构成（31 通用 + 6 状态）、R0–R7 未分组、R8–R12 与 R13/R14 的分组规则、CPSR 各字段含义（§2.7、§2.8）。
- **K5 异常机制**：七种异常的入口向量、优先级、响应流程中硬件自动完成的四件事（§2.9）。
- **K6 存储器视角**：字节/半字/字与对齐；统一编址与存储器映射 I/O；大端与小端（§2.4、§2.11）。
- **K7 指令系统**：九种寻址方式；单寄存器与多寄存器 Load/Store；数据处理与桶形移位器；分支与状态切换；伪指令的作用（§3.2–§3.9）。
- **K8 RTOS 概念**：任务状态机、调度时延；非抢占与抢占内核的行为差异；RMS/EDF/LLF 的规则与适用条件（§4.6–§4.8）。
- **K9 通行机制**：信号量/互斥量/消息队列/邮箱/事件标志各自解决什么问题；时钟节拍的角色（§4.9、§4.10）。
- **K10 工程背景**：安全关键系统为何要 DO-178B/C 与 ARINC 653 分区；微内核思路；主流 RTOS 谱系（§4.1–§4.5）。

## 技能（S）：动笔能做

- **S1 读程序**：给十行左右的 ARM 汇编，跟踪寄存器与存储器变化，说出条件后缀与 S 后缀的影响（§3.5）。
- **S2 编码拆解**：给一条 32 位编码，拆出 cond/opcode/Rd/operand2 并还原为汇编（§3.1、§3.3）。
- **S3 推异常**：给定异常类型与现场，写出进入/退出时 CPSR、SPSR、LR、PC 的完整变化（§2.9）。
- **S4 判调度**：给周期任务集，用 RMS 可行界与 EDF 判定可调度性并排时间轴（§4.8）。
- **S5 选机制**：面对并发场景描述，选出合适的 IPC 机制并说明理由（§4.9）。
- **S6 换算与对齐**：数制转换、补码、对齐检查、大小端下逐字节写出存储内容（§2.4、§2.11）。

## 态度（A）：口径与习惯

- **A1 口径意识**：区分"ARM 体系结构规定"与"具体核的实现"（如 v7 规定与 Cortex-A9 实现的差异），答题时先说清口径。
- **A2 对照习惯**：结论以课件与 ARM 体系结构参考手册为准，营销口径（"每秒出货多少芯片"）不当技术事实用。
- **A3 安全视角**：读到"快一点、省一点"的优化时，先问实时性与故障行为是否仍然确定。
