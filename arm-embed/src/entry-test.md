# 入学诊断：你该从哪一章开始

十二道小题，覆盖三章各自的前置。**不查资料、十分钟内做完**，按错题定位起点；答对不代表可以跳读对应章，只说明前置够用。

## 数制与编码（第二章前置）

**Q1** 把 `0x2F` 写成十进制和二进制；再写出 −5 的 8 位补码。

**Q2** 一个 32 位字按小端存到 0x100（值为 0x12345678）。写地址 0x100、0x101、0x102、0x103 各自的字节值。

## 计算机组成（第二章前置）

**Q3** 取指、译码、执行、访存、回写——这五步分别做什么？流水线为什么能提高吞吐？

**Q4** "程序计数器 PC 存的是下一条指令的地址"——这句话对顺序执行成立吗？对刚执行完跳转指令呢？

## 汇编阅读（第三章前置）

**Q5** 下面三行 C 对应什么操作？不要求写出汇编，说明每行需要访存几次：`a = b + c; p = &a; *p = *p + 1;`（a、b、c、p 都是变量）

**Q6** ADD 与 MOV 的区别是什么？一条指令能不能既做加法又更新标志位？

## 程序与并发（第四章前置）

**Q7** 进程和线程的区别，用自己的话说两句。

**Q8** 两个线程都执行 `count = count + 1`（count 初值 0），各执行一次后 count 一定是 2 吗？为什么？

**Q9** 中断和系统调用的相同点与不同点各一条。

## 实时系统（第四章前置）

**Q10** "实时"等于"快"吗？举一个反例场景。

**Q11** 周期 10 ms、执行 3 ms 的任务，CPU 利用率是多少？两个这样的任务呢？

**Q12** 优先级反转说的是什么现象？（说不出没关系，§4.9 会讲——这题答不出可以直接进第四章。）

## 定位

| 错题分布 | 建议 |
|:--|:--|
| Q1–Q2 有错 | 先补数制与补码（任意组成原理教材第一章），再进第二章；§2.4、§2.11 有最小回顾 |
| Q3–Q4 有错 | 可进第二章，但 §2.3 流水线一节放慢读 |
| Q5–Q6 有错 | 可进第二章；第三章开读前把 Q5 想清楚——Load/Store 结构正是围绕它设计的 |
| Q7–Q9 有错 | 可进第二、三章；第四章开读前补进程/线程概念 |
| Q10–Q12 有错 | 不影响学习，第四章正是从这些问题讲起的 |

十二题全对：直接从[第二章导览](ch02/overview.md)开始，第三章前重做 Q5 确认手感。
