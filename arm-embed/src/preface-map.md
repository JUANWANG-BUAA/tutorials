# 全书知识地图

三章是一条链：体系结构给出寄存器与异常这套"硬件接口"，指令集是操作这套接口的语言，操作系统用这套语言把多个任务装进一个核。下图从左到右是依赖方向——箭头右侧的内容要用到左侧的结论。

```
第二章 体系结构                第三章 指令集                 第四章 操作系统
─────────────────────      ─────────────────────      ─────────────────────
RISC取舍·Load/Store   ──►   寻址方式(9种)          ──►  任务切换=保恢复寄存器
七种处理器模式        ──►   SWI/MSR 访问CPSR      ──►  特权级·系统调用
37寄存器·分组R13/R14  ──►   LDM/STM·栈类型FD等    ──►  上下文切换·任务栈
CPSR/SPSR·I/F位      ──►   条件域cond·S后缀       ──►  中断管理·开关中断
异常向量·优先级       ──►   分支B/BL/BX           ──►  调度点·抢占时机
存储器映射I/O·大小端 ──►   LDR/STR外设访问        ──►  时钟节拍·设备驱动
```

## 每章内部的脉络

**第二章**先外围后核心：2.1–2.3 讲清"ARM 是什么、核里有什么"；2.4–2.8 逐层进入程序员模型（数据类型 → 状态 → 模式 → 寄存器 → 状态寄存器）；2.9–2.11 是这套模型的三块应用（异常、复位、存储器视角）。前向依赖最强的是 **2.6–2.8**：讲异常、讲调度都要回到模式与 CPSR。

**第三章**两条线并行：一条按指令功能分类（存储器访问 → 数据处理 → 乘法 → 分支 → 杂项 → 伪指令），一条按编码结构贯穿（cond 域 → operand2 与立即数 → 寻址方式组合）。**3.2 寻址方式**是全章地基，后面每类指令都只是"操作码 × 寻址方式"的组合。

**第四章**从"为什么要 RTOS"进入：4.1–4.5 是动机与谱系（安全关键 → 标准 → 选型），4.6–4.12 是机制内核（任务模型 → 调度 → 通信 → 中断时钟 → 内存 → 实时化 Linux）。考卷重心通常落在 **4.7–4.9**。

## 复习时的走法

- **正着走**（第一遍）：按章顺序读，每章末做回忆卡。
- **倒着走**（第二遍）：从速查卡的任意一张表出发，问"这张表背后是哪节的机制"，跳回去重读。比如从"异常向量表"跳回 §2.9，再跳到 §3.8 的 SWI——软中断就是人为制造的一次异常。
- **跨章走**（考前）：挑三条纵线各走一遍——①一次 IRQ 从发生到返回经过了哪些寄存器（2.8→2.9→4.10）；②一条 LDR 从编码到数据到达（3.1→3.2→3.3→2.11）；③三个任务从创建到调度运行（4.6→4.7→4.8→4.9）。
