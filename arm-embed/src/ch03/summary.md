# 第三章总结

本章讲 ARM 的语言。骨架是：**格式与条件（3.1）→ 寻址（3.2）→ 六族指令（3.3–3.8）→ 伪指令（3.9）→ Thumb 与汇编程序（3.10–3.11）**。考前把下面四张表过一遍。

## 表一：指令格式与条件码

`<opcode>{<cond>}{S} Rd, Rn{, operand2}`；cond 缺省 AL。

| 类别 | 条件码 | 判据 |
|:--|:--|:--|
| 相等 | EQ / NE | Z=1 / Z=0 |
| 无符号 | HS(CS) / LO(CC) / HI / LS | C=1 / C=0 / C=1且Z=0 / C=0或Z=1 |
| 有符号 | MI / PL | N=1 / N=0 |
| 有符号大小 | GE / LT / GT / LE | N=V / N≠V / Z=0且N=V / Z=1或N≠V |
| 溢出 | VS / VC | V=1 / V=0 |
| 其他 | AL / NV | 无条件 / 不用 |

（3.1.2）

## 表二：operand2 三形态

| 形态 | 例 | 要点 |
|:--|:--|:--|
| 立即数 | `#0x0F` | 8 位循环右移偶数位；装不下用 MVN 或 LDR= |
| 寄存器 | `R2` | —— |
| 寄存器移位 | `R2, LSL #3` | LSL/LSR/ASR/ROR/RRX，桶形移位器，不耗时 |

（3.1.3、3.2.4–3.2.5）

## 表三：六大指令族

| 族 | 代表 | 关键约束 |
|:--|:--|:--|
| 单寄存器访存 | LDR/STR/LDRB/LDRSB/LDRH/LDRSH | B/H 定宽度、S 定扩展、T 定权限；字 4 字节对齐、半字偶地址 |
| 多寄存器访存 | LDM/STM | 8 模式（IA/IB/DA/DB ↔ FD/ED/FA/EA）；FD=DB |
| 数据处理 | MOV/MVN/ADD/SUB/RSB/ADC/SBC/RSC/AND/ORR/EOR/BIC | 只碰寄存器；比较类（CMP/CMN/TST/TEQ）不存结果 |
| 乘法 | MUL/MLA/UMULL/UMLAL/SMULL/SMLAL | Rd≠Rm（32 位）；64 位三寄存器互异；只保证 NZ |
| 分支 | B/BL/BX | BL 存返回地址到 LR；BX 用 Rm[0] 切状态 |
| 杂项 | SWI/MRS/MSR | SWI 进 svc；MSR 必须带域掩码（c/x/s/f） |

（3.3–3.8）

## 表四：四种索引形态

| 写法 | 有效地址 | 基址回写 |
|:--|:--|:--|
| `[Rn]` | Rn | 否 |
| `[Rn,#off]!` | Rn+off | 是（访存前） |
| `[Rn],#off` | Rn | 是（访存后） |
| `[Rn,Rm,LSL #2]` | Rn+Rm×4 | 否 |

（3.2.3、3.3.3）

## 三个一秒判断

1. 立即数合法性：8 位窗口能装下所有 1 吗？装不下先想 MVN。
2. `LDR Rd,[Rn],#off` 与 `LDR Rd,[Rn,#off]!` 差在"先后"，不是差在"加不减"。
3. `^` 只在含 PC 的 LDM 上有特殊含义（异常返回）。

## 衔接

第四章会大量用到本章的三处机制：**上下文切换**要压栈/出栈（STMFD/LDMFD，3.4.3）；**系统调用**靠 SWI（3.8.2）；**关中断/开中断**靠 MRS+MSR（3.8.5）。上一章的分组寄存器（2.7）在这里变成 R13/R14 的栈与返回地址。
