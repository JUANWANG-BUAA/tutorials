# 勘误与补注（对照课件）

记录《第 3 章 ARM 指令集》课件与通用口径的差异。编号 #3-n；"已核"表示对照过课件原文。处理原则：正文按考纲口径书写，课件原文如实转述于此。

## 已核实的课件笔误

::: errata #3-1 基址寻址示例中操作数写错（Slide 13）
课件给出：`STR R1,[R0,R2]!    ; R0=R0+R2, [R0]<-R1` 与 `STR R1,[R0,R2] ; [R0+R1]<-R1`。
后一条注释应为 `[R0+R2]←R1`（操作数是 R2 不是 R1）。此外，`[R0,R2]!` 属**后索引**（先访存后回写），课件注释 "R0=R0+R2" 未说明先后；按 3.2.3 的口径，该写法是"先以 R0 为地址访存，再 R0←R0+R2"。
:::

::: errata #3-2 前索引/后索引示例中基址变化描述含糊（Slide 14）
课件：
```
LDR R0,[R1,#4]      ;R1=[R1＋4]，R0＝[R1]    ;前索引基址寻址
LDR R0,[R1,#4] !     ;R1=[R1＋4]，R0＝[R1]    ;前索引基址寻址
```
两条注释完全相同，**但只有带 `!` 的那条会回写 R1**。第一条（无 `!`）R1 不变，R0←[R1+4]。正文按 3.2.3 表列区分。
:::

::: errata #3-3 BL 返回地址记法与版本相关（Slide 102、104）
课件操作表写 `BL: LR←PC-4`，正文描述为"下一条指令的地址"。二者对 **ARMv5 及以后**是一致的（执行 BL 时 PC 读值 = 当前+8，故 LR = 当前+4 = 下一条）；但 **ARMv4 口径**下 BL 存的是"当前指令地址+8"，返回时需再减 4。遇到考题问 LR 具体值时，先确认课程采用的版本口径；本教程按课件的"下一条指令地址"书写。
:::

::: errata #3-4 栈模式与数据块模式的对照表有重复项（Slide 60）
课件表：
```
数据块传送存储 | 栈操作压栈 | 说明     | 数据块传送加载 | 栈操作出栈 | 说明
STMDA | STMED | 空递减      | LDMDA | LDMFA | 满递减
STMIA | STMEA | 空递增      | LDMIA | LDMFD | 满递增
STMDB | STMFD | 满递减      | LDMDB | LDMEA | 空递减
STMIB | STMFA | 满递增      | LDMIB | LDMED | 空递增
```
左半部分两行"说明"栏写的是**栈**类型（空递减/空递增），右半部分写的也是栈类型，但**加载侧的 FD 满递减与存储侧的 FD 满递减对应的数据块模式不同**（LDMFD 满递减 ≡ LDMDB，STMFD 满递减 ≡ STMDB）——课件表中"LDMDA | LDMFA | 满递减"一行把 LDMFA（满递增）与说明"满递减"混在一起，是排版错误。**通用对应关系是：FD=DB、ED=DA、FA=IB、EA=IA**（与 3.4.2 表格一致），正文按此书写。
:::

::: errata #3-5 立即数合法例 0x104 的说明（Slide 30–31）
课件把 0x104 列为合法立即数，并展示"0x12 循环右移 10 位"等构造图。0x104 可写成 8 位数 0x41 循环右移 2 位得到（0x41 = 0100_0001 → ROR 2 = 0x00000104），合法。课件构造图里的具体位数与示例位图不完全对应，属讲义图示问题，**结论（合法/非法清单）无误**。
:::

## 口径澄清（非笔误）

::: note #3-6 "37 个寄存器"与 A9 的 42 个
见第二章勘误 #2-7。本章不涉及寄存器总数，但 3.11.5 的预定义别名表里 R0–R15 是完整 16 个通用编号，注意其中 R9–R12 的 ATPCS 别名（SB/SL/FP/IP）。
:::

::: note #3-7 Thumb 与 T32
课件在 Slide 5 提到"16 位 Thumb 指令集（T32）"。严格说 **T32 指 Thumb-2 的 32 位指令形式**，而 Thumb-2 是 16/32 位混合集。正文按"Thumb 状态可执行 16 位 Thumb 与（Thumb-2 中的）32 位 Thumb 指令"表述，避免把 Thumb-2 等同于纯 16 位。
:::

::: note #3-8 SWI 处理程序中 LR 的偏移
Slide 111 的 SWI_Handler 用 `LDRNEH R0,[LR,#-2]`（Thumb）与 `LDREQ R0,[LR,#-4]`（ARM）取指令码。依据是 SWI 的 LR = 下一条指令地址（3.8.3）。若按 ARMv4 旧口径（LR = 当前+8）则偏移应为 −4/−8，**这里正好与课件现行口径自洽**。
:::
