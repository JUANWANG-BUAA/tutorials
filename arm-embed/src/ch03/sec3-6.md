# 3.6 乘法指令

加法一条指令就能做完，乘法在早期 ARM 上要多个周期——所以它有独立的六条指令、独立的编码空间、独立的限制。本节讲清三件套：32 位乘/乘加、64 位积怎么装进两个寄存器、以及那串"不能用 R15""Rd ≠ Rm"的规矩从哪来。（课件 Slide 90–98）

## 3.6.1 六条乘法指令总表

| 助记符 | 说明 | 操作 | 限制 |
|:--|:--|:--|:--|
| **MUL** | 32 位乘法 | Rd ← Rm × Rs（取低 32 位） | Rd ≠ Rm |
| **MLA** | 32 位乘加 | Rd ← Rm × Rs + Rn | Rd ≠ Rm |
| **UMULL** | 64 位无符号乘 | (RdHi,RdLo) ← Rm × Rs | RdLo/Hi、Rm、Rs 互不相同 |
| **UMLAL** | 64 位无符号乘加 | (RdHi,RdLo) ← Rm×Rs + (RdHi,RdLo) | 同上 |
| **SMULL** | 64 位有符号乘 | (RdHi,RdLo) ← Rm × Rs | 同上 |
| **SMLAL** | 64 位有符号乘加 | (RdHi,RdLo) ← Rm×Rs + (RdHi,RdLo) | 同上 |

命名规则好记：**U/S = 无符号/有符号**，**MUL/MLAL = 乘/乘加**，**带 L（Long）= 64 位结果**。

## 3.6.2 32 位：MUL 与 MLA

```asm
MUL{cond}{S}  Rd, Rm, Rs        ; Rd ← Rm × Rs
MLA{cond}{S}  Rd, Rm, Rs, Rn    ; Rd ← Rm × Rs + Rn
```

```asm
MUL   R1, R2, R3      ; R1 = R2 × R3
MULS  R0, R3, R7      ; R0 = R3 × R7，影响 N、Z
MLA   R1, R2, R3, R0  ; R1 = R2×R3 + R0
```

约束与副作用：

- **Rd、Rm、Rs 不能为 R15**；
- **Rd 不能与 Rm 相同**（编码字段重叠所致）——`MUL R2,R2,R3` 非法，要写成 `MUL R1,R2,R3` 再 `MOV R2,R1`；
- 带 S 时**只影响 N 和 Z，不影响 V，C 不确定**。

"只影响 NZ、C 不确定"是 ARM 乘法的历史遗留：乘法器是独立单元，进位链与 ALU 不同，硬件干脆不保证 C。写多字长乘法时不要依赖 MUL 之后的 C。

## 3.6.3 64 位：结果装进两个寄存器

两个 32 位数相乘，积最大 64 位，必须占**两个寄存器**：**RdLo 装低 32 位、RdHi 装高 32 位**。

```asm
UMULL  R0, R1, R5, R8    ; (R1:R0) = R5 × R8（无符号）
SMULL  R2, R3, R7, R6    ; (R3:R2) = R7 × R6（有符号）
UMLAL  R0, R1, R5, R8    ; (R1:R0) = R5×R8 + (R1:R0)
SMLAL  R2, R3, R7, R6    ; (R3:R2) = R7×R6 + (R3:R2)
```

**"乘加"在这里的含义**：把 64 位积加到**已有的 64 位数** (RdHi,RdLo) 上——这正是"累加"（accumulate）的语义，做多精度乘法的内层循环时非常省事。

约束（比 32 位更严）：

- RdLo/RdHi、Rm、Rs **都不能为 R15**；
- **RdLo、RdHi、Rm 必须互不相同**（Rs 可与其它重复？课件原话是"RdLo/Hi，Rm 必须是不同的寄存器"——即这三个互异，Rs 不受此限）；
- 同样只影响 N/Z，C 与 V 不确定。

::: ex 例 3.6.1 · 为什么无符号与有符号要分开 {#ex-3.6.1}
Rm = 0xFFFFFFFF（作无符号是 4294967295，作有符号是 −1），Rs = 2：

| 指令 | 结果 (RdHi:RdLo) | 解读 |
|:--|:--|:--|
| `UMULL` | 0x00000001_FFFFFFFE | 4294967295×2 = 8589934590 |
| `SMULL` | 0xFFFFFFFF_FFFFFFFE | −1×2 = −2（64 位补码） |

同一组位模式、两种解释，结果天差地别。**选择 UMULL 还是 SMULL，取决于你把操作数当什么类型**——这和 3.3 的 LDRB/LDRSB 是同一个哲学：硬件不猜类型，后缀替你说。
:::

## 本节小结

乘法六条：32 位（MUL/MLA）与 64 位（U/S + MULL/MLAL）各三条；64 位积的低半在 RdLo、高半在 RdHi；Rd ≠ Rm（32 位）与三寄存器互异（64 位）是编码硬约束；乘法只保证 N/Z。下一节跳出数据通路，讲"程序怎么拐弯"——分支指令。
