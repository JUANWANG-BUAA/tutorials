# 3.3 存储器访问指令：单寄存器加载与存储

Load/Store 结构（2.1.2）规定只有加载、存储、交换三类指令能碰存储器。这一族里最常用的是单寄存器 LDR/STR：一条指令一次搬运 1/2/4 字节，外加一整套地址偏移写法。本节把后缀系统与四种偏移格式讲透——考试里读程序题的一大半都在这。（课件 Slide 43–54）

## 3.3.1 为什么单独一族

ARM 是典型 RISC：存储器访问只能由加载、交换、存储指令完成。ARM7 这类核是冯·诺依曼结构、RAM 与 I/O 统一编址——**除了 RAM，对外围 I/O 与程序数据的访问也全走 LDR/STR**（2.11.2 的 MMIO 就靠它）。存储器访问指令分两类：**单寄存器**（本节）与**多寄存器**（3.4）。

## 3.3.2 加载族与存储族的后缀表

**加载（LDR）**：

| 助记符 | 说明 | 操作 |
|:--|:--|:--|
| **LDR** | 加载字数据 | Rd ← [addr]（32 位） |
| **LDRB** | 加载**无符号字节** | Rd ← [addr] 的 8 位，高 24 位**清零** |
| **LDRT** | 以**用户模式**加载字 | 同上，但权限按用户态 |
| **LDRBT** | 以用户模式加载无符号字节 | 同上 |
| **LDRH** | 加载**无符号半字** | 16 位，高 16 位清零 |
| **LDRSB** | 加载**有符号字节** | 8 位，高 24 位**符号扩展** |
| **LDRSH** | 加载**有符号半字** | 16 位，高 16 位符号扩展 |

**存储（STR）**：

| 助记符 | 说明 | 操作 |
|:--|:--|:--|
| **STR** | 存储字 | [addr] ← Rd（32 位） |
| **STRB** | 存储字节 | [addr] ← Rd 最低有效字节 |
| **STRT** | 以用户模式存储字 | 同上，权限按用户态 |
| **STRBT** | 以用户模式存储字节 | 同上 |
| **STRH** | 存储半字 | [addr] ← Rd 低 16 位 |

读后缀的次序是**"宽度 + 符号 + 特权"**三件事的组合：

- **B / H**：字节 / 半字（无后缀 = 字）；
- **S**（只在加载有）：符号扩展——有符号字节、半字加载；
- **T**：以用户模式访问（特权模式下也当作 usr 权限——给操作系统访问用户空间用）。

::: note T 后缀的两条限制（课件明说）
T 在用户模式下无效；**不能与前索引偏移一起使用 T**。原因是编码：T 用了位 21，与回写位 W 重叠。
:::

**符号扩展 vs 零扩展**是全节最易错的一点，用一句话钉住：**"B/H"给宽度，"S"决定高位怎么补**。LDRB 零扩展、LDRSB 符号扩展；LDRH 零扩展、LDRSH 符号扩展。对照 C 语言：`unsigned char` 用 LDRB，`signed char` 用 LDRSB。

::: ex 例 3.3.1 · 同一字节，两种扩展 {#ex-3.3.1}
地址 0x400 处字节为 **0xF5**（即 −11 的补码）。

| 指令 | Rd 结果 | 说明 |
|:--|:--|:--|
| `LDRB R0,[R1]`（R1=0x400） | 0x000000F5 | 高 24 位清零 |
| `LDRSB R0,[R1]` | 0xFFFFFFF5 | 高 24 位补 1（符号位为 1） |

若把 0xF5 当无符号数（245）用 LDRSB 读，得到的是 −11——一个真实的 bug 现场：串口收到的字节 0xF5 用有符号类型读，数值全错。
:::

## 3.3.3 四种偏移格式

从地址计算方式分，加载/存储有四种格式：

| 格式 | 写法 | 说明 |
|:--|:--|:--|
| **零偏移** | `LDR Rd,[Rn]` | 地址 = Rn |
| **前索引偏移** | `LDR Rd,[Rn,#0x04]!` | 先算 Rn+4，访存，回写 Rn（不带 `!` 则不回写） |
| **程序相对偏移** | `LDR Rd,label` | 地址 = PC ± 偏移（伪指令 LDR= 的落点，见 3.9.3） |
| **后索引偏移** | `LDR Rd,[Rn],#-0x04` | 先用 Rn 访存，再 Rn←Rn−4 |

偏移量的三种形态（与 3.2.3 一致）：

```asm
LDR   R1, [R0, #0x12]        ; 立即数：R1 ← [R0+0x12]
LDR   R1, [R0, R2]           ; 寄存器：R1 ← [R0+R2]
LDR   R1, [R0, -R2]          ; 寄存器减：R1 ← [R0−R2]
LDR   R1, [R0, R2, LSL #2]   ; 寄存器移位：R1 ← [R0+R2<<2]（数组下标×4）
```

最后一行是数组访问的标准写法：基址 = 数组首地址，R2 = 下标，`LSL #2` 把下标乘 4 变成字节偏移。

::: note 对齐是硬约束
**字数据操作的地址必须 32 位对齐（4 的倍数）；半字地址必须为偶数**（2.4）。"半字读写的指定地址必须为偶数，否则产生不可靠结果"是课件原话；对齐检查开启时，非对齐访问直接触发**数据中止**异常（2.9.1）。
:::

## 3.3.4 编码字段的含义

LDR/STR（字与无符号字节）的 32 位编码字段，读汇编题时按这几位反推：

| 字段 | 含义 |
|:--|:--|
| cond | 执行条件 |
| **I** | 0：偏移是 12 位立即数；1：偏移是寄存器（可带移位） |
| **P** | 1 = 前变址（前索引），0 = 后变址 |
| **U** | 1 = 加，0 = 减 |
| **B** | 1 = 字节访问，0 = 字访问 |
| **W** | 1 = 回写（write-back） |
| **L** | 1 = 加载（LDR），0 = 存储（STR） |
| Rn | 基址寄存器 |
| Rd | 源 / 目标寄存器 |

**P 与 W 的组合**决定四种索引：P=1,W=0 零偏移或前索引不回写；P=1,W=1 前索引回写；**P=0,W=1 后索引**（后索引必须 W=1）；P=0,W=0 保留。

半字与有符号字节家族（LDRH/LDRSB/LDRSH/STRH）是**另一套编码**：立即数偏移只有 **8 位**（不是 12 位），多出的编码位用于 **S**（1=有符号）与 **H**（1=半字，0=字节）：

| 字段 | 含义 |
|:--|:--|
| I | 0：8 位立即数偏移；1：寄存器偏移 |
| P / U / W | 同前 |
| **S** | 1 = 有符号访问（LDRSB/LDRSH） |
| **H** | 1 = 半字，0 = 字节 |
| L / Rd / Rn | 同前 |

所以"半字立即数偏移只有 256 可选"——这是两套编码并存的代价。

## 3.3.5 LDR 的两个特殊用法

**① LDR 到 PC = 跳转（程序散转）**。`LDR PC, [R0, R1, LSL #2]` 一类写法把跳转表地址算出来后直接装入 PC——一次完成"查表 + 跳转"，散转（switch 语句）的标准实现。

**② 双字 LDRD/STRD（64 位）**：一次搬两个相邻寄存器到相邻地址。规则（课件口径）：

```asm
LDRD  R6, [R11]        ; R6←[R11]，R7←[R11+4]
STRD  R4, [R9, #24]    ; R4→[R9+24]，R5→[R9+28]
```

- 另一个寄存器固定是 **Rd+1**；Rd 必须是**偶数**且**不是 R14**；
- Rn 一般不允许与 Rd/Rd+1 相同（零偏移或不带写回的前索引除外）；
- `label` 形式要求在当前指令 ±252 字节内。

## 3.3.6 示例串讲

课件的示例值得逐条读，注意每条的后缀与索引形态：

```asm
LDR   R2, [R5]               ; 字加载，零偏移
STR   R1, [R0, #0x04]        ; 字存储，前索引不回写
LDRB  R3, [R2], #-1          ; 字节零扩展加载，后索引：R2←R2−1
STRB  R0, [R3, -R8, ASR #2]  ; 存 R0 最低字节到 [R3 − R8/4]
LDRSB R1, [R0, R3]           ; 有符号字节加载，高 24 位符号扩展
LDRH  R6, [R2], #2           ; 半字零扩展加载，读出后 R2←R2+2
STRH  R1, [R0, #2]!          ; 存半字到 R0+2（只改低 2 字节），R0←R0+2
```

第三行 `[R2],#-1` 是"读字节、指针回退 1"——倒序扫描缓冲区的典型写法。第六行 `!` 在括号外：先写存储器，再把 R0 前移 2。

## 本节小结

LDR/STR = 宽度（B/H）+ 符号（S）+ 特权（T）+ 地址（零偏移/前索引/后索引/PC 相对）；**B/H 定宽度、S 定高位怎么补**；P/W 编码位决定索引形态；LDR 到 PC 即散转。下一节把这套地址写法扩展到"一次搬一排寄存器"。
