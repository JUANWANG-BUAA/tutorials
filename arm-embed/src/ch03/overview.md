# 第三章 · ARM 指令集

## 同一个"加一"，硬件为什么要看半个字节？

一条 32 位指令里，装得下一条完整动作——但也只够装一件事：或者"把数加上去"，或者"把结果写回"，或者"更新标志"。ARM 把这 32 位切得极细：4 位管"什么时候执行"，1 位管"要不要更新标志"，其余分段管寄存器编号、操作码与第二操作数。读懂了这套切法，你就读懂了本章所有指令——它们只是同一套字段的不同填法。

本教程依据《第 3 章 ARM 指令集》课件（2026 秋季，157 页）整理扩充。课件目录为三大块（寻址方式 / 指令集 / 汇编语言），本教程重排为十一节：把"指令格式与条件码"提前独立成节（3.1），寻址方式成节（3.2），随后按功能族展开（3.3–3.9），Thumb 与互操作收尾（3.10），最后补课件第三块"ARM 汇编程序设计"（3.11）。

## 读法建议

3.1–3.2 是全章的语法课，务必先过关：条件域那 16 行表要能默写，立即数的"8 位循环右移偶数位"要能判别任意常数合法与否。3.3–3.8 是六大功能族，读法与第二章相反——第二章自上而下（先模式后指令），本章自下而上：每类指令先记**格式与限制**（哪些寄存器不能写、偏移多大），再读示例，最后合上书默写两个自己想的例子。

考试重心通常在：条件码与标志的配合（3.1）、LDR/STR 前后索引与回写（3.3）、LDM/STM 八模式与栈（3.4）、SWI 与 MSR 域（3.8）。3.9–3.10 偏理解型，但要能解释"伪指令不是指令"和"BX 为什么能切状态"。

第二章的机制在本章全部落地：条件域读 CPSR 的 NZCV（2.8）、SWI 就是制造一次异常（2.9）、LDM^ 是异常返回的载体（2.9）、BX 的最低位切换状态（2.5）。读本章时每遇到这四处，翻回第二章对照一遍，两章就焊死了。
