# 3.2 寻址方式

同一条 `LDR R0, ...` 后面跟着不同的括号写法，硬件去的地方完全不同：`[R1]` 取 R1 指向的单元，`[R1,#4]` 取 R1+4 处的单元，`[R1],#4` 取完还给 R1 加上 4。寻址方式回答的就是"**真实操作数地址怎么算出来**"。ARM 共九种，是本章的地基。（课件 Slide 8–23、30–37）

## 3.2.1 定义与九种方式总表

**寻址方式**：根据指令中给出的地址码字段，计算真实操作数地址的方式。

| # | 方式 | 一句话 | 例 |
|:--|:--|:--|:--|
| 1 | 寄存器寻址 | 操作数在寄存器里 | `MOV R1,R2` |
| 2 | 立即寻址 | 操作数就在指令里 | `MOV R0,#0xFF00` |
| 3 | 寄存器移位寻址 | Rm 先移位再参与 | `MOV R0,R2,LSL #3` |
| 4 | 寄存器间接寻址 | 寄存器里存的是**地址** | `LDR R0,[R2]` |
| 5 | 基址寻址 | 基址寄存器 ± 偏移 | `LDR R2,[R3,#0x0C]` |
| 6 | 多寄存器寻址 | 一次搬多个寄存器 | `LDMIA R1!,{R2-R7,R12}` |
| 7 | 栈寻址 | SP 隐含指向栈顶 | `STMFD SP!,{R0-R3,LR}` |
| 8 | 块拷贝寻址 | 存储器块 ↔ 寄存器组 | `STMIA R0!,{R1-R7}` |
| 9 | 相对寻址 | PC 作基准 + 偏移 | `BL SUBR1`、`BEQ LOOP` |

## 3.2.2 前四种：寄存器、立即、移位、间接

**寄存器寻址**：地址码字段是寄存器编号，执行时直接取该寄存器的值。`MOV R1,R2`（R1←R2）、`SUB R0,R1,R2`（R0←R1−R2）。

**立即寻址**：操作数本身就在指令编码里（称"立即数"），取出指令就取出了操作数。`SUBS R0,R0,#1`（R0 减 1 并影响标志）、`MOV R0,#0xFF000`。

**寄存器移位寻址**：ARM 特有。第二操作数是"寄存器 + 移位"时，先移位、再与第一操作数结合；**移位不占额外时间**。`MOV R0,R2,LSL #3`（R0=R2×8）、`ANDS R1,R1,R2,LSL R3`（R2 左移 R3 位后与 R1 相与）。

**寄存器间接寻址**：寄存器里装的是**地址**，真正的操作数在那个地址的存储器单元里——"寄存器作地址指针"。`LDR R1,[R2]`（读 R2 指向的单元）、`SWP R1,R1,[R2]`（R1 与该单元互换）。这是 Load/Store 结构下访问存储器的最基本形态。

## 3.2.3 基址寻址：前索引与后索引

**基址寻址**：基址寄存器内容 ± 偏移量 = 有效地址，常用于查表、数组、外设寄存器访问。偏移可以是**立即数**（课件口径 <4K，即 12 位无符号）或**寄存器**（基址加索引）；**寄存器间接寻址是偏移量为 0 的基址寻址**。

四种书写形态，必须分清"什么时候更新基址"：

| 写法 | 名称 | 有效地址 | 基址回写 |
|:--|:--|:--|:--|
| `LDR R0,[R1,#4]` | 零偏移 / 前索引（不回写） | R1+4 | 否 |
| `LDR R0,[R1,#4]!` | 前索引（回写） | R1+4 | **是**：R1←R1+4 |
| `LDR R0,[R1],#4` | **后索引** | R1 | **是**：R1←R1+4（访存之后） |
| `LDR R0,[R1],R2` | 后索引（寄存器偏移） | R1 | 是：R1←R1+R2 |

{{#include ../assets/figures/arm-instruction.md}}

`!` 是"回写"（write-back）标记。前索引 = 先算地址再访存（地址参与回写）；后索引 = 先用当前地址访存、事后再把基址挪一格。课件的形容很到位——**这种自动索引机制不消耗额外时间**，所以"遍历数组"不需要单独的 ADD：
```asm
        LDR   R1, =array
        MOV   R2, #0
loop    LDR   R0, [R1], #4     ; 取一个字，R1 自动前进 4
        ADD   R2, R2, R0
        CMP   R0, #0
        BNE   loop
```

::: ex 例 3.2.1 · 四条指令，四个不同的 R1 {#ex-3.2.1}
设 R1 = 0x40000000，[0x40000000]=0x11，[0x40000004]=0x22。

| 指令 | R0 | R1（执行后） |
|:--|:--|:--|
| `LDR R0,[R1,#4]` | 0x22 | 0x40000000（不变） |
| `LDR R0,[R1,#4]!` | 0x22 | 0x40000004 |
| `LDR R0,[R1],#4` | 0x11 | 0x40000004 |
| `STR R1,[R0,#-4]!` | — | 先 R0←R0−4，再把 R1 存入 [R0] |

注意第三个：读的是**旧地址**的内容，读完才挪指针——这就是"后"索引的含义。
:::

## 3.2.4 立即数的构造：8 位循环右移偶数位

`#immed_8r` 只能装下 8 位，却要覆盖常用常数。ARM 的解法：**一个 8 位常数循环右移偶数位**（0、2、4、…、30）得到 32 位数。32 位里选 8 位、移位量 16 种选择，共约 $16 \times 256 = 4096$ 个可表示常数。

判别法（手算）：把目标数写成 32 位二进制，若**所有为 1 的位能落在一个 8 位连续窗口内（窗口边界按 2 位对齐）**，就合法。

| 常数 | 判定 | 为什么 |
|:--|:--|:--|
| 0xff | ✓ | 8 位窗口 [7:0] |
| 0x104 | ✓ | 二进制 1_0000_0100，1 跨 9 位？→ 实为 0x41 循环右移 2 位（0x41=0100_0001 → ROR 2 = 0x104）✓ |
| 0xff00 | ✓ | 0xff ROR 24 |
| 0xff000000 | ✓ | 0xff ROL 24（即 ROR 8） |
| 0x101 | ✗ | 1 分散在两端（bit 8 与 bit 0，跨度 9 位），任何 8 位窗口都装不下 |
| 0x102 | ✗ | 同上 |
| 0xff1 | ✗ | 需 12 位窗口 |
| 0xffffffff | ✗ | 需要 32 个 1；但可用 `MVN R0,#0` 得到 |

装不下怎么办？用 **MVN（取反装载）**绕：`0xFFFFFFFE` 不是合法立即数，但它的反码 0x1 是——`MVN R1,#0x1`。再不行，就让**伪指令 LDR =** 交给汇编器往文字池里放（3.9.3）。

::: note 立即数合法性的"±边界"
课件的合法例包含 0x104：写成 8 位循环右移时它有多种等价表述（0x41 ROR 2 与 0x104 本身），汇编器接受任一合法构造。手算时抓住"1 是否聚在一个 8 位窗口内"即可，不必真去凑移位量。
:::

## 3.2.5 桶形移位器

寄存器移位寻址能"不占额外时间"，靠的是 ALU 前一级的**桶形移位器（barrel shifter）**：

```
        Rm ──►[ 桶形移位器 ]──►┐
        Rn ──────────────────►[ ALU ]──► 结果 Rd
```

五种移位（`Y` 为移位量，可立即数 #0–31 或寄存器 Rs）：

| 助记符 | 说明 | 结果 | Y 取值 |
|:--|:--|:--|:--|
| **LSL** | 逻辑左移 | `x << y` | #0–31 或 Rs |
| **LSR** | 逻辑右移 | `(unsigned)x >> y` | #1–32 或 Rs |
| **ASR** | 算术右移 | `(signed)x >> y`（符号位补入） | #1–32 或 Rs |
| **ROR** | 循环右移 | `(x>>y) \| (x<<(32-y))` | #1–32 或 Rs |
| **RRX** | 带扩展循环右移 1 位 | `(C<<31) \| (x>>1)` | 无（固定 1 位） |

注意 LSL 的 Y 可以为 0（不移），LSR/ASR/ROR 从 1 起；LSR 的 32 表示"全移出得 0"。RRX 借 CPSR 的 C 位参与，是唯一"吃标志"的移位——多用于多字长数的逐位右移（配合 ADC/SBC 做 64/128 位运算）。

## 3.2.6 多寄存器、栈、块拷贝、相对

后四种方式都涉及"一次多个访问"或"PC 参与算地址"，放在 3.4（多寄存器与栈）与 3.7（分支与相对寻址）展开，这里先给定位：

- **多寄存器寻址**：一条指令搬运 16 个寄存器的任意子集，`LDMIA R1!,{R2-R7,R12}`；
- **栈寻址**：SP（R13）隐含为指针，按满/空 × 递增/递减分四型，`STMFD SP!,{R0-R3,LR}`；
- **块拷贝寻址**：存储器连续块 ↔ 寄存器组，`STMIA R0!,{R1-R7}`；
- **相对寻址**：PC 提供基准 + 指令中的偏移，**主要用于 B/BL 跳转**——跳转目标是"当前 PC ± 偏移"，所以位置无关代码（PIC）天然成立。

## 本节小结

九种寻址方式里，前五种是"单操作数怎么找"，后四种是"一把搬多个"或"PC 参战"。做题时两个高频陷阱：立即数合法性（8 位窗口判别）、前后索引与回写（`!` 与逗号位置）。下一节把其中最常用的 LDR/STR 家族完整铺开。
