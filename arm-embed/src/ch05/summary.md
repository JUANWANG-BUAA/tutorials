# 第五章总结

本章是延伸阅读，主线只有一条：**AArch64 为了 64 位与可维护性，把 AArch32 的机制几乎全部重做了一遍**。考前不必背全部细节，但下面这五张表必须能复述。

## 表一：AArch32 与 AArch64 的总账

| | AArch32（第二、三章） | AArch64（本章） |
|:--|:--|:--|
| 指令宽度 | 32 位 ARM + 16 位 Thumb | **恒定 32 位** |
| 通用寄存器 | R0–R15（16 个） | **x0–x30（31 个）**，SP/PC 独立 |
| 32 位视图 | —— | w0–w30（写 w 清高位） |
| 零寄存器 | 无 | **XZR / WZR** |
| 立即数 | 8 位循环右移偶数位 | **MOVZ / MOVK 拼装** |
| 条件执行 | 每条指令带 cond 域 | **CSEL 系列选择指令** |
| 异常模型 | 7 种异常 + 8 项 4 字节固定向量表 | **4 个异常级 EL + 16 项 128 字节可编程向量表（VBAR_ELx）** |
| 状态保存 | CPSR → SPSR（分组） | **PSTATE → SPSR_ELx**（系统寄存器） |
| 栈指针 | R13（每模式一份） | **SP_EL0 / SP_ELx**（SPSel 选择） |
| 返回地址 | LR（R14，每模式一份） | **x30（全局共享）** |
| 异常返回 | 写 PC + SPSR → CPSR | **ERET** |
| 条件码指令 | ADDcc 等 | 只有分支类保留条件 |

## 表二：异常体系四件套

| 机制 | AArch64 做法 |
|:--|:--|
| **分级** | EL0（用户）/ EL1（内核）/ EL2（虚拟化）/ EL3（安全） |
| **向量表** | 每级一张，16 项 × 128 字节；基址 **VBAR_ELx**，**2 KB 对齐** |
| **状态寄存器** | **ELR_ELx**（返回地址）、**SPSR_ELx**（原状态）、**ESR_ELx**（异常综合，EC/IL/ISS） |
| **栈选择** | **SP_EL0** / **SP_ELx**，由 **SPSel** 选；后缀 t/h；栈须 **16 字节对齐** |

## 表三：内存系统的三级缓存

| 层级 | 缓存什么 | 关键概念 |
|:--|:--|:--|
| **TLB** | 虚拟地址 → 物理地址 | 按 VA 位段分表；**ASID** 避免全清；**同名问题**需失效处理 |
| **Cache** | 物理地址 → 数据 | 三段编码（标记/索引/偏移）；直接/全相连/**组相连**；**VIPT** 主流 |
| **一致性** | 多个 Cache 副本 | **MESI**（M/E/S/I）；核间靠 SCU，系统级靠 **ACE / ACE-Lite** |

**共享属性**：Non-shareable / **Inner Shareable** / Outer Shareable / System Shareable。
**两个观察点**：**PoU**（处理器角度）与 **PoC**（系统角度）。

## 表四：多核并发的三个正交问题

| 问题 | 现象 | 手段 |
|:--|:--|:--|
| **互斥** | 两个核同时改同一数据 | 信号量 / 互斥量 / 独占访问（自旋锁） |
| **一致性** | 一个核改了，另一个还看旧值 | MESI（硬件）/ clean + invalidate（软件） |
| **存储序** | 看到的是别人操作的中间状态 | 内存屏障 **DMB / DSB / ISB**；更好的 **LDAR / STLR** |

**独占访问**：LDXR（独占读）+ STXR（独占写，失败重试）；带屏障的变体 LDAXR / STLXR。
**AArch32 写法是 LDREX / STREX。**

## 表五：内存维护动作的固定套路

| 场景 | 动作 |
|:--|:--|
| CPU 生产数据 → DMA 消费 | 启动 DMA **之前** clean（写回脏行） |
| DMA 生产数据 → CPU 消费 | 读取 **之前** invalidate（丢弃陈旧行） |
| 内核改了代码 | invalidate 指令 Cache（PoC）**并发 IPI** 让其它核也做 |
| 改了页表 | 失效 TLB（跨核用 IPI） |

## 一句话总结

**AArch32 是"为省硬件发明的"，AArch64 是"为可维护性重新发明的"**——固定 32 位编码换来规整与扩展空间，异常级换来权限分层，系统寄存器换来状态管理的清晰，屏障与原子指令换来多核正确性。
