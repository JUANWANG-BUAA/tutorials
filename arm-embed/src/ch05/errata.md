# 勘误与补注（对照素材来源）

本章内容依据《ARM64 体系结构编程与实践》（奔跑吧 Linux 社区编著，人民邮电出版社，2022）整理。本页记录三件事：**素材书自身的口径与笔误**、**本书按 ARM 官方手册补全的部分**、**与前四章（AArch32）容易混淆之处**。

## 素材书的口径说明

::: note #5-1 本章基于 ARMv8.6
素材书明确以 **ARMv8.6** 为基准，实验平台为树莓派 4B（BMC2711，含 GIC-400）与 QEMU。本章凡提到具体特性都按 ARMv8-A 族书写；若某特性属更晚的小版本（如 ARMv8.1 的 TTHM、MTE），已在正文标注小版本号。
:::

::: note #5-2 实验平台差异
素材书的实验基于树莓派 4B 与 QEMU 模拟器，**本书不复现这些实验**（本教材的实验环境由课程另行指定）。本章只取其**体系结构知识与陷阱清单**，所有代码片段均为教学用最小示例，未经目标平台验证——请勿直接当作可运行代码使用。
:::

::: note #5-3 素材书的编号习惯
素材书正文用形如 `15.8.2` 的小节号引用的是**书内页码上的节号**（如 15.8.2 指第 15 章第 8 节的第 2 小节）。本章改用自己的节号，并在需要时用"（素材书 15.8.2）"标注来源，便于对照原书。
:::

## 素材书笔误与易误处

::: errata #5-4 素材书正文中的排版缺字（多处）
原书 PDF 文本层存在大量缺字（如"高速缓存行中的状态"被拆成"高速缓 存行"、英文术语与中文之间丢字）。这属 PDF 抽取或排版问题，**不影响概念本身**。本章按上下文补全后书写，未逐处登记。
:::

::: note #5-5 独占访问指令的命名
素材书 18.3.2 节指出：**ARM64 写作 LDXR / STXR，ARM32 写作 LDREX / STREX**。容易误记成"AArch64 用 LDREX"——恰好相反。本章 [5.10.6](sec5-10.md) 已显式对照。
:::

::: note #5-6 ESR_ELx 的 EC 编码
素材书表 11.4 列出的异常类型编码中，`ESR_ELx_EC_SVC32 = 0x11`、`ESR_ELx_EC_SVC64 = 0x15`、`ESR_ELx_EC_HVC32 = 0x12`。注意 **SVC32 在前、SVC64 在后**，数值不随位宽递增——记编码时按表查，别凭直觉推。
:::

::: note #5-7 数据异常 ISS 的位域
素材书表 11.5 列出 ISS 中常用字段：DFSC(Bit[5:0])、WnR(Bit[6])、S1PTW(Bit[7])、CM(Bit[8])、EA(Bit[9])、FnV(Bit[10])、SET(Bit[12:11])、VNCR(Bit[13])、AR(Bit[14])、SF(Bit[15])、SRT(Bit[20:16])、SSE(Bit[21])、SAS(Bit[23:22])、ISV(Bit[24])。其中 **SF 位（Bit[15]）区分 32 位与 64 位访问**——AArch64 上同一个"数据中止"可能是 32 位访问触发的也可能是 64 位，排查时要看这一位。
:::

## 与前四章（AArch32）最容易混淆的五处

| # | 混淆点 | AArch32（第二、三章） | AArch64（本章） |
|:--|:--|:--|:--|
| 5-16 | 异常向量表 | 固定 0x0–0x1C，**8 项 × 4 字节** | **16 项 × 128 字节**，基址由 **VBAR_ELx** 设定 |
| 5-17 | 栈指针 | R13，**每模式一份**（分组） | **SP_EL0 / SP_ELx**，由 SPSel 选，**t/h 后缀** |
| 5-18 | 返回地址 | LR（R14），**每模式一份** | **x30 全局共享**，另有 **ELR_ELx** 存硬件返回地址 |
| 5-19 | 状态寄存器 | CPSR + SPSR（**硬件分组**） | **PSTATE + SPSR_ELx / ELR_ELx / ESR_ELx**（系统寄存器） |
| 5-20 | 内存屏障 | 无（用关中断或 SWP 顶替） | **DMB / DSB / ISB**，更细的 LDAR/STLR |

::: note #5-21 "关中断能替代内存屏障吗"——不能
第四章 4.10.2 给的互斥三选一（关中断 / 禁止任务切换 / 信号量）**只对单核成立**。多核系统里，另一个核的访存顺序不受本核关中断的影响，必须用 5.10 的屏障与原子指令。这是本书跨章对照里最重要的一条：**第四章的三条手段，在多核上全部失效**。
:::

## 待核事项

- 素材书基于 ARMv8.6；ARMv9 对某些特性（如 Realm、SVE2）的定义有更新，本章未展开——若课程后续涉及，需对照 ARMv9-A 手册补。
- 素材书第 15 章的 Cache 枚举实验、17 章的 TLB 实验、18–19 章的屏障实验都需要真实硬件或模拟器，本书未收录实验步骤，仅保留结论。
- 树莓派 4B 的具体 GIC-400 配置（中断号分配表）属平台专有内容，与体系结构无关，未收入。
