## 卡组 D · 任务与调度

| # | 问 | 答 | 回 |
|:--|:--|:--|:--|
| D1 | 进程 / 线程 / 任务 | 进程=内存保护单元；线程=执行单元（同进程共享地址空间）；嵌入式里线程=任务，有自己的寄存器与栈 | 4.7.1 |
| D2 | 任务三态与迁移动作 | 运行/就绪/阻塞；就绪→执行（选中）、执行→就绪（时间片用完）、执行→阻塞（等资源）、阻塞→就绪（得资源） | 4.7.2 |
| D3 | 前后台系统 | 前台=ISR 处理异步事件与关键操作；后台=主循环管资源与调度；各任务优先级相同 → 及时性差 | 4.7.3 |
| D4 | 内核做什么、代价 | 分配 CPU 时间、任务间通信、基本服务是任务切换；代价 2%～5%（另一处 5%～10%）CPU 与 RAM/ROM | 4.7.4 |
| D5 | 非抢占内核的 ISR 后行为 | CPU 仍归被中断任务，高优先级任务虽已就绪也要等它**主动让出** | 4.8.2 |
| D6 | 抢占内核的 ISR 后行为 | 中断结束时直接切给就绪的最高优先级任务 | 4.8.3 |
| D7 | 上下文切换做什么、开销取决于什么 | 全部 CPU 寄存器入任务栈 + 从新任务栈装载；**取决于寄存器数量** | 4.8.4 |
| D8 | VxWorks 缺省调度 | 优先级抢占式（0–255）；同优先级时间片轮转；另有动态优先级与优先级继承 | 4.8.6 |
| D9 | RMS 优先级依据 | **周期**（短者高），静态 | 4.9.2 |
| D10 | EDF 优先级依据 | **截止期**（早者高），动态，单处理器最优 | 4.9.3 |
| D11 | LLF 的空闲时间定义 | 截止期 − 剩余执行时间；小者高 | 4.9.4 |
| D12 | RMS 充分条件 | $U \le n(2^{1/n}-1)$；**充分非必要**，不成立要用时间轴模拟 | 4.9.2、4.9.6 |
