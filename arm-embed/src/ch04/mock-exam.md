# 综合自测卷

第四章自测卷：**90 分钟，闭卷，满分 100**。整章读完、间隔至少一天后再做。计算题必须写出过程与参数表。

## 一、填空（每空 2 分，共 20 分）

1. 线程的三种状态是____、____、____；由**内核**决定的状态迁移是"____→____"。
2. RMS 调度策略按任务的____分配优先级，属于____调度算法。
3. LLF 的空闲时间定义为____减____。
4. 中断时延、调度时延、上下文切换时延中，开销主要取决于 CPU **寄存器数量**的是____。
5. 按实时性分类，VxWorks 属____实时，RTLinux 属____实时。

## 二、选择（每题 4 分，共 20 分）

1. 非抢占式内核中，ISR 使一个高优先级任务就绪后：A. 立即切换到高优先级任务 B. CPU 仍归被中断任务，高优先级任务需等它主动让出 C. 高优先级任务被撤销 D. 内核挂起
2. 下列关于 EDF 的说法**错误**的是：A. 动态算法 B. 截止期越短优先级越高 C. 单处理器下最优 D. 调度开销小、实现简单
3. 关于共享内存的说法**正确**的是：A. 由内核自动完成数据搬运 B. 必须自己保证共享数据的排它性 C. 不存在竞态 D. 只能用于单核
4. 优先级反转发生的必要条件之一是：A. 互斥量无所有权 B. 低优先级任务持锁而高优先级任务等它 C. 使用抢占式内核 D. 时钟节拍过快
5. 某系统 100 次中断中 99 次在 5 ms 内响应，1 次为 200 ms，按实时性口径其中断响应时间应记为：A. 5 ms B. 约 5.1 ms C. 200 ms D. 无法确定

## 三、简答（每题 8 分，共 24 分）

1. 说明上下文切换的过程，并解释为什么"CPU 寄存器越多，任务切换开销越大"。结合第二章说明 ARM 上的上下文切换大致要搬运哪些内容。
2. 写出优先级反转的完整过程，说明为什么用普通信号量替代互斥量会使优先级继承失效。
3. 说明"实时"不等于"快"：给出实时系统的定义，并解释为什么性能很强的 Windows 仍不能用于硬实时控制。

## 四、推演（每题 12 分，共 36 分）

1. 三个周期任务：A（T=8 ms, C=3 ms, D=8 ms）、B（T=12 ms, C=2 ms, D=12 ms）、C（T=30 ms, C=4 ms, D=30 ms）。① 算 $U$；② 用 RMS 充分条件判定是否可调度，写出 RMS 优先级顺序；③ 若改用 EDF，说明它与 RMS 的优先级顺序何时会不同（举一个本题参数下的例子）；④ 若 C 的执行时间偶尔超出到 9 ms，指出最先出问题的任务与后果。

2. 某系统采用抢占式内核，ISR 流程为：读 UART 寄存器 → 写入环形缓冲区 → 置事件标志 → 返回。解析任务等待事件标志后取数据并做协议解析。回答：① 为什么解析不能放进 ISR；② 环形缓冲区的入队操作为什么必须原子，谁来保证；③ 若解析任务比写数据的中断源还频繁，可能出现什么状况，属于哪一类问题（提示：4.10.4 的三种用途）。

3. 一段 ISR 代码如下：
   ```asm
   ISR_ENTRY
           STMFD SP!, {R0-R3, LR}
           LDR   R0, =0x40000000
           LDR   R1, [R0]
           STR   R1, [R0, #4]
           LDMFD SP!, {R0-R3, PC}^
   ```
   回答：① 第 2 条与第 3 条指令分别对应第二章/第三章的什么机制？② 若把 `LDMFD SP!, {R0-R3, PC}^` 改成 `LDMFD SP!, {R0-R3, PC}`（去掉 `^`），系统会出现什么现象？③ 若 ISR 里调用了一个使用全局变量的函数，会出什么问题，依据是本讲的哪一条结论？

## 参考答案与评分点

**一、**1. 运行、就绪、阻塞；就绪→执行。2. 周期；静态。3. 截止期（deadline）；任务剩余执行时间。4. 上下文切换时延。5. 硬；软。（每空 2 分）

**二、**1.B。2.D（EDF 每次调度点都要重算优先级，开销大、不易实现）。3.B。4.B（外加"互斥量有所有权"这一前提，缺 B 则不成立）。5.C（按最坏情况取）。（每题 4 分）

**三、**1. 过程：保存当前任务的全部 CPU 寄存器内容到**任务自己的栈区**，再把下一任务的上下文从其栈装入 CPU 寄存器并开始运行；开销随需入栈的寄存器数量增长（每次多搬一个寄存器就多一次访存）。ARM 上涉及分组寄存器（R13_sp、R14）、被调用者保存的 R4–R11 及条件码，**共 37 个寄存器的体系结构**（2.7.1）意味着上下文相关部分相当可观。（4+4）2. A 高优先级但睡眠，B 低优先级运行并向文件服务进程发请求后睡眠；A 就绪后与文件服务进程同优先级队列中后者优先，而它代表的是 B，于是 A 被低优先级任务间接拖住，等待链长度随负载增长。优先级继承失效的原因：它要求内核能识别"**谁正持有锁**"，即锁必须有**所有权**；普通信号量无所有权，内核无法确定该提升谁的优先级。（4+4）3. 定义（Gillies）：正确性不仅取决于逻辑正确，还取决于结果产生的时间，未满足时间约束即算失效。Windows 在 CPU 空闲时响应很快，但后台任务运行时响应可能变得非常漫长（读文件任务长时间无响应甚至挂死）——**它不提供确定性**，这是调度结构问题而非性能问题；实时系统要求面对从最小到最坏的负载变化都确定性满足时间要求。（4+4）

**四、**1. ① $U = 3/8 + 2/12 + 4/30 = 0.375 + 0.1667 + 0.1333 = 0.675$。② $n=3$，界为 $3(2^{1/3}-1) \approx 0.7798$；$0.675 \le 0.78$ ⇒ **充分条件成立，可调度**；RMS 优先级：A（8 ms）> B（12 ms）> C（30 ms）。③ EDF 按截止期排；本题各任务 $D_i = T_i$，所以 EDF 顺序与 RMS **相同**；只有当某任务截止期与周期不一致时两者才会不同（例如把 C 的截止期提前到 20 ms，则 EDF 中 C 高于 B，而 RMS 中 C 仍最低）。④ C 执行时间超到 9 ms 时，**C 单次就占用 9 ms**，而 C 的周期是 30 ms ——但真正先出问题的是 **A**：C 的执行片段若与 A 的释放时刻重叠（30 ms 处 C 的下一次释放正好与 A 的第 4 次释放相撞），A 需等 C 跑完，可能错过 8 ms 的截止期；此时 A 是硬实时任务，**其截止期被错过即系统失效**（4.12.1 的定义）。（每问 3 分）
2. ① ISR 抢占所有任务，其每行代码都计入**最坏情况中断时延**（4.11.6 的公式第一项就是关中断最长时间）；解析可能耗时长、可能阻塞、可能调用不可重入函数（4.10.7），都会拉长中断响应、危及硬实时任务。② 入队 = 读头指针 → 写数据 → 更新头指针，这几步之间若被任务抢占，任务可能读到半写入的数据（共享内存无隐含的交接动作，4.10.2）；保证方式：关中断或禁止任务切换保护入队临界区，或用计数型信号量（4.10.2 三种手段）。③ 事件标志是信号量三种用途中的**"标志某事件的发生"**（4.10.4）；若解析速度跟不上产生速度，缓冲区会积压——表现为**溢出丢数据**（事件通知与数据流不匹配），若用阻塞式等待则表现为任务频繁阻塞与唤醒的额外开销。（每问 3 分）
3. ① 第 2 条 `LDR R0,=0x40000000` 是伪指令 LDR=（**文字池**机制，3.9.4），由汇编器展开为 PC 相对 LDR；第 3 条 `STR R1,[R0,#4]` 是**前索引偏移**的单寄存器存储（3.3.3），偏移 4；整体上这段代码对应第二章的 **MMIO**（对 0x40000000 这个外设寄存器地址的访问，2.11.2）。② 去掉 `^` 后，LDM 只恢复寄存器、**不把 SPSR 抄回 CPSR**（3.4.5）：CPSR 里的模式位仍是 IRQ 模式、I 位仍为 1——处理器回不到被中断的任务，且中断被永久屏蔽，系统挂死。③ 若被调用函数使用**全局变量**，它就是**不可重入函数**（4.10.7）；ISR 抢占任务时，任务可能正停在 swap 的中间，全局变量被 ISR 改写，数据被破坏。正确做法：ISR 只调用可重入函数（只用局部变量），或用关中断保护关键段。（每问 3 分）
