# 勘误与补注（对照课件）

记录《第 2 章 ARM 微处理器体系结构》课件与通用口径的差异。编号 #2-n；"已核"表示对照过课件原文；处理原则：正文按考纲口径书写，课件原文如实转述于此。随课程资料（测验、作业）发布后追加"对照记录"。

## 已核实的课件笔误

::: errata #2-1 SWI 伪操作中 SPSR 写错（Slide 92）
课件：`SPSR_und = CPSR`。SWI 进入的是 **svc** 模式，应为 `SPSR_svc = CPSR`。同一页 `CPSR[4:0] = 0b10011`（svc）自证。正文按正确口径书写。
:::

::: errata #2-2 预取中止伪操作中 LR 与 SPSR 下标写错（Slide 93）
课件：`r14_svc`、`SPSR_und`。预取中止进入 **abt** 模式，应为 `r14_abt`、`SPSR_abt`；同页 `CPSR[4:0] = 0b10111`（abt）自证。
:::

::: errata #2-3 大小端示意图与表格矛盾（Slide 117 vs 118）
Slide 117 的示意图把"小端模式"画成 0x12 在低位地址；Slide 118 的表格给出小端为 `78 56 34 12`（低地址→高地址）。两者矛盾，Slide 118 与通用口径一致（小端 = 低字节在低地址）。正文按 Slide 118 书写。
:::

::: errata #2-4 SWI 返回指令寄存器写错（Slide 103）
课件：SWI 处理程序返回 `SUBS PC, R14_irq, #4`。SWI 的 LR 在 **svc** 模式，应为 `R14_svc`。IRQ 的返回（Slide 98）才是 `R14_irq`。
:::

::: errata #2-5 未定义指令返回指令寄存器写错（Slide 106）
课件：`SUBS PC, R14_irq, #4`。未定义指令异常的 LR 在 **und** 模式，应为 `R14_und`。
:::

::: errata #2-6 数据中止向量地址笔误（Slide 94）
课件：高向量 `PC = 0xffff000C10`（多了一位）。应为 **0xFFFF0010**（与低向量 0x00000010 对应 +0xFFFF0000）。
:::

## 口径澄清（非笔误）

::: note #2-7 "42 个寄存器"与"37 个"并存
Slide 31（Cortex-A9 概述）出现"共有 42 个用户可以访问的 32 位寄存器"，属**实现口径**（含安全扩展等新增分组寄存器）；经典体系结构口径为 **37 个（31 通用 + 6 状态）**，全章寄存器表（Slide 47 起）均按 37 讲。答题用 37，除非题目明说 A9 实现细节。
:::

::: note #2-8 "中止模式在 ARM 没大用处"的语境（Slide 41–43 表注）
该备注是无 MMU 裸机系统的旧口径。带 MMU 的系统（Linux 等）中 abt 模式承载缺页与存储保护异常，用处很大。表格主口径（支持虚拟内存/存储器保护）两处一致，考试按表答。
:::

::: note #2-9 目录节号跳号
课件目录为 1 简介 … 10 存储器及存储器映射 I/O，正文小节标号出现 2.4（数据类型）而目录第 3 项是"Cortex-A9 概述、第 4 项数据类型"的错位，及个别页眉"2.3"缺号。本教程重排为连续 2.1–2.11，对应关系见[章导览](overview.md)。
:::
