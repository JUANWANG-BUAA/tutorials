# 习题集

第二章习题按节分组，概念题与推演题并重。先独立完成再看解答；照着答案做出来的题，改一个参数重做一遍。

## A 组 · 公司、族谱与总线（2.1–2.2）

**A1** 用三句话向不懂硬件的同学解释 ARM 的商业模式，并说明为什么这种模式能形成"各具特色的 ARM 芯片"。

**A2** RISC 的 Load/Store 结构是什么意思？从"译码简单、流水线友好"的角度说明为什么 ARM 坚持"运算只对寄存器"。

**A3** CISC 与 RISC 各举一条优势、一条代价。8/2 原则支持的是哪一方？

**A4** 一块 SoC 里，CPU 核、DMA、片上 SRAM 挂在 AHB，UART/GPIO/定时器挂 APB 经桥转换。为什么低速外设不直接挂 AHB？

::: sol A 组解答要点
A1：只设计不生产；把处理器设计授权给半导体厂商并配套工具/总线规范；厂商在统一指令集上各自集成外设形成差异。A2：只有加载/存储/交换指令碰存储器，ALU 运算只吃寄存器；指令等长、访存位置规整，译码与流水线分级简单。A3：CISC 优势是一条指令做得多、代码紧凑，代价是硬件复杂、不利流水线；RISC 相反；8/2 支持精简。A4：AHB 为高带宽设计（多主仲裁、流水线传输），低速设备挂上去白白增加仲裁开销；APB 接口简单省电，桥负责速率隔离。
:::

## B 组 · 数据类型与状态（2.4–2.5）

**B1** 地址 0x201 处放一个半字，合法吗？地址 0x202 呢？说明理由。

**B2** `LDRB R0, [R1]` 把字节装入 32 位寄存器时，高 24 位从哪来？零扩展与符号扩展的差别体现在哪（联系 §3.3 的 LDRB/LDRSB）？

**B3** 下列代码执行后处理器处于什么状态？为什么？
```asm
        LDR   R0, =sub_thumb+1
        BX    R0
sub_thumb:
        ...
```

**B4** 判断对错并纠错："ARM 状态切换到 Thumb 状态后，寄存器 R0 的值保持不变，但处理器模式变为 Thumb 模式。"

::: sol B 组解答要点
B1：0x201 是奇地址，半字须 2 字节对齐——不合法；0x202 偶地址合法。B2：由装载指令自动扩展：LDRB 零扩展（高 24 位补 0），LDRSB 符号扩展（按最高位补 0 或 1）。B3：Thumb 状态——BX 目标地址最低位为 1；模式不变。B4：错。寄存器内容与模式都不变；"Thumb"是执行状态不是模式，两维独立（2.5.1）。
:::

## C 组 · 模式与寄存器（2.6–2.7）

**C1** 闭卷默写七种模式表（缩写、进入方式、是否异常模式）。然后回答：哪些模式下能访问 SPSR？

**C2** 把 37 个寄存器的账目算给同桌听：为什么恰好是 37？

**C3** 用户程序（usr 模式）执行中发生 IRQ。分别列出 R0–R7、R8–R12、R13、R14、CPSR 中，哪些物理寄存器是"IRQ 模式下与 usr 共享的"，哪些换成了 irq 副本？

**C4** ISR 骨架为什么必须 `STMFD SP!, {…, LR}` 先把 LR 压栈？如果处理程序中途开中断（清 I）且不压 LR，画出出错的时间线。

**C5** 三级流水线下，`MOV R0, PC` 后 R0 的值与正在执行指令的地址差多少？这个差在什么场合必须记住？

::: sol C 组解答要点
C1：见速查卡表 2；仅 5 种异常模式有 SPSR（usr/sys 没有）。C2：8（R0–R7）+ 2×5（R8–R12 两组）+ 2×7（R13/R14 各七份）+ 1（PC）= 31 通用，+1 CPSR +5 SPSR = 37。C3：共享 R0–R12 与 PC、CPSR；换成副本的是 R13→R13_irq、R14→R14_irq，另有 SPSR_irq 可见。C4：嵌套 IRQ 会把新返回地址写进同一个 R14_irq，覆盖第一次的返回地址；时间线：进 ISR₁（LR=A）→ 清 I → IRQ₂ 到，LR 被改写为 B → ISR₂ 返回用 B 正确 → ISR₁ 返回仍用已被覆盖的 R14（=B′）→ 跳错。C5：+8（读 PC 得到取指地址）；手算跳转目标、取当前地址、异常返回偏移。
:::

## D 组 · CPSR 与异常（2.8–2.10）

**D1** R0=5、R1=7 执行 `SUBS R2, R0, R1` 后，NZCV 各为何？若接着 `BMI`（负则跳），跳不跳？`BLT`（有符号小于）呢？两者一致吗？

**D2** Thumb 状态、usr 模式、I=F=0 的程序发生 IRQ。按顺序写出硬件四步中 CPSR 的每一位变化（I、F、T、M[4:0]）与 LR、SPSR、PC 的动作。返回时哪一步让 T 回到 1？

**D3** 数据中止与预取中止的返回偏移为什么是 8 而不是 4？两类中止返回后分别做什么？

**D4** SWI 与未定义指令异常都用 `SUBS PC, R14_xxx, #4` 返回，xxx 各是什么模式？SWI 的处理程序如何区分不同的系统调用号？

**D5** 复位后软件要做的第一类初始化是什么？为什么不能等到第一次异常发生再做？

::: sol D 组解答要点
D1：N=1（−2 最高位 1）、Z=0、C=0（无符号 5<7 借位）、V=0（有符号不溢出）。BMI 跳（N=1）；BLT 判 N≠V，N=1、V=0 → 也跳；本例一致，但两者判据不同——负不等于小于（溢出时会分开，见 3.1）。D2：LR_irq ← 断点下一条+4；SPSR_irq ← 原 CPSR；I: 0→1、T: 1→0、M: 10000→10010；PC ← 0x00000018。返回时 LDM^/SUBS 把 SPSR 抄回 CPSR，T 随之回 1（自动切回 Thumb）。D3：中止要求**重试**触发指令本身——流水线已多走一条，多退 4；预取中止返回后重新取指该指令，数据中止返回后重新执行访存指令（注意基址回写副作用，2.9.5）。D4：svc 与 und；SWI 处理程序读触发指令的编码，取出其立即数字段作调用号（§3.8）。D5：为将用的每种模式初始化 R13 栈指针——异常一来硬件立刻用 R13_xxx 压栈，等不得。
:::

## E 组 · 存储器（2.11）

**E1** 0xCAFEBABE 存到 0x300（字对齐）。列表写出小端与大端下 0x300–0x303 各单元内容。

**E2** "存储器映射 I/O"与"独立编址 I/O"各自怎么访问外设寄存器？ARM 选了哪种，带来什么编程习惯？

**E3** 两块板子字节序不同（一小端一大端），通过内存直传一个 32 位字。接收方读到的值与发送方写入 0x00000001 时相差什么？给出逐字节拼装的修复代码（C 或汇编伪码均可）。

::: sol E 组解答要点
E1：小端 300:BE 301:BA 302:FE 303:CA；大端 300:CA 301:FE 302:BA 303:BE。E2：统一编址：外设寄存器占存储器地址，用普通 LDR/STR（及全部寻址方式）访问；独立编址要专用 IN/OUT 指令。ARM 选统一编址——驱动代码里到处是"对某地址的 LDR/STR"。E3：0x00000001 小端存为 01 00 00 00，大端方按本端读成 0x01000000；修复：发送前按约定字节序逐字节打包、接收方逐字节拼装，如 `x = p[0] | (p[1]<<8) | (p[2]<<16) | ((uint32_t)p[3]<<24)`。
:::
