# 2.2 AMBA 总线与系统互联

CPU 核算得再快，取不到指令和数据也是空转。核与存储器、外设之间要有一套明确的"挂接规则"——谁来驱动地址线、谁在哪个周期读数据、多个主设备抢总线听谁的。ARM 给这套规则的答案叫 AMBA。本节弄清三种总线的分工即可，时序细节课程不作要求。（课件 Slide 7，属课件 2.1"简介"内一页；本教程独立成节）

## 2.2.1 AMBA 是什么

**AMBA（Advanced Microcontroller Bus Architecture，高级微控制器总线架构）**是 ARM 制定的片上总线规范，与处理器核授权配套，让各家厂商的外设 IP 能按同一接口挂进 SoC。课件提到的三代成员：

| 总线 | 全称 | 定位 |
|:--|:--|:--|
| **ASB** | Advanced System Bus | 早期系统总线，已逐渐被 AHB 取代 |
| **AHB** | Advanced High-performance Bus | 高性能总线：接 CPU 核、DMA、片内主存等高带宽部件 |
| **APB** | Advanced Peripheral Bus | 外围总线：接低速外设（UART、GPIO、定时器一类） |
| AXI | Advanced eXtensible Interface | AHB 之后的高性能接口，向 v7/v8 系统演进（课件备注提及） |

## 2.2.2 典型拓扑：高速道与慢速道

一个经典 AMBA 系统是"两层结构"：高性能部件挂在 **AHB** 上直接对带宽敏感的通路；低速外设统一挂在 **APB** 上，由一个桥（bridge）把 AHB 的访问转成 APB 时序。

```
   CPU 核 ─┐
   DMA    ─┼──[ AHB 高性能总线 ]── 片上 SRAM / Flash 控制器 / 外部存储器控制器
   LCD    ─┘            │
                      [AHB→APB 桥]
                         │
                [ APB 外围总线 ]── UART · GPIO · 定时器 · 看门狗 …
```

为什么要分两层？AHB 为速度设计（流水线式传输、多主仲裁），APB 为简单省电设计（接口逻辑少、时钟可慢）。把 UART 这类每秒几千次的设备挂在 AHB 上，等于让高速公路直通每家门口——路是快了，路口的仲裁开销却拖累所有人。

::: think 总线仲裁发生在哪一刻？
DMA 控制器和 CPU 同时想访存，AHB 的仲裁器决定谁先走。第四章讲中断与 DMA 传输时会再次用到这一点：外设数据之所以能"不经过 CPU"进内存，靠的就是 DMA 作为总线主设备抢到总线周期。
:::

## 本节小结

AMBA 把 SoC 内部划分成 AHB 高速层与 APB 低速层，桥负责转换；ASB 是被 AHB 取代的历史角色，AXI 是后续演进。记住"分层挂接"的动机——按带宽需求分道，比背四条总线的全称更重要。下一节进入 Cortex-A9，看高性能核内部长什么样。
