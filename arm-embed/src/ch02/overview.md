# 第二章 · ARM 微处理器体系结构

## 芯片上电时，处理器"站"在哪里？

按下复位键，ARM 核丢掉手里的一切，跳到管理模式、关掉两类中断、从地址 0 取第一条指令。这一句话里藏着本章的全部角色：模式、中断禁止位、寄存器、向量地址。读完本章，你应该能不查书地把这次复位的每一步展开成完整的硬件动作清单，并说清每一步用到了本章哪个机制。

本教程依据《第 2 章 ARM 微处理器体系结构》课件（2026 秋季，127 页）整理扩充。课件共十个小节；本教程重排为十一节——AMBA 从"简介"中独立成节，其余对应关系见下表。课件只列结论的地方（异常响应流程、大小端规则），正文补全过程；课件笔误与口径差异收入[勘误页](errata.md)。

## 读法建议

2.6–2.8 是全章的腰：模式决定你能看到哪组寄存器，寄存器组里最特殊的是 CPSR，CPSR 的模式位又反过来决定模式。这三节务必连读，读完合上书默写"37 个寄存器的构成表"自测。2.9 异常是三节机制的综合应用，也是历年考查重心——先把 2.6–2.8 过关再进。2.1–2.3 偏认识型，第一遍快速读完建立图景即可，细节（流水线级数、核型号）留到考前突击。

第三章会大量使用本章结论：讲 LDM/STM 要用分组寄存器与栈，讲 SWI 就是一次人为制造的异常，讲条件执行就是 CPSR 的 N Z C V。学本章时每认出一个机制，可以预先想想它会在指令集那边变成什么。
