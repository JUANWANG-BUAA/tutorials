# 2.1 ARM 公司与体系结构族谱

手机里那颗 SoC 的 CPU 核，多半不是 ARM 公司造的——ARM 只画设计、收授权费，芯片由苹果、高通、三星这些授权商生产。一家"不生产芯片的芯片公司"为什么能拿下 95% 以上的智能手机？本节回答三件事：ARM 的商业模式、RISC 与 CISC 的取舍、版本号 v1–v9 和 Cortex 家族怎样对应。读完应能回答：同样跑一个加法，为什么 RISC 敢用更少的指令？（课件 Slide 3–25）

## 2.1.1 ARM 公司与授权模式

ARM 既是公司名（Advanced RISC Machines），也指它定义的微处理器体系结构。1991 年成立于英国剑桥，前身为 Acorn 计算机公司。它的商业特点是**只设计、不生产**：把处理器设计以授权（license）方式卖给半导体厂商与 OEM，再配套提供开发工具、评估板、调试工具、总线规范（AMBA）与外围 IP。市面上"各具特色的 ARM 芯片"由此而来——核是同一套指令集，外围与频率各厂不同。

选择 ARM 内核时，课件列的考量维度值得过一眼：工作频率、片内存储器容量，以及一长串片内外设清单——MMU、USB / 以太网、GPIO 数量、中断控制器、LCD 控制器、ADC/DAC、CAN、I²C、UART、看门狗、DMA、电源管理。嵌入式选型从来不是只看 CPU 跑分，而是看这颗 SoC 把你要的外设都集成了没有。

::: note 两条容易过眼即忘的背景事实
- 2016 年软银以约 320 亿美元收购 ARM；其后英伟达曾宣布以 400 亿美元收购，因高通、谷歌、微软等反对与监管审查未成。
- 授权模式的市场结果：授权商累计售出超 2000 亿颗 ARM 架构芯片，2024 年单年出货约 330 亿颗。
:::

## 2.1.2 CISC 与 RISC：一次指令集的取舍

微处理器由三大部分组成：**控制单元**（取指、译码、发控制信号，内含 PC 与 IR 两个关键寄存器）、**算术逻辑单元 ALU**（算术 + 逻辑）和**寄存器组**（暂存数据）。这条组成线两类处理器都一样，差别在指令怎么设计：

| | CISC（复杂指令集） | RISC（精简指令集） |
|:--|:--|:--|
| 指令数量与寻址方式 | 大量 | 只留最有用的 |
| 指令长度 | 可变 | 固定 |
| 访存方式 | 寻址方式复杂，指令可直接操作存储器 | **Load/Store 结构**：只有取数/存数指令碰存储器，运算只对寄存器 |
| 硬件与译码 | 复杂 | 简单，便于流水线 |
| 设计依据 | —— | 8/2 原则：80% 的程序只用 20% 的指令 |

RISC 的算盘：既然大多数程序只反复用少量指令，不如把留下的指令都做成**等长**、**单周期可完成**，译码电路简单了，流水线就好搭。代价是"一条 CISC 指令干完的活"要几条 RISC 指令拼——换来的是每条都飞快。课件用数据通道对比了两者：CISC 一条指令内部走"IF→ID→ALU→MEM→REG"的微操作通道，RISC 则是每级一行直通。

::: def 定义 2.1.1 · Load/Store 结构 {#def-2.1.1}
数据处理指令的操作数与结果都只能是寄存器；存储器里的数据必须先由加载（load）指令取入寄存器，算完再由存储（store）指令写回。对存储器的访问只有加载、存储、交换三类指令。
:::

这条定义是全书的分水岭：第三章你会在指令分类表里再次看到"存储器访问指令"单列一族，原因就在这里。

## 2.1.3 体系结构版本 v1–v9 与处理器核

"体系结构版本"（指令集版本，ARMvN）与"处理器核"（实现，如 ARM7、Cortex-A9）是两个层次：版本规定指令集与程序员模型，核是某版本的一次电路实现。ARM 定义了 v1–v9 九个主要体系结构版本；同一版本可以有多颗核实现，同一颗核也有衍生（ARM7TDMI 的 TDMI 是功能后缀：Thumb、Debug、快速乘法、ICE 在线仿真）。

经典核与版本的对应大致是：ARM7（v4T，三级流水线）→ ARM9（v4T，五级）→ ARM11（v6，八级）→ Cortex 时代（v7 起）。课件用一组流水线图展示了这段演进——ARM7 三级（取指/译码/执行），ARM9 五级（加访存、回写），ARM11 八级，到 Cortex 系列支持**超标量、乱序执行、寄存器重命名、动静态分支预测**，Cortex-A78 流水线已达 15 级。

Cortex 家族按应用三分：

| 家族 | 定位 | 场景举例 |
|:--|:--|:--|
| Cortex-A（Application） | 应用处理器，跑操作系统 | 手机 SoC；A725/X925/A520 组成 DynamIQ 大小核（1+4+3，共享 DSU） |
| Cortex-R（Real-time） | 实时处理器 | 硬实时控制（课件图示硬盘控制器、汽车电子类场景） |
| Cortex-M（Microcontroller） | 微控制器 | 低功耗 MCU |

::: think 为什么手机 SoC 要 1 个 X925 + 4 个 A725 + 3 个 A520？
大核跑突发重负载，中核跑日常，小核待机省电——同一指令集（v9.2）、不同性能/功耗点，由 DSU（DynamIQ Shared Unit）把它们联成一致性多核。指令集兼容让任务可以在核间迁移，这正是"版本与实现分离"带来的工程红利。
:::

## 本节小结

ARM 靠"授权设计"而非"生产芯片"建立了生态；RISC 用等长指令 + Load/Store 结构换来了流水线友好；v1–v9 是指令集的代际，Cortex-A/R/M 是实现的三条产品线。后续各节展开的处理器模型（模式、寄存器、异常）都建立在 v4T–v7 这几代经典定义之上。下一节先看核外面的世界——总线。
