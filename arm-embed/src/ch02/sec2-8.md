# 2.8 程序状态寄存器：CPSR 与 SPSR

上一节的模式开关、2.5 节的 T 位、第三章的条件执行，全都住在同一个寄存器里。CPSR 是 ARM 程序员模型的"控制面板"：上半层是运算结果留下的标志，下半层是处理器自己的控制位。本节逐位讲清，并回答"SPSR 为什么存在"。（课件 Slide 69–78）

## 2.8.1 位布局总览

```

┌───┬───┬───┬───┬───┬───────────────┬───┬───┬───┬──────────────┐
│ N │ Z │ C │ V │ Q │    保留        │ I │ F │ T │   M[4:0]     │
└───┴───┴───┴───┴───┴───────────────┴───┴───┴───┴──────────────┘
 └──── 条件代码标志 ────┘              └──────── 控制位 ────────┘
```

CPSR 一人一份、全局共享；**SPSR 只在异常模式可见**——进入异常时硬件把当时的 CPSR 抄进 SPSR_xxx，退出时抄回来。有了它，异常处理程序随便怎么改 CPSR（开关中断、换模式），原状态都能原样找回。

## 2.8.2 条件代码标志：N Z C V

大多数数据处理指令带 **S 后缀**时更新标志（有些指令天生更新，如 CMP）；所有 ARM 指令都能按条件执行（cond 域，§3.1），依据就是这四位。

| 标志 | 置 1 条件 |
|:--|:--|
| **N**（Negative） | 结果最高位为 1（补码意义下结果为负） |
| **Z**（Zero） | 结果为 0（比较"相等"就是看它） |
| **C**（Carry） | 加法（含 CMN）最高位进位→1；**减法（含 CMP）无借位→1、有借位→0**；移位类指令 = 最后移出的一位；其它不变 |
| **V**（oVerflow） | 有符号加/减发生溢出→1；其它指令通常不变 |

C 位最容易背反，记一个锚点：减法借位时 C=0。例：`CMP R0, R1`（做 R0−R1）若 R0 < R1（无符号视角），必然借位，C=0——这正是无符号比较 LS 的判据。

::: ex 例 2.8.1 · 一次减法留下三个标志 {#ex-2.8.1}
设 R0 = 5，R1 = 7，执行 `SUBS R2, R0, R1`（5 − 7）：

- 补码运算 5 − 7 = −2，结果非零 → Z = 0；最高位为 1 → N = 1；
- 无符号视角 5 < 7，发生借位 → C = 0；
- 有符号视角结果 −2 落在表示范围内 → V = 0。

若后续指令写 `BLS label`（无符号 ≤ 跳转），判据 C=0 或 Z=1 成立——跳转发生。条件码与标志的完整对应表见 [3.1](../ch03/sec3-1.md)。
:::

## 2.8.3 控制位：I、F、T、M[4:0]

**最低 8 位为控制位**，异常发生时由硬件改变；仅在**特权模式**下软件才可改写（MRS/MSR 指令，§3.8）：

- **I = 1 禁止 IRQ；F = 1 禁止 FIQ**。注意这不是"屏蔽某个设备"，是让核根本不响应这类输入；
- **T 位反映执行状态**：1 = Thumb，0 = ARM。CPTBIT 输出信号对外反映当前状态。**禁止用 MSR 直接改 T 位**——不配合取指切换直接写，处理器进入不可预测状态（想切换只能走 BX/BLX，见 2.5.2）；
- **M[4:0] 编码模式**，合法组合只有七种：

| M[4:0] | 模式 | | M[4:0] | 模式 |
|:--|:--|:--|:--|:--|
| 10000 | usr | | 10111 | abt |
| 10001 | fiq | | 11011 | und |
| 10010 | irq | | 11111 | sys |
| 10011 | svc | | | |

非法组合会引发**不可恢复的错误**——所以改模式位的代码必须读回验证。

**保留位**（如 27 位的 Q 及 26–8 段）留作将来扩展：改动 CPSR 时要**读—改—写**（先 MRS 读出，改目标位，再 MSR 写回），不要拿一个随手构造的 32 位值整字覆盖。

::: think 为什么"异常时硬件改控制位、平时只有特权软件能改"？
控制位决定核的敏感行为（开关中断、换模式）。若用户程序也能写，任何一段用户代码都能把自己切进 svc 提权、或把中断全关掉——分层访问控制的最小实现，就是"非特权模式对控制位只读"这一条。
:::

## 本节小结

CPSR 上半 NZCV 标志（供条件执行），下半 I/F/T/M[4:0] 控制（异常时硬件动、平时特权软件动）；SPSR 是异常模式的 CPSR 备份，进异常抄入、退出抄回。下一节的异常流程，每一步都是在对这些位做操作——学 2.9 时随时翻回本节对照。
