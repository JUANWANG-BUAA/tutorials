## 亮点与创新

### 1. 实验为先
每章实验先于正文完成或同步验证，保证可运行性：
- 第1章快排退化12倍（已排序输入）
- 第2章Bellman-Ford慢175倍（非负权图）
- 第3章记忆化加速8528倍（fib(20)）

### 2. Agent陷阱系统化
每章一个真实失败案例，结构统一：
- **症状**：什么行为触发问题
- **根因**：为什么会失败
- **如何发现**：检测方法
- **修复**：代码级解决方案
- **验证**：修复后的测试结果

### 3. 算法选择决策树
不只讲算法，更讲何时用哪个：
- 最短路：Dijkstra vs Bellman-Ford vs Floyd-Warshall（根据边权、规模、负环）
- MST：Kruskal vs Prim（根据稀疏/稠密）
- DP vs 贪心：贪心选择性质成立时用贪心，否则DP

### 4. 复杂度验证文化
每个算法都有：
1. 理论复杂度分析
2. 实验验证（规模2x → 时间4x）
3. 对抗性输入测试（最坏情况）
4. 真实数据特征影响（路网vs社交网络）
