# 第 10 章实验：假设检验与多重比较

## 运行实验

```bash
python hypothesis_lab.py
```

## 实验内容

1. **I 类错误率验证**：模拟 10000 次 H0 为真的场景，验证拒绝率 ≈ α = 0.05
2. **II 类错误率与统计功效**：模拟 H1 为真时的检验功效
3. **双样本 t 检验**：比较两组算法性能，计算 p 值和 Cohen's d
4. **多重检验问题**：演示测试 20 个假设时的家族错误率累积
5. **Bonferroni 校正**：验证 FWER 控制效果
6. **BH 过程（FDR）**：比较三种校正方法的功效
7. **统计功效曲线**：功效随样本量变化
8. **p-hacking 演示**：展示反复测试导致的假阳性
9. **Mann-Whitney U 检验**：非参数检验在偏态数据上的表现

## 关键学习点

- I/II 类错误的实际表现
- 多重检验校正的必要性
- p-hacking 的危害
- 统计功效与样本量的关系
- 参数检验 vs 非参数检验
