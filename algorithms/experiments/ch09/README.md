# 第 9 章实验：评估指标与度量

本实验对应《算法、评估与因果》教程第 9 章。

## 实验内容

**实验 A: 不平衡数据集的分类指标对比**
- 构造信用卡欺诈检测场景（99% 正常，1% 欺诈）
- 对比三个分类器：Baseline（全预测正常）、Poor（低召回率）、Good（高召回率）
- 展示准确率的陷阱：Baseline 准确率最高但完全无用

**实验 B: ROC 曲线与 AUC**
- 训练逻辑回归模型处理不平衡数据集
- 绘制 ROC 曲线并计算 AUC
- 对比是否使用类别加权的效果

**实验 C: 排序指标对比**
- 模拟搜索引擎返回结果（分级相关性 0-3）
- 计算 NDCG@5、NDCG@10、MAP、MRR
- 对比完美排序、中等排序、糟糕排序的指标差异

## 运行方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

依赖项：
- numpy >= 1.24.0
- matplotlib >= 3.7.0
- scikit-learn >= 1.3.0

### 2. 运行实验

```bash
python metrics_lab.py
```

### 3. 查看结果

实验会在当前目录生成三张图片：
- `confusion_matrices.png`: 三个分类器的混淆矩阵对比
- `roc_curve.png`: ROC 曲线与 AUC
- `ranking_metrics.png`: 四个排序指标的对比柱状图

终端输出包含详细的数值结果和解读。

## 学习目标

完成本实验后，你应该能够：

- [ ] 理解准确率在不平衡数据集上的失效
- [ ] 从混淆矩阵计算精确率、召回率、F1 值
- [ ] 绘制 ROC 曲线并解释 AUC 的含义
- [ ] 计算排序指标（NDCG、MAP、MRR）并理解差异
- [ ] 识别评估指标选择中的常见陷阱

## 扩展实验

1. **改变不平衡比例**：修改实验 A 中的欺诈比例（如 5%, 0.1%），观察指标变化
2. **绘制 PR 曲线**：对比 ROC 曲线与 Precision-Recall 曲线在不平衡数据上的差异
3. **多分类评估**：扩展实验 A 到三分类任务，计算宏平均和微平均
4. **阈值调优**：在实验 B 中找到最优分类阈值（最大化 F1 或 Youden's J 统计量）
