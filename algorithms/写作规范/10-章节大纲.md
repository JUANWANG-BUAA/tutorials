# 章节大纲与分工

本文件锁定 14 章的标题、节标题、核心产出与禁止重复的内容。写作时以 `src/partN/chNN.md` 里的骨架为准；本文件补充每章的**独有角度**与**必须给出的证据**。

## 第 1 篇 · 算法分析基础

### 1 渐进分析与实验验证
- 大 O/Ω/Θ 定义与性质；主定理；递归树；摊还分析；常数因子的实际意义。
- 必须画：递归树展开图，标出每层的工作量与合并成本。
- 证据：`experiments/ch01/asymptotic_lab.py` 对比理论预测 vs 实测时间曲线（O(n)、O(n log n)、O(n²)）。
- 禁止：只写公式推导不给实测数据；把"渐进"当"任何规模下都准确"。

### 2 分治算法与性能剖析
- 归并排序、快速选择、Karatsuba 乘法、Strassen 矩阵乘法；递归深度；阈值调优。
- 必须画：分治递归的调用栈深度图，标出基情况触发点。
- 证据：`experiments/ch02/divide_conquer_lab.py` 测量 Strassen 在不同矩阵规模下的实际加速比。
- agent 错误：Strassen 在小矩阵（<64×64）上反而慢于朴素算法，未设阈值切换。

### 3 图算法与最坏情况构造
- BFS/DFS；拓扑排序；强连通分量；Dijkstra/Bellman-Ford；最坏情况输入生成。
- 必须画：Dijkstra 的优先队列操作序列图，标出 decrease-key 时机。
- 证据：`experiments/ch03/graph_lab.py` 构造让 Dijkstra 退化的稠密图，对比堆实现与朴素实现。
- agent 错误：用 `heapq.heappush` 替代 decrease-key，退化为 O(m log m)。

### 4 数据结构与平摊分析
- 动态数组扩容；哈希表负载因子；二叉搜索树旋转；并查集路径压缩；平摊代价。
- 必须画：动态数组扩容的势能函数图，标出扩容时势能下降。
- 证据：`experiments/ch04/amortized_lab.py` 记录每次插入的实际耗时，验证 O(1) 平摊。
- agent 错误：哈希表负载因子 >0.9 时性能崩溃，agent 未设 rehash。

## 第 2 篇 · 算法设计范式

### 5 贪心算法与反例构造
- 活动选择；Huffman 编码；最小生成树（Kruskal/Prim）；调度问题；交换论证。
- 必须画：贪心选择的决策树，标出每步的局部最优选择。
- 证据：`experiments/ch05/greedy_lab.py` 对比贪心策略 vs 动态规划最优解，给出反例。
- agent 错误：agent 提出"最短作业优先"策略，但在加权完成时间最小化问题上失败。

### 6 动态规划与序列重建
- 最长公共子序列；背包；序列比对；最优二叉搜索树；序列重建路径；浮点精度。
- 必须画：DP 表的填充顺序图，标出依赖关系。
- 证据：`experiments/ch06/dp_lab.py` 通过重建序列验证 DP 正确性（如 LCS 的实际子序列）。
- agent 错误：agent 只返回最优值，无法重建最优解序列。

### 7 NP 难问题与近似算法
- NP 完全性；顶点覆盖（2-近似）；旅行商（1.5-近似）；集合覆盖（ln n-近似）；精确求解器。
- 必须画：归约链图，标出从 SAT 到目标问题的多项式转换。
- 证据：`experiments/ch07/approx_lab.py` 用 ILP 求解器（GLPK）得到最优解，测量近似算法的实际近似比。
- agent 错误：agent 声称"启发式效果很好"，但没有最优解上界作为基准。

### 8 在线算法与竞争比
- 缓存替换（LRU/LFU/FIFO）；滑雪租赁问题；秘书问题；在线匹配；竞争比定义。
- 必须画：在线算法 vs hindsight 最优解的时间线图。
- 证据：`experiments/ch08/online_lab.py` 在真实访问 trace（如 Redis benchmark）上对比 LRU/LFU。
- agent 错误：agent 实现的在线算法在对抗输入上表现差，但未计算竞争比。

## 第 3 篇 · 评估与统计推断

### 9 基准测试与实验设计
- 基准套件设计；输入分布选择；warmup 与稳态；微基准陷阱；控制变量法。
- 必须画：测量噪声的直方图，标出 outliers 与中位数。
- 证据：`experiments/ch09/benchmark_lab.py` 展示 JIT 预热前后的性能差异（如 Python 首次调用 vs 稳态）。
- agent 错误：agent 只跑一次就报告性能，忽略测量噪声。

### 10 假设检验与多重比较
- t 检验；Mann-Whitney U；Bonferroni/Holm 校正；FDR 控制；效应量（Cohen's d）；检验力。
- 必须画：多重比较下假阳性率的模拟曲线（未校正 vs Bonferroni vs FDR）。
- 证据：`experiments/ch10/hypothesis_lab.py` 模拟 100 次实验，10 个算法对比，展示 p<0.05 假阳性膨胀。
- agent 错误：agent 对比 10 种算法取 p<0.05 最好的，忽略多重检验问题。

### 11 模型评估与选择
- 训练/验证/测试划分；k-折交叉验证；bias-variance 分解；信息准则（AIC/BIC）；数据泄漏。
- 必须画：学习曲线（训练误差 vs 验证误差 vs 样本量）。
- 证据：`experiments/ch11/model_selection_lab.py` 演示在测试集上调超参导致过乐观估计。
- agent 错误：agent 在测试集上调超参，最终测试集 AUC 高但泛化失败。

### 12 因果推断入门
- RCT 黄金标准；观察研究的混淆；倾向得分匹配；工具变量；差分；因果图（DAG）；辛普森悖论。
- 必须画：因果图（治疗 → 结果，混淆变量 → 治疗 + 结果）。
- 证据：`experiments/ch12/causal_lab.py` 用辛普森悖论展示混淆（如治疗组病情更重导致观察结果误导）。
- agent 错误：agent 发现算法 A 在观察数据上表现更好就推荐 A，忽略选择偏差。
