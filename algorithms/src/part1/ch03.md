## 3.1 图的代数表示与存储结构性能剖析 {#sec-algorithms.1.3.1}

图 $G = (V, E)$ 的表示方式直接决定了算法访存的缓存局部性（Cache Locality）与空间占用。

### 1. 三大存储结构对比

| 存储结构 | 空间复杂度 | 判定边 $(u, v)$ 是否存在 | 遍历点 $u$ 的所有出边 | 缓存局部性 | 适用场景 |
|:--|:--|:--|:--|:--|:--|
| **邻接矩阵 (Adjacency Matrix)** | $\Theta(|V|^2)$ | $O(1)$ | $\Theta(|V|)$ | 极佳（行内连续） | 稠密图（$|E| \approx |V|^2$），规模较小 |
| **邻接表 (Adjacency List)** | $\Theta(|V| + |E|)$ | $O(\text{deg}(u))$ | $\Theta(\text{deg}(u))$ | 较差（链表指针跳跃） | 工业标准稀疏图（$|E| \ll |V|^2$） |
| **压缩稀疏行 (CSR / Forward Star)** | $\Theta(|V| + |E|)$ | $O(\log \text{deg}(u))$（二分）| $\Theta(\text{deg}(u))$ | 极佳（平坦数组顺序存） | 工业静态超大图（图神经网络、离线批处理） |

### 2. 现代生产环境的高性能 CSR 实现

在高性能计算中，指针链接的邻接表会造成大量的 L1 Cache Miss。CSR（Compressed Sparse Row）使用三个平坦的一维数组存储整个图：
- `head[u]`：存储节点 $u$ 的出边在边数组中的起始下标；
- `edges`：连续存储所有出边的终点 $v$；
- `weights`：连续存储对应的边权重 $w$。

```python
import numpy as np

class CSRGraph:
    """压缩稀疏行图表示：极高缓存友好度，零指针开销"""
    def __init__(self, num_nodes: int, edge_list: list[tuple[int, int, float]]):
        self.n = num_nodes
        self.m = len(edge_list)
        
        # 统计每个节点的度数
        degrees = np.zeros(num_nodes, dtype=np.int32)
        for u, v, w in edge_list:
            degrees[u] += 1
            
        # 构造前缀和指针偏移
        self.head = np.zeros(num_nodes + 1, dtype=np.int32)
        self.head[1:] = np.cumsum(degrees)
        
        # 填充平坦连续边数组
        self.edges = np.zeros(self.m, dtype=np.int32)
        self.weights = np.zeros(self.m, dtype=np.float64)
        
        curr_offset = self.head[:-1].copy()
        for u, v, w in edge_list:
            pos = curr_offset[u]
            self.edges[pos] = v
            self.weights[pos] = w
            curr_offset[u] += 1

    def get_neighbors(self, u: int):
        """利用数组切片瞬间返回连续内存邻居"""
        start = self.head[u]
        end = self.head[u + 1]
        return self.edges[start:end], self.weights[start:end]
```

## 3.2 图遍历基础：BFS 层次性与 DFS 时间戳 {#sec-algorithms.1.3.2}

### 1. BFS 队列与无权最短路

广度优先搜索（BFS）使用先进先出队列（FIFO Queue），按与源点的边数距离逐层向外扩张。

::: thm 定理 3.2.1 · BFS 最短路定理 {#thm-algorithms.1.3.2.1}

在边权全部相等的无权图（或单位权图）上，BFS 访问每个顶点的顺序严格按从源点 $s$ 到该点的最短边数递增。每个顶点被入队且仅入队一次，边被遍历一次，时间复杂度为严格的 $O(V + E)$。
:::

### 2. DFS 括号定理（Parenthesis Theorem）与边分类

深度优先搜索（DFS）记录每个顶点的发现时间 $d[u]$（入栈时刻）与完成时间 $f[u]$（所有后代访问完毕出栈时刻）。
时间区间 $[d[u], f[u]]$ 满足严格的嵌套结构：
- **后代关系**：节点 $v$ 是 $u$ 的真后代，当且仅当 $[d[v], f[v]] \subset [d[u], f[u]]$；
- **边分类准则**：
  - **树边（Tree Edge）**：从父节点指向首次发现的子节点；
  - **回边（Back Edge）**：指向当前递归栈中的祖先节点（**判定有向图存在环路的充要条件**）；
  - **前向边（Forward Edge）**：指向已经访问完毕的非直接子后代；
  - **横叉边（Cross Edge）**：指向没有祖先/后代关系的另一棵子树。

## 3.3 有向图深度分析：拓扑排序与 Kosaraju 强连通分量 {#sec-algorithms.1.3.3}

### 1. 拓扑排序的双重实现：Kahn 算法 vs DFS

- **Kahn 算法（入度表 + 队列）**：
  1. 统计所有节点的入度；
  2. 将所有入度为 0 的节点放入队列；
  3. 弹出节点并加入拓扑序列，将其所有出边的终点入度减 1；若邻居入度变为 0 则入队；
  4. 若最终序列长度 $< |V|$，说明**图中存在有向环**。
- **DFS 完成时间逆序法**：节点在递归完成（被涂为 `BLACK`）出栈时记录，按完成时间 $f[u]$ 从大到小排列即为拓扑序列。

### 2. 强连通分量（SCC）与 Kosaraju 双遍 DFS 算法

::: def 定义 3.3.1 · 强连通分量 (Strongly Connected Component) {#def-algorithms.3.3.1}

在有向图 $G$ 中，若极大子图 $C \subseteq V$ 内的任意两个顶点 $u, v$ 之间，均同时存在从 $u$ 到 $v$ 的有向路径和从 $v$ 到 $u$ 的有向路径，则称 $C$ 为一个强连通分量。
将每个强连通分量收缩为一个超节点，原图将折叠为一个纯粹的**有向无环超图（Meta-DAG）**。
:::

Kosaraju 算法是基于反图（Transposed Graph $G^T$）的双遍线性时间算法：

::: method 方法 3.3.1 · Kosaraju 算法两步执行法 {#method-algorithms.3.3.1}

1. **第一遍 DFS（在反图 $G^T$ 上）**：
   - 构造原图的反向图 $G^T$（将所有有向边反向）；
   - 在 $G^T$ 上运行完整的深度优先遍历，记录所有顶点完成遍历（出栈）的时间序号（Finish Times），得到一个按完成时间从大到小的排列序列。
   - *数学原理*：反图上的完成时间拓扑，使得最晚完成的顶点必定属于原图 Meta-DAG 中**入度为 0 的源头超节点（Source SCC）**！
2. **第二遍 DFS（在原图 $G$ 上）**：
   - 严格按照第一步得到的时间降序序列，依次挑选未访问过的节点作为起点运行 DFS；
   - 每次从该节点出发能够访问到的所有节点的集合，恰好精准构成一个完整的强连通分量！
:::

```python
def kosaraju_scc(n: int, adj: list[list[int]]) -> list[list[int]]:
    """Kosaraju 双遍 DFS 算法：时间复杂度严格 O(V + E)"""
    visited = [False] * n
    finish_stack = []

    # 1. 构造反图
    rev_adj = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            rev_adj[v].append(u)

    # 2. 第一遍 DFS (反图上收集完成顺序)
    def dfs_first_pass(u: int):
        visited[u] = True
        for v in rev_adj[u]:
            if not visited[v]:
                dfs_first_pass(v)
        finish_stack.append(u)

    for i in range(n):
        if not visited[i]:
            dfs_first_pass(i)

    # 3. 第二遍 DFS (原图上按栈弹出顺序提取分量)
    visited = [False] * n
    scc_list = []

    def dfs_second_pass(u: int, current_scc: list[int]):
        visited[u] = True
        current_scc.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs_second_pass(v, current_scc)

    while finish_stack:
        u = finish_stack.pop()
        if not visited[u]:
            scc = []
            dfs_second_pass(u, scc)
            scc_list.append(scc)

    return scc_list
```

## 3.4 单源最短路径体系：从 Dijkstra 到斐波那契堆理论界 {#sec-algorithms.1.3.4}

### 1. Dijkstra 算法与切分定理

Dijkstra 算法维护一个已经确定最短距离的顶点集合 $S$（初始为 $\{s\}$，$\text{dist}[s] = 0$）。在每一步中，考察所有跨越切分 $(S, V \setminus S)$ 的边 $(u, v)$，挑选使得 $\text{dist}[u] + w(u, v)$ 最小的顶点 $v^*$ 加入 $S$。

::: thm 定理 3.4.1 · Dijkstra 算法正确性条件 {#thm-algorithms.3.4.1}

**边权非负性**：只要图中的所有边权非负（$\forall e, w(e) \ge 0$），则每次贪心挑选出的顶点 $v^*$ 其当前距离值必定已经是全局最优最短路。
若图中存在负权边，贪心选择性质立刻破灭（后走的负权边可能会带来更小的全局距离）。
:::

### 2. 惰性入堆 vs 真 `decrease-key` 的复杂度陷阱

在大多数现代语言中（包括 Python `heapq` 和 C++ `std::priority_queue`），标准库优先队列**并不支持高效的 `decrease-key` 操作**。开发者通常采用**惰性入堆（Lazy Insertion）**：每当松弛一条边产生更小距离时，直接将元组 `(new_dist, v)` 压入堆中。

::: note 复杂度鸿沟分析
- **真正的 `decrease-key`（配对堆 / 斐波那契堆）**：
  堆中元素个数严格保持为 $|V|$。共执行 $|V|$ 次 `extract-min` 和最多 $|E|$ 次 `decrease-key`。
  二叉堆复杂度：$O((V + E) \log V)$；斐波那契堆复杂度：$O(E + V \log V)$。
- **惰性入堆（Python / C++ 常见写法）**：
  每次松弛成功都在堆中插入一个新副本，堆中元素数量可达 $O(|E|)$。
  执行一次 `heappop` 的开销上升为 $\log |E| = \Theta(\log V)$，总时间复杂度为 $O(E \log E)$。
  **更关键的缺陷**：弹出节点时必须检查 `if d > dist[u]: continue`，若遗漏此检查，算法在稠密图上会退化为指数级反复遍历！
:::

```python
import heapq

def dijkstra_correct_lazy(n: int, adj: list[list[tuple[int, float]]], src: int):
    """带严格重复过滤的工业级 Dijkstra 实现"""
    dist = [float('inf')] * n
    dist[src] = 0.0
    pq = [(0.0, src)]
    visited = [False] * n

    while pq:
        curr_d, u = heapq.heappop(pq)
        
        # 核心防退化防线：跳过堆中过期的陈旧副本
        if visited[u]:
            continue
        visited[u] = True

        for v, w in adj[u]:
            if not visited[v] and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))

    return dist
```

## 3.5 负权最短路与负环检测：Bellman-Ford 与 SPFA 退化 {#sec-algorithms.1.3.5}

当图中存在负权边时，必须使用动态规划本质的 **Bellman-Ford 算法**。

### 1. Bellman-Ford 算法原理

设无负权环的图中最短路径最多包含 $|V| - 1$ 条边。
定义状态：$dp[k][v]$ 表示从源点 $s$ 到 $v$ 且经过边数最多为 $k$ 的最短路径长度。
状态转移：
$$
dp[k][v] = \min \left( dp[k-1][v], \min_{(u, v) \in E} \{ dp[k-1][u] + w(u, v) \} \right)
$$
算法对全图所有边连续进行 $|V| - 1$ 轮松弛。若在第 $|V|$ 轮依然存在某条边满足 $\text{dist}[u] + w(u, v) < \text{dist}[v]$，则数学上严格证明**图中存在从源点可达的负权回路（Negative Cycle）**！

### 2. SPFA（Shortest Path Faster Algorithm）及其致命对抗图

SPFA 本质是带队列优化的 Bellman-Ford：只有在上一轮距离被成功缩小的点，其出边才有可能使邻居缩短，因此仅将发生更新的点推入队列。
在随机稀疏网格图上，SPFA 平均运行时间接近 $O(k \cdot E)$（$k \approx 2 \sim 3$）。
**但在竞赛与对抗环境下，SPFA 极度危险！**

::: errata 针对 SPFA 的网格菊花对抗图（Adversarial Grid-Cactus）
构造一个包含多层捷径与密集环路的特殊图（例如网格嵌套菊花图），使得每次松弛都只使目标节点的距离缩减微小的 $\epsilon$，迫使同一个节点被重新反复入队出队指数级次数。
实测证明：精心构造的 2000 个节点的对抗图，能让 SPFA 运行超过 10 亿次松弛操作，耗时从 5ms 暴涨到超时熔断（10 秒以上），严格退化到最坏复杂度 $O(V \cdot E)$。
:::

## 3.6 全源最短路：Floyd-Warshall 与 Johnson 重赋权算法 {#sec-algorithms.1.3.6}

求解任意两点 $(u, v)$ 之间的最短距离（All-Pairs Shortest Paths, APSP）：

### 1. Floyd-Warshall 算法（$O(V^3)$ 动规）

考虑顶点集合编号为 $\{1, 2, \ldots, n\}$。定义 $d^{(k)}_{ij}$ 为从 $i$ 到 $j$ 且**所有中间节点编号均取自 $\{1, 2, \ldots, k\}$** 的最短路长度：
$$
d^{(k)}_{ij} = \min \left( d^{(k-1)}_{ij}, d^{(k-1)}_{ik} + d^{(k-1)}_{kj} \right)
$$
该算法仅需三层极简循环，空间可压缩为 $O(V^2)$ 原地更新，是稠密图 APSP 的绝对王者。

### 2. Johnson 算法：稀疏图上的 $O(V \cdot E + V^2 \log V)$

若在稀疏图（$|E| \ll |V|^2$）上运行 Floyd-Warshall，耗时依然是 $O(V^3)$。
若对每个顶点运行一次 Dijkstra，总时间只需 $V \cdot O(E \log V) = O(V E \log V)$。但如果图中有负权边，Dijkstra 无法运行！
能否把所有负权边“合理地变成正权边”，且不改变任意两点间原有的相对最短路形态？

::: thm 定理 3.6.1 · Johnson 势能重赋权公式 {#thm-algorithms.3.6.1}

1. 引入虚构超级源点 $s$，向所有原图顶点连一条权重为 0 的有向边；
2. 运行一次单源 Bellman-Ford 算法，求出从 $s$ 到所有点的最短距离，记为**势能函数 $h(v)$**。若检测到负环则报错退出；
3. 根据三角不等式：$h(v) \le h(u) + w(u, v) \implies \hat{w}(u, v) = w(u, v) + h(u) - h(v) \ge 0$！
   **所有重赋权后的边权 $\hat{w}(u, v)$ 严格非负！**
4. 对每个顶点运行非负 Dijkstra 算法；
5. 将算出的距离逆向还原为真实距离：$\text{dist}(u, v) = \widehat{\text{dist}}(u, v) - h(u) + h(v)$。
:::

## 3.7 最小生成树与网络流 {#sec-algorithms.1.3.7}

### 1. Kruskal vs Prim 选型实战

- **Kruskal 算法**：按边权由小到大排序，利用并查集（Union-Find）维护连通块，无环即合并。时间为 $O(E \log E) = O(E \log V)$。在**稀疏图**上极具优势。
- **Prim 算法**：从单点出发，利用优先队列持续吸纳跨越割集的最小权重边。二叉堆时间为 $O(E \log V)$，斐波那契堆时间为 $O(E + V \log V)$。在**稠密图**上表现更优。

### 2. 网络流：Ford-Fulkerson 与 Edmonds-Karp

网络流的核心是**残差网络（Residual Network）**中的反向边设计：允许算法通过反向边“反悔”撤销之前做出的次优流分配。
- **Edmonds-Karp 算法**：每次使用无权广度优先遍历（BFS）寻找边数最少的增广路径（Shortest Augmenting Path）。
- **复杂度保证**：增广路径寻找最多执行 $O(V \cdot E)$ 次，每次 BFS 为 $O(E)$，全局运行时间严格受控在 $O(V \cdot E^2)$，彻底杜绝了朴素 Ford-Fulkerson 在大容量边上单步流增量仅为 1 的死循环风险。

### 2. 击崩 SPFA 的级联退化图生成器

```python
def generate_spfa_worst_case(k: int):
    """
    构造多层级联菱形图：每个阶段包含平行分支与指数级更新
    节点数 O(k)，但松弛次数达到 2^k
    """
    edges = []
    n = 2 * k + 1
    for i in range(k):
        u = 2 * i
        v1 = 2 * i + 1
        v2 = 2 * i + 2
        w_main = 10**(k - i)
        edges.append((u, v1, 0))
        edges.append((u, v2, w_main))
        edges.append((v1, v2, w_main - 1))
    return n, edges
```

## 3.10 Agent 陷阱案例：Dijkstra 误用于负权图 {#sec-algorithms.1.3.10}

::: errata 真实生产代码与生成缺陷分析
**用户 Prompt**：
> “写一个通用的单源最短路算法。输入可能包含负权边（如资金回扣），请以最快速度求出各点距离。”

**Agent 生成的典型错误代码**：
```python
def dijkstra_misused(n, edges, src):
    # Agent 简单将边插入图，随后直接调用 Dijkstra
    import heapq
    adj = [[] for _ in range(n)]
    for u, v, w in edges: adj[u].append((v, w))
    dist = [float('inf')] * n
    dist[src] = 0
    pq = [(0, src)]
    visited = [False] * n
    while pq:
        d, u = heapq.heappop(pq)
        if visited[u]: continue
        visited[u] = True
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

**灾难后果与排查流程**：
- *症状*：代码运行飞快（几毫秒返回），但在含负权边的测试集上，计算出的路径距离严重大于真实最短路。
- *根因*：Dijkstra 的数学基石是贪心切分定理（要求边权非负）。一旦某点被标记为 `visited = True`，Dijkstra 假定该点的最短路已确定，不再接受后续松弛。但负权边的存在意味着后走的路径可能“越走越短”，直接击穿贪心假设。
- *防御*：检测输入是否存在负权边：若全非负，使用 Dijkstra；若存在负权且无负环，使用 Bellman-Ford；若存在负环，必须抛出 `NegativeCycleError`。
:::

## 3.12 本章陷阱 {#sec-algorithms.1.3.12}

::: errata 本章陷阱

1. **负权图硬跑 Dijkstra**：非负假设破灭，贪心标记不可撤回，直接产生逻辑错误且不报错。
2. **惰性优先队列未做已访问过滤**：漏写 `if visited[u]: continue`，导致堆内冗余节点爆炸式重复展开。
3. **邻接矩阵初始化漏掉自环与重边**：重边情况下未取 `min(weight, old_weight)` 导致被大权覆盖。
4. **递归 DFS 在大深度图上栈溢出**：在百万长链图上直接抛出 `RecursionError`，工业代码必须使用显式系统栈模拟。
5. **Bellman-Ford 提前早停条件写错**：必须在一整轮松弛期间没有任何一条边发生更新时才能早停。
6. **Floyd-Warshall 三重循环顺序颠倒**：必须将中间枚举节点 $k$ 放在最外层循环，否则状态依赖被破坏。
7. **SPFA 遭遇负权环死循环**：每个节点的入队次数一旦超过 $|V|$ 必须强制报负环终止，否则进程挂死。
8. **无向图网络流反向弧建立失误**：无向边的残差网络反向边初始容量应设为原容量，而非 0。
9. **并查集漏写路径压缩**：只做按秩合并而漏写 `parent[x] = find(parent[x])`，导致退化为单链。
10. **拓扑排序未检测环路**：输出的拓扑序列长度小于 $|V|$ 时未抛出异常，掩盖了图中有环的致命结构缺陷。
11. **Johnson 算法未加入虚构源点**：直接以图内某点作为 Bellman-Ford 源点，无法覆盖非强连通分量节点。
12. **Prim 算法稠密图未选用邻接矩阵**：在 $|E| = \Theta(V^2)$ 稠密图上硬用二叉堆，耗时反而劣于朴素 $O(V^2)$ 邻接矩阵版本。

:::

::: method 即时自测

**题目**：在有向图 $G = (V, E)$ 中，如果所有边权均为负数（且图中无环，是一个有向无环图 DAG），能否通过“将所有边权加上一个足够大的正数 $C$，使得所有边权变为正数”，然后直接使用 Dijkstra 算法求解最短路径？

::: sol

**解答**：
**绝对不能！这种做法在数学上是彻底错误的！**

**反例与数学证明**：
假设从起点 $s$ 到终点 $t$ 存在两条不同的简单路径：
- 路径 $P_1$：包含 1 条边，原始权值为 $-10$；
- 路径 $P_2$：包含 10 条边，每条边原始权值为 $-2$。路径 $P_2$ 原始总权值为 $10 \times (-2) = -20$。
显然，真实最短路径是 $P_2$（总权重 $-20 < -10$）。

现在将所有边权全部加上常数 $C = 100$：
- 路径 $P_1$ 的新权值为：$(-10) + 1 \times 100 = 90$；
- 路径 $P_2$ 的新权值为：$(-20) + 10 \times 100 = 980$！
加常数后，原图中边数较多但原本更短的路径 $P_2$，因为包含 10 条边而被累加了 10 次常数 $C$，导致新总权值（$980$）远远暴涨超过了边数较少的路径 $P_1$（$90$）！
Dijkstra 算法在新图上必定会错误地挑选路径 $P_1$。

**正确做法**：
对于有向无环图（DAG），无论边权正负，均可按照拓扑排序顺序在线性时间 $O(V + E)$ 内直接通过单遍动规松弛求得精确最短路（或最长路）。
