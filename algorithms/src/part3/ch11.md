## 11.1 泛化误差与偏差-方差权衡（Bias-Variance Decomposition） {#sec-algorithms.3.11.1}

设真实的数据生成过程为：
$$
Y = f(X) + \epsilon, \quad \mathbb{E}[\epsilon] = 0, \quad \text{Var}(\epsilon) = \sigma^2
$$
其中 $f(X)$ 为真实但未知的潜在函数，$\epsilon$ 为均值为 0、方差为 $\sigma^2$ 的不可约不可控随机噪声（Irreducible Error）。
在给定训练数据集 $\mathcal{D}$ 上，我们训练得到了估计模型 $\hat{f}(X; \mathcal{D})$。
对一个新的测试点 $x_0$，模型的期望预测均方误差（Expected Prediction Error）是对训练集 $\mathcal{D}$ 的随机抽样以及噪声 $\epsilon$ 求期望。

::: thm 定理 11.1.1 · 偏差-方差分解定理 {#thm-algorithms.11.1.1.1}

在测试点 $x_0$ 处的期望平方泛化误差可以严格分解为三个正交分量：
$$
\mathbb{E}[(Y - \hat{f}(x_0))^2] = \text{Bias}^2(\hat{f}(x_0)) + \text{Var}(\hat{f}(x_0)) + \sigma^2
$$
其中：
- **偏差平方（$\text{Bias}^2$）**：估计量的期望与真实函数之间的系统性差距：
  $$
  \text{Bias}(\hat{f}(x_0)) = \mathbb{E}_{\mathcal{D}}[\hat{f}(x_0)] - f(x_0)
  $$
- **方差（$\text{Var}$）**：估计量在不同训练集抽样下的离散抖动程度：
  $$
  \text{Var}(\hat{f}(x_0)) = \mathbb{E}_{\mathcal{D}}\left[ \left(\hat{f}(x_0) - \mathbb{E}_{\mathcal{D}}[\hat{f}(x_0)]\right)^2 \right]
  $$
- **不可约误差（$\sigma^2$）**：物理世界本身的内在噪声，任何模型都无法逾越的下界。
:::

::: proof 证明 · 严格展开推导与交叉项消除 {#proof-algorithms.11.1.1.1}

为了简化记号，记 $\hat{f} = \hat{f}(x_0)$，$f = f(x_0)$，$\bar{f} = \mathbb{E}[\hat{f}]$。
利用恒等变形在括号内加减 $\bar{f}$ 与 $f$：
$$
Y - \hat{f} = (f + \epsilon) - \hat{f} = (f - \bar{f}) + (\bar{f} - \hat{f}) + \epsilon
$$
将三项平方展开并求期望：
$$
\begin{aligned}
\mathbb{E}[(Y - \hat{f})^2] &= \mathbb{E}\left[ \left( (f - \bar{f}) + (\bar{f} - \hat{f}) + \epsilon \right)^2 \right] \\
&= \mathbb{E}[(f - \bar{f})^2] + \mathbb{E}[(\bar{f} - \hat{f})^2] + \mathbb{E}[\epsilon^2] \\
&\quad + 2 \mathbb{E}[(f - \bar{f})(\bar{f} - \hat{f})] + 2 \mathbb{E}[(f - \bar{f})\epsilon] + 2 \mathbb{E}[(\bar{f} - \hat{f})\epsilon]
\end{aligned}
$$
逐项化简：
1. 第一项：$f - \bar{f}$ 是确定性常数，$\mathbb{E}[(f - \bar{f})^2] = (\mathbb{E}[\hat{f}] - f)^2 = \text{Bias}^2(\hat{f})$；
2. 第二项：$\mathbb{E}[(\bar{f} - \hat{f})^2] = \mathbb{E}[(\hat{f} - \mathbb{E}[\hat{f}])^2] = \text{Var}(\hat{f})$；
3. 第三项：$\mathbb{E}[\epsilon^2] = \text{Var}(\epsilon) = \sigma^2$；
4. 交叉项 1：$2(f - \bar{f}) \mathbb{E}[\bar{f} - \hat{f}] = 2(f - \bar{f})(\bar{f} - \mathbb{E}[\hat{f}]) = 2(f - \bar{f})(0) = 0$；
5. 交叉项 2：$2(f - \bar{f})\mathbb{E}[\epsilon] = 2(f - \bar{f})(0) = 0$（因为噪声均值为 0）；
6. 交叉项 3：模型由训练集 $\mathcal{D}$ 训练得到，而测试点噪声 $\epsilon$ 独立于训练集，故两者独立：
   $$
   2 \mathbb{E}[(\bar{f} - \hat{f})\epsilon] = 2 \mathbb{E}[\bar{f} - \hat{f}] \mathbb{E}[\epsilon] = 0 \cdot 0 = 0
   $$
所有交叉项完全抵消为 0！三项相加，证毕。
:::

### 偏差-方差的对抗权衡（Trade-off）

```text
  泛化误差
     ▲
     │                                            / 总泛化误差 EPE
     │ \                                         /
     │  \           欠拟合区       过拟合区     /
     │   \             │              │       /   高方差 Var
     │    \            ▼              ▼      /  /

```

## 11.2 交叉验证模型族与快速计算技巧 {#sec-algorithms.3.11.2}

交叉验证（Cross-Validation）是评估泛化能力最通用的非参数技术。

### 1. 四大交叉验证协议选型

| 协议类型 | 划分机制 | 适用数据特征 | 潜在风险 |
|:--|:--|:--|:--|
| **标准 k-Fold CV** | 均匀随机将数据划分为 $k$ 份 | 样本独立同分布（IID）的标准表格数据 | 类别不平衡时某折可能完全缺失少数类 |
| **分层 k-Fold (Stratified)** | 每一折中各分类标签的比例严格与全量数据一致 | 极度不平衡的分类任务（如欺诈检测 1:100） | 仅适用于离散分类，不适用于连续回归 |
| **时间序列滚动 (TimeSeriesSplit)** | 训练集仅包含历史窗口，测试集永远在未来 | 金融量化、气象预测、用户行为流 | 严禁随机打乱，否则发生未来信息泄漏 |
| **组交叉验证 (GroupKFold)** | 同一群体（如同一患者、同一学校）的所有数据必须完整归入同一折 | 具备聚类结构的数据 | 忽略 Group 会导致模型学习到个体记忆而非通用特征 |

### 2. 线性模型留一法（LOOCV）闭式解捷径

留一法（Leave-One-Out CV，即 $k = n$）方差极小且无偏，但朴素实现需要重新拟合模型 $n$ 次，对大规模数据计算成本不可承受。
对于**普通最小二乘线性模型（OLS）**与**岭回归**，存在一个极其神奇的数学定理：**仅需在全量数据上拟合一次，即可直接瞬时求出全部 $n$ 次 LOOCV 的残差！**

::: thm 定理 11.2.1 · 快速 LOOCV 公式（基于帽子矩阵对角线） {#thm-algorithms.11.2.1.1}

设帽子矩阵（Hat Matrix / Projection Matrix）为 $H = X (X^T X)^{-1} X^T$，其第 $i$ 个对角线元素为 $h_{ii}$（代表第 $i$ 个观测的杠杆值 Leverage）。
设在全量数据上拟合得到的第 $i$ 个预测值为 $\hat{y}_i$，残差为 $e_i = y_i - \hat{y}_i$。
则当从数据集中**剔除第 $i$ 个样本重新训练模型后**，对该样本的留一法预测误差为：
$$
y_i - \hat{y}_{(-i)} = \frac{y_i - \hat{y}_i}{1 - h_{ii}}
$$
因此，留一法交叉验证均方误差拥有完全闭式的即时解：
$$
\text{CV}_{(n)} = \frac{1}{n} \sum_{i=1}^n \left( \frac{y_i - \hat{y}_i}{1 - h_{ii}} \right)^2
$$
:::

利用该公式，计算 LOOCV 的时间由 $O(n \cdot d^3)$ 锐减至一次矩阵分解的 $O(d^3 + n d^2)$，加速成千上万倍！

## 11.3 正则化方法：L1 Lasso、L2 Ridge 与 ElasticNet {#sec-algorithms.3.11.3}

为了控制模型复杂度，降低模型方差，我们在损失函数（Empirical Risk）后引入对模型参数复杂度的惩罚项（Regularization Penalty）：
$$
\min_{\beta} \frac{1}{2n} \|y - X\beta\|_2^2 + \lambda \cdot R(\beta)
$$

### 1. 岭回归（L2 Ridge）：$R(\beta) = \frac{1}{2} \|\beta\|_2^2 = \frac{1}{2} \sum_{j=1}^d \beta_j^2$

- **解析闭式解**：
  $$
  \hat{\beta}_{\text{ridge}} = (X^T X + \lambda I)^{-1} X^T y
  $$
- **数学本质**：在协方差矩阵 $X^T X$ 对角线上增加正数 $\lambda$，确保矩阵即使存在严重多重共线性（Collinearity）也能严格可逆，收缩奇异值，大幅降低系数估计的方差。

### 2. 套索回归（L1 Lasso）：$R(\beta) = \|\beta\|_1 = \sum_{j=1}^d |\beta_j|$

- **稀疏性保证**：由于 L1 范数的等高线是一个带尖角的菱形多面体（Cross-polytope），二次损失函数的椭圆等高线极易在多面体的**坐标轴顶点**处与惩罚域相切。在顶点处，大量特征的权重被**精确置为 0**！因此 Lasso 天然自带特征选择能力。

### 3. 坐标下降法与软阈值算子

Lasso 损失函数在 $\beta_j = 0$ 处不可微，因此无法直接使用梯度下降。工业标准实现采用**坐标下降法（Coordinate Descent）**，依次固定其他维度，对单个维度 $\beta_j$ 进行闭式解析更新：

::: thm 定理 11.3.1 · 软阈值算子 (Soft-Thresholding Operator) {#thm-algorithms.11.3.1.1}

单变量更新解析解为：
$$
\hat{\beta}_j = S\left( \frac{1}{n} \sum_{i=1}^n x_{ij}(y_i - \hat{y}_i^{(j)}), \lambda \right)
$$
其中软阈值算子定义为：
$$
S(z, \lambda) = \text{sign}(z) \cdot \max(0, |z| - \lambda)
$$
若相关性绝对值 $|z| \le \lambda$，系数被直接硬置为 0；若 $|z| > \lambda$，系数向 0 收缩 $\lambda$ 的幅度。
:::

### 4. 弹性网络（ElasticNet）：组合双重优势

当特征维度 $d \gg n$ 或特征之间存在强相关组（Group of Correlated Features）时，Lasso 会随机选其中一个而扔掉其余全部，表现不稳定。
弹性网络引入混合惩罚：
$$
R(\beta) = \alpha \|\beta\|_1 + \frac{1 - \alpha}{2} \|\beta\|_2^2
$$
既保证了生成稀疏特征子集，又保持了强相关特征的成组保留（Grouping Effect）。

## 11.4 特征选择方法谱系（Feature Selection） {#sec-algorithms.3.11.4}

| 范式 | 核心思想 | 算法举例 | 计算开销 | 优缺点 |
|:--|:--|:--|:--|:--|
| **过滤法 (Filter)** | 独立于模型，基于统计指标排序特征 | 方差阈值、Pearson 相关系数、互信息（Mutual Information）、卡方检验 | 极低 $O(d)$ | 快速初筛；但忽略特征间的组合互补效应 |
| **包装法 (Wrapper)** | 将目标算法当做评估黑盒，贪心搜索最优子集 | 递归特征消除（RFE）、向前逐步贪心选择、向后淘汰 | 极高 $O(d^2 \times \text{Train})$ | 针对特定模型精度最高；超大特征容易过拟合且慢 |
| **嵌入法 (Embedded)** | 特征选择作为模型训练的一个内在副产物 | L1 Lasso、决策树特征重要性（Gini 增益） | 中等（与训练同级） | 综合平衡，工业界首选 |

## 11.5 模型比较的统计检验 {#sec-algorithms.3.11.5}

当模型 A 的交叉验证均值达到 85.2%，模型 B 达到 84.8% 时，我们能断言模型 A 优于模型 B 吗？绝不能！
因为各折之间的测试样本虽然不重叠，但**训练集存在高达 $\frac{k-2}{k-1}$ 的重叠共享**，各折的误差并非相互独立。

### 1. 分类任务：McNemar 配对检验

对同一份独立测试集上的两两预测构造列联表（Contingency Table）：

| | 模型 B 预测正确 | 模型 B 预测错误 |
|:--|:--|:--|
| **模型 A 预测正确** | $e_{00}$ | $e_{01}$ (A 对 B 错) |
| **模型 A 预测错误** | $e_{10}$ (A 错 B 对) | $e_{11}$ |

两个模型差异的本质完全集中在非对角线元素：
$$
\chi^2 = \frac{(|e_{01} - e_{10}| - 1)^2}{e_{01} + e_{10}} \sim \chi^2(1)
$$
若 $p < 0.05$，在统计学上拒绝两模型表现相同的假设。

### 2. 5×2 交叉验证配对 t 检验（Dietterich 规范）

为了彻底克服标准 k-fold 各折非独立性导致的极度高估显著性（伪假阳性）：
执行 5 次独立的 2-折交叉验证。在每次 2-折中，计算两个模型的指标差值 $p_i^{(1)}$ 与 $p_i^{(2)}$，方差估计仅使用单次划分内部的差值波动。
该检验严格服从自由度为 5 的 t 分布，被学术界与工业界公认为模型差异检验的金标准。

## 11.6 信息准则与模型复杂度：AIC 与 BIC {#sec-algorithms.3.11.6}

在参数化概率模型中，直接使用对数似然 $\ln L$ 会促使模型无限增加参数直至过拟合。信息准则通过引入模型参数量 $k$ 的惩罚来选择最优模型：

::: def 定义 11.6.1 · 赤池与贝叶斯信息准则 {#def-algorithms.11.6.1.1}

- **AIC（Akaike Information Criterion）**：
  $$
  \text{AIC} = 2k - 2\ln(\hat{L})
  $$
  基于 Kullback-Leibler 散度最小化推导，目标是寻找在未知未来数据上预测损失最小的模型。
- **BIC（Bayesian Information Criterion）**：
  $$
  \text{BIC} = k \ln(n) - 2\ln(\hat{L})
  $$
  基于贝叶斯边缘似然最大化推导。惩罚项 $k \ln n$ 强于 AIC 的 $2k$。当样本量 $n > e^2 \approx 7.4$ 时，BIC 对复杂模型的惩罚严厉得多。
- **渐进性质**：若真实模型包含在候选集中，当 $n \to \infty$ 时，BIC 具有**选择一致性（Consistent）**（以概率 1 挑出真实模型）；而 AIC 是渐进有效的（Asymptotically Efficient）。
:::

## 11.7 嵌套交叉验证（Nested CV）与超参数调优 {#sec-algorithms.3.11.7}

常规网格搜索常犯的错误是：在整个 5-折交叉验证中寻找最优超参数，并直接报告那组最优超参数对应的验证集均值作为模型的泛化误差。
**这是严重的乐观估计（Optimism Bias）！因为超参数本身就是根据验证集的表现挑选出来的，验证集已经被超参数“偷看过”了！**

::: method 方法 11.7.1 · 嵌套交叉验证双层架构 {#method-algorithms.11.7.1.1}

1. **外层循环（Outer Loop, 如 5 折）**：负责无偏估计泛化误差。
   - 每次保留 1 折作为“外层测试集”，其余 4 折进入内层；
2. **内层循环（Inner Loop, 如 3 折）**：仅使用外层的 4 折数据进行网格搜索与超参数选择。
   - 在内层 3 折中确定最优超参数 $\lambda^*$；
3. **外层评估**：使用内层选出的 $\lambda^*$ 在外层训练集上训练一个完整模型，并在该轮的外层测试集上计算误差。
4. 最终报告的是 5 次外层独立测试误差的均值与方差。
:::

## 11.9 Agent 陷阱案例：无意识特征泄露的 3 大灾难 {#sec-algorithms.3.11.9}

::: errata 真实生产代码与生成缺陷分析
**用户 Prompt**：
> “使用 Scikit-Learn 对数据进行标准化（StandardScaler），然后挑选相关性最高的 20 个特征，最后用 5-折交叉验证报告支持向量机（SVM）的交叉验证准确率。”

**Agent 生成的典型错误代码**：
```python
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.model_selection import cross_val_score
from sklearn.svm import SVC

# 1. 致命泄露点 A: 在交叉验证划分前对全量数据执行 fit_transform
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. 致命泄露点 B: 在交叉验证前利用全量标签 y 挑选 Top-20 特征
selector = SelectKBest(f_classif, k=20)
X_selected = selector.fit_transform(X_scaled, y)

# 3. 再运行交叉验证
model = SVC()
scores = cross_val_score(model, X_selected, y, cv=5)
print(f"虚假的超高交叉验证得分: {scores.mean():.4f}")
```

**灾难后果与排查流程**：
- *症状*：交叉验证准确率高达 95%，但在推向线上生产环境后，准确率骤降至 62%（甚至比简单基线还差）。
- *根因*：
  1. `StandardScaler` 在包含验证集样本的数据上计算了全局均值和方差，验证集的分布信息已经渗透到了训练集中；
  2. `SelectKBest` 使用了验证集的真实标签 $y$ 挑选特征，使得选出的特征天然契合验证集中的特异噪声。
- *正规修复*：所有预处理、归一化、特征选择必须通过 `Pipeline` 封装，确保 `fit` 严格且仅在外层训练折内部发生！
```python
from sklearn.pipeline import Pipeline

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('selector', SelectKBest(f_classif, k=20)),
    ('model', SVC())
])
# Pipeline 保证每折只在 4 折训练集上调用 fit, 在 1 折验证集上仅调用 transform!
scores = cross_val_score(pipeline, X, y, cv=5)
```

## 11.11 本章陷阱 {#sec-algorithms.3.11.11}

::: errata 本章陷阱

1. **全量数据归一化后再做 CV**：验证集统计量泄露到训练集，误差估计系统性低估。
2. **在 CV 外层做特征选择**：使用全量标签筛选特征，在随机白噪声数据上也能刷出 90% 的虚假准确率。
3. **时间序列使用随机打乱 K-Fold**：模型利用未来时刻的特征预测过去时刻，生产环境完全无法复现。
4. **忽略组结构（Group Leakage）**：同一用户的多条数据被同时切分到训练集与验证集，模型死记硬背了用户特征。
5. **在测试集上反复挑选超参数**：测试集沦为隐式验证集，失去独立的检验能力。
6. **类别不平衡时直接看均方误差或准确率**：少数类召回率为 0 依然能报出 99% 的准确率。
7. **误以为 L1 Lasso 永远优于 L2 Ridge**：在高度共线性的密集特征中，Ridge 的预测均方误差往往显著低于强制稀疏的 Lasso。
8. **比较两个模型只比平均值不报 p 值**：0.5% 的差异可能是折间方差引起的纯随机抖动。
9. **报告测试误差时未固定随机种子**：划分随机变动导致每次实验结果不可复现。
10. **过度调优（Over-searching）**：在极小数据集上搜索上万种超参数组合，必然过拟合验证集。
11. **混淆 AIC 与 BIC 的目标假设**：在寻找真实模型机制时误用 AIC，导致引入过多冗余噪声参数。
12. **嵌套 CV 外层未隔离完整特征管道**：在内外层之间共享了目标编码器，引发隐蔽信息泄漏。

:::

::: method 即时自测

**题目**：考虑普通最小二乘回归（OLS）模型 $\hat{y} = X(X^T X)^{-1} X^T y$。
1. 帽子矩阵 $H = X(X^T X)^{-1} X^T$ 的迹（Trace）$\text{Tr}(H)$ 等于多少？
2. 请解释为什么对角线元素 $h_{ii}$ 被称为样本 $i$ 的“杠杆值（Leverage）”？当某个样本的 $h_{ii} \to 1$ 时，留一法误差公式会有什么表现？

::: sol

**解答**：
1. **计算帽子矩阵的迹**：
   利用矩阵迹的循环置换性质 $\text{Tr}(AB) = \text{Tr}(BA)$：
   $$
   \text{Tr}(H) = \text{Tr}\left( X (X^T X)^{-1} X^T \right) = \text{Tr}\left( (X^T X)^{-1} X^T X \right) = \text{Tr}(I_p) = p
   $$
   其中 $p$ 为特征的维度（即自变量个数，包含截距项）。
   因此，所有样本杠杆值的总和严格等于模型参数数量：$\sum_{i=1}^n h_{ii} = p$。单个样本的平均杠杆值为 $\bar{h} = \frac{p}{n}$。

2. **杠杆值的物理与统计意义**：
   - 因为预测值向量满足 $\hat{y} = H y$，对第 $i$ 个预测值展开：$\hat{y}_i = h_{ii} y_i + \sum_{j \neq i} h_{ij} y_j$。
     偏导数 $\frac{\partial \hat{y}_i}{\partial y_i} = h_{ii}$。这表明 $h_{ii}$ 严格度量了“真实观测值 $y_i$ 对模型自身预测值 $\hat{y}_i$ 的拉扯力/影响力”！
   - 当某个特征孤立异常样本的 $h_{ii} \to 1$ 时，分母 $1 - h_{ii} \to 0$。根据快速 LOOCV 公式：
     $$
     y_i - \hat{y}_{(-i)} = \frac{y_i - \hat{y}_i}{1 - h_{ii}} \to \infty
     $$
     留一法预测误差会急剧趋向无穷大！
     这深刻揭示了高杠杆离群点（High-leverage Outliers）对模型参数的强力支配：如果强行把该样本剔除，整个回归超平面会被剧烈扭转，导致模型对该样本的预测发生毁灭性偏离。
:::
