因果推断（Causal Inference）是数据科学与智能决策皇冠上的明珠。与机器学习预测“在给定特征 $X$ 下目标 $Y$ 的条件分布”不同，因果推断要回答的是“**如果我们主动改变 $X$（实施干预），$Y$ 会发生什么变化**”。

在工业实践中，并非所有场景都能开展大规模随机对照试验（A/B 测试）：政策法规限制、伦理边界、不可逆的系统升级、高昂的试错成本，都迫使我们必须从**观察性数据（Observational Data）** 中挖掘因果效应。但观察数据天然存在内生性（Endogeneity）与选择偏差（Selection Bias）。

本章系统拆解准实验设计的三大核心工具（工具变量法 IV、断点回归 RD、双重差分 DID），并深入因果统计推断的下半场——从复杂非线性估计量的方差推导（Bootstrap 与 Delta 方法），到聚类数据下的稳健置信区间构造，再到量化未观测混杂的敏感性分析。

## 12.1 工具变量的原理与识别 {#sec-algorithms.12.1.1}

内生性问题的标准模型：我们想估计 X 对 Y 的因果效应，但

$$
Y = \beta_0 + \beta_1 X + \epsilon
$$

中，X 与误差项 ε 相关（Cov(X, ε) ≠ 0）。三种常见来源：

1. **遗漏变量偏误**：有未观测的变量 U 同时影响 X 和 Y（如能力影响教育和收入）
2. **反向因果**：Y 也影响 X（如健康影响医疗支出，医疗支出也影响健康）
3. **测量误差**：X 的观测值含噪声（如自报的吸烟量）

OLS 估计 $\hat{\beta}_1^{OLS} = \frac{Cov(X,Y)}{Var(X)}$ 此时有偏，因为

$$
\hat{\beta}_1^{OLS} \xrightarrow{p} \beta_1 + \frac{Cov(X, \epsilon)}{Var(X)}
$$

工具变量 Z 通过提供"外生变异"来解决这个问题。

::: def 定义 12.1.1 · 有效工具变量的条件 {#def-algorithms.12.1.1.1}

变量 Z 是 X 的有效工具变量，当且仅当：

1. **相关性（Relevance）**：Cov(Z, X) ≠ 0。Z 必须与内生变量 X 相关。
2. **外生性（Exogeneity）**：Cov(Z, ε) = 0。Z 不能与误差项相关，即 Z 只通过 X 影响 Y。

:::

**相关性**可以检验（第一阶段 F 统计量），**外生性**无法直接检验（需要理论论证或过度识别检验）。

::: ex 例 12.1.1 · 教育回报的工具变量 {#ex-algorithms.12.1.1.1}

**问题**：估计教育年限（X）对收入（Y）的回报。OLS 有偏，因为能力（未观测）同时影响教育和收入。

**工具变量**：Angrist & Krueger (1991) 使用出生季度（Z）。美国强制入学法规定：满6岁才能入学，且必须上学到16岁生日。出生在年初（如1月）的孩子比年末（如12月）的孩子晚入学几个月，但可以更早辍学（因为16岁生日更早到达）。

**验证**：

- 相关性：出生季度确实影响受教育年限（第一阶段 F = 23，显著）
- 外生性：出生季度（随机）不应直接影响成年后的收入潜力（需要假设）

**估计**：IV 估计的教育回报约 7-10%（每多一年教育，收入增加 7-10%），略高于 OLS 的 5-6%，表明 OLS 有向下偏误（可能因为能力偏误被测量误差抵消）。

:::

### IV 估计的简单推导

在简单线性模型中，IV 估计量为

$$
\hat{\beta}_1^{IV} = \frac{Cov(Z, Y)}{Cov(Z, X)}
$$

**直观理解**：分子是"Z 引起的 Y 的变化"，分母是"Z 引起的 X 的变化"，比值就是"X 对 Y 的因果效应"。

**一致性**：若 Z 满足两个条件，则

$$
\hat{\beta}_1^{IV} \xrightarrow{p} \frac{Cov(Z, Y)}{Cov(Z, X)} = \frac{Cov(Z, \beta_0 + \beta_1 X + \epsilon)}{Cov(Z, X)} = \frac{\beta_1 Cov(Z, X)}{Cov(Z, X)} = \beta_1
$$

（用了 Cov(Z, ε) = 0）。

### 局部平均处理效应（LATE）

当处理效应异质（不同个体 β₁ 不同）时，IV 估计的是**局部平均处理效应**：仅对"顺从者"（compliers）——那些因 Z 改变而改变 X 的个体——的平均效应。

::: def 定义 12.1.2 · LATE 框架中的个体类型 {#def-algorithms.12.1.1.2}

设 Z ∈ {0,1} 是二元工具变量，X(z) 是 Z=z 时的处理状态。个体分为四类：

- **顺从者（Compliers）**：X(1)=1, X(0)=0。Z 改变时 X 跟着变。
- **总是接受者（Always-takers）**：X(1)=1, X(0)=1。无论 Z 如何都接受处理。
- **总是拒绝者（Never-takers）**：X(1)=0, X(0)=0。无论 Z 如何都拒绝处理。
- **叛逆者（Defiers）**：X(1)=0, X(0)=1。Z 改变时 X 反向变动（通常假设不存在）。

IV 估计的是顺从者的平均处理效应（LATE）。

:::

**实际意义**：Angrist & Krueger 的 IV 估计的是"因出生季度而改变教育年限的那部分人"的教育回报，这可能与总体平均效应（ATE）不同。

## 12.2 两阶段最小二乘（2SLS） {#sec-algorithms.12.1.2}

当有多个工具变量或多个内生变量时，用两阶段最小二乘（2SLS）实现 IV 估计。

### 2SLS 的两步

**第一阶段**：用所有外生变量（包括工具变量 Z 和其他控制变量 W）回归内生变量 X：

$$
X = \pi_0 + \pi_1 Z + \pi_2 W + \nu
$$

得到拟合值 $\hat{X}$。

**第二阶段**：用 $\hat{X}$ 代替 X，回归 Y：

$$
Y = \beta_0 + \beta_1 \hat{X} + \beta_2 W + \epsilon
$$

得到的 $\hat{\beta}_1$ 就是 2SLS 估计量。

**为什么分两步**？第一阶段分解 X 为"外生部分" $\hat{X}$（由 Z 和 W 解释）和"内生部分" ν（与 ε 可能相关）。第二阶段只用 $\hat{X}$，排除了内生部分，得到一致估计。

::: note 标准误的计算

直接用第二阶段 OLS 的标准误是错误的（会低估真实标准误），因为 $\hat{X}$ 是估计出来的，有抽样误差。正确做法是：

1. 用专门的 2SLS 公式计算标准误（大部分统计软件自动处理）
2. 或用 Bootstrap 方法（见第 13 章）

:::

### 弱工具变量问题

::: def 定义 12.2.1 · 弱工具变量 {#def-algorithms.12.1.2.1}

若第一阶段 F 统计量 < 10（Stock & Yogo, 2005 的经验法则），则称工具变量"弱"。弱工具变量导致：

1. IV 估计量有偏（向 OLS 偏误）
2. 标准误不可靠（Wald 统计量的渐近分布失效）
3. 置信区间覆盖率不足

:::

**检验方法**：

1. **第一阶段 F 统计量**：检验 H₀: π₁ = 0。若 F < 10，警惕弱工具变量。
2. **Cragg-Donald 统计量**（多个内生变量时）：类似 F 统计量的推广。

::: ex 例 12.2.1 · 2SLS 估计与弱工具变量检验 {#ex-algorithms.12.1.2.1}

**数据生成过程**：

```python
n = 1000
Z = np.random.normal(0, 1, n)      # 工具变量
U = np.random.normal(0, 1, n)      # 未观测混杂因子
X = 0.5 * Z + U + np.random.normal(0, 0.5, n)  # 内生变量
Y = 2.0 * X + U + np.random.normal(0, 1, n)    # 结果变量
```

真实因果效应 β₁ = 2.0。X 与误差项相关（都包含 U），OLS 有偏。

**OLS 估计**：

```python
from sklearn.linear_model import LinearRegression

ols = LinearRegression().fit(X.reshape(-1,1), Y)
print(f"OLS 估计: {ols.coef_[0]:.3f}")  # 约 2.5（向上偏）
```

**2SLS 估计**：

```python
# 第一阶段：X ~ Z
stage1 = LinearRegression().fit(Z.reshape(-1,1), X)
X_hat = stage1.predict(Z.reshape(-1,1))

# 检验弱工具变量
from scipy import stats
residuals = X - X_hat
sse = np.sum(residuals**2)
mse = sse / (n - 2)
se_pi1 = np.sqrt(mse / np.sum((Z - Z.mean())**2))
t_stat = stage1.coef_[0] / se_pi1
f_stat = t_stat**2
print(f"第一阶段 F 统计量: {f_stat:.2f}")  # 应 > 10

# 第二阶段：Y ~ X_hat
stage2 = LinearRegression().fit(X_hat.reshape(-1,1), Y)
print(f"2SLS 估计: {stage2.coef_[0]:.3f}")  # 约 2.0（无偏）
```

**结果**：OLS 估计约 2.5（有偏），2SLS 估计约 2.0（一致估计），F 统计量 > 100（强工具变量）。

:::

### 过度识别检验（Sargan-Hansen J 检验）

当工具变量数量 > 内生变量数量时（过度识别），可以检验"多余"的工具变量是否都满足外生性条件。

**原理**：若所有工具变量都外生，则 2SLS 残差 $\hat{\epsilon}$ 应与所有工具变量不相关。J 统计量检验这个零假设：

$$
J = n \cdot R^2_{第一阶段} \sim \chi^2_{过度识别约束数}
$$

其中 $R^2_{第一阶段}$ 是用所有工具变量回归 2SLS 残差的 R²。

**注意**：J 检验的零假设是"至少一个工具变量外生"（而非"所有工具变量外生"）。若所有工具变量都内生，J 检验无能为力。

## 12.3 断点回归设计 {#sec-algorithms.12.1.3}

断点回归（Regression Discontinuity Design, RD）利用政策规则的不连续性识别因果效应。核心思想：在阈值附近，处理分配近似随机。

### RD 的基本框架

**设定**：存在一个"运行变量"（running variable）R 和阈值 c。处理分配规则为

$$
D = \begin{cases} 1 & \text{if } R \geq c \\ 0 & \text{if } R < c \end{cases}
$$

**估计目标**：阈值处的处理效应

$$
\tau = \lim_{r \to c^+} \mathbb{E}[Y | R=r] - \lim_{r \to c^-} \mathbb{E}[Y | R=r]
$$

即"刚好在阈值右侧"与"刚好在阈值左侧"的结果差异。

::: ex 例 12.3.1 · 录取分数线对大学成就的影响 {#ex-algorithms.12.1.3.1}

**研究问题**：被录取进名校对学生后续成就有多大影响？

**RD 设计**：录取分数线是阈值 c。刚好达线的学生（R ≈ c⁺）与刚好未达线的学生（R ≈ c⁻）能力相似，但一个被录取、一个未录取。比较两组的毕业率、就业率等。

**关键假设**：在阈值附近，除了处理分配，其他因素连续变化（见下文）。

:::

### Sharp RD vs Fuzzy RD

- **Sharp RD**：阈值处处理分配从 0 跳到 1（如例 12.3.1 的录取规则严格执行）。
- **Fuzzy RD**：阈值处处理概率跳跃，但不是 0→1（如录取后有人放弃入学）。Fuzzy RD 用 IV 方法估计，把"超过阈值"作为工具变量。

### RD 的识别假设与验证

::: def 定义 12.3.1 · RD 的核心假设 {#def-algorithms.12.1.3.1}

**连续性假设**：在阈值 c 处，潜在结果 Y(0) 和 Y(1) 关于运行变量 R 连续。即，若无处理，阈值两侧的结果应平滑过渡。

等价地：

$$
\lim_{r \to c^+} \mathbb{E}[Y(0) | R=r] = \lim_{r \to c^-} \mathbb{E}[Y(0) | R=r]
$$

$$
\lim_{r \to c^+} \mathbb{E}[Y(1) | R=r] = \lim_{r \to c^-} \mathbb{E}[Y(1) | R=r]
$$

:::

**如何验证**？

1. **检查协变量的连续性**：基线特征（性别、家庭背景等）在阈值处应连续。若某个协变量跳跃，说明阈值附近的个体不可比。

2. **检查运行变量密度的连续性（McCrary test）**：若个体能精确操控运行变量（如刚好踩线作弊），则阈值右侧会有异常多的观测。绘制 R 的密度函数，检验阈值处是否有跳跃。

3. **安慰剂检验（Placebo test）**：在真实阈值附近选一个假阈值，重新估计。若假阈值处也有显著"效应"，说明模型设定有问题。

::: ex 例 12.3.2 · RD 估计的实现 {#ex-algorithms.12.1.3.2}

**数据生成**（Sharp RD）：

```python
n = 500
R = np.random.uniform(-2, 2, n)  # 运行变量
D = (R >= 0).astype(int)         # 处理分配（阈值=0）
Y = 2 + 0.5*R + 1.5*D + np.random.normal(0, 0.5, n)  # 结果（真实效应=1.5）
```

**局部线性回归估计**（带宽 h=0.5）：

```python
from sklearn.linear_model import LinearRegression

h = 0.5
left = (R >= -h) & (R < 0)
right = (R >= 0) & (R < h)

model_left = LinearRegression().fit(R[left].reshape(-1,1), Y[left])
model_right = LinearRegression().fit(R[right].reshape(-1,1), Y[right])

# 阈值处的预测值
y_left = model_left.predict([[0]])[0]
y_right = model_right.predict([[0]])[0]
tau_est = y_right - y_left

print(f"RD 估计: {tau_est:.3f}  (真实值: 1.5)")
```

**带宽选择**：太小则方差大，太大则偏误大。常用 Imbens & Kalyanaraman (2012) 的最优带宽公式，或交叉验证。

:::

### RD 的优势与局限

**优势**：
- 识别假设比 IV 弱（只需阈值处连续，不需要全局外生性）
- 可视化直观（画出 Y 对 R 的散点图，跳跃一目了然）
- 部分可检验（协变量连续性、密度连续性）

**局限**：
- 外部效度有限：估计的是"阈值附近个体"的效应，不一定推广到远离阈值的群体
- 需要大样本（阈值附近的观测可能不多）
- 对函数形式敏感（线性？多项式？需要稳健性检验）

## 12.4 双重差分（DID） {#sec-algorithms.12.1.4}

双重差分（Difference-in-Differences, DID）比较处理组与对照组在干预前后的变化差异，控制不随时间变化的混杂因素。

### DID 的基本框架

**设定**：两个时期（t=0 前，t=1 后），两组（处理组 G=1，对照组 G=0）。只有处理组在 t=1 接受处理。

**结果的均值**：

| | t=0（前） | t=1（后） | 时间差异 |
|:--|:--|:--|:--|
| 处理组（G=1） | $\bar{Y}_{1,0}$ | $\bar{Y}_{1,1}$ | $\bar{Y}_{1,1} - \bar{Y}_{1,0}$ |
| 对照组（G=0） | $\bar{Y}_{0,0}$ | $\bar{Y}_{0,1}$ | $\bar{Y}_{0,1} - \bar{Y}_{0,0}$ |
| 组间差异 | $\bar{Y}_{1,0} - \bar{Y}_{0,0}$ | $\bar{Y}_{1,1} - \bar{Y}_{0,1}$ | **DID 估计量** |

**DID 估计量**：

$$
\hat{\tau}^{DID} = (\bar{Y}_{1,1} - \bar{Y}_{1,0}) - (\bar{Y}_{0,1} - \bar{Y}_{0,0})
$$

即"处理组的时间差异"减去"对照组的时间差异"。

**回归形式**：

$$
Y_{it} = \beta_0 + \beta_1 \cdot Post_t + \beta_2 \cdot Treat_i + \beta_3 \cdot (Post_t \times Treat_i) + \epsilon_{it}
$$

其中 $Post_t = \mathbb{1}(t=1)$，$Treat_i = \mathbb{1}(G=1)$。DID 估计量就是交互项系数 $\hat{\beta}_3$。

### 平行趋势假设

::: def 定义 12.4.1 · 平行趋势假设 {#def-algorithms.12.1.4.1}

若无干预，处理组与对照组的结果随时间的变化趋势相同。数学表达：

$$
\mathbb{E}[Y_{i,1}(0) - Y_{i,0}(0) | G=1] = \mathbb{E}[Y_{i,1}(0) - Y_{i,0}(0) | G=0]
$$

即，两组的"反事实时间趋势"平行。

:::

**为什么需要**？DID 估计的是

$$
\hat{\tau}^{DID} = \underbrace{[Y_{1,1}(1) - Y_{1,0}(0)]}_{\text{处理组时间差异}} - \underbrace{[Y_{0,1}(0) - Y_{0,0}(0)]}_{\text{对照组时间差异}}
$$

第一项 = $\tau$ (处理效应) + [处理组反事实趋势]，第二项 = [对照组反事实趋势]。若平行趋势成立，两个反事实趋势抵消，剩下 τ。

**如何检验**？

1. **事件研究图（Event study plot）**：若有多期数据，画出处理组与对照组相对于干预时点的趋势图。干预前应平行，干预后才分离。

2. **安慰剂检验**：用干预前的某个时点作为"假干预"，重新估计 DID。若显著，说明平行趋势不成立。

::: ex 例 12.4.1 · 最低工资对就业的影响（Card & Krueger, 1994） {#ex-algorithms.12.1.4.1}

**研究问题**：提高最低工资是否降低就业？

**设计**：1992 年新泽西州提高最低工资，宾夕法尼亚州未提高。比较两州快餐店就业人数的变化。

- 处理组：新泽西州快餐店
- 对照组：宾夕法尼亚州快餐店
- 干预前：1992年2月
- 干预后：1992年11月

**结果**：

| | 干预前 | 干预后 | 时间差异 |
|:--|:--|:--|:--|
| 新泽西（处理组） | 20.4 | 21.0 | +0.6 |
| 宾州（对照组） | 23.3 | 21.2 | -2.1 |
| **DID 估计** | | | **+2.7** |

最低工资提高后，新泽西的就业反而增加了 2.7 人（相对于宾州），与传统理论预测相反。

**平行趋势验证**：作者收集了更早期的数据，显示干预前两州快餐店就业趋势相似。

:::

### 多期 DID 与渐进采纳设计

当有多个时期、不同组在不同时点接受处理时（staggered adoption），标准 DID 估计量可能有偏（Goodman-Bacon, 2021）。问题在于：后处理的对照组可能包含早期处理组，导致"负权重"。

**解决方案**：

1. **事件研究设计**：估计相对于处理时点的每一期效应，而非单个平均效应。
2. **Callaway & Sant'Anna (2021) 估计量**：分组计算 DID，避免负权重问题。
3. **限制样本**：只用"从未处理"的组作为对照。


## 12.5 Bootstrap 方法 {#sec-algorithms.12.1.5}

Bootstrap 的核心思想：**用样本分布近似总体分布，用重抽样分布近似抽样分布**。

### 非参数 Bootstrap

::: def 定义 12.5.1 · 非参数 Bootstrap {#def-algorithms.13.1.1.1}

设样本为 $\{X_1, ..., X_n\}$，统计量为 $\hat{\theta} = T(X_1, ..., X_n)$。非参数 Bootstrap 的步骤：

1. **重抽样**：从原样本中有放回抽取 n 个观测，得到 Bootstrap 样本 $\{X_1^*, ..., X_n^*\}$。
2. **计算统计量**：在 Bootstrap 样本上计算 $\hat{\theta}^* = T(X_1^*, ..., X_n^*)$。
3. **重复 B 次**：得到 B 个 Bootstrap 统计量 $\{\hat{\theta}_1^*, ..., \hat{\theta}_B^*\}$。
4. **估计标准误**：Bootstrap 标准误为

$$
SE_{boot}(\hat{\theta}) = \sqrt{\frac{1}{B-1} \sum_{b=1}^B (\hat{\theta}_b^* - \bar{\theta}^*)^2}
$$

其中 $\bar{\theta}^* = \frac{1}{B} \sum_{b=1}^B \hat{\theta}_b^*$。

:::

**为什么有效**？Glivenko-Cantelli 定理保证：当 n→∞ 时，经验分布函数 $\hat{F}_n$ 一致收敛到真实分布 F。Bootstrap 用 $\hat{F}_n$ 代替 F，在大样本下近似抽样分布。

::: ex 例 13.1.1 · Bootstrap 估计中位数的标准误 {#ex-algorithms.13.1.1.1}

**问题**：样本中位数的标准误没有简单公式（取决于密度函数在中位数处的值）。用 Bootstrap 估计。

```python
import numpy as np

np.random.seed(42)
data = np.random.lognormal(0, 1, 100)  # 偏态分布
median_obs = np.median(data)
print(f"观测中位数: {median_obs:.3f}")

# Bootstrap
B = 10000
medians_boot = []
for b in range(B):
    sample_boot = np.random.choice(data, size=len(data), replace=True)
    medians_boot.append(np.median(sample_boot))

medians_boot = np.array(medians_boot)
se_boot = np.std(medians_boot, ddof=1)
print(f"Bootstrap 标准误: {se_boot:.3f}")

# 95% 置信区间（百分位法）
ci_lower = np.percentile(medians_boot, 2.5)
ci_upper = np.percentile(medians_boot, 97.5)
print(f"95% 置信区间: [{ci_lower:.3f}, {ci_upper:.3f}]")
```

**输出**：

```
观测中位数: 1.023
Bootstrap 标准误: 0.087
95% 置信区间: [0.862, 1.197]
```

:::

### Bootstrap 置信区间的三种方法

1. **正态近似区间**：

$$
[\hat{\theta} - z_{1-\alpha/2} \cdot SE_{boot}, \hat{\theta} + z_{1-\alpha/2} \cdot SE_{boot}]
$$

假设 $\hat{\theta}$ 渐近正态。简单但可能覆盖率不足（尤其是偏态统计量）。

2. **百分位法（Percentile method）**：

$$
[\hat{\theta}^*_{(\alpha/2)}, \hat{\theta}^*_{(1-\alpha/2)}]
$$

其中 $\hat{\theta}^*_{(q)}$ 是 Bootstrap 分布的 q 分位数。不依赖正态假设，但对变换不变性差。

3. **BCa 区间（Bias-Corrected and Accelerated）**：

调整了偏误和偏度，覆盖率更准确。计算复杂，需要 jackknife 估计加速常数。Python 的 `scipy.stats.bootstrap` 支持此方法。

**选择建议**：

- 统计量近似正态：用正态近似（最快）
- 统计量偏态：用百分位法或 BCa
- 样本量小（n < 50）：Bootstrap 本身不可靠，考虑参数方法

### 参数 Bootstrap

::: def 定义 12.5.2 · 参数 Bootstrap {#def-algorithms.13.1.1.2}

假设数据来自参数分布族 $F_\theta$，参数估计为 $\hat{\theta}$。参数 Bootstrap 的步骤：

1. 从 $F_{\hat{\theta}}$ 生成 Bootstrap 样本（而非从原样本重抽样）
2. 在 Bootstrap 样本上计算统计量
3. 重复 B 次，估计标准误

:::

**何时用参数 Bootstrap**？

- 数据明显来自特定分布（如正态、泊松），且参数估计稳定
- 样本量小，非参数 Bootstrap 不稳定
- 需要模拟罕见事件（如极端分位数）

**缺点**：若模型设定错误（如假设正态但实际偏态），参数 Bootstrap 失效。

::: ex 例 13.1.2 · 参数 Bootstrap 估计比率的标准误 {#ex-algorithms.13.1.1.2}

**问题**：两个泊松计数的比率 $\theta = \lambda_1 / \lambda_2$。

```python
from scipy.stats import poisson

# 观测数据
count1, count2 = 45, 30
n1, n2 = 100, 100
lambda1_hat = count1 / n1  # 0.45
lambda2_hat = count2 / n2  # 0.30
ratio_obs = lambda1_hat / lambda2_hat  # 1.5

# 参数 Bootstrap
B = 10000
ratios_boot = []
for b in range(B):
    count1_boot = poisson.rvs(lambda1_hat * n1)
    count2_boot = poisson.rvs(lambda2_hat * n2)
    lambda1_boot = count1_boot / n1
    lambda2_boot = count2_boot / n2
    if lambda2_boot > 0:  # 避免除零
        ratios_boot.append(lambda1_boot / lambda2_boot)

ratios_boot = np.array(ratios_boot)
se_boot = np.std(ratios_boot, ddof=1)
print(f"比率估计: {ratio_obs:.3f}, Bootstrap SE: {se_boot:.3f}")
```

:::

### 分层 Bootstrap 与聚类 Bootstrap

**分层 Bootstrap**：当样本有分层结构（如按年龄组抽样）时，在每层内独立 Bootstrap，保持层间比例。

**聚类 Bootstrap**：当数据有聚类结构（如学生嵌套在学校）时，重抽样单位是聚类（整个学校），而非个体。

::: ex 例 13.1.3 · 聚类 Bootstrap {#ex-algorithms.13.1.1.3}

**数据结构**：20 个学校，每校 50 个学生。估计教学方法对成绩的影响。

**错误做法**：把 1000 个学生当作独立样本，直接 Bootstrap。

**正确做法**：重抽样 20 个学校（有放回），每次抽到一个学校时，保留该校所有学生。

```python
# 数据结构：df 有 'school_id' 和 'score' 列
schools = df['school_id'].unique()  # 20 所学校
n_schools = len(schools)

B = 1000
effects_boot = []
for b in range(B):
    # 重抽样学校
    schools_boot = np.random.choice(schools, size=n_schools, replace=True)
    # 提取这些学校的所有学生
    df_boot = df[df['school_id'].isin(schools_boot)]
    # 计算效应（如 DID 估计量）
    effect_boot = compute_did(df_boot)
    effects_boot.append(effect_boot)

se_boot = np.std(effects_boot, ddof=1)
```

**为什么必须聚类**？同一学校的学生成绩相关（校内相关性），若当作独立样本，会低估标准误。

:::

## 12.6 Delta 方法 {#sec-algorithms.12.1.6}

Delta 方法用泰勒展开近似非线性函数的方差，适用于参数估计渐近正态的情形。

::: thm 定理 12.6.1 · Delta 方法（单变量） {#thm-algorithms.13.1.2.1}

设 $\hat{\theta} \sim \mathcal{N}(\theta, \sigma^2)$（至少渐近正态），g(·) 在 θ 处可微。则

$$
g(\hat{\theta}) \sim \mathcal{N}(g(\theta), [g'(\theta)]^2 \sigma^2)
$$

即，g($\hat{\theta}$) 的方差约为

$$
Var[g(\hat{\theta})] \approx [g'(\theta)]^2 \cdot Var(\hat{\theta})
$$

:::

**直观理解**：用一阶泰勒展开

$$
g(\hat{\theta}) \approx g(\theta) + g'(\theta) \cdot (\hat{\theta} - \theta)
$$

右侧是线性函数，方差为 $[g'(\theta)]^2 \cdot Var(\hat{\theta})$。

::: ex 例 13.2.1 · 对数变换的标准误 {#ex-algorithms.13.1.2.1}

**问题**：$\hat{\theta} = 5$, $SE(\hat{\theta}) = 1$。求 $\log(\hat{\theta})$ 的标准误。

**解**：g(θ) = log(θ), g'(θ) = 1/θ。在 θ=5 处，g'(5) = 0.2。

$$
SE[\log(\hat{\theta})] \approx |g'(5)| \cdot SE(\hat{\theta}) = 0.2 \times 1 = 0.2
$$

**验证**（用 Bootstrap）：

```python
theta_samples = np.random.normal(5, 1, 10000)
log_theta_samples = np.log(theta_samples)
print(f"Delta 方法: 0.200")
print(f"Bootstrap: {np.std(log_theta_samples):.3f}")  # 约 0.201
```

:::

### 多变量 Delta 方法

::: thm 定理 12.6.2 · Delta 方法（多变量） {#thm-algorithms.13.1.2.2}

设 $\hat{\theta} = (\hat{\theta}_1, ..., \hat{\theta}_p) \sim \mathcal{N}(\theta, \Sigma)$，g: ℝᵖ → ℝ 在 θ 处可微。则

$$
g(\hat{\theta}) \sim \mathcal{N}(g(\theta), \nabla g(\theta)^T \Sigma \nabla g(\theta))
$$

其中 $\nabla g(\theta) = (\frac{\partial g}{\partial \theta_1}, ..., \frac{\partial g}{\partial \theta_p})^T$。

:::

::: ex 例 13.2.2 · 比率的标准误 {#ex-algorithms.13.1.2.2}

**问题**：估计两个独立均值的比率 $\theta = \mu_1 / \mu_2$。已知 $\hat{\mu}_1 = 10$, $SE(\hat{\mu}_1) = 2$, $\hat{\mu}_2 = 5$, $SE(\hat{\mu}_2) = 1$。

**解**：g(μ₁, μ₂) = μ₁/μ₂。偏导数：

$$
\frac{\partial g}{\partial \mu_1} = \frac{1}{\mu_2}, \quad \frac{\partial g}{\partial \mu_2} = -\frac{\mu_1}{\mu_2^2}
$$

在 (10, 5) 处：

$$
\nabla g = \begin{pmatrix} 1/5 \\ -10/25 \end{pmatrix} = \begin{pmatrix} 0.2 \\ -0.4 \end{pmatrix}
$$

协方差矩阵（独立）：

$$
\Sigma = \begin{pmatrix} 4 & 0 \\ 0 & 1 \end{pmatrix}
$$

Delta 方法方差：

$$
Var(\hat{\theta}) \approx \nabla g^T \Sigma \nabla g = (0.2)^2 \times 4 + (-0.4)^2 \times 1 = 0.16 + 0.16 = 0.32
$$

$$
SE(\hat{\theta}) \approx \sqrt{0.32} = 0.566
$$

**比率**：10/5 = 2, 标准误 0.566。

:::

### Delta 方法的局限

1. **非线性强时**：一阶近似不够，需要二阶 Delta 方法或 Bootstrap。
2. **小样本**：渐近正态性不成立，Delta 方法失效。
3. **边界问题**：如概率（0-1 之间），Delta 方法可能给出越界置信区间。解决方案：先做 logit 变换，再用 Delta 方法。

## 12.7 因果效应的置信区间 {#sec-algorithms.12.1.7}

因果推断中的估计量（IV、RD、DID）有特殊的方差结构，需要考虑聚类、分层、异方差等因素。

### IV 估计量的标准误

2SLS 估计量的标准误公式复杂，手工推导容易出错。实践中有三种方法：

1. **解析公式**：大部分统计软件（R 的 `ivreg`, Python 的 `linearmodels.IVGMM`）自动计算，考虑异方差稳健标准误。

2. **Bootstrap**：对整个 2SLS 过程 Bootstrap（不能只 Bootstrap 第二阶段）。

3. **GMM 框架**：将 2SLS 视为 GMM 估计器，用 GMM 的标准误公式（Newey-West 或 HAC 标准误）。

::: ex 例 13.3.1 · IV 估计的稳健标准误 {#ex-algorithms.13.1.3.1}

```python
from linearmodels.iv import IV2SLS

# 数据：Y, X (内生), Z (工具变量), W (控制变量)
model = IV2SLS(Y, exog=W, endog=X, instruments=Z).fit(cov_type='robust')
print(model.summary)

# Bootstrap 验证
B = 1000
coefs_boot = []
n = len(Y)
for b in range(B):
    idx = np.random.choice(n, n, replace=True)
    Y_boot = Y[idx]
    X_boot = X[idx]
    Z_boot = Z[idx]
    W_boot = W[idx]
    model_boot = IV2SLS(Y_boot, exog=W_boot, endog=X_boot, instruments=Z_boot).fit()
    coefs_boot.append(model_boot.params['X'])

se_boot = np.std(coefs_boot, ddof=1)
print(f"解析 SE: {model.std_errors['X']:.3f}")
print(f"Bootstrap SE: {se_boot:.3f}")  # 应接近
```

:::

### RD 估计量的标准误

RD 估计的标准误取决于：

1. **带宽 h**：h 越小，方差越大（样本量少）但偏误越小。
2. **核函数**：三角核、Epanechnikov 核等，影响有效样本量。
3. **异方差**：阈值两侧方差可能不同，需要稳健标准误。

**实践建议**：用 `rdrobust` 包（R/Python），它自动选择最优带宽并计算稳健标准误。

```python
from rdrobust import rdrobust

# R: 运行变量, Y: 结果, c: 阈值
result = rdrobust(Y, R, c=0, kernel='triangular', bwselect='mserd')
print(result.summary())
# 输出包含：最优带宽、稳健 SE、置信区间
```

### DID 估计量的聚类标准误

DID 数据通常有两层聚类：

1. **个体层面**：同一个体的多期观测相关
2. **组层面**：同一组（如同一州）的不同个体可能相关

**标准做法**：双向聚类标准误（clustered by unit and time）。

::: ex 例 13.3.2 · DID 的双向聚类标准误 {#ex-algorithms.13.1.3.2}

```python
import statsmodels.formula.api as smf

# 数据：Y 结果, treat 处理组, post 干预后, unit_id 个体, time 时期
formula = 'Y ~ treat + post + treat:post'
model = smf.ols(formula, data=df).fit(
    cov_type='cluster',
    cov_kwds={'groups': df[['unit_id', 'time']]}  # 双向聚类
)
print(model.summary())
```

**注意**：当聚类数 < 50 时，渐近理论不可靠。考虑：

- Wild cluster bootstrap（Cameron et al., 2008）
- 或用 randomization inference（Fisher 精确检验）

:::

## 12.8 敏感性分析 {#sec-algorithms.12.1.8}

因果推断的识别假设（如 IV 的外生性、DID 的平行趋势）无法完全检验。敏感性分析量化："若假设违反到什么程度,结论会翻转？"

### Rosenbaum 界（匹配研究）

在倾向得分匹配（PSM）中，假设"条件独立性"：给定协变量 X，处理分配与潜在结果独立。但若有未观测混杂因子 U，这个假设失效。

::: def 定义 13.4.1 · Rosenbaum 敏感性参数 Γ {#def-algorithms.13.1.4.1}

设两个个体 i 和 j 有相同的观测协变量 X，但未观测因子 U 不同。Γ 是两者处理概率的比值上界：

$$
\frac{1}{\Gamma} \leq \frac{P(D_i=1 | X, U_i) / P(D_i=0 | X, U_i)}{P(D_j=1 | X, U_j) / P(D_j=0 | X, U_j)} \leq \Gamma
$$

Γ = 1 表示无隐藏偏误（条件独立性成立）。Γ = 2 表示，即使观测协变量相同，两个个体的处理几率比最多差 2 倍。

:::

**Rosenbaum 界的计算**：对每个 Γ（如 1.1, 1.2, ..., 2.0），计算在"最不利的隐藏偏误配置"下的 p 值上界。若 Γ=1.5 时 p 值上界 > 0.05，说明效应对中等隐藏偏误敏感。

::: ex 例 13.4.1 · Rosenbaum 敏感性分析 {#ex-algorithms.13.1.4.1}

**研究**：匹配研究显示吸烟者肺癌风险显著高于非吸烟者（p < 0.01）。但可能有未观测的遗传因素同时影响吸烟倾向和肺癌风险。

**敏感性分析**（用 R 的 `rbounds` 包）：

```text
# R 敏感性分析调用 (rbounds 包)
library(rbounds)
# outcome: 肺癌 (0/1), gamma 从 1 到 2
psens(outcome, Gamma=seq(1, 2, 0.1))
```

**结果示例**：

| Γ | p 值上界 |
|:--|:--|
| 1.0 | 0.008 |
| 1.3 | 0.023 |
| 1.5 | 0.051 |
| 1.8 | 0.102 |

**解读**：即使存在未观测混杂因子使处理几率比相差 50%（Γ=1.5），p 值上界刚好超过 0.05，效应仍"边缘显著"。若 Γ=1.8（几率比差 80%），效应不再显著。结论对中等隐藏偏误较稳健。

:::

### E-value（一般因果效应）

E-value（VanderWeele & Ding, 2017）推广了 Rosenbaum 界的思想，适用于任何因果效应估计（包括回归、IV、RD）。

::: def 定义 13.4.2 · E-value {#def-algorithms.13.1.4.2}

E-value 是"未观测混杂因子与处理、结果的关联强度"的最小值，使得观测到的因果效应可以完全被该混杂因子解释（效应降为 0）。

形式上，设风险比 RR 是观测到的效应（如 RR=2 表示处理组风险是对照组的 2 倍）。E-value 为

$$
E\text{-value} = RR + \sqrt{RR \cdot (RR - 1)}
$$

:::

**直观理解**：若 E-value = 3，则需要一个"与处理的关联强度 ≥ 3 且与结果的关联强度 ≥ 3"的未观测混杂因子，才能将观测效应解释为 0。E-value 越大,结论越稳健。

::: ex 例 13.4.2 · E-value 计算 {#ex-algorithms.13.1.4.2}

**研究**：某药物使心脏病风险降低 50%（RR = 0.5, 即处理组风险是对照组的一半）。

**E-value**（针对风险比 0.5）：

$$
E = \frac{1}{RR} + \sqrt{\frac{1}{RR} \cdot (\frac{1}{RR} - 1)} = 2 + \sqrt{2 \cdot 1} = 2 + 1.41 = 3.41
$$

**解读**：需要一个未观测混杂因子（如遗传标记）与用药的关联强度 ≥ 3.41，且与心脏病的关联强度 ≥ 3.41，才能将保护效应解释为 0。已知的最强混杂因子（如吸烟）关联强度约 2-3，故结论相对稳健。

**Python 实现**：

```python
def e_value(RR):
    """计算风险比 RR 的 E-value"""
    if RR < 1:
        RR = 1 / RR  # 转换为 RR > 1
    return RR + np.sqrt(RR * (RR - 1))

print(f"RR=0.5 的 E-value: {e_value(0.5):.2f}")  # 3.41
print(f"RR=2.0 的 E-value: {e_value(2.0):.2f}")  # 3.41（对称）
```

:::

### 安慰剂结果检验

安慰剂结果（placebo outcome）是理论上不应受处理影响的结果。若安慰剂结果也显示"效应"，说明存在未控制的混杂。

::: ex 例 13.4.3 · 安慰剂结果检验 {#ex-algorithms.13.1.4.3}

**主要分析**：教育干预对数学成绩的影响（显著正效应）。

**安慰剂结果**：干预前的数学成绩（干预不应影响过去）。若回归显示"干预对干预前成绩也有正效应"，说明：

- 处理组与对照组在基线就不可比（选择偏误）
- 或数据有测量误差/录入错误

**实施**：

```python
# 主要回归：干预 → 干预后成绩
main_result = smf.ols('post_score ~ treatment + baseline_controls', data=df).fit()
print(main_result.summary())

# 安慰剂回归：干预 → 干预前成绩（应不显著）
placebo_result = smf.ols('pre_score ~ treatment + baseline_controls', data=df).fit()
print(f"安慰剂效应: {placebo_result.params['treatment']:.3f}, p={placebo_result.pvalues['treatment']:.3f}")

if placebo_result.pvalues['treatment'] < 0.05:
    print("警告：安慰剂结果显著，存在未控制混杂或数据问题！")
```

:::


## 12.9 Agent 陷阱：因果推断中的隐蔽偏误与推断失真 {#sec-algorithms.12.1.9}

在因果推断任务中，大模型 Agent 最常犯的两类致命错误是：**弱工具变量（导致点估计严重有偏）** 与 **忽略聚类相关性（导致置信区间虚假狭窄）**。以下为典型失败模式与防御规范：

### 陷阱 1：不检验第一阶段 F 统计量，盲目采纳弱工具变量
```python
# 错误做法：直接运行 2SLS，若系数显著就报告结果
iv = IV2SLS(y, df[["const", "controls"]], df["treatment"], df["instrument"]).fit()
print(iv.summary()) # 忽视第一阶段 F 统计量！

# 正确做法：必须显式提取第一阶段回归的 F 统计量，确保 F > 10 (或 Stock-Yogo 临界值)
first_stage = sm.OLS(df["treatment"], sm.add_constant(df[["instrument", "controls"]])).fit()
f_stat = first_stage.fvalue
if f_stat < 10:
    raise ValueError(f"弱工具变量警告: 第一阶段 F = {f_stat:.2f} < 10，2SLS 点估计与标准误不可靠！")
```

### 陷阱 2：用“显著性”替代外生性论证
Agent 常犯的认识错误是：认为工具变量只要与内生变量高度显著相关（$p < 0.001$）就是好工具变量。但**外生性假设 $	ext{Cov}(Z, \epsilon) = 0$ 无法通过数据本身检验**（在恰好识别情形下），必须依靠经济学机制或物理实验设计论证排他性约束（Exclusion Restriction）。

### 陷阱 3：RD 中不检验断点两侧协变量连续性与密度连续性
```python
# 错误：只在断点两侧拟合多项式，直接报告跳跃值
# 正确：必须进行 McCrary 密度检验与预定协变量平滑性检验
for cov in ["age", "gender", "baseline_score"]:
    rd_cov = rdd.rdd(df, "running_var", cov, cut=threshold)
    # 断点处预定协变量不应存在显著跳跃
    assert rd_cov.p_values["treatment"] > 0.05, f"协变量 {cov} 在断点处不连续！"
```

### 陷阱 4：DID 中不画动态事件研究图，盲目相信两期差分
双重差分成立的基石是平行趋势。如果干预前处理组与对照组本身就存在分流趋势，DID 估计的政策效应就会吸收掉原有趋势。
```python
# 必须运行事件研究模型（Event Study Specification）：
# Y_it = alpha_i + lambda_t + sum_{k != -1} beta_k * D_{it}^k + eps_it
# 检验 k < 0 (干预前) 的 beta_k 是否联合为 0
pre_treatment_betas = [model.params[f"event_{k}"] for k in range(-5, 0)]
# 若预处理系数显著偏离 0，平行趋势假设被推翻！
```

### 陷阱 5：面板与分层数据忽略聚类标准误（Clustered SE）
```python
# 错误：使用默认的同方差或稳健标准误（假设残差在所有维度独立）
ols_se = sm.OLS(y, X).fit(cov_type="HC1").bse["treatment"]

# 正确：必须按聚类单元（学校、公司、用户 ID）聚类
cluster_se = sm.OLS(y, X).fit(cov_type="cluster", cov_kwds={"groups": df["cluster_id"]}).bse["treatment"]
# 实测聚类标准误通常是朴素标准误的 2~5 倍！
```

### 陷阱 6：在聚类数据上使用朴素行重抽样 Bootstrap
普通逐行重抽样会打碎同一组内的序列自相关结构。对于面板数据，必须使用**块重抽样（Block / Clustered Bootstrap）**：每次抽取一个完整的群组（如整个学校）。

### 陷阱 7：非线性参数变换使用 Delta 方法时忽略参数协方差
估计比例指标 $\hat{	heta} = \hat{eta}_1 / \hat{eta}_2$ 时，若直接使用独立方差计算公式，忽略 $	ext{Cov}(\hat{eta}_1, \hat{eta}_2)$，会导致方差估计严重偏误。必须使用完整的渐近雅可比矩阵：
$$
	ext{Var}(\hat{	heta}) pprox J V J^T = egin{bmatrix} rac{1}{eta_2} & -rac{eta_1}{eta_2^2} \end{bmatrix} egin{bmatrix} 	ext{Var}(eta_1) & 	ext{Cov}(eta_1, eta_2) \ 	ext{Cov}(eta_1, eta_2) & 	ext{Var}(eta_2) \end{bmatrix} egin{bmatrix} rac{1}{eta_2} \ -rac{eta_1}{eta_2^2} \end{bmatrix}

## 12.11 陷阱清单 {#sec-algorithms.12.1.11}

::: note 避坑速查表
1. **弱工具变量**：第一阶段 F 统计量小于 10，2SLS 点估计偏向 OLS，标准误严重失真。
2. **违背排他性约束**：工具变量直接影响结果 Y，或通过除 X 以外的中间路径影响 Y。
3. **把 LATE 当 ATE**：工具变量仅识别依从者（Compliers）的处理效应，无法直接推论到总体。
4. **RD 全局高阶多项式拟合**：Gelman & Imbens (2019) 证明高阶多项式（3阶以上）在边界处会产生虚假的巨大跳跃，必须用局部线性回归。
5. **RD 操纵检验缺失**：若个体能主动跨越阈值（如操纵考试成绩），断点附近密度不连续，RD 失效。
6. **DID 预干预趋势不平行**：若干预前两组斜率已有差异，两期差分会将自然分流错误记为政策效应。
7. **面板数据使用独立抽样标准误**：同一用户在时间维度的残差高度正相关，朴素 SE 缩小 2~4 倍，导致大量伪显著。
8. **重抽样破坏群组结构**：在以学校为单位的实验中，逐行抽样导致方差估计严重低估，必须按群组抽样。
9. **Delta 方法忽略交叉协方差**：推导分子/分母比率方差时，漏算协方差项导致方差计算严重失真。
10. **不报敏感性分析**：观察性研究声称因果显著，但对未观测混杂极其脆弱（E-value 仅略大于 1）。
:::
