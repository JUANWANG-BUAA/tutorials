## 0.1 渐进分析记号约定

| 记号 | 数学定义 | 直观含义 | 典型例子 |
|:--|:--|:--|:--|
| $f(n) = O(g(n))$ | $\exists c>0, n_0, \forall n \ge n_0, 0 \le f(n) \le c \cdot g(n)$ | 渐进上界（最坏情况不劣于） | 快速排序最坏时间为 $O(n^2)$ |
| $f(n) = \Omega(g(n))$ | $\exists c>0, n_0, \forall n \ge n_0, 0 \le c \cdot g(n) \le f(n)$ | 渐进下界（至少需要耗费） | 基于比较的排序时间为 $\Omega(n \log n)$ |
| $f(n) = \Theta(g(n))$ | $f(n) = O(g(n))$ 且 $f(n) = \Omega(g(n))$ | 渐进紧确界（精确等价） | 归并排序时间为 $\Theta(n \log n)$ |
| $f(n) = o(g(n))$ | $\lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$ | 严格非紧上界（高阶无穷小） | $n = o(n^2)$ |
| $f(n) = \omega(g(n))$ | $\lim_{n \to \infty} \frac{f(n)}{g(n)} = \infty$ | 严格非紧下界（严格更快） | $n^2 = \omega(n \log n)$ |
| $\tilde{O}(g(n))$ | $O(g(n) \cdot \text{polylog}(n))$ | 忽略对数因子的软上界 | 图算法中的 $\tilde{O}(m)$ |

## 0.2 概率与统计推断记法

| 记号 | 含义 | 解释与约束 |
|:--|:--|:--|
| $\mathbb{E}[X]$ | 随机变量 $X$ 的数学期望 | 在所讨论的概率测度下求期望 |
| $\text{Var}(X)$ | 随机变量 $X$ 的方差 | $\mathbb{E}[(X - \mathbb{E}[X])^2]$ |
| $\text{Cov}(X, Y)$ | 协方差 | $\mathbb{E}[(X - \mathbb{E}[X])(Y - \mathbb{E}[Y])]$ |
| $\rho_{XY}$ | Pearson 相关系数 | $\frac{\text{Cov}(X, Y)}{\sqrt{\text{Var}(X) \text{Var}(Y)}}$ |
| $\alpha$ | 显著性水平（Type I 错误率） | 零假设成立时误拒绝的概率（默认 0.05） |
| $1 - \beta$ | 统计功效（Power） | 备择假设成立时正确拒绝的概率（默认 0.80） |
| $Z_p$ | 标准正态分布分位数 | $\Phi(Z_p) = p$；如 $Z_{0.975} = 1.96$ |
| $H_0, H_1$ | 零假设与备择假设 | 统计检验的基本假设对 |

## 0.3 因果推断记号约定

| 记号 | 含义 | 解释 |
|:--|:--|:--|
| $T \in \{0, 1\}$ | 处理变量（Treatment） | $1$ 表示接受干预，$0$ 表示控制组对照 |
| $Y(0), Y(1)$ | 潜在结果（Potential Outcomes） | 个体未受干预与受干预时的理论结果 |
| $Y = T \cdot Y(1) + (1-T) \cdot Y(0)$ | 观测结果（Observed Outcome） | 只能观测到其中一个潜在结果（因果根本难题） |
| $\text{ATE}$ | 总体平均处理效应 | $\mathbb{E}[Y(1) - Y(0)]$ |
| $\text{CATE}(x)$ | 条件平均处理效应 | $\mathbb{E}[Y(1) - Y(0) \mid X = x]$ |
| $\text{LATE}$ | 局部平均处理效应 | 工具变量识别出的依从者子群（Compliers）处理效应 |
| $Z$ | 工具变量（Instrumental Variable） | 外生变量，仅通过影响 $T$ 进而影响 $Y$ |

## 0.4 语义盒分类与排版约定

本书采用统一标准语义盒展示技术规范：

- `::: def`：**数学定义与核心公理**。给出无歧义的形式化数学公式。
- `::: thm`：**定理、引理与核心结论**。包含渐进复杂度上界、最优性证明结论。
- `::: proof`：**完整数学证明**。展示严密的代数放缩、归纳法或反证过程。
- `::: method`：**工程方法与算法协议**。给出标准操作步骤与判定规则。
- `::: errata`：**陷阱清单与灾难台账**。剖析真实工程中的失败模式、根因与修复。
- `::: note`：**深入注解与直觉阐发**。阐述表面结论背后的本质机理。

## 0.5 实验代码与可复现性约定

1. **固定随机种子**：所有涉及随机数生成或蒙特卡洛仿真的实验代码，必须显式声明 `np.random.seed(42)` 或 `random.seed(42)`，确保跨平台结果完全可复现。
2. **多轮采样报告中位数**：任何性能测试均需进行多次重复（默认 20~100 次），报告中位数以及标准差，严禁只测单次运行耗时。
3. **消除预热偏差**：在测量 JIT 或虚拟机语言性能时，必须显式设置 Warmup 轮次，待进入稳态后再启动高精度采样。
