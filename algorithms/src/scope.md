# 范围、取舍与边界

## 本书涵盖的内容

### 核心范围

1. **算法设计与分析**（第 1-8 章）
   - 渐进分析：大 O/Ω/Θ、主定理、递归树、摊还分析
   - 分治算法：归并排序、快速选择、Karatsuba、Strassen
   - 图算法：BFS/DFS、最短路径、最小生成树
   - 数据结构：哈希表、堆、并查集、平摊代价
   - 贪心与动态规划：活动选择、背包、序列比对
   - NP 难问题与近似算法：顶点覆盖、TSP、集合覆盖
   - 在线算法：缓存替换、竞争比

2. **性能评估与实验方法**（第 9 章 + 全书实验）
   - 基准测试设计：输入分布、warmup、稳态测量
   - 性能剖析：缓存效应、分支预测、指令级并行
   - 最坏情况构造：如何为算法生成退化输入
   - 微基准陷阱：测量噪声、outliers、环境干扰

3. **统计推断**（第 10-11 章）
   - 假设检验：t 检验、Mann-Whitney U、检验力
   - 多重比较校正：Bonferroni、Holm、FDR 控制
   - 模型评估：训练/验证/测试划分、交叉验证
   - bias-variance 分解：过拟合检测、学习曲线
   - 数据泄漏：常见陷阱与防御方法

4. **因果推断入门**（第 12 章）
   - RCT 黄金标准：随机对照试验的原理与局限
   - 观察研究：混淆变量、选择偏差
   - 倾向得分匹配：如何用观察数据逼近 RCT
   - 工具变量与差分：自然实验的利用
   - 因果图（DAG）：Pearl 的因果推断框架入门

5. **工程实践**（第 13-14 章 + 两个项目）
   - 算法竞赛评测系统：正确性验证、性能测试、沙箱隔离
   - A/B 测试分析流水线：实验设计、样本量计算、序贯检验

## 本书不涵盖的内容

### 明确排除

1. **概率统计基础教程**
   - 期望、方差、中心极限定理 → 假设读者已有基础，或查阅专门教材
   - 多元统计、回归分析 → 只在需要时简要说明，不展开推导

2. **编程语言教程**
   - Python 语法、NumPy 用法 → 假设读者会用或能自学
   - C++/Rust 实现细节 → 算法伪代码为主，性能关键路径提供对照代码

3. **深度的形式化证明**
   - NP 完全性的完整证明 → 只给归约思路，不逐步推导
   - 近似算法的紧确性分析 → 只给近似比，不证明下界

4. **高级因果推断**
   - 中介分析、敏感性分析的完整理论 → 第 12 章只入门，深入需专门书籍
   - do 算子的完整形式化 → 只介绍基本概念，不推导所有定理

5. **生产级工程细节**
   - 分布式系统、微服务架构 → 项目是单机演示，不涉及集群部署
   - 监控告警、故障恢复 → 项目专注评估逻辑，不做运维

## 深度与广度的权衡

### 深度优先的章节（1-8 章）

- 每个算法给出：定义、伪代码、复杂度分析、正确性论证、实验验证
- 每章有可运行实验、agent 陷阱案例、8-15 条编号陷阱
- 目标：读者能独立实现、分析、测试这些算法

### 广度优先的章节（9-12 章）

- 覆盖核心概念与常见陷阱，不追求理论完备
- 第 10 章（假设检验）：讲 t 检验、Mann-Whitney、多重比较，不讲所有非参数检验
- 第 12 章（因果推断）：入门级，覆盖 RCT/观察研究/工具变量，不讲中介分析
- 目标：读者能在工程实践中正确使用，知道何时查阅专门文献

### 项目（13-14 章）

- 功能完整但不追求生产级：有沙箱、有评估，但无高可用、无监控告警
- 代码量：每个项目约 1500-2000 行 Python
- 目标：读者能理解端到端流程，必要时扩展为生产系统

## 先修要求

### 必需

- 数据结构与算法基础（本科大二水平）：数组、链表、树、图、排序、查找
- 编程能力：能读懂 Python 代码、会用命令行、会 git 基础操作
- 数学基础：高等数学（极限、微积分）、离散数学（集合、图论基础）

### 建议

- 概率统计（期望、方差、中心极限定理）→ 第 10-12 章会用到
- 线性代数（矩阵乘法、向量空间）→ 第 2 章 Strassen 算法、第 11 章 SVD 降维
- 操作系统基础（进程、内存）→ 第 13 章评测系统的沙箱隔离

### 可选

- 机器学习入门（监督学习、损失函数）→ 第 11 章模型评估更容易理解
- 编译原理（IR、优化）→ 理解算法优化与编译器优化的相似性

## 阅读顺序

### 线性阅读（推荐新手）

按章节顺序 1 → 14，每章读完运行实验，完成出口检查。

### 按需阅读（工程师）

- 需要算法设计 → 第 1-8 章
- 需要性能测试 → 第 1-2、9 章
- 需要统计推断 → 第 10-11 章
- 需要因果推断 → 第 12 章
- 需要评测系统 → 第 13 章
- 需要 A/B 测试 → 第 10、12、14 章

### 跳过建议

- 如果已熟练掌握算法分析，可以从第 9 章开始（但建议浏览第 1-8 章的实验部分）
- 如果只关心统计推断，可以只读第 9-11 章
- 如果只想学因果推断，建议先读第 10 章（假设检验基础），再读第 12 章

## 实验环境依赖

### 最小环境

- Python 3.11+（CPython）
- NumPy、SciPy（科学计算）
- 命令行工具：`time`、`bash`

### 推荐环境

- Python 3.11+ + statsmodels + matplotlib/plotly
- 性能剖析工具：
  - macOS：`hyperfine`（`brew install hyperfine`）
  - Linux：`perf`（内核自带）
- 构建工具：mdBook、KaTeX CLI

### 硬件说明

- 所有性能测试在 Apple Silicon（M1/M2/M3）或 x86-64 上验证
- 实验固定随机种子（`random.seed(42)`），保证可复现
- 绝对耗时依赖硬件，但**相对比值**（如"归并 vs 快排"）是跨平台一致的

## 术语约定

- **算法**：明确的计算步骤序列，有输入输出
- **复杂度**：时间/空间复杂度，默认指最坏情况，除非标注"平均""最好"
- **实测性能**：真实硬件上的耗时，用 `time.perf_counter()` 测量
- **基准测试**：在固定输入集上重复测量，报告中位数或均值±标准差
- **假设检验**：用样本数据推断总体，控制 I 类/II 类错误率
- **因果效应**：干预（do）导致的结果变化，区别于观察到的相关
- **agent**：AI 代理（如 LLM 驱动的代码生成器），本书特指生成算法代码的 LLM
