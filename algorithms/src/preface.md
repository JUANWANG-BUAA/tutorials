# 为什么写这本书

市面上算法书很多，统计推断和因果推断的书也不少，为什么还要再写一本？

## 现有材料的空白

**经典算法书**（如 CLRS、Roughgarden 系列）讲得很好，但：
- 理论分析为主，实验验证很少
- 对「如何测量性能」「如何证明算法确实更快」缺少系统方法
- agent 生成代码的常见陷阱未被总结

**机器学习书**（如李航《统计学习方法》）讲评估指标和模型选择，但：
- 偏向监督学习，对算法性能评估涉及较少
- 假设检验、多重比较这类实验方法学讲得不够深
- 缺少工程实践中的基准测试设计

**因果推断书**（如 Pearl、Imbens-Rubin）是专门领域，但：
- 门槛高，需要完整的统计学背景
- 与算法评估的结合不紧密
- 工程师缺少"入门就能用"的快速指南

本书填补这些空白：**将算法设计、性能评估、统计推断、因果分析融合**，用统一的实验框架贯穿全书。

## 这本书的定位

- **给算法课补上实验方法**：不仅推导复杂度，还测量真实性能，理解常数因子
- **给 ML 课补上严谨评估**：不仅准确率/AUC，还有置信区间、假设检验、数据泄漏检测
- **给工程师补上因果思维**：区分相关与因果，理解 A/B 测试为什么能（或不能）证明改进

对应读者：
- CS 本科生：作为算法课的配套实验教程
- 算法竞赛选手：理解「为什么这个解法更快」的量化方法
- 后端/算法工程师：学习基准测试、性能剖析、统计推断
- ML/数据科学从业者：掌握评估方法、避免过拟合、入门因果推断

## 与现有教程的关系

本书是《tutorials》系列的第 6 本，与已有教程互补：

| 教程 | 核心主题 | 本书的交叉引用 |
|:--|:--|:--|
| 深度学习导论 | 神经网络、CV、NLP | 评估指标（准确率/AUC）、过拟合检测 |
| 矩阵论 | 线性代数、SVD | 矩阵乘法算法（Strassen）的复杂度 |
| 编译器与程序分析 | IR/SSA、优化、验证 | 算法正确性验证的类似方法 |
| Agent 系统 | LLM agent、工具调用 | agent 生成代码的失败案例来源 |
| Linux 系统与内核 | 进程、内存、网络 | 性能剖析工具（perf、strace） |

**不重复已有内容**：概率统计基础、线性代数、编译优化只在必要时交叉引用，不重新讲解。

## 使用方式

### 作为算法课配套

- 第 1-8 章：每章对应一次实验课（2 学时）
- 学生运行 `experiments/chNN/xxx_lab.py`，提交实验报告
- 期末项目：二选一（评测系统 或 A/B 测试平台）

### 作为自学材料

- 按顺序读完 14 章（每章 1-2 小时）
- 运行所有实验（`bash experiments/run_all.sh`）
- 完成一个项目并通过验收

### 作为工程参考手册

- 需要设计基准测试 → 第 9 章
- 需要假设检验 → 第 10 章
- 需要评估模型 → 第 11 章
- 需要因果推断 → 第 12 章
- 需要评测系统 → 第 13 章
- 需要 A/B 测试 → 第 14 章
