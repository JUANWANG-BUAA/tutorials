动态规划（Dynamic Programming，简称 DP）是运筹学大师 Richard Bellman 在 20 世纪 50 年代创立的算法设计范式。它的核心智慧极其深刻：**通过存储已经解决过的子问题的解，彻底杜绝重复计算，从而将指数级搜索空间驯服为多项式级计算**。

然而，在大量现实业务场景（如编译器寄存器分配、DNA 基因组拼接、机器人轨迹决策序列规划）中，**我们不仅需要知道“最优解的目标函数值是多少”，更迫切需要知道“取得这个最优解的具体决策步骤是什么”**。
许多初学者（以及大语言模型 Agent）写出的 DP 代码，往往只能返回一个孤零零的最大数字，而在面对“请输出最优调度方案”、“请输出对齐后的文本”时彻底手足无措。

本章以 Tim Roughgarden《算法详解 卷 3》与 CLRS 第 15 章为母本，系统拆解动态规划从状态建模、空间压缩到方案完整序列重建的精妙工程实践。

## 6.1 动态规划的本质与求解双路径 {#sec-algorithms.2.6.1}

一个问题适合使用动态规划求解，必须满足两个基本特征：

::: def 定义 6.1.1 · 最优子结构 (Optimal Substructure) {#def-algorithms.2.6.1}

原问题的最优解包含其子问题的最优解。
例如在有向无环图中寻找从 $s$ 到 $t$ 的最短路径：若最短路径经过中间节点 $u$，则该路径从 $s$ 到 $u$ 的部分必然是 $s$ 到 $u$ 的全局最短路径。
:::

::: def 定义 6.1.2 · 重叠子问题 (Overlapping Subproblems) {#def-algorithms.2.6.2}

在递归树自顶向下展开的过程中，相同的子问题被反复求解多次，而不是每次产生全新的子问题。子问题的总数通常是多项式量级（如 $O(n^2)$ 或 $O(n \cdot W)$）。
:::

### 路径一：自顶向下记忆化搜索（Memoization）

保持原始递推函数的自然递归结构，但引入一个查找表（Cache / Memo）。在计算前先检查缓存：若已算过则直接返回；若未算过则计算并将结果填入缓存。
- **优点**：代码直观，且**只计算实际到达的状态**（稀疏状态空间下极其高效）；
- **缺点**：有调用栈开销，存在深度过大导致栈溢出的风险。

### 路径二：自底向上递推填表（Tabulation）

根据子问题的拓扑依赖顺序，从最小的子问题（基情况，如 $dp[0]$）开始循环填表，直至推导出原问题 $dp[n]$。
- **优点**：无递归调用栈开销，极佳的 CPU 连续内存缓存局部性，且**便于执行空间压缩优化**；
- **缺点**：必须严格规划填表顺序，且会无差别计算表中所有状态。

## 6.2 经典背包模型族与空间压缩技巧 {#sec-algorithms.2.6.2}

背包问题是理解动态规划维度的试金石。给定 $n$ 个物品，每个物品有重量 $w_i > 0$ 与价值 $v_i > 0$，背包最大承重为 $W$。

### 1. 0-1 背包问题（0-1 Knapsack）

每个物品只能选择 0 次或 1 次。
- **状态定义**：$dp[i][j]$ 表示前 $i$ 个物品中挑选、总重量不超过 $j$ 时所能获得的最大价值。
- **状态转移方程**：
  $$
  dp[i][j] = \begin{cases}
  dp[i-1][j], & \text{若 } j < w_i \\
  \max(dp[i-1][j], \; dp[i-1][j - w_i] + v_i), & \text{若 } j \ge w_i
  \end{cases}
  $$
- **基情况**：$dp[0][j] = 0, dp[i][0] = 0$。

### 2. 空间压缩：从二维 $O(n \cdot W)$ 到一维 $O(W)$

观察转移方程：计算第 $i$ 行状态时，**仅仅依赖于第 $i-1$ 行的正上方元素 $dp[i-1][j]$ 与左上方元素 $dp[i-1][j - w_i]$**。
如果我们直接在一维数组 `dp[j]` 上原地更新：

::: thm 定理 6.2.1 · 0-1 背包一维倒序更新准则 {#thm-algorithms.2.6.1}

在遍历背包容量 $j$ 时，**必须从 $W$ 严格倒序循环至 $w_i$**：
```python
for i in range(1, n + 1):
    for j in range(W, w[i] - 1, -1):  # 必须倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i])
```
**数学证明**：
倒序遍历时，当计算 `dp[j]` 时，所需的 `dp[j - w[i]]` 尚未被本轮第 $i$ 个物品更新过，它保留的依然是上一轮第 $i-1$ 件物品的历史值！保证了每个物品只被选择一次。
若错误使用正序遍历，计算 `dp[j]` 时引用的 `dp[j - w[i]]` 已经被本轮物品更新过，等价于同一个物品被累加了多次，退化为完全背包！
:::

### 3. 完全背包与多重背包

- **完全背包（Unbounded Knapsack）**：每个物品可以使用无限次。
  状态转移依赖同一行左侧状态，因此一维遍历方向**恰好为正序**：
  $$
  \text{for } j \text{ from } w_i \text{ to } W: \quad dp[j] = \max(dp[j], dp[j - w_i] + v_i)
  $$
- **多重背包（Bounded Knapsack）**：第 $i$ 种物品最多有 $c_i$ 件。
  - 朴素拆分：展开为 $\sum c_i$ 个 0-1 背包物品；
  - **二进制拆分优化**：将 $c_i$ 拆分为 $1, 2, 4, \ldots, 2^k, R$，利用二进制幂次组合表达 $[0, c_i]$ 内的任意数量，复杂度由 $O(W \sum c_i)$ 锐减至 $O(W \sum \log c_i)$。

## 6.3 序列比对与最长公共子序列（LCS） {#sec-algorithms.2.6.3}

给定两个字符串 $X = (x_1, \ldots, x_m)$ 与 $Y = (y_1, \ldots, y_n)$，求两者的最长公共子序列长度。

### 状态定义与转移

定义 $dp[i][j]$ 为 $X$ 的前 $i$ 个字符与 $Y$ 的前 $j$ 个字符的 LCS 长度：
$$
dp[i][j] = \begin{cases}
0, & \text{若 } i=0 \text{ 或 } j=0 \\
dp[i-1][j-1] + 1, & \text{若 } x_i = y_j \\
\max(dp[i-1][j], \; dp[i][j-1]), & \text{若 } x_i \neq y_j
\end{cases}
$$

```text
DP 表填充依赖示意图:
       j-1        j
i-1  [左上角] ──► [上方]
        │    \      │
        ▼      \    ▼
 i   [左方]   ──► [当前 dp[i][j]]
 (若 x[i] == y[j]，由左上角对角线 +1 转移)
 (若 x[i] != y[j]，取上方与左方的最大值)
```

## 6.4 方案序列完整重建（Sequence Reconstruction） {#sec-algorithms.2.6.4}

这是工业级动态规划最关键的下半场：**根据填好的 DP 表，逆向追溯出最优决策序列**。

### 1. 0-1 背包最优物品方案重建

```python
def knapsack_reconstruct(weights: list[int], values: list[int], W: int) -> tuple[int, list[int]]:
    """
    不仅返回最大价值，同时完整重建被选中的物品索引列表
    """
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    # 1. 自底向上填表
    for i in range(1, n + 1):
        w = weights[i - 1]
        v = values[i - 1]
        for j in range(W + 1):
            if j < w:
                dp[i][j] = dp[i - 1][j]
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w] + v)

    max_value = dp[n][W]

    # 2. 从右下角逆向回溯路径
    selected_items = []
    curr_w = W
    for i in range(n, 0, -1):
        # 若当前状态值不等于上一行的值，说明第 i 件物品必定被放入了背包！
        if dp[i][curr_w] != dp[i - 1][curr_w]:
            selected_items.append(i - 1) # 记录物品下标
            curr_w -= weights[i - 1]     # 扣除对应重量

    selected_items.reverse() # 恢复正序
    return max_value, selected_items
```

### 2. LCS 实际公共子串与对齐文本重建

```python
def lcs_reconstruct(x: str, y: str) -> tuple[int, str]:
    """
    完整输出两个字符串的 LCS 长度以及具体的对齐子序列字符串
    """
    m, n = len(x), len(y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # 反向回溯构造字符串
    lcs_chars = []
    i, j = m, n
    while i > 0 and j > 0:
        if x[i - 1] == y[j - 1]:
            lcs_chars.append(x[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1

    lcs_chars.reverse()
    return dp[m][n], "".join(lcs_chars)
```

## 6.5 编辑距离（Edit Distance）与生物信息对齐 {#sec-algorithms.2.6.5}

Levenshtein 距离衡量将字符串 $A$ 转化为 $B$ 所需的最少单字符编辑操作数（插入、删除、替换）。
- 状态：$dp[i][j]$ 为 $A[1..i]$ 转化到 $B[1..j]$ 的最小编辑代价；
- 转移方程：
  $$
  dp[i][j] = \min \begin{cases}
  dp[i-1][j] + c_{\text{del}}, & \text{删除 } A[i] \\
  dp[i][j-1] + c_{\text{ins}}, & \text{插入 } B[j] \\
  dp[i-1][j-1] + (0 \text{ 若 } A[i]=B[j] \text{ 否则 } c_{\text{sub}}), & \text{保留或替换}
  \end{cases}
  $$
在生物信息学（Needleman-Wunsch 算法）中，匹配给予正奖励，错配和空位（Gap）给予惩罚矩阵，通过回溯指针直接输出 DNA 序列的全局最佳对齐图景。

## 6.6 区间动态规划：矩阵链乘法与最优二叉搜索树 {#sec-algorithms.2.6.6}

区间 DP 的典型特征是：**状态由区间的左端点 $i$ 与右端点 $j$ 定义，通过遍历区间内的分割点 $k$ 进行状态合并**。

### 矩阵链乘法（Matrix Chain Multiplication）

给定 $n$ 个矩阵的连乘序列 $\langle A_1, A_2, \ldots, A_n \rangle$，矩阵 $A_i$ 的维度为 $p_{i-1} \times p_i$。矩阵乘法满足结合律，但不同的括号化次序所需的数乘总次数天差地别（例如 $(A_1 A_2) A_3$ 耗时 10,000，而 $A_1 (A_2 A_3)$ 可能高达 1,000,000）。

- 定义 $m[i][j]$ 为计算矩阵子链 $A_{i..j}$ 所需的最小数乘次数；
- 枚举所有可能的分隔位置 $k \in [i, j-1]$：
  $$
  m[i][j] = \min_{i \le k < j} \left\{ m[i][k] + m[k+1][j] + p_{i-1} p_k p_j \right\}
  $$
- **填表顺序**：按区间长度 $len = j - i + 1$ 从 2 递增循环到 $n$。
- 时间复杂度：枚举区间长度 $O(n)$，枚举左端点 $O(n)$，枚举切分点 $O(n)$，总时间为严格的 $\Theta(n^3)$。

## 6.8 Agent 陷阱案例：只算数字不算方案与一维更新顺序错误 {#sec-algorithms.2.6.8}

::: errata 真实生产代码与生成缺陷分析
**用户 Prompt**：
> “用动态规划求出 0-1 背包的最大价值，并给出所选取的具体物品名单。请用最节省空间的一维数组优化。”

**Agent 生成的典型错误代码**：
```python
def knapsack_faulty(weights, values, W):
    n = len(weights)
    # Agent 压缩为一维数组
    dp = [0] * (W + 1)
    
    # 错误 1: 压缩为一维后，历史决策被覆盖，根本无法逆向回溯被选物品！
    # 错误 2: 遍历顺序写成了正序遍历！
    for i in range(n):
        for j in range(weights[i], W + 1): # 致命：正序遍历使物品被重复选取！
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
            
    # Agent 试图通过差值猜测物品，输出完全错误的方案
    return dp[W], []
```

**灾难后果与数学推导**：
- *后果 1*：正序遍历 `for j in range(weights[i], W + 1)` 使得物品 $i$ 可以被多次放入背包，把 0-1 背包篡改为了完全背包。
- *后果 2*：**一维空间压缩与方案重建的天然矛盾**。一维优化覆盖了历史层的数据，在没有记录决策分支（Choice Array）的前提下，不可能从最后一行一维数组直接倒推物品序列！
- *防御规范*：
  1. 若业务只要求输出最大标量，使用一维倒序 DP；
  2. 若业务要求输出具体最优解序列，必须保留完整的二维表格 $dp[n][W]$，或者使用分治空间优化（Hirschberg 算法）将空间压缩为线性并同时输出方案。
:::

## 6.10 陷阱清单 {#sec-algorithms.2.6.10}

::: note 动态规划避坑速查表
1. **0-1 背包一维空间优化正序遍历**：导致同一件物品被重复放入多次，变相成为完全背包。
2. **只保留标量值导致无法重建方案**：业务需要调度执行序列，却只输出了一个最大收益数字。
3. **浮点价值背包直接作为数组下标**：DP 的状态下标必须是离散整数，若重量或容量为浮点数，必须量化缩放或改用以价值为状态的对偶 DP。
4. **矩阵链乘法外层循环枚举端点而非区间长度**：导致计算长区间时依赖的短区间状态尚未就绪。
5. **记忆化递归缺少已访问标记**：当函数返回值为 0 或负数时，`if memo[state] != 0` 会误判为未计算，引发重复递归。
6. **基情况边界初始化遗漏**：未初始化 $dp[0][...]$ 或负无穷哨兵，导致非法转移被采纳。
7. **混淆最长公共子序列（LCS）与最长公共子串（Substring）**：子序列可不连续，子串必须连续。
8. **忽略伪多项式时间陷阱**：背包容量 $W=10^{12}$ 时时间复杂度不是常数，而是指数级（取决于 $W$ 的二进制位数）。
9. **树形 DP 树未定向导致循环递归**：在无向树上做树形 DP 时未在参数中传入 `parent` 节点，导致父子无限互调。
10. **大状态空间内存未对齐造成换页中断**：开辟超大二维数组导致严重的操作系统缺页异常（Page Fault）。
:::
