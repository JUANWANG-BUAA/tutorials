# 章节大纲与分工

本文件锁定 14 章的标题、节标题、核心产出与禁止重复的内容。写作时以 `src/partN/chNN.md` 里的骨架为准；本文件补充每章的**独有角度**与**必须给出的证据**。

## 第 1 篇 · 前端与 IR

### 1 编译器全景：源码到可执行
- 四类执行模型；一条 minic 流水线；pass 管理器；正确性契约；可复现构建；预算。
- 必须画：源码→token→AST→IR→asm→进程的 ASCII 图，标出每步的失败模式。
- 证据：`experiments/ch01/pipeline_tour.py` 打印每阶段产物；`cc -S` 或 minic `--emit=asm`。
- 禁止：展开指令集/ABI 教程；把「编译」等同于「翻译成汇编」。

### 2 词法、语法与 AST
- 正则/DFA/最大匹配；手写 lexer；递归下降与 Pratt；AST/span；歧义与错误恢复；诊断。
- 必须画：字符流→token→AST 的数据流图，标出注释/数字/关键字的状态。
- 证据：`experiments/ch02/lexer_lab.py` 对 `--`、`1..2`、嵌套注释的实测。
- agent 错误：把 `--` 当注释导致减法吞掉；或 `1..2` 被最长匹配成一个错误 token。

### 3 类型、作用域与符号表
- 静态/动态、可靠/完备；作用域/绑定/遮蔽；符号表结构；类型检查/推导；泛型实例化边界；整数提升；增量分析。
- 必须画：作用域栈与 AST 遍历的时间线图。
- 证据：`experiments/ch03/scope_lab.py` 展示块作用域、遮蔽、未声明、重复声明。
- agent 错误：块退出未弹栈，导致后续同名变量解析到已销毁的符号。

### 4 中间表示：三地址码与 SSA
- 树/线性/图 IR；TAC/CFG；SSA/phi/支配边界；构造与验证；phi 消解；真实 IR 对照。
- 必须画：含 if/while 的 CFG 与支配边界，标出 phi 插入位置。
- 证据：`experiments/ch04/ssa_lab.py` 输出 CFG、支配树、DF、SSA；验证器拒绝重复定义。
- agent 错误：循环回边漏 phi，导致第二次迭代使用第一次的值。

## 第 2 篇 · 优化与后端

### 5 数据流分析与优化
- 格/单调框架/不动点；到达定值；活跃变量；可用表达式/常量传播；工作列表；保守性；验证。
- 必须画：前向/后向分析的 IN/OUT 数据流图，标出 merge 操作。
- 证据：`experiments/ch05/dataflow_lab.py` 用朴素迭代与工作列表对拍；给迭代次数。
- agent 错误：把 IN 初始化为空而不是「所有定值/所有变量」，导致漏报或过早收敛。

### 6 循环、内联、常量传播
- 自然循环/支配；LICM 的条件；内联成本模型；常量传播/折叠/DCE；别名/副作用屏障；pass 顺序。
- 必须画：循环 CFG 与 LICM 前后的指令移动图。
- 证据：`experiments/ch06/opt_lab.py` 对拍优化前后解释器结果，并展示一次「不安全外提」反例。
- agent 错误：把 `x/0` 折成常量或把有副作用的调用当纯函数内联/删除。

### 7 寄存器分配与指令选择
- 树覆盖/模式/成本；活跃区间/冲突图；图着色/溢出；线性扫描；调用破坏；调度；目标描述。
- 必须画：活跃区间与寄存器压力图，标出溢出点。
- 证据：`experiments/ch07/regalloc_lab.py` 分配前后指令计数、溢出槽、调用点冲突。
- agent 错误：调用返回后继续用 caller-saved 寄存器里的活跃值。

### 8 ABI、调用约定与代码生成
- ABI 合同；栈对齐；参数/返回值/聚合/浮点；callee-saved/x30/red zone；prologue/epilogue；位宽/movl/内存 add；ABI 测试；六条回归。
- 必须画：call 前后 rsp 变化图（call 前 0 mod 16，callee 入口 8，push rbp 后 0，sub 16 的倍数后仍 0）。
- 证据：`experiments/ch08/abi_lab.py` 生成/汇编/反汇编，检查 `movl`、`add`、栈对齐；用 `llvm-objdump`。
- 必须显式：六条历史错误逐条纠正（见协议 §6），但只写编译器生成/验证角度。

## 第 3 篇 · 正确性、验证与执行

### 9 UB、sanitizer 与静态分析
- UB/可观察行为；未定义/未指定/实现定义；溢出/移位/别名/生命周期；ASan/UBSan/TSan/MSan；抽象解释/符号执行；误报漏报；CI。
- 必须画：源码→优化→sanitizer 插桩→运行/静态分析的数据流图。
- 证据：`experiments/ch09/` 的 C 例子在 `-O0/-O2` 与 UBSan 下的差异（本机可跑）；静态规则实验。
- agent 错误：agent 用 `if (p) *p` 防空指针，但在 UB 被利用后该检查被优化掉。

### 10 fuzzing、差分测试、属性测试
- oracle；覆盖率引导；差分；属性/生成器/收缩；缩减去重；结构化输入；资源边界。
- 必须画：seed→mutate→execute→feedback→corpus 的闭环图。
- 证据：`experiments/ch10/fuzz_lab.py` 固定 seed，找到并缩减一个已知 bug；打印覆盖计数。
- agent 错误：oracle 把「两边都错」判为通过，或把异常一律当 crash 去重。

### 11 形式化验证入门
- 测试/证明；操作语义；Hoare；WP；符号执行；SMT；CompCert；轻量验证。
- 必须画：程序→VC→SMT/证明的流水线图，标出不变式。
- 证据：`experiments/ch11/proof_lab.py` 对一个小 IMP 程序做 WP/符号执行，给通过/反例。
- agent 错误：循环不变式过强，导致无法证明或「证明」了错误程序。

### 12 沙箱执行与 JIT 边界
- 解释/AOT/JIT；代码缓存；W^X/双重映射；沙箱谱系；资源限制；侧信道；JIT 验证。
- 必须画：JIT 信任边界与代码内存生命周期图。
- 证据：`experiments/ch12/sandbox_lab.py` 用子进程+资源限制+超时演示「遏制」与「隔离」的区别。
- agent 错误：把 `RLIMIT`/超时当安全边界，忽略继承的 fd、环境变量与写权限。

### 13 项目一：迷你 C/表达式编译器
- 语言子集与验收；架构；lexer/Pratt；语句/函数/类型；TAC/CFG/解释器；SSA/opt；x86-64 代码生成与栈对齐；测试与限制。
- 必须引用 `projects/minic/` 的真实文件与测试命令；贴关键代码片段（10–25 行），不整文件粘贴。
- 必须给：一条 `python3 projects/minic/minic.py examples/fib.mc --emit=ssa` 的真实输出；一条编译执行/解释器对拍结果；一条 `llvm-objdump` 栈对齐证据。
- 必须列：不支持的特性（数组、结构体、浮点、指针算术等）及原因。

### 14 项目二：agent 代码验证器
- 威胁模型；补丁/策略；静态规则；编译门禁；行为门禁；沙箱；裁决协议；测试与对抗。
- 必须引用 `projects/validator/` 的真实文件与测试命令；贴关键代码片段（10–25 行）。
- 必须给：一次 accept、一次 reject、一次 quarantine 的真实 JSON 裁决；说明每种裁决的证据。
- 必须列：明确不提供的保证（不是虚拟机、不防内核 0day、不证明语义正确）。
