## 0.1 语法记法

| 记法 | 含义 | 例子 |
|:--|:--|:--|
| `::=` | 产生式定义 | `expr ::= term ('+' term)*` |
| `*` / `+` / `?` | 零或多次 / 一或多次 / 可选 | `args ::= expr (',' expr)*` |
| `|` | 选择 | `stmt ::= expr ';' | 'return' expr ';'` |
| `ε` | 空串 | `opt ::= ε | expr` |
| `FIRST(α)` | 可从 α 开头的终结符集合 | 见 2.4 |
| `FOLLOW(A)` | 可紧跟在 A 后的终结符集合 | 见 2.4 |

## 0.2 IR 记法

本书的 TAC（三地址码）使用以下形式。临时变量记作 `t0, t1, ...`，源变量保留原名。

```text
t0 = a + b          // 二元运算
t1 = -t0            // 一元运算
x  = t1             // 复制
if t0 goto L1       // 条件跳转
goto L2             // 无条件跳转
L1:                 // 标签
call f(t0, 1)       // 调用；返回值可写 t2 = call f(...)
return t2           // 返回
phi(x1, x2)         // SSA 合流；参数按前驱顺序
```

基本块（basic block）是「只有一个入口、一个出口」的最大指令序列。CFG 的节点是基本块，边是跳转关系。SSA 中每个变量只被赋值一次；合流处用 $\phi$ 函数选择来自不同前驱的值。

## 0.3 数据流方程

统一写成：

$$
\mathrm{IN}[n] = \bigsqcup_{p \in pred(n)} \mathrm{OUT}[p], \qquad
\mathrm{OUT}[n] = f_n(\mathrm{IN}[n])
$$

其中 $\sqcup$ 是格上的合并（并集、交集或常量的最小上界），$f_n$ 是传递函数。前向/后向分析只改变「谁流向谁」，不改变框架。第 5 章会给出每个具体分析对应的格与函数。

## 0.4 语义盒

本书只用以下盒子：

| 类型 | 用途 | 阅读建议 |
|:--|:--|:--|
| `def` | 定义、接口、精确语义 | 必读 |
| `thm` | 可证明的结论、保证、边界 | 必读结论，证明可跳 |
| `ex` | 手算、走查、故障复盘 | 至少读一个 |
| `intuition` | 白话解释「为什么」 | 卡住时读 |
| `method` | 步骤、清单、排障顺序 | 动手时读 |
| `errata` | 常见误解、版本差异、陷阱 | 复习时读 |
| `note` | 延伸、历史、工具 | 选读 |
| `proof` | 推导 | 可折叠，第二遍读 |
| `sol` | 自测答案 | 先做再展开 |

盒子标题形如 `定义 4.2.1 · 支配关系`，锚点 `{#def-compilers.1.4.2.1}`。引用用 `[@def-compilers.1.4.2.1]` 或普通 Markdown 链接。

## 0.5 代码与命令

- `c`：C17；除标注 `text` 的片段外，都应能通过 `cc -std=c17 -Wall -Wextra -Werror`。
- `rust`：2021 edition；示例尽量自包含。
- `python`：3.11+，只用标准库；脚本可直接运行。
- `asm`：GNU/LLVM AT&T 语法；只展示代码生成结果，不教指令集。
- `bash`：POSIX 兼容为主；用到 bash 特性时标出。
- `text`：终端输出、IR、CFG、伪代码。
- `json` / `toml` / `yaml`：配置与裁决格式。

每段代码前说明「它验证什么」，后说明「预期输出/关键行」。命令块给出可从仓库根复现的路径。

## 0.6 证据等级

本书把证据分为四级，结论必须对应其中一级：

| 等级 | 含义 | 例子 |
|:--|:--|:--|
| E1 规范 | 标准/ABI/语言参考的条款 | C17 6.5.5、SysV ABI 3.2.3 |
| E2 可复现 | 本仓库能跑出的命令与输出 | `objdump`、测试通过、fuzz 复现 |
| E3 推理 | 从定义/不变量出发的证明 | 数据流终止性、SSA 支配性质 |
| E4 观察 | 单次实验或个案 | 某个输入下 sanitizer 报错 |

E4 不能单独支撑「所有输入都安全」；E1/E3 不能替代「本机确实跑过」。书中会明确写「在 macOS 14 / clang 21 上」这类条件。

::: errata 三个记法陷阱
1. **把 `→` 当成蕴含**：本书用 `→` 表示「步骤/转移」，$\Rightarrow$ 表示逻辑蕴含。
2. **把 SSA 的 `phi` 当成普通指令**：$\phi$ 只在 CFG 合流处有意义，不能随意移动或删除；退出 SSA 时要消解。
3. **把数据流解当成程序事实**：解是**保守近似**；`IN` 中的事实可能在实际路径上不成立，方向取决于分析是 may 还是 must。
:::
