# 数值分析修改与核验流程

本说明于 2026-11-12 替换旧版。执行状态只记入 [REPAIR-TODO](../REPAIR-TODO.md)，证据见 [修复记录](../../docs/numerical-repair-2026-11-12.md)。

1. 先备份待改内容，与现有教材底稿逐项比较，保留定义、定理、推导、例题、习题和稳定锚点。第 1 章在 `src/ch01/`，第 2–7 章在 `src/course/ch0N/`。
2. 来源题面以原件为准；教师口述、转写、教材正文和编者订正分别注明。没有核对过的时间戳和页码不能补造。原题有错时保留题面并标明条件或更正。
3. 语义盒类型以 `tools/mathbook.py` 为准，如 `::: thm`、`::: ex`、`::: note`，不能发明 `lecture`、`definition` 等类型。
4. 运行 `bash numerical/tools/check.sh`；它会核查当前源码链接、恢复清单、当前发表数值与选定数学反例，任何错误返回非零。Python 依赖与根目录数学门禁相同：`sympy`、`mpmath`。
5. 运行 `mdbook build numerical`，检查最新产物的公式、链接，以及桌面和移动阅读。源码通过不等于构建、浏览器通过。
6. 记录具体修改与实际验证范围。字数、时间戳数量、复选框比例都不能证明数学正确或融合完成。

兼容入口：`pre-fusion-check.sh <章号>` 为只读预检；`post-fusion-verify.sh <src 内文件路径>` 运行全书源码与选例核验；`chapter-summary.sh <章号>` 另加全书临时构建。脚本可从任意工作目录调用，目标文件路径按调用者当前目录解析。
