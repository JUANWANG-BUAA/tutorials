# 《数值分析》定制教程 · 课堂主线七章 + 补充篇 + 课堂精编

依据**颜庆津《数值分析》（第 4 版）**整理扩充的定制教程，与《矩阵论》教程同一套 mdBook 工具链：中文全文搜索、明暗主题、页内锚点、键盘翻页、离线公式（构建期渲染，不依赖 CDN）。

- **第一章 绪论：误差、算法与范数** —— 对标原书第 1 章「绪论」（原书 p.1–13）
- **第 2–7 章 课堂主线** —— 按庞刚老师七章顺序：线性方程组、特征值、非线性方程、插值、数值积分、常微分方程；第 2–5 章目前由讲座页承载
- **补充篇 · 数值线性代数工具箱** —— 原第二章后移；对标原书 1.3 节并大幅扩充，课堂未系统讲
- **课堂精编 · 2026 秋《数值分析 I》实录（主讲庞刚）** —— 逐讲归纳，与正文小节互相索引
- **特训 · 竞技与考场** —— 必考点限时竞技场 + 100 分制考场模拟卷，老师强调的考点全覆盖

### 补充篇 · 数值线性代数工具箱（原第二章后移，课堂未讲）

> 以下 2.1–2.8 是补充篇内部编号，不是课堂第 2 章的节号；课堂第 2 章是线性方程组，见 `src/course/ch02/overview.md`。

### 阅读分层

全书约 400 个语义盒子，若视觉权重完全相同，读者无法判断取舍。现在每个盒子都带优先级：

| 层级 | 内容 | 样式 |
|:--|:--|:--|
| `core` | 定义、定理族、每节速查表、常见错误清单 | 左侧粗边框，高对比 |
| `main` | 例题、方法盒、直觉框、边注、思考 | 正常 |
| `skip` | 证明、课程预告、纯拓展思考 | 弱化（灰、虚线） |

页面正文开头有**「只看核心」**开关：折叠全部 `skip` 层，留下一张「定义 + 定理 + 速查表 + 错误清单」的复习骨架——这是「证明第一遍跳过、二刷再亲手补全」的可执行版本。讲座页另分两层：页首是「10 分钟复习版」（结论 + 公式 + 考点），页身才是实录体。

### 编号与章号约定

- **正文一律用节级编号**（`定理 1.3.6`、`定义 1.2.1`、`例 1.2.1`）；原书编号只写在盒子标题的括注里（`定理 1.3.6（原书）`），两套编号的对照表放在该节开头；
- **章号必须可跳转**：未成章的章号一律链到[全书路线图](src/ch01/sec11.md#roadmap)（表里有「已成章 / 讲座页承载 / 待写」状态列）；原书章号必须带「原书」二字——两套章号是**错位**的（原书第 2 章是线性方程组，本书第 3、5 章才是）；
- 编号与章号在内容审校时核对；`mathbook.py` 在构建时校验语义盒和交叉引用。仓库不再提供单独的 `make numbering` 目标。

## 写作要点

内容用语义盒子书写，编号与引用交给构建器：

```markdown
::: def 定义 2.1.1 · 内积 {#def-2.1.1}
设 $V$ 是实数域上的线性空间，映射 $\langle\cdot,\cdot\rangle:V\times V\to\mathbb R$ ……
:::

……即 [@def-2.1.1] 定义的内积。
```

`[@def-2.1.1]` 自动渲染成「定义 2.1.1」并链接过去；**引用不存在的锚点会让构建失败**。正文一律用**节级编号**（定理 1.3.6、例 1.2.1、定义 2.1.1）；原书编号只写在盒子标题的括注里（`::: thm 定理 1.3.6（原书） · …`），可逐条对照。字母编号（定义 1.2.A 之类）是已废弃的历史方案；增删内容时需人工复核编号与原书对照。

**盒子的优先级**（决定阅读分层，可省略）：

```markdown
::: proof[core]      ← 这一节的证明是重点，别跳
::: thm[skip]        ← 这个定理只作背景，第一遍可跳
```

取值 `core` / `main` / `skip`，不写则按类型取默认值（定义、定理族默认 `core`；例题、方法、直觉、边注默认 `main`；证明、课程预告默认 `skip`）。锚点 ID 保持稳定且全书唯一，写法参照上面的语义盒示例；检查范围见 [质量检查与内容审校](../docs/quality-gates.md)。
