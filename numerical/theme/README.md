# 视觉层

设计规范：**Academy / Cool / standard density**，版式纪律参照 Rust Wiki，
表面语言参照 Physical Intelligence（pi.website）。风格由 serif-editorial-console
技能的 Academy 预设约束。

## 文件

| 文件 | 作用 |
|:--|:--|
| `css/na.css` | **唯一权威样式**。分段：设计令牌 → mdBook 变量映射 → 框架适配 → 语义盒子 → 表格/图/公式 → 首页 → 页内目录 → 侧栏（§6.5）→ 响应式 → 打印 |
| `css/katex.css` | KaTeX 布局规则 + 字体声明（仅 woff2，离线） |
| `js/na.js` | 进度条、本页目录、展开全部解答、打印前展开、宽公式滚动提示、返回教程库（渐进增强） |
| `js/search-cjk.js` | 中文搜索分词（见 docs/ARCHITECTURE.md §2.1） |

`src/404.md` 是 404 页的源文件（不在 `SUMMARY.md` 里，mdBook 单独渲染成
`404.html`）。GitHub Pages 会把它的内容返回给任意路径，所以页内链接在运行时
由一段内联脚本改写为站点根绝对地址（从样式表 URL 反推根，兼容 `/<repo>/` 子路径）。

字体文件在 `src/fonts/katex/`（mdBook 会整体复制 `src/`）。

## 规矩

1. **改样式只改 `na.css`**，不要新增覆盖层——旧版就是因为层层叠加而失去一致性。
2. **字体角色不越界**：display serif 用于章节标题；text serif 用于正文；sans 用于
   导航与控件；mono 用于编号、标签与证据。正文里不出现 mono，导航里不出现 serif。
3. **每个面板都有可见边框**，不用纯阴影做分隔；不用毛玻璃、发光、紫色渐变。
4. **动效只用于状态变化**，并遵守 `prefers-reduced-motion`。
5. **插图按 viewBox 宽度分档**：`figure svg` 默认铺满版心，缩放比 ≈1.1，适合
   viewBox 宽 ≥600 的宽图；窄图（宽 ≈360）铺满会被放大 2 倍以上，标注字号
   涨到正文的两倍、固定坐标的标注还会互相压叠——这类图在源文件里写
   `<figure class="fig-sm">`，图版限宽到 470px 居中，缩放比落到 ≈1.2。

## 两处容易踩的 mdBook 陷阱

写样式时必须知道 mdBook 的这两个行为，它们各引发过一个真实缺陷：

- **标题文字整段被包在 `<a class="header">` 里**。所以 `.header` 必须继承颜色
  （`color:inherit`），任何 `opacity:0` 都会让**整本书的标题消失**。锚点提示请用
  `::after` 悬停出现，而不是隐藏 `.header` 本身。
- **`--serif` 是 `var(--serif-display)` 的别名**，嵌套 `var()` 放在 `font` 简写里
  无法通过语法校验，整条声明会失效（回退到继承值）。因此对 `--serif` 一律用
  `font-family` 等长属性，不要用 `font:` 简写。

## 侧栏（§6.5）

侧栏**一比一交还原生**（连续目录、编号加粗、hover/当前项仅变色、本页大纲由
`toc.js` 折叠）。`na.css` §6.5 只保留与主题相关的滚动条与焦点环收尾；折叠钮、
吸顶分组标题、当前项底色/色条等自建样式均已移除，`na.js` 也不再处理侧栏。

## 框架界面文案

mdBook 的框架文案（菜单栏提示、搜索框占位符、搜索结果统计、主题名、复制按钮）
全部写死在模板与 `searcher.js` / `book.js` 里，**没有配置项**，只能由
`framework.js` 在运行时改写（`localizeChrome()` 与 `watchSearchResults()`）。
三条相关事实：

- **搜索结果统计行由 `formatSearchMetric()` 生成，每次搜索整体重建**，所以要用
  `MutationObserver` 盯住 `#mdbook-searchresults-header`，不能一次性改写。
- **搜索是 `keyup` 触发的**（`searchbarKeyUpHandler`），`input` 事件不生效——
  用脚本填值调试搜索时必须手动派发 `keyup`。
- **`#mdbook-search-wrapper` 在文档流里，没有定位也没有高度上限**：mdBook 原生
  会让 30 条结果把正文顶下去约 2600px。`framework.css` §3 给结果区加了高度上限与
  内滚，并补了一条 `MutationObserver` 让上下键移动高亮时把条目带进视野（mdBook
  自己不做）。

## 颜色与对比度

正文次级灰 `--muted` 与彩色文字 `--accent-text` 的取值，都按 **WCAG AA（≥4.5:1）**
在 `--page` 与 `--sidebar` 两种底色上验算过：

| 令牌 | 亮色取值 | 用途 |
|:--|:--|:--|
| `--muted` | `#6f675b` | 正文次级文字（sidebar 4.6:1 / page 5.1:1） |
| `--accent` | `#b96543` / `#8aa79d` | **仅装饰**：线条、底色、进度条、水印 |
| `--accent-text` | `#9f5033` / `#8aa79d` | 小字号彩色**文字**（侧栏高亮、交叉引用悬停） |

改色后请重新验算：正文级文字需 ≥4.5:1，大字与装饰线需 ≥3:1。暗色令牌与亮色
同名同结构，只换值。

### 外观设置：两个入口，各管一件事（2026-10）

| 想改什么 | 入口 |
|:--|:--|
| 明暗与配色 | 菜单栏画笔图标 → mdBook 原生主题弹层（跟随系统 / 浅色 / 浅色 · Rust / 深色 · Coal / 深色 · Navy / 深色 · Ayu）。**五个名字对应五种观感**：`§1.1` 里各有一份完整调色板 |
| 排版（字体 / 字号 / 行距间距 / 版心宽度） | 菜单栏 `Aa` → 阅读偏好面板（本地保存，仅本机生效） |
| 纸张色相（中性 / 冷灰 / 苔绿 / 高对比） | 同上，`Aa` 面板的「纸张配色」——**与明暗正交**：它只改中性面、文字、线与强调色，亮暗各一份取值，因此可叠在任意主题上。派生量（底纹 / 选区 / 悬停 / 阴影 / 斑马线）由 §1.3 自动跟随；**语义盒也会跟着协调**（见下） |
| 背景纹理（网格 / 方格纸 / 横线 / 点阵 / 纸张纤维） | 同上，`Aa` 面板的「背景纹理」。图案与重复尺寸各写成两个自定义属性（`--bg-stack` / `--bg-size`），再统一落到 `body` 与 `.page-wrapper` **两层**上——mdBook 会给 `.page-wrapper` 画一层不透明底（`background:var(--bg)`），只写在 `body` 上的底纹在正文区会被它完全挡住（默认档的暖光与网格就只在页面外围可见，故另有「暖光网格」一档把它铺满整页）。纹理全部由 `--grid-line/--grid-mid/--grid-strong/--dot/--fiber` 算出，随明暗与纸张配色自动走；打印一律回落纯色 |

**为什么语义盒要跟着纸张配色走**：语义盒（定义 / 定理 / 例题 / 思考 / 勘误 / 方法）的色相是语义，不能换；但只换中性面会造成「苔绿纸 + 蓝盒子」「冷灰纸 + 暖金盒子」——两套颜色系统并排。做法是在 §1.2 为每个语义声明一枚**锚色**（`--sem-*`，只表达色相，默认不参与渲染），选任意纸张配色后由 prefs.css 用「锚色 + 该配色的面 / 墨 / 线」算出底、框、字：底 = 锚 13% + 卡片面、框 = 锚 62% + 线色、字 = 锚 55% + 墨色。规则只写一遍，对以后新增的配色同样成立；插图配色（`--fig-*`）刻意不动——它是插图的语义色，跨主题一致更有用。

- **弹层里五个名字必须是五种观感。** 曾经 `light`≡`rust`、`coal`≡`navy`≡`ayu`（逐项实测 page/ink/accent
  完全相同），弹层六项里实际只有两套外观；现在每个主题独占一份调色板。"跟随系统" 取
  `default-theme`（Light · 中性白纸）作亮色侧、`preferred-dark-theme`（Coal · 冷灰蓝）作暗色侧——
  此前两者都写 `ayu`，浅色系统下也被强制成暗色。

- **一件事只有一个入口。** 自建偏好面板曾经也带「配色主题」，与原生弹层各存一套状态，
  读者看到的设置因此不统一：现在配色只走原生弹层，排版只走 `Aa` 面板。
- **默认档不写属性。** `serif / 中 / 标准 / 标准` 就是权威样式表自己的样子，面板只对
  非默认档写 `html[data-*]`，升级不改变老读者的观感。
- **`prefs.css` 必须排在 `additional-css` 最后**：读者偏好靠「同特异性 + 后加载」覆盖
  权威样式表；`head.hbs` 的内联脚本在首帧前落属性，避免先按默认外观画一帧再跳。
- 主题弹层保持 mdBook 原生外观（4px 圆角、1px 边框、0.7em 字号、2px 20px 内边距、
  条目内「✓」选中标记），不做皮肤。

### 令牌分层：组件不写颜色（2026-10）

§1 分四层，改配置只落在该落的那一层：

| 层 | 内容 | 什么时候动它 |
|:--|:--|:--|
| §1.1 主题调色板 | `rust` / `light` / `coal` / `navy` / `ayu` 各一份完整配色，键名固定（含 `--link-color`、`--scheme`） | 加一套配色 |
| §1.2 语义调色板 | 定义/定理/例题等语义盒与插图色，只分亮、暗两套 | 调某个语义盒 |
| §1.3 派生量 | 调色板 → mdBook 变量的映射，以及底纹/选区/悬停/表格斑马线等装饰量（`color-mix` 由令牌算出） | 加一个框架变量 |
| §1.4 尺寸令牌 | 版心、侧栏、菜单栏高度、圆角与间距刻度、字体栈 | 改版式尺寸 |

两条纪律：

1. **组件（§2 起）只引令牌**，不写颜色字面量。`rgba(185,101,67,.07)` 这类底纹、`rgba(197,74,38,.1)`
   这类悬停底色都已经改成 `--wash-accent` / `--accent-soft` 这类令牌或 `color-mix` 派生量，
   它们会跟着主题走；新增主题不需要再改组件。
2. **令牌要先能“被引用得全”**：写一次覆盖检查（引用 − 定义）就能救命——本次就是靠它发现
   《数值分析》的 `--rank-*` 段位色与《矩阵论》的 `.arena-*` 回退字面量已归位到令牌；
   同类问题在另一本书里曾表现为 40 处语义盒完全没有底色。

### 视觉动效：四条纪律（2026-10）

动效是本书设计语言里最容易被写坏的一层，因此定四条：

1. **只作用于状态变化**（悬停 / 聚焦 / 展开 / 进入视口 / 切换主题），不用来“吸引注意”，
   也没有常驻循环动画。
2. **`prefers-reduced-motion: reduce` 一律关闭**——插图进场、主题过渡、折叠块高度都在该条件下不启用；
   已读点、灯箱这类“信息”不依赖动效，因此照常显示。
3. **打印与无 JS 情形都必须是静止可见的**：进场用的是 `html.figure-reveal`（由 JS 加上）而不是默认隐藏，
   所以关掉 JS、或打印时图不会被卡在半透明状态；灯箱、继续阅读卡、`点击放大` 提示都在 `@media print` 里隐去。
4. **颜色与尺寸只引令牌**（`--overlay-bg` / `--shadow-soft` / `--shadow-deep` / `--radius-sm` / `--row-hover` …），
   包括 `color-mix` 也算“由令牌算出”；`framework.css` 是共用文件，不允许出现只对某一套主题成立的色值。

### 变量与令牌：三条纪律（2026-10）

三条都真踩过，改样式前先读：

1. **不自己声明 `--sidebar-width`。** mdBook 0.5 的它是派生值
   （`min(--sidebar-target-width, 80vw)`，见框架 `variables.css`）；权威样式表里再写一份
   会盖住派生值——拖拽把手改的是 `--sidebar-target-width`，宽度却永远不动，表现为
   **把手拖不动**。只声明 `--sidebar-target-width`。
2. **链接配色只有 `--links` 一个来源。** 曾经还有一条 `html.ayu a{color:var(--accent)}`
   兜底，它与 mdBook 的 `.chapter li a{color:var(--sidebar-fg)}` 特异性打平（0,1,2）
   而靠后加载胜出，把侧栏链接的 hover 与 `.active` 一并压成同色——暗色主题下侧栏没有
   悬停反馈、当前项也认不出来（而默认主题就是 ayu）。兜底已删，正文链接由 mdBook 的
   `.content a:link{color:var(--links)}` 负责。
3. **打印必须重设全部颜色令牌，含 `--links` 与 `--inline-code-color`。** 默认主题是暗色、
   纸却是白的：漏掉哪个，哪个就印成浅色。实测漏掉时强调色与盒标签只有 1.6–2.3:1，
   补齐后 5.7:1。改打印块后请照 §8 的注释复算对比度。
