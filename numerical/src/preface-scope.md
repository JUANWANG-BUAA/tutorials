# 范围声明与使用方法

本教程依据颜庆津《数值分析》（第 4 版，北京航空航天大学出版社，2012）整理扩充而成，目前包含两章正文与一个课堂精编部分：

- **第一章 绪论**（对应原书第 1 章「绪论」，原书第 1–13 页）：研究对象、误差知识与算法知识、向量范数与矩阵范数；
- **第二章 数值线性代数基础**（对标原书 1.3 节并大幅扩充）：内积与正交性、四个基本子空间与投影、正交化与 QR 分解、条件数与扰动分析、特征值与对称谱理论、奇异值分解与低秩逼近；
- **课堂精编**（2026 秋学期实录）：北航《数值分析 I》（主讲庞刚）的逐讲归纳，由课程录播的语音转写与板书整理、订正而成，随课程推进持续更新，并与正文小节互相索引——见[课堂精编导览](lectures/overview.md)。

原书叙述凝练、例题与习题经典，但部分证明标注「从略」或「留给读者」；又成书于 2012 年，未覆盖现代数值计算赖以运转的浮点标准、向后误差分析框架与 SVD 等方法；例题也以手算为主，缺少可复现的实验。为此，本教程在**不改动原书结论**的前提下做三类工作：

| 做法 | 说明 |
|:--:|:--|
| **不丢内容** | 原书第一章 1.1–1.3 三节的每一条定义、定理、例题与讨论**全部收录**；原书定理 1.1–1.5、例 1–6、习题 1–15 都能与原书逐条对照——原书编号写在盒子标题的括注与题面方括号里，正文用全书统一的节级编号（对照表见 1.3 节开头的「编号对照」注）。原书未编号的定义，本教程按所属小节补编号（如「定义 1.2.3」）。 |
| **补全与补注** | 原书省略的证明全部补出：定理 1.3.1 中 1-范数与 ∞-范数的范数性、定理 1.3.3 范数等价定理、Frobenius 范数的全部性质；另补 Cauchy–Schwarz、Neumann 级数、p-范数极限与 Sterbenz 引理。原书例 1–6 的全部数值也逐条复核过，结论见[勘误与补注](ch01/errata.md)。 |
| **扩充知识、例题与习题** | 第一章新增三块现代内容：机器数与 IEEE 754 浮点（[1.2.5](ch01/sec12.md#sec-1.2.5)）、向前 / 向后误差与条件数（[1.2.6](ch01/sec12.md#sec-1.2.6)）、范数与 SVD 的联系（[1.3.6](ch01/sec13.md#sec-1.3.6)）；第二章整章为新增，把原书 1.3 节的范数语言升级为完整的正交 / 投影 / 谱工具箱。两章共 7 组可复现数值实验；习题集各 20 题、**全部附解答或提示**，编程题另给验收标准。 |

新增内容只使用已讲过的概念和 Python（`numpy` / `math` / `decimal` 标准库），不引入后续章节的方法；凡属后续章节才严格展开的结论（矩阵条件数的完整理论、谱半径与迭代法收敛、SVD 的算法实现、PCA），一律用虚线的「课程预告」框标出。

::: note

**编号约定：**正文一律用**节级编号**，即「节号 + 组内序号」（`定理 1.3.6`、`定义 1.2.1`、`例 2.6.1`、`算法 2.3.1`）。原书编号（定理 1.1–1.5、例 1–6、习题 1–15）只写在盒子标题的括注与题面方括号里，正文提到时带「原书」二字；两套编号的对照表放在 1.3 节开头的「编号对照」注中。补全的证明在 `::: proof` 块内；补注条目统一编号（N1、N2、…）。原书页码以 2012 年第 4 版为准。

:::

::: method 怎么用这份教程

- **先做诊断**：[入学诊断自测](entry-test.md) 用 12 道题判断你该从哪一节开始——省时间，不必从头读到尾。
- **对照原书**：第一章的全部定理、例题、习题都**保留原书编号**，可逐条对照；小节标题也沿用原书 1.1 / 1.2 / 1.3 的划分。第二章是扩充章，没有原书编号可对，按本教程自己的编号阅读即可。
- **先读直觉，再抠证明**：每个定义、定理前都配一个蓝色「直觉」框，先用白话讲清它在说什么、为什么需要它；证明收在定理后的 `::: proof` 块内，**第一遍可以整段跳过**，二刷再逐行补。
- **动手实验**：[1.2.7](ch01/sec12.md#sec-1.2.7)、[1.3.6](ch01/sec13.md#sec-1.3.6) 与 [2.7](ch02/sec27.md) 的实验代码都可以直接复制运行；本教程中展示的输出都是真实运行结果，你复现时数字应当逐位一致（计时类除外）。
- **自检**：每节末尾有小结，列出常见错误与误解；每章末尾有习题集（A 概念 / B 证明 / C 计算编程 / D 开放建模，全部附解答或提示）以及把学习目标对应到小节的自检表。
- **跟课堂**：正在修读 2026 秋《数值分析 I》的同学，可把[课堂精编](lectures/overview.md)当作每周复习的对照材料——每讲开头都标了对应的正文小节；老师板书的例题与正文的例题在编号上可以互相印证。课堂精编按讲课顺序组织，正文按概念链组织，**两者交叉读效果最好**：先读正文小节建立框架，再读对应讲次看老师怎么讲、强调什么。

:::
