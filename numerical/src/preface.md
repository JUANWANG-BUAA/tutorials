# 范围与使用方法

本教程依据颜庆津《数值分析》（第 4 版，北京航空航天大学出版社，2012）整理扩充。建议先花十分钟读完本页——后面的正文会反复用到这里的约定。

## 一句话范围

全书以课堂问题组织学习，正文按七章建立理论联系。现有逐讲整理覆盖第 1–15 讲；七章依次讨论误差、线性方程组、特征值、非线性方程、插值与逼近、数值积分、常微分方程。补充篇提供 QR、条件数与 SVD 等可按需调用的工具。第一次学习从[七章学习路径](review/study-paths.md)进入，每章完成一个引导算例、关键推导和条件改变后的练习；跟课时再用逐讲页核对课堂讲法。

- **课堂主线 · 逐讲实录**：北航《数值分析 I》（主讲庞刚，2026-09-07 起）逐讲实录，由课程录播的语音转写与板书关键帧整理订正而成，随课程推进持续更新——见[课堂精编导览](lectures/overview.md)；
- **教材正文**（挂在各讲之下，与原书第 1–7 章同号）：第一章绪论（研究对象、误差知识与算法知识、范数），第 2–7 章为线性方程组、特征值、非线性方程、插值、数值积分、常微分方程；
- **教材拓展与后续内容**：包括 3.2/3.3 的 Jacobi 与 QR 方法、4.2 非线性方程组、5.3 样条、5.4 三角插值与 FFT，以及尚未有本班课堂对应的部分。曲线拟合在 5.6.4，第六章主要内容和第七章开篇已有对应课堂。其他班课件未出现的内容不自动等于本班考纲外；
- **补充篇**：内积与正交性、四个基本子空间与投影、正交化与 QR 分解、条件数与扰动分析、特征值与对称谱理论、奇异值分解与低秩逼近。

## 对原书做的三类工作

原书叙述凝练、例题与习题经典，但部分证明标注「从略 / 留给读者」；又成书于 2012 年，未覆盖现代数值计算赖以运转的浮点标准、向后误差分析框架与 SVD 等方法；例题也以手算为主，缺少可复现的实验。为此，本教程在**不改动原书结论**的前提下做三类工作：

| 做法 | 说明 |
|:--:|:--|
| **不丢内容** | 原书第一章 1.1–1.3 三节的每一条定义、定理、例题与讨论**全部收录**；原书定理 1.1–1.5、例 1–6、习题 1–15 都能与原书逐条对照——原书编号写在盒子标题的括注与题面方括号里，正文用全书统一的节级编号（对照表见 1.3 节开头的「编号对照」注）。原书未编号的定义，本教程按所属小节补编号（如「定义 1.2.3」）。 |
| **补全与补注** | 原书省略的证明全部补出：定理 1.3.1 中 1-范数与 ∞-范数的范数性、定理 1.3.3 范数等价定理、Frobenius 范数的全部性质；另补 Cauchy–Schwarz、Neumann 级数、p-范数极限与 Sterbenz 引理。原书例 1–6 的全部数值也逐条复核过，结论见[勘误与补注](ch01/errata.md)。 |
| **扩充知识、例题与习题** | 第一章新增三块现代内容：机器数与 IEEE 754 浮点（[1.2.5](ch01/sec12.md#sec-1.2.5)）、向前 / 向后误差与条件数（[1.2.6](ch01/sec12.md#sec-1.2.6)）、范数与 SVD 的联系（[1.3.6](ch01/sec13.md#sec-1.3.6)）；补充篇整篇为新增，把原书 1.3 节的范数语言升级为完整的正交 / 投影 / 谱工具箱。第一章与补充篇共 7 组可复现数值实验；习题集各 20 题、**全部附解答或提示**，编程题另给验收标准。 |

新增内容只使用已讲过的概念和 Python（`numpy` / `math` / `decimal` 标准库），不引入后续章节的方法；凡属后续章节才严格展开的结论（矩阵条件数的完整理论、谱半径与迭代法收敛、SVD 的算法实现、PCA），一律用虚线的「课程预告」框标出。

::: note 编号约定
正文一律用**节级编号**，即「节号 + 组内序号」（`定理 1.3.6`、`定义 1.2.1`、`例 2.6.1`、`算法 2.3.1`）。原书编号（定理 1.1–1.5、例 1–6、习题 1–15）只写在盒子标题的括注与题面方括号里，正文提到时带「原书」二字；两套编号的对照表放在 1.3 节开头的「编号对照」注中。补全的证明在 `::: proof` 块内；补注条目统一编号（N1、N2、…）。原书页码以 2012 年第 4 版为准。
:::

::: note 关于「课程预告」
凡要等到后续章节才严格展开的内容（如直接法消元与主元、迭代法的收敛性、SVD 的计算算法、PCA、谱半径与迭代矩阵的关系），本教程只在必要的衔接处用「课程预告」虚线框标出结论与推导要点，不作展开。这样一来，已讲章节的每个概念都有明确的「用武之地」，也就不必提前透支后续内容。
:::

::: method 怎么用这份教程

- **先做诊断**：[入学诊断自测](entry-test.md) 用 12 道题判断你该从哪一节开始——省时间，不必从头读到尾。
- **对照原书**：第一章的全部定理、例题、习题都**保留原书编号**，可逐条对照；小节标题也沿用原书 1.1 / 1.2 / 1.3 的划分。补充篇是扩充篇，没有原书编号可对，按补充篇内部编号阅读即可。
- **沿问题读推导**：先预测引导算例的结果，再读定理解释原因。核心证明至少走通“条件 → 关键等式 → 误差界 → 结论”，然后遮住步骤补写；技术拓展可以后读。不要把所有证明都当作可跳过内容。
- **动手实验**：从[跨章实验](training/learning-lab.md)运行独立的标准库脚本，比较数据、积分与 ODE 的误差；再按需做第一章和补充篇实验。不同浮点环境可能导致末位差异，应核对误差量级、关系式与容差，不能要求所有输出逐位一致。
- **自检**：每节末尾有小结，列出常见错误与误解；每章末尾有习题集（A 概念 / B 证明 / C 计算编程 / D 开放建模，全部附解答或提示）以及把学习目标对应到小节的自检表。
- **跟课堂**：正在修读 2026 秋《数值分析 I》的同学，按[课堂主线逐讲实录](lectures/overview.md)推进——每讲开头都标了对应正文小节，板书例题与正文例题在编号上互相印证；深挖或查漏时回到「教材正文」对应章。

:::
