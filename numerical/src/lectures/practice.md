## A 组 · 概念判断（10 题） {#sec-练-a}

**判定要求**：判断 + 一句话理由；判为「错」的要指出错在哪个条件上。题源见每题括号内的小节。

**A1.** 「误差四分类中，舍入误差是本课程要控制、要研究的核心对象；截断误差由机器字长决定，只能控制其传播。」（[第 1 讲 §四](lec01.md#四误差的来源与分类ppt误差的分类-1444)）

::: sol 答案
**错——两句恰好对调。** 四类误差里：模型 / 观测误差无法消除；**截断误差**是数值方法本身带来的近似，是本课程能控制、要研究的核心对象；**舍入误差**由机器字长决定，可控制的只是**它的传播**。把「截断」当成机器决定的，整条误差红线就搭错了。
:::

**A2.** 「绝对误差限变小，有效数字一定增加——例如 $a=3.1579$ 的 $\varepsilon(a)$ 从 $0.0004$ 减到 $0.0002$ 时，有效位数从 4 位变成 5 位。」（[第 2 讲 §一](lec02.md#一有效数字板书数轴半单位区间图示)）

::: sol 答案
**错。** 位数不看误差限变没变小，只看「误差限是否不超过**某一位的半个单位**」：$\varepsilon=0.0004$ 时区间 $[3.1575,3.1583]$ 落在千分位的半单位区间 $[3.1575,3.1585]$ 内 → 4 位；$\varepsilon=0.0002$ 时区间 $[3.1577,3.1581]$ **仍然**落在同一半单位区间内 → 还是 4 位。要想多一位，误差限必须跨过万分位的半单位 $0.00005$。
:::

**A3.** 「次可乘性 $\lVert AB\rVert\le\lVert A\rVert\lVert B\rVert$ 对任何矩阵范数都可以证明，所以不必列进公理。」（[第 2 讲 §四·§五](lec02.md#四矩阵范数-matrix-norm-与从属范数)）

::: sol 答案
**错。** 对**从属（算子）范数**，次可乘性确实可证（$x$ 取单位向量，用两次相容关系）；但对**一般矩阵范数**它是**公理**要求（矩阵范数四公理的第 4 条）。把「对某类范数成立」读成「对所有范数成立」是常见失分点——这条区分正是第 2 讲结尾证明乘积不等式的意义所在。
:::

**A4.** 「$\lVert G\rVert\lt1$ 只保证『存在某个初值』使迭代收敛；要保证对任意初值收敛，还得再验证 $\rho(G)\lt1$。」（[第 4 讲 §五](lec04.md#五迭代法引论)、[第 5 讲 §三](lec05.md#三范数充分条件与两个误差估计板书-29295709)）

::: sol 答案
**错——两条判据的强弱被颠倒了。** $\lVert G\rVert\lt1$（某个范数）$\Rightarrow$ 解存在唯一且**对任意初值**收敛（充分，但结论已经足够强）；$\rho(G)\lt1$ 才是**充要**条件（对任意初值收敛 $\iff$），只是大规模问题算不出特征根。正确表述：范数条件「好算但偏严」，谱半径条件「最准但难算」。
:::

**A5.** 「SOR 里 $\omega$ 越大越好：$\omega\to2$ 松弛越充分、收敛越快，取到 $\omega=2$ 是极限情形，仍有 $\rho(G)\lt1$。」（[第 6 讲 §五](lec06.md#五收敛的必要条件ω02omegain02ω0226003900)）

::: sol 答案
**错。** $\omega\in(0,2)$ 只是**必要**条件；本页 B5 对具体矩阵算出 $\omega=2$ 时 $\rho(G)=1$（特征值 $(-5\pm\mathrm i\sqrt{11})/6$，模恰为 1），充要条件不成立。C2 的实测也显示 $\omega=1.5$ 的步数（25）反而多于 $\omega\approx1.02$（5）——**参数不是越大越好，得看 $\rho(G(\omega))$**。
:::

**A6.** 「幂法改用 $\infty$-范数单位化后，$y_k^{\mathrm T}Ay_k$ 仍收敛到 $\lambda_1$，只是慢一点。」（[第 7 讲 §五](lec07.md#五特征值的计算为什么必须取-2-范数29004400)）

::: sol 答案
**错。** $\infty$-范数下 $\lVert y_k\rVert_2\ne1$，$y_k^{\mathrm T}y_k\ne1$，公式必须换成商 $y_k^{\mathrm T}Ay_k/y_k^{\mathrm T}y_k$（板书在「$\lVert\cdot\rVert_\infty$」那一行特意提示「另作调整」）。数值见 B6(3)：$\infty$-范数下 $y^{\mathrm T}Ay=5.0$、$y^{\mathrm T}y=1.381966$，商才等于 $3.618034=\lambda_1$。所以不是「慢一点」，而是**公式本身要换**。
:::

**A7.** 「位移反幂法里，$p$ 只要『接近』目标特征值 $\lambda_k$ 就行，不必是最近的那个；$A-pI$ 是否奇异也无所谓。」（[第 7 讲 §八](lec07.md#八位移反幂法求最接近已知-ppp-的特征值1070011530)）

::: sol 答案
**错。** 前提是 $|\lambda_k-p|$ **严格小于**其余所有 $|\lambda_i-p|$——只有这时 $A-pI$ 的目标特征值 $\lambda_k-p$ 才是模最小的，反幂法才瞄得准；否则求到的是别的特征值。第二个说法也错：反幂法要求每步解方程组，$A-pI$ 必须可逆。（$p$ 恰等于某个特征值时 $A-pI$ 奇异，这一点课堂未讨论，属**需核实**的延伸。）
:::

**A8.** 「牛顿法的二阶收敛是四条全局条件保证的：没有 (i)–(iv) 就只能得到一阶收敛。」（[第 9 讲 §二·§三·§四](lec09.md#二收敛阶定理导数消失阶数决定迭代阶数05301120)）

::: sol 答案
**错——把「阶」与「范围」混成了一件事。** 二阶收敛来自 $\varphi'(s)=0$（$\varphi=x-f/f'$，$\varphi'=ff''/(f')^2$，在 $f(s)=0$、$f'(s)\ne0$ 处为零），这是**收敛阶定理**给的，与四条件无关；四条条件管的是**收敛范围**——把「初值充分靠近」升级成「初值落在 $f(x_0)f''(x_0)\gt0$ 指定的阴影区」。所以：没有四条件，牛顿法**在合适的初值下仍是二阶**，只是你不知道多近才算「合适」。
:::

**A9.** 「单点割线法把 $x_{k-1}$ 钉死成 $x_0$ 后，收敛阶从 $1.618$ 降到 $1$，代价是每步仍要算两次函数值。」（[第 9 讲 §八](lec09.md#八割线法的全局收敛与单点割线法51276400)）

::: sol 答案
**错——后半句错。** 阶降为一阶是对的（实测误差比恒为 $0.424$，见 B7(5)）；但 $f(x_0)$ 只算一次并全程**复用**，每步只新增一次求值。它的处境正是「省一次求值，赔一档阶」：牛顿 4 步 / 割线 8 步 / 单点割线 31 步（阈值 $10^{-12}$，见 C4）。
:::

**A10.** 「插值多项式的存在唯一性依赖基的选取：只有换成拉格朗日基之后，存在唯一性才成立。」（[第 9 讲 §十一·§十二](lec09.md#十一范德蒙德矩阵存在唯一但病态80008500)）

::: sol 答案
**错。** 存在唯一由范德蒙德（Vandermonde）行列式 $\det A=\prod_{i\lt j}(x_j-x_i)\ne0$ 保证，**与基的选取无关**（同一个多项式空间的不同基而已）。基决定的是**系数好不好求**：$\{1,x,x^2,\dots\}$ 的系数矩阵病态（C5 实测 $n=12$ 时 $\mathrm{cond}_2=6.8\times10^9$），拉格朗日基在节点上的取值矩阵是单位阵，系数直接读出。这正对应复习页的口诀「存在唯一 $\ne$ 能算出来」。
:::

## B 组 · 推导与计算（8 题）

> 要求：写出每一步中间量；数值答案保留 4 位有效数字（有精确值时给精确值）。全部可手算，必要时用计算器核第 4 位。

**B1.** 有效数字、相对误差限与四则误差限（[第 1 讲 §六](lec01.md#六误差的基本概念板书推导)、[第 2 讲 §一·§二](lec02.md#一有效数字板书数轴半单位区间图示)）
(1) $a=3.1579$：分别取 $\varepsilon(a)=0.0004$ 与 $0.0008$，判断有效位数、给出规范写法并算相对误差限；
(2) $A=2.14$、$B=3.15$ 都是「末位取整」的近似值，求 $A+B$ 的误差限与有效位数；
(3) 取 $a=2.00$（$\varepsilon_a=0.005$）、$b=0.100$（$\varepsilon_b=0.0005$），算 $\varepsilon(a/b)$ 与 $\varepsilon_{\mathrm r}(a/b)$，并与「相对误差限相加」对照；再把 $b$ 缩到 $0.010$（误差限不变）重算一次；
(4) 递推 $I_n=\dfrac1n-5I_{n-1}$：判断正推是否稳定，写出稳定方向，并估计 10 步后初始误差被放大多少倍。

::: sol 答案
**(1)** $\varepsilon=0.0004$：区间 $[3.1575,3.1583]\subset[3.1575,3.1585]$（千分位半单位）→ **4 位**，写作 $3.158$，$\varepsilon_{\mathrm r}=0.0004/3.1579=1.27\times10^{-4}$。$\varepsilon=0.0008$：区间 $[3.1571,3.1587]$ 越出该半单位区间，退到百分位 $[3.155,3.165]$ 才包住 → **3 位**，写作 $3.16$，$\varepsilon_{\mathrm r}=0.0008/3.1579=2.53\times10^{-4}$（误差限翻倍，相对误差限也翻倍，但位数只退一位）。
**(2)** $\varepsilon_{A+B}=0.005+0.005=0.01$ 超过了百分位的半单位 $0.005$，而十分位的半单位 $0.05\ge0.01$ → $A+B=5.29\approx5.3$，只剩 **2 位**有效数字（相加会把位数「吃掉」，这是误差限公式的直接后果）。
**(3)** $\varepsilon(a/b)=\dfrac{|b|\varepsilon_a+|a|\varepsilon_b}{b^2}=\dfrac{0.1\times0.005+2\times0.0005}{0.01}=\dfrac{0.00075}{0.01}=0.15$，$a/b=20$，$\varepsilon_{\mathrm r}=0.15/20=0.75\%$；而 $\varepsilon_{\mathrm r}(a)+\varepsilon_{\mathrm r}(b)=0.25\%+0.5\%=0.75\%$ ✓ 两者一致（乘除法的相对误差限近似相加）。$b=0.010$ 时：$\varepsilon(a/b)=\dfrac{0.01\times0.005+2\times0.0005}{10^{-4}}=10.5$，$a/b=200$，$\varepsilon_{\mathrm r}=5.25\%$——从 $0.75\%$ 涨到 $5.25\%$，全部来自 $\varepsilon_{\mathrm r}(b)=5\%$ 与分母里的 $b^2$。**小数不放分母**的定量形态。
**(4)** 误差传播 $\varepsilon_n=-5\varepsilon_{n-1}$，放大因子 $|-5|=5\gt1$ → **正向不稳定**；反解 $I_{n-1}=\dfrac{1/n-I_n}{5}$，因子 $-1/5$，$|-1/5|\lt1$ → **反向稳定**（从较大的 $n$ 出发往回推）。10 步放大 $5^{10}=9\,765\,625\approx9.8\times10^6$ 倍：初始 $10^{-6}$ 的误差会被放大到量级 $10$。判据只看放大因子，与递推式长什么样无关。
:::

**B2.** 条件数估计与病态诊断（[第 3 讲 §一](lec03.md#一矩阵范数的计算公式本讲推导成果)、[第 9 讲 §十一](lec09.md#十一范德蒙德矩阵存在唯一但病态80008500)）
设 $A=\begin{pmatrix}1&1\\1&1.001\end{pmatrix}$，$b=(2,\ 2.001)^{\mathrm T}$。
(1) 手算 $A^{-1}$、$\lVert A\rVert_\infty$、$\lVert A^{-1}\rVert_\infty$ 与 $\mathrm{cond}_\infty(A)=\lVert A\rVert_\infty\lVert A^{-1}\rVert_\infty$；
(2) 把 $b_2$ 改成 $2.002$（右端相对扰动约 $0.05\%$）后重解，比较解的相对变化，并与扰动界 $\mathrm{cond}\times\delta$ 对照；
(3) 问：改用列主元高斯消去法能不能把条件数降下来？为什么？

::: sol 答案 {#prac-b2}
**(1)** $\det A=1\times1.001-1\times1=0.001$，
$$A^{-1}=\frac{1}{0.001}\begin{pmatrix}1.001&-1\\-1&1\end{pmatrix}=\begin{pmatrix}1001&-1000\\-1000&1000\end{pmatrix}.$$
$\lVert A\rVert_\infty=\max(1+1,\ 1+1.001)=2.001$；$\lVert A^{-1}\rVert_\infty=\max(1001+1000,\ 1000+1000)=2001$；
$$\mathrm{cond}_\infty(A)=2.001\times2001=4004.001\approx4.0\times10^3 .$$
（与[复习页 §2.3](review.md#sec-复习-条件数)登记的量级一致。）$\log_{10}4004=3.60$，数量级上对应 3~4 位有效数字的损失——注意「损失位数 $\approx\log_{10}\mathrm{cond}$」这条结论属补充篇 2.4，课堂未讲，**需核实**。
**(2)** 原方程两式相减得 $0.001x_2=0.001$，故原解 $x=(1,1)^{\mathrm T}$（代入可验）。新右端 $(2,\ 2.002)^{\mathrm T}$：相减得 $0.001x_2=0.002\Rightarrow x_2=2$，再回代 $x_1=0$，新解 $x'=(0,2)^{\mathrm T}$。相对扰动 $\lVert\Delta b\rVert_\infty/\lVert b\rVert_\infty=0.001/2.001=5.0\times10^{-4}$（$0.05\%$）；解的相对变化 $\lVert\Delta x\rVert_\infty/\lVert x\rVert_\infty=1/1=100\%$——放大 $2\times10^3$ 倍，与 $\mathrm{cond}_\infty$ 同量级。而界给出 $\mathrm{cond}\times\delta=4004\times5.0\times10^{-4}\approx2.0$（即 $200\%$）：实测 $100\%\le200\%$ ✓，界成立且几乎被取到。
**(3)** **不能。** 条件数是**问题**（矩阵与右端）的属性：$\mathrm{cond}=\lVert A\rVert\lVert A^{-1}\rVert$ 与用什么算法无关。列主元只把消去乘数控制到 $|m_{ik}|\le1$，防止误差在消去过程中被继续放大；它救不了「两行几乎相同」这个几何事实——第二行只比第一行多在第二分量上加了一个 $0.001$，两个方程几乎重合，交点对右端极敏感。处置要**换提法**（换基、换模型），见 D1 与[第 9 讲 §十一](lec09.md#十一范德蒙德矩阵存在唯一但病态80008500)。
:::

**B3.** 消去一步、主元与 LU 分解（[第 3 讲 §四·§五](lec03.md#四高斯消去法-gaussian-elimination)、[第 4 讲 §三](lec04.md#三直接三角分解doolittle-分解待定系数法)）
设 $A=\begin{pmatrix}0.5&1&1\\1&2&4\\2&1&3\end{pmatrix}$，$b=(3,7,6)^{\mathrm T}$。
(1) 算顺序主子式 $\Delta_1,\Delta_2$，判断不换行的高斯消去能走几步、卡在哪一步；$\det A=3\ne0$ 说明了什么？
(2) 不换行做第一步消去：写出 $m_{21},m_{31}$ 与消去后的第二、三行；再改用列主元做第一步，比较乘数；
(3) 用列主元把方程组解到底（含回代），给出解；
(4) 对 $A'=\begin{pmatrix}2&2&3\\4&7&7\\-2&4&5\end{pmatrix}$ 做 Doolittle 分解（逐圈），写出 $L$ 与 $U$。

::: sol 答案
**(1)** $\Delta_1=0.5\ne0$，$\Delta_2=0.5\times2-1\times1=0$。由充要条件（前 $n-1=2$ 个顺序主子式均不为零 $\iff$ 能不换行消成上三角）知：**第一步能走，第二步卡住**（实测第一步后第二行为 $(0,0,2)$，主元 $a^{(1)}_{22}=0$）。$\det A=3\ne0$ 说明 $Ax=b$ 有唯一解——「能不能消」看前 $n-1$ 个顺序主子式，「有没有唯一解」看第 $n$ 个，这是两件事。
**(2)** $m_{21}=-\dfrac{1}{0.5}=-2$，$m_{31}=-\dfrac{2}{0.5}=-4$（$|m|\gt1$，误差会被放大）；第二行 $(1,2,4)-2(0.5,1,1)=(0,0,2)$，第三行 $(2,1,3)-4(0.5,1,1)=(0,-3,-1)$。列主元：第一列绝对值最大元为 $2$（第 3 行），交换第 1、3 行得 $A=\begin{pmatrix}2&1&3\\1&2&4\\0.5&1&1\end{pmatrix}$、$b=(6,7,3)^{\mathrm T}$，此时 $m_{21}=-\frac12$、$m_{31}=-\frac14$，都满足 $|m|\le1$——**这就是列主元的全部目的**。
**(3)** 第一步消去后 $\begin{pmatrix}2&1&3\\0&1.5&2.5\\0&0.75&0.25\end{pmatrix}$，$b=(6,4,1.5)^{\mathrm T}$；第二步主元 $1.5\gt0.75$ 不必交换，$m_{32}=-\dfrac{0.75}{1.5}=-\dfrac12$，得 $\begin{pmatrix}2&1&3\\0&1.5&2.5\\0&0&-1\end{pmatrix}$，$b=(6,4,-0.5)^{\mathrm T}$。回代：$x_3=0.5$；$x_2=\dfrac{4-2.5\times0.5}{1.5}=\dfrac{11}{6}=1.8333$；$x_1=\dfrac{6-1\times\frac{11}{6}-3\times0.5}{2}=\dfrac43=1.3333$。即 $x=\left(\dfrac43,\dfrac{11}{6},\dfrac12\right)^{\mathrm T}$，代回三行逐行验证 ✓。
**(4)** 逐圈（第 1 行 U → 第 1 列 L → 第 2 行 U → 第 2 列 L）：$u_{11}=2,\ u_{12}=2,\ u_{13}=3$；$l_{21}=4/2=2,\ l_{31}=-2/2=-1$；$u_{22}=7-2\times2=3,\ u_{23}=7-2\times3=1$；$l_{32}=\dfrac{4-(-1)\times2}{3}=2$。回代得最后一元 $u_{33}=5-(-1)\times3-2\times1=6$，于是
$$L=\begin{pmatrix}1&0&0\\2&1&0\\-1&2&1\end{pmatrix},\qquad U=\begin{pmatrix}2&2&3\\0&3&1\\0&0&6\end{pmatrix},$$
乘回去逐元素等于 $A'$ ✓（顺序主子式 $\Delta_1=2,\Delta_2=6,\Delta_3=36$ 均非零，分解存在）。关键在**安排顺序**：每一圈只含一个未知数。

**B4.** 迭代矩阵、谱半径与收敛判定（[第 5 讲 §四·§五](lec05.md#四gaussjacobi-迭代板书-60097934)）
设 $A=\begin{pmatrix}3&-1\\-1&4\end{pmatrix}$，$b=(1,1)^{\mathrm T}$，三分 $A=L+D+U$。
(1) 写出 $D$、$L$、$U$ 与 $G_J=D^{-1}\bigl(-(L+U)\bigr)$，算 $\lVert G_J\rVert_\infty$ 与 $\rho(G_J)$（精确值 + 4 位小数）；
(2) 用行对角占优判断 Jacobi 收敛性，并说明这一步用的是哪条判据；
(3) 写出 $G_{GS}=-(L+D)^{-1}U$ 并算 $\rho(G_{GS})$；
(4) 后验估计的常数 $\dfrac{\lVert G_J\rVert_\infty}{1-\lVert G_J\rVert_\infty}$ 是多少？它有什么用？

::: sol 答案 {#prac-b4}
**(1)** $D=\operatorname{diag}(3,4)$，$L=\begin{pmatrix}0&0\\-1&0\end{pmatrix}$，$U=\begin{pmatrix}0&-1\\0&0\end{pmatrix}$，
$$G_J=D^{-1}\bigl(-(L+U)\bigr)=\begin{pmatrix}0&\tfrac13\\[2pt]\tfrac14&0\end{pmatrix}.$$
$\lVert G_J\rVert_\infty=\max\left(\tfrac13,\tfrac14\right)=\tfrac13=0.3333$。形如 $\begin{pmatrix}0&a\\b&0\end{pmatrix}$ 的矩阵特征值为 $\pm\sqrt{ab}$，故 $\rho(G_J)=\sqrt{\tfrac1{12}}=\dfrac{1}{2\sqrt3}=0.2887$。
**(2)** 行对角占优（strict diagonal dominance）：$|3|\gt|-1|$ ✓、$|4|\gt|-1|$ ✓，于是
$$\lVert G_J\rVert_\infty=\max_i\frac{\sum_{j\ne i}|a_{ij}|}{|a_{ii}|}=\max\left(\tfrac13,\tfrac14\right)=\tfrac13\lt1\ \Rightarrow\ \text{Jacobi 收敛}.$$
这一步走的是**充分**条件（$\lVert G\rVert_\infty\lt1$，手算即可）；(1) 的 $\rho(G_J)\lt1$ 是**充要**条件，本例太小、两者都能算，大规模问题只能走前者。
**(3)** $L+D=\begin{pmatrix}3&0\\-1&4\end{pmatrix}$，$(L+D)^{-1}=\begin{pmatrix}\frac13&0\\\frac1{12}&\frac14\end{pmatrix}$，
$$G_{GS}=-(L+D)^{-1}U=\begin{pmatrix}0&\tfrac13\\[2pt]0&\tfrac1{12}\end{pmatrix}\ (\text{下三角})\ \Rightarrow\ \rho(G_{GS})=\tfrac1{12}=0.0833 .$$
（数值上 $0.0833=0.2887^2$；这种「平方关系」需要额外的一致次序（consistently ordered）条件，本 8 讲未讲，**需核实**。）
**(4)** 常数 $=\dfrac{1/3}{2/3}=\dfrac12$。用途：后验误差估计 $\lVert x^*-x^{(k)}\rVert_\infty\le\dfrac12\lVert x^{(k)}-x^{(k-1)}\rVert_\infty$——这就是「相邻差小就停机」的定量依据。C2 会用实测比值（$0.36\sim0.45$）验证这条界成立。
:::

**B5.** SOR：构造、$\omega=2$ 与最优参数（[第 6 讲 §二·§三·§五](lec06.md#二sor-的构造把对角部分按参数分配07001003)）
仍用 $A=\begin{pmatrix}3&-1\\-1&4\end{pmatrix}$（$n=2$）。
(1) 写出 $N=L+\omega^{-1}D$、$P=(\omega^{-1}-1)D-U$，验证 $N-P=A$；
(2) 取 $\omega=1.2$，用 $|\det G|=|\omega-1|^n$ 算出 $|\det G|$，并用 $\det G=\det P/\det N$ 直接核对；
(3) 取 $\omega=2$，写出 $G=N^{-1}P$ 并算出 $\rho(G)$；为什么这说明 $\omega=2$ 不能用？
(4) 在 $(0,2)$ 上扫描 $\rho(G(\omega))$，找出使 $\rho$ 最小的 $\omega$；并说明「必要不充分」在这里意味着什么。

::: sol 答案 {#prac-b5}
**(1)** $N=L+\omega^{-1}D=\begin{pmatrix}3/\omega&0\\-1&4/\omega\end{pmatrix}$（下三角），$P=(\omega^{-1}-1)D-U=\begin{pmatrix}3(\omega^{-1}-1)&1\\0&4(\omega^{-1}-1)\end{pmatrix}$（上三角）。相减：对角元 $3/\omega-3(\omega^{-1}-1)=3$、$4/\omega-4(\omega^{-1}-1)=4$，下三角 $-1$，上三角 $-1$ → $N-P=A$ ✓（构造的检验式）。
**(2)** $\omega=1.2$：$|\det G|=|\omega-1|^2=0.2^2=0.04$。直接核对：$\det N=(3/\omega)(4/\omega)=12/1.44=8.3333$，$|\det P|=\left|\omega^{-1}-1\right|^2\times3\times4=0.16667^2\times12=0.33333$，故 $|\det G|=0.33333/8.3333=0.04$ ✓。
**(3)** $\omega=2$：$N=\begin{pmatrix}1.5&0\\-1&2\end{pmatrix}$，$P=\begin{pmatrix}-1.5&1\\0&-2\end{pmatrix}$，$N^{-1}=\begin{pmatrix}\frac23&0\\\frac13&\frac12\end{pmatrix}$，
$$G=N^{-1}P=\begin{pmatrix}-1&\tfrac23\\[2pt]-\tfrac12&-\tfrac23\end{pmatrix},\qquad \operatorname{tr}G=-\tfrac53,\quad \det G=1 .$$
特征方程 $\lambda^2+\tfrac53\lambda+1=0$，根 $\lambda=\dfrac{-5\pm\mathrm i\sqrt{11}}{6}$，$|\lambda|^2=\dfrac{25+11}{36}=1$ → $\rho(G)=1$。充要条件是 $\rho(G)\lt1$，而 $|\det G|=|\omega-1|^n=1$ 恰好落在必要条件的**边界**上：特征值模之积为 1，就不可能「每个模都小于 1」。所以 $\omega=2$ 不保证收敛，本题更是 $\rho=1$（误差按模 1 的复特征值旋转、不衰减）。
**(4)** 以步长 $10^{-3}$ 扫描得 $\omega\approx1.022$ 处最小：$\rho_{\min}\approx0.0218$（$\omega=1.02$ 时 $0.0354$、$\omega=1.05$ 时 $0.0500$——极小点很窄）。经典教材的最优参数公式 $\omega_{\mathrm{opt}}=\dfrac{2}{1+\sqrt{1-\rho(G_J)^2}}=1.0217$ 与扫描值吻合，**但此公式不在本 8 讲范围，需核实**。「必要不充分」的意思：定理只保证 $\omega\notin(0,2)$ **一定不收敛**；区间内部收不收敛要看矩阵——本题 $A$ 对称正定，由 Ostrowski 定理 $0\lt\omega\lt2$ 是充要（区间内都收敛）；换成一般矩阵，同样 $\omega\in(0,2)$ 也可能 $\rho(G)\ge1$。
:::

**B6.** 幂法一步、Rayleigh 商与反幂法（[第 7 讲 §四·§五·§七](lec07.md#四规范化幂法先单位化再乘-aaa19302900)）
设 $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$，特征值 $\lambda_1=\dfrac{5+\sqrt5}{2}=3.6180339887$、$\lambda_2=\dfrac{5-\sqrt5}{2}=1.3819660113$，取 $u_0=(1,0)^{\mathrm T}$。
(1) 按 $y_k=\dfrac{u_k}{\lVert u_k\rVert_2}$、$u_{k+1}=Ay_k$ 迭代 4 步，列出 $u_k$（可整型化）与 $y_k$；
(2) 每步算 Rayleigh 商 $R_k=y_k^{\mathrm T}Ay_k=\dfrac{u_k^{\mathrm T}Au_k}{u_k^{\mathrm T}u_k}$，列出 $e_k=|R_k-\lambda_1|$ 与比值 $e_{k+1}/e_k$，说明它趋于什么；
(3) 若改用 $\infty$-范数单位化，$y^{\mathrm T}Ay$ 等于多少？该怎么读特征值？
(4) 用反幂法求 $\lambda_2$（模最小）：写出 $A^{-1}$，按「每步解 $Au_{k+1}=y_k$」迭代 3 步，给出 $R_k$ 序列。

::: sol 答案
**(1)** $u_k$ 同乘正数不改变 $y_k$，故可整型化：$u_0=(1,0)\to u_1=(2,1)\to u_2=(5,5)\to u_3=(15,20)\to u_4=(50,75)$。对应
$$y_1=\frac{(2,1)}{\sqrt5}\approx(0.8944,0.4472),\quad y_2=\frac{(1,1)}{\sqrt2}\approx(0.7071,0.7071),\quad y_3=(0.6,0.8),\quad y_4=\frac{(2,3)}{\sqrt{13}}\approx(0.5547,0.8321).$$
（顺序不能反：**先单位化，再乘 $A$**。）
**(2)** $R_0=2$（$y_0=(1,0)$）、$R_1=3$、$R_2=3.5$、$R_3=3.6$、$R_4=\dfrac{47}{13}=3.6153846$；误差 $e=0.618034,\ 0.118034,\ 0.018034,\ 0.002650,\dots$，比值 $0.191\to0.153\to0.147\to0.146$，趋于 $0.1459=\left(\dfrac{\lambda_2}{\lambda_1}\right)^2=0.381966^2$。注意：**特征向量**的误差按 $|\lambda_2/\lambda_1|=0.382$ 衰减，而由 $R$ 读出的**特征值**误差按它的平方 $0.146$ 衰减——这条「平方加速」是本页的数值观察（课堂未展开，**需核实**）。
**(3)** $\infty$-范数极限单位向量为 $y=(0.618034,\ 1)$，此时 $y^{\mathrm T}Ay=5.0$、$y^{\mathrm T}y=1.381966$，两者不是同一个数；但
$$\frac{y^{\mathrm T}Ay}{y^{\mathrm T}y}=\frac{5.0}{1.381966}=3.618034=\lambda_1\ ✓ .$$
所以换范数后**必须补上分母** $y_k^{\mathrm T}y_k$。
**(4)** $A^{-1}=\dfrac15\begin{pmatrix}3&-1\\-1&2\end{pmatrix}$；迭代 $u_{k+1}=A^{-1}y_k$（实际每步解 $Au_{k+1}=y_k$，**不构造** $A^{-1}$），整型化序列 $(1,0)\to(3,-1)\to(2,-1)\to(7,-4)$：
$$R_0=2,\quad R_1=1.5,\quad R_2=1.4,\quad R_3=\tfrac{18}{13}=1.384615 ,$$
继续两步得 $1.382353$、$1.382022$ → 报 $\lambda_2=1.3820$，与 $\dfrac{5-\sqrt5}{2}=1.3819660$ 一致到 4 位以上小数（误差比同样趋于 $0.146$）。

**B7.** 二分法、不动点迭代、牛顿法与割线法族（[第 7 讲 §九·§十](lec07.md#九非线性方程不动点形式与二分法1160012630)、[第 9 讲 §四·§七·§八](lec09.md#四牛顿法的全局收敛定理16002100)）
统一取 $f(x)=x^3-x-1$（根 $s=1.3247179572447460$）。
(1) 验证 $f(1)f(2)\lt0$，做三步二分（写出中点与保留区间），并算「区间长 $\lt10^{-6}$」所需步数；
(2) 改写成 $x=(x+1)^{1/3}$：在 $[1,1.5]$ 上验证自映射与压缩条件（给出 $L$），迭代 4 步并算误差比；
(3) 另一变形 $x=x+f(x)=x^3-1$：算 $\varphi'(s)$ 并判断能否用；
(4) 牛顿法从 $x_0=1.5$ 出发迭代 4 步，用实测阶公式 $p\approx\dfrac{\ln(e_{k+1}/e_k)}{\ln(e_k/e_{k-1})}$ 算两个 $p$，并与理论因子 $\dfrac{f''(s)}{2f'(s)}$ 对照；
(5) 割线法（$x_0=1,x_1=2$）与单点割线法（$x_0=2$ 钉住、$x_1=1.5$）各迭代到误差 $\lt10^{-12}$，列出步数与实测阶，并解释两者与牛顿法的差距。

::: sol 答案 {#prac-b7}
**(1)** $f(1)=-1\lt0$，$f(2)=5\gt0$ ✓（介值定理保证有根）。$c_1=1.5$、$f=0.875\gt0\to[1,1.5]$；$c_2=1.25$、$f=-0.296875\to[1.25,1.5]$；$c_3=1.375$、$f=0.224609\to[1.25,1.375]$。区间长 $=\dfrac{1}{2^n}$，需 $\dfrac1{2^n}\lt10^{-6}\Rightarrow n\gt\log_210^6=19.93$，即 **20 步**。
**(2)** $\varphi(x)=(x+1)^{1/3}$ 单增：$\varphi(1)=1.2599\in[1,1.5]$，$\varphi(1.5)=1.3572\in[1,1.5]$ → 自映射 ✓；$\varphi'(x)=\dfrac13(x+1)^{-2/3}$，$\varphi'(1)=0.2100$、$\varphi'(1.5)=0.1810$，取 $L=0.21\lt1$ → 压缩 ✓（两条件各管什么：第一条管迭代值不越界，第二条管误差收缩）。迭代：$1\to1.2599210\to1.3122938\to1.3223538\to1.3242687$；误差 $6.48\times10^{-2},\,1.242\times10^{-2},\,2.364\times10^{-3},\,4.492\times10^{-4}$，比值 $0.1917,0.1903,0.1900\to\varphi'(s)=0.18995$：**线性（一阶）收敛**，误差每步约乘 $0.19$。
**(3)** $\varphi_2'(x)=3x^2$，$\varphi_2'(s)=3\times1.7548=5.2646\gt1$ → 在根附近误差被**放大**，迭代发散（实测 $1.5\to2.375\to12.40\to1904\to6.9\times10^9$）。变形不唯一，选错就发散——这正是收敛定理存在的理由。
**(4)** 牛顿迭代（$x_{k+1}=x_k-f/f'$，$f'=3x^2-1$）：

| $k$ | $x_k$ | $e_k=|x_k-s|$ |
|:--:|:--|:--|
| 0 | 1.5 | $1.7528\times10^{-1}$ |
| 1 | 1.3478260870 | $2.3108\times10^{-2}$ |
| 2 | 1.3252003990 | $4.8244\times10^{-4}$ |
| 3 | 1.3247181740 | $2.1675\times10^{-7}$ |
| 4 | 1.3247179572 | $4.4\times10^{-14}$ |

**B8.** 拉格朗日插值与误差界（[第 9 讲 §十·§十二](lec09.md#十插值法引论从散点到曲线65008000)）
(1) 求过 $(0,1),(1,2),(2,5)$ 的插值多项式：写出三个基函数 $l_i(x)$ 与 $L_2(x)$，化简后对照 $l_i$ 的筛选性质；
(2) 同一组节点上取 $f(x)=\mathrm e^x$（系数即 $(1,\mathrm e,\mathrm e^2)$），算 $x=0.5$ 与 $x=1.5$ 的插值值与真实误差；
(3) 用余项式 $R_2(x)=f(x)-L_2(x)=\dfrac{f^{(3)}(\xi)}{3!}\prod_{i=0}^{2}(x-x_i)$ 给出这两点的误差上界，并给出 $[0,2]$ 上的整体上界（提示：求 $\max|x(x-1)(x-2)|$）；
(4) 这个界「紧」吗？

::: sol 答案 {#prac-b8}
**(1)** $l_0(x)=\dfrac{(x-1)(x-2)}{(0-1)(0-2)}=\dfrac{(x-1)(x-2)}{2}$，$l_1(x)=\dfrac{x(x-2)}{(1)(1-2)}=-x(x-2)$，$l_2(x)=\dfrac{x(x-1)}{(2)(2-1)}=\dfrac{x(x-1)}{2}$。于是
$$L_2(x)=1\cdot l_0+2\cdot l_1+5\cdot l_2=\tfrac{x^2-3x+2}{2}-2x^2+4x+\tfrac{5x^2-5x}{2}=x^2+1 .$$
筛选性质：$l_i(x_i)=1$、$l_i(x_j)=0\ (j\ne i)$——代入节点时只有自己那项存活，**系数直接就是函数值** $(1,2,5)$，$L_2(x_i)=x_i^2+1$ 与数据一致 ✓（一步方程都不用解，这就是换基的收益）。
**(2)** 同一组基、系数换成 $(1,\mathrm e,\mathrm e^2)$：$(l_0,l_1,l_2)|_{x=0.5}=(0.375,\,0.75,\,-0.125)$，
$$L_2(0.5)=0.375+0.75\,\mathrm e-0.125\,\mathrm e^2=1.49007936,\qquad \mathrm e^{0.5}=1.64872127\ \Rightarrow\ R_2=-0.15864191 .$$
$x=1.5$：$L_2(1.5)=4.68460741$，$\mathrm e^{1.5}=4.48168907\Rightarrow R_2=+0.20291834$。
**(3)** $f^{(3)}=\mathrm e^x$ 在 $[0,2]$ 上最大为 $\mathrm e^2=7.389056$，故 $\dfrac{f^{(3)}(\xi)}{3!}\le\dfrac{7.389056}{6}=1.231509$；而 $x=0.5$ 与 $1.5$ 处 $\left|\prod(x-x_i)\right|=0.5\times0.5\times1.5=0.375$，于是
$$|R_2(0.5)|,\ |R_2(1.5)|\le1.231509\times0.375=0.461816 .$$
整体上界：$[0,2]$ 上 $\max|x(x-1)(x-2)|=0.384900$（在 $x=1\pm\dfrac{1}{\sqrt3}=0.4226,\ 1.5774$ 取到），故 $|R_2(x)|\le1.231509\times0.384900=0.474008$。
**(4)** **不紧。** 实测误差只占界的一部分：$x=0.5$ 处 $34\%$、$x=1.5$ 处 $44\%$；$[0,2]$ 上最大实测误差 $0.2135$ 也只到全局界的 $45\%$。余项界给的是**有保证的上界**，不是误差估计——要预测误差量级、判断「节点加密是否收敛」，得等下一讲（Runge 现象一类问题，**需核实**）。余项式本身出现在[第 9 讲 §十二 页末预告](lec09.md#十二拉格朗日插值换基避病态85009903)，本页只做误差界。
:::

实现 `doolittle(A) -> (L, U)` 与 `thomas(lo, diag, up, d) -> x`（前者前代 + 回代解 $Ax=b$）。
**验收标准**：① 对 $A'=\begin{pmatrix}2&2&3\\4&7&7\\-2&4&5\end{pmatrix}$：`max|L@U - A| < 1e-12`，且 `np.diag(L) == 1` 全部成立（B3(4) 的答案用来对表）；② 用前代 + 回代解 $A'x=(1,1,1)^{\mathrm T}$ 与 `np.linalg.solve` 的解差 $<10^{-10}$；③ 三对角 $T=\operatorname{tridiag}(-1,2,-1)$（$n=3$）：$L$、$U$ 的非零元数都等于 $2n-1=5$（**无填充**），并断言 `np.count_nonzero(np.triu(L, 2)) == 0` 且 `np.count_nonzero(np.tril(U, -2)) == 0`；④ 追赶法解 $\begin{pmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{pmatrix}x=(1,0,1)^{\mathrm T}$ 得 $(1,1,1)^{\mathrm T}$，误差 $<10^{-12}$；⑤ 打印 $n=1000$ 时追赶法（约 $3n$）与稠密 LU（约 $2n^3/3$）的运算量估计。
::: sol 参考实现要点
逐圈顺序不能乱——先 `U[k, k:] = A[k, k:] - L[k, :k] @ U[:k, k:]`，再 `L[k+1:, k] = (A[k+1:, k] - L[k+1:, :k] @ U[:k, k]) / U[k, k]`；追赶法的关键行是 `den = diag[i] - lo[i-1]*c_prev`（这一行就是「不产生填充」的全部内容），随后回代 `x[i] = d_[i] - c_[i]*x[i+1]`。
:::

**D1.** 病态方程组的诊断与处置流程
背景：B2 的 $A=\begin{pmatrix}1&1\\1&1.001\end{pmatrix}$（$\mathrm{cond}_\infty\approx4.0\times10^3$，两行近似平行）。给出从「发现病态」到「交一份可信结果」的完整流程。

::: sol 参考方案与评分要点
**方案（四步）**：① **诊断**——算（或估）$\mathrm{cond}=\lVert A\rVert\lVert A^{-1}\rVert$：小规模用范数手算（第 3 讲练的正是 $\lVert A\rVert_1$、$\lVert A\rVert_\infty$），大规模用已知解算例做扰动实验（把 $b$ 扰动 $\delta$，看解跑多远）；② **定风险**——把 $\mathrm{cond}$ 与「要求保留的有效位数」对照，预留 $\mathrm{cond}$ 倍的前向误差（补充篇 2.4 的界，**需核实**）；③ **处置（按代价从低到高）**——换提法/换基（插值问题从范德蒙德基换到拉格朗日基，[第 9 讲 §十二](lec09.md#十二拉格朗日插值换基避病态85009903)）→ 正则化/增广（把病态问题换成良态问题的近似）→ 提高浮点精度（float64 → float128 / 任意精度库）→ 若只关心残差，改用残差判据停止；④ **绝不指望**列主元或迭代改进「治好」条件数。
**理由**：条件数是**问题**的属性（第 9 讲的红线：存在唯一 $\ne$ 能算出来）；列主元只把消去乘数控制到 $|m|\le1$，避免误差在消去过程中被继续放大，它不改变 $\lVert A\rVert\lVert A^{-1}\rVert$。
**失败判据**：① **残差小但解误差大**——B2 的扰动实验里残差可以做到机器精度量级而解的相对误差仍是 $100\%$，所以「残差小」不能作为收工标准；② 把 $b$ 换成更高精度后解仍大幅变化（说明问题不在右端精度，而在条件数）；③ 换基后条件数没有下降（换错了基，或问题根本不是「基」的问题）。
**验证计划**：小规模时用已知解构造算例，扫 $\mathrm{cond}$ 从小到大，记录「实测前向误差 / 理论界」的比值（B2 实测 $100\%/200\%=0.5$）；大规模时用「残差 + 与高精度解对比」双轨；把每步的 $\mathrm{cond}$ 估计、采取的措施、剩余不确定度写进报告，形成可复现的检查表。
**评分要点**：四步流程具体（1 分）；理由指到「问题属性 vs 算法改良」（0.5 分）；失败判据可测量（0.5 分）；验证计划含高精度对照（1 分）。
:::

**D2.** 为什么 SOR 的 $\omega$ 不能取 2
不只回答「定理说不行」，而要给出可验证的完整论证。

::: sol 参考方案与评分要点 {#prac-d2}
**方案**：三步走——(a) 用必要条件算边界：$|\det G|=|\omega-1|^n$，$\omega=2$ 时恰为 $1$；(b) 对具体矩阵**直接把 $G(2)$ 写出来求谱**（B5(3)：$G=\begin{pmatrix}-1&\frac23\\-\frac12&-\frac23\end{pmatrix}$，$\operatorname{tr}G=-\frac53$、$\det G=1$，特征值 $\frac{-5\pm\mathrm i\sqrt{11}}{6}$，模为 $1$）；(c) 扫描 $\rho(G(\omega))$ 并检查两个端点与内部的行为。
**理由**：$\rho(G)=1$ 使充要条件 $\rho(G)\lt1$ 不成立——特征值模为 $1$ 时误差既不衰减也不放大，而是按复特征值**旋转**；且 $|\det G|=1$ 意味着「模之积为 1」，不可能推出「每个模都小于 1」。这正是[第 6 讲 §五](lec06.md#五收敛的必要条件ω02omegain02ω0226003900)「区间外一定不收敛」的**端点**形态：$\omega=2$ 卡在必要条件的边界上，既不能保证收敛，具体到本题更是 $\rho=1$。
**失败判据**：① $\omega\to0^+$ 时 $N=L+\omega^{-1}D$ 的元素发散（$1-\omega^{-1}\to\infty$），迭代失去意义——注意区间是**开**的（第 6 讲考注 1）；② $\omega\in(0,2)$ 内部、但矩阵非对称正定时 $\rho(G)\ge1$——只查区间不查谱就会漏（Ostrowski 定理只对对称正定给充要）；③ 「迭代若干步后误差不再下降」时，先怀疑 $\rho\ge1$，而不是「精度不够」。
**验证计划**：对同一个 $A$ 扫 $\omega\in(0.01,3.99)$（步长 $10^{-3}$）画 $\rho(G(\omega))$，标出 $\rho=1$ 的两个点；对 $\omega=2$ 单独跑一次迭代，打印前 20 步误差（应不衰减）；用 $\omega\approx1.022$ 对照（5 步进入 $10^{-8}$）。脚本留在仓库里，作为「SOR 参数不能凭直觉」的证据。
**评分要点**：给出 $\rho(2)=1$ 的**推导**而不只是结论（1 分）；理由说到「必要条件的边界」（0.5 分）；失败判据含「内部也可能不收敛」（0.5 分）；验证计划可执行（1 分）。
:::

**D3.** 从这 8 讲里挑一个算法：它在现代库里的替代品与理由
在「幂法 / 反幂法」「Jacobi–GS–SOR」「三对角追赶法」中挑**一个**（下面以第一个为例）。

::: sol 参考方案与评分要点
**方案**：以「幂法 / 反幂法」为例：课堂算法只求**一个**特征对（模最大 / 模最小 / 最接近 $p$），收敛率被 $|\lambda_2/\lambda_1|$ 支配；现代做法是 **Lanczos / Arnoldi + 隐式重启**（稀疏：`scipy.sparse.linalg.eigsh` / `eigs`，即 ARPACK），稠密对称全谱问题交 LAPACK 的对称特征求解器（`dsyevr` / `dsyevd`）；此外还常用「位移-反迭代精修」把近似特征对打到机器精度（课堂的位移反幂法就是它的种子）。若挑「三对角追赶法」：现代对应物是**结构保持**的带状求解器（LAPACK `dgtsv`），课堂强调的 $O(n)$、无填充正是它的设计目标；若挑「Jacobi–GS–SOR」：它们在现代退到**预条件子 / 平滑子**的位置，主干换成 Krylov 子空间方法（CG / GMRES，[第 4 讲 §五](lec04.md#五迭代法引论)已点名 GMRES）。
**理由**：① 幂法的收敛率由谱间隙决定，间隙很小时慢到不可用；重启动 Krylov 每次用**整个子空间**的信息（等价于把多个幂法步叠在一起），对谱间隙不敏感。② 幂法 / 反幂法每步都要矩阵-向量乘或解方程组，Lanczos 只做乘，天然适合稀疏与矩阵免乘法（matrix-free）场景。③ SOR 的最优 $\omega$ 事先不知道（B5 里靠扫描；本 8 讲没有最优 $\omega$ 的公式），而 GMRES 无参数、CG 只需对称正定——**少一个需要猜的参数**在工程上就是少一类失败模式。
**失败判据**：① `eigsh` 的残差 $\lVert A\hat y-\hat\lambda\hat y\rVert$ 不随迭代下降 → 先核对目标语义（`which='LM'` 不等于「按模最大」的直觉，必要时用 `sigma` 做位移）；② 稀疏矩阵却调了稠密 `np.linalg.eig` → 内存爆（对比 $n=10^6$ 的存储需求）；③ SOR 的 $\omega$ 扫描在目标矩阵上找不到明显极小 → 该矩阵不适合 SOR，换 Krylov + 预条件；④ 追赶法的 $O(n)$ 只在**结构保持**时成立——一旦为选主元换行破坏了带宽，填充立刻出现，$O(n)$ 失效。
**验证计划**：同一稀疏对称正定算例上比较自写幂法与 `eigsh` 的迭代数、残差、耗时（双对数图）；用**已知谱的小矩阵**核对正确性（例如 B4 的 $A$，谱为 $\frac{7\pm\sqrt5}{2}$）；把「三种目标（模最大 / 模最小 / 最接近 $p$）」与库参数的对照表写下来（本 8 讲的「一个算法解决三个问题」在库里对应不同参数，这张表就是迁移的桥）。
**评分要点**：替代品具体到库与函数（1 分）；理由指到收敛率 / 存储 / 参数敏感性（0.5 分）；失败判据可测量（0.5 分）；验证计划含已知谱核对（1 分）。
:::

| 3 | 规模大且稀疏吗？ | 大 → 迭代法：有行对角占优或对称正定才敢用 Jacobi / GS / SOR（[第 5 讲 §四](lec05.md#四gaussjacobi-迭代板书-60097934)、[第 6 讲 §八](lec06.md#八对称正定情形ostrowski-定理1303913217)）；否则上 Krylov（GMRES/CG，[第 4 讲 §五](lec04.md#五迭代法引论)） |
| 4 | 病态吗？ | $\mathrm{cond}$ 大 → 按 D1 处置（换提法/换基、加精度），别指望算法改良 |
三个问题的落点：(a) $n=100$ 稠密 → LU（多右端复用时）或列主元消去，重点查 $\mathrm{cond}$；(b) 三对角 → 追赶法，约 $3n$ 次运算；(c) 大而稀疏 → 迭代法 / Krylov + 预条件。
**理由**：复杂度与稳定性是两条独立的轴。三对角 $O(n)$（约 $3n$）对比朴素消去 $O(n^3)$：$n=10^6$ 时前者 $3\times10^6$ 次、后者约 $\frac23\times10^{18}$ 次（[第 3 讲 §四](lec03.md#四高斯消去法-gaussian-elimination)的 $10^{18}$ 量级），差十几个数量级。稳定性一侧：行对角占优给的是**充分**条件（好算），$\rho(G)\lt1$ 是**充要**但算不出（[第 5 讲 §二·§三](lec05.md#二收敛的充要条件ρg1rhoglt1ρg1板书-13592119)），SOR 的 $\omega$ 还额外依赖矩阵类型。
**失败判据**：① 用 $\lVert G\rVert_\infty\lt1$ 停机，却忽略「$\lVert G\rVert$ 接近 1 时相邻差小**不能**断定接近真解」的警告（[第 5 讲 §三](lec05.md#三范数充分条件与两个误差估计板书-29295709)）→ 停机判据失效；② 对 $n=10^6$ 稀疏矩阵用稠密 LU → 填充 + 内存爆；③ 对非对角占优的三对角矩阵直接追赶（不选主元）→ 主元可能为零，重演 B3 的卡壳——这时要么先做选主元的带状消去（可能破坏带宽），要么换迭代法；④ 病态问题用迭代法「磨」到收敛 → 得到的仍是病态问题的近似解。
**验证计划**：① 已知解算例：造 $x_{\text{true}}$、算 $b=Ax_{\text{true}}$，比较解相对误差与**归一化**残差 $\dfrac{\lVert b-A\hat x\rVert_\infty}{\lVert A\rVert_\infty\lVert\hat x\rVert_\infty}$；② 结构测试：断言追赶法在 $n=1000$ 时 $L$、$U$ 的非零元数为 $2n-1$；③ 规模测试：$n$ 从 $10^2$ 扫到 $10^4$，双对数图上斜率应为 $1$（三对角）与 $3$（稠密）；④ 病态测试：把 B2 的 $A$ 扩成 $n\times n$ 的「相邻行近似成比例」版本，观察 $\mathrm{cond}$ 增长与解质量退化。
**评分要点**：流程表四问清晰（1 分）；理由含复杂度与稳定性两条轴（0.5 分）；失败判据可测量（0.5 分）；验证计划含斜率与残差归一化（1 分）。

::: note 关键数值的复核方式
本页所有可复算的数值——B2 的条件数与扰动实验、B3 的消元与 LU、B4 / B5 的谱半径与 SOR 扫描、B6 的幂法 / 反幂法序列、B7 的四种迭代步数与实测阶、B8 的插值误差界、C5 的范德蒙德条件数——均已用 NumPy（v2.4.6，float64）复核，脚本片段如下（与本文数值一一对应）：

```python
import numpy as np
A = np.array([[1.,1],[1,1.001]]); print(np.linalg.cond(A, np.inf))    # 4004.001 —— B2
Ab = np.array([[3.,-1],[-1,4]])                                       # B4：ρ(G_J)=1/(2√3)
GJ = -np.linalg.solve(np.diag(np.diag(Ab)), np.tril(Ab,-1)+np.triu(Ab,1))
print(np.linalg.eigvals(GJ), np.linalg.norm(GJ, np.inf))              # ±0.2887, 0.3333

def G_sor(A, w):                                                      # B5：ω=2 的谱
    D = np.diag(np.diag(A)); L = np.tril(A,-1); U = np.triu(A,1)
    return np.linalg.solve(L + D/w, (1/w - 1)*D - U)
print(np.linalg.eigvals(G_sor(Ab, 2.0)))                              # (-5±i√11)/6，|λ|=1

f = lambda x: x**3 - x - 1; s = 1.3247179572447460                    # B7：实测阶
e = [abs(1.5 - s)]; x = 1.5
for _ in range(4): x = x - f(x)/(3*x**2 - 1); e.append(abs(x - s))
print([np.log(e[k+1]/e[k]) / np.log(e[k]/e[k-1]) for k in (2, 3)])    # [1.9922, 2.0000]
```

复核记录：$\mathrm{cond}_\infty=4004.001$；$\rho(G_J)=0.2886751$、$\lVert G_J\rVert_\infty=0.3333333$；$\omega=2$ 时特征值 $\frac{-5\pm\mathrm i\sqrt{11}}{6}$、$|\lambda|=1$；幂法第 4 步 $R_4=47/13=3.615385$；步数（阈值 $10^{-12}$）牛顿 4 / 割线 8 / 单点割线 31 / 二分 40；范德蒙德（节点 $0,\dots,1$，$n=12$）$\mathrm{cond}_2=6.8\times10^9$。
凡标「**需核实**」的结论——$\log_{10}\mathrm{cond}$ 与有效数字损失的对应、Rayleigh 商的「平方加速」、SOR 最优 $\omega$ 的显式公式、$\rho(G_{GS})=\rho(G_J)^2$ 的「平方关系」——**都不是**这 8 讲的课堂结论，属补充篇 / 原书或需另行推导的延伸；答题时若要引用，请按需核实处理。
