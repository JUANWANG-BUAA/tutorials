**一句话**：牛顿法**快**（二阶）但只保证**局部**，四条条件（异号 + 两个导不变号 + $f(x_0)f''(x_0)\gt0$）能把它升级为**全局收敛**；导数不好算就用**差商代替**，得到**割线法**（需两初值，收敛阶 $\approx1.618$）与**单点割线法**（一阶）；下半场转入**插值**——用多项式穿 $n+1$ 个点，直接解**范德蒙德**系数病态，**换成拉格朗日基**后系数就是函数值本身。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **三定理复盘** | ① 存在（自映射 + 压缩）② 收敛（同上）③ 收敛阶：$\varphi'(s)=\varphi''(s)=\cdots=\varphi^{(m-1)}(s)=0,\ \varphi^{(m)}(s)\neq0\Rightarrow m$ 阶 |
| **收敛阶定理** | $\lim\limits_{k\to\infty}\dfrac{x_{k+1}-s}{(x_k-s)^m}=\dfrac{\varphi^{(m)}(s)}{m!}$；牛顿法 $\varphi'(s)=0$ 故**至少二阶** |
| **牛顿法** | $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$（切线法）；一般只保证**局部**收敛，初值须靠近根 |
| **全局收敛定理** | (1) $f(a)f(b)\lt0$；(2) $f'(x)$ 在 $[a,b]$ **不变号**；(3) $f''(x)$ 在 $[a,b]$ **不变号**；(4) $f(x_0)f''(x_0)\gt0$；则牛顿迭代收敛到 $[a,b]$ 上**唯一**根 |
| **条件含义** | (1) 有根；(2) 单调；(3) 凸性不变；(4) 初值取在「$f$ 与 $f''$ 同号」的一侧 |
| **证明骨架** | 以上凸单增为例：$x_0\lt x_1\lt s$（$f(x_0)\lt0$，Taylor 展开 + $f'$ 单调降）；$x_k$ 单调有界 $\Rightarrow$ 有极限；代入迭代式得 $f(s')=0\Rightarrow s'=s$ |
| **割线法** | $f'(x_k)\approx\dfrac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}$，$x_{k+1}=x_k-\dfrac{f(x_k)(x_k-x_{k-1})}{f(x_k)-f(x_{k-1})}$；**需两个初值** |
| **割线几何** | 过 $(x_{k-1},f_{k-1})$ 与 $(x_k,f_k)$ 的**割线**与 $x$ 轴的交点即 $x_{k+1}$ |
| **割线收敛阶** | **超线性**，$r=\dfrac{1+\sqrt5}{2}\approx1.618$，是 $r^2-r-1=0$ 的根——介于线性与二阶之间 |
| **单点割线法** | $x_{k+1}=x_k-\dfrac{f(x_k)(x_k-x_0)}{f(x_k)-f(x_0)}$（$x_0$ 钉住）；**一阶**收敛 |
| **Steffensen** | 课上只说「大家自己看一看」，留作自阅 |
| **插值问题** | 已知 $n+1$ 个点 $(x_i,f(x_i))$，求一个多项式 $P_n$ 穿过它们 |
| **范德蒙德** | 系数矩阵 $A_{ij}=x_i^{\,j}$，$\det A=\prod_{i\lt j}(x_j-x_i)\neq0$（点互异）$\Rightarrow$ 存在唯一；但**病态**，直接解系数不可行 |
| **拉格朗日** | $l_i(x)=\prod_{j\neq i}\dfrac{x-x_j}{x_i-x_j}$，$l_i(x_i)=1,\ l_i(x_j)=0$；$L_n(x)=\sum_{i=0}^n f(x_i)\,l_i(x)$，**系数就是 $f(x_i)$** |

## 一、开场复盘：不动点迭代的三条定理（01:30–05:30）

本讲从**回顾上节课（周一）**的三个结论开始。求 $f(x)=0$ 的根，先把方程改写成等价的不动点
形式 $x=\varphi(x)$，再迭代 $x_{k+1}=\varphi(x_k)$（[第 7 讲](lec07.md)已引入）。围绕它有三条
层层递进的定理：

1. **不动点存在（唯一）定理**：$\varphi$ 在 $[a,b]$ 上连续，且把区间映到自身
   $\varphi([a,b])\subseteq[a,b]$，再加压缩条件 $|\varphi'(x)|\le L\lt1\ (x\in[a,b])$，
   则 $[a,b]$ 内存在**唯一**不动点 $s$；
2. **收敛定理**：在上述两条条件下，任取初值 $x_0\in[a,b]$，迭代 $x_{k+1}=\varphi(x_k)$
   **收敛**到 $s$（[第 7 讲](lec07.md)已证存在性，收敛/唯一由本周一补齐）；
3. **收敛阶定理**：迭代收敛得有多快，取决于 $\varphi$ 在 $s$ 处**导数消失到第几阶**。

板书左板把三条定理自上而下并排成三块（定理一、定理二、定理三），其中定理二、三的条件框
被老师**加框强调**——「这两条各管什么」是本讲反复回扣的一条线。

::: note 三条定理的「递进」
存在 $\to$ 收敛 $\to$ 收敛阶，是「**有没有** $\to$ **收不收敛** $\to$ **有多快**」的三级跳。
前两级只看 $\varphi$ 的整体性质（自映射 + 压缩），第三级才看 $s$ 局部的**高阶导**。老师
开场特意把这条链重新捋一遍，因为本讲后半的牛顿法、割线法都是「在这条链上做文章」：
牛顿法靠 $\varphi'(s)=0$ 拿到二阶，割线法用差商逼近导数，把阶数卡在 $1$ 与 $2$ 之间。
:::

## 二、收敛阶定理：导数消失阶数决定迭代阶数（05:30–11:20）

**定理（收敛阶）**：设 $s=\varphi(s)$ 是不动点，$\varphi$ 在 $s$ 附近有 $m$ 阶连续导数，且

$$\varphi'(s)=\varphi''(s)=\cdots=\varphi^{(m-1)}(s)=0,\qquad \varphi^{(m)}(s)\neq0,$$

则迭代 $x_{k+1}=\varphi(x_k)$ 在 $s$ 附近是 **$m$ 阶收敛**，且（板书在定理右侧写出极限式）

$$\lim_{k\to\infty}\frac{x_{k+1}-s}{(x_k-s)^m}=\frac{\varphi^{(m)}(s)}{m!}.$$

**为什么是 $m$ 阶**（把 $\varphi(x_k)$ 在 $s$ 处 Taylor 展开）：由 $x_{k+1}-s=\varphi(x_k)-\varphi(s)$，

$$\varphi(x_k)=\varphi(s)+\underbrace{\varphi'(s)(x_k-s)+\cdots+\frac{\varphi^{(m-1)}(s)}{(m-1)!}(x_k-s)^{m-1}}_{=\ 0}
+\frac{\varphi^{(m)}(\xi)}{m!}(x_k-s)^m,$$

前 $m-1$ 项因导数全为零而消失，只剩最高阶项，于是

$$x_{k+1}-s=\frac{\varphi^{(m)}(\xi)}{m!}(x_k-s)^m\ \approx\ \frac{\varphi^{(m)}(s)}{m!}(x_k-s)^m,$$

即误差按 $m$ 次方缩小——这正是「$m$ 阶收敛」的含义。板书把这一结论的右边单独写成
$\dfrac{\varphi^{(m)}(s)}{m!}$，与 $\lim$ 式并列。

**两种常见情形**（对上课板）：
- 若 $\varphi'(s)\neq0$：只有 $m=1$，**线性收敛**（误差每步乘一个常数）；
- 若 $\varphi'(s)=0,\ \varphi''(s)\neq0$：$m=2$，**二阶（平方）收敛**——每步有效数字大约翻倍。

**牛顿法为什么是二阶**：牛顿迭代 $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$ 等价于不动点迭代，其迭代函数

$$\varphi(x)=x-\frac{f(x)}{f'(x)},\qquad
\varphi'(x)=\frac{f(x)f''(x)}{[f'(x)]^2}.$$

在根 $s$ 处 $f(s)=0$、$f'(s)\neq0$，故 $\varphi'(s)=0$；而
$\varphi''(s)=\dfrac{f''(s)}{f'(s)}$ 在一般情形下 $\neq0$（若也恰好为零则阶数更高）。代入上面的
收敛阶定理，牛顿法**至少是二阶收敛**（当 $\varphi''(s)\neq0$ 时恰为二阶）——板书在这一行右侧
专门标了「(至少二阶)」，并另起一行写「且 $\varphi'(s)=0$，二阶收敛」。这正是周一讲过的
结论，本讲用它作为「收敛阶定理」的标准例子。

::: intuition 「二阶」到底快多少
一阶收敛：误差按固定比例 $\rho\lt1$ 缩小，如 $10^{-1},10^{-2},10^{-3},\dots$；
二阶收敛：误差按**平方**缩小，即有效数字**翻倍**——若某步误差是 $10^{-3}$，下一步约
$C\cdot10^{-6}$，再下一步 $C\cdot10^{-12}$。牛顿法一般 $5\!\sim\!6$ 步就打到机器精度，
割线法（阶 $1.618$）稍慢但每步更省，见第七节。
:::

## 三、牛顿法的局部性：初值必须靠近目标根（11:20–16:00）

既然牛顿法有二阶收敛这么快，为什么还要专门讨论「收敛范围」？老师画出反例图像说明：
**牛顿法的一般收敛定理只保证局部结果。**

> 「牛顿迭代的二阶收敛虽然快，但它对**初值**是有要求的——你必须选择在**目标根附近**。」

板书画出一条多峰的曲线（有多个根/极值），标出想求的目标根 $s$，再把初值 $x_0$ 取在离
$s$ **很远**的另一侧：做切线得 $x_1$，再在 $x_1$ 处做切线得 $x_2$……迭代**跑到了另一个根**
（或收敛到某个**局部极值**），而不是想要的 $s$。

$$x_0\ \text{取在远处}\ \Rightarrow\ x_1,x_2,\dots\ \text{收敛到别的根 }s'\neq s .$$

老师用优化语言解释了这层「局部 vs 全局」：目标函数的各个根就像优化问题的各个**极值点**，
有全局最优也有局部最优；初值离全局最优太远，迭代就可能落进某个局部最优。「你本来要找
最高的那座山，结果初值选在矮山上，它就爬到矮山的顶了。」

::: note 一般定理的适用条件
牛顿法的一般（局部）收敛定理是：$f$ 在根 $s$ 的某邻域内二次连续可导、$f'(s)\neq0$，
则只要 $x_0$ **充分靠近** $s$，牛顿迭代就收敛到 $s$（且二阶）。「充分靠近」是一个
**存在性**的邻域，定理并不告诉你它多大——这正是下一节要解决的：**给出一组可以用图像检验
的条件，把「充分靠近」替换成「初值取在某个明确的范围内」**。
:::

## 四、牛顿法的全局收敛定理（16:00–21:00）

**定理（全局收敛）**：设 $f$ 在 $[a,b]$ 上满足四条

$$(\mathrm i)\ \ f(a)f(b)\lt0;\qquad
(\mathrm{ii})\ \ f'(x)\ \text{在}\ [a,b]\ \text{上不变号};\qquad
(\mathrm{iii})\ \ f''(x)\ \text{在}\ [a,b]\ \text{上不变号};$$

$$(\mathrm{iv})\ \ f(x_0)\,f''(x_0)\gt0\ \ \text{（初值条件）},$$

则以 $x_0$ 为初值的牛顿迭代 $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$ 收敛到 $[a,b]$ 上的
**唯一根** $s$。

板书把定理写成「定理」二字起头、四条并列，再画一个大括号接迭代格式，右边写收敛结论
$x_k\xrightarrow[k\to\infty]{}s$。四条条件逐条翻译：

| 条件 | 数学含义 | 作用 |
|:--|:--|:--|
| (i) $f(a)f(b)\lt0$ | 端点异号 | 保证 $[a,b]$ 内**至少一个**根（介值定理） |
| (ii) $f'$ 不变号 | 函数在 $[a,b]$ 上**单调** | 保证**至多一个**根（单调函数最多穿零一次） |
| (iii) $f''$ 不变号 | 函数的**凸性**不变（一直上凸或一直下凸） | 保证迭代序列**不越界**、单调趋向 $s$ |
| (iv) $f(x_0)f''(x_0)\gt0$ | 初值取在「$f$ 与 $f''$ 同号」的一侧 | 把初值钉在曲线的「外侧」，切线步长方向正确 |

::: intuition 四条条件合起来说了什么
(i)+(ii) 已经把根夹在 $[a,b]$ 里且**唯一**；真正的关键是 (iii)：**凸性与单调性都不变**，
意味着曲线在整个区间上是「一段光滑的弧」，没有拐点、没有极值转折——于是从 (**iv**) 指定的
那一侧出发，切线永远「踩着」曲线单调地逼近根，既不会冲过头也不会来回震荡。老师把这层
意思概括为一句：「它的凸性和单调性都不变，那么你的初值就**不必**取在根附近，可以离得
很远。」这就是全局版比局部版强的地方。
:::

## 五、四种函数图像与初值取值范围（19:00–21:30）

「凸性不变」有两种（上凸、下凸），「单调性不变」有两种（单增、单减），组合起来正好
**四种图像**，板书分四格画出，并标出条件 (iv) 允许的初值区间（打阴影）：

| 情形 | $f'$ | $f''$ | (iv) 要求 | 初值 $x_0$ 的取值范围 |
|:--|:--|:--|:--|:--|
| (1) 上凸 + 单增 | $\gt0$ | $\lt0$ | $f(x_0)\lt0$ | 取在**根左侧**（$f\lt0$ 一侧） |
| (2) 上凸 + 单减 | $\lt0$ | $\lt0$ | $f(x_0)\lt0$ | 取在**根右侧**（$f\lt0$ 一侧） |
| (3) 下凸 + 单增 | $\gt0$ | $\gt0$ | $f(x_0)\gt0$ | 取在**根右侧**（$f\gt0$ 一侧） |
| (4) 下凸 + 单减 | $\lt0$ | $\gt0$ | $f(x_0)\gt0$ | 取在**根左侧**（$f\gt0$ 一侧） |

规律是**统一的**：把初值取在「曲线与它自己切线相切后、切线落在 $x$ 轴外侧」的那一端——
也就是 $f(x_0)$ 与 $f''(x_0)$ **同号**的一端。

::: note 「上凸 / 下凸」的术语
本讲沿用课堂说法：**上凸**指曲线「拱起来」（$f''\lt0$，英文 concave down），**下凸**指曲线
「凹下去」（$f''\gt0$，英文 convex）。这与中国工科教材常把 $f''\gt0$ 叫「凹」（或「下凸」）、
$f''\lt0$ 叫「凸」的习惯一致；与西方教材的 convex/concave 恰好是反的（convex $\leftrightarrow$
$f''\gt0\leftrightarrow$ 本讲的「下凸」）。读英文资料时以 $f''$ 的符号为准，别被词面骗。
:::

## 六、全局收敛定理的证明（21:30–34:20）

以**第一种情形**（(1) 上凸 + 单增：$f'\gt0,\ f''\lt0$）为例，证明牛顿序列收敛到根 $s$。
此时 $f$ 在 $[a,b]$ 上严格单增，由 (i) 知 $s$ 唯一，且条件 (iv) 给出 $f(x_0)\lt0$（因
$f''\lt0$ 要求 $f(x_0)$ 与之同号），即 $x_0$ 在 $s$ 的**左侧**：$x_0\lt s$。

**第一步：$x_1\gt x_0$。** 由 $f(x_0)\lt0,\ f'(x_0)\gt0$，

$$x_1=x_0-\frac{f(x_0)}{f'(x_0)}=x_0+\frac{|f(x_0)|}{f'(x_0)}\ \gt\ x_0 .$$

**第二步：$x_1\lt s$。** 在 $x_0$ 处把 $f$ 关于 $s$ 作 Taylor 展开（用 $f(s)=0$），
存在 $\xi\in(x_0,s)$ 使

$$f(x_0)=f(s)+f'(\xi)(x_0-s)=f'(\xi)(x_0-s).$$

代入 $x_1$ 的表达式：

$$x_1=x_0-\frac{f'(\xi)(x_0-s)}{f'(x_0)}
=x_0+(s-x_0)\cdot\frac{f'(\xi)}{f'(x_0)}.$$

因为 $f''\lt0$，$f'$ 在 $[a,b]$ 上**单调下降**；$\xi\in(x_0,s)$ 故 $\xi\gt x_0$，于是

$$0\ \lt\ \frac{f'(\xi)}{f'(x_0)}\ \lt\ 1
\qquad\Longrightarrow\qquad
x_0\ \lt\ x_1=x_0+(s-x_0)\cdot\frac{f'(\xi)}{f'(x_0)}\ \lt\ s .$$

**第三步：归纳与收敛。** 对 $x_1$ 重复同样的论证（$x_1$ 仍满足 $f(x_1)\lt0$、$x_1\lt s$），得
$x_1\lt x_2\lt s$，依此类推：

$$x_0\lt x_1\lt x_2\lt\cdots\lt x_k\lt\cdots\lt s .$$

这是**单调递增且有上界**（上界 $s$）的数列，故有极限，记为 $s'$：

$$\lim_{k\to\infty}x_k=s' .$$

**第四步：极限就是根。** 在迭代式 $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$ 两边令 $k\to\infty$，
由 $f,f'$ 连续、$f'(s')\neq0$：

$$s'=s'-\frac{f(s')}{f'(s')}\qquad\Longrightarrow\qquad f(s')=0 .$$

故 $s'$ 是 $[a,b]$ 上的一个根；由 (ii) 保证**唯一**，得 $s'=s$。$\blacksquare$

::: note 另外三种情形
(2)(3)(4) 的证明完全同构，只是单调递/递减方向与 Taylor 展开的符号不同，结论都是
「初值落在 (iv) 指定的阴影区 $\Rightarrow$ 序列单调趋近 $s$」。老师板书上把 (1) 的完整推理
一步步写出来（含 $\xi\in(x_0,s)$ 的取点、$f'$ 单调降的比较），其余三种留给同学仿照验证。
:::

## 七、割线法：用差商代替导数（34:20–46:40）

牛顿法的**软肋**是每步要算 $f'(x_k)$。老师点出动机：

> 「很多时候 $f$ 特别复杂，对它求导很费劲——**尤其是当 $f$ 已经变成函数向量**（方程组）的时候，
> 求导数就变成求**矩阵**了，更贵。那我用**差商**来替代它。」

**做法**：把牛顿法里的 $f'(x_k)$ 用**差商**近似代替：

$$f'(x_k)\ \approx\ \frac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}},$$

代回牛顿格式，得到**割线法**（也称弦截法，板书把差商框出）：

$$\boxed{\ x_{k+1}=x_k-\frac{f(x_k)}{\dfrac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}}
=x_k-\frac{f(x_k)\,(x_k-x_{k-1})}{f(x_k)-f(x_{k-1})}\ }$$

上式两种写法是同一个式子（把分母的差商「翻」上去）。**注意：割线法需要两个初值**
$x_0,x_1$（因为它用到前两步 $x_k,x_{k-1}$），比牛顿法多给一个起点。

**几何意义**：$x_{k+1}$ 是**过两点 $(x_{k-1},f(x_{k-1}))$ 与 $(x_k,f(x_k))$ 的割线**与 $x$ 轴
的交点。板书把它写成直线方程来点明：

$$y-f(x_k)=\underbrace{\frac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}}_{\text{斜率}}\ (x-x_k),$$

令 $y=0$ 解得的 $x$ 即为 $x_{k+1}$——**牛顿法用切线（一点 + 导数），割线法用割线（两点 + 差商）**。

**收敛阶**：割线法仍是超线性收敛，但阶数**不是整数**。由

$$r^2-r-1=0\qquad\Longrightarrow\qquad r=\frac{1+\sqrt5}{2}\approx1.618\quad(\text{黄金比}),$$

即每步误差按 $e_{k+1}\sim C\,e_k^{\,1.618}$ 缩小。板书末行专门写出 $r^2-r-1=0$ 并标
$r=1.618$。

::: intuition 为什么割线法的阶是黄金比
牛顿法用切线，误差传播是「平方」；割线法用两点连线，本质上用了**两个**带误差的量，误差
耦合后递推关系变成 $r^2=r+1$——恰是斐波那契数列的增长率方程。所以阶数是一个无理数
$1.618$，介于线性（$1$）与二阶（$2$）之间：**比牛顿慢一点，但每步省一次求导**，在导数
昂贵时反而更快。
:::

## 八、割线法的全局收敛与单点割线法（51:27–64:00）

**割线法的全局收敛**：与牛顿法**同一套四条条件** (i)–(iv) 下（两个初值 $x_0,x_1$ 都取在
合适的阴影区内），割线迭代同样收敛到 $[a,b]$ 上的唯一根 $s$——「还是和刚刚那四条一模一样」。

**单点割线法**：割线法的麻烦是「要记住前两个值」。把 $x_{k-1}$ **钉死为固定的 $x_0$**，就得到
**单点割线法**（板书框出）：

$$\boxed{\ x_{k+1}=x_k-\frac{f(x_k)\,(x_k-x_0)}{f(x_k)-f(x_0)}\ }$$

**几何意义**：每次都用**同一个固定点 $(x_0,f(x_0))$** 与当前点 $(x_k,f(x_k))$ 连线，取割线
与 $x$ 轴交点。老师一边画一边说：「原来连的是 $x_{k-1}$ 和 $x_k$，现在我把 $x_{k-1}$ 换成
$x_0$——就是把 $x_0$ 的图像和 $x_k$ 的图像连一下。」

**代价：收敛阶降为一阶。** 单点割线法**只线性收敛**（不再是割线法的 $1.618$）：

$$|x_{k+1}-s|\le\rho\,|x_k-s|,\qquad 0\lt\rho\lt1 .$$

板书用一版的图像（凸性与单调性都不变）说明：当 $x_0$ 选在合适的一侧、$x_k$ 从另一侧逼近时，
每条割线都「朝着根」去，序列单调收敛——这四种情形与第六节的证明同构，老师讲「就不必再证了」。

::: note 割线法族的谱系
老师把这一族归纳成一句话：**「牛顿法是原型，割线法是牛顿法的修正，单点割线法又是割线法的
修正」**——三层「修正」对应三次「松弛」：先去掉导数（换成差商），再去掉「记住前两点」
（换成固定 $x_0$），每松一步，收敛阶就掉一档。收敛阶一览：

| 方法 | 每步信息 | 收敛阶 |
|:--|:--|:--|
| 牛顿法 | $f(x_k),f'(x_k)$ | $2$ |
| 割线法 | $f(x_k),f(x_{k-1})$ | $1.618$ |
| 单点割线法 | $f(x_k),f(x_0)$ | $1$ |
:::

## 十、插值法引论：从散点到曲线（65:00–80:00）

非线性方程到此收束，下半场转入**插值/逼近**。老师用一个工程场景开场：

> 潜水器测海底温度随**深度**的变化曲线。真实曲线是连续的一条，但**采样只能取有限个点**
> ——「你不可能把随深度变化的所有数据都采完，只能在这儿采一个、那儿采一个……」

于是问题变成：**已知有限个采样点，如何恢复（近似）整条曲线？** 形式上：

**插值问题**：已知 $n+1$ 个互异的采样点 $(x_0,f(x_0)),(x_1,f(x_1)),\dots,(x_n,f(x_n))$，
求一个函数 $P$，使它在每个采样点处与被逼近函数取**相同值**：

$$P(x_i)=f(x_i),\qquad i=0,1,\dots,n .$$

**用什么函数来逼近？** 老师的回答体现了数学建模的取舍：「**尽量找最简单的函数**。」
并给出一层更深的直觉——自然界的东西往往可以被简单函数逼近（「世界的本质就是压缩：信息看着
很多，真正有效的信息并不多」）。而**最简单**的函数族，就是**多项式**：

$$P(x)=a_0+a_1x+a_2x^2+\cdots+a_nx^n .$$

**未知量个数与方程个数的匹配**：$n+1$ 个插值条件 $\Rightarrow$ $n+1$ 个方程；而 $n$ 次多项式
恰有 $n+1$ 个待定系数 $a_0,a_1,\dots,a_n$——「**正好**」。板书把方程组逐行写出：

$$\begin{cases}
a_0+a_1x_0+a_2x_0^2+\cdots+a_nx_0^n=f(x_0)\\[2pt]
a_0+a_1x_1+a_2x_1^2+\cdots+a_nx_1^n=f(x_1)\\[2pt]
\qquad\vdots\\[2pt]
a_0+a_1x_n+a_2x_n^2+\cdots+a_nx_n^n=f(x_n)
\end{cases}$$

## 十一、范德蒙德矩阵：存在唯一，但病态（80:00–85:00） {#sec-lec09-11}

上一节的方程组写成矩阵形式 $A\boldsymbol a=\boldsymbol f$，其中

$$A=\begin{pmatrix}
1&x_0&x_0^2&\cdots&x_0^n\\
1&x_1&x_1^2&\cdots&x_1^n\\
\vdots&\vdots&\vdots&&\vdots\\
1&x_n&x_n^2&\cdots&x_n^n
\end{pmatrix},\qquad A_{ij}=x_i^{\,j}.$$

这就是**范德蒙德（Vandermonde）矩阵**，其行列式有闭式：

$$\det A=\prod_{0\le i\lt j\le n}(x_j-x_i).$$

**只要采样点互不相同**，每对 $(x_j-x_i)\neq0$，故 $\det A\neq0$，方程组有**唯一解**：

$$\text{互异节点}\ \Longrightarrow\ \text{存在唯一的}\ n\ \text{次插值多项式}\ P_n .$$

::: note 存在唯一 ≠ 能算出来
老师说得很明确：这**理论上**告诉你插值多项式一定存在、唯一，「但你要是**真去解**这个系数
方程，那可不好办」——范德蒙德矩阵是出了名的**病态**：节点稍多、稍靠近，条件数就指数级恶化，
用消去法解出 $a_i$ 会丢掉大量有效数字。**「存在唯一」是一个存在性结论，不是一条数值可用的
算法。** 出路见下一节。这正是全书反复强调的红线：**conditioning ≠ 能不能算**。
:::

## 十二、拉格朗日插值：换基避病态（85:00–99:03）

既然「在这组基 $\{1,x,x^2,\dots,x^n\}$ 下系数不好求」，就**换一组基**。老师提出构造
（板书框出）：

$$l_i(x)=\prod_{j=0,\,j\neq i}^{n}\frac{x-x_j}{x_i-x_j}
\qquad(i=0,1,\dots,n),$$

即「分子用 $x$ 去减除 $x_i$ 以外所有节点、分母把 $x$ 换成 $x_i$」。这些 $l_i$ 称为
**拉格朗日基函数**，它们有极好的**筛选性质**（板书逐点代入验证）：

$$l_i(x_i)=1,\qquad l_i(x_j)=0\quad(j\neq i).$$

**性质的意义**：$l_i$ 在「自己那个节点」取 $1$、在**其他所有节点**取 $0$——是一个只在 $x_i$
处「点亮」的开关。于是若把插值多项式写成这组基的线性组合

$$L_n(x)=b_0l_0(x)+b_1l_1(x)+\cdots+b_nl_n(x),$$

代入节点 $x_i$：因为除 $l_i$ 外其余基函数在该点全为 $0$，方程立刻退化为

$$L_n(x_i)=b_i\cdot1=b_i\ \overset{!}{=}\ f(x_i)\qquad\Longrightarrow\qquad b_i=f(x_i).$$

**系数直接就是函数值**，一步不用解方程！于是

$$\boxed{\ L_n(x)=\sum_{i=0}^{n}f(x_i)\,l_i(x)\ }$$

这就是**拉格朗日插值公式**。它把「解 $n+1$ 元病态方程组」换成了「按点加权求和」——**换基
绕开了范德蒙德矩阵的病态**。

::: intuition 为什么换基就灵了
插值多项式的**存在唯一性**与**基的选择无关**（同一空间的不同基）；病态的是「$1,x,x^2,\dots$
这组基在节点上张成的系数矩阵」。拉格朗日基是**为该组节点量身定做**的基：它在节点上的取值
矩阵恰是**单位矩阵**，所以系数一读即得。这是数值代数里「**选对基**」的经典范例——同一个
问题，换一组基就从「病态」变成「显然」。
:::

::: preview 下一讲起点
老师把插值式写完后指出还差一环：插值多项式在**采样点**上当然等于函数值，但「**在别的地方**
（非采样点）它和原函数差多少？逼近效果怎么样？我们下节课再说。」——即插值**误差/余项**
$R_n(x)=f(x)-L_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\displaystyle\prod_{i=0}^{n}(x-x_i)$
与收敛性（Runge 现象等），留给下一讲。
:::

## 十四、老师强调

- **局部 vs 全局**：牛顿法的一般定理只给「初值靠近根」的局部保证；**全局**版本靠四条条件，
  核心是**凸性与单调性都不变**。
- **四条条件各有其职**：(i)+(ii) 夹住并唯一化根；(iii) 保证序列不越界、单调趋近；(iv) 指
  定初值落在曲线的哪一侧——「$f(x_0)$ 与 $f''(x_0)$ 同号」。
- **割线法一族**：**牛顿法（二阶）$\to$ 割线法（差商代导，阶 $1.618$）$\to$ 单点割线法
  （钉住 $x_0$，一阶）**，每松一步掉一档阶；越松越省，也越慢。
- **割线法要两个初值**，单点割线法只要一个（外加固定点 $x_0$）。
- **插值的坑**：范德蒙德矩阵「存在唯一但病态」——**存在性结论不等于可用算法**；
  **换基**（拉格朗日）让系数直接读出。
- **建模的直觉**：自然界的东西「有效信息不多」，可用**简单函数**（多项式）逼近——这是
  整章插值/逼近的出发点。
- 方法论（承[第 7 讲](lec07.md)）：证明的过程不必人人掌握，「但结论和公式必须记得住、
  能自己推」。
