# 第二章 · 数值线性代数基础

第一章把「用计算机算数」的两个基本问题立了起来：误差怎么度量、怎么控制（1.2），以及度量「大小」的尺子怎么造（1.3）。但第一章的范数只回答「多大」——它答不出「哪个方向」「有多敏感」「有多低维」。**第二章正是从这里出发，把范数升级为几何**：引入内积（2.1），由内积定义正交；正交给出投影（2.2）；投影导出最小二乘与 QR 分解（2.3）；条件数把「敏感」量化为一个数（2.4）；谱把「矩阵的本质行为」压缩成特征值与奇异值（2.5、2.6）。一句话，第一章教你把「大小」量准，第二章教你看清「结构」。

本章对标原书 1.3 节并**大幅扩充**：原书只讲了向量范数与矩阵范数的公理与公式，本章补上的是后面每一章都要反复动用的正交 / 投影 / 分解 / 谱工具箱，四者合起来构成了「现代数值线性代数的最小完备集合」。学完本章，你才具备读懂[第三至第六章](../ch01/sec11.md#roadmap)的全部语言。

## 八节一览

这一张表是本章唯一的「逐节总览」：预习时先看「核心问题」列，弄清每节要解决什么；复习时看「关键结论」与「典型陷阱」两列，直接对答案、避坑。

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[2.1 内积与正交](sec21.md)** | 「垂直」怎么公理化，才能用到任意维空间？ | 内积的四条公理（[@def-2.1.1]）；**只有 2-范数来自内积**（判据是平行四边形恒等式 [@thm-2.1.2]）；正交组必线性无关（[@thm-2.1.3]）；勾股定理与标准正交基下的坐标、Parseval（[@thm-2.1.4]）；正交矩阵的等价刻画（[@thm-2.1.5]）；正交变换保持 2-范数与 Frobenius 范数（[@thm-2.1.6]） | 向量长度为 1 就当成标准正交（忘了查两两内积为零）；把 1-范数 / ∞-范数当成内积范数 |
| **[2.2 子空间与投影](sec22.md)** | 一个矩阵把空间分成哪几块？ | 四个基本子空间与两对正交补（[@thm-2.2.1]、[@thm-2.2.2]）；正交分解与最近点（[@thm-2.2.3]、[@thm-2.2.4]）；投影矩阵 $P=A(A^{\mathrm T}A)^{-1}A^{\mathrm T}$（[@thm-2.2.5]）；正态方程给出的最小二乘刻画（[@thm-2.2.6]）；加权最小二乘（[@thm-2.2.7]） | 用行变换后得到的列去当列空间的基；解完不回代检查 $A^{\mathrm T}\boldsymbol{r}=\boldsymbol{0}$ |
| **[2.3 正交化与 QR](sec23.md)** | 怎么造出一组标准正交基？ | CGS 与 MGS 的代码只差一行，稳定性却相差一个 $\mathrm{cond}$；Householder（选符号防相消）；Givens（适合稀疏）；QR 唯一性（[@thm-2.3.2]）；**QR 解最小二乘 $\mathrm{cond}\,u$ vs 正态方程 $\mathrm{cond}^2u$**（[@thm-2.3.5]） | 手写 CGS；把 MGS 写成 CGS；Householder 符号取错 |
| **[2.4 条件数与扰动](sec24.md)** | 算出来的解能信几位？ | 条件数的定义 $\mathrm{cond}=\lVert A\rVert\lVert A^{-1}\rVert$、$\mathrm{cond}_2=\sigma_1/\sigma_r$；右端扰动界（[@thm-2.4.2]）；系数扰动界（[@thm-2.4.3]）；有效数字估计 $k\approx\log_{10}\mathrm{cond}$；**$\boldsymbol{e}=A^{-1}\boldsymbol{r}$，残差 ≠ 误差**（[@thm-2.4.4]） | 拿残差当误差；忘了行均衡化；写 $\mathrm{cond}$ 时不注明是哪个范数 |
| **[2.5 谱与对称谱](sec25.md)** | 矩阵的本质行为由什么刻画？ | $\rho\le\lVert A\rVert$；Gerschgorin 圆盘圈住全部特征值（[@thm-2.5.2]）；Rayleigh 商与变分原理（[@thm-2.5.4]、[@thm-2.5.5]）；幂法的收敛速度（[@thm-2.5.3]）；Weyl 与 Bauer–Fike 扰动界（[@thm-2.5.6]）；**重特征值开方敏感** | 把 $\rho$ 当成 $\lVert A\rVert$；以为重特征值也能算准；忘记 Gerschgorin 还有列版本 |
| **[2.6 SVD 与低秩](sec26.md)** | 长方形矩阵也有谱吗？ | $A=U\Sigma V^{\mathrm T}$ 的两种读法；四个子空间的标准正交基（[@thm-2.6.2]）；伪逆与秩亏最小二乘（[@thm-2.6.3]）；**Eckart–Young 的最优低秩逼近**（[@thm-2.6.4]）；数值秩与截断 | 拿 $A^{\mathrm T}A$ 的特征值去算 SVD；伪逆不截断；PCA 忘了中心化 |
| **[2.7 数值实验](sec27.md)** | 理论在浮点下还成立吗？ | 四组实验：$\mathrm{cond}^2u/\mathrm{cond}\,u/u$ 实测、$k\approx\log_{10}\mathrm{cond}$、Eckart–Young 与压缩曲线、幂法速度与开方敏感 | 只贴代码，拿不出与理论量级的逐项对照 |
| **[2.8 小结与陷阱](sec28.md)** | 全章怎么用、哪些坑别踩？ | 八工具选型表；八个陷阱（全部有实测证据）；与前后章的连接 | — |

**一条红线贯穿**：第一章的「误差 → 条件数 → 稳定性」，在第二章找到了三个矩阵版的落点——

$$A^{\mathrm T}A\ \text{把}\ \mathrm{cond}\ \text{平方}\ (\text{正态方程}) \;\longrightarrow\; A\boldsymbol{x}=\boldsymbol{b}\ \text{的}\ \mathrm{cond}\cdot u \;\longrightarrow\; \sigma_1/\sigma_r\ (\text{条件数的谱表达}).$$

## 学习路径建议

- **只想先会解最小二乘**：读 [2.2](sec22.md)（投影与正态方程）和 [2.3.6](sec23.md#sec-2.3.6)（为什么改用 QR），[2.5](sec25.md)、[2.6](sec26.md) 可以先跳过。
- **要做数据分析 / 机器学习**：主线是 [2.1](sec21.md)→[2.2](sec22.md)→[2.6](sec26.md)；上 SVD 之前，先补 [2.5.4](sec25.md#sec-2.5.4)（Rayleigh 商与变分）。
- **要读懂后续章节的全部算法**：本章逐节通读，尤其别跳过 [2.3](sec23.md)（正交化）与 [2.6](sec26.md)（SVD）——这两节是[第三至第六章](../ch01/sec11.md#roadmap)的共同基础。
- **只想应付考试 / 快速复习**：[2.1.4](sec21.md#sec-2.1.4)、[2.2.6](sec22.md#sec-2.2.6)、[2.3.7](sec23.md#sec-2.3.7)、[2.4.6](sec24.md#sec-2.4.6)、[2.5.6](sec25.md#sec-2.5.6)、[2.6.7](sec26.md#sec-2.6.7) 六张「公式速查 + 常见错误」合起来就是全章精华；跨章的复习路线见[最小必读路径](../review/study-paths.md)。
