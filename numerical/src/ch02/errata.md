## 二、术语与常见译误

| 术语 | 常见说法 | 建议用法 | 要点与出处 |
|:--|:--|:--|:--|
| **内积 vs 点积** | 两者互换使用 | 内积（inner product）是公理化概念；点积（dot product）专指 $\boldsymbol{x}^{\mathrm T}\boldsymbol{y}$ 这个算式 | 加权内积 $\boldsymbol{x}^{\mathrm T}D\boldsymbol{y}$ 是合法的内积，却不是点积；提「投影」时必须说明是在哪个内积下（[2.1.1](sec21.md#sec-2.1.1)、[2.2.5](sec22.md#sec-2.2.5)） |
| **正交 vs 酉** | 把复矩阵的酉性也叫「正交」 | 实矩阵说**正交**（orthogonal），复矩阵说**酉**（unitary） | 本教程只处理实矩阵（[定义 2.1.3](sec21.md#sec-2.1.3)）；复情形要把 $\lvert\det Q\rvert=1$、保范数等结论按共轭转置改写。另注意：正交阵的**复**特征值只是「模为 1」（$\mathrm e^{\pm\mathrm i\theta}$），并非 $\pm1$（[例 2.1.4](sec21.md#ex-2.1.4)） |
| **投影 vs 正交投影** | 工程语境里把「投影」默认当成正交投影 | 投影 = 幂等算子（可以斜）；正交投影 = **对称 + 幂等** | 只幂等、不对称的是**斜投影**，其余项不垂直于目标子空间（[定理 2.2.5](sec22.md#thm-2.2.5) 后的注、[习题 A2(b)](exercises.md)） |
| **特征值 vs 奇异值** | 把 $\sigma_i$ 读成「特征值」，或直接写 $\sigma_i=\lvert\lambda_i\rvert$ | 特征值只有方阵有、可负可复；奇异值总非负、共 $\min(m,n)$ 个 | $\sigma_i=\lvert\lambda_i\rvert$ 只在正规矩阵（含对称）上成立。反例：$\begin{pmatrix}0&1\\0&0\end{pmatrix}$ 的 $\lambda=0$ 而 $\sigma_1=1$（[2.6.7](sec26.md#sec-2.6.7)） |
| **条件数 vs 谱半径** | 「用条件数判断迭代收敛」 | 条件数 $\mathrm{cond}(A)=\lVert A\rVert\lVert A^{-1}\rVert$ 管**精度**；谱半径 $\rho(A)$ 管**收敛速度** | $\rho(A)\le\lVert A\rVert$ 是估计式而非等式：非正规矩阵上两者可以差几个数量级（[2.5.1](sec25.md#sec-2.5.1) 的注、[例 2.5.6](sec25.md#ex-2.5.6)） |
| **正态方程** | 以为 normal equations 与概率的「正态分布」有关 | 本教程统一译作**正态方程** | 这里的 normal 是「法向 / 垂直」的意思：$A^{\mathrm T}(A\boldsymbol{x}-\boldsymbol{b})=\boldsymbol{0}$ 正是「余项与列空间垂直」的代数写法（[定理 2.2.6](sec22.md#thm-2.2.6)）。中译另有「正规方程」「法方程」两种说法 |
| **正规矩阵 vs 正交矩阵** | 把 normal matrix 与 orthogonal matrix 混为一谈 | 正规（normal）：$A^{\mathrm T}A=AA^{\mathrm T}$；正交（orthogonal）：$Q^{\mathrm T}Q=I$ | 正交矩阵是正规矩阵的特例；「非正规矩阵」指特征向量组不正交的那些矩阵，是[重特征值开方敏感](sec25.md#sec-2.5.5)的主角 |
| **病态 vs 不稳定** | 「这个算法病态」 | 病态（ill-conditioned）属于**问题**；不稳定（unstable）属于**算法** | 同一病态矩阵换 Cholesky / QR / SVD，误差量级相同（[2.4.6](sec24.md#sec-2.4.6)、[2.8.2 陷阱 4](sec28.md#sec-2.8.2)） |
| **秩 vs 数值秩** | 用「秩」描述带噪矩阵 | 秩是精确概念；数值秩 $=\#\{i:\sigma_i\gt t\sigma_1\}$，阈值 $t$ 按噪声水平选取 | 阈值选错会让秩判定差好几倍（[2.6.4](sec26.md#sec-2.6.4) 思考、[实验三 (d)](sec27.md#sec-2.7.3)） |

::: note 本表的边界
这里只处理「叫什么、怎么用」；概念之间**成对的辨析**在[易混对照卡](../review/contrast-cards.md)，术语的中英对照与定义位置全表在[术语索引](../review/glossary.md)。
:::

## 三、时效与工具补注

原书成书于 2012 年。本章讲的线性代数结论**没有变**，变的是「怎么算」：当年需要手算或借 MATLAB 的分解，如今同一批 LAPACK 例程由 NumPy / SciPy 直接暴露。逐条对照如下。

| 教材年代的写法 | 现在的一行代码 | 补注 |
|:--|:--|:--|
| 形成 $A^{\mathrm T}A$ 再解正态方程 | `np.linalg.lstsq(A, b)` | 当年正态方程是默认做法；现在默认走 SVD / QR，条件数不再被平方（[2.3.6](sec23.md#sec-2.3.6)） |
| 手写 Gram–Schmidt 正交化 | `np.linalg.qr(A)` | 现在默认是 Householder（LAPACK `geqrf`）；经典 Gram–Schmidt 只留作教学反例（[2.3.3](sec23.md#sec-2.3.3)、[实验一](sec27.md#sec-2.7.1)） |
| 查表 / 手估条件数 | `np.linalg.cond(A, 2)` | 2-范数版走 SVD；而 `cond(A, 1)` / `cond(A, inf)` 按「范数 × 逆的范数」实现，**会显式求逆**（[2.4.5](sec24.md#sec-2.4.5)、[工具箱第四节](../toolbox.md#sec-工具箱-4)） |
| 手工消元判秩 | `np.linalg.matrix_rank(A)` | 默认阈值 $\sigma_1\max(m,n)\mathrm{eps}$ 只适合「精确矩阵、数值降秩」；带噪数据要自己给 `tol`（[2.6.7](sec26.md#sec-2.6.7)） |
| 手推幂法 / 反幂法 | `scipy.sparse.linalg.eigsh`（对称）/ `eigs`（非对称，Arnoldi） | 大规模稀疏用 Lanczos / Arnoldi；小矩阵直接 `eigh` / `eig`（[2.5.3](sec25.md#sec-2.5.3)） |
| 把求逆当通用工具 | `np.linalg.solve` | 显式求逆解方程既慢约 2.5 倍，又损精度（复算见[工具箱第五节](../toolbox.md#sec-工具箱-5)） |

::: note 两条与日期挂钩的提醒
① 库的**默认阈值**随版本变（`lstsq` / `pinv` 的 `rcond`、`matrix_rank` 的 `tol` 都在其列）；本页与[工具箱](../toolbox.md)的数值在本机 numpy 2.4.6 / scipy 1.18.0 上核对过，动手前查当前版本文档。② 本章不写「某库某版本更快」这类结论——性能随 BLAS 实现与硬件变化，需要时以本机实测为准。
:::
