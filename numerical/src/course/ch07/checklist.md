## K · 知识

| 编号 | 目标 | 自检标准 | ✓ |
|:--|:--|:--|:--|
| K7.1 | 写出局部误差与全局误差的关系 | 全局误差 $\approx\dfrac{h^p}{p!}\|y^{(p+1)}\|$ 量级（Euler $p=1$、RK4 $p=4$） | ☐ |
| K7.2 | 写出 Euler 与 RK4 公式 | $y_{n+1}=y_n+hf(t_n,y_n)$；$y_{n+1}=y_n+\dfrac h6(k_1+2k_2+2k_3+k_4)$ | ☐ |
| K7.3 | 说明相容性与收敛 | 相容（截断误差 $\to0$）+ 稳定 ⟹ 收敛 | ☐ |
| K7.4 | 写出绝对稳定条件 | 测试方程 $y'=\lambda y$、$z=h\lambda$；$|R(z)|<1$ | ☐ |
| K7.5 | 写出线性多步法的一般形式 | $\sum\alpha_jy_{n+j}=h\sum\beta_jf_{n+j}$；$\beta_k=0$ 显式 | ☐ |
| K7.6 | 写出根条件与稳定域 | $\rho(\zeta)$ 的根在单位圆内且圆上单根；稳定域由 $\rho(\zeta)-z\sigma(\zeta)=0$ 的根轨迹给出 | ☐ |
| K7.7 | 说明 A-稳定与刚性 | A-稳定 = 稳定域含整个左半平面；后退 Euler 与梯形是 A-稳定 | ☐ |
| K7.8 | 写出高阶方程化一阶系统 | $Y=(y,y',\dots,y^{(m-1)})^{\mathrm T}$，$Y'=F(t,Y)$ | ☐ |
