# 第七章练习与解答

本组练习使用几个可写出精确解的方程，分别检查一步计算、全局误差、稳定性和自适应误差估计。

::: ex 7.A · 同一步长的三种结果
对 $y'=-y$、$y(0)=1$，取 $h=0.1$，分别用显式 Euler、Heun 改进 Euler、经典 RK4 计算第一步，并与 $e^{-0.1}$ 比较。
:::

::: sol 参考答案
三个放大因子依次为 $1-h$、$1-h+h^2/2$、$1-h+h^2/2-h^3/6+h^4/24$。第一步结果依次为 $0.9$、$0.905$、$0.9048375$，精确值约为 $0.9048374180$。这只比较当前一步；判断全局阶还要固定终点并改变步长。
:::

::: ex 7.B · 从递推得到全局误差
仍对 $y'=-y$ 使用显式 Euler。取 $h=1/N$，求 $t=1$ 处的数值解，并说明其一阶收敛。
:::

::: sol 参考答案
$y_N=(1-h)^N=(1-h)^{1/h}$。由 $h^{-1}\ln(1-h)=-1-h/2+O(h^2)$，可得
$$y_N=e^{-1}(1-h/2+O(h^2)),$$
所以 $e^{-1}-y_N=e^{-1}h/2+O(h^2)$，为一阶全局误差。展开用于 $h\to0^+$。
:::

::: ex 7.C · 稳定性与精度
对 $y'=-10y$，求显式 Euler 保持衰减的步长范围。取范围内的 $h=0.1$，解释为什么仍可能不准确。
:::

::: sol 参考答案
需要 $|1-10h|<1$，所以 $0<h<0.2$。但 $h=0.1$ 时放大因子为零，非零初值在一步后被算成零；精确解这时还保留初值的 $e^{-1}$ 倍。稳定性条件控制持续放大，并不直接给出精度保证。
:::

::: ex 7.D · 多步法的根条件
对二步格式 $y_{n+2}-2y_{n+1}+y_n=h(f_{n+1}-f_n)$，检查相容性与零稳定性。
:::

::: sol 参考答案
特征多项式为 $\rho(\zeta)=(\zeta-1)^2$、$\sigma(\zeta)=\zeta-1$。有 $\rho(1)=0$、$\rho'(1)=\sigma(1)=0$，满足一阶相容条件；但单位圆上的根 $1$ 为二重根，违反零稳定根条件，因此不能由相容性推出收敛。
:::

::: ex 7.E · 步长加倍误差估计
某个四阶方法一步长 $h$ 的结果为 $Y_h$，连续两次半步的结果为 $Y_{h/2}$。假设已进入渐近区，说明细解和 Richardson 外推解应怎样计算。
:::

::: sol 参考答案
设粗解的主误差为 $Ch^5$，两个半步合成的主误差约为 $Ch^5/16$。由两结果之差，细解的误差大小约为 $|Y_{h/2}-Y_h|/15$；外推解为 $Y_{h/2}+(Y_{h/2}-Y_h)/15$。这个估计依赖主误差展开，不能代替对突变或奇异性的检查。
:::

::: ex 7.F · 把高阶方程化成系统
对 $y''+y=0$、$y(0)=1,y'(0)=0$，写出一阶系统，并用显式 Euler、$h=0.1$ 计算第一步。
:::

::: sol 参考答案
令 $v=y'$，则 $Y=(y,v)^{\mathrm T}$，$Y'=(v,-y)^{\mathrm T}$，$Y_0=(1,0)^{\mathrm T}$。第一步 $Y_1=(1,-0.1)^{\mathrm T}$。精确值为 $(\cos0.1,-\sin0.1)^{\mathrm T}$；两个分量应使用同一旧状态计算，不能更新第一个后再把它代入第二个。
:::

::: ex 7.G · 从链式法则构造二阶格式
对 $y'=t+y,\ y(0)=1$，分别求 $f_t,f_y$，写出二阶 Taylor 格式，并以 $h=0.1$ 算到 $t=0.2$。说明在什么条件下能把局部 $O(h^3)$ 推成整体 $O(h^2)$。
:::

::: sol 参考答案
$f_t=f_y=1$，故 $B=f_t+f_yf=1+t+y$，格式为
$$y_{n+1}=y_n+h(t_n+y_n)+\frac{h^2}{2}(1+t_n+y_n).$$
第一步 $y_1=1.11$；第二步 $f(0.1,1.11)=1.21$、$B(0.1,1.11)=2.21$，因此 $y_2=1.11+0.121+0.01105=1.24205$。精确解 $2e^t-t-1$ 在 $t=0.2$ 约为 $1.242805516$。全局二阶需要固定有限区间、统一 $O(h^3)$ 缺陷界、增量关于状态的一致 Lipschitz 界，以及精确或 $O(h^2)$ 准确的初值；这道题的线性函数满足所需状态界。两步数值比较本身不是整体阶的证明。
:::

::: ex 7.H · 两个初值决定两个模态
对 $u_{n+1}=\tfrac52u_n-u_{n-1}$，原初值为 $u_0=1,u_1=1/2$。现在只改成 $\widehat u_1=1/2+\delta$，保持 $\widehat u_0=1$。求误差通项。若另有人写 $\widehat u_n=2^{-n}+\varepsilon2^n$，它对应的两个初值是什么？
:::

::: sol 参考答案
令 $e_n=\widehat u_n-u_n=A2^{-n}+B2^n$。由 $A+B=0$、$A/2+2B=\delta$ 得 $A=-2\delta/3,B=2\delta/3$，所以
$$e_n=\frac{2\delta}{3}(2^n-2^{-n}).$$
另一表达式对应 $\widehat u_0=1+\varepsilon$、$\widehat u_1=1/2+2\varepsilon$，两个初值都变了。即使增长分支的系数只有机器精度量级，指数放大仍可能使它主导结果；不能由此断言二进制可精确表示的无扰动初值必然立即发生舍入。
:::

::: ex 7.I · 两端判据需要什么条件
设实标量 $f$ 对 $y$ 连续可微，在两条 Euler 数值轨道之间的整个相关区域都有 $-5\le f_y(t,y)\le-1$。证明 $0<h<0.4$ 保证齐次初值扰动逐步收缩，并求 $h=0.1$ 时的统一收缩因子。若只知道参考轨道某一个点的导数值，能否作相同结论？
:::

::: sol 参考答案
中值定理给 $\delta_{n+1}=(1+h\lambda_n)\delta_n$，其中 $\lambda_n\in[-5,-1]$。对正步长 $h<0.4$，两端的 $|1-5h|$ 与 $|1-h|$ 都小于 $1$，区间内部由凸性也不超过两端最大值。$h=0.1$ 时可取 $q=\max(0.5,0.9)=0.9$，因而 $|\delta_n|\le0.9^n|\delta_0|$。一个点的导数值不能控制中值点 $\xi_n$，所以不足以证明该结论；这里也没有证明任意 RK 或方程组都可仅查两个端点。
:::
