# 第七章练习与解答

本组练习使用几个可写出精确解的方程，分别检查一步计算、全局误差、稳定性和自适应误差估计。

::: ex 7.A · 同一步长的三种结果
对 $y'=-y$、$y(0)=1$，取 $h=0.1$，分别用显式 Euler、Heun 改进 Euler、经典 RK4 计算第一步，并与 $e^{-0.1}$ 比较。
:::

::: sol 参考答案
三个放大因子依次为 $1-h$、$1-h+h^2/2$、$1-h+h^2/2-h^3/6+h^4/24$。第一步结果依次为 $0.9$、$0.905$、$0.9048375$，精确值约为 $0.9048374180$。这只比较当前一步；判断全局阶还要固定终点并改变步长。
:::

::: ex 7.B · 从递推得到全局误差
仍对 $y'=-y$ 使用显式 Euler。取 $h=1/N$，求 $t=1$ 处的数值解，并说明其一阶收敛。
:::

::: sol 参考答案
$y_N=(1-h)^N=(1-h)^{1/h}$。由 $h^{-1}\ln(1-h)=-1-h/2+O(h^2)$，可得
$$y_N=e^{-1}(1-h/2+O(h^2)),$$
所以 $e^{-1}-y_N=e^{-1}h/2+O(h^2)$，为一阶全局误差。展开用于 $h\to0^+$。
:::

::: ex 7.C · 稳定性与精度
对 $y'=-10y$，求显式 Euler 保持衰减的步长范围。取范围内的 $h=0.1$，解释为什么仍可能不准确。
:::

::: sol 参考答案
需要 $|1-10h|<1$，所以 $0<h<0.2$。但 $h=0.1$ 时放大因子为零，非零初值在一步后被算成零；精确解这时还保留初值的 $e^{-1}$ 倍。稳定性条件控制持续放大，并不直接给出精度保证。
:::

::: ex 7.D · 多步法的根条件
对二步格式 $y_{n+2}-2y_{n+1}+y_n=h(f_{n+1}-f_n)$，检查相容性与零稳定性。
:::

::: sol 参考答案
特征多项式为 $\rho(\zeta)=(\zeta-1)^2$、$\sigma(\zeta)=\zeta-1$。有 $\rho(1)=0$、$\rho'(1)=\sigma(1)=0$，满足一阶相容条件；但单位圆上的根 $1$ 为二重根，违反零稳定根条件，因此不能由相容性推出收敛。
:::

::: ex 7.E · 步长加倍误差估计
某个四阶方法一步长 $h$ 的结果为 $Y_h$，连续两次半步的结果为 $Y_{h/2}$。假设已进入渐近区，说明细解和 Richardson 外推解应怎样计算。
:::

::: sol 参考答案
设粗解的主误差为 $Ch^5$，两个半步合成的主误差约为 $Ch^5/16$。由两结果之差，细解的误差大小约为 $|Y_{h/2}-Y_h|/15$；外推解为 $Y_{h/2}+(Y_{h/2}-Y_h)/15$。这个估计依赖主误差展开，不能代替对突变或奇异性的检查。
:::

::: ex 7.F · 把高阶方程化成系统
对 $y''+y=0$、$y(0)=1,y'(0)=0$，写出一阶系统，并用显式 Euler、$h=0.1$ 计算第一步。
:::

::: sol 参考答案
令 $v=y'$，则 $Y=(y,v)^{\mathrm T}$，$Y'=(v,-y)^{\mathrm T}$，$Y_0=(1,0)^{\mathrm T}$。第一步 $Y_1=(1,-0.1)^{\mathrm T}$。精确值为 $(\cos0.1,-\sin0.1)^{\mathrm T}$；两个分量应使用同一旧状态计算，不能更新第一个后再把它代入第二个。
:::
