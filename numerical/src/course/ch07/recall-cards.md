# 闭卷回忆卡 · 第 7 章：常微分方程初值问题

## A. 定义卡

**A1.** 什么是绝对稳定性？为什么要用测试方程来定义它？
::: sol
对衰减测试方程 $y'=\lambda y$、$z=h\lambda$，单步法的严格衰减区为 $|R(z)|<1$；允许有界的边界定义需另说明，多步法还要检查单位圆上根的重数。线性化提供有用的局部诊断，但不能把标量稳定域直接当成所有非线性、时变或非正规系统的完整保证。（✓ / △ / ×）
:::

**A2.** 什么是刚性（stiff）？
::: sol
刚性的实际困难是：显式法受稳定性限制的步长远小于精度要求所需的步长。快慢衰减模态相差很大是常见来源，但不是普适定义；单个快速衰减问题在长时间区间也可造成这一限制。应结合求解区间、容差和实际解的变化判断。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 单步法收敛需要哪两个条件？
::: sol
在光滑性、Lipschitz 和初值收敛等条件下，相容性给出单步缺陷趋零，稳定的误差传播估计将它推广为固定区间的全局收敛。这里的传播控制不是“某个固定步长在标量绝对稳定域内”的同义词。相容性译为 consistency，不能译作 convergence order。（✓ / △ / ×）
:::

**B2.** 线性多步法收敛的判据是什么？
::: sol
在解的光滑性、$f$ 对 $y$ 的 Lipschitz 条件与启动值收敛等假设下，检查相容性与零稳定根条件：$\rho$ 的根模不超过 $1$，圆上根为单根。要保留 $p$ 阶全局精度还需启动误差 $O(h^p)$。反例 $\rho=(\zeta-1)^2$ 中，启动误差 $h$ 可在固定终点累积成 $O(1)$。（✓ / △ / ×）
:::

**B3.** A-稳定是什么意思？哪些方法是 A-稳定的？
::: sol
绝对稳定域包含整个开左半平面时称 A-稳定。后退 Euler 与梯形法满足，显式 Euler、经典 RK4 不满足。A-稳定消除了衰减标量测试方程的稳定性步长上限，却不保证大步长准确；强刚性还要考虑对快速模式的阻尼，且处理刚性不要求所有方法都 A-稳定。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 拿到一个初值问题，你的求解流程是什么？
::: sol
1. **估刚性**：用 $F_Y$ 的特征值量级（或行范数）估 $|\lambda_{\max}|$；
2. **选方法**：非刚性 ⟹ 高阶显式 RK（快、精度高）；刚性 ⟹ 隐式 / A-稳定方法；
3. **定步长**：受**稳定域**约束 $h\lesssim z_{\max}/|\lambda_{\max}|$ 与受截断误差约束两者取小；
4. **跑**：先算几步，用步长减半实验验证实测阶；
5. **报告**：给解、步长、实测阶与误差估计。（✓ / △ / ×）
:::

**C2.** 为什么高阶方程要化成一阶系统？
::: sol
化成一阶系统 $Y=(y,y',\dots,y^{(m-1)})^{\mathrm T}$ 后，可直接使用向量形式的数值方法。维度增加会改变一次右端求值与隐式求解的成本，但 RK 的阶段数不会因此乘以 $m$。各分量可能量纲与尺度不同，误差检查应采用分量容差或尺度化范数。（✓ / △ / ×）
:::


## D. 课件增补复习

**D1.** Euler 的初值扰动稳定性与绝对稳定性分别比较什么？
::: sol
有限时间初值扰动稳定性比较同一网格上的两组数值解，Lipschitz 条件给出 $|u_n-v_n|\le e^{L(T-t_0)}|u_0-v_0|$。绝对稳定性在 $y'=\lambda y$ 上检查 $|R(h\lambda)|<1$，要求该步长下的扰动逐步衰减。见[证明](sec71.md#euler-initial-stability)。（✓ / △ / ×）
:::

**D2.** 三级三阶 RK 的四个系数条件是什么？
::: sol
在[本页采用的级量形式](sec71.md#rk3-construction)下，$\sum c_i=1$、$c_2a_2+c_3a_3=1/2$、$c_2a_2^2+c_3a_3^2=1/3$、$c_3a_2b_{32}=1/6$。它们分别匹配 $f,F,G,Ff_y$ 的系数；只在测试方程上匹配稳定多项式，不能代替对一般 f 的全部阶条件。（✓ / △ / ×）
:::

**D3.** RK4 步长加倍为什么除以 15，拒步后能否更新时间？
::: sol
同一宏步 h 上，两半步的领先局部误差是粗步的 $1/16$，所以 $(y_{\mathrm{fine}}-y_{\mathrm{coarse}})/15$ 估计细解误差。拒步时保留原时刻、原解，只缩短步长重新试算；接受后才提交细解。误差按 $h^5$ 缩放，步长倍率使用 $E^{-1/5}$。见[完整示例](sec74.md#adaptive-rk4-loop)。（✓ / △ / ×）
:::
