# 闭卷回忆卡 · 第 7 章：常微分方程初值问题

## A. 定义卡

**A1.** 什么是绝对稳定性？为什么要用测试方程来定义它？
::: sol
方法对测试方程 $y'=\lambda y$ 产生的扰动**随步数不增长**（即解不指数放大）称绝对稳定。用测试方程是因为它是**线性**的：任何非线性方程在局部都近似线性，其稳定性由该处的线性化矩阵决定，于是线性方法的稳定性分析可以搬过去。（✓ / △ / ×）
:::

**A2.** 什么是刚性（stiff）？
::: sol
若方程组 $Y'=F(t,Y)$ 的 Jacobian $F_Y$ 的特征值实部全为负，且**量级相差很大**（如 $-10^6$ 与 $-1$），称刚性。困难在于：显式方法为保稳定必须取 $h\sim1/|\lambda_{\max}|$，而解的实际变化只需 $h\sim1/|\lambda_{\min}|$，两者相差巨大。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 单步法收敛需要哪两个条件？
::: sol
**相容**（convergence order 一致、截断误差随 $h\to0$ 趋于零）与**稳定**（绝对稳定）。二者合起来才推出收敛；只相容不稳定会在 $n\to\infty$ 时把舍入误差放大成垃圾解。（✓ / △ / ×）
:::

**B2.** 线性多步法收敛的判据是什么？
::: sol
**相容 + 根条件**：特征多项式 $\rho(\zeta)=\sum\alpha_j\zeta^j$ 的全部根在单位圆内，且位于单位圆上的根是**单根**。根条件是零稳定性要求，它与相容一起保证方法收敛。（✓ / △ / ×）
:::

**B3.** A-稳定是什么意思？哪些方法是 A-稳定的？
::: sol
方法的绝对稳定域包含**整个左半平面**时称 A-稳定。**后退 Euler 与梯形法是 A-稳定的**；显式 Euler、RK4 的稳定域有界，不是 A-稳定。A-稳定是处理刚性问题的入场券。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 拿到一个初值问题，你的求解流程是什么？
::: sol
1. **估刚性**：用 $F_Y$ 的特征值量级（或行范数）估 $|\lambda_{\max}|$；
2. **选方法**：非刚性 ⟹ 高阶显式 RK（快、精度高）；刚性 ⟹ 隐式 / A-稳定方法；
3. **定步长**：受**稳定域**约束 $h\lesssim z_{\max}/|\lambda_{\max}|$ 与受截断误差约束两者取小；
4. **跑**：先算几步，用步长减半实验验证实测阶；
5. **报告**：给解、步长、实测阶与误差估计。（✓ / △ / ×）
:::

**C2.** 为什么高阶方程要化成一阶系统？
::: sol
化成一阶系统 $Y=(y,y',\dots,y^{(m-1)})^{\mathrm T}$ 后，所有单步法与多步法都能**逐分量**使用，不必为每个 $m$ 阶方程单独推导公式；代价是维度从 1 变成 $m$，每步函数求值次数乘以 $m$，误差度量也要改用与分量无关的范数。（✓ / △ / ×）
:::
