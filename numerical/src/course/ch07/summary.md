# 第七章小结：从初值逐步计算解

常微分方程初值问题给出当前位置的变化率，我们用它推进到下一个时刻。单步法在一步内计算斜率，多步法复用先前节点的信息；步长则同时影响截断误差、计算量和稳定性。

以 $y'=-10y$、$y(0)=1$ 为例，显式 Euler 给出
$$y_{n+1}=(1-10h)y_n.$$
若希望这个衰减模式在数值上也衰减，需要 $|1-10h|<1$，即 $0<h<0.2$。但稳定区间内也可能不够准确：取 $h=0.1$，第一步得到 $0$，精确值却为 $e^{-1}$。

| 要检查的问题 | 方法与结论 |
|:--|:--|
| 一步误差多大 | 将精确解代入格式，计算局部截断误差，并核对是否除以步长 |
| 固定时间区间内误差多大 | 结合局部缺陷与稳定传播；Euler 在相应条件下全局一阶 |
| 初始扰动怎样传播 | 比较两组数值解，在有限时间区间建立扰动界 |
| 固定步长是否稳定 | 对模型方程写出放大因子，或对多步法检查特征根 |
| 多步法是否收敛 | 相容性加零稳定性，并满足解与起步值的相应条件 |
| 怎样调整步长 | 比较不同精度近似估计局部误差；超限就拒绝该步并减小步长 |
| 问题是否刚性 | 稳定性所需步长是否远小于分辨目标解变化所需的步长 |

后退 Euler 对上面的衰减方程在任意正步长下都衰减，但粗步长仍可能丢失快速变化。隐式方法也并非都 A-稳定，需要逐个分析其稳定域。

高阶方程先化为一阶系统，再对整个状态向量应用相同方法。做[本章练习](exercises.md)，并用固定终点的步长减半实验检查收敛阶。最后可到[综合练习](../../training/exam-sprint.md)复习七章方法的选择与误差分析。
