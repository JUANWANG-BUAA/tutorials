## 二、从一道题串起全章

取 $y'=-10y,\ y(0)=1$。显式 Euler 为 $y_{n+1}=(1-10h)y_n$。

1. **先看稳定性**：要求该衰减模式在数值上也衰减，需 $|1-10h|<1$，即 $0<h<0.2$。$h=0.2$ 时只是不增长，会持续交替符号。
2. **再看精度**：$h=0.1$ 虽在稳定区内，第一步就给出零，而真值为 $e^{-1}$。稳定并不等于准确。
3. **最后做收敛试验**：固定终点，比较 $h,h/2,h/4$；进入渐近区后 Euler 全局误差应约按 $2:1$ 缩小。不能同时改变终点再比较误差。

后退 Euler 的放大因子为 $1/(1+10h)$，对任意正步长均衰减，但粗步长仍不能准确分辨快速变化。运行[跨章实验](../../training/learning-lab.md)检验这两层结论。

## 三、易错清单

| 常见错误 | 正确说法 |
|:--|:--|
| 「Euler 局部二阶，所以全局二阶」 | 从精确起点出发的未归一化单步缺陷为 $O(h^2)$；在光滑性与稳定传播条件下，固定区间全局误差为 $O(h)$ |
| 「隐式方法都 A-稳定」 | A-稳定要检查整个左半平面；后退 Euler 与梯形法满足，不能推广到所有隐式格式 |
| 「特征值大小差很多就是刚性」 | 关键是稳定性要求的步长远小于解析所需解变化的步长；单个快速衰减方程也可出现这一困难 |
| 「多步法比 RK 更好」 | 还要考虑起步值、变步长处理和每步成本，不能只比较阶数 |
| 「步长越小必然越准」 | 截断误差可能降低，但舍入、函数求值误差与原始数据误差会限制最终精度 |
| 「高阶方程要多写几阶」 | 化成一阶系统 $Y' = F(t,Y)$ 后**逐分量**用同样的方法 |
