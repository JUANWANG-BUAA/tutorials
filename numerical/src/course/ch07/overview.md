# 第7章 常微分方程

前面计算积分时，被积函数是已知的。现在考虑一种常见的变化规律：某个量的变化率取决于当前时间和当前状态，而状态本身未知。例如

$$y'(t)=f(t,y(t)),\qquad y(t_0)=y_0.$$

方程给出变化率，初值给出起点。我们希望据此算出后续时刻的状态。这称为常微分方程的初值问题。

从起点沿当前斜率走一小步，就得到 Euler 方法。由于真实曲线一般会弯曲，直线走出的新点会有误差；下一步又从近似点出发，因此必须分析误差怎样累积。Runge–Kutta 方法通过在一步内多计算几个斜率改善精度，多步法则利用前几步的信息。

步长决定一次向前走多远。它既影响精度，也影响稳定性：即使真实解逐渐衰减，某些步长下的数值解仍可能增大。本章最后讨论怎样选择步长，以及怎样处理方程组与刚性问题。
