# 第五章小结：用数据与函数构造近似

插值要求近似函数通过给定节点；最小二乘要求在选定函数空间内，使规定的平方误差最小。两种任务的条件不同，应先根据数据和用途决定目标，再选计算方法。

| 方法 | 已知条件 | 构造与误差 |
|:--|:--|:--|
| Lagrange 插值 | 互异节点上的函数值 | 用节点基函数构造唯一插值多项式 |
| Newton 插值 | 同上 | 用差商逐项增加节点，便于更新 |
| Hermite 插值 | 函数值与若干导数值 | 条件个数决定次数上限；余项反映节点重数 |
| 三次样条 | 节点值与边界条件 | 分段三次并保持规定的连续性 |
| 三角插值 | 周期节点数据 | DFT 给出系数，FFT 减少计算量 |
| 最佳平方逼近 | 函数、内积与近似空间 | 误差与近似空间正交；正交基使系数分别可算 |
| 离散最小二乘 | 采样数据与模型 | 解投影问题，再回到原始量纲检查残差 |

多项式存在唯一，不等于采用任何表示都能稳定计算。换到 Lagrange 或 Newton 基可以避免直接求解单项式系数方程组；它不会消除数据中的噪声，也不改变节点本身造成的插值敏感性。

做模型变换时，要看清最小化的量。对 $y$ 取对数后拟合，最小化的是对数残差平方和，一般不再是原始 $y$ 的残差平方和。比较不同模型时，应使用相同数据、相同量纲和适合问题的指标。
