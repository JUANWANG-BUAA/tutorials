# 第 5 章学习目标自检表

## K · 知识

| 编号 | 目标 | 自检标准 | ✓ |
|:--|:--|:--|:--|
| K5.1 | 写出 Lagrange 插值与基函数 | $n+1$ 个互异节点，$L_n(x)=\sum f(x_i)l_i(x)$，$l_i(x_j)=\delta_{ij}$ | ☐ |
| K5.2 | 写出 Lagrange 余项 | $f\in C^{n+1}$，区间包含节点与求值点；$R=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^n(x-x_i)$，节点处误差为零 | ☐ |
| K5.3 | 写出 Newton 插值与差商定义 | $f[x_0,\dots,x_k]$，加节点只添一项 | ☐ |
| K5.4 | 写出 Hermite 条件与余项 | $n+1$ 个互异节点各给函数值与一阶导，合计 $2n+2$ 个条件、次数至多 $2n+1$；$f\in C^{2n+2}$ 时余项含平方节点乘积 | ☐ |
| K5.5 | 说明样条的条件计数 | $4n$ 个未知、$4n-2$ 个条件、差 2 个由边界条件补 | ☐ |
| K5.6 | 写出实内积四公理 | 对称、齐次、可加、正定；后者包括零向量的充要条件 | ☐ |
| K5.7 | 写出法方程与投影条件 | $f-p\perp M\iff (f-p,\varphi_i)=0$，$G\boldsymbol a=\boldsymbol b$ | ☐ |
| K5.8 | 写出 Gram–Schmidt 公式与次数保持 | $\varphi_k=x^k-\sum_{j<k}\dfrac{(x^k,\varphi_j)}{(\varphi_j,\varphi_j)}\varphi_j$，$\deg\varphi_k=k$ | ☐ |
| K5.9 | 写出四族正交多项式的区间与权 | Legendre $[-1,1],1$；Chebyshev $[-1,1],\frac1{\sqrt{1-x^2}}$；Laguerre $[0,\infty),e^{-x}$；Hermite $(-\infty,\infty),e^{-x^2}$ | ☐ |
| K5.10 | 写出离散内积与最小二乘 | $(f,g)=\sum_i f(x_i)g(x_i)$ 在采样向量空间上为内积；对函数空间一般仅为半内积，拟合系数唯一要求采样矩阵列满秩 | ☐ |
| K5.11 | 说明 B 样条基与局部支撑 | Cox–de Boor 递推；$N_{i,k}$ 的支撑在结点区间 $[t_i,t_{i+k+1}]$ 内，方程组带状 | ☐ |
| K5.12 | 写出三角插值、DFT 与 FFT 复杂度 | 等距节点三角函数组正交；$c_k=\frac1N\sum_l f_le^{-2\pi ikl/N}$；FFT 为 $O(N\log N)$ | ☐ |
