# 第 5 章练习与解答

先练习插值的存在唯一性与误差，再完成下面的逼近计算。各题都使用本页给出的条件。

## 入门练习

::: ex 5.A · 范德蒙德行列式
节点为 $x_0=0,x_1=1,x_2=2$，写出范德蒙德矩阵并算行列式。
:::

::: sol 参考答案
$$A=\begin{pmatrix}1&0&0\\1&1&1\\1&2&4\end{pmatrix},\qquad
\det A=\prod_{0\le i\lt j\le2}(x_j-x_i)=(1-0)(2-0)(2-1)=2.$$
非零，故三个点唯一确定一个次数不超过 $2$ 的插值多项式。
:::

::: ex 5.B · 拉格朗日插值
已知 $f(0)=1,f(1)=3$，写出两点拉格朗日插值多项式。
:::

::: sol 参考答案
$l_0(x)=\dfrac{x-1}{0-1}=1-x$，$l_1(x)=\dfrac{x-0}{1-0}=x$。故
$$L_1(x)=f(0)l_0(x)+f(1)l_1(x)=1\cdot(1-x)+3\cdot x=1+2x.$$
直接验证：$L_1(0)=1,L_1(1)=3$。
:::

::: ex 5.C · 插值余项
设 $f(x)=e^x$，在 $[0,1]$ 上用节点 $0,1$ 做线性插值，给出 $|R_1(x)|$ 的一个上界。
:::

::: sol 参考答案
$R_1(x)=\dfrac{e^{\xi}}{2!}x(x-1)$，$\xi\in(0,1)$。故
$$|R_1(x)|\le\frac{e}{2}\max_{[0,1]}|x(x-1)|=\frac{e}{2}\cdot\frac14=\frac{e}{8}\approx0.34.$$
:::

::: ex 5.D · 病态与换基
为什么用单项式基的范德蒙德矩阵直接解插值系数可能损失精度？拉格朗日基改变了什么，又没有改变什么？
:::

::: sol 参考答案
单项式基的范德蒙德矩阵可能严重病态；具体条件数取决于节点、区间缩放、次数及所用范数，不能仅由节点数给出固定数值。大条件数表示系数对数据扰动可能敏感，并不表示每组右端都达到最坏误差。拉格朗日基满足 $l_i(x_j)=\delta_{ij}$，展开系数直接是 $f(x_i)$，因而绕开了求解单项式系数的方程组。插值多项式仍是同一个，节点引起的插值敏感性也仍在；换基不能消除 Runge 现象。
:::

## 逼近与拟合练习

::: ex 5.E · 用导数确定插值
求次数不超过 $3$ 的多项式 $H$，满足 $H(0)=0$、$H'(0)=0$、$H(1)=1$、$H'(1)=0$。解释为什么解唯一。
:::

::: sol 参考答案
由前两个条件，$H(x)=ax^2+bx^3$；其余条件给出 $a+b=1$、$2a+3b=0$，所以 $H(x)=3x^2-2x^3$。若另有一个解，两解之差在 $0,1$ 都有二重零点，而次数不超过 $3$，只能恒为零。
:::

::: ex 5.F · 一次最佳平方逼近
在内积 $(f,g)=\int_{-1}^1f(x)g(x)\,dx$ 下，求 $f(x)=x^2$ 的一次最佳平方逼近 $p(x)=a+bx$，并计算误差平方。
:::

::: sol 参考答案
投影条件为 $\int_{-1}^1(x^2-a-bx)\,dx=0$、$\int_{-1}^1x(x^2-a-bx)\,dx=0$。奇函数项积分为零，得到 $a=1/3,b=0$。误差平方为
$$\int_{-1}^1(x^2-1/3)^2\,dx=\frac8{45}.$$
常数也属于次数不超过 $1$ 的多项式空间，所以该结果符合题意。
:::

::: ex 5.G · 拟合后检查残差
对数据 $(0,1),(1,2),(2,2)$ 拟合直线 $p(x)=a+bx$。求系数，列出三个残差，并检查它们与设计矩阵两列的内积。
:::

::: sol 参考答案
解法方程 $\begin{pmatrix}3&3\\3&5\end{pmatrix}(a,b)^{\mathrm T}=(5,6)^{\mathrm T}$，得 $a=7/6,b=1/2$。残差为 $(-1/6,1/3,-1/6)^{\mathrm T}$，它们之和为零，与 $(0,1,2)^{\mathrm T}$ 的内积也为零。残差平方和为 $1/6$。
:::
