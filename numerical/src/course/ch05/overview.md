# 第5章 插值与逼近

前面几章从已知方程出发求未知量。本章换一种情形：已知的可能只有几个测量点，需要先建立一个便于计算的函数。第一章的水温问题就是如此——我们知道若干深度的温度，希望估计测点之间的温度。

最直接的要求是让构造的函数通过全部数据点，这称为插值。两点之间可以用直线；节点更多时，可以使用多项式，也可以在各小区间上分别使用低次多项式，再把它们光滑地接起来。

如果数据带有测量误差，强求曲线经过每个点未必合适。另一种做法是选定一类简单函数，使总体偏差尽量小，这就引出逼近与最小二乘拟合。本章会明确区分这两种要求，并说明各自的误差怎样分析。

学到本章后半部分时，第二章的线性方程组会再次出现：求最佳平方逼近可以转化为求系数的方程组。选择正交基后，方程组会变得简单。
