# 闭卷回忆卡 · 第 3 章：特征值与特征向量的计算

> **用法**：遮住答案写；标 ✓ / △ / ×。压缩在[公式与结论卡](../../review/formula-cards.md)，考场节奏在[综合自测卷](mock-exam.md)。

## A. 定义卡

**A1.** 幂法的基本迭代格式是什么？为什么要先单位化？
::: sol
幂法：取初值 $\boldsymbol y_0$，迭代 $\boldsymbol y_{k+1}=A\boldsymbol y_k$，再令 $\boldsymbol y_{k+1}\leftarrow\boldsymbol y_{k+1}/\lVert\boldsymbol y_{k+1}\rVert_2$。**先单位化**有两个理由：① $A^k$ 的元素会指数增长/衰减，不归一化会溢出或下溢；② 归一化后 Rayleigh 商 $y_k^{\mathrm T}Ay_k$ 的极限才有意义（$\to\lambda_1$）。（✓ / △ / ×）
:::

**A2.** 反幂法求的是什么？位移反幂法又求什么？
::: sol
反幂法迭代 $A^{-1}$，收敛到**模最小**的特征值（对应 $1/\lambda$ 最大）。位移反幂法迭代 $(A-pI)^{-1}$，收敛到**最接近给定数 $p$** 的特征值。实现上不显式求逆：每步解线性方程组 $A\boldsymbol u_{k+1}=\boldsymbol y_k$（位移时解 $(A-pI)\boldsymbol u_{k+1}=\boldsymbol y_k$），用第 2 章的 LU 分解复用因子。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 为什么实矩阵的特征值可能不是实数？幂法怎么暴露这一点？
::: sol
一般实矩阵 $A$ 的特征值可能是**一对共轭复数**。反证思路：若 $\lambda$ 是实特征值，$Ay=\lambda y$ 取某分量可推出 $\lambda\in\mathbb R$ 需 $y$ 分量非零，逐分量递推即得 $\lambda$ 必实——所以当 $A$ 有非实特征值时，幂法迭代向量会出现**方向振荡**（逐分量符号交替），这正是识别复特征对的信号。（✓ / △ / ×）
:::

**B2.** 谱半径与谱范数是什么关系？
::: sol
对任意方阵，$\rho(A)\le\lVert A\rVert$（任一相容范数）。取 2-范数时 $\lVert A\rVert_2=\sigma_{\max}$（最大奇异值）。对称正定阵才有 $\lVert A\rVert_2=\rho(A)$ 之外的更好性质。详见[补充篇 2.5](../../supplement/overview.md)。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 要算「最接近 $\lambda=3$ 的特征值」，你怎么做？
::: sol
用**位移反幂法**：取 $p=3$，每步解 $(A-3I)\boldsymbol u_{k+1}=\boldsymbol y_k$ 并归一化，迭代到 Rayleigh 商稳定；再用 $\mu=1/\rho$ 反推 $\lambda$（注意符号：位移后求得的是 $\frac{1}{\lambda-p}$）。用 LU 分解复用因子，每步 $O(n^2)$。（✓ / △ / ×）
:::

**A3.** Jacobi 方法用什么变换消去非对角元？消元条件是什么？
::: sol
用平面旋转 $U_{pq}$（正交相似变换），只改变第 $p,q$ 两行/两列。取 $\cot2\varphi=\dfrac{a_{pp}-a_{qq}}{2a_{pq}}$，旋转后 $a_{pq}^{(1)}=0$。每次选模最大的非对角元，迭代到 $\max_{i\ne j}|a_{ij}|<\varepsilon$；对角元即特征值，累积旋转矩阵 $V=U_1U_2\cdots$ 的列为特征向量。（✓ / △ / ×）
:::

**B3.** QR 迭代为什么能求全部特征值？收敛到什么？
::: sol
因为 $A_{k+1}=R_kQ_k=Q_k^{\mathrm T}A_kQ_k$，每步都是正交相似，特征值不变。实对称矩阵收敛到对角矩阵；一般实矩阵本质上收敛到分块上三角，一阶块给实特征值、二阶块给复共轭特征值。实用算法先 Householder 拟上三角化（$O(n^2)$/步），再用双步位移与降阶加速。（✓ / △ / ×）
:::

**C2.** 给定矩阵结构，怎么在幂法、Jacobi、QR 之间选？
::: sol
只要**一个**主特征值 → 幂法；要最接近某个 $p$ 的特征值 → 位移反幂法；**实对称**且要全部特征值/特征向量 → Jacobi；**一般实矩阵**要全部特征值 → 先拟上三角化再双步位移 QR。幂法/反幂法每步 $O(n^2)$ 且可解稀疏；Jacobi 破坏稀疏；QR 是中小型稠密矩阵的通用选择。（✓ / △ / ×）
:::
