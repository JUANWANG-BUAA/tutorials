# 闭卷回忆卡 · 第 3 章：特征值与特征向量的计算

> **用法**：遮住答案写；标 ✓ / △ / ×。压缩在[公式与结论卡](../../review/formula-cards.md)，考场节奏在[综合自测卷](mock-exam.md)。

## A. 定义卡

**A1.** 幂法的基本迭代格式是什么？归一化与 Rayleigh 商有什么关系？
::: sol
取非零初值，每步算 $w=Ay_k$，确认 $w\ne0$ 后令 $y_{k+1}=w/\|w\|_2$。归一化控制量级；完整 Rayleigh 商 $v^{\mathrm T}Av/(v^{\mathrm T}v)$ 对非零缩放不变。只有省略分母时才要求 $\|v\|_2=1$。收敛到主方向还需谱间隙与初始分量条件。（✓ / △ / ×）
:::

**A2.** 反幂法求的是什么？位移反幂法又求什么？
::: sol
反幂法迭代 $A^{-1}$，收敛到**模最小**的特征值（对应 $1/\lambda$ 最大）。位移反幂法迭代 $(A-pI)^{-1}$，收敛到**最接近给定数 $p$** 的特征值。实现上不显式求逆：每步解线性方程组 $A\boldsymbol u_{k+1}=\boldsymbol y_k$（位移时解 $(A-pI)\boldsymbol u_{k+1}=\boldsymbol y_k$），用第 2 章的 LU 分解复用因子。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 实矩阵为什么可能有复特征值？迭代向量交替符号能说明什么？
::: sol
实系数特征多项式可能有复共轭根，例如 $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 的根为 $\pm i$，实向量在幂迭代中旋转。符号交替也可能来自负实主特征值，例如 $\operatorname{diag}(-2,1)$；因此不能仅凭振荡判断有复特征值。（✓ / △ / ×）
:::

**B2.** 谱半径与谱范数是什么关系？
::: sol
对任意方阵及从属矩阵范数，$\rho(A)\le\|A\|$；$\|A\|_2=\sigma_{\max}$。实对称矩阵即有 $\|A\|_2=\rho(A)=\max_i|\lambda_i|$，不要求正定；复正规矩阵也成立。正定时才可进一步去掉特征值绝对值。详见[补充篇 2.5](../../supplement/overview.md)。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 要算「最接近 $\lambda=3$ 的特征值」，你怎么做？
::: sol
取位移 $p=3$，先检查 $A-3I$ 是否可求解，再复用其分解进行反幂迭代。若 $3$ 恰为特征值，该矩阵奇异，需调整位移或另求零空间。若得到的是逆矩阵特征值估计 $\mu$，应还原为 $\lambda\approx3+1/\mu$；若直接算原矩阵 $A$ 的 Rayleigh 商，则已经是原特征值估计，不再变换。用原特征对残差验收。（✓ / △ / ×）
:::

**A3.** Jacobi 方法用什么变换消去非对角元？消元条件是什么？
::: sol
用平面旋转 $U_{pq}$（正交相似变换），只改变第 $p,q$ 两行/两列。取 $\cot2\varphi=\dfrac{a_{pp}-a_{qq}}{2a_{pq}}$，旋转后 $a_{pq}^{(1)}=0$。每次选模最大的非对角元，迭代到 $\max_{i\ne j}|a_{ij}|<\varepsilon$；对角元即特征值，累积旋转矩阵 $V=U_1U_2\cdots$ 的列为特征向量。（✓ / △ / ×）
:::

**B3.** QR 迭代为什么能求全部特征值？收敛到什么？
::: sol
因为 $A_{k+1}=R_kQ_k=Q_k^{\mathrm T}A_kQ_k$，每步保持谱；成功分离块后，一阶块给实特征值，二阶块可给复共轭特征值。但基本无位移 QR 不保证任意矩阵收敛，$\begin{pmatrix}0&1\\1&0\end{pmatrix}$ 是停滞反例。实用算法先化 Hessenberg，再通过位移、结构化更新和降阶推进。（✓ / △ / ×）
:::

**C2.** 给定矩阵结构，怎么在幂法、Jacobi、QR 之间选？
::: sol
只要**一个**主特征值 → 幂法；要最接近某个 $p$ 的特征值 → 位移反幂法；**实对称**且要全部特征值/特征向量 → Jacobi；**一般实矩阵**要全部特征值 → 先拟上三角化再双步位移 QR。幂法/反幂法每步 $O(n^2)$ 且可解稀疏；Jacobi 破坏稀疏；QR 是中小型稠密矩阵的通用选择。（✓ / △ / ×）
:::
