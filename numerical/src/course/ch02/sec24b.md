# 2.4.2–2.4.4 Jacobi、Gauss–Seidel 与 SOR

上一节把线性迭代写成“用旧近似值算出新近似值”的统一形式。现在具体选择怎样更新每个分量。

Jacobi 方法在一轮更新中始终使用上一轮的数据；Gauss–Seidel 方法随算随用，立即采用本轮已经更新的分量；SOR 方法再引入一个参数调整更新幅度。下面分别推导公式，并检查它们的收敛条件。

<a id="sec-2.4.2"></a>
## 2.4.2 Jacobi 迭代

::: def 定义 2.4.2 · $A=L+D+U$ 三分与 Jacobi 迭代 {#def-2.4.2}
把 $A$ 分成对角部分 $D$、严格下三角部分 $L$ 和严格上三角部分 $U$。这里 $L$、$U$ 均不含对角线：

$$A=L+D+U,\qquad
L=\begin{bmatrix}0&&&\\ a_{21}&0&&\\ \vdots&\ddots&\ddots&\\ a_{n1}&\cdots&a_{n,n-1}&0\end{bmatrix},\
D=\operatorname{diag}(a_{11},\dots,a_{nn}),\
U=\begin{bmatrix}0&a_{12}&\cdots&a_{1n}\\&0&\cdots&a_{2n}\\&&\ddots&\vdots\\&&&0\end{bmatrix}$$

**Jacobi 的分裂**：$N=D$、$P=-(L+U)$。由于 $N$ 是对角阵，$N^{-1}$ 也是对角阵，用它左乘 $P$ 相当于“给 $P$ 的第 $i$ 行每个数都乘 $1/a_{ii}$”，于是

$$G_J=-D^{-1}(L+U),
\qquad
x_i^{(k+1)}=\frac{1}{a_{ii}}\left(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\right).$$

逐元素看，$G_{ij}=-a_{ij}/a_{ii}\ (j\ne i)$、$G_{ii}=0$，$\boldsymbol d=\big[\tfrac{b_1}{a_{11}},\dots,\tfrac{b_n}{a_{nn}}\big]^{\mathrm T}$。
:::

Jacobi 用**上一步的全部旧值**，可并行；每步一次矩阵-向量乘（或按行算）。

::: thm 定理 2.10 · Jacobi 收敛的充要条件 {#thm-2.10}
Jacobi 迭代收敛的充要条件是 $\rho(G_J)\lt1$。
:::

（这是 [@thm-2.8] 对 $G=G_J$ 的直接特化。）

::: thm 定理 2.11 · Jacobi 收敛的范数充分条件 {#thm-2.11}
若 $\lVert G_J\rVert\lt1$（某种范数），则 Jacobi 迭代收敛。
:::

（这是 [@thm-2.9] 对 $G=G_J$ 的直接特化。）

::: def 定义 2.4.5 · 严格对角占优 {#def-2.4.5}
若 $A$ 的主对角线按行（或按列）**严格占优**，即

$$|a_{ii}|\gt\sum_{j\ne i}|a_{ij}|\quad(\forall i,\ \text{行占优}),\qquad
|a_{jj}|\gt\sum_{i\ne j}|a_{ij}|\quad(\forall j,\ \text{列占优}),$$

分别称 $A$ 为严格行对角占优阵、严格列对角占优阵。
:::

::: lem 引理 2.1 · 严格对角占优 ⟹ 非奇异 {#lem-2.1}
若 $A$ 是主对角线按行（或按列）严格占优阵，即
$$
|a_{ii}|\gt\sum_{j\ne i}|a_{ij}|\quad(\forall i),
$$
则 $A$ 非奇异。
:::

::: proof 证明
反设 $A\boldsymbol x=0$ 有 $\boldsymbol x\ne0$，取 $|x_k|=\max_i|x_i|\gt0$，由第 $k$ 个方程
$$
|a_{kk}||x_k|=\left|\sum_{j\ne k}a_{kj}x_j\right|\le\sum_{j\ne k}|a_{kj}||x_k|
\lt|a_{kk}||x_k|,
$$
矛盾。$\blacksquare$
:::

::: method 引理的另一条证法 · 范数法
不用最大分量，改用[第一章的可逆性判据](../../ch01/sec13.md#sec-1.3.5)（[1.3.5](../../ch01/sec13.md#sec-1.3.5)：存在某个矩阵范数使 $\lVert B\rVert\lt1$ $\Rightarrow$ $I\pm B$ 可逆）：

1. **对角元非零**：严格占优保证每个 $|a_{ii}|$ 大于同行其余元素绝对值之和，故 $a_{ii}\ne0$，$D$ 可逆。于是（行占优情形，$D$ 提在左边）
   $$A=D+(L+U)=D\big[I+D^{-1}(L+U)\big];$$
2. **化归到 $I+B$**：$D$ 可逆，只需证 $I+B$（$B=D^{-1}(L+U)$）可逆；
3. **选范数**：$B=D^{-1}(L+U)$ 的第 $i$ 行为 $\big[\tfrac{a_{i1}}{a_{ii}},\dots,\widehat{0},\dots,\tfrac{a_{in}}{a_{ii}}\big]$（对角位置为零）。取 $\infty$-范数（最大行和）：
   $$\lVert B\rVert_\infty=\max_i\ \frac{1}{|a_{ii}|}\sum_{j\neq i}|a_{ij}|\lt1,$$
   每个比值恰好是“行占优”定义中的那个商：严格占优即每个比值都小于 1，故最大者仍小于 1。由可逆性判据，$I+B$ 可逆，$A=D(I+B)$ 可逆。

若 $A$ 严格按列对角占优，则写成 $A=\big[I+(L+U)D^{-1}\big]D$。右乘 $D^{-1}$ 把第 $j$ 列除以 $a_{jj}$，所以 $\lVert(L+U)D^{-1}\rVert_1<1$，同样得到可逆性。论证只用到绝对值和范数，对复矩阵也成立。
:::

::: thm 定理 2.12 · 严格对角占优 ⟹ Jacobi 收敛 {#thm-2.12}
若 $A$ 按行（或按列）严格对角占优，则 Jacobi 迭代收敛。
:::

::: proof 证明
由 [@lem-2.1]，$D$ 可逆；反设 $\rho(G_J)\ge1$，取特征值 $\mu$、$|\mu|\ge1$，则 $\det(\mu I-G_J)=0$。把 $\mu I-G_J$ 写成 $\mu D^{-1}[D+\mu^{-1}(L+U)]$，其行列式为零意味着 $D+\mu^{-1}(L+U)$ 奇异；但 $|\mu^{-1}|\le1$ 使该矩阵仍严格对角占优，矛盾。$\blacksquare$
:::

::: method 更短的一条路
行占优时不必绕特征值，直接算迭代矩阵的范数。$G_J$ 的第 $i$ 行为 $\big[-\tfrac{a_{i1}}{a_{ii}},\dots,\widehat{0},\dots,-\tfrac{a_{in}}{a_{ii}}\big]$，逐行求和（$\widehat{\cdot}$ 表示跳过对角元；回忆 $\lVert\cdot\rVert_\infty$ = 最大行和）：

$$\lVert G_J\rVert_\infty=\max_i\sum_{j=1}^n|G_{ij}|
=\max_i\frac{\sum_{j\neq i}|a_{ij}|}{|a_{ii}|}\lt1
\quad(\text{行占优}).$$

由 [@thm-2.9] 立即得到严格行对角占优时 Jacobi 收敛。严格列对角占优时也收敛，不过不能直接把行和范数的证明照搬过去；可以转而估计迭代矩阵的特征值。下面给出这两种情形的统一证明。
:::

::: note 对角占优不是稀罕矩阵
**应用背景**：热 / 扩散方程用 **Crank–Nicolson 格式**离散后，左端矩阵就是行对角占优的——“不是稀罕的矩阵，而是比较常见的”。这就是对角占优判据值得单独记的原因。
:::

## 2.4.3 Gauss–Seidel 迭代

::: def 定义 2.4.3 · Gauss–Seidel 迭代 {#def-2.4.3}
取 $N=L+D$、$P=-U$，则
$$
G_{GS}=-(L+D)^{-1}U,
\qquad
x_i^{(k+1)}=\frac{1}{a_{ii}}\left(b_i-\sum_{j\lt i}a_{ij}x_j^{(k+1)}-\sum_{j\gt i}a_{ij}x_j^{(k)}\right).
$$
:::

与 Jacobi 的唯一差别：**本轮已算出的新分量立刻投入使用**。形式上是隐式的，实际按 $i=1,\dots,n$ 一行一行显式计算。

::: method 「形式隐式、实际显式」的机理
困难在于 $(L+D)^{-1}$ **写不出显式**。两边乘 $N$、移项，转而利用 $D$ 好求逆这一点：

$$(L+D)x^{(k+1)}=-Ux^{(k)}+b
\ \Longrightarrow\
D x^{(k+1)}=-L\,x^{(k+1)}-U x^{(k)}+b .$$

“右边还有 $x^{(k+1)}$，你会觉得有问题——实际上我一写出来，你就发现没问题”：$-D^{-1}L$ 的**第一行全为零**，故 $x^{(k+1)}_1$ 完全由 $x^{(k)}$ 显式给出；第二行只含 $x^{(k+1)}_1$（已算出）；依此类推——**自上而下逐分量代入，全程显式**，“相当于追赶法（前代），不存在任何解方程的问题”。
:::

::: thm 定理 2.13 · GS 收敛的充要条件 {#thm-2.13}
GS 迭代收敛的充要条件是 $\rho(G_{GS})\lt1$。
:::

::: thm 定理 2.14 · GS 收敛的范数充分条件 {#thm-2.14}
若 $\lVert G_{GS}\rVert\lt1$（某种范数），则 GS 迭代收敛。
:::

::: thm 定理 2.15 · 严格对角占优 ⟹ GS 收敛 {#thm-2.15}
若 $A$ 按行（或按列）严格对角占优，则 GS 迭代收敛。
:::

::: thm 定理 2.16 · 对称正定 ⟹ GS 收敛 {#thm-2.16}
若 $A$ 对称正定，则 GS 迭代收敛。
:::

::: proof 证明要点
严格对角占优时，可以反设 $G_{GS}$ 有模不小于 $1$ 的特征值，再利用相应矩阵的对角占优性导出矛盾。对称正定时，则可以考察每次更新引起的二次型变化。两个证明使用的矩阵条件不同。
:::

| 2 | 0.196667 | 0.130667 | 0.486000 |
| 3 | 0.223333 | 0.143267 | 0.503289 |
| 4 | 0.229311 | 0.146191 | 0.507231 |
| 5 | 0.230684 | 0.146860 | 0.508135 |
| 6 | 0.230999 | 0.147013 | 0.508342 |

9 次迭代即达到 $10^{-5}$，比 Jacobi 的 16 次快。
:::

::: ex 例 10 · 没有一般优劣 {#ex-2.4-textbook10}
对例 7 的方程组，$G_{GS}$ 的特征值为 $0,-0.5,-0.5$，$\rho(G_{GS})=0.5\lt1$，故 GS 收敛——尽管 Jacobi 发散（例 7）。这说明“GS 一定比 Jacobi 好/坏”都不对，必须看具体矩阵。
:::

::: note Jacobi 与 GS：无一般优劣
Jacobi 与 Gauss–Seidel 没有对所有矩阵都成立的快慢或收敛性排序。二者可能同时收敛，也可能只有一个收敛；[例 10](#ex-2.4-textbook10) 给出了后一种情形。比较具体问题时，应分别考察迭代矩阵的谱半径。
:::

## 2.4.4 逐次超松弛（SOR）

::: def 定义 2.4.4 · 逐次超松弛（SOR） {#def-2.4.4}
把 GS 的增量乘上松弛因子 $\omega$：

$$
x_i^{(k+1)}=(1-\omega)x_i^{(k)}
+\frac{\omega}{a_{ii}}\left(b_i-\sum_{j\lt i}a_{ij}x_j^{(k+1)}-\sum_{j\gt i}a_{ij}x_j^{(k)}\right).
$$

矩阵形式：$N=L+\omega^{-1}D$、$P=(\omega^{-1}-1)D-U$，
$$
G_S=N^{-1}P.
$$
$\omega=1$ 退化为 GS；$0\lt\omega\lt1$ 为低松弛，$1\lt\omega\lt2$ 为超松弛。
:::

::: method SOR 的构造：把对角部分按参数分配
GS 的 $P$ 里完全没有对角成分，SOR 的构造正从这里入手——“现在我引入一个参数，把这个对角部分**分配**到 $N$ 和 $P$ 两部分”。取松弛因子 $\omega\neq0$，把 $D$ 拆成 $\omega^{-1}D$ 与 $(1-\omega^{-1})D$ 两份：

$$N=L+\omega^{-1}D\ (\text{下三角，对角元 }\omega^{-1}a_{ii}),\qquad
P=N-A=(\omega^{-1}-1)D-U=-\big[(1-\omega^{-1})D+U\big].$$

检验：$N-P=L+\omega^{-1}D+(1-\omega^{-1})D+U=L+D+U=A$ ✓。迭代矩阵

$$G=N^{-1}P=-\big(L+\omega^{-1}D\big)^{-1}\big[(1-\omega^{-1})D+U\big].$$

代入松弛参数后，还要把含 $x_i^{(k+1)}$ 的项移到等号左边，得到可以逐行计算的显式公式。
:::

::: method 显示化：移项 + 两边乘 $\omega D^{-1}$
$N=L+\omega^{-1}D$ 是下三角，$N^{-1}$ **写不出显式**（对比 Jacobi 的 $N=D$），于是回到 $N\boldsymbol x^{(k+1)}=P\boldsymbol x^{(k)}+\boldsymbol b$ 再变形：

$$\big(L+\omega^{-1}D\big)\,\boldsymbol x^{(k+1)}=-\big[(1-\omega^{-1})D+U\big]\boldsymbol x^{(k)}+\boldsymbol b .$$

将各项整理后得到下面的逐分量更新式。计算第 $i$ 个分量时，前 $i-1$ 个分量使用本轮的新值，其余分量使用上一轮的旧值：

$$\boxed{\ \boldsymbol x^{(k+1)}=(1-\omega)\,\boldsymbol x^{(k)}-\omega D^{-1}L\,\boldsymbol x^{(k+1)}-\omega D^{-1}U\,\boldsymbol x^{(k)}+\omega D^{-1}\boldsymbol b\ }$$

右边出现 $\boldsymbol x^{(k+1)}$，“你表面上看起来……好像是一个隐式的格式，但实际上它是个**显式**的格式”。理由与 GS 完全相同（逐行论证）：作用于 $\boldsymbol x^{(k+1)}$ 的只有 $-\omega D^{-1}L$——对角阵左乘下三角相当于每行乘一个常数，**不改变三角结构**，故 $-\omega D^{-1}L$ 仍是对角为零的严格下三角；作用于 $\boldsymbol x^{(k)}$ 的 $(1-\omega)I-\omega D^{-1}U$ 则是对角为 $1-\omega$ 的上三角。**第一个方程**：$x^{(k+1)}_1$ 前的系数全为零，右端只含 $\boldsymbol x^{(k)}$ 的分量——显式；**第二个方程**：右端只含 $x^{(k+1)}_1$（刚算出）与 $\boldsymbol x^{(k)}$ 的分量——显式；依此类推，“一行一行就在解”，全程显式。分量形式即本节开头的公式。

读法：括号内恰是 Gauss–Seidel 的修正量，外层用 $\omega$ 加权后与旧值的 $(1-\omega)$ 倍做线性组合——这就是“逐次超松弛”这个名字的来源。
:::

::: note $\omega=1$：SOR 就是 Gauss–Seidel
对比两个分裂：GS 的 $P$ 完全不含对角，SOR 的 $P$ 里则含带参数的对角部分 $(1-\omega^{-1})D$。“我只要把这个 $\omega$ 取成 $1$，整个对角部分就没了”：

$$\omega=1\ \Longrightarrow\ N=L+D,\ P=-U\ \Longrightarrow\ \text{SOR 就是 Gauss–Seidel}.$$

令 $\omega=1$，SOR 的更新式就退化为 Gauss–Seidel。因此，满足相应条件的 SOR 收敛结论，也包含了 Gauss–Seidel 的结论。
:::

::: thm 定理 2.17 · SOR 收敛的充要条件 {#thm-2.17}
SOR 收敛的充要条件是 $\rho(G_S)\lt1$。
:::

::: thm 定理 2.18 · SOR 收敛的范数充分条件 {#thm-2.18}
若 $\lVert G_S\rVert\lt1$，则 SOR 收敛。
:::

::: thm 定理 2.19 · 收敛的必要条件 {#thm-2.19}
SOR 收敛 $\Rightarrow 0\lt\omega\lt2$。
:::

::: proof 证明
**链条**：格式收敛 $\iff\rho(G)\lt1$（[@thm-2.8]）$\Longrightarrow$ $|\det G|\lt1$（行列式 = 全体特征值之积）。而 $G=N^{-1}P$，故

$$\det G=\det(N^{-1})\det P=\frac{\det P}{\det N}.$$

两个行列式都能**直接算**（三角阵行列式 = 对角元之积）：

$$\det N=\prod_{i=1}^n\frac{a_{ii}}{\omega}=\omega^{-n}\prod_{i=1}^n a_{ii},\qquad
|\det P|=\Big|1-\frac1\omega\Big|^n\prod_{i=1}^n|a_{ii}| ,$$

相除，$\prod|a_{ii}|$ 全部消去：

$$|\det G|=\frac{|1-\omega^{-1}|^n}{\omega^{-n}}=|\,\omega-1\,|^n .$$

于是收敛 $\Rightarrow|\omega-1|^n\lt1\Rightarrow|\omega-1|\lt1$，即 $0\lt\omega\lt2$。$\blacksquare$
:::

::: note 必要 $\ne$ 充分
“$\omega$ 这个参数还是**不能乱取**的”；“我不能保证在 0 到 2 这个范围之内它一定收敛，但我可以保证它在 0 到 2 **之外**一定不收敛”。原因：$\omega\in(0,2)$ 只保证 $|\det G|\lt1$（特征值之积的模小），**不能**保证每个特征值的模都小于 1——积小可以来自“一个大一个小”。
:::

::: thm 定理 2.20 · 充分条件①：对角占优 + $0\lt\omega\le1$ {#thm-2.20}
若 $A$ 按行（或按列）严格对角占优，且 $0\lt\omega\le1$，则 SOR 收敛。
:::

::: proof 证明
要证 $\rho(G)\lt1$，即 $G$ 的每个特征值的模都小于 1。反设存在特征值 $\mu$ 满足 $|\mu|\ge1$，由此推出矛盾。

**(1) 特征值 ⟹ 奇异。**$G\boldsymbol x=\mu\boldsymbol x$（$\boldsymbol x\ne0$ 为特征向量）⟹ $(\mu I-G)\boldsymbol x=0$ 有非零解 ⟹ $\mu I-G$ 不满秩 ⟹ $\det(\mu I-G)=0$。目标是证明在定理条件下这个行列式**不可能**为零。

**(2) 两边乘 $N$、提因子。**$\mu I-G=\mu I+N^{-1}[(1-\omega^{-1})D+U]$，两边左乘可逆的 $N=L+\omega^{-1}D$（对角占优 ⟹ 对角元非零 ⟹ 下三角可逆），奇异性不变：

$$\det\big[\mu(L+\omega^{-1}D)+(1-\omega^{-1})D+U\big]=0 .$$

把公共因子 $\mu$ 提到括号外（括号内其余两项相应乘 $\mu^{-1}$），再合并对角系数并做恒等变形（凑成便于下一步估计模的形状）：

$$\mu\big[\,\underbrace{L}_{\text{不变}}+\ \underbrace{c\,D}_{\text{对角}}\ +\ \underbrace{\mu^{-1}U}_{\text{上三角}}\,\big]=0,
\qquad c=\omega^{-1}+\mu^{-1}\big(1-\omega^{-1}\big)=1+\big(\omega^{-1}-1\big)\big(1-\mu^{-1}\big).$$

$\mu\neq0$，故 $\det[L+cD+\mu^{-1}U]=0$。

**(3) 常数 $c$ 的模 $\ge1$。**写 $\mu=re^{\mathrm i\theta}$（$r=|\mu|\ge1$），用欧拉公式 $e^{-\mathrm i\theta}=\cos\theta-\mathrm i\sin\theta$ 分出实部、虚部：

$$c=1+(\omega^{-1}-1)\big(1-r^{-1}e^{-\mathrm i\theta}\big),
\qquad
\operatorname{Re}c=1+(\omega^{-1}-1)\big(1-r^{-1}\cos\theta\big),$$

$$\operatorname{Im}c=(\omega^{-1}-1)\,r^{-1}\sin\theta .$$

逐项看符号：$\omega\le1\Rightarrow\omega^{-1}-1\ge0$；$r\ge1\Rightarrow r^{-1}\le1\Rightarrow1-r^{-1}\cos\theta\ge1-r^{-1}\ge0$。故 $\operatorname{Re}c\ge1$，于是

$$|c|\ \ge\ \operatorname{Re}c\ \ge\ 1 .$$

（口述：“实部都是大于等于一的，那它加一个虚部，这个数的模长肯定是大于等于一的”。）

**(4) 三个部分的对角占优被强化 ⟹ 矛盾。**看矩阵 $L+cD+\mu^{-1}U$：

| 部分 | 变化 |
|:--|:--|
| 对角 $D$ | 每个对角元乘上 $c$，$\lvert c\rvert\ge1$——**放大** |
| 严格下三角 $L$ | 不变 |
| 严格上三角 $U$ | 每个元乘 $\mu^{-1}$，$\lvert\mu^{-1}\rvert=r^{-1}\le1$——**缩小** |

原矩阵 $A$ 本来严格对角占优（对角元大于同行其余元素绝对值之和）；现在“对角又放大了、其他地方又缩小了”——**更是**严格对角占优。由 [@lem-2.1]（范数证法按模比较，在复矩阵上原样成立），该矩阵必可逆，$\det[L+cD+\mu^{-1}U]\ne0$，与 (2) 矛盾。$\blacksquare$
:::

::: note 证明的两个火候
证明的关键是比较各部分的缩放：对角元的模是否增大，非对角元的模是否减小，从而保留严格对角占优。$\omega=0$ 时更新不推进，且上述含 $\omega^{-1}$ 的证明不适用；$\omega=1$ 时 $c=1$，上三角部分的缩放因子 $|\mu^{-1}|\le1$，论证仍成立。因此参数范围包含 $1$，但不包含 $0$。
:::

::: thm 定理 2.21 · Ostrowski 定理（充分条件②） {#thm-2.21}
若 $A$ 对称正定，则 $0\lt\omega\lt2$ 时 SOR 收敛；$\omega\notin(0,2)$ 时发散。
:::

::: note 对称正定矩阵上的 SOR
对于对称正定矩阵，SOR 收敛的充要条件是 $0<\omega<2$。因此可以在 $\omega>1$ 的范围内尝试超松弛。这个区间保证收敛，但具体哪个参数更快，仍取决于矩阵。
:::

::: method[core] SOR 收敛条件

下面把谱半径判据、一般矩阵的必要条件，以及两类特殊矩阵的充分条件放在一起。使用时先检查矩阵满足哪一类假设。

| 结论 | 条件 | 结论内容 | 定理 |
|:--|:--|:--|:--:|
| **充要**（基本定理） | 无（对迭代矩阵本身） | SOR 收敛 $\iff\rho(G_S)\lt1$ | 定理 2.17 |
| **必要** | SOR 收敛（对一般 $A$） | $\Longrightarrow 0\lt\omega\lt2$ | 定理 2.19 |
| **充分①** | $A$ 严格对角占优 + $0\lt\omega\le1$ | $\Longrightarrow$ SOR 收敛 | 定理 2.20 |
| **充分②**（Ostrowski） | $A$ 对称正定 + $0\lt\omega\lt2$ | $\Longleftrightarrow$ SOR 收敛 | 定理 2.21 |

对一般矩阵，$\omega\notin(0,2)$ 可以排除“对任意初值收敛”，而 $\omega\in(0,2)$ 本身还不能保证收敛。严格对角占优与对称正定是两类不同的充分条件；它们的适用参数范围也不同。若这些条件都不满足，可以直接计算或估计 $\rho(G_S)$。当 $\omega=1$ 时，两个充分条件都给出相应的 Gauss–Seidel 收敛结论。
:::

::: ex 例 11 · $\omega=1.25$ 的加速 {#ex-2.4-textbook11}
用 $\omega=1.25$ 求解
$$
\begin{cases}
4x_1+3x_2=16,\\
3x_1+4x_2-x_3=20,\\
-x_2+4x_3=-12.
\end{cases}
$$
系数矩阵 $A$ 对称正定，故由 Ostrowski 定理，$0\lt\omega\lt2$ 时 SOR 收敛。取 $x^{(0)}=0$，迭代到 $\lVert x^{(k)}-x^{(k-1)}\rVert_\infty\lt0.00005$：

| $k$ | $x_1^{(k)}$ | $x_2^{(k)}$ | $x_3^{(k)}$ |
|:--:|:--:|:--:|:--:|
| 0 | 0 | 0 | 0 |
| 1 | 5.00000 | 1.56250 | -3.26172 |
| 2 | 2.28516 | 2.69775 | -2.09152 |
| 3 | 1.89957 | 2.77963 | -2.35849 |
| 4 | 1.91920 | 3.01881 | -2.21700 |
| 5 | 1.69007 | 3.21804 | -2.19011 |
| 6 | 1.56057 | 3.29805 | -2.17183 |
| 7 | 1.51794 | 3.32372 | -2.16838 |
| 8 | 1.50453 | 3.33095 | -2.16698 |
| 9 | 1.50110 | 3.33280 | -2.16676 |
| 10 | 1.50023 | 3.33322 | -2.16668 |

解约 $(1.50001,3.33333,-2.16667)^{\mathrm T}$。同样精度 GS（$\omega=1$）需 22 次；合适 $\omega$ 能加速，但最优 $\omega$ 通常不知道，实际靠试算。

::: preview 下一讲起点 · 特征值问题开篇
求矩阵特征值的算法“看起来简单，到现在历史还是蛮长的”。源头是**定态薛定谔方程**的能级计算：哈密顿算子 = 动能项（$-\frac{\hbar^2}{2m}\nabla^2$，拉普拉斯算子）+ 势能项 $V$；复杂（多粒子）系统必须离散化数值求解：

$$\text{微分算子}\ \xrightarrow{\ \text{离散}\ }\ \text{矩阵},\qquad
\text{能级}= \text{特征值}，\qquad
\text{本征态（波函数）}= \text{特征向量}.$$

多粒子系统维度极高，至今**没有一般性的方法**能高效算出全部特征对；本课程只研究一件事：求**按模最大**的特征值及其特征向量（幂法及其加速，从下一讲展开）。
:::

<a id="sec-2.4-comparison"></a>
## 三种方法的对比

::: method[core] 一张表看三种分裂

| 方法 | 分裂 $N$ / $P$ | 每步信息 | 收敛判据 | 备注 |
|:--|:--|:--|:--|:--|
| Jacobi | $N=D$，$P=-(L+U)$ | 全部旧值 | $\rho(G_J)\lt1$；DD 充分 | 可并行 |
| Gauss–Seidel | $N=L+D$，$P=-U$ | 新分量立刻用 | $\rho(G_{GS})\lt1$；DD/SPD 充分 | 通常更快，但非绝对 |
| SOR | $N=L+\omega^{-1}D$，$P=(\omega^{-1}-1)D-U$ | 新分量 + 松弛 | $\rho(G_S)\lt1$；$0\lt\omega\lt2$ 必要 | $\omega=1$ 退化为 GS |
:::

**选择顺序**：先看结构（三对角/稀疏/对角占优/对称正定），再选方法；不要一上来就 SOR。对大规模稀疏问题，现代做法是 Krylov 方法 + 预条件（补充篇/后续课程），但经典迭代仍是理解分裂与谱半径的入口。

::: method[core] 本节概念速查
| 概念 | 一句话 | 本节出现位置 | 将在何处深入 |
|:--|:--|:--|:--|
| $A=L+D+U$ 三分 | $L$、$U$ 均不含对角线 | [@def-2.4.2] | [2.4.1](sec24.md#sec-2.4.1) 分裂框架 [@def-2.4.1] |
| Jacobi | $N=D$，全用旧值，可并行 | [@def-2.4.2] | Krylov 方法（后续课程） |
| Gauss–Seidel | $N=L+D$，新分量立刻用 | [@def-2.4.3] | 逐行代入“相当于追赶法的前代”（[2.2](sec22.md#sec-2.2.4)） |
| SOR | $N=L+\omega^{-1}D$；$\omega=1$ 退化 GS | [2.4.4](#sec-2.4.4) | [@thm-2.21] Ostrowski |
| 严格对角占优 | $\lvert a_{ii}\rvert\gt\sum_{j\ne i}\lvert a_{ij}\rvert$ | [@def-2.4.5] | [@lem-2.1] 非奇异；[@thm-2.12]、[@thm-2.15]、[@thm-2.20] |
| 谱半径判据 | $\rho(G)\lt1$ 是充要条件 | [@thm-2.10] | [2.4.1](sec24.md#sec-2.4.1) [@thm-2.8] |
| SOR 收敛条件 | $0<\omega<2$ 是必要条件；严格对角占优时 $0<\omega\le1$ 可保证收敛；对称正定时 $0<\omega<2$ 可保证收敛 | [条件对照](#sec-2.4.4) | 使用前核对矩阵性质及参数范围 |
:::

::: think 本节常见错误
1. **背反分裂。**“拆法即名字”：Jacobi 按对角 / 非对角拆（$N=D$），Seidel 按上 / 下三角拆（$N=L+D$），SOR 把对角按 $\omega^{-1}:(1-\omega^{-1})$ 分配（$N=L+\omega^{-1}D$）。
2. **以为 GS 一定比 Jacobi 好。**无一般优劣：可能都收敛、都不收敛、或一收一散（[例 10](#ex-2.4-textbook10)）。
3. **SOR 的 $\omega$ 乱取。**$\omega\notin(0,2)$ 必发散（必要，[@thm-2.19]）；$\omega\in(0,2)$ 不保证收敛（必要不充分）；$\omega\gt1$ 的加速要靠对称正定保驾（[@thm-2.21]）。
4. **把对角占优当对称正定。**严格对角占优与对称正定是不同的条件，不能相互替代。使用前者时，本节给出的保证范围是 $0<\omega\le1$；使用后者时，范围是 $0<\omega<2$。
5. **把 GS / SOR 当隐式格式去“解方程”。**形式隐式、实际显式：$x^{(k+1)}$ 前只挂严格下三角，一行一行往下算。
:::

<a id="sec-2.4b-exercises"></a>
## 习题

::: ex 2.15 · Jacobi 解方程组 {#exercise-2.15}
对方程组 $4x_1-x_2=3$、$-x_1+3x_2=2$，从 $(0,0)^{\mathrm T}$ 开始作 Jacobi 迭代。使用后验界保证无穷范数误差不超过 $10^{-4}$，并核对精确解。
:::

::: sol 参考答案
迭代为 $x_1^{(k+1)}=(3+x_2^{(k)})/4$、$x_2^{(k+1)}=(2+x_1^{(k)})/3$。矩阵严格对角占优，且 $q=\lVert G_J\rVert_\infty=1/3$。后验界为 $\lVert\boldsymbol e_k\rVert_\infty\le\frac12\lVert\boldsymbol x^{(k)}-\boldsymbol x^{(k-1)}\rVert_\infty$，故相邻差不超过 $2\times10^{-4}$ 即可。精确解为 $(1,1)^{\mathrm T}$。
:::

::: ex 2.16 · Jacobi 收敛性讨论 {#exercise-2.16}
对以下四个矩阵，分别判断 Jacobi 是否对任意初值收敛：
$$A_1=\begin{pmatrix}2&1\\1&2\end{pmatrix},\quad A_2=\begin{pmatrix}1&2\\2&1\end{pmatrix},\quad A_3=\begin{pmatrix}1&1\\1&1\end{pmatrix},\quad A_4=\begin{pmatrix}1&2\\0&1\end{pmatrix}.$$
对 $A_3$ 讨论的是收敛到唯一不动点的性质，不预先假定方程组有唯一解。
:::

::: sol 参考答案
四个 Jacobi 迭代矩阵的谱半径依次为 $1/2,2,1,0$。因此 $A_1,A_4$ 的迭代对任意初值收敛到唯一解；$A_2,A_3$ 不具有这一保证。$A_4$ 的迭代矩阵虽然无穷范数为 $2$，但平方为零，可在有限步消除初始误差。
:::

::: ex 2.17 · Gauss–Seidel 解第 15 题 {#exercise-2.17}
用 Gauss–Seidel 法解第 2.15 题的方程组，初值仍为 $(0,0)^{\mathrm T}$。求 $q=\lVert G_{GS}\rVert_\infty$，并给出保证误差不超过 $10^{-4}$ 的停止条件。
:::

::: sol 参考答案
按顺序更新 $x_1^{(k+1)}=(3+x_2^{(k)})/4$、$x_2^{(k+1)}=(2+x_1^{(k+1)})/3$。迭代矩阵为 $\begin{pmatrix}0&1/4\\0&1/12\end{pmatrix}$，所以 $q=1/4$，后验因子为 $q/(1-q)=1/3$。相邻差不超过 $3\times10^{-4}$ 即可。该例的谱半径 $1/12$ 小于 Jacobi 的 $1/\sqrt{12}$；这个比较只针对本题。
:::

::: ex 2.18 · GS 收敛性讨论 {#exercise-2.18}
对第 2.16 题的四个矩阵，判断 Gauss–Seidel 的收敛性，并与 Jacobi 比较。
:::

::: sol 参考答案
四个 Gauss–Seidel 迭代矩阵的谱半径依次为 $1/4,4,1,0$，所以与第 2.16 题的分类相同。这是 $2\times2$ 矩阵的特殊关系 $\rho(G_{GS})=\rho(G_J)^2$；不能据此推断任意阶矩阵都同时收敛。
:::

::: ex 2.19 · 构造必收敛的迭代 {#exercise-2.19}
对 $4x_1+x_2=5$、$x_1+3x_2=4$，构造一个对任意初值收敛的迭代，并说明理由。
:::

::: sol 参考答案
取 Jacobi 迭代 $x_1^{(k+1)}=(5-x_2^{(k)})/4$、$x_2^{(k+1)}=(4-x_1^{(k)})/3$。迭代矩阵的无穷范数为 $1/3<1$，故对任意初值收敛到唯一解 $(1,1)^{\mathrm T}$。
:::

::: ex 2.20 · 2×2 的 Jacobi 与 GS {#exercise-2.20}
设 $A$ 是 $2\times2$ 且 $a_{11},a_{22}\ne0$，证明 Jacobi 与 GS 同时收敛或同时发散。
:::

::: sol 参考答案
对 $2\times2$，$G_J$ 的特征值是 $\pm\sqrt{a_{12}a_{21}/(a_{11}a_{22})}$，$G_{GS}$ 的特征值是 $0$ 与 $a_{12}a_{21}/(a_{11}a_{22})$；故 $\rho(G_{GS})=\rho(G_J)^2$，同时小于 1 或同时不小于 1。
:::

::: ex 2.21 · 含参数 a 的收敛范围 {#exercise-2.21}
设 $A(a)=\begin{pmatrix}1&a\\a&1\end{pmatrix}$，$a\in\mathbb R$。分别求 Jacobi 与 Gauss–Seidel 对任意初值收敛到唯一解的参数范围。
:::

::: sol 参考答案
Jacobi 迭代矩阵特征值为 $a,-a$，Gauss–Seidel 的特征值为 $0,a^2$。因此两种方法都恰在 $|a|<1$ 时具有要求的收敛性。端点 $a=\pm1$ 处矩阵奇异，不能保留在这个参数区间中。
:::

::: ex 2.22 · 直接判定 GS {#exercise-2.22}
设 $A=\begin{pmatrix}4&-1&0\\-1&4&-1\\0&-1&4\end{pmatrix}$。不计算迭代矩阵的特征值，证明 Gauss–Seidel 法对任意右端与初值收敛。
:::

::: sol 参考答案
$A$ 的每行主对角元绝对值都严格大于其余元素绝对值之和，因此严格对角占优。直接由 [@thm-2.15] 得到收敛。也可证明它对称正定，再用 [@thm-2.16]。
:::

::: ex 2.23 · SOR（ω=0.9） {#exercise-2.23}
用 SOR（$\omega=0.9$）求解第 2.15 题的方程组，从 $(0,0)^{\mathrm T}$ 开始。说明为何收敛，并以原方程残差的无穷范数不超过 $10^{-4}$ 为停止条件。
:::

::: sol 参考答案
$A=\begin{pmatrix}4&-1\\-1&3\end{pmatrix}$ 对称，且顺序主子式为 $4,11>0$，所以对称正定。由于 $0<0.9<2$，SOR 收敛。更新为
$$x_1^{(k+1)}=(1-\omega)x_1^{(k)}+\frac\omega4(3+x_2^{(k)}),$$
$$x_2^{(k+1)}=(1-\omega)x_2^{(k)}+\frac\omega3(2+x_1^{(k+1)}).$$
每轮计算 $\max(|3-4x_1+x_2|,|2+x_1-3x_2|)$，满足要求后停止。精确解为 $(1,1)^{\mathrm T}$；若要求解误差保证，还可使用 $\lVert A^{-1}\rVert_\infty=5/11$ 将残差界换算为误差界。
:::

::: ex 2.24 · SOR（ω=1.25） {#exercise-2.24}
用 SOR（$\omega=1.25$）求解第 2.15 题的方程组，从 $(0,0)^{\mathrm T}$ 开始。说明为何收敛，并以原方程残差的无穷范数不超过 $10^{-5}$ 为停止条件。
:::

::: sol 参考答案
$A=\begin{pmatrix}4&-1\\-1&3\end{pmatrix}$ 对称，且顺序主子式为 $4,11>0$，所以对称正定。由于 $0<1.25<2$，SOR 收敛。更新为
$$x_1^{(k+1)}=(1-\omega)x_1^{(k)}+\frac\omega4(3+x_2^{(k)}),$$
$$x_2^{(k+1)}=(1-\omega)x_2^{(k)}+\frac\omega3(2+x_1^{(k+1)}).$$
每轮计算 $\max(|3-4x_1+x_2|,|2+x_1-3x_2|)$，满足要求后停止。精确解为 $(1,1)^{\mathrm T}$；若要求解误差保证，还可使用 $\lVert A^{-1}\rVert_\infty=5/11$ 将残差界换算为误差界。
:::
