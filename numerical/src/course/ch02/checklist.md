# 第 2 章学习目标自检表

> 用法：逐条自评，**能不看书写出做法**才打勾；只会「见过」不算。
> 与[闭卷回忆卡](recall-cards.md)配合：卡是「记不记得」，本表是「用不用得对」。

## K · 知识（能说出是什么）

| 编号 | 目标 | 自检标准 | ✓ |
|:--|:--|:--|:--|
| K2.1 | 说出顺序 Gauss 消去的充要条件 | 前 $n-1$ 个顺序主子式非零保证消元可进行；还需 $D_n\ne0$ 才能回代得到唯一解 | ☐ |
| K2.2 | 解释列主元为什么必要 | 能举出零主元或小主元的例子，说明换行如何避免除零或控制乘数 | ☐ |
| K2.3 | 写出 Doolittle 分解 | $A=LU$ 中 $L$ 为单位下三角、$U$ 为上三角；Crout 的单位对角线则在 $U$ | ☐ |
| K2.4 | 说明追赶法为什么是 $O(n)$ | 只用三个递推式扫一遍三对角带，不需要存储 $L,U$ | ☐ |
| K2.5 | 写出条件数的定义 | $\mathrm{cond}(A)=\lVert A\rVert\lVert A^{-1}\rVert$，并说明它是**问题**的属性 | ☐ |
| K2.6 | 写出迭代法收敛的充要条件 | 对任意初值收敛到同一解当且仅当迭代矩阵的谱半径 $\rho(G)<1$ | ☐ |
| K2.7 | 说明 Jacobi / GS / SOR 的关系 | 三者迭代矩阵不同；SOR 是 GS 的推广，$\omega=1$ 时退化为 GS | ☐ |
| K2.8 | 说出 SOR 收敛的必要条件 | $0<\omega<2$ | ☐ |

## 一句话自检

> 如果只能记住一件事：**先问「解有多可信」（条件数），再问「怎么算」（算法）**。
