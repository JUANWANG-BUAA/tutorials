# 2.2 直接三角分解

> 对应教材 2.2.1–2.2.5、定理 2.3–2.5、例 2–3、习题 4–8；对应老师第 4 讲 §二–§四。
> 主线：把“消元”写成“分解” $A=LU$，一次分解、反复使用；三对角结构再把 $O(n^3)$ 降到 $O(n)$。

<a id="sec-2.2.1"></a>
## 2.2.1 Doolittle 分解与 Crout 分解

::: method LU 分解从哪来：消去过程的矩阵化（老师第 4 讲 §一）
高斯消去的第 $k$ 步，相当于给矩阵左乘一个初等矩阵 $P_k$——它是主对角线为 1 的下三角阵，第 $k$ 列对角线以下的元素依次为该步的消元乘数：

$$P_k=\begin{pmatrix}1&&&&\\&\ddots&&&\\&l_{k+1,k}&1&&\\&l_{k+2,k}&&\ddots&\\&l_{nk}&&&1\end{pmatrix},
\qquad l_{ik}=-\frac{a_{ik}}{a_{kk}}\ (i>k),$$

$P_1$ 的显式形式是：第 1 列对角线以下依次为 $-\frac{a_{21}}{a_{11}},-\frac{a_{31}}{a_{11}},\dots$。消去 $n-1$ 步之后

$$(P_{n-1}\cdots P_1)A=U,\qquad\text{记 } P=P_{n-1}\cdots P_1\ \Rightarrow\ A=P^{-1}U .$$

这就是 LU 分解的形状：**消元的信息一点没丢，全装进 $L:=P^{-1}$ 里**。
:::

::: lem 引理 2.2.1（课堂补充）· 单位下三角阵的封闭性 {#lem-2.2.1}
单位下三角阵的乘积与逆仍是单位下三角阵。
:::

::: proof 证明
乘积情形直接：两个单位下三角阵相乘，对角线仍是 $1$，对角线以上仍是 $0$。逆的情形：单位下三角阵 $L=I+N$（$N$ 严格下三角，$N^n=0$），$(I+N)^{-1}=I-N+N^2-\cdots+(-N)^{n-1}$ 是有限和，仍是对角线为 1 的下三角阵。$\blacksquare$
:::

于是 $P$ 可逆，且 $L:=P^{-1}$ 也是单位下三角阵（对角线为 1，元素恰为消元乘数的相反数）。

::: def 定义 2.2.1 · Doolittle 分解 {#def-2.2.1}
设 $A$ 非奇异，且前 $n-1$ 个顺序主子式不为零。把 $A$ 分解为

$$A=LU,$$

其中 $L$ 是单位下三角矩阵（对角元为 1），$U$ 是上三角矩阵，称为 $A$ 的 **Doolittle 分解**（直接三角分解）。
:::

逐圈公式（教材式 2.12）——按“第 1 行 $U$ → 第 1 列 $L$ → 第 2 行 $U$ → 第 2 列 $L$ → …”的顺序逐圈解出：

$$
u_{kj}=a_{kj}-\sum_{s=1}^{k-1}l_{ks}u_{sj}\quad(j=k,\dots,n),
\qquad
l_{ik}=\frac{a_{ik}-\sum_{s=1}^{k-1}l_{is}u_{sk}}{u_{kk}}\quad(i=k+1,\dots,n).
$$

关键在于安排计算顺序，使每个方程只含**一个**未知数，从而避开未知数相乘带来的非线性项（[例 2.2.2](#ex-2.2.2) 完整走一遍）。

解方程组分两步：先解 $L\boldsymbol y=\boldsymbol b$（**前代**），再解 $U\boldsymbol x=\boldsymbol y$（**回代**）：

$$y_i=b_i-\sum_{j=1}^{i-1}l_{ij}y_j\quad(i=1,\dots,n),\qquad
x_i=\frac{y_i-\sum_{j=i+1}^n u_{ij}x_j}{u_{ii}}\quad(i=n,\dots,1).$$

::: note 名词考古：「追赶法」的广义与狭义（老师第 4 讲 §二）
老师口中的“追赶法”有时**泛指**前代（“追”）与回代（“赶”）这一对过程；狭义的**追赶法**专指求解三对角方程组的 Thomas 算法（见 [2.2.4](#sec-2.2.4)）。读到“追赶”二字，先分辨是哪一种。
:::

::: note 一次分解，反复使用（老师第 4 讲 §二、§六强调）
LU 分解的价值：多组右端 $\boldsymbol b^{(1)},\boldsymbol b^{(2)},\dots$ **共享同一组 $L,U$**，对每组右端只需做一次前代和一次回代（各 $O(n^2)$），分解的 $O(n^3)$ 只付一次。这就是“把消元写成分解”的全部理由。
:::

::: def 定义 2.2.2 · Crout 分解 {#def-2.2.2}
**Crout 分解**：$A=LU$，其中 $L$ 是下三角矩阵（对角元不一定是 1），$U$ 是单位上三角矩阵。教材给出推论：与 Doolittle 分解存在唯一性等价；两者只差一个对角缩放。
:::

::: note 存在性用“⇒”、唯一性用“⇔”（老师第 4 讲 §三板书注意）
老师板书的 LU 存在性定理表述为“若前 $n-1$ 个顺序主子式不为 0，**则** $A=LU$”——单向 **⇒**；而高斯消去的充要条件（[@thm-2.1]）用的是 **⟺**。两者不矛盾：⇒ 方向给出“能分解”，而“唯一 Doolittle 分解”才谈得上充要（[@thm-2.3] 的 ⟸ 方向由 $D_k=u_{11}\cdots u_{kk}$ 得到）。考前别把这两个措辞搞混。
:::

::: thm 定理 2.3 · 唯一 Doolittle 分解的充要条件 {#thm-2.3}
$n\ge2$ 阶矩阵 $A$ 有唯一 Doolittle 分解的充要条件是前 $n-1$ 个顺序主子式 $D_k\ne0\ (k=1,\dots,n-1)$。
:::

::: proof 证明
充分性由 [@thm-2.1] 的顺序消去得到 $P_{n-1}\cdots P_1A=U$，取 $L=P_1^{-1}\cdots P_{n-1}^{-1}$（引理 [@lem-2.2.1] 保证它是单位下三角）；必要性由 $A_k=L_kU_k$ 得 $D_k=u_{11}\cdots u_{kk}$，若某个 $u_{kk}=0$ 则分解不唯一。$\blacksquare$
:::

::: note 随机矩阵几乎必然非奇异（老师第 4 讲 §二题外话、§六强调）
实际遇到的矩阵几乎不必担心“分解不存在”：三个随机向量几乎不可能共面，所以**随机矩阵几乎必然非奇异**，前 $n-1$ 个顺序主子式也几乎必然非零——可以放心使用分解算法。真正要防的是 $u_{kk}\approx0$ 的“差一点奇异”（见 [2.2.2](#sec-2.2.2) 选主元）。
:::

::: ex 例 2（教材 2.2.1，四位十进制） · 逐圈分解一个 3×3 方程组 {#ex-2.2-textbook2}
方程组
$$
\begin{cases}
8.1x_1+2.3x_2-1.5x_3=6.1,\\
0.5x_1-6.23x_2+0.87x_3=2.3,\\
2.5x_1+1.5x_2+10.2x_3=1.8.
\end{cases}
$$
Doolittle 分解后前代得 $y_1=6.1,\ y_2\approx1.923,\ y_3\approx0.1560$，再回代得 $\boldsymbol x\approx(0.8409,-0.2997,0.0145)^{\mathrm T}$（此值按未舍入的有理数算出；若全程按四位十进制舍入，末位会有出入）。这个例子说明：分解本身不神秘，**逐圈公式的顺序不能乱**——每一步只让一个新未知数出现。
:::

::: ex 例 2.2.2（老师第 4 讲 §三板书） · Doolittle 逐圈演算完整走一遍 {#ex-2.2.2}
分解 $A=\begin{pmatrix}1&2&3\\2&5&2\\3&1&5\end{pmatrix}$（前两个顺序主子式 $1,1\ne0$，由 [@thm-2.3] 可分解）：

$$\begin{pmatrix}1&2&3\\2&5&2\\3&1&5\end{pmatrix}
=\begin{pmatrix}1&0&0\\l_{21}&1&0\\l_{31}&l_{32}&1\end{pmatrix}
\begin{pmatrix}u_{11}&u_{12}&u_{13}\\0&u_{22}&u_{23}\\0&0&u_{33}\end{pmatrix}$$

按圈求解（板书原始等式）：

- 第一行：$1=1\cdot u_{11},\ 2=1\cdot u_{12},\ 3=1\cdot u_{13}\Rightarrow u_{11}=1,\ u_{12}=2,\ u_{13}=3$；
- 第一列：$2=l_{21}\cdot1,\ 3=l_{31}\cdot1\Rightarrow l_{21}=2,\ l_{31}=3$；
- 第二圈：
  - $5=2\times2+1\times u_{22}\Rightarrow u_{22}=1$；
  - $2=2\times3+1\times u_{23}\Rightarrow u_{23}=-4$；
  - $1=3\times2+l_{32}\times1\Rightarrow l_{32}=-5$；
- 最后：$5=3\times3+(-5)\times(-4)+1\times u_{33}\Rightarrow u_{33}=-24$。

$$L=\begin{pmatrix}1&0&0\\2&1&0\\3&-5&1\end{pmatrix},\qquad
U=\begin{pmatrix}1&2&3\\0&1&-4\\0&0&-24\end{pmatrix}.$$

验算 $LU$ 的三行：$[1,2,3]$、$2[1,2,3]+[0,1,-4]=[2,5,2]$、$3[1,2,3]-5[0,1,-4]+[0,0,-24]=[3,1,5]$，与 $A$ 一致。
:::

::: note 编程提示（老师第 4 讲 §三）
算法本身“不难，难在编程时别把顺序搞乱”——解出的元素要及时更新存储；整个程序“充其量两个循环”。老师要求：**自己动手实现 Doolittle，不要全让 AI 代劳**。
:::

## 2.2.2 选主元的 Doolittle 分解

若某个 $u_{kk}=0$ 或相对很小，分解不能继续或误差会被放大。与列主元 Gauss 消去类似，在分解过程中选主元：第 $k$ 步在当前列的剩余行中选绝对值最大者，交换行，再继续分解。

::: thm 定理 2.4 · 选主元的 LU 分解 {#thm-2.4}
若 $A$ 非奇异，则存在置换矩阵 $Q$，使 $QA=LU$，其中 $L$ 单位下三角、$U$ 上三角。
:::

::: proof 证明
由 [@thm-2.2]，列主元消去可把 $A$ 化为上三角；把行交换矩阵 $Q_k$ 与消元矩阵 $P_k$ 合并，得到 $QA=LU$。$\blacksquare$
:::

实际实现时通常把 $Q$ 记录为一个排列向量，不显式构造矩阵；解方程组时对右端做同样的行交换。

::: ex 例 2.2.1 · 第二步才换行时，$L$ 的旧乘数也必须跟着换 {#ex-2.2.1}

取 $A=\begin{pmatrix}4&1&1\\2&1&0\\1&3&2\end{pmatrix}$。第一列无需换行，乘数为 $m_{21}=1/2$、$m_{31}=1/4$，消去后工作矩阵为

$$\begin{pmatrix}4&1&1\\0&1/2&-1/2\\0&11/4&7/4\end{pmatrix}.$$

第二列要交换第 $2,3$ 行。此时不但工作矩阵要交换，**已经存进 $L$ 的第一列乘数 $1/2,1/4$ 也要交换**；尚未计算的 $L$ 后续列不用交换。再取第二列乘数 $m_{32}=(1/2)/(11/4)=2/11$，得到

$$Q=\begin{pmatrix}1&0&0\\0&0&1\\0&1&0\end{pmatrix},\quad L=\begin{pmatrix}1&0&0\\1/4&1&0\\1/2&2/11&1\end{pmatrix},\quad U=\begin{pmatrix}4&1&1\\0&11/4&7/4\\0&0&-9/11\end{pmatrix}.$$

验算 $LU=QA$，才能确认 $L$ 中的每个乘数仍对应当前行。若保留旧顺序，错误的 $L$ 与 $U$ 相乘连第一列都会变成 $(4,2,1)^{\mathrm T}$，而 $QA$ 的第一列应为 $(4,1,2)^{\mathrm T}$。

**迁移练习。**对同一 $A$ 解 $A\boldsymbol x=(6,3,6)^{\mathrm T}$，写出前代使用的右端与中间向量 $\boldsymbol y$，再回代求解。
:::

::: sol 核对与回查

前代右端是 $Q\boldsymbol b=(6,6,3)^{\mathrm T}$；$L\boldsymbol y=Q\boldsymbol b$ 给出 $\boldsymbol y=(6,9/2,-9/11)^{\mathrm T}$，回代得 $\boldsymbol x=(1,1,1)^{\mathrm T}$。把解乘回原始 $A$ 得 $(6,3,6)^{\mathrm T}$。若误用原始 $\boldsymbol b$，回查 $QA=LU$ 两侧同时作用于 $\boldsymbol x$ 的等式；若乘积不等，先检查每次换行是否同步处理了 $L$ 的已完成列。
:::

## 2.2.3 带状矩阵的保带状分解

::: def 定义 2.2.3 · 带状矩阵 {#def-2.2.3}
若 $a_{ij}=0$ 当 $i-j\gt r$ 或 $j-i\gt s$，称 $A$ 为上半带宽 $s$、下半带宽 $r$ 的**带状矩阵**（banded matrix）。
:::

::: thm 定理 2.5 · 保带状结构的三角分解 {#thm-2.5}
设 $A$ 是上半带宽 $s$、下半带宽 $r$ 的带状矩阵，且前 $n-1$ 个顺序主子式不为零；则 $A$ 有唯一 Doolittle 分解 $A=LU$，其中 $L$ 是下半带宽 $r$ 的单位下三角，$U$ 是上半带宽 $s$ 的上三角。
:::

::: proof 证明
由 [@thm-2.3] 有唯一分解；当 $i-j\gt r$ 时，$a_{ik}=0\ (k\le j)$，由逐圈公式推出 $l_{ij}=0$；同理 $j-i\gt s$ 时 $u_{ij}=0$。$\blacksquare$
:::

::: cor 推论 2.2.1 · 保带宽的 Crout 分解与 $O(n)$ 计算量 {#cor-2.2.1}
同样条件下，$A$ 有唯一 Crout 分解，且保带宽。**计算量**：只需存 $(r+s+1)n$ 个带内元素，当半带宽 $r,s$ 固定时，分解与求解都是 $O(n)$；若带宽也随 $n$ 增长，则不能省掉带宽因子。
:::

## 2.2.4 追赶法（三对角方程组）

::: intuition 直觉 · 三对角矩阵从哪来（老师第 4 讲 §四）
对一维两点边值问题（Poisson 型方程）$u''=f$ 做二阶差分离散，得

$$\frac{u_{j+1}-2u_j+u_{j-1}}{h^2}=f_j\qquad(\text{边界 }u_0=u_{n+1}=0),$$

即三对角方程组 $\frac{1}{h^2}\operatorname{tridiag}(1,-2,1)\,\boldsymbol u=\boldsymbol f$。**每个方程只和左右邻居打交道**——这就是三对角结构在工程里最常见的出身，也是它值得单独造算法的原因。
:::

三对角方程组
$$
a_i x_{i-1}+b_i x_i+c_i x_{i+1}=d_i,\qquad i=1,\dots,n
$$
（$a_1=c_n=0$）是 $r=s=1$ 的带状矩阵。用 Crout 分解可写成“追”和“赶”两步：

**追（前代）**：
$$
c'_1=\frac{c_1}{b_1},\quad d'_1=\frac{d_1}{b_1};
\qquad
den_i=b_i-a_i c'_{i-1},\quad
c'_i=\frac{c_i}{den_i},\quad
d'_i=\frac{d_i-a_i d'_{i-1}}{den_i}.
$$

**赶（回代）**：
$$
x_n=d'_n,\qquad x_i=d'_i-c'_i x_{i+1}\quad(i=n-1,\dots,1).
$$

::: method[core] 计算量与使用前提
计算量约 $3n$ 次乘除法，即 $O(n)$；不需要选主元的前提是 $den_i\ne0$（如严格对角占优）。**稀疏 / 三对角 $O(n)$ 方法是工程主流，实际中没人用朴素高斯消去**（老师第 4 讲 §四、§六反复强调）。
:::

::: ex 例 2.2.3（老师第 4 讲 §四板书） · $\operatorname{tridiag}(1,-2,1)$ 分解不产生填充 {#ex-2.2.3}
对 $T=\operatorname{tridiag}(1,-2,1)$ 按待定系数法分解，板书逐条验证：

- $u_{11}=-2,\ u_{12}=1,\ u_{1j}=0\ (j\ge3)$；
- $1=l_{21}(-2)\Rightarrow l_{21}=-\frac12$；
- $0=l_{31}(-2)\Rightarrow l_{31}=0$，以下全为零；$u_{24}=0$ …

结论：$L$ 为**下双对角**（主对角 + 次对角）、$U$ 为**上双对角**——分解不产生填充 (fill-in)。继续算可归纳出 $u_{ii}=-(i+1)/i$、$l_{i+1,i}=-i/(i+1)$（编者验算，可用归纳法证明）；带外元素始终为零，这正是 [@thm-2.5] 的三对角特例。
:::

::: ex 例 3（教材 2.2.4） · 追赶法解三对角方程组 {#ex-2.2-textbook3}
教材用五对角/三对角方程组演示追赶法，精确解为 $(0.21,-0.52,1.2,0.82,-0.64)^{\mathrm T}$。关键是：分解不产生填充，带外元素始终为零。
:::

## 2.2.5 拟三对角方程组（教材有、课堂未展开）

拟三对角矩阵形如
$$
A=\begin{pmatrix}
b_1&c_1&&&d_1\\
a_2&b_2&c_2&&\\
&\ddots&\ddots&\ddots&\\
&&a_{n-1}&b_{n-1}&c_{n-1}\\
e_1&&&a_n&b_n
\end{pmatrix},
$$
即三对角外加右上角 $d_1$ 与左下角 $e_1$。教材 2.2.5 给出把它分解为两个三对角矩阵乘积的方法，从而仍可用追赶法求解。课堂未展开，考试按老师范围；需要时按教材补读。

::: method[core] 本节概念速查
| 概念 | 一句话 | 本节出现位置 | 将在何处深入 |
|:--|:--|:--|:--|
| Doolittle 分解 | $A=LU$，$L$ 单位下三角、$U$ 上三角 | [@def-2.2.1] | [2.4.2](sec24b.md#sec-2.4.2) 取 $N=D$ 即 Jacobi 的分裂特写 |
| 单位下三角封闭性 | 乘积与逆仍是单位下三角 | [@lem-2.2.1] | [@thm-2.3] 的充分性证明 |
| 唯一分解充要条件 | 前 $n-1$ 个顺序主子式非零 | [@thm-2.3] | [2.2.3](#sec-2.2.3) 带状版再用一次 |
| Crout 分解 | $L$ 下三角、$U$ 单位上三角，只差对角缩放 | [@def-2.2.2] | [2.2.4](#sec-2.2.4) 追赶法按 Crout 推导 |
| 选主元 LU | $QA=LU$，$Q$ 记为排列向量 | [@thm-2.4] | [2.1.2](sec21.md#sec-2.1.2) 列主元消去 |
| 保带状分解 | $L$、$U$ 带宽不增，$O(n)$ | [@thm-2.5]、[@cor-2.2.1] | [2.2.4](#sec-2.2.4) 三对角是 $r=s=1$ |
| 追赶法 | 追（前代）+ 赶（回代），约 $3n$ 次乘除 | [2.2.4](#sec-2.2.4) | [2.4.3](sec24b.md#sec-2.4.3) GS 逐行代入“相当于追赶法的前代” |
:::

::: think 本节常见错误
1. **逐圈公式的顺序乱。**每一圈只让一个新未知数出现；顺序一乱，公式里就会出现两个未知数相乘，直接卡住（[例 2](#ex-2.2-textbook2)、[例 2.2.2](#ex-2.2.2)）。
2. **选主元只换工作矩阵。**第二步才换行时，$L$ 中已存好的乘数、以及前代使用的右端，都必须同步交换——漏一个，$LU$ 连第一列都对不上（[例 2.2.1](#ex-2.2.1)）。
3. **把存在性（⇒）和唯一性（⟺）混为一谈。**“前 $n-1$ 个顺序主子式非零 ⇒ 分解存在”是单向陈述；谈“唯一”才是充要条件（[@thm-2.3]）。
4. **追赶法按 $O(n^3)$ 估计算量，或不检查 $den_i\ne0$ 就用。**三对角是 $r=s=1$ 的带状特例，$O(n)$；$den_i=0$ 时公式直接除零。
5. **多组右端重复分解。**$L,U$ 与右端无关，一次分解反复使用；重复分解等于把 $O(n^3)$ 付了 $m$ 次。
:::

## 习题（教材习题 4–8）

::: ex 2.4 · Doolittle 运算量（教材习题 4）
统计 Doolittle 分解法求解 $n$ 元线性方程组所需的乘除法次数。
:::

::: sol 参考答案
分解约 $n^3/3$ 次，前代约 $n^2/2$ 次，回代约 $n^2/2$ 次；主导项 $n^3/3$。与高斯消去同阶，但一次分解可反复用于多个右端。
:::

::: ex 2.5 · 不选主元的 Doolittle（教材习题 5）
用不选主元的 Doolittle 分解求解教材习题 5 的方程组。
:::

::: sol 参考答案
按逐圈公式算 $L,U$，前代得 $y$，回代得 $x$。若某步 $u_{kk}=0$ 或很小，说明不能直接分解，应改用选主元版本；本题数据下分解可进行，结果按四位十进制核对。
:::

::: ex 2.6 · 选主元的 Doolittle（教材习题 6）
用选主元的 Doolittle 分解求解教材习题 6 的方程组。
:::

::: sol 参考答案
第 $k$ 步在当前列剩余行中选绝对值最大者，交换行并记录排列；分解得 $QA=LU$，对右端做同样行交换后前代/回代。与列主元 Gauss 消去等价，只是把消元信息存进了 $L$。
:::

::: ex 2.7 · 带状存储下计算 Ax（教材习题 7）
带状矩阵的带内元素存在 $(r+s+1)\times n$ 的矩阵 $C$ 中，写出由 $C$ 计算 $\boldsymbol u=A\boldsymbol y$ 的公式。
:::

::: sol 参考答案
对每个 $i$，只累加 $j\in[\max(1,i-r),\min(n,i+s)]$：$u_i=\sum_j C_{r+1+i-j,j}\,y_j$。带外元素不参与，故每行最多 $r+s+1$ 次乘法，总体 $O((r+s)n)$。
:::

::: ex 2.8 · 追赶法（教材习题 8）
用追赶法求解教材习题 8 的五元三对角方程组。
:::

::: sol 参考答案
按 2.2.4 的“追/赶”公式，先算 $c'_i,d'_i$，再从 $x_5$ 回代。精确解为 $(0.21,-0.52,1.2,0.82,-0.64)^{\mathrm T}$；计算量 $O(n)$，不要写成 $O(n^3)$。
:::
