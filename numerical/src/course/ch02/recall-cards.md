## A. 定义卡

**A1.** 顺序 Gauss 消去的充要条件是什么？为什么它等价于「每步主元非零」？
::: sol
要让前 $n-1$ 步顺序消元都能进行，需要且只需要 $D_k=\det A_k\ne0$（$k=1,\dots,n-1$）。其中 $A_k$ 是前 $k$ 阶顺序主子矩阵，主元满足 $a_{kk}^{(k)}=D_k/D_{k-1}$，约定 $D_0=1$。若还要求通过回代得到唯一解，最后一个主元也要非零，即再加上 $D_n\ne0$。（✓ / △ / ×）
:::

**A2.** 列主元 Gauss 消去做了什么？它与「部分选主元」是不是一回事？
::: sol
列主元（部分选主元）在**每一列**消元之前，从当前列的下方各元素中选出**绝对值最大**的那个，交换到主元位置。它保证该步主元是当前列中绝对值最大的，从而避免「大数被小数除」的精度损失，同时控制乘子的绝对值 $\lvert m_{ik}\rvert\le1$。它**不改变方程组的解**（行交换是初等变换），只改变计算过程与舍入误差。（✓ / △ / ×）
:::

**A3.** 什么叫矩阵的条件数？它是算法的性质还是问题的性质？
::: sol
$A$ 的条件数 $\mathrm{cond}(A)=\lVert A\rVert\lVert A^{-1}\rVert$（或 $\lVert A\rVert_\infty\lVert A^{-1}\rVert_\infty$）度量**解对右端项扰动的敏感性**：$\dfrac{\lVert\delta x\rVert}{\lVert x\rVert}\le \mathrm{cond}(A)\,\dfrac{\lVert\delta b\rVert}{\lVert b\rVert}$。它是**问题本身（矩阵 $A$）的属性**，与用什么算法无关——算法只能控制舍入误差的传播，改不了条件数。（✓ / △ / ×）
:::

**A4.** 迭代矩阵 $G$ 是什么？迭代法收敛的充要条件是什么？
::: sol
把 $Ax=b$ 改写成 $x=Gx+d$（等价地 $x=(I-G)^{-1}d$），$G$ 称为**迭代矩阵**。迭代 $x_{k+1}=Gx_k+d$ 收敛的**充要条件**是 $\rho(G)<1$，即 $G$ 的谱半径小于 1（等价地 $\lVert G\rVert<1$ 对某个范数成立，此时 $I-G$ 可逆）。（✓ / △ / ×）
:::

**A5.** 严格对角占优是什么意思？它给出什么结论？
::: sol
严格行对角占优指每行都满足 $|a_{ii}|>\sum_{j\ne i}|a_{ij}|$；严格列对角占优则对每列作同样比较。取 $A=D+L+U$，Jacobi 矩阵为 $G_J=-D^{-1}(L+U)=I-D^{-1}A$。严格行占优时，直接求行和得到 $\lVert G_J\rVert_\infty=\max_i\sum_{j\ne i}|a_{ij}|/|a_{ii}|<1$。严格列占优时可用正文的特征值证明。两种条件也都保证 Gauss–Seidel 收敛，但不能仅凭占优就断言它在每道题中都更快。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** SOR 方法收敛的必要条件是什么？对角占优能推出什么？
::: sol
**必要条件**是 $0<\omega<2$。若 SOR 收敛，则所有特征值的模都小于 $1$，从而 $|\det G_\omega|=|1-\omega|^n<1$，得到这个区间。$\omega=1$ 在区间内，此时 SOR 就是 Gauss–Seidel；$\det G_1=0$ 只表示 $G_1$ 有零特征值，不能推出 $I-G_1$ 奇异。**充分条件**：$A$ 严格对角占优时，$0<\omega\le1$ 保证收敛；$A$ 对称正定时，$0<\omega<2$ 全部收敛。（✓ / △ / ×）
:::

**B2.** 残差与误差之间是什么关系？
::: sol
设 $\tilde x$ 是近似解，残差 $\boldsymbol r=\boldsymbol b-A\tilde x$。因 $x^*-\tilde x=A^{-1}\boldsymbol r$，故

$$\lVert x^*-\tilde x\rVert\le\lVert A^{-1}\rVert\lVert\boldsymbol r\rVert,$$

即**相对误差 $\le\mathrm{cond}(A)\,\times\,$ 相对残差**。关键推论：残差小**不能**保证解准——当 $\mathrm{cond}(A)$ 很大时，残差很小也可能有很大误差。（✓ / △ / ×）
:::

**B3.** 追赶法为什么是 $O(n)$？它的适用前提是什么？
::: sol
三对角方程组 $a_iy_{i-1}+b_iy_i+c_iy_{i+1}=d_i$ 的矩阵是三对角带，Doolittle 分解后 $L$ 是下二对角、$U$ 是上二对角；消元时每一步只需代入**两个**非零元，于是前代、后代各扫一遍，每个节点 $O(1)$，总 $O(n)$，存储也只要 $O(n)$。前提是**非零主元存在**（否则要换行，或改用选主元版本）。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 给定一个实际线性方程组，你的求解流程是什么？
::: sol
1. **看结构**：稠密 / 带状 / 三对角？规模多大？——决定直接法还是迭代法；
2. **估条件数**：用 $\lVert A\rVert_\infty\lVert A^{-1}\rVert_\infty$ 或 1 范数估计，条件数大时应检查数据精度与尺度，必要时提高计算精度或重新考虑问题的提法；
3. **选算法**：小中规模稠密 → 选主元 LU（$O(n^3)$，一次分解多次求解）；三对角 → 追赶法（$O(n)$）；固定半带宽 $w$ 的带状矩阵 → 带状 LU（通常 $O(nw^2)$）；大规模 → 迭代（先验 $\rho(G)$ 或残差检验）；
4. **验证**：计算残差，并结合条件数或其他误差界判断能保留多少有效数字；使用迭代法时还应报告停止条件。（✓ / △ / ×）
:::

**C2.** 老师反复强调「算法评价三要素」，是哪三个？
::: sol
**算得准**（稳定性与收敛性）、**算得快**（时间复杂度）、**用得省**（存储量）。三者一般不可兼得：稠密 LU 准但 $O(n^3)$，迭代 $O(n^2)$ 每次但要迭代很多次且可能不收敛，带状方法 $O(n)$ 却只对特定结构成立。选算法就是在三者之间按问题结构取舍。（✓ / △ / ×）
:::
