::: method[core] 本章学习目标
学完本章，你应该能：

1. 根据矩阵结构（稠密 / 三对角 / 稀疏 / 病态）选择直接法或迭代法，并说明理由；
2. 写出高斯消去、LU 分解、追赶法的复杂度与适用条件；
3. 判断 Jacobi / Gauss–Seidel / SOR 的收敛性，分清 $\rho(G)\lt1$、$\lVert G\rVert\lt1$、对角占优、对称正定四条判据；
4. 用条件数解释「残差小 ≠ 误差小」，知道什么时候要换提法而不是换算法。
:::

::: method[core] 三句话带走
1. **结构决定算法**：稠密小规模用列主元/LU，三对角用追赶法，大规模稀疏用迭代法。
2. **直接法的核心是分解**：一次 LU，反复前代/回代；稠密 $O(n^3)$，三对角 $O(n)$。
3. **迭代法先过谱半径**：$\rho(G)\lt1$ 是充要条件，$\lVert G\rVert\lt1$ 是好算的充分条件。
:::
