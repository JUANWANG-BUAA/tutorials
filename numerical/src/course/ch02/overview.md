# 第2章 线性方程组

第一章介绍了误差的度量和传播。现在考虑一组最基本的计算关系：若干未知量同时满足若干线性方程。把它们写成矩阵形式，就是 $A\boldsymbol x=\boldsymbol b$。本章要把线性代数中的“解存在且唯一”变成实际的求解过程，并分析数据和舍入误差对解的影响。

先从熟悉的消元开始。每消去一个未知量，方程组就更接近容易回代求解的三角形式。把这些步骤记录为矩阵分解，同一个矩阵对应多个右端项时，就可以重复使用分解结果。对于特殊的三对角结构，还能省去大量运算和存储。

当矩阵很大、非零元素较少时，也可以从一个近似解出发反复修正。这就是本章后半部分的迭代法。无论采用哪条路线，都还需要判断算出的结果有多准确：把近似解代回方程得到的残差很小，是否就意味着解的误差很小？条件数将帮助我们回答这个问题。
