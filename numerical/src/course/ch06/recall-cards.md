# 闭卷回忆卡 · 第 6 章：数值积分

## A. 定义卡

**A1.** 什么是代数精度？判定方法是什么？
::: sol
对求积公式 $\int_a^bf\approx\sum_k\lambda_kf(x_k)$：若对任何次数 $\le m$ 的多项式都精确，而对某个 $m+1$ 次多项式不精确，则称有 **$m$ 次代数精度**。判定法：只要对 $f=1,x,x^2,\dots,x^m$ 都精确、对 $x^{m+1}$ 不精确即可。（✓ / △ / ×）
:::

**A2.** 插值型求积公式的权怎么来的？
::: sol
以节点作 Lagrange 插值 $p_n=\sum f(x_k)\ell_k(x)$，对它在 $[a,b]$ 积分：
$$\int_a^bf\approx\sum_{k=0}^n\underbrace{\Big(\int_a^b\ell_k(x)\,dx\Big)}_{\lambda_k}f(x_k).$$
所以权 $\lambda_k$ 只与**节点和区间**有关，与 $f$ 无关；若 $f\in C^{n+1}[a,b]$，误差 $R=\int_a^b\frac{f^{(n+1)}(\xi(x))}{(n+1)!}\prod_{j=0}^n(x-x_j)\,dx$。（✓ / △ / ×）
:::

**A3.** 什么是复化求积法？为什么它是 Newton–Cotes 的正确用法？
::: sol
把 $[a,b]$ 分成若干子区间，在每段使用固定低阶公式，再将结果相加。不断提高整段等距 Newton–Cotes 的阶数不保证收敛；[6.4](sec64.md) 区分了有限数表展示的风险与教材引用的渐近结论。在相应光滑性条件下，复化梯形与复化 Simpson 的截断误差分别为 $O(h^2)$、$O(h^4)$，还须另查舍入误差。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 定理 6.1、6.2、6.3 分别说什么？
::: sol
**6.1**：$n+1$ 个节点的插值型求积公式**至少 $n$ 次**代数精度（$f$ 为 $\le n$ 次时 $p_n=f$，误差为零）。
**6.2**：$n+1$ 个节点的求积公式若具 $n$ 次或更大精度，则**必是插值型**（取 $p=\ell_j$ 代入得 $\int\ell_j=\lambda_j$）。
**6.3**：$n$ 为**偶数**时，Newton–Cotes 的代数精度**至少 $n+1$**（误差中的高次项在对称区间上积分为 0——奇函数）。（✓ / △ / ×）
:::

**B2.** 定理 6.4（Romberg / Richardson）说什么？
::: sol
若 $F(h)$ 逼近 $F^*$ 的误差有渐近展开 $F^*-F(h)=a_1h^{p_1}+a_2h^{p_2}+\cdots$，则 Richardson 外推
$$F_j(h)=\frac{F_{j-1}(qh)-q^{p_j}F_{j-1}(h)}{1-q^{p_j}}$$
这里 $F_0=F$，每一步消去前一步尚存的最低阶项，要求相应渐近展开及余项控制成立；$q>0$ 且 $q\ne1$。取 $F(h)=T_n,\ q=1/2,\ p_j=2j$，其中 $h=(b-a)/n$，即得 Romberg 表。若只知道二阶误差界，没有更高阶展开，就不能保证反复外推仍逐次升阶。（✓ / △ / ×）
:::

**B3.** Gauss 型求积的精度为什么是 $2n-1$？
::: sol
设权函数非负、所需矩有限，且每个非零多项式的平方积分为正。$n$ 点公式有 $2n$ 个自由参数，提示尝试 $2n$ 个矩条件，但参数计数不是上界的证明。节点多项式的平方 $\prod_i(x-x_i)^2$ 在各节点为零，而其带权积分为正，因此不能达到 $2n$ 次。取带权 $n$ 次正交多项式的根作节点、积分插值基函数定权，可达到 $2n-1$ 次。具体地，对 $\deg p\le2n-1$ 作除法 $p=q\pi_n+r$，其中 $\deg q,\deg r\le n-1$；正交性消去积分中的 $q\pi_n$，节点处该项也为零，而插值型公式对 $r$ 精确，故对 $p$ 精确。再对 $\ell_i^2$ 使用精确性得 $\lambda_i=\int w\ell_i^2>0$。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 给一个积分与精度要求，你的选择流程是什么？
::: sol
1. **看被积函数**：光滑？端点有奇点或间断？先检查积分是否收敛，再考虑分段、变量替换或匹配奇异权的求积；开型公式只避开端点取值，并不自动解决奇点的误差控制。
2. **选公式**：少量点高精度可考虑 Gauss；低阶复化可选梯形/Simpson；支持偶次幂误差展开时可用 Romberg。光滑误差界不能直接用于奇异函数。
3. **定步长**：用误差界反解 $h$（复化梯形在 $f\in C^2$ 时 $\le\frac{b-a}{12}h^2\max|f''|$；复化 Simpson 在 $f\in C^4$、子区间数为偶数时 $\le\frac{b-a}{180}h^4\max|f^{(4)}|$），并检查舍入误差不占主导。
4. **验证**：做步长加密试验并比较相邻差值；观察阶数需要三层网格，且差值可能漏掉未采样的变化。
5. **报告**：给近似值 + 误差界 + 实际用的节点数。（✓ / △ / ×）
:::

**C2.** 为什么不能只靠增加整段 Newton–Cotes 的节点数控制误差？
::: sol
[6.4](sec64.md) 分别讨论收敛性与扰动放大。对 $f(x)=\frac1{1+x^2}$、区间 $[-4,4]$，$n=2,4,6,8,10$ 时算得 $5.4902,2.2776,3.3288,1.9411,3.5956$，没有显示稳定下降的误差；这五个值本身不能证明序列不收敛。该页另引用教材关于 $\sum_k|\lambda_k|$ 无界的结论，并注明未给完整渐近证明。实际计算常选 $n=1,2,4$ 等低阶公式及其复化形式，再用误差界或加密试验验收；不能将此说成所有 Newton–Cotes 公式都不能用。（✓ / △ / ×）
:::

**C3.** 复化梯形加密后，差值除以 3 估计哪一层误差？符号怎么定？
::: sol
令 $T_m$ 的步长为 $h$、$T_{m+1}$ 的步长为 $h/2$，本章用 $E_m=I-T_m$。若光滑性支持 $E_m=Ch^2+O(h^4)$ 且领先项未消失，则 $T_{m+1}-T_m=E_m-E_{m+1}=3Ch^2/4+O(h^4)$，所以
$$E_{m+1}\approx\frac{T_{m+1}-T_m}{3},\qquad E_m\approx\frac{4(T_{m+1}-T_m)}{3}.$$
例如 $f=x^2$、$[0,1]$，$T_0=1/2$、$T_1=3/8$，差值为 $-1/8$，细网格误差为 $-1/24$，粗网格误差为 $-1/6$。取绝对值才得到误差大小；不能把这一渐近估计当成无条件上界。（✓ / △ / ×）
:::
