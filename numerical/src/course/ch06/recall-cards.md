# 闭卷回忆卡 · 第 6 章：数值积分

## A. 定义卡

**A1.** 什么是代数精度？判定方法是什么？
::: sol
对求积公式 $\int_a^bf\approx\sum_k\lambda_kf(x_k)$：若对任何次数 $\le m$ 的多项式都精确，而对某个 $m+1$ 次多项式不精确，则称有 **$m$ 次代数精度**。判定法：只要对 $f=1,x,x^2,\dots,x^m$ 都精确、对 $x^{m+1}$ 不精确即可。（✓ / △ / ×）
:::

**A2.** 插值型求积公式的权怎么来的？
::: sol
以节点作 Lagrange 插值 $p_n=\sum f(x_k)\ell_k(x)$，对它在 $[a,b]$ 积分：
$$\int_a^bf\approx\sum_{k=0}^n\underbrace{\Big(\int_a^b\ell_k(x)\,dx\Big)}_{\lambda_k}f(x_k).$$
所以权 $\lambda_k$ 只与**节点和区间**有关，与 $f$ 无关；误差 $R=\int_a^b\xi(x)\prod(x-x_j)\,dx$。（✓ / △ / ×）
:::

**A3.** 什么是复化求积法？为什么它是 Newton–Cotes 的正确用法？
::: sol
把 $[a,b]$ 分成若干子区间，在每个子区间上用**少节点**的 Newton–Cotes 公式，再把结果相加。因为[6.4](sec64.md) 证明多节点 NC 不收敛且稳定性无保证，正确做法不是加大 $n$，而是**把区间切小、用低阶公式累加**——误差按 $O(h^2)$/$O(h^4)$ 稳定下降。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 定理 6.1、6.2、6.3 分别说什么？
::: sol
**6.1**：$n+1$ 个节点的插值型求积公式**至少 $n$ 次**代数精度（$f$ 为 $\le n$ 次时 $p_n=f$，误差为零）。
**6.2**：$n+1$ 个节点的求积公式若具 $n$ 次或更大精度，则**必是插值型**（取 $p=\ell_j$ 代入得 $\int\ell_j=\lambda_j$）。
**6.3**：$n$ 为**偶数**时，Newton–Cotes 的代数精度**至少 $n+1$**（误差中的高次项在对称区间上积分为 0——奇函数）。（✓ / △ / ×）
:::

**B2.** 定理 6.4（Romberg / Richardson）说什么？
::: sol
若 $F(h)$ 逼近 $F^*$ 的误差有渐近展开 $F^*-F(h)=a_1h^{p_1}+a_2h^{p_2}+\cdots$，则 Richardson 外推
$$F_j(h)=\frac{F_{j-1}(qh)-q^{p_j}F_{j-1}(h)}{1-q^{p_j}}$$
逼近 $F^*$ 的误差为 $a_{j+1}'h^{p_{j+1}}+\cdots$，即**每次外推消去一个低阶项、精度升到下一阶**。取 $F=T_n,\ q=2,\ p_1=2$ 即得 Romberg 表。（✓ / △ / ×）
:::

**B3.** Gauss 型求积的精度为什么是 $2n-1$？
::: sol
$n$ 点公式有 $2n$ 个自由参数（$n$ 个节点 + $n$ 个权），最多能做到 $2n-1$ 次代数精度；Gauss 型公式**恰好达到**这个上限——节点取 $[a,b]$ 上带权 $\rho$ 的 $n$ 次正交多项式的根，权 $A_k=\int\rho\ell_k>0$，精度恰为 $2n-1$。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 给一个积分与精度要求，你的选择流程是什么？
::: sol
1. **看被积函数**：光滑？端点有奇点或间断？（有奇点 ⟹ 先分段或用开型 Newton–Cotes）
2. **选公式**：少量点高精度 ⟹ Gauss；稳健 ⟹ 复化梯形/Simpson；要更高阶 ⟹ Romberg
3. **定步长**：用误差界反解 $h$（复化梯形 $\le\frac{b-a}{12}h^2\max|f''|$，复化 Simpson $\le\frac{b-a}{180}h^4\max|f^{(4)}|$），并检查舍入误差不占主导
4. **验证**：做一次步长减半实验，看误差是否按理论阶下降
5. **报告**：给近似值 + 误差界 + 实际用的节点数。（✓ / △ / ×）
:::

**C2.** 为什么说「Newton–Cotes 精度高但不能用」？
::: sol
[6.4](sec64.md) 给两条硬证据：① **不收敛**——$f(x)=\frac1{1+x^2}$ 在 $[-4,4]$ 上，$I_n$ 的计算值在 $n=2,4,6,8,10$ 时为 $5.4902,2.2776,3.3288,1.9411,3.5956$，不趋近真值 $2.6516$；② **稳定性无保证**——理论证明 $\sum_k|\lambda_k|$ 在 $n\to\infty$ 时无界，舍入误差会被无界放大。结论：只用 $n=1,2,4$ 及它们的复化形式。（✓ / △ / ×）
:::
