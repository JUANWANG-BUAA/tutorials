# 第 6 章学习目标自检表

## K · 知识

| 编号 | 目标 | 自检标准 | ✓ |
|:--|:--|:--|:--|
| K6.1 | 写出求积公式与代数精度的定义 | $\int f\approx\sum\lambda_kf(x_k)$；对 $\deg\le m$ 精确、对某个 $m+1$ 次不精确 ⟹ $m$ 次精度 | ☐ |
| K6.2 | 写出插值型求积的权 | $\lambda_k=\int_a^b\ell_k(x)\,dx$ | ☐ |
| K6.3 | 说出定理 6.1、6.2 | 6.1：$n+1$ 节点插值型至少 $n$ 次精度；6.2：精度 $\ge n$ ⟹ 必是插值型 | ☐ |
| K6.4 | 写出梯形 / Simpson / 3-8 / Cotes 公式与误差 | 单面板余项分别含区间长度的三次、五次、五次、七次幂；复化梯形与 Simpson 在相应光滑条件下的全局误差为 $O(h^2)$、$O(h^4)$ | ☐ |
| K6.5 | 说明定理 6.3 | $n$ 偶数时 Newton–Cotes 精度至少 $n+1$（靠奇函数积分为零） | ☐ |
| K6.6 | 说明 6.4 的结论 | 增加整段等距节点不保证收敛；区分有限数表与渐近证明，说明权绝对和无界的含义 | ☐ |
| K6.7 | 写出复化梯形 / Simpson 与步长界 | 固定区间、$f\in C^2$ / $C^4$ 时误差界为 $O(h^2)$ / $O(h^4)$；Simpson 子区间数须为偶数；按 $I-T$ 约定，梯形细网格误差估计为 $(T_{m+1}-T_m)/3$ | ☐ |
| K6.8 | 写出 Richardson 外推与 Romberg 表 | $R_{k,j}=\dfrac{4^jR_{k,j-1}-R_{k-1,j-1}}{4^j-1}$ | ☐ |
| K6.9 | 说出 Gauss 型求积的三条 | 对所需矩有限的正权内积，$n$ 个节点为 $n$ 次正交多项式的根；权为正；精度恰为 $2n-1$，不能达到 $2n$ | ☐ |
| K6.10 | 写出二维复化求积的权表 | 矩形区域、张量网格：梯形角点 1、边 2、内点 4，公因子 $h_xh_y/4$；Simpson 为两方向一维权的乘积，公因子 $h_xh_y/9$，两个方向子区间数均为偶数 | ☐ |
