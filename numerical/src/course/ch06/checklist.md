# 第 6 章学习目标自检表

## K · 知识

| 编号 | 目标 | 自检标准 | ✓ |
|:--|:--|:--|:--|
| K6.1 | 写出求积公式与代数精度的定义 | $\int f\approx\sum\lambda_kf(x_k)$；对 $\deg\le m$ 精确、对某个 $m+1$ 次不精确 ⟹ $m$ 次精度 | ☐ |
| K6.2 | 写出插值型求积的权 | $\lambda_k=\int_a^b\ell_k(x)\,dx$ | ☐ |
| K6.3 | 说出定理 6.1、6.2 | 6.1：$n+1$ 节点插值型至少 $n$ 次精度；6.2：精度 $\ge n$ ⟹ 必是插值型 | ☐ |
| K6.4 | 写出梯形 / Simpson / 3-8 / Cotes 公式与误差 | 梯形 $O(h^2)$、Simpson $O(h^4)$（精度 3 次）、3-8 与 Cotes 的系数与误差常数 | ☐ |
| K6.5 | 说明定理 6.3 | $n$ 偶数时 Newton–Cotes 精度至少 $n+1$（靠奇函数积分为零） | ☐ |
| K6.6 | 说明 6.4 的结论 | 多节点 NC 不收敛且 $\sum\lvert\lambda_k\rvert$ 无界 ⟹ 稳定性无保证 | ☐ |
| K6.7 | 写出复化梯形 / Simpson 与步长界 | 误差 $\propto h^2$ / $h^4$；用导数界反解 $h$ | ☐ |
| K6.8 | 写出 Richardson 外推与 Romberg 表 | $R_{k,j}=\dfrac{4^jR_{k,j-1}-R_{k-1,j-1}}{4^j-1}$ | ☐ |
| K6.9 | 说出 Gauss 型求积的三条 | 节点 = $n$ 次正交多项式的根；权为正；精度恰 $2n-1$ | ☐ |
| K6.10 | 写出二维复化求积的权表 | 角点 1、边 2、内点 4（梯形）；Simpson 版角 1、边奇 4/偶 2、内奇奇 16/奇偶 8/偶偶 4 | ☐ |
