# 第六章小结：用有限个函数值计算积分

数值求积用加权和 $\sum_i A_i f(x_i)$ 近似积分。节点给出计算函数值的位置，权决定各点的贡献。固定节点时，可以积分插值多项式求权；允许选择节点时，可以进一步构造 Gauss 公式。

| 方法 | 计算思路 | 复习时要检查什么 |
|:--|:--|:--|
| Newton–Cotes | 等距节点上积分插值多项式 | 代数精度与权的正负、绝对值之和 |
| 复化梯形 | 在各个小区间重复梯形公式 | 光滑条件下全局二阶；网格与函数变化是否匹配 |
| 复化 Simpson | 每两个小区间使用 Simpson 公式 | 子区间数为偶数；足够光滑时全局四阶 |
| Romberg | 利用步长误差展开逐次外推 | 外推依赖光滑性与偶次幂误差展开 |
| Gauss 求积 | 节点取为正交多项式的零点 | $n$ 点达到 $2n-1$ 次代数精度，区间与权必须配套 |
| 二重求积 | 在两个方向应用一维求积 | 区域边界与被积函数的光滑性影响精度 |

代数精度与收敛阶要分开。前者说公式能精确积分哪些多项式；后者说固定函数在网格加密时，误差怎样随步长变化。提高代数精度并不保证任意函数的实际误差逐次减小。

对足够光滑的函数，可以比较 $h,h/2,h/4$ 三层网格，观察是否进入预期的渐近区。复化梯形的细网格误差可在二阶渐近区内用 $|T_{2m}-T_m|/3$ 估计。若采样漏掉同一个窄峰，两次结果接近也可能失准。
