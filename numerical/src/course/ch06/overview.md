::: method[core] 本章学习目标
学完本章，你应该能：

1. 写出插值型求积公式，判断代数精度；
2. 写出梯形/Simpson/复化公式，并估计截断误差；
3. 用 Romberg 外推抬阶，理解 Gauss 求积为什么能到 $2n-1$ 次精度；
4. 用中心差分/外推算数值导数，知道步长不能无限小。
:::

::: method[core] 三句话带走
1. **插值型**：用插值多项式代替 $f$，积分变成节点函数值的加权和。
2. **复化 + 外推**：复化把区间切小，Romberg 用 Richardson 外推再抬阶。
3. **Gauss 让节点也自由**：$n$ 个节点、$n$ 个权重，最高 $2n-1$ 次代数精度；代价是节点不固定。
:::
