# 第 6 章 数值积分

> 对应颜庆津《数值分析》（第 4 版）第 6 章「数值积分」。课堂第 12–14 讲已覆盖求积基础、Newton–Cotes、复化梯形与 Simpson、Gauss 型求积；其余内容按教材展开，具体对应见各节页首。
> **注意**：教材第 6 章**不含数值微分**；本教程把数值微分单列为[附录 D · 数值微分（编者补充）](../../appendix/numerical-diff.md)。

:::

::: method[core] 本章学习目标
学完本章，你应该能：

1. 写出插值型求积公式，判断代数精度；
2. 写出梯形/Simpson/复化公式，并估计截断误差；
3. 用 Romberg 外推抬阶，理解 Gauss 求积为什么能到 $2n-1$ 次精度；
4. 区分代数精度、收敛阶、严格误差界和渐近估计，用三层网格检查结果并指出采样漏峰的失败情形。
:::

## 本章结构

先把第五章的插值多项式积分，理解权重从哪里来，再比较两种提高精度的方向：固定低阶公式、不断细分区间；允许节点自由、提升代数精度。对应 [6.5 的引导算例](sec65.md)与 [6.7](sec67.md)。

练习顺序是“对单项式验精度 → 手推复化误差 → 三层网格估阶 → 找估计失效的反例”。每份计算报告都应写明被积函数的光滑性、节点数、函数求值次数，以及误差结论是保证还是观察。

::: method[core] 三句话带走
1. **插值型**：用插值多项式代替 $f$，积分变成节点函数值的加权和。
2. **复化 + 外推**：复化把区间切小，Romberg 用 Richardson 外推再抬阶。
3. **Gauss 让节点也自由**：$n$ 个节点、$n$ 个权重，最高 $2n-1$ 次代数精度；代价是节点不固定。
:::
