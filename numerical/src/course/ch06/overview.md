# 第6章 数值积分

第五章用简单函数近似复杂函数。把近似函数积分，就得到一种计算积分的方法。例如，用连接两个端点的直线代替曲线，直线下面的面积是梯形面积，于是得到梯形求积公式。

本章从这个想法出发，把积分近似成若干函数值的加权和。采样位置称为节点，每个函数值前的系数称为权。要构造一个求积公式，就要决定节点和权；要评价它，还要分析截断误差和数据扰动的影响。

提高精度有几种不同的做法。可以把区间分小，在每一段使用简单公式；可以把不同步长的结果组合起来，消去误差展开中的低阶项；也可以同时选择节点和权，使公式对更多多项式精确。这些做法分别通向复化公式、Romberg 积分和 Gauss 求积。
