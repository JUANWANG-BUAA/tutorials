# 6.5 复化求积与 Romberg 积分

> 对应教材 6.5.1–6.5.2、6.6.1–6.6.2、定理 6.4、例 4–6。老师本章尚未开讲，先按教材铺。
> 主线：把大区间切小，用低阶公式累加；再用 Richardson 外推把误差阶逐级抬高。

<a id="sec-6.5.1"></a>
## 6.5.1 复化梯形与复化 Simpson

把 \([a,b]\) 分成 \(n\) 等份，\(h=(b-a)/n\)，\(x_i=a+ih\)。

**复化梯形**：
$$
T_n=\frac{h}{2}\left[f(a)+2\sum_{i=1}^{n-1}f(x_i)+f(b)\right],
$$
误差
$$
I-T_n=-\frac{b-a}{12}h^2f''(\xi),\qquad \xi\in(a,b).
$$
即 \(O(h^2)\)。

**复化 Simpson**（\(n\) 为偶数，\(h=(b-a)/n\)）：
$$
S_n=\frac{h}{3}\left[f(a)+4\sum_{i\ \text{odd}}f(x_i)+2\sum_{i\ \text{even}}f(x_i)+f(b)\right],
$$
误差
$$
I-S_n=-\frac{b-a}{180}h^4f^{(4)}(\xi),\qquad \xi\in(a,b).
$$
即 \(O(h^4)\)。

**例 4（教材 6.5.1）**：用 11 个节点（\(n=10,h=0.1\)）的复化 Simpson 算
$$
I=\int_0^1e^{-x}dx=1-e^{-1}\approx0.632120559.
$$
按公式
$$
S_{10}=\frac{0.1}{3}\left[f(0)+4\sum_{i\ \text{odd}}f(x_i)+2\sum_{i\ \text{even}}f(x_i)+f(1)\right]
\approx0.6321206,
$$
误差已在 \(10^{-7}\) 量级，远小于单区间 Simpson 的 \(2.1\times10^{-4}\)。

**例 5（教材 6.5.1）**：若要求 \(I_n\) 至少有四位有效数字，用误差界
$$
|I-T_n|\le\frac{b-a}{12}h^2\max|f''|
$$
反解 \(h\)，再取 \(n=\lceil(b-a)/h\rceil\)。复化公式的步长不是越小越好：太小会放大舍入误差，且计算量线性增长。

<a id="sec-6.5.2"></a>
## 6.5.2 步长与舍入的平衡

总误差 ≈ 截断误差 + 舍入误差。复化梯形截断 \(O(h^2)\)，舍入约 \(\varepsilon/h\)；令两者同阶，得最优步长 \(h\sim\varepsilon^{1/3}\)。实际做法：用两三种步长试算，看结果是否稳定，而不是盲目加密。

<a id="sec-6.6"></a>
## 6.6 Romberg 积分

复化梯形有一个漂亮性质：若把步长减半，
$$
T_{2n}=\frac12T_n+\frac{h}{2}\sum_{i=0}^{n-1}f\left(a+\left(i+\frac12\right)h\right),
$$
只需算新增的中点，不用重算旧点。

Romberg 用 Richardson 外推消去 \(h^2\) 项：
$$
R_{k,0}=T_{2^k},\qquad
R_{k,j}=\frac{4^jR_{k,j-1}-R_{k-1,j-1}}{4^j-1}\quad(j=1,\dots,k).
$$
\(R_{k,1}\) 是 Simpson，\(R_{k,2}\) 是 Cotes，\(R_{k,3}\) 更高阶；每外推一次，误差阶提高 2。

**定理 6.4**：若 \(f\) 足够光滑，Romberg 表第 \(j\) 列收敛到 \(I\)，且误差为 \(O(h^{2j+2})\)。

**例 6（教材 6.6）**：对 $\int_0^1e^{-x}dx$ 造 Romberg 表（$R_{k,0}=T_{2^k}$）：

| $k$ | $R_{k,0}$ | $R_{k,1}$ | $R_{k,2}$ | $R_{k,3}$ | $R_{k,4}$ |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 0 | 0.6839397206 | | | | |
| 1 | 0.6452351901 | 0.6323336800 | | | |
| 2 | 0.6354094290 | 0.6321341753 | 0.6321208750 | | |
| 3 | 0.6329434182 | 0.6321214146 | 0.6321205639 | 0.6321205590 | |
| 4 | 0.6323263138 | 0.6321206124 | 0.6321205589 | 0.6321205588 | 0.6321205588 |

精确值 $1-e^{-1}=0.6321205588$。第 4 行对角元已到 $10^{-10}$；实际停机用相邻两行对角元之差。
