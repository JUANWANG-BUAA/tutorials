# 第六章练习与解答

先检查简单公式的精度，再练习误差限、外推与节点选择。计算题完成后，将数值与可直接求出的积分比较。

::: ex 6.A · 从矩条件求权
求 $A,B$，使 $Q(f)=Af(-1)+Bf(1)$ 对所有一次多项式精确近似 $\int_{-1}^1f(x)\,dx$。判断其代数精度。
:::

::: sol 参考答案
代入 $1,x$ 得 $A+B=2$、$-A+B=0$，故 $A=B=1$。对 $x^2$，公式给出 $2$，真积分为 $2/3$，所以代数精度为 $1$。
:::

::: ex 6.B · 选择梯形法的分段数
用等长分段的复化梯形计算 $\int_0^1x^2\,dx$。求保证绝对误差不超过 $10^{-4}$ 的最小子区间数 $m$。
:::

::: sol 参考答案
因 $f''=2$，误差绝对值为 $1/(6m^2)$。需要 $m\ge\sqrt{1/(6\times10^{-4})}\approx40.825$，所以取 $m=41$。这里对二次函数，二阶导数为常数，误差公式直接给出精确误差。
:::

::: ex 6.C · 用外推消去误差
仍取 $f(x)=x^2$，分别计算单区间梯形值 $T_1$ 与两子区间梯形值 $T_2$，再计算 $(4T_2-T_1)/3$。解释结果。
:::

::: sol 参考答案
$T_1=1/2$、$T_2=3/8$，外推值为 $1/3$，与真积分相同。梯形误差的 $h^2$ 项被消去；对这个函数，更高次误差项为零。
:::

::: ex 6.D · 自由节点能增加多少精度
构造 $\int_{-1}^1f(x)\,dx\approx w[f(-a)+f(a)]$，其中 $a>0$。要求对三次及以下多项式精确，求 $w,a$，再用 $x^4$ 检查精度上限。
:::

::: sol 参考答案
对称性已使奇次矩精确；由 $2w=2$、$2wa^2=2/3$ 得 $w=1,a=1/\sqrt3$。对 $x^4$，近似值为 $2/9$，真值为 $2/5$，所以代数精度恰为 $3$。
:::

::: ex 6.E · 函数值误差怎样进入积分
在第 6.D 题中，两个函数值分别带有绝对值不超过 $\varepsilon$ 的误差。估计它们对求积结果的影响，并写出一般权重的对应界。
:::

::: sol 参考答案
两点权均为 $1$，所以求积值的扰动不超过 $2\varepsilon$。一般地，若 $Q(f)=\sum_iA_if(x_i)$，则扰动不超过 $\varepsilon\sum_i|A_i|$。这个界只计算数据扰动，不包含求积公式自身的截断误差。
:::

::: ex 6.F · 二维求积
在 $[0,1]^2$ 上，对 $f(x,y)=x+y$ 使用两个方向均只有一个小区间的张量积梯形公式。写出四个角点的权与求积值。
:::

::: sol 参考答案
每个角点的权为 $1/4$，所以结果为 $(0+1+1+2)/4=1$。直接积分也为 $1$，因为公式在两个方向分别对一次函数精确。
:::

::: ex 6.G · “至少”的条件与 Simpson 的额外精度
给出三个节点 $0,1/2,1$。（1）是否任取三个权就能保证二次代数精度？（2）求插值型公式的权，检验它对 $x^3,x^4$ 的结果。（3）说明推导余项时为何不能直接将普通二次插值余项中的三阶导数因子提出积分。
:::

::: sol 参考答案
（1）不能。必须取 $A_i=\int_0^1\ell_i(x)\,dx$，或等价地满足常数、一次、二次的三个矩条件。（2）由 $A_0+A_1+A_2=1$、$A_1/2+A_2=1/2$、$A_1/4+A_2=1/3$，得权为 $(1,4,1)/6$。对 $x^3$，公式给 $[4/8+1]/6=1/4$，精确；对 $x^4$ 给 $[4/16+1]/6=5/24\ne1/5$，故恰有三次精度。（3）核 $x(x-1/2)(x-1)$ 在中点两侧变号，不能直接用固定符号的积分中值定理。增加中点导数条件作三次 Hermite 插值后，核成为 $x(x-1/2)^2(x-1)$，在区间内非正；若 $f\in C^4[0,1]$，可用导数上下界和连续性得到四阶导数余项。实际 Simpson 计算仍只使用三个函数值。
:::

::: ex 6.H · 二维精度要逐方向判断
在 $[0,1]^2$ 上，对 $f(x,y)=x^2y$ 使用两个方向各只有一个面板的 Simpson 公式。（1）不列九个函数值，利用可分离结构求结果。（2）若改成两个方向均用复化梯形，只加密 $y$ 方向能否消除误差？
:::

::: sol 参考答案
（1）权的外积使结果分解为一维结果之积。Simpson 对 $x^2$ 和 $y$ 均精确，故 $Q=(1/3)(1/2)=1/6$。（2）不能。任意 $y$ 网格的梯形公式对一次函数 $y$ 已精确，细分它不再改善这一方向。若 $x$ 方向仍只有一个面板，其结果为 $1/2$，二维结果一直是 $(1/2)(1/2)=1/4$，与真值相差 $1/12$。应加密存在误差的 $x$ 方向。
:::
