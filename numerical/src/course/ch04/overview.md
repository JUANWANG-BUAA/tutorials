# 第4章 非线性方程

现在把求解对象从线性关系推广到一般方程 $f(x)=0$。例如，要计算 $\sqrt2$，可以求 $x^2-2=0$ 的正根；轨道计算中的方程还可能同时含有未知数和三角函数。它们通常不能通过有限次消元直接求解。

一个自然的办法是从近似值出发，逐步缩小它与根的距离。但“反复计算”本身并不保证成功。同一个方程可以改写出多种迭代式，有的收敛，有的在两个数之间来回跳动。

本章先用二分法保留一个含根的区间，再研究不动点迭代为什么收敛、误差缩小得多快。在此基础上，用切线构造 Newton 法，用两个点构造割线法。最后把这些思想推广到非线性方程组。
