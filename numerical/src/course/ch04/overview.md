# 第 4 章 非线性方程与非线性方程组的迭代解法

解 $f(x)=0$ 往往容易写出很多迭代式，难的是证明它们会走向需要的根。本章先找可靠区间，再设计迭代，最后比较精度与代价。对应第 7 讲末、第 8–9 讲及教材 4.1；4.2 的非线性方程组按教材拓展。

## 从一个问题进入整章

先读 [4.1 的 $\sqrt2$ 三种迭代](sec41.md)：一个来回跳，一个线性收敛，一个在根附近按平方缩小误差。它们的根相同，却有不同的动力学行为。“方程等价”和“算法收敛”必须分别证明。

| 顺序 | 本次要回答的问题 | 正文与练习要求 |
|:--|:--|:--|
| 夹根 | 怎样保证区间里有根？误差由什么保证？ | [二分法](sec41.md)：记录区间、中点、区间长度；区分区间长和中点误差 |
| 构造迭代 | 为什么迭代不会走出去，而且越来越近？ | [不动点](sec41.md)：分别验证自映射、压缩，再推误差界 |
| 提高速度 | 怎样让误差的一阶项消失？ | [Newton](sec41b.md)：由 Taylor 展开推迭代式，检查简单根与初值条件 |
| 扩大可靠性 | 初值较远时有什么额外保证？ | 同节大范围收敛定理：给每条条件标出证明中用到的位置 |
| 节省导数 | 不计算导数要付出什么？ | 割线与单点割线：记录函数求值数、残差和停止理由 |

## 核心证明怎样练

不动点证明先完成“中值定理 → 压缩 → 几何级数”；Newton 局部分析先完成“误差恒等式或 Taylor 式 → 一阶项消失 → 分母不为零”。第一遍先补这两条链，再独立写完整证明。

常见的二阶 Newton 定理要求根附近足够光滑、$f'(s)\ne0$ 且初值充分接近。重根、导数很小或离根很远时，不能直接套用。同样，割线法的黄金比例阶是适当光滑性、简单根与局部非退化条件下的结论，不是对任意函数和任意初值的承诺。

## 一道题至少写三个停止理由中的一个

| 已知信息 | 可给出的保证 | 不应混淆的说法 |
|:--|:--|:--|
| 二分括区间 $[a_k,b_k]$ | 中点误差不超过 $(b_k-a_k)/2$ | 区间长与中点误差相差因子 $2$ |
| 不动点压缩常数 $q<1$ | 误差不超过 $q\lvert x_k-x_{k-1}\rvert/(1-q)$ | 相邻差不能脱离 $q$ 单独解释 |
| 根与近似值之间有 $\lvert f'\rvert\ge m>0$ | 由中值定理得 $\lvert x-s\rvert\le\lvert f(x)\rvert/m$ | 小残差不自动等于小根误差 |

实现还需要最大迭代次数、零分母和非有限数值的处理。它们属于异常退出，不应记作“达到精度”。

## 闭卷迁移：缩放函数会改变根吗？

::: ex 残差的尺度
$f(x)=x-1$ 与 $g(x)=10^{-12}(x-1)$ 有相同根。对 $x=2$，如果都用“残差小于 $10^{-8}$”停止，会发生什么？Newton 的精确迭代是否因这个非零常数缩放而改变？
:::

::: sol 参考解答
$f(2)=1$ 不通过，$g(2)=10^{-12}$ 却通过，但两者根误差都为 $1$。Newton 比值 $g/g'=f/f'$，精确迭代不变。残差阈值须考虑尺度，或结合导数下界、括区间及经过论证的误差估计。
:::

## 入门短题（旧版保留）

::: ex 4.A · 二分法步数
已知连续函数在 $[1,2]$ 两端异号，要求二分后的区间长度不超过 $10^{-3}$，至少折半多少次？
:::
::: sol 参考解答
$2^{-n}\le10^{-3}$，故至少 10 次。这里控制的是区间长度；输出最终区间中点时，根位置误差界是区间长度的一半。
:::

::: ex 4.B · 不动点收敛
验证 $\varphi(x)=\cos x$ 在 $[0,1]$ 上的自映射与压缩条件，并判断收敛阶。
:::
::: sol 参考解答
由单调性，像为 $[\cos1,1]\subset[0,1]$；$|\varphi'|\le\sin1<1$。所以任意区间内初值都收敛到唯一不动点 $s$；$0<\sin s<1$，局部恰为线性收敛，且通常交替趋近。
:::

::: ex 4.C · Newton 两步
对 $f(x)=x^2-2$，$x_0=1.5$，算两次 Newton 更新并说明误差关系。
:::
::: sol 参考解答
$x_1=17/12\approx1.4166667$，$x_2=577/408\approx1.4142157$。令 $e_k=x_k-\sqrt2$，则 $e_{k+1}=e_k^2/(2x_k)$，该恒等式解释了单根附近的二阶速度。
:::

::: ex 4.D · 验证全局四条件
对 $f(x)=x^2-2$、区间 $[1,2]$、初值 $x_0=2$，逐条验证大范围收敛定理的条件。
:::
::: sol 参考解答
$f(1)f(2)=-2<0$，$f''=2>0$，$f'=2x>0$，且 $f(2)f''(2)=4>0$。因此该初值的 Newton 迭代收敛到区间内唯一根。定理所称“大范围”仍带初值侧的条件。
:::

::: ex 4.E · 割线法的阶
为什么割线法通常出现黄金比例阶，而固定端点后通常只有一阶？
:::
::: sol 参考解答
光滑简单根与非退化条件下，割线满足 $e_{k+1}\sim Ce_ke_{k-1}$，配平渐近幂次得 $p^2=p+1$。固定端点后则由一个固定迭代函数控制，若根处导数模在 0 与 1 之间即线性收敛；其他边界不能一概判为一阶。完整条件及因子见[推导回忆卡](recall-cards.md#recall-secant-order)。
:::
