# 闭卷回忆卡 · 第 4 章：非线性方程的迭代解法

## A. 定义卡

**A1.** 什么叫不动点迭代？把 $f(x)=0$ 变成迭代问题的关键是什么？
::: sol
找等价形式 $x=\varphi(x)$，迭代 $x_{k+1}=\varphi(x_k)$。关键在**选 $\varphi$**：不同的 $\varphi$ 给出完全不同的收敛速度（甚至不收敛）。常用构造：① 移项 $\varphi(x)=x+\lambda(x)f(x)$；② Newton 的 $\varphi(x)=x-\dfrac{f(x)}{f'(x)}$ 就是取 $\lambda(x)=-1/f'(x)$。（✓ / △ / ×）
:::

**A2.** 收敛阶怎么定义？阶越高越好吗？
::: sol
对收敛且不在有限步终止的序列，若 $\lim_{k\to\infty}|e_{k+1}|/|e_k|^p=C$，其中 $0<C<\infty$，则称恰为 **$p$ 阶收敛**；线性收敛还要求 $C<1$。$C=0$ 不能用来宣称“恰为该阶”。阶数描述局部渐近速度，总效率还取决于误差常数、初值和每步成本。（✓ / △ / ×）
:::

## B. 定理卡

**B1.** 压缩映射不动点定理的条件与结论是什么？
::: sol
条件：$\varphi:\,[a,b]\to[a,b]$（**自映射**）且存在 $L<1$ 使 $\lvert\varphi'(x)\rvert\le L$（**压缩**）。
结论：存在**唯一**不动点 $s$；任意初值 $x_0\in[a,b]$ 的迭代都收敛到 $s$；且有先验估计 $\lvert x_k-s\rvert\le\dfrac{L^k}{1-L}\lvert x_1-x_0\rvert$ 与后验估计 $\lvert x_k-s\rvert\le\dfrac{L}{1-L}\lvert x_k-x_{k-1}\rvert$。（✓ / △ / ×）
:::

**B2.** Newton 法的全局收敛四条件是什么？
::: sol
设 $f\in C^2[a,b]$：① $f(a)f(b)<0$（异号）；② $f''$ 在 $[a,b]$ 上不变号；③ $f'\ne0$；④ $x_0\in[a,b]$ 且 $f(x_0)f''(x_0)>0$。则 Newton 迭代收敛到区间内唯一根。初值条件比较的是函数值与二阶导数的符号，与 $b-a$ 的符号无关。（✓ / △ / ×）
:::

**B3.** Newton 法为什么至少二阶？重根时为什么掉阶？
::: sol
设 $f\in C^2$、$f(s)=0$、$f'(s)\ne0$，根附近可取 $|f'|\ge m_0>0$、$|f''|\le M$。Taylor 展开给出 $|e_{k+1}|\le M|e_k|^2/(2m_0)$，因此局部至少二阶，不要求 $f''(s)\ne0$。若 $s$ 为有限 $m\ge2$ 重根，写成 $f(x)=(x-s)^m g(x)$、$g(s)\ne0$，连续延拓后的迭代函数满足 $\varphi'(s)=1-1/m$，普通 Newton 线性收敛；已知重数时用 $x-mf/f'$ 可恢复至少二阶。$m>2$ 时 $f''(s)=0$，不能把所有重根都当二重根。（✓ / △ / ×）
:::

## C. 方法卡

**C1.** 课堂自选题 $x-\ln x=2$（$[2,4]$）的验证四步是什么？
::: sol
取 $\varphi(x)=2+\ln x$。① 连续性与异号：$f(x)=x-\ln x-2$，$f(2)=-\ln2<0$，$f(4)=2-\ln4\approx0.614>0$，端点异号；② **自映射**：$\varphi([2,4])=[2+\ln2,\,2+\ln4]\subset[2,4]$；③ **压缩**：$\varphi'(x)=1/x\le1/2<1$；④ 收敛与误差估计。答案区间在 $[2,4]$，迭代 $x_{k+1}=2+\ln x_k$ 收敛。（✓ / △ / ×）
:::

**C2.** 非线性方程组的 Newton 法怎么写？每步代价是什么？
::: sol
设 $F(\boldsymbol x)=\boldsymbol 0$，Jacobi 矩阵 $J(\boldsymbol x)=\partial F/\partial\boldsymbol x$。Newton 步为

$$
J(\boldsymbol x^{(k)})\Delta\boldsymbol x=-F(\boldsymbol x^{(k)}),\qquad
\boldsymbol x^{(k+1)}=\boldsymbol x^{(k)}+\Delta\boldsymbol x .
$$

每步解一个 $n$ 元线性方程组（不是显式求 $J^{-1}$）；在根附近 $J$ 满足适当的 Lipschitz 条件、根处非奇异且初值足够近时平方收敛。差商近似 $J$ 时，是否超线性还取决于差商误差是否随迭代趋零，不能只因“不用解析导数”就断言超线性。（✓ / △ / ×）
:::

**C3.** 单点割线法究竟需要几个给定点？缓存后每步算几次函数？
::: sol
需要固定端点 $c$ 与不同的迭代初值 $x_1$，或明确另外生成第一步。取 $x_1=c$ 会使分母为零。缓存 $f(c)$ 与当前 $f(x_k)$ 后，每步只需一次新的函数求值；线性收敛也必须检查固定点迭代的局部因子。（✓ / △ / ×）
:::

**C4.** 如何识别“改写后换了方程”和“振荡但收敛”？
::: sol
$x=1+1/x$ 等价于 $x^2-x-1=0$，不等价于 $x^3-x-1=0$。从 1.5 出发，它交替趋向黄金比 $(1+\sqrt5)/2$。先代数检查根是否相同，再用误差或压缩条件判断收敛，不能把正负交替当成发散。（✓ / △ / ×）
:::

## D. 闭卷推导卡

**D1.** Newton 的四幅初值图怎样统一记忆？
::: sol {#recall-newton-four-cases}
在大范围收敛定理的其他条件成立且 $f''$ 严格定号时，逐行用 $f(x_0)f''(x_0)>0$ 判断：

| $f'$ | $f''$ | 要求 $f(x_0)$ | 初值相对根的位置 |
|:--:|:--:|:--:|:--:|
| 正 | 正 | 正 | 右侧 |
| 正 | 负 | 负 | 左侧 |
| 负 | 正 | 正 | 左侧 |
| 负 | 负 | 负 | 右侧 |

例如 $f=x^3-3x+1$ 在 $[0,0.9]$ 内严格递减且 $f''\ge0$，应选根左侧、函数值为正且 $x_0>0$ 的点，例如 $x_0=0.2$。根右侧并不适合套该充分条件。（✓ / △ / ×）
:::

**D2.** 不动点与 Newton 的证明各缺哪一步就不完整？
::: sol {#recall-root-proof-chain}
不动点：自映射给 $\varphi(a)-a\ge0$、$\varphi(b)-b\le0$，连续性给存在；中值定理给 $|s-t|\le L|s-t|$，从 $L<1$ 得唯一；再将相邻差压缩所得的几何尾和加起来，才得到后验误差界。

Newton：在小邻域取 $|f'|\ge m_0>0$、$|f''|\le M$，在当前点把 $f(s)=0$ 作二阶 Taylor 展开，得
$$e_{k+1}=\frac{f''(\xi_k)}{2f'(x_k)}e_k^2,\qquad |e_{k+1}|\le\frac{M}{2m_0}|e_k|^2.$$
邻域还须取到足够小，使迭代保持在其中。这个证明只需 $C^2$，无须为了求 $\varphi''(x)$ 引入题目未给的三阶导数；单根也不保证 $f''(s)\ne0$。（✓ / △ / ×）
:::

**D3.** 黄金比例阶和单点割线的线性因子来自哪里？
::: sol {#recall-secant-order}
光滑简单根附近，且 $f''(s)\ne0$ 时，割线误差满足
$$e_{k+1}=\left(\frac{f''(s)}{2f'(s)}+o(1)\right)e_ke_{k-1}.$$
用渐近模型 $|e_k|\asymp|e_{k-1}|^p$ 配平幂次，得到 $p=1+1/p$、$p=(1+\sqrt5)/2$。这是阶数来源的推导思路，使用时仍需局部收敛和不退化条件；不能把模型本身当成任意初值都收敛的证明。

固定端点 $c$、另给不同初值时，迭代函数在单根处的导数为
$$\psi'(s)=1-\frac{f'(s)(c-s)}{f(c)}\qquad(f(c)\ne0).$$
若 $0<|\psi'(s)|<1$，局部恰为线性；若模大于 1 则排斥；模等于 1 时此判据不能判断，导数为零时还需分析更高项。（✓ / △ / ×）
:::
