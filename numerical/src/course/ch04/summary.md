# 第四章小结：构造能收敛的迭代

方程可以有多种等价改写，但不同改写产生的迭代不一定都收敛。分析一个迭代时，先检查它的不动点是否仍是原方程的根，再研究它从哪些初值出发会收敛。

| 方法 | 每步需要什么 | 主要结论 |
|:--|:--|:--|
| 二分法 | 连续函数在异号端点与中点处的值 | 区间每步减半，可以直接控制误差 |
| 不动点迭代 | $x_{k+1}=\varphi(x_k)$ | 闭区间上的自映射与压缩条件保证唯一不动点和区间内任意初值收敛 |
| Newton 法 | 函数值和导数 | 光滑单根附近至少二阶收敛；离根较远时要另查条件 |
| 割线法 | 最近两点的函数值 | 非退化单根附近通常为约 $1.618$ 阶收敛 |
| Steffensen 法 | 连续两次不动点函数计算 | 在相应局部条件下可加速到至少二阶 |
| 方程组 Newton 法 | Jacobian 与一次线性求解 | 单根的矩阵对应条件是解处 Jacobian 非奇异 |

收敛速度与停止条件解决不同问题。收敛阶描述误差足够小时怎样递减；后验误差界则帮助判断当前是否达到要求。相邻两步很接近，可能是误差已经小，也可能只是迭代更新很慢，应结合可用的误差界或残差与导数条件判断。

Newton 法遇到重根时通常退化为线性收敛。已知重数时可修正更新式；导数昂贵时可考虑割线或差商近似。方法选择要同时考虑每步成本、可用信息和收敛范围。
