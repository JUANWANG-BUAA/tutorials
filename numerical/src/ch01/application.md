# 第一章 · 真实应用案例：GPS 定位的误差预算

GPS 定位把第一章的误差分类、误差传播和矩阵范数连在了一起：测得的距离带有误差，卫星几何决定这些误差怎样传入位置与钟差估计。本页用四颗卫星的简化模型计算这一过程，并区分几何精度因子 GDOP 与矩阵条件数。

::: intuition 直觉 · GPS 在解一个什么方程
卫星告诉你「我到你有多远」——这个距离称为伪距，你据此反推自己的坐标。四颗卫星给出四个观测，要估计的量是三个位置分量和接收机钟差。方程数够了，还须检查线性化后的几何矩阵是否非奇异。如果卫星方向过于集中，几何矩阵可能接近奇异，同样的测距扰动会造成更大的解误差。
:::

## 一、定位方程与线性化

设接收机位置为 $\boldsymbol{p}=(x,y,z)^{\mathrm T}$，钟差用距离量 $d$ 表示，即接收机时钟偏差乘以光速。第 $i$ 颗卫星的位置 $\boldsymbol{s}_i$ 已知，测得的伪距为

$$\rho_i=\lVert\boldsymbol{p}-\boldsymbol{s}_i\rVert_2+d+\eta_i\qquad(i=1,2,3,4), \tag{A.1}$$

其中 $\eta_i$ 是测距噪声，来源包括电离层延迟、多径、接收机噪声等。这是一个非线性方程组，要先在近似位置 $\boldsymbol{p}_0$（例如上一次定位结果）处把它线性化：记 $\Delta\boldsymbol{p}=\boldsymbol{p}-\boldsymbol{p}_0$、$\boldsymbol{u}_i=\dfrac{\boldsymbol{p}_0-\boldsymbol{s}_i}{\lVert\boldsymbol{p}_0-\boldsymbol{s}_i\rVert_2}$ 为**单位视线向量**，则

$$\Delta\rho_i\approx\boldsymbol{u}_i^{\mathrm T}\Delta\boldsymbol{p}+d+\eta_i,\qquad G\begin{pmatrix}\widehat{\Delta\boldsymbol{p}}\\\hat d\end{pmatrix}=\Delta\boldsymbol{\rho}, \tag{A.2}$$

$$G=\begin{pmatrix}u_{1x}&u_{1y}&u_{1z}&1\\u_{2x}&u_{2y}&u_{2z}&1\\u_{3x}&u_{3y}&u_{3z}&1\\u_{4x}&u_{4y}&u_{4z}&1\end{pmatrix}\in\mathbb{R}^{4\times4}. \tag{A.3}$$

右端 $\Delta\rho_i=\rho_i-\|\boldsymbol p_0-\boldsymbol s_i\|_2$ 含观测噪声；（A.2）右式用观测右端求解位置与钟差的估计，帽号用于区别估计值和真值。

**$G$ 称为几何矩阵**：前三列记录四颗卫星在天空中的方向，最后一列全为 $1$，对应钟差。于是定位问题（A.2）化为一个 4 阶线性方程组，本章的误差传播理论立刻适用：在给定线性化模型中，$G^{-1}$ 描述右端扰动如何传入位置与钟差；放大多少还取决于扰动方向。这里 $\Delta\boldsymbol{\rho}$ 是观测减去近似几何距离所得的右端，并非全部都是误差。

## 二、误差链条上的四类误差（对应 1.2.1）

下面用 [1.2.1](sec12.md#sec-1.2.1) 的四类误差，逐环节清点 GPS 的误差来源：

| 环节 | 误差类型 | GPS 中的具体来源 |
|:--|:--|:--|
| 建模 | **模型误差** | 用直线传播代替对流层折射；把地球当作球体；忽略相对论效应 |
| 测量 | **观测误差** | 星历误差（卫星轨道预报不准）、电离层 / 对流层延迟、多径、接收机噪声 |
| 近似求解 | **截断误差** | （A.2）是一阶 Taylor 近似；在局部光滑条件下忽略二阶项，重新线性化有助于减小它，但仍需检查迭代收敛 |
| 机器执行 | **舍入误差** | 双精度舍入单位约 $u=1.1\times10^{-16}$；最终求解误差还取决于算法、维数和几何条件，不能直接等同于 $u$ |

同样的观测噪声在不同卫星几何下会产生不同的估计误差，这对应 [1.2.3](sec12.md#sec-1.2.3) 的误差传播和 [1.2.6](sec12.md#sec-1.2.6) 的问题敏感性。稳定算法能避免额外的数值损失，却不能改变既定几何的敏感性；增加观测、改变可用卫星组合或引入额外约束，会改变原来的估计问题。

## 三、几何放大倍数：区分 GDOP 与条件数

记位置与钟差组成的估计量为 $\boldsymbol\xi$。对非奇异 $G$，右端扰动满足
$$\delta\boldsymbol\xi=G^{-1}\delta\boldsymbol\rho,\qquad
\|\delta\boldsymbol\xi\|_2\le\|G^{-1}\|_2\|\delta\boldsymbol\rho\|_2.$$
这是给定右端扰动的绝对误差界；[2.4](../supplement/sec24.md) 的相对条件数还包含 $\|G\|_2$。

若四个测距误差均为零均值、不相关且标准差同为 $\sigma_\rho$，则线性化估计误差的协方差为
$$\operatorname{Cov}(\delta\boldsymbol\xi)=\sigma_\rho^2Q,\qquad Q=(G^{\mathrm T}G)^{-1}.$$
于是几何精度因子定义为
$$\mathrm{GDOP}=\sqrt{\operatorname{tr}Q},\quad
\mathrm{PDOP}=\sqrt{Q_{11}+Q_{22}+Q_{33}},\quad
\mathrm{TDOP}=\sqrt{Q_{44}}. \tag{A.4}$$

GDOP 合成了三个位置分量与距离单位钟差的方差；只讨论三维位置误差，应使用 PDOP。在上述噪声假设下，位置误差的均方根为 $\sigma_\rho\mathrm{PDOP}$，位置与钟差合成误差的均方根为 $\sigma_\rho\mathrm{GDOP}$。它们不是不附条件的误差上限，也不直接给出某个置信概率。

本页的方阵情形下，$\mathrm{GDOP}=\|G^{-1}\|_F$，而 $\mathrm{cond}_2(G)=\|G\|_2\|G^{-1}\|_2$。两者都反映几何敏感性，但数值与定义不同。DOP 与协方差的定义可查 [ESA Navipedia：Positioning Error](https://gssc.esa.int/navipedia/index.php/Positioning_Error)。

::: method 两组可复算的示例几何

把接收机放在原点，为四颗卫星各取一组（方位角，仰角）坐标：

| 情形 | 四颗卫星（方位°, 仰角°） | $\mathrm{cond}_2(G)$ | GDOP |
|:--|:--|:--:|:--:|
| **好几何** | $(0,90),(120,10),(240,10),(0,10)$ | $3.25$ | $\mathbf{1.96}$ |
| **差几何** | $(0,60),(120,60),(240,60),(0,80)$ | $36.11$ | $\mathbf{13.63}$ |

这两组方向是人为选取的对照数据。第二组卫星方向较集中，其 GDOP 约为第一组的 7 倍；按本页的噪声模型，这比较的是位置与钟差合成误差，位置部分要另算 PDOP。

:::

## 四、误差预算：把数字算出来

作为计算示例，取 $\sigma_\rho=5$ m，并沿用零均值、不相关、同方差的假设。两种误差度量的结果如下：

| 几何 | PDOP | GDOP | 三维位置 RMS | 位置与钟差合成 RMS |
|:--|:--:|:--:|:--:|:--:|
| 好几何 | $1.824$ | $1.965$ | $9.12$ m | $9.82$ m |
| 差几何 | $10.273$ | $13.634$ | $51.36$ m | $68.17$ m |

例如，好几何的三维位置 RMS 是 $5\times1.824\approx9.12$ m。实际数据可能带有偏差、相关性或不同的观测方差，届时应修改误差模型；不能把这里选定的 5 m 当作所有接收机和环境的固定指标。

::: ex 案例计算 · 好几何下的 GDOP 与误差传播 {#ex-case-gps}

用（A.3）构造好几何下的 $G$，计算 $\mathrm{cond}_2(G)$ 与 GDOP，并回答：若某颗卫星突然失效、只剩三颗可用（未知数仍是 4 个，方程数不足），会发生什么？

::: proof 解与代码
好几何的单位视线向量（取近似位置 $\boldsymbol{p}_0=\boldsymbol{0}$）为

$$G=\begin{pmatrix}
0&0&-1&1\\
-0.853&0.492&-0.174&1\\
0.853&0.492&-0.174&1\\
0&-0.985&-0.174&1
\end{pmatrix},\qquad
G^{\mathrm T}G=\begin{pmatrix}
1.455&0&0&0\\
0&1.455&0&0\\
0&0&1.090&-1.521\\
0&0&-1.521&4.000
\end{pmatrix}.$$

按未舍入的三角函数值构造时，水平分量与其余分量解耦；上面两个矩阵仅显示三位小数，不能把显示值相乘当成精确恒等式。解耦不表示误差不放大，各分量方差仍由 $Q$ 的对角元给出。计算得 $\mathrm{cond}_2(G)\approx3.25$、GDOP $\approx1.965$、PDOP $\approx1.824$；当 $\sigma_\rho=5$ m 时，三维位置 RMS 约为 $9.12$ m。

```python
import numpy as np
R = 26560e3                                    # GPS 轨道半径（m），用于还原卫星位置
def Gmat(pairs, R=R):
    S = np.array([[np.cos(np.radians(e))*np.sin(np.radians(a)),
                   np.cos(np.radians(e))*np.cos(np.radians(a)),
                   np.sin(np.radians(e))] for a, e in pairs]) * R
    U = -S / np.linalg.norm(S, axis=1)[:, None]   # 单位视线向量
    return np.hstack([U, np.ones((4, 1))])        # 末列是钟差

def report(pairs, name):
    G = Gmat(pairs)
    Q = np.linalg.inv(G.T @ G)
    gdop = np.sqrt(np.trace(Q))
    pdop = np.sqrt(np.trace(Q[:3, :3]))
    print(f"{name}: cond2(G)={np.linalg.cond(G):6.3f}  "
          f"GDOP={gdop:6.3f}  PDOP={pdop:6.3f}  "
          f"σ=5m → 位置RMS {pdop*5:5.2f} m，合成RMS {gdop*5:5.2f} m")

report([(0,90),(120,10),(240,10),(0,10)],      "好几何")
report([(0,60),(120,60),(240,60),(0,80)],      "差几何（聚顶）")
```

```text
好几何: cond2(G)= 3.249  GDOP= 1.965  PDOP= 1.824  σ=5m → 位置RMS  9.12 m，合成RMS  9.82 m
差几何（聚顶）: cond2(G)=36.112  GDOP=13.634  PDOP=10.273  σ=5m → 位置RMS 51.36 m，合成RMS 68.17 m
```

**只剩三颗星：** $G$ 变成 $3\times4$，（A.2）成为欠定方程组——**方程数少于未知数，定位问题本身没有唯一解**。这正是「至少需要四颗卫星」的根本原因：位置与钟差须联合估计，不能将某一颗卫星单独分配给钟差。若用上一时刻的位置或已知高程等信息补充约束，可能重新得到可解的估计问题；这种处理引入了额外假设，属于 [1.2.6](sec12.md#sec-1.2.6) 所说的重述问题。
:::

## 五、历史教训：误差失控的两个真实事故

GPS 案例分析了观测误差怎样传入估计结果。下面再看两起历史事故，分别说明时间转换中的表示误差和数据类型转换的范围限制。

::: think 案例一 · Patriot 导弹系统（1991 年，海湾战争）
系统时钟以十分之一秒为单位记录整数计数，再将计数换算为秒。[GAO/IMTEC-92-26 报告](https://www.gao.gov/assets/imtec-92-26.pdf)第 5–7 页及附录 II（第 15 页）指出，24 位计算中的时间转换精度不足，偏差随连续运行时长增大；事故时系统已运行超过 100 小时。[报告原件的大学镜像](https://www-users.cse.umn.edu/~arnold/disasters/GAO-IMTEC-92-96.pdf)中，100 小时时间偏差约为 $0.3433$ 秒，跟踪范围门的位置偏移约为 $687$ m。1991 年 2 月 25 日，来袭导弹未被拦截，击中营房，造成 28 人死亡。

可以用下面的简化计算理解量级：若用于换算的 $0.1$ 近似值偏小约 $9.54\times10^{-8}$，100 小时对应的计数为 $100\times3600\times10=3.6\times10^6$，时间误差便约为 $0.343$ 秒。这是一个转换系数误差乘上大计数的放大过程，不能描述成每隔 $0.1$ 秒都执行一次加法、把舍入误差逐次相加，也不能直接套用 $nu$ 作为事故原因。

**教训：** 表示误差的影响不仅取决于它有多小，还取决于它乘上的数据尺度，以及新旧计算结果如何用于后续跟踪。第 [1.2.3](sec12.md#sec-1.2.3) 的误差传播分析需要沿着实际计算链进行。
:::

::: think 案例二 · Ariane 5 首飞（1996 年）
Ariane 5 沿用了 Ariane 4 惯性基准系统的部分设计。调查报告指出，异常发生在把一个与水平速度有关的内部校准量 BH（Horizontal Bias）从 64 位浮点数转换为 16 位有符号整数时：数值超出目标整数类型的范围，且该转换没有异常保护。主备系统因同一软件原因失效，诊断数据又被当作飞行数据使用，导致错误控制指令。

这里须分清时间基准：主发动机点火序列开始后约 37 秒，姿态与制导信息完全丢失，相当于离地约 30 秒；随后火箭解体并触发自毁，不能简写成「起飞 37 秒后自毁」。详见 [ESA 调查报告 §2.1，报告页 3–4](https://esamultimedia.esa.int/docs/esa-x-1819eng.pdf)。

**教训：** 这里超出的是 16 位整数的表示范围，并非 64 位浮点数的指数范围。数值代码不仅要检查运算精度，也要检查类型转换的目标范围、输入假设和异常处理。
:::

::: preview 课程预告 · 从「刚好可解」到「最优估计」
本页处理的是**恰好四个观测**、方程数与未知数刚好相等的方阵情形。若有更多独立观测，方程变成**超定**（$G\in\mathbb{R}^{m\times4}$，$m\gt4$），要解的是最小二乘问题 $\min\lVert G\boldsymbol{\xi}-\Delta\boldsymbol{\rho}\rVert_2$——这正是[补充篇 2.2 节](../supplement/sec22.md)讲的投影与最小二乘。可以用 QR 分解（[2.3](../supplement/sec23.md)）求解，并用 $G$ 的奇异值分析几何质量（[2.6](../supplement/sec26.md)）。这给出了简化定位求解器的线性代数部分；完整系统还需卫星状态、时间和传播误差等处理。
:::
