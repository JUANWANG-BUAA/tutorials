## 1.1.1 科学计算：第三种研究方法

现代科学技术问题的研究方法可分为三种：**理论推导、科学实验和科学计算**。三种方法相辅相成，又相互独立、缺一不可。

理论推导给出普适规律，但许多问题（三体问题、湍流、大规模结构）没有闭式解；科学实验直接接触真实世界，但受成本、尺度、伦理限制——不能试飞一百次机翼，更不能对地核做实验。科学计算则在两者之间搭桥：**用计算机模拟代替不可行的实验，用数值解代替不存在的闭式解。**

科学计算的完整链条是：

> **实际问题** ——建立数学模型→ **数学模型** ——离散化→ **数值问题** ——数值方法（算法）→ **数值解**

最后把数值解当作原问题的解交出去。链条的每一环都是一次「翻译」，而**每次翻译都会引入或放大误差**：

| 环节 | 引入的误差 | 例子 |
|:--|:--|:--|
| 实际问题 → 数学模型 | 模型误差 | 把空气当理想流体、把梁当一维杆 |
| 模型参数来自测量 | 观测误差 | 重力加速度 $g$ 只测到 $9.81$ |
| 数学模型 → 数值问题 | 截断误差（方法误差） | 用 Taylor 展开的前 $n$ 项代替 $\sin x$ |
| 数值问题在计算机上执行 | 舍入误差（计算误差） | $1/3$ 存成 $0.3333333333$ |

这张表是全章的地图：[1.2.1](sec12.md#sec-1.2.1) 节将逐一给四类误差下定义，其后的全部内容都在处理最后两类——**我们唯一能通过算法设计控制的误差**。

::: intuition 误差链条的直觉
把这条链条想象成一场**传话游戏**：目击者（实际问题）把看到的事告诉第一个人（数学模型），第一个人再转述给第二个人（数值问题），第二个人再转述给第三个人（算法），最后由计算机写出最终版本（数值解）。每一环都会丢一点信息、加一点噪声，传到最后一棒，结果往往与原始事实相去甚远。

数值分析的工作就是：**承认信息一定会丢，然后精确量化丢了多少**。模型误差和观测误差我们管不了（那是物理学家和实验学家的事），但截断误差和舍入误差——最后两环——是算法设计者能控制的，这也是本章的核心战场。
:::

::: note 名词的边界
「数学模型」指反映实际问题中有关量之间关系的计算公式（方程、方程组、泛函等）；「数值问题」指可以在有限步四则运算内求解的问题（如解线性方程组、算积分的近似值）。有些数学模型要先离散化（微分方程 → 差分方程）才成为数值问题；也有许多问题（如解 $\cos x = x$）本身就是数值问题。
:::

## 1.1.2 数值分析研究什么

**数值分析**（numerical analysis）是计算数学中最基本的内容，它研究两件事：

1. **怎样用数值计算方法求解各种基本数学问题**——线性方程组、特征值问题、非线性方程、插值与逼近、数值积分、微分方程……这是「方法」的层面；
2. **求解过程中出现的收敛性、数值稳定性和误差估计**——这是「可靠」的层面，也是数值分析区别于「编程算数」的本质所在。

::: method 四个关键词 · 贯穿全书
- **收敛性**（convergence）：算法无限做下去，极限是不是问题的解？收敛多快？
- **数值稳定性**（numerical stability）：执行算法时产生的舍入误差，会被压住还是被放大？
- **误差估计**（error estimation）：给出解之前，能不能先给出「解与真值差多少」的定量界限？
- **计算复杂性**（computational complexity）：达到给定精度需要多少计算量、多少内存？

四个关键词两两组合，就是全部数值算法的评审表——本教程在每一个算法面前都会把这张表填一遍。
:::

::: intuition 四个关键词到底在说什么
用大白话把这四个词翻译一遍——

- **收敛性**回答「方向对不对」：步长 $h\to 0$（或迭代次数 $k\to\infty$）时，数值解是不是趋向真解？不收敛的算法再快也没用。
- **稳定性**回答「小扰动会不会炸」：输入有一个小误差（测量噪声、舍入噪声），输出会不会被放大到面目全非？不稳定，就是误差的雪球越滚越大。
- **误差估计**回答「答案可信到什么程度」：不算出真解，能不能先给一个「误差不超过 $\varepsilon$」的保证？没有估计的解只是一个数字。
- **计算复杂性**回答「代价有多大」：同样的精度，谁的 CPU 时间少、内存省？工程中精度和代价永远在博弈。

收敛性和稳定性是**定性**的（行不行），误差估计和复杂性是**定量**的（好多少、贵多少）。全书 12 章的每个算法，都会被这四把尺子量一遍。
:::

随着计算机性能不断提高，科学计算已渗透到科学技术的各个领域：数值天气预报、飞机全机气动仿真、芯片电路仿真（SPICE）、医学影像重建、大模型训练（本质是大规模非凸优化——一个数值分析问题）。**这些应用的可靠性，最终都落在上面四个关键词上。**

## 1.1.3 一个预告性的例子：算出来 ≠ 算对了

在进入技术细节之前，先看一个 30 秒的小实验。取 $\sqrt2\approx1.4$（有误差的输入，就像一切测量数据一样），计算 $(\sqrt2-1)^6$。准确值约为 $0.0050506339$。用六个数学上**完全等价**的公式（证明见[习题 C4](exercises.md)）：

| 公式 | 用 $1.4$ 代入的结果 | 与真值的差 |
|:--|:--:|:--:|
| $(\sqrt2-1)^6$ | $0.004096$ | $9.6\times10^{-4}$ |
| $(3-2\sqrt2)^3$ | $0.008$ | $3.0\times10^{-3}$ |
| $99-70\sqrt2$ | $1.000$ | $9.9\times10^{-1}$ |
| $1/(\sqrt2+1)^6$ | $0.0052328$ | $1.8\times10^{-4}$ |
| $1/(3+2\sqrt2)^3$ | $0.0051253$ | $7.5\times10^{-5}$ |
| $1/(99+70\sqrt2)$ | $0.0050761$ | $\mathbf{2.6\times10^{-5}}$ |

同一个数学问题，六个等价公式，最坏与最好的结果相差**近五个数量级**——第 $3$ 个公式甚至给出 $1.000$，与真值 $0.005$ 毫无关系。差别不在数学（六个公式恒等），而在**计算过程中误差被放大了多少**。

::: preview 课程预告
解释这张表只需要本章的三件工具：

- **误差传播**（[1.2.3](sec12.md#sec-1.2.3)）：六个公式都是 $\sqrt2\approx1.4$ 的函数，输入的误差被放大多少倍，取决于公式「长什么样」；
- **相近数相减**（[1.2.4](sec12.md#sec-1.2.4) 原则 (3)）：$99-70\sqrt2$ 是两个 $\approx10^2$ 的数相减，结果却只有 $10^{-2}$ 量级——最危险的写法；
- **有效数字**（[1.2.2](sec12.md#sec-1.2.2)）：用来数一数每个结果还剩几位可靠数字。

读完 1.2 节后，你应能独立算出每个公式的误差放大因子，并复现这张表的每一行（[习题 C4](exercises.md)）。
:::

这个例子说明数值分析的核心立场：**算法不是公式的机械执行，公式写法本身就是算法设计的一部分。**

## 1.1.5 小结与常见误解

::: method 本节小结
- 科学计算 = 理论推导与科学实验之外的第三条路，链条是「实际问题 → 数学模型 → 数值问题 → 数值解」，**每一环都有误差进入**。
- 数值分析研究**方法**（怎么算）与**可靠**（收敛性、稳定性、误差估计、复杂性）两个层面。
- 公式写法即算法设计：等价公式可以差出五个数量级（$(\sqrt2-1)^6$ 六公式）。
- 全书主线：误差 → 条件数 → 稳定性；第一章负责把「误差」与「尺子（范数）」造好。
:::

::: think 三个常见误解 · 现在就可以检验
1. **「计算机算出来的结果就是对的。」**——反例见 1.1.3 的表格：公式 3 给出 $1.000$，真值是 $0.00505$。计算机只会忠实执行公式，误差是公式与算法的属性，不是机器的「故障」。
2. **「精度不够就提高精度（换 double、加位数）。」**——提高精度只能推迟问题，不能消除方法性的误差放大。六个公式的例子全部用同一精度计算，差别完全来自公式本身。当然，「该用多少位」也是一件严肃的事，[1.2.5](sec12.md#sec-1.2.5) 节给出定量答案。
3. **「误差分析是理论家的事，工程上跑通就行。」**——1991 年 2 月 25 日海湾战争中爱国者导弹系统因累计舍入误差（0.1 秒的二进制表示误差 × 100 小时运行时间）导致拦截失败、28 名士兵死亡；1996 年 Ariane 5 首飞因数值溢出 37 秒后自毁。跑通 ≠ 算对，误差分析是工程义务。
:::
