# 学习目标自检表

第一章共 7 条知识目标、6 条技能目标、4 条素养目标。用法只有一条：逐条自问「能不能做到」；哪一条答不上来，就按右侧「依据与习题」回到对应小节重读，再把那几道题做一遍。目标的完整定义见[学习目标](../preface-objectives.md)。

::: note 配套复习材料
写不出来的条目，先查[公式与结论卡](../review/formula-cards.md)（两章必记项汇总）与[术语索引](../review/glossary.md)（术语 → 定义位置）；时间不够时，[最小必读路径](../review/study-paths.md)告诉你该读哪几页。
:::
