# 第一章 · 绪论

本教程依据颜庆津《数值分析》（第 4 版）第一章「绪论」（原书第 1–13 页）整理、扩充而成，覆盖数值分析的研究对象、误差知识与算法知识、向量范数与矩阵范数三节。**原书 5 条定理、6 道例题、15 道习题全部收录，原编号保留不变**；原书「从略 / 留给读者」的证明一律补全；在此基础上新增 IEEE 754 浮点、向后误差与条件数，以及四组可复现的数值实验。

## 三节一览

这张表是本章唯一的逐节总览：**预习时先扫「核心问题」一列**，看清每节要解决什么；**复习时只读「关键结论」与「典型陷阱」**，逐行自问能否复述。

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[1.1 研究对象](sec11.md)** | 科学计算是什么？数值分析研究什么？ | 问题链条「实际问题 → 数学模型 → 数值问题 → 数值解」；四个关键词（收敛性 / 稳定性 / 误差估计 / 复杂性）；「公式写法即算法设计」——$(\sqrt2-1)^6$ 的六个等价公式相差 5 个数量级 | 误以为「计算机算出来的就是对」；误以为「精度不够就加位」 |
| **[1.2 误差与算法](sec12.md)** | 误差怎么度量、传播、控制？ | 四类误差（[@def-1.2.1]–[@def-1.2.4]）；$\varepsilon$ / $\varepsilon_{\mathrm r}$ / 有效数字三件套（[@def-1.2.5]–[@def-1.2.7]）；误差传播（[@thm-1.2.2]、式 1.1、四则公式）；秦九韶 $O(n)$；算法设计四原则；IEEE 754 公理（[@def-1.2.10]）；向前 / 向后误差与条件数（[@def-1.2.11]） | 把有效数字当小数位数；相近数相减；递推系数 $\lvert\beta\rvert\gt1$ 还正向跑；浮点用 `==` 比较 |
| **[1.3 范数](sec13.md)** | 「向量大小」「矩阵大小」怎么公理化？ | 向量范数三公理（[@def-1.3.1]）；$\lVert\cdot\rVert_{1,2,\infty}$（[@thm-1.3.1]）与 $p$-范数极限；等价定理（[@thm-1.3.3]）；算子范数（[@thm-1.3.4]）；$\lVert A\rVert_1$ 列和、$\lVert A\rVert_\infty$ 行和、$\lVert A\rVert_2=\sqrt{\lambda_{\max}(A^{\mathrm T}A)}$（[@thm-1.3.5]）；F-范数相容但非从属（[@def-1.3.4]）；$\lVert A\rVert\lt1\Rightarrow I\pm A$ 非奇异 + Neumann 级数（[@thm-1.3.6]、[@thm-1.3.7]） | 把 $\lVert AB\rVert=\lVert A\rVert\lVert B\rVert$ 当等式；把 $\lVert A\rVert_2$ 写成 $\lambda_{\max}(A)$；行列混淆 |
