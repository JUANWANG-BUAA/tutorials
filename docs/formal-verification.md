# 矩阵论与数值分析：形式化核验记录

本轮优先核验矩阵论第三章、数值分析课程第二至四章，并抽查内积不等式、范数与插值误差中的代数环节。源文件、断言和期望结果列在 [manifest.json](../tools/formal/manifest.json)，全部可在本地和 CI 重跑。

## 方法与复现

形式化语言采用 **SMT-LIB 2**，逻辑为精确实数上的无量词非线性算术 `QF_NRA`，求解器固定为 **Z3 4.15.4**。每项先检查前提可满足，避免矛盾前提造成空证明；再检查“前提且结论的否定”。证明项预期 `sat → unsat`，反例项预期 `sat → sat` 并保存模型。任何 `unknown`、超时、错误、来源锚点缺失均让门禁失败。

```bash
python3 -m venv .work/formal-venv
.work/formal-venv/bin/python -m pip install -r tools/formal/requirements.txt
Z3_BIN="$PWD/.work/formal-venv/bin/z3" node tools/check_formal.mjs
.work/formal-venv/bin/python tools/check_math_examples.py
```

安装依赖后，也可将虚拟环境的 `bin` 加入 `PATH`，直接执行 `bash check.sh`。结构化结果保存在忽略目录 `output/formal/results.json`，每次运行重建，不将某次日志当作永久证明。

语义参考：[SMT-LIB 的 QF_NRA 定义](https://smt-lib.org/logics-all.shtml)、[Z3 的命题有效性检查](https://microsoft.github.io/z3guide/docs/logic/propositional-logic/)、[Z3 算术理论](https://microsoft.github.io/z3guide/docs/theories/Arithmetic/)。

## 覆盖与结论

当前共 **33 项**形式化义务：**20 项代数结论的否定不可满足**，**13 项反例可满足**。另以精确有理数与 60 位精度重算迭代表，核对正文 **196 个数值**和两种方法的首次停止步数。

| 范围 | 已核验的具体环节 | 限制 |
|:--|:--|:--|
| 内积、行列式、Gram 矩阵 | 实二维/三维 Cauchy–Schwarz 平方式、二维行列式乘法、二维 Gram 核蕴含 | 未推广为任意维复内积空间的形式化定理 |
| QR 与正交结构 | 二维 QR 一步相似恒等式、正交型对角表达式的对称性、幂等补投影；异模两周期和不自动排序反例 | 双侧正交关系作为前提；未形式化任意维 QR 存在唯一性或渐近收敛定理 |
| 矩阵算例 | 例 3.6.1 的三阶零化式与特征基恒等式 | 特征基的非奇异性仍由直接手算核对 |
| 条件数与迭代误差 | 扰动、相对残差、压缩映射后验界中的标量不等式；对称不定条件数反例 | 范数性质、可逆性与极限存在等已明确作为数学前提，未由求解器重建 |
| 幂法 | 缺 Rayleigh 分母、等模方向交替、代数顺序与模顺序混淆的反例 | 不声称有限次计算证明渐近方向收敛 |
| Newton、Steffensen、Halley | 指定多项式的精确误差恒等式、Halley 正半轴误差缩减因子、Steffensen 退化实例 | 一般光滑函数的 Taylor 定理与收敛阶极限仍属人工推导 |
| 二分与插值 | 区间中点误差界、线性插值余项的二次因子界 | 未形式化介值定理或插值余项定理 |
| 数值表 | Jacobi/GS 用精确有理数判停；幂法/反幂法用 60 位精度复算六位小数 | 这是可执行数值回归，不是 SMT 定理证明 |

SMT 反例中有的只编码反例的代数核心：例如 `qr-period-two` 编码上三角元的变号递推，其 QR 分解在正文直接回乘；`steffensen-missing-hypothesis` 编码误差比，另以 `steffensen-exact-map` 验证完整迭代映射。不得将 SAT 模型本身说成一般收敛阶的形式化反证。Newton 四阶例同样另有精确映射证明，极限阶数由正文推导。

## 已修正的问题

| 位置 | 原问题 | 修正 |
|:--|:--|:--|
| 矩阵论 §3.1 | 先列核基，却直接得到左上角秩标准形 | 调整基顺序，补空间在前、核在后 |
| 矩阵论 §3.4 | 将模互异当作全矩阵收敛充分条件，并保证降序排序 | 给出正线 QR 的异模两周期反例；`diag(1,2)` 不动说明不自动排序；补有明确初始条件的正定情形 |
| 矩阵论 §3.4 自测 | 将一般列正交矩阵的正交补误认为固定坐标方向 | 改为 `R(Q)` 的正交补 |
| 矩阵论 §3.6 | 将一般可对角化等同于酉对角化的 Schur 特例 | 非正规可对角化反例，区分一般相似与酉相似 |
| 数值分析 §1.3 | 平方无穷范数例误称满足一次齐次性 | 给出缩放反例，同时指出三角不等式失败 |
| 课程 §2.3 | 对称不定阵也按代数最大/最小特征值相除；大条件数即无解 | 改为最大/最小特征值绝对值之比，区分敏感性与可解性；相对残差补非零右端项 |
| 课程 §2.4 | 谱半径为 1 就必定没有序列极限；要求用不满足的范数判收敛 | 区分任意初值趋向指定解与序列本身有极限；算例改用谱半径 |
| 课程 §2.4 迭代表 | 表值和停止步数不一致 | 重算 Jacobi/GS；Jacobi 首次满足相邻差阈值为第 16 步，GS 为第 9 步 |
| 课程 §3.1 | 幂法特征值必须用二范数、等模仍保证收敛、负主值向量有固定极限 | 保留 Rayleigh 分母即可使用其他归一化；区分方向与向量极限；补等模反例 |
| 课程 §3.1 | 幂法/反幂法表值及指定特征值策略错误 | 重算表格；按代数大小排序不能代替按模排序，位移须保证目标唯一最近 |
| 课程 §4.1 | 固定点收敛阶、Steffensen、开方三阶法缺条件 | 补固定点、光滑性、非终止条件及 `φ′(x*)≠1`；开方法限定正参数和正初值，给精确误差式 |
| 课程 §4.2 | 用“恰二阶”条件证明一般 Newton 局部收敛；二阶导数为零即恰三阶 | 用 Taylor 界证明至少二阶；恰三阶还需三阶导数非零，给四阶反例；重根题去除矛盾条件 |
| 课程 §4.1–4.2 | 二分残差判停混同根误差、收敛阶漏条件、单点割线仅凭单调性断言收敛 | 明确区间判停与恰阶条件；补单点割线局部导数判据及排斥反例，重算非线性表 |
| 复习、速查、题库 | 重复传播上述过强结论；题目将两种规范化索引误作算法正误 | 同步修订；历史讲课标题保留以维持已有链接，并加范围说明 |
| 数值分析实践 | 错解 `eigsh(which='LM')` | 无位移时就是按模最大；位移后作用于变换谱，链接 [SciPy 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.eigsh.html) |

## 尚未完成形式化证明的范围

这是一批有明确范围的机器核验，并不表示两卷已全部形式化验证。Jordan 标准形、任意维谱定理、一般 QR 收敛、Banach 不动点定理、Newton 的一般 Taylor/极限论证，以及未列入 manifest 的正文仍未转换为形式化证明。数值高精度复算、人工审读与 SMT 义务分别报告，不能相互替代。
