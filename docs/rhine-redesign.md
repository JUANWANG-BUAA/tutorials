# 莱茵档案：整体重设计

## 研究依据与判断

主要参考：官方《Rhine Lab: Access》PV（https://www.youtube.com/watch?v=-_HeLFGCw7M）。本地已有原片 5–39 秒分镜及 27.6 / 29.16 / 31.56 / 35 / 39 秒截图，本轮逐帧重新检查。官方漫画入口 https://www.arknights.global/comic?name=Rhodes+Island%27s+Records+Of+Originium+-+Rhine+Lab 用于确认题材来源；漫画正文未被当前工具读取，不作为具体版式证据。同人实现仅作技术参考，不当作官方设计。

PV 的识别要素是暖灰白留白、左上紧凑黑字、规律重复的磨砂档案阵列、杏金局部光、细线与小方点定位、选中对象抬升及镜头展开。教材站借用这套组织方式，文案与模型原创，仍清楚标识教程库。

现状实拍：1440×960、390×844。青色大色块、巨大衬线 ATLAS、黑卡、书架与巨大直立书同时竞争；移动端模型被挤出首屏。此前大量覆盖 CSS 叠加使响应式难以推断。门户样式应整体替换。

## 信息架构与构图

1. 工具栏：教程库身份、书目、路线、构建信息、源代码、皮肤与明暗选择。
2. 首屏：紧凑标题「课程档案 / COURSE ARCHIVE」，左侧约 62% 为档案阵列，右侧约 32% 为当前课程详情。留 6% 呼吸区。详情依次为文件编号、英文领域、中文课程、摘要、真实覆盖范围、进入讲义。无覆盖模型的大型营销字标。
3. 底部完整八项索引；按钮同时显示编号和中文课程。鼠标、方向键、Home/End 可选，触屏可横向滚动。进入讲义始终是明确链接。
4. 目录为细线分隔的课程记录；显示真实进度与待补状态。之后依次是教学图版、四条学习路线、项目说明。
5. 小于 900px 改为标题 → 模型 → 课程详情 → 索引。模型高度有上限，信息不盖在模型上。目录单列；320px 不出现整页横向滚动。

## 颜色、字体与组件

标题与中文界面用系统无衬线，编号用等宽。入口课程标题 32–44px，正文摘要 14–16px；教学页维持读者字号/行距设置。正文表头与语义标签至少 12–13px，不采用 9px 装饰元信息字号。控制最小触控高度 44px。选中状态同时有线条/底色与 aria-pressed，不只靠颜色。

组件：档案索引、课程详情、目录记录、学习路线、教学图版、章节头、定义/定理/例题盒、折叠解答、宽表与代码、搜索及偏好弹层。所有组件共享纸张/文字/细线令牌。正文无连续动画，公式保持原始 KaTeX 字号与横向滚动，宽表不压缩到不可读。

## 三维与动效

模型改为横向薄厚适中的磨砂档案片，三列重复阵列营造资料库纵深；中央列八件对应八门课程，选中件从原槽升起。平面标签、内部双环、四角螺钉与暖色边沿提供近景层次。不要书封开合、漂浮书架、蓝色扫描带。

统一状态：selectedIndex + 每件当前位置。切档用时间步长阻尼收敛，快速切换直接更改目标。首屏短淡入；悬停 160ms，文字切换约 240ms，模型约 800ms 收敛。隐藏标签页或离开首屏时暂停绘制；减少动态效果只绘制必要静态帧。WebGL 失败显示对应封面，所有导航仍由 DOM 提供。

## 视觉闭环与验收

先整体、后组件、再动态：1440×960 检查左右重心/留白与参考帧；390×844 与 320px 检查内容顺序和点击区；浅/深色检查字级与对比；随后逐帧观察快速切档。每一轮记录问题、修改与复拍结果。

教材抽样：矩阵论对角化（长证明/公式/表格）、数值分析第 10 讲（板书图片/长宽表/折叠答案）、机器人位姿（SVG 图版）、编译器与 Linux（代码与目录），另检查八本首页。验证经典往返、持久化、搜索、偏好、打印、键盘和减少动态效果。

实现完成后运行全量构建与主题契约检查，提交明确范围的 commit；既有课程编辑不混入本轮提交。
