## 判断

现有教程已经有值得保留的基础：图解、交互实验、宽图阅读、图鉴定位、公式与折叠推导。问题集中在这些内容进入不同展示容器时失去样式，以及主题、皮肤、偏好、打印对同一属性的重复控制。

建议先恢复图形与文字的正确表达，再建立两套经过验证的配色和组件状态，最后增加局部教学效果。正文应安静；工程感来自准确的图形、坐标、单位、参数、状态和反馈。教程首页可以保留有辨识度的封面与三维档案，长文阅读不必继承首页的展示强度。

## 已确认的问题

### P1：放大和缩略图改变了数学图形的表达

机器人欧拉角页的反函数误差放大图，在正文中正常的 `.diagram-axis`、`.diagram-text`、`.sb`，进入灯箱后丢失样式。

| 属性 | 正文 | 放大灯箱 |
|---|---|---|
| 坐标轴 stroke | `rgb(101,105,92)` | `none` |
| 标题 fill | `rgb(238,238,229)` | 黑色 |
| 下标字号 | `9.1px` | `16px` |
| 下标 baseline-shift | `-18%` | `0px` |

根因：`shared/theme/css/base.css:603` 附近的图形语义样式绑定 `.content figure`，`robot/theme/css/robot.css:81` 的上下标同样依赖该祖先。`shared/theme/js/framework-media.js:66` 将 SVG 克隆到 body 下的 dialog；`shared/theme/js/atlas.js:306` 的图鉴也使用不同容器。因此坐标、文字、上下标与填充规则不能继续匹配。图鉴里部分图形也出现黑色实心块。

修改方向：把图形内部的视觉语义放到独立组件类；正文、缩略图、灯箱都复用。容器只负责布局、缩放和滚动。保留 clone 的 ID 去重，不能简单复制所有旧 ID，也不宜用一份冻结的 inline 计算样式代替响应主题的组件样式。

证据：`visual-review-20261108-figure-results.txt`、`visual-review-20261108-figure-zoom.png`。

### P1：莱茵图鉴的悬停状态接近白底白字

Light＋莱茵，在“图鉴”里悬停第一条目，文字变为 `rgb(248,247,243)`，背景为 `rgb(232,230,223)`，对比约 1.16:1。截图中标题和次级文字明显消失。

根因：`shared/theme/css/atlas.css:1276` 同时反转背景和文字；`shared/theme/css/rhine.css:551` 仅把背景改回浅色。原来的浅色文字仍然生效，`atlas.css:1302` 的次级文字也有相同问题。

修改方向：为 normal、hover、focus、selected、disabled 定义完整前景/背景配对。皮肤不能只改状态的一半。也应检查键盘焦点，不将“鼠标移开后恢复”视为可接受。

证据：`visual-review-20261108-state-results.txt`、`visual-review-20261108-gallery-hover.png`。

### P1：夜间工程蓝污染打印样式

通过 UI 选择 Coal＋工程蓝＋方格纸，再模拟 print，纸面仍为 `#0d1b27`；正文却已转为近黑色。打印媒体截图显示深底黑字。实际打印还受“背景图形”开关影响，本轮确认的是 print CSS 渲染冲突，没有打印实物。

根因：`shared/theme/css/prefs.css:239` 的屏幕调色板不限 screen，特异性超过各书的打印白纸回退；`prefs.css:556` 又将最终 `--page` 作为打印背景。

修改方向：屏幕外观与打印输出分开拥有颜色。打印保持白纸、深字和可区分线型；字体与字号等可继续尊重适用的阅读偏好。

证据：`visual-review-20261108-print.png`、`visual-review-20261108-state-results.txt`。

### P2：背景偏好与实际渲染不一致

“纸张纤维”是默认选中项，但在莱茵阅读页，`.page-wrapper` 的 `background-image` 实际为 `none`；选择“纯净”后也为 `none`。方格纸虽然能写入外层背景，内部 `.page` 的不透明背景又会遮住正文区域纹理。

根因：`shared/theme/js/prefs-config.js:17` 将 paper 设为默认；`shared/theme/js/prefs.js:61` 对默认值删除属性；`shared/theme/css/rhine.css:482` 对无属性情况清除背景，并在下一行给 `.page` 着色。偏好层与皮肤层同时控制同一结果。

修改方向：状态显式区分“跟随方案”与“指定纸张纤维”。背景只在一个最终容器绘制。即使决定默认关闭纹理，也必须让设置面板如实反映状态。

证据：`visual-review-20261108-theme-results.txt`。

### P2：课程清单增长，门户视觉资源与数字未同步

现有目录有 13 门课程。莱茵封面生成器只有 8 门，浏览器对 algorithms、embodied、cpp-rust、edge、mlm 的莱茵 SVG 发出 404，然后回退到经典封面。本轮回退完成后没有持续破图，但封面风格混用且有不必要失败请求。

根因：`shared/theme/js/rhine-portal.js:110` 为所有课程推导图片路径；`tools/theme-renderer/build_art.py:10` 只列出 8 门；`rhine-portal.js:151` 在请求失败后执行回退。经典首页的 `site-index.html:316`、`:322`、`:325`、`:349` 还分别保留“01—10”“十一本”“11 本书”“/ 12”。

修改方向：课程、数量、封面和可用主题资源来自一份清单；构建期检查完整性。缺专属封面时直接使用声明的回退图，不靠 404 发现。

## 审美和阅读上的改进空间

以下是基于实拍的设计判断，不能等同于已证明的学习效率提升。

1. **默认纹理过强。** 经典页三组密集斜线/横线叠在文字后，产生明显织物感。建议阅读区默认纯色，纸感保留在封面或空白边缘。网格用于坐标图、实验画布和草稿区域，具有明确含义。
2. **装饰层级多于信息层级。** 页首档案条、标题卡、重复课程标签、阅读元数据、目录分隔线都争夺首屏。建议合并为课程路径＋标题＋一句学习目标，元信息轻量显示。
3. **手机首屏没有进入教学内容。** 在 390×844 的莱茵矩阵论页面，标题和十条目录占据几乎整个首屏。建议手机目录默认折叠为一行“本节 10 个主题”，正文先出现；保留随时打开目录的入口。
4. **灰色文字和微小元信息过多。** 工程气质可以通过对齐、标注、线型、单位和间距表达，正文标签不必模拟仪器铭牌小字。建议正文从 17px/1.8 行距起评估，控件与图注 13–14px，关键图内标注按实际显示尺寸检查。
5. **颜色需要职责。** 品牌强调色表示链接与选中；定义、结论、注意等有稳定语义；图中不同对象保持固定映射和线型。换主题只调整同一语义的明度与对比，不随意改变含义。

## 推荐视觉方向

### 清晰教材：默认阅读体验

- 中性纸白 / 冷灰夜间底，蓝色作为链接和交互信号。
- 左侧课程目录，正文宽度约 720–820px；宽图可独立扩展，长段落不跟着无限拉宽。
- 标题不套大卡片；定义只用轻底色与细侧线；证明和例题通过结构与标签区分。
- 重点效果是“指向哪里就同步解释哪里”：图中对象、变量、公式步骤之间对应，高亮局部而不让整页动。

### 实验手册：交互密集章节

- 暖灰纸 / 炭灰夜间底，少量黄铜用于控件和章节编号；教学图形仍使用稳定对象配色。
- 桌面在同一局部区域并排放“问题与推导”和“图形与参数”；手机按问题→图→控制→解释排列。
- 参数变化同时更新几何、数值、条件与解释。加入暂停、步进、复位应由具体教学任务决定，不机械给每张图添加播放按钮。
- “清晰教材”与“实验手册”可以成为同一设计系统的页面模板，不必让读者在两个互相覆盖的全站皮肤之间做选择。

会话内预览仅使用二维正交投影小例子演示层级和交互，不代表已重写矩阵论正文，也不能替代实际课程的复杂公式与图形验证。

预览检查：两种方向在 1024/600/390/320px 下检查无横向溢出，320px 夜间与较大正文组合也检查通过；主审亲自通过预览中的鼠标和键盘控件切换两个方向，并操作滑块与折叠推导。60° 时投影为 1.00、垂直分量为 1.73，符合本例长度为 2 的计算。会话宿主的 Tweak 面板未单独实测，不把局部预览的通过扩大为正式教程的通过。

## 代码上的实施顺序

### 第一批：先修复表达正确性

修复 SVG 跨容器样式、图鉴 hover/focus、print 调色板与背景偏好，并同步门户资源清单。给本轮真实失败场景补回归；这些修复无需先选定新审美风格。

### 第二批：建立明确的外观职责

建议状态拆成：

- 明暗：system / light / dark；
- 外观预设：清晰教材 / 档案纸面，预设给出完整表面和控件颜色；
- 阅读偏好：字号、字体、行距、版心；
- 材质：默认纯净，可选轻纸感，只在明确的绘制容器应用；
- 教学组件状态：图中对象、步骤、参数独立于外观预设。

界面常用设置保留明暗、字号与版心；其他选项收在高级设置。旧读者存储值要有迁移映射，不直接清空。旧的 Rust/Navy/Ayu 可以先保留兼容入口，再评估是否需要长期支持。

主题计算提供一份确定结果，DOM、SVG、Canvas 和门户订阅同一变化通知。图形语义色与 UI 强调色分开。组件依赖角色令牌，例如正文、次级文字、面板、边框、焦点、选中状态；不要让每个文件独立判断主题名称。

可用 CSS cascade layers 固化 vendor→tokens→components→skin→preferences→print 的职责顺序，但必须一并梳理 mdBook 原样式和未分层规则。不能只把新 CSS 塞进 `@layer` 就宣称优先级问题解决；未分层普通样式有更高优先级，`!important` 的层顺序另有规则。

无需为这轮改造更换 mdBook 或引入 React。保留静态正文和现有教学组件，先修清晰的边界。

### 第三批：用真实样板页完成视觉验收

先用矩阵论长公式/证明、机器人 SVG/灯箱、Linux 代码/表格和门户组成样板。支持清晰教材与实验手册两种构图后，再扩展到全站；不要一次重做十三本正文。

验收覆盖：

- 浅/深 × 两种预设，桌面/窄屏，普通/hover/focus/selected 状态。
- 同一 SVG 在正文、图鉴、灯箱里的轴线、填充、文字和上下标一致。
- 切换→刷新→跨书→返回仍一致；Canvas 在主题变化后重绘，不依赖无关 class 副作用。
- 长公式、宽表、图注、中文大字号、200% 缩放与减少动态效果；打印白纸深字。
- 普通文字对比度目标至少 4.5:1；必要图形与控件边界按 3:1 检查。两者需要按实际背景与状态测量。
- 图示作用是否清晰：读者能否定位当前变量、说明滑杆改变什么、找到推导和返回阅读位置。以真实任务观察验证，不把视觉复杂度或动画数量当作学习效果指标。

现有 `tools/browser-reader-variants.js:44` 的五主题循环仅检查 main 未隐藏；它无法发现本轮的低对比、坐标轴消失和错误下标。保留已有功能测试，再补关键样式和截图验证。

## 保留与边界

建议保留：可拖动向量/机械臂、逐步演示、图鉴定位、宽图平移、公式复制、折叠推导，以及首页已有按需渲染的 3D 档案。`tools/theme-renderer/scene.js:83` 起已处理减少动态效果、停止连续绘制、离屏/隐藏状态，不能仅因为有三维效果就判定需要重写。

本轮未实测 Safari、Firefox、实体手机、WebGL 性能和最终打印纸张；也未穷举所有偏好组合。一个初步 Canvas 重绘疑点未通过真实 UI 复现，不列为确认故障。菜单白字 hover 的静态怀疑也没有作为已确认问题收入：实际最终计算样式存在其他覆盖。

规范参考：W3C《WCAG 2.2 Understanding SC 1.4.3 Contrast (Minimum)》《SC 1.4.11 Non-text Contrast》与《CSS Cascading and Inheritance Level 5》。以上规范支撑对比和层叠判断；具体视觉取舍为本次建议。
