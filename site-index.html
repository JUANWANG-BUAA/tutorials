PATHS / 02 学习路线 03

从哪里开始

每本书都可以独立开始。下面三条是按学科与前置关系整理的建议顺序，依据来自各书的导览页与入学诊断。

ROUTE A · 系统线

Linux → Agent 与分布式

进程、网络与容器的基础在 Linux 卷里已经讲过；Agent 的沙箱与权限、分布式的 TCP 与容器基础都建立在它上面，两本书都不重讲。

依据：Agent 卷导览写明前置 Linux 第 2、3、5 篇；分布式卷引用 Linux 第 4、5 篇。 05 Linux→06 Agent/07 分布式
ROUTE B · 智能线

深度学习 → Agent

模型基础读深度学习导论；Agent 卷只写新增的系统层：循环、工具、沙箱、上下文与评估，不重讲神经网络与训练。

依据：Agent 卷导览写明「模型基础读《深度学习导论》」。 04 深度学习→06 Agent
ROUTE C · 数学线

矩阵论 → 数值分析 → 机器人

线性映射与矩阵分解是雅可比、广义逆与奇异性的语言；数值分析补上误差控制与数值求解。

依据：机器人卷的入学诊断要求线性代数（正交矩阵、特征值）；第 3 章讲雅可比与广义逆。 02 矩阵论→03 数值分析→01 机器人
