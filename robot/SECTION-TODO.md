## 固定工作流程

每次只推进一个正文小节；节内按三级标题逐项阅读。开始下一节前，先读当前记录和 git diff，接续未完成项。按 SUMMARY 顺序推进；跨页只修正本节结论的直接依赖，不把配套页整体计为已审。

1. **完整阅读**：正文、全部图注/折叠答案/脚本、上一节出口和下一节入口；列出节内每个三级标题及其任务，禁止用搜索命中或抽读代表通读。
2. **列问题再修改**：逐项记录原文位置、问题、对学习的影响、证据和改法。保留清楚的段落，不为改字数重写。
3. **核实内容**：定义写清口径，公式写清假设与单位；逐步复算本节例题；检查反例、退化条件及可能的误读。对照教材原页，版本相关陈述核对官方来源。无法核实的内容注明待核，不当成确认事实。
4. **改善教学**：从读者能理解的问题进入；术语首次解释；逐段检查句意、指代与推导衔接，避免只改公式或堆缩写；给出示范、独立练习和可检查答案；题干与答案一一对应，图表前后说明读法；末尾能闭卷自测并衔接下一节。
5. **审查工具**：每个 SVG/画布/操作台均核对模型、箭头、单位、默认值与文字。交互要求先预测、操作、读数、解释；验证关键输入、重置和读数；桌面键盘操作适用时检查，不增加手机端或无关防御性工作。无适合交互的概念使用纸笔或原生折叠练习，不为数量添加控件。
6. **同步依赖**：更新本节相关习题、答案、回忆卡、总结、自检表、术语/易错点；记录触及哪些条目，其他条目保持未审。
7. **实际验证**：执行本书结构检查和相关数学/运行测试；用根 `./build.sh` 生成含搜索/术语的完整预览；在真实桌面浏览器检查本节演示、答案、关键输入和输出。按 2026-11-11 用户补充，结束前必须亲看整页总览，再检查公式、图示、演示和展开答案的局部画面，记录并修复渲染问题；长页同时检查默认收起与答案展开状态，不能用局部截图代替全页检查。手机端继续暂缓，不作为当前逐节前置条件；运行与数学正确性仍须验证。
8. **复核与结账**：重读最终全文，对照问题表逐项关闭；记录命令、退出状态、结果、截图或日志位置、未覆盖边界。更新本表后再进入下一节。

### 第三章起的补充要求（用户纠正后执行）

- 每个核心公式写出已知、假设、中间变形、使用的数学知识和物理解释，不能用「比较得」「易知」或课堂引语代替推导。
- 对李群/李代数、切空间、叉乘矩阵、指数映射等新增概念，先定义对象、维度、单位与用途，再给可跟算例子和反例；分清姿态、导数、角速度及表达坐标系。

- 教程正文应能独立学习，PPT 作为对照材料；不让读者靠放大截图补回正文漏掉的推导。
- 每节的练习和可视化须帮助解释公式的来源和边界，结束前亲看默认、展开与整页画面。

## 验收规则

状态只允许：待审 → 审读中 → 修改中 → 待验证 → 已验收。遇到问题可退回，不按阅读时长、改动行数、构建成功或截图数量验收。

- [ ] 节内全部内容已读，问题表没有未解释的概念/数学错误。
- [ ] 本节学习目标有对应练习，答案足以让读者判断自己错在哪里。
- [ ] 图示与工具表达正确，适用的浏览器检查实际执行。
- [ ] 直接配套材料已同步；未审范围明确。
- [ ] 构建、结构、相关回归及差异检查有本轮结果；失败项已解决或明确导致本节不能验收。
- [ ] 最终全文复读；逐项记录保留、修改和依据，不写“全书已检查”等范围过大的结论。

每完成一章，再整体核对该章导览、总结、习题、自检、回忆卡、自测卷与作业。全书最后检查卷首/复习层/跨章工具，并运行 `bash check.sh`；逐节通过不能代替最终全站门禁。用户于 2026-11-11 授权本轮结束后提交并推送先前成果。
