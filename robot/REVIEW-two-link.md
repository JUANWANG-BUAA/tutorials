# 两连杆跨章练习复审记录

## 范围与方法

本轮只复审 `src/training/two-link.md` 的四关与变式，以及它直接引用的运动学、雅可比和静力平衡约定。不扩写后续章节，不调整共享样式。这是同一作者的自审，不是独立审稿，也不是全书数学正确性认证。

核对方法：逐式手算；用标准 DH 链独立计算位置、姿态与几何雅可比，并与位置中心差分比较；用力臂计算核对关节力矩；在实际浏览器中检查答案展开、公式与阅读布局。

## 发现与处置

| 项目 | 复审结论与处理 |
|:--|:--|
| 第一关：两支逆解 | 两组关节角均到达 `(1,1) m`，末端指向分别为 `π/2` 与 `0`。保留“只要求位置”的限制。 |
| 第二关与变式：速度 | 两个位形的雅可比和速度回代正确。将姿态差异、两组速度回代纳入持久化测试。 |
| 第三关：奇点 | 伸直时位置雅可比为 `[[0,0],[2,1]]`，秩为 1。补充径向正反方向均不能瞬时产生速度，以及“一阶瞬时限制不等于不能弯曲到内侧”的区别。 |
| 第三关：阻尼 | 阻尼不能产生值域以外的速度。测试增加奇点、近奇点、普通位形下的正规方程残差、速度上界和阻尼权衡。 |
| 第四关：原检验力度不足 | 旧练习只检查两端均为零的功率，算反驱动力矩符号也能通过。增加非零虚速度，两端功率应同为 `1 W`，相反符号应检验失败。明确这里使用虚速度而非动态仿真。 |
| 正文与回忆卡的符号错误 | `src/ch03/sec3-8.md` 的虚功推导由负号中间式跳到正号结论，C4 回忆卡与正文默写答案也有同类问题。局部统一为向外施力 `F_e`、环境反作用力 `-F_e`，由总虚功 `(τᵀ−F_eᵀJ)dq=0` 推出 `τ=JᵀF_e`。 |
| 阅读顺序 | 原导语让第二章读者先做前两关，但第二关已需要第三章雅可比知识。改为第二章后做第一关，学过第三章相应内容再逐关完成。 |
