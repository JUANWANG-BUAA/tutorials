# 机器人教程重构计划

## 目标

将当前"知识点陈列式"教程改造为"任务驱动式"学习路径，解决主线不清、章节割裂、数学动机缺失、记忆点少的问题。**约束：不丢弃任何知识点、不删除老师课堂强调的内容。**

## 四、风险与缓解

### 4.1 锚点失效
**风险**：合并小节后，`[@def-6.1.2]` 指向的文件变了
**缓解**：
1. 合并时保留所有 `<a id="def-6.1.2"></a>` 锚点
2. SUMMARY.md 用 `[6.1.1 动能计算](ch06/sec6-1.md#sec-6.1.1)` 指向锚点
3. 构建前运行 `tools/check_book.py` 检查断链

### 4.2 数值回归失败
**风险**：改写例题时改错了公式
**缓解**：
1. 每改完一个例题，立即运行对应的 `verify_*.py`
2. 不改公式本身，只改公式前后的文字说明
3. 例题的"目标句"和"反思"写在公式盒子外面

### 4.3 老师强调的内容丢失
**风险**：删除铺垫时误删了课堂强调
**缓解**：
1. 所有 `::: note 考点 · 老师原话` 盒子不动
2. 删除前检查：这句话是模板套话，还是老师解释的原因？
3. 改写后对照录播时间戳，检查关键概念是否保留

### 4.4 humanizer 过度删减
**风险**：AI 为了"去AI味"删掉了有用的限定词
**缓解**：
1. 改写后人工复核：条件、范围、归因是否完整
2. 特别检查："可能""假设""在…条件下""老师说"等限定
3. 数学推导的"由…得"不能简化成"所以"（要保留推理依据）

## 五、成功标准

改造完成后，随机抽取一章（例如第三章），检查：

1. **主线清晰**：读者能在章首知道"上一章留下什么问题，本章解决它"
2. **动机明确**：每个公式前都有"为什么需要它"（不超过3句话）
3. **记忆点足**：核心概念都有白话口诀（不超过20字）
4. **例题衔接**：每个例题都有"验证什么"（目标句）和"动手练"（反思）
5. **实验嵌入**：关键推导中途有"停，动手验证"
6. **知识完整**：没有丢失原有的定理、性质、课堂强调、数值算例
7. **工具可用**：`bash check.sh` 通过，浏览器中实验正常
