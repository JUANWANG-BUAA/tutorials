## A. 定义卡

### A1 · 视觉伺服

用一句话定义视觉伺服，并说出它与 look-and-move 的唯一区别。

::: sol A1 核对
把视觉测量**反馈**进控制回路，用「当前看到的」与「应该看到的」之差作为误差来调节。
与 look-and-move 的区别只在这一步：后者把视觉测量开环用一次（识别 → 规划 → 执行），
不修正随时间发生的偏差。（[9.1.1](sec9-1.md#sec-9.1.1)）
:::

### A2 · 位置式与图像式

位置式视觉伺服与图像式视觉伺服的分野是什么？各自的误差是什么？

::: sol A2 核对
分野在**误差定义在哪个空间**。位置式：先实时估计目标相对相机的位姿 $T^c_o$，误差是操作空间的
位姿误差 $x=[o^d_c;\varphi^d_c]$，再按操作空间控制律伺服。图像式：不做位姿估计，误差就是图像
特征差 $e_s=s_d-s$，直接在图像空间伺服。（[9.1.2](sec9-1.md#sec-9.1.2)）
:::

### A3 · 眼在手与眼到手

两种相机装法的优缺点各是什么？

::: sol A3 核对
眼到手（相机固定）：视野不变、测量精度原则上恒定，但机械手可能遮挡工件。
眼在手（相机装在末端）：视野随运动变化、精度随之变化，但末端靠近目标时精度通常更高、
几乎没有遮挡。（[9.1.3](sec9-1.md#sec-9.1.3)）
:::

### A4 · 交互矩阵

交互矩阵 $L_s$ 描述的是什么运动到什么的映射？和图像雅可比 $J_s$ 差在哪？

::: sol A4 核对
$L_s$ 描述**相机自身**的速度 $v^c_c$ 到图像速度 $\dot s$ 的映射，**前提是目标固定**；
$J_s$ 描述**目标相对相机**的速度 $v^c_{c,o}$ 到 $\dot s$ 的映射。
两者可互换：$J_s=L_s\Gamma(-o^c_{c,o})$，秩相同。（[9.4.2](sec9-4.md#sec-9.4.2)）
:::

## B. 结论卡

### B1 · 标定误差为什么对位置式更敏感

::: sol B1 核对
位置式用标定后的量去估位姿，标定误差因此污染**反馈通道**里的量，而反馈通道抗扰能力低。
图像式用的量本来就在图像平面上、期望值也是相机直接实测的，标定误差落在**前向通道**，抗扰能力高。
关键不在「标定准不准」，而在「误差落在环的哪一侧」。（[9.7.4](sec9-7.md#sec-9.7.4)）
:::

### B2 · 为什么单点特征不够

::: sol B2 核对
单点的交互矩阵是 $2\times6$，秩 2，**零空间维数 4**。零空间里含沿视线的平移与绕视线的旋转，
这两种运动**不改变该点在像平面上的位置**——单目丢了一维深度，所以看不出来。
解法：多取点或改用线段特征，让 $k>m$。（[9.4.5](sec9-4.md#sec-9.4.5)）
:::

### B3 · 为什么要内外环分离

::: sol B3 核对
视觉测量的频率（相机帧率）比运动控制低至少一个数量级。不分环就得为保稳定把增益压得很小，
收敛慢、抗扰差。分开后，外环（视觉）慢、只生成期望关节角，内环（运动控制）快、原样不变地跟踪。
内环至少要比外环**快 5 倍**以上。（[9.8.4](sec9-8.md#sec-9.8.4)）
:::

### B4 · 位置式速度分解为什么走直线

::: sol B4 核对
误差方程 $\dot x+Kx=0$ 是线性的，$K$ 取对角阵且位置分量权重相同 ⇒ 每个分量独立指数收敛、
比例恒定 ⇒ 相机原点沿初始点与期望点的**线段**运动。（[9.8.3](sec9-8.md#sec-9.8.3)、
[9.10.2](sec9-10.md#sec-9.10.2)）
:::

### B5 · 相机后退

一句话解释图像式控制里的「相机后退」，并说它的后果。

::: sol B5 核对
绕光轴的纯旋转要求特征点在像平面里走**圆弧**，而图像式要求走**直线**；这个约束迫使相机原点
先退后进。后果：相机路径不可预测，可能违反关节限位或撞上障碍物；期望旋转趋近 $\pi$ 时相机
到目标的距离趋于无穷，系统失稳。（[9.10.3](sec9-10.md#sec-9.10.3)）
:::

## C. 公式卡

### C1 · 投影方程

写出归一化坐标下的投影齐次方程，并解释 $\Pi$ 与 $\lambda_i$ 各是什么。

::: sol C1 核对
$$\lambda_i\tilde s_i=\Pi\,T^c_o\,\tilde r^o_{o,i},\qquad \tilde s_i=[X_i\ Y_i\ 1]^{\mathrm T}.$$
$\Pi$ 取齐次变换的前三维（$4\times3$），$\lambda_i$ 是深度 $z_{c,i}$（正）。归一化坐标的好处是
**方程里不含相机内参**。（[9.3.1](sec9-3.md#sec-9.3.1)）
:::

### C2 · 平面单应与线性方程

共面时 $H$ 是什么？怎么得到关于 $H$ 的线性方程？

::: sol C2 核对
共面（$z_o=0$）时降成平面单应 $\lambda_i\tilde s_i=H[r_x\ r_y\ 1]^{\mathrm T}$，
$H=[r_1\ r_2\ o^c_o]$（$r_1,r_2$ 是 $R^c_o$ 的前两列）。
左乘 $S(\tilde s_i)$（斜对称，$S(v)v=0$）消掉每点各不相同的 $\lambda_i$，得
$S(\tilde s_i)H[r_x\ r_y\ 1]^{\mathrm T}=0$，再摞成 $A_i(s_i)h=0$，
$A_i=[r_{x,i}S\ |\ r_{y,i}S\ |\ S]$。（[9.3.2](sec9-3.md#sec-9.3.2)）
:::

### C3 · 尺度与符号

$|\zeta|$ 怎么定？符号怎么定？为什么不能硬编码？

::: sol C3 核对
$|\zeta|=1/\|h_1\|=1/\|h_2\|$（旋转阵列是单位向量）。符号由「目标在相机前方」定，即
$o_z=(\zeta h_3)_z>0$。**不能硬编码**——SVD 零空间向量的整体符号本身是任意的，
教材印的 $\zeta=-1.5$ 只是那一次求解的结果。（[9.3.2](sec9-3.md#sec-9.3.2)、
[勘误 3](errata.md#err-3)）
:::

### C4 · 最近旋转阵

噪声下 $Q$ 不是旋转阵怎么办？写出解。

::: sol C4 核对
求离 $Q$ 最近的旋转阵：$\min\|R^c_o-Q\|_F$ 等价于 $\max\operatorname{Tr}(R^{\mathrm T}Q)$。
设 $Q=U\Sigma V^{\mathrm T}$，则 $R^c_o=U\operatorname{diag}(1,1,\sigma)V^{\mathrm T}$，
$\sigma=\det(UV^{\mathrm T})$ 保证行列式为 1。（[9.3.3](sec9-3.md#sec-9.3.3)）
:::

### C5 · 单点交互矩阵

写出单点的交互矩阵，并说清哪些列带 $1/z_c$、哪些不带。

::: sol C5 核对
$$L_s(s,z_c)=\frac1{z_c}\begin{bmatrix}
-1/z_c&0&X/z_c&XY&-(1+X^2)&Y\\
0&-1/z_c&Y/z_c&1+Y^2&-XY&-X
\end{bmatrix}.$$
前三列（平移）带深度；后三列（旋转）是纯几何量。相机转一个小角度图像怎么动只看点在画面里的
位置；相机平移一小段还要看它有多远。（[9.4.3](sec9-4.md#sec-9.4.3)）
:::

### C6 · 位姿估计迭代律

写出数值位姿估计的迭代律与它带来的误差方程。

::: sol C6 核对
$e_s=s-\tilde s(\tilde x^c_o)$，$\dot{\tilde x}^c_o=J_{A_s}^{-1}K_se_s$，代入得
$\dot e_s+K_se_s=0$。$K_s$ 正定时误差指数收敛，收敛速度由 $K_s$ 的特征值决定。
用伪逆（$k>m$）时 Lyapunov 导数只是半负定 ⇒ **稳定但非渐近稳定**，可能卡住。（[9.5.2](sec9-5.md#sec-9.5.2)）
:::

### C7 · 位置式与图像式的控制律

写出两类伺服的「PD + 重力补偿」与「速度分解」控制律。

::: sol C7 核对
位置式：$u=g(q)+J_{A_d}^{\mathrm T}(K_Px-K_DJ_{A_d}\dot q)$；速度分解：$\dot q_r=J_{A_d}^{-1}Kx$，
误差方程 $\dot x+Kx=0$。
图像式：$u=g(q)+J_L^{\mathrm T}(K_{P_s}e_s-K_{D_s}J_L\dot q)$；速度分解：$\dot q_r=J_L^{-1}K_se_s$，
误差方程 $\dot e_s+K_se_s=0$。（[9.8](sec9-8.md)、[9.9](sec9-9.md)）
:::

## D. 陷阱卡

### D1 · 「装了相机就是视觉伺服」

::: sol D1 核对
不是。必须把视觉测量接进反馈回路、以视觉量定义的误差去调节。相机只提供测量；
若测量开环用（look-and-move），就不是视觉伺服。（[9.1.1](sec9-1.md#sec-9.1.1)）
:::

### D2 · 「图像式不需要物体几何，所以更简单」

::: sol D2 核对
「不需要物体几何」成立（单目也如此），但代价换到了别处：特征到操作空间的映射是非线性，
可能有奇异与饱和；相机轨迹事先不可预测，可能违反关节限位或撞障碍物；
而且判据变成「投影一致」，在单目多解下不等于位姿唯一。（[9.7.3](sec9-7.md#sec-9.7.3)、
[9.9](sec9-9.md)）
:::

### D3 · 「位置式更准」

::: sol D3 核对
位置式的**位姿估计**更准、误差在操作空间、整定时能直接对时间响应指标；
但它**对标定误差更敏感**（误差在反馈路径），且目标出视野就丢反馈、回路变开环。
更准不等于更适用。（[9.7.2](sec9-7.md#sec-9.7.2)、[9.7.4](sec9-7.md#sec-9.7.4)）
:::

### D4 · 「用了伪逆就等于用了最小二乘，所以结论不变」

::: sol D4 核对
不变的是**误差有界**，不是**误差趋于零**。用左伪逆后 Lyapunov 导数只是半负定（$L_s^{\mathrm T}$
的零空间非空），闭环稳定但**非渐近稳定**，可能出现 $e_s\ne0$ 而 $K_se_s\in N(L_s^{\mathrm T})$
的「卡住」情形。（[9.5.3](sec9-5.md#sec-9.5.3)、[9.9.3](sec9-9.md#sec-9.9.3)）
:::
