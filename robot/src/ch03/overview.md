# 第三章 · 微分运动学和静力学

> **核心问题**：已知各关节的速度 $\dot{\boldsymbol q}$，机械臂末端线速度与角速度是多少？反过来，给出末端期望运动或接触外力 $\boldsymbol F_e$，各关节应有多大速度 $\dot{\boldsymbol q}$ 与静态保持力矩 $\boldsymbol\tau$？

第二章解决了“给定关节角，机械臂末端在哪里（位姿正/逆解）”。但控制机械臂沿轨迹平稳运动或与环境接触施力，必须在速度与力的瞬时线性映射层面建立工具。本章在正运动学求导的基础上建立**几何雅可比矩阵 $J(\boldsymbol q)$** 与**分析雅可比矩阵 $J_A(\boldsymbol q)$**，系统的回答速度合成、奇点降秩、冗余零空间分配、逆微分求解及静力学对偶这五类工程问题（对应原书第 3 章）。

## 从两连杆臂引出速度与奇点问题

沿用第二章平面 2R 机械臂（杆长 $l_1,l_2$，关节角 $q_1,q_2$ 逆时针度量），末端平面位置为

$$\boldsymbol p(\boldsymbol q)=\begin{bmatrix}l_1\cos q_1+l_2\cos(q_1+q_2)\\l_1\sin q_1+l_2\sin(q_1+q_2)\end{bmatrix} \implies \dot{\boldsymbol p}=J_p(\boldsymbol q)\dot{\boldsymbol q}.$$

先思考三个直觉问题，再进入各节严谨推导：
1. **哪些速度方向会突然失效？** 两杆完全伸直（$q_2=0$）时，无论两个关节如何转动，末端在瞬间能否沿着杆身径向产生非零速度？（[3.1 几何雅可比](sec3-1.md)与 [3.3 奇点分析](sec3-3.md)）
2. **多出来的关节能干什么？** 三连杆平面臂如果只控制笔尖位置，多出的一个自由度在速度上服从什么结构，靠近奇点时又如何避免关节飙速？（[3.4 冗余分析](sec3-4.md)与 [3.5 逆微分运动学](sec3-5.md)）
3. **同一个 $J$ 如何换算静力？** 机械臂末端用 $10\,\mathrm N$ 力顶住工件，为什么平衡力矩取决于 $J^{\mathrm T}$ 而不是 $J^{-1}$？（[3.8 静力学](sec3-8.md)与[两连杆第二至四关](../training/two-link.md#mission-velocity)）
