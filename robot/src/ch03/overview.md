# 第三章 · 微分运动学和静力学

本章依据Siciliano等《机器人学：建模、规划与控制》第三章与第3周录播整理，覆盖§3.1–§3.8（2026-09-21，录播时长2:29:00）。正文独立说明概念与推导，时间点用于回看课堂，纯课件插图用于对照。

## 从两连杆臂开始

第二章已能根据关节角 $q_1,q_2$ 求末端位置。现在让两根长度为 $l_1,l_2$ 的杆动起来：

$$p=\begin{bmatrix}l_1\cos q_1+l_2\cos(q_1+q_2)\\l_1\sin q_1+l_2\sin(q_1+q_2)\end{bmatrix},\qquad \dot p=J_p(q)\dot q.$$

**先预测**：当两杆完全伸直时，末端能否瞬时沿杆的方向运动？先画图思考，再读 [3.1 雅可比](sec3-1.md) 与 [3.3 奇点](sec3-3.md)。这里 $J_p$ 只描述平面位置速度，是 $2\times2$ 矩阵；它不是包含角速度的完整几何雅可比。

对上式求偏导得到 $J_p$；令 $q_2=0$，检查其秩并解释丢失的速度方向。接着读 [3.5](sec3-5.md)，核对阻尼的作用与代价，再做[两连杆第二至四关](../training/two-link.md#mission-velocity)，用同一个 $J_p$ 检验速度与功率。

做完后合上正文，解释“末端位置相同，雅可比却可能不同”和“转置不等于求逆”。下次换一组关节角复算。这里算的都是某个瞬间的量；第四章会把这些瞬间连成一段有起停的运动。

## 全章知识联系（据课堂板书整理）

$$\text{运动学}\begin{cases}\text{位姿}\begin{cases}\text{正}&\underline{x}_e=k(\underline{q}),\quad \underline{q}\in\mathbb{R}^{n},\ \underline{x}_e\in\mathbb{R}^{m}\\[1mm]\text{逆}&\underline{q}=k^{-1}(\underline{x}_e)\quad\text{①闭合解 ②数值解}\end{cases}\\[4mm]\text{微分}\begin{cases}\text{正}&\underline{v}_e=J\,\dot{\underline{q}}\ \ \text{或}\ \ \dot{\underline{x}}_e=J_A\,\dot{\underline{q}}\\[1mm]\text{逆}&\dot{\underline{q}}=J^{-1}\underline{v}_e\ \text{或}\ \dot{\underline{q}}=J_A^{-1}\dot{\underline{x}}_e\quad\text{①奇异 ②冗余}\end{cases}\end{cases}\qquad\text{静力}\quad \tau=J^{\mathrm T}F_e$$

课堂在00:19:21用这张图概括全章关系。对第二章的位姿映射求导，得到当前位形的速度映射；奇异与冗余分别影响任务可实现方向和关节速度的选择，不能混为一种问题。静力学则从功率配对得到 $J^{\mathrm T}$，将末端负载换成关节广义力。

## 一条主线

> 对正运动学求导得到当前位形的速度映射；雅可比的列是各关节的瞬时贡献。固定任务后，奇点看秩是否降低，冗余看关节数与任务维数，二者不能等同于“不方阵”。接着按速度代价求逆解、用误差反馈做迭代，最后由功率对偶推导转置传力。（完整版见[全章总结](summary.md)）
