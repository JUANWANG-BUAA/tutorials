## A 组 · 概念判断

::: ex A1 · 雅可比的行与列各代表什么

(a) 几何雅可比 $J\in\mathbb R^{6\times n}$ 的**行**对应什么物理量？**列**呢？(b) 第 $i$ 列 $J_i$ 的物理含义是什么（用「锁死其他关节」的语言说一遍）？(c) 为什么说「雅可比是位形的函数」？

::: sol 解答

(a) 行 $\leftrightarrow$ 操作空间速度的六个分量（$v_x,v_y,v_z,\omega_x,\omega_y,\omega_z$，前 3 行 $J_P$ 线速度、后 3 行 $J_O$ 角速度）；列 $\leftrightarrow$ 关节（第 $i$ 列 = 关节 $i$ 的单位速度作用）（录播 0:21:46）。(b) **其余关节全部锁死、只以单位速度驱动关节 $i$ 时，末端产生的六维速度**——$v_e=J\dot q$ 展开后 $J_i\dot q_i$ 即该项贡献（1:00:52）。(c) $J$ 的每一列由 $z_{i-1},p_{i-1},p_e$ 组成，这些量全从 $T_i^0(q)$ 读取——$q$ 变则 $J$ 变（[@def-3.1.1]）。

:::

::: ex A2 · 三种「不方阵」与三味药

把 $J$ 的方阵满秩 / 行满秩长方 / 不满秩三种情形与 $J^{-1}$、$J^\dagger$、$J^*$ 对号，并各说一句「什么时候用、解的性质」。

::: sol 解答

| $J$ 的情形 | 工具 | 使用条件与解的性质 |
|:--|:--|:--|
| 方阵、满秩（$n=r$，无奇异） | $J^{-1}$ | $\dot q=J^{-1}v_e$ 唯一解；配数值积分（[@def-3.5.1] 前的 3.5.0） |
| 长方、行满秩（$r<n$，冗余） | $J^\dagger=J^{\mathrm T}(JJ^{\mathrm T})^{-1}$ | 解最小范数（$W=I$）；加零空间项 $(I-J^\dagger J)\dot q_0$ 做内部运动（[@def-3.5.1]） |
| 退化 / 邻域（奇异） | $J^*=W^{-1}J^{\mathrm T}(JW^{-1}J^{\mathrm T}+K^{-1})^{-1}$ | 容许末端速度误差 $\delta$；$K$ 大治奇点、$K\to0$ 退回伪逆（[@def-3.5.2]） |

一句话：**方阵求逆、矮胖求伪逆、退化加阻尼**。

:::

::: ex A3 · 几何 / 分析雅可比之差

(a) $J$ 与 $J_A$ 的前三行（线速度部分）是否相同？(b) 后三行为何不同？(c) $T_A$ 的两块分别是什么，$J_A$ 何时退化？

::: sol 解答

(a) 相同——$\dot p_e$ 对 $q$ 直接求偏导与几何法逐列给出的 $J_P$ 一致（[@def-3.6.1]）。(b) 后三行描述的是**同一个角速度在不同基下的读数**：$J$ 用基系正交轴（$\omega$ 分量有物理意义），$J_A$ 用欧拉角三根非正交瞬时轴（$\dot\varphi$）——二者差一个换基 $T$（[@thm-3.6.A]）。(c) $T_A=\operatorname{diag}\{I_3,T(\varphi)\}$，左上 $I_3$、右下 $T(\varphi)$（ZYZ 显式见 [3.6.2](sec3-6.md#sec-3.6.2)）；$s_\vartheta=0$（$\vartheta=0,\pi$）时 $T$ 奇异 ⇒ $J_A$ 退化，与 ZYZ 表示歧义同源。

::: ex A4 · 静力对偶三问

(a) 写出 $\tau=J^{\mathrm T}F_e$ 并说明 $F_e$ 的六个分量。(b) 为什么力映射用 $J^{\mathrm T}$ 而不是 $J^{-1}$？(c) 长方阵（冗余）时该式还成立吗？

::: sol 解答

(a) $F_e=[f_e;\mu_e]$：3 个平动力 + 3 个转动力矩；$\tau$ 为 $n$ 个关节力矩（移动关节为力）（[@def-3.8.1]）。(b) **功率守恒**：$\dot q^{\mathrm T}\tau=v_e^{\mathrm T}F_e=(J\dot q)^{\mathrm T}F_e$ 对任意 $\dot q$ 成立 ⇒ $\tau=J^{\mathrm T}F_e$——速度变换的转置就是力变换（对偶），无需方阵、无需满秩（[@def-3.8.1] 证明框）。(c) 成立——与 $J$ 的形状无关。

## B 组 · 分析证明

::: ex B1 · 证明 $RS(\omega)R^{\mathrm T}=S(R\omega)$（原书 3.1，即式 3.11）

按其物理含义（「先叉乘再旋转 = 先旋转再叉乘」）给出证明，并说明它在角速度递推中的用处。

::: sol 解答

对任意向量 $p$，用旋转不改变模长与夹角（或直接展开 $S$ 与 $R$ 的元素）验证 $R(\omega\times(R^{\mathrm T}p))=R\omega\times p$… 更简的路线：$\forall p$，

$$RS(\omega)R^{\mathrm T}p=R\,(\omega\times R^{\mathrm T}p)=R\omega\times p=S(R\omega)p,$$

最后一步用了「旋转与叉乘可交换」：$R(a\times b)=Ra\times Rb$（在 $R$ 的行列式为 $+1$ 时成立）。对任意 $p$ 成立即得 (3.11)。**用处**：$\dot R_i=S(\omega_i)R_i$ 的递推里把 $R_{i-1}S(\omega_{i-1,i}^{i-1})R_i^{i-1}$ 化为 $S(R_{i-1}\omega_{i-1,i}^{i-1})R_i$，三个算子便能对同一矩阵比较（[3.1.2](sec3-1.md#sec-3.1.2)(d)）。

:::

::: ex B2 · 拟人臂雅可比与两类臂奇点（原书 3.5 相关）

由 $J_P$（[3.2.2](sec3-2.md#sec-3.2.2)）证明 $\det J_P=-a_2a_3s_3(a_2c_2+a_3c_{23})$，并解释两个因子的几何意义。

::: sol 解答

记 $P=a_2c_2+a_3c_{23}$、$Q=a_2s_2+a_3s_{23}$、$R=a_3s_{23}$、$S=a_3c_{23}$，则

$$J_P=\begin{bmatrix}-s_1P&-c_1Q&-c_1R\\ c_1P&-s_1Q&-s_1R\\ 0&P&S\end{bmatrix}.$$

按**第三行**展开（第一项系数为零）：

$$\det J_P=-P\begin{vmatrix}-s_1P&-c_1R\\ c_1P&-s_1R\end{vmatrix}+S\begin{vmatrix}-s_1P&-c_1Q\\ c_1P&-s_1Q\end{vmatrix}
=-P\,(PR)+S\,(PQ)=P\,(SQ-PR)$$

（两个二阶行列式分别用了 $s_1^2+c_1^2=1$）。再算

$$SQ-PR=(a_2s_2+a_3s_{23})(a_3c_{23})-(a_2c_2+a_3c_{23})(a_3s_{23})=a_2a_3(s_2c_{23}-c_2s_{23})=-a_2a_3\,s_3 .$$

故

$$\det J_P=-a_2a_3\,s_3\,(a_2c_2+a_3c_{23}).$$

两个因子：$s_3=0$（$\vartheta_3=0,\pi$）为**肘奇点**——臂伸直 / 折回，与两连杆平面臂 [@ex-book-3.2] 概念等价；$a_2c_2+a_3c_{23}=0$ 为**肩奇点**——腕点坐标 $p_x=p_y=0$（落在 $z_0$ 轴上），$J_P$ 第一列恒为零（[@thm-3.3.A] 后）。**与第一个关节变量无关**（$\vartheta_1$ 被消去，教材原文即指出）。

:::

::: ex B3 · 奇点解耦的合法性（原书 3.5 / 3.44）

(a) 说明为什么「奇点是结构固有属性」允许把参考点挪到腕中心。(b) 写出解耦后的行列式关系。(c) 这个下三角 $J$ 能不能拿去做速度控制？为什么？

::: sol 解答

(a) $J$ 不满秩 ⇔ 各列（关节轴方向与其矩的叉乘）线性相关；参考点选取只改变每列的**表示**（$p_e-p_{i-1}$ 换成 $p_w-p_{i-1}$），不改变「轴的共线 / 平行关系」这一结构事实（1:32:40）。(b) $\det J=\det J_{11}\det J_{22}$，其中 $J_{12}=0$（因 $p_w-p_i \parallel z_i$，$i=3,4,5$，叉乘为零）。(c) **不能**——参考点已不是末端，该矩阵不再表示「关节速度 → 末端速度」的映射；它只用于奇点分析（教材 §3.3.1 原文同样强调）。

:::

::: ex B4 · 零空间解族（原书 3.46）

证明：若 $\dot q^*$ 满足 $J\dot q=v_e$，$P=NN^{\mathrm T}$（$N$ 为零空间基），则 $\dot q^*+P\dot q_0$ 仍是解；并说明 $I-J^\dagger J$ 与 $NN^{\mathrm T}$ 的关系。

::: sol 解答

$J(\dot q^*+P\dot q_0)=v_e+JNN^{\mathrm T}\dot q_0=v_e+0=v_e$——用了 $JN=0$（[@thm-3.4.B]）。两者都是**到 $\mathcal N(J)$ 的投影**：$I-J^\dagger J$ 是伪逆诱导的正交投影（$W=I$ 时按欧氏内积正交），$NN^{\mathrm T}$ 是给定基 $N$ 的（非正交）投影；当 $N$ 的列标准正交时两者一致。作用相同：**不惊动末端的内部运动**。

:::

::: ex B5 · DLS 的极限行为（原书 3.59 / 3.10）

对 $J^*=J^{\mathrm T}(JJ^{\mathrm T}+k^2I)^{-1}$（$r\le n$ 行满秩）：(a) $k\to0$ 且 $J$ 行满秩时趋于什么？(b) 在奇异位形（$JJ^{\mathrm T}$ 奇异）时 $k>0$ 的作用是什么？

::: sol 解答

(a) $k\to0$ 得 $J^{\mathrm T}(JJ^{\mathrm T})^{-1}=J^\dagger$（右伪逆）——[3.5.2](sec3-5.md#sec-3.5.2) 的「远离奇点取小、甚至趋 0」。(b) 对 $JJ^{\mathrm T}$ 做特征分解，特征值 $\sigma_i^2$，则 $J^*$ 的第 $i$ 个奇异方向增益为 $\sigma_i/(\sigma_i^2+k^2)\le 1/(2k)$——**有界**：$\sigma_i\to0$ 时增益不再发散（$\sigma_i/k^2$ 与 $k$ 同阶），这就是「容许误差换关节速度有界」；代价是末端速度有小偏差 $\delta$（教材 §3.5.2）。

:::

::: ex B6 · 速度 / 力变换的转置对偶（原书 3.16 / 3.112–3.116）

设坐标系 1 与基系 0 之间旋转 $R_1^0$、位置 $\tilde p$，写出速度与力的变换矩阵，并说明二者互为转置的**理由**。

::: sol 解答

$$\begin{bmatrix}\dot p_1^0\\ \omega_1^0\end{bmatrix}=\begin{bmatrix}R&-RS(\tilde p)\\ 0&R\end{bmatrix}\begin{bmatrix}v_1\\ \omega_1\end{bmatrix},
\qquad
\begin{bmatrix}f_1^0\\ \mu_1^0\end{bmatrix}=\begin{bmatrix}R&0\\ RS(\tilde p)&R\end{bmatrix}\begin{bmatrix}f_1\\ \mu_1\end{bmatrix}$$

理由：**虚功率不变**（$\dot q^{\mathrm T}\tau$ 的对偶推广）——两坐标系里算出的功率必须相等：$(v^0)^{\mathrm T}f^0=v^{\mathrm T}f$ 对任意 $v$ 成立 ⇒ $f^0=(J_v)^{\mathrm T}f$，即力变换矩阵 = 速度变换矩阵的转置（教材式 3.113–3.115 的 $v_2^2=J_2^1v_1^1\Rightarrow\gamma_1^1=(J_2^1)^{\mathrm T}\gamma_2^2$）。

## C 组 · 计算编程

::: ex C1 · 数值雅可比校验器（自编）

写一个函数 `jac_check(fk, q, eps=1e-6)`：给定正运动学 `fk(q)`（返回 $4\times4$ 齐次矩阵）与位形 `q`，用中心差分算 $(3\times n)$ 的线速度雅可比 $J_P$，与解析 $J_P$ 比对。用它验证 [3.2.1](sec3-2.md#sec-3.2.1) 三连杆平面臂的 $\bar J$（前两行）。

## D 组 · 开放研讨

::: ex D1 · 「奇点不可避免吗」

任选一种工业构型（如 6 轴球腕串联臂），检索其手册中的奇异位形说明，讨论：哪些奇点是结构性的（不可避免，只能规划绕开），哪些可以通过冗余 / 变构型（7 轴）消除？结合 [3.3](sec3-3.md) 的边界 / 内部分类与 Doosan 两种规避策略（[3.3.3](sec3-3.md#sec-3.3.3) 工程注记）写成 300 字小报告。

::: sol 解答要点

- 结构性：球腕 $s_5=0$（内部）、肘 $s_3=0$、肩「腕点落轴」——串联 6 轴无法消除，只能避开（规划 / 变速度 / 自动规避）；
