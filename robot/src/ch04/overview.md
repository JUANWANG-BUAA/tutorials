# 第四章 · 轨迹规划

## 从位姿与速度到时间律

第二章由关节变量 $\boldsymbol q$ 给出末端正运动学位姿 $T_e^b(\boldsymbol q)$，第三章通过几何雅可比与分析雅可比建立关节速度到末端速度的线性映射 $[\dot{\boldsymbol p}_e^{\mathrm T}\ \boldsymbol\omega_e^{\mathrm T}]^{\mathrm T}=J(\boldsymbol q)\dot{\boldsymbol q}$。进入实际控制任务——无论是让机械臂从桌面拾取工件并放置到目标位置，还是在卷首任务中移动螺丝刀对准螺栓——仅知道几何起点与终点还不够：系统还必须回答「各关节何时启动、途经各处有多快、何时停下，以及末端究竟沿什么几何曲线移动」。

本章把关节变量与末端位姿写成时间 $t$ 的光滑或分段光滑函数：

$$\boldsymbol q(t)=\begin{bmatrix}q_1(t)&\cdots&q_n(t)\end{bmatrix}^{\mathrm T},\qquad
\dot{\boldsymbol q}(t),\quad\ddot{\boldsymbol q}(t).$$

其中 $t\in[0,t_f]$ 为时间（$\mathrm s$），$q_j(t)$ 为第 $j$ 个关节在时刻 $t$ 的角位移（$\mathrm{rad}$）或线位移（$\mathrm m$），一、二阶导数分别为关节速度与加速度。**轨迹规划器**生成位置、速度与加速度参考时间序列，供底层伺服控制器跟踪；借助正运动学可同步还原末端实际路径，而即使每个关节各自按简单的点对点规律运动，非线性正运动学也会使末端走出的三维空间曲线偏离直线。

本章按「**问题区分 → 单轴时间律 → 多点插值 → 操作空间路径与指向**」四步展开：先在 [§4.1](sec4-1.md) 分清路径、轨迹与运动规划的界限；再在 [§4.2.1](sec4-2-1.md) 构造单关节三次、五次与梯形速度（LSPB）时间律，并在 [§4.2.2](sec4-2-2.md) 讨论经由系列路径点时的 Hermite、三次样条与抛物线混合法；最后在 [§4.3.1](sec4-3-1.md)–[§4.3.3](sec4-3-3.md) 把几何路径 $\boldsymbol p_e=\boldsymbol f(s)$ 与时间律 $s(t)$ 解耦，并解决欧拉角、固定轴角与单位四元数 SLERP 下的三维姿态规划问题。

读完后可在[两连杆第五关](../training/two-link.md#mission-path)检验多关节共用同一标量时间律时末端路径的非线性变形与奇异/零空间瞬间速度抵消现象；第五章将在此轨迹参考的基础上进一步校核电机与减速器的转速—力矩约束。
