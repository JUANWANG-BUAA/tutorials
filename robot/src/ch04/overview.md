# 第四章 · 轨迹规划

## 换一种肘姿，末端会经过哪里？

第二章中，两种关节构型都能到达 $(1,1)$。现在让关节从一种平滑地转到另一种。先画出运动一半时的手臂，猜猜末端是否还在原地，再读 [4.1 路径与轨迹](sec4-1.md)和 [4.2.1 点对点运动](sec4-2-1.md)。

读完后做[两连杆第五关](../training/two-link.md#mission-path)，算中点位置与速度峰值，再把运动时间减半。中间会出现一个关节仍在动、末端瞬时速度却为零的时刻，用第三章的雅可比解释它。

下次先闭卷重算时间减半后的加速度。第五章会接着检查这条轨迹对电机转速的要求。

## 本章怎样学习

本章参考Siciliano等教材第四章与2026年9月28日课程内容。先掌握单个标量的时间律，再把它用于多个关节或一条已给定的空间路径。

| 节 | 阅读后要能完成的计算 |
|:--|:--|
| [§4.1 路径与轨迹](sec4-1.md) | 为同一路径选不同时间律，说明参考与实际运动的区别 |
| [§4.2.1 点对点](sec4-2-1.md) | 从边界解三次、五次系数，并由峰值反推时间；用速度面积求LSPB |
| [§4.2.2 系列点](sec4-2-2.md) | 确定接点速度，推导普通三次样条的三对角方程 |
| [§4.3.1 路径基元](sec4-3-1.md) | 建立直线、圆弧路径，区分一般参数与弧长 |
| [§4.3.2 位置](sec4-3-2.md) | 两次求导得到切向和法向加速度，计算分段重叠后的走向 |
| [§4.3.3 姿态](sec4-3-3.md) | 保持合法旋转，并把参数导数换成物理角速度 |

先完整求出静止起停三次时间律，再增加零端点加速度条件，求五次系数。读过基本算例后，再看最优性证明与虚拟点样条：前者还需指定模型和代价，后者用于处理额外端点条件。

复习时从[全章总结](summary.md)挑一个公式，在[回忆卡](recall-cards.md)中恢复条件，再做一道[习题](exercises.md)。先预测“总时间减半”怎样改变速度与加速度，再代数核对，比只背曲线形状更能发现问题。
