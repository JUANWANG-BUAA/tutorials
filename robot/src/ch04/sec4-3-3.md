# 4.3.3 指向

[§4.3.2](sec4-3-2.md) 安排了末端位置轨迹；而在装配、焊接、喷涂等任务中，夹爪或工具在沿路径平动的同时还需调整三维朝向。与位置向量不同，旋转群 $SO(3)$ 是弯曲流形而非欧氏线性空间，不能直接对旋转矩阵逐元素插值。本节先证明其原因，再依次建立 **ZYZ 欧拉角**、**固定轴角**与 **单位四元数 SLERP** 三种姿态规划方法。

<a id="sec-4.3.3.1"></a>

## 4.3.3.1 旋转矩阵不能直接逐元素插值

旋转矩阵的三列分别代表末端坐标系三个正交单位轴在基坐标系中的方向。正交性与单位长度条件使合法矩阵构成非线性流形 $SO(3)$，对线性组合并不封闭。

::: thm 定理 4.3.E · 旋转矩阵逐元素线性插值破坏正交性 {#thm-4.3.E}
设初始与最终姿态 $R_i,R_f\in SO(3)$。若对两矩阵的 $9$ 个元素直接做线性插值

$$R(\lambda)=(1-\lambda)R_i+\lambda R_f,\qquad \lambda\in[0,1],$$

则对一般 $R_f\ne R_i$ 与 $\lambda\in(0,1)$ 恒有 $R(\lambda)^{\mathrm T}R(\lambda)\ne I_3$，即中间矩阵不属于 $SO(3)$，不能表示刚体姿态。
:::

::: proof 证明与退化反例
记 $D=R_f-R_i$，则 $R(\lambda)=R_i+\lambda D$，展开正交性检验式：

$$R(\lambda)^{\mathrm T}R(\lambda)=I_3+\lambda(R_i^{\mathrm T}R_f+R_f^{\mathrm T}R_i-2I_3)+\lambda^2(R_f-R_i)^{\mathrm T}(R_f-R_i).$$

除 $\lambda=0,1$ 外上式一般不等于 $I_3$。具体反例：取 $R_i=I_3$、$R_f=\operatorname{diag}(-1,-1,1)$（绕 $z$ 轴转 $180^\circ$），则 $R(\lambda)=\operatorname{diag}(1-2\lambda,\,1-2\lambda,\,1)$；在中点 $\lambda=1/2$ 处得到 $R(1/2)=\operatorname{diag}(0,0,1)$，前两列模长塌陷为零，矩阵秩降为 $1$，退化为一条直线而非正交标架。
:::

## 4.3.3.2 方法一：ZYZ 欧拉角空间插值

::: def 定义 4.3.6 · 欧拉角时间律 {#def-4.3.6}
沿用 [第 2 章](../ch02/sec2-4.md) ZYZ 欧拉角约定 $\boldsymbol\varphi_e=[\varphi,\ \vartheta,\ \psi]^{\mathrm T}$，即 $R(\boldsymbol\varphi_e)=R_z(\varphi)R_{y'}(\vartheta)R_{z''}(\psi)$。在选定**同一连续分支**的初终欧拉角向量 $\boldsymbol\varphi_i$ 与 $\boldsymbol\varphi_f$ 后（例如分量从 $179^\circ$ 转到 $-179^\circ$ 时应将终值等价改写为 $181^\circ$，避免绕行 $-358^\circ$），沿三维参数空间线段引入标量进度 $s\in[0,\|\boldsymbol\varphi_f-\boldsymbol\varphi_i\|]$（此处的 $s$ 为参数空间线段长度，非以米计的路径弧长）并分配一维时间律 $s(t)$（若 $\boldsymbol\varphi_f=\boldsymbol\varphi_i$ 则保持姿态）：

$$\boldsymbol\varphi_e=\boldsymbol\varphi_i+\frac{s}{\|\boldsymbol\varphi_f-\boldsymbol\varphi_i\|}(\boldsymbol\varphi_f-\boldsymbol\varphi_i),\qquad
\dot{\boldsymbol\varphi}_e=\dot s\,\frac{\boldsymbol\varphi_f-\boldsymbol\varphi_i}{\|\boldsymbol\varphi_f-\boldsymbol\varphi_i\|},\qquad
\ddot{\boldsymbol\varphi}_e=\ddot s\,\frac{\boldsymbol\varphi_f-\boldsymbol\varphi_i}{\|\boldsymbol\varphi_f-\boldsymbol\varphi_i\|}. \tag{4.51}$$
:::

由式 (4.51) 得到的 $\dot{\boldsymbol\varphi}_e$ 是欧拉角速率，并非基坐标系下的物理角速度 $\boldsymbol\omega_e$。需先算出 $R_e(t)=R(\boldsymbol\varphi_e(t))$（见 [@thm-2.4.A]），再通过 [§3.6](../ch03/sec3-6.md) 的转换矩阵 $T(\boldsymbol\varphi_e)$（见 [@thm-3.6.A]）换算至基坐标系：

$$\boldsymbol\omega_e=T(\boldsymbol\varphi_e)\,\dot{\boldsymbol\varphi}_e,\qquad
\dot{\boldsymbol\omega}_e=\dot T(\boldsymbol\varphi_e)\,\dot{\boldsymbol\varphi}_e+T(\boldsymbol\varphi_e)\,\ddot{\boldsymbol\varphi}_e,\qquad
T(\boldsymbol\varphi_e)=\begin{bmatrix}0 & -s_\varphi & c_\varphi s_\vartheta\\ 0 & c_\varphi & s_\varphi s_\vartheta\\ 1 & 0 & c_\vartheta\end{bmatrix}.$$

由 $\det T=-\sin\vartheta$ 可知，当 $\vartheta=0$ 或 $\vartheta=\pi$ 时 $T$ 降秩，存在 ZYZ **表示奇异**（无法由已知物理角速度 $\boldsymbol\omega_e$ 唯一反解 $\dot{\boldsymbol\varphi}_e$，而前向由 $\dot{\boldsymbol\varphi}_e$ 算 $\boldsymbol\omega_e$ 仍平滑有定义）。计算导数与 $T$ 时，欧拉角统一采用弧度制。

## 4.3.3.3 方法二：固定轴角插值

欧拉角插值沿参数空间直线前进，物理旋转轴随时间晃动且非最短路径；若希望末端绕一根**固定等效轴**单调转至目标姿态，可采用固定轴角表示，将三维姿态规划降为一维标量问题。

::: thm 定理 4.3.F · 角和轴的轨迹生成 {#thm-4.3.F}
给定基系下的初始与最终旋转阵 $R_i,R_f\in SO(3)$。由 $R_f=R_iR_i^f$ 得相对旋转矩阵（描述在初始姿态坐标系 $i$ 中）：

$$R_i^f=R_i^{\mathrm T}R_f,\qquad R'(0)=I_3,\quad R'(t_f)=R_i^f.$$

当 $0<\theta_f<\pi$（非零转且非精确半圈）时，通过矩阵对数映射（[§2.5.2](../ch02/sec2-5.md#sec-2.5.2)）提取固定单位轴 $\boldsymbol r'$（初始系表达）与总转角 $\theta_f$（$\mathrm{rad}$）：

$$\theta_f=\arccos\!\left(\frac{r_{11}+r_{22}+r_{33}-1}{2}\right),\qquad
\boldsymbol r'=\frac{1}{2\sin\theta_f}\begin{bmatrix}r_{32}-r_{23}\\ r_{13}-r_{31}\\ r_{21}-r_{12}\end{bmatrix}. \tag{4.52}$$

其中 $r_{kl}$ 为 $R_i^f$ 的元素（$\theta_f=0$ 时保持静止；$\theta_f=\pi$ 时分母 $\sin\theta_f=0$ 失效，须由 $R_i^f=2\boldsymbol r'\boldsymbol r'^{\mathrm T}-I_3$ 按 [§2.5](../ch02/sec2-5.md) 特殊提取 $\boldsymbol r'$）。

轴 $\boldsymbol r'$ 固定后，只需对标量转角 $\theta(t)$（$\theta(0)=0,\ \theta(t_f)=\theta_f$）安排一维时间律，由指数映射得 $R'(t)=\exp(\theta(t)S(\boldsymbol r'))$，初始系下的角速度与角加速度为：

$$\boldsymbol\omega'(t)=\dot\theta(t)\,\boldsymbol r',\qquad \dot{\boldsymbol\omega}'(t)=\ddot\theta(t)\,\boldsymbol r'. \tag{4.53,4.54}$$

最后左乘 $R_i$ 转换回基坐标系：

$$R_e(t)=R_iR'(t),\qquad
\boldsymbol\omega_e(t)=R_i\boldsymbol\omega'(t)=\dot\theta(t)(R_i\boldsymbol r'),\qquad
\dot{\boldsymbol\omega}_e(t)=R_i\dot{\boldsymbol\omega}'(t)=\ddot\theta(t)(R_i\boldsymbol r'). \tag{4.55}$$
:::

::: ex 例 4.3.G · 从 $R_i^f$ 反解转角与轴（(4.52) 的代入） {#ex-4.3.G}
设相对旋转是绕单位轴 $(1,1,1)^{\mathrm T}/\sqrt3$ 转 $\pi/2$。由第二章的 Rodrigues 公式，精确矩阵的对角元为 $1/3$，非对角元为 $1/3\pm1/\sqrt3$；保留四位小数得

$$R_i^f=\begin{bmatrix}
0.3333&-0.2440&0.9107\\
0.9107&0.3333&-0.2440\\
-0.2440&0.9107&0.3333
\end{bmatrix}.$$

用精确矩阵代入 (4.52)，其迹为 1，因此

$$\theta_f=\arccos\frac{1/3+1/3+1/3-1}{2}=\frac{\pi}{2}.$$

反对称部分的三个分量都是 $2/\sqrt3$：例如 $r_{32}-r_{23}=(1/3+1/\sqrt3)-(1/3-1/\sqrt3)=2/\sqrt3$；其余两项同样为正。于是

$$r'=\frac{1}{2\sin(\pi/2)}\begin{bmatrix}2/\sqrt3\\2/\sqrt3\\2/\sqrt3\end{bmatrix}
=\frac1{\sqrt3}\begin{bmatrix}1\\1\\1\end{bmatrix}
\approx\begin{bmatrix}0.5774\\0.5774\\0.5774\end{bmatrix}.$$

**代数自检**：精确轴的模为 1，代回 Rodrigues 公式可恢复精确矩阵。若直接使用上面的四位小数矩阵，迹为 $0.9999$ 而不是精确的 1，反求角度和单位轴都会有舍入偏差，不能把这类近似计算写成零误差的数值验证。

顺带看清 (4.52) 的两个前提：**取迹**给出的是 $\cos\theta_f$——它分不清 $\theta_f$ 与 $2\pi-\theta_f$，所以轴的公式里必须除以 $\sin\theta_f$（本例 $\sin(\pi/2)=1$，最省事的情形）；而当 $\theta_f=0$（两姿态相同）或 $\theta_f=\pi$（分母为零）时，(4.52) 都不能直接用。
:::

固定等效轴 $\boldsymbol r'$ 后，三维姿态规划彻底降维为一维转角规划 $\theta(t)$，可直接复用点对点与系列点的全部标量时间律；最后经式 (4.55) 转换至基坐标系。

## 4.3.3.4 方法三：单位四元数 SLERP 与三法对比

为同时消除欧拉角奇异与式 (4.52) 在 $\theta_f=\pi$ 处的除零奇异，现代机械臂与仿真引擎最常使用**单位四元数**配合**球面线性插值（SLERP）**。

回顾 [第 2 章](../ch02/sec2-5.md) 标量在前约定：绕单位轴 $\boldsymbol r$ 旋转 $\vartheta$ 对应单位四元数 $Q=\{\eta,\ \boldsymbol\epsilon\}=\left\{\cos\frac{\vartheta}{2},\ \sin\frac{\vartheta}{2}\,\boldsymbol r\right\}\in S^3\subset\mathbb R^4$（满足 $\eta^2+\|\boldsymbol\epsilon\|^2=1$），且对径点 $Q$ 与 $-Q$ 代表 $SO(3)$ 中同一个物理姿态。

::: def 定义 4.3.7 · 单位四元数球面线性插值（SLERP） {#def-4.3.7}
给定对应 $R_i$ 与 $R_f$ 的单位四元数 $Q_0,Q_1\in S^3$。先计算四维点积 $d=Q_0^{\mathrm T}Q_1=\eta_0\eta_1+\boldsymbol\epsilon_0^{\mathrm T}\boldsymbol\epsilon_1$；若 $d<0$，先执行**符号对齐** $Q_1\leftarrow -Q_1$ 使 $d\in[0,1]$（确保沿最短圆弧旋转而非绕远）。记四维球面半角 $\Omega=\arccos(d)\in[0,\pi/2]$，当 $0<\Omega\le\pi/2$ 时：

$$Q(\sigma)=\frac{\sin\!\big((1-\sigma)\Omega\big)}{\sin\Omega}\,Q_0+\frac{\sin(\sigma\Omega)}{\sin\Omega}\,Q_1,\qquad \sigma\in[0,1].$$

当 $d=1$（$\Omega=0$）时两姿态重合，保持 $Q(\sigma)\equiv Q_0$（$\Omega$ 极小时可用归一化线性插值 NLERP 避免数值除零）。取 $\sigma(t)=\theta(t)/\theta_f$ 即可嵌入任意一维时间律。
:::

SLERP 具有两条关键几何性质：(1) 恒有 $Q(\sigma)^{\mathrm T}Q(\sigma)\equiv 1$，插值曲线严格留在单位球面 $S^3$（对应矩阵恒属 $SO(3)$）并沿测地大圆弧运动；(2) 因 $\theta_f=2\Omega$，对齐主转角后的 SLERP 与固定轴角插值在 $SO(3)$ 上生成**完全相同的几何姿态路径**（取 $\sigma=t/t_f$ 时角速度恒定为 $\dot\theta=2\Omega/t_f$），而四元数表示彻底规避了 $\theta_f=0,\pi$ 提轴时的除零奇异。

|:--|:--|:--|:--|

## 4.3.3 小结与常见错误

- **一条主线**：旋转矩阵不能直接插值（正交性）⇒ 两条正路：**欧拉角**（三标量分别插值，再经 $T$ 换算回基系）与**角和轴**（轴固定、只规划 $\theta$）。
- **一个统一**：位置规划可以落在 $s(t)$，姿态规划可以落在 $\theta(t)$；两者都化成一维标量时间律，可以复用 [4.2.1](sec4-2-1.md) / [4.2.2](sec4-2-2.md) 的方法。
- **一句话**：「姿态规划比位置规划复杂，复杂在**表示**；一旦选对表示（欧拉角或角和轴），剩下的还是那几套一维时间律。」

::: think 常见错误清单 · 自查三条
1. **逐元素插值旋转矩阵**：除相同端点等特殊情形外，中间矩阵一般不保持正交性，不能直接当作姿态。
2. **把欧拉角速度当角速度**：应通过 $\omega_e=T(\varphi_e)\dot\varphi_e$ 换算。正向映射在 ZYZ 奇异角仍能算出角速度，但反向由角速度唯一求欧拉角速度会失效；不能把 $T$ 奇异误解成任意前向姿态插值都不连续。
3. **角和轴法忘了 $r'$ 是在哪个系里**：$r'$ 是 $R_i^f=R_i^{\mathrm T}R_f$ 的等效轴；$\omega'$ 还要左乘 $R_i$ 才是基系下的 $\omega_e$。
