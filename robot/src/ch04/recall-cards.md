## A. 定义卡

### A1 · 路径、轨迹、运动规划

分别说明路径、轨迹与运动规划解决什么问题，并各给一个例子。

::: sol A1 核对
路径描述经过哪些点、连成什么形状；轨迹再指定何时到达，可由时间律求速度与加速度。运动规划求满足任务与约束的可行运动，可进一步优化时间或其他指标；它可以离线完成，在线重规划是另一项设计选择。例如先指定焊缝形状，再给焊接速度，最后检查整臂运动是否碰撞。这三个概念不能写成严格的集合包含关系。（[@def-4.1.1]–[@def-4.1.3]）
:::

### A2 · 运动律的两条硬约束

写出两条约束，并各说明它限制的是哪个物理量。

::: sol A2 核对
一是驱动限制：沿轨迹所需的关节力矩、速度和功率须在执行器允许范围内。二是结构振动：轨迹变化的频率成分可能激发柔性结构的固有模式，需要检查并抑制。连续加速度或 jerk 限制可减轻突变，但光滑阶次本身不决定力矩、功率峰值；还须结合总时间和动力学计算。（[@thm-4.1.A]）
:::

### A3 · 轨迹规划器的接口与用户可指定的参量

写出输入 / 输出，并列出四类可指定参量。

::: sol A3 核对
输入为任务、路径或路径点及运动约束，输出为带时间的参考运动，供控制器使用。可指定几何基元、中间点、总时间，以及部分点的速度或加速度。操作空间路径还需求相容的关节运动，并检查奇异性与限位。直接指定总时间或指定速度、加速度比例都可以，规划器仍须检查可行性。（[@method-4.1.A]、[@def-4.1.4]）
:::

### A4 · 三次与五次多项式时间律

写出两者各需要几个约束、分别因为什么，并说明两者的最优性各需要什么指标与约束。

::: sol A4 核对
**三次** $q(t)=a_3t^3+a_2t^2+a_1t+a_0$：**4 个系数需 4 个约束** = 初终位置 $q_i,q_f$ + 初终速度 $\dot q_i,\dot q_f$（一般设为 0——「一般的初始肯定是从零开始加速，终止完成任务一般也是回到零的」）。导数是**抛物线形式的速度曲线**与**线性形式的加速度曲线**。**五次** $q(t)=a_5t^5+\cdots+a_0$：若还要**同时指定初始与最终的加速度**，约束增加到 6 个 ⇒ 至少需要五阶；系数由 $t=0$ 与 $t=t_f$ 处对 $q$ 及**前两阶导数**的 6 个条件解出。**代价**：五次不继承原问题的平方力矩最优性——固定端点位置、速度、加速度时，最小平方 jerk 的解则是五次，不能脱离指标谈最优。（[@thm-4.2.A]、[@def-4.2.1]、[@def-4.2.2]）
:::

### A5 · 梯形速度曲线（LSPB）与两条标准假设

写出运动分段、两条假设，以及"两条假设为什么这么选"。

::: sol A5 核对
指定一条**梯形速度曲线**：起始段为**常值加速度**、中段维持**巡航速度**、末段为**常值减速度**；对速度积分得位置轨迹——由**一条直线段**和在其两端分别连接到初始位置与最终位置的**两段抛物线**组成，因此又称**抛物线混合**（linear segments with parabolic blends，LSPB）。类比电梯拖动：先匀加速、再巡航、再匀减速，正好到零停下来。**两条标准假设**：① **初始速度与最终速度都为零**；② 两个常加速度分段的**时间长度相同**（因此两段加速度等量），轨迹在 $t_m=t_f/2$ 时刻关于**平均值点** $q_m=(q_f+q_i)/2$ **对称**。**为什么取相等**：可以减少需要解的参数与方程——实际过程中这种计算可能要做千万次以上，「你节省一点计算的时间，累积起来就非常多了」。（[@def-4.2.3]）
:::

### A6 · 圆形路径的三要素与随体坐标系

写出三要素、圆心公式，以及随体坐标系怎么建。

::: sol A6 核对
**三要素**：圆轴的**单位向量** $\boldsymbol r$、圆轴上**一点的位置向量** $\boldsymbol d$、圆上**一点的位置向量** $\boldsymbol p_l$。令 $\boldsymbol\delta=\boldsymbol p_l-\boldsymbol d$，为使 $p_l$ 不在轴上（圆不退化成一点）必有 $|\boldsymbol\delta^{\mathrm T}\boldsymbol r|<\|\boldsymbol\delta\|$，此时**圆心**为

$$\boldsymbol c=\boldsymbol d+(\boldsymbol\delta^{\mathrm T}\boldsymbol r)\,\boldsymbol r .$$

**随体坐标系 $o'\!-\!x'y'z'$**：原点 $o'$ 与圆心重合；轴 $z'$ 沿 $\boldsymbol r$；轴 $x'$ 沿向量 $\boldsymbol p_l-\boldsymbol c$ 的方向；轴 $y'$ 按**右手系**选取。在参考坐标系中圆的参数表达式为 $\boldsymbol p'=\begin{bmatrix}\rho\cos(s/\rho)&\rho\sin(s/\rho)&0\end{bmatrix}^{\mathrm T}$（$\rho=\|\boldsymbol p_l-\boldsymbol c\|$），换到一般参考系即 $\boldsymbol p=\boldsymbol c+R\boldsymbol p'$，其中 $R=[\boldsymbol x'\ \boldsymbol y'\ \boldsymbol z']$。**为什么这样建**：「如果在经过它自己圆心、然后有一个面跟圆弧面重合的坐标系里表示，这个角是非常简单的」。（[@def-4.3.3]）
:::

### A7 · 操作空间位置轨迹、弧长时间律与多段路径

写出解耦形式、$\dot{\boldsymbol p}_e$ 的分解，以及多段路径的参数表达式。

::: sol A7 核对
**解耦**：令 $\boldsymbol p_e=f(s)$ 为路径作为**弧长** $s$ 的函数（几何），时间律由标量函数 $s(t)$ 描述（时间）——于是 $\dot{\boldsymbol p}_e=\dfrac{\mathrm d\boldsymbol p_e}{\mathrm ds}\dot s=\dot s\,\boldsymbol t$，其中 $\boldsymbol t$ 为路径在点 $p$ 的**切向量**；$\dot s$ 为带符号的路径速度，速度大小为 $|\dot s|$；负号表示沿切向反向运动。**关键**：$s$ 是一维标量，**上述针对关节轨迹的生成技术全部可以使用**（三次、梯形、样条都能直接套在 $s(t)$ 上）。**多段路径**：$\boldsymbol p_e=\boldsymbol p_0+\sum_{j=1}^N\dfrac{s_j}{\|\boldsymbol p_j-\boldsymbol p_{j-1}\|}(\boldsymbol p_j-\boldsymbol p_{j-1})$，其中 $s_j(t)$ 分段定义（在 $t_{j-1}$ 前为 0、在 $[t_{j-1},t_j]$ 中由 $s'_j(t)$ 连续变化到 $\|\boldsymbol p_j-\boldsymbol p_{j-1}\|$、之后保持）；微分得 $\dot{\boldsymbol p}_e=\sum_j\dot s_j\boldsymbol t_j$。**问题**：两条**不共线**分段之间，路径点处一阶导数不连续，机械手将**不得不停下来**——这类允许松弛约束的点称为**经由点**（via point）。（[@def-4.3.4]、[@def-4.3.5]）
:::

## B. 结论卡

### B1 · 为什么常惯量模型下最小平方力矩解恰好是三次多项式

写出被优化的方程与指标，并说明端点速度与动力学模型的限制。

::: sol B1 核对
**模型**：绕定轴转动的刚体，转动惯量 $I$，转动由电机力矩 $\tau$ 提供；令 $\dot q=\omega$，求解 $I\dot\omega=\tau$，固定初终速度为零，并服从条件 $\int_0^{t_f}\omega(t)\,\mathrm dt=q_f-q_i$，使性能指标 $\int_0^{t_f}\tau^2(t)\,\mathrm dt$ 最小化。其解的形式为

$$\omega(t)=at^2+bt+c .$$

即**速度是二阶多项式 ⇒ 位置是三阶（三次）多项式、加速度是线性函数**。**适用边界**：三次可用于更复杂系统的插值，但一般不再是其真实动力学下的最优解；若未规定端点速度，匀速即可令平方力矩指标为零。**方法论提示**：这个问题本身是**泛函问题**（变分法 / 现代控制理论里的同类内容），所以课程直接给结论。（[@thm-4.2.A]）
:::

### B2 · 四条修正路线与各自保证到几阶连续

列出四条路线、各自补的两个约束与连续性。

::: sol B2 核对
| 路线 | 补的两个约束 | 保证的连续性 |
|:--|:--|:--|
| ① 在路径点**指定**速度 | 用户给出 $q_k$ 与 $\dot q_k$ | 位置、速度连续 |
| ② 按规则**计算**速度 | 用相邻分段斜率的平均值定 $\dot q_k$（异号则取 0） | 位置、速度连续 |
| ③ 要求**加速度连续**（样条） | 速度连续 + 加速度连续 | 位置、速度、**加速度**连续 |
| ④ **低于三阶**的多项式 + 抛物线混合 | 用梯形速度曲线的做法 | 位置、速度连续（加速度跳跃） |

前两种分段三次通常只保证 $C^1$，三次样条进一步要求 $C^2$。指定速度可能造成超调，简单斜率平均也不保证所有数据都无超调，仍需检查各段导数。样条需要联立求解；抛物线混合允许从部分中间点附近经过。（[@method-4.2.B]）
:::

### B3 · 为什么不用单个高阶多项式

写出五条缺点，并说明"出路"的阶数下限为什么是三次。

::: sol B3 核对
全局高次插值可能摆动、幂基可能病态，单个数据变化会影响全局。若恰用 $N-1$ 次通过 $N$ 个不同时间节点，通常已没有自由度独立指定端点速度。分段三次则能独立满足每段两端位置与速度；这是这组独立边界条件所需的次数，不是所有分段连续方法的绝对下限。见[@method-4.2.A]。
:::

### B4 · 样条的方程计数与两个虚拟点

写出方程数与未知数的差距，以及三种出路。

::: sol B4 核对
普通三次样条共有 $4N-4$ 个系数，位置插值和内部一、二阶连续给 $4N-6$ 条条件，还需两条端点条件。若首末速度和加速度全任意给定，一般超定两条，可增两个位置未知的虚拟点或改变分段次数。虚拟点扩展后方程计数相等，仍须检验矩阵非奇异。见[@thm-4.2.G]。
:::

### B5 · 样条的降维：为什么最终是一个三对角系统

写出三个步骤，并说明 $A$ 与关节的关系。

::: sol B5 核对
令 $h_k=t_{k+1}-t_k$、$m_k=\ddot q(t_k)$、$d_k=(q_{k+1}-q_k)/h_k$。每段二阶导数线性插值，积分并使用两端位置后，速度连续给

$$h_{k-1}m_{k-1}+2(h_{k-1}+h_k)m_k+h_km_{k+1}=6(d_k-d_{k-1}).$$

每行只连相邻三个加速度，因此三对角。普通自然样条给 $m_1=m_N=0$；指定速度则改边界行。同一时间网格的各关节复用矩阵，节点位置改变右端。虚拟点扩展不能不改边界就冒充普通系统。见[@thm-4.2.H]。
:::

### B6 · 位置规划的两次"降维"

写出操作空间规划把几维问题化成一维的两处，以及由此得到的统一图景。

::: sol B6 核对
已知位置路径 $p=f(s)$ 后，用一个标量 $s(t)$ 安排进度；已选固定轴后，用一个标量 $\theta(t)$ 安排转角。这是已规定几何后的参数化，不代表任意六维规划自动只有一个自由变量。位置和姿态还要同步，并检查逆运动学、关节和驱动限制。见[@method-4.3.A]、[@thm-4.3.F]。
:::

### B7 · 关节空间还是操作空间

写出两个空间各自的优势与麻烦，并给出那条贯穿全章的结论。

::: sol B7 核对
操作空间便于直接描述末端直线、圆弧等任务；关节空间便于检查关节限位与驱动约束。障碍物虽在物理空间给出，也可通过碰撞检测映射到构形空间；避障并不限定在操作空间中求解。末端路径经逆运动学得到关节运动后，仍须核查整臂碰撞、奇异性和速度限制。（[4.1.4](sec4-1.md#sec-4.1.4)）
:::

## C. 公式卡

### C1 · 三次多项式的系数方程组

写出四个方程，并说明例 4.2.B（$0\to\pi$，$t_f=1$）的解与三张曲线的形状。

::: sol C1 核对
$$a_0=q_i,\qquad a_1=\dot q_i,\qquad a_3t_f^3+a_2t_f^2+a_1t_f+a_0=q_f,\qquad 3a_3t_f^2+2a_2t_f+a_1=\dot q_f .$$

**例 4.2.B**：$q_i=0,\ q_f=\pi,\ t_f=1,\ \dot q_i=\dot q_f=0$ ⇒ $a_0=0,a_1=0$，$a_3+a_2=\pi$、$3a_3+2a_2=0$ ⇒ $a_2=3\pi,\ a_3=-2\pi$，即

$$q(t)=-2\pi t^3+3\pi t^2,\qquad \dot q(t)=-6\pi t^2+6\pi t,\qquad \ddot q(t)=-12\pi t+6\pi .$$

**读图要点**：位置平滑且连续；速度连续但**不平滑**（$t=0$ 与 $t=1$ 两处各有一个折点）；加速度在这两点上**跳跃**（从 0 跳到 $6\pi$，再从 $-6\pi$ 跳回 0）。这正是「位置 / 速度光滑、加速度跳跃」那一档的典型代表。**通用解法**：整个过程都是「**解方程 / 待定系数法**」——根据任务找约束（约束就是方程），再把系数解出来；方程多了就**超定**（提高阶次或改解析式形式），方程少了就**多解**（补优化约束或工程约束）。（[@def-4.2.1]、[@ex-4.2.B]）
:::

### C2 · 梯形速度曲线：$t_c$ 方程与加速度下界

写出 $q_c$、衔接条件、二次方程、根与下界，并说明等号对应什么形状。

::: sol C2 核对
$$q_c=q_i+\tfrac12\ddot q_ct_c^2,\qquad \ddot q_ct_c=\frac{q_m-q_c}{t_m-t_c}\quad(t_m=t_f/2,\ q_m=(q_f+q_i)/2),$$

$$\ddot q_ct_c^2-\ddot q_ct_f t_c+q_f-q_i=0\qquad\text{(关于 }t_c\text{ 的二次方程)},$$

$$|\ddot q_c|\ge\frac{4|q_f-q_i|}{t_f^2}\quad\text{(加速度下界；根号内非负)},$$

取 $t_c\le t_f/2$ 的根：$t_c=\dfrac{t_f}{2}-\dfrac12\sqrt{\dfrac{t_f^2\ddot q_c-4(q_f-q_i)}{\ddot q_c}}$，并以 $\operatorname{sgn}\ddot q_c=\operatorname{sgn}(q_f-q_i)$ 指定加速度方向。**等号的形状**：下界取等号时轨迹**不再有常值速度段**，只剩加速段与减速段——速度曲线退化为**三角形**（$t_c=t_f/2$）。**分段位置序列**：$0\le t\le t_c$ 段 $q=q_i+\frac12\ddot q_ct^2$；巡航段 $q=q_i+\ddot q_ct_c\left(t-\frac{t_c}{2}\right)$；末段 $q=q_f-\frac12\ddot q_c(t_f-t)^2$。**代价**：性能指标比最优（三次）情形**在 $t_c/T=1/3$ 时增加 12.5%**——「但是折中考虑，它更简单、计算速度更快、轨迹没那么复杂，最后也是可接受的」。（[@thm-4.2.C]）
:::

### C3 · 指定巡航速度与它的约束区间

写出两条式子与区间，并说明两个端点各对应什么形状。

::: sol C3 核对
若除 $q_i,q_f,t_f$ 外直接指定**巡航速度** $\dot q_c$，它须服从

$$\frac{|q_f-q_i|}{t_f}<|\dot q_c|\le\frac{2|q_f-q_i|}{t_f},\qquad
t_c=\frac{q_i-q_f+\dot q_ct_f}{\dot q_c},\qquad
\ddot q_c=\frac{\dot q_c^2}{q_i-q_f+\dot q_ct_f}.$$

由此得到的 $t_c,\ddot q_c$ 同样代入 LSPB 的分段序列生成轨迹。**两端取等号的几何含义**：**右边**取等号相当于**三角形**（没有直线段）；**左边**取等号相当于**矩形**（没有抛物线混合段）——但矩形在实际中**不可能出现**（「速度不可能在零时间内从零加速到某个速度」），所以**左边必须是严格不等号**。（[@def-4.2.4]）
:::

### C4 · 按规则计算路径点速度

写出分段斜率与速度规则，并说明它与"指定速度"的差别。

::: sol C4 核对
令 $v_k=\dfrac{q_k-q_{k-1}}{t_k-t_{k-1}}$ 为时间区间 $[t_{k-1},t_k]$ 内分段的**斜率**，则

$$\dot q_1=0,\qquad
\dot q_k=\begin{cases}0, & \operatorname{sgn}(v_k)\neq\operatorname{sgn}(v_{k+1})\\[1mm] \dfrac{v_k+v_{k+1}}{2}, & \operatorname{sgn}(v_k)=\operatorname{sgn}(v_{k+1})\end{cases}\qquad
\dot q_N=0 .$$

**读法**：**前后两段斜率异号**（路径在此折返，该点是极值点）⇒ 该点速度取 **0**；**同号**（路径继续朝一个方向）⇒ 取两段斜率的**平均**。全部速度确定之后，插值多项式的求解与「指定速度」路线**完全相同**。**与路线①的差别**：路线①的速度由用户自由指定、因此**可能超调**（在中间点速度不为零时会越过该点再返回来）；路线②的速度由斜率规则算出，异号处取 0，可避免本例折返点的超调；一般数据仍须检查各段是否单调。**看数值才看得清**：同一组路径点，路线① 指定 $\dot q_2=\pi$ 时轨迹会超过 $2\pi$；路线② 在 $q_2=2\pi$ 处斜率由正转负 ⇒ 速度取 0 ⇒「到这点的情况下它就是 $2\pi$ 的，没有到高，到 $2\pi$ 就往回返」。（[@method-4.2.D]）
:::

### C5 · 直线与圆弧路径的速度 / 加速度

写出两组的 $\dot{\boldsymbol p}_e$、$\ddot{\boldsymbol p}_e$ 与 Frenet 分解，并说明直线为什么是退化情形。

::: sol C5 核对
**直线**（参数式 $\boldsymbol p(s)=\boldsymbol p_l+\frac{s}{\|\boldsymbol p_f-\boldsymbol p_l\|}(\boldsymbol p_f-\boldsymbol p_l)$）：

$$\dot{\boldsymbol p}_e=\dot s\,\frac{\boldsymbol p_f-\boldsymbol p_i}{\|\boldsymbol p_f-\boldsymbol p_i\|}=\dot s\,\boldsymbol t,\qquad
\ddot{\boldsymbol p}_e=\ddot s\,\boldsymbol t .$$

——**速度与加速度都沿直线方向**，模分别为 $|\dot s|$、$|\ddot s|$。**圆弧**：

$$\ddot{\boldsymbol p}_e=\underbrace{\frac{\dot s^2}{\rho}\,\boldsymbol n}_{\text{向心：只改方向}}+\underbrace{\ddot s\,\boldsymbol t}_{\text{切向：只改大小}} .$$

（其中 $\rho$ 为圆半径，$\boldsymbol n$ 为**法线单位向量**。）**Frenet 标架三关系**：$\boldsymbol t=\dfrac{\mathrm d\boldsymbol p}{\mathrm ds}$、$\boldsymbol n=\dfrac{\mathrm d^2\boldsymbol p/\mathrm ds^2}{\|\mathrm d^2\boldsymbol p/\mathrm ds^2\|}$、$\boldsymbol b=\boldsymbol t\times\boldsymbol n$。**直线的退化**：$\dfrac{\mathrm d^2\boldsymbol p}{\mathrm ds^2}=\boldsymbol 0$ ⇒ 法线方向**无从定义**，**直线路径上不能唯一地定义坐标系 $(\boldsymbol t,\boldsymbol n,\boldsymbol b)$**——这不是推导出错，而是直线作为路径基元的固有性质。（[@thm-4.3.B]、[@def-4.3.2]）
:::


### C6 · 多段路径与时间超前

写出 $s_j(t)$ 的分段定义与超前量的递归关系，并说明为什么需要它。

::: sol C6 核对
$s_j$ 在原开始前为0，原结束后为段长，中间按时间律变化。提前后使用 $\widetilde s_j(t)=s_j(t+\Delta t_j)$，累计提前量满足 $\Delta t_j=\Delta t_{j-1}+\delta t_j$。这里提前的是实际运动启动，使相邻段重叠，不只是提早计算。重叠一般改变中间几何路径；若各截断增量速度连续，其和也连续，但需重算总峰值和碰撞余量。见[@thm-4.3.D]、[@ex-4.2.K]。
:::

### C7 · 角和轴法的姿态轨迹式

写出 $\theta_f$、$\boldsymbol r'$、$\boldsymbol\omega'$ 与回到基系的变换。

::: sol C7 核对
令 $R_i,R_f$ 为初始 / 最终坐标系绕基系的旋转矩阵，两坐标系之间的旋转矩阵 $R_{\rm rel}=R_i^{\mathrm T}R_f$；当 $\sin\theta_f\neq0$ 时，

$$\theta_f=\arccos\!\left(\frac{r_{11}+r_{22}+r_{33}-1}{2}\right),\qquad
\boldsymbol r'=\frac{1}{2\sin\theta_f}\begin{bmatrix}r_{32}-r_{23}\\ r_{13}-r_{31}\\ r_{21}-r_{12}\end{bmatrix}$$

（$r_{ij}$ 为 $R_{\rm rel}$ 的元素——**这不是新公式**，它就是角和轴的逆解「取迹求角、反对称部分求轴」，即对数映射 $\log R_{\rm rel}=\theta_fS(\boldsymbol r')$）。矩阵 $R'(t)$ 可视为 $R'(\theta(t),\boldsymbol r')$，从而**只需为标量 $\theta$ 指定一个时间律**（类型与单个关节的时间律相同，$\theta(0)=0$、$\theta(t_f)=\theta_f$）。因为 $\boldsymbol r'$ 为**常量**：

$$\boldsymbol\omega'=\dot\theta\,\boldsymbol r',\qquad \dot{\boldsymbol\omega}'=\ddot\theta\,\boldsymbol r',\qquad
R_e(t)=R_iR'(t),\qquad \boldsymbol\omega_e=R_i\boldsymbol\omega'(t),\qquad \dot{\boldsymbol\omega}_e=R_i\dot{\boldsymbol\omega}'(t) .$$

零角可保持姿态，半圈时不能除以正弦，须另外求固定轴并选连续方向。
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「路径和轨迹是同义词」

::: sol D1 核对
路径只给几何；轨迹还须给时间律，才能求出速度与加速度。运动规划求满足约束的可行运动，可以离线完成，也可以随观测在线更新。（[@def-4.1.1]–[@def-4.1.3]）
:::

### D2 · 「用户可以直接指定总时间 $t_f$」

::: sol D2 核对
可以指定总时间，但必须验证限速、限加速度与力矩等约束。另一种接口让用户指定相对速度、加速度比例，再由规划器确定时间；这两种接口都不能免去可行性检查。（[@def-4.1.4]）
:::

### D3 · 「约束数不够就升阶、次数越高越好」

::: sol D3 核对
应先检查约束的独立性与相容性。独立条件太多时通常要扩大函数族或放松要求；条件不足时可补边界或优化准则。方程数相等还不保证唯一，方程多也可能兼容。更高次数不自动改善峰值或数值条件，三次、五次的比较要连同边界和指标进行。
:::

### D4 · 「$t_c$ 就是 $t_f/2$」

::: sol D4 核对
**错，$t_c\le t_f/2$ 只是上界。** $t_c=t_f/2$ 只在**三角形极限**（加速度取到 (4.7) 的下界、常值速度段消失）时才成立。一般情形下解出的 $t_c$ 由 (4.6) 给出：$t_c=\dfrac{t_f}{2}-\dfrac12\sqrt{\dfrac{t_f^2\ddot q_c-4(q_f-q_i)}{\ddot q_c}}$，随指定的 $\ddot q_c$ 增大而减小（加速度越大，加速段越短、巡航段越长）。**更常见的两个错误**：① 把 $\ddot q_c$ 的**符号**写反——必须 $\operatorname{sgn}\ddot q_c=\operatorname{sgn}(q_f-q_i)$，否则 (4.6) 的根无意义；② 忘了 (4.7) 的**加速度下界**——根号内为负就无解。（[@thm-4.2.C]）
:::

### D5 · 「样条和抛物线混合的区别只是阶数」

::: sol D5 核对
这里的三次样条要求位置、速度、加速度连续并通过指定节点；抛物线混合通常只保证位置和速度连续，允许偏离中间经由点。混合不代表任何点都绝不经过；具体偏离量与相邻斜率、混合时间有关。见[@def-4.2.7]。
:::


### D6 · 「$\dot s$ 是个向量」

::: sol D6 核对
$\dot s$ 是标量，$\dot p=\dot s\,t$ 才是速度向量，速度模为 $|\dot s|$。圆弧上还有 $\ddot p=(\dot s^2/\rho)n+\ddot s\,t$：第一项沿法向改变速度方向，第二项沿切向；两项都须保留。（[@def-4.3.4]、[@thm-4.3.B]）
:::

### D7 · 「多段路径会自动在路径点处平滑过渡」

::: sol D7 核对
严格沿不共线折线且保持连续速度时，折角处必须停下。若要以非零速率通过，需改变附近几何，例如圆弧或混合。提前重叠也可能改变路径，但仅有提前量递推式不足以保证峰值、碰撞或光滑性全部合格。见[@def-4.3.5]。
:::
