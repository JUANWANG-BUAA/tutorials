## A. 定义卡

### A1 · 路径、轨迹、运动规划

用一句话写出三层各自"比上一层多了什么"，并给每种规划一个典型应用。

::: note A1 核对
**路径**（path）：机械手执行指定运动时**必须跟随的点的轨迹**——运动的**纯几何描述**，只回答「经过哪些点、连成什么形状」，**不回答「何时经过、多快经过」**。**轨迹**（trajectory）：**指定了时间律**的路径——不仅包括几何路径，还包括沿路径每一点的**速度与加速度**；控制提出更高要求时还可把**加加速度**也包含进来（计算量与成本更高，只在必要时做）。**运动规划**（motion planning）：在轨迹规划之上再加**避障**与**轨迹优化**（时间最短 / 损耗最小）——它是一个**动态过程**，整个运动过程中都在规划，因此还要考虑动力学。**关系**：路径 ⊂ 轨迹 ⊂ 运动规划。应用示例：直线焊缝（路径）→ 焊缝 + 恒速（轨迹）→ 焊缝 + 恒速 + 绕开工件（运动规划）。（[@def-4.1.1]–[@def-4.1.3]）
:::

### A2 · 运动律的两条硬约束

写出两条约束，并各说明它限制的是哪个物理量。

::: note A2 核对
**（一）执行器施加到关节的广义力不得违反饱和限制。** 加速度最终由电机输出的力矩决定，而电机力矩有限——若设计的加速度超过电机能提供的力矩，运动律**根本实现不了**；速度同理，最大速度受**功率**限制。**（二）不得激发结构的典型谐振模式。** 控制信号本身含有频率成分，要避免它与**结构本身的固有频率**重叠；一旦重叠就激起**共振**，很大的振幅会损伤结构甚至导致失效。**两条合起来** ⇒ 工程上最常用的要求是**设计光滑的轨迹**；而「光滑到什么程度」是可选的档位：**位置连续 / 速度连续（加速度跳跃）→ 加速度连续 → 加加速度连续**，档位越高**对电机的要求反而越低**（曲线越柔和，力矩与功率峰值越小），代价是计算量与成本上升。（[@thm-4.1.A]）
:::

### A3 · 轨迹规划器的接口与用户可指定的参量

写出输入 / 输出，并列出四类可指定参量。

::: note A3 核对
**输入**：路径描述、路径约束，以及由机械手**动力学**施加的约束。**输出**：按时间顺序给出的**位置、速度和加速度**值所构成的末端执行器轨迹（即底层伺服的参考输入）。**接口的另一半**：因为控制是在**关节空间**中完成的，还要用适当的**逆运动学算法**把操作空间的序列重构成关节变量的时间序列；若规划通过**示教再现**（第 6 章）进行，则对关节变量**直接测量**。**四类可指定参量**：① **极值点**（最大速度点、最大加速度点）；② **可能的中间点**（为避障等目的设定）；③ **插入点的几何基元**（两点之间用直线、圆弧还是抛物线连接）；④ **整个轨迹的时间**，以及对**特别感兴趣的点**指定的速度与加速度。**工业上的一条反直觉设计**：**一般不让用户指定总时间 $t_f$**，而是让用户指定**相对最大容许速度 / 最大加速度的百分比**（如 30% / 50% / 80%）——因为时间给得太短，所需速度加速度会超出机械手的物理极限，设计必然失败。（[@method-4.1.A]、[@def-4.1.4]）
:::

### A4 · 三次与五次多项式时间律

写出两者各需要几个约束、分别因为什么，并说明两者的最优性各需要什么指标与约束。

::: note A4 核对
**三次** $q(t)=a_3t^3+a_2t^2+a_1t+a_0$：**4 个系数需 4 个约束** = 初终位置 $q_i,q_f$ + 初终速度 $\dot q_i,\dot q_f$（一般设为 0——「一般的初始肯定是从零开始加速，终止完成任务一般也是回到零的」）。导数是**抛物线形式的速度曲线**与**线性形式的加速度曲线**。**五次** $q(t)=a_5t^5+\cdots+a_0$：若还要**同时指定初始与最终的加速度**，约束增加到 6 个 ⇒ 至少需要五阶；系数由 $t=0$ 与 $t=t_f$ 处对 $q$ 及**前两阶导数**的 6 个条件解出。**代价**：五次不继承原问题的平方力矩最优性——固定端点位置、速度、加速度时，最小平方 jerk 的解则是五次，不能脱离指标谈最优。（[@thm-4.2.A]、[@def-4.2.1]、[@def-4.2.2]）
:::

### A5 · 梯形速度曲线（LSPB）与两条标准假设

写出运动分段、两条假设，以及"两条假设为什么这么选"。

::: note A5 核对
指定一条**梯形速度曲线**：起始段为**常值加速度**、中段维持**巡航速度**、末段为**常值减速度**；对速度积分得位置轨迹——由**一条直线段**和在其两端分别连接到初始位置与最终位置的**两段抛物线**组成，因此又称**抛物线混合**（linear segments with parabolic blends，LSPB）。类比电梯拖动：先匀加速、再巡航、再匀减速，正好到零停下来。**两条标准假设**：① **初始速度与最终速度都为零**；② 两个常加速度分段的**时间长度相同**（因此两段加速度等量），轨迹在 $t_m=t_f/2$ 时刻关于**平均值点** $q_m=(q_f+q_i)/2$ **对称**。**为什么取相等**：可以减少需要解的参数与方程——实际过程中这种计算可能要做千万次以上，「你节省一点计算的时间，累积起来就非常多了」。（[@def-4.2.3]）
:::

### A6 · 圆形路径的三要素与随体坐标系

写出三要素、圆心公式，以及随体坐标系怎么建。

::: note A6 核对
**三要素**：圆轴的**单位向量** $\boldsymbol r$、圆轴上**一点的位置向量** $\boldsymbol d$、圆上**一点的位置向量** $\boldsymbol p_l$。令 $\boldsymbol\delta=\boldsymbol p_l-\boldsymbol d$，为使 $p_l$ 不在轴上（圆不退化成一点）必有 $|\boldsymbol\delta^{\mathrm T}\boldsymbol r|<\|\boldsymbol\delta\|$，此时**圆心**为

$$\boldsymbol c=\boldsymbol d+(\boldsymbol\delta^{\mathrm T}\boldsymbol r)\,\boldsymbol r .$$

**随体坐标系 $o'\!-\!x'y'z'$**：原点 $o'$ 与圆心重合；轴 $z'$ 沿 $\boldsymbol r$；轴 $x'$ 沿向量 $\boldsymbol p_l-\boldsymbol c$ 的方向；轴 $y'$ 按**右手系**选取。在参考坐标系中圆的参数表达式为 $\boldsymbol p'=\begin{bmatrix}\rho\cos(s/\rho)&\rho\sin(s/\rho)&0\end{bmatrix}^{\mathrm T}$（$\rho=\|\boldsymbol p_l-\boldsymbol c\|$），换到一般参考系即 $\boldsymbol p=\boldsymbol c+R\boldsymbol p'$，其中 $R=[\boldsymbol x'\ \boldsymbol y'\ \boldsymbol z']$。**为什么这样建**：「如果在经过它自己圆心、然后有一个面跟圆弧面重合的坐标系里表示，这个角是非常简单的」。（[@def-4.3.3]）
:::

### A7 · 操作空间位置轨迹、弧长时间律与多段路径

写出解耦形式、$\dot{\boldsymbol p}_e$ 的分解，以及多段路径的参数表达式。

::: note A7 核对
**解耦**：令 $\boldsymbol p_e=f(s)$ 为路径作为**弧长** $s$ 的函数（几何），时间律由标量函数 $s(t)$ 描述（时间）——于是 $\dot{\boldsymbol p}_e=\dfrac{\mathrm d\boldsymbol p_e}{\mathrm ds}\dot s=\dot s\,\boldsymbol t$，其中 $\boldsymbol t$ 为路径在点 $p$ 的**切向量**；$\dot s$ 表示速度向量的**数量（模）**，正负号取决于 $p$ 沿 $\boldsymbol t$ 的方向。**关键**：$s$ 是一维标量，**上述针对关节轨迹的生成技术全部可以使用**（三次、梯形、样条都能直接套在 $s(t)$ 上）。**多段路径**：$\boldsymbol p_e=\boldsymbol p_0+\sum_{j=1}^N\dfrac{s_j}{\|\boldsymbol p_j-\boldsymbol p_{j-1}\|}(\boldsymbol p_j-\boldsymbol p_{j-1})$，其中 $s_j(t)$ 分段定义（在 $t_{j-1}$ 前为 0、在 $[t_{j-1},t_j]$ 中由 $s'_j(t)$ 连续变化到 $\|\boldsymbol p_j-\boldsymbol p_{j-1}\|$、之后保持）；微分得 $\dot{\boldsymbol p}_e=\sum_j\dot s_j\boldsymbol t_j$。**问题**：两条**不共线**分段之间，路径点处一阶导数不连续，机械手将**不得不停下来**——这类允许松弛约束的点称为**经由点**（via point）。（[@def-4.3.4]、[@def-4.3.5]）
:::

## B. 结论卡

### B1 · 为什么最小能量解恰好是三次多项式

写出被优化的方程与指标，并说明端点速度与动力学模型的限制。

::: note B1 核对
**模型**：绕定轴转动的刚体，转动惯量 $I$，转动由电机力矩 $\tau$ 提供；令 $\dot q=\omega$，求解 $I\dot\omega=\tau$，固定初终速度为零，并服从条件 $\int_0^{t_f}\omega(t)\,\mathrm dt=q_f-q_i$，使性能指标 $\int_0^{t_f}\tau^2(t)\,\mathrm dt$ 最小化。其解的形式为

$$\omega(t)=at^2+bt+c .$$

即**速度是二阶多项式 ⇒ 位置是三阶（三次）多项式、加速度是线性函数**。**适用边界**：三次可用于更复杂系统的插值，但一般不再是其真实动力学下的最优解；若未规定端点速度，匀速即可令平方力矩指标为零。**方法论提示**：这个问题本身是**泛函问题**（变分法 / 现代控制理论里的同类内容），所以课程直接给结论。（[@thm-4.2.A]）
:::

### B2 · 四条修正路线与各自保证到几阶连续

列出四条路线、各自补的两个约束与连续性。

::: note B2 核对
| 路线 | 补的两个约束 | 保证的连续性 |
|:--|:--|:--|
| ① 在路径点**指定**速度 | 用户给出 $q_k$ 与 $\dot q_k$ | 位置、速度连续 |
| ② 按规则**计算**速度 | 用相邻分段斜率的平均值定 $\dot q_k$（异号则取 0） | 位置、速度连续 |
| ③ 要求**加速度连续**（样条） | 速度连续 + 加速度连续 | 位置、速度、**加速度**连续 |
| ④ **低于三阶**的多项式 + 抛物线混合 | 用梯形速度曲线的做法 | 位置、速度连续（加速度跳跃） |

**小结**：前两条可以保证位置的平滑连续、速度连续，但**不能保证速度的平滑性**（加速度有跳跃）；**只有样条能保证加速度连续**。**三条路线的代价各不相同**：① 的代价是**可能超调**（中间点速度由用户自由指定，故轨迹可能越过该点再返回来）；② 用斜率规则算速度就**不再超调**（异号处速度取 0）；③ 的代价是计算量最高（要解 $N$ 元方程组）；④ 的代价是**轨迹不经过路径点**（只能从附近经过，此时应把路径点改称**经由点**）。（[@method-4.2.B]）
:::

### B3 · 为什么不用单个高阶多项式

写出五条缺点，并说明"出路"的阶数下限为什么是三次。

::: note B3 核对
① **不可能指定起始速度和终点速度**——所有自由度都被「过点」用光了；② **阶数增加时振动特性增加**，可能导致机械手产生**不自然的轨迹**（一个 10 阶多项式经过 10 个点，其导数有 9 个极值点，实际运动中会出现震荡）；③ **阶数增加时系数计算的数值精度降低**（方程系统的矩阵维度变大）；④ **约束方程系统求解繁难**（耗费大量计算资源）；⑤ **系数取决于所有指定的点**——「只要其中某一个点变了，所有的量都得重新算」。

**出路**：改用一组适当数量、在路径点处**彼此连续的低阶插值多项式**；**下限是三次**——三次多项式在满足两端**位置**约束后还剩**两个自由度**，正好可以用来施加**速度的连续性**。（[@method-4.2.A]、[@def-4.2.5]）
:::

### B4 · 样条的方程计数与两个虚拟点

写出方程数与未知数的差距，以及三种出路。

::: note B4 核对
**计数**：中间点贡献 $4(N-2)$ 个方程、两端点贡献 6 个方程，共 $4N-2$ 个；而 $N-1$ 个三次多项式只有 $4(N-1)$ 个未知系数——**方程比未知数多 2**，系统不能直接求解。多出来的这两个，正是「初始与最终**加速度**」这两个可以任意指定的条件。**三种出路**：① 让第一段和最后一段改用**四阶多项式**（5 个系数容纳 5 个约束）——但算法通常要求各段形式一致，不理想；② 只要求在**部分时间**内保持轨迹一致（工程近似）；③ **引入两个虚拟点**：对它们施加位置、速度和加速度的**连续性约束**，但**不指定其实际位置**（由于位置约束只考虑连续性，虚拟点定位在何处无关紧要）。**引入后**：$N+1$ 个三次多项式即 $4(N+1)$ 个未知数；方程侧为 $4(N-2)+6+6=4(N+1)$——**未知数与方程数相等，解存在且唯一**。（[@thm-4.2.G]）
:::

### B5 · 样条的降维：为什么最终是一个三对角系统

写出三个步骤，并说明 $A$ 与关节的关系。

::: note B5 核对
**第一步** 利用三次多项式的二阶导数必为时间的**线性函数**：$\ddot\Pi_k(t)=\dfrac{\ddot\Pi_k(t_{k+1})}{\Delta t_k}(t_{k+1}-t)+\dfrac{\ddot\Pi_k(t_k)}{\Delta t_k}(t-t_k)$，$\Delta t_k=t_{k+1}-t_k$；对时间**两次积分**后 $\Pi_k(t)$ 只取决于 **4 个未知数**（两端的 $\ddot\Pi_k$ 与 $\Pi_k$）。**第二步** 借助 $N$ 个位置指定值 + 位置连续性 + 加速度连续性，把未知数从 $4(N+1)$ 降到 $2(N+1)$，再降到 $N$（被消掉的 $q_2,q_{N+1}$ 是虚拟点位置）。**第三步** 用唯一还没用上的**速度连续性**补齐：左侧多项式右端点的速度等于右侧多项式左端点的速度，恰给出 $N$ 个方程 $A\big[\ddot\Pi_2(t_2)\ \cdots\ \ddot\Pi_{N+1}(t_{N+1})\big]^{\mathrm T}=\boldsymbol b$，$A$ **非奇异**且具有**三对角带结构**（前向 + 后向计算即可）。**最大红利**：$A$ **对所有关节都一样**——因为它只依赖指定的**时间间隔** $\Delta t_k$，而所有关节的时间间隔相同；唯一随关节变化的只有右端项 $\boldsymbol b$（它与关节角度相关）。（[@thm-4.2.H]）
:::

### B6 · 位置规划的两次"降维"

写出操作空间规划把几维问题化成一维的两处，以及由此得到的统一图景。

::: note B6 核对
**第一次降维（位置）**：几何归几何、时间归时间——$\boldsymbol p_e=f(s)$（路径决定形状）+ $s(t)$（一个**标量**函数决定沿路径走多快）。**第二次降维（姿态）**：旋转矩阵不能逐元素插值（正交性会被破坏），于是或用**欧拉角**三个标量分别插值、或用**角和轴**把姿态化为「绕一根固定轴转过的角度」$\theta(t)$——**轴是常量，只规划一个标量 $\theta$**。**统一图景**：位置落在 $s(t)$、姿态落在 $\theta(t)$，**两次降维把六维操作空间规划变回一维标量规划**，于是关节空间的方法（三次、梯形、样条）全部复用。**代价**：每个设定点都要过一次逆运动学（[@def-2.10.1] 的操作空间到关节空间），运算量非常大，因此要给生成序列的**最大采样率设上限**；工程上的对策是规划时采样率不高，但把它输入底层伺服控制系统时先做一次**线性微小内插**——这样提高了参考输入的更新频率，「对于增强系统的动态性能是有关键的」。（[@method-4.3.A]、[4.3.2](sec4-3-2.md)）
:::

### B7 · 关节空间还是操作空间

写出两个空间各自的优势与麻烦，并给出那条贯穿全章的结论。

::: note B7 核对
**操作空间规划**：任务本身就在操作空间中描述（末端要走直线、要绕开某个障碍物），最直观；而且**避障必须在操作空间做**——「在关节空间中，我们不知道障碍物在什么地方，很可能就撞上了」。**关节空间规划**：控制直接在关节上做，所以关节空间是**基础**（「其实咱们大部分篇幅也是讲关节空间的规划」），而且**关节空间的方法都可以推广到操作空间**。**两个空间之间隔着正运动学的非线性**：关节空间里的一条直线映射到操作空间就成了一条曲线，反之亦然。**为什么不能只在操作空间做**：① **奇异位形邻域**——在奇异位形附近做逆运动学，求出的关节速度可能非常大；② **冗余自由度**——逆解有无穷多个解，难以直接求解。此时宁可在关节空间指定路径。**贯穿全章的结论**：**即使在操作空间中规划，最后也要把它转到关节空间中，得到关节变量的值，才能实现对机械手的控制。**（[4.1.4](sec4-1.md#sec-4.1.4)）
:::

## C. 公式卡

### C1 · 三次多项式的系数方程组

写出四个方程，并说明例 4.2.B（$0\to\pi$，$t_f=1$）的解与三张曲线的形状。

::: note C1 核对
$$a_0=q_i,\qquad a_1=\dot q_i,\qquad a_3t_f^3+a_2t_f^2+a_1t_f+a_0=q_f,\qquad 3a_3t_f^2+2a_2t_f+a_1=\dot q_f .$$

**例 4.2.B**：$q_i=0,\ q_f=\pi,\ t_f=1,\ \dot q_i=\dot q_f=0$ ⇒ $a_0=0,a_1=0$，$a_3+a_2=\pi$、$3a_3+2a_2=0$ ⇒ $a_2=3\pi,\ a_3=-2\pi$，即

$$q(t)=-2\pi t^3+3\pi t^2,\qquad \dot q(t)=-6\pi t^2+6\pi t,\qquad \ddot q(t)=-12\pi t+6\pi .$$

**读图要点**：位置平滑且连续；速度连续但**不平滑**（$t=0$ 与 $t=1$ 两处各有一个折点）；加速度在这两点上**跳跃**（从 0 跳到 $6\pi$，再从 $-6\pi$ 跳回 0）。这正是「位置 / 速度光滑、加速度跳跃」那一档的典型代表。**通用解法**：整个过程都是「**解方程 / 待定系数法**」——根据任务找约束（约束就是方程），再把系数解出来；方程多了就**超定**（提高阶次或改解析式形式），方程少了就**多解**（补优化约束或工程约束）。（[@def-4.2.1]、[@ex-4.2.B]）
:::

### C2 · 梯形速度曲线：$t_c$ 方程与加速度下界

写出 $q_c$、衔接条件、二次方程、根与下界，并说明等号对应什么形状。

::: note C2 核对
$$q_c=q_i+\tfrac12\ddot q_ct_c^2,\qquad \ddot q_ct_c=\frac{q_m-q_c}{t_m-t_c}\quad(t_m=t_f/2,\ q_m=(q_f+q_i)/2),$$

$$\ddot q_ct_c^2-\ddot q_ct_f t_c+q_f-q_i=0\qquad\text{(关于 }t_c\text{ 的二次方程)},$$

$$|\ddot q_c|\ge\frac{4|q_f-q_i|}{t_f^2}\quad\text{(加速度下界；根号内非负)},$$

取 $t_c\le t_f/2$ 的根：$t_c=\dfrac{t_f}{2}-\dfrac12\sqrt{\dfrac{t_f^2\ddot q_c-4(q_f-q_i)}{\ddot q_c}}$，并以 $\operatorname{sgn}\ddot q_c=\operatorname{sgn}(q_f-q_i)$ 指定加速度方向。**等号的形状**：下界取等号时轨迹**不再有常值速度段**，只剩加速段与减速段——速度曲线退化为**三角形**（$t_c=t_f/2$）。**分段位置序列**：$0\le t\le t_c$ 段 $q=q_i+\frac12\ddot q_ct^2$；巡航段 $q=q_i+\ddot q_ct_c\left(t-\frac{t_c}{2}\right)$；末段 $q=q_f-\frac12\ddot q_c(t_f-t)^2$。**代价**：性能指标比最优（三次）情形**在 $t_c/T=1/3$ 时增加 12.5%**——「但是折中考虑，它更简单、计算速度更快、轨迹没那么复杂，最后也是可接受的」。（[@thm-4.2.C]）
:::

### C3 · 指定巡航速度与它的约束区间

写出两条式子与区间，并说明两个端点各对应什么形状。

::: note C3 核对
若除 $q_i,q_f,t_f$ 外直接指定**巡航速度** $\dot q_c$，它须服从

$$\frac{|q_f-q_i|}{t_f}<|\dot q_c|\le\frac{2|q_f-q_i|}{t_f},\qquad
t_c=\frac{q_i-q_f+\dot q_ct_f}{\dot q_c},\qquad
\ddot q_c=\frac{\dot q_c^2}{q_i-q_f+\dot q_ct_f}.$$

由此得到的 $t_c,\ddot q_c$ 同样代入 LSPB 的分段序列生成轨迹。**两端取等号的几何含义**：**右边**取等号相当于**三角形**（没有直线段）；**左边**取等号相当于**矩形**（没有抛物线混合段）——但矩形在实际中**不可能出现**（「速度不可能在零时间内从零加速到某个速度」），所以**左边必须是严格不等号**。（[@def-4.2.4]）
:::

### C4 · 按规则计算路径点速度

写出分段斜率与速度规则，并说明它与"指定速度"的差别。

::: note C4 核对
令 $v_k=\dfrac{q_k-q_{k-1}}{t_k-t_{k-1}}$ 为时间区间 $[t_{k-1},t_k]$ 内分段的**斜率**，则

$$\dot q_1=0,\qquad
\dot q_k=\begin{cases}0, & \operatorname{sgn}(v_k)\neq\operatorname{sgn}(v_{k+1})\\[1mm] \dfrac{v_k+v_{k+1}}{2}, & \operatorname{sgn}(v_k)=\operatorname{sgn}(v_{k+1})\end{cases}\qquad
\dot q_N=0 .$$

**读法**：**前后两段斜率异号**（路径在此折返，该点是极值点）⇒ 该点速度取 **0**；**同号**（路径继续朝一个方向）⇒ 取两段斜率的**平均**。全部速度确定之后，插值多项式的求解与「指定速度」路线**完全相同**。**与路线①的差别**：路线①的速度由用户自由指定、因此**可能超调**（在中间点速度不为零时会越过该点再返回来）；路线②的速度由斜率规则算出，异号处取 0 ⇒ **不再超调**。**看数值才看得清**：同一组路径点，路线① 指定 $\dot q_2=\pi$ 时轨迹会超过 $2\pi$；路线② 在 $q_2=2\pi$ 处斜率由正转负 ⇒ 速度取 0 ⇒「到这点的情况下它就是 $2\pi$ 的，没有到高，到 $2\pi$ 就往回返」。（[@method-4.2.D]）
:::

### C5 · 直线与圆弧路径的速度 / 加速度

写出两组的 $\dot{\boldsymbol p}_e$、$\ddot{\boldsymbol p}_e$ 与 Frenet 分解，并说明直线为什么是退化情形。

::: note C5 核对
**直线**（参数式 $\boldsymbol p(s)=\boldsymbol p_l+\frac{s}{\|\boldsymbol p_f-\boldsymbol p_l\|}(\boldsymbol p_f-\boldsymbol p_l)$）：

$$\dot{\boldsymbol p}_e=\dot s\,\frac{\boldsymbol p_f-\boldsymbol p_i}{\|\boldsymbol p_f-\boldsymbol p_i\|}=\dot s\,\boldsymbol t,\qquad
\ddot{\boldsymbol p}_e=\ddot s\,\boldsymbol t .$$

——**速度与加速度都沿直线方向**，模分别由 $\dot s$、$\ddot s$ 给出。**圆弧**：

$$\ddot{\boldsymbol p}_e=\underbrace{\frac{\dot s^2}{\rho}\,\boldsymbol n}_{\text{向心：只改方向}}+\underbrace{\ddot s\,\boldsymbol t}_{\text{切向：只改大小}} .$$

（其中 $\rho$ 为圆半径，$\boldsymbol n$ 为**法线单位向量**。）**Frenet 标架三关系**：$\boldsymbol t=\dfrac{\mathrm d\boldsymbol p}{\mathrm ds}$、$\boldsymbol n=\dfrac{\mathrm d^2\boldsymbol p/\mathrm ds^2}{\|\mathrm d^2\boldsymbol p/\mathrm ds^2\|}$、$\boldsymbol b=\boldsymbol t\times\boldsymbol n$。**直线的退化**：$\dfrac{\mathrm d^2\boldsymbol p}{\mathrm ds^2}=\boldsymbol 0$ ⇒ 法线方向**无从定义**，**直线路径上不能唯一地定义坐标系 $(\boldsymbol t,\boldsymbol n,\boldsymbol b)$**——这不是推导出错，而是直线作为路径基元的固有性质。（[@thm-4.3.B]、[@def-4.3.2]）
:::


### C6 · 多段路径与时间超前

写出 $s_j(t)$ 的分段定义与超前量的递归关系，并说明为什么需要它。

::: note C6 核对
**多段路径**的弧长分量分段定义为：在 $t\le t_{j-1}$ 时为 0、在 $t_{j-1}<t<t_j$ 时由 $s'_j(t)$ 从 0 连续变化到 $\|p_j-p_{j-1}\|$、在 $t\ge t_j$ 时保持该值；于是 $\dot{\boldsymbol p}_e=\sum_j\dot s_j\boldsymbol t_j$、$\ddot{\boldsymbol p}_e=\sum_j\ddot s_j\boldsymbol t_j$。**时间超前**：在弧长规划中使用梯形速度曲线时，只要适当预测单个分段的生成、**赶在前一个分段的计算完成之前**就足够了；这带来对 $s'_j(t)$ 的修正（在 $[t_{j-1}-\Delta t_j,\ t_j-\Delta t_j]$ 区间内取 $s_j(t+\Delta t_j)$），其中超前量按

$$\Delta t_j=\Delta t_{j-1}+\delta t_j,\qquad j=1,\dots,N,\quad \Delta t_0=0$$

**递归**估计——它等于**前一分段已产生的时间超前**加上**当前分段开始的时间超前**。**为什么需要**：如果每一段都等前一段算完再开始，整体时间就会被拖长（例 4.2.K：保守做法会让机械手在中间点「被强迫停在那里」——加速、匀速、减速到零、停住、再重新加速）；用超前量做预测可以让关节**仍到达最终点**但不再保证在指定时刻穿越中间点（$\pi$ 点于是成了**经由点**），全局持续时间更短。**老师提醒**：这种规划**没有考虑速度连续性**，实际中要加抛线段做平滑过渡。（[@thm-4.3.D]、[@ex-4.2.K]）
:::

### C7 · 角和轴法的姿态轨迹式

写出 $\theta_f$、$\boldsymbol r'$、$\boldsymbol\omega'$ 与回到基系的变换。

::: note C7 核对
令 $R_i,R_f$ 为初始 / 最终坐标系绕基系的旋转矩阵，两坐标系之间的旋转矩阵 $R_i^f=R_i^{\mathrm T}R_f$；当 $\sin\theta_f\neq0$ 时，

$$\theta_f=\arccos\!\left(\frac{r_{11}+r_{22}+r_{33}-1}{2}\right),\qquad
\boldsymbol r'=\frac{1}{2\sin\theta_f}\begin{bmatrix}r_{32}-r_{23}\\ r_{13}-r_{31}\\ r_{21}-r_{12}\end{bmatrix}$$

（$r_{ij}$ 为 $R_i^f$ 的元素——**这不是新公式**，它就是角和轴的逆解「取迹求角、反对称部分求轴」，即对数映射 $\log R_i^f=\theta_fS(\boldsymbol r')$）。矩阵 $R'(t)$ 可视为 $R'(\theta(t),\boldsymbol r')$，从而**只需为标量 $\theta$ 指定一个时间律**（类型与单个关节的时间律相同，$\theta(0)=0$、$\theta(t_f)=\theta_f$）。因为 $\boldsymbol r'$ 为**常量**：

$$\boldsymbol\omega'=\dot\theta\,\boldsymbol r',\qquad \dot{\boldsymbol\omega}'=\ddot\theta\,\boldsymbol r',\qquad
R_e(t)=R_iR'(t),\qquad \boldsymbol\omega_e=R_i\boldsymbol\omega'(t),\qquad \dot{\boldsymbol\omega}_e=R_i\dot{\boldsymbol\omega}'(t) .$$

**为什么高明**：「**这个轴是固定的、不变的**，那我们只要规划 $\theta$ 就可以了——相当于把它变成一个**一维**的问题。」（[@thm-4.3.F]）
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「路径和轨迹是同义词」

::: note D1 核对
**差一个时间律。** 路径是**纯几何描述**（经过哪些点、连成什么形状），轨迹是**指定了时间律的路径**（沿路径每一点的速度与加速度）。**实操判据**：写「轨迹」时必须能说出**每点的速度或加速度从哪来**——说不出就说明你手上只有一条路径。**连带的错**：把**运动规划**也当同义词——它还要加避障与轨迹优化，且是一个**动态过程**（整个运动过程中都在规划）。（[@def-4.1.1]–[@def-4.1.3]）
:::

### D2 · 「用户可以直接指定总时间 $t_f$」

::: note D2 核对
**工业上一般不这么干。** 原因是时间给得太短时，所需的速度与加速度就可能超过机械手的物理极限，设计必然失败。**正确做法**：让用户指定**相对最大容许速度 / 最大加速度的百分比**（如最大速度的 30% / 50% / 80%），从源头避开「运动周期太短 ⇒ 速度加速度过高」的失效。**更一般的纪律**：几何轨迹**不可能由用户完全指定**——只能指定少量参量（极值点、可能的中间点、插入点的几何基元、总时间与个别点的速度加速度），其余各点的运动律由规划算法**按约束反解**出来。（[@def-4.1.4]、[4.1.3](sec4-1.md#sec-4.1.3)）
:::

### D3 · 「约束数不够就升阶、次数越高越好」

::: note D3 核对
**前半句对、后半句错。** 约束与阶次必须**匹配**：三次有 4 个系数、所以只能给 4 个条件，任务一旦要求指定初终**加速度**就必须升到五次；但**升阶有代价**——五次不继承原问题的平方力矩最优性（固定端点位置、速度、加速度时，最小平方 jerk 则可得到五次），而且阶次越高计算量越大、系数求解的数值精度越低。**更进一步**：点一多就**不要**用一个 $(N-1)$ 阶多项式穿所有点（[@method-4.2.A] 的五条缺点），而应改用**一组低阶多项式首尾相接**——**下限是三次**，因为三次在满足两端位置后还剩两个自由度，正好用来施加速度连续性。（[@def-4.2.2]、[@method-4.2.A]）
:::

### D4 · 「$t_c$ 就是 $t_f/2$」

::: note D4 核对
**错，$t_c\le t_f/2$ 只是上界。** $t_c=t_f/2$ 只在**三角形极限**（加速度取到 (4.7) 的下界、常值速度段消失）时才成立。一般情形下解出的 $t_c$ 由 (4.6) 给出：$t_c=\dfrac{t_f}{2}-\dfrac12\sqrt{\dfrac{t_f^2\ddot q_c-4(q_f-q_i)}{\ddot q_c}}$，随指定的 $\ddot q_c$ 增大而减小（加速度越大，加速段越短、巡航段越长）。**更常见的两个错误**：① 把 $\ddot q_c$ 的**符号**写反——必须 $\operatorname{sgn}\ddot q_c=\operatorname{sgn}(q_f-q_i)$，否则 (4.6) 的根无意义；② 忘了 (4.7) 的**加速度下界**——根号内为负就无解。（[@thm-4.2.C]）
:::

### D5 · 「样条和抛物线混合的区别只是阶数」

::: note D5 核对
**不是阶数问题，而是两处本质差别。** ① **连续性档位不同**：样条保证位置、速度、**加速度**都连续；抛物线混合的线性内插**容忍加速度的不连续**（位置、速度连续）。② **是否经过路径点不同**：样条**经过**每个指定点；抛物线混合的轨迹**不达到**路径点中的任何一个，而是从**附近经过**——此时把路径点称为**经由点**（via point）更合适。**混合加速度越大，通路与经由点越接近**；混合时间越短，越贴近经由点，但以**更高的加速度**为代价（「在更短的时间内完成从一个速度到另一个速度的过渡，就需要更大的加速度」）。**工业上的选择**：**当不要求轨迹恰在指定瞬时从经由点附近经过时**，用梯形速度曲线开发轨迹规划算法就很有吸引力——因为足够简单。（[@def-4.2.7]、[@ex-4.2.J]）
:::


### D6 · 「$\dot s$ 是个向量」

::: note D6 核对
**错，$\dot s$ 是标量（速度的模）。** 在 $\dot{\boldsymbol p}_e=\dfrac{\mathrm d\boldsymbol p_e}{\mathrm ds}\dot s=\dot s\,\boldsymbol t$ 里，**方向由切向量 $\boldsymbol t$ 承担**；$\dot s$ 表示与点 $p$ 有关的速度向量的**数量**，其**正负号**取决于 $p$ 沿 $\boldsymbol t$ 的方向。**连带的错**：算圆弧加速度时漏掉**向心项**——圆弧上 $\ddot{\boldsymbol p}_e=\dfrac{\dot s^2}{\rho}\boldsymbol n+\ddot s\,\boldsymbol t$，**两项缺一不可**：向心项只改**方向**、切向项只改**大小**。（[@def-4.3.4]、[@thm-4.3.B]）
:::

### D7 · 「多段路径会自动在路径点处平滑过渡」

::: note D7 核对
**不会。** 因为两条**不共线**分段之间，路径点处**一阶导数不连续**，机械手将**不得不停下来**，然后再沿下一个分段的方向前进。**两条对策**：① 用**经由点**（抛物线混合「削角」把分段连起来，至少保证一阶导数连续）；② 用**时间超前**避免全局时间被拉长（$\Delta t_j=\Delta t_{j-1}+\delta t_j$——在前一段完成前就启动下一段）。**但要清楚时间超前的代价**：「咱们这个规划**没有考虑速度连续性**，就是从一段到另一段，它是不是平滑过渡的（不是）……实际过程中还需要加一个抛线段来进行平滑过渡，或者进行提前的规划。」（[@def-4.3.5]、[@thm-4.3.D]）
:::
