# 4.1 路径和轨迹

给定关节变量 $\boldsymbol q$ 可以由第二章正运动学确定末端位姿，给定关节速度 $\dot{\boldsymbol q}$ 可以由第三章雅可比确定末端速度；但要把机械臂真正动起来——例如让末端从桌面上的一点平稳移到另一点，或先抬高避障再落下——仅仅知道起终点位姿还不够：规划器必须同时交代清楚**几何路线**和**时间安排**。

<a id="sec-4.1.1"></a>

{{#include ../assets/figures/robot-trajectory.md}}

## 4.1.1 三个核心概念：路径、轨迹、运动规划

同一条空间直线，既可以在 $1\,\mathrm s$ 内走完，也可以在 $2\,\mathrm s$ 内走完：两次运动经过的几何点完全相同，但中途时刻的速度、加速度与所需的电机力矩截然不同。在机器人控制系统分层中，轨迹规划承上启下，为底层伺服控制生成参考输入：

| 控制层级 | 核心职责 | 本课程对应章节 |
|:--|:--|:--|
| 高层 · 任务与行为层 | 将复杂作业拆解为子任务并规划无碰撞全局方案 | [第 10–12 章](../ch10/overview.md)（移动机器人规划） |
| 中层 · 轨迹规划层 | 为给定子任务构造随时间演化的参考运动 $\boldsymbol q(t),\dot{\boldsymbol q}(t),\ddot{\boldsymbol q}(t)$ | **本章** |
| 底层 · 伺服控制层 | 依靠传感器反馈跟踪规划器输出的参考轨迹 | [第 7–9 章](../ch07/overview.md) |

围绕中层与高层的分工，先严格界定三个基本概念：

::: def 定义 4.1.1 · 路径 path {#def-4.1.1}
**路径（path）**纯粹是**空间几何**描述：它规定机械臂在关节空间或操作空间中经过的点序列及其几何形状（如直线、圆弧），**不包含任何时间信息**。
:::

::: def 定义 4.1.2 · 轨迹 trajectory {#def-4.1.2}
**轨迹（trajectory）**是在路径基础上叠加**时间律（timing law）**的运动描述，即给出位置随时间变化的显式规律，使任意时刻的速度与加速度（更高要求下还可包含加速度对时间的导数，即**加加速度**）都可确定。

**定量对比**：对同一段静止起停的位移 $\Delta q=1\,\mathrm{rad}$，若按三次多项式分别在 $t_f=1\,\mathrm s$ 与 $t_f=2\,\mathrm s$ 内完成，位置曲线仅仅是在时间轴上横向拉伸；但速度峰值从 $1.5$ 降至 $0.75\,\mathrm{rad/s}$（减半），加速度峰值则从 $6$ 降至 $1.5\,\mathrm{rad/s^2}$（降至四分之一）。可见同一条几何路径对应无穷多条轨迹，而时间安排直接决定执行器峰值负担。
:::

::: def 定义 4.1.3 · 运动规划 motion planning {#def-4.1.3}
**运动规划（motion planning）**涵盖更广的作业决策层面：除生成轨迹本身外，还根据任务目标与环境约束求解可行运动，通常包含**避障路径搜索**、在线重规划以及按最短时间或最小能耗等性能指标进行轨迹优化。
:::

### 易混对照：路径、轨迹与运动规划

| 概念 | 核心区分 | 典型问题 |
|:--|:--|:--|
| 路径（path） | 纯几何形态，无时间参数 | 「经过哪些点、走哪条线」 |
| 轨迹（trajectory） | 路径 + 时间律 $s(t)$ 或 $q(t)$ | 「何时到达、各时刻速度/加速度是多少」 |
| 运动规划（motion planning） | 融合环境避障、动力学约束与代价优化 | 「怎样避开障碍且满足硬件限制地完成任务」 |

> **自检练习**：只给定一条几何“路径”，能否直接算出机械臂各关节的转动速度？为什么？（答案：不能；速度是位置对时间的导数，纯几何路径不含时间信息，必须补充时间律构成轨迹后才能求导。）

## 4.1.2 运动律的两条硬约束

并非任意光滑曲线都能被真实机械臂跟踪。设计任何运动律都必须满足两类物理硬约束（教材 §4.1）：

::: thm 定理 4.1.A · 运动律的两条硬约束 {#thm-4.1.A}
1. **执行器广义力饱和限制**：关节加速度决定所需惯性力矩，速度直接关联电机功率与反电动势。若规划出的加速度或速度超出电机/减速器的物理上限，控制器将因执行器饱和而无法跟踪参考轨迹；
2. **抑制结构谐振激发**：控制信号含有的频率成分不得与机械臂机械结构本身的固有频率重叠。一旦频率接近，会激起剧烈**共振**，轻则破坏跟踪精度，重则导致机械结构疲劳损伤或失效。
:::

曲线导数的连续阶次直接影响高频激振与执行冲击：若位置连续而速度跳变，理想模型需要无穷大加速度脉冲，工程上不可实现；因此至少应保证**速度连续**。提高连续阶次可以让动作更柔和，但也会抬高设计与计算代价，且平滑度本身并不自动保证峰值力矩更小——不同时间律的性能比较必须给定运动时间、负载和动力学约束。

| 连续性要求 | 位置 | 速度 | 加速度 | 加加速度 | 本章例子 |
|:--|:--|:--|:--|:--|:--|
| 速度连续 | 连续 | 连续 | 可以跳变 | — | 三次多项式、梯形速度曲线（LSPB）、Hermite 分段插值 |
| 加速度连续 | 连续 | 连续 | 连续 | 可以跳变 | 零端点加速度的五次轨迹接静止段、三次样条 |
| 加加速度连续 | 连续 | 连续 | 连续 | 连续 | 需要更高阶的连续性约束 |

因为正运动学 $\boldsymbol p_e=\boldsymbol f(\boldsymbol q)$ 通常高度非线性：关节空间中的一条直线路径（各关节线性同步变化）映射到操作空间一般是曲线；反之，操作空间中的直线轨迹在关节空间中也不再是直线。

选择规划空间时必须权衡两者的物理与计算局限：

1. **关节空间规划**：直接为各关节安排 $q_j(t)$，完全规避实时逆运动学开销，也不会在局部遭遇操作空间逆解奇异或冗余消解难题。若任务仅指定末端起终点或少数稀疏位姿而不限定中间几何曲线，优先选用关节空间（但关节空间中仍须检查全臂连杆的碰撞包络）；
2. **操作空间规划**：当作业必须严格遵循焊缝、涂胶路径等三维几何形状或绕开工作空间近旁障碍时，必须在操作空间中直接指定路径 $\boldsymbol p_e(t)$ 与 $R_e(t)$（同样不能因末端避障就默认连杆不碰撞）。但其主要工程困难有两项：
   - **奇异位形邻域**：在奇异点附近反解 $\dot{\boldsymbol q}=J^{-1}\boldsymbol v_e$ 会导致关节速度骤增甚至失控（[§3.5.2](../ch03/sec3-5.md#sec-3.5.2) 的 DLS 阻尼伪逆正源于此）；
   - **冗余自由度**：冗余臂的逆解有无穷多组，必须额外嵌入优化或零空间准则才能定解。

在本章讨论的**关节伺服闭环架构**下，规划执行遵循统一流水线：

$$\text{操作空间规划 } (\boldsymbol p_e(t), R_e(t)) \;\xrightarrow{\;\text{逆运动学}\;}\; \text{关节参考 } \boldsymbol q_d(t) \;\longrightarrow\; \text{关节伺服控制}.$$

---

### 易混对照：关节空间规划与操作空间规划

| 特征 | 关节空间规划 | 操作空间规划 |
|:--|:--|:--|
| 规划对象 | 关节角/位移矢量 $\boldsymbol q(t)$ | 末端位置 $\boldsymbol p_e(t)$ 与姿态 $R_e(t)$ |
| 避障 | 须把环境障碍映射到关节空间并校核全臂安全 | 可直观规划末端避障路径，但**仍须额外校核肘/连杆碰撞** |
| 奇异与冗余 | 不涉及逆运动学奇异与冗余歧义 | 奇异点邻域关节速度暴涨；冗余臂须附带选解准则 |
| 映射关系 | 正运动学 $\boldsymbol p_e=\boldsymbol f(\boldsymbol q)$ 非线性，关节直线不对应末端直线 | 须伴随逆运动学求解（计算开销大，制约采样率） |
| 最终执行 | 关节伺服直接跟踪 $\boldsymbol q_d(t)$ | 本章伺服架构下仍须经逆运动学转化为 $\boldsymbol q_d(t)$ |

> **自检练习**：某装配任务只要求末端从 A 点无障碍快速移到 B 点、不限制中途轨迹形状，应优先选哪种空间？若任务改为「末端沿桌面直线涂胶」，又该如何选？（提示：前者优先选关节空间并检全臂与硬件限制；后者须在操作空间指定直线，再经逆运动学检查奇异、关节限幅与连杆避障。）

::: sol 核对
点对点且不限定中间路径形状时，优先在关节空间规划（省去逆解并规避局部奇异），再检验关节极限与全臂碰撞；直线涂胶必须保证末端几何直线，先在操作空间规定路径，再经逆解检查奇异邻域、关节限幅与机械臂整体安全。
:::

## 4.1 小结与常见错误

- **本节问题**：路径描述几何形状，轨迹还指定时间；规划器按任务和机械手限制生成参考运动。
- **两个空间**：关节空间便于安排关节运动，操作空间便于描述末端路径；本章的关节伺服需要关节参考量。
- **规划器接口**：输入路径描述及约束，输出随时间变化的位置、速度和加速度参考值。
