# 10.1 移动机器人系统与建模问题

前面九章讨论的机械手固定在一张底座上，运动学和动力学都在关节空间与末端之间转；接续 [1.3 移动机器人：轮系与机动性](../ch01/sec1-3.md) 的底盘分类，本章面对一个底座本身会跑的机器人——必须重新定义状态量、约束和运动学模型，才能回答「给一组速度或转向指令，机器人在环境里怎么走」。

<a id="sec-10.1.1"></a>

## 10.1.1 移动机器人与机械臂的差别

工业机械臂或医疗手术机器人依靠固定基座和多级关节，改变的是末端执行器相对于底座的位姿。移动机器人则不固定在单一基座上，它是指**能在环境中自主改变自身位置/姿态的机器人**，定义包含三个关键要素：

::: def 定义 10.1.1 · 移动机器人三要素 {#def-10.1.1}
1. **在环境中**：运行在室内、厂房、仓库、道路、野外、太空或水下等大尺度空间，而非局限在固定基座的有限工作空间内。
2. **自主改变自身位置／姿态**：机器人的整体位置和朝向都会随时间变化。位置与朝向在数学上表达方式不同，工程上常合称**位姿（pose）**。
3. **机器人**：不是单纯依靠人手遥控的运动底盘，而必须包含完整的**感知、规划和控制系统**。
:::

从 [1.3](../ch01/sec1-3.md) 已经知道地面移动载体形态众多：既有双足、四足与轮腿复合平台，也有仓库 AGV、服务机器人、家用扫地机、自动驾驶车辆以及星球探测车。本编以**轮式移动机器人**为核心展开：在各类移动构形中，轮式结构简单、成本低、能耗低且可靠性高，最为常见；掌握轮式平台的位形描述与非完整约束分析框架后，同样的方法可直接推广到其他移动底盘。

沿逆时针走完一圈，每一步回答一个独立问题：

1. **传感与信息提取**：相机输出图像、LiDAR 输出点云、IMU 输出角速度与加速度、轮编码器输出轮转角增量（例如车辆驶入隧道失去卫星信号后，仍可依靠编码器与 IMU 里程计短时推算位置）。原始异构数据经特征提取得到车道线、障碍物与目标位置，回答**「我周围有什么」**。
2. **定位与建图**：更新环境地图并确定自身在地图中的位置，回答**「我在哪里、环境长什么样」**——不知自身位姿和地图，规划与避障便无从谈起。
3. **决策与运动规划**：根据任务目标和地图生成可行路径或轨迹，回答**「我要去哪、怎么去」**。
4. **轨迹执行与闭环纠偏**：地面摩擦、建模误差、传感噪声及执行偏差（例如下发走 $1\,\mathrm m$ 指令而实测走了 $1.1\,\mathrm m$）都会导致开环偏离，因此需要 **PID 或 MPC** 控制器实时修正并向电机、舵机发送指令。执行后机器人位置、时间与周围动态环境全部改变，传感器必须重新测量，闭环由此持续运转。

<a id="sec-10.1.3"></a>

## 10.1.3 建模问题与全章核心目标

既然规划模块要给出「车体走得出来」的轨迹，控制器要算出正确的电机指令，就必须先回答一个底层问题：**给定控制输入 $u$，机器人的位形 $q$ 如何随时间变化？**

$$\boxed{\ \dot q = f(q, u)\ }\tag{10.1-1}$$

围绕这一主方程，本章聚焦四个核心目标：
1. 确立移动机器人的位形空间与状态量定义；
2. 刻画轮式机器人受到的瞬时速度约束（不可积的**非完整约束**）；
3. 掌握三类典型轮式机器人运动学模型——**独轮车模型、差速驱动模型、两轮车模型**；
4. 掌握一阶无漂移运动学向**有漂移扩展及动力学模型**的推进方式。

## 10.1 小结与常见错误

**一句话主线**：移动机器人是不固定基座的感知–思考–行动闭环系统，底层建模的核心是建立控制输入到机器人位形变化率的微分关系 $\dot q = f(q,u)$。

1. **三关键词定义**：在环境中运行、自主改变自身位姿（位置 + 朝向）、包含完整感知–规划–控制系统。
2. **闭环的必要性**：传感噪声、执行器误差与环境变化决定了必须由 PID/MPC 等反馈控制器持续纠偏。
3. **建模的地位**：没有准确的速度约束与 $\dot q=f(q,u)$ 模型，规划器会生成诸如「令普通汽车横向平移」等物理上不可执行的轨迹。

| 概念／关系 | 物理含义 | 所属模块 | 易错点 |
|:--|:--|:--|:--|
| 位姿（pose） | 整体位置与朝向的合称 | 状态描述 | 位置与姿态数学空间不同，不能简单同维相加 |
| 轮编码器里程计 | 积分车轮转角估算短时位移 | 传感与定位 | 地面打滑或久无外部定位修正时会累积漂移 |
| $\dot q = f(q,u)$ | 输入 $u$ 到位形变化率 $\dot q$ 的映射 | 运动学／动力学建模 | 运动学里 $u$ 常取速度量，并非直接的电机力矩 |

::: think 常见错误清单 · 自查三条
1. **把移动机器人等同于「带轮子的机械结构」** → 忽略感知、定位与闭环控制 → 只能算遥控运动平台，不能在不确定环境中自主避障与纠偏。
2. **认为轨迹规划只要几何避障就够了** → 规划出横移折线 → 忽视轮地非完整速度约束，物理车体无法跟踪执行。
3. **混淆运动学输入与底层电机输入** → 把一阶模型中的 $(v,\omega)$ 直接当力矩指令发给电机 → 忽略底层速度伺服带宽与加速度/打滑限制。
:::
