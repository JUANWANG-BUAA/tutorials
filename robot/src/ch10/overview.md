# 第十章 · 移动机器人建模

前面九章讨论的机械手始终固定在一个机座上，位形空间就是关节空间。从本章起（接续 [1.3 移动机器人：轮系与机动性](../ch01/sec1-3.md) 与 [第九章视觉伺服](../ch09/overview.md)），基座不再固定——机器人必须在环境中自主改变整体的位置和朝向。本章交付移动机器人的平面位形描述、非完整约束判据（可积性与李括号/Chow 定理）、独轮车与两轮车运动学方程、链式标准形，以及向二阶动力学的扩展，为后续移动机器人的规划、控制与感知打下数学底座。

## 本章阅读路线

全章按一条因果链展开：

1. **先建坐标系与速度表达**（[§10.1](sec10-1.md)–[§10.2](sec10-2.md)）：定义平面位形 $q=(x,y,\theta)^{\mathrm T}$ 与车体速度 $v^B$，用 $R_B^W(\theta)$ 连接载体与世界两个参考系。
2. **再把物理接触写成速度约束**（[§10.3](sec10-3.md)–[§10.4](sec10-4.md)）：无侧滑条件给出 $A^T(q)\dot q=0$ 与零空间模型 $\dot q=G(q)u$；用积分因子、李括号与 Chow 定理判定「此刻不能横移，最终却能到达平面任意位姿」。
3. **最后落到典型底盘与后续接口**（[§10.5](sec10-5.md)–[§10.6](sec10-6.md)）：依次完成独轮车、差速小车、两轮车的方程与秩检验，给出理论轨迹构造的链式形式，并把一阶速度输入扩展到含非完整约束的动力学模型。
