# 10.3 非完整约束与可积性判据

在 [§10.2](sec10-2.md) 中我们得到了车体速度与世界系速度之间的变换式 (10.2-3)。然而对于普通轮式小车，$v_x^B,v_y^B$ 并不是彼此自由的——车轮与地面滚动接触且不发生侧滑，迫使车体沿车轴侧向的瞬时速度恒为零。本节把这一物理事实写成数学方程，区分限制位置的「完整约束」与限制速度的「非完整约束」，并通过积分因子检验与零空间分解得到无漂移运动学模型 $\dot q = G(q)u$。

<a id="sec-10.3.1"></a>

## 10.3.1 直观理解：从「不能横着走」到非完整约束

将式 (10.2-3) 求逆（正交阵 $R_B^W(\theta)^{-1} = R_W^B(\theta) = R_B^W(\theta)^{\mathrm T}$），把世界系线速度投影回载体坐标系 $B$：

$$v_b^b = R_w^b(\theta)\,v_b^w = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix} \begin{bmatrix} \dot x \\ \dot y \end{bmatrix} = \begin{bmatrix} \dot x\cos\theta + \dot y\sin\theta \\ -\dot x\sin\theta + \dot y\cos\theta \end{bmatrix}.$$

理想无侧滑条件下，载体在 $y_B$ 轴方向的速度恒为零（$v_y^B = 0$），令第二分量为零即得核心约束方程：

$$\boxed{\ \dot x\sin\theta - \dot y\cos\theta = 0\ }\tag{10.3-1}$$

对照矩阵写法 $A^{\mathrm T}(q)\dot q = 0$，其中 $A^{\mathrm T}(q) = [\sin\theta,\ -\cos\theta,\ 0]$（若状态包含转向角 $\phi$ 则末位再补 $0$）。

日常「侧方停车」直接展示了它的物理内涵：这条方程限制的是**此刻允许朝哪个速度方向动**（不能瞬时横移），却**没有限制机器人最终能不能停到侧面的车位里**——它只限制了瞬时速度而不是位置流形本身，故称**非完整约束**。物理系统中非完整约束主要有两大来源：
1. **滚动无侧滑**：轮式机器人、滚动球或灵巧手指与刚体物体的纯滚动接触；
2. **角动量守恒**：自由飘浮的卫星／空间机器人、空中翻腾或腾空运动姿态调节。

<a id="sec-10.3.2"></a>

## 10.3.2 完整约束与 Pfaffian 运动学约束

先把「限制位置」和「限制速度」两类约束严格区分定义：

::: def 定义 10.3.1 · 完整约束（holonomic constraint） {#def-10.3.1}
若约束可直接写成关于位形变量 $q$ 的光滑独立等式：
$$h_i(q) = h_i(q_1,\dots,q_n) = 0, \qquad i = 1,\dots,k < n,$$
则称其为**完整约束**。每增加一个独立完整约束，系统的可达位形流形就降低 1 维，整体从 $n$ 维降至 $n-k$ 维子空间。
:::

以下两类物理系统属于典型的完整约束：
- **平面摆杆**：质量块 $m$ 固连在长度为 $\ell$ 的轻杆末端，约束 $x^2+y^2-\ell^2=0$ 将其位置永久锁在平面内半径为 $\ell$ 的一维圆周上，自由度从 $2$ 降至 $1$；
- **机械臂**：$n$ 个刚体连杆原本各自有 $6$ 个自由度（共 $6n$），由于相邻连杆在关节处必须重合的完整约束，总自由度从 $6n$ 降为 $n$，才得以简化为关节空间。

::: def 定义 10.3.2 · 运动学约束与 Pfaffian 约束 {#def-10.3.2}
同时涉及广义坐标和广义速度的约束 $a_i(q,\dot q)=0\ (i=1,\dots,k<n)$ 称为**运动学方程（约束）**。对速度呈线性齐次的常见形式称为 **Pfaffian 约束（Pfaffian constraint）**：
$$a_i^{\mathrm T}(q)\dot q = 0\quad (i=1,\dots,k<n) \qquad\text{或矩阵形式}\qquad A^{\mathrm T}(q)\dot q = 0,\tag{10.3-2}$$
其中 $a_i:\mathcal Q\mapsto\mathbb R^n$ 光滑且线性独立。
:::

完整约束与运动学约束之间有一条不对称关系：对任意完整约束 $h_i(q)=0$ 两端关于时间求导，总能得到一个对应的 Pfaffian 约束
$$\frac{\mathrm d h_i(q)}{\mathrm dt} = \frac{\partial h_i(q)}{\partial q}\dot q = 0;$$
但**反过来未必成立**。若一个 Pfaffian 约束**无法积分**还原成某个仅含位形的方程 $h(q)=0$，它就是**非完整约束（nonholonomic constraint）**——尽管瞬时速度被限在 $n-k$ 维子空间，位姿却依然能走遍整个 $n$ 维状态空间。

> **例：平面滚动圆盘**。一枚硬币（圆盘）直立在水平面上滚动，接触点位置 $(x,y)$ 与轮面朝向 $\theta$ 构成位形 $q=(x,y,\theta)^{\mathrm T}$。理想无侧滑给出约束 $[\sin\theta,\ -\cos\theta,\ 0]\dot q = 0$。直观上圆盘靠「前进与转向交替」可以侧移到平面任意 $(x,y,\theta)$，下文可严格证明此 Pfaffian 约束不可积，是非完整的。

<a id="sec-10.3.3"></a>

## 10.3.3 可积性条件：速度约束何时能积成位置约束？

直觉需要证明。对于单一 Pfaffian 约束 $a^T(q)\dot q = \sum_{j=1}^n a_j(q)\dot q_j = 0$，这里 $\dot q$ 是位形空间 $\mathcal Q$ 在点 $q$ 处**切空间** $T_q(\mathcal Q)$ 中的速度向量，而 $a^T(q)$ 是**余切空间** $T_q^*(\mathcal Q)$ 上的协向量（covector）。注意 $a^T(q)\dot q = 0$ 与 $2\,a^T(q)\dot q = 0$ 定义完全相同的零空间，协向量只差一个非零标量倍数。因此，若它等价于某个光滑函数 $h(q)$ 的微分 $\sum \frac{\partial h}{\partial q_j}\dot q_j = 0$，必存在非零标量函数 $\gamma(q)$（**积分因子**）使 $\gamma(q)a_j(q) = \frac{\partial h}{\partial q_j}(q)$。利用光滑函数二阶混合偏导交换相等的性质，立刻得到单约束可积性的充要条件：

::: thm 定理 10.3.3 · 单一 Pfaffian 约束可积性判据 {#thm-10.3.1}
单一光滑 Pfaffian 约束 $a^T(q)\dot q = 0$ 是完整（可积）的，当且仅当存在非零光滑积分因子 $\gamma(q)\neq 0$，使得对所有分量下标 $i,j\in\{1,\dots,n\}$ 满足混合偏导对称条件：
$$\frac{\partial(\gamma a_i)}{\partial q_j} = \frac{\partial(\gamma a_j)}{\partial q_i},\qquad \forall i,j.\tag{10.3-3}$$
否则称为不可积的（nonintegrable）／非完整的（nonholonomic）。
:::

::: ex 例 10.3.4 · 证明平面滚动圆盘约束不可积 {#ex-10.3.1}
对 $q=(x,y,\theta)^{\mathrm T}$ 与 $a=(\sin\theta,\ -\cos\theta,\ 0)^{\mathrm T}$，逐对代入式 (10.3-3) 的 $(i,j)=(1,2),(2,3),(1,3)$：
$$\begin{aligned}
\sin\theta\,\frac{\partial\gamma}{\partial y} &= -\cos\theta\,\frac{\partial\gamma}{\partial x}, &(1)\\
\cos\theta\,\frac{\partial\gamma}{\partial\theta} &= \gamma\sin\theta, &(2)\\
\sin\theta\,\frac{\partial\gamma}{\partial\theta} &= -\gamma\cos\theta. &(3)
\end{aligned}$$
将 (2)、(3) 两端平方后相加，利用 $\sin^2\theta+\cos^2\theta=1$ 得 $\left(\frac{\partial\gamma}{\partial\theta}\right)^2 = \gamma^2 \implies \frac{\partial\gamma}{\partial\theta} = \pm\gamma$。若取 $\frac{\partial\gamma}{\partial\theta}=\gamma$ 代回 (2)(3)，则有 $\gamma\cos\theta=\gamma\sin\theta$ 且 $\gamma\sin\theta=-\gamma\cos\theta$，消去知唯一解为 $\gamma\equiv 0$；取 $-\gamma$ 同理得 $\gamma\equiv 0$。故不存在非零积分因子 $\gamma(q)$，该约束确为非完整约束。
:::

然而，一旦系统有**多条** Pfaffian 约束（$A^T(q)\dot q=0$，其中 $A^T$ 为 $k\times n$ 矩阵），逐条套用 [@thm-10.3.1] 会落入陷阱：

::: ex 例 10.3.5 · 单条均不可积，整体却完整的双约束反例 {#ex-10.3.2}
考虑三维位形空间中带有两条 Pfaffian 约束的系统：
$$a_1^T(q)\dot q = \dot q_2 - q_3\dot q_1 = 0,\qquad a_2^T(q)\dot q = \dot q_3 - q_1\dot q_2 = 0.$$
按 (10.3-3) 分别检验可知，无论是 $a_1$ 还是 $a_2$，单独看都不是完整的（留作自检练习）。但将两者作线性组合 $q_1 a_1 + a_2$ 后消去 $\dot q_2$：
$$(q_1 a_1 + a_2)^T\dot q = \dot q_3 - q_1 q_3 \dot q_1 = 0 \implies \frac{\mathrm dq_3}{q_3} = q_1\,\mathrm dq_1 \implies q_3 = k e^{q_1^2/2},\quad q_2 = \int k e^{q_1^2/2}\,\mathrm dq_1.$$
两条单独不可积的约束竟能凑出完整的位形积分！这说明多约束情况下硬凑积分极为困难，必须转向一套不依赖求积分的新语言。
:::

## 10.3.4 从零空间构造无漂移运动学模型 $\dot q = G(q)u$

换个思路：既然直接把「不允许的速度方向」积分成 $h(q)$ 太难，不如直接问**「允许的速度方向长什么样」**。

设 $n$ 维系统受 $k$ 条线性独立的 Pfaffian 约束 $A^T(q)\dot q = 0$，其中 $A^T(q)\in\mathbb R^{k\times n}$ 满秩（$\operatorname{rank}A^T=k$）。那么线性方程组 $A^T(q)\dot q=0$ 的**零空间**维度为 $m = n - k$。选取该零空间的一组光滑基向量 $\{g_1(q),\dots,g_m(q)\}$（即满足 $A^T(q)g_j(q) = 0$），则一切满足约束的可行速度 $\dot q$ 都能写成它们的线性组合：

$$\boxed{\ \dot q = g_1(q)u_1 + \dots + g_m(q)u_m = \sum_{j=1}^m g_j(q)u_j = G(q)u\ }\tag{10.3-4}$$

其中 $q\in\mathbb R^n$ 为状态（位形）向量，$u=[u_1,\dots,u_m]^{\mathrm T}\in\mathbb R^m$ 为运动学输入向量（如轮速或线速度/角速度，而不是电机的力或力矩；且零空间基 $\{g_j\}$ 选法不唯一，对应输入 $u$ 的物理意义随之改变）。

当输入 $u=0$ 时必有 $\dot q=0$——不踩油门车就停住，这类系统称为**无漂移系统（driftless system）**。这与高速漂移车辆、航天器或导弹不同：后者受惯性主导，输入为零时状态仍会继续演化（属于含漂移的动力学系统，将在 [§10.6](sec10-6.md) 扩展）。

本步转换的核心可以归结为两条对偶视角：
1. **$A^{\mathrm T}(q)\dot q = 0$**：刻画**哪些速度方向不被允许**；
2. **$\dot q = G(q)u$**：刻画**所有允许的速度方向如何由输入生成**。

## 10.3 小结与常见错误

**一句话主线**：轮式机器人的无侧滑条件是限制瞬时速度的 Pfaffian 约束 $A^{\mathrm T}(q)\dot q=0$；对 $A^{\mathrm T}$ 的零空间取基即得无漂移运动学模型 $\dot q=G(q)u$，它把「排除禁行方向」翻译成「由输入生成可行方向」。

1. **完整 vs 非完整**：完整约束 $h(q)=0$ 降维位形流形；非完整约束只限制切空间中的速度方向，不能积分成 $h(q)=0$。
2. **单约束与多约束**：单一 Pfaffian 约束可用积分因子混合偏导判据检查可积性；多约束时单条不可积不保证整体不可积。
3. **无漂移含义**：$u=0\implies \dot q=0$，符合低速无侧滑轮式运动学特征。

| 公式 | 条件与假设 | 单位／量纲 | 易错点 |
|:--|:--|:--|:--|
| $\dot x\sin\theta - \dot y\cos\theta = 0$ | 轮地理想无侧滑，$y_B$ 朝左 | $\mathrm{m/s}$ | 写成 $\dot x\cos\theta+\dot y\sin\theta=0$（误把前向速度设成 0） |
| $\frac{\partial(\gamma a_i)}{\partial q_j}=\frac{\partial(\gamma a_j)}{\partial q_i}$ | 单一光滑 Pfaffian 约束；$\gamma(q)\neq 0$ | — | 忘记引入积分因子 $\gamma(q)$ 而直接检验 $\partial a_i/\partial q_j$ |
| $\dot q = G(q)u$ | $\operatorname{rank}A^{\mathrm T}(q)=k$，列向量 $g_j$ 为 $A^{\mathrm T}$ 零空间基 | 状态导数单位 | 误以为 $u$ 的选法或 $G(q)$ 唯一，或把 $u$ 当作力矩 |

::: think 常见错误清单 · 自查三条
1. **检验单条 Pfaffian 约束可积性时漏掉积分因子 $\gamma(q)$** → 把可积约束（如带非零积分因子的精确微分倍数）误判成非完整 → 务必对 $\gamma(q)a(q)$ 求混合偏导并检验是否存在非零 $\gamma$。
2. **在多约束系统中看到每条 $a_i^{\mathrm T}\dot q=0$ 都不可积，就断定系统是非完整的** → 忽略线性组合可消去交叉项形成可积约束（[@ex-10.3.2]） → 多约束判定必须转向下一节的对合闭包与 Frobenius 定理。
3. **误认为 $A^{\mathrm T}(q)\dot q=0$ 把系统限制在 $n-k$ 维子流形上** → 混淆切空间降维与位形空间降维 → 速度被限在 $n-k$ 维切子空间内，位姿仍可能到达全部 $n$ 维状态空间。
:::
