# 10.6 链式系统与动力学模型扩展

上一节 [§10.5](sec10-5.md) 证明了独轮车与两轮车都是全局可控的——存在连接任意两个位姿的可行控制输入。接下来的问题是：**这条满足非完整约束的可行轨迹具体怎么构造？** 以及**当考虑真实机器人的电机驱动力矩与惯性时，怎么把一阶速度模型升级为动力学模型？**

<a id="sec-10.6.1"></a>

## 10.6.1 $(2,n)$-链式系统标准形式

在原始坐标 $q=(x,y,\theta,\phi)^{\mathrm T}$ 中，三角函数 $\sin\theta,\cos\theta,\tan\phi$ 与状态量高度耦合，直接求解两点边值轨迹很不直观。对于两输入、$n$ 状态的无漂移系统，如果状态维数 $n \le 4$，常可通过光滑状态变换 $z = T(q)$ 和输入变换 $v = \beta(q)u$（一般不唯一，可基于嵌套分布与李导数 $L_{g_i}h_j$ 构造），将其化为**$(2,n)$-链式模型（chained form）** $\dot z = \gamma_1(z)v_1 + \gamma_2(z)v_2$：

$$\boxed{\ \dot z_1 = v_1,\qquad \dot z_2 = v_2,\qquad \dot z_3 = z_2 v_1,\qquad \dots,\qquad \dot z_n = z_{n-1} v_1\ }\tag{10.6-1}$$

其中 $\gamma_1 = [1,\ 0,\ z_2,\ z_3,\ \dots,\ z_{n-1}]^{\mathrm T}$、$\gamma_2 = [0,\ 1,\ 0,\ \dots,\ 0]^{\mathrm T}$。对 $\gamma_1,\gamma_2$ 反复取伴随李括号 $\operatorname{ad}_{\gamma_1}^k\gamma_2 = [\gamma_1,\ \operatorname{ad}_{\gamma_1}^{k-1}\gamma_2]$，第 $k+2$ 个分量恰好为 $(-1)^k$、其余全为 0，故 $\Delta_A = \operatorname{span}\{\gamma_1,\gamma_2,\operatorname{ad}_{\gamma_1}\gamma_2,\dots,\operatorname{ad}_{\gamma_1}^{n-2}\gamma_2\}$ 恒满足 $\dim\bar\Delta = n$——链式标准形天生可控且结构一目了然。

<a id="sec-10.6.2"></a>

## 10.6.2 独轮车、两轮车链式变换与控制策略

1. **独轮车 $(2,3)$-链式模型**：
   取坐标变换与输入变换：
   $$\begin{cases} z_1 = \theta & \text{（旋转，基变量）} \\ z_2 = x\cos\theta + y\sin\theta & \text{（前向，基变量）} \\ z_3 = x\sin\theta - y\cos\theta & \text{（侧向，纤维变量）} \end{cases},\qquad
   \begin{cases} \omega = v_1 \\ v = v_2 + z_3 v_1 \end{cases}.\tag{10.6-2}$$
   求导即可直接验证 $\dot z_1 = v_1,\ \dot z_2 = v_2,\ \dot z_3 = z_2 v_1$。把 $\dot z_3$ 积分得：
   $$z_3(T) - z_3(0) = \int_0^T z_2(t)v_1(t)\,\mathrm dt,$$
   这就把非完整性直观地展露出来：**基变量** $(z_1,z_2)$ 可由 $(v_1,v_2)$ 直接控制，而侧向**纤维变量** $z_3$ 必须借助基变量周期变化积累积分面积来间接改变。
2. **两轮车 $(2,4)$-链式模型**：
   取坐标变换（$\cos\theta\neq 0$）：
   $$z_1 = x,\qquad z_2 = \frac{1}{l}\sec^3\theta\tan\phi\quad\text{（基变量）};\qquad z_3 = \tan\theta,\qquad z_4 = y\quad\text{（纤维变量）}.\tag{10.6-3}$$
   配套输入变换使 $\dot z_1=v_1,\ \dot z_2=v_2,\ \dot z_3=z_2 v_1,\ \dot z_4=z_3 v_1$：
   $$v = \frac{v_1}{\cos\theta},\qquad \dot\phi = -\frac{3}{l}v_1\sec\theta\tan\theta\sin^2\phi + l v_2\cos^3\theta\cos^2\phi.\tag{10.6-4}$$
   式 (10.6-4) 由对 $z_2$ 求导并代入 $\dot\theta = \frac{v}{l}\tan\phi$ 严格推导得到（与参考讲义部分印刷版笔误对照见[勘误](errata.md)）。

3. **两步可行轨迹构造策略与工程定位**：
   - 第一步：用 $v_1, v_2$ 先将基变量 $z_1, z_2$ 调至目标值（纤维变量暂跑到某个中间状态 $z_k(t_1)$）；
   - 第二步：对每个纤维变量 $z_3\sim z_n$ 逐个施加周期 $T$ 的振荡控制输入（例如正弦波组合），利用积分项使其在周期末净增期望变化，而其余变量在一个周期内的净变化为零。
   - **理论与工程边界**：链式系统长于从理论上构造可行轨迹、证明系统可控性；由于坐标变换繁琐、局部存在奇异角（如 $\theta = \pm\pi/2$）且真实车辆带有速度与转角硬限幅，实际工程轨迹规划更常使用微分平坦（differential flatness）、几何曲线拼接（如圆弧+直线/样条）或 MPC。

<a id="sec-10.6.3"></a>

## 10.6.3 动力学模型扩展：二阶有漂移模型与带约束 Euler-Lagrange 方程

一阶运动学模型默认给定速度指令 $(v,\omega)$ 后车体瞬时响应；但在真实机器人上，底层施加的是**轮电机驱动力或力矩**，速度不能突变，高速急转弯还会发生轮胎打滑或复杂路面跟踪失稳。向动力学推进主要有两条模型扩展路径：

1. **工程直白扩展——二阶运动学（有漂移系统）**：
   把原来的速度输入 $u$ 提升为扩展状态量 $[q^{\mathrm T}, u^{\mathrm T}]^{\mathrm T}$，令速度变化率（加速度指令）$v = \dot u$ 作为新的控制输入：
   $$\begin{bmatrix} \dot q \\ \dot u \end{bmatrix} = \begin{bmatrix} G(q)u \\ 0 \end{bmatrix} + \begin{bmatrix} 0 \\ I \end{bmatrix} v.\tag{10.6-5}$$
   当新输入 $v=0$ 时，只要原有速度 $u\neq 0$，位形 $q$ 仍会继续漂移前进（好比刹车未踩死时车辆仍靠惯性滑行），因此该系统已变为**有漂移系统**。

2. **力学严格建模——带非完整约束的 Euler-Lagrange 方程**：
   接续 [第六章拉格朗日动力学](../ch06/sec6-1.md)，先对广义坐标 $q\in\mathbb R^n$ 定义拉格朗日函数 $L(q,\dot q)=T(q,\dot q)-U(q)$，当动能为 $T=\frac{1}{2}\dot q^{\mathrm T}M(q)\dot q$ 时，无约束的 Euler-Lagrange 方程为：
   $$M(q)\ddot q + C(q,\dot q)\dot q + g(q) = Q,$$
   其中 $M(q)$ 为惯性矩阵，$C(q,\dot q)\dot q$ 为科氏／离心力项，$g(q)$ 为势能梯度项，$Q$ 为广义外力。

   现在把 $k$ 条理想无摩擦的 Pfaffian 速度约束记作 $A(q)\dot q = 0$（此处采用 $A\in\mathbb R^{k\times n}$，与前文 $A^{\mathrm T}\dot q=0$ 写法差一个转置）。由于**静摩擦只阻止侧向滑移而不做功**，对应的广义约束反力沿被限制速度方向的法向作用，可借助**拉格朗日乘子** $\lambda\in\mathbb R^k$ 写成 $Q_c = A^{\mathrm T}(q)\lambda$；再把执行器力矩 $\tau\in\mathbb R^m$ 经映射矩阵 $B(q)$ 变为广义驱动力 $Q_a = B(q)\tau$，总广义力 $Q = Q_a + Q_c$ 代回得完整**非完整移动机器人动力学方程**：

   $$\boxed{\ M(q)\ddot q + C(q,\dot q)\dot q + g(q) = A^{\mathrm T}(q)\lambda + B(q)\tau, \qquad A(q)\dot q = 0\ }\tag{10.6-6}$$

   将未知约束乘子 $\lambda$ 消去（例如左乘零空间矩阵 $G^{\mathrm T}(q)$，利用 $G^{\mathrm T}A^{\mathrm T} = O$）即可化为面向力矩控制的降维动力学模型，作为后续规划与控制模块的输入。

## 10.6 小结与常见错误

**一句话主线**：$(2,n)$-链式系统把耦合的三角函数运动学化成级联形式以从理论上构造可行轨迹，而动力学扩展则通过提升速度为状态或引入拉格朗日乘子反力把控制输入推进到加速度与电机力矩层面。

1. **基变量与纤维变量**：$(z_1,z_2)$ 直接由 $(v_1,v_2)$ 控制；纤维变量 $z_3\sim z_n$ 依赖基变量振荡配合的积分效果改变。
2. **理论 vs 工程**：链式系统长于证明可控性与构造性轨迹；实际机器人轨迹规划优先用微分平坦、几何曲线拼接或 MPC。
3. **非完整动力学要点**：约束力 $A^{\mathrm T}(q)\lambda$ 体现了阻止侧滑的静摩擦力，不消耗机械功，是动力学校对不可或缺的一项。

| 公式 | 条件与假设 | 单位／量纲 | 易错点 |
|:--|:--|:--|:--|
| $\dot z_1=v_1,\ \dot z_2=v_2,\ \dot z_k=z_{k-1}v_1$ | 两输入无漂移系统（常用 $n\le 4$），$\cos\theta\neq 0$ | 变换坐标单位 | 把坐标变换 $z=T(q)$ 当作全局无奇异（两轮车变换在 $\theta=\pm\pi/2$ 奇异） |
| $\begin{bmatrix}\dot q\\\dot u\end{bmatrix}=\begin{bmatrix}G(q)u\\0\end{bmatrix}+\begin{bmatrix}0\\I\end{bmatrix}v$ | 二阶扩展，$v=\dot u$ 为加速度输入 | 状态/导数单位 | 误以为仍是无漂移系统（$v=0$ 时 $q$ 仍会运动） |
| $M\ddot q+C\dot q+g=A^{\mathrm T}\lambda+B\tau,\ A\dot q=0$ | 理想无摩擦滚动约束，$A\in\mathbb R^{k\times n}$ | 广义力 $\mathrm N$ 或 $\mathrm{N\cdot m}$ | 漏写约束反力项 $A^{\mathrm T}(q)\lambda$，或与前文 $A^{\mathrm T}\dot q=0$ 的转置记号混用 |

::: think 常见错误清单 · 自查三条
1. **在链式系统中直接强行给 $z_3$ 设期望反馈而不配合 $v_1$** → 当 $v_1=0$ 时 $\dot z_3=z_2 v_1=0$，纤维变量彻底锁死 → 必须让 $v_1$ 与 $z_2$ 交替同振才能积出 $z_3$ 的净增量。

3. **写移动机器人动力学时直接套机械臂无约束方程 $M\ddot q+C\dot q+g=B\tau$** → 丢掉侧向约束反力 $A^{\mathrm T}\lambda$ 和约束方程 $A\dot q=0$ → 仿真中车体会脱离无侧滑约束。
