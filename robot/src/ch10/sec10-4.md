# 10.4 李括号、对合性与可控性

上一节 [§10.3](sec10-3.md) 留下了两样东西：受约束后允许的瞬时速度模型 $\dot q = G(q)u$，以及「多条 Pfaffian 约束下硬求积分几乎做不到」的现实困难。本节不求积分，转而直接问：**把系统此刻能走的几个基本方向来回组合踩踏，能不能生成原本没有的新方向？** 这个问题引出李括号、对合闭包、Frobenius 定理和 Chow 定理，让我们只凭微分计算就能同时判定「约束是否完整」和「机器人是否能从任意位姿到达任意位姿」。

<a id="sec-10.4.1"></a>

## 10.4.1 分布与「踏板」直觉

给定无漂移运动学模型 $\dot q = \sum_{j=1}^m g_j(q)u_j$，在当前位形 $q$ 处，系统所有容许瞬时速度方向张成切空间 $T_q(\mathcal Q)$ 的一个子空间，称为**分布（distribution）**：

$$\Delta(q) = \operatorname{span}\{g_1(q),\dots,g_m(q)\} \subset T_q(\mathcal Q).\tag{10.4-1}$$

可以把每个基向量 $g_j(q)$ 看作脚下的一个**踏板**，把输入 $u_j$ 看作对应的**油门**。普通轮式小车只有「前后进退」和「原地转向」两个踏板，没有「直接横向平移」的踏板；但老司机做侧方停车时，靠「前进–转向–后退–回正」四个动作小幅度循环，车子竟然真的往侧向挪动了一小段——等于用原有踏板组合出了一只**虚拟的新踏板**。

## 10.4.2 李括号、对合性与非完整度

把上图这四步循环写成精确的微分运算，就得到**李括号（Lie Bracket）**：

::: def 定义 10.4.1 · 李括号 {#def-10.4.1}
给定 $\mathbb R^n$ 上两个光滑向量场 $g_1(q)$ 与 $g_2(q)$，它们的**李括号**定义为：
$$[g_1, g_2](q) = \frac{\partial g_2}{\partial q}g_1 - \frac{\partial g_1}{\partial q}g_2,\tag{10.4-2}$$
其中 $\frac{\partial g_i}{\partial q}$ 是 $n\times n$ 雅可比矩阵（第 $r$ 行第 $c$ 列为 $\partial g_{i,r}/\partial q_c$）。
:::

若把式 (10.4-2) 算出的新向量场放进分布里，看它到底有没有跳出原来的切子空间，就能定义**对合性**与**对合闭包**：

::: def 定义 10.4.2 · 对合性与对合闭包 {#def-10.4.2}
1. 若分布 $\Delta = \operatorname{span}\{g_1,\dots,g_m\}$ 中任意两个向量场 $g_i,g_j\in\Delta$ 的李括号仍然落回 $\Delta$ 内（即 $[g_i,g_j]\in\Delta$），则称分布 $\Delta$ 是**对合的（involutive）**。
2. 若 $\Delta$ 不对合，按如下递推构造逐层扩大的分布序列 $\{\Delta_i\}$：
   $$\Delta_1 = \Delta,\qquad \Delta_i = \Delta_{i-1} + [\Delta_1, \Delta_{i-1}],$$
   其中 $[\Delta_1,\Delta_{i-1}] = \operatorname{span}\{[g,\bar g]: g\in\Delta_1,\ \bar g\in\Delta_{i-1}\}$。使 $\operatorname{rank}(\Delta_{\kappa+1}) = \operatorname{rank}(\Delta_\kappa)$ 成立的最小整数 $\kappa$ 称为分布 $\Delta$ 的**非完整度（degree of nonholonomy）**；达到稳定时的最小对合分布 $\Delta_\kappa$ 记作 $\bar\Delta$，称为分布 $\Delta$ 的**对合闭包（involutive closure）**。
:::

从物理直觉上看，$\Delta_1$ 是原有的 $m$ 个踏板；每做一层李括号就检查有没有新踏板产生，有就加进集合直到再也造不出新踏板为止；新生成的独立方向总数为 $\dim\bar\Delta - m$，而所需迭代层数 $\kappa-1$ 越多，说明系统操纵越曲折、非完整性越强。按 $\kappa$ 与 $\dim\Delta_\kappa$ 可将全部无漂移系统分为三类：

::: def 定义 10.4.3 · 完整与非完整系统分类 {#def-10.4.3}
对满足 $k$ 个独立 Pfaffian 约束的 $n$ 维系统（$\dim\Delta = m = n-k$），其非完整度满足 $\kappa \in [1, n-m+1]$，且 $\operatorname{rank}(\Delta_\kappa)\in [m,n]$：
1. **完整的（holonomic）**：$\kappa = 1,\ \dim\Delta_\kappa = m$（李括号不产生任何新方向）；
2. **部分非完整的（partially nonholonomic）**：$1 < \kappa < n-m+1,\ m < \dim\Delta_\kappa < n$（可生成部分新方向，但仍被困在较低维子流形上）；
3. **完全非完整的（completely nonholonomic）**：$\kappa = n-m+1,\ \dim\Delta_\kappa = n$（经过组合运动终能张满全部 $n$ 维状态空间）。
:::

## 10.4.3 Frobenius 定理与 Chow 定理

前面两套语言——[§10.3](sec10-3.md) 的「能不能积分出 $h(q)=0$」与本节的「李括号下是不是封闭」——由著名的 **Frobenius 定理** 划上等号：

::: thm 定理 10.4.4 · Frobenius 定理 {#thm-10.4.1}
设分布 $\Delta(q)$ 光滑且维数恒定，则：
$$\text{分布 }\Delta\text{ 是对合的} \iff \text{分布 }\Delta\text{ 是可积的（即存在完整约束 }h(q)=0\text{）}.$$
:::

**几何意义**：若 $\Delta$ 对合且维数 $m < n$，说明系统运动只能停留在 $m$ 维子流形上；反之只要 $\Delta$ 不对合，就能够通过微小循环运动获得新方向，证明存在非完整约束——从此**不必硬算积分 $h(q)$**，只需对向量场求李括号即可。

进一步，工程上最关心的问题是：**小车能不能从任意初始位姿开到任意目标位姿？** 这对应控制论中的**可控性**（编号与原教材对比说明见[勘误](errata.md)）：

::: def 定义 10.4.5 · 无漂移系统的可控性（controllability） {#def-10.4.4}
对于无漂移系统 $\dot q = G(q)u$（假设 $\{g_1(q),\dots,g_m(q)\}$ 对所有 $q$ 光滑且线性独立），如果对任意初态 $q_0\in\mathbb R^n$ 和任意目标态 $q_1\in\mathbb R^n$，都存在有限时间 $T > 0$ 与这段时间内可调节的控制输入 $u(t)$，使得系统从 $q(0)=q_0$ 出发并在 $t=T$ 时到达 $q(T)=q_1$，则称该系统是**可控的（controllable）**。
:::

::: thm 定理 10.4.6 · Chow 定理与可控性秩条件 {#thm-10.4.2}
无漂移系统 $\dot q = G(q)u$ 是可控的，当且仅当对所有 $q\in\mathbb R^n$ 成立**可控性秩条件（controllability rank condition）**：
$$\operatorname{rank}\bigl(\bar\Delta(q)\bigr) = n,\tag{10.4-3}$$
其中对合闭包 $\bar\Delta$ 又称系统的**控制李代数（control Lie algebra）**。
:::

由 [@def-10.4.3] 与 [@thm-10.4.2] 立刻得出一条极其简洁的推论：**对于 $q\in\mathbb R^n, u\in\mathbb R^m$ 的无漂移系统，它是可控的 $\iff$ 它是完全非完整的**。分析系统的非完整性，正是为了在设计规划与控制律之前先判断「到底能不能控、有几层绕路才能控」。

::: note 可控性 vs 可达性
**可达性（reachability）**通常针对某一给定初态 $q_0$，问系统经过输入能到达哪些状态集合；而**可控性（controllability）**是全局性质，要求状态空间中**任意两个状态**之间都能用可行输入曲线连接起来。
:::

## 10.4 小结与常见错误

**一句话主线**：李括号量化了「四步循环组合踏板产生的新运动方向」；Frobenius 定理把可积性化归为对合性检验，Chow 定理则证明只要对合闭包满秩 $\operatorname{rank}(\bar\Delta)=n$（完全非完整），无漂移系统即全局可控。

1. **李括号记忆法**：$[g_1,g_2] = \frac{\partial g_2}{\partial q}g_1 - \frac{\partial g_1}{\partial q}g_2$，常向量场对 $q$ 偏导为零阵，先算可省一半力气。
2. **两座定理之桥**：Frobenius 定理管「完整性 ↔ 对合性」；Chow 定理管「全局可控性 ↔ $\operatorname{rank}(\bar\Delta)=n$」。
3. **非完整度 $\kappa$**：从 $m$ 维基方向扩到稳定所需的层数 $\kappa$ 越大，说明需要越高阶的往复转向动作才能把车「揉」进自由方向。

| 公式／判据 | 条件与假设 | 单位／量纲 | 易错点 |
|:--|:--|:--|:--|
| $[g_1,g_2] = \frac{\partial g_2}{\partial q}g_1 - \frac{\partial g_1}{\partial q}g_2$ | $g_1,g_2$ 光滑向量场 | 同 $\dot q$ 向量场 | 把 $\frac{\partial g_2}{\partial q}g_1$ 与 $\frac{\partial g_1}{\partial q}g_2$ 顺序写反导致符号反转（虽不影响张成子空间但容易算错后续交叉括号） |
| 对合 $\iff$ 可积（Frobenius） | 分布维数在邻域内常数且光滑 | — | 对合且 $m < n$ 时系统是**完整**的（被锁在低维流形），并非可控 |
| $\operatorname{rank}(\bar\Delta(q)) = n$（Chow） | 无漂移系统 $\dot q=G(q)u$ | 整数维数 $n$ | 算到第 1 层 $[g_1,g_2]$ 不够 $n$ 维就放弃——还需算 $[g_1,g_3]$ 等高阶括号 |

2. 分别用一句话说明 Frobenius 定理和 Chow 定理的结论。

::: sol 默写核对

2. Frobenius 定理：光滑等维分布是对合的当且仅当它是可积的；Chow 定理：无漂移系统可控当且仅当对所有 $q$ 其控制李代数对合闭包满秩 $\operatorname{rank}(\bar\Delta(q))=n$。
:::
:::

::: think 常见错误清单 · 自查三条
1. **把「完全非完整」误解成「不完整所以不可控」** → 恰恰相反：对无漂移系统，**完全非完整**意味着非完整约束只挡住瞬时方向而不降维位形空间，$\operatorname{rank}(\bar\Delta)=n$ 正保证了全局可控。
2. **求雅可比 $\frac{\partial g}{\partial q}$ 时把矩阵转置了** → 行与列搞混导致乘向量方向错误 → 第 $i$ 行第 $j$ 列始终是「第 $i$ 个分量对第 $j$ 个状态 $q_j$ 的偏导」。
3. **只算一阶李括号 $[g_i,g_j]$ 就下结论** → 对 $n=4, m=2$（如两轮车模型）一阶括号最多给出第 3 个方向，必须再算二阶括号 $[g_1,g_3]$ 才能判断是否张满 4 维。
:::
