# 10.5 典型轮式机器人运动学模型

有了 [§10.4](sec10-4.md) 的李括号和 Chow 定理，现在回到具体的地面小车。本节在几何直观和黑板逐行演算上完成三类核心轮式底盘的建模：**独轮车模型**（及其最重要的物理实现——**差速驱动小车**），以及分为后驱和前驱两种构型的**两轮车（自行车／汽车）模型**，并逐一验证它们「不能横移却全局可控」。

## 10.5.1 独轮车运动学模型与完整分析

独轮车（unicycle）是用单只理想垂直滚动轮抽象出来的平面运动模型：

- **位形（状态）向量**：取载体系原点 $O_B$ 在轮心，世界坐标系 $W$ 下位形为 $q = (x,y,\theta)^{\mathrm T}\in\mathbb R^3$（二维位置与车身航向角 $\theta$）；
- **控制输入**：取前向线速度 $v$ 与转向角速度 $\omega$，记 $u = (v,\omega)^{\mathrm T}\in\mathbb R^2$。

由式 (10.2-3) 令 $v_x^B = v,\ v_y^B = 0$，立即写出**独轮车运动学模型**：

$$\boxed{\ \begin{cases} \dot x = v\cos\theta \\ \dot y = v\sin\theta \\ \dot\theta = \omega \end{cases}
\quad\Longrightarrow\quad
\dot q = \begin{bmatrix} \cos\theta & 0 \\ \sin\theta & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} v \\ \omega \end{bmatrix} \equiv G(q)u\ }\tag{10.5-1}$$

下面按老师在 `01:33:16–01:48:29` 黑板上的完整手推步骤做完整性与可控性分析：

1. **写出分布 $\Delta_1$**：两个直接可行方向（踏板）为
   $$g_1(q) = \begin{bmatrix} \cos\theta \\ \sin\theta \\ 0 \end{bmatrix}, \qquad g_2(q) = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}.$$
   两者明显线性无关，$\dim\Delta_1 = 2 < n = 3$。
2. **计算李括号 $g_3 = [g_1, g_2]$**：套用式 (10.4-2)：
   $$[g_1, g_2] = \frac{\partial g_2}{\partial q}g_1 - \frac{\partial g_1}{\partial q}g_2.$$
   - 先算第一项：因为 $g_2 = [0,0,1]^{\mathrm T}$ 是常向量，不依赖 $x,y,\theta$，所以雅可比矩阵 $\frac{\partial g_2}{\partial q} = \mathbf 0_{3\times 3}$，第一项为零向量。
   - 再算第二项：$g_1$ 仅依赖 $\theta$（对 $x,y$ 偏导全为 0），逐行对 $(x,y,\theta)$ 求偏导得：
     $$\frac{\partial g_1}{\partial q} = \begin{bmatrix} 0 & 0 & -\sin\theta \\ 0 & 0 & \cos\theta \\ 0 & 0 & 0 \end{bmatrix} \implies \frac{\partial g_1}{\partial q}g_2 = \begin{bmatrix} 0 & 0 & -\sin\theta \\ 0 & 0 & \cos\theta \\ 0 & 0 & 0 \end{bmatrix}\begin{bmatrix}0\\0\\1\end{bmatrix} = \begin{bmatrix} -\sin\theta \\ \cos\theta \\ 0 \end{bmatrix}.$$
   - 相减即得：
     $$g_3(q) = [g_1, g_2] = \mathbf 0 - \begin{bmatrix} -\sin\theta \\ \cos\theta \\ 0 \end{bmatrix} = \begin{bmatrix} \sin\theta \\ -\cos\theta \\ 0 \end{bmatrix}.\tag{10.5-2}$$
3. **检验正交性与满秩**：计算内积得 $g_1^{\mathrm T}g_3 = 0,\ g_2^{\mathrm T}g_3 = 0$——新方向 $g_3$ 与 $g_1,g_2$ 两两正交，物理上恰好指向车体右侧（$-y_B$ 方向），且 $\det([g_1,g_2,g_3]) = -(-\cos^2\theta-\sin^2\theta) = +1 \neq 0$。于是对合闭包维数为
   $$\dim\bar\Delta = \dim\Delta_2 = \operatorname{dim}\operatorname{span}\{g_1,g_2,[g_1,g_2]\} = 3 = n.$$
   由 Frobenius 定理（[@thm-10.4.1]）与 Chow 定理（[@thm-10.4.2]）确认：**独轮车系统是完全非完整的，因而是全局可控的**。同时可验证 $A^T G = [\sin\theta,-\cos\theta,0]G = [0,0]$，与无侧滑 Pfaffian 约束 (10.3-1) 完全吻合。

## 10.5.2 差速驱动小车的等效模型

现实中极少见到真正只有一只轮子的移动机器人，老师在 `01:48:35–01:50:57` 强调：**独轮车模型是把具体驱动轮、万向脚轮或履带抽象掉之后的通用等效运动学模型**。

其中最典型的物理实现是**差速驱动小车（differential drive robot）**：左右两侧驱动轮共轴，轮半径均为 $r$、轮距为 $d$，各自以角速度 $\omega_R, \omega_L$ 绕轮轴向前滚动，载体原点 $O_B$ 取两驱动轮轴线中点。左、右轮接地点沿车体前向的线速度分别为 $v_L = r\omega_L$ 与 $v_R = r\omega_R$，绕后轴中点作刚体平面运动时，整车中心线速度 $v$ 与绕竖直轴角速度 $\omega$ 满足：

$$\boxed{\ v = \frac{r(\omega_R + \omega_L)}{2}, \qquad \omega = \frac{r(\omega_R - \omega_L)}{d}\ }\tag{10.5-3}$$

检验极限情况即可心算核对：当 $\omega_R=\omega_L$ 时 $\omega=0,\ v=r\omega_R$（直线前进）；当 $\omega_R=-\omega_L$ 时 $v=0,\ \omega=2r\omega_R/d$（绕 $O_B$ 原地左转）。将式 (10.5-3) 代入式 (10.5-1) 就得到差速小车从电机轮速到世界系位姿变化率的完整运动学模型。履带式小车与常见双轮差速 AGV 在**地面平坦、低速运行、无侧滑**三大假设下均可直接使用这套等效模型。

由于前轮转角 $\phi$ 会影响整车转弯方向，它必须进入状态向量：
$$q = (x, y, \theta, \phi)^{\mathrm T}\in\mathbb R^4, \qquad u = (v, \dot\phi)^{\mathrm T}\in\mathbb R^2.$$
在**后轮驱动**下，$v$ 是后轮前向线速度，$\dot\phi$ 是前轮转向角速度。因为原点就在后轴中点，且后轮无侧滑，直接有 $\dot x = v\cos\theta,\ \dot y = v\sin\theta$。至于角速度 $\dot\theta$：前后轮均无侧滑意味着两者瞬时速度垂直于各自轮轴，两垂线交于瞬时旋转中心（ICR），在由 ICR、后轮与前轮构成的直角三角形中，后轮转弯半径 $r$ 满足 $\tan\phi = l / r \implies r = l / \tan\phi$，于是 $\dot\theta = \omega = v/r = \frac{v}{l}\tan\phi$。写成矩阵形式：

$$\boxed{\ \dot q = \begin{bmatrix} \cos\theta & 0 \\ \sin\theta & 0 \\ \frac{1}{l}\tan\phi & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} v \\ \dot\phi \end{bmatrix} = g_1(q)v + g_2(q)\dot\phi\ }\tag{10.5-4}$$

下面做 4 维状态空间的非完整性与可控性分析（`01:58:23–02:01:52`）：
1. $g_1(q) = [\cos\theta,\ \sin\theta,\ \frac{1}{l}\tan\phi,\ 0]^{\mathrm T}$，$\ g_2(q) = [0,\ 0,\ 0,\ 1]^{\mathrm T}$。
2. 第一层李括号 $g_3 = [g_1, g_2]$：因为 $g_2$ 是常向量，$\frac{\partial g_2}{\partial q}=0$，只需算 $-\frac{\partial g_1}{\partial q}g_2$，也就是取 $g_1$ 对第 4 分量 $\phi$ 的偏导并加负号：
   $$g_3(q) = [g_1, g_2] = -\frac{\partial g_1}{\partial\phi} = \begin{bmatrix} 0 \\ 0 \\ -\dfrac{1}{l\cos^2\phi} \\ 0 \end{bmatrix}.\tag{10.5-5}$$
3. 此时仅有 3 个向量，尚不满 4 维；继续算第二层李括号 $g_4 = [g_1, g_3]$：注意到 $g_3$ 只含 $\phi$ 而不含 $x,y,\theta$，且 $g_1$ 第 4 分量为 0，故 $\frac{\partial g_3}{\partial q}g_1 = 0$；而 $g_1$ 只有前两项依赖 $\theta$（恰对应 $g_3$ 的第 3 分量非零），于是：
   $$g_4(q) = [g_1, g_3] = -\frac{\partial g_1}{\partial\theta}\left(-\frac{1}{l\cos^2\phi}\right) = \begin{bmatrix} -\dfrac{\sin\theta}{l\cos^2\phi} \\ \dfrac{\cos\theta}{l\cos^2\phi} \\ 0 \\ 0 \end{bmatrix}.\tag{10.5-6}$$
4. **用行列式而非正交性判别（`02:00:16–02:01:52`）**：$g_1$ 与 $g_3$ 均在 $\theta$ 分量非零、彼此并不正交，不能靠求内积为零来检验无关性，而应直接把四列拼成 $4\times 4$ 方阵求行列式：
   $$\det\bigl([g_1,\ g_2,\ g_3,\ g_4]\bigr) = \frac{1}{l^2\cos^4\phi} \neq 0\quad (\cos\phi\neq 0).$$
   四列向量线性无关，$\dim\bar\Delta = \dim\Delta_3 = 4 = n$。由 Chow 定理得出：**后轮驱动两轮车也是完全非完整的（非完整度 $\kappa=3$），因而是全局可控的**。

## 10.5.4 前轮驱动两轮车与后轮驱动对比

许多城市乘用车采用**前轮驱动**：输入 $u=(v,\dot\phi)^{\mathrm T}$ 中的 $v$ 改为**前轮滚动线速度**，但位形原点 $O_B=(x,y)$ 依然设在**后轴中点**。在车身坐标系下把前轮速度 $v$ 沿车身前后方向与横向正交分解：
- 后轴中心的前向速度不再是 $v$，而是投影分量 **$v\cos\phi$**；
- 前轮垂直于车身方向的速度分量为 $v\sin\phi$，绕后轴产生的转动角速度为 $\dot\theta = \frac{v}{l}\sin\phi$（等价于将后驱公式中的 $v_{\text{rear}}$ 换成 $v\cos\phi$：$\frac{v\cos\phi}{l}\tan\phi = \frac{v}{l}\sin\phi$）。

由此直接得到**前轮驱动两轮车运动学模型**：

$$\boxed{\ \dot q = \begin{bmatrix} \cos\phi\cos\theta & 0 \\ \cos\phi\sin\theta & 0 \\ \frac{1}{l}\sin\phi & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} v \\ \dot\phi \end{bmatrix}\ }\tag{10.5-7}$$

## 10.5 小结与常见错误

**一句话主线**：独轮车、差速小车与后驱/前驱两轮车均可写成无漂移模型 $\dot q=G(q)u$；尽管存在无侧滑速度约束，计算对合闭包均可验证其控制李代数满秩，均为完全非完整且可控的系统。

1. **独轮车是通用母型**：差速小车与履带车在平坦、低速、无侧滑假设下直接由 $(v,\omega)\leftrightarrow(\omega_R,\omega_L)$ 等效为独轮车。
2. **两轮车的转向状态**：前轮偏角 $\phi$ 必须作为第 4 个状态量，输入第二维是转向角速度 $\dot\phi$（而非车身角速度 $\omega$）。
3. **无关性检验要算行列式**：四个 $4\times 1$ 向量是否张满 4 维空间，判据是 $\det([g_1,g_2,g_3,g_4])\neq 0$，不要求彼此正交。

| 模型 | 状态与输入 | 核心公式 | 非完整度与秩 |
|:--|:--|:--|:--|
| 独轮车 | $q=(x,y,\theta),\ u=(v,\omega)$ | $\dot x=v\cos\theta,\ \dot y=v\sin\theta,\ \dot\theta=\omega$ | $\kappa=2,\ \dim\bar\Delta=3$ |
| 差速小车 | $u_{\mathrm{wheel}}=(\omega_R,\omega_L)$ | $v=\frac{r(\omega_R+\omega_L)}{2},\ \omega=\frac{r(\omega_R-\omega_L)}{d}$ | 等效为独轮车 |
| 后驱两轮车 | $q=(x,y,\theta,\phi),\ u=(v,\dot\phi)$ | $\dot x=v\cos\theta,\ \dot y=v\sin\theta,\ \dot\theta=\frac{v}{l}\tan\phi$ | $\kappa=3,\ \dim\bar\Delta=4$ |
| 前驱两轮车 | $q=(x,y,\theta,\phi),\ u=(v,\dot\phi)$ | $\dot x=v\cos\phi\cos\theta,\ \dot y=v\cos\phi\sin\theta,\ \dot\theta=\frac{v}{l}\sin\phi$ | 同上，$\phi=\pm\pi/2$ 后轴锁死 |

::: think 默写点 · 合上书再写
1. 写出差速驱动小车的 $v,\omega$ 与左右轮角速度 $\omega_R,\omega_L$ 的换算关系，并反解出给定 $(v,\omega)$ 时的左右轮目标角速度。
2. 写出后轮驱动两轮车的 $g_1, g_2$，并手推一阶李括号 $g_3=[g_1,g_2]$ 与二阶李括号 $g_4=[g_1,g_3]$。

::: sol 默写核对
1. $v=\frac{r(\omega_R+\omega_L)}{2},\ \omega=\frac{r(\omega_R-\omega_L)}{d}$；反解：$\omega_R = \frac{v + \frac{d}{2}\omega}{r},\ \omega_L = \frac{v - \frac{d}{2}\omega}{r}$。
2. $g_1=[\cos\theta,\sin\theta,\frac{1}{l}\tan\phi,0]^{\mathrm T},\ g_2=[0,0,0,1]^{\mathrm T}$；$g_3=-\frac{\partial g_1}{\partial\phi}=[0,0,-\frac{1}{l\cos^2\phi},0]^{\mathrm T}$；$g_4=-\frac{\partial g_1}{\partial\theta}(-\frac{1}{l\cos^2\phi})=[-\frac{\sin\theta}{l\cos^2\phi},\frac{\cos\theta}{l\cos^2\phi},0,0]^{\mathrm T}$。
:::
:::

::: think 常见错误清单 · 自查三条
1. **差速公式把 $\omega_R-\omega_L$ 的符号写反** → 右轮比左轮快时（右手系 $y_B$ 朝左、逆时针为正）本来应左转（$\omega>0$），写反成顺时针 → 用「右轮快 → 左转 → $\omega>0$」十秒验算正负号。
2. **前驱两轮车漏掉 $\cos\phi$ 投影因子，照搬 $\dot x=v\cos\theta$** → 误把前轮速度直接当成后轴中心速度 → 记住原点在后轴，前轮速度在车身方向投影只有 $v\cos\phi$。
3. **检验两轮车 $\{g_1,g_2,g_3,g_4\}$ 时误用「两两正交」判别线性无关** → 发现 $g_1^{\mathrm T}g_3\neq 0$ 就以为算错了 → 线性无关只要求矩阵满秩（$\det\neq 0$），不要求正交。
:::
