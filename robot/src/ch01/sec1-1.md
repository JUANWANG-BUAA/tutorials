# 1.1 机器人学：定义、历史与系统构成

本节回答三个问题：**「机器人」这个词从哪里来、科学定义是什么？一台机器人由哪些子系统构成？这门学科为什么是交叉学科？** 它同时是全章的总纲：1.2、1.3 讲「身体」（两类机械结构），1.4 讲「用武之地」，1.5 讲「方法论」——后面这些内容，全部挂靠在本节给出的系统构成框架上。

## 1.1.1 从神话到科幻：词源与三定律

人类「寻求自身替身」的冲动贯穿整部文化史。希腊神话里，普罗米修斯用粘土造人，赫费斯托斯铸造青铜巨人泰拉斯保卫克里特岛；到了工业时代，自动机器正是承接这一冲动，被赋予「代替人类从事低级劳动」的使命。而现代术语的诞生，则有明确的时间坐标：

- **1920 年**，捷克剧作家 Karel Čapek 在戏剧《罗素姆万能机器人》（*R. U. R.*）中杜撰 **robot** 一词，该词源于斯拉夫语中表示「强迫劳动」的 **robota**——剧中这些自动机器最终奋起反抗人类；
- **20 世纪 40 年代**，科幻作家阿西莫夫（Isaac Asimov）把机器人设想为由「正电子大脑」程序控制的自动机器，**剥离情感、服从伦理规则**，并首创「机器人学（Robotics）」一词。他据此提出的三条定律是：

::: note 阿西莫夫三定律（科幻设定，1940s）
**定律 1**　机器人不得伤害人类，也不能坐视人类受到伤害而无所作为。
**定律 2**　机器人必须服从人类的命令，但不得违背定律 1。
**定律 3**　机器人必须保护自己，但不得违背定律 1 和定律 2。
:::

三定律虽属科幻设定，却长期影响着公众对机器人安全与责任的想象。但有一点必须澄清：它**不是**任何工程安全标准的替代物。工程上可验证的安全性，来自风险评估、限力 / 限速、急停、联锁与故障处置等可测试机制——现行核心标准为 **ISO 10218**（工业机器人安全要求）与 **ISO/TS 15066**（协作机器人安全规范）：前者覆盖传统工业机器人的设计与集成安全，后者针对人机物理接触场景，补充了生物力学极限与功率 / 力阈值。另一边，科幻作品也让大众形成了「机器人长得像人、会说话行走」的预期；**本课程要建立的第一个习惯，就是把科幻形象、伦理讨论与工程定义分开**。

## 1.1.2 科学定义：感知与行为之间的智能联系

抛开外表、只看功能，机器人可以这样定义：

::: def 定义 1.1.1 · 机器人（工作定义） {#def-1.1.1}
**机器人**是一种能够影响其所处工作环境的机器，**无关其外表**。这种影响通过机器人内置的、根据一定规则设定的行为模式实现，而行为由机器人**感知其自身状态和环境**所获得的数据决定。等价的一句话：**机器人学研究的是感知与行为之间的智能联系**（the intelligent connection between perception and action）。
:::

::: intuition 定义的白话版
判断是不是机器人，看的是「闭环」而非「人形」。一台机器要同时满足三点：(i) **感知**（知道自己和环境的状态），(ii) **决策**（按规则产生行为），(iii) **作用于环境**（行为改变世界，而世界的变化又被感知到）。对照这三条：洗衣机定时器没有感知闭环，遥控玩具的决策在人手上，两者都不算机器人；数控机床加上传感反馈，闭环已经成立，也就具备了机器人的核心属性——事实上，工业机器人正是从数控机床与遥操纵装置发展而来（见 [1.4.1](sec1-4.md#sec-1.4.1)）。
:::

## 1.1.3 机器人系统的四个子系统

按定义 1.1.1，实际的**机器人系统**是复杂系统，其功能由四个子系统分工实现（原书图 1.1 画的是一台移动小车，上面装了两台机械手）：

| 子系统 | 功能 | 典型组成 |
|:--|:--|:--|
| **机械系统** | 身体：实现移动与操作 | 运动装置（轮系、履带、机械腿）+ 操作装置（机械手、末端执行器、人工手） |
| **执行系统** | 肌肉：使机械组件运动 | 伺服电机、驱动器、传动装置——涉及运动控制的具体构成 |
| **传感系统** | 感官：获取内部状态与环境数据 | 本体传感器（如位置传感器）+ 外部传感器（如力传感器、照相机） |
| **控制系统** | 大脑：指挥动作执行 | 依据任务规划设定的目标，在机器人与环境约束下实现「感知 → 行为」的智能联系；实现服从与人体功能控制相同的**反馈原理** |

四条职责链，一句话概括：**机械系统**提供身体，**执行系统**提供力气，**传感系统**提供眼睛，**控制系统**则在感知与行为之间建立智能联系。原书特别指出：控制系统的实现，或许还需利用对机器人系统组成的描述——即**建模**；这正是 [1.5](sec1-5.md) 的起点，也是全书主线「建模、规划与控制」的入口。

把图 1.1 写成控制语言，就是先把目标与测量值相减得到误差，再由控制器给出作用量：

$$e(t)=r(t)-y(t),\qquad u(t)=C\bigl(e(t),\text{状态},\text{约束}\bigr).$$

这不是某一种固定的控制律，而是阅读全书的**变量账本**：$r$ 是任务要求，$y$ 是传感器看见的结果，$e$ 是两者差距，$u$ 是电机 / 执行器的命令。后续各章的区别，正是怎样建立 $y$ 的模型、怎样生成 $r$、怎样设计 $C$。

::: note 交叉学科
机器人学是**机械、控制、计算机、电子**四个领域的交叉。范围更广的「控制论（cybernetics）」一词，还涵盖运动监测、人工智能与专家系统、算法结构与编程环境。这对学习者意味着：本课程每一章都会同时用到力学语言（力 / 力矩 / 运动）和计算机语言（算法 / 数据流），偏向任何一侧，都会在中途卡住。
:::

## 1.1 小结与常见错误

- **一条主线**：文化冲动 → 科学定义（感知与行为的智能联系）→ 四子系统（机械 / 执行 / 传感 / 控制）→ 交叉学科。
- **两个分离**：科幻形象 ≠ 工程定义；三定律是科幻设定，工程安全必须落实为可验证的机制与标准。
- **一个钩子**：控制系统需要「对系统组成的描述」——建模，引出全书主线。

::: think 常见错误清单 · 自查四条
1. 把机器人想象成人形机器——定义 1.1.1 明确「无关其外表」；工业领域以臂状机械手为绝对主力（IFR 口径下拟人型一家即占约 59%，[1.2.2](sec1-2.md#sec-1.2.2)）；
2. 认为三定律是真实存在的法律或技术标准——它是 1940s 的科幻设定，但其精神被安全规范继承；
3. 把「自动化」等同于「机器人」——刚性自动化中的专用机器不含感知—行为闭环（对照 [1.4.1](sec1-4.md#sec-1.4.1) 的三层次）；
4. 以为控制系统只是「写程序」——控制服从反馈原理，与人体功能控制同构，这是第 6、8 章的物理基础。
:::
