# 1.1 机器人学：定义、历史与系统构成

机械臂要把夹爪送到指定位置，实际却停偏了。谁负责发现偏差，谁决定怎样纠正，谁提供运动所需的力？从这个问题出发，本节先说明“机器人”在教材中指什么，再把一次动作拆成机械、执行、传感、控制四个子系统的协作。

读完后，应能画出这四个子系统的联系，沿箭头解释一次纠偏过程，并说明为什么“有反馈”还不足以判定一台机器属于机器人。词源和科幻是背景，系统分工才是后续各章会反复用到的内容。

<a id="sec-1.1.1"></a>

## 1.1.1 从神话到科幻：词源与三定律

人类设想过许多能代替自己行动的造物。教材从普罗米修斯用粘土造人、赫费斯托斯铸造青铜巨人泰拉斯的神话讲起；工业时代的自动机器，则把“替人劳动”变成了工程任务。现代术语 **robot** 出现在 Karel Čapek 于 **1920 年写成的戏剧《罗素姆万能机器人》（R. U. R.）**中，与表示劳役的 **robota** 一词有关。这里的日期说的是剧作写作背景。

教材随后介绍阿西莫夫在 20 世纪 40 年代的科幻设想：机器人由“正电子大脑”控制，行为受伦理规则约束；他也引入了 **robotics（机器人学）**一词。三定律的要点如下：

::: note 阿西莫夫三定律（科幻设定，按教材转述）
1. 机器人不得伤害人类，也不能因不作为而让人类受到伤害。
2. 机器人必须服从人类的命令，但不能违背第一定律。
3. 机器人必须保护自身存在，但不能违背前两条定律。
:::

这些规则描述了科幻作品中的行为要求。工程上还必须回答：危险由什么测出，什么条件触发停止，停止需要多久，故障时由谁处置？限速、急停、联锁等机制需要明确的适用条件与验证方法。**背出三定律不能替代安全设计与验收。**本节不据此讲授具体设备的安全合规要求。

## 1.1.2 科学定义：感知与行为之间的智能联系

科幻形象容易让人把外形当成判断依据。教材关注的则是机器怎样利用信息采取行动：

::: def 定义 1.1.1 · 机器人（教材的工作定义） {#def-1.1.1}
机器人是一种能够改变其工作环境的机器，与外表无关。它按内置的行为规则行动，行动还受到它所获取的自身状态与环境数据的影响。

在这一框架下，**机器人学研究感知与行为之间的智能联系**（the intelligent connection between perception and action）。前一句描述机器，后一句概括学科的研究对象。
:::

这里的“智能联系”不要求机器像人一样思考，也不要求采用机器学习。按预设规则处理测量值、据此调整动作，同样属于本课程要研究的内容。“感知自身状态”可以只是测量关节位置，不意味着机器人必然装有相机。

::: intuition 怎样使用这个定义
先问三件事：**测到了什么，机器怎样使用这些数据，产生了什么物理动作？**如果动作的结果又被测量并用于后续调整，就形成了反馈闭环。

这个框架帮助我们分析系统，但**闭环不是机器人分类的充分条件**。例如恒温器也能根据温度启停设备。判断它属于哪一类设备，还需要说明使用的定义及分类目的，不能只凭“有传感器”下结论。
:::

同一设备可能同时含有人在回路中的操作和机器自动完成的局部控制。分析遥控装置时，应先划清范围：讨论的是人的决策、设备的自动调节，还是两者组成的整体？

| 已知条件 | 能得出的结论 | 仍不能直接推出的结论 |
|:--|:--|:--|
| 仅按时间表通断、没有状态测量的定时控制器 | 题设中的控制器没有利用测量反馈 | 所有洗衣机都没有传感器或反馈 |
| 人根据画面发出命令，设备执行命令 | 高层动作选择由人完成；局部是否自动调节还需查看设备 | 遥操作装置一律不属于机器人 |
| 数控机床具有位置反馈 | 它存在位置控制闭环 | 仅凭位置反馈就能认定它是工业机器人 |

工业机器人还有专门的分类口径。例如 [IFR 对 ISO 8373:2021 定义的说明](https://ifr.org/industrial-robots)同时要求自动控制、可重新编程、多用途机械手、三个或更多可编程轴等条件。它与本节工作定义的用途不同。读分类题时，应先写出采用哪一种口径，再判断题设信息是否足够。

## 1.1.3 机器人系统的四个子系统

回到开头的机械臂任务。下面按功能区分四个子系统；同一件产品的硬件封装未必恰好分成四块。

| 子系统 | 在本任务中负责什么 | 典型组成 |
|:--|:--|:--|
| **机械系统** | 通过连杆、关节和夹爪完成运动与操作 | 机械臂、末端执行器；移动机器人还包括轮系、履带或腿 |
| **执行系统** | 提供并传递运动所需的力或力矩 | 电机、驱动器、传动装置 |
| **传感系统** | 获取关节等内部状态，以及接触或环境信息 | 位置传感器等本体传感器；力传感器、相机等外部传感器 |
| **控制系统** | 结合任务目标、测量数据和约束，计算动作命令 | 反馈控制器，以及与任务规划连接的计算环节 |

读图时先沿上方箭头找出命令怎样变成运动，再沿下方箭头追踪运动结果怎样经传感器返回控制器。**执行系统负责产生和传递驱动力，机械系统决定这些力怎样带动机构运动。**

### 用同一种量比较目标与反馈

为免一次引入整台机械臂的变量，先只观察一个直线运动轴。规定正方向后，目标位置为 $r=0.50\ \mathrm m$，位置传感器读数为 $y=0.46\ \mathrm m$。本例定义误差为目标减测量值：

$$e=r-y=0.04\ \mathrm m.$$

误差为正，表示**测得的位置小于目标位置**。控制器据此计算命令 $u$，交给驱动器和电机，机构运动后再测量。$u$ 可以是力矩、电流或速度等接口中的命令，不能把位置误差 $0.04\ \mathrm m$ 直接当成电流值送给电机。

::: note 相减前先检查
目标与反馈必须描述同一个量，并使用相同单位与坐标约定。本例中的 $r$ 和 $y$ 都是同一轴上的位置。若一个是末端位置、另一个是关节角，就必须先建立两者的映射；第二章会讨论这类运动学关系。

这里用 $y$ 表示**测量值**。只有在测量足够准确时，才能把它近似看成真实位置；反馈本身不会保证传感器没有偏差。
:::

控制器往往还要结合速度、模型和约束，而不只看位置误差。模型描述机构怎样响应命令；规划给出期望运动；控制根据实际反馈纠偏。这三项工作将在 [1.5](sec1-5.md) 串成全书路线。

### 先预测，再核对：两种“停偏了”

下面是一项纸笔练习。两题分别从各自给定的初始条件开始，均假设驱动能够响应命令；只判断反馈中的信息，不需要设计控制律。

<details id="sec11-disturbance">
<summary>练习一：外力把轴推到 0.43 m，传感器准确。目标仍为 0.50 m，此时测得误差是多少？四个子系统怎样参与纠偏？先写再展开。</summary>

误差为 $0.50-0.43=0.07\ \mathrm m$。传感系统报告位置变化，控制系统依据误差和其他状态计算命令，执行系统产生驱动力，机械系统随之运动。新的位置继续被测量。本题只说明反馈能提供纠偏信息，尚不能据此保证任意控制器都能稳定到达目标。

</details>

<details id="sec11-bias">
<summary>练习二：真实位置为 0.46 m，传感器总是多报 0.04 m。控制器读到多少，算出的误差是多少？为什么它可能没有继续纠偏？</summary>

控制器读到 $y=0.46+0.04=0.50\ \mathrm m$，算得 $e=0$。真实位置仍比目标少 $0.04\ \mathrm m$，但位置误差信号没有反映这项偏差。仅凭这一路位置反馈，无法区分“真实到位”和“传感器偏了”；需要校准或其他信息。

</details>

两题分别改变了**真实运动状态**和**测量结果**。沿反馈路径定位变化发生在哪一步，比只记住“闭环会纠错”更有用。

::: note 为什么机器人学需要多门学科
教材把机器人学归为机械、控制、计算机、电子四个领域的交叉：机构与材料涉及机械；反馈与稳定性涉及控制；算法和程序涉及计算机；驱动、测量与信号处理涉及电子。教材还把运动控制与监督、人工智能、计算架构和编程环境放在控制论（cybernetics）的背景下讨论。这里是知识联系的说明，不是对这些学科划定包含关系。
:::

## 1.1 小结与闭卷自检

本节建立了一个分析方法：先明确采用的定义和系统范围，再沿“目标 → 控制 → 执行 → 机械运动 → 测量 → 控制”追踪动作。外形不能决定分类，存在反馈也不能独自决定分类。

合上正文，先回答，再核对：

1. 为什么“数控机床有位置反馈”还不足以判定它属于工业机器人？
2. 电机、连杆、编码器和反馈算法分别承担哪种功能？
3. 目标位置与关节角能直接相减吗？应先检查什么？
4. 测得误差为零，能否保证真实到位？用本节练习举例。

::: sol 核对与回读位置
1. 位置反馈只证明存在位置闭环，不能代替完整分类条件。回读 §1.1.2 的边界表。
2. 分别对应执行、机械、传感、控制；应能继续解释命令与测量怎样在它们之间传递。回读四子系统表和图。
3. 不能。须先统一所比较的物理量、单位与坐标约定；不同变量可能需要模型映射。回读“相减前先检查”。
4. 不能。练习二中测得误差为零，真实位置仍偏了 $0.04\ \mathrm m$。回读传感器偏差题。
:::
