# 习题集

原书第 1 章无习题，以下四组 21 题**全部自编**，按 A（概念判断）、B（分析论证）、C（计算与调研）、D（开放研讨）分层，**全部附解答或提示**（默认折叠）；C 组每题给验收标准。行业数据类题目回到[勘误与补注](errata.md)核对口径。

::: method A / B 组的自评标准（C / D 组另给验收标准）

- **A 组（概念判断）**：达标要求是「**判对 + 说得出依据**」。只写「是 / 否」不算过——每题必须能指出依据来自哪条定义或原理（本编的 A 组解答都标了出处，对着核）。
- **B 组（分析论证）**：按「**思路 → 关键步 → 结论**」三步自评。思路错则整题重做；思路对而关键步缺一环，记半过；结论与教材口径不符，回到对应小节重读。
- **通用扣分点**：用了未定义的记号、把「不能即时做某事」写成「不能做某事」、引用行业数据不带年份与机构。

:::

## A 组 · 概念判断

::: ex A1 · 定义三连

判断下列对象是否满足 [@def-1.1.1] 的机器人定义，并指出缺什么：
(a) 洗衣机定时控制器；(b) 遥控玩具汽车；(c) 带位置反馈闭环的数控机床；(d) Roomba 扫地机器人。

::: sol 解答

(a) 否——程序固定，无对环境的感知；(b) 否——决策（感知与行为的联系）在人手上，本体只有执行；(c) 基本满足——感知（位置反馈）+ 决策（数控程序）+ 作用于环境，历史上工业机器人正源于数控机床（[1.4.1](sec1-4.md#sec-1.4.1)）；(d) 是——差动驱动底盘 + 感知（跌落 / 碰撞 / 里程）+ 自主决策，原书将其作为服务机器人实例。

:::

::: ex A2 · 四子系统对号

「伺服电机与驱动器」「位置传感器」「轮系与机械手」「任务规划与反馈控制器」分别属于哪个子系统？各用一句话说明功能。

::: sol 解答

执行系统（使机械组件具有运动能力，涉及运动控制构成）；传感系统（本体传感器，获取内部状态数据）；机械系统（运动装置 + 操作装置，身体）；控制系统（依据规划目标、在机器人与环境约束下指挥动作执行，实现感知到行为的智能联系）。见 [1.1.3](sec1-1.md#sec-1.1.3) 表格。

::: ex A3 · 五构形识别

写出下列关节序列对应的构形名称与工作空间形状：
(a) 移动—移动—移动（三轴垂直）；(b) 转动—移动—移动；(c) 转动—转动—移动（三轴平行）；(d) 转动—转动—转动（首轴垂直、后两轴平行）。

::: sol 解答

(a) 笛卡儿型，长方体；(b) 圆柱型，空心圆柱体的一部分；(c) SCARA，扁形回转体（竖直方向高稳定 + 水平柔性）；(d) 拟人型，近似球形的一部分。球型（转动—转动—移动，第二轴转动）为另一支——注意 (c) 与球型的区别在**轴的几何关系**（平行 vs 相交）。识别口诀见 [@ex-1.2.B]。

::: ex A4 · 三类车轮

「走、转、飘」分别对应哪类车轮？购物车前轮、汽车前轮、差动机器人驱动轮各属哪类？

::: sol 解答

定轮（只能沿轮面直走）、导向轮（电机控制转向，两轴均过轮心）、自位轮（垂直轴不过轮心、带偏移量，被动对齐）——见 [@def-1.3.1]。购物车前轮 = 自位轮；汽车前轮 = 导向轮（阿克曼几何保证两前轮转角不一致）；差动机器人驱动轮 = 定轮。

## B 组 · 分析论证

::: ex B1 · 完整位姿的六变量与任务降维

(a) 为什么 3D 空间「任意定位 + 任意定向」任务有 6 个独立变量？(b) 四轴 SCARA 为什么仍可能「够用」于竖直装配？(c) 七轴 LWR 的冗余拿来做什么？

::: sol 解答

(a) 完整位姿可写作 $T=(\boldsymbol p,R)$：位置 $\boldsymbol p$ 有 3 个独立分量，定向 $R\in SO(3)$ 有 3 个独立参数，故一般完整位姿有 $3+3=6$ 个变量（[@thm-1.2.A]）。若要在一般位形附近独立调节全部变量，至少需要 6 个独立关节变量；(b) 竖直装配任务在**任务空间**只需 $x,y$（水平定位）+ $z$（下压）+ 绕竖直轴的转角 $\theta$，任务变量只有 4 个，SCARA 的 3 转动 + 1 移动恰好覆盖，且其「水平顺从 + 竖直刚」与任务方向一致；(c) 7 > 6 产生运动学冗余，可用于避障、避开奇异位形、优化姿态（原书：改装成更为灵活的姿态），见 [1.4.2](sec1-4.md#sec-1.4.2) LWR 条目。

:::

:::

::: ex B2 · 球形腕解耦论证

用 [@thm-1.2.C] 论证：(a) 为什么「三轴交于一点」能实现定位与定向解耦？(b) 若三轴不交于一点，逆运动学求解会发生什么变化？(c) 解耦的工程代价是什么？

::: sol 解答

(a) 腕心（三轴交点）在腕的任何转动下**位置不变**，故「腕心位置」只由臂决定、「末端姿态」只由腕决定，两子问题独立可解；(b) 定位与定向**耦合**——末端姿态的改变会牵动腕心（进而牵动臂的位形），逆解必须联立求解，协调臂与腕动作的复杂度大增（原书原文）；(c) 三轴交于一点要求腕结构紧凑、电机 / 传动 / 传感高度集成，机械设计复杂度上升（[@def-1.2.3]）。

:::

::: ex B3 · 机动性与位形之辨

平面三轮机器人（后两定轮 + 前导向轮）的位形变量有几个？即时容许运动方向有几个？两者为什么不等？「不能即时横移」为什么不妨碍它到达任意位形？

::: sol 解答

位形变量 3 个（$x,y$ 与朝向 $\theta$）。定轮不能沿轮面横向滑动，因而满足 $-\sin\theta\,\dot x+\cos\theta\,\dot y=0$（式 (1.1)）；这给平面刚体速度加上一条独立约束，理想运动学模型中即时容许方向为 2 个 < 3（[@def-1.3.2]）。它是「速度层面的限制」而非「位置层面的限制」：通过先转向再前进的机动操纵，可在运动**结束时**获得任意净位移与净转角——「能到达」与「能即时到达」是两个命题（[1.3.3](sec1-3.md#sec-1.3.3)）。其数学本质（非完整约束不可积）留待第 11 章。

:::

::: ex B4 · 结构决定用途

对照七款实例（[1.4.2](sec1-4.md#sec-1.4.2) 表），论证：(a) FlexPicker 为什么快？(b) IRB 4400 为什么加平行四边形闭链？(c) 同为拟人六轴，Smart NS 与 M-16iB 的差异化在哪？

::: sol 解答

(a) 并联构形：多杆同时承载 → 结构刚性极高，允许大加速度（100 m/s²）与高速度（10 m/s），代价是工作空间与负载（1 kg）小——高速分拣任务（150 件 / 分）正好匹配；(b) 60 kg 大负载要求结构刚度以保证定位精度，开链拟人臂刚度不足，肩肘间平行四边形闭链**以结构复杂度换刚度与承载**（驱动装置移向根部、刚度提高，自由度仍为 6——见 [1.2.3](sec1-2.md#sec-1.2.3)）；(c) Smart NS 走「轻负载高精度」（0.05 mm，16 kg，弧焊装配）；M-16iB 走「集成传感」（3D 视觉伺服 + 六轴力传感器，搬运任意放置物体）——同一构形族内按任务再分化。

::: ex B5 · 反馈不可替代论证

(a) 为什么「动力学模型 + 完美计算」不能取代反馈回路？(b) 原书说「除各轴两两垂直的笛卡儿结构外」关节间存在耦合动态——笛卡儿结构为什么例外？(c) 这条原理与 [1.1.3](sec1-1.md#sec-1.1.3) 的哪句话呼应？

::: sol 解答

(a) 模型不能完全描述真实结构（未建模摩擦、间隙、负载变化、磨损），开环执行会把模型误差全额转化为轨迹误差；反馈用「参考输入与传感器数据的偏差」不断修正，误差被回路压低（[@thm-1.5.B]）；(b) 笛卡儿结构每个关节沿一个独立笛卡儿轴平移，各轴动力学（质量矩阵）解耦、不互相牵动；转动关节则因惯性耦合与离心 / 科氏项牵一发而动全身（第 7 章将给出方程）；(c) 「控制系统的实现服从与人体功能控制相同的反馈原理」——工程反馈与生物反馈同构。

::: ex C2 · FlexPicker 的「150 件 / 分钟」从哪来（A1.3 · 数值）

IRB 340 FlexPicker 数据表同时给出「周期 0.4 s」与「150 件 / 分钟」。请：(a) 用周期换算件 / 分钟，核对两个数字是否自洽；(b) 若一家药厂要求 120 件 / 分钟、每件行程不同的两次抓放，估算所需周期上限；(c) 说明该机型「周期」的定义为何允许 10 m/s 的峰值速度与 100 m/s² 的加速度共存。

验收标准：(a) 写出换算式与两个数字的关系；(b) 给出带假设的估算过程。

::: sol 解答

(a) $\frac{60\ \text{s}}{0.4\ \text{s/件}}=150$ 件 / 分钟——数据表两数字完全自洽（「150」不是独立测量值，就是 0.4 s 的倒数换算）。(b) $\frac{60}{120}=0.5$ s / 件是周期**上限**；但 0.4 s 是「标准拾放行程」的口径，行程更长则周期变长——若两段行程合计超出标准行程，0.5 s 预算可能仍紧张，应向厂商索取「行程—周期曲线」而非只看单点数字。(c) 周期计的是**完整抓放循环**（含加速、减速、换向），峰值速度与加速度只在循环内瞬间出现；并联机构的高刚度使 100 m/s² 的加减速能在几十毫秒内完成，这正是短周期的来源（[1.4.2](sec1-4.md#sec-1.4.2) FlexPicker 行）。

:::

::: ex C2b · 用式 (1.1) 判定容许速度（K1.6 · 数值）

某差动底盘当前朝向 $\theta=30°$，给出三组候选瞬时速度（m/s）：$(\dot x,\dot y)=(1,0)$、$(0,1)$、$(\tfrac{\sqrt3}{2},\tfrac12)$。用 [1.3.3](sec1-3.md#sec-1.3.3) 式 (1.1) 判定各组是否容许（不侧滑）；再给出一组你自选的容许速度并验证。

验收标准：每组代入式 (1.1) 的计算过程与结论（容许 / 禁止）。

::: sol 解答

式 (1.1)：$-\sin\theta\,\dot x+\cos\theta\,\dot y=0$，$\theta=30°$ 时为 $-0.5\dot x+0.866\dot y=0$。$(1,0)$：$-0.5\ne0$ → **禁止**（这是纯 $x$ 向速度，含侧向分量）；$(0,1)$：$0.866\ne0$ → **禁止**；$(\tfrac{\sqrt3}{2},\tfrac12)$：$-0.5\times0.866+0.866\times0.5=0$ → **容许**——恰沿车头方向 $\theta=30°$ 的单位速度（$\cos\theta,\sin\theta$）。自选验证要点：任何 $(v\cos\theta,\ v\sin\theta)$ 形式的速度都使式 (1.1) 归零，即**容许瞬时速度方向只有沿车头的一条线**——差动底盘「不能即时横移」的代数表达。

:::

## D 组 · 开放研讨

::: ex D1 · 三定律的工程化

阿西莫夫三定律是科幻设定。任选一条，指出它对今天的哪类工程标准（工业安全、协作机器人、自动驾驶伦理）有「精神上的继承」，并论证这条继承在哪里失效。

::: sol 解答提示

例：定律 1「不得伤害人类」→ 协作机器人的 ISO/TS 15066 功率与力限制、安全停止（精神继承）；失效处：定律要求「不能坐视人类受到伤害」——这要求机器人具备识别人类风险情境并**主动干预**的能力，超出任何现行安全标准（标准只约束机器人自身行为，不课以救助义务）。论证时可对照 LWR 的「接触安全」：它保证的是「碰了不重伤」，不是「看到危险去救人」。

:::

原书说「意大利机器人密度 13 / 万工人，美国 99」——意大利数值反常地低。分组辩论两种解释：(a) 原书 / IFR 口径问题（如仅统计某类机器人）；(b) 真实产业结构差异。给出你们组的验证方案。

::: ex D3 · 「结构化」的分界线

原书以「环境几何与物理特征是否事先已知」区分工业与先进机器人学。请按 [1.4.1](sec1-4.md#sec-1.4.1) 的四个问题，判断家庭扫地机器人、仓库 AGV、达芬奇手术系统各落在谱线的哪个位置；「结构化程度」是连续谱还是二分？

::: sol 解答要点

仓库 AGV：**人为改造过的半结构化环境**（地面平整、路径标记 / 预建地图）——比工厂松、比家庭紧；扫地机：家庭环境几何大体已知但动态变化（家具挪动、宠物、人）——中度非结构化，靠碰撞 + 跌落传感的简单自治应对；达芬奇：**操作环境是人体内部**——几何未知但被手术视野约束，且**决策权始终在人**（医生），自治度低而精度要求极高。结论方向：结构化程度是**连续谱**（环境的先验知识量 × 变化速度），且与「自治度」并非单调对应（达芬奇环境未知但自治低）；还应把风险后果与最终决策权一并纳入判断。

::: ex D5 · 「感知—行为」定义的边界

[@def-1.1.1] 把机器人定义为「感知与行为之间智能联系」的机器。智能恒温器有感知（温度）有行为（启停压缩机），它是机器人吗？写出你们组的边界判据（至少两条），并用它裁决恒温器、达芬奇、Roomba 三个案例。

::: sol 解答提示

可能的判据：① 行为的空间自由度（恒温器的行为空间是 1 维开关，机器人的行为是**多自由度的物理运动**——这是本教材以机械结构开篇的隐含立场）；② 感知—行为映射的复杂度 / 适应性（是否需要规划与推理）；③ 是否作用于物理世界的**几何**属性。三案例按不同判据会得到不同裁决——这正是本题的教学目的：**定义服务于分析目的**，工程定义没有唯一正确版本，但必须自洽且可操作（呼应 A1.2「定义先行」）。
