# 1.4 工业机器人学与先进机器人学

本节回答三个问题：**机器人在工业中怎么用、用什么衡量？原书中的产品实例说明了怎样的“结构—任务”关系？环境越开放，机器人学又要面对哪些新问题？**

原书 §1.3（工业机器人学）与 §1.4（先进机器人学）在此合并为一节——两者共享同一套机械结构（见 1.2、1.3），区别则要从**环境先验、变化速度、风险后果与所需自治水平**四个维度去看，而不要把「工业 / 先进」误读成非黑即白的标签。

## 1.4.1 工业机器人学：定义、三层次与三能力

::: def 定义 1.4.1 · 工业机器人学（industrial robotics） {#def-1.4.1}
**工业机器人学**是有关工业机器人设计、控制和应用的学科。典型应用中，机器人在几何及物理特征**大多事先已知**的**结构化环境（structured environment）**中操作；环境先验既已充分，原书由此推出「因而只需**有限的自治性**」。（本教程补注：现代部署中，安全围栏内也常加入视觉与力觉在线调整，自治程度仍由具体任务与安全责任决定，不能仅由「在工厂里」一项推断。）美国机器人学会（RIA，1980）定义：**机器人是一种通过不同的程式化运动来完成移动原料、零配件、工具或专用设备等各种不同任务的可重复编程多功能机械手**。
:::

**为什么先在工厂落地**（原书归纳的四个动因）：**降低制造成本、提高生产率、提高产品质量标准**，以及**消除制造系统中有害或令人生厌的人工作业**——这四条动因决定了工业机器人先于服务机器人成熟。

**历史起源**：早期工业机器人于 20 世纪 60 年代在两种技术的影响下发展起来——**用于精确制造的数控机床**与**用于放射性物质处理的主从遥操纵装置**。与其先驱相比，第一代机器人机械手具备四个特征：**多功能性**（不同的末端执行器）、**对未知环境的适应性**（传感器的使用）、**定位的精确性**（反馈控制技术）、**执行的可重复性**（可编程性）。

**自动化的三个层次**（工业机器人是可编程自动化的典型组件）：

| 层次 | 适用背景 | 特征 | 机器人的角色 |
|:--|:--|:--|:--|
| **刚性自动化** | 大批量同一产品 | 特定目标机器 + 固定操作流程 | 可承担任务，无优势 |
| **可编程自动化** | 少量到中等批量、多品种 | 操作流程较易改变，机器通用 | **典型组成成分** |
| **柔性自动化（FMS）** | 减少批次间转换的重新编程时间 | 计算机技术与工业技术有力结合 | 与 AGV、FMS 深度集成 |

::: note IFR 行业快照（原书口径，2005–2007）
截至 2006 年全世界**近 100 万台**工业机器人在役（一半在亚洲、三分之一在欧洲、16% 在北美）；保有量前四：日本、德国、美国、意大利；预计 2010 年末达 **120 万台**。平均服务年限约 **12 年**（可能增至 15）。**机器人密度**（每万名工人）：日本 349、韩国 187、德国 186、意大利 13、美国 99。含控制单元与开发软件的六轴工业机器人均价 **2 万–6 万欧元**。汽车工业仍是最大用户，化工与电子行业比重上升。——引用这些数字时务必注明 2005–2007 年口径（时效对照见[勘误与补注](errata.md)）。
:::

**三种基本能力与典型应用**：

| 能力 | 任务性质 | 典型应用 |
|:--|:--|:--|
| **材料搬运** | 传递中不改变对象物理特性 | 码垛、仓库装卸、轧模机 / 机床管理、零件排架、包装（配合 **AGV** 自动导引车辆） |
| **操作** | 加工改变特性或装配改变功能 | 弧焊 / 点焊、喷涂、胶合密封、激光 / 水射流切割、研磨钻孔、铸造冲模、去毛刺、旋螺丝配线、机械 / 电器 / 电路板装配 |
| **测量** | 检测产品质量 | 对象检查、轮廓勾画、制造瑕疵检测 |

按原书图 1.23（欧洲 2005–2006 供应量），**搬运机器人约为焊接的两倍**，装配仍占少数。

::: method 用四个问题读“工业 / 先进”
原书的二分法适合建立概念，但实际系统应按下表逐项判断；同一台机器人在不同部署中可能处于不同位置。

| 问题 | 结构化工位的典型答案 | 开放部署的典型答案 | 对设计的影响 |
|:--|:--|:--|:--|
| 几何与物理特征是否已知？ | 工装、工件位姿和边界大多已知 | 地图、对象与接触条件部分未知 | 感知与状态估计需求上升 |
| 环境变化有多快？ | 节拍可预测、变化受工艺管理 | 人、物体、地形持续变化 | 规划需要在线重算 |
| 出错的后果由谁承担？ | 可隔离的安全围栏与工艺验收 | 与人共处、任务风险更难预先穷尽 | 安全约束进入系统级设计 |
| 谁作最终决策？ | 程序 / 操作员按既定流程切换 | 自主系统、远程操作者或人机共享 | “自治”须具体到决策权范围 |
:::

把这四个问题画在一条轴上，「工业 / 先进」的二分就变成了一张**连续谱**——左端是结构化工位，右端是开放部署，四个维度一起向右移动：

## 1.4.2 七款工业机器人：构形 ↔ 参数 ↔ 应用

原书以七款产品给出「结构决定用途」的实例（图 1.24–1.30）。先看参数速览：

::: note 读参数表先会两个词（原书脚注）
**重复精度（repeatability）**：机器人**回到之前到达过的位置**的能力，即同一指令反复执行时，末端实际位置的散布半径。它是数据表中的典型参数，**单位为 mm，通常小于定位精度**。**有效负载（payload）**：**末端执行器平均载荷**（含工件与夹具），单位 kg。注意**重复精度 ≠ 定位精度（accuracy）**：前者量「回到老地方的手稳不稳」，后者量「你让它去的地方它到底能不能到」——选型与验收时两者都要问（与习题 C4 直接相关）。
:::

下表中「行程」一列其实混着两种指标，读表时要留意区分：臂式机型的**可达半径（outreach，基座到末端的最大水平伸展）**与滑轨机型的**行程（stroke，线性轴的可移动距离）**——KR 60 的 0.4–20 m 是后者。

| 机器人（厂商） | 结构 | 关键参数 | 典型应用 |
|:--|:--|:--|:--|
| AdeptOne XL（Adept） | 四关节 **SCARA** | 可达半径 800 mm；水平重复精度 0.025 mm；移动关节 1200 mm/s | 小零件搬运、装配、包装 |
| Smart NS（COMAU） | 六关节**拟人 + 球形腕** | 可达半径 1650–1850 mm；重复精度 0.05 mm；负载 16 kg | 弧焊、轻量搬运、装配、加工 |
| IRB 4400（ABB） | 六关节拟人 + **平行四边形闭链** | 可达半径 1960–2550 mm；重复精度 0.07–0.1 mm；末端速度 2200 mm/s；负载 60 kg | 搬运、机器放料、碾磨、胶合、铸造、喷涂、装配 |
| KR 60 Jet（KUKA） | 五轴 + **龙门架 / 滑轨安装** | 线性轴行程 0.4–20 m、速度 3200 mm/s；可达半径 820 mm；负载 60 kg；重复精度 0.15 mm | 机器放料、弧焊、修边、涂层、密封、等离子 / 水射流切割 |
| IRB 340 FlexPicker（ABB） | 四轴**并联** | 周期 0.4 s → **150 件 / 分钟**；伸展速度 10 m/s、加速度 100 m/s²；负载 1 kg；重复精度 0.1 mm | 食品 / 制药高速分拣 |
| M-16iB（Fanuc） | 六关节拟人 + 球形腕 + **集成传感**（3D 视觉伺服 + 六轴力传感器） | 可达半径 1667–1885 mm；重复精度 0.1 mm；负载 10–20 kg | 任意放置物体搬运、修边、密封、切割 |
| LWR（DLR→KUKA，2006 技术转让） | **七轴**轻质（结构重仅 15 kg） | 负载 7–14 kg；可达半径 868 mm；**关节力矩传感器** | 人机接触安全的灵活操作；第七轴提供**运动冗余** |

::: ex 例 1.4.A · 按任务选结构（新增） {#ex-1.4.A}
(a)「每分钟抓放 150 件小食品」→ 需要极致速度与刚度 → **并联**（FlexPicker，加速度 100 m/s²）；(b)「60 kg 铸件搬运 + 大范围」→ 需刚度与负载 → **拟人 + 平行四边形闭链**（IRB 4400）；(c)「竖直方向精密插件」→ SCARA（AdeptOne，水平柔性 + 竖直刚性）；(d)「与人协作」→ 轻质 + 关节力矩传感的 LWR 是有利起点，但仍须结合限力、限速、监测与具体风险评估设计安全系统。**结构约束用途**，先定结构族，再比参数与安全方案。
:::

除钳子之外，还有**多触点机器人手**：Barrett Hand（一固定指 + 两活动指，操作不同尺寸 / 形状 / 方位的对象）；SCHUNK 仿人手 SAH（DLR 与哈尔滨工业大学技术转让，三独立手指 + 对向拇指，关节装磁性角度传感器与力矩传感器，灵敏性接近人手）。DLR **Justin** 类人机器人将 LWR 技术用于双臂（三关节躯干 + 两个七轴臂 + 传感头部）——原书以这些系统作为「从传统工业机器人向革新性先进机器人转变」的桥接。

## 1.4.3 先进机器人学：野外与服务

::: def 定义 1.4.2 · 先进机器人学（advanced robotics） {#def-1.4.2}
**先进机器人学**是原书使用的历史性分类，指显著依赖**自治能力**、工作于**较少结构化乃至非结构化环境**的机器人：环境的几何或物理特征不能完全预先给定。它不是“比工业机器人更高级”的等级称号；工业、服务、野外、医疗等分类可交叉。原书成书时，这些技术相对不成熟、产品多具雏形；今天阅读这一节，应把它作为理解**不确定环境为何要求感知、规划与安全闭环**的框架。两大应用驱动力仍清晰：**无人或不安全场景**（野外机器人）与**提高生活质量**（服务机器人）。
:::

**野外机器人（field robots）**部署在人类难以生存或有危险的环境中，借助合适的传感器向远程操作员反馈环境数据：

- **空间 / 深海探测**：NASA 火星**漫游者**（Sojourner 1997 年探测 250 m² 火星表面；后继者巡行穿过岩石、山地与裂缝），采用遥控与自主性并用的方式；**火山探测**与有毒气体 / 辐射污染区域的干预作业同属此类典型场景（原书列举）；
- **灾难救援**：2001 年 9·11 世贸遗址微型机器人穿透废墟搜寻幸存者；隧道火灾、地震场景（存在次生灾害与有害气体风险，机器人救援队与人类救援队协作）；
- **战场**：无人飞行器、装照相机的遥控探测机器人；**DARPA Grand Challenge**（2005）——无人战车竞赛，冠军 **Stanley** 自主驾驶 **132 英里（约 212 km）、用时 6 h 53 min**。

**服务机器人（service robots）**——与人共处、面向日常生活与专业服务：

- **家用 / 娱乐**：IFR 口径截至 2005 年已售出**约 190 万台家用服务机器人**（如 Roomba 真空吸尘机器人，**差动驱动**运动学系统），另有约 100 万台玩具机器人（Sony AIBO）；Honda **Asimo**（1996 年投放）以更自然的移动性与人机交互能力成为类人机器人标志；
- **智能交通**：城区自主运输电驱车 Cycab、ITS 智能交通系统、博物馆导游机器人（Rhino）；
- **医疗**：**达芬奇**手术系统——外科医生坐控制台观察 3D 影像、远程操作腹腔镜器械（遥操作型的代表）；**髋关节假体植入**等利用机器人高精度定位的外科辅助（精度型的代表，原书 §1.4.2 开篇例）；小型遥控机器人进入肠 / 胃等体腔实时传像、活检给药；
- **康复**：自动轮椅、助行升降器、辅助喂食器；偏瘫病人穿戴**外骨骼**，由系统按临床计划与患者交互、提供支撑并纠正动作。

原书展望：服务机器人将像个人电脑一样普及，「机器人技术也将为科学界提供无处不在的挑战性话题」。

## 1.4 小结与常见错误

- **一条主线**：从结构化工位到开放部署，环境先验、变化、风险与决策权同步改变；同一副身体（1.2 / 1.3 的结构谱系）需要不同的感知、规划与安全预算；LWR / 灵巧手 / Justin 是两个世界之间的桥。
- **三个数字组**：近 100 万台（2006 保有量）；密度 349 / 187 / 186 / 13 / 99；搬运 ≈ 2 × 焊接（欧洲供应量）。
- **一条选型逻辑**：任务（速度 / 负载 / 精度 / 安全）→ 结构族（并联 / 闭链拟人 / SCARA / 轻质冗余）→ 参数对比（例 1.4.A）。

::: think 常见错误清单 · 自查四条
1. 把「工业机器人」与「机器人学」混同——前者只是一个重要应用域；环境、风险与决策权要分开判断（定义 1.4.1 与方法盒）；
2. 引用「100 万台 / 密度」等数据不注年份——它们是 2006 年口径，今天的数量级已完全不同（见[勘误页](errata.md)时效补注）；
3. 以为并联机器人「全方位更好」——它以**工作空间缩减**换刚度与速度（对照 [1.2.3](sec1-2.md#sec-1.2.3) 与 FlexPicker 的 1 kg 负载）；
4. 以为先进机器人 = 人形机器人——野外与医疗（火星车、达芬奇）同样属于原书的“先进”讨论，关键是**环境不确定性与自治范围**，不是形态（呼应 [1.1.2](sec1-1.md#sec-1.1.2)）。
:::
