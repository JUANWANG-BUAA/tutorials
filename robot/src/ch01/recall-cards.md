## A. 定义卡

### A1 · 机器人（工作定义）

请写出 [@def-1.1.1] 的机器人定义，并说明为什么「长得像人」不是定义要件。

::: note A1 核对
**机器人**是一种能够影响其所处工作环境的机器，**无关其外表**；这种影响通过内置的、按一定规则设定的行为模式实现，而行为由机器人**感知其自身状态和环境**所获得的数据决定。等价说法：**机器人学研究的是感知与行为之间的智能联系**（the intelligent connection between perception and action）。判据是三条**闭环**：感知、决策、作用于环境——不是外形。「无关其外表」五个字就是对外形误读的直接否定。
:::

### A2 · 机器人系统的四个子系统

不看书写出四个子系统及其功能，并对每个子系统举一个典型组成。

::: note A2 核对
**机械系统**（身体：运动装置 + 操作装置）、**执行系统**（肌肉：伺服电机、驱动器、传动装置）、**传感系统**（感官：本体传感器 + 外部传感器）、**控制系统**（大脑：依任务规划目标、在约束下实现感知→行为的智能联系）。一句话链：机械提供身体、执行提供力气、传感提供眼睛、控制在感知与行为之间建立智能联系。**易漏点**：控制系统服从的是与人体功能控制相同的**反馈原理**，不是「写程序」。见 [1.1.3](sec1-1.md#sec-1.1.3)。
:::

### A3 · 开式链与闭式链、关节类型

写出运动链的两种拓扑，并说出两类关节各实现什么运动、哪一类工程上更常见。

::: note A3 核对
连杆链两端之间只有一个连接序列 ⇒ **开式运动链**；存在连杆序列构成回路 ⇒ **闭式运动链**。关节分**移动关节**（prismatic，实现相对平移）与**转动关节**（revolute，实现相对转动）；转动关节结构紧凑、可靠，**工程上最常见**。自由度计数：开链每个单自由度关节贡献一个独立变量；**闭链有回路约束，不能直接数关节数**。（[@def-1.2.2]）
:::

### A4 · 工作空间

写出工作空间的定义，并说明它的形状取决于哪两件事。

::: note A4 核对
末端执行器**能到达的区域**称为工作空间（workspace）。形状与容积取决于**结构形式**及**关节限位**。易错点：工作空间描述的是末端执行器**原点**扫过的区域，不是「带姿态的可达性」——后者是灵活工作空间的含义。（[@def-1.2.2]、[2.10.2](../ch02/sec2-10.md#sec-2.10.2)）
:::

### A5 · 球形腕

写出球形腕的定义，并说清它买到的东西与付出的代价。

::: note A5 核对
**球形腕**由三个转动关节构成，且**三条转动轴交于一点**（腕心）。关键特征是实现了末端执行器**定位与定向之间的解耦**：臂把腕心送到指定位置，腕确定末端朝向，两个子问题可分别设计 / 求解。代价：腕结构必须紧凑、**机械设计复杂度上升**；不用球形腕的结构实现更简单——这就是「解耦收益 vs 结构复杂度」的工程权衡。（[@def-1.2.3]、[@thm-1.2.C]）
:::

### A6 · 三类车轮

分别写出定轮、导向轮、自位轮的定义，并说出「走 / 转 / 飘」各指哪一类。

::: note A6 核对
**定轮**（fixed）：只有一个旋转轴（过轮心且垂直轮面），指向相对底盘不变 →「**走**」。**导向轮**（steerable）：两个旋转轴，第二个**垂直且穿过车轮中心**，可相对底盘调整方向 →「**转**」。**自位轮**（caster）：也有两个轴，但**垂直轴不穿过轮心**、有固定偏移量，可自由转动并快速与底盘运动方向对齐 →「**飘**」。（[@def-1.3.1]）
:::

### A7 · 即时机动性与无侧滑约束

写出定义 1.3.2 的核心表述，并写出定轮的无侧滑约束式。

::: note A7 核对
**非全向**移动机器人的**局部机动性总是被缩减的**：形式化地说，机器人的**即时自由度数（容许瞬时运动的方向数）比位形变量数少**。对不允许横滑的定轮，设横向单位向量 $\boldsymbol n=(-\sin\theta,\cos\theta)$，则 $-\sin\theta\,\dot x+\cos\theta\,\dot y=0$，即式 (1.1)。全向机器人（主动牵引自位轮 / 麦克纳姆轮）是例外：即时自由度与位形变量数相等。（[@def-1.3.2]、[1.3.3](sec1-3.md#sec-1.3.3)）
:::

### A8 · 工业机器人学

写出工业机器人学的定义，并指出它给自动化划出的三个层次中机器人的角色。

::: note A8 核对
**工业机器人学**是有关工业机器人设计、控制和应用的学科。典型应用中机器人在几何及物理特征**大多事先已知**的**结构化环境**中操作，环境先验充分 ⇒ **只需有限的自治性**。三层次：**刚性自动化**（大批量同一产品，机器人可承担任务但无优势）、**可编程自动化**（小到中批量多品种，机器人是**典型组成成分**）、**柔性自动化 FMS**（与 AGV、FMS 深度集成）。（[@def-1.4.1]）
:::


### A9 · 运动学、微分运动学与动力学

分别写出三者的定义，并说清它们"逐层加信息"的差别。

::: note A9 核对
**运动学**（kinematics）：相对固定参考笛卡儿系描述运动，**不考虑力与力矩**——对机械手即关节位置与末端位姿的解析关系。**微分运动学**：通过**雅可比矩阵**描述关节运动与末端运动在**速度层面**的关系。**动力学**：把运动方程描述为**作用其上的力与力矩的函数**。信息链：$\boldsymbol x=f(\boldsymbol q)\to\dot{\boldsymbol x}=J(\boldsymbol q)\dot{\boldsymbol q}\to\boldsymbol\tau=M(\boldsymbol q)\ddot{\boldsymbol q}+\boldsymbol h(\boldsymbol q,\dot{\boldsymbol q})$——第一式答「在哪儿」、第二式答「怎么动」、第三式答「要多大力矩」。（[@def-1.5.1]、式 (1.2)）
:::

### A10 · 正问题与逆问题

按 [@thm-1.5.A] 写出运动学两个关键问题的方向，并各说一句特点。

::: note A10 核对
**正运动学**：已知关节变量，求末端位姿（「给了胳膊的姿势，手在哪？」）——利用线性代数工具，**存在系统性、一般性的构造方法**。**逆运动学**：已知末端期望位姿，求关节变量（「手要到那里，胳膊怎么摆？」）——把期望运动翻译为关节运动的必经环节，**解的存在性与多解性由结构决定**。运动学模型对确定**静力学**关系同样有用。
:::

## B. 结论卡

### B1 · 为什么一般位姿任务至少需要 6 个自由度

给出「3 + 3」的来历，并写出两条推论。

::: note B1 核对
三维空间中完成一般的「任意定位 + 任意定向」任务，任务空间有 **6 个独立变量**：3 个定位（$x,y,z$）+ 3 个定向。数学来源：$\boldsymbol p$ 有 3 个分量；$R$ 写成 9 个数但受 $R^{\mathrm T}R=I$ 与 $\det R=1$ 约束，**实际只剩 3 个独立量**。推论一：自由度少于 6 时，**只有任务本身降低了姿态要求**才可能够用（如 4 轴 SCARA）。推论二：自由度多于任务变量数 ⇒ 机械手是**冗余**的，可用来避障、优化姿态。（[@thm-1.2.A]）
:::

### B2 · 五种构形的判据与工作空间

不看表，对五种构形各写「臂的关节序列 → 工作空间形状」，并说出识别口诀。

::: note B2 核对
笛卡儿（移—移—移，三轴垂直 → **长方体**）、圆柱型（转—移—移 → **空心圆柱体的一部分**）、球型（转—转—移 → **中空球体的一部分**）、SCARA（转—转—移，**三轴平行** → **扁形回转体**）、拟人型（转—转—转，首轴垂直、后两轴平行 → **近似球形的一部分**）。口诀：**看臂的关节序列与工作空间形状，腕先放一边**；判别关键在「轴的几何关系（相交 / 平行）」而非关节类型序列本身。（[1.2.2](sec1-2.md#sec-1.2.2) 表、[@ex-1.2.B]）
:::

### B3 · 球形腕凭什么解耦

用一句话说出解耦的机制，再说出这条原理在本课程后面兑现的位置。

::: note B3 核对
腕心是三轴交点，**腕的任何转动都不改变腕心位置**——所以「把腕心送到哪里」由臂决定、「末端朝向哪里」由腕决定，两个子问题可分别求解。故带球腕的六轴臂逆运动学可**分两步求解**（[2.12.3](../ch02/sec2-12.md#sec-2.12.3)）；奇点判定也据此把 $6\times6$ 行列式拆成两个 $3\times3$（[3.3.3](../ch03/sec3-3.md#sec-3.3.3)）。
:::

### B4 · 五构形的行业占比

写出 IFR 口径下四种构型的占比，并说明这组数据的使用纪律。

::: note B4 核对
截至 2005 年：**拟人型 59%、笛卡儿型 20%、圆柱型 12%、SCARA 8%**（合计 99%，其余为球型等）。纪律：**这是 2006 年前后的口径，引用必须注明年份与机构**（[errata.md](errata.md) 第三节给出现代量级对照：全球在役从近 100 万台增至 400 万台以上）。（[1.2.2](sec1-2.md#sec-1.2.2)）
:::

### B5 · 差分底盘为什么能原地转、不能即时横移

分别给出两件事的机制。

::: note B5 核对
**能原地转**：两个同轴定轮**独立控制**角速度，两轮**等速反向**即绕中心旋转（自位轮仅保平衡、从动）。**不能即时横移**：车轮只能沿轮面方向运动，式 (1.1) 的无侧滑约束禁止垂直于轮面的速度分量 ⇒ 瞬时速度里没有横向分量。**但**这只是**速度**约束：通过「转向—前进」仍可到达任意位置，只是不能**瞬时**到达。（[1.3.2](sec1-3.md#sec-1.3.2)、[@def-1.3.2]）
:::

### B6 · 支撑三角形条件

写出静平衡的判据，并给出一条推论。

::: note B6 核对
三轮机器人的**重心落在三个轮地接触点构成的支撑三角形以内**时静态平衡；多于三轮则形成支撑多边形，平衡条件更易满足。推论：机器人在**不平整地面**上移动时，需要**悬挂系统**保证每个车轮与地面的接触。（[@thm-1.3.B]）
:::

### B7 · 移动机械手的收益与代价

说出移动机械手把哪两种身体合到一起，收益与额外难点各是什么。

::: note B7 核对
把机械手装在移动小车上即**移动机械手**，它结合了**关节臂的灵活性与底座的无限移动性**。代价：**静态与动态力学平衡问题**、**两套系统的驱动问题**——「结构融合 1 + 1 > 2，难度也 > 2」。（[1.3.4](sec1-3.md#sec-1.3.4)）
:::

### B8 · 选型五约束

不看书写出机器人选型的五条约束，并说明为什么「多功能性」不足以论证「够用」。

::: note B8 核对
① 工作空间的**维数与形状**（能否覆盖所有工位）；② 最大**有效负载**（对象 + 末端执行器重量）；③ **定位精度 / 重复精度**（对照任务公差）；④ **动态性能**（节拍与速度）；⑤ **安装方式**（地面 / 龙门 / 天花板 / 滑轨）。多功能性与灵活性**并不意味结构足以完成给定任务**——约束来自具体应用条件，必须先过这五条。（[1.2.4](sec1-2.md#sec-1.2.4)）
:::

### B9 · 反馈为什么不可替代

写出原理 1.5.B 的两条技术理由。

::: note B9 核对
① 机械手是**连杆相互牵连的系统**，运动方程含**耦合动态**；理想化的笛卡儿机构可能近似解耦，实际仍受负载、摩擦与传动影响。② **动力学模型本身不能完全描述真实结构**，故「算准了再开环执行」不可行——必须闭合反馈回路，按 $\boldsymbol e(t)=\boldsymbol q_d(t)-\boldsymbol q(t)$ 持续修正 $\boldsymbol\tau(t)$。（[@thm-1.5.B]）
:::

### B10 · 工业 / 先进是连续谱

不看书写出区分两者的四个维度，并说明为什么不能按「在不在工厂」判断。

::: note B10 核对
四个维度：**环境先验**（几何与物理特征是否已知）、**变化速度**（节拍可预测 vs 人 / 物体 / 地形持续变化）、**风险后果**（可隔离围栏 vs 与人共处、风险难穷尽）、**最终决策权**（程序 / 操作员 vs 自主 / 远程 / 人机共享）。四者**一起**向右移动，把二分变成连续谱；**同一台机器人在不同部署中可能落在轴上不同位置**，标签不能替代逐项判断。（[1.4.1](sec1-4.md#sec-1.4.1)）
:::

## C. 公式卡

### C1 · 无侧滑约束（式 1.1）

写出定轮底盘的位形向量与无侧滑约束，并说明它能积分成位置约束吗。

::: note C1 核对
$$\boldsymbol q=\begin{bmatrix}x&y&\theta\end{bmatrix}^{T},\qquad \boldsymbol n=(-\sin\theta,\cos\theta),\qquad -\sin\theta\,\dot x+\cos\theta\,\dot y=0 .$$

这条约束只限制**瞬时速度**，**不能积分成只含 $x,y,\theta$ 的位置等式**——这就是「非完整约束」的入口。它删掉侧向的一条瞬时运动方向，却没有把某个地点从可达集合中删掉。**典型错误**：把它当成"不能横移"。（[1.3.3](sec1-3.md#sec-1.3.3) 式 (1.1)）
:::


### C2 · 建模三层的层级公式（式 1.2）

写出从位姿到力矩的三段式，并标注每一步"新加了什么"。

::: note C3 核对
$$\boldsymbol x=f(\boldsymbol q)\ \xrightarrow{\text{对时间求导}}\ \dot{\boldsymbol x}=J(\boldsymbol q)\dot{\boldsymbol q}\ \xrightarrow{\text{加入力与质量}}\ \boldsymbol\tau=M(\boldsymbol q)\ddot{\boldsymbol q}+\boldsymbol h(\boldsymbol q,\dot{\boldsymbol q}).$$

第一步只答「在哪儿」，求导后答「怎么动」，加入力与质量后答「要多大力矩」。$J,M,\boldsymbol h$ 的构造与物理意义分别留到第 3、7 章。（[1.5.1](sec1-5.md#sec-1.5.1)）
:::

### C3 · 机器人密度与「搬运 ≈ 2 × 焊接」

写出这组行业数字（含年份口径），并说明引用纪律。

::: note C4 核对
**机器人密度**（每万名工人）：日本 349、韩国 187、德国 186、意大利 13、美国 99；截至 2006 年全世界**近 100 万台**工业机器人在役，平均服务年限约 12 年；六轴工业机器人均价 **2 万–6 万欧元**。按欧洲 2005–2006 供应量，**搬运机器人约为焊接的两倍**。**引用纪律**：必须注明 2005–2007 年口径——现代量级已完全不同（[errata.md](errata.md) 第三节）。（[1.4.1](sec1-4.md#sec-1.4.1)）
:::

### C4 · 构形参数表的读法

以 AdeptOne XL 与 IRB 4400 为例，写出各自的「结构 — 关键参数 — 应用」三要素。

::: note C5 核对
**AdeptOne XL**：四关节 SCARA；可达半径 800 mm、水平重复精度 0.025 mm、移动关节 1200 mm/s；小零件搬运、装配、包装。**IRB 4400**：六关节拟人 + **平行四边形闭链**；可达半径 1960–2550 mm、重复精度 0.07–0.1 mm、末端速度 2200 mm/s、负载 60 kg；搬运、机器放料、碾磨、胶合、铸造、喷涂、装配。**读表要点**：「行程」一列混着**可达半径**（基座到末端的最大水平伸展）与**滑轨行程**（线性轴可移动距离）——KR 60 的 0.4–20 m 是后者。（[1.4.2](sec1-4.md#sec-1.4.2)）

### C5 · 重复精度与定位精度

写出两个术语的判据式（用一句话各自表述），并说明选型时该问哪一个。

::: note C6 核对
**重复精度**（repeatability）：机器人**回到之前到达过的位置**的能力——同一指令反复执行时，末端实际位置的**散布半径**；单位 mm，**通常小于定位精度**。**定位精度**（accuracy）：「你让它去的地方它到底能不能到」——指令位姿与真实到达位姿之差（随工作空间位置变化，可由标定改善）。**两个都要问**：前者决定示教再现的可靠性，后者决定离线段程序的可信度。（[1.4.2](sec1-4.md#sec-1.4.2) note、[2.10.2](../ch02/sec2-10.md#sec-2.10.2)）
:::

### C6 · 手册里「行程」两列的量纲陷阱

给定一台臂式机型（可达半径 1650–1850 mm）与一台滑轨机型（行程 0.4–20 m），说明为什么两个数不能直接比大小。

::: note C7 核对
臂式机型的数是**可达半径**（outreach）：基座到末端的**最大水平伸展**，是几何可达范围的一维摘要；滑轨机型的数是**行程**（stroke）：**线性轴的可移动距离**，是附加自由度的可移动量。两者量纲同为长度，**含义不同**：前者描述工作空间形状，后者描述一条轴能走多远。跨机型比较必须回到「工作空间必否覆盖所有工位」这条约束上（选型五约束之一）。（[1.4.2](sec1-4.md#sec-1.4.2)）
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「不能即时横移 = 不能横移」

::: note D1 核对
**错在把速度约束当位置约束。** 式 (1.1) 只禁止侧向的**瞬时速度分量**；改变 $\theta$ 后允许的前进方向也随之改变，因此通过「前进—转向—再前进」的机动操纵仍可获得任意净位移。想象开车入库：此刻不能横着滑进去，但「前—后—打轮」最终能停进去。**正确说法**：轮式小车的世界没有「此路不通」，只有「此向需绕行」。（[@def-1.3.2]、[1.3.3](sec1-3.md#sec-1.3.3) 常见错误 3）
:::

### D2 · 「并联构形全方位更好」

::: note D2 核对
**错在只算收益不算代价。** 并联的基本优势是**很高的结构刚性**与可达较高操作速度，代价正是**工作空间被缩减**——IRB 340 FlexPicker 负载仅 1 kg、周期 0.4 s（150 件 / 分钟），正是「以工作空间换刚度与速度」的典型。大范围搬运不会被并联吸引，高速小件分拣才会。
:::

### D3 · 「自位轮只是被动支撑轮」

::: note D3 核对
**只说对了一半。** 自位轮的**转向**确实永远被动自适应，但**牵引（滚动）既可以不装电机（被动），也可以独立驱动（主动）**。三个**主动牵引自位轮**按约 $120^\circ$ 对称布置、牵引速度独立驱动，就是原书图 1.17 的**全向**方案；而差动式布局里的小自位轮是纯被动、只保平衡。**混同两者会漏掉一整类全向构型。**（[1.3.2](sec1-3.md#sec-1.3.2)、常见错误 2）
:::

### D4 · 「阿克曼几何是工艺误差」

::: note D4 核对
**错。** 汽车式布局沿曲线运动时两前轮方向**必须不一致**（内侧轮转角更大），由**阿克曼转向几何**保证不滑动——这是**机构要求**，不是制造偏差。三轮式布局则不同：转弯半径**受导向轮限制**，可实现更小的转弯半径。**正确说法**：前轮转角差是设计出来的自由度，不是要消除的误差。（[1.3.2](sec1-3.md#sec-1.3.2) 表）
:::

### D5 · 「数移动机器人自由度就数轮子」

::: note D5 核对
**数错了对象。** 应当数**容许瞬时运动的方向数**，它与位形变量数（平面刚体是 3：$x,y,\theta$）**未必相等**。三轮机器人不能即时向平行于后轮轴的方向移动，即时自由度小于 3；全向机器人的即时自由度数才等于位形变量数。**连带的错**：把「工作空间无限」当成「局部机动性无限」。（[@def-1.3.2]）
:::

### D6 · 「自动化就是机器人」「先进机器人 = 人形机器人」

::: note D6 核对

三门都错。① **自动化 ≠ 机器人**：刚性自动化中的专用机器**不含感知—行为闭环**，按定义 1.1.1 不算机器人（三层次的区别在环境先验与批量：刚性自动化里机器人「可承担任务、无优势」，可编程自动化里它才是**典型组成成分**）。② **先进 ≠ 人形**：野外与医疗（火星漫游者、达芬奇手术系统）同样属于原书的「先进」讨论，关键是**环境不确定性与自治范围**；反过来人形外形也不自动使它属于先进机器人学——**拿四个维度逐项量（先验、变化、风险、决策权），不看外形**。（[1.4.1](sec1-4.md#sec-1.4.1)、[@def-1.4.2]）

:::

### D7 · 「自由度越多越好」

::: note D7 核对
**多算一笔账。** 冗余确实带来灵活性（避障、优化姿态），但也带来**更高的控制与标定成本**——逆解有无穷多组、标定的参数变多、控制律要处理零空间。判据是**任务相关**的：同一台机械手可能对此任务冗余、对彼任务不冗余。**正确说法**：自由度要按任务配，不是按「越多越好」配。（[@thm-1.2.A] 推论二、[1.2.1](sec1-2.md) 常见错误 3）
:::

### D8 · 「精度只取决于控制器」

::: note D8 核对
**结构先于算法。** 构形决定精度分布：拟人型精度**随位置变化**、笛卡儿型**处处一致**；SCARA 竖直方向刚、水平面内顺从，所以适合插装。控制与补偿只能在既定分布上做优化，改不了分布本身。**正确说法**：选型时先看结构决定的工作空间与精度分布，再谈算法。（[1.2.1](sec1-2.md) 常见错误 4）
:::

### D9 · 「规划只是找路径」

::: note D9 核对
**把两个概念压成了一个。** **轨迹规划**生成的是**时间律**（何时在何处——从简明描述出发生成相关变量的时间律），描述可给在关节空间或操作空间；**运动规划**解决**避障**（工作空间出现障碍物时，规划的运动必须防碰撞），并有轨迹优化目标（时间最短、损耗最小）。所以「让机械手沿直线从 A 移到 B 并避开工件」= 第 2 章逆运动学 + 第 4 章轨迹规划 + 第 12 章避障 + 原书第 8 章运动控制。（[@def-1.5.2]、[1.5.4](sec1-5.md#sec-1.5.4)）
:::

### D10 · 「引用行业数据不带年份也能说明问题」

::: note D10 核对
**不能。** 原书第一章的 IFR 数据是 **2005–2007 年口径**：近 100 万台在役、密度 349 / 187 / 186 / 13 / 99、六轴均价 2 万–6 万欧元。这些数字今天的量级已完全不同（保有量超 400 万台；中、韩、新加坡的密度量级翻了数倍）。**引用纪律**：数据必带年份与机构口径；跨年比较必须说明口径差异。这条纪律本身就是本章的学习目标 A1.3。（[errata.md](errata.md) 第三节）
:::
