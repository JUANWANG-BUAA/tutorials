## A. 定义卡

### A1 · 机器人（工作定义）

请区分 [@def-1.1.1] 的机器工作定义与机器人学研究对象，说明为什么「长得像人」不是定义要件。再回忆 robota、R.U.R. 与阿西莫夫三定律各属于什么背景。

::: sol A1 核对
教材用“按内置规则与获取的数据采取行动、改变环境”描述机器人，与外表无关；机器人学研究感知与行为之间的智能联系。前者描述机器，后者概括学科。可用“测到什么、怎样使用数据、产生什么动作”分析系统，但有反馈不等于满足机器人分类的全部条件；恒温器也是反馈系统。robota 与劳役词源有关，R.U.R. 是 1920 年发表的戏剧，三定律是科幻设定，均不能独自充当工程分类或验收条件。见 [1.1.1](sec1-1.md#sec-1.1.1)–[1.1.2](sec1-1.md#sec-1.1.2)。
:::

### A2 · 机器人系统的四个子系统

不看书写出四个子系统及其功能，对每个子系统举一个典型组成，再列出机器人学涉及的四个学科领域。

::: sol A2 核对
跨学科核对：机械、控制、计算机、电子。它们是参与领域，不是把四子系统逐一分给四个专业。

**机械系统**（身体：运动装置 + 操作装置）、**执行系统**（肌肉：伺服电机、驱动器、传动装置）、**传感系统**（感官：本体传感器 + 外部传感器）、**控制系统**（大脑：依任务规划目标、在约束下实现感知→行为的智能联系）。一句话链：机械提供身体、执行提供力气、传感提供眼睛、控制在感知与行为之间建立智能联系。**易漏点**：说明测量结果怎样返回控制器，再影响下一次命令；机械系统和执行系统按功能区分，不一定各自封装成一块硬件。见 [1.1.3](sec1-1.md#sec-1.1.3)。
:::

### A3 · 开式链与闭式链、关节类型

写出运动链的两种拓扑，并说出两类关节各实现什么运动、哪一类工程上更常见。

::: sol A3 核对
连杆链两端之间只有一个连接序列 ⇒ **开式运动链**；存在连杆序列构成回路 ⇒ **闭式运动链**。关节分**移动关节**（prismatic，实现相对平移）与**转动关节**（revolute，实现相对转动）；转动关节结构紧凑、可靠，**工程上最常见**。自由度计数：开链每个单自由度关节贡献一个独立变量；**闭链有回路约束，不能直接数关节数**。（[@def-1.2.2]）
:::

### A4 · 工作空间

定义位置工作空间，并说明为什么“点能到达”还不够判断任务可行。

::: sol A4 核对
位置工作空间是选定末端参考点能到达的位置集合，受轴布局、连杆尺寸、限位和工具偏置影响。点能到达不保证目标朝向可实现；灵活工作空间进一步要求在该点能实现任意朝向。具体任务还须核对所需朝向和路径。（[@def-1.2.2]、[2.10.2](../ch02/sec2-10.md#sec-2.10.2)）
:::

### A5 · 球形腕

写出球形腕的定义，并说清它买到的东西与付出的代价。

::: sol A5 核对
球形腕的三个转动轴交于腕心 W。固定臂后，转腕不改变 W；带偏置的工具点 P 则可能移动。已知目标工具位姿，可先算 W 并求臂解，再求相对腕姿态。设计时须满足三轴共点的几何要求，并处理空间布置、传动与奇异位形。（[@def-1.2.3]、[@thm-1.2.C]）
:::

### A6 · 三类车轮

分别按轮轴几何定义定轮、导向轮、自位轮，并说明滚动驱动和转向驱动为什么要分开记录。

::: sol A6 核对
**定轮**：滚动轴过轮心、轮向相对底盘固定；**导向轮**：转向轴也过轮心，可改变轮向；**自位轮**：竖直转向轴偏离轮心，常靠被动回转调整轮向。轮型是几何分类，驱动配置另记：定轮可主动或从动，自位轮的牵引也可主动。（[@def-1.3.1]）
:::

### A7 · 即时机动性与无侧滑约束

写出定义 1.3.2 的核心表述，并写出定轮的无侧滑约束式。

::: sol A7 核对
对选定参考点，**即时机动性**是当前满足无侧滑约束的独立底盘速度方向数；它可能少于位形变量数。定轮轴中点满足 $-\sin\theta\,\dot x+\cos\theta\,\dot y=0$；差动式另有前进和角速度输入，汽车式还受 $\omega=v\tan\delta/L$ 约束。全向结论要结合具体轮向、偏置和无滑动假设，不能只由轮数推出。（[@def-1.3.2]、[1.3.3](sec1-3.md#sec-1.3.3)）
:::

### A8 · 工业机器人学

写出工业机器人学的定义、自动化三个层次与机器人的角色，再用搬运、操作、测量三种能力分别解释一个任务。

::: sol A8 核对
工业机器人学研究工业中的机器人设计、控制与应用。原书典型场景的几何/物理条件大多已知，因而描述为有限自治需求；实际仍须逐项核查。刚性自动化面向大批量固定流程；可编程自动化面向多品种、可更改流程；柔性自动化进一步减少批次换型损失，FMS 即柔性制造系统。机器人是可编程系统的典型组件，也可用于另外两类，不能断言其在刚性系统中一概无优势。搬运改变物体位置，如抓放；操作由工具改变工件，如焊接；测量获取信息，如尺寸检测。同一工作站可以组合三种能力。（[@def-1.4.1]）
:::


### A9 · 运动学、微分运动学与动力学

分别写出三者的定义，并说明求导与加入力学信息有什么区别。

::: sol A9 核对
运动学给几何关系；微分运动学给相应速度关系；动力学另需质量、惯量与外力等信息，不是几何关系再求导即可。$\boldsymbol\tau$ 为广义驱动力，转动关节用 N·m，移动关节用 N。局部任务坐标的雅可比与“线速度 + 角速度”的几何雅可比须区分，欧拉角导数不直接等于角速度。（[@def-1.5.1]、式 (1.2)）
:::

### A10 · 正问题与逆问题

按 [@thm-1.5.A] 写出运动学两个关键问题的方向，并各说一句特点。

::: sol A10 核对
正运动学从关节变量求末端位姿；逆运动学从目标位姿求满足它的关节变量，可能无解或多解，并须检查限位等条件。从末端目标生成关节参考时要做这一步转换；直接给关节参考则不必另解一次逆运动学。运动学还可用于静态平衡中的末端力与关节广义力关系。（[@thm-1.5.A]）
:::

## B. 结论卡

### B1 · 为什么一般位姿任务至少需要 6 个自由度

给出「3 + 3」的来历，并写出两条推论。

::: sol B1 核对
一般完整位姿有 3 个位置变量和 3 个定向变量；旋转矩阵受正交与正行列式条件约束，局部只有 3 个独立量。六个独立关节变量是局部调节完整位姿的必要条件，还须检查可达性、限位与奇点。任务减少位置或朝向要求时，少于六轴也可能够用；机构自由度多于任务变量数时，相对该任务存在运动学冗余。（[@thm-1.2.A]）
:::

### B2 · 五种构形的判据与工作空间

不看表，对五种构形各写「臂的关节序列 → 工作空间形状」，并说出识别口诀。

::: sol B2 核对

笛卡儿（移—移—移，三轴垂直 → **长方体**）、圆柱型（转—移—移 → **空心圆柱体的一部分**）、球型（转—转—移 → **中空球体的一部分**）、SCARA（转—转—移，**三轴平行** → **扁形回转体**）、拟人型（转—转—转，首轴垂直、后两轴平行 → **近似球形的一部分**）。口诀：**看臂的关节序列与工作空间形状，腕先放一边**；判别关键在「轴的几何关系（相交 / 平行）」而非关节类型序列本身。（[1.2.2](sec1-2.md#sec-1.2.2) 表、[@ex-1.2.B]）
:::

### B3 · 球形腕凭什么解耦

用一句话说出解耦的机制，再说出这条原理在本课程后面兑现的位置。

::: sol B3 核对
固定臂后，腕转动不改变腕心。若工具沿自身 $z$ 轴偏置 $d$，先由目标位姿求 $\boldsymbol p_W=\boldsymbol p_P-dR\boldsymbol e_z$，再求臂解和相对腕旋转 $R_{AW}=R_{0A}^{\mathrm T}R$；绝对朝向由臂与腕共同决定。见 [2.12.3](../ch02/sec2-12.md#sec-2.12.3)，奇点分解见 [3.3.3](../ch03/sec3-3.md#sec-3.3.3)。
:::

### B4 · 五构形的行业占比

写出 IFR 口径下四种构型的占比，并说明这组数据的使用纪律。

::: sol B4 核对
原书引用 IFR 截至 2005 年的数据：拟人型 59%、笛卡儿型 20%、圆柱型 12%、SCARA 8%。须注明历史年份；取整后合计 99%，不能推出球型恰好占 1%，也不能替代当前市场统计。构形识别应依据轴几何，而非比例。（[1.2.2](sec1-2.md#sec-1.2.2)）

### B5 · 差动底盘为什么能原地转、不能即时横移

分别给出两件事的机制。

::: sol B5 核对
**能原地转**：两轮等速反向，平均前进速度为零而角速度非零。**不能即时横移**：轮轴中点的侧向速度受式 (1.1) 约束。该约束只限制瞬时速度；空间足够且无障碍时，改变朝向后再前进可取得侧向净位移，具体路径仍受转弯半径限制。（[1.3.2](sec1-3.md#sec-1.3.2)、[@def-1.3.2]）
:::

### B6 · 支撑三角形条件

写出静平衡的判据，并给出一条推论。

::: sol B6 核对
水平地面静止时，重心竖直投影在有效接触点支撑多边形内部才有抗倾覆余量；在边界上余量为零。轮数增加不等于有效接触点增加；坡地、加速、转弯和机械臂伸出时要重新计算受力。悬挂或柔顺接地可帮助不平地面保持接触。（[@thm-1.3.B]）
:::

### B7 · 移动机械手的收益与代价

说出移动机械手把哪两种身体合到一起，收益与额外难点各是什么。

::: sol B7 核对
把机械手装在移动底盘上即**移动机械手**。底盘扩大作业区域，机械臂调整工具位姿；两者须协调驱动，伸臂也会改变整机重心与受力。实际范围仍受障碍、地形和续航限制。（[1.3.4](sec1-3.md#sec-1.3.4)）
:::

### B8 · 选型五约束

不看书写出机器人选型的五条约束，并说明为什么「多功能性」不足以论证「够用」。

::: sol B8 核对
① 工位位置与工具朝向可达，路径无碰撞；② 对象与工具的质量、重心、力矩和惯量满足负载要求；③ 定位偏差与重复散布满足公差；④ 实际载荷下的节拍、速度和加速度满足要求；⑤ 安装方式适合工位。第五项是本教程增加的布置检查。（[1.2.4](sec1-2.md#sec-1.2.4)）
:::

### B9 · 反馈为什么不可替代

说清模型误差、测量误差与反馈效果的关系。

::: sol B9 核对
模型遗漏摩擦或负载变化时，仅靠模型命令不能保证轨迹精度。反馈用参考与测量的差调整命令，但还须检查稳定性、采样与驱动限制；测量有偏时，测量零误差也可伴随真实偏差。滑台多报 0.02 m 时，调大比例增益不能消除被掩盖的实际位置差。（[反馈练习](sec1-5.md#sec15-feedback-answer)、[@thm-1.5.B]）
:::

### B10 · 四个部署问题分别判断

不看书写出分析部署要求的四个问题，并说明为什么不能按「在不在工厂」判断。

::: sol B10 核对
四问：事先知道什么？任务中什么会变？错误可能造成什么？谁选目标、执行和处理异常？它们不必同步变化。开放环境也可由人选目标；结构化工位也须检查严重危险。四问用于列出部署要求，不相加成“先进程度”，也不按是否在工厂或是否人形判断。（[部署练习](sec1-4.md#sec14-deployment-answer)）
:::

## C. 公式卡

### C1 · 无侧滑约束（式 1.1）

写出定轮底盘的位形向量与无侧滑约束，并说明它能积分成位置约束吗。

::: sol C1 核对
$$\boldsymbol q=\begin{bmatrix}x&y&\theta\end{bmatrix}^{T},\qquad \boldsymbol n=(-\sin\theta,\cos\theta),\qquad -\sin\theta\,\dot x+\cos\theta\,\dot y=0 .$$

参考点须取驱动轮轴中点或后轴中点。该式限制瞬时速度，不能化成只含 $x,y,\theta$ 的固定位置等式；改变朝向后可取得侧向净位移，具体路线仍受障碍与转向限制。（[1.3.3](sec1-3.md#sec-1.3.3) 式 (1.1)）
:::


### C2 · 建模三层的层级公式（式 1.2）

写出式 (1.2) 的三个关系，并说明变量、单位和新增假设。

::: sol C2 核对
$$\boldsymbol x=f(\boldsymbol q),\qquad \dot{\boldsymbol x}=J_x(\boldsymbol q)\dot{\boldsymbol q},\qquad \boldsymbol\tau=M(\boldsymbol q)\ddot{\boldsymbol q}+\boldsymbol h(\boldsymbol q,\dot{\boldsymbol q}).$$

第二式对同一组局部任务坐标求导；第三式另加入质量、惯量及模型中的速度/重力项，此处暂不含外接触力。移动关节的广义力是力，不是力矩。教程第三章学雅可比，第六章学动力学；后者对应原书第七章。（[1.5.1](sec1-5.md#sec-1.5.1)）
:::

### C5 · 重复精度与定位精度

写出两个术语的判据式（用一句话各自表述），并说明选型时该问哪一个。

::: sol C5 核对

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「不能即时横移 = 不能横移」

::: sol D1 核对
**错在把速度约束当位置约束。** 式 (1.1) 禁止侧向瞬时速度；改变 $\theta$ 后允许方向也随之改变，因此在空间足够、无障碍的理想场景中可用前进/倒车和转向取得侧向净位移。具体通道仍可能因障碍和最小转弯半径不可行。（[@def-1.3.2]、[1.3.3](sec1-3.md#sec-1.3.3) 常见错误 3）
:::

### D2 · 「并联构形全方位更好」

::: sol D2 核对
**错在由构形名称推出全类性能。** 原书 FlexPicker 实例侧重轻载快速抓放，表列 1 kg、0.4 s；实际选型还要核查工作空间、载荷、刚度和循环工况。工件加夹具超过 1 kg 时，该历史实例即不能仅因“快”而入选。（[@ex-1.4.A]）
:::

### D3 · 「自位轮只是被动支撑轮」

::: sol D3 核对
**只说对了一半。** 自位轮的竖直转向轴偏离轮心，常靠被动回转对齐；牵引可以被动，也可以独立驱动。原书三主动自位轮是理想全向实例；差动式小自位轮才是纯支撑从动。分析时要同时写轮向、偏置和牵引输入。（[1.3.2](sec1-3.md#sec-1.3.2)、常见错误 2）
:::

### D4 · 「阿克曼几何是工艺误差」

::: sol D4 核对
**错。** 理想无侧滑转弯要求两前轮与后轮对应同一瞬时转动中心，因而内侧前轮转角更大。阿克曼机构协调两个角度，并没有增加一个独立转向自由度。三轮式的最小转弯半径也取决于轴距和舵角范围，不能仅凭轮数比较。（[1.3.2](sec1-3.md#sec-1.3.2) 表）
:::

### D5 · 「数移动机器人自由度就数轮子」

::: sol D5 核对
**数错了对象。** 先选参考点，列轮面无侧滑约束，再判断当前轮向下的独立速度数；它与位形变量数、驱动器数量都可能不同。障碍、偏置和转弯限制也会影响具体路径。（[@def-1.3.2]）
:::

### D6 · 「自动化就是机器人」「先进机器人 = 人形机器人」

::: sol D6 核对

两种说法都不成立。① 自动化与机器人不是同一分类问题：专用自动设备也可能使用反馈，存在反馈不能独自决定机器人分类；应先明确采用的定义，再查看结构、用途与自动控制范围（[1.1.2](sec1-1.md#sec-1.1.2)）。② **先进 ≠ 人形**：野外与医疗（火星漫游者、达芬奇手术系统）同样属于原书的「先进」讨论，关键是**环境不确定性与自治范围**；反过来人形外形也不自动使它属于先进机器人学——**拿四个维度逐项量（先验、变化、风险、决策权），不看外形**。（[1.4.1](sec1-4.md#sec-1.4.1)、[@def-1.4.2]）

:::

### D7 · 「自由度越多越好」

::: sol D7 核对
冗余可用于避障与姿态优化，也增加建模、标定和解选择的工作。在任务映射满秩且限位允许的正则位形附近，冗余常对应保持任务不变的连续构形变化；不能因此断言每个目标在限位或奇点处都有无穷多组可行解。同一台机械手可对某任务冗余、对另一任务不冗余。应按任务检查收益与代价。（[@thm-1.2.A]、[1.2.1](sec1-2.md)）
:::

### D8 · 「精度只取决于控制器」

::: sol D8 核对
构形影响关节误差怎样传到末端。理想正交 PPP 模型中，关节误差直接对应坐标误差；实际精度仍受导轨、标定、载荷和温度影响。转动臂的误差传播随构形变化，也不能简单理解为“离基座越远必然越差”。应核对任务区域内的实际精度与补偿效果。（[1.2.2](sec1-2.md#sec-1.2.2)）
:::

### D9 · 「规划只是找路径」

::: sol D9 核对
路径给几何，轨迹还给时间律；运动规划寻找满足任务和约束的运动，原书第十二章重点讲避碰。不能只凭两个端点判断中间无碰撞，也不能把三者写成简单集合包含关系。本站可在第二章求位姿换算、第四章生成时间律、第六章检查模型力、第七章研究跟踪；原书第十二章未收录。（[@def-1.5.2]、[时间缩放练习](sec1-5.md#sec15-timing-answer)）
:::

### D10 · 「引用行业数据不带年份也能说明问题」

::: sol D10 核对
不能。原书引用的是 2005–2007 年历史资料，须分别注明年份、地区、统计对象与分母。“某年新增安装量”“年末在役量”“每万名制造业员工的密度”不是同一指标，不能互作排名依据。英文原书同样写意大利 13，只能排除本次 OCR 单独造成该值，仍不能证明原书或 IFR 转录无误。核查流程与固定年份对照见[勘误页第三节](errata.md)；尚缺原报告时保留待核。
:::
