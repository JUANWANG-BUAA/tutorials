# 入学诊断：你该从哪一章开始

这一页只回答一个问题：**这份教程该从哪一章开始读、以什么速度读**。下面 17 道题请在 **20 分钟**内闭卷做完，再按文末的[分数→起点建议表](#entry-route)选路线、按[错题定位表](#entry-map)回读对应页。

题目只考**先修**——数学基础、力学与空间直觉、编程与工具三类，**不考本书正文**。所以「做不出来」不等于「学不会」，只说明有一个前置工具需要先补上。

::: note 怎么用这份自测
- **闭卷、计时、不查资料**：不会的题直接标记跳过——跳过比猜更有信息量（猜对会把缺口藏起来）。
- **每题都要读「诊断含义」**：这一页的价值不在分数，而在告诉你**缺口落在哪个工具上**。
- **三组各有分工**：A 组是第二、三、五章共用的数学地基；B 组决定你能不能把公式「想成图」；C 组决定你能不能把公式「跑起来」。
- **诊断是为了省时间**，不是贴标签。三组全对的人可以从第一章速读完直接进第二章。
:::

## A 组 · 数学基础（6 题，每题 1 分）

::: ex A1 · 形状与可乘性
设 $A\in\mathbb{R}^{3\times4}$、$B\in\mathbb{R}^{4\times2}$。$AB$ 与 $A^{\mathrm T}B$ 的形状各是什么？后者能不能算？
::: sol 答案
$AB\in\mathbb{R}^{3\times2}$（内维 $4$ 对上）；$A^{\mathrm T}\in\mathbb{R}^{4\times3}$ 要乘 $B$ 需内维 $3=4$——**不成立，不能算**。

**诊断含义**：错这题说明还没有「先对形状、再动手」的习惯。齐次变换连乘（[2.7](ch02/sec2-7.md)）与雅可比的行列分工（[3.1](ch03/sec3-1.md)）全靠形状先行，这是**必须补**的第一课。
:::
:::

::: ex A2 · 正交性与行列式
$Q=\dfrac{1}{\sqrt2}\begin{bmatrix}1&1\\-1&1\end{bmatrix}$ 是否正交？$\det Q$ 是多少？它是否属于 $SO(2)$？
::: sol 答案
两行模长各为 $1$、内积 $(-1+1)/2=0$，故 $Q^{\mathrm T}Q=I_2$，**正交**；$\det Q=\frac12\bigl(1-(-1)\bigr)=1$，故 $Q\in SO(2)$（它是绕原点转 $-45^{\circ}$ 的平面旋转）。

**诊断含义**：旋转矩阵的两条性质「正交 + $\det=+1$」必须成为条件反射。只记得「转置等于逆」而忘了行列式，就回 [2.2](ch02/sec2-2.md) 重读「两个符号各有归属」一段。
:::
:::

::: ex A3 · 特征值
$A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ 的特征值是什么？它在几何上表示什么变换？
::: sol 答案
$\det(A-\lambda I)=\lambda^{2}+1=0\Rightarrow\lambda_{1,2}=\pm\mathrm i$（一对共轭纯虚根）。$A$ 就是 2 维版的 $R_z(90^{\circ})$。

**诊断含义**：实旋转矩阵的复特征值总是**成对共轭、模为 1**，因此除 $\vartheta=0,\pi$ 外**没有实特征向量**（没有一条实轴被保持方向）。这条直觉是「为什么求 $R$ 的逆要绕一圈走角和轴 / 四元数」的入口（[2.5](ch02/sec2-5.md)、[2.6](ch02/sec2-6.md)）。想不到这一点，线代需要补一轮。
:::
:::

::: ex A4 · 多元微分
$f(\boldsymbol x)=\lVert\boldsymbol x\rVert^{2}=\boldsymbol x^{\mathrm T}\boldsymbol x$（$\boldsymbol x\in\mathbb{R}^{n}$）。求梯度 $\nabla f(\boldsymbol x)$。
::: sol 答案
$\nabla f=2\boldsymbol x$。逐分量看最清楚：$f=\sum_ix_i^{2}$，故 $\partial f/\partial x_i=2x_i$。

**诊断含义**：这个结果会在三处反复出现——速度合成里对位置求导、伪逆的最小范数解、零空间项 $k_0(\partial g/\partial\boldsymbol q)^{\mathrm T}$ 的构造（[3.4](ch03/sec3-4.md)）。梯度指向 $f$ 增长最快的方向，其模长是该方向的方向导数。
:::
:::

::: ex A5 · 一阶小量
写出 $e^{x}$ 在 $0$ 处的二阶 Taylor 展开与余项量级；写出 $\cos\epsilon$ 与 $\sin\epsilon$ 的一阶小量近似（$|\epsilon|\ll1$）。
::: sol 答案
$$e^{x}=1+x+\frac{x^{2}}{2}+O(x^{3}),\qquad \cos\epsilon\approx1-\frac{\epsilon^{2}}{2}\approx1,\qquad \sin\epsilon\approx\epsilon.$$

**诊断含义**：这就是「**微小旋转在忽略二阶效应时像向量一样可加**」的代数根源——$R_k(\mathrm d\vartheta)=I+S_k\,\mathrm d\vartheta+O(\mathrm d\vartheta^{2})$，两个一阶项相加可交换。微分运动学整章都建立在这条近似上（[2.3.2](ch02/sec2-3.md#sec-2.3.2)、[3.1](ch03/sec3-1.md)）。
:::
:::

::: ex A6 · 一阶线性常微分方程
解 $\dot y+\dfrac{1}{T}y=\dfrac{k}{T}u$（$u$ 为常数，$y(0)=0$），给出稳态值 $y_\infty$ 与时间常数。
::: sol 答案
$y(t)=ku\bigl(1-e^{-t/T}\bigr)$，故 $y_\infty=ku$，时间常数就是 $T$（经 $T$ 达终值的 $63.2\%$，经 $3T$ 达 $95\%$）。

**诊断含义**：放大器的一阶惯性 $\dfrac{V_a}{V_c}=\dfrac{G_v}{1+sT_v}$ 与直流的机械时间常数 $T_m=\dfrac{R_aI_m}{k_vk_t}$ 是同一条曲线。这题会做，[5.2.1](ch05/sec5-2-1.md) 的四个方程就只是代数整理。
:::
:::

## B 组 · 力学与空间直觉（6 题，每题 1 分）

::: ex B1 · 坐标变换
点 $P$ 在坐标系 $O'$ 中的坐标为 $\boldsymbol p'=(1,0,0)^{\mathrm T}$；$O'$ 相对参考系 $O$ 的旋转矩阵 $R=\begin{bmatrix}0&0&1\\1&0&0\\0&1&0\end{bmatrix}$，$O'$ 原点在 $O$ 中位于 $\boldsymbol o'=(2,1,0)^{\mathrm T}$。求 $P$ 在 $O$ 中的坐标。
::: sol 答案
$\boldsymbol p=R\boldsymbol p'+\boldsymbol o'$。$R\boldsymbol p'$ 就是 $R$ 的**第一列** $=(0,1,0)^{\mathrm T}$，故 $\boldsymbol p=(2,2,0)^{\mathrm T}$。

**诊断含义**：这是齐次变换的作用规则（**先转、再加平移**），也是「$R$ 的第 $j$ 列 = 系 $j$ 的 $x_j$ 轴在参考系中的方向余弦」的活用（[2.7](ch02/sec2-7.md)）。
:::
:::

::: ex B2 · 旋转的合成
从姿态 $R_z(90^{\circ})$ 出发，再绕**新的** $y'$ 轴（即旋转后坐标系自己的 $y$ 轴）转 $90^{\circ}$。写出最终的旋转矩阵。
::: sol 答案
绕当前（动系）轴转用**右乘**：$R=R_z(90^{\circ})R_y(90^{\circ})=\begin{bmatrix}0&-1&0\\0&0&1\\-1&0&0\end{bmatrix}$。（自查：三列两两正交、模长各 $1$、$\det R=+1$。）

**诊断含义**：口诀「**右乘当前轴、左乘固定轴**」是第二章的母规则——ZYZ、RPY、DH 的 $A_i$ 连乘、角和轴的五步序列都是它的换装登场。记反了，第二章后面每道题都会错（[2.3](ch02/sec2-3.md)）。
:::
:::

::: ex B3 · 哪些矩阵是旋转矩阵
$I_3$ 与 $-I_3$ 中哪个是旋转矩阵？另一个是什么？为什么不能叫「转 $180^{\circ}$」？
::: sol 答案
$I_3$ 是（$\det=+1$）；$-I_3$ 的 $\det=-1$，是**中心反演（镜像）**，不属于 $SO(3)$。「转 $180^{\circ}$」的公式是 $R(\pi,\boldsymbol r)=2\boldsymbol r\boldsymbol r^{\mathrm T}-I_3$，它需要一条实轴 $\boldsymbol r$ 被映到自己；$-I_3$ 把每个向量都反向，没有这样的轴。

**诊断含义**：$\det R=+1$ 不是装饰性约定，它承担「排除镜像」的筛选功能。凡由「三个正交向量」拼出的矩阵，都要查这一个数（[2.2](ch02/sec2-2.md)、[2.5](ch02/sec2-5.md)）。
:::
:::

::: ex B4 · 力臂与力矩
一根长 $L=0.5$ m 的无质量杆，一端铰接在原点，另一端受 $F=20$ N 的力。分别求：(a) 力垂直于杆时对铰点的力矩；(b) 力沿杆方向（推 / 拉）时对铰点的力矩。
::: sol 答案
(a) 力臂等于力的作用线到铰点的垂直距离 $L$，故 $M=FL=0.5\times20=10\ \mathrm{N\cdot m}$。(b) 力臂为零（力线穿过铰点），故 $M=0$。

**诊断含义**：这就是雅可比移动行 $J_{P_i}=z_{i-1}\times(\boldsymbol p_e-\boldsymbol p_{i-1})$ 的物理原型——**叉乘里那个矢径就是力臂**。理解力臂才能理解「为什么某些位形下关节再怎么出力也推不动末端」（[3.1](ch03/sec3-1.md)、[3.8](ch03/sec3-8.md)）。
:::
:::

::: ex B5 · 角速度与线速度
刚体绕过原点的 $z$ 轴以 $\omega=4\ \mathrm{rad/s}$ 旋转。刚体上一点位于 $(0.3,0,0)$（单位 m）。求该点的线速度向量。
::: sol 答案
$\boldsymbol v=\boldsymbol\omega\times\boldsymbol p=(0,0,4)\times(0.3,0,0)=(0,\ 1.2,\ 0)\ \mathrm{m/s}$。

**诊断含义**：$\boldsymbol v=\boldsymbol\omega\times\boldsymbol p$ 是 $\dot R=S(\boldsymbol\omega)R$ 的几何图像，也是雅可比角速度行 $J_{O_i}=z_{i-1}$ 的来历。手算叉乘不过关，第三章的逐列构造就会退化成抄公式（[3.1](ch03/sec3-1.md)）。
:::
:::

::: ex B6 · 自由度与工作空间
(a) 刚体在平面上、空间中各有几个自由度？(b) 只有两个转动关节的平面臂，末端能否到达工作区域内**任意**位置？
::: sol 答案
(a) 平面刚体 $3$ 个（两平移 + 一转动），空间刚体 $6$ 个（三平移 + 三转动）。(b) **不能**。两个转动关节只有 $2$ 个自由度，末端落在二维平面内的**一维曲线**上，覆盖不了区域。

**诊断含义**：这条区分了「关节空间维数」与「任务维数」——只有 $n$ 与任务实际维数 $r$ 的关系才对得上号，$n>r$ 即冗余（[2.10](ch02/sec2-10.md)）。它也是「可达工作空间 ≠ 灵活工作空间」的第一课（[1.2](ch01/sec1-2.md)）。
:::
:::

## C 组 · 编程与工具（5 题，每题 1 分）

::: ex C1 · NumPy 的形状规则
`A = np.random.rand(3,4)`、`B = np.random.rand(4,2)`。`A @ B` 的形状是什么？写成 `A * B` 会发生什么？
::: sol 答案
`A @ B` → `(3, 2)`（矩阵乘）。`A * B` 是**逐元素乘**，需要广播：`(3,4)` 与 `(4,2)` 无法对齐，抛 `ValueError`（broadcast 失败）。

**诊断含义**：`@` 与 `*` 的差别是本书数值实验里最常见的错误。形状刚好兼容时矩阵乘错了**不会报错**，只会静默给出错误结果——比报错更危险。
:::
:::

::: ex C2 · 把公式翻译成代码
用 NumPy 写一个函数 `Rz(t)`，返回绕 $z$ 轴转 $t$ 的 $3\times3$ 旋转矩阵。
::: sol 答案
```python
import numpy as np

def Rz(t):
    c, s = np.cos(t), np.sin(t)
    return np.array([[c, -s, 0.0],
                     [s,  c, 0.0],
                     [0.0, 0.0, 1.0]])
```

**诊断含义**：注意写 `0.0` 而不是 `0`——否则整张矩阵的 dtype 会被隐式转换，后续精度判断容易出意外。这题写不出，各章习题集的「数值验证」类题目（[第二章 C1](ch02/exercises.md)）都要先补 Python 基础。
:::
:::

::: ex C3 · 合法性自检
给定一个 $3\times3$ 矩阵 `R`，写一两行代码判断它是否是合法旋转矩阵，并说明容差取多大。
::: sol 答案
```python
ok = np.allclose(R @ R.T, np.eye(3), atol=1e-10) and abs(np.linalg.det(R) - 1.0) < 1e-10
```
容差取 $10^{-10}$ 量级：双精度下几十步乘加的累积误差在 $10^{-15}$ 量级，留五个数量级余量既能容下正常误差、又能挡住离谱的矩阵。**不要**用 `==` 比较浮点。

**诊断含义**：本书的验算习惯是「每个解析解回代正运动学，每个 $R$ 查 $R^{\mathrm T}R=I$、$\det R=1$」。不会写这个自检，等于放弃对自己结果的第一次把关（[2.2](ch02/sec2-2.md)）。
:::
:::

::: ex C4 · 数值导数
写出用中心差分近似 $\left.\dfrac{\mathrm df}{\mathrm dx}\right|_{x_0}$ 的公式，并说明它为什么比前向差分准。
::: sol 答案
$$\left.\frac{\mathrm df}{\mathrm dx}\right|_{x_0}\approx\frac{f(x_0+h)-f(x_0-h)}{2h},$$
截断误差 $O(h^{2})$；前向差分 $\dfrac{f(x_0+h)-f(x_0)}{h}$ 只是 $O(h)$——中心差分把一阶误差项对消掉了。

**诊断含义**：这是「用中心差分校验任何一个亲手推导的雅可比」的工具（[3.1](ch03/sec3-1.md) 小结、[第三章 C1](ch03/exercises.md)）。$h$ 不能太小（会被舍入误差吃掉），工程上取 $10^{-6}$ 数量级。
:::
:::

::: ex C5 · 把结果画出来
要在同一张图上展示一条关节轨迹 $q(t)$ 与它的速度 $\dot q(t)$。你会怎么排布？最容易犯的两个错是什么？
::: sol 答案
**排布**：分成上下两个子图、共享横轴（位置一张、速度一张）——两者**单位不同**（rad 与 rad/s），量级常差一个数量级以上。**两个常见错**：① 画在同一纵轴上，小量被压成直线；② 不标单位、不加图例，看过一遍等于没看。

**诊断含义**：教材图 4.1（三次多项式）与图 4.3（梯形速度曲线）都是「位置 + 速度」双图。判断一条轨迹是否满足约束、加速度在哪跳跃，全靠这张图（[4.2.1](ch04/sec4-2-1.md)）。
:::
:::
