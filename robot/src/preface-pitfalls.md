# 易错点总表

正文每节末尾都有一份「常见错误清单」，共 64 组、约 230 条。它们分散在各节时容易变成墙纸——本页把它们**按「错在什么心智模型上」重新归组**（19 组），并配一套判断题做主动回忆。

::: note 怎么用这一页
- **和正文里那份的关系**：各节末尾的「常见错误清单」是**就地提醒**——读完那一节立刻自查用；本页是按「错在什么心智模型上」**重新归组**的复习版，把散在 64 个小节里的同一类错误并到一起。两者内容对应、用途不同，不必都读。
- **读完一章后**：扫一遍对应主题组，把「我确实这么想过」的条目抄进笔记——错误清单的价值在于认领，不在于读完。
- **考前**：直接做末尾的 44 道判断题。遮住答案逐条判断，错了再回正文。
- **每条后面的编号**可跳回正文该节的完整清单与推导。
:::

## 一、按主题归组的易错点

### 组 1 · 上下标与约定（第二章最贵的错误）

| 错法 | 正解 |
|:--|:--|
| 把 $R_1^0$ 的上下标读反 | **上标是参考系、下标是被描述对象**：$R_1^0$ 的**列**是系 1 的轴在系 0 中的像。顺口令：$A$ 的右上块 =「动系原点用固定系的话说」 |
| 把方向余弦说成「夹角」 | 是**夹角的余弦**，取值 $[-1,1]$，符号携带朝向信息 |
| 只说旋转“逆时针”而不定视线 | 从转轴正端朝原点看，逆时针才是右手正方向（[§2.2](ch02/sec2-2.md#sec-2.2.2)） |
| 模长没变就认为坐标变换正确 | $R$ 与 $R^{\mathrm T}$ 都保长；先写清输入/输出在哪个系，再检查 $\pm90^\circ$ 的方向（[数值对照](ch02/sec2-2.md#ex-2.2.compare)） |
| 给出位置和一根工具轴就当完整位姿 | 绕工具轴的滚转仍未确定；须说明完整固连系的朝向（[§2.1 练习 2](ch02/sec2-1.md#practice-2.1.handedness)） |
| 把点与自由方向一起加平移 | 位置坐标随原点改变；同向平移坐标系时，自由方向分量不变（[§2.1 练习 1](ch02/sec2-1.md#practice-2.1.point)） |
| 以为 $\det R$ 取 $\pm1$ 无所谓 | $\det R=-1$ 是左手系（含镜像），不属于 $SO(3)$，用它会得到「照镜子」的假姿态 |
| 对 A 整体转置当逆 | 非零平移时不成立；统一用 $[R^{\mathrm T},-R^{\mathrm T}o;0,1]$，零平移是整体正交的特例 |
| 把 $R^{-1}=R^{\mathrm T}$ 推广到任意矩阵 | 所有正交矩阵均有此性质；一般含平移的齐次变换不满足，须用分块逆公式 |

出处：[2.1](ch02/sec2-1.md)、[2.2](ch02/sec2-2.md)、[2.7](ch02/sec2-7.md)。

### 组 2 · 旋转合成方向

| 错法 | 正解 |
|:--|:--|
| 背错乘法方向 | **右乘当前轴、左乘固定轴**。检验法：把序列复述成中文——「在转完的基础上再绕它的 $y'$ 转」= 右乘 |
| 倒序时省略初始姿态 | 从 $I$ 出发，固定轴与轴角成对倒序的当前轴序列终态相同；一般 $R_0$ 会分别留在乘积右端与左端，不保证相等 |
| 用角度三元组相加代替旋转合成 | 数值三元组可以逐分量相加、在选定连续分支上局部插值，但加法一般不对应矩阵乘积，不能作为全局姿态合成规则 |
| 混淆五步构造与净角轴旋转 | β 从 +z 量起；五步全绕固定轴依次左乘，第 3 步只在辅助姿态绕 z，第 5 步才得到净旋转 |
| 半圈只开三个正平方根 | 对角线只给绝对值，必须用交叉项确定相对符号；整体反号才等价 |
| 把零角的轴任意叫作 exp 多值 | exp 单值但非单射；零角主向量为 0，半圈主轴有 ± 两选 |
| 把角速度称为 so(3) 矩阵 | ω 是向量；S(ω)=ṘRᵀ 才是反对称矩阵 |

出处：[2.3](ch02/sec2-3.md)、[2.5](ch02/sec2-5.md)。

### 组 3 · 欧拉角与反解

| 错法 | 正解 |
|:--|:--|
| 认为 Atan2 能消除所有反解问题 | 它保留象限，但输入半径趋零仍病态，原点无方向；$\arccos$ 在预选 $[0,\pi]$ 主支可用，单独用余弦则不足以判断完整象限 |
| 忘记 ZYZ / RPY 各有**两支**解 | 两支效果等价但角度值不同；编程时须固定取值区间 |
| 把 RPY 的「滚转」配给绕 $z$ 的角 | 滚转（roll）绕**纵轴 $x$**，偏航（yaw）绕**竖轴 $z$**（英文原书与课件此页标签均反，见[勘误 E2.1](ch02/errata.md)） |
| 在 $s_\vartheta=0$ 附近强行分离 $\varphi,\psi$ | 数据上表现为两角剧烈跳变——这是**表示奇点**，不是物理抖动 |
| 认为换成四元数后表示完全唯一 | $Q$ 与 $-Q$ 表示同一旋转；$\eta\ge0$ 在 $\eta=0$ 时仍不能消除符号二义性，选代表还须说明边界规则 |
| 忘记四元数的单位约束 | 已确认表示旋转时可归一化；零四元数必须拒绝，数值积分后的单位长度仍需检查 |
| 只检查提取轴的单位长度就认定 R 合法 | 还须检查 $R^{\mathrm T}R=I$ 与 $\det R=1$；归一化轴不能修复输入矩阵 |
| 认为「4 个参数比欧拉角多所以更差」 | 四元数方便合成与插值，但提取须选稳定支路、跟踪须对齐符号；参数个数不是唯一判断标准 |

出处：[2.4](ch02/sec2-4.md)、[2.5](ch02/sec2-5.md)、[2.6](ch02/sec2-6.md)。

### 组 4 · DH 建系与正运动学

| 错法 | 正解 |
|:--|:--|
| $z_i$ 配错关节 | **$z_{i-1}$ 沿关节 $i$ 的轴**。$i<n$ 时系 $i$ 放在关节 $i+1$ 轴上，末杆系另选；读其他约定须同时查编号与因子顺序（见[勘误 E2.4](ch02/errata.md)） |
| $\alpha_i$ 符号凭感觉 | 用右手定则，绕 $x_i$ 从 $z_{i-1}$ 转到 $z_i$；从 $+x_i$ 端朝原点看，逆时针为正 |
| 移动关节还让 $\vartheta_i$ 当变量 | 变量只能有一个；类型判定的唯一依据是**关节**，不是杆的形状 |
| 漏掉或写反基座/工具 | $T_e^b=T_0^bT_n^0T_e^n$，从右向左是 e→n→0→b；$T_b^0$ 为反向变换 |
| 对带腕拟人臂强行 $T_{\text{臂}}T_{\text{腕}}$ 相乘 | **接口不齐**，结果错且难察觉；正确动作是整体重建系或插常值变换 |
| 忘记零位约定与编程零位的常值漂移 | 读任何 DH 表先问「标准还是改进」，先对零位约定再对数 |
| 平行 P 关节每帧重放原点，把 $d_i$ 消掉 | 系须固连各杆；参考行程选好后，$d_i$ 必须保留活动量 |
| 换 DH 系就要求 $T_n^0$ 不变 | 中间系可变；统一物理基座、工具与关节零位并补偿常值变换后，$T_e^b$ 才一致 |
| 轴平行就断言 $a=d=0$ | 同向平行给出 α=0；a 是轴距，d 还取决于固连原点；同轴才保证轴距为零 |
| 拟人臂的 $z_2,z_3$ 同向就叫重合 | $a_3>0$ 时两条平行轴分开，矩阵列只报告方向 |
| 球形腕的关节角无条件等于 ZYZ | 先核对本表扭角、轴向与零位；共点本身不足，第二角为 0/π 时另查奇异 |

出处：[2.8](ch02/sec2-8.md)、[2.9](ch02/sec2-9.md)。

### 组 5 · 工作空间、冗余与精度

| 错法 | 正解 |
|:--|:--|
| 把位置可达当成姿态或路径可行 | 固定参考点的可达位置只需一种方向；灵活性须满足规定方向集合，路径还须另查限位、连通与碰撞 |
| 认为 6 自由度机械手对任何任务都「刚好」 | 激光切割（$r=5$）就是**功能冗余**的日常反例 |
| 混淆精度与重复定位精度 | 定位精度比较实际到达与指令目标；重复定位精度描述同条件回访的集中程度。小散布可以伴随大目标偏差，比较指标须统一测试口径 |
| 用 $m$ 而不是 $r$ 判冗余 | 冗余相对**任务**：$n=m=3$ 的平面臂对定位任务（$r=2$）已是冗余 |
| 忘了按任务构造 $J$ 并检查秩 | 一般瞬时核维数是 $n-\operatorname{rank}J_{\rm task}$；任务行满秩时才是 $n-r$，奇异点的核不保证有限自运动 |
| 将关节域周界的像当成整个工作空间 | 工作空间是整个域的像；轮廓还要检查内部临界集合，且候选像可能在内部。全转 2R 的 $q_2=0$ 是域内水平线 |
| 以为自由度越多越好 | 冗余带来灵活性，也带来更高的控制与标定成本 |

出处：[2.10](ch02/sec2-10.md)、[3.4](ch03/sec3-4.md)、[1.2](ch01/sec1-2.md)。

### 组 6 · 逆运动学

| 错法 | 正解 |
|:--|:--|
| 忘记从 $\boldsymbol p_e$ 里扣掉 $d_6\boldsymbol a_e$ 直接解臂 | 先算**腕心** $\boldsymbol p_w=\boldsymbol p_e-d_6\boldsymbol a_e$；$d_6\neq0$ 时不扣就全错 |
| 平方相加后只写 $c$ 不写 $s$ 的符号分支 | 丢掉整支解（肘上/肘下、肩左/肩右） |
| 在 $c_2\notin[-1,1]$ 时继续往下算 | 这是「给定点在工作空间外」，应报告**无解**而不是硬套 Atan2 |
| 把球形腕的解当独立问题硬推 | 先查旋转块是否恰为某个欧拉角矩阵——**球形腕 = ZYZ 反解** |

出处：[2.12](ch02/sec2-12.md)。

### 组 7 · 雅可比构造

| 错法 | 正解 |
|:--|:--|
| 把 $z_{i-1}$ 预设成 $[0,0,1]^{\mathrm T}$ | 从 $R_{i-1}$ 第三列读取基系轴向；平面平行轴可以恰好都等于该向量，一般情况不能预设 |
| 转动关节列叉乘方向写反 | $J_{P_i}=z_{i-1}\times(\boldsymbol p_e-\boldsymbol p_{i-1})$，矢径从**关节轴上的点**指向末端；写反差一个负号 |
| 把通用三项递推的牵连项写成 $\omega_i\times r$ | 通用式用 $\omega_{i-1}$；转动关节加上相对项、合并后才得到 $\omega_i\times r$ |
| 认为转动关节的 DH 平移列恒定 | 标准 DH 中 $r^{i-1}=[a_i\cos\vartheta_i,a_i\sin\vartheta_i,d_i]^{\mathrm T}$，故 $\dot r^{i-1}=\dot\vartheta_i z^{i-1}\times r^{i-1}$，一般不为零 |
| 不含工具偏置就直接取末端位置 | 应从 $T_e^0=T_n^0T_e^n$ 取 $p_e$；固连工具通常改变转动列的位置块，不改变角速度块 |
| 把局部相对角速度直接当成基系量相加 | 先写 $\omega_{i-1,i}^{i-1}$，再乘 $R_{i-1}$ 变成基系量；同一坐标系后才能相加 |
| 认为 $\omega_e\neq\omega_n$ | 末端执行器与连杆 $n$ 之间无关节变量，两者角速度**相同** |
| 斯坦福第 3 列误取转动列 | $q_3=d_3$ 是**移动**关节，$J_3=[z_2;\ 0]$，角速度行是零 |
| 拟人臂忘了 $z_1\neq z_0$ | 肩部 $\pi/2$ 扭转后关节 2、3 的轴水平（$[s_1,-c_1,0]^{\mathrm T}$），不随 $\vartheta_2,\vartheta_3$ 变、但**随 $\vartheta_1$ 变** |
| 平面臂保留全部六行做运算 | 第三、四、五行恒为零，先选有效行，行列式与秩的讨论才有意义 |

出处：[3.1](ch03/sec3-1.md)、[3.2](ch03/sec3-2.md)。

### 组 8 · 奇点与冗余

| 错法 | 正解 |
|:--|:--|
| 把奇点当「数值 bug」 | 固定任务下的实际降秩不会因提高精度而消失；规划绕行、减速或容许受控误差分别改变路径、节拍或精度 |
| 未转换参考点就混用速度指令 | 腕心与工具点的完整六维速度映射可逆；控制腕心可用 $J_w$，工具点指令须先作参考点转换 |
| 忘了「邻域」二字 | 最小奇异值很小时，困难方向的非零速度分量可能要求很大关节速度；结合任务方向与限速判断 |
| 把 $P\dot{\boldsymbol q}_0$ 当作误差修正项 | 它对末端速度的贡献**恒为零**，只改内部姿态；「干活」永远靠第一项 $J^\dagger\boldsymbol v_e$ |

出处：[3.3](ch03/sec3-3.md)、[3.4](ch03/sec3-4.md)。

### 组 9 · 逆微分运动学

| 错法 | 正解 |
|:--|:--|
| 对冗余臂硬求 $J^{-1}$ | $r\times n$ 长方阵**没有逆**，要用广义逆：方阵求逆、矮胖求伪逆、退化加阻尼 |
| 忘了 $JW^{-1}J^{\mathrm T}$ 可逆的前提是 $J$ **行满秩** | 奇点情形必须换 DLS，老配方失效 |
| 混淆 $J^\dagger$ 与 $J^{-1}$ | $J^\dagger=J^{\mathrm T}(JJ^{\mathrm T})^{-1}$ 是右伪逆（$r<n$）；$J^*$ 是奇异情形广义逆——三者对应三种「不方 / 退化」 |

出处：[3.5](ch03/sec3-5.md)。

### 组 10 · 分析雅可比

| 错法 | 正解 |
|:--|:--|
| 把 $J_A$ 与 $J$ 的差别当「笔误」 | 两者**角速度行不同是本质差异**（换基），线速度行才相同 |
| 直接用 $\dot\varphi$ 积分做姿态更新 | $\varphi$ 可积但非线性；工程上通常仍走旋转矩阵 / 四元数 |
| 在 ZYZ 奇点只怪欧拉角「反解跳变」 | $J_A$ 本身也在此失效（$T$ 不可逆），二者同源 |

出处：[3.6](ch03/sec3-6.md)。

### 组 11 · 静力学

| 错法 | 正解 |
|:--|:--|
| 用 $J^{-1}$ 或 $J^\dagger$ 传力 | 力变换是 $J^{\mathrm T}$（**对偶**），不是逆；长方阵也成立 |
| 忘记力的坐标系 | $F_e$ 与 $J$ 必须在**同一坐标系**下；传感器力要先变换到基系 |
| 把 $\tau=J^{\mathrm T}F_e$ 用于动态 / 高速情形 | 它是**静力**平衡式；含惯性、科氏力时须回到动力学方程 |

出处：[3.8](ch03/sec3-8.md)。

### 组 12 · 标定

| 错法 | 正解 |
|:--|:--|
| 以为一轮线性化就能得到最终参数 | $k$ 非线性，$\Phi$ 与 $\Delta\boldsymbol x$ 都随参数更新而变，**必须迭代** |
| 量测位姿取位「太整齐」 | 全挤在工作空间一隅会让 $\Phi^{\mathrm T}\Phi$ 接近奇异；量测应铺满工作空间并富余（$tm\gg p$，其中 $p\le4n$ 是实际未知数） |

出处：[2.11](ch02/sec2-11.md)。

### 组 13 · 第一章的概念边界

| 错法 | 正解 |
|:--|:--|
| 把机器人想象成人形机器 | 定义「**无关其外表**」；工业领域以臂状机械手为绝对主力 |
| 认为三定律是真实的法律或技术标准 | 它是科幻行为规则；工程要求还须说明危险检测、停止条件与验证方法 |
| 把「自动化」等同于「机器人」 | 专用自动设备也可能有反馈；闭环不是机器人分类的充分条件，须明确分类口径 |
| 以为控制系统只是「写程序」 | 控制服从**反馈原理**，与人体功能控制同构 |
| 数自由度时把关节数直接相加 | 开链可直接计数，**闭链必须先列独立约束** |
| 把 SCARA 当「三轴拟人」 | SCARA 三轴**平行**；拟人型后两轴平行、首轴垂直——工作空间与柔性完全不同 |
| 认为精度只取决于控制器 | 构形影响误差传播，实际精度还受标定、载荷和温度等影响；正交 PPP 的理想模型不保证实机处处同精度 |
| 只按驱动方式给车轮分类 | 先按轴几何区分定轮、导向轮、自位轮，再分别记录牵引和转向驱动 |
| 以为「不能即时横移 = 不能横移」 | 速度约束不等于固定位置等式；空间和障碍仍决定具体路径是否可行 |
| 忽略阿克曼几何 | 汽车式前两轮方向不一致是**避免滑动**的机构要求，不是工艺误差 |
| 数移动机器人自由度时直接数轮子 | 应数**容许瞬时运动的方向数**，它与位形变量数（平面刚体 3）未必相等 |
| 引用行业数据不注年份 | 原书数据属于 2005–2007 年资料；必须保留年份、地区与统计对象，预测不当作已验证结果 |
| 把四个部署问题排成先进程度 | 环境先验、变化速度、风险后果与决策分工分别分析；感知需求增加不证明任务决策更自主 |
| 只算工件质量或只看峰值速度 | 工具与附件也计入负载并检查重心、惯量；产能按完整循环及等待计算 |
| 以为并联机器人「全方位更好」 | 并联设计常在可达范围与刚度、速度之间取舍，须按具体机构和载荷核查 |
| 把球形腕的腕心当工具点 | 固定臂时转腕只保证腕心 W 不动；偏置工具点 P 可移动，先由目标工具位姿计算腕心 |
| 以为先进机器人 = 人形机器人 | 关键是**环境不确定性与自治范围**，不是形态 |
| 把运动学与动力学混谈 | 运动学**不含力**，动力学才是力与运动的关系 |
| 以为规划只是「找路径」 | 轨迹还给时间律；运动规划检查任务与约束，端点可达不证明中间避碰 |
| 以为模型够准或闭环就保证准确 | 模型有遗漏，反馈也受稳定性、测量偏差和执行限制影响；测量零误差不等于实际零误差 |
| 把所有移动平台都当作输入不足 | 差动底盘是两个输入、三个位形变量的实例；全向平台须按其约束另行分析 |

出处：[第一章各节](ch01/overview.md)。

### 组 14 · 轨迹规划的概念与选型（第四章前半）

| 错法 | 正解 |
|:--|:--|
| 把路径当轨迹 | 差一个**时间律**——轨迹必须能说出每点的速度或加速度 |
| 以为「平滑」只有一个档次 | 位置 / 速度 / 加速度的连续性分三档；要求的阶次越高，对电机的要求反而**越低**，代价是算力 |
| 约束数与阶次不匹配 | 三次 4 个系数只能给 4 个条件；要指定初终**加速度**必须升到五次（6 个条件） |
| 用五次多项式还声称能量最优 | 最小能量解**只能是三次**；选五次就放弃了该指标 |
| 把 $t_c$ 当 $t_f/2$ | $t_c\le t_f/2$ 只是上界；等号对应**三角形**速度曲线（无巡航段） |
| 忘了 $\operatorname{sgn}\ddot q_c=\operatorname{sgn}(q_f-q_i)$ | 加速度符号必须与位移同号，否则 (4.6) 的根无意义 |
| 让用户指定总时间 $t_f$ | 工业上给的是**最大速度 / 加速度的百分比**，避免用户给出不可实现的短周期 |

出处：[4.1](ch04/sec4-1.md)、[4.2.1](ch04/sec4-2-1.md)。

### 组 15 · 系列点插值与操作空间（第四章后半）

| 错法 | 正解 |
|:--|:--|
| 用单个高阶多项式穿过所有点 | 五个缺点（振动、数值精度、求解繁难、全局耦合、不能指定端点速度）；改用分段低阶 |
| 把样条说成「光滑插值」 | 样条的**定义性特征**是**加速度连续**；只保证速度连续的是「指定速度 / 计算速度」两法 |
| 给虚拟点赋位置值 | 虚拟点**不指定位置**，只施加位置 / 速度 / 加速度的连续性约束 |
| 直接解样条的 $4(N+1)$ 元系统 | 必须降维：位置指定值 + 位置 / 加速度连续性 ⇒ $N$ 个未知量 ⇒ 三对角系统 (4.28)，且 $A$ 与关节无关 |
| 把经由点当路径点 | 抛物线混合下 $q(t)$ **不到达**路径点，只从附近经过；混合加速度越大越贴近 |
| 多段直线路径以为能自动平滑通过 | 不共线分段在路径点处速度必跳跃——要么削角（经由点），要么接受停顿 |
| 把 $\dot s$ 当速度向量 | $\dot s$ 是速度的**模**（带符号），方向由切向 $t$ 提供 |
| 圆弧只算切向加速度 | 漏掉 $\dot s^2/\rho$ 的**向心**项；曲率越大漏得越多——这正是曲率大处要限速的原因 |
| 直接对旋转矩阵逐元素插值 | 中间矩阵不再正交，不是旋转矩阵；必须换表示（欧拉角 / 角和轴） |
| 欧拉角插值后忘换回基系 | 插出的是 $\boldsymbol\varphi_e$，控制要的是 $\boldsymbol\omega_e$，中间必须过 $T(\boldsymbol\varphi_e)$（且 $T$ 有奇点） |

### 组 16 · 执行系统与传动装置（第五章前半）

| 错法 | 正解 |
|:--|:--|
| 把功率放大器当「信号放大器」 | 放大的是**功率**：$P_e$ 供能量，$P_c$ 只决定「取多少」——正因此功率增益能到 $10^6$ |
| 忽略传动装置的损失 $P_{dt}$ | 算总效率要用 $P_u/P_a=\eta_m\eta_t$，不能只看电机效率 |
| 以为理想传动装置改变功率 | 无间隙刚性传动**不改变功率**，只重新分配力与速度；损失才体现为 $P_{dt}$ |
| 只记住「减速增矩」 | 传动装置还有**定性变换**（转动→平动）与**减重解耦**（发动机后置）两个作用，老师反复强调 |
| 把直驱当「更先进所以更好」 | 直驱换来的是**无弹性无间隙**，代价是**控制复杂度**（失去减速后非线性耦合无法忽略）；工业上并不普遍 |
| 选传动装置不看工况 | 同步带适合**高速低矩**（轻，但橡胶带矩大会变形），正时链适合**低速高矩**（钢质，但质量大高速会颤） |
| 把步进电机的优点说成「精度高」 | 它的特点是**不需要转角位置测量**（开环可控）；代价是动态性能受载荷影响、会引起结构振荡 |
| 混淆换向器与静态整流器 | 有刷的**换向器**是机械的（靠电刷），无刷的**静态整流器**是电子的（靠位置传感器 + 控制模块） |

### 组 17 · 驱动建模与传感器（第五章后半）

| 错法 | 正解 |
|:--|:--|
| 把 $k_v$ 与 $k_t$ 当成两个独立参数 | 标准国际单位下**数值相等**（$k_t=k_v$）——这是 (5.12)(5.13) 化简的前提 |
| 认为「加了电流反馈一定更好」 | 恰恰相反：**独立关节控制不加更好**（干扰增益 $R_a/(k_vk_t)\ll1/F_m$），集中控制才需要 |
| 忘记放大器时间常数的量级 | $T_v$ 在 $10^{-5}$–$10^{-4}$ s，比机械时间常数小几个数量级——这才使降阶模型成立 |
| 液压驱动漏掉 $Q_l$ 与 $Q_c$ | 渗漏与可压缩性是液压区别于电气的**核心动态项**，100 atm 级下不可忽略 |
| 把 $k_c=\gamma V$ 当常数 | 只有**旋转式**是常数；**直线式**流体体积随行程变，响应取决于工作点 |
| 混淆伺服阀与分布器 | 伺服阀可当一阶惯性（$T_c$ 毫秒级可忽略），分布器是**强非线性**、必须线性化 |
| 两个折算因子写反 | **惯量与摩擦按 $1/k_r^2$**，**负载力矩与非线性按 $1/k_r$**——前者是速度的系数，后者是外力 |
| 摆的例子里 $k_r$ 只出现在一处 | 正确形式 $\dfrac{mgl}{k_r}\sin\dfrac{\vartheta_m}{k_r}$：**幅值**与**自变量**各被缩小一次 |
| 位置环只写「PI 控制器」说不出分工 | **积分管稳态**（消除干扰影响）、**比例管稳定与阻尼**（前向通路有两个原点极点） |
| 以为测速反馈只是「多测一个量」 | 它的实质是**多一个反馈回路**——故瞬态干扰也被抑制，带宽更宽、振荡更少 |
| 把编码器分辨率当精度 | 量化分辨率 $2\pi/2^n$ 只是**能分辨的最小增量**；精度还受偏心、回弹、码盘工艺限制 |
| 忘格雷码的用途 | 它让相邻码字**只变一位**，避免多轨同时翻转产生的过渡错码 |
| 力传感器读数直接当末端力用 | 传感器测的是**作用在传感器上的等价力**，与末端受的力不同；必须经 (5.32) 换到**约束坐标系** |
| 声纳测距忘除以 2 或忘温度修正 | $d=vt/2$（回波走了往返）；$v\approx331.4+0.6T$，$0\to25^{\circ}\mathrm{C}$ 就有 4.5% 漂移 |
| 相机投影省掉除以深度 | $X_I=x_I/\lambda$ 中的 $\lambda$ 不能省——省了就是把归一化平面当像素平面 |

### 组 18 · 动力学建模与结构性质（第六章）

| 错法 | 正解 |
|:--|:--|
| 两种「重力矩」混名 | $\boldsymbol g=\partial U/\partial q$ 是方程**左端**重力项；$\boldsymbol\tau_{\mathrm{grav}}=-\boldsymbol g$ 是重力实际施加的广义力。静止保持时电机出 $\tau=\boldsymbol g$，与 $\tau_{\mathrm{grav}}$ 等值反向、恰好相抵 |
| 漏掉转子动能 $k_r^2I_m$ | 转子角速度是 $k_r\dot q$，**平方后**进动能；大减速比时这项常是对角元主导（习题 C1 占 97%），不是小量 |
| 平面臂 $b_{12}$ 漏 $k_{r_2}I_{m_2}$ | 转子 2 的**总**角速度是 $\dot\vartheta_1+k_{r_2}\dot\vartheta_2$，展开交叉项得一次方 $k_{r_2}I_{m_2}$——与对角的 $k_{r_2}^2$ 是两回事 |
| 把势能写成 $\dot q$ 的函数 | $U=U(\boldsymbol q)$：质心位置由正运动学给出，与速度无关；写出 $\dot q$ 说明把动能项混进来了 |
| $\boldsymbol g_0$ 照抄 $[0,0,-g]^{\mathrm T}$ | 重力向量跟**坐标轴**走：平面臂取 $y$ 竖直向上，$\boldsymbol g_0=[0,-g,0]^{\mathrm T}$；换轴不换符号，整个重力项就错了 |
| 把 $b_{ii}$ 当连杆 $i$ 自己的惯量 | 是「**锁住其他关节**时关节 $i$ 看到的惯量」——锁死后下游全部连杆被刚性带动，全折进来 |
| $h_{ijk}$ 里的 $\frac12$ 丢失 | 第二项是 $-\frac12\partial b_{jk}/\partial q_i$；对称化（Christoffel）那一步的 $\frac12$ 同理，丢了 $C$ 就不满足 (7.43) |
| 把 $C$ 当唯一 | 只有**乘积 $C\dot q$** 唯一；讨论「$C$ 的对称性」前先声明选法（Christoffel / 其他） |
| 把 $\dot q^{\mathrm T}N\dot q=0$ 说成「$N$ 反对称」 | (7.49) 对**任意**选法成立（能量守恒）；反对称 (7.48) 只对 Christoffel 选法成立。$N$ 还依赖 $\dot q$——(B)⇏(A)，作业六 7-2 有显式反例 |
| 11 / 13 / 最小参数集混用 | 11 = 刚体惯性参数（每扩展连杆）；13 = 无接触力时加两摩擦；最小参数集 ≤ 13n 且可大幅压缩（平面臂 25→8→5） |
| 把 $Y$ 当常数矩阵 | $Y=Y(q,\dot q,\ddot q)$ **每次采样重算**；常的是 $\pi$。且 11 个参数未必都可辨识——$Y$ 的零列/相关列告诉你哪些测不出 |
| 笛卡儿臂也硬套 Christoffel | $B$ 常数 ⇒ $\dot B=0$ ⇒ $C=O$，不必算；但**轴不正交**时 $B$ 非对角（$m_2\cos\alpha$），耦合仍在 |
| 平面臂 $b_{22}$ 也写成随位形变 | $b_{22}=I_2+m_2\ell_2^2+k_{r_2}^2I_{m_2}$ 是**常数**（关节 2 之后没有连杆了）——这正是例 7.2 关节 2 力矩「分段恒定」的原因 |
| 末端力方向凭感觉写 | 教材约定 $\boldsymbol h_e$ 是末端**施加在环境上**的力；方程右端为 $-J^{\mathrm T}\boldsymbol h_e$。环境反力则符号相反——先统一约定再代数 |

| 错法 | 正解 |
|:--|:--|
| 把设计出的 $\boldsymbol\tau$ 直接当控制电压用 | $\boldsymbol\tau$ 是**关节侧广义力**，电机只认电压/电流；中间隔着 $K_r,K_t,R_a,K_v,G_v$ 与**反电动势** $K_v\dot{\boldsymbol q}_m$（[7.2.5](ch07/sec7-2.md#sec-7.2.5)） |

| 以为操作空间方案一定更准 | $\boldsymbol x$ 多由 $\boldsymbol q$ 经正运动学算出，误差会被 $J$ 放大；课件原话「这种优点是潜在的」（[7.1.4.2](ch07/sec7-1.md#sec-7.1.4.2)） |

| 重力补偿用期望角 $\boldsymbol q_d$ 算 $\boldsymbol g$ | 必须用**实测** $\boldsymbol q$：$\boldsymbol q\neq\boldsymbol q_d$ 时用期望值等于开环补偿，方向都可能错（[7.3.5](ch07/sec7-3.md#sec-7.3.5)） |
| 把计算力矩的 $\boldsymbol q$ 写成 $\boldsymbol q_d$ | 写成就退回「计算力矩前馈」：不再是反馈线性化，误差方程也不再是 $\ddot{\boldsymbol e}+K_D\dot{\boldsymbol e}+K_P\boldsymbol e=0$（[7.3.4](ch07/sec7-3.md#sec-7.3.4)、[7.2.7](ch07/sec7-2.md#sec-7.2.7)） |

| 把「课件编号」与「本书编号」混为一谈 | 课件 §8.3–§8.7 = 本书 7.2–7.5（课件第八章 = 本书第七章）；对照表见[勘误 E7.1](ch07/errata.md)。本章全部内容来自第 8–9 周课堂，没有「教材补」的节（[第七章导览](ch07/overview.md)） |

## 二、判断题（主动回忆）

44 道（31–36 为第六章增补，37–44 为第七章增补）。先逐条判断对错，再展开答案核对——**遮住答案**是这一节的全部意义。

::: ex 判断题 1–10

1. 旋转矩阵的逆等于它的转置，齐次变换矩阵也一样。
2. 绕当前坐标系的轴连续旋转要左乘。
3. $\operatorname{Atan2}(y,x)$ 与 $\arctan(y/x)$ 的区别只在于前者能处理 $x=0$。
4. ZYZ 欧拉角在 $\vartheta=0$ 时无法唯一确定 $\varphi$ 和 $\psi$。
5. DH 参数中 $a_i$ 与 $\alpha_i$ 永远是常数，$d_i$ 与 $\vartheta_i$ 中恰有一个是关节变量。
6. 一个 6 自由度机械手对任何任务都不冗余。
7. 球形腕的逆运动学可以拆成「先解臂、再解腕」两步。
8. 工具点与腕心雅可比行列式相等，因此可以不转换参考点就混用二者的期望速度。
9. 雅可比矩阵的第 $i$ 列，是其余关节锁死时关节 $i$ 对末端速度的贡献。
10. 冗余机械手的零空间运动会让末端产生额外的速度。

::: sol 答案与解析

1. **错**。R 的逆等于转置；整个刚体 A 的逆为 $[R^{\mathrm T},-R^{\mathrm T}o;0,1]$，当且仅当 $o=0$ 时才等于 $A^{\mathrm T}$。不能把含平移的一般情形也判为正交。
2. **错**。绕当前轴（动系）是**右乘**；绕固定轴才是左乘。口诀：右乘当前轴、左乘固定轴。
3. **错**。Atan2 保留两个输入各自的符号，因此能区分完整象限；例如 $\operatorname{Atan2}(1,-1)=135°$，而 $\arctan(1/(-1))=-45°$。两者差别不只在 $x=0$；$(0,0)$ 本身没有方向。
4. **对**。$s_\vartheta=0$ 时两次绕 $z$ 类轴的旋转绕平行轴进行、效果合并，只能确定 $\varphi\pm\psi$ 的和或差——这是表示奇点。
5. **对**。这就是「3 常 1 变」；关节类型（转动/移动）决定哪个是变量。
6. **错**。冗余是相对**任务**的：激光切割任务 $r=5$，6 轴机械手就是功能冗余的。
7. **对**。球腕三轴交于腕心，腕的转动不改变腕心位置——臂定位、腕定向，两个子问题可分别求解。
8. **错**。完整六维映射满足 $J_w=MJ_e$，$M$ 可逆且行列式为 1，保留信息与秩。控制腕心可用 $J_w$；工具点指令应同步转换成 $v_w=Mv_e$，行列式相等不表示两者输出相同。
9. **对**。这是逐列构造的物理解读，也是 $J_i$ 公式的来源。
10. **错**。零空间运动满足 $JP\dot{\boldsymbol q}_0=0$，对末端速度贡献**恒为零**——它是「不惊动末端」的内部运动（自运动）。

::: ex 判断题 11–20

11. 力和速度的变换矩阵互为转置。
12. $\tau=J^{\mathrm T}F_e$ 要求 $J$ 是方阵且满秩。
13. 分析雅可比 $J_A$ 与几何雅可比 $J$ 的前三行（线速度部分）相同。
14. 冗余机械手的伪逆解 $J^\dagger\boldsymbol v_e$ 是最小范数解。
15. 阻尼最小二乘里的 $K$ 越大越好。
16. 运动学奇点可以用更高精度的数值算法避免。
17. 闭环运动链的自由度等于关节数。
18. 移动机器人的即时机动自由度一定等于它的位形变量数。
19. 轨迹规划和运动规划是同一件事的两种叫法。
20. 只要模型足够准确，开环控制就可以替代反馈。

::: sol 答案与解析

11. **对**。这是「运动静力学对偶」——功率守恒 $\dot{\boldsymbol q}^{\mathrm T}\boldsymbol\tau=\boldsymbol v_e^{\mathrm T}F_e$ 的直接推论。
12. **错**。$J^{\mathrm T}$ 对长方阵也成立，**无需方阵、无需满秩**——这正是对偶关系比求逆更普适的地方。
13. **对**。位置部分两者都是 $\partial\boldsymbol p_e/\partial q_i$；差别只在姿态部分（角速度 $\boldsymbol\omega$ vs 欧拉角速率 $\dot{\boldsymbol\varphi}$，差一个换基 $T$）。
14. **对**。它是约束 $J\dot{\boldsymbol q}=\boldsymbol v_e$ 下最小化 $\frac12\|\dot{\boldsymbol q}\|^2$ 的解。
15. **错**。取 $K=k^{-2}I$：奇点邻域可增大阻尼 $k$（减小误差权重 $K$），以任务误差限制速度；$J$ 行满秩时，$k\to0^+$ 才趋于右伪逆。
16. **错**。奇点是固定任务下机构的实际降秩，提高精度不能恢复缺失的方向。邻域内困难方向可能产生很大速度要求，应结合最小奇异值、指令方向及关节限速判断，再选择绕行、减速或容许受控误差。
17. **错**。闭链存在回路约束，必须扣除独立约束数；开链才可直接计数。
18. **错**。即时机动自由度是**容许瞬时运动的方向数**，可能小于位形变量数（如汽车式底盘的平面位形有 3 个变量，但瞬时不能侧移）。
19. **错**。轨迹规划生成**时间律**（何时在何处），运动规划解决**避障**（路径本身）。
20. **错**。模型永远不能完全描述真实结构（摩擦、间隙、未建模动态），**反馈不可省略**——这是全书从第 6 章到第 11 章反复回响的第一性理由。

::: ex 判断题 21–25

21. 三次多项式在初终速度为零时，也能满足指定初终加速度的要求。
22. 梯形速度曲线（LSPB）的加速度峰值一定小于三次多项式。
23. 三次样条要指定初终加速度，必须引入两个虚拟点。
24. 抛物线混合插值时，轨迹精确经过每一个路径点。
25. 角和轴法可以把姿态规划化为一维标量规划。

::: sol 答案与解析

21. **错**。三次只有 4 个系数，容不下「初终加速度」这 2 个额外条件——必须升到五次（6 个系数、6 个条件）。这正是 [4.2.1.2](ch04/sec4-2-1.md#sec-4.2.1.2) 的出发点。
22. **错**。LSPB 的加速度是**分段常值**，其峰值 $|\ddot q_c|$ 可由用户直接指定（只要满足下界 (4.7)）；教材图 4.1 的三次例峰值也是 $6\pi$，而 LSPB 用同样峰值时能量指标已高 12.5%。两者的峰值不在同一个量级关系上——LSPB 的价值是**峰值可控且可验证**，不是更小。
23. **对**。$N$ 个路径点 + 初终加速度 ⇒ 方程数比未知数多 2，须引入两个虚拟点补到 $4(N+1)$ 对 $4(N+1)$ 才可解（[@thm-4.2.G]）。
24. **错**。抛物线混合下轨迹**不经过**路径点，只从附近经过——故改称「经由点」；偏离量与相邻速度差、混合时间成正比（[@def-4.2.7]）。
25. **对**。等效轴 $r'$ 固定不变，姿态轨迹完全由转角 $\theta(t)$ 决定，于是姿态规划降为一维标量规划，可复用点对点 / 系列点的全部方法（[@thm-4.3.F]）。

::: ex 判断题 26–30

26. 减速比越大，电机轴上看到的负载惯量越小，所以减速比越大越好。
27. 传动装置只影响力矩的传递，不影响系统的动态特性。
28. 不加电流反馈时驱动抗干扰更好，因此电流反馈没有存在的必要。
29. 位置伺服只要控制器增益足够大，就可以不用积分项。
30. 六维力传感器测出的 6 个数可以直接拿去算末端执行器受到的力。

::: sol 答案与解析

26. **错**。$I_{eq}=I_m+I/k_r^2$ 确实随 $k_r$ 单调减小，但**减速比受其他因素限制**：传动装置本身的惯量与摩擦、间隙与弹性（降低精度、引发振荡）、效率、体积与成本；而且 $k_r$ 太大时 $I_m$ 反而成为主导（本例 $k_r=100$ 时负载惯量已只占 5%），再增大收益趋零。工程上是**权衡**，不是单调最优。
27. **错**。§5.2.3 的全部内容就是「传动装置如何改变动态」——它按 $1/k_r^2$ 改写等效惯量与摩擦、按 $1/k_r$ 改写负载力矩与非线性，从而**把强耦合的多轴系统解耦成可独立设计的单轴系统**。
28. **错**。电流反馈有两个不可替代的用途：**限流保护**（用带死区非线性的反馈实现，比控制信号饱和更精确）与**力矩控制特性**（集中控制方案需要）。取舍是「什么时候加」，不是「要不要」。
29. **错**。缺积分会导致**稳态干扰**（负载力矩、重力矩）造成恒定的位置误差——因为干扰点之前的有限增益只能把误差压小而不能压到零。PI 中的 I 正是为消除该稳态误差（[@thm-5.2.D]）。
30. **错**。传感器读数描述的是**作用在传感器上的等价力**，与作用在末端执行器上的力不同（参考点与方向不同）；必须用式 (5.32) 从传感器坐标系 $s$ 变换到约束坐标系 $c$。作业 5.6 正是这道变换的算例。

:::

::: ex 判断题 31–36（第六章）

31. 用拉格朗日法列方程时，关节的约束反力会以未知力的形式出现在方程里，必须补充方程才能求解。
32. 势能零点选得不好，会导致运动方程整体错误。
33. $N=\dot B-2C$ 的反对称性对任何满足式 (7.43) 的 $C$ 都成立。
34. $\tau=Y(q,\dot q,\ddot q)\pi$ 中 $Y$ 与 $\pi$ 都随时间变化。
35. 两连杆平面臂的 $b_{22}$ 与 $\vartheta_1$、$\vartheta_2$ 都无关。
36. 参数辨识时采样越多，11 个参数就都能辨识出来。

::: sol 答案与解析

31. **错**。理想约束力**不做虚功**，被拉格朗日方程自动排除——这正是能量法不用画受力图的原因。要补的是非保守力（力矩、摩擦、末端接触力），它们走广义力进右端。
32. **错**。势能加减**常数**只改 $L$ 的常数项，求导为零，运动方程不变。致命的是「非常数项」写错（如 $\cos$ 写成 $\sin$），那不是零点问题而是函数写错。
33. **错**。(7.48) 只在 **Christoffel 选法**下成立（代数构造）；对任意 $C$ 成立的是 (7.49) $\dot q^{\mathrm T}N\dot q=0$（能量守恒）。作业六 7-2 的 $C_{\text{alt}}$ 是显式反例。
34. **错**。$Y$ 依赖 $q,\dot q,\ddot q$，**每次采样重算**；$\boldsymbol\pi$ 是**常参数**向量（结构与负载决定，不随时间变）——「一个变一个不变」正是辨识可行的前提。
35. **对**。$b_{22}=I_2+m_2\ell_2^2+k_{r_2}^2I_{m_2}$：关节 2 之后只有连杆 2，没有下游位形可依赖。这也是例 7.2 中关节 2 惯性力矩「分段恒定」的原因。
36. **错**。可辨识性由 $Y$ 的**列**决定：零列与相关列对应的参数无论采样多少都分不开；正确做法是先看最小参数集（平面臂 8 个甚至 5 个），再设计能激活全部列的激励轨迹。

::: ex 判断题 37–44（第七章）

37. 设计出的关节力矩 $\boldsymbol\tau$ 可以直接作为功率放大器的控制电压送给电机。
38. 关节空间控制方案里，末端位姿 $\boldsymbol x_e$ 处在闭环之内，所以运动学标定误差会被自动纠正。
39. 只要减速比足够大，任何工况下都可以把机械手当作 $n$ 个独立关节来控制。
40. 对 PD 控制器，增大 $K_P$ 就能消除常值扰动下的稳态误差。
41. 计算力矩控制中，只要 $B(\boldsymbol q)$ 正定可逆，误差方程就一定是 $\ddot{\boldsymbol e}+K_D\dot{\boldsymbol e}+K_P\boldsymbol e=\boldsymbol 0$。
42. 重力补偿 PD 中，$\boldsymbol g$ 应当用期望关节角 $\boldsymbol q_d$ 计算，这样可离线预算。
43. 操作空间动力学模型里，把分析雅可比 $J_A$ 换成几何雅可比 $J$ 不影响结论。
44. 计算力矩前馈与计算力矩（逆动力学）控制的区别只是名字不同。

::: sol 答案与解析

37. **错**。$\boldsymbol\tau$ 是关节侧广义力，控制器实际给出的是功率放大器的控制电压 $\boldsymbol v_c$；两者之间隔着减速比 $K_r$、转矩常数 $K_t$、电枢电阻 $R_a$、反电动势 $K_v\dot{\boldsymbol q}_m$ 与增益 $G_v$（式 (7.2-15)）。
38. **错**。关节空间方案的闭环量是 $\boldsymbol q$，$\boldsymbol x_e$ 只经运动学**开环**受控——逆解与标定误差不会被关节闭环纠正（这正是操作空间方案存在的理由）。
39. **错**。「可分散」的前提是大减速比、小电枢电阻、**小转矩**（式 (7.2-16) 的三条假设）；高速、大加速度、大转矩时近似失效，必须用整机模型（集中控制），并给驱动器加电流环。
40. **错**。常值扰动下 $e_{\mathrm{ss}}=d/K_P$，增大 $K_P$ 只把它变小；要零误差须引入积分（1 型系统）或把扰动补偿掉（如重力补偿）。
41. **错**。还要求**模型精确**且**未限幅**：模型误差使右边多出 $B^{-1}[\Delta B\boldsymbol u+\Delta C\dot{\boldsymbol q}+\Delta\boldsymbol g]$；限幅会让「精确对消」失效——这是计算力矩最常见的失效原因。
42. **错**。必须用**实测** $\boldsymbol q$ 算 $\boldsymbol g$：用 $\boldsymbol q_d$ 相当于开环补偿，位形偏差时补偿方向都可能错。
43. **错**。位置部分相同、姿态部分不同（$\dot{\boldsymbol\phi}\neq\boldsymbol\omega$），必须用分析雅可比 $J_A$；换用 $J$ 会把姿态误差算错。
44. **错**。计算力矩前馈（课件题名「计算转矩前馈」）用**期望值** $\boldsymbol q_d,\dot{\boldsymbol q}_d,\ddot{\boldsymbol q}_d$ 算前馈（可离线预算），计算力矩用**实测** $\boldsymbol q,\dot{\boldsymbol q}$ 精确对消——后者是大范围反馈线性化，前者只是前馈补偿。
