# 综合自测卷 · 第七章 运动控制

> **时间 90 分钟 · 满分 110**。闭卷，只允许带一张手写 A4 公式纸。
> 难度按「概念 15 + 推导 25 + 分散 20 + 集中 25 + 操作空间/选型 15」分配。
> 建议先做 2、3，再做 4，最后做 5、6；每题的评分点写在答案框里。

## 一、概念（15 分）

**1.（8 分）** 控制与正、逆动力学计算的区别是什么？写出控制问题的输入、输出与至少三个指标。

**2.（7 分）** 分散控制与集中控制的四条对照是什么？判别依据是「算法先进程度」吗？为什么？

::: note 一、参考答案
**1.** 正动力学由输入和状态求加速度，逆动力学由运动求力矩；控制使用期望运动、模型和实际反馈决定输入。输入可为 $q_d$ 或 $x_d$ 与实际测量，输出为实际接口允许的关节命令；指标有稳态误差、超调、调节时间和驱动限制。（8分）

**2.** 分散分别设计单轴反馈并把残余耦合作扰动，集中显式使用多轴状态和模型。驱动、运动工况与误差要求决定是否合适，不能将接口或算法名称直接当作性能排名。（7分）（[7.1.5](sec7-1.md#sec-7.1.5)）
:::

## 二、驱动接口推导（25 分）

**3.（15 分）** 写出驱动系统五式（减速器、电机、功率放大器），消元推出
$\boldsymbol\tau=K_rK_tR_a^{-1}(G_v\boldsymbol v_c-K_vK_r\dot{\boldsymbol q})$。

**4.（10 分）** 从上式解出 $\dot q$，指出电压近似速度接口时忽略的负载项。为什么大减速比和额定转矩余量还不足以单独保证该近似？

::: note 二、参考答案
**3.** 五式：$q_m=K_rq$；$\tau_m=K_r^{-1}\tau=K_ti_a$；$v_a=R_ai_a+K_v\dot q_m$；$v_a=G_vv_c$。
由后两式 $i_a=R_a^{-1}(G_vv_c-K_vK_r\dot q)$，乘 $K_t$ 得 $\tau_m$，再乘 $K_r$ 得
$\tau=K_rK_tR_a^{-1}(G_vv_c-K_vK_r\dot q)$。（10 分；每式 2 分，消元 5 分）

**4.** $\dot q=(K_vK_r)^{-1}G_vv_c-(K_vK_r)^{-1}R_aK_t^{-1}K_r^{-1}\tau$。（5分）第二项必须在任务允许速度偏差内足够小，还需电气快动态和刚性传动近似。参数对角支持逐轴换算，但负载项取决于实际转矩和工况；静止带载仍需电阻压降，不能忽略。（5分）
:::

## 三、分散控制（20 分）

**5.（8 分）** 写出分散控制的等效单轴方程，说明 $B=\bar B+\Delta B$ 中 $\bar B$ 怎么取，
$d$ 里至少包含哪三项。

**6.（12 分）** 位置环开环传递函数为 $L(s)=k_mK_Pk_{tp}(1+sT_p)/[s^2(1+sT_m)]$。
（a）$T_p<T_m$ 时为什么不稳定？（b）直接转矩单轴对象加入 $k_pe+k_d\dot e+k_i\int e\,dt$ 后，特征式和稳定条件是什么？（c）怎样证明常负载偏差为零？

::: note 三、参考答案
**5.** $K_r^{-1}\bar BK_r^{-1}\ddot q_m+F_m\dot q_m+d=\tau_m$；$\bar B$ 取各关节惯量平均值的
对角阵；$d$ 含 $\Delta B\ddot q_m$、$C\dot q_m$、重力 $\boldsymbol g$（库仑摩擦也算）。
（每项 2 分，方程 2 分）

**6.** （a）$T_p<T_m$ 时，零点 $-1/T_p$ 在极点 $-1/T_m$ 左侧。Routh 首列为 $T_m,1,\kappa(T_p-T_m),\kappa$（$\kappa>0$），有两次符号变化，闭环不稳定。（4 分）
（b）$Js^3+(b+k_d)s^2+k_ps+k_i$，正参数还需 $(b+k_d)k_p>Jk_i$。（4分）
（c）固定目标负载通道为 $E/D=s/[Js^3+(b+k_d)s^2+k_ps+k_i]$；闭环稳定、常负载 $D=d_0/s$ 时应用终值定理，得到 $e_{\rm ss}=0$。还须说明无限幅等模型条件。（4分）
:::

## 四、集中控制（25 分）

**7.（12 分）** 写出重力补偿 PD 的李雅普诺夫函数 $V$ 与 $\dot V$，指出哪一步用了 $\dot B-2C$
的反对称性，并用拉萨尔原理证明 $\tilde{\boldsymbol q}\to0$。

**8.（13 分）** 写出逆动力学控制律与误差方程；说明它与计算转矩前馈的区别。若模型不准确，
误差方程多出什么？这通向哪两类方法？

::: note 四、参考答案
**7.** $V=\frac12\dot q^{\mathrm T}B\dot q+\frac12\tilde q^{\mathrm T}K_P\tilde q$（2 分）；
$\dot V=\frac12\dot q^{\mathrm T}(\dot B-2C)\dot q-\dot q^{\mathrm T}F\dot q
+\dot q^{\mathrm T}(u-g-K_P\tilde q)$（4 分）；第一项由反对称性为零（2 分）；
取 $u=g+K_P\tilde q-K_D\dot q$ 得 $\dot V=-\dot q^{\mathrm T}(F+K_D)\dot q\le0$（2 分）；
按正文的理想模型假设，先说明 $V$ 的子水平集紧致且正向不变；$\dot V=0$ 中要一直保持 $\dot q=0$，还需 $\ddot q=0$，代回闭环得 $K_P\tilde q=0$。最大不变集只有目标平衡点，故收敛（2 分）。

**8.** $u=B(\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q)+n$（3 分）；
$\ddot{\tilde q}+K_D\dot{\tilde q}+K_P\tilde q=0$（3 分）。
区别：逆动力学用当前状态计算 $B,n$ 并在虚拟加速度中反馈误差；完整转矩前馈沿期望状态计算，再与反馈相加。两者反馈注入位置和增益单位也不同（3分）。
模型不准时多出 $B^{-1}[\Delta B y+\Delta n]$（2 分）；通向鲁棒控制与自适应控制（2 分）。
:::

## 五、鲁棒、自适应与操作空间（15 分）

**9.（8 分）** 鲁棒控制的 $\omega=(\rho/\|z\|)z$ 为什么要加边界层？加边界层后误差还能到零吗？
自适应控制能保证参数估计收敛到真值吗？

**10.（7 分）** 操作空间模型为什么必须用分析雅可比 $J_A$？写出转置雅可比控制律，
并说明 $\tau=J_A^{\mathrm T}F$ 的来历。

::: note 五、参考答案
**9.** 符号函数在实际执行器上引起抖振；边界层内改成线性 $(\rho/\varepsilon)z$，平滑但只保证
最终有界估计，界还依赖 $P,Q,\rho$；不保证一般误差趋零，也不能断言每次实验都必有非零残差。（4分）
自适应只保证跟踪误差收敛、$\hat\pi$ 有界，**不保证** $\hat\pi\to\pi$；参数收敛需要持续激励。
（4 分）

**10.** 姿态部分 $J$ 给角速度 $\omega$，$J_A$ 给欧拉角导数 $\dot\phi$，二者差一个矩阵；
用错雅可比，姿态误差与 $\dot J_A\dot q$ 都错。（3 分）
$F=K_P(x_d-x)$，$\tau=J_A^{\mathrm T}F$（2 分）；由虚功原理
$F^{\mathrm T}\delta x=F^{\mathrm T}J_A\delta q=\tau^{\mathrm T}\delta q$ 得到（2 分）。
:::

## 六、选型（10 分）

**11.（10 分）** 已知减速比100、电阻10 Ω，额定转矩大于轨迹所需。任务要求关节跟踪误差不超过0.01 rad。现有信息能否唯一选出方案并预测误差？还需要哪些数据，怎样设计验证？

::: note 六、参考答案
信息不足。（2分）还需实际驱动接口、完整惯量与负载模型、期望轨迹及导数、耦合与摩擦、测量与更新周期、力矩及电压电流限制。（4分）先建立可复现基线，再依失败原因比较前馈、积分、逆动力学等修改，记录误差与输入，并加入明确的失配或限幅对照；不能由一个精度数字指定算法。（4分）见[§7.5.4](sec7-5.md#sec-7.5.4)。
:::
