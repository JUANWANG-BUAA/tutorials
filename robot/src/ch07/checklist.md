## 一页复习路线

1. **先过 7.1**：两套框图 + 分散/集中判别，这是全章地图。
2. **再过 7.2**：等效模型 → 三种控制器 → 根轨迹 → 干扰抑制 → 驱动接口 → 前馈；
   每个公式都要能说出「它解决了上一节的哪个问题」。
3. **7.3 分两遍**：第一遍只记四套控制律的**形式与适用条件**；第二遍再补李雅普诺夫证明。
4. **7.4 只抓两条**：转置雅可比（不求逆）与逆动力学（要 $J_A^{-1}$）；其余是代价清单。
5. **7.5 当索引**：记误差量级与选型表，做题时回来查。

> 全部打勾后，做 [综合自测卷](mock-exam.md)；错题回到对应节，不要直接看答案。
