# 第七章 · 运动控制

> **核心问题**：给定机械手的期望轨迹 $\boldsymbol q_d(t)$ 或末端位姿轨迹 $\boldsymbol x_d(t)$，如何在关节存在耦合、参数存在偏差、只有位置与速度测量且执行器只接收电压/电流指令的实际条件下，设计闭环控制律 $\boldsymbol u(t)$ 使实际运动稳定跟踪目标？

第六章解决了“已知运动求所需力矩”（动力学逆解），但它依赖精确模型且不含反馈修正：一旦负载发生变化或模型存在公差，开环计算的前馈力矩就会立即产生跟踪偏差。本章建立机械臂自由空间**运动控制（Motion Control）**的完整体系（对应原书第 8 章），将前六章的运动学、雅可比、轨迹、驱动与动力学模型装配为真实闭环控制器。

::: note 章号说明（与原书对照）
本教程按课程体系把原书第 7 章编为第六章（动力学），把原书第 8 章编为**第七章（运动控制）**；各节正文中公式与命题均严谨对齐物理与控制理论推导。
:::

## 先看一个具体工况：负载变重后，单轴还跟得住吗？

拿起螺丝刀后末端负载增加：
1. 若维持原有前馈力矩，关节会由于惯量变大和重力增加而出现显著稳态落差或动态滞后；
2. 即使误差变大，这究竟意味着参数失配导致的稳态误差，还是闭环极点跨过虚轴导致的**不稳定**？
3. 靠单轴高减速比 PD/PID 能否把耦合压成微小扰动，何时必须整机建模做计算力矩或在线自适应？

完成 [7.1 控制体系](sec7-1.md)、[7.2 分散控制](sec7-2.md) 与 [7.3 集中控制](sec7-3.md) 后，可在[两连杆第八关](../training/two-link.md#mission-feedback)完成闭合反馈消项，并在[作业七（8-10～8-16）](homework07.md)中完成完整 2R 模型与 $+10\%$ 质量摄动对比验证。

## 全章三维架构：空间 $\times$ 耦合深度 $\times$ 驱动接口

```text
控制问题（7.1.1）：设计广义力/指令使实际轨迹跟踪期望轨迹（自由空间 h_e = 0）
   │
   ├── 维度一：按反馈空间划分（任务在末端，动作在关节）
   │     ├── 关节空间方案：x_d ─IK→ q_d ─→ 控制器 ─→ τ，闭环反馈 q       （x_e 开环）
   │     └── 操作空间方案：x_d ─→ 控制器 ─→ J_Aᵀ折算 ─→ τ，反馈 x_e      （x_e 闭环）
   │
   ├── 维度二：按动力学耦合深度划分
   │     ├── 分散控制（7.2）：1/k_r² 与 1/k_r 衰减 → 单轴线性 PI/PID + 驱动五式 v_c + 前馈
   │     └── 集中控制（7.3）：整机矩阵补偿四档递进
   │           ① 重力补偿 PD（定点 LaSalle 全局渐近稳定）
   │           ② 逆动力学/计算力矩（全工作空间反馈线性化）
   │           ③ 鲁棒滑模 + 边界层（已知不确定界下的 UUB 保证）
   │           ④ 参数线性化自适应控制（Yπ 在线更新 + Barbalat 收敛）
   │
   └── 选型与出口（7.4 操作空间，7.5 仿真比较）：A–H/J 与 K/L 误差量级与三步工程选型
```
