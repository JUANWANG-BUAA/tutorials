## A. 定义卡

### A1 · 分散控制

用一句话定义分散控制，并说出它把哪三类东西塞进了 $d$。

::: sol A1 核对
将各轴反馈分别设计，并把未显式补偿的惯性偏差、速度耦合、重力及其他负载归入扰动。轴侧必须一致；改写为扰动并不证明它足够小。见[§7.2.1](sec7-2.md#sec-7.2.1)。
:::

### A2 · 独立关节近似

写出分散控制的等效单轴方程，并说明 $\bar B$ 怎么取。

::: sol A2 核对
电机侧单轴为 $J_i\ddot q_{m_i}+b_i\dot q_{m_i}+d_i=\tau_{m_i}$，$J_i=\bar b_i/k_{ri}^2>0$。$\bar B$ 是选定的常数标称对角阵，不一定非要取算术平均；残余耦合和偏差进入 $d$。见[§7.2.1](sec7-2.md#sec-7.2.1)。
:::

### A3 · 重力补偿 PD

写出重力补偿 PD 的控制律与它的适用前提。

::: sol A3 核对
$u=g(q)+K_Pe-K_D\dot q$，$e=q_d-q$。正文证明固定目标、精确模型与重力补偿、足够阻尼、无限幅及有界性条件下的调节收敛。移动参考会改变能量导数，不能照搬这段证明。见[§7.3.3](sec7-3.md#sec-7.3.3)。
:::

### A4 · 逆动力学控制

写出逆动力学控制律，并说明它为什么叫「反馈线性化」。

::: sol A4 核对
$\boldsymbol u=B(\boldsymbol q)(\ddot{\boldsymbol q}_d+K_D\dot{\tilde{\boldsymbol q}}
+K_P\tilde{\boldsymbol q})+\boldsymbol n(\boldsymbol q,\dot{\boldsymbol q})$，
$\boldsymbol n=C\dot{\boldsymbol q}+F\dot{\boldsymbol q}+\boldsymbol g$。
控制律里显式含**实测** $\boldsymbol q,\dot{\boldsymbol q}$，用反馈把非线性对象改造成
$\ddot{\boldsymbol q}=\boldsymbol y$ 的双积分器；大范围有效，区别于工作点附近的小偏差线性化。
（[7.3.4](sec7-3.md#sec-7.3.4)）
:::

## B. 结论卡

### B1 · 分散控制成立的两条结论

写出定理 7.2.A 的两条结论，并说明它们各自依赖哪条假设。

::: sol B1 核对
忽略电感，负载造成的速度偏差为 $(K_vK_r)^{-1}R_aK_t^{-1}K_r^{-1}\tau$。它在任务误差范围内足够小时，才可近似 $G_vv_c\approx K_vK_r\dot q$。对角参数允许逐轴换算，但不意味着所有工况都对机械负载不敏感；静止带载不能用零反电动势估保持力矩。见[@thm-7.2.A]。
:::

### B2 · 根轨迹三种情形

位置环开环传递函数为 $k_mK_Pk_{tp}(1+sT_p)/[s^2(1+sT_m)]$。$T_p<T_m$、$T_p>T_m$、$T_p\gg T_m$
分别对应什么稳定性/响应？

::: sol B2 核对
$T_p<T_m$ 时不稳定，$T_p>T_m$ 时稳定；等号对应临界情形。须同时满足该节的连续时间线性模型与正参数假设。
实际响应速度还受增益、采样、执行器带宽与噪声限制。（[7.2.3](sec7-2.md#sec-7.2.3)）
:::

### B3 · 四种集中控制的分工

按「补什么」排列重力补偿 PD、逆动力学、鲁棒、自适应。

::: sol B3 核对
重力补偿 PD：只补 $\boldsymbol g$，点对点；逆动力学：全补 $B,C,\boldsymbol g$，模型精确时误差解耦；
鲁棒：全补 + 不确定项上界 $\rho$，保证有界误差；自适应：全补 + 参数在线估计 $\hat\pi$，
保证跟踪收敛但不保证参数辨识。（[7.3.3](sec7-3.md#sec-7.3.3)–[7.3.6](sec7-3.md#sec-7.3.6)）
:::

### B4 · 鲁棒控制的边界层

为什么加边界层？加了以后误差还能到零吗？

::: sol B4 核对
理想方向项在零点不连续。连续边界层缓和切换，但不保证实际抖振全部消失。其证明给最终有界估计，界依赖 $P,Q,\rho,\varepsilon$；既不保证一般误差趋零，也不能断言每次实验的最终误差都非零。见[§7.3.5](sec7-3.md#sec-7.3.5)。
:::

### B5 · 自适应控制保证什么

自适应控制能保证 $\tilde{\boldsymbol q}\to0$ 吗？能保证 $\hat{\boldsymbol\pi}\to\boldsymbol\pi$ 吗？

::: sol B5 核对
能保证 $\boldsymbol\sigma\to0$、$\tilde{\boldsymbol q}\to0$、$\dot{\tilde{\boldsymbol q}}\to0$
（须满足本节的刚体、常参数及有界性假设）；不能保证 $\hat{\boldsymbol\pi}\to\boldsymbol\pi$，但理想模型下估计保持
有界。参数收敛需要持续激励，且不是跟踪的必要条件。（[7.3.6](sec7-3.md#sec-7.3.6)）
:::

## C. 公式卡

### C1 · 驱动五式

默写五式并消元推出 $\boldsymbol\tau$ 与 $\boldsymbol v_c$ 的关系。

::: sol C1 核对
$q_m=K_rq$；$\tau_m=K_r^{-1}\tau=K_t i_a$；$v_a=R_ai_a+K_v\dot q_m$；$v_a=G_vv_c$。
消元：$\tau=K_rK_tR_a^{-1}(G_vv_c-K_vK_r\dot q)$。（[7.2.5](sec7-2.md#sec-7.2.5)）
:::

### C2 · 电流环

加电流环后 $\boldsymbol\tau$ 与 $\boldsymbol v_c$ 的关系是什么？为什么它能消掉反电动势项？

::: sol C2 核对
若电流内环在适用带宽和限幅内跟随 $i_d=G_iv_c$，则 $\tau\approx K_rK_tG_iv_c$。反电动势仍存在于电气对象中，由内环调电压处理，不是在物理上消失。见[§7.2.5](sec7-2.md#sec-7.2.5)。
:::

### C3 · 常负载与积分

写出转矩PD加积分的负载误差传递函数、稳定条件与常负载稳态结论。

::: sol C3 核对
对转矩对象 $J\ddot q_m+b\dot q_m+d=\tau_m$ 加PD及积分后，$E/D=s/[Js^3+(b+k_d)s^2+k_ps+k_i]$。正参数还需 $(b+k_d)k_p>Jk_i$；稳定后常负载误差为零。调节时间须按实际闭环极点和误差带判断。见[§7.2.4](sec7-2.md#sec-7.2.4)。
:::

### C4 · 计算转矩前馈

写出完整关节转矩前馈，说明怎样避免重复补偿，以及它与反馈线性化的区别。

::: sol C4 核对
完整关节前馈为 $\tau_{\rm ff}=\hat B(q_d)\ddot q_d+\hat C(q_d,\dot q_d)\dot q_d+\hat g(q_d)+\hat F\dot q_d$。若名义项已有补偿，只加残余。电压换算保留 $G_v^{-1}$、减速比和反电动势；反馈线性化还在实际状态上指定虚拟加速度，反馈注入位置也不同。见[§7.2.7](sec7-2.md#sec-7.2.7)。
:::

### C5 · 重力补偿 PD 的稳定性

写出 $V$ 与 $\dot V$，指出哪一步用了 $\dot B-2C$ 的反对称性。

::: sol C5 核对
$V=\frac12\dot q^{\mathrm T}B\dot q+\frac12\tilde q^{\mathrm T}K_P\tilde q$；
$\dot V=\frac12\dot q^{\mathrm T}(\dot B-2C)\dot q-\dot q^{\mathrm T}F\dot q
+\dot q^{\mathrm T}(u-g-K_P\tilde q)$；第一项由反对称性为零，取 $u=g+K_P\tilde q-K_D\dot q$
得 $\dot V=-\dot q^{\mathrm T}(F+K_D)\dot q\le0$。这里的负号对应实际速度；若改用误差速度，才写 $+K_D\dot{\tilde q}$。渐近收敛还需在有界不变集中应用拉萨尔原理，不能仅凭 $\dot V\le0$ 判断。（[7.3.3](sec7-3.md#sec-7.3.3)）
:::

### C6 · 逆动力学的误差方程

把逆动力学律代入 $B\ddot q+n=u$，推出误差方程。

::: sol C6 核对
$u=B(\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q)+n$，代入得
$\ddot q=\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q$，即
$\ddot{\tilde q}+K_D\dot{\tilde q}+K_P\tilde q=0$；$B$ 正定保证可逆。（[7.3.4](sec7-3.md#sec-7.3.4)）
:::

### C7 · 操作空间两种实现

写出转置雅可比与逆雅可比两种控制律，各说一个优缺点。

::: sol C7 核对
转置：$F_A=K_Pe_x$，$\tau=J_A^{\mathrm T}F_A$，输出为弹簧力矩；降秩时虽能计算，可能形成非目标驻点。逆雅可比：$\ddot q_c=J_A^{-1}(\ddot x_d+K_D\dot e_x+K_Pe_x-\dot J_A\dot q)$，输出为加速度，随后还需动力学实现。两者都不凭名称保证最短路径。见[§7.4.3](sec7-4.md#sec-7.4.3)。
:::

## D. 陷阱卡

### D1 · 三种控制器串起来

怎样判断多环串级是否成立？为什么不能从课堂并列方案推出“所有多环都不允许”？

::: sol D1 核对
应按完整框图与带宽设计判断。外位置、内速度、更内电流的串级可以成立，但不能随意串接若干PID。课堂的并列例子也不构成禁止所有多环结构的定理。见[§7.2.2](sec7-2.md#sec-7.2.2)。
:::

### D2 · 重力补偿 PD 做跟踪

为什么重力补偿 PD 不能直接用于轨迹跟踪？

::: sol D2 核对
固定目标时 $\dot e=-\dot q$，移动目标则 $\dot e=\dot q_d-\dot q$，势能导数多出 $e^{\mathrm T}K_P\dot q_d$。因此固定目标的能量证明不能直接推出移动参考的零误差跟踪；可另设计参考前馈、PD跟踪或逆动力学等方案。见[§7.3.3](sec7-3.md#sec-7.3.3)。
:::

### D3 · 逆动力学写错自变量

把逆动力学律里的 $\boldsymbol q$ 写成 $\boldsymbol q_d$，会变成什么？

::: sol D3 核对
模型不再与当前状态精确匹配，因此原来的精确线性误差方程通常不成立。但仅替换模型自变量，表达式仍含反馈项，不能一概称为纯前馈。完整前馈与反馈线性化须比较整个控制律及反馈作用位置。见[§7.2.7](sec7-2.md#sec-7.2.7)。
:::

### D4 · 操作空间用几何雅可比

采用欧拉角任务坐标时，为什么速度和广义力必须与 $J_A$ 配对？

::: sol D4 核对
采用 $x=[p;\phi]$ 时，应让 $\dot x=J_A\dot q$，相应广义力也要与 $\dot x$ 配对。物理角速度或几何姿态误差的控制也可以使用几何雅可比，但必须另行保持速度、误差与物理力系一致，不能混在同一个欧拉角坐标式中。见[§7.4.2](sec7-4.md#sec-7.4.2)。
:::
