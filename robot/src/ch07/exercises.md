# 习题集 · 第七章 运动控制

> 题目按认知层级分四组：**A 概念**（4 题）、**B 推导**（5 题）、**C 控制律**（5 题）、
> **D 综合**（3 题）。每题给出「考点 + 答案」，答案在折叠框里，先自己做再展开。
> 计算题默认使用 7.5 的两连杆参数；需要数值复算的题在答案里给出公式与量级。

## A · 概念

### A1 · 控制与动力学计算

分别说明正动力学、逆动力学和控制求什么量，反馈新增了哪些要求？

::: sol A1 答案
给定运动求力矩是逆动力学；正动力学则由力矩和状态求加速度并积分。控制利用期望运动、模型和实际测量决定输入，还需说明误差收敛、超调、调节时间和驱动限制。即使模型准确，未反馈的初始偏差也未必消失。见[§7.1.1](sec7-1.md#sec-7.1.1)。
:::

### A2 · 自由运动与环境交互

本章为什么可以忽略末端反力 $-J^{\mathrm T}\boldsymbol h_e$？什么情况下不能忽略？

::: sol A2 答案
本章模型先处理没有持续接触的自由运动，故取 $h_e=0$。接触时应恢复环境反作用及接触约束；根据任务决定哪些方向控制运动、哪些方向控制力或柔顺性，不是一接触就能独立指定全部位姿与全部力。
:::

### A3 · 两套框图

画出关节空间与操作空间两套框图，标出误差在哪里形成、实际量怎样获得，以及末端误差是否被独立测量。

::: sol A3 答案
关节反馈以 $q_d-q$ 形成误差，任务参考可先经逆运动学得到 $q_d$。操作空间反馈以 $x_d-x$ 形成误差，再换成关节输入。前者没有独立末端误差校正，但末端仍受关节闭环影响；后者若由同一运动学模型估计 $x$，也看不见该模型自身偏差。
:::

### A4 · 分散 vs 集中

分别说明分散与集中控制怎样处理耦合，并判断误差空间、驱动接口和速度标签能否单独决定分类。

::: sol A4 答案
分散：分别设计单轴反馈，把未补偿耦合归入扰动；集中：利用多轴状态和模型显式处理耦合。判别应看控制律与信息依赖，驱动接口、速度、负载只影响其可实现性与适用性，不能充当绝对分类规则。
:::

## B · 推导

### B1 · 驱动五式

从 $q_m=K_rq$、$\tau_m=K_r^{-1}\tau=K_ti_a$、$v_a=R_ai_a+K_v\dot q_m$、$v_a=G_vv_c$
推出 $\tau=K_rK_tR_a^{-1}(G_vv_c-K_vK_r\dot q)$，并说明三条假设。

::: sol B1 答案
$i_a=R_a^{-1}(G_vv_c-K_vK_r\dot q)$，依次乘 $K_t$、$K_r$即得。反解速度后，被省去的负载项为 $(K_vK_r)^{-1}R_aK_t^{-1}K_r^{-1}\tau$；还需忽略快电气动态并满足刚性传动近似。这项是否足够小要按任务误差判断，不能只看额定转矩余量。
:::

### B2 · 单轴闭环

从 $J_i\ddot q_i+F_i\dot q_i+d_i=\tau_i$ 与 PD 律出发，写出误差方程、$\omega_n$、$\zeta$，
并区分物理阻尼与附加速度反馈。

::: sol B2 答案
对一般参考，代入可得 $J\ddot e+(F+K_D)\dot e+K_Pe=J\ddot q_d+F\dot q_d+d$。固定目标右端简化为 $d$，所以 $\omega_n=\sqrt{K_P/J}$，$\zeta=(F+K_D)/(2\sqrt{K_PJ})$。当物理阻尼 $F>0$ 时，即使 $K_D=0$ 也未必无阻尼；附加速度反馈用来调整总阻尼。
:::

### B3 · 根轨迹

位置环开环传递函数 $L(s)=k_mK_Pk_{tp}(1+sT_p)/[s^2(1+sT_m)]$。说明 $T_p<T_m$ 为什么不稳定。

::: sol B3 答案
$T_p<T_m$ 时，零点 $-1/T_p$ 位于极点 $-1/T_m$ 的左边。闭环特征式为 $T_ms^3+s^2+\kappa T_ps+\kappa$（$\kappa=k_mK_Pk_{tp}>0$），Routh 首列的第三项为 $\kappa(T_p-T_m)$，出现符号变化，因此不稳定；调正增益不能改变这个符号。
（[7.2.3](sec7-2.md#sec-7.2.3)）
:::

### B4 · 干扰抑制

对转矩单轴对象加入PD和积分，写出常负载到误差的传递函数、稳定条件和稳态结论。

::: sol B4 答案
令 $\tau=k_pe+k_d\dot e+k_i\int e\,dt$，固定目标下 $E/D=s/[Js^3+(b+k_d)s^2+k_ps+k_i]$。正参数的稳定条件为 $(b+k_d)k_p>Jk_i$。稳定后常负载误差为零；斜坡负载斜率为 $d_1$ 时误差为 $d_1/k_i$。结论来自指定扰动通道，不能笼统说“PI把系统变成1型”。
:::

### B5 · 三种「用模型」的方式

比较分散前馈、计算转矩前馈、逆动力学控制：自变量、能否离线、对消精度。

::: sol B5 答案
单轴前馈补标称惯性与黏性参考项；整机转矩前馈还使用沿期望轨迹的耦合与重力模型。两者可以离线也可以在线计算，均不依赖实际误差来形成模型前馈量。逆动力学反馈使用当前状态计算 $B,n$，并把误差反馈加到虚拟加速度中，精确模型下得到线性误差方程。
:::

## C · 控制律

### C1 · 重力补偿 PD

写出 $V$ 与 $\dot V$，说明哪一步用了 $\dot B-2C$，并用拉萨尔原理补完稳定性。

::: sol C1 答案
$V=\frac12\dot q^{\mathrm T}B\dot q+\frac12\tilde q^{\mathrm T}K_P\tilde q$；
$\dot V=\frac12\dot q^{\mathrm T}(\dot B-2C)\dot q-\dot q^{\mathrm T}F\dot q
+\dot q^{\mathrm T}(u-g-K_P\tilde q)$。第一项由反对称性为零。取
$u=g+K_P\tilde q-K_D\dot q$ 得 $\dot V=-\dot q^{\mathrm T}(F+K_D)\dot q\le0$。
在正文给定的精确补偿、无限幅与惯性一致正定等假设下，$V$ 的子水平集紧致且正向不变。拉萨尔原理要求寻找 $\dot V=0$ 的最大不变集：$\dot q\equiv0$ 还要求 $\ddot q\equiv0$，代回闭环才得 $K_P\tilde q=0$，从而收敛到目标。
（[7.3.3](sec7-3.md#sec-7.3.3)）
:::

### C2 · 逆动力学与模型误差

写出逆动力学律与误差方程；若用标称模型 $\hat B,\hat n$，误差方程多出什么？

::: sol C2 答案
$u=B(\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q)+n$ ⇒
$\ddot{\tilde q}+K_D\dot{\tilde q}+K_P\tilde q=0$。用标称模型时多出
$B^{-1}[\Delta B\,y+\Delta n]$（$\Delta B=B-\hat B$ 等）——这就是鲁棒/自适应的入口。
（[7.3.4](sec7-3.md#sec-7.3.4)、[7.3.5](sec7-3.md#sec-7.3.5)）
:::

### C3 · 鲁棒控制

写出鲁棒项 $\omega$ 与边界层形式，说明 $\rho$、$\varepsilon$ 各控制什么。

::: sol C3 答案
在正文已知 $B$、$\|n-\hat n\|\le\rho$ 的模型中，$z=D^{\mathrm T}Q\xi$，边界层外取 $\omega=\rho z/\|z\|$，内部取 $\rho z/\varepsilon$。于是 $\dot V\le-\lambda_{\min}(P)\|\xi\|^2+\rho\varepsilon/2$。$\rho$ 必须覆盖所用区域的误差界，$\varepsilon$ 控制连续近似宽度；最终跟踪界还受 $P,Q$ 影响，不直接等于 $\varepsilon$。
:::

### C4 · 自适应控制

写出 $q_r$、$\sigma$、控制律、更新律，并说明它保证什么、不保证什么。

::: sol C4 答案
$\dot q_r=\dot q_d+\Lambda\tilde q$，$\sigma=\dot q_r-\dot q=\dot{\tilde q}+\Lambda\tilde q$；
$u=Y(q,\dot q,\dot q_r,\ddot q_r)\hat\pi+K_D\sigma$；
$\dot{\hat\pi}=K_\pi^{-1}Y^{\mathrm T}\sigma$。
在正文的未知常参数模型、惯性一致正定及闭环信号有界等条件下，可得 $\sigma\to0$、$\tilde q\to0$。参数误差有界，但不保证 $\hat\pi\to\pi$；还需足够辨识信息才能讨论参数真值收敛（[7.3.6](sec7-3.md#sec-7.3.6)）。

:::

### C5 · 操作空间

对欧拉角表示的位姿任务，写出操作空间模型与任务弹簧控制律。说明如何选择与任务坐标配套的 $J_A$，以及 $\tau=J_A^{\mathrm T}F$ 中的力应怎样定义，才能保持功率配对。

::: sol C5 答案
$B_x\ddot x+C_x\dot x+g_x=\gamma_A-h_A$，完整欧拉角任务下 $h_A=T_A^{\mathrm T}h_e$。任务弹簧给 $F_A=K_Pe_x$，折回为 $\tau=J_A^{\mathrm T}F_A$，因为 $F_A^{\mathrm T}\delta x=F_A^{\mathrm T}J_A\delta q$。几何速度与欧拉角导数不同，物理力矩也要按同一功率配对换算。
:::

## D · 综合

### D1 · 选架构

一台机械手：$k_r=100$、$R_a=10\ \Omega$、额定转矩远大于轨迹所需。该用分散还是集中？
若改成直驱（$k_r=1$）呢？

::: sol D1 答案
信息不足，不能仅凭减速比、电阻和额定余量决定架构。需知道惯量、参考运动、耦合大小、实际接口和误差要求；再检查电压速度近似中的负载项及闭环。直驱需要重新评估这些量，也不自动排除分散控制，电压输入也不必然禁止集中控制。
:::

### D2 · 误差预算

任务要求关节跟踪误差 $\le0.01$ rad。现有分散位置+速度环误差约 $0.2$ rad。给出两条待验证的改进路线，
并说明各自代价。

::: sol D2 答案
可先比较参考惯性与负载前馈，再比较按当前状态补偿的逆动力学方案。分别记录模型、增益、接口、采样及力矩限制，重算是否达到0.01 rad。一次基线误差0.2 rad不能预测修改后必到哪个量级；若末端指标是位置误差，还需用m表达而非直接用rad。
:::

### D3 · 仿真设计

用 7.5 的两连杆臂，设计一个仿真实验，比较「分散 PD」「分散 PD + 前馈」「逆动力学」三套方案。
写出你要记录的量与预期结论。

::: sol D3 答案
统一对象、初值、参考及其导数、控制周期、测量和限幅，明确每套控制律与增益单位。记录每轴最大误差、RMS、力矩峰值、限幅时间和计算耗时。先提出可检验假设：准确前馈应减小参考运动引起的名义残差；匹配逆动力学应接近其理想误差方程。再引入明确参数失配，观察结论怎样变化，不预填其他方案的误差数字。
:::

复习时可先做B2、B3、C1和C2，分别检查单轴模型、Routh条件、能量抵消与模型失配。选型题应明确现有信息是否足够，不以控制器名称代替计算。
