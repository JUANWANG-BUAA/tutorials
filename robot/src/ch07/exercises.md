# 习题集 · 第七章 运动控制

> 题目按认知层级分四组：**A 概念**（4 题）、**B 推导**（5 题）、**C 控制律**（5 题）、
> **D 综合**（3 题）。每题给出「考点 + 答案」，答案在折叠框里，先自己做再展开。
> 计算题默认使用 7.5 的两连杆参数；需要数值复算的题在答案里给出公式与量级。

## A · 概念

### A1 · 控制问题与动力学正问题

控制问题与第六章的动力学正问题，差别在哪三点？

::: sol A1 答案
① **模型只是近似**：$B,C,\boldsymbol g$ 永远有误差，任何「用模型算力」的方案都必须配反馈；
② **测量有限**：通常只测关节位置/速度，末端位姿靠运动学算，带误差；
③ **有指标**：稳态误差、超调、调节时间、带宽——动力学正问题没有这些词。
（[7.1.1](sec7-1.md#sec-7.1.1)）
:::

### A2 · 自由运动与环境交互

本章为什么可以忽略末端反力 $-J^{\mathrm T}\boldsymbol h_e$？什么情况下不能忽略？

::: sol A2 答案
本章是**自由空间运动控制**：末端与环境不接触，$\boldsymbol h_e=0$。一旦末端接触环境（打磨、
拧螺丝、人形机器人行走），接触力成为必须主动控制的量，就要进入第九章力控制，$\boldsymbol h_e$
不能再扔。（[7.1.2](sec7-1.md#sec-7.1.2)）
:::

### A3 · 两套框图

画出关节空间与操作空间两套控制框图，指出各自的闭环量与开环段。

::: sol A3 答案
关节空间：$x_d\to$ 逆运动学 $\to q_d\to$ 控制器 $\to\tau$，反馈 $q$；**$x$ 是开环的**
（逆解误差没人管）。操作空间：$x_d\to$ 控制器 $\to F\to J_A^{\mathrm T}\to\tau$，反馈 $x$；
**$x$ 闭环**，但 $x$ 通常由 $q$ 正算，信息仍是间接的。（[7.1.4](sec7-1.md#sec-7.1.4)）
:::

### A4 · 分散 vs 集中

列出分散/集中的四条对照，并说明判别依据。

::: sol A4 答案
① 设计对象：单轴 vs 整机；② 模型：少 vs 全；③ 耦合：当扰动 vs 显式补偿；
④ 驱动器：速度源（电压）vs 力矩源（电流环）。判别依据是**工况**（速度、加速度、负载、
是否直驱），不是「哪个先进」。（[7.1.5](sec7-1.md#sec-7.1.5)）
:::

## B · 推导

### B1 · 驱动五式

从 $q_m=K_rq$、$\tau_m=K_r^{-1}\tau=K_ti_a$、$v_a=R_ai_a+K_v\dot q_m$、$v_a=G_vv_c$
推出 $\tau=K_rK_tR_a^{-1}(G_vv_c-K_vK_r\dot q)$，并说明三条假设。

::: sol B1 答案
由第 3、4 式：$i_a=R_a^{-1}(G_vv_c-K_vK_r\dot q)$；乘 $K_t$ 得 $\tau_m$；再乘 $K_r$ 得 $\tau$。
三条假设：$K_r\gg I$、$R_a\to0$、$\tau$ 小 ⇒ 括号趋于零 ⇒ $G_vv_c\approx K_vK_r\dot q$。
（[7.2.5](sec7-2.md#sec-7.2.5)）
:::

### B2 · 单轴闭环

从 $J_i\ddot q_i+F_i\dot q_i+d_i=\tau_i$ 与 PD 律出发，写出误差方程、$\omega_n$、$\zeta$，
并说明 $K_D$ 为什么不能省。

::: sol B2 答案
取 $e=q_d-q$，PD：$\tau=K_Pe+K_D\dot e$。代入并令 $d'=d+F\dot q_d$（慢变时近似常值）：
$J\ddot e+K_D\dot e+K_Pe=d'$。$\omega_n=\sqrt{K_P/J}$，$\zeta=K_D/(2\sqrt{K_PJ})$。
$K_D=0$ 时 $\zeta=0$，无阻尼振荡；$K_D>0$ 提供阻尼，把极点拉进左半平面。（[7.2.2](sec7-2.md#sec-7.2.2)）
:::

### B3 · 根轨迹

位置环开环传递函数 $L(s)=k_mK_Pk_{tp}(1+sT_p)/[s^2(1+sT_m)]$。说明 $T_p<T_m$ 为什么不稳定。

::: sol B3 答案
零点 $-1/T_p$ 在极点 $-1/T_m$ 的**右边**时，根轨迹分支从开环极点出发、终止于零点，会向右半平面
弯；闭环极点出现正实部 ⇒ 不稳定。物理上「位置环太快、电机跟不上」，反馈变成正反馈效应。
（[7.2.3](sec7-2.md#sec-7.2.3)）
:::

### B4 · 干扰抑制

写出干扰抑制因子 $X_R$ 与收敛时间 $T_R$，说明 $K_P$ 的取舍与 PI 的作用。

::: sol B4 答案
$X_R=K_Pk_{tp}$；$T_R=\max\{T_p,1/(\zeta\omega_n)\}$。$K_P\uparrow$ ⇒ 干扰增益 $\downarrow$，
但 $\zeta\downarrow$、噪声放大 $\uparrow$。PI 的积分把系统变成 1 型，常值干扰稳态误差为零；
代价是相位滞后、积分饱和、低速极限环。（[7.2.4](sec7-2.md#sec-7.2.4)）
:::

### B5 · 三种「用模型」的方式

比较分散前馈、计算转矩前馈、逆动力学控制：自变量、能否离线、对消精度。

::: sol B5 答案
分散前馈（7.2.6）：只用 $q_d,\dot q_d,\ddot q_d$ 的一部分，离线，精度受跟踪误差限制；
计算转矩前馈（7.2.7）：用完整 $q_d$ 轨迹，离线，精度同上；逆动力学（7.3.4）：用**实测**
$q,\dot q$，在线，模型精确时精确对消。三者是「前馈 → 前馈 → 反馈线性化」的递进。
（[7.2.6](sec7-2.md#sec-7.2.6)、[7.2.7](sec7-2.md#sec-7.2.7)、[7.3.4](sec7-3.md#sec-7.3.4)）
:::

## C · 控制律

### C1 · 重力补偿 PD

写出 $V$ 与 $\dot V$，说明哪一步用了 $\dot B-2C$，并用拉萨尔原理补完稳定性。

::: sol C1 答案
$V=\frac12\dot q^{\mathrm T}B\dot q+\frac12\tilde q^{\mathrm T}K_P\tilde q$；
$\dot V=\frac12\dot q^{\mathrm T}(\dot B-2C)\dot q-\dot q^{\mathrm T}F\dot q
+\dot q^{\mathrm T}(u-g-K_P\tilde q)$。第一项由反对称性为零。取
$u=g+K_P\tilde q-K_D\dot q$ 得 $\dot V=-\dot q^{\mathrm T}(F+K_D)\dot q\le0$。
在正文给定的精确补偿、无限幅与惯性一致正定等假设下，$V$ 的子水平集紧致且正向不变。拉萨尔原理要求寻找 $\dot V=0$ 的最大不变集：$\dot q\equiv0$ 还要求 $\ddot q\equiv0$，代回闭环才得 $K_P\tilde q=0$，从而收敛到目标。
（[7.3.3](sec7-3.md#sec-7.3.3)）
:::

### C2 · 逆动力学与模型误差

写出逆动力学律与误差方程；若用标称模型 $\hat B,\hat n$，误差方程多出什么？

::: sol C2 答案
$u=B(\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q)+n$ ⇒
$\ddot{\tilde q}+K_D\dot{\tilde q}+K_P\tilde q=0$。用标称模型时多出
$B^{-1}[\Delta B\,y+\Delta n]$（$\Delta B=B-\hat B$ 等）——这就是鲁棒/自适应的入口。
（[7.3.4](sec7-3.md#sec-7.3.4)、[7.3.5](sec7-3.md#sec-7.3.5)）
:::

### C3 · 鲁棒控制

写出鲁棒项 $\omega$ 与边界层形式，说明 $\rho$、$\varepsilon$ 各控制什么。

::: sol C3 答案
$\omega=(\rho/\|z\|)z$（$\|z\|\ge\varepsilon$），$\omega=(\rho/\varepsilon)z$（$\|z\|<\varepsilon$），
$z=D^{\mathrm T}Q\xi$。$\rho$ 是不确定上界：越大越能压住大扰动，但抖振越强；
$\varepsilon$ 是边界层厚度：越大越平滑，但稳态误差越大（有界，不为零）。（[7.3.5](sec7-3.md#sec-7.3.5)）
:::

### C4 · 自适应控制

写出 $q_r$、$\sigma$、控制律、更新律，并说明它保证什么、不保证什么。

::: sol C4 答案
$\dot q_r=\dot q_d+\Lambda\tilde q$，$\sigma=\dot q_r-\dot q=\dot{\tilde q}+\Lambda\tilde q$；
$u=Y(q,\dot q,\dot q_r,\ddot q_r)\hat\pi+K_D\sigma$；
$\dot{\hat\pi}=K_\pi^{-1}Y^{\mathrm T}\sigma$。
保证 $\sigma\to0$、$\tilde q\to0$；不保证 $\hat\pi\to\pi$（只保证有界）。（[7.3.6](sec7-3.md#sec-7.3.6)）
:::

### C5 · 操作空间

写出操作空间模型与转置雅可比控制律；说明为什么必须用 $J_A$，以及 $\tau=J_A^{\mathrm T}F$ 的来历。

::: sol C5 答案
$B_x\ddot x+C_x\dot x+g_x=\tau_x-h_e$；$F=K_P(x_d-x)$，$\tau=J_A^{\mathrm T}F$。
$J_A$ 的姿态行对应欧拉角导数，$J$ 对应角速度，$\dot\phi\neq\omega$。$\tau=J_A^{\mathrm T}F$
由虚功原理 $\delta W=F^{\mathrm T}\delta x=F^{\mathrm T}J_A\delta q=\tau^{\mathrm T}\delta q$ 得到。
（[7.4.2](sec7-4.md#sec-7.4.2)、[7.4.3](sec7-4.md#sec-7.4.3)）
:::

## D · 综合

### D1 · 选架构

一台机械手：$k_r=100$、$R_a=10\ \Omega$、额定转矩远大于轨迹所需。该用分散还是集中？
若改成直驱（$k_r=1$）呢？

::: sol D1 答案
第一台：大减速比、转矩余量大 ⇒ 三条假设大致成立 ⇒ **分散控制**（电压 + 单轴 PI/PID）即可。
直驱：$k_r=1$，耦合不缩小、反电动势项显著 ⇒ 必须**集中控制**，且驱动器要加电流环变成力矩源。
（[7.2.5](sec7-2.md#sec-7.2.5)）
:::

### D2 · 误差预算

任务要求末端跟踪误差 $\le0.01$ rad。现有分散位置+速度环误差约 $0.2$ rad。给出两条改进路线，
并说明各自代价。

::: sol D2 答案
路线一：加**分散前馈/计算转矩前馈**，误差可降到 $10^{-2}$ 量级，代价小、可离线；
路线二：上**逆动力学**（需电流环 + 整机模型 + 快采样），误差可到 $10^{-4}$，代价大。
若 $0.01$ 是硬指标，路线一通常够；若要 $10^{-3}$ 以下或高速重载，才上路线二。
（[7.5.3](sec7-5.md#sec-7.5.3)、[7.5.4](sec7-5.md#sec-7.5.4)）
:::

### D3 · 仿真设计

用 7.5 的两连杆臂，设计一个仿真实验，比较「分散 PD」「分散 PD + 前馈」「逆动力学」三套方案。
写出你要记录的量与预期结论。

::: sol D3 答案
记录：关节角跟踪误差 $e_i(t)$ 的最大值与 RMS、控制力矩峰值、计算耗时。
预期：分散 PD 误差 $\sim0.1$–$0.2$ rad；加前馈后 $\sim0.01$；逆动力学 $\sim10^{-4}$（模型精确时）。
再加 10% 参数误差，逆动力学退化到 $10^{-3}$，用来观察「模型误差把性能拉回哪一档」。
（[7.5.1](sec7-5.md#sec-7.5.1)–[7.5.3](sec7-5.md#sec-7.5.3)）
:::
