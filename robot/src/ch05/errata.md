# 勘误与补注（对照原书与工程口径）

本页汇总第五章在对照原书《机器人学：建模、规划与控制》（Siciliano 等）、配套课件与数值验算时发现的关键公式口径辨析、常见误算订正与语音转写正字表。

## 一、核心公式口径与易错点勘误

::: errata E5.1 · 丝杠传动比量纲与电—机常数单位一致性（[5.2.1](sec5-2.md#part-5.2.1)、[5.2.3](sec5-2.md#part-5.2.3)）
- 转动齿轮副减速比 $k_r=\omega_m/\omega$ 无量纲；但滚珠丝杠驱动移动关节时 $k_r=2\pi/h$ 的量纲为 $\mathrm{rad/m}$，此时电机等效惯量仍满足 $I_{eq}=I_m+m_{\mathrm{load}}/k_r^2\ (\mathrm{kg\cdot m^2})$。
- 仅当采用一致 SI 单位制（$k_v$ 用 $\mathrm{V\cdot s/rad}$、$k_t$ 用 $\mathrm{N\cdot m/A}$）且作理想集总直流近似时，$k_v$ 与 $k_t$ 数值相等；使用厂家手册中的 $\mathrm{V/krpm}$ 或线电压峰值规格前须先换算统一。
:::

::: errata E5.2 · 腕力传感器校准矩阵元素位置与参考点搬移矢量方向（[5.4.1](sec5-4.md#part-5.4.1)）
- 原书式 5.31 的 $6\times 8$ 校准矩阵第 4 行对应 $\mu^s_x$ 的非零项分别为第 4 列的 $c_{44}$ 与第 8 列的 $c_{48}$（部分早期排印易将 $c_{44}$ 错位对齐）。
- 搬移力矩公式 $\boldsymbol\mu^c_c=R^c_s\boldsymbol\mu^s_s+\boldsymbol r^c_{cs}\times(R^c_s\boldsymbol f^s_s)$ 中，$\boldsymbol r^c_{cs}$ 严格定义为**由约束系原点 $O_c$ 指向传感器原点 $O_s$**（即传感器在 $\{c\}$ 下的位置坐标）。若在具体习题中给定由传感器指向接触点（如[习题集](exercises.md) C6），反号相减 $\boldsymbol\mu_c = R\boldsymbol\mu_s - \boldsymbol r_{sc}\times(R\boldsymbol f_s)$ 不可直接照搬加号。
:::

::: errata E5.3 · 声纳音速温度误差算例订正（[5.4.2](sec5-4.md#part-5.4.2)）
当真实环境温度为 $0^\circ\mathrm C$（$c_s=331.4\,\mathrm{m/s}$）、目标真实距离 $2.0\,\mathrm m$，若算法仍按 $20^\circ\mathrm C$（$343.4\,\mathrm{m/s}$）音速解算时，测量距离 $d_{\mathrm{meas}}=2.0\times 343.4/331.4\approx 2.0724\,\mathrm m$，结果**高估约 $7.2\text{ cm}$**（非早年草稿误估的低估 9 cm）。
:::

::: errata E5.4 · 针孔相机外参数矩阵须取位姿逆 $(T^b_c)^{-1}$（[5.4.3](sec5-4.md#part-5.4.3)）
机械臂正运动学自然求得相机相对于基座的位姿齐次矩阵 $T^b_c$（将相机系点映回基系）；投影公式 $\Xi=\Omega\Pi(T^b_c)^{-1}$ 需要的是**基系点换入相机系**的外参矩阵 $T^c_b=(T^b_c)^{-1}$，切勿直接拿 $T^b_c$ 代入透视投影（对应[作业五 5.7](homework05.md)）。
:::

::: errata E5.5 · 大减速比与线性化的边界条件（[5.2.3](sec5-2.md#part-5.2.3)）
减速比 $k_r$ 仅在**电机转角行程受限在平衡点附近小区域**时压缩摆角 $\vartheta_m/k_r$ 实现线性化；若关节本身须扫过大角度（如 $\pi/2$），终点小角线性近似误差仍高达 $57.08\%$。同时不可仅凭 $k_r$ 数值较大就直接丢弃负载惯量 $I/k_r^2$，必须检验无量纲比值 $I/(k_r^2 I_m)$ 是否确远小于 $1$。
:::
