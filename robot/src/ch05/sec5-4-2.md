# 5.4.2 距离传感器

测距器的读数需要同时说明“离谁多远”和“沿哪个观测方向”。一次回波也不等于整个视场中的目标都被看见：反射、遮挡和波束范围决定了它实际覆盖的区域。本节先计算传播时间法，再用简单几何推导三角测量。课堂回看：02:14:15–02:20:35。

<a id="sec-5.4.2.1"></a>

## 5.4.2.1 从「有没有」到「多远、在哪个方位」

::: def 定义 5.4.4 · 接近传感器与距离传感器（含敏感距离） {#def-5.4.4}
接近传感器通常判断目标是否进入可检测范围；距离传感器还给出与距离相关的数值。敏感距离表示规定条件下的检测范围，通常还与目标材料、尺寸和反射条件有关。

若传感器提供扫描方向，可把距离配到该方向。单个数值并不自动给出准确三维位置，还须知道测量原点、朝向、视场与返回信号来自哪里。
:::

<a id="sec-5.4.2.2"></a>

## 5.4.2.2 声纳：用回波计时

声纳发出声脉冲并接收回波。先采用最简单的几何假设：发射与接收近似共点，目标在一次测量中运动可忽略，回波沿同一路径往返，介质中的传播速度为 $c_s$。

::: thm 定理 5.4.B · 声纳测距方程与音速的温度修正 {#thm-5.4.B}
若目标单程距离为 $d_o$，声波走过的总路程为 $2d_o$，因此 $c_st_v=2d_o$，即

$$d_o=\frac{c_st_v}{2}. \tag{5.33}$$

$t_v$ 是发射到接收的往返时间，不能当成单程时间。在低湿度空气的教材近似中，温度 $T$ 用摄氏度表示：

$$c_s\approx20.05\sqrt{T+273.16}\ \mathrm{m/s}. \tag{5.34}$$

介质和环境条件改变时，应使用相应传播速度；不能把空气近似直接用于水中。
:::

例如取 $c_s=340$ m/s、往返时间6 ms，则 $d_o=340\times0.006/2=1.02$ m。漏掉分母2会算成2.04 m。对小误差展开，$\delta d\approx(t_v\delta c_s+c_s\delta t_v)/2$；这说明测温和计时都会影响距离，而不是只提高定时器分辨率就足够。

![声纳回波计时、发射与接收转换的示意](../assets/ch05/dist-sonar.jpg)

同一个换能器兼作发射与接收时，发射脉冲结束后还可能有振铃及接收恢复时间。若最早可接收的时刻为 $t_b$，则相应近距离盲区约为 $c_st_b/2$。双换能器可以改变部分限制，但还须考虑其几何与串扰，不能只把机械惯量大小当成唯一原因。

波束有宽度，反射也有方向性，回波可能受三类情况影响：表面将能量反射到接收器之外，造成漏检；同一波束覆盖多个目标，难以确定返回来源；多次反射的回波被当作直达路径，形成错误距离。因此没有回波，并不足以证明前方没有障碍。

压电换能器通过电场和机械形变交换能量，静电换能器利用膜片与电场耦合完成收发。两类器件的带宽、灵敏度、偏压、声学匹配和振铃均依具体结构而定。课件中的单一型号和参数用于举例，不应外推成所有声纳的统一量程或波束角。

## 5.4.2.3 激光：传播时间法与三角测量法

::: method 方法 5.4.C · 两种激光测距传感器：原理与取舍 {#method-5.4.C}
脉冲传播时间法用激光器发光、光电接收器收光，再测往返延迟。按与声纳相同的几何假设，

$$d=\frac{ct}{2}.$$

取 $c\approx3\times10^8$ m/s，1 mm距离差对应的往返时间差为 $2\times10^{-3}/c\approx6.7$ ps。这里计算的是往返延迟，不能把单程1 mm的约3.3 ps直接代入该分辨率关系。实际测距精度还受波形、信噪比、标定与估计方法影响。

若每隔 $T_r$ 发一次相同脉冲，且只根据返回时刻识别脉冲，则超过一个重复周期的回波可能与后续脉冲混淆，简单无歧义距离为 $cT_r/2$。具体编码、门控与解模糊方法可以改变这一限制；任意接收窗口长度不能不加说明地当作脉冲重复周期。

三角测量则用激光光斑在接收器上的位置求距离。它依赖发射端与接收端的已知相对几何，而不是靠测极短的往返时间。
:::

把三角测量算一次。取接收光心为 $(0,0)$，光轴沿 $z$；发射器位于 $(b,0)$，光束也沿 $z$。光斑在目标上的位置为 $(b,Z)$。虚拟像平面距光心 $f$，由相似三角形得

$$\frac{x_p}{f}=\frac{b}{Z},\qquad Z=\frac{fb}{x_p}.$$

例如 $b=50$ mm、$f=10$ mm、$x_p=2$ mm，求得 $Z=250$ mm；$x_p$ 变为1 mm时，$Z=500$ mm。这组几何中距离与光斑位置是反比，不能概括成总是成正比。实际结构还要考虑基线方向、像素尺度和零位，由标定模型处理。

扫描可让单束测距依次获得多个方向的信息，但传播时间法本身既不限于单点，也不要求必须机械扫描。解释数据时，应以实际通道、视场和采样方式为准。

三角测量需要接收器看见可定位的光斑，传播时间法需要能识别的返回信号。表面颜色、反射、遮挡和环境光都可能影响结果；水下与低能见度条件同样需要按波长、介质和距离分析，不能写成“光学一律不能用、声纳一定是唯一选择”。激光器还须遵守所用设备的眼睛安全条件。
