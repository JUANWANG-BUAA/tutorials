# 5.4.2 距离传感器

上一节的力传感器在末端碰到物体之后才给出读数；要想让机械手或移动机器人在碰撞发生之前主动绕开障碍、识别工作空间里的工件方位，就需要在“能量—驱动—传动—测量”链的外部测量端加上距离传感器。测距读数只有同时标明测量原点、观测方向以及反射和波束条件，才能变成三维空间里可信的障碍物位置。本节先区分“有没有”和“有多远”，再依次推导声纳回波计时与激光的传播时间法、三角测量法。课堂回看：02:14:15–02:20:35（定位与接近传感并参照 02:11:36–02:14:15）。

<a id="sec-5.4.2.1"></a>

## 5.4.2.1 从「有没有」到「多远、在哪个方位」

外部传感使机器人能依据周围环境主动决策而不再盲走（02:12:04–02:12:40）。按输出信息量，非接触探测分成接近传感器和距离传感器两档。

::: def 定义 5.4.4 · 接近传感器与距离传感器（含敏感距离） {#def-5.4.4}
接近传感器是距离传感器的简化形式：无需物理接触，仅判断目标是否落入规定的敏感距离内（只回答“有没有”）；距离传感器则给出定量的距离读数和相应观测方位，用于避障、建立环境地图和目标识别。只有把单方向的距离读数配上传感器自身位姿、波束方向和视场范围，才能得到障碍物相对机器人的空间位置。
:::

<a id="sec-5.4.2.2"></a>

## 5.4.2.2 声纳：用回波计时

在空气或水中，如果传播速度 $c_s$ 已知，就能把声音脉冲从发出到返回的时间变成距离。声纳成本低、功耗小、计算量轻；在水下或粉尘浓烟等低能见度环境里激光难以穿透时，声纳常成为首选甚至唯一可行的测距手段（02:13:45–02:14:15）。

先在最简几何假设下建方程：发射和接收共点，测量瞬间目标静止，声波沿原路往返。

::: thm 定理 5.4.B · 声纳测距方程与音速的温度修正 {#thm-5.4.B}
声波从传感器到达单程距离为 $d_o$ 的目标再返回，总路程为 $2d_o$，因此由往返传播时间 $t_v$（emission 到 echo 的时间差）得（教材式 5.33）

$$d_o=\frac{c_st_v}{2}. \tag{5.33}$$

在低湿度空气中，音速 $c_s$ 随摄氏温度 $T$（$^\circ\mathrm C$）变化（教材式 5.34）：

$$c_s\approx20.05\sqrt{T+273.16}\ \mathrm{m/s}. \tag{5.34}$$

介质改变（如进入水中）必须更换对应介质的声速，不能套用空气公式。
:::

拿一组数代入核对：取 $c_s=340\ \mathrm{m/s}$，往返时间 $t_v=6\ \mathrm{ms}$，则 $d_o=340\times0.006/2=1.02\ \mathrm m$（若漏掉分母 2 会直接算成 2 倍距离 $2.04\ \mathrm m$）。把小误差展开，$\delta d_o\approx\frac12(t_v\delta c_s+c_s\delta t_v)$：这说明高精度测距同时受测温精度和计时分辨率制约，光提高定时器主频却不修正温度照样有误差（例如室温从 $0^\circ\mathrm C$ 升到 $25^\circ\mathrm C$ 音速变化超过 4%）。

![声纳回波计时、发射与接收转换的示意](../assets/ch05/dist-sonar.jpg)

实际使用声纳还要注意器件转换盲区和三类反射失效（02:15:18–02:17:50）：

1. **收发切换与近距离盲区**：如果用同一个压电换能器兼作发射和接收，压电晶体共振惯性大，发完脉冲后仍需一段振铃和恢复时间 $t_b$ 才能切回接收模式，近处回波在传感器尚未恢复前就已返回，形成约 $c_st_b/2$ 的近距离盲区；分设独立发射／接收器或选用机械惯性更低的静电膜片换能器（如 Polaroid 600 系列静电声纳，波束宽约 $15^\circ$、有效量程约 $0.15\text{–}10\ \mathrm m$，代价是需较高偏置电压与相应驱动电路，课件参数只作单型号示例）可改善近距表现。
2. **非检测平面与临界角漏检**：超声能量分布在锥形波束（典型不小于 $15^\circ$）内。光滑平坦表面且入射角大于临界角（例如 Polaroid 对光滑胶合板约为 $65^\circ$）时，声波像镜面反射一样弹向别处，接收器收不到回波，系统就会把面前的大平面误判成“前方无障碍”。
3. **多重反射虚检**：光滑壁面之间发生多次折返后回到接收器，飞行时间变长，传感器就会在光路延长线方向凭空报出一个不存在的“虚拟远目标”。

## 5.4.2.3 激光：传播时间法与三角测量法

激光光束极窄、单色性好（可用窄带滤光抑制环境杂光）、方向可控，因此角分辨率远高于声纳（02:17:55–02:21:45）。按测距原理分为传播时间法（ToF）和三角测量法两条路线。

::: method 方法 5.4.C · 两种激光测距传感器：原理与取舍 {#method-5.4.C}
**① 激光传播时间法（ToF）** 原理与声纳同形：半导体激光器发脉冲、光电二极管收脉冲，由光速 $c\approx3\times10^8\ \mathrm{m/s}$ 算得 $d=ct/2$。光速极快带来苛刻的计时要求：1 mm 距离差对应的**往返**路程差为 2 mm，所需时间分辨率为 $2\times10^{-3}/(3\times10^8)\approx6.7\ \mathrm{ps}$（单程 1 mm 才约 3.3 ps，代入往返关系不要漏乘 2）。此外，若每隔重复周期 $T_r$ 发一串相同脉冲，超过 $T_r$ 才返回的远距离回波会混入下一周期，造成以 $cT_r/2$（典型模糊区间量级约 20–40 m）为周期的距离歧义（可通过脉冲编码或门控缓解）。单束激光只测一个点，通常利用轻量反射镜面高速扫描而无需摆动笨重的激光器和探测器本身。

**② 激光三角测量法** 不测时间，改用发射端与接收 CCD 之间已知的几何基线：漫反射光斑落在感光芯片上的像点位置直接反映目标深度，不受光速计时皮秒级门槛限制，常用于近距离高精度工业轮廓或圆度检测，但对表面颜色、漫反射特性（镜面反射会使光斑偏离或失效）及环境光较敏感。
:::

把激光三角测量的相似三角形算一遍：设接收镜头光心位于 $(0,0)$、光轴沿 $+z$，激光发射器在 $(b,0)$ 沿 $+z$ 射出一束平行光，打在深度为 $Z$ 的表面点 $(b,Z)$ 上；接收侧虚拟像平面距光心焦距为 $f$，漫反射光经光心在像平面上成斑坐标为 $x_p$。由相似三角形得

$$\frac{x_p}{f}=\frac{b}{Z} \qquad\Longrightarrow\qquad Z=\frac{fb}{x_p}.$$

例如取基线 $b=50\ \mathrm{mm}$、焦距 $f=10\ \mathrm{mm}$：当光斑在像面上偏离光轴 $x_p=2\ \mathrm{mm}$ 时，目标深度 $Z=10\times50/2=250\ \mathrm{mm}$；当光斑位置减半为 $x_p=1\ \mathrm{mm}$ 时，深度翻倍为 $Z=500\ \mathrm{mm}$。可见在这种正交发射几何中深度 $Z$ 与像点坐标 $x_p$ 成**反比**而不是正比（工程实际结构往往带倾斜角并通过标定直接建立像元刻度到距离的查表或曲线）。

## 5.4.2 小结与常见错误

接近传感器探测敏感距离内有无目标，距离传感器提供距离与方位。声纳与激光传播时间法均基于 $d=ct/2$，分别受音速温漂／换能器盲区／临界角漏检／多径虚检和皮秒级计时／模糊重复间隔限制；激光三角测量依靠基线和相似三角形 $Z=fb/x_p$ 近距高精度测距，但依赖漫反射光斑定位。

::: think 常见错误清单 · 自查三条
1. 忘记往返测距公式 $d=ct/2$ 中的除以 2，或估算 1 mm 光时间分辨时错按单程 3.3 ps 而非往返 6.7 ps。
2. 把“未收到回波”等同于“前方没有障碍物”，忽略声纳临界角镜面漏检与收发切换近距离盲区。
3. 以为三角测距里光斑坐标与目标深度总是成正比（平行垂直基线几何中是反比关系 $Z=fb/x_p$，实际器件还须按倾斜基线标定曲线换算）。
:::
