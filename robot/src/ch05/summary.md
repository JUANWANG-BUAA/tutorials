## 一条主线

> **关节要「低速度、大转矩」，伺服发动机的最优工况却是「高速度、低转矩」——传动装置抹平这个矛盾，作用是三重（定量 / 定性 / 减重解耦），三种装置各管一段（齿轮换向、丝杠转平动、带与链做远置传动）。发动机按输入功率分三类，电机内部再分有刷与无刷，选型看「低速大转矩 vs 集成与效率」。建模时把整条链写成方程：电气驱动四个方程给出速度控制与力矩控制两种「发电机」特性，液压驱动是同一套结构的平行版本（多出渗漏与可压缩性），传动装置则按 $1/k_r^2$ 改写惯量与摩擦、按 $1/k_r$ 改写力矩与非线性——于是多轴强耦合被削弱成「可独立设计的单轴 + 干扰」，位置环的 PI 加测速反馈才立得住。传感器分内外：本体传感器（位置 / 速度）是伺服的反馈源，外部传感器（力 / 距离 / 视觉）让机器人知道自己在与什么打交道。**

## 三句话带走

1. **两个折算因子管住整章**：惯量与摩擦按 $1/k_r^2$、力矩与非线性按 $1/k_r$。传动装置的「减重解耦」、摆例子的「线性化」、独立关节控制的合法性，需结合这两条与具体惯量比、耦合强度及运动范围检验。
2. **功率链 + 两种发电机**：能源 → 功放 → 发动机 → 传动装置；电气驱动在「加不加电流反馈」上分岔出速度控制（抗扰好、独立关节用）与力矩控制（力矩独立于转速、集中控制用）两条特性，统一写成 $M(s)=k_m/[s(1+sT_m)]$。
3. **传感器要分清「量的是谁」**：本体量（关节位置、速度、关节力矩）用来闭环伺服；外部量（末端力、距离、视觉）用来认识环境。**测量精度先受物理原理限制**（编码器的量化分辨率、声纳的温度漂移、相机的标定残差），不是换个算法就能补上。
