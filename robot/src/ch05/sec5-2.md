## 5.2.0 两条路线与一条类比

两类驱动都能从物理方程建立输入、输出和反馈之间的关系；教材指出图 5.2 与图 5.6 有结构上的类比。类比是观察方框图的工具，不代表元件可以互换：

| 电气驱动 | 液压驱动 | 角色 |
|:--|:--|:--|
| 电枢电压 $v_a$ | 阀杆位移 $x$ | **控制作用的入口** |
| 电枢电流 $i_a$ | 压差 $p$ | **与输出力矩成正比的内变量** |
| 电流反馈回路（传感器 $k_i$，可选） | 压力与阀口流量的耦合 | 都会影响输入输出关系，但成因不同 |
| 电感 $L_a$ 储存磁场能，电阻 $R_a$ 耗能 | 液体压缩储能，渗漏耗能 | 都要分别列出储能与耗散关系 |

但教材随即给出一句重要的**警告**：**「这种类比不应令人相信，可以由液压驱动来实现速度控制发电机或力矩控制发电机的作用」**——压力反馈回路是液压系统的**固有结构特征**，「除非引入适当变换器并实现相关控制电路，否则不能将其修正」。换句话说：电气驱动可以**选用**要不要电流反馈，液压驱动的压力反馈**去不掉**。

### 5.2.0.1 小结与常见错误

- **一条方法论**：从**数学模型**出发，把每一段写成方程，最后拼成能拿去设计控制器的**框图**（本节给出的两张图，原书第 8 章直接使用）。
- **一组类比**：电气驱动与液压驱动的框图**结构平行**（控制入口、与力矩成正比的内变量、局部反馈回路），但**压力反馈是液压的结构特征、去不掉**，电流反馈则是可取舍的设计选择。
- **本章其余各节的引子**：5.2.1 建立电气模型、5.2.2 建立液压模型、5.2.3 量化传动装置的影响、5.2.4 用它设计位置环。

::: think 常见错误清单 · 自查三条
1. 把局部框图类比当作两类驱动具有完全相同的控制特性；实际实现取决于元件与控制电路。
2. 把驱动建模当成纯理论——方程和框图是后续控制器设计的起点。
3. 把液压固有的压力耦合误认为额外安装的压力传感反馈；电机电流环则是可选的控制结构。
:::

## 5.2.1 电气驱动

本节从电枢电压、电流和转速的关系建立伺服驱动模型。有刷永磁直流电机与采用适当换相控制的无刷电机，可以在一定工作范围内用相同形式的等效方程讨论；这不意味着两者的换相、电流波形和参数定义完全相同。

<a id="sec-5.2.1.1"></a>

### 5.2.1.1 四个基本方程

::: def 定义 5.2.1 · 电气驱动的四个基本方程 {#def-5.2.1}
在 $s$ 复数域内（教材式 5.1–5.4）：

**电枢电平衡方程**

$$V_a=(R_a+sL_a)I_a+V_g \tag{5.1}$$

**反电动势**

$$V_g=k_v\Omega_m \tag{5.2}$$

其中 $V_a,I_a$ 分别为**电枢电压和电流**，$R_a,L_a$ 分别是**电枢电阻和电感系数**，$V_g$ 表示**反电动势**——它通过**电压常数 $k_v$** 与角速度 $\Omega_m$ 成正比；$k_v$ 由电机的**具体结构与线圈磁通量**决定。

**力学平衡方程**

$$C_m=(sI_m+F_m)\Omega_m+C_l \tag{5.3}$$

**驱动力矩**

$$C_m=k_tI_a \tag{5.4}$$

其中 $C_m$ 和 $C_l$ 分别是驱动力矩与负载转矩，$I_m$ 和 $F_m$ 分别是转动惯量与电机轴上的黏滞摩擦系数。对本节理想集总直流模型，在采用一致的 SI 口径时，转矩常数 $k_t$ 与反电动势常数 $k_v$ 数值相等；换用三相电机的线电压、相电压、峰值或有效值时，须先核对各自定义。
:::

四个方程的读法：**(5.1)+(5.2) 是「电」，(5.3)+(5.4) 是「机」，$k_t=k_v$ 是电与机之间的桥**。反电动势 $V_g$ 的存在说明：电机转得越快，留给「推电流」的电压越少——这正是电机**自然的速度负反馈**。

这些 $s$ 域式子来自时域电压平衡 $v_a=R_ai_a+L_a\dot i_a+v_g$、机械平衡 $c_m=I_m\dot\omega_m+F_m\omega_m+c_l$，以及 $v_g=k_v\omega_m$、$c_m=k_ti_a$。这里 $s$ 为拉普拉斯变量，$\Omega_m$ 是角速度的拉普拉斯变换；式 (5.1)–(5.4) 假定初始条件为零。$R_a$ 的单位为 $\Omega$，$L_a$ 为 H，$I_m$ 为 $\mathrm{kg\,m^2}$，$F_m$ 为 $\mathrm{N\,m\,s/rad}$，$k_v$ 为 $\mathrm{V\,s/rad}$，$k_t$ 为 $\mathrm{N\,m/A}$。

怎样从四式得到驱动模型？先由电压式消去电流，再代入力矩平衡：

$$I_a=\frac{V_a-k_v\Omega_m}{R_a+sL_a},\qquad
\big[(sI_m+F_m)(R_a+sL_a)+k_tk_v\big]\Omega_m
=k_tV_a-(R_a+sL_a)C_l.$$

这一步保留了电感与负载。下面的两种近似是在不同反馈结构下简化它，而不是同一公式无条件地变形。

<a id="sec-5.2.1.2"></a>

### 5.2.1.2 含电流反馈的驱动框图

功率放大器本身的模型很简单（教材式 5.5）：

$$\frac{V_a}{V_c}=\frac{G_v}{1+sT_v} \tag{5.5}$$

其中 $G_v$ 是**电压增益**，$T_v$ 是**时间常数**。它的量级值得记：当调制频率在 **10 kHz 到 100 kHz** 范围时，放大器的时间常数在 $10^{-5}$ 到 $10^{-4}$ s 量级——**比机械时间常数小几个数量级**，因此后面做降阶模型时可以令 $T_v\approx 0$。

::: def 定义 5.2.2 · 电流反馈回路的双重目的 {#def-5.2.2}
带功率放大器的电气驱动框图（教材图 5.2）里，除上述环节外还有三样东西：

1. 一个**电枢电流反馈**（current feedback）回路——电流由**电机功率放大器与电枢线圈之间的传感器 $k_i$** 测量；
2. 一个**电流调节器** $C_i(s)$；
3. 一个**饱和非线性特性**元件。

**这一反馈有双重目的**（教材 §5.2.1）：

- **其一**：电压 $v_c$ 起到**参考电流**的作用；通过选择适当的调节器 $C_i(s)$，可以**减小电流 $I_a$ 与电压 $v_c$ 之间的滞后**。
- **其二**：引入**饱和非线性**可以限制 $v_c$ 的值，从而**起限流作用**——在非正常工作条件下**保证对功率放大器的保护**。
:::



<a id="sec-5.2.1.3"></a>

### 5.2.1.3 两种特性：速度控制发电机与力矩控制发电机

现在到了本节的核心：**同一个电机，配上不同的调节器与电流反馈取舍，会表现成两种完全不同的「发电机」**（教材 §5.2.1）。

::: thm 定理 5.2.A · 两种特性与统一传递函数 {#thm-5.2.A}
**（一）$k_i=0$（不加电流反馈）⇒ 速度控制发电机（velocity-controlled generator）。**
驱动器具有与**速度控制发电机**相同的特性。除 $T_v\approx0$、单位比例控制器、电气动态可忽略外，还需 $F_m\ll k_vk_t/R_a$。令 $V_a\approx G_vV_c'$、$L_a\approx0$，上式化为 $(sI_m+F_m+k_vk_t/R_a)\Omega_m=(k_tG_v/R_a)V_c'-C_l$；再忽略 $F_m$ 得

$$\Omega_m=\frac{\dfrac{1}{k_v}}{1+s\dfrac{R_aI_m}{k_vk_t}}\;G_vV_c'-\frac{\dfrac{R_a}{k_vk_t}}{1+s\dfrac{R_aI_m}{k_vk_t}}\;C_l \tag{5.9}$$

**（二）$k_i\neq0$ 且电流回路取大回路增益（$Kk_i\gg R_a$）⇒ 力矩控制发电机（torque-controlled generator）。**
此时（教材式 5.10）：

$$\Omega_m=\frac{\dfrac{k_t}{k_iF_m}}{1+s\dfrac{I_m}{F_m}}\;V_c'-\frac{\dfrac{1}{F_m}}{1+s\dfrac{I_m}{F_m}}\;C_l \tag{5.10}$$

力矩控制时，合成比例增益为 $K$，近似写 $V_a=K(V_c'-k_iI_a)$。忽略电感后，$(R_a+Kk_i)I_a=KV_c'-k_v\Omega_m$；代入机械方程，残余电磁阻尼为 $k_tk_v/(R_a+Kk_i)$。式 (5.10) 还要求该项远小于正的 $F_m$，且 $Kk_i\gg R_a$，才可取 $I_a\approx V_c'/k_i$ 并采用所列机械时间常数。若 $F_m=0$，应直接保留 $I_m s$ 的形式，不用含 $1/F_m$ 的表达式；饱和和有限电流环带宽也会限制近似。

式 (5.9) 的输入是 $G_vV'_c$，式 (5.10) 的输入是 $V'_c$。角位置满足 $\Theta_m=\Omega_m/s$（零初始条件），因此把两式的参考输入到速度关系各乘 $1/s$，才得到下面的统一形式。$M(s)$ 在速度控制情形不包含外置的 $G_v$。

「考虑到 $G_v$ 的值比较大，**驱动力矩实际上独立于角速度**。」

**（三）统一形式。** 控制输入与执行器位置输出之间的关系，可以用统一的传递函数表示（教材式 5.11–5.13）：

$$M(s)=\frac{k_m}{s(1+sT_m)} \tag{5.11}$$

$$\text{速度控制：}\quad k_m=\frac{1}{k_v},\qquad T_m=\frac{R_aI_m}{k_vk_t} \tag{5.12}$$

$$\text{力矩控制：}\quad k_m=\frac{k_t}{k_iF_m},\qquad T_m=\frac{I_m}{F_m} \tag{5.13}$$
:::

**注意放大器的位置差别**：在速度控制近似式 (5.9) 中，功率放大器的 $G_v$ 显式作用于输入；在力矩控制的大电流环增益近似式 (5.10) 中，$G_v$ 不再单独出现，电流参考与力矩之间含 $1/k_i$。老师提到电流环使带宽增大；具体带宽取决于调节器、放大器及电机参数，不能只由外层机械时间常数确定。


::: thm 定理 5.2.B · 电流反馈的取舍结论 {#thm-5.2.B}
在 $F_m\ll k_vk_t/R_a$ 且前述降阶条件成立时，比较 5.9 与 5.10 可见：所列速度控制模型的负载力矩到速度的静态增益和时间常数较小。这是这两个模型和参数条件下的比较，不代表所有带电流环的驱动器都比无电流环方案抗扰差。

**但保护问题仍要解决**：此时可以通过**在反馈回路上使用具有死区非线性特性的电流反馈**来限制电流，而**不是**用控制信号的饱和来限制（教材图 5.5）。这样得到的电流限制「切实可行，**其精度与死区斜率一样高**」。

**反过来**：原书第 8.5 节的集中控制方案要求驱动近似为力矩源，可用适当的电流调节器 $C_i(s)$ 实现。电流测量间接提供电磁力矩信息：$C_m=k_tI_a$，反过来 $I_a=C_m/k_t$；不要把电流到力矩的增益写成 $1/k_t$。
:::

**死区限流怎样工作？** 课件把正常工作和大电流分成两个区间：电流未达到设定阈值时，非线性反馈输出为零，驱动保留上述速度控制特性；超过阈值后，反馈随超出部分增大，抑制电流继续上升。理想对称死区可写作 $d(i_a)=0$（$|i_a|\le i_{\rm lim}$）和 $d(i_a)=g_d[i_a-\operatorname{sgn}(i_a)i_{\rm lim}]$（$|i_a|>i_{\rm lim}$），其中 $i_{\rm lim}>0$ 为电流阈值、$g_d>0$ 为死区外的反馈斜率，$d(i_a)$ 从参考输入中减去；这只是把课件的折线写成分段式，并未给出具体设定值。有限斜率下电流仍会随输入和反电动势变化，并非精确钳在阈值上。老师在 01:21:07–01:21:50 解释的正是这种分区：低电流时不启用电流反馈，大电流时再由反馈限制。

### 5.2.1 小结与常见错误

- **四个方程**：电枢电平衡、反电动势、力学平衡、力矩方程；$k_t=k_v$ 是电—机之间的桥。
- **一条反馈**：电流反馈的**双重目的**（减小滞后 + 限流保护），以及它与**饱和非线性**的分工（饱和用在控制信号上，死区非线性用在反馈上）。
- **两种特性**：速度控制与力矩控制分别来自不同反馈结构和近似；负载扰动响应须在给定模型及参数下比较。
- **一个统一式**：$M(s)=\dfrac{k_m}{s(1+sT_m)}$——位置输出对控制输入，一阶惯性 + 一个积分。

::: think 常见错误清单 · 自查三条
1. 混用电机常数口径：本节理想直流模型中 $k_v$ 与 $k_t$ 的 SI 数值相等，其他电机或测量口径须核对定义。
2. 把本节两种近似模型的抗扰比较推广到所有驱动器：电流环是否有利要结合控制结构、参数、限幅与任务判断。
3. 忘了放大器的时间常数**比机械时间常数小几个数量级**——这是降阶模型成立、模型里可以令 $T_v\approx0$ 的根据。
:::

## 5.2.2 液压驱动

上一节从电压、电流建立电机模型。液压驱动也从物理平衡出发，但变量换成流量与压力，必须另写渗漏、液体压缩和阀口关系，才能画出液压框图。

<a id="sec-5.2.2.1"></a>

### 5.2.2.1 六条基础方程

::: def 定义 5.2.3 · 液压驱动的基础方程组 {#def-5.2.3}
「无论液压伺服发动机的构造如何」，其输入/输出数学模型的导出都需要借助三类基础方程：**流速与压力的关系、流体与运动部件的关系、运动部件的力学平衡**（教材 §5.2.2）。令 $Q$ 为**分布器提供的体积流速**：

**（一）流速平衡**

$$Q=Q_m+Q_l+Q_c \tag{5.14}$$

其中 $Q_m$ 为**传送到发动机的流速**，$Q_l$ 为**渗漏的流速**，$Q_c$ 为**与液体可压缩性相关的流速**。教材强调：**在高工作压力（100 个大气压级）下，需要考虑 $Q_l$ 项和 $Q_c$ 项**。

**（二）渗漏**（$p$ 为由载荷造成的伺服发动机压差）

$$Q_l=k_l p \tag{5.15}$$

**（三）可压缩性**（$V$ 为流体瞬时体积，$\gamma$ 为液体的均匀可压缩性系数）

$$Q_c=\gamma V sp \tag{5.16}$$

注意比例因子 $k_c=\gamma V$ **取决于流体体积**：**旋转伺服发动机**中 $k_c$ 为常数；而**线性伺服器**中流体体积是变化的，**从而响应特性取决于工作点**。

**（四）流速与运动**

$$Q_m=k_q\Omega_m \tag{5.17}$$

传送到发动机的体积流速**与每单位时间的腔体容积变化成比例**；对旋转伺服发动机，这种变化与**角速度**成比例。

**（五）力学平衡**

$$C_m=(sI_m+F_m)\Omega_m+C_l \tag{5.18}$$

与电气驱动的 (5.3) 式**形式完全相同**。

**（六）驱动力矩与压差**

$$C_m=k_p p \tag{5.19}$$

**（七）伺服阀**（阀杆位置 $x$ 与控制电压 $v_c$ 之间）

$$\frac{x}{V_c}=\frac{G_c}{1+sT_c} \tag{5.20}$$

上式得益于**通过位置反馈得到的线性化影响**；$G_c$ 为伺服阀的**等价增益**，时间常数 $T_c$ 为**毫秒级**，相对系统其他时间常数可忽略。

**（八）分布器**（压差、流速与阀杆位移的关系**高度非线性**，在工作点处线性化）

$$p=k_x x-k_r^{(v)} Q \tag{5.21}$$
:::

这里 $Q,Q_m,Q_l,Q_c$ 的单位是 $\mathrm{m^3/s}$，压差 $p$ 的单位是 Pa，$x$ 为阀杆位移（m），$\Omega_m$ 为角速度（rad/s）。式中使用零初始条件下的拉普拉斯变换，$s$ 是拉普拉斯变量，$V$ 在工作点附近取常数。$k_l$ 是渗漏流量对压差的系数，$\gamma$ 的单位是 $\mathrm{Pa^{-1}}$；$k_q$ 是每单位转角的排量，$k_p$ 是压差到转矩的系数。$k_x$ 和 $k_r^{(v)}$ 分别是工作点附近压差对阀杆位移、流量的线性化系数；上标 $(v)$ 用来区分下一节的减速比 $k_r$。

阀口线性化式中的 $p,Q,x$ 应理解为选定工作点附近的增量；非零工作点的完整变量还须加回常值项。式 (5.16) 的 $V$ 是该集总压力模型的等效受压体积，多腔液压缸须按各腔面积、容积和压差定义重新推导，不能直接把两腔总体积不加系数地代入。

把几条支路连起来：流量平衡代入渗漏、压缩和运动方程，得

$$Q=k_q\Omega_m+k_lp+k_cs p,\qquad k_c=\gamma V.$$

压缩项在时域为 $k_c\dot p$：升压时，一部分流量用于压缩腔内油液。再把分布器式代入，可整理成

$$\bigl[1+k_r^{(v)}(k_l+k_cs)\bigr]p=k_xx-k_r^{(v)}k_q\Omega_m.$$

因此阀杆位移影响压差，压差通过 $C_m=k_pp$ 驱动机械侧；转速和压差又经流量平衡影响压差。这是方框图中固有的物理耦合，而不是额外安装的电流传感反馈。

::: method 方法 5.2.C · 与电气驱动逐条对照 {#method-5.2.A}
| 电气驱动 | 液压驱动 | 说明 |
|:--|:--|:--|
| (5.1) $V_a=(R_a+sL_a)I_a+V_g$ | (5.14)(5.15)(5.16) | 电气侧一个方程，液压侧拆成**渗漏 + 可压缩性**两项 |
| (5.2) $V_g=k_v\Omega_m$ | (5.17) $Q_m=k_q\Omega_m$ | 都是「转动产生一个抵消输入的效应」 |
| (5.3) $C_m=(sI_m+F_m)\Omega_m+C_l$ | (5.18) 同式 | **完全相同的机械侧方程** |
| (5.4) $C_m=k_tI_a$ | (5.19) $C_m=k_pp$ | 电流 ↔ 压差 |
| (5.5) 放大器 $G_v/(1+sT_v)$ | (5.20) 伺服阀 $G_c/(1+sT_c)$ | 均用一阶惯性近似；时间常数能否忽略须与其他动态比较 |
| （无对应） | (5.21) 分布器线性化 | 液压侧特有的非线性环节 |
:::

对照出来的结论就是 [5.2 驱动](sec5-2.md#sec-5.2.a) 那句：**框图结构平行，但压力反馈层是液压的结构特征，不像电流反馈那样可以拆掉**。

### 5.2.2 小结与常见错误

- **一句话**：液压和电气模型可按变量类比，但液压模型的渗漏、压缩和阀口压差关系须分别建立。

- **一个差别**：压力反馈去不掉（结构特征）；旋转式 $k_c$ 为常数，直线式与工作点有关。

## 5.2.3 传动装置影响

第四章算出了关节速度。装上减速器以后，电机转速与关节速度不同，动力学方程也必须说明写在哪一侧。先从理想传动的功率相等出发：如果电机转得更快，它需要提供的力矩应怎样变化？

本节把负载折算到电机侧，推导力矩的一次减速比因子，以及惯量、黏滞摩擦的平方因子。推导时一直保留“电机侧”与“关节侧”的标记。读完做[两连杆第六关](../training/two-link.md#mission-drive)，同时检查力矩获益与电机转速要求。

<a id="sec-5.2.3.1"></a>

### 5.2.3.1 齿轮模型与减速比

教材用一个**一对圆柱齿轮**（半径 $r_m$ 与 $r$）构成的机械齿轮来量化（教材图 5.7）：假定运动副是**理想的（没有间隙）**，并把伺服发动机旋转轴与相应关节轴连接起来。

::: def 定义 5.2.4 · 减速比与齿轮耦合 {#def-5.2.4}
记号约定（教材 §5.2.3）：伺服电机转子由绕其旋转轴的**转动惯量 $I_m$** 与**粘滞摩擦系数 $F_m$** 表征；同样地 $I$ 和 $F$ 表示**载荷**的转动惯量与粘滞摩擦系数。齿轮本身的转动惯量和摩擦系数**被包含在**上述参数里。

- $C_m$：发动机**驱动转矩**；$C_l$：施加到载荷的**负载转矩**；
- $\omega_m,\vartheta_m$：发动机轴的角速度与位置；$\omega,\vartheta$：载荷的相应量；
- $f$：两齿轮齿咬合时的**交换力**。

**减速比**定义为

$$k_r=\frac{\omega_m}{\omega}=\frac{r}{r_m} \tag{5.22}$$

这里两轴各自的正方向按传动关系选取，使 $k_r>0$；若外啮合两齿轮都按同一空间方向记角，则需另带反向符号。无打滑关系在本节的正向约定下为 $r_m\vartheta_m=r\vartheta$。

**典型值**：对机器人机械手伺服发动机与关节耦合的情形，减速比**远大于 1**（$r_m\ll r$），典型值**从几十到几百**。
:::

把这个定义用到前面那台两连杆上。两杆各长 $1\,\mathrm m$，$q_1$ 从固定 $x$ 轴逆时针量起，$q_2$ 是第二杆相对第一杆的角度。在 $q_A=(0,\pi/2)$，末端向外施加 $F=(0,10)\,\mathrm N$；仍按第三章的静力题忽略杆的自重、惯量与摩擦。位置雅可比与所需关节驱动力矩是

$$J_p(q_A)=\begin{bmatrix}-1&-1\\1&0\end{bmatrix}\,\mathrm m,\qquad
\tau=J_p^{\mathrm T}F=\begin{bmatrix}10\\0\end{bmatrix}\,\mathrm{N\cdot m}.$$

只给关节 1 接上理想减速器，取 $k_r=10$（也就是本题的 $k=10$），不计传动损耗和惯量。由 $\omega_m=k_r\dot q_1$ 与虚功关系，电机力矩为

$$\tau_m\,\delta\vartheta_m=\tau_1\,\delta q_1,\qquad
\delta\vartheta_m=10\,\delta q_1
\quad\Longrightarrow\quad
\tau_m=\frac{10}{10}=1\,\mathrm{N\cdot m}.$$

静止时两侧真实角速度都为零，真实机械功率都是零；不能把两个零相除来求力矩比。核对折算时，另取兼容的**虚速度** $\dot q_1^*=0.1\,\mathrm{rad/s}$，则 $\omega_m^*=1\,\mathrm{rad/s}$，有

$$\tau_m\omega_m^*=1\times1=1\,\mathrm W
=\tau_1\dot q_1^*=10\times0.1.$$

这个 $1\,\mathrm W$ 是虚功关系的检验值，不表示静止保持正在输出 $1\,\mathrm W$ 的机械功率，也不表示电机没有电损耗。

省下力矩以后，再检查转速。现在撤掉接触力，回到第四章从 $q_A=(0,\pi/2)$ 到 $q_B=(\pi/2,-\pi/2)$ 的换姿势轨迹；这里只核对运动学转速，不计算运动力矩。取 $u=t/T$、$s=3u^2-2u^3$，$q_1=\pi s/2$、$q_2=\pi/2-\pi s$，则

$$\dot q_1=\frac{\pi}{2}\frac{6u(1-u)}{T},\qquad
|\dot q_1|_{\max}=\frac{3\pi}{4T},\qquad
|\omega_m|_{\max}=\frac{30\pi}{4T}.$$

峰值在 $u=1/2$。当 $T=2\,\mathrm s$，关节 1 峰值为 $3\pi/8\approx1.178\,\mathrm{rad/s}$，电机峰值却是 $15\pi/4\approx11.781\,\mathrm{rad/s}$。若电机限速为 $10\,\mathrm{rad/s}$，必须满足

$$\frac{30\pi}{4T}\le10\,\mathrm{rad/s}
\quad\Longrightarrow\quad T\ge\frac{3\pi}{4}\,\mathrm s\approx2.356\,\mathrm s.$$

这只是关节 1 电机的转速下限检查，不是整机可行时间的完整判据；第二台电机、驱动力矩和加速度等限制还要分别核对。减速器把力矩需求降了十倍，也把电机转速需求提高了十倍。下面保留惯量和摩擦，看看它们为什么要按平方折算。

::: thm 定理 5.2.D · 等效惯量与等效摩擦 {#thm-5.2.C}
交换力 $f$ 在两个轴上分别产生**负载力矩 $f\,r_m$**（作用在发动机轴上）与**驱动力矩 $f\,r$**（作用于载荷）。于是发动机与载荷的力学平衡分别是

$$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m \tag{5.23}$$
$$fr=I\dot\omega+F\omega+C_l \tag{5.24}$$

利用 $k_r$ 把载荷量折算到发动机轴、消去 $f$，得到**发动机轴上的等效力学平衡**：

由 $r_m/r=1/k_r$，先把负载式乘 $1/k_r$，再用 $\omega=\omega_m/k_r$：

$$fr_m=\frac{I\dot\omega+F\omega+C_l}{k_r}
=\frac{I}{k_r^2}\dot\omega_m+\frac{F}{k_r^2}\omega_m+\frac{C_l}{k_r}.$$

惯量和摩擦各有两个因子：一个来自力矩折算，另一个来自速度或加速度折算。将此式代回电机轴平衡得

$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{C_l}{k_r} \tag{5.25}$$

其中

$$I_{eq}=I_m+\frac{I}{k_r^2},\qquad F_{eq}=F_m+\frac{F}{k_r^2} \tag{5.26}$$

上述动力学折算假定刚性、定比、无打滑且齿轮接触传力无损。若电机正向驱动负载、效率为 $\eta_t$，稳态传递转矩的大小满足 $C_{\rm out}=\eta_t k_r C_{\rm in}$，而不是无条件的 $k_r C_{\rm in}$。例如 $k_r=10$、$\eta_t=0.9$、关节需 $10\ \mathrm{N\cdot m}$ 时，电机输入传动的转矩需 $10/(0.9\times10)\approx1.111\ \mathrm{N\cdot m}$。反向驱动、静摩擦和动态储能须另建损耗模型，不能把同一个效率直接套到所有符号方向。

**读法（教材原话）**：在齿轮具有大减速比的情形下，式 (5.25)(5.26) 描述了**载荷的转动惯量和粘滞摩擦系数是如何按减速因子 $1/k_r^2$ 反映到发动机轴的**；相反，**负载力矩由因子 $1/k_r$ 而减小**。而且——**如果这个力矩以非线性方式依赖于 $\vartheta$，则存在大减速比将使其趋向于线性化动态方程**。
:::

这一条是本节的**全部要害**：$1/k_r^2$ 与 $1/k_r$ 两个因子解释了为什么工业机器人敢于用「小电机 + 大减速器」：

| 量 | 折算因子 | 减速比 100 时 |
|:--|:--|:--|
| 载荷转动惯量 $I$ | $1/k_r^2$ | 缩小 **10000 倍** |
| 载荷粘滞摩擦 $F$ | $1/k_r^2$ | 缩小 **10000 倍** |
| 负载力矩 $C_l$ | $1/k_r$ | 缩小 **100 倍** |
| 非线性项（如重力矩） | $1/k_r$（且自变量也缩小） | 显著弱化 |

对照 [@def-5.1.6] 第 1 条「低惯量」：**减速器降低载荷折算到电机轴的惯量；能否忽略它，还要与电机自身惯量比较**——这正是老师说的「惯量小就比较容易控制」（0:33:01）。


<a id="sec-5.2.3.2"></a>

### 5.2.3.2 例 5.1：由齿轮驱动的刚体摆

::: ex 例 5.1 · 由机械齿轮驱动的摆（教材例 5.1） {#ex-5.2.D}
如图 5.8，一个**刚体摆**受到转矩 $f\cdot r$ 通过齿轮到载荷轴的驱动。系统的动态方程组为

$$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m \tag{5.27}$$
$$fr=I\dot\omega+F\omega+mgl\sin\vartheta \tag{5.28}$$

其中 $\vartheta$ 从竖直向下的稳定平衡位置量起，$\omega=\dot\vartheta$，电机角零点与之按传动关系对齐；因此重力恢复力矩写在平衡式右侧为 $mgl\sin\vartheta$。$I$ 为摆绕载荷轴的惯量，$F$ 为黏滞摩擦系数，$m$ 为质量，$l$ 为转轴到质心的距离（均匀杆长 $L$ 时 $l=L/2$），$g$ 为重力加速度。

**把 (5.28) 折算到发动机轴**，得到

$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{mgl}{k_r}\sin\frac{\vartheta_m}{k_r} \tag{5.29}$$

教材的评语是：「从中可以清楚地看到**因子 $k_r$ 是如何降低非线性项的作用的**」。

**这一步为什么重要？** 幅值除以 $k_r$，使负载重力项在电机端的绝对值减小；但坐标代换不消除正弦的非线性。只有把**电机角变化范围固定**，$\Delta\vartheta=\Delta\vartheta_m/k_r$ 才会随着减速比增大而变小，适合局部线性化。

如果任务要求关节转过同样的 $90^\circ$，则电机必须转过 $k_r\times90^\circ$，正弦的自变量仍覆盖原来的关节角范围。大减速比本身不保证整个工作区能用一条直线近似；还需比较负载项、耦合项与电机惯性项的实际大小。
:::

**推广到 n 连杆机械手**：教材指出，这个摆的例子「被看作是对具有转动关节的 $n$ 连杆机械手的描述」——**把连杆视为孤立于其他连杆，其每一个连杆可以看作简单的刚体摆**。当然，与其他连杆的连接会引入使输入/输出模型复杂化的非线性影响：「在**双摆**情形下，**第一连杆的发动机转动惯量同样取决于第二连杆的角位置**」。

这里引用的“发动机转动惯量”应理解为电机侧包含载荷的等效惯量；电机转子自身的惯量并不因第二连杆改变位置而改变。

结论：**「不同连杆的发动机之间的非线性耦合，将如何通过存在大减速比的（传动）而得到减小」**——本教程[第六章动力学](../ch06/overview.md)（原书第 7 章）会继续研究这一点。

**老师把「两端情形」讲得很清楚**（01:29:05–01:29:49），值得单独记下来：

| | $k_r$ 很大（工业常态，典型几十到几百） | $k_r$ 接近 1（直驱或小减速比） |
|:--|:--|:--|
| 载荷惯量 $I/k_r^2$ | 比较 $I/(k_r^2I_m)$ 后判断能否忽略 | 负载惯量几乎原样落到电机轴，是否主导取决于 $I/I_m$ |
| 非线性项 $mgl\sin(\cdot)/k_r$ | 电机端幅值减小；固定电机小行程时可局部线性化 | 电机端负载项较大，需按实际范围建模 |
| 建模与控制的后果 | 剩余耦合及负载扰动足够小时，可采用独立关节近似 | 更需检查非线性与关节耦合，决定是否补偿 |
| $I_{eq}$ 的构成 | 当 $I/(k_r^2I_m)\ll1$ 时由 $I_m$ 主导 | 由给定惯量决定，不能只看 $k_r$ |

一句话：**$k_r$ 改变负载折算量级，是否可线性近似还取决于行程与参数**——这既解释了工业机械手为什么敢用「小电机 + 大减速器」，也解释了直驱（[@def-5.1.4]）为什么「对控制算法的要求非常高」（0:35:19）。

### 5.2.3 小结与常见错误

- **两个因子**：惯量与摩擦 $1/k_r^2$；负载力矩与非线性 $1/k_r$。
- **一个方程**：$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+C_l/k_r$ ——后面几章到处用它。
- **一个推论**：大减速比有助于减小折算负载项；独立关节线性近似还需检验惯量比、耦合与实际行程。

::: think 常见错误清单 · 自查三条
1. 把两个折算因子都用成 $1/k_r$ 或都用成 $1/k_r^2$——记住**惯量/摩擦是平方，力矩是一次**。
2. 在 (5.29) 里只写 $mgl\sin\vartheta_m/k_r$ 而把 $k_r$ 放错位置——正确形式是 $\dfrac{mgl}{k_r}\sin\dfrac{\vartheta_m}{k_r}$（两个 $k_r$ 各在一处）。
3. 以为减速比只影响「力矩放大」——它对**惯量**的影响（平方缩小）往往更重要。
:::

## 5.2.4 位置控制

前面三节建立了驱动模型，本节用位置反馈让电机跟踪给定轨迹。先区分驱动对象与控制器：对象本身有一个原点极点；在所讨论的结构中加入积分控制器后，开环才有两个原点极点。

<a id="sec-5.2.4.1"></a>

### 5.2.4.1 从驱动模型到关节运动控制

教材的问题陈述是：在研究了电气/液压驱动的**角速度控制模式**之后，需要解决**一般的机械手连杆运动控制问题**——「寻找一种能够以自动化方式决定数值时间变化的结构来控制驱动，从而驱使关节执行期望的运动，使末端执行器完成给定的任务」。

流程：**末端执行器姿态轨迹 → 逆运动学 → 各关节期望轨迹 $\vartheta'(t)$**。若控制的是电机侧位置，按上一节的正向约定，参考值需先换成 $\vartheta'_m=k_r\vartheta'$；传感器测量值和参考值必须位于同一侧。

::: def 定义 5.2.5 · 独立关节近似 {#def-5.2.5}
教材先给出**最简解**：「首先近似地，设关节运动**独立于其他关节**的运动，即**可以将交互作用视为干扰**」。

于是问题化为：假定关节参考轨迹 $\vartheta'(t)$ 已知，电机角位置 $\vartheta_m$ 要跟踪换算后的 $\vartheta'_m$。位置传感器的增益记为 $k_{TP}$；反馈控制器还须处理发动机和载荷的模型不确定性与干扰。

**为什么选直流伺服电机**做关节位置控制？教材给的动机是：「这些执行器具有的**高度灵活性**，在大多数运动控制应用中提供了**优良的响应能力**」。
:::

上一节给出近似的出发点：大减速比可以减小电机侧折算负载与耦合的影响。是否足以把剩余耦合作为扰动，仍要检查具体惯量比、运动范围和控制精度；本教程[第七章](../ch07/sec7-2.md)进一步讨论独立关节控制。

<a id="sec-5.2.4.2"></a>

### 5.2.4.2 位置反馈：积分解决什么问题

位置伺服需要一个**控制器**：它产生施加到功率放大器的信号，「信号能够自动生成驱动转矩，产生非常接近期望运动 $\vartheta'$ 的轴运动。其结构应该使得参考输入和测量输出之间的**误差最小化**，即使是在发动机、载荷和扰动的动态知识**不准确**的情形下」。

::: thm 定理 5.2.F · 位置反馈控制器：PI 的理由 {#thm-5.2.D}
先分析单位位置反馈、恒定目标及恒定负载力矩。设 $r$ 为期望位置，$y=\vartheta_m$ 为电机位置，$e=r-y$ 为位置误差，$u$ 为驱动输入；传感器增益与放大器增益先并入比例常数。由 [@thm-5.2.A]，电压到位置的对象为

$$M(s)=\frac{k_m}{s(1+sT_m)},\qquad k_m>0,\quad T_m>0.$$

对象的极点是 $s=0$ 和 $s=-1/T_m$，只有一个在原点。速度控制驱动中，把负载力矩折算为输入端的等效扰动 $d$，于是 $Y=M(U-D)$。例如式 (5.9) 中，若 $u=G_vV'_c$，则 $d=(R_a/k_t)C_l$；比例系数取决于选定的输入位置。

先试比例控制 $U=K_pE$，其中 $E$ 是误差 $e$ 的拉普拉斯变换，$K_p>0$。闭环特征方程为

$$1+K_pM(s)=0\quad\Longleftrightarrow\quad T_ms^2+s+k_mK_p=0.$$

它可以稳定，但对恒定扰动 $d_0$，稳态需要 $u=d_0$，所以 $e_{\rm ss}=d_0/K_p$：增大 $K_p$ 可减小误差，却不能在有限增益下完全消除它。

再令 $C(s)=K_p+K_I/s$，其中 $K_I>0$ 是积分增益。积分器可在误差趋于零后保留抵消恒定扰动所需的控制输出。前向通路为

$$C(s)M(s)=\frac{k_m(K_ps+K_I)}{s^2(1+sT_m)}.$$

这里两个原点极点分别来自**位置对象和控制器的积分项**，不是对象自身的两个极点。其闭环特征方程为

$$T_ms^3+s^2+k_mK_ps+k_mK_I=0.$$

由三阶 Routh 判据，在上述正参数下还需 $K_p>T_mK_I$ 才稳定。闭环稳定时，恒定位置参考和恒定负载扰动下 $e_{\rm ss}=0$。积分并非所有位置伺服都必须采用；这一结论针对本节的反馈结构和恒定扰动，也可通过其他结构满足稳态要求。
:::

纯比例的位置环和带 PI 的位置环是两个不同结构。加入测速反馈是为了提供额外的动态调节自由度；是否改善瞬态还取决于参数、传感器噪声和机械共振。


<a id="sec-5.2.4.3"></a>

### 5.2.4.3 位置 + 速度反馈：测速反馈的作用

::: method 方法 5.2.G · 测速反馈的两条改进 {#method-5.2.E}
为了改善瞬态响应，工业中使用的位置伺服驱动还可能具有**基于角速度测量的局部反馈回路（测速反馈）**。具有**位置和速度反馈**的一般结构如图 5.11：除位置传感器外，还使用一个常数为 $k_{TV}$ 的**速度传感器**，以及一个增益为 $K_r$ 的**简单比例控制器**。**采用测速反馈的同时，在内部速度回路中保留具有参数 $K_v$ 和 $T_v$ 的比例积分控制器**，以消除稳定状态下干扰对位置 $\vartheta_m$ 的影响。

它带来两条改进：

1. **干扰抑制更强**：在干扰点附近存在**两个（而非一个）反馈回路**，期望在**瞬态过程中也能进一步减小**干扰对输出的影响；
2. **瞬态响应更好**：灵活选择控制参数，有可能得到具有**更宽带宽**并且**减少振荡**的 $\vartheta_m$ 与 $\vartheta'$ 之间的传递函数——其结果是**更快的瞬态响应并减小振荡**，从而提高 $\vartheta_m(t)$ 跟踪更高要求的参考轨迹 $\vartheta'(t)$ 的能力。
:::

用符号看两个环的连接：设 $G(s)=k_m/(1+sT_m)$ 是从电机侧等效输入到角速度的对象，$C_v(s)=K_{pv}+K_{iv}/s$ 是速度 PI，$K_r$ 是位置比例增益，$R,\Theta_m,\Omega_m$ 分别是电机侧位置参考、实际位置和速度的拉普拉斯变换。将传感器增益并入控制器，并在本段忽略负载扰动，则

$$\Omega_m=G C_v\left[K_r(R-\Theta_m)-\Omega_m\right],\qquad \Theta_m=\frac{\Omega_m}{s}.$$

内环比较的是速度指令 $K_r(R-\Theta_m)$ 与测得速度，外环比较的是位置。整理可得 $\Theta_m/R=K_rGC_v/[s(1+GC_v)+K_rGC_v]$。调节 $C_v$ 与 $K_r$ 会改变闭环极点；增加测速通路本身不保证所有参数下都更快或更稳定。


**两条收尾结论**（教材 §5.2.4 末）：

::: note 两条推广 {#note-5.2.1}
**（一）用电流控制电机实现位置伺服。** 从 [@thm-5.2.A] 的力矩控制式可见，若以参考电压为输入，负载力矩对应的等效输入扰动为 $(k_i/k_t)C_l$；速度控制式若以 $G_vV'_c$ 为输入，则为 $(R_a/k_t)C_l$。大电流环增益近似下 $G_v$ 不再单独出现，但这不是对有限增益和全部频率的精确结论。

**（二）推广到齿轮耦合。** 上面给出的一般控制结构可以推广到**发动机通过齿轮耦合到负载**的情形：此时采用式 (5.25)(5.26) 就足够了，即**用 $I_{eq}$ 和 $F_{eq}$ 代替 $I_m$ 和 $F_m$，并用因子 $1/k_r$ 衡量干扰**。
:::

**「上述分析将在 8.3 节中进一步详述。」**——本节到此为止，控制器怎么设计、参数怎么取，是原书第 8 章的正题。

4. 用电流控制电机做位置伺服时，$G_v$ 为什么不起作用？推广到齿轮耦合时要用哪些量替换？

::: sol 核对

**把关节之间的耦合当作干扰**，先假设各关节独立，再靠鲁棒反馈抑制耦合。成立依据：大减速比把耦合惯量按 $1/k_r^2$、把耦合力矩按 $1/k_r$ 削弱（[@thm-5.2.C]）。

对象 $M(s)$ 只有一个原点极点；PI 控制器再加入一个。对本节的恒定输入端扰动，纯比例控制有 $e_{\rm ss}=d_0/K_p$；闭环稳定时，积分作用可消除该稳态误差。稳定还要求参数满足 $K_p>T_mK_I$，不能只凭加了比例项就断言稳定。

测速内环增加了动态调节自由度；若参数合适，可改善瞬态与扰动响应，但不保证必然改善。速度 PI 的积分项可在闭环稳定等条件下消除恒定扰动造成的稳态误差。

在所列大增益近似下，放大器增益不再单独出现在力矩控制近似式中；有限增益时仍会影响结果。齿轮耦合时用 $I_{eq},F_{eq}$，负载力矩按 $1/k_r$ 折算。

:::

:::

### 5.2.4 小结与常见错误

- **一条近似**：独立关节（耦合当干扰），依据是大减速比的削弱作用。
- **两个结构**：位置反馈（PI）与位置 + 速度反馈（外环位置、内环速度 PI）。
- **一条理由**：在所给结构中，积分可消除恒定负载造成的稳态误差；对象与控制器各贡献一个原点极点，参数须满足稳定条件。
- **两条推广**：电流控制电机的输入等效扰动为 $(k_i/k_t)C_l$；齿轮耦合用 $I_{eq},F_{eq}$，负载力矩按 $1/k_r$ 折算。

::: think 常见错误清单 · 自查三条
1. 认为加入积分就一定稳定：还要满足闭环稳定条件。
2. 认为测速反馈必然改善瞬态：还需检查参数、噪声与机械共振。
3. 将某组近似条件下的抗扰结论推广为所有驱动器的必然结论。
:::
