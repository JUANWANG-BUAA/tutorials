# 第五章 · 执行器与传感器

## 从运动轨迹到驱动与测量

第二到第四章算出了机械手应当怎样运动：期望位置、速度、加速度都已写成时间函数。要让真实机械手真的按这条轨迹动起来，还得回答两个硬件问题：驱动关节的力和力矩从哪里来？控制器又怎样知道关节现在转到哪儿、末端碰到了什么？本章沿“能量—驱动—传动—测量”一条链拆解这两件事。课堂对应第 6 周（2026-10-12）内容，可对照 Siciliano 等教材第 5 章阅读。

一条关节运动背后同时走着两条通路：能量通路由一次能源出发，经功率放大器、伺服发动机和传动装置把功率送到关节；信息通路由传感器测出实际运动和环境交互，送回控制器与期望值比较后再修改控制律。读 [5.1 执行系统](sec5-1.md)前先做一笔估算：给关节装上减速比 $k_r>1$ 的减速器后，输出力矩可以放大；但要保持同样的关节角速度，电机必须转得更快还是更慢？先画下“电机—减速器—关节”标明两侧转速与力矩，再读 [5.1](sec5-1.md) 与 [5.2.3 传动装置影响](sec5-2-3.md)。

## 本章主线与学习顺序

全章按“能量—驱动—传动—测量”推进，下一环用到上一环的端口口径和方程，最后交接给第六章动力学：

1. **执行系统与功率链（[5.1](sec5-1.md)–[5.1.4](sec5-1-4.md)）**：先立稳态能量账，毫瓦级控制命令经功放等比例调制一次能源送给执行器，再由传动匹配关节的低速高转矩工况；[5.1.1](sec5-1-1.md) 到 [5.1.4](sec5-1-4.md) 按从关节倒推回能源的选型顺序展开传动、发动机、功放与能源。
2. **驱动动态与位置控制（[5.2](sec5-2.md)–[5.2.4](sec5-2-4.md)）**：把部件写成微分方程与传递函数，[5.2.1](sec5-2-1.md) 与 [5.2.2](sec5-2-2.md) 分别从电气四方程和液压六方程消元；[5.2.3](sec5-2-3.md) 用减速比 $k_r$ 把负载惯量和摩擦按 $1/k_r^2$、外力矩按 $1/k_r$ 折回电机轴；[5.2.4](sec5-2-4.md) 在轴侧模型上加位置 PI 与速度反馈，为控制器闭合提供对象模型。完成 [5.2.3](sec5-2-3.md) 后可到[两连杆第六关](../training/two-link.md#mission-drive)用功率核对力矩折算和上一章轨迹所需的电机转速。
3. **本体测量（[5.3](sec5-3.md)–[5.3.2](sec5-3-2.md)）**：闭合机器人自身状态反馈环，[5.3](sec5-3.md) 把关节位置与速度接回外位置环和内速度环；[5.3.1](sec5-3-1.md) 算清编码器分辨率、格雷码与旋转变压器解调；[5.3.2](sec5-3-2.md) 对比位置差分重建速度与测速发电机的噪声、纹波边界。
4. **外部测量（[5.4](sec5-4.md)–[5.4.3](sec5-4-3.md)）**：补齐环境与接触信息，[5.4.1](sec5-4-1.md) 从应变片电桥和校准矩阵算出力系并搬回约束坐标系；[5.4.2](sec5-4-2.md) 推导声纳与激光测距模型；[5.4.3](sec5-4-3.md) 建立针孔相机外参、正面透视与内参像素映射。

## 下一章接口与复习配套

读完本章后，应能把第四章算出的任一条关节轨迹对应到电机转速、折算惯量、放大器接口与传感器反馈读数。但单轴模型里的负载阻力矩 $C_l$ 还是外部给定的已知量；[第六章动力学](../ch06/sec6-1.md)将用拉格朗日法和牛顿—欧拉法精确算出连杆加速、科氏离心与重力究竟要求每个关节输出多大力矩，并与本章的转子折算项 $k_r^2I_m$ 汇合到整机惯性矩阵里。

学习时建议先用一组减速比数值算清轴侧换算，再把折算对象代入驱动与反馈方程；微分、拉普拉斯变换与叉乘矩阵可通过正文中的回忆链接随时调回。配套自检与题解见[总结](summary.md)、[闭卷回忆卡](recall-cards.md)、[习题](exercises.md)和[作业五](homework05.md)。
