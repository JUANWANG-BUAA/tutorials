# 第五章 · 执行器与传感器

## 轨迹对电机提出了什么要求

第四章算出了关节角、速度和加速度。给关节装上减速器以后，输出力矩可以放大；但要保持同样的关节速度，电机需要转得更快还是更慢？先画出电机、减速器与关节，标出两侧速度，再读 [5.1 执行系统](sec5-1.md)和 [5.2.3 传动折算](sec5-2-3.md)。

读到 [5.3 本体传感器](sec5-3.md)时，在第一章的系统图上补上测量回路，标明控制器拿到的读数是什么。完成[两连杆第六关](../training/two-link.md#mission-drive)，用功率检查力矩折算，再核对上一章轨迹所需的电机转速。

下次只给自己减速比的定义，重新推一遍乘除方向。第六章要计算另一项驱动要求：杆有重量，还要加速，关节究竟需要多少力矩？

## 本章怎样学习

本章参考Siciliano等教材第五章与2026年10月12日课程内容。沿供能通路看能源怎样变成机械输出，沿反馈通路看实际状态怎样送回控制器；分别核对功率与信息，避免把控制信号当成主要供能。

先完成一个减速比数值例，再把轴侧关系代入电机方程。求导与拉普拉斯等旧知识可通过正文回忆链接恢复，新器件的测量或驱动原理则在正文中学习。

本章结束时，应能把一条关节轨迹对应到电机转速、负载力矩与反馈读数。第六章进一步计算连杆加速和承受重力所需的关节力矩。配套复习见[总结](summary.md)、[习题](exercises.md)和[作业五](homework05.md)。
