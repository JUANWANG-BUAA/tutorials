# 第五章 · 执行器与传感器

前四章在运动学、静力学与轨迹规划层面算出了期望的关节角位置 $\boldsymbol q(t)$、角速度 $\dot{\boldsymbol q}(t)$、角加速度 $\ddot{\boldsymbol q}(t)$ 及接触力映射。在物理机械手中，这些数学指令必须借助硬件装置实现，并由测量系统在线送回控制环：前半章（[5.1 关节执行系统](sec5-1.md)、[5.2 驱动](sec5-2.md)）分析功率如何从能源经功放、伺服发动机与传动装置传向关节并折算为 $s$ 域动力学模型；后半章（[5.3 本体传感器](sec5-3.md)、[5.4 外部传感器](sec5-4.md)）讨论如何测量关节自身状态以及机器人与环境交互的力、距离与视觉信息。

## 三、全章学习要点与后续接口

1. **硬件选型从关节端倒推**：关节通常需要低速高转矩，发动机往往处于高速低转矩高效区。先由关节力（矩）与速度确定 $P_u$，再顺次考虑传动比 $k_r$、发动机类型与放大器选配，而不是先选手边现成电机。
2. **两个减速比折算因子**：惯量与黏滞摩擦折算到电机侧按 $1/k_r^2$ 衰减，外负载力矩与重力非线性按 $1/k_r$ 衰减；但是大减速比并不自动保证全行程线性化或忽略负载惯量，仍须核算行程范围与比值 $I/(k_r^2 I_m)$。
3. **本体闭环与环境感知分工**：按**被测量物理属性**而非安装位置划分本体传感器（关节位置、速度、力矩）与外部传感器（接触力、接近、距离、视觉）。关节力矩属本体量，六维腕力传感器测交互接触力属外部传感器。
4. **向后对接动力学与控制**：本章导出的电机侧等效模型 $I_{eq},F_{eq}$ 直接进入[第六章动力学](../ch06/overview.md)（作为各关节折算转子惯量 $k_{ri}^2 I_{mi}$）；速度控制与力矩控制驱动特性及位置/速度双环反馈，则是[第七章运动控制](../ch07/overview.md)的直接被控对象。
