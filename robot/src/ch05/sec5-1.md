## 5.1.1 执行系统组成、功率流与选型出发点

### 执行系统的四个组成部分

::: def 定义 5.1.1 · 关节执行系统（actuating system） {#def-5.1.1}
施加在机械手各关节上的运动由执行系统实现。按能量转化与传递顺序，系统由四部分串联构成：
1. **能源（power supply）**：提供一次能源功率 $P_e$，自身输出能力与控制规律无关；
2. **功率放大器（power amplifier）**：接收控制器输出的微弱控制信号 $P_c$，据此调制一次能源 $P_e$，向发动机提供受控输入功率 $P_a$（内部损耗 $P_{da}$）；
3. **伺服发动机（servomotor）**：把电、液压或气动功率 $P_a$ 转化为机械功率 $P_m$（内部损耗 $P_{dm}$）；
4. **传动装置（transmission）**：将发动机输出的高转速低转矩机械功率 $P_m$ 匹配成关节所需的机械功率 $P_u$（内部摩擦损耗 $P_{dt}$）。

整条功率流链如下（功率流符号汇总见下节[定义 5.1.2](#sec-5.1.b)）：
$$P_c+P_e\;\Longrightarrow\;\boxed{\text{功率放大器}}\;\Longrightarrow\;P_a\;\Longrightarrow\;\boxed{\text{伺服发动机}}\;\Longrightarrow\;P_m\;\Longrightarrow\;\boxed{\text{传动装置}}\;\Longrightarrow\;P_u.$$
:::

控制器由快速微电子电路（例如 TTL 电平 $3.3\,\mathrm V$、电流毫安级）实现，信号功率仅 $P_c \approx 3.3\,\mathrm V\times 1\,\mathrm{mA}=3.3\,\mathrm{mW}$，计算速度可达每秒千万次以上；而单关节电机常需数十瓦至上千瓦功率（如 $100\,\mathrm W$ 约为 $P_c$ 的 $3\times 10^4$ 倍）。因此必须引入功率放大器：放大器**不能凭空创造能量**，而是由一次能源供能，按控制信号指定的幅值、极性或相位比例调制能量输出。

<a id="sec-5.1.b"></a>

### 功率流符号与准稳态功率平衡

::: def 定义 5.1.2 · 执行系统五项功率与三处损耗 {#def-5.1.2}
| 符号 | 含义 | 物理位置与口径（单位：$\mathrm W$） |
|:--|:--|:--|
| $P_c$ | 控制规律信号功率 | 控制器输出 → 功放控制端口（通常为微弱电信号） |
| $P_e$ | 一次能源供给功率 | 电源/泵站输出 → 功放主能量端口 |
| $P_a$ | 供给发动机的受控功率 | 功放输出 → 发动机输入（电、液压或气动） |
| $P_m$ | 发动机生成的机械功率 | 发动机输出轴 → 传动输入 |
| $P_u$ | 驱动关节所需机械功率 | 传动输出 → 关节负载 |
| $P_{da},\ P_{dm},\ P_{dt}$ | 三级内部损耗功率 | 分别为功放耗散、发动机损耗、传动装置摩擦损耗 |
:::

::: note 功率总是广义力与广义速度的乘积 {#note-5.1.1}
机械平动功率 $\boldsymbol F^{\mathrm T}\boldsymbol v$、机械转动功率 $\boldsymbol\tau^{\mathrm T}\boldsymbol\omega$、电功率 $V_a I_a$、液压功率 $p Q$ 均满足「功率 $=$ 广义力 $\times$ 广义速度」。该恒等式明确指出了功率的物理种类与接口匹配变量，决定选型必须从**关节端所需力（力矩）与速度**出发反推。
:::

::: method 方法 5.1.A · 准稳态功率平衡与效率计算 {#method-5.1.A}
在正向驱动、稳态或准稳态且忽略环节内部储能变化率（如加减速动能变化率、电感磁场储能变化及油液压缩储能）时，各段功率平衡与效率分别为：
$$P_e+P_c=P_a+P_{da},\qquad P_m=P_a-P_{dm},\qquad P_u=P_m-P_{dt},$$
$$\eta_a=\frac{P_a}{P_e+P_c}\approx\frac{P_a}{P_e},\qquad \eta_m=\frac{P_m}{P_a},\qquad \eta_t=\frac{P_u}{P_m}.$$
在再生制动、能量回馈或静止零速保持重力矩工况（机械功率为零但电热耗散非零）下，能流方向与损耗定义改变，不可直接套用正向效率公式。
:::

### 选型出发点：工况矛盾

::: thm 原理 5.1.B · 发动机与关节的根本工况矛盾 {#thm-5.1.B}
由作业轨迹确定的关节要求通常是**低转速、高转矩**；而绝大多数伺服发动机（尤其电动机）在高效率和高功率密度工作区呈现**高转速、低转矩**特性。这种需求与供给之间的工况错位，直接引出必须依赖传动装置进行阻抗与速度匹配。
:::

## 5.1.2 传动装置与直接驱动

### 传动装置的三重作用与典型机构

::: def 定义 5.1.3 · 传动装置的三重作用 {#def-5.1.3}
连接伺服发动机与机械关节之间的传动装置（transmission），承担以下三项职能：
1. **定量变换**：降速增矩（改变速比以匹配发动机高速低矩与关节低速高矩工况）；
2. **定性变换**：改变运动形式（将电机的连续旋转运动转化为移动关节所需的直线平移）；
3. **远置减重**：把体积与质量较大的发动机安装在基座或上游连杆上，经传动将功率送至远端关节，从而减小运动连杆承载的末端质量与等效转动惯量。
:::

由于转动惯量在动力学方程中决定系统响应滞后，将质量移回基座同时配以轻量化远端连杆能大幅改善动态性能与负载自重比；但若未同步减重连杆结构并计入额外传动件自重，单纯移动电机并不必然减轻整机总质量。

<a id="sec-5.1.1.2"></a>

::: method 方法 5.1.C · 常见机械传动装置分类与选型 {#method-5.1.C}
| 传动装置 | 运动变换 | 结构特征与误差源 | 适用场合 |
|:--|:--|:--|:--|
| **圆柱直齿轮 / 斜齿轮** | 旋转 $\to$ 旋转 | 平行轴间降速增矩、改向或偏置轴线；存在齿隙与啮合弹性 | 紧凑平行轴传动 |
| **丝杠 / 滚珠丝杠** | 旋转 $\to$ 平移 | 将旋转变为直线移动；预紧滚珠丝杠以滚动摩擦取代滑动摩擦，刚度高、回差小 | 移动（P）关节直线驱动 |
| **同步带 / 正时链** | 旋转 $\to$ 旋转 | 用于发动机远置传动；橡胶同步带质轻适合**高速低矩**（大矩易拉伸变形），钢制正时链刚性强适合**低速高矩**（高速易颤振） | 基座电机向远端关节传递动力 |
| **谐波齿轮减速器** | 旋转 $\to$ 旋转 | 由波发生器、柔轮、刚轮构成；单级可实现 $50\text{–}300$ 大减速比、体积小、近零背隙；存在柔性扭转弹性与迟滞摩擦 | 工业与协作机械臂旋转关节（尤适末端腕部/肘部） |

<div class="lab" data-lab="drive3d"></div>
:::

::: thm 定理 5.1.D · 理想定比传动与正向传动效率 {#thm-5.1.F}
设刚性、无齿隙、无打滑的减速机构传动比为正常数 $k_r=\omega_m/\omega$（两侧位移与力矩正向约定一致），则角速度与角位置满足
$$\omega_m=k_r\omega,\qquad \vartheta_m=k_r\vartheta.$$
若理想无损耗（$P_{dt}=0$），由瞬时功率守恒 $C_m\omega_m=C_l\omega$ 可得无损增矩关系 $C_l=k_r C_m$。当计入传动摩擦损耗且处于电机正向驱动负载工况时，设正向传动效率为 $\eta_t\in(0,1]$，稳态输出转矩为
$$C_{\mathrm{out}}=\eta_t k_r C_{\mathrm{in}}.$$
例如减速比 $k_r=10,\ \eta_t=0.9$ 时，输出 $10\,\mathrm{N\cdot m}$ 转矩需电机端输入 $10/(0.9\times 10)\approx 1.111\,\mathrm{N\cdot m}$。实际工程器件还存在齿隙（backlash，换向空程）与传动弹性引起的谐振模态。
:::

### 直接驱动（Direct Drive）

::: def 定义 5.1.4 · 直接驱动 {#def-5.1.4}
省去一切中间减速与传动装置，将具有高转矩—速度特性的伺服电机转子**直接刚性连接**至机械关节轴的驱动方式称为**直接驱动**。
:::

直接驱动与减速驱动的工程权衡如下：
- **收益**：彻底消除传动齿隙、非线性摩擦及扭转弹性，机械固有频率与定位重复性显著提升；
- **代价**：(1) 电机须直接提供全部静态重力矩与加速转矩，体积和质量随输出力矩急剧膨胀（同等电磁拓扑下转矩放大 10 倍往往伴随电机质量呈高次方增长，远超同倍减速箱附加重量）；(2) 缺少[§5.2.3](sec5-2.md#part-5.2.3)中 $1/k_r^2$ 对负载与变位形惯量的缩减隔离作用，多连杆非线性强耦合直接暴露给关节控制器，对控制算法和算力提出极高要求。

## 5.1.3 伺服发动机

按输入功率 $P_a$ 的能量形式，机器人发动机分为**电动机**、**液压发动机**与**气动发动机**三类（典型伺服功率覆盖 $10\,\mathrm W\text{–}10\,\mathrm{kW}$）。气动装置因气体可压缩性大、刚度极低，通常仅用于夹爪抓放与二位点动，不用于高精度连续轨迹伺服。

::: def 定义 5.1.5 · 伺服发动机定义 {#def-5.1.5}
能够依据控制输入连续调节输出机械功率（位置、速度或转矩），并可稳定跟踪伺服指令的发动机称为**伺服发动机（servomotor）**。
:::

::: def 定义 5.1.6 · 机器人对伺服发动机的六项基本要求 {#def-5.1.6}
高性能机器人执行系统对伺服发动机提出以下六项定量要求：
1. **高功率—重量比**与低转子转动惯量；
2. **强过载与脉冲峰值转矩能力**；
3. **产生大角加速度**的能力；
4. **宽调速范围**（例如 $1\text{–}1000\,\mathrm{rad/min}$ 连续可调）；
5. **高角定位精度**（优于 $1/1000\,\mathrm{rad}$）；
6. **低转矩脉动**，保证低速追踪平滑无爬行。
:::

### 永磁直流有刷电机 vs 无刷直流电机

::: def 定义 5.1.7 · 永磁直流伺服电机组成 {#def-5.1.7}
永磁直流有刷伺服电机由三部分构成：
1. **定子磁场**：由永磁体（铁氧体陶瓷或稀土磁钢）在静止侧产生恒定磁通；
2. **转子电枢**：通电绕组绕制在旋转磁心转子上；
3. **机械换向机构**：固定**电刷**与随转子旋转的铜片**换向器**机械滑动接触，根据转子转角自动切换电枢电流方向。

::: intuition 动手实验 · 比较有刷与无刷直流电机内部拓扑（3D）
切换对比有刷电机与无刷电机的定转子布置及换向机构：有刷采用「定子永磁 + 转子绕组 + 机械电刷换向器」，无刷采用「转子永磁 + 定子多相绕组 + 转子位置传感器 + 电子逆变」。

::: def 定义 5.1.8 · 无刷直流伺服电机与电子换相 {#def-5.1.8}
无刷直流伺服电机（BLDC）将有刷电机的定转子功能互换：
1. **永磁转子**：稀土强永磁体位于旋转转子上，转动惯量显著减小；
2. **固定多相定子电枢**：通电绕组直接嵌在外部定子铁芯内，紧贴外壳极易散热；
3. **静态电子整流器**：依据轴端**转子位置传感器**实时测得的角度信号，按序控制各相定子电流换相（相当于用「位置传感器 + 电力电子逆变」替代了机械电刷与换向器）。
:::

::: thm 原理 5.1.E · 无刷替代有刷的四项结构优势 {#thm-5.1.C}
定转子功能互换为机器人伺服带来四项直接收益：(1) 彻底消除电刷机械磨损与碳粉污染；(2) 消除机械换向电弧损耗（注意：电弧损耗属电气接触损耗而非单纯摩擦）；(3) 热源转子绕组移到定子外壳，冷却能力与连续转矩大幅上升；(4) 转子仅保留永磁体且无换向器，结构紧凑、轴惯量小、功率—重量比更高，非常适合轻量化机械臂。
:::

### 步进电动机与液压伺服发动机

::: def 定义 5.1.9 · 步进电动机 {#def-5.1.9}
**步进电动机（stepper motor）**由控制脉冲序列依次激励定子各相绕组，每输入一个电脉冲转过固定步距角 $\alpha$（输入 $N$ 个脉冲对应理论位移 $N\alpha$）。它可以**开环**运行而不必配置角位置传感器，但大惯量或急加减速工况极易发生**失步**，且低频离散激励易引发结构振荡，一般仅适于轻载低成本微小型机械装置。
:::

::: def 定义 5.1.10 · 液压伺服发动机 {#def-5.1.10}
**液压伺服发动机**分为驱动转动关节的旋转液压马达与直接驱动移动关节的双作用对称液压缸（有效活塞面积 $A$）：在理想无漏、无摩擦且油液不可压缩时，输出力 $F=A\Delta p$、运动速度 $v=Q/A$（其中 $\Delta p$ 为两侧压差，$Q$ 为控制阀供给流量）。它在极低转速下即可直接输出极大转矩且无失速烧毁风险、功率重量比极高且本质防爆；但须配置独立高压泵站（$100\,\mathrm{atm}$ 量级），存在油液泄漏污染、低效率和温度敏感性，且静止保持力矩**不等于失压自锁**（失压防坠落必须外加液压锁）。
:::

::: method 方法 5.1.F · 四类伺服发动机工程对比（必背对照表） {#method-5.1.D}
| 发动机类型 | 作用与换相/驱动机制 | 主要优点 | 主要缺点 | 适用场合 |
|:--|:--|:--|:--|:--|
| **永磁直流有刷** | 电能 $\to$ 机械能；电刷与换向器机械切换电枢电流 | 电路简单、线性度好、电源易得、无油污 | 电刷磨损、换向电弧损耗、转子散热差、轴惯量较大；断电不保位需抱闸 | 中小功率、成本敏感且非防爆常规臂 |
| **无刷直流（BLDC）** | 电能 $\to$ 机械能；转子位置传感器 + 电子逆变换相 | 无电刷与电弧损耗、定子易散热、转子惯量小、轻量化高功率密度 | 须配置转子位置传感器与三相逆变驱动器，成本略高 | 现代工业、装配与协作机器人主流关节 |
| **步进电动机** | 脉冲序列 $\to$ 离散步距转角 $N\alpha$ | 可开环运行无需位置传感器，控制器极简、廉价 | 重载或高速易失步、步进振荡显著、无法保证强动态精度 | 低成本、轻载微小型平台与辅助定位轴 |
| **液压伺服发动机** | 高压油压差 $\to$ 大直线力（$A\Delta p$）或大旋转转矩 | 极高功率—重量比、低速直接出大力矩、防爆、静态不烧毁 | 需配庞大泵站与管路、效率低、漏油污染、温漂大；失压不自锁 | 超重载搬运、矿山/防爆恶劣工业环境 |
:::

## 5.1.4 功率放大器与一次能源（了解·精简）

::: def 定义 5.1.11 · 功率放大器调节作用 {#def-5.1.11}
**功率放大器（power amplifier）**根据控制器输入的弱电信号功率 $P_c$，按比例调制来自一次能源的能量流 $P_e$ 并输送至伺服发动机（$P_a$）。放大器本身不是能源，仅执行开关调制或阀口节流调节。
:::

::: thm 定理 5.1.G · 按发动机类型选配功放 {#thm-5.1.D}
- **永磁直流有刷电机** $\longleftrightarrow$ **斩波器（Chopper，DC–DC 变换器）**：以高开关频率控制母线电压接通占空比 $D=t_{\mathrm{on}}/T$，输出平均电枢电压 $\bar V=D V_{\mathrm{dc}}$；
- **无刷直流电机（BLDC）** $\longleftrightarrow$ **逆变器（Inverter，DC–AC 变换器）**：同时受控调制多相交流输出的幅值与频率以匹配转子电子换相；
- **液压伺服发动机** $\longleftrightarrow$ **电液伺服阀与分布器**：见下述[定义 5.1.12](#def-5.1.12)。
:::

::: method 方法 5.1.H · 现代晶体管 PWM 开关功放指标 {#method-5.1.E}
现代电驱动普遍采用脉冲宽度调制（PWM）开关功率级，避免线性功放巨大的串联压降功耗，典型技术指标：**转换效率 $>0.9$**、**功率放大倍数 $P_a/P_c \sim 10^6$ 量级**（以毫瓦控制信号调度千瓦级电力）。
:::

::: def 定义 5.1.12 · 电液伺服阀接口与分布器 {#def-5.1.12}
**电液伺服系统**以小信号控制电流驱动电磁力矩马达，进而带动**分布器（distributor）**滑阀阀芯移动，改变主高压油路进入伺服发动机流量的流速与方向。工程上常借助机械或电气**阀杆位置局部反馈**组成位置内环，抑制流体非线性与滞回，确保流速正比于控制指令。
:::

::: def 定义 5.1.13 · 一次能源构成 {#def-5.1.13}
**能源（power supply）**向放大器提供与控制律无关的基准能量 $P_e$：
- **电源（电动系统）**：由降压变压器、无控二极管桥式整流器与直流支撑滤波电容构成，将工业电网交流电转为平稳直流母线电压；
- **液压源（液压系统）**：由三相异步交流电动机、定量/变量液压泵、溢流安全阀组及承压**储液器 / 蓄能器（accumulator）**构成（$100\,\mathrm{atm}$ 级工作压力）。
:::

::: note 概念辨析：蓄能器才对应滤波电容 {#note-5.1.4}
在电—液类比中，液压管路中带有压缩气囊或弹簧加载的**蓄能器**（常俗称储液器，指承压储能元件）通过压力变化储存并释放高压油液能量以平抑流量与压力脉动，物理作用恰如直流电源中的**滤波电容**（切不可误将常压回油箱当作滤波电容）。
:::

## 5.1 小结与常见错误

| 核心概念 / 公式 | 关键要点 | 典型错误 |
|:--|:--|:--|
| 功率链与效率 | $P_m=P_a-P_{dm},\ P_u=P_m-P_{dt}$；功率 $=$ 广义力 $\times$ 速度 | 把功放误当成仅放大电压波形的微弱信号放大器；制动或静态保持仍套用正向效率 |
| 传动与直接驱动 | 三重作用（定量/定性/减重）；$C_{\mathrm{out}}=\eta_t k_r C_{\mathrm{in}}$ | 认为直驱“一定优于”带减速器；忽略直驱体积剧增与关节非线性耦合直接暴露问题 |
| 伺服发动机对比 | 有刷（电刷磨损）、BLDC（位置传感器+逆变）、步进（开环易失步）、液压（大功率密度需泵站） | 将电刷换向电弧损耗归入机械摩擦；误以为液压在停电失压下会自动锁紧定位 |
| 功放与能源 | 斩波器配直流有刷、逆变器配无刷；PWM 效率 $>0.9$、增益 $\sim 10^6$；蓄能器类比滤波电容 | 记反斩波/逆变对象；把常压回油箱混淆为承压储能蓄能器 |
