## 5.1.0 总览：功率链与选型

### 5.1.0.1 执行系统的四个组成部分

::: def 定义 5.1.1 · 关节执行系统 actuating system {#def-5.1.1}
施加在机械手关节上的运动，通常由**执行系统**实现。执行系统由四部分组成（教材 §5.1、课件 0:23:44 页）：

1. **能源**（power supply）——一次能源，提供与控制信号无关的功率；
2. **功率放大器**（power amplifier）——把控制规律给出的**小信号**放大成能驱动发动机的功率；
3. **伺服发动机**（servomotor）——把电/液压/气动的功率转成**机械功率**；
4. **传动装置**（transmission）——把发动机的高转速低转矩，匹配成关节需要的低转速高转矩。

这四部分串成一条**功率链**，末端才是关节与机械手本体：

$$P_c+P_e\ \Longrightarrow\ \boxed{\text{功放}}\ \Longrightarrow\ \boxed{\text{发动机}}\ \Longrightarrow\ \boxed{\text{传动}}\ \Longrightarrow\ \text{关节}$$

沿途的功率符号与三处损失见下面 [5.1.0.2](#sec-5.1.b) 的八个符号表。
:::

<a id="fig-5.1.1"></a>

**板书画的也是同一条链**（教师流 142:30 板书帧）：左侧是给定值与误差 $e$，中间一串方框——**能源 → 功放 → 执行器 → 机器人本体**，输出 $z,\omega,\theta$，下方**传感器**闭环回输入端。板书框上标注的章节号是老师指出的全书位置：$chpt\,5$ 是本章（能源 / 功放 / 执行器 / 传动），$chpt\,6,7,10$ 是后面的控制器，$chpt\,2$ 是传感器信息的来源（位姿与运动学）；左下两行 $v_e=J\dot q$、$\tau=J^{\mathrm T}F_e$ 是上一章留下的（未擦）。

**为什么要有功放这一环？** 老师在 00:09:29–00:11:20 用一组具体数字把这件事讲得最清楚，值得完整记下来：

| | 控制器输出 | 电机 |
|:--|:--|:--|
| 器件 | 快速计算的**微电子电路**（如 TTL） | 几十瓦 / 几百瓦 / 上千瓦 |
| 电压 | 约 **3.3 V** | 视电机而定 |
| 电流 | **微安级到毫安级** | 安培级 |
| 功率 | 按 $3.3\ \mathrm{V}\times1\ \mathrm{mA}$ 算约 **3.3 mW** | 例如 $100\ \mathrm W$ 约为控制信号功率的 $3\times10^4$ 倍 |
| 好处 | **计算快**——每秒万次到千万次 | 能产生运动 |

控制器输出通常不足以直接驱动电机。功率放大器依据控制信号调节从能源送来的功率；它放大输出功率，但能量来自电源，不能凭空产生。老师用「等比例地放大」描述信号与输出之间的关系；具体电压、电流或功率的关系取决于功放结构。

::: note 功率总是「力 × 速度」 {#note-5.1.1}
教材特意提醒：**功率总可以表示为速度和力的乘积**。这条恒等式的好处是，它**物理内涵上指明了功率的种类**——机械功率是「力 × 线速度」或「力矩 × 角速度」，电功率是「电压 × 电流」，液压/气动功率是「压力 × 流量」。因此功率链上每一段的功率，都能用该段的「力」和「速度」两个量写出来，这正是 §5.1.3 选型要从力和速度出发的原因。
:::

### 5.1.0.2 功率流：八个符号

::: def 定义 5.1.2 · 执行系统的功率符号 {#def-5.1.2}
按教材 §5.1 的约定（图 5.1，即上面的课件页）：

| 符号 | 含义 | 出现在哪一段 |
|:--|:--|:--|
| $P_c$ | 与控制规律信号相关的功率（**通常是电的**） | 控制器输出，功放的输入 |
| $P_e$ | 由**一次能源**提供的功率，与 $P_a$ 物理性质相同 | 能源 → 功放 |
| $P_a$ | 提供给**发动机**的功率（电动、液压或气动） | 功放输出，发动机输入 |
| $P_m$ | 由**发动机产生**的机械功率 | 发动机输出，传动装置输入 |
| $P_u$ | 关节所需、用以**驱动运动**的机械功率 | 传动装置输出，关节输入 |
| $P_{da}$ | 由**放大器**耗费的功率损失 | 功放内部 |
| $P_{dm}$ | 由**发动机**耗费的功率损失 | 发动机内部 |
| $P_{dt}$ | 由**传动装置**耗费的功率损失（主要是摩擦） | 传动装置内部 |
:::

控制信号 $P_c$ 和能源 $P_e$ 一起进入功率放大器，由放大器向发动机提供 $P_a$；发动机输出 $P_m$，再经传动装置得到 $P_u$。沿途分别有功放、电机和传动损失。老师 0:30:54 的原话是「（加）传动装置会引起一部分的（损耗）、摩擦」，说的就是 $P_{dt}$。

::: method 方法 5.1.A · 功率链怎么算 {#method-5.1.A}
沿链写功率平衡（教材 §5.1）：

$$P_c+P_e\;\Longrightarrow\;P_a\;\Longrightarrow\;P_m\;\Longrightarrow\;P_u,\qquad
P_m=P_a-P_{dm},\qquad P_u=P_m-P_{dt}$$

- **放大器**：$P_a$ 的绝大部分来自能源 $P_e$，$P_c$ 主要提供控制信息。若按进入放大器的功率为正，且忽略储能变化，功率平衡为 $P_c+P_e=P_a+P_{da}$；通常 $P_c$ 很小，可以近似忽略。
- **发动机**：输入 $P_a$、输出 $P_m=P_a-P_{dm}$，效率 $\eta_m=P_m/P_a$；
- **传动装置**：输入 $P_m$、输出 $P_u=P_m-P_{dt}$，效率 $\eta_t=P_u/P_m$。

这些平衡式采用准稳态、忽略内部储能变化的模型；加减速时还可能有动能、磁场能或压缩能的变化率。上述效率比值用于能源向关节正向供能且输入功率为正的工况；静止保持或再生制动不能不改符号与能流方向便套用。

在 §5.2.3 会用无间隙、刚性的传动模型写出输入输出比例；再假设没有摩擦等损失，才有理想传动两侧功率相等（$P_u=P_m$）。传动改变的是力与速度的分配。
:::

### 5.1.0.3 选型的出发点：从关节的力和速度出发

教材 §5.1 给出一句很简短的方针：**为了选择执行系统的组成，应当「从构成机械功率 $P_u$ 所需的描述关节运动的力和速度出发」**。这句话看起来平淡，实际是本章往后所有工程取舍的源头——因为我们真正知道的需求，只有关节端要出多大力、走多快。

于是矛盾立刻出现（教材 §5.1.1、课件 0:33:23 页）：

::: thm 定理 5.1.B · 发动机与关节的根本工况矛盾 {#thm-5.1.B}
- **关节需要的**：同时具有**低速度和高转矩**；
- **伺服发动机最优工作条件下的**：**高速度和低转矩**。

两者不匹配时，可以通过传动装置把电机的工作点匹配到关节需求；但这不是所有机器人的必需条件。直驱方案直接由适合负载的电机驱动关节，不使用减速器，代价与适用条件见 [5.1.1](sec5-1.md#part-5.1.1)。
:::

传动装置的三重作用是定量变换、定性变换，以及通过改变电机安装位置减小运动部分的负载，见 [5.1.1](sec5-1.md#part-5.1.1)。

### 5.1.0.4 小结与常见错误

- **一条功率链**：能源 → 功率放大器 → 伺服发动机 → 传动装置 → 关节。四部分各司其职，三处损失各记一个符号。
- **一个出发点**：选型从**关节端的力与速度**倒推，而不是从手上现成的电机倒推。
- **一对矛盾**：「关节低速高转矩」对「发动机高速低转矩」——这是传动装置存在的理由，也是 §5.2.3 要定量分析的起点。

::: think 常见错误清单 · 自查三条
1. 把**功率放大器**当成「信号放大器」——它放大的是**功率**；控制信号 $P_c$ 只是「指挥」，能量来自能源 $P_e$。
2. 以为所有理想传动都由「无间隙、刚性」保证功率相等——还需假设无摩擦等损失；真实传动的损失体现为 $P_{dt}$。
3. 只算电机效率而漏掉其他环节：从发动机输入算到关节，$P_u/P_a=\eta_m\eta_t$；若从能源端算整体效率，还须乘放大器效率（通常忽略控制端功率）。
:::

## 5.1.1 传动装置

上一节提出的工况匹配问题在这里展开：电机与关节所需的速度、力矩可能不同，传动装置可以改变两侧的组合。老师把作用分为定量变换、定性变换和减小运动部分负载。本节还讨论不经减速器的直接驱动，并保留老师的经验估算。

<a id="sec-5.1.1.1"></a>

### 5.1.1.1 传动装置的三个作用

教材 §5.1.1 的表述是：传动装置的选择取决于**功率需求、期望的运动类型、以及发动机相对关节的安装**——这三条恰好对应三个作用。

::: def 定义 5.1.3 · 传动装置的三重作用 {#def-5.1.3}
1. **定量变换**：**定量地传输发动机的输出**（速度和力矩）——即「降速增矩」。老师 0:31:03：「就是降速增矩」。
2. **定性变换**：**定性地改变运动形式**——把绕发动机轴的**旋转运动**转化为关节的**平移运动**。老师 0:31:26：「电机只能提供一个转动的需求，但实际的过程中我们可能需要一个平动的需求……就需要一个机构，把转动转化成为平动。」
3. **减轻运动负担（优化有效载荷）**：把发动机移到关节上游或基座，通过传动向远端送力，可减轻运动连杆承载的质量和惯量，改善静态负载及动态性能。教材称「机械手总重量将降低、功率—重量比将提高」；严格说，单靠搬动同一台电机不改变整机总质量，若要降低整机重量，还需相应减轻支撑结构并计入新增传动的质量。
:::

例如理想减速比为 10，电机以 $100\ \mathrm{rad/s}$、$1\ \mathrm{N\cdot m}$ 输出时，关节侧速度为 $10\ \mathrm{rad/s}$、力矩为 $10\ \mathrm{N\cdot m}$；两侧功率都是 $100\ \mathrm W$。这是忽略损耗的结果，实际关节输出功率更低。传动能改变速度和力矩的组合，却不能凭空增加功率；[5.2.3](sec5-2.md#part-5.2.3) 将进一步折算负载惯量。

第 3 条老师在 0:32:10 展开得最细，值得原样保留：**把比较重的质量和机械臂都放在基座附近，通过传动方式把动力传到末端**，这样末端惯量小，「其实是有助于控制的」。他举的例子是实验室做的**线缆驱动**（远端驱动）机械手——电机放在身上或近端，通过线缆把动力传到末端，「这样可以大大减小（末端）附加惯量」。

为什么惯量小就好控制？老师给了一句很本质的话（0:33:01）：

> **「惯量它是起到一个延迟的作用。」** 惯量大了，做算法补偿时始终得考虑这个惯量、提前预判它会带来什么影响；惯量小的话就比较容易控制。

这正是 [3.8 静力学](../ch03/sec3-8.md) 之后第一次出现「**动力学**」这个词——本章只做定性讨论，第 7 章才正式建模。

### 5.1.1.2 三种典型传动装置

教材 §5.1.1 与课件 0:33:23 页给出工业机器人上最常用的三种：


::: method 方法 5.1.C · 三种传动装置的选型 {#method-5.1.C}
| 装置 | 变换性质 | 特点 | 什么时候用 |
|:--|:--|:--|:--|
| **圆柱齿轮**（这里以直齿轮 spur gears 为例） | 旋转 → 旋转 | 典型外啮合直齿轮用于平行轴之间传动，可改变轴的位置与转向；不能把平行轴齿轮当作任意换轴方向的装置 | 需要匹配转速、力矩或平移轴位置时 |
| **丝杠**（lead screws） | 旋转 → **平移** | 把发动机的旋转运动**转换为平移运动**，用于**移动关节**；为减小摩擦常预装**滚珠丝杠**以提高刚性并降低间隙 | 移动关节（棱柱关节）的驱动 |
| **同步带**（timing belts） / **正时链**（chains） | 旋转 → 旋转 | 运动学上**二者等价**，用于把发动机**定位在远离驱动关节的轴上**；皮带靠拉紧传动，用于**高速度、低力量**；链条质量大，高速时会**颤动**，用于**低速度**需求 | 按速度高低二选一 |
:::

老师在 0:34:07 把「二选一」讲成了物理直觉，比教材更直白：

- **同步带**「相对来说比较轻，可以（在）高速的时候效果好一点」——但带是橡胶的，「**矩太大的话就会变形**」；
- **正时链**「质量比较大，所以说它速度高的话，惯量大是会有（震颤）」，所以高速不合适；「但是低速高矩是可以，**因为它是钢的**」。

一句话总结：**要快要轻用带，要重（大力矩）耐操用链。**

::: thm 定理 5.1.D · 理想定比传动的关系 {#thm-5.1.F}
设传动刚性、无间隙、不打滑，且传动比 $k_r$ 为常数，则两侧角速度满足 $\omega_m=k_r\omega$。再假设传动无摩擦等损失，由功率相等 $C_m\omega_m=C_l\omega$ 得 $C_l=k_rC_m$。刚性和无间隙给出运动关系，并不单独保证无损；实际有摩擦时，力矩关系还需计入损耗。第 [5.2.3](sec5-2.md#part-5.2.3) 节用这些关系折算等效惯量。

### 5.1.1.3 直接驱动：可以不用传动装置吗

::: def 定义 5.1.4 · 直接驱动 direct drive {#def-5.1.4}
某些时候，执行系统发动机的机械特性可能允许**不使用任何传动装置**而把发动机**直接连接**到关节上，称为**直接驱动**。

**收益**：由于传动装置**弹性和间隙**导致的缺点被消除——没有齿隙、没有回差、没有传动刚度问题。

**代价**：电机必须直接提供关节所需的力矩；没有减速器时，也须评估负载及各关节之间的动力学耦合是否需要补偿。控制复杂程度取决于机械结构、负载和任务精度。
:::

老师把「代价」讲得更具体（0:35:19–0:36:30）：直驱时「**它对控制算法的要求就非常高**」——因为关节与下游各关节之间是**强耦合**的：

> 「因为（没有）传动装置的情况下，相当于这个关节和下游关节，它都是**强耦合**的……如果我们加上传动装置，**我控制这个关节就单独控制这个关节**；通过传动装置这个比例系数，可以把下游的动力耦合或者非线性的耦合因素给减弱了。」

传动装置可降低折算到电机侧的负载与耦合影响，但不会自动消除耦合。只有剩余耦合相对所需控制精度足够小时，才适合把各关节近似为独立系统；条件与推导见 [5.2.3](sec5-2.md#part-5.2.3) 和 [5.2.4](sec5-2.md#part-5.2.4)。

结论（教材 §5.1.1）：由于**成本、发动机尺寸和控制复杂性**的原因，直接驱动在工业机械手中**并不普遍**。

**老师的经验估算（0:36:53–0:38:23）。** 他用一个「不严格但工厂上可以这样理解」的算法说明直驱为什么不划算：**直驱所需的电机质量随所需转矩的平方增长**——要产生 1 N·m 也许要 10 kg 的电机；那么同样用直驱去产生 10 N·m，就要 $10\times 10^2=1000$ kg（一吨）级的电机。而如果改成**减速比 10 的减速器**，「输入的是一牛米，这个是 10 倍，输出的就可以是（10 N·m）」，而「这个减速箱可能几百克、几十克就可以了」。

板书右下角画的正是这个算例：矩形标 $F,v$（平动侧）、圆标 $\tau,\omega$（转动侧），两侧弧形箭头表示传动关系；左侧圈注 $(100\,\mathrm{g})$、$\tau=10$、$10\times10^{-2}=10^{-2}\ \mathrm{kg}$ 与 $10\ \mathrm{cm}$——「1 N·m 输入、减速比 10、输出 10 N·m」与「10 cm 臂长举 100 g」两个数都在这块黑板里。

<a id="sec-5.1.1"></a>

::: think 考点 · 老师原话（录播时间点）

### 5.1.1 小结与常见错误

- **一句话**：传动装置把发动机的工作点（高速低矩）搬到关节需要的工作点（低速高矩），顺带完成换向、换运动形式和减重解耦。
- **三种装置**：齿轮换向、丝杠转平动、带/链做远置传动（带快、链重）。
- **一条假定**：无间隙、刚性且定比时速度成比例；进一步忽略损耗，才能由功率平衡得到相应的力矩比例。
- **一个取舍**：直驱精度高但控制难、成本高，工业上用「电机 + 减速器」更普遍。

::: think 常见错误清单 · 自查三条
1. 只记住「减速增矩」，漏掉**定性变换**与**减重解耦**——后两条恰是老师反复强调的。
2. 认为传动装置「改变功率」——理想传动不改变功率（$P_u=P_m$），只重新分配力与速度。
3. 把直驱当成「更先进所以更好」——它换掉的是**弹性与间隙**，代价是**控制复杂度**；工业上多数场合并不采用。
:::

## 5.1.2 伺服发动机

执行系统的心脏是**伺服发动机**——注意老师特意强调用「发动机」而不是「电机」（0:38:41）：「因为实际的部分不可能、或者可能不完全采用电机，有些情况采用液压，有些情况采用气动」。本节按输入功率的种类把发动机分成三类，然后重点讲用得最多的**伺服电机**（永磁直流与无刷直流），最后给出电动机与液压伺服发动机的全面对比。

<a id="sec-5.1.2.1"></a>

### 5.1.2.1 三类发动机与「伺服」的来历

::: def 定义 5.1.5 · 发动机的分类与伺服发动机 {#def-5.1.5}
**按输入功率 $P_a$ 的类型**，发动机分为三类（教材 §5.1.2）：

| 类别 | 能量来源 | 能量转换方式 |
|:--|:--|:--|
| **气动发动机**（pneumatic motors） | 压缩机提供的气压能 | 通过**活塞或涡轮**转换为机械能 |
| **液压发动机**（hydraulic motors） | 泵将储液池中的流体加压 | 压力作用于活塞或马达，将液压能转换为机械能 |
| **电动机**（electric motors） | 电力分配系统提供的电能 | 电磁作用转换为机械能 |

输入功率 $P_a$ 的一部分转换为输出机械功率 $P_m$，余下的（$P_{dm}$）由于**机械、电、液压或气压损失**而被耗散。

**伺服发动机**（servomotor）：随着机器人执行系统对**轨迹跟踪能力**和**定位精确性**的要求提高，上述要求也被提高，**从而发动机必须起到伺服作用**——这就是「伺服发动机」这个说法的来历。
:::

**机器人用的发动机有多大？** 教材给的范围是**功率 10 W 左右到 10 kW 左右**。老师在这一页（课件 0:39:06）逐条念了机器人对发动机的六条性能要求，它们是本章后面所有讨论的验收标准：

::: def 定义 5.1.6 · 机器人发动机的六条性能要求 {#def-5.1.6}
1. **低惯量**和**高的功率—重量比**；
2. 过载能力和**脉冲转矩释放能力**；
3. 产生**大加速度**的能力；
4. **调速范围**（从 1 到 1000 rad/min）；
5. **高定位精度**（小于 $1/1000$ rad）；
6. **低转矩脉动**，以保证即使在低速下的连续转动。
:::


对照这六条再看 §5.1.1：第 1 条（低惯量）正是「把发动机放到基座、用传动装置把动力送下去」的理由；第 4、6 条（宽调速 + 低速连续）是液压的强项（见本节末尾对照表）。

**气动为什么用得不广？** 教材 §5.1.2 给出的原因很物理：**流体的可压缩性误差不可避免**，因而**很难精确控制**。所以气动发动机只用在两类场合：典型的**驱动钳子钳口开合**运动，或者**不关注连续运动控制**的简单臂驱动。

<a id="sec-5.1.2.2"></a>

### 5.1.2.2 伺服电机：有刷与无刷

「在机器人应用中使用最多的发动机是**伺服电机**（electric servomotors），其中**永磁直流**与**无刷直流**两种因控制灵活性高而得到广泛应用」（教材 §5.1.2）。老师 0:43:02 的概括是「一般两种，**永磁的**和**无刷的**」。

::: def 定义 5.1.7 · 永磁直流伺服电机的组成 {#def-5.1.7}
1. **定子磁场**：通常由**永磁体**产生，可采用铁磁陶瓷或稀土材料；永磁体不需要定子励磁线圈。
2. **电枢**：包括绕旋转磁心（**转子**）的**通电绕组**。
3. **换向器**：根据转子的运动**决定换向逻辑**，并通过**电刷**为旋转的电枢线圈与外部绕组线圈提供电连接。
:::


::: intuition 动手实验 · 把伺服电机剖开看（3D）
两台电机并排剖开：**有刷**的磁极固定在定子上、电枢绕组在转子上，**换向器随转子转、电刷固定不动**——机械换向就发生在这个错位里；**无刷**的永磁体搬到转子上，定子是多相绕组，轴上加位置传感器，由电子模块按转子位置依次给相通电。切换两台电机，看清楚 5.1.2 那句「**电刷+换向器 ≈ 位置传感器+电子模块**」在空间上到底意味着什么。

<div class="lab" data-lab="motor3d"></div>
:::

::: def 定义 5.1.8 · 无刷直流伺服电机的组成与换相原理 {#def-5.1.8}
**组成**（与有刷的恰好「功能互换」）：

1. **转子**：由磁陶或稀土制成的**永磁体**产生磁场；
2. **固定电枢（定子）**：由**多相线圈**制成；
3. **静态整流器**：基于**电机轴上的位置传感器**提供的信号，把转子运动的函数**生成电枢线圈相位的馈入序列**。

**换相原理**（教材 §5.1.2）：控制器利用转子位置决定定子各相绕组的通电顺序，使定子产生的磁场与转子永磁体的磁场保持合适的相对角度，从而产生所需方向的转矩。某些控制方法以接近正交的磁场方向作为目标；实际角度随换相方式与工况变化。

**一句话对照**：有刷电机里**电刷与换向器**所起的作用，与无刷电机里**位置传感器与电子控制模块**所起的作用**是类似的**（老师 0:45:57 说的也是这一句）。

为什么需要换向？转子转过一定角度后，如果线圈电流方向始终不变，产生的转矩可能改变方向。有刷电机靠旋转换向片与固定电刷切换转子绕组电流；无刷电机则根据转子位置切换定子各相电流。两种方式都要让磁场相对转子保持合适的方向，但实际夹角并非任何时刻都严格为 $90^\circ$。
:::


::: thm 定理 5.1.E · 为什么用无刷：定转子功能互换的四个好处 {#thm-5.1.C}
**动机**：使用无刷直流电动机的主要原因是**消除永磁直流电动机中电刷机械换向所产生的问题**（教材 §5.1.2）：

- **电损耗**：电刷与换向器的**接触产生接触压降**；
- **机械与换向损耗**：接触摩擦属于机械损耗；线圈自感在换向中引起的电弧属于电气换向损耗，不能把电弧能量损失归为机械摩擦。

**结果**（定子与转子功能交换带来的便利）：

1. **散热更好**——电枢线圈放在**定子**上而不在转子上，有利于散热；
2. **转子紧凑**——转子上没有绕组，且可用**稀土永磁**，转子结构更紧凑；
3. **转动惯量更小**——紧凑的转子结构直接减小惯量（对照 [@def-5.1.6] 第 1 条「低惯量」！）；
4. **同功率下尺寸更小、动态性能更好**。

**但成本也必须考虑**：「对于在一个特定应用场合选择一个最合适的伺服电动机，**成本也是必须考虑的问题**」。
:::

<a id="sec-5.1.2.3"></a>

### 5.1.2.3 步进电动机

::: def 定义 5.1.9 · 步进电动机 {#def-5.1.9}
步进电动机由**合适的激磁序列**控制，其运行**不需要电动机转角位置的测量信息**——这是它最大的特点（也就是「开环可控」）。

把一个控制脉冲对应的理想角位移记为步距角 $\alpha$。驱动器每收到一个脉冲，就将定子励磁切到下一个状态；若转子跟得上，$N$ 个脉冲对应 $N\alpha$ 的转角，单位时间内脉冲越多，平均转速越高；反转励磁顺序则反转方向。例如步距角 $1.8^\circ$，理想情况下 200 步转一圈。负载过大或加速过快可能失步，因此不测位置不等于一定跟踪准确。

**两条限制**（教材 §5.1.2）：

1. 其**动态性能在很大程度上受到有效载荷的影响**；
2. 它还会**导致机械手机械结构的振荡**。

这些限制使步进电机的选用受工况约束；在微型机械手等成本敏感场合，若动态要求允许，仍可采用。
:::

老师 0:47:25 把步进与无刷的差别讲得更直白：两者**原理有很大区别**——无刷是「转子用永磁体，定子里通电产生旋转磁场，用旋转磁场带动转子」，因此「**需要比较高级的算法**」去处理**转子位置与磁场（电流）的关系**；步进而不需要位置反馈。

<a id="sec-5.1.2.4"></a>

### 5.1.2.4 液压伺服发动机

::: def 定义 5.1.10 · 液压伺服发动机 {#def-5.1.10}
工作原理是受压流体作用于活塞，将液压能转为机械能。对于液压缸，固定缸体内的活塞和活塞杆往复运动，进出油引起腔体容积变化：

- **线性伺服发动机**：行程**有限**，仅由一个活塞构成；
- **旋转伺服马达**：行程**不受限制**，由**多个（通常是奇数个）活塞**相对于发动机旋转轴**轴向或径向**布置构成。

例如两侧有效面积相等且均为 $A$、压差为 $\Delta p$ 时，忽略摩擦，作用力近似 $F=A\Delta p$；若进入腔体的有效流量为 $Q$，忽略泄漏和压缩，活塞速度为 $v=Q/A$。单杆缸两侧有效面积通常不同，须分别计算两侧压力产生的力。因此压力关系决定力，流量关系决定速度；[5.2.2](sec5-2.md#part-5.2.2) 将把泄漏和压缩加回模型。

其**静态和动态性能与电动伺服马达具有可比性**。
:::


::: method 方法 5.1.F · 电动 vs 液压：一张对照表 {#method-5.1.D}
教材 §5.1.2 从「使用的角度」做了完整对照，这是本章最典型的**选型素材**：

| | **伺服电机** | **液压伺服发动机** |
|:--|:--|:--|
| **优势** | 能源来源广泛；成本低且产品范围宽；功率转化效率高；易于维护；对工作环境无污染 | 静态下**不会熄火**；**自润滑**，循环液体便于热处理；在**有害环境**下也很安全；**很高的功率—重量比** |
| **局限/缺点** | 堵转时电机仍可能通电发热，垂直负载还须考虑断电保持或制动；在**易燃环境**下工作需特别保护 | 需要**液压源**；成本高、产品范围窄、**难以小型化**；功率转化效率低；需要操作维护；**漏油会造成环境污染** |
| **工况特点** | 某些高速低转矩电机需配齿轮；也可选择直接驱动电机 | **能在低速度下产生大转矩** |
| **动态性能** | 有更好的**控制灵活性**（但两者都有很好的动态性能） | 动态性能**取决于压缩流体的温度** |
| **适用场合** | 一般工业机械手 | **搬运重载荷**——不仅最合适，而且装置成本能降低操纵系统的整体开销 |

比较时先看关节所需速度、转矩和负载，再看电源、环境、维护及断电安全。是否需要减速器取决于电机与任务的匹配，不由「电动」两个字直接决定。
:::

<a id="sec-5.1.2"></a>

::: think 考点 · 老师原话（录播时间点）

气动 / 液压 / 电动（按 $P_a$ 类型）。随着对轨迹跟踪能力与定位精确性要求提高，发动机必须起到伺服作用，故称伺服发动机。

有刷永磁直流电机：永磁定子、电枢（转子上的通电绕组）、换向器和电刷。无刷：永磁转子、多相定子（固定电枢）、静态整流器（结合转子位置）。两者分别靠机械换向与电子换相控制绕组电流。

消除电刷的接触压降、摩擦和换向电弧损耗；电枢挪到定子有利于散热，转子去掉绕组后可做得紧凑、惯量小。具体尺寸与动态性能还取决于电机设计，不能仅凭「无刷」保证所有指标更好。

特点：由激磁序列控制，**不需要转角位置测量**。限制：动态性能受有效载荷影响大；会引起机械结构振荡（因而在微型机械手领域让位于低成本的考虑）。

**液压**伺服发动机。理由：① 低速下能产生**大转矩**（伺服电机速度高转矩低，需齿轮传动并带来弹性与间隙）；② 静态下不会熄火、功率—重量比高；此外装置成本还能降低整体开销。

:::

:::

### 5.1.2 小结与常见错误

- **三分类**按**输入功率 $P_a$ 的类型**：气动（可压缩、难精确控制、用得少）、液压（低速度大转矩）、电动（用得最多）。
- **伺服电机的两条技术路线**：永磁直流（定子/电枢/换向器）与无刷直流（永磁转子/多相定子/静态整流器），后者的动机是**消除电刷换向**，收益是散热、紧凑、小惯量。
- **一张对照表**：电动 vs 液压的优劣与适用场合，是本节的选型结论。
- **一条线索**：六条性能要求（[@def-5.1.6]）——后面每一节都在往这几条上靠。

::: think 常见错误清单 · 自查三条
1. 把**换向器**与**整流器**混为一谈：有刷电机的换向器是**机械**装置（靠电刷），无刷电机的静态整流器是**电子**装置（靠位置传感器 + 控制模块）。
2. 说「无刷就是没有损耗」——无刷消除的是**电刷接触与换向电弧**两类损耗，电机本身的铜损铁损照旧。
3. 忘记**步进电机不需要位置反馈**这一条——它常是概念题的分水岭；但也要同时说出它的两条限制。
:::

## 5.1.3 功率放大器

功率放大器位于能源与发动机之间：它根据控制信号调节能源送来的功率，使发动机得到所需的电压、电流或流量。本节比较电机的斩波器、逆变器和液压系统的电液伺服阀。

<a id="sec-5.1.3.1"></a>

### 5.1.3.1 放大器的任务

::: def 定义 5.1.11 · 功率放大器的调节任务 {#def-5.1.11}
功率放大器具有**调节任务**：在控制信号的作用下，**功率流由一次能源提供，而且必须被传输到执行器**以执行期望的运动。

教材 §5.1.3 将这一过程描述为：放大器从能源中取得受控制信号调节的功率，并以适当形式送到发动机。控制信号的电压或电流等变化决定输出如何调节；不能把信号功率 $P_c$ 的大小直接等同于控制指令本身。

若输入功率均取正且忽略储能变化，功率平衡为 $P_e+P_c=P_a+P_{da}$。其中 $P_a$ 送到发动机，$P_{da}$ 是放大器的损耗；通常 $P_c$ 远小于能源提供的功率，参见 [5.1 功率流](sec5-1.md#sec-5.1.b)。
:::

<a id="sec-5.1.3.2"></a>

### 5.1.3.2 伺服电机的放大器：斩波器与逆变器

教材 §5.1.3 从「电机的类型」出发：**要控制伺服电机，需要根据所用的电机类型，为其提供适当形式的电压和电流**。

::: thm 定理 5.1.G · 按电机类型选放大器 {#thm-5.1.D}
- **永磁直流伺服电机**：电压（或电流）是**直流**的 ⇒ 用 **DC-DC 变换器**（choppers，**斩波器**）；
- **无刷直流伺服电机**：电压（或电流）是**交流**的 ⇒ 用 **DC-AC 变换器**（inverters，**逆变器**）。

**控制什么量**：对永磁直流伺服电机是**电压值**；对无刷直流伺服电机是**电压和频率值**——两者都由放大器的控制信号确定，「以使电机执行期望的运动」。
:::

::: method 方法 5.1.H · PWM 晶体管放大器与两个指标 {#method-5.1.E}
对于关节运动通常需要的功率范围（**千瓦级**），使用通过**脉宽调制（PWM）**技术进行适当切换的**晶体管放大器**。教材给出两个量化指标：

$$\text{功率转化率}=\frac{P_a}{P_a+P_{da}}>0.9,\qquad \text{功率增益}=\frac{P_a}{P_c}\ \text{达到}\ 10^6\ \text{级}$$

读法：**功率转化率**衡量「从能源取来的电有多少真正到了电机」（效率，>90%）；**功率增益**衡量「控制信号以小博大到什么程度」（$10^6$ 量级）。后者能这么大，正因为 $P_c$ 只是控制信号功率、真正的能量来自 $P_e$。

以理想斩波器为例：直流母线电压为 $V_{\rm dc}$，开关每个周期 $T$ 内接通 $t_{\rm on}$，占空比 $D=t_{\rm on}/T$。若输出在接通时为 $V_{\rm dc}$、关断时为零，周期平均电压为 $\bar V=D V_{\rm dc}$。例如 $V_{\rm dc}=48\ \mathrm V$、$D=0.25$ 时平均为 $12\ \mathrm V$。这是理想开关周期平均值，电机端瞬时电压仍是脉冲；电流是否平滑取决于电感、开关频率和负载。逆变器则按相位切换多个开关，产生电机各相所需电压。
:::


<a id="sec-5.1.3.3"></a>

### 5.1.3.3 液压侧的放大器：电液伺服系统

液压发动机由压差和流量共同传递功率；这里讨论的控制方式是通过阀调节流量（教材 §5.1.3）：

::: def 定义 5.1.12 · 电液伺服系统与分布器 {#def-5.1.12}
**对液压伺服发动机的控制，可通过调节送往发动机的体积流量完成。** 本节沿用教材「流速」一词时指体积流量（$\mathrm{m^3/s}$），不是管内流体的线速度（$\mathrm{m/s}$）。电液伺服机构将电控信号转换为分布器阀芯的运动。

- **分布器**：能够改变从一次能源传送到发动机的**流体流速**；
- **执行链**：电控信号通常是**电流放大**，并馈入一个（直接地或间接地）驱动分布器的**电磁阀**，其位置由适当的**传感器测量**；
- **结果**：得到一个**基于阀杆位置的伺服系统**——「它可以减少可能在发动机控制中发生的任何稳定性问题」。

**线性化**：通过**灵巧的机械设计**可能获得**线性化特性**；控制信号的量值决定压缩流体通过分布器的流速。
:::

这一页要学的是方法：**液压放大器的核心不是「放大电流」，而是「用一个位置伺服系统去驱动一个阀」**——把流量控制问题转化成一个成熟的阀杆位置控制问题，这正是教材所说的「减少稳定性问题」。

::: think 考点 · 老师原话（录播时间点）

> **直流与交流的分工**：「而对于控制无刷，这时候就需要把它**转化成交流**，把直流转成交流，来提供给无刷（直流）电机的各个（相）」（01:01:00）。

> **液压靠改流速**：「对于液压发动机呢，可以通过**改变传送到发动机的流体的流速**，来实现对发动机的（控制）」（01:02:04）。
:::

::: think 默写点 · 合上书再写（主动回忆）

1. 放大器从能源取功率，取多少由什么决定？取来的功率分成哪两部分？
2. 永磁直流与无刷直流各配什么放大器？为什么？
3. 功率转化率与功率增益的定义式各是什么？为什么增益能到 $10^6$？
4. 液压侧靠什么调节发动机？「基于阀杆位置的伺服系统」是怎么构成的？

::: sol 核对

功率调节由控制信号的电压、电流等信息决定，不是只由信号功率 $P_c$ 的数值决定；能源和控制端输入的功率满足 $P_e+P_c=P_a+P_{da}$（忽略储能变化），通常可忽略很小的 $P_c$。

永磁直流配 **DC-DC 变换器（斩波器）**，因为其电压/电流是直流的；无刷直流配 **DC-AC 变换器（逆变器）**，因为其电压/电流是交流的（需把直流转成交流供给各相）。

$\dfrac{P_a}{P_a+P_{da}}>0.9$；$\dfrac{P_a}{P_c}$ 达 $10^6$ 级。因为分母 $P_c$ 只是控制信号的功率，能量主体 $P_e$ 从能源来，故比值可以极大。

靠**改变传送到发动机的压缩液体的流速**。构成：电流放大后的电控信号 → 电磁阀（直接或间接驱动分布器）→ 分布器改变流速；阀杆位置由传感器测量并闭环，构成**阀杆位置伺服系统**。

:::

:::

### 5.1.3 小结与常见错误

- **一句话**：放大器根据控制信号调节能源送往执行器的功率，功率增益所需的能量来自能源。
- **两条路线**：电机侧按电压形式分斩波器/逆变器，控制量是电压（或电压与频率）；液压侧控制流量，靠电液伺服系统 + 分布器 + 阀杆位置反馈。
- **两个数**：功率转化率 > 0.9，功率增益 $10^6$ 级。

::: think 常见错误清单 · 自查三条
1. 把 $P_c$ 当成「被放大的信号」以为能量来自它——能量来自 $P_e$，$P_c$ 只决定分配比例。
2. 记反斩波器/逆变器：**斩波 = DC-DC（永磁直流）**，**逆变 = DC-AC（无刷）**。
3. 以为液压功放只是电流放大器——电信号控制阀芯位移，进而调节来自液压源的流量与压差；功率来源仍是液压源。
:::

## 5.1.4 能源

能源向功率放大器供能。电机侧需要合适的直流母线；液压侧需要泵站提供受压流体。储液器与整流输出的滤波电容都能储能、缓和波动，但它们的储能机理和设计条件并不相同。

<a id="sec-5.1.4.1"></a>

### 5.1.4.1 能源的任务

::: def 定义 5.1.13 · 能源的任务 {#def-5.1.13}
**能源的任务是向放大器提供一级功率**，这是执行系统工作所必须的。

**电源（伺服电机用）**：通常由一个**变压器**和一个典型的**无控桥式整流器**组成。它们允许把分配器提供的**交流电**转化为**大小适当的、需要输入功率放大器的直流电**。

**液压源（液压伺服发动机用）**：**显然更复杂**。它需要：

1. 一个**齿轮泵**或**柱塞泵**，用来压缩流体；
2. 一台原动机（典型地是**三相异步电动机**），通常按**常速**驱动泵；
3. 一个**储液器**，用来储存液压能——目的是**降低由发动机工作条件决定的流速需求所引起的、不可避免的压力振荡**；
4. 一整套确保系统正常运行的组成：**过油器、压力阀、配流阀**（即液压泵站）。
:::

::: note 储液器 = 滤波电容 {#note-5.1.4}
教材 §5.1.4 给出一条极干净的类比：**储液器的作用，与桥式整流器输出中使用的滤波电容的作用相同**。

- **电源侧**：整流器把交流变直流，输出带有**纹波**；并联的**电容**储能、把电压纹波抹平；
- **液压侧**：泵的流速需求随工况波动，回路中产生**压力振荡**；并联的**储液器**储能、把压力振荡抹平。

两者的共同点是储能并在供需不平衡时交换能量。类比只说明作用：电容储存电场能，液压蓄能器通常借气体压缩等方式储存能量；容量、压力限制和动态响应必须分别设计，增加储能也不保证消除所有振荡。

这里教材称「储液器」的储能元件是**液压蓄能器**，不是常压储油箱。泵主要输送流量，压力由负载与回路约束建立；蓄能器储存压力能，常压油箱主要储存、冷却和回收油液，不能互相代替。
:::

**代价**：教材最后给出一句警示——「在**高压（100 atm 级）**下工作的复杂液压回路，将引起**可观的工作环境污染**」。这与 [@method-5.1.D] 对照表中「漏油会对工作环境造成污染」是同一条。


<a id="sec-5.1.4"></a>

::: think 考点 · 老师原话（录播时间点）

> **能源是「被忽略的一环」**：「第四个呢，就是能源」——老师在这一页只讲了两分钟，但把两种能源的结构都点了（01:02:21）。

> **储液器与电容同功**：「要降低压力震荡，还需要加入一个储液器。这储液器的功能呢，跟（整流）电路中的（滤波）电容是一样（的）」（01:03:12）。

> **执行系统是心脏**：讲完能源后老师总结「整个上面就是咱们的关节执行系统……**是（机器人）机械系统的心脏**，相当于咱们**人体的肌肉**这部分」（01:03:27）。
:::

1. 能源的任务是什么？
2. 电源由哪两部分构成？完成什么转换？
3. 液压源由哪几部分构成？储液器解决什么问题？
4. 「储液器 ↔ 滤波电容」这条类比的关键是什么？

::: sol 核对

向**放大器提供一级功率**，这是执行系统工作所必须的。

**变压器 + 无控桥式整流器**；把分配器提供的**交流电**转化为大小适当的、供功率放大器使用的**直流电**。

**齿轮泵或柱塞泵**（压缩流体）+ **三相异步电动机**（按常速驱动）+ **储液器**（储存液压能）+ **过油器、压力阀、配流阀**（泵站组成）。储液器解决**由流速需求引起的压力振荡**。

两者都是「**并接在输出端的储能元件**」，吸收波动：电容抹平整流输出的**电压纹波**，储液器抹平泵站回路的**压力振荡**。

:::

:::

### 5.1.4 小结与常见错误

- **一句话**：能源给放大器提供**一级功率**——电机侧是「变压器 + 整流 → 直流」，液压侧是「泵 + 电机 + 储液器 + 阀组」。
- **一个类比**：储液器与滤波电容都储能、缓和输出波动；具体机理和适用条件不同。
- **一个代价**：高压液压回路带来可观的环境污染。

::: think 常见错误清单 · 自查三条
1. 把**能源**与**放大器**的职责搞反：能源给「与 $P_a$ 同性质」的一级功率 $P_e$，放大器才是受 $P_c$ 调制的那一级。
2. 认为液压源只是「一只泵」——泵站还必须有过油器、压力阀、配流阀，以及**储液器**。
3. 忽略环境污染这一条：它是 §5.2.2 液压驱动取舍里的硬约束之一。
:::

核心公式速查：

| 公式 | 条件与假设 | 单位/量纲 | 易错点 |
|:--|:--|:--|:--|
| 功率链：$P_c+P_e\to P_a\to P_m\to P_u$；$P_m=P_a-P_{dm}$，$P_u=P_m-P_{dt}$ | 准稳态、忽略内部储能 | W | 功放放大的是功率，能量来自 $P_e$；$P_c$ 只是「指挥」 |
| 功率 = 力 × 速度：机械「力矩 × 角速度」、电「电压 × 电流」、液压「压力 × 流量」 | 恒等式 | W | 这条恒等式指明功率的种类，是选型出发点 |
| 效率：$\eta_m=P_m/P_a$，$\eta_t=P_u/P_m$ | 正向供能、输入功率为正 | — | 静止保持或再生制动不能照套；从能源端算整体效率还要乘放大器效率 |
| 工况矛盾：关节要「低速高转矩」，发动机最优区是「高速低转矩」 | 一般 R/P 关节 + 旋转电机 | — | 传动是解法之一；直驱是另一条路（代价见 5.1.1.3） |
