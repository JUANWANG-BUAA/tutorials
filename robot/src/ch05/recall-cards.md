## A. 定义卡

### A1 · 关节执行系统与功率链

写出四个组成部分、各自的职能，以及八个功率符号里哪三个是损失。

::: sol A1 核对
四部分为能源、功率放大器、伺服发动机、传动装置；分别供能、按控制信号调节功率、转为机械功率、匹配两侧工况。功率符号为 $P_c,P_e,P_a,P_m,P_u$，三处损耗为 $P_{da}$（功放）、$P_{dm}$（发动机）、$P_{dt}$（传动）。控制信号也有功率，只是很小；例如 $3.3\ \mathrm V\times1\ \mathrm{mA}=3.3\ \mathrm{mW}$，$100\ \mathrm W$ 约为它的 $3\times10^4$ 倍。主要输出能量来自能源，功放不创造能量。（[@def-5.1.1]、[@def-5.1.2]）
:::

### A2 · 传动装置的三个作用

写出三个作用，并说明第三个作用改善的是什么性能。

::: sol A2 核对
① **定量变换**：定量地传输发动机的输出（速度和力矩）——即「**降速增矩**」。② **定性变换**：定性地改变运动形式——把绕发动机轴的**旋转运动**转化为关节的**平移运动**（「电机只能提供一个转动的需求，但实际的过程中我们可能需要一个平动的需求」）。③ **减重（优化有效载荷）**：当发动机位于关节**上游**时，通过减小有效载荷优化机械手的**静态性能和动态性能**——典型做法是把发动机装在机器人**基座**上，则机械手总重量降低、**功率—重量比**提高。**第三条的机制**：把比较重的质量和机械臂都放在**基座附近**、通过传动方式把动力传到末端，这样末端惯量小，「其实是有助于控制的」——老师说得很本质：「**惯量它是起到一个延迟的作用**」。（[@def-5.1.3]）

这里「总重量降低」须结合结构重新设计理解：把同一台电机移到基座并不改变整机总质量，直接减小的是运动连杆负担；整机能否减重还要计入新增传动和支撑结构。
:::

### A3 · 三种典型传动装置

写出三种装置各实现什么变换、各自用在什么场合。

::: sol A3 核对
**圆柱齿轮**（spur gears）：旋转 → 旋转，通过**改变旋转轴**和 / 或**平移作用点**来改变发动机的旋转运动——需要换向 / 换轴位置时用。**丝杠**（lead screws）：旋转 → **平移**，用于**移动关节**；为减小摩擦常预装**滚珠丝杠**以提高刚性并降低间隙。**同步带**（timing belts）与**正时链**（chains）：运动学上**二者等价**，用于把发动机**定位在远离驱动关节的轴上**——皮带靠拉紧传动，用于**高速度、低力量**（带轻但「矩太大的话就会变形」）；链条质量大、高速时会**颤动**，用于**低速度**（「但是低速高矩是可以，因为它是钢的」）。**一句话**：**要快要轻用带，要重（大力矩）耐操用链。**（[@method-5.1.C]）
:::

### A4 · 直接驱动的收益与代价

写出直驱省掉了什么、付出了什么，并说明传动装置"隐藏的第四个作用"。

::: sol A4 核对
直驱省去减速传动的齿隙与弹性，但仍有电机、轴承及机械结构的刚度和误差；电机须直接满足关节转矩。老师用「直驱时对控制算法要求非常高」「加上传动装置，我控制这个关节就单独控制这个关节」说明折算耦合的作用。严格说减速器不精确解耦，是否可独立控制须比较惯量、耦合、运动范围与精度；直驱也不必在所有任务下都用复杂算法。成本、尺寸、带宽与传动误差共同决定取舍。（[@def-5.1.4]）
:::

### A5 · 永磁直流与无刷直流伺服电机的组成

各写出三部分，并说清「哪两个角色在互相对应」。

::: sol A5 核对
**有刷永磁直流**：永磁定子、电枢绕组转子、换向器与电刷。**无刷直流**：永磁转子、多相定子绕组、根据转子位置换相的电子模块。有刷通过机械换向切换转子电流，无刷通过电子开关切换定子各相电流；二者都为持续产生转矩调整磁场相对方向。（[@def-5.1.7]、[@def-5.1.8]）
:::

### A6 · 电气驱动的四个基本方程

写出四个方程，并指出哪一个常数把"电"与"机"连起来。

::: sol A6 核对
**电枢电平衡**：$V_a=(R_a+sL_a)I_a+V_g$；**反电动势**：$V_g=k_v\Omega_m$；**力学平衡**：$C_m=(sI_m+F_m)\Omega_m+C_l$；**驱动力矩**：$C_m=k_tI_a$。**读法**：前两式是「电」、后两式是「机」，而 **$k_t=k_v$ 是电与机之间的桥**——「**转矩常数 $k_t$ 在标准国际单位上与电压常数 $k_v$ 数值相等**」，这一条在后续推导中反复用到。**反电动势的物理含义**：电机转得越快，留给「推电流」的电压越少——这正是电机的**自然速度负反馈**。**降阶的前提**：放大器时间常数 $T_v$ 在 $10^{-5}$ 到 $10^{-4}\ \mathrm{s}$ 量级（调制频率 10 kHz–100 kHz 时），**比机械时间常数小几个数量级**，故可令 $T_v\approx0$。（[@def-5.2.1]）

上述数值等式限定于理想直流集总模型、固定磁通和一致 SI 定义，两常数单位不同。拉普拉斯方程按零初始条件书写；是否忽略电感及功放动态，还须核对研究频带，不能仅凭开关频率推断所有机械系统的时间尺度。
:::

### A7 · 两种传感器：本体与外部

写出定义、各自测什么、典型成员，并解释「关节力矩为什么算本体量」。

::: sol A7 核对
**本体传感器**（proprioceptive）：对表征机械手**内部状态**的变量进行**在线测量**——三个量是**关节位置、关节速度、关节力矩**；目的是让参数辨识与控制算法产生「与任务规划相对应的机械结构协调运动」；典型成员：编码器、旋转变压器（位置）、转速计（速度）。**外部传感器**（exteroceptive）：提取**表征机器人与环境目标交互作用的特征**，以提高系统的自动化程度；典型成员：**力传感器、触觉传感器、接近传感器、距离传感器、视觉传感器**（此外声音、湿度、烟尘、压力、温度等特殊传感器也属这一类）。**关节力矩的「名分」**：教材把它列为本体量（它是机械手自己的内部状态），而承载测力的**腕力传感器**却归入外部传感器（它测的是**末端与环境交互**的力）。两者之间隔着静力学的雅可比转置映射 $\boldsymbol\tau=J^{\mathrm T}F$。**一句话**：**分类看「测什么」，不看「装在哪」。**（[@def-5.3.1]、[@def-5.4.1]）

本体量不意味着每个量都必须直接独立测量，也可由其他测量和模型估计。使用 $\tau=J^{\mathrm T}F$ 时须统一坐标系、作用点及正方向；该式只给该末端力产生的关节力矩分量，不自动包含惯性、摩擦和其他负载。
:::

## B. 结论卡

### B1 · 「无间隙刚性传动 ⇒ 纯比例」这条假定买到了什么

写出假定本身与它的两个推论。

::: sol B1 核对
刚性、无间隙、无打滑且定比给出 $\omega_m=k_r\omega$；进一步无摩擦等损失，才由功率相等得到 $C_{\rm out}=k_rC_{\rm in}$。两条假设不能混用。正向供能、忽略储能变化时，$P_m=P_a-P_{dm}$、$P_u=P_m-P_{dt}$，$\eta_m=P_m/P_a$、$\eta_t=P_u/P_m$；功放满足 $P_e+P_c=P_a+P_{da}$，主要能量来自 $P_e$。（[@thm-5.1.F]、[@method-5.1.A]）
:::

### B2 · 电动 vs 液压：一张对照表

按「优势 / 局限 / 工况特点 / 适用场合」四行各写要点。

::: sol B2 核对
| | **伺服电机** | **液压伺服发动机** |
|:--|:--|:--|
| **优势** | 能源来源广泛；成本低且产品范围宽；功率转化效率高；易于维护；对工作环境无污染 | 静态下**不会熄火**；**自润滑**、循环液体便于热处理；在**有害环境**下也很安全；**很高的功率—重量比** |
| **局限** | 堵转或静止输出转矩时仍可能通电发热；垂直负载须考虑失电制动；易燃环境须适当防护 | 需液压源；成本、效率、维护与漏油污染须权衡，失压保持须另设安全措施 |
| **工况特点** | 按所需转矩—速度选择电机与减速器，也可直驱 | 可在低速产生大转矩，但具体能力仍取决于压力、排量与热限制 |
| **适用场合** | 一般工业机械手 | **搬运重载荷**——不仅最合适，而且装置成本能降低操纵系统的整体开销 |

先核对任务的力矩—速度与负载，再比较环境、防护、维护和失能安全；「静止不熄火」不等于无需负载保持措施。教材指出电动控制灵活，液压动态也受油液温度影响；二者不存在不分工况的优劣排序。（[@method-5.1.D]）
:::

### B3 · 电流反馈的双重目的与"加不加"的取舍

写出双重目的，并限定教材所列电流反馈取舍结论的适用条件。

::: sol B3 核对
电流调节器可改善参考电流跟踪；参考限幅与电流反馈配合可限流、保护功放。在 $F_m\ll k_vk_t/R_a$ 等降阶条件下，所列无电流反馈速度模型的负载静态增益与时间常数较小，不代表所有电流环都使抗扰变差。教材另给带死区电流反馈的限流结构；集中控制需要力矩源时，可用电流环近似实现，但仍须检查带宽与饱和。（[@def-5.2.2]、[@thm-5.2.B]）
:::

### B4 · 两个折算因子：$1/k_r^2$ 与 $1/k_r$

写出两个等效量的表达式与负载力矩的折算因子，并给一个 $k_r=100$ 的数量感。

::: sol B4 核对
$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{C_l}{k_r},\qquad
I_{eq}=I_m+\frac{I}{k_r^2},\qquad F_{eq}=F_m+\frac{F}{k_r^2}.$$

载荷惯量与摩擦先经过力矩折算 $1/k_r$，再经过速度或角加速度折算 $1/k_r$，合计 $1/k_r^2$；外负载力矩只做一次力矩折算。$k_r=100$ 时分别为 $1/10000$ 与 $1/100$。重力项幅值变小，但是否可以线性化还须看关节的实际运动范围。（[@thm-5.2.C]）
:::

### B5 · 位置伺服中的比例与积分

写出对象和 PI 控制器的原点极点，并说明恒定负载下积分的作用和稳定条件。

::: sol B5 核对
$M(s)=k_m/[s(1+sT_m)]$ 自身只有一个原点极点；PI 控制器 $K_p+K_I/s$ 再引入一个。对单位位置反馈、恒定位置参考和恒定输入端扰动，纯比例稳定时仍有 $e_{\rm ss}=d_0/K_p$。PI 闭环稳定时误差可趋于零；在 $k_m,T_m,K_p,K_I>0$ 下还要求 $K_p>T_mK_I$。积分并非所有位置伺服结构的必需条件。（[@thm-5.2.D]）
:::

### B6 · 编码器：分辨率、格雷码与"置换零"

写出绝对式与增量式的关键差别，以及各自的两个工程细节。

::: sol B6 核对
单圈绝对式码盘的 $n$ 位对应 $2^n$ 个圈内位置；格雷码相邻只变一位，可避免多位切换的中间错误码，不能消除全部误差。减速后多圈位置还须可靠保存，掉电运动时易失计圈不够。增量式 A/B 正交，用于计数与判向；领先相与顺逆时针的对应取决于接线和观察方向。Z 相每转提供一个参考，不单独给出减速后关节绝对位置；通常先建立参考，再累计带符号计数，漏计或掉电运动后须重新确定位置。多圈绝对式另有保持圈数的机制，不能与单圈码盘混称。（[@def-5.3.3]、[@thm-5.3.B]）
:::

## C. 公式卡

### C1 · 电气驱动的统一传递函数（两种发电机）

写出统一式与两种情形下的 $k_m,T_m$，并说明放大器在两种情形下分别出现在哪里。

::: sol C1 核对
$$M(s)=\frac{k_m}{s(1+sT_m)},\qquad
\text{速度控制：}k_m=\frac{1}{k_v},\ T_m=\frac{R_aI_m}{k_vk_t};\qquad
\text{力矩控制：}k_m=\frac{k_t}{k_iF_m},\ T_m=\frac{I_m}{F_m}.$$

**两种近似的条件**：无电流反馈的速度控制式还要求电枢电阻产生的电磁阻尼远大于 $F_m$；力矩控制式要求电流环增益足够大，并满足忽略电感等模型近似。速度控制中放大器增益作用于参考输入；力矩控制的大增益近似中，电流环使输入增益趋近 $k_t/k_i$。带宽仍需结合完整闭环和参数判断。([@thm-5.2.A])
:::

### C2 · 齿轮耦合的力学平衡

写出 $k_r$ 的定义、两个力学平衡式与消去 $f$ 后的结果。

::: sol C2 核对
$$k_r=\frac{\omega_m}{\omega}=\frac{r}{r_m}\qquad(\text{无打滑：}r_m\vartheta_m=r\vartheta).$$

对机器人机械手，减速比**远大于 1**（$r_m\ll r$），**典型值从几十到几百**。交换力 $f$ 在两个轴上分别产生**负载力矩 $f r_m$**（作用在发动机轴上）与**驱动力矩 $f r$**（作用于载荷），于是

$$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m,\qquad fr=I\dot\omega+F\omega+C_l .$$

消去 $f$ 即得 $C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{C_l}{k_r}$（$I_{eq},F_{eq}$ 见 B4）。**注意**：齿轮本身的转动惯量和摩擦系数**被包含在**上述参数里。（[@def-5.2.4]、[@thm-5.2.C]）
:::

### C3 · 摆的例子：大减速比如何"线性化"非线性

写出折算前后的方程，并指出 $k_r$ 从哪两条途径削弱重力矩。

::: sol C3 核对
原始方程组：$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m$、$fr=I\dot\omega+F\omega+mgl\sin\vartheta$。$I$ 为绕载荷轴的惯量，$m$ 为质量，$l$ 为转轴到质心距离；$\vartheta$ 从竖直向下量起。折算为：

$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{mgl}{k_r}\sin\frac{\vartheta_m}{k_r}.$$

重力项幅值除以 $k_r$；固定电机小行程时，关节变化范围也除以 $k_r$，有利于局部线性化。固定关节行程时没有范围缩小的收益，不能把大减速比当作全工作区线性化证明。多连杆还存在构形相关惯量和速度耦合；双摆中变化的是第一轴的**含载荷等效惯量**，不是电机转子自身惯量。是否可独立控制须检查这些项与电机惯性及所需精度的相对大小。本教程第六章（原书第七章）讨论整机动力学。（[@ex-5.2.D]）
:::

### C4 · 液压驱动的六条基础方程

写出流速平衡与各项，并说明 $k_c$ 在旋转式与直线式上的差别。

::: sol C4 核对
$$Q=Q_m+Q_l+Q_c\quad(\text{流速平衡}),\qquad
Q_l=k_lp\ (\text{渗漏}),\qquad
Q_c=\gamma Vsp\ (\text{可压缩性}),$$
$$Q_m=k_q\Omega_m,\qquad C_m=(sI_m+F_m)\Omega_m+C_l,\qquad C_m=k_pp .$$

另有伺服阀 $x/V_c=G_c/(1+sT_c)$ 和工作点增量关系 $p=k_xx-k_r^{(v)}Q$；这里 $k_r^{(v)}$ 是阀口系数，不是排量系数 $k_q$ 或减速比。$Q$ 是体积流量（$\mathrm{m^3/s}$），$p$ 是压差（Pa），$k_c=\gamma V$ 为工作点等效压缩系数。旋转模型取固定等效体积，直线模型通常随行程变化；泄漏耗散、压缩储能都须按工况判断。它们与电阻、电感可作角色类比，但不是可互换元件。压力—流量耦合是物理结构，不是可任选安装的测量反馈。（[@def-5.2.3]、[@method-5.2.A]）
:::

### C5 · 位置 + 速度反馈的两条改进

写出结构与两条改进，并说明内部速度回路为什么还要保留 PI。

::: sol C5 核对
**结构**：位置外环产生速度参考，速度内环比较速度参考与测量值；内环可用 PI 来消除稳定闭环中的恒定扰动偏差。合适的参数可能改善瞬态抗扰和带宽，但环路数量本身不保证改善。**推广到齿轮耦合**：用 $I_{eq}$、$F_{eq}$ 替代电机惯量与摩擦，并将载荷力矩按 $1/k_r$ 折算到电机轴。电流控制近似下放大器增益不再单独出现在参考输入增益中；有限增益时仍有影响。([@method-5.2.E]、[@note-5.2.1])
:::

### C6 · 惠斯通电桥与温度补偿

写出式 (5.30)，并说明温度补偿与提高灵敏度各靠什么。

::: sol C6 核对
$$V_o=\left(\frac{R_2}{R_1+R_2}-\frac{R_s}{R_3+R_s}\right)V_i .$$

张力计嵌入惠斯通电桥的**一个桥臂**，**张力计上没有应力时电桥平衡（输出为零）**。**温度补偿**：如果温度变化，没有外力时金属丝也会改变长度 ⇒ 解决办法是在电桥**相邻的臂**上再嵌入**另一个张力计**，并把它粘合到可扩张元件**不受张力作用**的部分——两个张力计处于同一环境，温度引起的那部分电阻变化就在电桥里**相减抵消**。**提高灵敏度**：用到**两个张力计**，让它们以「**一个受牵引、一个受压缩**」的方式贴到可扩展元件上，并嵌入电桥的**两个相邻臂**——同一位置的两种应变符号相反，于是两路的信号变化在输出中**相加**（老师用**梁**举例：梁受弯曲时上面受拉、下面受压，「它的灵敏度是大体相反的」）。（[@def-5.4.2]）
:::

### C7 · 传感器校准矩阵

写出式 (5.31) 的含义与「8 路测量 → 6 个分量」的关系，并说明测量通道可否少于 8 路。

::: sol C7 核对
$$\begin{bmatrix}\boldsymbol f^s\\ \boldsymbol\mu^s\end{bmatrix}=\Phi\,\boldsymbol w,\qquad \boldsymbol w=[w_1\ \cdots\ w_8]^{\mathrm T}\ (\text{八个电桥的输出信号}).$$

$6\times8$ 校准矩阵 $\Phi$ 将八路测量组合成六维力与力矩，每个系数由标定确定。八路可提供冗余，但并非必须多于六路；六个独立通道的响应矩阵满秩时也可重构。马耳他十字是教材给出的具体结构，不应把它的通道数当成所有设计的要求。（[@thm-5.4.A]）
:::

### C8 · 力传感器坐标系 → 约束坐标系的变换

写出变换式，并说明两个待准备的量与一条使用条件。

::: sol C8 核对
$$\begin{bmatrix}\boldsymbol f^c_c\\ \boldsymbol\mu^c_c\end{bmatrix}=
\begin{bmatrix}R^c_s&O\\ S(\boldsymbol r^c_{cs})R^c_s&R^c_s\end{bmatrix}
\begin{bmatrix}\boldsymbol f^s_s\\ \boldsymbol\mu^s_s\end{bmatrix}.$$

$r^c_{cs}$ 是传感器原点在 $c$ 中的位置，$R^c_s$ 是两坐标系的相对旋转。力矩既要旋转，也要加 $r^c_{cs}\times R^c_sf^s_s$ 的参考点迁移项。变换使用当前相对位姿；两个坐标系刚性固连时，整体运动不改变相对位姿。实际接触力还需考虑工具重力、惯性和受力方向。（[@method-5.4.B]）
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「功率放大器放大的是信号」

::: sol D1 核对
控制信号也有小功率；例如 $3.3\ \mathrm V\times1\ \mathrm{mA}=3.3\ \mathrm{mW}$，而 $100\ \mathrm W$ 约为它的 $3\times10^4$ 倍。功放按信号的电压、电流等信息调节能源送来的功率，不能只把 $P_c$ 的数值当作指令，也不能说信号本身「没有功率」。忽略储能变化时 $P_e+P_c=P_a+P_{da}$。（[@def-5.1.1]、[@method-5.1.A]）
:::

### D2 · 「理想传动装置改变功率 / 减速比只影响力矩」

::: sol D2 核对
**两处都错。** ① **理想传动装置不改变功率**（$P_u=P_m$），它改变的是**力与速度的分配**——降速增矩是把「高转速低转矩」翻译成「低转速高转矩」，总功率（理想情形下）守恒。② **减速比对惯量的影响往往更重要**：载荷惯量与摩擦按 **$1/k_r^2$** 折算（$k_r=100$ 时缩小 **10000 倍**），而负载力矩只按 **$1/k_r$** 缩小。**连带的一条**：**直驱不等于更先进**——它换掉的是弹性与间隙，代价是**控制复杂度**（非线性耦合项无法忽略），工业上多数场合并不采用。（[@thm-5.2.C]、[5.1.1](sec5-1.md#part-5.1.1) 常见错误 2、3）
:::

### D3 · 「把 $k_v$ 与 $k_t$ 当成两个独立参数」

::: sol D3 核对
本节理想直流模型、磁通固定且采用一致 SI 定义时，$k_t$ 与 $k_v$ **数值相等、单位不同**。三相电机的线/相、峰值/有效值等口径须先统一，不能直接照抄数值等式。忽略功放和电气动态也须在所研究频带内检查时间尺度，而非所有电机均可忽略。（[@def-5.2.1]）
:::

### D4 · 「加了电流反馈一定更好」

::: sol D4 核对
「一定更好」不成立，但也不能反过来说「一定更差」。教材比较的是两种降阶模型：在 $F_m\ll k_vk_t/R_a$ 等条件下，无电流反馈模型的负载静态增益和时间常数较小。实际伺服的抗扰还取决于内外环控制器、带宽、限幅和噪声。力矩控制需要时可选电流环；无常规线性电流环时仍须采取适当限流保护。（[@thm-5.2.B]）
:::

### D5 · 「用编码器差分就能精确得到速度」

::: sol D5 核对
编码器可通过计数或测周期重建速度；固定窗口下高速时计数多，周期法在低速时通常有利。量化和噪声会影响差分，延长窗口又带来延迟；转速计也有纹波、偏置等误差，因此应按精度、带宽及工况比较，而不能断言直接测量一定更准。（[@method-5.3.A]）
:::

### D6 · 「直流转速计的纹波可以靠滤波消掉」

::: sol D6 核对
直流转速计的换向纹波频率随转速变化。若与有用速度信号的频带分开，可通过滤波衰减；频带重叠时，固定滤波器难以同时保留信号并去掉纹波。交流转速计的原始感应信号与励磁同频，同步检波后出现两倍励磁频率的分量，频带分开时可滤除。（[@method-5.3.A]）
:::
