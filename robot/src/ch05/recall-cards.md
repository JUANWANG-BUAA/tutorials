## A. 定义卡

### A1 · 关节执行系统与功率链

写出四个组成部分、各自的职能，以及八个功率符号里哪三个是损失。

::: note A1 核对
**四部分**：① **能源**（一次能源，提供与控制信号无关的功率）；② **功率放大器**（把控制规律给出的**小信号**放大成能驱动发动机的功率）；③ **伺服发动机**（把电 / 液压 / 气动的功率转成**机械功率**）；④ **传动装置**（把发动机的高转速低转矩匹配成关节需要的低转速高转矩）。四者串成一条**功率链**，末端才是关节与机械手本体。**八个符号**：$P_c$（与控制规律信号相关的功率，通常是电的）、$P_e$（一次能源提供的功率）、$P_a$（提供给发动机的功率）、$P_m$（发动机产生的机械功率）、$P_u$（关节所需的机械功率）；三个损失是 $P_{da}$（**放大器**耗费）、$P_{dm}$（**发动机**耗费）、$P_{dt}$（**传动装置**耗费，主要是摩擦）。**为什么必须有功放这一环**：控制器输出约 3.3 V、微安到毫安级（约 3.3 mW），而电机是几十瓦到上千瓦——**差 $10^5$ 量级**；控制器信号**没有功率但有规律**，功放要做的不是造能量，而是**按这个规律去调制能源送来的功率**——放大的是**功率**，不是信号。（[@def-5.1.1]、[@def-5.1.2]）
:::

### A2 · 传动装置的三个作用

写出三个作用，并说明第三个作用改善的是什么性能。

::: note A2 核对
① **定量变换**：定量地传输发动机的输出（速度和力矩）——即「**降速增矩**」。② **定性变换**：定性地改变运动形式——把绕发动机轴的**旋转运动**转化为关节的**平移运动**（「电机只能提供一个转动的需求，但实际的过程中我们可能需要一个平动的需求」）。③ **减重（优化有效载荷）**：当发动机位于关节**上游**时，通过减小有效载荷优化机械手的**静态性能和动态性能**——典型做法是把发动机装在机器人**基座**上，则机械手总重量降低、**功率—重量比**提高。**第三条的机制**：把比较重的质量和机械臂都放在**基座附近**、通过传动方式把动力传到末端，这样末端惯量小，「其实是有助于控制的」——老师说得很本质：「**惯量它是起到一个延迟的作用**」。（[@def-5.1.3]）
:::

### A3 · 三种典型传动装置

写出三种装置各实现什么变换、各自用在什么场合。

::: note A3 核对
**圆柱齿轮**（spur gears）：旋转 → 旋转，通过**改变旋转轴**和 / 或**平移作用点**来改变发动机的旋转运动——需要换向 / 换轴位置时用。**丝杠**（lead screws）：旋转 → **平移**，用于**移动关节**；为减小摩擦常预装**滚珠丝杠**以提高刚性并降低间隙。**同步带**（timing belts）与**正时链**（chains）：运动学上**二者等价**，用于把发动机**定位在远离驱动关节的轴上**——皮带靠拉紧传动，用于**高速度、低力量**（带轻但「矩太大的话就会变形」）；链条质量大、高速时会**颤动**，用于**低速度**（「但是低速高矩是可以，因为它是钢的」）。**一句话**：**要快要轻用带，要重（大力矩）耐操用链。**（[@method-5.1.C]）
:::

### A4 · 直接驱动的收益与代价

写出直驱省掉了什么、付出了什么，并说明传动装置"隐藏的第四个作用"。

::: note A4 核对
**收益**：消除了传动装置**弹性和间隙**导致的缺点——没有齿隙、没有回差、没有传动刚度问题。**代价**：需要**更复杂精密的控制算法**——「**没有了减速齿轮，就无法忽略动力学模型中的非线性耦合项**」。老师讲得更具体：直驱时「它对控制算法的要求就非常高」，因为关节与下游各关节之间是**强耦合**；而「如果我们加上传动装置，**我控制这个关节就单独控制这个关节**」——传动装置通过比例系数把下游的**动力耦合与非线性耦合因素减弱了**。**这就是传动装置的第四个隐藏作用：解耦**——把「一整条链上的强耦合系统」切成「每轴一个近似独立的单输入单输出系统」，这正是后面几章控制器能**按关节分别设计**的物理根据。**结论**：由于**成本、发动机尺寸和控制复杂性**，直接驱动在工业机械手中**并不普遍**。（[@def-5.1.4]）
:::

### A5 · 永磁直流与无刷直流伺服电机的组成

各写出三部分，并说清「哪两个角色在互相对应」。

::: note A5 核对
**永磁直流**：① **定子线圈**（产生磁通量，磁场通常由**永磁体**产生——铁磁陶瓷或稀土类材料）；② **电枢**（包括绕旋转磁心即**转子**的**通电绕组**）；③ **换向器**（根据转子的运动决定换向逻辑，并通过**电刷**为旋转的电枢线圈与外部绕组线圈提供电连接）。**无刷直流**：① **产生磁通量的旋转线圈（转子）**（由磁致伸缩陶瓷或稀土制成的**永磁体**）；② **固定电枢（定子）**（由**多相线圈**制成）；③ **静态整流器**（基于电机轴上的**位置传感器**提供的信号，把转子运动的函数生成电枢线圈相位的**馈入序列**）。**两个角色的对应**：有刷电机里**电刷与换向器**所起的作用，与无刷电机里**位置传感器与电子控制模块**所起的作用**是类似的**。**换相原理**：通过转子位置传感器找到**与磁场正交的线圈**，磁场作用于该线圈产生转子旋转；转子转过后电子控制模块使磁场依次与定子各相绕组作用，从而**电枢磁场始终与定子磁场正交**。（[@def-5.1.7]、[@def-5.1.8]）
:::

### A6 · 电气驱动的四个基本方程

写出四个方程，并指出哪一个常数把"电"与"机"连起来。

::: note A6 核对
**电枢电平衡**：$V_a=(R_a+sL_a)I_a+V_g$；**反电动势**：$V_g=k_v\Omega_m$；**力学平衡**：$C_m=(sI_m+F_m)\Omega_m+C_l$；**驱动力矩**：$C_m=k_tI_a$。**读法**：前两式是「电」、后两式是「机」，而 **$k_t=k_v$ 是电与机之间的桥**——「**转矩常数 $k_t$ 在标准国际单位上与电压常数 $k_v$ 数值相等**」，这一条在后续推导中反复用到。**反电动势的物理含义**：电机转得越快，留给「推电流」的电压越少——这正是电机的**自然速度负反馈**。**降阶的前提**：放大器时间常数 $T_v$ 在 $10^{-5}$ 到 $10^{-4}\ \mathrm{s}$ 量级（调制频率 10 kHz–100 kHz 时），**比机械时间常数小几个数量级**，故可令 $T_v\approx0$。（[@def-5.2.1]）
:::

### A7 · 两种传感器：本体与外部

写出定义、各自测什么、典型成员，并解释「关节力矩为什么算本体量」。

::: note A7 核对
**本体传感器**（proprioceptive）：对表征机械手**内部状态**的变量进行**在线测量**——三个量是**关节位置、关节速度、关节力矩**；目的是让参数辨识与控制算法产生「与任务规划相对应的机械结构协调运动」；典型成员：编码器、旋转变压器（位置）、转速计（速度）。**外部传感器**（exteroceptive）：提取**表征机器人与环境目标交互作用的特征**，以提高系统的自动化程度；典型成员：**力传感器、触觉传感器、接近传感器、距离传感器、视觉传感器**（此外声音、湿度、烟尘、压力、温度等特殊传感器也属这一类）。**关节力矩的「名分」**：教材把它列为本体量（它是机械手自己的内部状态），而承载测力的**腕力传感器**却归入外部传感器（它测的是**末端与环境交互**的力）。两者之间隔着静力学的雅可比转置映射 $\boldsymbol\tau=J^{\mathrm T}F$。**一句话**：**分类看「测什么」，不看「装在哪」。**（[@def-5.3.1]、[@def-5.4.1]）
:::

## B. 结论卡

### B1 · 「无间隙刚性传动 ⇒ 纯比例」这条假定买到了什么

写出假定本身与它的两个推论。

::: note B1 核对
在**无间隙刚性传动**的假定下，**输入力（速度）与输出力（速度）之间是纯比例关系**。**推论一**：传动装置可以写成**比例环节**，从而得到「传动比如何改变系统的等效惯量、等效刚度与非线性影响」的全部结论（[5.2.3](sec5-2-3.md)）。**推论二**：**理想传动装置不改变功率**（$P_u=P_m$），它改变的是**力与速度的分配**。**配套的功率链**：$P_m=P_a-P_{dm}$、$P_u=P_m-P_{dt}$，效率 $\eta_m=P_m/P_a$、$\eta_t=P_u/P_m$；而 $P_a$ 与 $P_c$ 之间是**放大关系、不是守恒关系**（$P_a$ 的绝大部分来自能源 $P_e$，$P_c$ 只起控制作用）。（[@thm-5.1.F]、[@method-5.1.A]）
:::

### B2 · 电动 vs 液压：一张对照表

按「优势 / 局限 / 工况特点 / 适用场合」四行各写要点。

::: note B2 核对
| | **伺服电机** | **液压伺服发动机** |
|:--|:--|:--|
| **优势** | 能源来源广泛；成本低且产品范围宽；功率转化效率高；易于维护；对工作环境无污染 | 静态下**不会熄火**；**自润滑**、循环液体便于热处理；在**有害环境**下也很安全；**很高的功率—重量比** |
| **局限** | 由于机械手受重力作用，**静态条件下会引起熄火问题**（需紧急刹车）；在**易燃环境**下工作需特别保护 | 需要**液压源**；成本高、产品范围窄、**难以小型化**；效率低；需维护；**漏油会造成环境污染** |
| **工况特点** | 速度高、转矩低 ⇒ **需要用齿轮传动装置**（带来弹性与间隙） | **能在低速度下产生大转矩** |
| **适用场合** | 一般工业机械手 | **搬运重载荷**——不仅最合适，而且装置成本能降低操纵系统的整体开销 |

**读表的正确方式**：抓两行——**「速度高转矩低 vs 低速大转矩」**决定**用不用传动装置**；**「会不会熄火 + 环境要求」**决定在**危险或大负载场合选谁**。**动态性能**：伺服电机有更好的**控制灵活性**（两者都有很好的动态性能）；液压的动态性能**取决于压缩流体的温度**。（[@method-5.1.D]）
:::

### B3 · 电流反馈的双重目的与"加不加"的取舍

写出双重目的，并说明为什么独立关节控制**不建议**加电流反馈。

::: note B3 核对
**双重目的**：其一，电压 $v_c$ 起**参考电流**的作用——通过选择适当的调节器 $C_i(s)$，可以**减小电流 $I_a$ 与 $v_c$ 之间的滞后**；其二，引入**饱和非线性**可以限制 $v_c$ 的值，从而**起限流作用**——在非正常工作条件下**保证对功率放大器的保护**。**取舍**：**没有电流反馈时，系统对干扰力矩的抑制更好**（无论等价增益 $\frac{R_a}{k_vk_t}\ll\frac{1}{F_m}$ 还是时间响应 $\frac{R_aI_m}{k_vk_t}\ll\frac{I_m}{F_m}$）。因此在**需要高度抑制干扰力矩**的场合（如**独立关节控制**）**不建议在回路中有电流反馈**。**但保护问题仍要解决**：改用**在反馈回路上具有死区非线性特性的电流反馈**来限制电流，而**不是**用控制信号的饱和来限制——这样得到的电流限制「切实可行，其精度与死区斜率一样高」。**反过来**：**集中控制**方案要求驱动具有**力矩控制发电机**特性，这时就**应该**使用带适当调节器 $C_i(s)$ 的电流反馈。（[@def-5.2.2]、[@thm-5.2.B]）
:::

### B4 · 两个折算因子：$1/k_r^2$ 与 $1/k_r$

写出两个等效量的表达式与负载力矩的折算因子，并给一个 $k_r=100$ 的数量感。

::: note B4 核对
$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{C_l}{k_r},\qquad
I_{eq}=I_m+\frac{I}{k_r^2},\qquad F_{eq}=F_m+\frac{F}{k_r^2}.$$

**读法**（教材原话）：在齿轮具有大减速比的情形下，**载荷的转动惯量和粘滞摩擦系数按减速因子 $1/k_r^2$ 反映到发动机轴**；相反，**负载力矩由因子 $1/k_r$ 而减小**；而且——**如果这个力矩以非线性方式依赖于 $\vartheta$，则存在大减速比将使其趋向于线性化动态方程**。**数量感**（$k_r=100$）：载荷惯量与摩擦缩小 **10000 倍**、负载力矩缩小 **100 倍**。**为什么两个因子不同**：惯量 / 摩擦是「**速度的系数**」，在动力学方程里随 $\omega_m$ 的幂次变换；而力矩是「与速度量纲无关的**外力**」，只做一次量纲折算。（[@thm-5.2.C]）
:::

### B5 · 位置伺服为什么必须"积分 + 比例"

写出两个原点极点的含义，以及积分与比例各解决什么。

::: note B5 核对
传递函数 $M(s)=\dfrac{k_m}{s(1+sT_m)}$ 里，$1/s$ 来自「电压 → 位置」的积分，另一个 $1/(1+sT_m)$ 在低频近似的意义上**又贡献一个积分特性**——**两个原点极点 ⇒ 纯比例闭环的相位裕度极差**。**两条分工**：**积分**——若在稳态（$\vartheta',\dot\vartheta'$ 均为常量）期望**完全消除**干扰对输出的影响，控制器必须对 $\vartheta'$ 与 $k_{TP}\vartheta_m$ 之差引入的误差应用**积分控制**；**比例**——「加入**比例控制**的目的是实现**稳定控制**，但它**不能给闭环系统带来采样时间非常短的阻尼瞬态响应**」，原因正是「前向通路传递函数上有两个位于原点的极点」。**结论**：采用对误差具有**积分 + 比例**控制的简单控制器，参数 $K_r$ 与 $T_p$ 应灵活选择以确保稳定性与良好的动态特性。**一条上位结论**：**若驱动是速度控制的，则干扰达到最小**（负载力矩影响发动机轴速度的系数 $\frac{R_a}{k_vk_t}$ 远小于 $\frac{1}{F_m}$）——这是选速度控制模式的理由。（[@thm-5.2.D]）
:::

### B6 · 编码器：分辨率、格雷码与"置换零"

写出绝对式与增量式的关键差别，以及各自的两个工程细节。

::: note B6 核对
**绝对式**：光学玻璃盘上有**同心圆轨道**，每轨交替的透明 / 不透明扇区；**轨道数决定字长、从而决定分辨率**（$n$ 轨给出 $2^n$ 个角位置）。**工程细节一（码制）**：若用普通二进制，从一个扇区转到另一个时**可能同时有多位翻转**（如 $0001\to0010$），而光电元件与码道的安装不可能绝对对齐，读出码字既不是起点也不是终点 ⇒ **必须用格雷码**（相邻两码字**只差一位**），「每次转换仅发生一次对比的变化」，多位同时翻转引起的测量不确定性**被消除**。**工程细节二（圈数）**：$n$ 轨绝对式**只在一圈之内**给出唯一读数，跨圈之后码字重复，需要一个简单的电子装置**计数并存储实际的圈数**（每次经过零位加 1，反方向减 1，加减由转向决定）。**增量式**：光学盘只有**两条轨道**，透明扇区数相等且两路信号**相互正交**（相差 $90°$ 电角度）——除了给出转换（脉冲）**数目**，还额外地提供**旋转方向**（**A 先升沿 ⇒ 顺时针；B 先升沿 ⇒ 逆时针**）；通常还有**第三条轨道**，上面只有一个不光滑扇区，给出**一个绝对的机械零**。**增量式的结构性弱点**：使用它显然需要**对绝对位置赋值**（上电后先回零位、再累加），而**位置信息保存在非永久性（易失）存储器上**——电路上的扰动或**电源电压波动**都可能使位置信息出错；**这一缺陷在绝对式上不存在**（角位置直接编码在码盘上）。（[@def-5.3.3]、[@thm-5.3.B]）
:::

## C. 公式卡

### C1 · 电气驱动的统一传递函数（两种发电机）

写出统一式与两种情形下的 $k_m,T_m$，并说明放大器在两种情形下分别出现在哪里。

::: note C1 核对
$$M(s)=\frac{k_m}{s(1+sT_m)},\qquad
\text{速度控制：}k_m=\frac{1}{k_v},\ T_m=\frac{R_aI_m}{k_vk_t};\qquad
\text{力矩控制：}k_m=\frac{k_t}{k_iF_m},\ T_m=\frac{I_m}{F_m}.$$

**两点读数**：① **$k_i=0$（不加电流反馈）⇒ 速度控制发电机**，驱动器具有与**速度控制发电机**相同的特性；**$k_i\neq0$ 且取大回路增益（$Kk_i\gg R_a$）⇒ 力矩控制发电机**——「考虑到 $G_v$ 的值比较大，**驱动力矩实际上独立于角速度**」。② **放大器的位置差别**（教材专门提醒）：**速度控制**下放大器以常数 $G_v$ **直接作用于输入 / 输出关系**；**电流控制**下放大器处在**局部反馈回路内部**，不再单独出现，而是**以因子 $1/k_i$ 的形式钻进 $k_m$ 里**——老师把这一条概括为「**带宽增大**」（电流环把电气时间常数包进了内环，外层只剩机械时间常数 $I_m/F_m$）。（[@thm-5.2.A]）
:::

### C2 · 齿轮耦合的力学平衡

写出 $k_r$ 的定义、两个力学平衡式与消去 $f$ 后的结果。

::: note C2 核对
$$k_r=\frac{\omega_m}{\omega}=\frac{r}{r_m}\qquad(\text{无打滑：}r_m\vartheta_m=r\vartheta).$$

对机器人机械手，减速比**远大于 1**（$r_m\ll r$），**典型值从几十到几百**。交换力 $f$ 在两个轴上分别产生**负载力矩 $f r_m$**（作用在发动机轴上）与**驱动力矩 $f r$**（作用于载荷），于是

$$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m,\qquad fr=I\dot\omega+F\omega+C_l .$$

消去 $f$ 即得 $C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{C_l}{k_r}$（$I_{eq},F_{eq}$ 见 B4）。**注意**：齿轮本身的转动惯量和摩擦系数**被包含在**上述参数里。（[@def-5.2.4]、[@thm-5.2.C]）
:::

### C3 · 摆的例子：大减速比如何"线性化"非线性

写出折算前后的方程，并指出 $k_r$ 从哪两条途径削弱重力矩。

::: note C3 核对
原始方程组：$C_m=I_m\dot\omega_m+F_m\omega_m+fr_m$、$fr=I\dot\omega+F\omega+mgl\sin\vartheta$（$I$ 为摆在载荷轴的转动惯量、$m$ 为质量、$l$ 为长度）。**把第二式折算到发动机轴**：

$$C_m=I_{eq}\dot\omega_m+F_{eq}\omega_m+\frac{mgl}{k_r}\sin\frac{\vartheta_m}{k_r}.$$

教材评语：「从中可以清楚地看到**因子 $k_r$ 是如何降低非线性项的作用的**」。**两条途径**：① **幅值除以 $k_r$**；② **自变量变成 $\vartheta_m/k_r$**——在电机转一整圈的范围内，$\sin$ 只走过很短一段**近似直线**的区间。**为什么这一步重要**：重力矩 $mgl\sin\vartheta$ 是机器人动力学里**最主要的非线性来源**，所以大减速比把「非线性」在电机端退化成了「近似线性的小扰动」——这正是第 8 章能对每个关节做**独立线性控制**的物理根据。**推广到 $n$ 连杆**：把连杆视为孤立于其他连杆、每一个可看作简单刚体摆；连接会引入使模型复杂化的非线性影响（双摆情形下**第一连杆的发动机转动惯量同样取决于第二连杆的角位置**）——「不同连杆的发动机之间的非线性耦合，将如何通过存在大减速比而得到减小」，第 7 章详细研究。（[@ex-5.2.D]）
:::

### C4 · 液压驱动的六条基础方程

写出流速平衡与各项，并说明 $k_c$ 在旋转式与直线式上的差别。

::: note C4 核对
$$Q=Q_m+Q_l+Q_c\quad(\text{流速平衡}),\qquad
Q_l=k_lp\ (\text{渗漏}),\qquad
Q_c=\gamma Vsp\ (\text{可压缩性}),$$
$$Q_m=k_q\Omega_m,\qquad C_m=(sI_m+F_m)\Omega_m+C_l,\qquad C_m=k_pp .$$

（另加伺服阀 $p=k_xx-k_qQ$ 与分布器线性化式。）**与电气的逐条对照**：(5.1) 电枢电平衡 ↔ (5.14)(5.15)(5.16)——电气侧一个方程，液压侧拆成**渗漏 + 可压缩性**两项；(5.2) 反电动势 ↔ (5.17) $Q_m=k_q\Omega_m$——都是「转动产生一个抵消输入的效应」；**机械侧方程完全相同**；(5.4) $C_m=k_tI_a$ ↔ $C_m=k_pp$——**电流 ↔ 压差**。**为什么高压（100 atm 级）下 $Q_l$ 与 $Q_c$ 都不能忽略**。**$k_c=\gamma V$ 的差别**：**旋转伺服发动机**中流体体积恒定 ⇒ $k_c$ 为**常数**；**线性伺服器**中流体体积随行程变化 ⇒ **响应特性取决于工作点**。**一条警告**：教材明确「这种类比不应令人相信，可以由液压驱动来实现速度控制发电机或力矩控制发电机的作用」——**压力反馈回路是液压系统的固有结构特征，去不掉**；而电流反馈在电气驱动里是一个**可以取舍的设计选择**。（[@def-5.2.3]、[@method-5.2.A]）
:::

### C5 · 位置 + 速度反馈的两条改进

写出结构与两条改进，并说明内部速度回路为什么还要保留 PI。

::: note C5 核对
**结构**：除位置传感器外，还使用一个常数为 $k_{TV}$ 的**速度传感器**，以及一个增益为 $K_r$ 的**简单比例控制器**；**采用测速反馈的同时，在内部速度回路中保留具有参数 $K_v$ 与 $T_v$ 的比例积分控制器**。**两条改进**：① **干扰抑制更强**——在干扰点附近存在**两个（而非一个）反馈回路**，期望在**瞬态过程中也能进一步减小**干扰对输出的影响；② **瞬态响应更好**——灵活选择控制参数，有可能得到具有**更宽带宽**并且**减少振荡**的传递函数，其结果是**更快的瞬态响应并减小振荡**，从而提高跟踪更高要求参考轨迹的能力。**内部速度回路为什么保留积分**：为了**消除稳定状态下干扰对位置 $\vartheta_m$ 的影响**。**两条推广**：① **用电流控制电机实现位置伺服**——若用 (5.13) 的常数且**用 $k_t/k_i$ 代替 $R_a/k_v$** 来衡量干扰权重，则**功率放大器的电压增益 $G_v$ 将不会对控制行为起作用**（已被包在电流环内部）；② **推广到齿轮耦合**——**用 $I_{eq}$ 和 $F_{eq}$ 代替 $I_m$ 和 $F_m$，并用因子 $1/k_r$ 衡量干扰**。（[@method-5.2.E]、[@note-5.2.1]）
:::

### C6 · 惠斯通电桥与温度补偿

写出式 (5.30)，并说明温度补偿与提高灵敏度各靠什么。

::: note C6 核对
$$V_o=\left(\frac{R_2}{R_1+R_2}-\frac{R_s}{R_3+R_s}\right)V_i .$$

张力计嵌入惠斯通电桥的**一个桥臂**，**张力计上没有应力时电桥平衡（输出为零）**。**温度补偿**：如果温度变化，没有外力时金属丝也会改变长度 ⇒ 解决办法是在电桥**相邻的臂**上再嵌入**另一个张力计**，并把它粘合到可扩张元件**不受张力作用**的部分——两个张力计处于同一环境，温度引起的那部分电阻变化就在电桥里**相减抵消**。**提高灵敏度**：用到**两个张力计**，让它们以「**一个受牵引、一个受压缩**」的方式贴到可扩展元件上，并嵌入电桥的**两个相邻臂**——同一位置的两种应变符号相反，于是两路的信号变化在输出中**相加**（老师用**梁**举例：梁受弯曲时上面受拉、下面受压，「它的灵敏度是大体相反的」）。（[@def-5.4.2]）
:::

### C7 · 传感器校准矩阵

写出式 (5.31) 的含义与"8 个张力 → 6 个分量"的关系，并说明为什么变形数要大于 6。

::: note C7 核对
$$\begin{bmatrix}\boldsymbol f^s\\ \boldsymbol\mu^s\end{bmatrix}=\Phi\,\boldsymbol w,\qquad \boldsymbol w=[w_1\ \cdots\ w_8]^{\mathrm T}\ (\text{八个电桥的输出信号}).$$

**联系矩阵**称**传感器校准矩阵**（式 5.31 给出一个 $6\times8$ 的稀疏阵）：每一行给出一个分量是**哪几个张力**的线性组合，每个 $c_{ij}$ 是**标定出来**的系数（工程上由厂商标定给出，用户不自己标）；重构由**传感器中可用的信号处理电路**完成。**为什么变形数要大于 6**：由于**难以做到完全解耦**（「目前没有人设计出来这种完全解耦的一种结构」），为了重构力和力矩向量的 6 个分量，所需要的**明显变形数量应该大于 6**。**典型结构**：**马耳他十字**——4 个平行六面体形状的棒、**每一个棒的对面**粘合**两个张力计**构成一个电桥的**两个桥臂**，共 **8 个桥臂** ⇒ 8 个张力。**放置要求**：元件必须以**灵活的方式**放置，确保**至少有一个元件**在任何可能方向的力和力矩作用下会产生**轻微的变形**（否则某个方向的力就会测不到）。**典型指标**：直径约 10 cm、高约 5 cm；力 50–500 N、转矩 5–70 N·m；分辨率分别为最大力 / 最大转矩的 0.1% / 0.05%；输出端**采样频率 1 kHz**。（[@def-5.4.3]、[@thm-5.4.A]）
:::

### C8 · 力传感器坐标系 → 约束坐标系的变换

写出变换式，并说明两个待准备的量与一条使用条件。

::: note C8 核对
$$\begin{bmatrix}\boldsymbol f^c_c\\ \boldsymbol\mu^c_c\end{bmatrix}=
\begin{bmatrix}R^c_s&O\\ S(\boldsymbol r^c_{cs})R^c_s&R^c_s\end{bmatrix}
\begin{bmatrix}\boldsymbol f^s_s\\ \boldsymbol\mu^s_s\end{bmatrix}.$$

**要准备哪两个量**（都在坐标系 $c$ 中表示）：① $\boldsymbol r^c_{cs}$——**坐标系 $s$ 的原点在坐标系 $c$ 中的位置**；② $R^c_s$——**坐标系 $s$ 相对于坐标系 $c$ 的方位**。**力矩那一行分两项读**：**旋转项** $R^c_s\boldsymbol\mu^s_s$（把力矩的方向转过去）加**平移迁移项** $S(\boldsymbol r^c_{cs})R^c_s\boldsymbol f^s_s$（把力挪一个新的参考点，附加的力偶）。**与 [3.8.2](../ch03/sec3-8.md#sec-3.8.2) 的对偶结构对照**：平移块 $S(\boldsymbol r^c_{cs})R^c_s$ 与旋转块 $R^c_s$ 的搭配，和「速度变换的转置 = 力变换」是**同一套结构**。**一条使用条件**：$\boldsymbol r^c_{cs}$ 与 $R^c_s$ 这两个量「只有当**末端执行器是静止的**时候才保持恒定不变」——末端在动时参考系本身在变，变换要跟着更新。**为什么要做这一步**：力传感器的测量值**不能直接应用于力 / 运动控制算法**——它表征的是**作用在传感器上的等价力**，与**作用在末端执行器上的力不同**（参考点与参考方向不同）。（[@method-5.4.B]）
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「功率放大器放大的是信号」

::: note D1 核对
**错，放大的是功率。** 控制器输出约 **3.3 V、微安到毫安级**（约 3.3 mW），电机是几十瓦到上千瓦——**差 $10^5$ 量级**。控制器信号**本身没有功率**，但它**有规律**（幅值、相位都是确定的），而这个「规律」正是控制律的载体。所以功放要做的不是「造出能量」，而是**按这个规律去调制能源 $P_e$ 送来的功率**——$P_a$ 与 $P_c$ 之间是**放大关系、不是守恒关系**：$P_a$ 的绝大部分来自能源，$P_c$ 只起控制作用。（[@def-5.1.1]、[@method-5.1.A]）
:::

### D2 · 「理想传动装置改变功率 / 减速比只影响力矩」

::: note D2 核对
**两处都错。** ① **理想传动装置不改变功率**（$P_u=P_m$），它改变的是**力与速度的分配**——降速增矩是把「高转速低转矩」翻译成「低转速高转矩」，总功率（理想情形下）守恒。② **减速比对惯量的影响往往更重要**：载荷惯量与摩擦按 **$1/k_r^2$** 折算（$k_r=100$ 时缩小 **10000 倍**），而负载力矩只按 **$1/k_r$** 缩小。**连带的一条**：**直驱不等于更先进**——它换掉的是弹性与间隙，代价是**控制复杂度**（非线性耦合项无法忽略），工业上多数场合并不采用。（[@thm-5.2.C]、[5.1.1](sec5-1-1.md) 常见错误 2、3）
:::

### D3 · 「把 $k_v$ 与 $k_t$ 当成两个独立参数」

::: note D3 核对
**错。** **$k_t=k_v$**——「**转矩常数 $k_t$ 在标准国际单位上与电压常数 $k_v$ 数值相等**」，这是 (5.12)(5.13) 化简的前提，也是把「电」与「机」连起来的桥。**连带的一条**：**放大器的时间常数比机械时间常数小几个数量级**（$T_v\sim10^{-5}$–$10^{-4}\ \mathrm{s}$）——这是降阶模型成立、可以在模型里令 $T_v\approx0$ 的根据。（[@def-5.2.1]）
:::

### D4 · 「加了电流反馈一定更好」

::: note D4 核对
**恰恰相反。** **没有电流反馈时，系统对干扰力矩的抑制更好**——无论是**等价增益**（$\frac{R_a}{k_vk_t}\ll\frac{1}{F_m}$）还是**时间响应**（$\frac{R_aI_m}{k_vk_t}\ll\frac{I_m}{F_m}$）。所以**独立关节控制**（需要高度抑制干扰力矩）**不建议**在回路中有电流反馈；而**集中控制**要求驱动器具有**力矩控制发电机**特性，这时才**应该**用带适当调节器 $C_i(s)$ 的电流反馈。**保护怎么办**：改用**在反馈回路上具有死区非线性特性**的电流反馈来限流（而**不是**用控制信号的饱和来限流）——「切实可行，其精度与死区斜率一样高」。（[@thm-5.2.B]）
:::

### D5 · 「用编码器差分就能精确得到速度」

::: note D5 核对
**不总是够用。** **虽然速度测量可以从位置传感器重构，一般情况下人们还是会优先选择直接速度测量**（转速计）。**从位置重建的三条途径**：① 使用**电压—频率转换器**（把脉冲串变成与频率成正比的模拟电压）；② 数字地**测量脉冲序列的频率**（固定时间窗内数脉冲个数）；③ 数字地**测量脉冲序列的抽样时间**（相邻脉冲之间的周期）。**分工**：**频率法适合高速测量**（窗口内脉冲多，±1 个脉冲的相对误差小）、**周期 / 抽样时间法适合低速测量**（周期长、定时器相对精度高；高速时反而撞上定时器分辨率极限）。**恢复的精度问题**：差分会把位置量的**量化台阶与测量噪声**按约 $1/\Delta t$ 放大，**低速时最差**（噪声不变而真实速度变小，相对误差急剧上升）——所以「需要对速度做准确测量」时就要另装转速计。（[@method-5.3.A]）
:::

### D6 · 「直流转速计的纹波可以靠滤波消掉」

::: note D6 核对
**不能。** 换向器每转过一个片间就切换一次电枢回路，因此输出电压上叠加着**与换向次数同步的纹波**；关键在于**纹波的频率由角速率决定**——转速变了纹波频率就跟着变。而滤波器（低通、陷波）都是**按固定频率设计**的：中心频率选在 20 Hz 的滤波器，转速一变就跑偏了；转速越低纹波频率越低，直到滑进有用信号的频带里，**根本无法用固定的滤波电路剔除**。所以教材把**纹波系数（输出信号均值的 2%–5%）**与**线性误差（0.1%–1%）**一起写进器件规格。**交流转速计怎么解决的**：它用**杯形转子 + 定子上两个相互正交的绕组**，输出电压的**幅值与角速度成正比**、相位与转向有关；其**基频是电源频率的 2 倍、固定不变**——「因而选择一个合适的滤波器就可以消除输出信号的纹波」。**注意不要混淆**：**同步发电机**输出信号的**频率**与角速度成正比（而不是幅值），那不是转速计要的特性。（[@method-5.3.A]）
:::
