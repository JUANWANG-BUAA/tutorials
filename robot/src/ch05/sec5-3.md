## 5.3.0 概览：本体/外部之分与两个基本反馈量

### 5.3.0.1 本体传感器与外部传感器

**传感器的地位，教材第一句话就说尽了**：「为了获得高性能机器人系统，传感器的使用是至关重要的。」紧接着是分类——把传感器分成测量**机械手内部状态**的本体传感器与提供**周围环境信息**的外部传感器，是「有意义」的（教材 §5.3）。这条分界不是学术洁癖：它决定了两类器件此后各自挂在哪一半回路上，也决定了本章 §5.3 与 §5.4 的分工。

::: def 定义 5.3.1 · 本体传感器 proprioceptive sensors {#def-5.3.1}
为了确保产生与任务规划相对应的机械结构的**协调运动**，需要采用适当的**参数辨识和控制算法**；这就要求用**本体传感器**对表征机械手**内部状态**的变量进行**在线测量**（教材 §5.3）。这些变量是：

- **关节位置**（joint positions）
- **关节速度**（joint velocities）
- **关节力矩**（joint torques）

这些是关节控制中常用的量，但不意味着每种控制器都必须直接测量三者：速度可以由位置估计，力矩也可能由电流与模型估计。选用哪种测量或估计方式，要看控制结构、精度与成本；「在线」指运动过程中持续取得所需信息。
:::


三个量在本教程里各有归宿：**关节位置**与**关节速度**就是下面两小节的主题（[§5.3.1 位置传感器](sec5-3.md#part-5.3.1)、[§5.3.2 速度传感器](sec5-3.md#part-5.3.2)）；**关节力矩**则是唯一一个「名分」有交叉的量——教材把它列为本体量（内部状态变量），而承载测力的力传感器却与力、触觉、接近、距离、视觉一起被列进了**外部传感器**。

::: intuition 动手实验 · 传感器装在哪儿（3D）
把传感器摆到机械臂的真实位置上看：**本体传感器**（编码器在关节电机轴上、测速反馈在电机侧、应变片在关节根部）测的是关节**内部**的状态量；**外部传感器**（腕力传感器在腕部、距离与视觉在腕部朝外）测的是**与环境交互**。切到「编码器怎么测角」看关节剖面：码盘随轴转、遮光槽让光电开关出脉冲——角位置变数字的空间实现。

:::

::: think 易混点 · 关节力矩算本体量还是外部量（教材 §5.3 的分类）
教材的两处表述看似打架，其实是两个视角：

- 从**被测量**看，关节力矩是机械手自己的内部状态，属于本体量；
- 从**器件**看，机器人上常用的力传感器（腕力传感器）装在最远端，测的是**末端与环境交互**的力与力矩，提取的是环境的信息，所以教材把它归入外部传感器。

在静力学中，若 $F$ 是与雅可比矩阵 $J$ 使用同一坐标系、同一作用点且符号约定一致的末端广义力，则 $\tau=J^{\mathrm T}F$ 给出该末端力对应的关节广义力（[@def-3.8.1]）。它不自动包含惯性、摩擦和其他负载，因此不等于所有情况下的关节驱动力矩。分类应看被测量，而不只看安装位置。
:::

**外部传感器这一侧，教材给了一份短清单**：力传感器、触觉传感器、接近传感器、距离传感器、视觉传感器；此外，声音、湿度、烟尘、压力、温度这类针对具体应用的特殊传感器也属于这一类。它们的目标不同于本体传感器——**提取表征机器人与环境目标交互作用的特征，以提高系统的自动化程度**。教材还给了一句很「高」的话：可用传感器的**数据融合**可以应用于（高层）任务规划，而任务规划反过来把机器人表征为一个「**由感知到执行的智能联系**」（教材 §5.3）。清单里每一类的展开见 [5.4 外部传感器](sec5-4.md)，本节只取这条分界本身。

::: thm 定理 5.3.A · 位置与速度反馈 {#thm-5.3.A}
位置伺服需要知道位置误差；一种常见结构还加入速度内环：

1. **位置反馈**：测得的位置与参考位置 $\vartheta_r$ 比较，误差送入位置控制器。
2. **速度反馈**：在带测速内环的结构中，以传感器增益 $k_{TV}$ 测量速度；内部速度回路可采用参数为 $K_v$ 和 $T_v$ 的比例积分控制器。

测速内环提供额外的调节自由度。参数合适时，它可以改善瞬态响应和扰动抑制；效果仍取决于控制器、噪声和机械系统。速度也可从位置估计，并非所有位置伺服都要配独立转速计。老师介绍的带位置和速度反馈结构及其推导见 [5.2.4](sec5-2.md#part-5.2.4)。

### 5.3.0.3 小结与常见错误

- **一条分界**：本体传感器测机械手的**内部状态量**（关节位置 / 速度 / 力矩，在线测量）；外部传感器提供**周围环境**信息（力 / 触觉 / 接近 / 距离 / 视觉，另有声音、湿度、烟尘、压力、温度等专用传感器）。
- **一段动机**：为了让机械结构产生「与任务规划相对应的**协调运动**」，参数辨识与控制算法必须拿到实时的关节状态——这是本体传感器存在的理由，也是它「在线」的由来。
- **后续两节**：位置传感器（§5.3.1）与速度测量（§5.3.2）；电流可用于估计电机电磁力矩。
- **一个易混点**：关节力矩是本体量，腕部接触力是外部交互量；静力映射须满足坐标和作用点约定。

::: think 常见错误清单 · 自查三条
1. 把「本体传感器」理解成「装在机器人身上的传感器」——分类依据是**测什么**：机器人自身的内部状态量（本体），还是环境与交互信息（外部）。
2. 以为「有了编码器就不需要任何别的传感器」——位置、速度、力矩是**三个**量，且位置一侧还有一圈「从位置重建速度」的取舍要算（见 §5.3.2）。
3. 把测速反馈当成单纯增加测量：它还改变反馈结构，能否改善响应须结合控制器和噪声判断。
:::

## 5.3.1 位置传感器

位置反馈首先需要把关节或电机的位移转换成电信号。本节比较电位计、绝对式与增量式编码器、旋转变压器，重点讨论分辨率、转向和掉电后的位置信息。

<a id="sec-5.3.1.1"></a>

### 5.3.1.1 位置传感器的定义与器件清单

::: def 定义 5.3.2 · 位置传感器 position transducers {#def-5.3.2}
**位置传感器**的作用，是提供与机械设备**相对给定参考位置的线位移或角位移成比例的电信号**。它们主要用于**机器工具（机床）控制**，因而应用范围宽广（教材 §5.3.1）。

按测量对象分两张清单：

| 测什么 | 可用器件 |
|:--|:--|
| **线位移** | **电位计**、**线性差动变换器**（linear variable-differential transformer, **LVDT**）、**感应同步器**（inductosyn） |
| **角位移** | **电位计**、**编码器**（encoder）、**旋转变压器**（resolver）、**同步器**（synchro） |

**机器人上更常用角位移传感器**，原因是伺服的发动机是旋转型的——注意这条对**移动关节（棱柱关节）也成立**：即使关节本身做平动，上游的伺服发动机仍然输出转角。从**精确性、鲁棒性和可靠性**的角度，最常用的两类是**编码器**与**旋转变压器**，它们的工作原理是本节的主体；线位移传感器（LVDT 与感应同步器）则主要在**测量机器人**中使用。
:::


**先说被教材一笔带过的电位计，因为课件上给了它两张原理图。** 电位计（potentiometer）的做法最直观：把一段电阻体两端分别接到电源电压 $V$ 与地，**滑动触点（电刷）** 在电阻体上移动，把总电阻分成 $R_1$、$R_2$ 两段，输出就是触点到某一端的那段分压——触点越靠近 $V$ 端（课件标注 Maximum R），输出越大；越靠近接地端（Minimum R），输出越小。测角度的版本把这根电阻体弯成一段圆弧（课件右下：阻力片 + 滑动触点 + 输出电压），电刷随轴一起转。

::: think 电位计的两条工程短处（本教程按课件原理图补注）
教材只把电位计列进器件清单、没有展开。按上面的分压原理图，它的短处是自明的：

1. **线性度**：分压关系 $V_{\text{out}}/V$ 只在「电阻体均匀、输出端不取电流」的理想条件下严格正比于位移；绕组 / 膜层的均匀性、负载效应都会让它变成**近似**线性，教材因此把它与「精确性」要求高的场合分开。
2. **噪声与磨损**：滑动触点是**接触式**的，摩擦、磨损、接触电阻的跳动都会直接叠加到输出上，而且这类器件寿命有限、长期使用后阻值还会变化。

这也解释了为什么教材把「精确性、鲁棒性和可靠性」最好的一档让给编码器与旋转变压器：**它们都不靠接触传递信息。**（本节后文只按教材与课件展开这两类。）
:::

### 5.3.1.2 绝对式编码器：码盘、分辨率与格雷码

::: def 定义 5.3.3 · 编码器 encoder {#def-5.3.3}
编码器有**两种类型**：**绝对式**（absolute）与**增量式**（incremental）。**绝对式编码器**的构造是：

- 一个布有**同心圆（轨道）** 的**光学玻璃盘**；
- 每一条轨道都有交替出现的、通过**金属薄膜沉积**得到的**透明扇区**与**不光滑扇区**序列；
- 光束相应于每一条轨道发出，被位于光盘背面的**光电二极管或光电晶体管**截取（课件图注：LED 对 photo sensor）；
- 通过对透光区与不光滑扇区的适当安排，可以把**有限数量的角位置转换为相应的数字数据**；
- **轨道的数目决定信息的长度（字长），从而决定编码器的分辨率。**

光学编码器把信号处理电子装置做在盒子里，直接提供数字位置测量，与控制计算机通过接口相连。
:::


**一圈能分辨多细？** 分辨率完全由轨道数（位数）决定：$n$ 条轨道给出 $2^n$ 个角位置。关节控制需要的典型分辨率先由老师算了一遍——12 条轨道。

::: ex 例 5.3.B · 12 轨编码器的角分辨率与齿轮减速后的换算 {#ex-5.3.A}
**题 1**：某关节用 **12 轨**绝对式编码器，一圈能分辨多少个角位置？每格对应多少度？

**题 2**：若关节与发动机之间有一个减速比为 $k_r$ 的减速器，编码器装在**发动机侧**，关节侧的分辨率是多少？

**题 3**：此时为什么还要另配一套装置去记「圈数」？

**解**：

1. $2^{12}=4096$ 个角位置，即分辨率为**每圈 1/4096**，每格对应 $360^{\circ}/4096\approx0.0879^{\circ}$。老师 01:52:00 的原话：「相当于把 360 度分成 4096（份），它的分辨率每个度数就是 4096 分之 360。」——对关节控制而言，教材给出「**最少 12 个轨道**」这个量级。
2. 减速器做的是**定量变换**（[@def-5.1.3]）：关节侧转一圈，发动机侧要转 $k_r$ 圈（「在关节处的一圈相应于发动机处的几圈」）。编码器在发动机侧数它的 4096 格，折算到关节侧就是 $360^{\circ}/(4096\,k_r)$——**关节侧的等效分辨率被减速比放大了 $k_r$ 倍**。
3. 因为这里讨论的是**单圈**绝对式编码器：码字每转一圈重复，单靠码盘分不出电机转到第几圈。运行时可用电子装置记录经过零位的次数，正反方向分别加一和减一。若掉电期间仍可能转动，易失计数器不足以恢复圈数；需要保持多圈信息的装置，或重新确定参考位置。多圈绝对式编码器则另有记录圈数的机构。
:::

**为什么不用普通二进制码？** 这就引出了本节第一个「考试型」结论——码盘上的码制不能随手选。

::: thm 定理 5.3.C · 格雷码：一次只变一位 {#thm-5.3.B}
**（一）问题：同时发生多重转换。** 若码盘按普通二进制编码，从一个扇区转到另一个扇区时**可能同时有多个位发生翻转**：老师举的例子是从 $0001$ 到 $0010$（1 变 2），「其实是两位变」。光电元件与码道的安装不可能绝对对齐，多位同时翻转的那一瞬间，读出的码字**既不是起点也不是终点**，于是产生**不准确的测量**。

**（二）对策：格雷码。** 格雷码（Gray code）的相邻码字只相差一位，因此能避免普通二进制码在扇区交界处因多个码位不同时切换造成的中间错误码。单个码位在边界仍可能受噪声、抖动或读头误差影响，格雷码不能消除所有测量误差（教材 §5.3.1、课件 01:51:43 页）。

**（三）规模：4 轨分辨 16 个角位置。** 教材以 4 条轨道为例给出示意与码表（表 5.1，$2^4=16$）。

**表 5.1 格雷码的码表（教材表 5.1）**

| # | 编码 | # | 编码 |
|:--|:--|:--|:--|
| 0 | 0000 | 8 | 1100 |
| 1 | 0001 | 9 | 1101 |
| 2 | 0011 | 10 | 1111 |
| 3 | 0010 | 11 | 1110 |
| 4 | 0110 | 12 | 1010 |
| 5 | 0111 | 13 | 1011 |
| 6 | 0101 | 14 | 1001 |
| 7 | 0100 | 15 | 1000 |

盯住表里的相邻两行：从 7 到 8 是 $0100\to1100$，从 15 绕回 0 是 $1000\to0000$——**永远只翻一位**。这就是「格雷码不按大小顺序，但按圈顺序」的全部秘密（老师 01:51:13：「它就不（像）普通的二进制编码对应了」）。
:::

### 5.3.1.3 增量式编码器：计数、判向与置零

**绝对式给出「我在哪」，增量式只给出「我动了多少」。** 教材的判断很明确：增量式编码器**结构简单、价格低廉，因此使用范围比绝对式编码器更广泛**。它的构造与绝对式相似——也是一个光学盘，但只有**两条轨道**：两条轨道上透明扇区与不光滑扇区的**数目相等**，且两路信号**相互正交**（相位相差 90° 电角度）。这两条轨道除了给出与角旋转相关联的**转换（脉冲）数目**，还额外地提供了**旋转方向（符号）**。

**第三条轨道：机械零位。** 通常还会引入第三条轨道，上面**只有一个不光滑扇区**，它允许定义**一个绝对的机械零**，作为角位置的参考（教材 §5.3.1、图 5.13）。


**判向靠「谁先来」。** 老师把 A/B 两路的分工讲得很干脆（01:53:40–01:54:21）：

> **A 先升沿 ⇒ 顺时针（clockwise）；B 先升沿 ⇒ 逆时针（counter-clockwise）**——「每次都是 A 先升（沿），然后 B 在这个（后面），它就是 clockwise」；反过来「每次都是 B 先于 A……它就是 counter-clockwise」。所以「这（两路）主要是为了进行方向的判断」，具体由后续的逻辑 / 算法完成。

这里的顺、逆时针对应课件的观察方向和接线；换观察轴端或交换 A/B，关系就会反转。一般规则是先据相位先后定义正负方向，再用已知转向标定，不能把「A 先就是顺时针」作为所有编码器的统一规定。

**Z 相负责「转了几圈」。** 第三条轨道的作用是记圈数：「每次经过（零位）就加一圈或者是减一圈」，同样要**配合 A、B 判断方向**（老师 01:54:24–01:54:36）。

**增量式编码器需要建立位置参考。** 关节使用增量式编码器时，须先确定一个参考位置，再由计数电路累计 A、B 的变化。例如上电后可以用限位开关找到关节参考区间，再结合 Z 脉冲确定精确零位。电机轴上的 Z 信号每转出现一次，不能单独区分减速器输出端的不同位置。掉电期间若发生运动，或计数过程中漏脉冲，累计位置可能错误，需要重新确定位置或使用其他可靠的参考。单圈绝对式码盘重上电后能恢复圈内角度，但不能仅靠它恢复多圈位置。

**顺带一条通向下一节的线索**：编码器盒子里的电子装置直接给出数字位置；**若使用外接电路，速度测量可以从位置测量重建**——每次转换产生一个脉冲时，有三条可能的途径（见 §5.3.2）。处理器件里最常用的就是编码器本身：老师说「编码器其实是最常用的」（01:56:15–01:56:18）。

### 5.3.1.4 旋转变压器与线性位移传感器

::: note 注 5.3.4 · 另两类器件：旋转变压器与线性位移传感器 {#note-5.3.1}
**旋转变压器**（resolver）是一种**结构紧凑且具有鲁棒性**的机电位置传感器。它的工作原理基于**两个电子电路之间的相互感应**，容许**没有机械限制**的角位置的**连续传送**（可以一直转下去，没有机械限位）。角位置的信息与**两个正弦电压的幅值**相关联，经适当的**轴角—数字转换器**（resolver-to-digital converter, **RDC**）处理后，获得与位置测量相对应的数字信息。

**线性位移一侧**：**线性差动变换器**（LVDT，课件图注为 AC 激磁 + 一次绕组 + 可动铁芯 + 两个二次绕组，输出随铁芯位移变化）与**感应同步器**（inductosyn，尺面上印制绕组、随位移输出相位 / 幅值变化的信号）——「线性位移传感器（LVDT 和感应同步器）主要在**测量机器人**中使用」。此外，教材把**同步器**（synchro）与旋转变压器并列，作为可测角位移的器件（教材未展开其原理）。
:::

**旋转变压器的结构：一台「小电动机」。** 从结构上看，它是一个**带转子和定子的小型电动机**：**感应（激磁）线圈在转子上**，而**定子上有两个相互成 90° 电角度的线圈**。给转子输入一个正弦电压 $V\sin\omega t$（典型频率范围 **0.4 kHz～10 kHz**），定子线圈上就会产生电压，其**幅值取决于旋转角 $\theta$**（两路分别正比于 $\sin\theta$ 与 $\cos\theta$）。这就是「角位置信息藏在两个正弦电压的幅值里」的含义。


**跟踪型 RDC：一条闭环把幅值变成数字。** 教材图 5.14 给出带跟踪型 RDC 函数表的电路方案（课件 01:56:23 页），信号链如下：

1. 定子两路电压送入**两个数字乘法器**，乘法器的另一个输入是**数字量 $\alpha$**；
2. 两路输出求**代数和**，得到 $V\sin\omega t\,\sin(\theta-\alpha)$；
3. 该信号经**放大**后送**同步探测器**，其**滤波后的输出与 $\sin(\theta-\alpha)$ 成比例**；
4. 得到的信号经适当的**补偿**后**积分**，再送入**电压控制振荡器**（voltage-controlled oscillator, **VCO**，即电压—频率转换器）；
5. VCO 的输出**脉冲**送入一个**正反向计数器**；计数器输出寄存器上的数字量 $\alpha$，就是角 $\theta$ 的测量。

具体地，若两路为 $v_s=V\sin(\omega t)\sin\theta$、$v_c=V\sin(\omega t)\cos\theta$，分别乘 $\cos\alpha$ 和 $-\sin\alpha$ 后相加，就得到 $v_s\cos\alpha-v_c\sin\alpha=V\sin(\omega t)\sin(\theta-\alpha)$。同步检波去掉载波后，误差信号驱动计数器调整 $\alpha$；在稳定锁定的小误差工作区，误差朝零收敛。量化、噪声和有限带宽仍会限制精度。

回路按反馈原理工作：误差信号驱动 $\alpha$ 跟踪 $\theta$。理想线性模型中，若闭环稳定且未发生饱和，两个积分环节可使恒速输入的稳态跟踪误差趋于零；实际还有量化、噪声与带宽限制。补偿环节用于调整稳定性与带宽；若要数字速度输出，还需对模拟速度信号做 A/D 转换。

**精度定位**：旋转变压器是**非常精确**的传感器——教材说在 RDC 的输出中可以获得「**1/16 比特**」的分辨率（原文照录；英文原版作 *a resolution of 1 bit out of 16*，本教程理解为「16 位量级的细分辨」，译文疑有讹，存疑待考）。

4. 旋转变压器的角位置信息藏在哪？跟踪型 RDC 回路里的两个积分器保证了什么？它的分辨率定位是什么？

::: sol 核对

输出是**与相对给定参考位置的线位移或角位移成比例的电信号**，主要用于机床控制。线位移：**电位计、LVDT、感应同步器**；角位移：**电位计、编码器、旋转变压器、同步器**。更常用角位移是因为**伺服的发动机是旋转型的**——即使关节做平动（棱柱关节），上游仍是回转运动。

分辨率由**轨道数（位数 $n$）**决定，$2^n$ 个角位置。12 轨 ⇒ **4096** 格 / 圈，每格 $360^{\circ}/4096\approx0.0879^{\circ}$。有减速比 $k_r$ 时，关节一圈 = 发动机侧 $k_r$ 圈，关节侧分辨率提高 $k_r$ 倍；但绝对式**只在一圈内唯一**，跨圈读数重复，所以要「一个简单的电子装置计数并存储圈数」——经过零位时按转向加 1 或减 1。

二进制码在扇区切换时可能同时翻转多位，读头不对齐可能产生错误码；格雷码相邻码字只差一位，可避免这种多位切换错误。增量式的 A/B 相差 90°，用于计数和判向；Z 相提供每转一次的参考脉冲，配合 A/B 可计圈，但减速后还须确定对应的关节参考位置。

旋转变压器把角位置编码在两路交流电压的幅值中，两路幅值分别随 $\sin\theta$、$\cos\theta$ 变化。跟踪型 RDC 用误差信号调整数字角 $\alpha$；在理想模型闭环稳定且未饱和时，双积分结构可使恒速输入的稳态跟踪误差趋于零，实际仍受量化、噪声和带宽限制。教材所称「1/16 比特」的译法及英文原文见正文，不能据此直接断言具体精度。

:::

:::

### 5.3.1 小结与常见错误

- **两张清单**：线位移——电位计、LVDT、感应同步器；角位移——电位计、编码器、旋转变压器、同步器。机器人上**角位移更常用**（发动机是旋转型，移动关节亦然），主力是**编码器与旋转变压器**。
- **一条原理线**：光电码盘 ⇒ 轨道数 = 位数 = 分辨率；码制改用**格雷码**消除多重转换的不确定性（相邻只变一位）；12 轨 ⇒ 每圈 1/4096。
- **一组对照**：单圈绝对式直接给出圈内位置，多圈位置需另行保存；增量式依靠脉冲计数、判向和参考位置，漏脉冲或掉电运动可能使累计位置错误。
- **一条闭环**：旋转变压器用互感应把角位置放进两路电压幅值，跟踪型 RDC 再把它转换成数字；恒速零稳态误差是理想稳定模型下的结论。LVDT 与感应同步器属于线性位移传感器。

::: think 常见错误清单 · 自查三条
1. 把**增量式**当成「精度更低的绝对式」——差别不在精度，而在**读数结构**：一个是绝对编码、一个是增量计数加零位，掉电后行为完全不同。
2. 忘了码制的理由：能说出「用格雷码」，却说不清它对付的是**多位同时翻转**这一具体现象（也答不出 $0001\to0010$ 这个反例）。
3. 混淆**发动机侧与关节侧**：分辨率、圈数、减速比三件事必须各归各位——编码器装在发动机侧时，关节一圈对应发动机侧 $k_r$ 圈，故关节侧分辨率被放大，而圈数计数必须另做。
:::

## 5.3.2 速度传感器

位置已经读回来了，速度还需要单独测吗？位置差分可以估计速度，但编码器量化和采样会影响结果。本节比较从位置重建速度与使用转速计直接测量，再介绍直流和交流转速计的工作原理。

<a id="sec-5.3.2.1"></a>

### 5.3.2.1 直接测量，还是从位置重建

教材先把话说清楚：**虽然速度测量可以从位置传感器重构，一般情况下，人们还是会优先选择使用合适的传感器进行直接速度测量。** 这类器件被统称为**转速计**（tachometer），应用场合非常多；而**最常用的转速计是基于电机的原理工作的**，两种基本类型是**直流（DC）转速计**与**交流（AC）转速计**（教材 §5.3.2）。

老师把这两条路线叫做**直接测量**与**间接测量**（01:54:44–01:55:19）：间接测量即「用编码器测量角位置」，再做「角位置和时间的**数值微分**」，就得到转动的角速度；但「要（对）速度进行精确的测量时，就得采用速度传感器」直接测（01:57:08–01:57:18）。

::: method 方法 5.3.D · 从位置信号重建速度的三条途径 {#method-5.3.A}
教材 §5.3.1 末尾给出：如果每次转换产生一个**脉冲**，速度测量可以通过三种可能的途径获得：

1. 使用**频率—电压转换器**——把脉冲串变成与频率成正比的**模拟**电压输出；
2. （数字地）**测量脉冲序列的频率**——固定时间窗内数脉冲个数；
3. （数字地）**测量脉冲序列的抽样时间**——即测出相邻脉冲之间的**周期**。

**怎么选**：后两种都是数字方法，教材直接给了分工——**前者（频率法）适合于高速测量，后者（周期 / 抽样时间法）适合于低速测量**。

**为什么是这个分工**（本教程补注，定量推导属「检测技术」课程的内容——老师 01:55:35 亦如此交代）：频率法在固定的时间窗内数脉冲，转速高时窗口里脉冲多、计数量大，±1 个脉冲的计数误差相对很小；转速低时窗口里只有寥寥几个脉冲，同样的 ±1 就被放大成很大的相对误差。周期法反过来：测一个脉冲的周期，低速时周期长、定时器相对精度高；高速时周期太短，反而撞上定时器的分辨率极限。

设编码器每转产生 $N$ 个可计数脉冲，窗口长 $\Delta t$，窗口内计得 $n$ 个。如果窗口内旋转方向不变，平均角速度估计的大小为 $|\hat\omega|=2\pi n/(N\Delta t)$；相邻脉冲间隔为 $\Delta t_p$ 时，周期法给出 $|\hat\omega|=2\pi/(N\Delta t_p)$。旋转方向须由 A/B 相或其他方向信息另行确定；窗口内换向时应使用带符号的净计数。例如 $N=100$、$\Delta t=0.1\ \mathrm s$ 时，少计一个脉冲就相差约 $0.628\ \mathrm{rad/s}$。延长窗口能减小计数相对误差，但会增加响应延迟；周期法停止时没有新脉冲，也需要结合超时判断。
:::

### 5.3.2.2 直流转速计

**直流转速计是实际应用中使用最多的一类**，它实质上是一台**小型的直流发电机**，磁场由**永磁体**提供。教材特意指出它「在其构造中（有）特别设计」，目的是两件事：获得**线性的输入 / 输出关系**，以及**减小磁滞现象和温度的影响**——因为这两者都会破坏线性度、进而影响测量的准确性（老师 01:57:31–01:57:50）。

**输出关系很简单**：由于**磁通量是常数**，当转子转动起来以后，**输出电压与角速度成比例**，比例系数由电机的常数决定。换句话说，它是一台「**天然的速度传感器**」：不需要微分、不需要计数器，转速进去、电压出来，而且方向信息就藏在电压的**极性**里。


**它最大的缺陷：换向器带来的纹波。**

::: think 直流转速计的纹波为什么「不能通过滤波消除」（教材 §5.3.2）
教材的推理只有一步，但要读懂它需要想清楚滤波器的工作方式：

- 换向器每转过一个片间就切换一次电枢回路，因此输出电压上叠加着**与换向次数同步的纹波**；
- 关键在下一句：**纹波的频率由角速率决定**——转速变了，纹波频率就跟着变；
- 固定滤波器可以在纹波与有用信号频带分开时衰减纹波，但转速下降时纹波可能进入有用频带；此时继续滤波会损失速度变化信息或增加延迟，不能无条件彻底消除。

所以教材给出的指标里，纹波是一项**写进器件规格**的固有误差。老师 01:58:09 的总结很直白：「纹波是不能通过滤波来消除的，（因为）它的频率其实是由角速率来决定的。」
:::

**教材给出的直流转速计指标**：

| 项目 | 教材给出的内容 |
|:--|:--|
| 构造 | 小型直流发电机，磁场由**永磁体**提供；构造上特别设计以获得线性输入 / 输出关系、减小磁滞与温度影响 |
| 输出关系 | 磁通量为常数 ⇒ **输出电压与角速度成比例**，系数由电机常数决定 |
| 纹波 | 换向器产生残余纹波；频率随速度变化，与有用信号重叠时难以滤除 |
| **线性误差** | **0.1%～1%** |
| **纹波系数** | 输出信号**均值的 2%～5%** |
| 地位 | 「在大多数实际应用中使用」——三个本体量里，速度是最容易直接换成模拟电压的一个 |

<a id="sec-5.3.2.3"></a>

### 5.3.2.3 交流转速计

**为了改变纹波的频率结构，换一种电机。** 本节交流转速计用固定频率励磁，使输出幅值与速度关联。同步发电机的电频率虽随转速变化，但其空载感应电动势幅值在磁通固定时通常也随转速变化，不能概括成「频率变、幅值不变」。老师 01:59:02 的原话是「如果采用同步发电机的话，输出信号的频率是与角速度成正比的，而不是幅值」；这里应理解为本节要比较的测量结构，而非一般同步发电机的幅值定律。

**于是需要一台结构不同的电机**：交流转速计的**定子上有两个相互正交的绕组**，还有一个**杯形转子**。工作原理：

- 给其中一个定子绕组通入**幅值不变**的正弦电压（激磁频率通常设为 **400 Hz**）；
- 另一个定子绕组上就会感应出**频率相同**的正弦电压；
- 该电压的**幅值与角速度成正比**，相位**与转动方向有关**——与输入电压**同相**或者是**反相**；
- 用一个**同步探测器**就可以得到角速度的**模拟值**（相位即携带了转向信息）。

**纹波这次为什么容易滤除？** 原始交流感应信号与励磁同频；经同步检波后，输出包含与速度有关的低频分量，以及两倍励磁频率附近的分量。后者频率固定，若与所需速度信号频带分开，就可用低通滤波器衰减；滤波仍有响应速度的代价。

**优点与缺点**（教材 §5.3.2）：

- **性能**：交流转速计的性能可以与直流转速计**相媲美**；
- **两个优点**：**不存在摩擦触点**（没有换向器与电刷），以及使用**杯形转子**时**转动惯量比较小**——后者意味着传感器对被测轴的机械负载更小，动态测量更「轻」；
- **一个缺点**：存在**剩余电压**（residual voltage）。其产生原因是：当**转子处于静止状态**时，定子线圈和测量电路之间存在**难以克服的寄生耦合**——所以哪怕转速为零，输出也不严格为零。

**两张转速计对照表**（本教程整理，内容均取自教材 §5.3.2）：

| | **直流转速计** | **交流转速计** |
|:--|:--|:--|
| 原理 | 小型直流发电机，永磁磁场 | 定子两个互成正交的绕组 + 杯形转子；一相交流激磁（典型 400 Hz） |
| 输出与转速的关系 | 有符号输出电压近似正比于有符号角速度 | 感应电压幅值 ∝ 角速度大小，频率与激磁相同（400 Hz） |
| 转向信息 | 输出电压的**极性** | 感应电压相对激磁的**相位**（同相 / 反相），由同步探测器读出 |
| 纹波 | 换向器纹波频率随转速变；频带重叠时难以滤除 | 同步检波后有两倍励磁频率分量，频带分开时可滤除 |
| 教材给出的指标 | 线性误差 **0.1%～1%**；纹波系数为输出信号**均值的 2%～5%** | 性能可与直流媲美；另有剩余电压（未给数值） |
| 优点 | 多数实际应用采用；结构简单 | **无摩擦触点**；**杯形转子转动惯量小** |
| 缺点 | 纹波可能进入有用频带 | **剩余电压**（转子静止时定子线圈与测量电路的寄生耦合） |

<a id="recall-5.3.2"></a>

::: think 考点 · 老师原话（录播时间点）

> **速度的两条测法，按精度要求选。** 「其实对于电机的速度的判断或者测量，我们可以采用直接测量和间接测量的方式，很多时候可以采用间接测量」——用编码器测角位置，「那么角位置和时间的数值微分，其实就可以得到转动的角速度」；但「要进行速度准确测量的时候，就得采用速度（传感器）测量」（01:54:44–01:55:29）。

> **频率法管高速，周期法管低速。** 「比如说脉冲（序列）频率的这种方法，**高速旋转的时候我采用这种方法**，我看频率……对于**低速的时候**，（用）另外一种方法」（01:55:53–01:56:05）。

> **转速计的两大类型。** 「常用的转速计是基于电动机的原理（工作的），主要有**直流转速计**和**交流转速计**。直流转速计其实是一个**小型的直流发电机**」；「（输入）的速度和（输出）电压之间是有线（性）关系的。但是设计过程中要减少**磁滞**现象（和）**温度**的影响，因为它们会影响这个线性度，同时也影响测量的准确性」（01:57:24–01:57:48）。

> **直流转速计的纹波不可滤。** 「由于有换向器的存在，输出电压是存在**纹波**的……纹波是不能通过滤波来消除的，它的频率其实是由角速率来决定的」；转速越快，纹波频率越高（01:58:00–01:58:16）。指标「也列了**线性误差**以及（纹波系数与输出）信号均值的关系，可以参考」（01:58:22）——即 0.1%～1% 与 2%～5% 这两个数。

> **交流转速计要「另造一台电机」。** 「交流转速计不需要用换向器」（01:58:36）；「交流转速计与交流发电机是有区别的……如果采用同步发电机的话，输出信号的频率是与角速度成正比，而不是幅值」（01:58:48–01:59:04）；「为了获得幅值与速度成正比的（交流电压），这个时候就需要利用一个结构（与）同步发电机不同的（电）机，需要两个相互正交的绕组，（加）一个杯形转子」（01:59:08–01:59:24）。

> **优点与缺点各一句。** 优点：「不存在摩擦的触点，而且杯形转子的转动惯量是比较小的」（01:59:44–01:59:50）；缺点：「它是有**剩余电压**的，因为转子静止的时候，（定）子线圈和（测量电路）之间是有**寄生耦合**的」（01:59:56–02:00:07）。

::: sol 核对

**直接测量**（转速计）与**从位置重建**。三条途径：① 频率—电压转换；② 数字测脉冲频率；③ 数字测脉冲周期。频率法在高速时窗口脉冲数较多；周期法在低速时计时相对分辨率较好。

直流转速计是永磁小型发电机，输出电压近似正比于角速度。换向纹波的频率随转速变化；与有用信号频带重叠时，固定滤波难以同时保留信号并去掉纹波。教材列出的线性误差为 0.1%～1%，纹波系数为输出均值的 2%～5%。

交流转速计使用正交绕组与杯形转子，感应电压与励磁同频，其幅值和相位携带速度大小与方向。同步检波后产生低频速度信号和两倍励磁频率分量；频带分开时可滤除后者。

优点：**不存在摩擦触点**；**杯形转子转动惯量小**。缺点：**剩余电压**——转子静止时，定子线圈与测量电路之间存在难以克服的**寄生耦合**，输出不严格为零。

### 5.3.2 小结与常见错误

- **两条路线**：从位置估计速度，或用转速计直接测量。量化、噪声、响应延迟和传感器自身误差共同决定取舍。
- **两种转速计**：直流机的换向纹波频率随速度变化；交流机经同步检波后有固定频率分量，但存在剩余电压。

::: think 常见错误清单 · 自查三条
1. 认为位置差分与直接测量必有一种更精确：应比较分辨率、噪声、带宽与实际工况。
2. 混淆交流转速计的原始载波频率与同步检波后的两倍频纹波。
3. 把纹波滤波说成总能或绝不能实现；关键是纹波与有用信号的频带是否分开。
:::
