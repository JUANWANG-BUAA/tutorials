# 易混对照卡

本页把全书最常被混淆的 **15 组概念**并排对照。每组给出一句分辨口诀、一张对比表、以及区分两者的最小反例或检验方法。用途：做题卡壳时单点查阅；考前遮住右列默写。

正文权威版本在各节；公式默写去[公式速查卡](preface-formulas.md)；逐条错误去[易错点总表](preface-pitfalls.md)。

## 1 · 几何雅可比 ⟷ 分析雅可比

**口诀：几何雅可比配角速度向量，分析雅可比配欧拉角导数；换算需要 $T(\varphi_e)$。**

| | 几何雅可比 $J$ | 分析雅可比 $J_A$ |
|:--|:--|:--|
| 输出速度 | $[\dot p_e^\mathrm T,\ \omega_e^\mathrm T]^\mathrm T$（角速度向量） | $[\dot p_e^\mathrm T,\ \dot\varphi_e^\mathrm T]^\mathrm T$（欧拉角速率） |
| 关系 | 基础量 | $J_A = T_A^{-1} J$，$T_A=\operatorname{diag}(I_3,T(\varphi_e))$ |
| 奇点 | 机构运动学奇点（相对该任务的最大秩下降；方阵满秩情形可看 $\det J=0$） | 机构奇点及姿态参数奇点（$T$ 不可逆） |
| 转置法控制 | $\tau = J^\mathrm T F_e$ | $\tau = J_A^\mathrm T h_A$，$h_A=T_A^\mathrm T h_e$ |
| 插值规划 | 角速度路径一致 | 欧拉角路径一致，须选连续分支 |

检验：在 ZYZ 的 $\vartheta=0$ 附近，$T(\varphi_e)$ 奇异，$J_A$ 不可用；$J$ 仍然有定义（若机构不奇异）。见 [@thm-3.6.A]。

## 2 · ZYZ 欧拉角 ⟷ RPY 角

**口诀：ZYZ 绕当前轴（右乘），RPY 绕固定轴（左乘）；奇点位置不同。**

| | ZYZ $(\varphi,\vartheta,\psi)$ | RPY $(\varphi,\vartheta,\psi)$ |
|:--|:--|:--|
| 轴序列 | $Z\to Y'\to Z''$（动轴） | $X\to Y\to Z$（固定轴；矩阵从右往左作用） |
| 奇点 | $\vartheta=0$：只知 $\varphi+\psi$；$\vartheta=\pi$：只知 $\varphi-\psi$ | $\vartheta=\pm90°$：只知 $\varphi\mp\psi$ |
| $\vartheta$ 的反解 | $\operatorname{Atan2}(\sqrt{r_{13}^2+r_{23}^2},r_{33})$ | $\operatorname{Atan2}(-r_{31},\sqrt{r_{11}^2+r_{21}^2})$ |
| 适用场景 | 末端执行器姿态规划，分析雅可比 | 飞行器姿态（偏航/俯仰/滚转描述） |
| 参数名 | $\varphi$=进动，$\vartheta$=章动，$\psi$=自旋 | $\varphi$=偏航，$\vartheta$=俯仰，$\psi$=滚转 |

反例：同一组三个角代入两套公式会得到**不同**的旋转矩阵——不能因为都叫「欧拉角」就互换。见 [@thm-2.4.A]、[@thm-2.4.B]。

## 3 · 右伪逆 ⟷ 阻尼最小二乘（DLS）

**口诀：行满秩时可用右伪逆闭式；DLS 在 $k>0$ 时对任意秩都有解，但允许任务误差。**

| | 右伪逆 $J^\dagger=J^\mathrm T(JJ^\mathrm T)^{-1}$ | DLS $J^*=J^\mathrm T(JJ^\mathrm T+k^2I)^{-1}$ |
|:--|:--|:--|
| 存在条件 | $J$ 行满秩 | 任意 $J$，$k>0$ 即可 |
| 任务速度 | 精确实现 $v_e=J\dot q$ | 通常存在残差 $\delta=v_e-J\dot q$；失去的任务方向不能靠阻尼恢复 |
| 奇异点行为 | 闭式在降秩处失效；邻域内困难方向可能放大速度，并非每个指令都发散 | 固定 $k>0$ 时增益有界；增大 $k$ 会减小解的范数、增大或保持残差范数 |
| $k\to0^+$ | 不含阻尼参数 | 行满秩时趋向左列右伪逆；一般秩时趋向 Moore–Penrose 伪逆 |
| 参数选择 | — | $k$ 可依距奇异的程度动态调节 |

见 [@def-3.5.2]。近奇异时，困难方向的非零指令分量可能要求很大的关节速度；DLS 以任务残差换取较小的关节速度，是否合适要同时检查两者。

## 4 · 计算力矩前馈 ⟷ 逆动力学控制

**口诀：前馈用期望状态算模型，逆动力学用实测状态算模型；后者精确对消非线性。**

| | 计算力矩前馈 | 逆动力学控制（反馈线性化） |
|:--|:--|:--|
| 模型自变量 | $q_d,\dot q_d,\ddot q_d$ | 实测 $q,\dot q$ |
| 非线性补偿 | 按期望状态计算，跟踪误差大时留有残差 | 按实测状态精确对消（模型准确时） |
| 计算时机 | 可离线预算 | 每控制周期在线算 $B(q),n(q,\dot q)$ |
| 闭环误差方程 | 多出未补偿项 | $\ddot{\tilde q}+K_D\dot{\tilde q}+K_P\tilde q=0$（模型精确时） |
| 本质 | 前馈 | 反馈线性化 |

见 §7.3.4 表格。检验：二者在跟踪误差趋于零时趋于相同输出；误差大时逆动力学仍精确对消，前馈则偏离。

## 5 · 重力补偿 PD ⟷ 逆动力学控制

**口诀：重力补偿 PD 只用于点对点，逆动力学可跟踪移动目标；后者需完整模型。**

| | 重力补偿 PD | 逆动力学控制 |
|:--|:--|:--|
| 目标类型 | 固定目标 $q_d=\text{const}$ | 时变目标 $q_d(t)$ |
| 补偿项 | 仅 $g(q)$ | $B(q)\ddot q+n(q,\dot q)$ 全部 |
| 控制律 | $u=g(q)+K_P\tilde q-K_D\dot q$ | $u=B(q)(\ddot q_d+K_D\dot{\tilde q}+K_P\tilde q)+n(q,\dot q)$ |
| 稳定性证明 | 李雅普诺夫，全局（理想条件下） | 误差方程为线性常系数 ODE |
| 高速运动 | 耦合项未补偿，误差随速度增大 | 精确对消，误差方程独立于速度 |

见 §7.3.3–§7.3.4。检验：给点对点任务，两者都能稳定；换成路径跟踪，重力补偿 PD 推导失效（$\dot q_d\neq0$ 时多出 $\tilde q^\mathrm TK_P\dot q_d$）。

## 6 · 鲁棒控制 ⟷ 自适应控制

**口诀：鲁棒控制知道误差的界但不估计参数，自适应控制在线估计参数但需持续激励才能辨识真值。**

| | 鲁棒控制 | 自适应控制 |
|:--|:--|:--|
| 对不确定性的假设 | 有界：$\|d\|\le\rho(q,\dot q,t)$ | 动力学对常参数线性：$B\ddot q_r+C\dot q_r+g=Y_r\pi$ |
| 参数处理 | 不估计，直接用界 | 在线更新 $\hat\pi$，$\dot{\hat\pi}=\Gamma Y_r^\mathrm T\sigma$ |
| 控制律核心 | 切换项 $\omega=\rho z/\|z\|$ | 自适应控制律消去 $Y\tilde\pi$ 交叉项 |
| 稳定性结论 | 误差指数收敛到有界球 $\|z\|<\varepsilon$ | 跟踪误差 $e\to0$，参数有界 |
| 参数收敛 | 不涉及参数 | 跟踪收敛不保证真参数收敛；还需可辨识性与持续激励（PE）；无 PE 不等于必然漂移 |
| 抖振 | 不连续切换可能产生；边界层平滑可缓解 | 标准光滑更新律无切换抖振，但仍受噪声与未建模动态影响 |

见 §7.3.5–§7.3.6。检验：已知不确定性的界时，可按鲁棒控制的假设设计；自适应控制的标准证明通常假设未知参数恒定，负载突变或缓慢变化都要另检验更新速度与稳定性，不能直接套常参数结论。

## 7 · 分散控制 ⟷ 集中控制

**口诀：分散控制把耦合当干扰靠反馈压，集中控制把耦合显式计算补偿；"集中"是信息依赖，不是算法口味。**

| | 分散控制（§7.2） | 集中控制（§7.3） |
|:--|:--|:--|
| 控制器结构 | $n$ 个独立单轴回路 | 利用全部关节状态的 MIMO 控制律 |
| 耦合处理 | 视为干扰 $d$，靠反馈抑制 | 用整机动力学模型主动补偿 $C\dot q,B\ddot q$ |
| 信息需求 | 仅需本关节 $q_i,\dot q_i$ | 需全部关节 $q,\dot q$（甚至 $\ddot q$） |
| 失效工况 | 高速/大加速/直接驱动（耦合不再是小量） | 模型不准时对消不完全 |
| 计算量 | $O(1)$ 每关节 | 每周期 $O(n^2)\sim O(n^3)$（递推法可到 $O(n)$） |

见 §7.1–§7.3。检验：同一控制律，把 $q,\dot q$ 换成 $q_j,\dot q_j$（单关节版）能独立运行的是分散；不能独立运行的是集中。

## 8 · 关节空间规划 ⟷ 操作空间规划

**口诀：关节空间直接规划关节；操作空间直接描述末端，执行时仍要得到关节指令。**

| | 关节空间规划 | 操作空间规划 |
|:--|:--|:--|
| 规划对象 | $q(t)$ | $p_e(t),\varphi_e(t)$ |
| 避障 | 可用正运动学和碰撞检测，在关节空间规划避障 | 可直接描述末端绕障路径，仍需检查整条机械臂是否碰撞 |
| 奇异点 | 不必为每个关节点反解，但末端速度和力的能力仍受机构奇点影响 | 求解逆运动学时，奇点附近可能无解或要求很大关节速度 |
| 计算量 | 取决于规划方法、碰撞检测与约束 | 通常还需为路径求解逆运动学并检查可行性 |
| 中间点轨迹形状 | 由关节轨迹与正运动学共同决定，简单插值不能直接指定末端形状 | 可以直接指定末端直线或圆弧，但须检查逆解和关节限制 |
| 执行 | 直接控制 | 须转回关节空间 |

见 §4.1.4。检验：焊缝要求末端沿直线运动时，先在操作空间描述直线较直接；简单点对点搬运可先考虑关节空间规划。两种方法都要检查碰撞与关节约束。

## 9 · 路径 ⟷ 轨迹 ⟷ 运动规划

**口诀：路径描述经过哪里；轨迹再安排时间；运动规划还要根据任务处理可行性与障碍。**

| | 路径（path） | 轨迹（trajectory） | 运动规划（motion planning） |
|:--|:--|:--|:--|
| 描述内容 | 经过的位置或位形，不包含时间 | 路径或关节变量随时间的变化 | 根据任务、环境和约束求可执行的运动方案 |
| 包含速度 | 不指定 | 可由时间变化求出 | 若需要执行轨迹，须考虑速度等约束 |
| 避障与优化 | 路径可以经过避障规划 | 轨迹可以沿避障路径生成 | 可包含避障或优化；并非每个规划问题都要求最优 |
| 典型问题 | 走哪条线 | 何时到达各点 | 怎样在给定约束下完成运动 |

见 [@def-4.1.1]–[@def-4.1.3]。

## 10 · 三次多项式时间律 ⟷ 梯形速度曲线（LSPB）

**口诀：三次由端点位置和速度定系数；LSPB 用常加速段与巡航段拼接。**

| | 三次多项式 | 梯形速度（LSPB） |
|:--|:--|:--|
| 速度 | 连续（抛物线形） | 连续 |
| 加速度 | 段内线性；接静止段时通常在端点跳变 | 恒值段之间**跳跃** |
| 参数 | 4 个系数，需给定 $q_i,q_f,\dot q_i,\dot q_f$ | 加速度 $\ddot q_c$ 或巡航速度 $\dot q_c$（一个自由参数） |
| 多段路径点 | 可分段构造，并按需要约束相邻段的连续性 | 可用混合段平滑衔接；是否精确经过点取决于具体构造 |
| 老师强调 | 「理论最优」（固定初终位置/速度、常惯量且忽略重力摩擦等项时，最小平方力矩） | **「工业重点」**，「节省计算时间非常多」 |

见 [@def-4.2.1]、[@def-4.2.3]。

## 11 · 欧拉角姿态规划 ⟷ 角和轴姿态规划

**口诀：欧拉角三分量分别插值，角和轴把三维旋转降成一维 $\theta(t)$；两者都要最终换回基系角速度。**

| | 欧拉角法 | 角和轴法 |
|:--|:--|:--|
| 插值对象 | $\varphi_e=\varphi_i+\lambda\Delta\varphi$（三维线性段） | 单一转角 $\theta(t)$，轴 $r'$ 固定不变 |
| 角速度换算 | $\omega_e=T(\varphi_e)\dot\varphi_e$，$\dot\omega_e=\dot T\dot\varphi_e+T\ddot\varphi_e$ | $\omega_e=R_ir'\dot\theta$，$\dot\omega_e=R_ir'\ddot\theta$ |
| 奇点风险 | ZYZ 为 $\sin\vartheta=0$；RPY 为 $\cos\vartheta=0$ | 零角轴不唯一；半圈不能用除以 $\sin\theta_f$ 的轴公式，须换提取分支 |
| 最短路径 | 不保证 | 若旋转角最短，角和轴给最短弧 |
| 维度 | 三维参数问题 | **一维**标量问题（三维规划压成一维） |

见 §4.3.3。检验：角和轴的 $\omega_e=(R_ir')\dot\theta$ 中若漏掉 $R_i$，就会错误地把初始系分量当基系分量。

## 12 · 可操作度椭球 ⟷ 力椭球

**口诀：单位关节速度球映成速度椭球；单位关节力矩约束对应的力椭球半轴与之互为倒数。**

下表令任务雅可比 $J\in\mathbb R^{m\times n}$ 行满秩，关节速度和关节力矩均以欧氏范数限制；只比较同一任务空间的共轭速度与力。

| | 可操作度椭球 | 力椭球 |
|:--|:--|:--|
| 定义 | $\{J\dot q:\|\dot q\|_2\le1\}$ | $\{f:\|J^{\mathrm T}f\|_2\le1\}=\{f:f^{\mathrm T}JJ^{\mathrm T}f\le1\}$ |
| 半轴 | 奇异值 $\sigma_i(J)$（长轴方向易动） | $1/\sigma_i(J)$（短轴方向易施力） |
| 大奇异值 | 末端易在该方向快速移动 | 末端难在该方向施加大力 |
| 奇异点 | 速度集合在丧失的方向退化 | 理想约束下该方向不再有界；不能推成实际接触力无限 |

见 §3.3、§3.5。行满秩时，同一奇异方向的速度半轴为 $\sigma_i$，力半轴为 $1/\sigma_i$；实际可施力还受结构强度、摩擦与接触条件约束。

## 13 · 牛顿-欧拉法 ⟷ 拉格朗日法

**口诀：牛顿-欧拉递推算动力学效率高但物理图像不直观；拉格朗日直接给方程结构，适合分析性质。**

| | 牛顿–欧拉递推 | 拉格朗日法 |
|:--|:--|:--|
| 计算复杂度 | $O(n)$（前向传播 + 后向传播） | 显式构造 $B(q)$：$O(n^4)$；递推形式：$O(n^2)$ |
| 给出内容 | 关节力矩数值 | $B(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$ 的显式结构 |
| 物理图像 | 逐杆力与力矩平衡 | 能量视角，$T-V$ 的广义力 |
| 分析性质 | 不直接给出 $B,C,g$ 的表达式 | 直接可见惯量矩阵结构、$\dot B-2C$ 反对称性 |
| 控制设计 | 逆动力学实现用递推高效 | 推导李雅普诺夫函数、能量守恒条件 |

见 §6.3–§6.4。检验：要算一次具体关节力矩 → 牛顿-欧拉递推；要推导控制律的稳定性证明 → 拉格朗日结构。

## 14 · $\dot B-2C$ 反对称性 ⟷ Christoffel 矩阵定义

**口诀：能量恒等式给出二次型为零；Christoffel 选法进一步给出矩阵反对称。**

| | 能量恒等式 | Christoffel 选法 |
|:--|:--|:--|
| 对 $C$ 的要求 | 在动力学及其能量恒等式下，满足 $\dot q^{\mathrm T}(\dot B-2C)\dot q=0$ | 按惯量矩阵的偏导数构造一组具体的 $C$ |
| $\dot B-2C$ 的性质 | 只由上述二次型条件不能断言整个矩阵反对称 | 该选法下 $\dot B-2C$ 严格反对称 |
| 用于稳定证明 | 沿运动的二次型为零即可消去对应项 | 由反对称性得到同一消去结果 |

见 §6.1.3、§7.3.3。检验：在李雅普诺夫证明中用到的只是「二次型为零」，不是「矩阵本身反对称」；两者对二次型都成立。

## 15 · 机构奇点 ⟷ 姿态表示奇点

**口诀：机构奇点看任务雅可比降秩；表示奇点看姿态参数换算失去可逆性。**

| | 机构奇点 | 姿态表示奇点 |
|:--|:--|:--|
| 判断对象 | 所选任务的 $J$ 相对机构可达最大秩下降 | $\omega=T(\varphi)\dot\varphi$ 中的 $T$ 不可逆 |
| 后果 | 部分末端瞬时速度方向无法实现 | 无法从角速度唯一求取该组姿态参数的变化率 |
| 改变姿态参数 | 不改变机构本身的速度能力 | 换用在该姿态有效的参数化可避开该表示奇点 |

检验：ZYZ 表示在 $\vartheta=0$ 时奇异，即使此时机构雅可比仍满秩也一样；反之，机械臂伸直造成的位置雅可比降秩，不会因换一套欧拉角而消失。见 [§3.3](ch03/sec3-3.md) 和 [§3.6](ch03/sec3-6.md)。

## 16 · 完整约束 ⟷ 非完整约束

**口诀：完整约束积分掉自由度、压缩可达空间；非完整约束只锁瞬时速度方向、不减小可达位形维数。**

| | 完整约束 | 非完整约束 |
|:--|:--|:--|
| 数学形式 | 可写成 $h_j(q)=0$（或可积分的 $a^T(q)\dot q=0$） | 不可积分的 Pfaffian 约束 $a^T(q)\dot q=0$ |
| 分布对合性 | 对应分布 $\Delta$ 对合（$\dim\bar\Delta = m$） | 对李括号不封闭（$\dim\bar\Delta > m$） |
| 可达位形空间 | 被限制在 $n-k$ 维子流形上，少掉 $k$ 个自由度 | 若完全非完整（$\dim\bar\Delta = n$），仍可到达 $n$ 维空间任意位姿 |

检验：圆盘或独轮车的无侧滑约束 $\dot x\sin\theta-\dot y\cos\theta=0$ 不可积，虽有 1 条约束且只有 2 个输入 $(v,\omega)$，车体仍可到达三维平面位姿 $(x,y,\theta)$ 的任意位置。见 [§10.3](ch10/sec10-3.md) 和 [§10.4](ch10/sec10-4.md)。

## 17 · 无漂移系统 ⟷ 有漂移系统

**口诀：零输入能不能停在原地，是区分一阶运动学与动力学模型的界线。**

| | 无漂移系统（driftless） | 有漂移系统（with drift） |
|:--|:--|:--|
| 标准形式 | $\dot q = G(q)u$（典型一阶运动学） | $\dot x = f(x) + G(x)u$，其中漂移项 $f(x)\not\equiv 0$ |
| 输入归零 $u=0$ | $\dot q = 0$，位形立即保持静止 | 状态仍沿 $f(x)$ 继续演化（例如惯性滑行） |
| 可控性判据 | 直接适用 Chow 定理（对合闭包满秩 $\dim\bar\Delta=n$） | Chow 定理的单纯李代数秩条件不再充分，须额外分析漂移向量场 |

检验：独轮车速度模型 $(v,\omega)=0$ 时车立即停下；把 $(v,\omega)$ 变成状态量、以加速度为控制输入后，即使刹车加速度输入为零，车辆只要当前速度非零就会继续漂移前进。见 [§10.3.4](ch10/sec10-3.md#sec-10.3.4) 和 [§10.6.3](ch10/sec10-6.md#sec-10.6.3)。

## 18 · 后轮驱动两轮车 ⟷ 前轮驱动两轮车

**口诀：速度指令加在谁身上，转角三角函数就跟在谁身上。**

| | 后轮驱动两轮车 | 前轮驱动两轮车 |
|:--|:--|:--|
| 线速度 $v$ 参考点 | 后轴中心（方向永远沿车身纵轴 $\theta$） | 前舵轮中心（方向沿前轮偏角 $\theta+\phi$） |
| 位置方程 | $\dot x=v\cos\theta,\ \dot y=v\sin\theta$ | $\dot x=v\cos\phi\cos\theta,\ \dot y=v\cos\phi\sin\theta$ |
| 航向角速度 $\dot\theta$ | $\dot\theta=\dfrac{v}{l}\tan\phi$（$\phi\to\pm\frac{\pi}{2}$ 时发散） | $\dot\theta=\dfrac{v}{l}\sin\phi$（在车身纵轴分量为 $v\cos\phi$） |

检验：把后驱公式里的 $v$ 替换为前轮速度沿着车身纵轴的投影 $v_{\text{前}}\cos\phi$，正好把 $\tan\phi\cdot\cos\phi$ 化为 $\sin\phi$，两组方程严丝合缝。见 [§10.5.3](ch10/sec10-5.md#sec-10.5.3) 和 [§10.5.4](ch10/sec10-5.md#sec-10.5.4)。
