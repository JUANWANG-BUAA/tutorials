# 2.11 运动学标定

制造加工误差、连杆装配公差以及编码器零位偏置，使得物理机械手真实的 DH 参数 $\boldsymbol\xi$ 略微偏离 CAD 名义设计值 $\boldsymbol\xi_n$。即便各关节传感器读数完全一致、重复精度极高，直接把名义参数代入正运动学算出的末端位置仍可能存在毫米级的**绝对定位偏差**（准确度不足）。**运动学标定（kinematic calibration）**通过测量若干已知关节构型下的真实末端位姿，把真实几何参数 $\boldsymbol\xi$ 反演出来。

::: note 考纲定位 · 了解·精简
掌握标定问题的非线性最小二乘数学建模、基于加权最小二乘先修引理的高斯—牛顿迭代闭合流程、姿态残差采用矩阵对数 $(\operatorname{Log}(R_n^{\mathrm T}R_m))^\vee$ 而非欧拉角作差的原因，以及未知数个数 $p\le 4n$ 与激发构型满秩可辨识条件。
:::

## 2.11.1 标定问题的数学表述与最小二乘引理

::: def 定义 2.11.1 · 运动学标定参数向量与待辨识维数 {#def-2.11.1}
把所有参与正运动学的真实结构几何参数与零位偏置（包括连杆长度、扭角、偏距、转角零位等需要辨识的分量）聚成参数向量 $\boldsymbol\xi\in\mathbb R^p$，记正运动学对参数的显式依赖为
$$\boldsymbol x_e=\boldsymbol k(\boldsymbol\xi,\boldsymbol q).$$
对标准 DH 的 $n$ 关节机构，若将全部 DH 参数（含固定安装变换参数）计入并剔除冗余共轴零偏或不可观常数（例如完全不可测量的基座/末端局部参数组合），实际有效独立未知数维数为 $p\le 4n$（加装常值基座/工具变换参数时可略增，详见[勘误 E2.11](errata.md#errata-2.11)）；不可不经几何可观性分析一律硬套 $p=4n$。
:::

标定算法每次线性迭代步均依赖加权最小二乘求解器，先给出如下线性代数结论（先修引理）：

::: thm 引理 2.11.A · 加权线性最小二乘正定解（先修结论） {#thm-2.11.A}
考虑过约束线性系统 $\boldsymbol\Phi\,\Delta\boldsymbol\xi\approx\boldsymbol r$，其中设计矩阵 $\boldsymbol\Phi\in\mathbb R^{N\times p}$ 满足 $N\ge p$ 且**列满秩**（$\operatorname{rank}\boldsymbol\Phi=p$），$\boldsymbol W\in\mathbb R^{N\times N}$ 为对称正定权重矩阵（平衡位置米与姿态弧度的量纲或传感器方差差异）。则极小化加权平方残差代价函数
$$J(\Delta\boldsymbol\xi)=\frac{1}{2}(\boldsymbol r-\boldsymbol\Phi\Delta\boldsymbol\xi)^{\mathrm T}\boldsymbol W(\boldsymbol r-\boldsymbol\Phi\Delta\boldsymbol\xi)$$
的唯一最优解满足**正规方程**（normal equations）$\boldsymbol\Phi^{\mathrm T}\boldsymbol W\boldsymbol\Phi\,\Delta\boldsymbol\xi=\boldsymbol\Phi^{\mathrm T}\boldsymbol W\boldsymbol r$，解为
$$\Delta\boldsymbol\xi=\big(\boldsymbol\Phi^{\mathrm T}\boldsymbol W\boldsymbol\Phi\big)^{-1}\boldsymbol\Phi^{\mathrm T}\boldsymbol W\boldsymbol r.$$
实际数值实现中，为避免计算 $\boldsymbol\Phi^{\mathrm T}\boldsymbol W\boldsymbol\Phi$ 将矩阵条件数平方放大而引发病态，通常对白化系统 $\boldsymbol W^{1/2}\boldsymbol\Phi\,\Delta\boldsymbol\xi=\boldsymbol W^{1/2}\boldsymbol r$ 采用 **QR 分解**或**奇异值分解（SVD）**直接求解，并在 $\boldsymbol\Phi$ 奇异或病态时及时诊断不可观参数。
:::

现在回到非线性标定问题。在名义参数 $\boldsymbol\xi_n$ 附近作一阶泰勒展开（设第 $k$ 组测试构型关节角读数为 $\boldsymbol q^{(k)}$，实测末端位姿向量为 $\boldsymbol x_m^{(k)}$，当前名义模型预测为 $\boldsymbol x_n^{(k)}=\boldsymbol k(\boldsymbol\xi,\boldsymbol q^{(k)})$）：
$$\Delta\boldsymbol x^{(k)} = \boldsymbol x_m^{(k)} - \boldsymbol x_n^{(k)} \approx \left.\frac{\partial \boldsymbol k(\boldsymbol\xi,\boldsymbol q^{(k)})}{\partial\boldsymbol\xi}\right|_{\boldsymbol\xi}\Delta\boldsymbol\xi = \boldsymbol\Phi_k(\boldsymbol\xi,\boldsymbol q^{(k)})\,\Delta\boldsymbol\xi.$$
采集 $l$ 组位姿量测（$k=1,\dots,l$），每次提供 $m\le 6$ 个独立分量（如 3 位置 + 3 姿态误差，或纯三维位置 $m=3$），纵向叠置成总残差向量与堆叠回归矩阵（原书式 2.86–2.87）：
$$\bar{\boldsymbol r}=\begin{bmatrix}\Delta\boldsymbol x^{(1)}\\ \vdots\\ \Delta\boldsymbol x^{(l)}\end{bmatrix}\in\mathbb R^{lm},\qquad
\bar{\boldsymbol\Phi}=\begin{bmatrix}\boldsymbol\Phi_1\\ \vdots\\ \boldsymbol\Phi_l\end{bmatrix}\in\mathbb R^{lm\times p}.$$
必要条件是观测量总数不少于待估参数个数，即 $lm\ge p$；但这仅是必要条件——测试构型还必须覆盖工作空间的不同姿态与关节组合，使得回归矩阵 $\bar{\boldsymbol\Phi}$ **列满秩且条件数适中**。

::: note 为什么姿态残差不能直接用欧拉角差，而要取 $\operatorname{Log}$？ {#note-2.11.log}
若实测旋转矩阵为 $R_m$、模型预测为 $R_n$，则名义系下的相对旋转误差为 $R_{\mathrm{err}}=R_n^{\mathrm T}R_m\in SO(3)$（或固定参考系左差 $R_m R_n^{\mathrm T}$）。直接用三参数欧拉角作差 $\boldsymbol\phi_m-\boldsymbol\phi_n$ 会在表示奇异点（如 $\vartheta=0$）和 $2\pi$ 卷绕处发生跳变。利用 [§2.5 角和轴](sec2-5.md) 的矩阵对数映射到李代数反对称矩阵空间再取矢量坐标：
$$\boldsymbol e_R = \big(\operatorname{Log}(R_n^{\mathrm T}R_m)\big)^{\vee}\in\mathbb R^3$$
（小误差时即相当于旋转轴 $\boldsymbol r$ 乘小旋转角 $\Delta\vartheta$），局部平滑无坐标奇异且与单位正交几何完全一致。位置残差直接取 $\boldsymbol e_p=\boldsymbol p_m-\boldsymbol p_n$，合并构成 $\Delta\boldsymbol x=[\boldsymbol e_p^{\mathrm T},\ \boldsymbol e_R^{\mathrm T}]^{\mathrm T}$。
:::

## 2.11.2 迭代求解流程与线性/非线性特征辨析

因为大多数机构（除仅辨识杆长的特殊线性模型外）的正运动学关于扭角和关节零偏都是高度非线性的，所以必须从初始名义参数 $\boldsymbol\xi^{(0)}=\boldsymbol\xi_n$ 出发，沿高斯—牛顿闭环多次更新（原书 §2.11）：

::: method 运动学标定迭代四步法（含独立校验） {#method-2.11.steps}
1. **算名义预测**：代入当前参数估计值 $\boldsymbol\xi$ 与采集的关节读数 $\boldsymbol q^{(k)}$，求预测末端位置 $\boldsymbol p_n^{(k)}$ 与姿态 $R_n^{(k)}$；
2. **求堆叠残差与回归阵**：计算位置误差 $\boldsymbol p_m^{(k)}-\boldsymbol p_n^{(k)}$ 与局部旋转向量误差 $(\operatorname{Log}(R_n^{(k)\mathrm T}R_m^{(k)}))^\vee$ 构成 $\bar{\boldsymbol r}$，同时重新求取参数雅可比矩阵 $\bar{\boldsymbol\Phi}(\boldsymbol\xi)$；
3. **加权线性求解**：选定合理权重 $\boldsymbol W$（平衡位置米与姿态弧度量纲及传感器精度），用 QR/SVD 解出参数修正量 $\Delta\boldsymbol\xi=(\bar{\boldsymbol\Phi}^{\mathrm T}\boldsymbol W\bar{\boldsymbol\Phi})^{-1}\bar{\boldsymbol\Phi}^{\mathrm T}\boldsymbol W\bar{\boldsymbol r}$；
4. **更新与独立验证**：更新 $\boldsymbol\xi \leftarrow \boldsymbol\xi + \Delta\boldsymbol\xi$；若 $\|\Delta\boldsymbol\xi\|$ 尚未收敛至容差则返回第 1 步。收敛后，必须另取一组**未参与拟合的独立检验位形**计算测试集均方根（RMS）与最大残差，排除过拟合。
:::

::: note 谁负责标定、标定与开机回零（Homing）有何区别 {#note-2.11.who}
- **工程分工**：工业机器人的出厂标定通常由**制造商**完成（部分高精密应用会在出厂手册给出补偿后的真实运动学参数）；然而，**用户**在设备经历剧烈碰撞、更换减速器/连杆、重新安装重型工具或底座移位后，必须重新检核定位精度并按需执行现场重标定。
- **标定 ≠ 开机回零（Homing）**：增量式编码器开机后返回参考限位并清零计数属于**回零找参考点**；它仅确立了软件编码器计数起点，并不能测出连杆制造公差、垂直度歪斜或基座外参偏差，绝不能替代外部位姿测量的几何标定（参见[习题集 D2](exercises.md#exercise-2.D2)的真实数值实验）。
:::

### 2.11.2.1 2R 臂特例：纯杆长线性标定 vs 含零偏非线性标定

观察平面 2R 臂位置映射
$$p_x=a_1\cos(\vartheta_1+\Delta q_1)+a_2\cos(\vartheta_1+\Delta q_1+\vartheta_2+\Delta q_2),\qquad p_y=a_1\sin(\vartheta_1+\Delta q_1)+a_2\sin(\vartheta_1+\Delta q_1+\vartheta_2+\Delta q_2).$$
1. **情形 A（仅辨识杆长 $\boldsymbol\xi=[a_1,a_2]^{\mathrm T}$，零偏已知为零）**：关于 $(a_1,a_2)$ **严格线性**！单组非奇异量测的雅可比即正交方向矩阵
   $$\boldsymbol\Phi_1=\begin{bmatrix}\cos\vartheta_1 & \cos(\vartheta_1+\vartheta_2)\\ \sin\vartheta_1 & \sin(\vartheta_1+\vartheta_2)\end{bmatrix},\qquad \det\boldsymbol\Phi_1=\sin\vartheta_2.$$
   可见**只在单组伸直/折回位形 $\sin\vartheta_2=0$ 采集数据时，$\det\boldsymbol\Phi_1=0$，无法区分 $a_1$ 与 $a_2$ 各自是多少**（仅测出 $a_1\pm a_2$）；即使采样位形不是严格共线而具有满秩 $\operatorname{rank}\bar{\boldsymbol\Phi}=2$，只要全部采样点集中在极窄邻域内，条件数 $\kappa(\bar{\boldsymbol\Phi})$ 仍可能超过 $10^2$ 而放大测量噪声；只有跨工作空间大角度分布采样（例如真实杆长误差 $\Delta\boldsymbol\xi=(0.04,-0.03)\,\mathrm m$ 在 6 组广泛分布关节角下无迭代一次即可精确反演），才能获得良态稳定辨识结果。
2. **情形 B（同时存在编码器零偏 $\Delta q_1,\Delta q_2$）**：变量进入三角函数自变量内，模型转为非线性，单步矩阵求逆不再一步到位，必须按上述高斯—牛顿四步法迭代收敛，且需保证采集构型充分变化以激发四参数的可辨识度。

3. 当 $\vartheta_2\equiv 0$ 时，$\boldsymbol\Phi_k$ 的两列永远相等（$\cos\vartheta_1=\cos(\vartheta_1+0),\ \sin\vartheta_1=\sin(\vartheta_1+0)$），故堆叠后列仍线性相关（$\operatorname{rank}\bar{\boldsymbol\Phi}=1<2$），只能确定总长 $a_1+a_2$ 而不能分辨各自长度。

## 2.11 小结

| 核心要素 | 数学关键 | 常见陷阱 |
|:--|:--|:--|
| 问题建模 | $\boldsymbol x_e=\boldsymbol k(\boldsymbol\xi,\boldsymbol q)$，$p\le 4n$ | 把不可辨识的冗余参数强行设为全 $4n$ |
| 线性求解步 | $\Delta\boldsymbol\xi=(\bar{\boldsymbol\Phi}^{\mathrm T}\boldsymbol W\bar{\boldsymbol\Phi})^{-1}\bar{\boldsymbol\Phi}^{\mathrm T}\boldsymbol W\bar{\boldsymbol r}$（QR/SVD） | 直接算欧拉角差，忽略正定权重 $\boldsymbol W$ 量纲平衡 |
| 可辨识与验证 | $lm\ge p$（必要）；激发构型令 $\bar{\boldsymbol\Phi}$ 满秩（关键） | 只看拟合集误差，未在工作空间做独立交叉验证；混淆开机回零与标定 |
