# 2.11 运动学标定

DH 几何量有些可以直接测量，但装配公差、柔性、工具接口和传感器零位会让图纸值不能直接代表运行中的有效模型。**运动学标定**用末端位姿量测反推一组固定规范下可辨识的有效参数；它能降低模型可解释的系统误差，不能凭一次实验保证全工作空间准确。课程把它定位在「了解」层次（录播 1:51:03：「只讲一下基本原理」），本节对应录播区间 1:49:32–1:55:29。

::: preview 先修补 · 最小二乘（本节只用到这一条）

标定要用到的「超定方程最小二乘」，一句话就能说清：**方程数多于未知数、又没有精确解时，就取使残差平方和最小的那个解**。

$$\min_{\boldsymbol\xi}\|A\boldsymbol\xi-\boldsymbol b\|^2\ \Longrightarrow\ \boldsymbol\xi=(A^{\mathrm T}A)^{-1}A^{\mathrm T}\boldsymbol b$$

（推导思路：展开目标函数，对 $\boldsymbol\xi$ 求导并置零，即得**正规方程** $A^{\mathrm T}A\boldsymbol\xi=A^{\mathrm T}\boldsymbol b$；$A$ 列满秩时 $A^{\mathrm T}A$ 可逆。）式中的 $(A^{\mathrm T}A)^{-1}A^{\mathrm T}$ 是 $A$ 的左广义逆。它适合解释公式来源；实际程序优先用 QR 或 SVD，避免显式形成可能病态的 $A^{\mathrm T}A$。

不过有三点要提醒。① 上述逆矩阵公式要求 $A$ **列满秩**；方程数不少于未知数只是必要条件，秩不足时最小二乘解不唯一。② 位姿分量有长度和角度两种单位，需先选局部姿态残差并按噪声尺度加权。③ 线性模型可一次求解；一般运动学模型对所估参数非线性，需要反复线性化，但下方只估两杆长的例子恰好是线性的。

:::

<a id="sec-2.11.1"></a>

## 2.11.1 问题设定

要做标定，先得把正运动学中隐含的参数显式写出来。固定 DH 规范、基座、工具和零位约定，令 $\boldsymbol\xi\in\mathbb R^p$ 表示真正要估的参数子集。教材把 $\boldsymbol a,\boldsymbol\alpha,\boldsymbol d,\boldsymbol\vartheta$ 四列暂列为 $4n$ 个上限项，但 R 行的 $\vartheta_i$、P 行的 $d_i$ 通常是当前关节读数，不是固定几何常数；若估计编码器零偏，应写成 $\vartheta_i=q_i+b_i$ 或 $d_i=q_i+b_i$，把 $b_i$ 单独列入。固定项、已知项和不可辨识的组合都应删去，实际未知数是 $p\le4n$。于是式 2.82 改写为

$$\boldsymbol x_e=k(\boldsymbol\xi,\boldsymbol q).$$

接下来还要引入两个位姿：$\boldsymbol x_m$ 为外部测量位姿，$\boldsymbol x_n=k(\boldsymbol\xi_0,\boldsymbol q)$ 为当前参数和关节读数算出的名义位姿。录播 1:52:00 的旧教程记录用「一个是算的、一个是测的……不会太大」区分两者；偏差是否足够小，仍须由数据和模型检查。位置残差可直接用米或毫米；姿态残差应在选定的局部坐标中表达，例如在当前名义工具系表达的相对旋转向量 $\big(\operatorname{Log}(R_n^{\mathrm T}R_m)\big)^\vee\in\mathbb R^3$，不要在欧拉角跨分支或奇异点时直接相减。将位置差与局部姿态残差合记为 $\boldsymbol r$；位置和姿态噪声不同则使用权重矩阵 $W$。线性化需要当前参数足够接近可用解，使一阶近似在所考虑的修正范围内有效。

<a id="sec-2.11.2"></a>

## 2.11.2 线性化、最小二乘与迭代

::: method 标定三步法（原书式 2.85–2.89） {#method-2.11.steps}
1. **线性化**：在当前参数附近一阶展开（录播 1:53:10 老师：「在标称值附近给它展开……整理之后得到了（下式）」）：

$$\boldsymbol r\approx\Phi_k\,\Delta\boldsymbol\xi,\qquad
\Phi_k=-\left.\frac{\partial\boldsymbol r(\boldsymbol\xi,\boldsymbol q)}{\partial\boldsymbol\xi}\right|_{\boldsymbol\xi=\boldsymbol\xi_k},$$

其中 $\Phi_k$ 是 $m\times p$ 的**运动学标定矩阵**，即参数修正到所选残差减少量的雅可比。因为 $\boldsymbol r(\boldsymbol\xi_k+\Delta\boldsymbol\xi)\approx\boldsymbol r(\boldsymbol\xi_k)-\Phi_k\Delta\boldsymbol\xi$，令新残差尽量小就得到上式。若残差直接取 $\boldsymbol x_m-k(\boldsymbol\xi,\boldsymbol q)$，才可简写为 $\Phi_k=\partial k/\partial\boldsymbol\xi$；用旋转对数作姿态残差时须对该残差求导，不能直接套欧拉角导数。教材的 $m\times4n$ 是把所有上限项都列入的特例。堆叠 $t$ 个位形后，$\Phi_k^*\in\mathbb R^{tm\times p}$。英文原版把参数偏差记作 $\boldsymbol\zeta$，本编用 $\Delta\boldsymbol\xi$，以区别于关节变量 $\boldsymbol q$。

2. **超定量测 + 最小二乘**：算术条件是 $tm\ge p$，但还必须满足 $\operatorname{rank}(\Phi_k^*)=p$，并让最小奇异值不能太小。把各次残差堆叠起来（原书式 2.87 的子集形式），得 $\boldsymbol r^*\approx\Phi_k^*\,\Delta\boldsymbol\xi$，再取最小二乘解

$$\Delta\boldsymbol\xi=(\Phi_k^{*T}\Phi_k^*)^{-1}\Phi_k^{*T}\,\boldsymbol r^* ,$$

上式取等权。若残差权重 $W$ 对称正定，则目标改为 $\min_u\|W^{1/2}(\Phi_k^*u-\boldsymbol r^*)\|^2$，理论解为 $\Delta\boldsymbol\xi=(\Phi_k^{*T}W\Phi_k^*)^{-1}\Phi_k^{*T}W\boldsymbol r^*$。正规方程中的逆只用于推导；程序对加权设计矩阵优先用 QR/SVD，接近奇异时可使用阻尼最小二乘，但阻尼不会补回不可辨识的信息。量测位形要覆盖任务中的参数敏感方向，不能只把样本数堆在一角。

3. **修正、验证 + 迭代**：参数按 $\boldsymbol\xi_{k+1}=\boldsymbol\xi_k+\Delta\boldsymbol\xi$ 更新（原书式 2.89）。每轮都用新参数重算 $\Phi_k^*$、名义位姿和残差；录播 1:55:00–1:55:18 的旧教程记录说「再迭代，一直到这个差值特别小……满足你的要求之后就停止迭代」。实际应明确修正量与训练残差的停止条件，再用未参与拟合的验证位形检查 RMS 和最大误差。修正量变小不等于真值恢复，验证误差变坏时应停止并检查模型、量测、权重和可辨识性。
:::

这三步不是走一遍就结束：每轮都刷新参数、线性化矩阵和残差，再用独立位形验证。

<a id="lab-2.11.calibration"></a>

::: think 操作任务 · 宽分布真的比多测几次同姿态好吗？
下面演示用名义两连杆臂 $a^0=(1.00,0.60)$ m 合成量测。真实长度是 $a^\star=(1.04,0.57)$ m，所以待估偏差为 $(0.04,-0.03)$ m。每个样本只估两个长度偏差；这是一个故意简化的可辨识例，不代表工业标定的完整参数表。

1. 先选“宽分布、无噪声”，预测估计值应接近 $(0.04,-0.03)$ m。
2. 选“集中分布”：即使样本数增加，$\Phi$ 的两列也可能近相关；看秩、条件数和估计误差。
3. 加入毫米级固定模式扰动，比较训练分量 RMS 与真值偏差；再用少量样本观察 $tm\ge p$ 只是必要条件。滑杆给的是扰动幅值 $A$，不是随机正态噪声的标准差；训练分量 RMS 对 $N$ 个样本的 $2N$ 个位置坐标分量求均方根。
4. 读数中的“估计偏差”不是“已证明全域准确”：还要用未参与拟合的位形验证。[习题 D2](exercises.md#exercise-2.D2) 另用独立随机噪声讨论统计误差，不与本演示的固定扰动混为一谈。

:::

::: note 不运行脚本也能核对
对样本 $q=(q_1,q_2)$，只估长度偏差时模型对参数线性，因而下式是精确等式，不是截去高阶项的近似：

$$\begin{bmatrix}\Delta p_x\\\Delta p_y\end{bmatrix}
=
\begin{bmatrix}
\cos q_1&\cos(q_1+q_2)\\
\sin q_1&\sin(q_1+q_2)
\end{bmatrix}
\begin{bmatrix}\Delta a_1\\\Delta a_2\end{bmatrix}.$$

这个单样本 $2\times2$ 矩阵的行列式为 $\sin q_2$。因此一个 $q_2=90^\circ$ 的位形就能满列秩，无扰动时可精确恢复 $(0.04,-0.03)$ m；并不需要“至少两个不共线样本”。若所有样本都取 $q_2=0$，两列完全相同，改变 $q_1$ 或重复测量也不能分开两杆长。若 $q_2$ 始终接近 0，两列可能近相关；要比较实际奇异值，不能仅凭“样本集中”断定病态。
:::

::: sol 核对

1. 教材的 $m\times4n$ 是上限写法；实际 $\Phi$ 是 $m\times p$，$p$ 只包含当前规范下可辨识的参数子集。R 行的角度通常是当前 $q_i$ 读数；编码器零偏则写成 $\vartheta_i=q_i+b_i$ 并估 $b_i$。
2. 姿态残差须选局部分支，避免欧拉角跨分支或遇到奇异点时直接相减；位置与角度单位不同，噪声尺度也可能不同，因此要按所选残差坐标加权。
3. $tm\ge p$ 只说明方程数够；列满秩才能唯一确定线性化参数修正，条件数反映噪声放大程度。独立验证集用于检查未参与拟合的位形，不能仅凭训练残差判断泛化效果。
4. 真实长度偏差为 $(0.04,-0.03)$ m。演示采用固定正弦模式乘幅值 $A$，不是独立随机正态噪声；训练分量 RMS 为 $\sqrt{\sum_{j=1}^{N}\|\boldsymbol r_j\|^2/(2N)}$。单个位形的设计矩阵行列式为 $\sin q_2$，故 $q_2=90^\circ$ 时即可列满秩；这只针对已固定零位、基座和工具、仅估两杆长的模型。

## 2.11 小结与常见错误

- **一个闭环**：机械误差 → 位姿量测 → 残差坐标与权重 → 线性化 + 最小二乘 → 参数修正 → 独立验证。$p$ 是实际未知数，$tm\ge p$ 只是必要条件。
- **一般模型与特例**：一般标定是迭代的非线性最小二乘；只估本例两杆长时则是线性问题，可一次求解。正规方程便于推导，QR/SVD 更适合实现，拟合和独立验证必须分开看。
- **下一节**：[2.12 逆运动学问题](sec2-12.md) 回到两连杆主线：从末端位置**反解**关节角，并处理多解与不可达。

核心公式速查：

| 公式 | 条件与假设 | 单位/量纲 | 易错点 |
|:--|:--|:--|:--|
| $\boldsymbol r\approx\Phi_k\Delta\boldsymbol\xi$，$\Phi_k=-\partial\boldsymbol r/\partial\boldsymbol\xi$ | 残差坐标与权重选定；当前参数接近可用解 | 混合（m/rad） | 位置与姿态残差单位不同，须加权；姿态残差用旋转对数 |
| $\Delta\boldsymbol\xi=(\Phi_k^{*T}\Phi_k^*)^{-1}\Phi_k^{*T}\boldsymbol r^*$ | $\operatorname{rank}\Phi_k^*=p$（等权特例） | 视参数 | $tm\ge p$ 只是必要条件；正规方程逆用于推导，程序用 QR/SVD |
| $\boldsymbol\xi_{k+1}=\boldsymbol\xi_k+\Delta\boldsymbol\xi$ | 迭代刷新 $\Phi_k^*$、名义位姿、残差 | — | 修正量变小 ≠ 真值恢复；独立验证位形另行检查 |

::: think 常见错误清单 · 自查三条
1. 对非线性参数模型只做一轮线性化，或反过来认为所有参数子模型都必须迭代；先检查所估参数如何进入模型；
2. 把 $tm\ge p$ 当成充分条件——还要列满秩、条件数可接受、姿态残差口径一致；
3. 把回零当成几何标定，或把训练残差小当成全域精度已证——两者都需要单独复核。
:::
