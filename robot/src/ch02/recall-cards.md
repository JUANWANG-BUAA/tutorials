## A. 定义卡

### A1 · 旋转矩阵与 $SO(3)$

写出旋转矩阵的列是什么、两条代数性质，以及 $SO(3)$ 的定义式。

::: sol A1 核对
把 9 个方向余弦**按列**排成 $R=\begin{bmatrix}\boldsymbol x'&\boldsymbol y'&\boldsymbol z'\end{bmatrix}$，**每一列就是固连系对应轴在参考系中的表示**（故又称方向余弦阵）。两条性质：**正交性** $R^{\mathrm T}R=I_3$（等价 $R^{-1}=R^{\mathrm T}$）、行列式 $\det R=+1$（右手系；$\det=-1$ 是含镜像的左手系，不属于 $SO(3)$）。$SO(3)=\{R\in\mathbb R^{3\times3}:R^{\mathrm T}R=I_3,\ \det R=1\}$。（[@def-2.2.1]、[@def-2.2.2]）
:::

### A2 · 9 量、6 约束、3 独立

写出三条单位长度约束、三条垂直约束，并说明右手条件是否再减少一个连续自由度。只给出原点位置和一根轴的方向，是否能确定姿态？

::: sol A2 核对
$R$ 的三列是本体三轴在参考系中的坐标。三列模长为 1 给 3 个约束、两两点积为 0 再给 3 个约束，9 个元素留下 3 个连续独立参数。还须 $\boldsymbol x'\times\boldsymbol y'=\boldsymbol z'$，排除左手镜像；右手条件选择手性，不再扣除一个连续自由度。这是局部参数计数，不保证一套欧拉角能全局唯一、无奇异地表示姿态。

原点位置加一根轴的方向仍不够：绕该轴的滚转会改变另外两轴。可用 [§2.1 练习 2](sec2-1.md#practice-2.1.handedness) 的两组横向轴检查。（[@thm-2.1.A]、[@note-2.2.2]）
:::

### A3 · 旋转矩阵的三重几何身份

同一个 $R$ 有哪三种读法？各配一个工程例子。

::: sol A3 核对
① 姿态描述：列为本体三轴在参考系中的方向余弦，例如工具相对法兰的朝向。② 坐标变换：共原点时，同一点满足 $\boldsymbol p^0=R_1^0\boldsymbol p^1$；反向则用转置，点不动。相机与基座原点不同时还需处理平移。③ 旋转算子：同一固定系内，$\boldsymbol v_{\rm after}=R\boldsymbol v_{\rm before}$，向量真正转动，例如绕过原点的 $z$ 轴转 $30^\circ$。

取 $R=R_z(90^\circ)$，输入列为 $(1,0.5,0)^{\mathrm T}$：主动转向量得 $(-0.5,1,0)^{\mathrm T}$；若它是固定点的参考坐标，换成本体系坐标则用 $R^{\mathrm T}$，得 $(0.5,-1,0)^{\mathrm T}$。两项都保长，须检查输入/输出的系别。（[@thm-2.2.B]、[数值对照](sec2-2.md#ex-2.2.compare)）
:::

### A4 · ZYZ 与 RPY 的序列与轴族

分别写出两种欧拉角的旋转序列、各绕哪一族轴、乘法的方向。

::: sol A4 核对
两者均从 $I$ 出发。**ZYZ**：当前 $z(\varphi)$ → 新 $y(\vartheta)$ → 新 $z(\psi)$，逐次右乘得到 $R_z(\varphi)R_y(\vartheta)R_z(\psi)$。**本书 RPY**：固定 $x(\psi)$（滚转）→ 固定 $y(\vartheta)$（俯仰）→ 固定 $z(\varphi)$（偏航），逐次左乘得到 $R_z(\varphi)R_y(\vartheta)R_x(\psi)$；等价于当前轴 $z(\varphi)\to y(\vartheta)\to x(\psi)$。ZYZ 与 RPY 轴序列不同，不是同组三个角的左右乘对偶。（[2.4.2](sec2-4.md#sec-2.4.2)、[2.4.5](sec2-4.md#sec-2.4.5)）
:::

### A5 · 角和轴表示与表示不唯一

写出四参数表示、单位约束与不唯一性。

::: sol A5 核对
四参数 $(\vartheta,\boldsymbol r)$，轴受 $\|\boldsymbol r\|=1$ 约束，正向用右手定则。重复表示包括同步反号与 $2k\pi$ 周期。取主角 $[0,\pi]$ 后，一般角的轴唯一；零角轴任意但主旋转向量为 0；半圈轴有 ± 两选。半角打包仍保留四元数整体正负的双重覆盖。（[@def-2.5.1]、[@thm-2.5.A]）
:::

### A6 · 齐次坐标与齐次变换矩阵

写出点与方向的齐次坐标、A 的分块结构，并说明整体正交的条件。

::: sol A6 核对
点 $[p;1]$，自由方向 $[d;0]$；$A_1^0=[R_1^0,o_1^0;0,1]\in SE(3)$，作用为 $[Rx+wo;w]$。底行保持末分量；整体正交当且仅当 $o=0$，非零平移时不能用转置求逆。群的合成是 $(R,o)(S,t)=(RS,o+Rt)$，第二段平移要先旋转。（[@def-2.7.1]、[2.7.3](sec2-7.md#sec-2.7.3)）
:::

### A7 · DH 参数与"3 常 1 变"

写出四个参数的几何含义、哪些恒为常数、变量怎么定。

::: sol A7 核对
| 参数 | 含义 | 属性 |
|:--|:--|:--|
| $a_i$ | **杆件长度**（公垂线长度，沿 $x_i$） | 恒为常数 |
| $d_i$ | **关节距离**（从 $o_{i-1}$ 到垂足 $o_i'$ 沿 $z_{i-1}$ 的有向距离） | 移动关节时为变量 |
| $\alpha_i$ | **杆件扭角**（绕 $x_i$ 从 $z_{i-1}$ 到 $z_i$ 的右手有向角） | 恒为常数 |
| $\vartheta_i$ | **关节转角**（绕 $z_{i-1}$ 从 $x_{i-1}$ 到 $x_i$ 的右手有向角） | 转动关节时为变量 |

固定选系、固定几何的单自由度 R/P 行是“3 常 1 变”；四参数来自 DH 选系，机构自由度没有由六减到四。关节 $i$ 沿 $z_{i-1}$，平行 R 可取 $d_i=0$，平行 P 的 $d_i$ 仍随行程变；不平行相交轴的 $x_i$ 须垂直两轴。换选系后中间矩阵可变，统一物理基座、工具和关节零位并补偿常值变换后，物理位姿才一致。有向角从转轴正端朝原点看，逆时针为正。见[§2.8 练习 1、2](sec2-8.md#practice-2.8.chain)与[补注 E2.4](errata.md#errata-2.4)。
:::

### A8 · 逆运动学的四难点与存在性判据

写出四条难点，并给出解存在的判据。

::: sol A8 核对
① **非线性**：三角函数复合，闭式解随结构而异；② **有限多解**：同一位姿可对应多支关节解，一般 6R 的非退化孤立解上界可达 16，不能把它当作每台机械臂的实际支数；③ **连续解族**：可由任务冗余或特殊奇异位形产生；④ **无解**：位置或所需姿态不满足约束。

位置落在针对方向集合定义的灵活工作空间内，且目标姿态属于该集合，是存在解的充分保证；**不在灵活空间内，不等于指定的某一个姿态无解**。工作空间若已经按限位定义，其存在性保证就包含该关节域；碰撞或连续路径等未计入的限制仍须另外检查。本章使用平面几何与球腕解耦，其他结构须选择相应的解析或数值方法。

核查时先确认任务、工具接口与关节域，再用该结构的容许性条件筛选，最后逐支回代。奇异位形可能有连续解族，不能把分母为零一律当作无解。（[@thm-2.12.A]、[例 2.12.D](sec2-12.md#ex-2.12.D)）
:::

### A9 · 解耦的充分条件与腕心

写出闭式逆解的两个充分条件与腕心公式，并说明 $d_6$ 的角色。

::: sol A9 核对
本节给出六自由度串联结构的闭式求解充分条件：三个连续转动轴交于一点，或三个连续转动轴平行。它们不是必要条件，也不保证任意目标有解。

若**末三个转动轴**交于一点，才按本节“臂 + 球形腕”的安排求解。腕心公式 $\boldsymbol p_w=\boldsymbol p_e-d_6\boldsymbol a_e$ 还要求工具偏置恰沿接近轴，满足 $p_e-p_w=d_6a_e$；一般工具偏置须按完整固连变换回退。$d_6$ 是该约定下的有向外移长度，不扣它会把工具尖端位置错当腕心。（[@thm-2.12.B]、[@method-2.12.decouple]）
:::

## B. 结论卡

### B1 · 当前轴右乘、固定轴左乘，何时能倒序？

写出两条更新规则，并说明当前轴「先 $z(\beta)$ 后新 $y(\alpha)$」与固定轴「先 $y(\alpha)$ 后 $z(\beta)$」何时等价。

::: sol B1 核对
当前轴新增转动 $B$：$R_{\rm new}=RB$；固定轴新增转动 $S$：$R_{\rm new}=SR$。题中两序列分别为 $R_0R_z(\beta)R_y(\alpha)$、$R_z(\beta)R_y(\alpha)R_0$。从 $I$ 出发二者相等；一般 $R_0$ 时不保证相等。倒序要连同轴与角一起倒序，不能只交换角度数值。（[@thm-2.3.A]、[@thm-2.3.B]、[@ex-2.3.C]）
:::

### B2 · 三个基本旋转的记忆结构

写出三个不动轴对应的列，并用 $+90^\circ$ 检查另外两轴的方向，尤其是绕 $y$ 轴时的符号。

::: sol B2 核对
绕 $x,y,z$ 时，不动轴对应的列分别是 $(1,0,0)^{\mathrm T}$、$(0,1,0)^{\mathrm T}$、$(0,0,1)^{\mathrm T}$，相应行是其转置。按右手定则正转 $90^\circ$：绕 $x$ 有 $y\to z,z\to-y$；绕 $y$ 有 $x\to-z,z\to x$；绕 $z$ 有 $x\to y,y\to-x$。因此 $R_y$ 的 $(3,1)$ 元是 $-s_\beta$、$(1,3)$ 元是 $+s_\beta$。逆关系为 $R_k(-\vartheta)=R_k^{\mathrm T}(\vartheta)$。（[@note-2.2.Ry]）
:::

### B3 · 27 种组合里为什么只剩 12 种

说明取舍机制，并指出 ZYZ 与 RPY 的奇点各在什么条件。

::: sol B3 核对
相邻同轴旋转可合并，$ZXX$ 只剩两转，$XXX$ 只剩一个有效角，不能覆盖任意姿态。相邻不同轴的序列共 $3\times2\times2=12$ 种：6 种首末相同、6 种三轴互异；序列名还须配固定/当前轴约定。**奇点**：ZYZ 在 $\vartheta=0$ 只定 $\varphi+\psi$，在 $\pi$ 只定 $\varphi-\psi$；RPY 在 $+\pi/2$ 只定 $\varphi-\psi$，在 $-\pi/2$ 只定 $\varphi+\psi$。这不表示刚体真实自由度消失。（[2.4.1](sec2-4.md#sec-2.4.1)、[@thm-2.4.B]）
:::

### B4 · Atan2 的用途与边界

用一个例子说明 Atan2 如何判象限；写出输入半径与角度敏感度的关系。它能否消除欧拉角表示奇点？

::: sol B4 核对
$\operatorname{Atan2}(1,-1)=135°$，而 $\arctan(-1)=-45°$，因为比值丢失象限。对 $\alpha=\operatorname{Atan2}(y,x)$，$d\alpha=(x\,dy-y\,dx)/(x^2+y^2)$，梯度模为 $1/\rho$，$\rho=\sqrt{x^2+y^2}$。ZYZ 首末角的 $\rho=|\sin\vartheta|$，RPY 为 $|\cos\vartheta|$，趋零仍病态，原点无方向。$\arccos$ 可求预先选定的 $[0,\pi]$ 主支，不能独自判完整象限。（[@thm-2.4.A]）
:::


### B5 · 齐次链式变换与非正交性

写出两段连乘的旋转和平移块，并说明整体转置求逆何时成立。

::: sol B5 核对
$A_2^0=A_1^0A_2^1$，右侧先换 $2\to1$，再换 $1\to0$；块为 $R_1^0R_2^1$、$o_1^0+R_1^0o_2^1$。逆为 $[R^{\mathrm T},-R^{\mathrm T}o;0,1]$；$A^{\mathrm T}A=[I,R^{\mathrm T}o;o^{\mathrm T}R,1+o^{\mathrm T}o]$，故整体正交恰在 $o=0$ 时成立。不能把坐标系接口不相接的交换乘积当成同一换系链。（[@thm-2.7.A]、[@ex-2.7.C]）
:::

### B6 · 接口一致才能连乘

举出「接口一致」与「接口不一致」各一例，并说明不一致时怎么办。

::: sol B6 核对
斯坦福臂两段的系 3 原点、三轴一致，故 $T_6^0=T_3^0T_6^3$。单独拟人臂与球腕中同名的系 3 定义不同，必须按安装关系补常值接口变换，或对整臂重建系；重建后 $a_3$ 改由 $d_4$ 表示，$\alpha_3=\pi/2,\alpha_4=-\pi/2$，旧肘角 = 新肘角 $-\pi/2$。两类整臂均有 $p_w=p_6-d_6a_6$；腕心固定并不保证尖端固定。（[2.9.6](sec2-9.md#sec-2.9.6)、[2.9.7](sec2-9.md#sec-2.9.7)）
:::

### B7 · 标定何时需要迭代

写出一般非线性标定的三步，并说明一轮线性化的局限。若选定模型对未知参数本来就线性，还一定要反复迭代吗？

::: sol B7 核对
先固定建模规范和待估的可辨识参数子集。① 用当前参数计算量测残差与线性化矩阵；② 堆叠多组量测，统一单位或加权后，用 QR/SVD 求最小二乘更新量，同时检查列秩与条件数；③ 更新参数，重新计算预测、残差和线性化矩阵，直到达到停止准则，再用独立位形验证。

一般运动学模型对参数是非线性的，一轮线性化只在局部有效；若选定模型恰好对未知参数线性，则不一定需要反复迭代。$tm\ge p$ 只是方程数的必要条件，增加相同或近相关的量测不能代替可辨识性检查。符号与理论解见 C8。（[@method-2.11.steps]）
:::

### B8 · 工作空间与两种冗余

写出两个工作空间的包含关系与适用条件；解释 $n-r$ 何时成立，以及“关节域周界的像就是工作空间”为何错误。

::: sol B8 核对
可达工作空间是固定参考点的位置映射对**整个允许关节域**的像；灵活工作空间还要求指定方向集合中每一种方向都可实现，因此灵活 ⊆ 可达。有限闭关节盒紧且连通，连续像才可据此说闭、有界、连通；无界行程、开放限位、碰撞与分支须另看。轮廓候选既来自关节域边界，也来自内部临界位形；候选的像可能落在位置像内部。全转 2R 的内部水平线 $q_2=0$ 映到外圆。

$n$ 为独立关节数，$m$ 为结构适配的完整位姿维数，$r$ 为任务独立约束数。本质冗余 $n>m$；功能冗余可由放松任务到 $r<m$ 产生。任务行满秩的正常点，局部自由度为 $n-r$；一般瞬时核为 $n-\operatorname{rank}J_{\rm task}$。奇异点瞬时核变大不保证有限自运动，限位也不保证能被其他关节补偿。（[@def-2.10.2]、[@def-2.10.3]；[本节练习](sec2-10.md#practice-2.10)）
:::

## C. 公式卡

### C1 · 三个基本旋转（默写）

写出 $R_x,R_y,R_z$ 与负角关系。

::: sol C1 核对
$$R_x(\gamma)=\begin{bmatrix}1&0&0\\ 0&c_\gamma&-s_\gamma\\ 0&s_\gamma&c_\gamma\end{bmatrix},\quad
R_y(\beta)=\begin{bmatrix}c_\beta&0&s_\beta\\ 0&1&0\\ -s_\beta&0&c_\beta\end{bmatrix},\quad
R_z(\alpha)=\begin{bmatrix}c_\alpha&-s_\alpha&0\\ s_\alpha&c_\alpha&0\\ 0&0&1\end{bmatrix};$$
$$R_k(-\vartheta)=R_k^{\mathrm T}(\vartheta),\qquad k=x,y,z .$$
约定从转轴正端朝原点看，逆时针为正（右手定则）。先查不动轴对应的行/列，再查 $+90^\circ$ 的轴方向，最后用 $R_k(-\vartheta)=R_k^{\mathrm T}(\vartheta)$ 检查逆转。
:::

### C2 · ZYZ / RPY 的正解与逆解（第一支）

写出两种表示的正解乘积顺序与逆解三式（ZYZ 给第一支，RPY 给 $\vartheta\in(-\pi/2,\pi/2)$ 一支）。

::: sol C2 核对
**ZYZ 正解**：$R=R_z(\varphi)R_{y'}(\vartheta)R_{z''}(\psi)$（第三列 = $[c_\varphi s_\vartheta,\ s_\varphi s_\vartheta,\ c_\vartheta]^{\mathrm T}$）。**ZYZ 逆解（第一支，设 $s_\vartheta\ne0$）**：
$$\varphi=\operatorname{Atan2}(r_{23},r_{13}),\quad \vartheta=\operatorname{Atan2}\!\big(\sqrt{r_{13}^2+r_{23}^2},\,r_{33}\big),\quad \psi=\operatorname{Atan2}(r_{32},-r_{31});$$
第二支可取 $(\varphi+\pi,-\vartheta,\psi+\pi)$，首末角按周期规范；$\vartheta$ 式的 $r_{33}$ 不变号。
**RPY 正解**：$R=R_z(\varphi)R_y(\vartheta)R_x(\psi)$。**RPY 逆解**（$\vartheta\in(-\pi/2,\pi/2)$）：$\varphi=\operatorname{Atan2}(r_{21},r_{11})$、$\vartheta=\operatorname{Atan2}(-r_{31},\sqrt{r_{11}^2+r_{21}^2})$、$\psi=\operatorname{Atan2}(r_{32},r_{33})$。
RPY 第二支可取 $(\varphi+\pi,\pi-\vartheta,\psi+\pi)$，其中 $\vartheta$ 的 Atan2 只把第二个实参变号，$-r_{31}$ 保持不变。
**反解策略口诀**：**挑只含单个角度的元素——先 $\varphi$ 后 $\vartheta$ 再 $\psi$**（ZYZ 用第三列定 $\varphi,\vartheta$、第三行定 $\psi$）。（[2.4.4](sec2-4.md#sec-2.4.4)、[2.4.5](sec2-4.md#sec-2.4.5)）
:::

### C3 · Rodrigues 紧凑形式、指数映射与逆解

写出紧凑形式、两个幂次关系、$\exp$ 闭式，以及由 $R$ 求 $(\vartheta,\boldsymbol r)$ 的两式。

::: sol C3 核对
取单位轴 $\|\boldsymbol r\|=1$，记 $S=S(\boldsymbol r)$、$c=\cos\vartheta,s=\sin\vartheta$。$R=cI+(1-c)\boldsymbol r\boldsymbol r^{\mathrm T}+sS$；$S^2=\boldsymbol r\boldsymbol r^{\mathrm T}-I$、$S^3=-S$，非零幂四周期。$\exp(\vartheta S)=I+\sin\vartheta S+(1-\cos\vartheta)S^2$ 单值但非单射；指数坐标是三维向量 $\phi=\vartheta\boldsymbol r$。合法 R 的迹给余弦、反对称部分给 $v=\sin\vartheta\boldsymbol r$；主角可取 $\operatorname{atan2}(\|v\|,(\operatorname{tr}R-1)/2)$。零角取主向量 0；半圈用 $B=(R+I)/2$ 最大主元加交叉项恢复轴。一般姿态的 $\dot RR^{\mathrm T}\in so(3)$，$\dot R$ 通常不在其中。（[@thm-2.5.B]、[@thm-2.5.D]、[@thm-2.5.E]）
:::

### C4 · 四元数正解 / 逆解 / 逆 / 乘

写出四组公式。

::: sol C4 核对
**换算与约束**：$q=(\eta,\boldsymbol\epsilon)=(\cos(\vartheta/2),\sin(\vartheta/2)\boldsymbol r)$，$q^{\mathrm T}q=1$。**正解**：$R=(2\eta^2-1)I+2\boldsymbol\epsilon\boldsymbol\epsilon^{\mathrm T}+2\eta S(\boldsymbol\epsilon)$。**稳定逆解**：按 [@method-2.6.extract] 构造 $H=4qq^{\mathrm T}$，选最大 $H_{kk}$，取 $q_k=\sqrt{H_{kk}}/2$、$q_i=H_{ik}/(4q_k)$。精确半圈不能从反对称差定相对符号。**逆**：$Q^{-1}=\{\eta,-\boldsymbol\epsilon\}$。**乘**：$Q_1\otimes Q_2=\{\eta_1\eta_2-\boldsymbol\epsilon_1^{\mathrm T}\boldsymbol\epsilon_2,\ \eta_1\boldsymbol\epsilon_2+\eta_2\boldsymbol\epsilon_1+\boldsymbol\epsilon_1\times\boldsymbol\epsilon_2\}$，对应 $R_1R_2$，右侧 $Q_2$ 先作用。一般不可交换。
:::

### C5 · 齐次变换的逆

写出分块公式，并用一句话说明它为什么正确。

::: sol C5 核对
$$A_0^1=(A_1^0)^{-1}=\begin{bmatrix}R_1^{0\mathrm T}&-R_1^{0\mathrm T}\boldsymbol o_1^0\\ \boldsymbol 0^{\mathrm T}&1\end{bmatrix}
=\begin{bmatrix}R_0^1&-R_0^1\boldsymbol o_1^0\\ \boldsymbol 0^{\mathrm T}&1\end{bmatrix}.$$

**读法**：旋转块取转置，平移块**先反向、再左乘转置**。一句话验证：分块乘一次即得单位阵（左上用 $R^{\mathrm T}R=I$，右上两项恰好相消）。**边界**：方向向量（自由向量）的变换**只用左上块** $R$——自由向量不吃平移。
:::

### C6 · DH 关节变换 $A_i^{i-1}$

默写 $4\times4$ 矩阵，并指出第 4 列三个元素各对应哪个参数。

::: sol C6 核对
$$A_i^{i-1}(q_i)=\begin{bmatrix}
c_{\vartheta_i}&-s_{\vartheta_i}c_{\alpha_i}&s_{\vartheta_i}s_{\alpha_i}&a_ic_{\vartheta_i}\\
s_{\vartheta_i}&c_{\vartheta_i}c_{\alpha_i}&-c_{\vartheta_i}s_{\alpha_i}&a_is_{\vartheta_i}\\
0&s_{\alpha_i}&c_{\alpha_i}&d_i\\
0&0&0&1\end{bmatrix}.$$

第四列为 $(a_i\cos\vartheta_i,a_i\sin\vartheta_i,d_i,1)^{\mathrm T}$；旋转块 $R_z(\vartheta_i)R_x(\alpha_i)$ 是 $3\times3$，不能等同完整 A。纯转自检须 $a_i=\alpha_i=d_i=0$，拟人肩的 $\alpha_1=\pi/2$ 不属于此例。串接接口从右向左是 $e\to n\to0\to b$，左因子为系 0 在物理基座中的位姿。用[例 2.8.B](sec2-8.md#ex-2.8.B)和混合链练习复算。
:::

### C7 · 平面臂、拟人臂、球形腕的正运动学（结果默写）

各写一行位置部分，并指出球形腕旋转块的特别之处。

::: sol C7 核对
**平面臂**：$p=[a_1c_1+a_2c_{12}+a_3c_{123},a_1s_1+a_2s_{12}+a_3s_{123},0]^T$，朝向 $\phi=\vartheta_1+\vartheta_2+\vartheta_3$，不能遗漏。**拟人臂**：$p=[c_1(a_2c_2+a_3c_{23}),s_1(a_2c_2+a_3c_{23}),a_2s_2+a_3s_{23}]^T$；$z_2,z_3$ 同向但相隔 $a_3$。**球腕**：本表取 $\alpha_4=-\pi/2,\alpha_5=\pi/2$，由 $Q R_z(\vartheta_5)Q^{-1}=R_y(\vartheta_5)$ 得 $R_6^3=R_z(\vartheta_4)R_y(\vartheta_5)R_z(\vartheta_6)$，而 $p_6^3=d_6(c_4s_5,s_4s_5,c_5)^T$；共点本身不足以保证任意选系的角都等于 ZYZ。独立核对见[练习 2.9.B](sec2-9.md#ex-2.9.B)。
:::

### C8 · 标定方程与量测条件

写出线性化方程、最小二乘解与量测条件。

::: sol C8 核对
单个位形的局部模型为 $\Delta\boldsymbol x=\Phi\Delta\boldsymbol\xi$，其中 $\Phi\in\mathbb R^{m\times p}$。把 $t$ 个位形的矩阵和残差逐组堆叠，得 $\Phi^*\in\mathbb R^{tm\times p}$ 与 $\Delta\boldsymbol x^*\in\mathbb R^{tm}$。这里的星号表示堆叠，不是伪逆。对称正定权重 $W$ 用于统一残差尺度及量测精度：

$$\widehat{\Delta\boldsymbol\xi}=\operatorname*{argmin}_{u}\|W^{1/2}(\Phi^*u-\Delta\boldsymbol x^*)\|^2.$$

满列秩时，理论表达为 $(\Phi^{*\mathrm T}W\Phi^*)^{-1}\Phi^{*\mathrm T}W\Delta\boldsymbol x^*$；实现应对加权矩阵用 QR/SVD，不显式求这个逆。$tm\ge p$ 仅是必要条件，还须固定参数规范、检查列秩和条件数；比较条件数时须说明参数的单位与尺度。仅估 DH 子集时 $p\le4n$；若另加基座/工具参数，应重新计数并处理其不可辨识方向。

量测应在任务允许的区域提供足够不同的参数敏感方向，不能靠重复近似相同的位形消除病态；用未参与估计的位形检查预测误差。详见 [§2.11 练习](sec2-11.md#practice-2.11)。（[@method-2.11.steps]）
:::

## D. 陷阱卡（先指出错在哪，再给正确说法）

### D1 · 「$z_{i-1}$ 就是 $[0,0,1]^{\mathrm T}$」

::: sol D1 核对
**错在预设。** 基系轴向应取 $R_{i-1}$（$T_{i-1}^0$ 左上 $3\times3$ 块）的第三列；局部坐标中才按建系约定为 $[0,0,1]^{\mathrm T}$。平面臂平行轴的基系读数也可能恰好都等于该向量，一般空间链则须实际读取。$p_{i-1}$ 取 $T_{i-1}^0$ 的平移列；工具点 $p_e$ 须取 $T_e^0=T_n^0T_e^n$ 的平移列，不能漏掉固连工具偏置。（[3.1.3](../ch03/sec3-1.md#sec-3.1.3)）
:::

### D2 · 「$\det R$ 取 $\pm1$ 无所谓」

::: sol D2 核对
**错。** $\det R=-1$ 是**左手系**（含镜像翻转），不属于 $SO(3)$，用它算出来的是「照镜子」的假姿态。**理由**：正交性只给出 $(\det R)^2=1$；而右手系的固连坐标系总可以**连续**转回与参考系重合，$\det$ 是元素的连续函数、途中不可能从 $+1$ 跳到 $-1$，故右手系必为 $\det R=+1$。（[2.2.1](sec2-2.md#sec-2.2.1)）
:::

### D3 · 「$A^{\mathrm T}$ 就是 $A$ 的逆」

::: sol D3 核对
**一般不成立。** 非零平移时整个 A 不正交；平移为 0 时整体转置等于逆。始终可用分块逆 $[R^{\mathrm T},-R^{\mathrm T}o;0,1]$。右上块 $o_1^0$ 是系 1 原点在系 0 中的坐标；逆的平移 $-R^{\mathrm T}o_1^0$ 改用系 1 表示，通常不是直接取负。（[2.7.3](sec2-7.md#sec-2.7.3)）
:::

### D4 · 「姿态合成等于角度三元组逐分量相加」

::: sol D4 核对
**错。** 三个数可以逐分量相加，但这种加法可交换，不能代表一般不可交换的旋转合成。按相应轴约定乘矩阵，才得到合成姿态。在选定连续、避开奇点的角度分支上可做局部插值，也要处理周期与分支；它不是全局姿态空间的向量加法。（[2.3](sec2-3.md) 常见错误 1；[4.3.3](../ch04/sec4-3-3.md)）
:::

### D5 · 「$\arccos$ 反解角度最省事」

::: sol D5 核对
**先说明分支与输入。** 若已限定 $\vartheta\in[0,\pi]$，$\arccos$ 可以求这一主支，但单独的余弦不能判完整象限，且近 $\pm1$ 敏感。Atan2 同时读取正弦、余弦类信息，仍须检查输入半径：ZYZ 的 $\vartheta=0.01°$ 时，首末角敏感度约为 $1/\sin0.01°=5729.6$，不是处处稳定。（[@thm-2.4.A]）
:::


### D6 · 「四元数 $Q$ 与 $-Q$ 是漏了一个解」

::: sol D6 核对
**它们表示同一旋转。** 同步反号角轴参数合并成同一个 Q，但转角加 $2\pi$ 得到 −Q。非半圈姿态取 $\eta>0$ 可定符号；半圈时 $\eta=0$，单靠 $\eta\ge0$ 仍无法区分两符号，须额外约定。不能据此宣称全局唯一且连续。（[2.6](sec2-6.md)）
:::

### D7 · 「改取腕心后，可以直接沿用末端期望速度」（第三章预告）

::: sol D7 核对
**必须同时换算目标速度。** 取 $r=p_e-p_w$，两个点固连、所有分量同用基系，则 $v_e=v_w+\omega\times r$。所以 $v_w=v_e+S(r)\omega$，相应的完整六维雅可比满足

$$J_w=\begin{bmatrix}I&S(r)\\0&I\end{bmatrix}J_e.$$

左侧变换可逆、行列式为 1，保留完整雅可比的秩；当 J 为 $6\times6$ 方阵时也保留行列式。**$J_w$ 确实映射到腕心速度**，可以用于该点的速度求解；若任务原来指定工具点速度，就必须同时把目标改为 $[v_e+S(r)\omega;\omega]$，或先换回 $J_e$。例如 $r=(1,0,0)\ \mathrm m$、$\omega=(0,0,1)\ \mathrm{rad/s}$、$v_e=(0,2,0)\ \mathrm{m/s}$，则 $v_w=(0,1,0)\ \mathrm{m/s}$。只取位置行时，换点可能改变秩，不能照搬上述完整六维结论。回读 [§3.1 刚体两点速度与工具偏置](../ch03/sec3-1.md#sec-3.1.2)。
:::

### D8 · 「逆解解不出来就是算法有 bug」

::: sol D8 核对
先检查任务、坐标系和工具接口；本节球腕按 $p_w=p_e-d_6a_e$ 回退，一般工具须用其完整固连变换。再检查该结构的实数容许条件与允许关节域，例如 $|c_2|\le1$。位置超出可达空间可判无解；不属于针对整个方向集合定义的灵活空间，则不能据此否定某一个目标姿态，见 A8。

若容许条件成立，再看分母退化与支合并：例如球腕 $s_5=0$ 时应按 §2.4 的和/差关系处理连续解族。最后逐支回代并筛选限位；碰撞和从当前位形出发的连续路径若未包含在求解模型中，还须另外检查。（[2.12.1](sec2-12.md#sec-2.12.1)、[例 2.12.D](sec2-12.md#ex-2.12.D)）
:::
