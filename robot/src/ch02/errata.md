# 勘误与补注（对照原书、课件与教程体例）

本页汇总第二章在对照《机器人学：建模、规划与控制》（Siciliano 等，原书英文版及中译本）与课程配套课件时发现的符号约定差异、原书/课件勘误、严谨化补注及语音转写正字表，供习题对答案与跨教材对照时查验。第一章通用 OCR 字形勘误见[第一章勘误](../ch01/errata.md)。

## 一、课件与原书约定对照

<a id="errata-2.1"></a>

::: errata E2.1 · RPY 角名与转轴配对标反（[2.4.5](sec2-4.md#sec-2.4.5)）
原书英文版 §2.4.2 及课程课件曾把三行写成「绕 $x$ 轴转 $\psi$（yaw）、绕 $y$ 轴转 $\vartheta$（pitch）、绕 $z$ 轴转 $\varphi$（roll）」，将俯仰之外的两个航空标签调换了名称。其乘法矩阵 $R_z(\varphi)R_y(\vartheta)R_x(\psi)$ 与转轴分配正确，本教程统一按国际航空标准惯例订正名称：$\varphi$ 绕 $z$ 为**偏航（yaw）**、$\vartheta$ 绕 $y$ 为**俯仰（pitch）**、$\psi$ 绕 $x$ 为**滚转（roll）**。
:::

::: errata E2.2 · $\operatorname{Atan2}(y,x)$ 参数次序统一（[2.4.3](sec2-4.md#sec-2.4.3)） {#errata-2.2}
部分讲义标题曾出现 $\operatorname{Atan2}(x,y)$ 泛指记号。为与现代编程接口（如 Python `math.atan2(y, x)`、JavaScript `Math.atan2(y, x)`、C++ `std::atan2(y, x)`）保持严格一致，本教程全章统一写作 **$\operatorname{Atan2}(y,x)$**：第一宗量为纵坐标（$\sin$ 侧分量），第二宗量为横坐标（$\cos$ 侧分量）。禁止先相除取 $\arctan(y/x)$，以免丢失四象限符号并在横坐标为零时引发除零崩溃。
:::

::: note 选修与拓展范围界定
本教程完整覆盖原书第二章全部 12 节及课后重点习题：其中标准 DH、基本旋转矩阵、旋转合成、欧拉角、齐次变换、典型开链结构及闭式逆运动学属核心要求；单位四元数（[2.6](sec2-6.md)）、闭链处理（[2.8.3](sec2-8.md#sec-2.8.3)）、平行四边形与双臂类人系统（[2.9.2](sec2-9.md#sec-2.9.2)、[2.9.9](sec2-9.md#sec-2.9.9)）作拓展补充。具体考试要求以[范围声明](../preface-scope.md)为准。

## 二、数学严谨性与文献补注

::: errata E2.3 · 译者注保留与四元数覆盖辨析（[2.3](sec2-3.md)、[2.6](sec2-6.md)）
1. 原书 §2.3 例 2.3 讨论围绕固定坐标轴（而非当前轴）的合成差异，对应原书图 2.7。
2. §2.9.4 中 anthropomorphic arm 在机器人学中文规范译法为**拟人臂**（非早期直译“类人手”）。
3. §2.6 同步反号 $(\vartheta,\boldsymbol r)\to(-\vartheta,-\boldsymbol r)$ 在半角三角函数中自然映射到同一四元数，但这仅抵消角轴的符号镜像，$Q$ 与 $-Q$ 对 $SO(3)$ 的**拓扑 $2:1$ 双重覆盖**依然存在，在精确半圈（$\eta=0$）和球面插值（SLERP）前必须显式检验并对齐符号。
:::

<a id="errata-2.4"></a>

::: errata E2.4 · 标准 DH 与改进 DH 约定辨析（[2.8.2](sec2-8.md#sec-2.8.2)）
本教程全面采用**标准 DH（Standard DH）**：连杆系 $\{i\}$ 的 $z_i$ 沿关节 $i+1$ 轴线，且四基本步为 $\operatorname{Rot}_z(\vartheta_i)\operatorname{Trans}_z(d_i)\operatorname{Trans}_x(a_i)\operatorname{Rot}_x(\alpha_i)$。部分文献或仿真工具（如 Craig 教材 / Pinocchio / URDF 部分插件）采用**改进 DH（Modified DH）**，将 $\{i\}$ 的 $z_i$ 固连于关节 $i$ 轴线上，把 $a_{i-1},\alpha_{i-1}$ 的 $x$ 轴因子放到左端。跨书核对矩阵时，不可只比对表格数值，必须先确认建系位置、下标归属与乘法次序，并配合固定物理安装变换 $T_0^b, T_e^n$ 检验最终 $T_e^b$。
:::

::: errata E2.6 · Pieper 闭式逆解条件文献溯源（[2.12.3](sec2-12.md#sec-2.12.3)） {#errata-2.6}
定理 2.12.B「连续三根转动关节轴相交于同一点或互相平行，则 6-DOF 串联臂存在解析闭式逆解」出自 D. L. Pieper 于 1968 年提交的斯坦福博士学位论文 *The Kinematics of Manipulators under Computer Control*（Stanford AI Memo AIM-72）。原书未在正文给出完整文献出处，特此补注。
:::

<a id="errata-2.7"></a>

::: note E2.7 · 四元数符号提取公式在精确半圈（$\eta=0$）的失效反例（[2.6.2](sec2-6.md#sec-2.6.2)）
原书 §2.6 式 2.34–2.35 采用 $\operatorname{sgn}(r_{32}-r_{23})$ 等反对称差恢复四元数矢量 $\boldsymbol\epsilon$ 的符号，并约定 $\operatorname{sgn}(0)=+1$。在精确半圈 $\vartheta=\pi$（即 $\eta=0$）时 $R$ 必为对称阵（$R-R^{\mathrm T}=0$），全部非对角差归零，原公式把一切负交叉项强制判作正号。例如取绕轴 $\frac{1}{\sqrt{2}}(1,-1,0)^{\mathrm T}$ 旋转 $\pi$ 给出 $R=\begin{bmatrix}0&-1&0\\-1&0&0\\0&0&-1\end{bmatrix}$，原公式给出 $(0,\frac{1}{\sqrt{2}},\frac{1}{\sqrt{2}},0)$ 而重建出 $+1$ 反号误差。本教程统一改为 [方法 2.6.extract](sec2-6.md#method-2.6.extract) 中基于 $H=4\boldsymbol q\boldsymbol q^{\mathrm T}$ 最大对角主元与对称项符号的提取算法，彻底消除 $\eta=0$ 奇异。
:::

::: note E2.8 · 工作空间连通性、边界来源与奇异零空间适用范围（[2.10](sec2-10.md)） {#errata-2.8}
1. 仅当关节可行域 $\mathcal Q$ 为**有界闭集且连通**时，连续位置像 $\mathcal W_R=\boldsymbol p_e(\mathcal Q)$ 才保证是紧连通集。
2. [例 2.6](sec2-10.md#ex-book-2.6) 中的曲线 $q_2=0$ 在全周转关节空间矩形内部，映成工作空间外圆边界；不可误将全周周期接缝 $q_1=\pm\pi$ 画成外边界，也不可误称内部直线为“对角线”。
3. 瞬时微动零空间维数公式一般为 $n-\operatorname{rank}\boldsymbol J_{\mathrm{task}}$（$n-r$ 仅对行满秩非奇异点成立）；且在如伸直平面 2R 等奇异构型处，一阶零空间存在非零向量并不意味着存在有限自运动流形。
:::

<a id="errata-2.11"></a>

::: errata E2.11 · 运动学标定的独立未知参数上界 $p\le 4n$（[2.11.1](sec2-11.md#sec-2.11.1)）
原书把 DH 表整体写作 $4n$ 个参量进而写必要条件 $tm\ge 4n$，易使读者误以为所有 $4n$ 个表项皆须或皆可独立标定。实际上每个单自由度关节中总有 1 个为已测编码器变量，且基座共轴偏置或末杆非可控参数可能互相关联导致不可辨识。严格未知数个数记为有效可观参数维数 $p\le 4n$（加计外参 $T_0^b, T_e^n$ 后据可观性独立计数），必要采样条件为 $lm\ge p$ 且要求堆叠矩阵 $\bar{\boldsymbol\Phi}$ 列满秩、条件数良好。
:::
