## 一、课件问题（课堂 PPT 对照英文原版）

<a id="errata-2.1"></a>

::: errata E2.1 · RPY 角名与转轴配对标反（课件沿袭英文原版，约 18:49 页）
课件把三行定义写成「绕 $x$ 轴旋转 $\psi$（**偏航角**）、绕 $y$ 轴旋转 $\vartheta$（俯仰角）、绕 $z$ 轴旋转 $\varphi$（**滚动角**）」。核对英文原版 §2.4.2，**原书自己也把这两个标签写反**（原文作 "the angle $\psi$ about axis $x$ (yaw)"、"the angle $\phi$ about axis $z$ (roll)"），课件沿袭了原书。按航空标准惯例应为：$\varphi$ 绕 $z$ 为**偏航（yaw）**、$\vartheta$ 绕 $y$ 为**俯仰（pitch）**、$\psi$ 绕 $x$ 为**滚转（roll）**。矩阵本身（$R_z(\varphi)R_y(\vartheta)R_x(\psi)$）与转轴指派无误，仅角名标签错位。本教程按航空惯例订正收录（[2.4.5](sec2-4.md#sec-2.4.5)）。
:::

::: errata E2.2 · Atan2 的参数序写法（课件 2.4.1 节，约 15:02 页）
课件写「双变量的反正切函数 $\operatorname{Atan2}(x,y)$」，而原书脚注与全部用式（如 $\varphi=\operatorname{Atan2}(r_{23},r_{13})$）的约定是 $\operatorname{Atan2}(y,x)$ 计算 $y/x$ 的反正切、以两参数符号定象限——**第一个参数是「分子」**。课件的 $(x,y)$ 只是泛指两个变量，不代表参数顺序；动手实现时务必以所用的语言为准（MATLAB / Python `atan2(y, x)`，即「分子在前」）。
:::

::: note 课件编号跳空的说明（非错误）
课件节号依次为 2.3、2.4、2.5、2.7、2.8、2.9、2.10、2.11、2.12——**缺 2.6（单位四元数）**，属课程裁剪而非编号笔误；2.9 小节从 2.9.1 直接跳 2.9.3（缺平行四边形臂）、无 2.9.9（类人机械手）、2.8 无 2.8.3（闭链，老师明确「闭链我们不讲」）。以上四处**课件未授**，本编已按原书补入正文并标注「教材补充 · 课程未授」（[2.6](sec2-6.md)、[2.8.3](sec2-8.md#sec-2.8.3)、[2.9.2](sec2-9.md#sec-2.9.2)、[2.9.9](sec2-9.md#sec-2.9.9)），以保章节完整；考试不作要求。详见[范围声明](../preface-scope.md)。
:::

## 二、中文版译文问题（对照英文原版）

::: errata E2.3 · 译者注保留与正字
原书中文版在三处自加「似有误——译者注」，本教程沿用英文原版为准：(a) [2.3 小结前](sec2-3.md#sec-2.3.2) 的例 2.3「在相对当前（应为固定，原文似有误——译者注）坐标系进行旋转的情形」——对照英文版，此段比较的正是**固定轴**情形（原书图 2.7）；(b) §2.9.4「从这个角度说，平行四边形臂（似应为拟人臂——译者注）可以用于两连杆平面臂的场合」——英文版为 *anthropomorphic arm*，中文版误植；(c) §2.6「绕 $-\boldsymbol r$ 旋转 $-\vartheta$ 的四元数与绕 $\boldsymbol r$ 旋转 $\vartheta$ 的四元数是**一样**的」——译者注「似有误」判断错了：英文原版明写 *a rotation by $-\vartheta$ about $-\boldsymbol r$ gives the **same** quaternion …; this solves the above nonuniqueness problem*，代入半角公式两组参数确映到**同一**四元数，这正是四元数消除角和轴表示不唯一的机制（见 [原理 2.6.A](sec2-6.md#thm-2.6.A)）。
:::

<a id="errata-2.4"></a>

::: errata E2.4 · DH 约定与「改进 DH」的辨析（补注，非错误）
原书与课件采用**标准（经典）DH 约定**：$z_{i-1}$ 沿**关节 $i$** 的轴、$x_i$ 沿相邻 $z$ 轴的公垂线（[2.8.2](sec2-8.md#sec-2.8.2)）。部分教材（如 Craig《机器人学导论》）用**改进 DH**：$z_i$ 就沿关节 $i$ 的轴、变换次序为「先转 $\alpha$ 后转 $\vartheta$」，参数表整列不同。读文献遇到 DH 表「对不上」时，先查约定再怀疑自己；两种约定对同一机械手给出不同的 $(a_i,\alpha_i,d_i,\vartheta_i)$ 但同一个 $T_n^0$。
:::

::: errata E2.6 · Pieper 闭解条件补注（[2.12.3](sec2-12.md#sec-2.12.3) 文献注） {#errata-2.6}
「三轴交于一点或三轴平行则 6 自由度机械手存在闭式逆解」的充分条件出自 D. L. Pieper 博士学位论文 *The Kinematics of Manipulators under Computer Control*（Stanford AI Memo AIM-72 / Stanford CS 机器人学系列，1968）——录播 2:02:06 老师所说「一个博士（论文）里给出的条件」即指此。该文系统研究了带球形腕 / 平行三轴结构的逆运动学，是「臂 + 腕」解耦设计的理论源头；原书未给文献条目，特此补注。
:::
