# 勘误与补注（对照原书与课件）

本编的对照对象有三个：**原书中文版**（OCR 扫描版）、**原书英文版** *Robotics: Modelling, Planning and Control*、**课程课件**（智学北航平台 251 张场景图）。三方互勘的结果如下；第 1 章的通用 OCR 字形错误（机械于 / 主复精度之类）见[第一章勘误](../ch01/errata.md)，不再重复。

## 一、课件问题（课堂 PPT 对照英文原版）

<a id="errata-2.1"></a>

::: errata E2.1 · RPY 角名与转轴配对标反（课件沿袭英文原版，约 18:49 页）
课件把三行定义写成「绕 $x$ 轴旋转 $\psi$（**偏航角**）、绕 $y$ 轴旋转 $\vartheta$（俯仰角）、绕 $z$ 轴旋转 $\varphi$（**滚动角**）」。核对英文原版 §2.4.2，**原书自己也把这两个标签写反**（原文作 "the angle $\psi$ about axis $x$ (yaw)"、"the angle $\phi$ about axis $z$ (roll)"），课件沿袭了原书。按航空标准惯例应为：$\varphi$ 绕 $z$ 为**偏航（yaw）**、$\vartheta$ 绕 $y$ 为**俯仰（pitch）**、$\psi$ 绕 $x$ 为**滚转（roll）**。矩阵本身（$R_z(\varphi)R_y(\vartheta)R_x(\psi)$）与转轴指派无误，仅角名标签错位。本教程按航空惯例订正收录（[2.4.5](sec2-4.md#sec-2.4.5)）。
:::

::: errata E2.2 · Atan2 的参数序写法（课件 2.4.1 节，约 15:02 页）
课件标题写 $\operatorname{Atan2}(x,y)$，容易让读者把参数次序读反；不能仅凭这一标题认定它只是泛指变量。本文与反解用式统一按 $\operatorname{Atan2}(y,x)$：求向量 $(x,y)$ 的方向，先传纵坐标、后传横坐标，利用各自符号判象限。实现时核对具体接口；本节脚本使用 JavaScript 的 `Math.atan2(y, x)`。不要先除出 $y/x$，否则会丢失象限并在 $x=0$ 处引入除零。
:::

::: note 课件编号跳空的说明（非错误）
本编保留原书的单位四元数、闭链、平行四边形臂与类人分支模型（[2.6](sec2-6.md)、[2.8.3](sec2-8.md#sec-2.8.3)、[2.9.2](sec2-9.md#sec-2.9.2)、[2.9.9](sec2-9.md#sec-2.9.9)）。现有课堂截图不足以证明完整授课或考试范围；本轮未核实的录播引语不作范围证据，具体要求以实际课程通知为准。原书补充与本编练习会在正文分别说明，详见[范围声明](../preface-scope.md)。
:::

## 二、中文版译文问题（对照英文原版）

::: errata E2.3 · 译者注保留与正字
原书中文版三处译者注需区分：(a) §2.3 例 2.3 比较的是固定轴情形，见原书图 2.7；(b) §2.9.4 的 anthropomorphic arm 应译“拟人臂”；(c) §2.6 同步反号的角轴参数确实映到同一个四元数，可直接代入半角公式核验。但这只合并了该组重复参数，不能推广成“四元数没有不唯一性”：$Q\sim-Q$ 双重覆盖仍在，半圈 $\eta=0$ 还需额外定符号。
:::

<a id="errata-2.4"></a>

::: errata E2.4 · DH 约定与「改进 DH」的辨析（补注，非错误）
本书标准 DH 取关节 $i$ 沿 $z_{i-1}$，四因子依次为 $\operatorname{Rot}_z(\vartheta_i)\operatorname{Trans}_z(d_i)\operatorname{Trans}_x(a_i)\operatorname{Rot}_x(\alpha_i)$。常见改进约定把 x 方向的固定变换放到前面，且可能将杆长、扭角标为 $i-1$；须核对整套定义，不能只换下标。不同选系的 $T_n^0$ 未必相同；统一物理基座、工具与关节零位，并同步串接矩阵后，$T_e^b$ 才一致。见[§2.8 特殊情形](sec2-8.md#note-2.8.dh-cases)。
:::

::: errata E2.6 · Pieper 闭解条件补注（[2.12.3](sec2-12.md#sec-2.12.3) 文献注） {#errata-2.6}
「三轴交于一点或三轴平行则 6 自由度机械手存在闭式逆解」的充分条件出自 D. L. Pieper 博士学位论文 *The Kinematics of Manipulators under Computer Control*（Stanford AI Memo AIM-72 / Stanford CS 机器人学系列，1968）——录播 2:02:06 老师所说「一个博士（论文）里给出的条件」即指此。该文系统研究了带球形腕 / 平行三轴结构的逆运动学，是「臂 + 腕」解耦设计的理论源头；原书未给文献条目，特此补注。
:::

::: note E2.8 · 两空间与工作空间的适用条件补充 {#errata-2.8}
原书 §2.10 印刷 83–88 页中，方向分量一般无封闭式、连续像闭有界连通，以及边界曲面类型的表述需补条件。本教程在 [§2.10](sec2-10.md) 明确：DH 正解可显式连乘，欧拉角可在分支非奇异域显式提取；有限闭且连通的关节盒，连续位置像才据此为紧连通集；典型曲面不能穷尽一般约束的轮廓。

原书例 2.6 的作图同时考虑关节边界和伸直线段 ad。教程旧稿把 ad 叫“对角线”、把一般限位图画成全转圆环、把周界像直接当成整个工作空间，均已纠正。现在图区分关节域边界与内部临界候选，并另标全转假设。瞬时核维数一般为 n−rank J，n−r 只适用于任务行满秩；这也不能保证在限位或奇异点存在有限自运动。
:::

<a id="errata-2.11"></a>

::: errata E2.11 · 标定未知数不是固定的 $4n$
原书把 DH 四列写成 $4n$ 个表项，容易被读成「有 $4n$ 个都能独立估计的物理常数」，并据此把量测条件写成 $tm\ge4n$。严格说，R 行的 $\vartheta_i$、P 行的 $d_i$ 通常是当前关节读数，固定项、已知项以及不可辨识的参数组合也应删去；实际标定未知数记为 $p\le4n$，必要条件是 $tm\ge p$，此外还要检查 $\operatorname{rank}\Phi=p$、条件数和独立验证误差。$4n$ 仍可作为教材上限记号，但不能替代参数选择与可辨识性分析。
:::

::: note E2.7 · 四元数符号提取在精确半圈失效
英文原书 §2.6 印刷 54–55 页式 2.34–2.35 用反对称差的符号恢复向量分量，并约定 sgn(0)=+1。但半圈时 η=0、R−Rᵀ=0，三个差无法提供相对符号。取轴 (1,−1,0)/√2，精确矩阵为 [[0,−1,0],[−1,0,0],[0,0,−1]]；原式给出 (0,1/√2,1/√2,0)，重建的两个非对角元素变成 +1，最大元素差为 2。

该符号公式须限定在 η>0；精确半圈改从对称交叉项恢复相对符号。本编使用 H=4qqᵀ 的最大分量法，避免除以趋零的标量，详见 [§2.6 反例和稳定提取](sec2-6.md#method-2.6.extract)。这是原书公式适用范围的勘误；浮点 cos(π/2) 的残留不能当作边界正确性的证据。
:::
