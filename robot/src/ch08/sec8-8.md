# 8.8 综合算例：平面打磨时同时控力与控速

前面各节分别建立了接触力符号、串联弹性、内环力控与互易选择矩阵。本节用一套自包含的数值算例把这些工具串在一条设计线上：给定一个平整水平工件表面的三维平动打磨任务，亲手写出选择矩阵、闭合速度型直接力环、计算接触力上升时间常数，并检验刚度估计不准时系统如何变化。（注：本算例参数为配合教学设计的示例数字，非物理样机实测报告。）

<a id="sec-8.8.1"></a>

## 8.8.1 构造约束坐标系与平动选择矩阵

设工件为一水平光滑平板，在约束坐标系 $\{C\}$ 中取 $x_C, y_C$ 轴贴合工件表面，取 $+z_C$ 轴沿**工具压向工件表面内部**的方向。假设不计切向摩擦且保持持续面接触，接触点附近法向等效接触刚度为 $k_e = 2.0\times 10^4\,\mathrm{N/m}$。任务要求工具仅控制三维平动：沿 $x_C$ 以恒速 $v_{x,d} = 0.04\,\mathrm{m/s}$ 前进打磨，沿 $y_C$ 保持横向定位速度为零（$v_{y,d} = 0$），同时沿 $+z_C$ 维持法向压紧力 $f_{z,d} = 20\,\mathrm N$。

::: ex 例 8.8.1 · 平面打磨任务的完整闭环设计 {#ex-8.8.1}
**第一步：划分三维平动选择矩阵。** 仅考虑线速度 $\boldsymbol{v}_e^C = [v_x,\,v_y,\,v_z]^{\mathrm T}$ 与线力 $\boldsymbol{f}_e^C = [f_x,\,f_y,\,f_z]^{\mathrm T}$：$x_C, y_C$ 轴无切向支承反力，归运动子空间；$z_C$ 轴受板面阻挡无法继续穿透，归力子空间。因此

$$S_f = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}, \qquad S_v = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{bmatrix}, \qquad S_f^{\mathrm T}S_v = \begin{bmatrix} 0 & 0 \end{bmatrix}.$$

若完整任务还需要约束姿态（例如防止砂轮倾斜或要求盘面绕 $z_C$ 自转），必须扩展至 6 维，按 [8.6.2 节](sec8-6.md#sec-8.6.2) 补齐角速度与力矩列。

**第二步：建立速度型力闭环与一阶接触动态。** 记 $x$ 为沿 $+z_C$ 方向压入工件表面的局部弹性压缩量，则法向接触力（工具对工件）为 $f_e = k_e x$。对法向采用理想速度内环跟踪的**比例直接力外环**，设期望法向力 $f_d = 20\,\mathrm N$、速度力环比例增益 $k_f = 10^{-4}\,\mathrm{m/(N\cdot s)}$：

$$\dot x = k_f(f_d - f_e).$$

在不脱离表面（$x \ge 0$）、不触及速度饱和且表面刚度 $k_e$ 保持局部不变时，对接触力方程求时间导数 $\dot f_e = k_e\dot x$ 并代入速度指令，得一阶常微分闭环方程：

$$\dot f_e = k_e k_f(f_d - f_e).$$

代入数值算得**闭环等效时间常数** $\tau$ 与**极点频率**：

$$k_e k_f = (2.0\times 10^4)\times 10^{-4} = 2.0\,\mathrm{s^{-1}} \implies \tau = \frac{1}{k_e k_f} = 0.5\,\mathrm s.$$

**第三步：求解零初始接触力响应曲线与关键点。** 当工具刚刚好接触平板表面时（$f_e(0) = 0\,\mathrm N$），上述一阶系统的解析解为：

$$f_e(t) = f_d\bigl(1 - e^{-t/\tau}\bigr) = 20\bigl(1 - e^{-2t}\bigr)\,\mathrm N.$$

- **初始瞬间压入速度**：$\dot x(0) = k_f f_d = 10^{-4}\times 20 = 0.002\,\mathrm{m/s} = 2\,\mathrm{mm/s}$；
- **经过一个时间常数（$t = 0.5\,\mathrm s$）**：$f_e(0.5) = 20(1 - e^{-1}) \approx 20\times 0.6321 = 12.64\,\mathrm N$；
- **经过三个时间常数（$t = 1.5\,\mathrm s$）**：$f_e(1.5) = 20(1 - e^{-3}) \approx 20\times 0.9502 = 19.00\,\mathrm N$，接近 $20\,\mathrm N$；
- **稳态最终压入量**：$x_\infty = f_d / k_e = 20 / (2.0\times 10^4) = 1.0\,\mathrm{mm}$（由速度环自然达到，无需提前知道板面精准高度）。

**第四步：检验环境刚度变化对响应时间的影响。** 若实际接触区材料比名义估计偏软一半（真实刚度降至 $k_e' = 1.0\times 10^4\,\mathrm{N/m}$），在相同控制增益 $k_f = 10^{-4}\,\mathrm{m/(N\cdot s)}$ 下，乘积减半而时间常数**翻倍**至 $\tau' = 1/(k_e' k_f) = 1.0\,\mathrm s$；反过来若工件比估计硬一倍，时间常数减半至 $0.25\,\mathrm s$，甚至可能超越底层速度内环带宽而引发超调颤振。可见，力环响应快慢由**真实环境刚度与控制增益的乘积 $k_e k_f$** 共同支配。

## 8.8.2 从算例复核力控设计的五项基本检查

实际部署上述平面打磨控制器时，不能把一阶理想指数解直接等同于真机响应。工程上每次调参前，按以下五步依次过一遍设计检查表：

1. **符号与作用对象**：确认此处 $f_e > 0$ 代表工具向工件 $+z_C$ 施加压紧力；若六维力传感器向上报给驱动器的数值定义是“工件反向顶起工具的力”，送入 $f_d - f_e$ 减法器前必须先取反。
2. **指令可行性**：确认期望法向力 $f_d = 20\,\mathrm N$ 指向物理平面可承载的推压半空间（单边无粘附表面不可给定拉力），且切向滑行速度 $0.04\,\mathrm{m/s}$ 位于机器臂可达工作空间速度与加速能力包络内。
3. **几何对齐检查**：一旦工件相对世界坐标系斜放，必须先将测量力与速度指令统一旋入对齐局部法线/切面的约束坐标系 $\{C\}$ 中再左乘 $S_f, S_v$；绝不能让全球垂直 $z$ 轴直接充当法线。
4. **物理假设破裂点**：干摩擦会在 $x_C$ 切向额外消耗驱动力（须交给速度环积分或摩擦前馈），碰撞高速初触瞬间可能触发弹跳脱开（此时 $f_e = 0$，一阶线性微分方程立刻失效），而关节速度限幅也会拉长响应时间。
5. **全闭环稳定性检验**：本节的一阶时间常数 $\tau = 1/(k_e k_f)$ 忽略了机械臂连杆惯性 $m_d$、内环速度跟踪延迟、低通滤波相位滞后和离散控制采样周期。真机场景上，若味提高增益 $k_f$ 以期加快收敛，当 $\tau$ 被压近底层速度环响应时间时，二阶或多阶相位滞后会迅速把单调收敛的一阶指数变成强烈振荡。

## 8.8 小结与常见错误

- **完整串联流程**：选定局部约束坐标系 $\{C\}$ $\to$ 列出选择矩阵 $S_f, S_v$ $\to$ 在运动子空间跟速度、力子空间套速度型直接力控 $\dot x = k_f(f_d - f_e)$ $\to$ 由 $k_e k_f$ 核算时间常数 $\tau = 1/(k_e k_f)$。
- **核心规律**：直接力控的响应速度取决于**接触刚度 $\times$ 控制增益**。估计刚度偏大或工件变软都会显著拖慢收敛；一味调高增益会挤压内环相位裕度与放大测力噪声。

::: think 常见错误清单 · 自查三条
1. 只看控制增益 $k_f$ 而忽视环境刚度 $k_e$：同一增益换了塑料工件和钢工件，时间常数会相差一个数量级。
2. 忘记确认力传感器报送正方向：工具对工件（$+z_C$）与工件对工具方向相反，符号未对齐会瞬间向后撤飞或往里猛撞。
3. 以为打磨就是一阶响应不会振荡：只要加上内环带宽限制、滤波器延迟或数字采样周期，一阶极点立刻变高阶振荡系统。
:::
