# 第八章 · 力控制

第七章把机械臂当成在自由空间里运动的机构：给定期望轨迹 $\boldsymbol{x}_d(t)$，控制器只关心如何把跟踪误差压小。一旦末端执行器接触工件——例如打磨曲面、将轴插入孔中或拧紧螺钉——参考轨迹只要因标定误差落进表面内部 $1\,\mathrm{mm}$，对刚度 $k_e = 10^5\,\mathrm{N/m}$ 的金属面就会产生 $\Delta f_e = 100\,\mathrm N$ 的接触力冲击。纯位置控制器越努力消除位置误差，撞击越严重。

要把机械臂从“尽量走准”改造成“安全且可控地与环境交互”，必须先统一接触力的作用对象与符号约定，再按任务需要设计平衡关系、过渡动态、直接力反馈或约束子空间分工。

## 按控制目标划分的四条路线

不能仅凭“是否安装了六维力/力矩传感器”来区分力控制方案。阻抗与导纳控制同样可以引入实测力信号，但它们建立的是**力与运动之间的动态关系**；直接力控制才把接触力误差 $\boldsymbol{h}_d - \boldsymbol{h}_e$ 作为被调节目标。

| 控制策略 | 直接建立的闭环目标 | 适用场景与核心检查点 | 本章入口 |
|:--|:--|:--|:--|
| **被动柔顺 / 主动柔顺** | 静态弹性关系 $\boldsymbol{h}_A = K_P\boldsymbol{e}$ | 依靠串联双弹簧达成允许让步的静态平衡，须结合环境刚度分析压入与接触力 | [8.2 柔顺控制](sec8-2.md) |
| **阻抗控制 / 导纳控制** | 二阶动态关系 $M_d\ddot{\tilde{\boldsymbol{x}}} + D_d\dot{\tilde{\boldsymbol{x}}} + K_P\tilde{\boldsymbol{x}} = \boldsymbol{h}_A$ | 控制撞击瞬间的加速度、阻尼与过渡振荡；导纳由测力生成内环运动参考 | [8.3 阻抗与导纳](sec8-3.md) |
| **直接力控制** | 使实测力趋近给定力 $\boldsymbol{h}_e \to \boldsymbol{h}_d$ | 恒力按压或抛光；稳态是否无偏取决于位置内环/速度内环与积分项 | [8.4 直接力控制](sec8-4.md) |
| **混合力/运动控制** | 互易子空间解耦：约束法向控力、自由切向控运动 | 沿已知几何表面滑行与加压；前提是正确划分自然约束与人工约束 | [8.5 约束运动](sec8-5.md) – [8.7 混合力/运动控制](sec8-7.md) |

## 本章结构与学习路线

- [8.1 接触任务与力的约定](sec8-1.md)：给出局部弹性接触模型、$\boldsymbol{h}_e$（机械手对环境）的符号约定与含接触动力学方程 $\boldsymbol{u} - J^{\mathrm T}\boldsymbol{h}_e$，用瞬时功率配对校验广义力坐标变换 $\boldsymbol{h}_A = T_A^{\mathrm T}\boldsymbol{h}_e$。
- [8.2 柔顺控制：两个刚度决定平衡](sec8-2.md)：推导主动柔顺静力平衡、大转角相对位姿误差 $\boldsymbol{e}_d$ 的必要性，以及串联双弹簧模型（先看[单轴接触平衡](sec8-2.md#sec-8.2.balance)的数值表）。
- [8.3 阻抗与导纳：设计接触的过渡过程](sec8-3.md)：分析无测力补偿时的惯量耦合 $M_d B_A^{-1}\boldsymbol{h}_A$、同一阻尼参数面临更硬表面时阻尼比下降的反直觉现象（见[两种刚度算例](sec8-3.md#sec-8.3.example)），以及导纳控制“测力 $\to$ 虚拟参考 $\to$ 内环跟踪”的结构。
- [8.4 直接力控制：把力误差闭环](sec8-4.md)：对比位置内环（比例必有稳态误差，加积分需满足三阶 Routh 条件）与速度内环（理想比例无偏）的稳态差异，给出并联力/位置控制的相容条件 $f_d = k_e(x_d - x_r)$。
- [8.5 约束运动：接触允许哪些速度和力](sec8-5.md)：由完整约束 $\boldsymbol{\phi}(\boldsymbol{q})=\boldsymbol{0}$ 导出约束雅可比 $J_\phi$、虚功互易性，以及力与速度子空间 $S_f^{\mathrm T} S_v = O$。
- [8.6 控制方向的选择：自然约束和人工约束](sec8-6.md)：在约束坐标系 $\{C\}$ 中按四步法判定六维自然约束与人工目标，重点掌握平面滑动的 $6\times 3$ 选择矩阵构造方法。
- [8.7 混合力/运动控制](sec8-7.md)：通过操作空间逆动力学解耦两个互补子空间，讨论力导数放大噪声的刚度估计替代法与时变几何附加项 $\dot S_v\boldsymbol{\nu}$。
- [8.8 综合算例：平面打磨时同时控力与控速](sec8-8.md)：将约束坐标系、选择矩阵与一阶速度型力环串联为完整的可算闭环算例。

本章重点作业（教材第 9 章习题 **9-7 必做**，**9-3 / 9-10 任选一题**）解析与仿真验证见[作业八](homework08.md)；章末配套[习题](exercises.md)、[检验清单](checklist.md)、[回忆卡片](recall-cards.md)、[模拟测验](mock-exam.md)与[符号对照说明](errata.md)。

## 记号与预备知识

本章对应 Siciliano 等《Robotics》第 9 章（§9.1–§9.7）。全章统一记 $\boldsymbol{h}_e = [\boldsymbol{f}_e^{\mathrm T},\,\boldsymbol{\mu}_e^{\mathrm T}]^{\mathrm T}\in\mathbb R^6$ 为**机械手末端执行器施加给环境**的广义接触力（单位 $\mathrm N$、$\mathrm{N\cdot m}$，均先统一到同一坐标系再做矩阵乘法）；环境对机械手的反作用力则为 $-\boldsymbol{h}_e$。预备工具见[静力学与虚功](../ch03/sec3-8.md)、[操作空间动力学](../ch06/sec6-7.md)与[操作空间运动控制](../ch07/sec7-4.md)。
