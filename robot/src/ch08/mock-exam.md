# 综合自测卷 · 第八章 力控制

> **时间 90 分钟 · 满分 100**。闭卷，只允许带一张手写 A4 公式纸。
> 分值按「接触建模 20 + 柔顺与阻抗 25 + 直接力控制 25 + 约束与混合控制 30」分配。
> 建议先做 1、2，再做 4、6，最后做 5、7。

## 一、接触建模（20 分）

**1.（10 分）** 写出含接触的动力学方程，说明 $\boldsymbol h_e$ 的方向约定；用功率等式说明
$J^{\mathrm T}$ 映射的正确性，并解释为什么符号约定改变时整个模型和控制律要一起改。

::: note 一、参考答案
**1.** $B(q)\ddot q+C\dot q+F\dot q+\boldsymbol g(q)=u-J^{\mathrm T}(q)\boldsymbol h_e$，
$\boldsymbol h_e$ 为**机器人施加给环境**的六维力/力矩（环境反作用为 $-\boldsymbol h_e$）。（3 分）
功率检查：$v_e=J\dot q$，$\dot q^{\mathrm T}J^{\mathrm T}\boldsymbol h_e=\boldsymbol v_e^{\mathrm T}\boldsymbol h_e$，
两边都是机器人向环境输出的瞬时机械功率，故 $J^{\mathrm T}$ 是唯一与功率一致的映射。（4 分）
若改把传感器读数定义为环境作用在机器人上的力，方程右端变 $+J^{\mathrm T}\boldsymbol f_{\mathrm{env}}$，
控制律中的补偿项同步变号；只改控制律不改模型会把负反馈变成正反馈。（3 分）
（[8.1.2](sec8-1.md#sec-8.1.2)）
:::

**2.（10 分）** $k=10^5\ \mathrm{N/m}$ 的接触表面，位置估计偏差 $1\ \mathrm{mm}$ 对应多大的力变化？
由此说明为什么「位置控制得好」不等于「接触力可控」。这个弹簧模型在什么情况下失效？

::: note 参考答案
**2.** $\Delta f=k\,\Delta x=100\ \mathrm N$。（3 分）
位置控制器把 $\Delta x$ 压得再小，接触刚度大时力的变化依然可观；接触任务要求控制的量
（力）与位置控制器控制的量（位置）不同，需要改变目标的描述方式。（4 分）
失效情形：脱离表面（应取 $f_e=0$，不能沿用负弹簧）、刚性接触、摩擦与接触切换。
（3 分）（[8.1.1](sec8-1.md#sec-8.1.1)）
:::

## 二、柔顺与阻抗（25 分）

**3.（12 分）** 两弹簧串联：机器人刚度 $k_P$、环境刚度 $k$、参考 $x_d$、环境静止位姿 $x_r$。
写平衡位置与接触力；取 $k_P=2500\ \mathrm{N/m}$、$x_d=1.1\ \mathrm m$、$x_r=1\ \mathrm m$，
算 $k=1000$ 与 $k=10000\ \mathrm{N/m}$ 两组，并回答：位移小的那组力也小吗？为什么？

::: note 二、参考答案
**3.** $x_e=\dfrac{k_Px_d+kx_r}{k_P+k}$，$f_e=\dfrac{k_Pk}{k_P+k}(x_d-x_r)$。（4 分）
$k=1000$：$x_e=1.07143\ \mathrm m$，压入 $7.143\ \mathrm{cm}$，$f_e=71.43\ \mathrm N$；
$k=10000$：$x_e=1.02000\ \mathrm m$，压入 $2.000\ \mathrm{cm}$，$f_e=200.00\ \mathrm N$。（5 分）
不是。更硬的环境压入更少但力更大：力的表达式是 $k_P$ 与 $k$ 的**并联**分压，$k$ 增大
使力趋近 $k_P(x_d-x_r)=250\ \mathrm N$ 的上限。（3 分）（[8.2.4](sec8-2.md#sec-8.2.4)）
:::

**4.（13 分）** 阻抗控制 $M_d\ddot e+D_d\dot e+K_Pe=f_e$，取 $m_d=100\ \mathrm{kg}$、
$d_d=500\ \mathrm{N\,s/m}$、$k_P=2500\ \mathrm{N/m}$。求自由方向（$k=0$）的 $\omega_n,\zeta$；
再对 $k=10000\ \mathrm{N/m}$ 重算，并解释课堂曲线中硬环境振荡更明显的原因。
若要在 $k=10000$ 时达到 $\zeta_\star=0.5$，$d_d$ 应取多少？

::: note 二、参考答案
**4.** $k=0$：$\omega_n=\sqrt{2500/100}=5.000\ \mathrm{rad/s}$，
$\zeta=500/2\sqrt{100\cdot2500}=0.500$。（4 分）
$k=10^4$：$\omega_n=\sqrt{12500/100}=11.180\ \mathrm{rad/s}$，
$\zeta=500/2\sqrt{100\cdot12500}=0.224$。（4 分）
总刚度增大使闭环频率上升而 $d_d$ 不变，阻尼比反降——同一阻尼在更硬环境里相对不足，
故硬环境振荡更明显。（3 分）
$d_d=2\zeta_\star\sqrt{m_d(k_P+k)}=2\times0.5\times\sqrt{100\times12500}=1118\ \mathrm{N\,s/m}$。
这个 $d_d$ 在自由方向会给出 $\zeta=1118/1000=1.118$（过阻尼）——一个 $d_d$ 不能同时让两种
刚度达标。（2 分）（[8.3.3](sec8-3.md#sec-8.3.3)）
:::

## 三、直接力控制（25 分）

**5.（13 分）** 位置内环 $m_d\ddot x_e+d_d\dot x_e+k_Px_e=k_Px_F$ 加比例力环
$x_F=k_Fe_f$。推出稳态接触力表达式，说明有限增益为何必有稳态偏差；加入积分后写出
三阶特征多项式与 Routh 稳定条件，并说明积分增益过大的后果。

::: note 三、参考答案
**5.** 代入 $f_e=k(x_e-x_r)$ 得
$m_d\ddot x_e+d_d\dot x_e+k_P(1+kk_F)x_e=k_Pk_F(f_d+kx_r)$，
平衡 $f_e=\dfrac{kk_Ff_d-kx_r}{1+kk_F}$；即使 $x_r=0$ 仍有
$f_e/f_d=kk_F/(1+kk_F)<1$——非零误差才能维持非零位置参考，故有限比例增益必有偏差。
（5 分）
积分 $x_F=k_Fe_f+k_I\int e_f$ 后特征多项式
$m_ds^3+d_ds^2+k_P(1+kk_F)s+k_Pkk_I$；（4 分）
Routh 要求 $d_d(1+kk_F)>m_dkk_I$（正参数外）；积分增益过大失稳——增加积分消偏
以稳定与可实现为前提。（4 分）（[8.4.1](sec8-4.md#sec-8.4.1)）
:::

**6.（12 分）** 速度内环 $m_d\ddot x_e+d_d\dot x_e=k_f(f_d-f_e)$ 下推导稳态
$(f_e,x_e)$；若右端另有恒偏置 $b$，稳态变为什么？再答：同一环境、$f_d=10\ \mathrm N$、
$x_r=1\ \mathrm m$，$k=1000$ 与 $10000\ \mathrm{N/m}$ 两组的 $x_e$ 各是多少？这说明
力控目标与位置目标有什么本质差别？

::: note 三、参考答案
**6.** 平衡：$f_e=f_d$，$x_e=x_r+f_d/k$——无位置恢复项，理想模型即达给定力。（4 分）
恒偏置 $b$：$0=k_f(f_d-f_e)+b$ ⇒ $f_e=f_d+b/k_f$；比例方案理想无偏 ≠ 实际无偏，
是否加积分看误差来源与稳定裕度。（4 分）
$k=1000$：$x_e=1.01\ \mathrm m$；$k=10000$：$x_e=1.001\ \mathrm m$——两种环境取得
**相同接触力**、位置却不同；力控的目标量（力）与环境刚度解耦，位置目标是刚度的函数。
课堂 01:34:22–01:36:08 正是用这一差别解释力控目标。（4 分）（[8.4.2](sec8-4.md#sec-8.4.2)）
:::

## 四、约束与混合控制（30 分）

**7.（12 分）** 写出平面滑动任务（接触面 $x_Cy_C$、法线 $z_C$、无摩擦）六个自由度的
自然约束与人工约束表，并给出对应的 $S_f,S_v$ 矩阵。核对 $S_f^{\mathrm T}S_v=0$。

::: note 四、参考答案
**7.** 沿 $x_C,y_C$：允许运动、反力为零 ⇒ 人工指定 $v_{x,d},v_{y,d}$；沿 $z_C$：
法向限制压入、反力可非零 ⇒ 指定 $f_{z,d}$；绕 $x_C,y_C$：刚性接触限制倾斜 ⇒
指定 $\mu_{x,d},\mu_{y,d}$；绕 $z_C$：无摩擦不提供力矩 ⇒ 指定 $\omega_{z,d}$。（6 分）
$S_f$ 三列 = $f_z,\mu_x,\mu_y$（行 3、4、5），$S_v$ 三列 = $v_x,v_y,\omega_z$
（行 1、2、6）——逐列单位向量，任一 $S_f$ 列与任一 $S_v$ 列点积均为零。（6 分）
（[8.6.2](sec8-6.md#sec-8.6.2)）
:::

**8.（10 分）** 混合控制用逆动力学得到 $\dot v_e=\alpha$ 后，如何用 $S_v,S_f$ 把
$\alpha$ 分解成两条闭环？写出两条闭环方程；接触几何随时间变化时多出哪一项、
什么条件下才能省略？

::: note 四、参考答案
**8.** 令 $v_e=S_v\nu$、$h_e=S_f\lambda$，取
$\alpha=S_v\alpha_\nu+C_eS_f\ddot\lambda$（$C_e$ 为接触方向等效柔度映射，按可逆受限
子空间理解），得 $\dot\nu=\alpha_\nu$（速度子空间，PI 类）与
$\ddot\lambda=\ddot\lambda_{\rm cmd}$（力子空间，PD 类）。（6 分）
几何时变时 $v_e=S_v(t)\nu$ 求导多出 $\dot S_v\nu$；仅当接触几何静态（$S_v$ 常数）
才可省略；斜面等问题先把表面法向/切向变换到同一约束坐标系再选。（4 分）
（[8.7.1](sec8-7.md#sec-8.7.1)、[8.7.2](sec8-7.md#sec-8.7.2)）
:::

**9.（8 分）** 打磨算例：$k_e=2.0\times10^4\ \mathrm{N/m}$、$k_f=10^{-4}\ \mathrm{m/(N\,s)}$、
$f_d=20\ \mathrm N$。求时间常数与 $f_e(t)$；若刚度估计减半，$\tau$ 变多少？
执行前要按哪五步复核？

::: note 四、参考答案
**9.** $\tau=1/(k_ek_f)=0.5\ \mathrm s$，
$f_e(t)=20(1-e^{-2t})\ \mathrm N$；$t=0.5\ \mathrm s$ 约 $12.6\ \mathrm N$，
$t=1.5\ \mathrm s$ 约 $19.0\ \mathrm N$；初始压入速度 $k_ff_d=0.002\ \mathrm{m/s}$。（4 分）
刚度估计减半（$10^4$）时 $\tau=1\ \mathrm s$，翻倍——力环快慢由 $k_ek_f$ 乘积决定。（2 分）
五步复核：作用对象与正方向 → 参考可实现 → 选择矩阵对应接触几何 → 理想假设核查 →
稳定性验证。（2 分）（[8.8.2](sec8-8.md#sec-8.8.2)、[8.8.3](sec8-8.md#sec-8.8.3)）
:::
