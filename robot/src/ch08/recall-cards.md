## A. 定义卡

### A1 · 交互任务的两类目标

自由空间控制与环境交互控制的分界是什么？各自闭环什么？

::: sol A1 核对
分界在**末端是否受环境约束**。自由空间控制：不接触、无环境接触力，闭环位置/速度；
环境交互控制：末端受约束，同时考虑运动与接触力。（[8.1.3](sec8-1.md#sec-8.1.3) 表）
:::

### A2 · 主动柔顺、阻抗、直接力控

三种方法各自要建立的关系是什么？力传感器存在与否能分类吗？

::: sol A2 核对
主动柔顺：$h_e=K_Pe$（静态刚度关系）；阻抗：$M_d\ddot e+D_d\dot e+K_Pe=f_e$（二阶动态关系）；
直接力控：调节 $f_d-f_e$ 使接触力趋于给定值。力传感器存在与否**不能**分类——
要看力信息建立的是哪一种关系。（[8.1.3](sec8-1.md#sec-8.1.3)、[8.3](sec8-3.md)、[8.4](sec8-4.md)）
:::

### A3 · 阻抗与导纳

阻抗与导纳的实现方向各是什么？

::: sol A3 核对
阻抗：测运动偏差、按期望 $M_d,D_d,K_P$ 生成力（「测运动 → 出力」）；
导纳：测力、经动态模型生成运动参考（「测力 → 出运动」），内层运动控制器跟踪该参考。
内快外慢是导纳的设计条件而非证明。（[8.3.1](sec8-3.md#sec-8.3.1)、[8.3.4](sec8-3.md#sec-8.3.4)）
:::

### A4 · 自然约束与人工约束

自然约束、人工约束各由什么决定？判定在哪套坐标系里做？

::: sol A4 核对
自然约束由**环境几何**决定（该方向环境阻止运动，或只可能施加反作用力）；
人工约束由**任务需要**决定（在剩下方向指定力或运动目标）。判定在与任务几何相容的
**约束坐标系 $\{C\}$** 里逐方向做。（[8.6.1](sec8-6.md#sec-8.6.1)）
:::

### A5 · 选择矩阵

$S_f$ 与 $S_v$ 的列各张成什么空间？互补条件是什么？它们表达的是「测出来的力」吗？

::: sol A5 核对
$S_f$ 的列张成**接触力可以出现的空间**（$h_e=S_f\lambda$），$S_v$ 的列张成**可行末端速度空间**
（$v_e=S_v\nu$）；理想互易接触要求 $S_f^{\mathrm T}S_v=0$。它们表达的是**计划施加的人工目标空间**，
不是测出来的自然力。（[8.5.2](sec8-5.md#sec-8.5.2)、[8.6.2](sec8-6.md#sec-8.6.2)）
:::

## B. 结论卡

### B1 · 两个弹簧决定平衡

接触后 PD 与弹性环境各自的刚度如何共同决定平衡？

::: sol B1 核对
单轴：$x_e=\dfrac{k_Px_d+kx_r}{k_P+k}$，$f_e=\dfrac{k_Pk}{k_P+k}(x_d-x_r)$。
$k_P\gg k$：机器人顺应环境没发生（$x_e\approx x_d$）；$k_P\ll k$：机器人顺应环境（$x_e\approx x_r$）。
更硬的环境压入更少但力更大——「位移小」推不出「力小」。（[8.2.4](sec8-2.md#sec-8.2.4)）
:::

### B2 · 环境变硬，阻尼比怎样变

同一组 $m_d,d_d,k_P$ 遇到更硬的环境，$\omega_n$ 与 $\zeta$ 各怎么变？

::: sol B2 核对
$\omega_n=\sqrt{(k_P+k)/m_d}$ 上升；$\zeta=d_d/2\sqrt{m_d(k_P+k)}$ **下降**（$d_d$ 不变）。
所以硬环境振荡更明显。要目标阻尼比 $\zeta_\star$ 需配 $d_d=2\zeta_\star\sqrt{m_d(k_P+k)}$，
但同一个 $d_d$ 不能让两种刚度同时达标。（[8.3.3](sec8-3.md#sec-8.3.3)）
:::

### B3 · 内环结构决定比例力控的稳态

位置内环与速度内环下，比例力控制的稳态各是什么？

::: sol B3 核对
位置内环（$k_Px_e$ 恢复项）：$f_e=\dfrac{kk_Ff_d-kx_r}{1+kk_F}$，有限增益必有稳态偏差，
积分消偏须 Routh 条件 $d_d(1+kk_F)>m_dkk_I$。速度内环（无恢复项）：
理想模型平衡即 $f_e=f_d$、$x_e=x_r+f_d/k$；有恒偏置 $b$ 时仍出 $f_d+b/k_f$。
结论取决于**整个闭环**，不是「比例必偏」的定理。（[8.4.1](sec8-4.md#sec-8.4.1)、[8.4.2](sec8-4.md#sec-8.4.2)）
:::

### B4 · 逆动力学补偿后接触仍耦合

只补偿机器人动力学的阻抗控制，接触耦合藏在哪一项？

::: sol B4 核对
误差方程右端是 $M_dB_A^{-1}h_A$（$B_A=J_A^{-\mathrm T}BJ_A^{-1}$ 位形相关）——接触力仍经
操作空间惯量耦合进阻抗关系。要干净的 $M_d\ddot e+D_d\dot e+K_Pe=h_A$ 须外层再补
$+J^{\mathrm T}h_e$、$y$ 里再引回 $-h_A$。（[8.3.2](sec8-3.md#sec-8.3.2)）
:::

### B5 · 混合控制解决什么、不解决什么

混合力／运动控制解决什么问题？哪些事它不保证？

::: sol B5 核对
解决「哪些方向控力、哪些方向控运动」的**分配**（经 $S_v,S_f$ 把 $\alpha$ 分解成
$\dot\nu=\alpha_\nu$ 与 $\ddot\lambda=\ddot\lambda_{\rm cmd}$ 两条闭环）。
不保证接触永不丢失、不保证六维力/速度都能产生、不替代传感器坐标/带宽/饱和/切换的核对。
（[8.7.1](sec8-7.md#sec-8.7.1)、[8.7.3](sec8-7.md#sec-8.7.3)）
:::

## C. 公式卡

### C1 · 弹性接触与含接触动力学

写出接触力模型与含接触的动力学方程，并说明符号约定。

::: sol C1 核对
$f_e=k(x_e-x_r)$（$k>0$，已接触分支）；
$B(q)\ddot q+C\dot q+F\dot q+\boldsymbol g(q)=u-J^{\mathrm T}(q)h_e$，
其中 $\boldsymbol h_e$ = **机器人施加给环境**的六维力/力矩。符号约定改变时整个模型与控制律
一起改；功率检查 $\dot q^{\mathrm T}J^{\mathrm T}h_e=v_e^{\mathrm T}h_e$。（[8.1](sec8-1.md)）
:::

### C2 · 双弹簧公式

写出双弹簧串联的平衡位置与接触力，并指出矩阵情形的禁忌。

::: sol C2 核对
$h_e=K_Pe=K(d-e)$ ⇒ $e=(K_P+K)^{-1}Kd$；单轴
$x_e=\dfrac{k_Px_d+kx_r}{k_P+k}$。矩阵情形**不能照标量分式交换 $K,K_P$**；
$K_P\succ0,K\succeq0$ 时 $K_P+K$ 可逆。（[8.2.4](sec8-2.md#sec-8.2.4)）
:::

### C3 · 阻抗关系与导纳外层

写出阻抗关系与导纳外层的方程，单位各是什么？

::: sol C3 核对
阻抗：$M_d\ddot e+D_d\dot e+K_Pe=f_e$，单轴单位 kg、N·s/m、N/m；
$M_d$ 是期望惯量不必等于真实质量。导纳外层：$M_t\ddot z+D_t\dot z+K_tz=f_e$，
$x_t=x_d-z$ 作为内层参考。（[8.3.1](sec8-3.md#sec-8.3.1)、[8.3.4](sec8-3.md#sec-8.3.4)）
:::

### C4 · 位置内环 + PI 力环的 Routh 条件

写出三阶特征多项式与稳定条件。

::: sol C4 核对
$m_ds^3+d_ds^2+k_P(1+kk_F)s+k_Pkk_I=0$；正参数外还须
$d_d(1+kk_F)>m_dkk_I$。积分增益过大失稳——课堂 01:27:14 特别提醒了阶次上升。
（[8.4.1](sec8-4.md#sec-8.4.1)）
:::

### C5 · 平面滑动的选择矩阵

写出平面滑动任务的 $S_f$ 与 $S_v$（排列 $[v_x,v_y,v_z,\omega_x,\omega_y,\omega_z]$）。

::: sol C5 核对
$S_f$ 三列对应 $f_z,\mu_x,\mu_y$（第 3、4、5 行为单位向量）；
$S_v$ 三列对应 $v_x,v_y,\omega_z$（第 1、2、6 行）。逐列读单位向量核对；
$S_f^{\mathrm T}S_v=0$ 自动成立。（[8.6.2](sec8-6.md#sec-8.6.2)）
:::

### C6 · 速度型力环的时间常数

写出打磨算例的力环一阶动态与时间常数。

::: sol C6 核对
$\dot x=k_f(f_d-f_e)$ ⇒ $\dot f_e=k_ek_f(f_d-f_e)$，
$f_e(t)=f_d(1-e^{-t/\tau})$，$\tau=\dfrac{1}{k_ek_f}$。
刚度估计减半则 $\tau$ 翻倍；初始压入速度 $\dot x(0)=k_ff_d$。
（[8.8.2](sec8-8.md#sec-8.8.2)）
:::

## D. 陷阱卡

### D1 · 位移小 ≠ 力小

同一位置参考遇到更硬的环境，压入与接触力各怎么变？

::: sol D1 核对
压入**变少**、接触力**变大**：$k$ 从 1000 到 10000 N/m，压入 7.14→2.00 cm，
力 71.4→200 N。「位移小」不能推「力小」——两弹簧分压的比例变了。（[8.2.4](sec8-2.md#sec-8.2.4)）
:::

### D2 · 互易性 ≠ 欧氏正交

「约束力与可行速度正交」这句话缺了什么前提？

::: sol D2 核对
缺**功率度量**。力与速度单位不同，$S_f^{\mathrm T}S_v=0$ 是在选定的功率配对坐标下成立；
换基底或加权度量，子空间的「正交」表述随之改变。不能直接说成欧氏正交。
（[8.5.1](sec8-5.md#sec-8.5.1)）
:::

### D3 · 力导数放大噪声

混合控制为什么不能直接对力信号求导？

::: sol D3 核对
力传感器读数含噪声，微分放大高频成分。教材的替代：用位移与**估计刚度** $\widehat C_e$
估力变化率——但估计偏差会改变力环响应，且需保留真实速度空间的假设。
（[8.7.2](sec8-7.md#sec-8.7.2)）
:::

### D4 · 切向零刚度方向给恒力

无摩擦平面的切向指定非零恒力会怎样？

::: sol D4 核对
切向不存在可持续的弹性接触力：外层持续要求运动，表现为位置漂移或积分积累，
恒力调节无法完成。先把参考限制到环境能支持的接触力方向 $\mathcal F$。
（[8.4.4](sec8-4.md#sec-8.4.4)、[8.6.3](sec8-6.md#sec-8.6.3)）
:::
