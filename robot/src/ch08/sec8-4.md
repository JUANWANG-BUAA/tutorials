# 8.4 直接力控制：把力误差闭环

前面两节的柔顺与阻抗控制都能吸收碰撞并调节软硬程度，但它们都不能回答一个在抛光、压装和涂胶任务里最直白的需求：**不管工件位置差了一毫米还是表面刚度变了，我都要把法向接触力稳稳控制在 $f_d = 10\,\mathrm N$**。为此，必须摆脱“靠位置偏差间接借力”的思路，明确引入期望力与实测力之差 $e_f = f_d - f_e$，构造直接力控制闭环。

本节在固定坐标下的单轴平动与理想弹性接触分支 $f_e = k_e(x_e - x_r)$（其中 $k_e > 0$，部分文献亦记为 $k$）上展开分析，揭示为什么同样采用最简单的比例力控制律，**位置内环必有稳态力偏置，而速度内环理想下却可以无静差跟踪**。

<a id="sec-8.4.1"></a>

## 8.4.1 位置内环下的比例偏置与积分 Routh 判据

许多机器人出厂时已具备稳定的二阶位置跟踪内环：

$$m_d\ddot x_e + d_d\dot x_e + k_P x_e = k_P x_F,$$

其中 $x_F$ 是外层力环计算出的位置参考（约定相对于同一坐标原点；注意区别于独立的几何期望轨迹 $x_d$）。

**比例力外环**：令外层根据力误差 $e_f = f_d - f_e$ 产生位置参考 $x_F = k_F e_f$，其中外环力增益 $k_F > 0$ 在此处量纲为柔度 $\mathrm{m/N}$。将 $x_F = k_F(f_d - f_e)$ 与环境弹簧 $f_e = k_e(x_e - x_r)$ 代入内环动力学方程：

$$m_d\ddot x_e + d_d\dot x_e + k_P(1 + k_e k_F)x_e = k_P k_F(f_d + k_e x_r).$$

所有二阶项系数均为正，系统稳定收敛至静态平衡时 $\ddot x_e = \dot x_e = 0$，由此解得平衡位置与稳态接触力：

$$x_e = \frac{k_F(f_d + k_e x_r)}{1 + k_e k_F}, \qquad f_e = k_e(x_e - x_r) = \frac{k_e k_F f_d - k_e x_r}{1 + k_e k_F}.$$

即便选取坐标系原点使 $x_r = 0$，也只有 $f_e = \frac{k_e k_F}{1 + k_e k_F}f_d < f_d$。直观上看，内环里始终存在着把末端拉回原点的刚度恢复项 $k_P x_e$，只要机械臂压进了平衡点（$x_e \neq 0$），就必须由一个**非零的稳态力误差 $e_f = x_e / k_F \neq 0$** 不断供养外层位置参考 $x_F$，因此纯比例力环无法消除稳态力误差（且绝对环境位置 $x_r$ 直接掺入了力偏置；若 $x_r$ 过正，$f_e$ 甚至在数学式上跌破零而触发脱离接触）。

**引入积分消偏与 Routh 稳定性极限**：要消除对常数力设定值 $f_d$ 与表面原位 $x_r$ 的稳态敏感，外层须升级为 PI 力控制律：

$$x_F = k_F e_f + k_I\int_0^t e_f(\tau)\,d\tau, \qquad k_F, k_I > 0.$$

假设闭环保持渐近稳定，积分器输出趋于稳态常量必迫使积分输入 $e_f = f_d - f_e \to 0$，即理想稳态力精确达到 $f_e = f_d$。但加了积分环节后，系统阶次从二阶升为三阶！将含积分的闭环方程对时间再求一次导（$f_d, x_r$ 为常量）：

$$m_d x_e^{(3)} + d_d\ddot x_e + k_P(1 + k_e k_F)\dot x_e + k_P k_e k_I x_e = k_P k_e k_I x_r + k_P k_I f_d.$$

::: thm 定理 8.4.1 · 直接力控制内环结构与稳态/稳定性条件 {#thm-8.4.1}
在单轴线性弹性接触分支 $f_e = k_e(x_e - x_r)$（$k_e > 0$）上，两类典型内环结构的直接力控制满足以下精确结论：
1. **位置内环 + PI 力外环**：闭环特征多项式为 $m_d s^3 + d_d s^2 + k_P(1 + k_e k_F)s + k_P k_e k_I = 0$；当各物理参数均为正时，闭环渐近稳定当且仅当满足三阶 **Routh–Hurwitz 判据**：
   $$d_d(1 + k_e k_F) > m_d k_e k_I.$$
   只要稳定，稳态力即完全无偏且不依赖表面位置 $x_r$（$f_e \to f_d$）。
2. **速度内环（纯阻尼内环）+ P 力外环**：若撤除位置内环的位置恢复刚度项 $k_P x_e$，只保留速度阻尼并令外层以比例力误差生成速度阻尼驱动：
   $$m_d\ddot x_e + d_d\dot x_e = k_f(f_d - f_e), \qquad k_f = k_P k_F > 0,$$
   则无需力积分环节，二阶理想闭环即可无条件稳定并实现稳态无偏力跟踪：
   $$f_e \to f_d, \qquad x_e \to x_r + \frac{f_d}{k_e}.$$
:::

**证明**：对三阶实系数多项式 $a_3 s^3 + a_2 s^2 + a_1 s + a_0$（其中 $a_3 = m_d,\,a_2 = d_d,\,a_1 = k_P(1+k_e k_F),\,a_0 = k_P k_e k_I$ 全正），Routh 稳定充要条件为 $a_2 a_1 > a_3 a_0$，代入得 $d_d k_P(1+k_e k_F) > m_d k_P k_e k_I$，约去正参数 $k_P$ 即得 (1)。这表明积分增益 $k_I$ 绝不能无节制调大，尤其当遇到高刚度表面 $k_e$ 时极易打破 $d_d(1+k_e k_F) > m_d k_e k_I$ 导致失稳。

对于 (2)，将 $f_e = k_e(x_e - x_r)$ 代入速度内环方程并移项，立即化为严格正系数二阶线性系统：

$$m_d\ddot x_e + d_d\dot x_e + k_f k_e x_e = k_f(f_d + k_e x_r).$$

因 $m_d, d_d, k_f k_e > 0$，闭环必然渐近稳定到静态平衡 $\ddot x_e = \dot x_e = 0$，由此立刻消去零位置恢复刚度的影响：$k_f k_e x_e = k_f(f_d + k_e x_r) \implies x_e = x_r + f_d / k_e$，从而 $f_e = k_e(x_e - x_r) = f_d$。$\square$

## 8.4.2 为什么速度内环下比例控制就能无偏，但工程上仍需留心

为什么同样只用比例力增益，速度内环下就不会出现稳态误差？本质原因是**位置内环多了一项依赖于绝对坐标的恢复刚度 $k_P x_e$**，必须有持续力误差来顶住它；而在速度内环里，控制器只调节加速度与阻尼，没有哪一项把工具拉向原点——从末端速度到位置本身的物理积分关系（$\int \dot x_e\,dt = x_e$）已经天然充当了一个积分器，只要稳态静止下来（$\dot x_e = \ddot x_e = 0$），平衡式右端 $k_f(f_d - f_e)$ 就必须为零。

例如指定 $f_d = 10\,\mathrm N$、$x_r = 1.0\,\mathrm m$：对 $k_e = 1000\,\mathrm{N/m}$ 的较软表面，机械臂自动收敛压入至 $x_e = 1.01\,\mathrm m$ 处停下；换用 $k_e = 10000\,\mathrm{N/m}$ 的较硬表面，无需重设任何位置参数，同一控制器会自动少压入至 $x_e = 1.001\,\mathrm m$，同样把接触力停在精确的 $10\,\mathrm N$。

但务必看清“理想模型无偏”的前提边界：速度内环对模型右端的**未补偿常值扰动力 $b$**（如未建好模型的关节库仑摩擦力、重力残差或力传感器零点漂移）没有内环积分抑制力！一旦闭环方程变成 $m_d\ddot x_e + d_d\dot x_e = k_f(f_d - f_e) + b$，静态平衡处立刻产生稳态力偏差：

$$f_e = f_d + \frac{b}{k_f}.$$

此时仍需适度调大增益 $k_f$ 或引入积分环节来压低偏置，同时注意此处的组合力增益 $k_f = k_P k_F$（单位不再是 8.4.1 中位置内环单独柔度增益 $k_F$ 的 $\mathrm{m/N}$）。

## 8.4.3 并联力/位置控制的参考相容条件

很多作业希望既把末端带到某设定位置 $x_d$ 附近，又指定一段恒定压力 $f_d$。若把位置参考 $x_d$ 与力外环调节量 $x_F$ 直接叠加送给位置内环：

$$m_d\ddot x_e + d_d\dot x_e + k_P x_e = k_P(x_d + x_F),$$

这称为**并联力/位置控制（Parallel Force/Position Control）**。由于接触界面的物理规律永远满足 $f_e = k_e(x_e - x_r)$，任何稳定平衡点上的实际位置 $x_e$ 和接触力 $f_e$ 都只能落在这条弹性直线上：若要求同一轴上同时严格满足 $x_e = x_d$ 和 $f_e = f_d$，两份参考必须预先满足**环境刚度相容条件**：

$$f_d = k_e(x_d - x_r).$$

例如 $k_e = 1000\,\mathrm{N/m},\,x_r = 1.0\,\mathrm m$ 时，设定 $x_d = 1.02\,\mathrm m$ 就唯一对应 $20\,\mathrm N$ 的接触力；如果同时还要求 $f_d = 10\,\mathrm N$，世界上没有任何线性控制律能让同一根弹簧在同一位置既伸长出 $20\,\mathrm N$ 又只产生 $10\,\mathrm N$。当力外环含积分环节且闭环稳定时，力反馈的积分作用最终会压过比例位置项，令**力精确收敛到 $f_d$，位置则不得不让步退守到与力相容的 $x_r + f_d/k_e$**。

## 8.4.4 先核对方向与噪声，再调增益

执行直接力控前，还必须守住两项基本物理前提：
1. **检查环境能否承载所指定的力**：例如在无摩擦理想平面上，切向刚度 $k_e = 0$，无法产生任何持久弹性抗力。若在切向错误地给出非零期望力 $f_d \neq 0$，外环会无休止地积分累加并驱使机械臂沿表面一直飘走失控。因此力闭环指令必须只加在有物理支承的方向上。
2. **避免直接对力传感器读数微分**：工业六维力传感器信号常带有较强高频测量噪声，直接对 $e_f$ 求导构成力 PD 环会剧烈放大噪声引发抖振，工程上普遍借**速度反馈阻尼** $d_d\dot x_e$ 来提供系统阻尼。同时必须监控接触丢失、驱动饱和与传感器零漂的影响。

<details>
<summary>检查理解：为什么不能把“纯比例控制必然存在稳态误差”当作所有力控制律的普遍定理？</summary>

稳态误差由**整个闭环的前向通路积分阶次**决定，而不是孤立由力调节器是不是“比例项”决定。位置内环有恢复弹簧项 $k_P x_e$ 顶在末端上，从力调节输出 $x_F$ 到末端力 $f_e$ 之间只是零型系统，所以比例外环必须留着误差才能撑住平衡；速度内环移除了绝对位置恢复项，末端速度到末端位移之间本身带有 $1/s$ 积分链条（一型系统），因此理想无静摩擦扰动下仅靠比例力环就足以消除常值力设定点的稳态误差。

</details>

## 8.4 小结与常见错误

- **核心对比**：直接力控是否需要外环积分，取决于内环形式——位置内环（有 $k_P x_e$）用纯比例必有稳态偏置，加积分则受三阶 Routh 条件 $d_d(1+k_e k_F) > m_d k_e k_I$ 约束；速度内环（纯阻尼，无绝对位置刚度）利用自身速度积分特性，理想情形只用比例力环即可到达 $f_e = f_d$。
- **一条相容条件**：在同一自由度下同时指定位置 $x_d$ 与力 $f_d$ 时，必须满足 $f_d = k_e(x_d - x_r)$；否则积分力环生效时，位置必然让步给 $x_r + f_d/k_e$。
- **物理前置**：只往存在刚度支承的方向发非零力指令，且用运动速度阻尼取代对含噪测力信号的直接微分。
- **下一节**：[8.5 约束运动](sec8-5.md) 把前面一直单轴讨论的思路推广到完整六维空间——先从几何上认清，哪些方向受环境卡死只能控力、哪些方向允许自由运动只能控速。

核心公式速查：

| 三阶 Routh 稳定条件：$d_d(1 + k_e k_F) > m_d k_e k_I$ | 位置内环 + PI 力环、参数全正 | 乘积量纲一致 | 高刚度环境 $k_e$ 下过大积分增益 $k_I$ 会直接触发振荡失稳 |
