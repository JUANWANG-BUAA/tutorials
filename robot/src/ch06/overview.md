## 为什么要学动力学：从「看得见」到「算得出」

老师在正式讲公式前，用一组「AI 困境」的幻灯片做了动机铺垫（00:16:38–00:21:47）：

- **AI 困境：看得见，却看不懂**——视频模型能生成很逼真的画面，但不知道物体为什么会那样动；
- **解决途径：世界模型**——智能体从数据和交互中建立外部世界的内部模型，预测世界如何随行动演化
  （幻灯片举了 DreamerV3、Nature 640, 647–653 (2025) 等例子）；
- **机器人动力学的定位**——「世界模型：从数据经验出发，建立隐式内部模型，预测未来状态；
  **机器人动力学：从物理规律出发，建立显式数学模型，推演未来运动**」；
- **混合动力学模型**——$\dot x=f_{\text{physics}}(x,u)+f_{\text{learned}}(x,u)$，
  「动力学先验 × 数据 AI 学习」，是当前机器人学习的一个活跃方向。

课件将数据得到的隐式模型与物理规律得到的显式模型并列，讨论二者的分工。本章从后者入手，学习用拉格朗日方程构造可计算、可核验的机械臂模型。

::: note 正动力学与逆动力学（老师用一张幻灯片把两个问题分开）
- **正动力学问题（forward dynamics）**：给定力/力矩，求机器人的运动。要解**非线性微分方程组**，
  一般没有闭式解，只能数值积分——「求解困难」。
- **逆动力学问题（inverse dynamics）**：已知机器人的运动（$q,\dot q,\ddot q$），求实现该运动所需的
  力/力矩。**不需求解非线性方程组**，只是代入公式——「求解简单」。

逆动力学可根据参考运动生成前馈力矩，正动力学则预测给定输入下的运动。本章的模型 $B(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$ 可从两个方向使用：代入运动求力矩，或解出 $\ddot q$ 后积分。
:::

## 全章路线图

本章可以按「两条方法 → 一组性质 → 两个算例 → 三类应用」来读：

```text
方法一：拉格朗日（能量路线，6.1–6.3）
  广义坐标 q → 动能 T=½q̇ᵀB(q)q̇（6.1.1）→ 势能 U(q)（6.1.2）
      → 运动方程 Bq̈+Cq̇+Fq̇+f+g = τ−Jᵀh（6.1.3）
      → 两条结构性质：Ḃ−2C 反对称（6.2.1）、τ=Yπ 参数线性（6.2.2）
      → 两个算例：笛卡儿臂（解耦）、平面臂（耦合，可手算）

方法二：牛顿–欧拉（递推路线，6.4）
  逐杆列牛顿/欧拉方程 → 向外递推运动量、向内递推力/力矩 → O(n)

应用（6.5–6.7）
  正解（仿真）/ 逆解（控制与规划）
  轨迹的动态标度：τ 超限时重排时间
  操作空间动力学：把模型搬到末端位姿，交给第七章做控制
```

将动能写成 $\frac12\dot q^{\mathrm T}B\dot q$、势能写成 $U(q)$，代入拉格朗日方程，就得到关于 $q$ 的二阶运动方程；牛顿–欧拉法按连杆递推计算同一模型。随后分别检查 $B$ 的对称正定性、所选 $\dot B-2C$ 的反对称性，以及 $\tau=Y\pi$ 的参数线性结构。

**优先级说明（按课堂权重）**

- **核心 · 必知**（6.1）：由标量能量构造拉格朗日方程，适合展示多连杆模型的来源。能量换基后不变，但质心位置、速度和惯性张量仍须先采用相容坐标，不能理解成不需要参考系。
- **核心 · 重点**（6.1.1、6.1.3）：动能写成二次型是全部结构性质的来源；运动方程的三项
  （惯性、速度耦合、重力）是控制里逐项补偿的对象。
- **精读 · 证明**（6.2.1）：按Christoffel选法逐步证明 $\dot B-2C$ 反对称，再验证 $w^{\mathrm T}Nw=0$。同时区分任意测试向量的二次型与只沿实际速度成立的能量恒等式。
- **核心 · 重点**（6.2.2）：$\tau=Y\pi$ 是参数辨识与自适应控制的入口；老师说这条性质
  「对于动力学参数辨识以及控制算法推导都有帮助」。
- **核心 · 重点**（6.3.2）：完整手算平面臂的 $B,C,g$，识别惯性、离心、科氏和重力各项的来源。再与§6.3.1的正交移动臂比较，分开判断惯性是否恒定、轴间是否耦合。
- **核心 · 重点**（6.4）：给定一次状态与要求加速度时，两遍牛顿–欧拉递推可用 $O(n)$ 运算求关节力矩。学习重点是各运动量的传递方向、力矩参考点与重力初始化；比较计算量时仍要注明任务。
- **概念 · 必知**（6.5）：正动力学先解当前加速度，再随时间积分；逆动力学代入给定运动求力矩。两者可用相同模型互相核验，不能只按名称比较求解难度。
- **精读 · 选学**（6.6、6.7）：动态标度分别检查动态力矩、重力与摩擦，判断改时间是否可行；操作空间模型为第七章的任务反馈提供动力学关系，使用前需明确局部坐标与秩条件。

> **第一遍的验收标准**：能默写拉格朗日方程并解释 $L=T-U$；能把 $n$ 连杆的动能写成
> $\frac12\dot q^{\mathrm T}B\dot q$ 并说出 $B$ 的三条性质；能写出完整的关节空间运动方程并解释
> $B\ddot q$、$C\dot q$、$g$ 各是什么；能证明 $\dot B-2C$ 反对称；能说明 $\tau=Y\pi$ 中 $Y$ 与 $\pi$
> 各是什么；能手算两连杆平面臂的 $B(q)$ 与 Christoffel 符号。
