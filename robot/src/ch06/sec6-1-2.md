# 6.1.2 势能计算

动能已经写成关节速度的二次型，拉格朗日函数 $L=T-U$ 还缺势能 $U$。在多关节机械臂里，连杆和电机转子各自有高度，而重力项和关节驱动力矩又在方程左右两侧。本节先由质心位置写出系统总势能，解释为什么势能对速度偏导恒为零，再通过链式法则对关节坐标求导，核对左端重力项 $\boldsymbol g(\boldsymbol q)$ 与重力实际施加的广义力之间差一个负号。课堂回看：01:09:10–01:15:30。

![课堂幻灯片 · 32:33：预备知识——动能与势能](../assets/ch06/energy-intro.jpg)



## 6.1.2.1 只算重力

对刚性连杆，势能来自重力（弹性、磁力等暂不考虑）：

$$U=\sum_{i=1}^{n}\bigl(U_i+U_{m_i}\bigr),$$

$$U_i=-\int_{V_i}\boldsymbol g_0^{\mathrm T}\boldsymbol p_i^*\,\rho\,\mathrm dV
=-m_i\boldsymbol g_0^{\mathrm T}\boldsymbol p_i,\qquad
U_{m_i}=-m_{m_i}\boldsymbol g_0^{\mathrm T}\boldsymbol p_{m_i},$$

其中 $\boldsymbol g_0$ 是基坐标系中的重力加速度向量。若 $z$ 轴竖直向上，则

$$\boldsymbol g_0=[0,\ 0,\ -g]^{\mathrm T},\qquad g=9.81\ \mathrm{m/s^2}.$$

于是

$$\boxed{\ U(\boldsymbol q)=-\sum_{i=1}^{n}\bigl(m_i\boldsymbol g_0^{\mathrm T}\boldsymbol p_i(\boldsymbol q)
+m_{m_i}\boldsymbol g_0^{\mathrm T}\boldsymbol p_{m_i}(\boldsymbol q)\bigr)\ }$$

## 6.1.2.2 为什么只依赖 $\boldsymbol q$

质心位置 $\boldsymbol p_i$ 与转子质心位置 $\boldsymbol p_{m_i}$ 都是**位形**的函数（由正运动学给出），
与速度无关。因此

$$U=U(\boldsymbol q),\qquad \frac{\partial U}{\partial\dot{\boldsymbol q}}=\boldsymbol 0.$$

因此求速度偏导时，势能这一半直接消失，只需对动能求导：

$$\frac{\partial L}{\partial\dot q_i}=\frac{\partial T}{\partial\dot q_i}.$$

求位置偏导时则不同：不仅势能 $U$ 随构形变化，动能里的惯性矩阵 $B(\boldsymbol q)$ 一般也依赖位形，所以两项都保留：

$$\frac{\partial L}{\partial q_i}=\frac{\partial T}{\partial q_i}-\frac{\partial U}{\partial q_i}.$$

前一项 $\partial T/\partial q_i$ 在常惯量单摆里恰好为零，在多连杆机械臂里会进入速度二次项（[6.1.3](sec6-1-3.md)），计算时必须保留。
## 6.1.2.3 势能的梯度就是重力矩

把 $U$ 对 $q_i$ 求偏导，用链式法则：

$$\frac{\partial U}{\partial q_i}
=-\sum_{j=1}^{n}\Bigl(m_j\boldsymbol g_0^{\mathrm T}\frac{\partial\boldsymbol p_j}{\partial q_i}
+m_{m_j}\boldsymbol g_0^{\mathrm T}\frac{\partial\boldsymbol p_{m_j}}{\partial q_i}\Bigr).$$

由质心线速度 $\dot{\boldsymbol p}_j=J_P^{(j)}\dot{\boldsymbol q}=\sum_{i=1}^{n}j_{Pi}^{(j)}\dot q_i$ 与全微分 $\dot{\boldsymbol p}_j=\sum_{i=1}^{n}\frac{\partial\boldsymbol p_j}{\partial q_i}\dot q_i$ 比较系数，得 $\frac{\partial\boldsymbol p_j}{\partial q_i}=j_{Pi}^{(j)}$（质心位置雅可比第 $i$ 列）；同理 $\frac{\partial\boldsymbol p_{m_j}}{\partial q_i}=j_{Pi}^{(m_j)}$。代入上式并定义为重力项的第 $i$ 分量 $g_i(\boldsymbol q)$：

$$\frac{\partial U}{\partial q_i}
=-\sum_{j=1}^{n}\Bigl(m_j\boldsymbol g_0^{\mathrm T}j_{Pi}^{(j)}
+m_{m_j}\boldsymbol g_0^{\mathrm T}j_{Pi}^{(m_j)}\Bigr)
\triangleq g_i(\boldsymbol q).$$

写成列向量：

$$\boxed{\ \boldsymbol g(\boldsymbol q)=\frac{\partial U}{\partial\boldsymbol q}
=-\sum_{j=1}^{n}\Bigl(m_jJ_P^{(j)\mathrm T}\boldsymbol g_0
+m_{m_j}J_P^{(m_j)\mathrm T}\boldsymbol g_0\Bigr)\ }$$

::: intuition 先说清「谁在施力」，再判断正负号
把 $g_i$ 记在左端容易让人误以为它是“重力产生的力矩”。按虚功原理，重力矢量 $m_j\boldsymbol g_0$ 在虚位移 $\delta\boldsymbol p_j=J_P^{(j)}\delta\boldsymbol q$ 上做的虚功为 $\sum_j(m_j\boldsymbol g_0^{\mathrm T}J_P^{(j)}+m_{m_j}\boldsymbol g_0^{\mathrm T}J_P^{(m_j)})\delta\boldsymbol q$，因此重力实际施加在关节上的[广义力](../recall.md#lagrange)为
$$\boldsymbol\tau_{\mathrm{grav}}=\sum_{j=1}^{n}\Bigl(m_jJ_P^{(j)\mathrm T}\boldsymbol g_0+m_{m_j}J_P^{(m_j)\mathrm T}\boldsymbol g_0\Bigr)=-\frac{\partial U}{\partial\boldsymbol q}.$$
它与势能[梯度](../recall.md#gradient)恰好相反。本教程的运动方程 $B\ddot{\boldsymbol q}+C\dot{\boldsymbol q}+\boldsymbol g=\boldsymbol\tau$ 把 $-\boldsymbol\tau_{\mathrm{grav}}$ 移到了左端，记作 $\boldsymbol g=\partial U/\partial\boldsymbol q$。因此左端的“重力项”$\boldsymbol g$ 是**平衡重力所需提供的力矩**：静止、无摩擦也无外力时，电机必须输出 $\boldsymbol\tau=\boldsymbol g$ 才能托住机械臂。
:::

::: ex 例 6.1.2.A · 一个单摆，两条路径核对符号 {#ex-6.1.2.A}
质点质量 $m=2\ \mathrm{kg}$，到铰点距离 $l=0.5\ \mathrm m$，忽略杆与转子质量。
取 $z$ 向上、摆角 $q$ 从竖直垂下方向向 $+x$ 增大，则
$\boldsymbol p=(l\sin q,0,-l\cos q)^{\mathrm T}$。求 $q=\pi/6$ 时的重力项和保持力矩。

::: sol 解
**势能路径**：以垂下位置为零点，$U=mgl(1-\cos q)$，
故 $g(q)=mgl\sin q=4.905\ \mathrm{N\cdot m}$。

**力与雅可比路径**：$J_P=(l\cos q,0,l\sin q)^{\mathrm T}$，
重力 $m\boldsymbol g_0=(0,0,-mg)^{\mathrm T}$，故
$\tau_{\mathrm{grav}}=J_P^{\mathrm T}m\boldsymbol g_0=-mgl\sin q=-4.905\ \mathrm{N\cdot m}$。
电机保持力矩为 $\tau=+4.905\ \mathrm{N\cdot m}$，与实际重力相抵。

两条路径必须满足 $g+\tau_{\mathrm{grav}}=0$。若不相抵，先查重力向量和角度正向；
势能加减常数不影响梯度，不能靠改势能零点修复符号。
:::
:::

::: think 迁移练习 · 换一个角度定义
若改用 $\alpha=q-\pi/2$（从水平向右方向向上量角），同一质心写成
$\boldsymbol p=(l\cos\alpha,0,l\sin\alpha)^{\mathrm T}$。
求左端重力项 $g_\alpha$，并在 $\alpha=-\pi/3$ 核对上例。

::: sol 核对与回读
$U=mgl\sin\alpha+\text{常数}$，所以 $g_\alpha=mgl\cos\alpha$。
$\alpha=-\pi/3$ 时仍得 $4.905\ \mathrm{N\cdot m}$，实际重力广义力仍为其相反数。
若写成正弦，回到质心高度表达式再求导；若两路径同号，回读上面的「谁在施力」。
能独立完成两种角度定义后，再到 [运动方程](sec6-1-3.md) 把重力项放回完整模型。
:::

## 6.1.2.4 小结与常见错误

由质心位置给出的重力势能 $U(\boldsymbol q)$ 不依赖关节速度，因此 $\partial U/\partial\dot{\boldsymbol q}=\boldsymbol 0$；对位置求梯度就得到运动方程左端的重力项 $\boldsymbol g(\boldsymbol q)=\partial U/\partial\boldsymbol q=-\boldsymbol\tau_{\mathrm{grav}}$，大小等于静止托住机械臂所需的电机力矩。改变势能的常数零点不影响梯度，改变坐标轴或角度正向则必须重算 $\boldsymbol g_0$ 与质心高度。

::: think 常见错误清单
1. **把势能写成速度的函数**：$U$ 只依赖正运动学给出的质心位置，与 $\dot{\boldsymbol q}$ 无关；写出 $\dot q$ 说明把动能项混进来了。
2. **重力方向与坐标轴不一致**：$\boldsymbol g_0$ 的符号取决于竖直轴朝向；平面臂若取 $y$ 竖直向上，必须写 $\boldsymbol g_0=[0,-g,0]^{\mathrm T}$，而不是 $[0,0,-g]^{\mathrm T}$。
3. **重力矩符号反**：先用手算单摆检验——摆角增大时左端重力项是正是负取决于角度定义，同时用 $g+\tau_{\mathrm{grav}}=0$ 交叉核对；符号错了，后面的前馈重力补偿会整体反向。
:::

::: think 默写点 · 合上书再写
1. 写出系统总重力势能 $U(\boldsymbol q)$（连杆 + 转子），并说明为什么 $\partial U/\partial\dot{\boldsymbol q}=\boldsymbol 0$。
2. 写出 $\boldsymbol g(\boldsymbol q)=\partial U/\partial\boldsymbol q$ 的雅可比表达式，并写出它与 $\boldsymbol\tau_{\mathrm{grav}}$ 的关系。
3. 用单摆（$q$ 从下垂向上量起）写出势能路径与力-雅可比路径的重力矩检查。
:::
