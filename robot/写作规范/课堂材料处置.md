# robot 书课堂材料处置规范

本规范回答两个问题：课件截图与板书照片在正文里怎么处置；「老师在 XX:XX 说……」式的课堂引语怎么取舍。目标与 `SECTION-TODO.md` 的既有要求一致——**教程正文自足，课堂材料是对照源**——2026-11-22 起在全书面执行。

## 一、课件截图的三步处置

每张嵌在正文的课件截图（`![课堂幻灯片 · mm:ss：…](../assets/chNN/*.jpg)`）逐张过三步：

1. **补全**：这张图承载了正文没有的信息（公式、框图、数值、图形关系）吗？有，就把信息写进正文——文字推导或编号公式；正文写完后，图对理解正文是否必需？
2. **替代**：信息适合用图表达、且图上的量可以由已知参数算准的，**自绘 SVG 替代**（工作流见第三节）。课件图不再进正文。
3. **收编**：前两步之后仍有保留价值的（板书原貌、课堂强调的排版、原始推导痕迹），移入节末 `::: think 本节的课堂幻灯片（源料对照）` 四栏表：

```
| 时间点 | 幻灯片 | 提供了什么 | 本书如何处理 |
|:--|:--|:--|:--|
| 0:54:40 | [dh-rules.jpg](../assets/ch02/dh-rules.jpg) | DH 建系四规则 | 正文 §2.8.2 完整重写，自绘图替代 |
```

   - 「本书如何处理」一栏写实际处置：正文何处给出（§/定理号）、是否自绘图替代、未采纳时为什么。
   - 表头注明一句：正文已自足，截图保留以备核对，不构成正文替代。
   - 截图文件不删、不改名（勘误与 review 记录引用文件名）；只是从正文移进对照表。

处置后的验收标准：**只读正文（不看任何截图）能完成本节的例题与默写点**。

## 二、课堂引语的取舍

1. **进正文的门槛**：这条原话讲清了「为什么重要 / 为什么这样做」，且比教材表述更直白或补充了教材没有的动机。只有结论没有理由的话不进正文。
2. **格式**：`老师在 00:54:40–00:55:12 说「……」，这解释了……`。时间精确到秒；讲的是哪几个字要与转写核对（方法见第五节）。转写缺失的章（如 ch04），以既有 `review/` 记录与教材原页为准，核不了的降格为「教材指出 / 课件口径是」表述，不写「老师说」。
3. **收编**：未达门槛但值得留档的（量级口径、课堂去留说明、ASR 错词来源），移到节末源料对照表或章末 `errata.md`，不在正文占位。
4. **每节顶部的「录播回看：…」行取消**：时间范围并入源料对照表表头（如「本节对应录播 0:08:47–0:39:00」一行放进对照表 `:::` 块首段）；没有对照表的节写在 `errata.md` 的来源说明里。
5. **归属纪律**（对 2026-11-20 复核教训的固化）：「教材说」与「老师说」永远分句；两者一致也不合并成「老师指出」；年份、人名、量化口径拿不准就写教材侧，不替老师编。

## 三、自绘图工作流

1. **先算准再画**：图上的每个数（坐标、角度、曲线、读数）先由脚本算出再生成 SVG；不允许目测描点。数值算例沿用该书对应章的 `verify_*.py` 或 `verify_teaching_examples.py` 口径，能挂进验证脚本的挂进去。
2. **画完目检**：mdbook build 后打开页面截图目检——线段方向、坐标架手性、标注遮挡、配色可读。
3. **代码规范**：
   - `<figure><svg class="figure-svg" viewBox="…">`，含 `<title>`/`<desc>` 与 `<figcaption>`，figcaption 注明「本教程绘」；
   - **alt 与 SVG `<text>` 内禁 `$`**（mdbook-katex 会在原始 markdown 层替换，注入 KaTeX HTML 打碎页面）——数学一律用 Unicode 纯文本（Δ、q̇、ᵀ、²等，全书已有字体覆盖先例）；
   - SVG 内裸 `<` 转义为 `&lt;`；
   - 颜色用主题变量（`var(--fig-blue)` 等），不写死 hex 之外的语义色。
4. **交互实验**：需要 3D/交互时用既有 `robot-labs-3d.js` 注册表新增或复用实例；`data-lab`/`data-mech` 取值必须在注册表内（check_book 会拦）；数学内核写成纯函数并进 `tools/check_labs3d_math.mjs` 对拍。

## 四、处置过程中发现的材料问题

- 教材印刷出入：记章末 `errata.md`，正文按自洽形式实现并注明与本教程的选择；
- 课件与教材不一致：正文取其一并说明取舍理由，另一份口径进 errata；
- ASR 错词订正（如「钢琴」=刚体）：订正后全书 grep 该词，确认没有别处照抄；
- 每轮处置在 errata 增加一行「2026-11-XX 教材化处置」记录：处置张数、替代方式、遗留待核项。

## 五、引语复核的切片法

复核一条「老师在 HH:MM 说……」时，用转写文本按秒切片比对而不是通读：

1. 解析转写的 `[HH:MM:SS] 文本` 行；
2. 取引语时间戳前后 ±90 秒窗口内的文本；
3. 问「老师在那段时间里具体说了哪几个字」，说法对 ≠ 是老师说的——教材与课堂重合处最易张冠李戴；
4. 抓出错归属记入章末 errata 的「归属错」表，留档错误与教训。
