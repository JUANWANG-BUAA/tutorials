# robot 书标题与节骨架规范

适用于 `robot/src/` 全部正文页（`chXX/sec*.md`、`overview.md`）。本规范落实 2026-11-22 全书优化方案的取舍：正文自足、节末三件套、标题编号 = 目录树位置。与仓库根 `AGENTS.md` 冲突时以本文件为准；本文件未覆盖的措辞问题仍按 `AGENTS.md`。

## 一、标题编号

1. **编号等于标题在目录树中的位置。** 每个正文文件一个 H1，编号与 `SUMMARY.md` 中该页的节号一致，如 `# 2.5 角和轴`。H1 可在冒号后带副题点明任务，如 `# 8.2 柔顺控制：两个刚度决定平衡`。
2. **H2 一律带编号** `## 2.5.1 …`。无编号 H2 只允许两种：
   - 文件末的小结：`## 2.5 小结与常见错误`（编号与 H1 相同、标题必须含「小结」）；
   - ch04 式三段文件（H1 已是三级号 `# 4.2.1`）中，H2 编号写到四级 `## 4.2.1.1 …`，小结为 `## 4.2.1 小结与常见错误`。
3. **H3 一律带编号** `### 2.5.1.1 …`；ch01–ch03 现存的无编号描述式 H3 在本轮逐章循环中补号。H1 下的承接段不带标题；导语超过一段时按内容补号，不留长篇无标题地带（sec2-9 的百行导语是反例）。
4. **禁止**：
   - 同一编号在同文件出现两次及以上（ch05/sec5-3、sec5-4、ch04/sec4-3-1 是待修实例）；
   - 编号乱序（ch04/sec4-2-2 的 4.2.2.5 在 4.2.2.4 前是待修实例）；
   - 与 H1 标题同名同级的无编号 H2（ch06/sec6-1:7 是待修实例）；
   - 标题携带源料字样「课件 / 幻灯片 / 老师 / 第 X 周 / 教材补充 / 本编补充 / 原书」——出处写进正文句或勘误，不进标题。
   - 小结标题使用「本节小结 / 本节要记住的三件事 / 实现要点与小结」等变体，一律统一为「X.Y 小结与常见错误」。
5. 改标题不等于改锚点：显式 `{#…}`、`<a id>`、`[@…]` 引用保持原样，`tools/check_book.py` 兜底查唯一性与可达性。

## 二、节文件骨架

每节按此顺序组织（仿 ch04 六节）：

```
# X.Y 标题

（承接段，1–2 段，无标题）上一节交出了什么量 → 本节要解决什么问题；
需要新记号时在此处一并说明。录播时间范围不写在这里，进节末源料对照表。

## X.Y.1 …
（正文；定义/定理/方法用 ::: def/::: thm/::: method 盒子承载并给 {#} 锚点；
 核心公式带 \tag{X.n}；推导按「已知→假设→变形→物理意义→自检」展开）

## X.Y.2 …

## X.Y 小结与常见错误
（一句话主线 + 2–3 条要点 + 核心公式速查表）

::: think 默写点 · 合上书再写        （可选：本节有手算技能时）
::: think 常见错误清单 · 自查三条
::: think 本节的课堂幻灯片（源料对照）  （四栏表；规范见 课堂材料处置.md）
```

## 三、小结与常见错误的写法

- 小结正文含三块：**一句话主线**（本节要点）；**要点条目**（2–3 条，合并原「谨记」清单——谨记式四连排不再使用）；**核心公式速查表**，四栏 `公式 | 条件与假设 | 单位/量纲 | 易错点`，只收本节出现的、考试会手算的式子；行数以本节实际需要为准，不放凑数条目。速查表条目应与章末 `preface-formulas.md` 对应条目互链或至少同口径。
- 常见错误清单收 3 条左右真实易错处，每条「错法 → 后果 → 正确做法」；已在本节正文讲过的边界条件不必重复收录。
- 默写点仅当本节有「合上书应能写出」的手算技能时保留，2–4 题，配 `::: sol` 核对。

## 四、衔接与主线

1. **承接段**写的是量不是课：从上一节出口处的量（一个矩阵、一个误差、一条轨迹）进入本节问题，不用「上一节我们学习了…」式回顾；出口量来自哪一节用 `[§X.Y](secX-Y.md)` 链接。
2. **交棒句**：小结最后一条之后写一句下一节的入口，如「下一节 [§2.4](sec2-4.md) 把旋转矩阵换成三个参数的欧拉角」；不用「接下来将深入探讨」。
3. **两连杆主线接力块**：主线关卡的节（索引见 `training/two-link.md`）在小结之前放：

```
::: note 主线 · 两连杆（第 N 关 · 本节任务名）
上一关（[§X.Y](…)）交付了……；本关用同一台 2R 臂算出……；
下一关（[§X.Y](…)）将把……变成……。
:::
```

   接力块必须与 `training/two-link.md` 的关卡表一致，编号以该表为准。

## 五、章级文件

- `overview.md`：承接上一章出口（对应哪个量）→ 本章交付清单（哪几节、各产出什么）→ 来源口径（录播/课件/板书）一句话。
- 章末六件套（summary/errata/exercises/checklist/recall-cards/mock-exam）齐全；recall-cards 与 mock-exam 标题中的自称张数/分值必须与实际条目数一致，正文改动后先跑计数再提交。
- 每节正文改动触及概念、公式或数字时，同步检查：`exercises.md` 题号覆盖、`recall-cards.md` 对应卡、`preface-formulas.md`、`preface-pitfalls.md`、`preface-contrast.md` 的对应条目。

## 六、自检清单（每节提交前）

1. 标题编号 = 目录树位置，同文件无重复、无乱序、无源料字样。
2. 承接段讲量不讲课；交棒句存在且链接可达。
3. 小结含一句话主线 + 要点 + 公式速查表；无「谨记」连排。
4. 每个凭空出现的公式有来源与条件；「显然/易证/代入可得」十秒内可验。
5. 截图已按 `课堂材料处置.md` 处置完；alt 与 SVG 文本无 `$`。
6. 保留的课堂引语归属已复核（或已降格）；勘误页有记录。
7. `check_book.py`、`mdbook build`、`make verify` 全过。
