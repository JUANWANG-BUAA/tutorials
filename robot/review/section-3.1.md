## 问题与处理

| 位置 | 问题及教学影响 | 处理与证据 |
|---|---|---|
| 3.1.1 | 求导证明错写 $R\dot R^{\mathrm T}R=-S$；把角速度矩阵与有限姿态矩阵混称同构 | 补为 $-SR$，从定义式右乘得 $\dot R=SR$；明确 $S$ 是角速度的线性矩阵表示。用两轴组合旋转的中心差分分别验证基系/刚体系摘帽和换基 |
| 3.1.2 | 标准 DH 转动关节的局部平移列被错误设为常量，会把固定基座单杆的线速度算成零 | 从 $r^{i-1}=[a\cos\vartheta,a\sin\vartheta,d]^{\mathrm T}$ 推导非零 $\dot r$，保留通用三项式并给合并后的 R/P 特例。新增 0.8 m 单杆练习；60 条混合 R/P 链的全部 240 个原点，与 FK 中心差分对拍 |
| 3.1.2 | 局部相对角速度和基系轴向混用；一般刚体两点公式被称为定轴公式 | 明确局部量上标与 $R_{i-1}$ 转换，补基座固定假设；把刚体两点关系与基点可平移条件写清 |
| 3.1.3 | 工具点被当成第 n 系原点；差分混淆列偏导与方向导数；运动参考系位置导数与速度分量可能混淆 | 统一从 $T_e^0=T_n^0T_e^n$ 取工具点；区分 $\varepsilon e_i$ 与 $h\dot q$ 两种差分；用 $v_{P,e}^u$ 表示同一向量换基。独立验证带平移/旋转工具的 JP、JO 和表达基变换 |
| 首图与逐列图 | 首图把位置偏导写成速度偏导、2×2 块冒充完整 J、角速度画成平面箭头；逐列图切向方向反了 | 同步修正生成器与资产；明确平面位置块与 6×2 完整 J、单位驱动条件、出纸面角速度；切向箭头改为左上并数值核对叉乘方向 |
| 教学工具 | 静态例题无法直接比较两列贡献、抵消与工具偏置 | 新增 `jacobian2d`：五个滑杆、三组预设与重置、两列线速度贡献及矢量叠加、角速度、矩阵和独立位置差分读数。零向量不画伪箭头，静态练习仍可无脚本使用 |
| 直接配套 | 固定轴方向、末端点、牵连项和差分口径存在重复错误；自检表的递推题实际指向共轭证明 | 同步公式卡、易错表、回忆卡 C1/C2/D1/D2、自测卷 11/12、总结 §3.1 行、勘误 E3.7；自检 K3.2 指向新增递推练习。习题 B1 的局部角速度记号已与本节一致；两连杆第二关已核对，无需重写 |
