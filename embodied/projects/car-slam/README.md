# 项目一 · 小车 2D SLAM 闭环系统

本目录为《具身感知：SLAM、状态估计与传感器融合》的第一个工程实战项目：**面向轮式移动机器人的 2D 激光 SLAM 闭环系统**（`car-slam`）。

## 1. 系统架构

```text
激光扫描 / 里程计
       │
       ▼
┌───────────────────────────────┐
│ ① 前端扫描匹配 (Scan Matcher)   │ ──▶ 高斯-牛顿法 / Huber 鲁棒核
└──────────────┬────────────────┘
               │ 关键帧判断 (距离/角度阈值)
               ▼
┌───────────────────────────────┐
│ ② 局部子图与关键帧库           │ ──▶ 拼接局部高密度参考点云
└──────────────┬────────────────┘
               │ 空间邻域搜索
               ▼
┌───────────────────────────────┐
│ ③ 回环检测 (Loop Detection)    │ ──▶ 几何验证与粗精匹配
└──────────────┬────────────────┘
               │ 触发回环边
               ▼
┌───────────────────────────────┐
│ ④ 位姿图优化 (Pose Graph Opt)  │ ──▶ SE(2) 流形高斯-牛顿迭代
└──────────────┬────────────────┘
               │ 广播修正后位姿
               ▼
┌───────────────────────────────┐
│ ⑤ 占据栅格地图 (Occupancy Grid) │ ──▶ 对数几率更新 + Bresenham
└───────────────────────────────┘
```

## 2. 模块说明

- `car_slam/types.py`：SE(2) 刚体变换群流形类、指数对数映射、伴随矩阵、激光扫描数据结构；
- `car_slam/occupancy_grid.py`：对数几率（log-odds）栅格地图，包含快速 Bresenham 光线投射与概率恢复；
- `car_slam/scan_matching.py`：SE(2) 流形上的点云高斯-牛顿扫描配准器与 Huber 鲁棒损失函数；
- `car_slam/pose_graph.py`：二维位姿图非线性最小二乘优化器，支持回环边鲁棒核与全局坐标对齐；
- `car_slam/slam_system.py`：集成系统调度器，管理关键帧、子图匹配、回环触发与全局地图重构；
- `car_slam/simulator.py`：室内多障碍物封闭环境仿真器，生成真实闭环轨迹与带噪声激光雷达数据。
