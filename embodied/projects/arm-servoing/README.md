# 项目二 · 机械臂视觉伺服控制系统

本目录为《具身感知：SLAM、状态估计与传感器融合》的第二个工程实战项目：**面向机械臂操作的视觉伺服控制系统**（`arm-servoing`）。

## 2. 模块说明

- `arm_servoing/camera_model.py`：针孔相机内参模型、三维投影与归一化图像平面反投影；
- `arm_servoing/interaction_matrix.py`：图像相互作用矩阵（Image Jacobian）点特征推导、多点堆叠与阻尼伪逆；
- `arm_servoing/visual_features.py`：空间几何标靶（正方形 4 点平面靶标）与特征跟踪器；
- `arm_servoing/servo_controller.py`：IBVS 与 PBVS 控制律实现、速度饱和保护、眼在手（Eye-in-Hand）坐标系速度变换；
- `arm_servoing/simulator.py`：6 自由度空间运动学闭环仿真器，提供轨迹回放与误差收敛分析。
