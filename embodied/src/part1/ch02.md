在确定性控制理论中，系统的状态 $x_k$ 被视为欧氏空间中唯一的确定实数向量。然而，在具身智能体与物理机器人的实际运行中，**真实状态永远无法被直接测量**：
- 机器人的编码器只能测量车轮转角，无法直接感知车轮与地面的微滑移；
- 激光雷达测得的是一束光子在飞行时间（ToF）上的模糊统计分布，而不是绝对空间坐标；
- 相机捕捉的是三维世界投影到二维平面上的发光强度矩阵，丢失了物理深度尺度的绝对信息。

我们面对的是一个本质上的**部分可观测马尔可夫决策过程（POMDP）**。智能体在任何时刻对物理世界的认知，都只能表现为状态空间上的一个概率密度函数——即**置信度（Belief State）**。

本章推导状态估计领域最根本的数学公理系统：**贝叶斯滤波（Bayes Filter）**。全书后续讨论的卡尔曼滤波（KF/EKF/UKF/ESKF）、粒子滤波（MCL）乃至因子图优化（Factor Graph），全部是本章贝叶斯法则在特定分布假设（高斯分布）或特定采样方法（蒙特卡洛法）下的具象工程实现。

## 2.1 概率公理与状态空间随机变量 {#sec-embodied.1.2.1}

在现代概率机器人学中，状态估计建立在柯尔莫哥洛夫（Kolmogorov）概率测度公理之上。

::: def 定义 2.1.1 · 条件独立性与马尔可夫链 {#def-embodied.1.2.1.1}
设 $X, Y, Z$ 为概率空间中的随机变量。若在已知 $Y$ 的条件下，$X$ 的条件分布与 $Z$ 无关，则称 **$X$ 与 $Z$ 关于 $Y$ 条件独立**，记作 $(X \perp Z \mid Y)$，其充要条件为：

$$
p(x, z \mid y) = p(x \mid y) \cdot p(z \mid y) \iff p(x \mid y, z) = p(x \mid y)
$$

在具身机器人运动学中，一阶马尔可夫假设（First-order Markov Assumption）规定：
1. **状态马尔可夫性**：当前物理状态 $x_k$ 仅取决于上一时刻的状态 $x_{k-1}$ 与控制输入 $u_{k-1}$，与更早的历史状态 $x_{0:k-2}$ 条件独立：
   $$
   p(x_k \mid x_{0:k-1},\ u_{0:k-1},\ z_{1:k-1}) = p(x_k \mid x_{k-1},\ u_{k-1})
   $$
2. **观测马尔可夫性**：当前传感器观测 $z_k$ 仅由当前时刻的状态 $x_k$ 决定，与历史所有控制与观测在已知 $x_k$ 下条件独立：
   $$
   p(z_k \mid x_{0:k},\ u_{0:k-1},\ z_{1:k-1}) = p(z_k \mid x_k)
   $$
:::

一阶马尔可夫假设是所有递归状态估计器的基石。它使得我们无需在内存中无限保存自机器人启动以来的全部历史数据，而只需维护当前时刻的置信分布。

然而，在真实具身场景中，**马尔可夫假设常常被环境隐变量所破坏**：
- 如果小车行驶在摩擦系数不断变化的湿滑泥地上，泥土阻力构成了未建模的高阶未观测隐状态；
- 如果相机的自动曝光（Auto Exposure）在强光下动态改变增益，相邻两帧的像素观测直接依赖于上一帧的曝光参数，破坏了观测独立性。
工程师必须在滤波状态向量中显式扩增隐变量（如增加 IMU 零偏、路面摩擦因子），以恢复马尔可夫性质。

### 2.1.2 连续时间马尔可夫扩散与福克-普朗克方程（Fokker-Planck Equation）

在连续时间随机动力学中，智能体的运动状态演化由**伊藤随机微分方程（Itô Stochastic Differential Equation, SDE）**主导：

$$
\mathrm{d}x(t) = f(x(t),\ u(t))\,\mathrm{d}t + G(x(t))\,\mathrm{d}W(t)
$$

其中 $W(t)$ 为标准布朗运动过程，$Q(t)$ 为扩散矩阵。状态概率密度 $p(x, t)$ 随时间的演化完全遵从偏微分方程领域的**福克-普朗克方程（Fokker-Planck Equation，亦称 Kolmogorov 前向偏微分方程）**：

$$
\frac{\partial p(x, t)}{\partial t} = -\sum_{i=1}^n \frac{\partial}{\partial x_i} \Big( f_i(x, t) p(x, t) \Big) + \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \frac{\partial^2}{\partial x_i \partial x_j} \Big( [G Q G^T]_{ij} p(x, t) \Big)
$$

该偏微分方程包含两个物理意义极其明确的动力学项：
1. **漂移项（Drift Term）**：一阶偏导数描述确定性控制与系统速度对概率团块的平移输运；
2. **扩散项（Diffusion Term）**：二阶偏导数等价于热传导或物理分子扩散方程，描述过程噪声不可避免地导致概率密度由尖锐向平缓散开、方差单调膨胀。

在离散时间步 $\Delta t = t_k - t_{k-1}$ 下，查普曼-科尔莫戈罗夫积分方程 $\overline{\mathrm{bel}}(x_k) = \int p(x_k \mid x_{k-1}) \mathrm{bel}(x_{k-1}) \mathrm{d}x_{k-1}$ **本质上就是福克-普朗克偏微分方程在时间区间 $[t_{k-1}, t_k]$ 上的离散格林函数（Green's Function）卷积解**。

### 2.1.3 Python 置信状态概率密度结构化表示类

为了在软件架构中支持多模态（Multimodal）与离散/连续统一的状态表示，我们构建如下通用置信度管理类：

```python
import numpy as np


class ProbabilisticBeliefState:
    """具身智能体通用概率置信度状态管理器。"""

    def __init__(self, state_dim: int):
        self.dim = state_dim
        # 模式：'gaussian' 或 'particles' 或 'gmm'
        self.mode = "gaussian"
        self.mean = np.zeros(state_dim, dtype=float)
        self.covariance = np.eye(state_dim, dtype=float)
        # 高斯混合模型分量：weights, means, covs
        self.gmm_components = []

    def set_gaussian(self, mean: np.ndarray, cov: np.ndarray):
        self.mode = "gaussian"
        self.mean = mean.copy()
        self.covariance = cov.copy()

    def set_gmm(self, weights: list, means: list, covs: list):
        self.mode = "gmm"
        assert len(weights) == len(means) == len(covs)
        self.gmm_components = list(zip(weights, means, covs))

    def evaluate_pdf(self, x: np.ndarray) -> float:
        """计算给定状态点 x 处的概率密度值。"""
        if self.mode == "gaussian":
            diff = x - self.mean
            inv_cov = np.linalg.inv(self.covariance)
            det = np.linalg.det(self.covariance)
            denom = np.sqrt(((2.0 * np.pi)**self.dim) * max(det, 1e-12))
            expo = -0.5 * (diff.T @ inv_cov @ diff)
            return float(np.exp(expo) / denom)
        elif self.mode == "gmm":
            total = 0.0
            for w, mu, cov in self.gmm_components:
                diff = x - mu
                inv_c = np.linalg.inv(cov)
                det = np.linalg.det(cov)
                denom = np.sqrt(((2.0 * np.pi)**self.dim) * max(det, 1e-12))
                total += w * np.exp(-0.5 * (diff.T @ inv_c @ diff)) / denom
            return float(total)
        return 0.0

    def compute_entropy(self) -> float:
        """连续高斯微分熵解析解。"""
        if self.mode == "gaussian":
            det = np.linalg.det(self.covariance)
            return 0.5 * np.log(((2.0 * np.pi * np.e)**self.dim) * max(det, 1e-12))
        return 0.0
```

## 2.2 贝叶斯法则与最大后验估计对偶性 {#sec-embodied.1.2.2}

当传感器返回观测值 $z$ 时，我们如何修正对状态 $x$ 的认知？贝叶斯法则是连接先验概率与后验概率的唯一数学桥梁。

::: thm 定理 2.2.1 · 贝叶斯法则（Bayes' Rule） {#thm-embodied.1.2.2.1}
设状态为连续随机变量 $x \in \mathcal{X}$，传感器观测为 $z \in \mathcal{Z}$。给定先验概率密度 $p(x)$ 与传感器正向物理生成模型（似然函数）$p(z \mid x)$，状态的后验概率密度（Posterior）为：

$$
p(x \mid z) = \frac{p(z \mid x) p(x)}{p(z)} = \frac{p(z \mid x) p(x)}{\int_{\mathcal{X}} p(z \mid x') p(x')\,\mathrm{d}x'}
$$

分母积分项 $p(z) = \int_{\mathcal{X}} p(z \mid x') p(x')\,\mathrm{d}x'$ 与待估计状态 $x$ 无关，在状态优化中常写作归一化常数 $\eta = 1 / p(z)$。
:::

### 2.2.1 最大后验（MAP）、极大似然（MLE）与最小二乘的统一

根据对后验概率的不同决策准则，衍生出三大经典估计量：

1. **最大后验估计（Maximum A Posteriori, MAP）**：
   寻找使后验概率密度达到绝对峰值的状态点：
   $$
   \hat{x}_{\mathrm{MAP}} = \arg\max_{x} p(x \mid z) = \arg\max_{x} \Big( \ln p(z \mid x) + \ln p(x) \Big)
   $$
2. **极大似然估计（Maximum Likelihood Estimation, MLE）**：
   当没有任何先验知识（$p(x)$ 为全空间均匀分布）时，MAP 退化为仅最大化观测生成概率：
   $$
   \hat{x}_{\mathrm{MLE}} = \arg\max_{x} p(z \mid x) = \arg\max_{x} \ln p(z \mid x)
   $$
3. **最小均方误差估计（Minimum Mean Square Error, MMSE）**：
   寻找使后验均方误差 $\mathbb{E}[(x - \hat{x})^2 \mid z]$ 最小的估计量，其数学解严格等于后验分布的**数学期望**：
   $$
   \hat{x}_{\mathrm{MMSE}} = \mathbb{E}[x \mid z] = \int_{\mathcal{X}} x \cdot p(x \mid z)\,\mathrm{d}x
   $$

### 2.2.2 共轭先验（Conjugate Priors）与解析贝叶斯更新

在贝叶斯推断中，如果先验分布 $p(x)$ 与似然函数 $p(z \mid x)$ 的乘积所得到的后验分布 $p(x \mid z)$ **属于与先验分布同类型的概率分布族**，则称该先验分布为该似然模型的**共轭先验（Conjugate Prior）**。

在具身感知工程中，共轭先验具有压倒性的计算优势：它允许后验概率更新直接退化为分布超参数的简单代数加法，而无需任何高维数值积分或采样。以下为三种在机器人领域高频使用的经典共轭对：

1. **高斯-高斯共轭（Gaussian-Gaussian）**：
   - 先验：$\mu \sim \mathcal{N}(\mu_0, \sigma_0^2)$；
   - 似然：$z_i \sim \mathcal{N}(\mu, \sigma^2)$；
   - 后验：$\mu \mid z_{1:N} \sim \mathcal{N}(\mu_N, \sigma_N^2)$，其中精度（方差之逆）直接线性累加：
     $$
     \frac{1}{\sigma_N^2} = \frac{1}{\sigma_0^2} + \frac{N}{\sigma^2},\qquad \mu_N = \sigma_N^2 \left( \frac{\mu_0}{\sigma_0^2} + \frac{\sum z_i}{\sigma^2} \right)
     $$

2. **Beta-二项分布共轭（Beta-Binomial）**：
   - 用于离散栅格占据建图（Occupancy Grid Mapping，第 11 章）；
   - 先验：占据概率 $p \sim \mathrm{Beta}(\alpha_0, \beta_0)$；
   - 观测：激光雷达击中次数 $k$，穿透次数 $n-k$；
   - 后验：$p \mid \text{obs} \sim \mathrm{Beta}(\alpha_0 + k, \beta_0 + n - k)$。

3. **狄利克雷-多项分布共轭（Dirichlet-Multinomial）**：
   - 用于语义 SLAM 中多分类目标（如地面、墙壁、人、车辆）的后验语义推断；
   - 先验类别分布：$\mathbf{p} \sim \mathrm{Dirichlet}(\alpha_1, \dots, \alpha_K)$；
   - 观测到各类别的检测计数：$c_1, \dots, c_K$；
   - 后验超参数更新：$\alpha_k \leftarrow \alpha_k + c_k$。

以下 Python 类封装了这三种共轭更新模型：

```python
class ConjugateBayesianUpdater:
    """机器人常用共轭先验极速闭式更新器。"""

    @staticmethod
    def update_gaussian_mean(mu_0: float, var_0: float, measurements: list, var_meas: float):
        """一维高斯均值共轭更新。"""
        n = len(measurements)
        if n == 0:
            return mu_0, var_0
        prec_0 = 1.0 / var_0
        prec_meas = 1.0 / var_meas
        prec_post = prec_0 + n * prec_meas
        var_post = 1.0 / prec_post
        mu_post = var_post * (prec_0 * mu_0 + prec_meas * sum(measurements))
        return mu_post, var_post

    @staticmethod
    def update_beta_occupancy(alpha_0: float, beta_0: float, hits: int, misses: int):
        """占据栅格 Beta-二项共轭更新。"""
        alpha_post = alpha_0 + hits
        beta_post = beta_0 + misses
        expected_occ = alpha_post / (alpha_post + beta_post)
        return alpha_post, beta_post, expected_occ
```

::: thm 定理 2.2.2 · 高斯假设下 MAP 与加权非线性最小二乘的对偶等价性 {#thm-embodied.1.2.2.2}
设先验状态与传感器观测均服从多元正态高斯分布：
- 先验分布：$x \sim \mathcal{N}(\check{x},\ \Sigma_0)$，信息矩阵 $\Omega_0 = \Sigma_0^{-1}$；
- 观测模型：$z = h(x) + v,\ v \sim \mathcal{N}(0,\ R)$，观测信息矩阵 $\Omega_v = R^{-1}$。
则最大后验估计 $\hat{x}_{\mathrm{MAP}}$ 严格等价于一个加权非线性最小二乘优化问题：

$$
\hat{x}_{\mathrm{MAP}} = \arg\min_{x} \left( \|x - \check{x}\|_{\Sigma_0}^2 + \|z - h(x)\|_R^2 \right)
$$

其中马氏距离范数定义为 $\|e\|_M^2 = e^T M^{-1} e = e^T \Omega e$。
:::

::: proof 证明
将高斯概率密度函数展开代入 MAP 目标函数：

$$
p(x) = \frac{1}{\sqrt{(2\pi)^n \det\Sigma_0}} \exp\left( -\frac{1}{2} (x - \check{x})^T \Sigma_0^{-1} (x - \check{x}) \right)
$$

$$
p(z \mid x) = \frac{1}{\sqrt{(2\pi)^m \det R}} \exp\left( -\frac{1}{2} (z - h(x))^T R^{-1} (z - h(x)) \right)
$$

对后验联合概率取负自然对数（Negative Log-Likelihood, NLL）：

$$
\begin{aligned}
-\ln p(x \mid z) &= -\ln p(z \mid x) - \ln p(x) + \ln p(z) \\
&= \frac{1}{2} (x - \check{x})^T \Sigma_0^{-1} (x - \check{x}) + \frac{1}{2} (z - h(x))^T R^{-1} (z - h(x)) + \mathrm{const}
\end{aligned}
$$

常数项与 $x$ 无关，忽略常数倍数 $\frac{1}{2}$，最大化后验概率即等价于最小化马氏距离残差平方和：

$$
\min_x \Big( (x - \check{x})^T \Sigma_0^{-1} (x - \check{x}) + (z - h(x))^T R^{-1} (z - h(x)) \Big)
$$

证毕。该定理奠定了现代因子图优化与 Bundle Adjustment 将概率状态估计转化为非线性数值优化的理论基石。
:::

## 2.3 连续与离散贝叶斯滤波通用递推方程 {#sec-embodied.1.2.3}

有了马尔可夫性质与贝叶斯法则，我们可以推导状态估计领域最核心的连续与离散贝叶斯滤波通用递推公式。

::: def 定义 2.3.1 · 状态置信度（Belief State） {#def-embodied.1.2.3.1}
在时刻 $t_k$，已知历史至当前的所有控制量 $u_{0:k-1}$ 与所有传感器测量值 $z_{1:k}$，机器人对状态 $x_k$ 的后验概率分布定义为：

$$
\mathrm{bel}(x_k) \triangleq p(x_k \mid z_{1:k},\ u_{0:k-1})
$$

在传感器观测尚未到来、仅通过控制输入外推预测得到的先验置信度定义为：

$$
\overline{\mathrm{bel}}(x_k) \triangleq p(x_k \mid z_{1:k-1},\ u_{0:k-1})
$$
:::

### 2.3.1 贝叶斯滤波双步递推方程数学推导

我们从全概率公式与贝叶斯法则出发，严格推导从 $\mathrm{bel}(x_{k-1})$ 到 $\mathrm{bel}(x_k)$ 的递推过程。

#### 1. 预测步（时间更新推导）：
根据条件全概率公式，引入上一时刻状态 $x_{k-1}$ 作为积分边缘变量：

$$
\begin{aligned}
\overline{\mathrm{bel}}(x_k) &= p(x_k \mid z_{1:k-1},\ u_{0:k-1}) \\
&= \int_{\mathcal{X}} p(x_k,\ x_{k-1} \mid z_{1:k-1},\ u_{0:k-1})\,\mathrm{d}x_{k-1} \\
&= \int_{\mathcal{X}} p(x_k \mid x_{k-1},\ z_{1:k-1},\ u_{0:k-1}) \cdot p(x_{k-1} \mid z_{1:k-1},\ u_{0:k-1})\,\mathrm{d}x_{k-1}
\end{aligned}
$$

利用一阶马尔可夫状态独立性：
- $p(x_k \mid x_{k-1}, z_{1:k-1}, u_{0:k-1}) = p(x_k \mid x_{k-1}, u_{k-1})$（当前状态只由上一步状态与动作决定）；
- 上一时刻状态与当前动作 $u_{k-1}$ 无关，故 $p(x_{k-1} \mid z_{1:k-1}, u_{0:k-1}) = p(x_{k-1} \mid z_{1:k-1}, u_{0:k-2}) = \mathrm{bel}(x_{k-1})$。

代入整理，即得到著名的**查普曼-科尔莫戈罗夫预测方程（Chapman-Kolmogorov Equation）**：

$$
\overline{\mathrm{bel}}(x_k) = \int_{\mathcal{X}} p(x_k \mid x_{k-1},\ u_{k-1}) \cdot \mathrm{bel}(x_{k-1})\,\mathrm{d}x_{k-1}
$$

在离散状态网格空间中，积分符号退化为离散全概率矩阵求和：

$$
\overline{\mathrm{bel}}(x_k^i) = \sum_{j} p(x_k^i \mid x_{k-1}^j,\ u_{k-1}) \cdot \mathrm{bel}(x_{k-1}^j)
$$

#### 2. 更新步（测量更新推导）：
在获得当前观测 $z_k$ 后，应用贝叶斯法则展开：

$$
\begin{aligned}
\mathrm{bel}(x_k) &= p(x_k \mid z_k,\ z_{1:k-1},\ u_{0:k-1}) \\
&= \frac{p(z_k \mid x_k,\ z_{1:k-1},\ u_{0:k-1}) \cdot p(x_k \mid z_{1:k-1},\ u_{0:k-1})}{p(z_k \mid z_{1:k-1},\ u_{0:k-1})}
\end{aligned}
$$

利用观测马尔可夫性：$p(z_k \mid x_k, z_{1:k-1}, u_{0:k-1}) = p(z_k \mid x_k)$。
而分子第二项正是预测步计算出的先验分布 $\overline{\mathrm{bel}}(x_k)$。
分母对于具体状态点 $x_k$ 而言为一个标量归一化因子：

$$
\eta_k = \frac{1}{\int_{\mathcal{X}} p(z_k \mid x') \overline{\mathrm{bel}}(x')\,\mathrm{d}x'}
$$

代入得到**贝叶斯滤波测量更新方程**：

$$
\mathrm{bel}(x_k) = \eta_k \cdot p(z_k \mid x_k) \cdot \overline{\mathrm{bel}}(x_k)
$$

预测步通过控制动作在状态空间中做卷积，导致**概率质量扩散、方差增大、信息熵上升**；
### 2.3.2 从贝叶斯滤波高斯卷积严格推导离散线性卡尔曼滤波五大公式

为了让读者透彻领悟经典卡尔曼滤波的数学母体，我们在本节直接从连续贝叶斯积分出发，通过高斯分布的指数代数运算与 **Woodbury 矩阵恒等式（Matrix Inversion Lemma）**，完整推导出卡尔曼滤波器的五大黄金公式。

设系统为线性高斯系统：
- 状态转移概率：$p(x_k \mid x_{k-1},\ u_{k-1}) = \mathcal{N}(x_k;\ F x_{k-1} + B u_{k-1},\ Q)$；
- 观测概率模型：$p(z_k \mid x_k) = \mathcal{N}(z_k;\ H x_k,\ R)$；
- 上一时刻后验置信度：$\mathrm{bel}(x_{k-1}) = \mathcal{N}(x_{k-1};\ \hat{x}_{k-1},\ P_{k-1})$。

#### 1. 预测步高斯积分求解：

预测步要求解 Chapman-Kolmogorov 全概率积分：

$$
\overline{\mathrm{bel}}(x_k) = \int_{\mathcal{X}} \mathcal{N}(x_k;\ F x_{k-1} + B u_{k-1},\ Q) \cdot \mathcal{N}(x_{k-1};\ \hat{x}_{k-1},\ P_{k-1})\,\mathrm{d}x_{k-1}
$$

注意到随机变量 $x_k$ 是两个独立高斯随机变量的线性组合：

$$
x_k = F x_{k-1} + B u_{k-1} + w_{k-1}
$$

根据高斯随机变量在线性变换下的封闭性质：
- 均值具有线性期望算子性质：
  $$
  \check{x}_k = \mathbb{E}[x_k] = \mathbb{E}[F x_{k-1} + B u_{k-1} + w_{k-1}] = F \hat{x}_{k-1} + B u_{k-1}
  $$
- 误差方差根据定义计算：
  $$
  x_k - \check{x}_k = F (x_{k-1} - \hat{x}_{k-1}) + w_{k-1}
  $$
  由于上一时刻状态误差 $x_{k-1} - \hat{x}_{k-1}$ 与当前过程噪声 $w_{k-1}$ 相互独立，交叉项期望为零：
  $$
  \check{P}_k = \mathbb{E}[(x_k - \check{x}_k)(x_k - \check{x}_k)^T] = F \mathbb{E}[(x_{k-1} - \hat{x}_{k-1})(x_{k-1} - \hat{x}_{k-1})^T] F^T + \mathbb{E}[w_{k-1} w_{k-1}^T]
  $$
  即得卡尔曼滤波前两大预测方程：
  $$
  \check{x}_k = F \hat{x}_{k-1} + B u_{k-1}
  $$
  $$
  \check{P}_k = F P_{k-1} F^T + Q
  $$

#### 2. 更新步贝叶斯高斯乘积求解：

更新步是两个高斯概率密度的点对点乘积：

$$
\mathrm{bel}(x_k) \propto \mathcal{N}(z_k;\ H x_k,\ R) \cdot \mathcal{N}(x_k;\ \check{x}_k,\ \check{P}_k)
$$

将指数项提取出来，合并二次型：

$$
J(x_k) = (z_k - H x_k)^T R^{-1} (z_k - H x_k) + (x_k - \check{x}_k)^T \check{P}_k^{-1} (x_k - \check{x}_k)
$$

将关于 $x_k$ 的项展开并配方：

$$
J(x_k) = x_k^T (H^T R^{-1} H + \check{P}_k^{-1}) x_k - 2 x_k^T (H^T R^{-1} z_k + \check{P}_k^{-1} \check{x}_k) + \mathrm{const}
$$

上式显然是一个新的高斯分布的指数二次型。记后验协方差矩阵为 $P_k$，后验均值为 $\hat{x}_k$：

$$
P_k^{-1} = \check{P}_k^{-1} + H^T R^{-1} H
$$

$$
P_k^{-1} \hat{x}_k = \check{P}_k^{-1} \check{x}_k + H^T R^{-1} z_k
$$

上两式即为著名的**信息滤波（Information Filter）**形式，在多传感器测量融合中极具威力（信息矩阵直接线性相加！）。

为了将其转化为标准卡尔曼滤波的协方差更新形式，我们应用著名的 **Woodbury 矩阵恒等式**：

$$
(A + B C D)^{-1} = A^{-1} - A^{-1} B (C^{-1} + D A^{-1} B)^{-1} D A^{-1}
$$

将 $A = \check{P}_k^{-1}$，$B = H^T$，$C = R^{-1}$，$D = H$ 代入：

$$
\begin{aligned}
P_k &= (\check{P}_k^{-1} + H^T R^{-1} H)^{-1} \\
&= \check{P}_k - \check{P}_k H^T (R + H \check{P}_k H^T)^{-1} H \check{P}_k
\end{aligned}
$$

定义卡尔曼增益（Kalman Gain）矩阵 $K_k \in \mathbb{R}^{n \times m}$：

$$
K_k \triangleq \check{P}_k H^T (H \check{P}_k H^T + R)^{-1}
$$

则后验协方差公式直接简化为：

$$
P_k = (I - K_k H) \check{P}_k
$$

将 $P_k$ 乘以信息状态向量，展开化简后验均值：

$$
\begin{aligned}
\hat{x}_k &= P_k (\check{P}_k^{-1} \check{x}_k + H^T R^{-1} z_k) \\
&= (I - K_k H) \check{x}_k + P_k H^T R^{-1} z_k
\end{aligned}
$$

利用恒等式 $P_k H^T R^{-1} = K_k$，最终化简为：

$$
\hat{x}_k = \check{x}_k + K_k (z_k - H \check{x}_k)
$$

至此，五大经典卡尔曼公式从贝叶斯全概率积分与高斯乘积中得到完全严格的闭式解析推导。数学的美感在此展现得淋漓尽致：**卡尔曼滤波不是凭空发明的启发式算法，而是贝叶斯滤波在线性高斯世界下的唯一解析真解**。

### 2.3.3 连续时间卡尔曼-布西滤波（Kalman-Bucy Filter）与微分黎卡提方程

在连续时间控制与高频惯导积分中，若采样时间间隔 $\Delta t \to 0$，离散卡尔曼滤波将连续平滑退化为著名的 **卡尔曼-布西滤波（Kalman-Bucy Filter）**。

设连续线性时变系统为：

$$
\dot{x}(t) = F(t) x(t) + B(t) u(t) + w(t),\qquad w(t) \sim \mathcal{N}(0,\ Q_c(t))
$$

$$
z(t) = H(t) x(t) + v(t),\qquad v(t) \sim \mathcal{N}(0,\ R_c(t))
$$

其中连续过程噪声谱密度为 $Q_c$，连续测量噪声谱密度为 $R_c$。
对离散后验协方差公式做微小时间极限推演：

$$
P(t + \Delta t) \approx (I - K(t) H(t) \Delta t) \Big( (I + F(t)\Delta t) P(t) (I + F(t)\Delta t)^T + Q_c(t) \Delta t \Big)
$$

将连续卡尔曼增益定义为 $K_c(t) \triangleq \lim_{\Delta t \to 0} \frac{K_k}{\Delta t} = P(t) H(t)^T R_c(t)^{-1}$。
忽略 $(\Delta t)^2$ 阶高阶无穷小量，整理得到关于协方差矩阵导数 $\dot{P}(t)$ 的连续微分方程：

$$
\dot{P}(t) = F(t) P(t) + P(t) F(t)^T + Q_c(t) - P(t) H(t)^T R_c(t)^{-1} H(t) P(t)
$$

上式即为现代最优控制理论中威名远扬的 **连续时间微分黎卡提方程（Differential Riccati Equation, DRE）**！
而连续状态估计的导数方程为：

$$
\dot{\hat{x}}(t) = F(t) \hat{x}(t) + B(t) u(t) + K_c(t) \Big( z(t) - H(t) \hat{x}(t) \Big)
$$

在机器人长时间稳态运行（$t \to \infty$）且系统满足完全可观测与可控条件时，协方差变化率趋于稳定 $\dot{P}(t) \to 0$，微分黎卡提方程退化为**代数黎卡提方程（Algebraic Riccati Equation, ARE）**：

$$
F P_{\infty} + P_{\infty} F^T + Q_c - P_{\infty} H^T R_c^{-1} H P_{\infty} = 0
$$

这证明了在稳态下，卡尔曼滤波器的增益 $K_c$ 会收敛为一个恒定常数矩阵，此时卡尔曼滤波严格等价于一个时不变的最优维纳滤波器（Wiener Filter）。

## 2.4 信息熵演化与传感器信息增益 {#sec-embodied.1.2.4}

如何定量衡量一次传感器测量给机器人带来了多少“确定性”？信息论为具身感知提供了严格的标尺。

::: def 定义 2.4.1 · 香农信息熵与互信息增益 {#def-embodied.1.2.4.1}
对于离散概率分布 $\mathrm{bel}(x)$，其香农信息熵（Shannon Entropy）定义为：

$$
H(\mathrm{bel}) = -\sum_{i=1}^N \mathrm{bel}(x_i) \log_2 \mathrm{bel}(x_i)
$$

对于连续多元高斯分布 $x \sim \mathcal{N}(\mu, \Sigma) \in \mathbb{R}^n$，其微分熵（Differential Entropy）具有极其优美的闭式解析解：

$$
h(x) = \frac{1}{2} \ln\left( (2\pi e)^n \det\Sigma \right) = \frac{n}{2} (1 + \ln(2\pi)) + \frac{1}{2} \sum_{i=1}^n \ln \lambda_i
$$

其中 $\lambda_i$ 为协方差矩阵 $\Sigma$ 的特征值。信息熵直接与协方差矩阵的行列式（对应误差椭球的超体积）成对数正比。
传感器观测 $z$ 带来的**信息增益（Information Gain）**定义为互信息（Mutual Information）：

$$
I(x;\ z) = H(\overline{\mathrm{bel}}) - H(\mathrm{bel}) = \frac{1}{2} \ln\left( \frac{\det\Sigma_{\text{prior}}}{\det\Sigma_{\text{post}}} \right)
$$
:::

在主动 SLAM（Active SLAM）与自主探索中，机器人路径规划的目标函数通常就是最大化未来的互信息增益：机器人应主动行驶至那些能最大程度压缩地图与本体位姿协方差行列式的地方。

### 2.4.2 费希尔信息矩阵（FIM）与克拉美-罗下界（CRLB）

在统计估计理论中，任何无偏估计量 $\hat{x}$ 所能达到的方差下限，受制于被测系统固有的 **克拉美-罗下界（Cramér-Rao Lower Bound, CRLB）**：

$$
\mathrm{Cov}(\hat{x}) \ge \mathcal{I}(x)^{-1}
$$

其中 $\mathcal{I}(x) \in \mathbb{R}^{n \times n}$ 为**费希尔信息矩阵（Fisher Information Matrix, FIM）**，定义为对数似然函数关于状态二阶偏导数（海森矩阵）的负期望：

$$
\mathcal{I}(x) = \mathbb{E}\left[ \left(\nabla_x \ln p(z \mid x)\right) \left(\nabla_x \ln p(z \mid x)\right)^T \right] = -\mathbb{E}\left[ \nabla_x^2 \ln p(z \mid x) \right]
$$

在高斯观测模型 $z = h(x) + v,\ v \sim \mathcal{N}(0, R)$ 下，费希尔信息矩阵退化为具有极其清晰物理几何含义的加权高斯二次型：

$$
\mathcal{I}(x) = J_h(x)^T R^{-1} J_h(x)
$$

其中 $J_h(x) = \frac{\partial h}{\partial x}$ 为观测模型的雅可比矩阵。该式深刻揭示了具身感知系统精度的物理决定因素：
1. **传感器本体精度**：观测噪声协方差 $R$ 越小（$R^{-1}$ 越大），信息矩阵特征值越大，CRLB 下界越低，理论估计精度越高；
2. **环境几何可观测性**：雅可比矩阵 $J_h$ 的行空间张成了当前观测能够约束的状态子空间。如果 $J_h$ 在某个方向的投影为零（例如机器人在长廊中沿前进方向观察光滑墙壁，$\frac{\partial h}{\partial x_{forward}} \approx 0$），则该方向对应的费希尔信息特征值为 0，CRLB 下界逆矩阵在该方向趋于无穷大——**此即机器人学中“几何退化（Degeneracy）”的数学本质**！

#### 3. 最优感知实验设计的准则（A/D/E-Optimality）

在主动移动探索与传感器布局标定中，常采用以下三种基于 FIM 的凸优化设计准则：
- **D-最优性（D-Optimality）**：最大化信息矩阵行列式 $\det(\mathcal{I}(x))$，等价于最小化置信误差椭球的几何超体积；
- **A-最优性（A-Optimality）**：最小化信息矩阵逆的迹 $\mathrm{Tr}(\mathcal{I}(x)^{-1})$，等价于最小化所有状态分量误差方差之和；
- **E-最优性（E-Optimality）**：最大化信息矩阵的最小特征值 $\lambda_{\min}(\mathcal{I}(x))$，专注于消除最薄弱、最容易退化的未约束自由度。

## 2.5 离散网格贝叶斯滤波器 Python 从零实现 {#sec-embodied.1.2.5}

离散网格滤波器（Discrete Grid Filter）不需要对状态分布做任何高斯或线性化假设，能够自然支持多峰假设（Multimodal Belief）。以下为无依赖的一维环形空间完整 Python 实现：

```python
import math
import numpy as np


class DiscreteBayesFilter1D:
    """一维离散拓扑环形世界贝叶斯滤波器。"""

    def __init__(self, n_cells: int = 50):
        self.N = n_cells
        # 初始状态先验：最大不确定性均匀分布
        self.belief = np.ones(n_cells, dtype=float) / n_cells

    def predict(self, motion_kernel: list):
        """预测步：卷积位移转移核 motion_kernel = [(offset, probability), ...]"""
        prior = np.zeros(self.N, dtype=float)
        for offset, prob in motion_kernel:
            # 环形滚动位移
            prior += prob * np.roll(self.belief, offset)
        self.belief = prior

    def update(self, likelihood_func):
        """更新步：似然乘积与归一化。"""
        likelihood = np.array([likelihood_func(i) for i in range(self.N)], dtype=float)
        unnorm = self.belief * likelihood
        total = np.sum(unnorm)
        if total < 1e-12:
            # 似然严重冲突，防御性保持先验防止除零
            return
        self.belief = unnorm / total

    def entropy(self) -> float:
        """计算当前置信状态香农熵 (bits)。"""
        safe_p = self.belief[self.belief > 1e-12]
        return float(-np.sum(safe_p * np.log2(safe_p)))

    def get_max_posterior(self) -> tuple:
        """提取最大后验状态网格索引与置信度。"""
        idx = int(np.argmax(self.belief))
        return idx, float(self.belief[idx])


class DiscreteBayesFilter2D:
    """二维空间占据网格贝叶斯定位器（支持多模态航位推算）。"""

    def __init__(self, width: int = 40, height: int = 40, resolution: float = 0.5):
        self.W = width
        self.H = height
        self.res = resolution
        # 初始二维先验概率平面 (H, W)
        self.belief = np.ones((height, width), dtype=float) / (width * height)

    def predict_2d(self, dx: float, dy: float, sigma_trans: float = 0.5):
        """二维高斯卷积预测步。"""
        shift_x = int(round(dx / self.res))
        shift_y = int(round(dy / self.res))
        prior = np.zeros_like(self.belief)

        # 构造局部高斯运动扩散核 (5x5)
        kernel_size = 5
        half = kernel_size // 2
        kx, ky = np.meshgrid(np.arange(-half, half + 1), np.arange(-half, half + 1))
        dist2 = (kx * self.res)**2 + (ky * self.res)**2
        kernel = np.exp(-0.5 * dist2 / (sigma_trans**2))
        kernel /= np.sum(kernel)

        # 卷积传播
        from scipy.signal import convolve2d
        # 先做平移
        shifted = np.roll(np.roll(self.belief, shift_y, axis=0), shift_x, axis=1)
        prior = convolve2d(shifted, kernel, mode="same", boundary="wrap")
        self.belief = prior / np.sum(prior)

    def update_range_bearing(self, landmark_world: tuple, measured_range: float, sigma_range: float = 0.2):
        """融合到已知地标的距离观测。"""
        lx, ly = landmark_world
        # 坐标网格
        cols, rows = np.meshgrid(np.arange(self.W), np.arange(self.H))
        xs = (cols + 0.5) * self.res
        ys = (rows + 0.5) * self.res

        pred_range = np.hypot(xs - lx, ys - ly)
        # 高斯似然环形带
        likelihood = np.exp(-0.5 * ((pred_range - measured_range) / sigma_range)**2) + 1e-12

        unnorm = self.belief * likelihood
        self.belief = unnorm / np.sum(unnorm)


class LogOddsBayesFilter:
    r"""对数几率（Log-Odds）数值防溢出贝叶斯更新器。
    
    在长时间运行中，直接乘积概率 p 会迅速下溢到 0.0 或溢出到 1.0。
    对数几率定义：l = \ln(p / (1 - p))
    更新方程完全退化为无溢出加法：l_post = l_prior + \ln(p(z|x) / p(z|~x)) - l_0
    """

    def __init__(self, n_cells: int = 100, prior_prob: float = 0.5):
        self.n_cells = n_cells
        self.l_0 = math.log(prior_prob / (1.0 - prior_prob))
        # 初始对数几率向量
        self.l_grid = np.full(n_cells, self.l_0, dtype=float)

    def update_log_odds(self, measurement_log_odds: np.ndarray, l_min: float = -5.0, l_max: float = 5.0):
        """累加对数几率增量并进行饱和截断。"""
        self.l_grid = np.clip(self.l_grid + measurement_log_odds - self.l_0, l_min, l_max)

    def get_probabilities(self) -> np.ndarray:
        """从对数几率恢复连续物理概率：p = 1 - 1 / (1 + exp(l))。"""
        return 1.0 - 1.0 / (1.0 + np.exp(self.l_grid))

    @staticmethod
    def log_sum_exp(log_weights: np.ndarray) -> float:
        """数值稳定的 Log-Sum-Exp 归一化技巧，防止指数上溢与下溢。"""
        max_lw = np.max(log_weights)
        if not np.isfinite(max_lw):
            return 0.0
        return float(max_lw + np.log(np.sum(np.exp(log_weights - max_lw))))
```

## 2.6 强非线性观测下的高斯二阶矩畸变推导 {#sec-embodied.1.2.6}

在第 3 章深入卡尔曼滤波前，必须从数学上彻底证明：**当观测函数存在强非线性时，一阶泰勒展开会必然产生固有系统偏差（Bias）**。

设状态 $x \in \mathbb{R}^n$ 服从对称高斯分布 $x \sim \mathcal{N}(\mu, \Sigma)$。观测函数 $z = g(x)$ 在均值点 $\mu$ 进行二阶多元泰勒展开：

$$
g(x) \approx g(\mu) + \nabla g(\mu)^T (x - \mu) + \frac{1}{2} (x - \mu)^T \nabla^2 g(\mu) (x - \mu)
$$

两边取数学期望：
- 线性一阶项期望为零：$\mathbb{E}[\nabla g(\mu)^T (x - \mu)] = \nabla g(\mu)^T \mathbb{E}[x - \mu] = 0$；
- 二阶项利用矩阵迹（Trace）性质：
  $$
  \mathbb{E}\left[ (x - \mu)^T \nabla^2 g(\mu) (x - \mu) \right] = \mathbb{E}\left[ \mathrm{Tr}\Big( \nabla^2 g(\mu) (x - \mu)(x - \mu)^T \Big) \right] = \mathrm{Tr}\Big( \nabla^2 g(\mu) \Sigma \Big)
  $$

因此，非线性观测的真实均值为：

$$
\mathbb{E}[g(x)] = g(\mu) + \frac{1}{2} \mathrm{Tr}\Big( \nabla^2 g(\mu) \Sigma \Big)
$$

而在经典 EKF 中，预测观测值被粗暴地假设为 $g(\mu)$。只要观测函数的二阶海森矩阵（Hessian）$\nabla^2 g(\mu)$ 非零（如雷达极坐标测距 $r = \sqrt{x^2 + y^2}$、相机透视投影除法 $x/z$），**EKF 的观测残差就必然包含大小为 $\frac{1}{2} \mathrm{Tr}(\nabla^2 g \Sigma)$ 的固有不可消除偏差**！当机器人位置不确定性 $\Sigma$ 较大时，这种偏差会直接导致滤波器发散。

### 2.6.2 极坐标变换的向内径向收缩定理（Lerro & Bar-Shalom 定理）

为了让读者在工程中切身体会非线性对高斯假设的破坏，我们以激光雷达与毫米波雷达极坐标测量转笛卡儿坐标为例。

设雷达测量真实极坐标距离 $r_m = r + v_r$，方位角 $\theta_m = \theta + v_\theta$，其中 $v_r \sim \mathcal{N}(0, \sigma_r^2)$ 与 $v_\theta \sim \mathcal{N}(0, \sigma_\theta^2)$ 相互独立。
若直接通过欧几里得解析三角函数计算笛卡儿坐标：

$$
x_m = r_m \cos\theta_m,\qquad y_m = r_m \sin\theta_m
$$

很多算法工程师直接认为 $\mathbb{E}[x_m] = r \cos\theta$。然而根据高斯特征函数的数学积分：

$$
\mathbb{E}[\cos v_\theta] = \int_{-\infty}^{\infty} \cos(v) \frac{1}{\sqrt{2\pi}\sigma_\theta} e^{-\frac{v^2}{2\sigma_\theta^2}}\,\mathrm{d}v = e^{-\frac{\sigma_\theta^2}{2}}
$$

$$
\mathbb{E}[\sin v_\theta] = 0
$$

利用独立随机变量积的期望等于期望的积，展开计算 $x_m$ 的真实数学期望：

$$
\begin{aligned}
\mathbb{E}[x_m] &= \mathbb{E}[(r + v_r)(\cos\theta \cos v_\theta - \sin\theta \sin v_\theta)] \\
&= \mathbb{E}[r + v_r] \cdot \left( \cos\theta \mathbb{E}[\cos v_\theta] - \sin\theta \mathbb{E}[\sin v_\theta] \right) \\
&= r \cdot e^{-\frac{\sigma_\theta^2}{2}} \cos\theta
\end{aligned}
$$

同理可得：

$$
\mathbb{E}[y_m] = r \cdot e^{-\frac{\sigma_\theta^2}{2}} \sin\theta
$$

注意出现的**指数衰减因子 $e^{-\frac{\sigma_\theta^2}{2}} \lt 1$**！
这意味着：**任何直接通过三角函数转换雷达极坐标的滤波算法，在数学期望上必然把障碍物系统性地向雷达原点拉近！**
当测角不确定性 $\sigma_\theta = 5^\circ \approx 0.087\,\mathrm{rad}$ 时，衰减系数为 $e^{-0.087^2/2} \approx 0.9962$。在 100 米远处，目标位置会被向内拉近近 0.4 米！如果滤波代码没有进行非线性二阶矩补偿，机器人就会误认为障碍物距离偏近，并在高速行驶时产生突发性的不合理急刹。

以下代码直观复现了这种非线性径向内缩现象：

```python
import numpy as np


def verify_polar_radial_bias():
    """验证极坐标高斯噪声转换至笛卡儿坐标的向内收缩偏置。"""
    np.random.seed(42)
    r_true = 50.0  # 50m
    th_true = np.radians(30.0)  # 30 deg
    sigma_r = 0.2  # 0.2m 测距标准差
    sigma_th = np.radians(6.0)  # 6 deg 测角标准差

    N = 1000000
    r_samples = np.random.normal(r_true, sigma_r, size=N)
    th_samples = np.random.normal(th_true, sigma_th, size=N)

    # 转换至笛卡儿坐标
    x_samples = r_samples * np.cos(th_samples)
    y_samples = r_samples * np.sin(th_samples)

    mc_x = float(np.mean(x_samples))
    mc_y = float(np.mean(y_samples))

    # 理论预测
    attenuation = np.exp(-0.5 * (sigma_th**2))
    pred_x = r_true * attenuation * np.cos(th_true)
    pred_y = r_true * attenuation * np.sin(th_true)

    naive_x = r_true * np.cos(th_true)
    naive_y = r_true * np.sin(th_true)

    print(f"朴素无偏假设坐标 (Naive):   x={naive_x:.4f}, y={naive_y:.4f}")
    print(f"真实蒙特卡洛经验坐标 (MC):     x={mc_x:.4f}, y={mc_y:.4f}")
    print(f"二阶补偿理论预测坐标 (Theory): x={pred_x:.4f}, y={pred_y:.4f}")
    print(f"向内系统性径向收缩距离:      {r_true - np.hypot(mc_x, mc_y):.4f} m")

if __name__ == "__main__":
    verify_polar_radial_bias()
```

### 2.7.2 根因排查与工程启示

单峰高斯假设（如标准卡尔曼滤波、EKF）的根本缺陷在于：它用一个单一的二次型椭球去拟合多模态分布。当系统面临双峰分布时，EKF 计算出的加权均值直接落入了两峰之间的概率低谷甚至不可能区域，且协方差更新公式强行将方差缩小，形成所谓的“虚假收敛（False Confidence）”。

#### 1. KL 散度视角下的拟合病态证明

设真实多模态后验分布为双峰高斯混合分布：

$$
p(x) = \frac{1}{2} \mathcal{N}(x;\ \mu_1,\ \sigma^2) + \frac{1}{2} \mathcal{N}(x;\ \mu_2,\ \sigma^2),\qquad |\mu_1 - \mu_2| \gg \sigma
$$

如果强行用单一高斯分布 $q(x) = \mathcal{N}(x;\ \mu_q,\ \sigma_q^2)$ 进行近似拟合，选择不同的 Kullback-Leibler (KL) 散度优化方向会产生完全不同的灾难：

- **正向 KL 散度（Forward KL / 矩匹配，Moment Matching）**：
  $$
  \min_q D_{KL}(p \parallel q) = \int p(x) \ln \frac{p(x)}{q(x)}\,\mathrm{d}x
  $$
  要求 $q(x)$ 覆盖 $p(x)$ 的所有支撑集（Zero-avoiding）。最优解被迫将均值置于中点 $\mu_q = \frac{\mu_1 + \mu_2}{2}$，而方差被剧烈拉大为：
  $$
  \sigma_q^2 = \sigma^2 + \frac{1}{4} (\mu_1 - \mu_2)^2
  $$
  均值落入了概率几乎为零的荒谬区域！
- **反向 KL 散度（Reverse KL / 寻模特性，Mode Seeking）**：
  $$
  \min_q D_{KL}(q \parallel p) = \int q(x) \ln \frac{q(x)}{p(x)}\,\mathrm{d}x
  $$
  $q(x)$ 必须避开 $p(x)$ 为零的区域（Zero-forcing），最终只能随机塌陷锁定在其中一个局部峰值上，彻底遗忘另一个同等可能的假设。

在高度对称或退化环境中，状态估计必须升级为：
1. **多重假设追踪（Multiple Hypothesis Tracking, MHT）** 或高斯混合模型（GMM）；
2. **非参数化粒子滤波（MCL）**（第 4 章详解）；
3. **位姿图延迟回环决断机制**（第 9 章详解）。

#### 2. 双模态崩溃最小复现脚本

以下代码直接复现了双模态似然注入下，标准 EKF 与高斯混合滤波（GMF）的不同表现：

```python
import numpy as np


def simulate_multimodal_collapse():
    """复现单峰高斯假设在双模态走廊中的虚假收敛与均值陷阱。"""
    np.random.seed(42)

    # 真实环境：走廊中有两个对称门，分别位于 x = 8.0m 和 x = 12.0m
    # 机器人真实位于 x = 12.0m，但里程计报告先验 x_prior = 10.0m, P_prior = 4.0
    x_prior = 10.0
    P_prior = 4.0

    # 传感器测得“正处于门前”，似然函数为双峰混合高斯
    doors = [8.0, 12.0]
    sigma_meas = 0.3

    # 1. 传统 EKF 做法：线性化点取在先验均值 10.0 处，由于对称性，雅可比正负对消
    # 强行以门 8.0 作为最近关联点进行 EKF 单步更新：
    H = 1.0
    z = 8.0  # 误关联到 8.0m 的门
    K = P_prior * H / (H * P_prior * H + sigma_meas**2)
    x_ekf_wrong = x_prior + K * (z - x_prior)
    P_ekf = (1.0 - K * H) * P_prior

    # 2. 真实后验网格离散积分 (Ground Truth)
    xs = np.linspace(5.0, 15.0, 1000)
    prior_pdf = np.exp(-0.5 * ((xs - x_prior)**2) / P_prior)
    likelihood_pdf = 0.5 * np.exp(-0.5 * ((xs - 8.0)**2) / (sigma_meas**2)) + \
                     0.5 * np.exp(-0.5 * ((xs - 12.0)**2) / (sigma_meas**2))
    post_pdf = prior_pdf * likelihood_pdf
    post_pdf /= np.trapz(post_pdf, xs)

    # 计算真实后验的均值与双峰位置
    true_mean = np.trapz(xs * post_pdf, xs)
    peaks = [xs[np.argmax(post_pdf[:500])], xs[500 + np.argmax(post_pdf[500:])]]

    print(f"先验估计位置: {x_prior:.2f} m (真实位置在 12.0m)")
    print(f"真实后验双峰位置: {peaks[0]:.2f} m 与 {peaks[1]:.2f} m")
    print(f"真实后验期望均值: {true_mean:.2f} m (物理上根本没有门的中点空白区)")
    print(f"传统 EKF 误收敛位置: {x_ekf_wrong:.2f} m, 协方差被压缩为: {P_ekf:.4f} (虚假收敛！)")

if __name__ == "__main__":
    simulate_multimodal_collapse()
```

| 9 | 混淆 MAP 众数与均值 | 在强偏斜分布（如对数正态）中将 MAP 峰值当作条件期望 | 输出的控制量无法最小化均方物理误差，产生持续稳态偏置 | 在非对称分布下明确选择 MMSE（期望）作为最优控制输入 |
| 10 | 归一化常数除零崩溃 | 当外部所有传感器观测与先验分布无任何空间重合时 | 分母 $\eta = 1/0$，滤波器产生全矩阵 `NaN` 并中断进程 | 增加常数逃逸背景底噪：$p_{safe}(z \mid x) = (1-\epsilon) p(z \mid x) + \epsilon p_{uniform}$ |
| 11 | 概率矩阵存储内存爆炸 | 在三维连续位姿空间构建高分辨率离散网格（$1000^3$ 个单元） | 显存与内存迅速爆仓耗尽，计算一次全概率卷积耗时数十秒 | 仅在拓扑拓扑骨架上使用离散网格，空间连续位姿采用八叉树/流形压缩 |
| 12 | 忽略环境反光动态隐变量 | 玻璃幕墙反射虚假镜像，机器人认为后方走廊存在虚假孪生镜像 | 镜像似然误导机器人掉头并撞向真实幕墙玻璃 | 结合红外超声波与多几何约束对光电观测进行交叉手征性验证 |
