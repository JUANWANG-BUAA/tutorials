在人类与动物的感知系统中，视觉提供了超过 80% 的外部环境信息输入。对于具身智能体而言，**相机（Camera）**是唯一一种能够同时以极高空间分辨率（数百万像素）获取环境**几何轮廓**、**纹理细节**与**丰富语义信息**的传感器。

然而，相机传感器在物理本质上是一个**降维投影装置（Dimension Reduction Projector）**。它将三维连续物理世界的光子通过光学透镜组，投射折射到二维平面的感光元器件（CMOS/CCD）上，这一过程不可避免地丢失了最重要的物理尺度——**深度（Depth, $Z$）**。

为了让机器人“从二维投影图像中逆向恢复出真实三维物理世界”，我们必须攻克三大核心关卡：
1. **光学几何建模**：透镜透视投影与透镜制造缺陷引入的非线性畸变（Pinhole & Distortion Model）；
2. **绝对几何标定**：求解相机内部固有焦距与主点（内参标定），以及双目或多相机之间的刚体相对位姿（外参标定）；
3. **图像不变特征**：在剧烈运动、光照变化与视角倾斜下，依然能从图像中稳定提取具有空间几何指纹意义的不变特征点（Feature Detection & Matching）。

本章系统推导现代计算机视觉与视觉 SLAM 的几何与特征地基，为后续的视觉里程计、光流跟踪、光束法平差（BA）与视觉伺服建立严密的数学支柱。

## 6.1 针孔相机几何模型与透镜畸变数学模型 {#sec-embodied.2.6.1}

光线穿过相机镜头在感光芯片上成像的过程，最早由文艺复兴时期的小孔成像实验所揭示。现代光学镜头利用透镜组汇聚光线，但其几何主干依然遵从经典**针孔相机模型（Pinhole Camera Model）**。

### 6.1.1 针孔相机透视投影全推导

设空间三维点在世界坐标系下为 $P_w = [X_w, Y_w, Z_w]^T$。通过相机的外参矩阵 $T_{cw} = [R_{cw} \mid t_{cw}]$，该点被变换到相机自身的右手光学直角坐标系 $\mathcal{F}_C$（X 轴朝右，Y 轴朝下，Z 轴沿主光轴朝前）：

$$
P_c = \begin{bmatrix} X_c \\ Y_c \\ Z_c \end{bmatrix} = R_{cw} P_w + t_{cw}
$$

::: def 定义 6.1.1 · 相机内参矩阵与齐次像素投影方程 {#def-embodied.2.6.1.1}
点 $P_c$ 经透镜聚焦至距光心物理焦距为 $f$ 的感光成像平面。根据三角形相似定理：

$$
x_n = \frac{X_c}{Z_c},\qquad y_n = \frac{Y_c}{Z_c}
$$

其中 $(x_n, y_n)$ 称为点在**归一化图像平面（Normalized Image Plane，即 $Z = 1$ 平面）**上的物理坐标。
设感光芯片（CMOS）上单位物理尺寸内分布的像素数为：水平方向 $k_x$（像素/米），垂直方向 $k_y$（像素/米）；主光轴与成像平面的交点（主点，Principal Point）在像素平面的坐标为 $(c_x, c_y)$。
定义等效像素焦距为 $f_x = f \cdot k_x$，$f_y = f \cdot k_y$。像素坐标 $(u, v)$ 为：

$$
u = f_x x_n + c_x = f_x \frac{X_c}{Z_c} + c_x
$$

$$
v = f_y y_n + c_y = f_y \frac{Y_c}{Z_c} + c_y
$$

以齐次坐标（Homogeneous Coordinates）形式写成紧凑矩阵投影形式：

$$
Z_c \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = \begin{bmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} X_c \\ Y_c \\ Z_c \end{bmatrix} = K P_c
$$

其中 $K \in \mathbb{R}^{3 \times 3}$ 称为相机的**内参矩阵（Camera Intrinsic Matrix）**。
:::

以下 Python 类实现了完整的针孔相机投影与逆向光线投射：

```python
class PinholeCameraModel:
    """完整针孔相机内参与三维反投影器。"""

    def __init__(self, fx: float, fy: float, cx: float, cy: float, width: int = 640, height: int = 480):
        self.fx, self.fy = float(fx), float(fy)
        self.cx, self.cy = float(cx), float(cy)
        self.W, self.H = int(width), int(height)
        self.K = np.array([[fx, 0.0, cx], [0.0, fy, cy], [0.0, 0.0, 1.0]], dtype=float)
        self.K_inv = np.linalg.inv(self.K)

    def project_3d_to_pixel(self, P_c: np.ndarray) -> tuple:
        """空间点 (X, Y, Z) 投影至像素平面 (u, v)，若 Z <= 0 返回无效。"""
        Z = float(P_c[2])
        if Z <= 1e-4:
            return None, None
        u = self.fx * (float(P_c[0]) / Z) + self.cx
        v = self.fy * (float(P_c[1]) / Z) + self.cy
        if 0 <= u < self.W and 0 <= v < self.H:
            return float(u), float(v)
        return None, None

    def pixel_to_ray(self, u: float, v: float) -> np.ndarray:
        """像素坐标反投影为相机系空间三维单位视线方向光线。"""
        xn = (float(u) - self.cx) / self.fx
        yn = (float(v) - self.cy) / self.fy
        ray = np.array([xn, yn, 1.0], dtype=float)
        return ray / np.linalg.norm(ray)
```

透视投影除法（除以深度 $Z_c$）是一个高度非线性的代数操作。它不仅破坏了欧几里得距离，而且将无穷远处的三维点映射为图像上的消失点（Vanishing Point）。在三维点云投影计算中，必须在执行除法前严格过滤 $Z_c \le 0$ 的非物理位于相机光心后方的背向点，以防止产生无意义的负坐标反转投射。

### 6.1.2 Brown-Conrady 径向与切向畸变方程

真实的透镜由多片球面或非球面玻璃研磨而成。由于光学工艺限制，光线在透镜边缘的折射偏转往往大于或小于中心透射，这种物理缺陷被称为**像差畸变（Lens Distortion）**。

畸变通常由两类物理机理引起：
1. **径向畸变（Radial Distortion）**：透镜自身的球面几何形状导致远离中心的边缘光线产生桶形（Barrel）或枕形（Pincushion）向外/向内弯折；
2. **切向畸变（Tangential Distortion）**：相机组装时透镜平面与感光芯片 CMOS 平面未能实现绝对平行（存在微小倾角安装公差）导致的透视拉伸。

::: def 定义 6.1.2 · Brown-Conrady 经典非线性多项式畸变模型 {#def-embodied.2.6.1.2}
设归一化平面理想无畸变坐标为 $(x, y)$，其距主光轴中心的半径平方为 $r^2 = x^2 + y^2$。
引入径向畸变系数 $k_1, k_2, k_3$ 与切向畸变系数 $p_1, p_2$，真实感光芯片接收到的畸变后坐标 $(x_{\text{dist}}, y_{\text{dist}})$ 满足多项式非线性展开：

$$
x_{\text{dist}} = x \Big( 1 + k_1 r^2 + k_2 r^4 + k_3 r^6 \Big) + \underbrace{2 p_1 x y + p_2 (r^2 + 2 x^2)}_{\text{切向分量}}
$$

$$
y_{\text{dist}} = y \Big( 1 + k_1 r^2 + k_2 r^4 + k_3 r^6 \Big) + \underbrace{p_1 (r^2 + 2 y^2) + 2 p_2 x y}_{\text{切向分量}}
$$

最终投影到像素平面的坐标为：$u = f_x x_{\text{dist}} + c_x$，$v = f_y y_{\text{dist}} + c_y$。
:::

对于广角镜头或鱼眼镜头，多项式阶数需扩展，或采用广角等距投影模型（Equidistant / Kannala-Brandt 模型）：$r(\theta) = k_1 \theta + k_2 \theta^3 + k_3 \theta^5 + k_4 \theta^7$。

### 6.1.3 牛顿迭代数值去畸变逆映射实现

上述 Brown-Conrady 模型是一个典型的**前向非线性映射（Forward Mapping）**：给定理想归一化坐标 $(x, y)$，可以直接解析代入计算出畸变坐标 $(x_d, y_d)$。
然而，在图像去畸变（Undistortion）与特征点校正中，我们需要解决**反向问题**：从测得的真实畸变像素 $(u, v)$，反解出未畸变的物理空间光线方向 $(x, y)$。

由于式中含有 $r^6$ 高阶多项式，不存在代数解析闭式反函数。工程上采用多维**牛顿-拉夫逊数值迭代法（Newton-Raphson Iteration）**进行亚像素反解：

```python
import numpy as np


def undistort_normalized_point(xd: float, yd: float,
                               k1: float, k2: float, p1: float, p2: float,
                               max_iter: int = 15, tol: float = 1e-8) -> tuple:
    """利用牛顿迭代法求解 Brown-Conrady 去畸变逆映射。"""
    x, y = xd, yd
    for _ in range(max_iter):
        r2 = x**2 + y**2
        radial = 1.0 + k1 * r2 + k2 * (r2**2)

        # 当前迭代点的正向残差 f(x)
        fx = x * radial + 2.0 * p1 * x * y + p2 * (r2 + 2.0 * x**2) - xd
        fy = y * radial + p1 * (r2 + 2.0 * y**2) + 2.0 * p2 * x * y - yd

        if abs(fx) < tol and abs(fy) < tol:
            break

        # 解析雅可比矩阵 J = \partial f / \partial (x, y)
        d_rad_dx = 2.0 * k1 * x + 4.0 * k2 * r2 * x
        d_rad_dy = 2.0 * k1 * y + 4.0 * k2 * r2 * y

        dfx_dx = radial + x * d_rad_dx + 2.0 * p1 * y + 6.0 * p2 * x
        dfx_dy = x * d_rad_dy + 2.0 * p1 * x + 2.0 * p2 * y
        dfy_dx = y * d_rad_dx + 2.0 * p1 * x + 2.0 * p2 * y
        dfy_dy = radial + y * d_rad_dy + 6.0 * p1 * y + 2.0 * p2 * x

        J = np.array([[dfx_dx, dfx_dy],
                      [dfy_dx, dfy_dy]], dtype=float)

        delta = np.linalg.solve(J, np.array([fx, fy]))
        x -= delta[0]
        y -= delta[1]

    return float(x), float(y)
```

## 6.2 双目立体视觉与深度恢复原理 {#sec-embodied.2.6.2}

单目相机无法恢复绝对尺度，而人类的双眼通过两眼之间的物理间距（基线，Baseline）感知三维空间深度。**双目立体相机（Stereo Camera）**是移动机器人恢复稠密三维点云的标准物理装置。

### 6.2.1 极线校正（Epipolar Rectification）与视差公式

设左右两个平行相机的光轴完全平行，垂直于基线连接线，焦距同为 $f$，两相机光心在水平轴上的物理距离为基线 $b$。
空间三维点 $P = [X, Y, Z]^T$ 投影到左目图像平面的物理坐标为 $x_L$，投影到右目图像平面的物理坐标为 $x_R$。

根据几何三角形相似：

$$
\frac{x_L}{f} = \frac{X}{Z},\qquad \frac{x_R}{f} = \frac{X - b}{Z}
$$

两式相减，消去空间坐标 $X$：

$$
x_L - x_R = \frac{f b}{Z}
$$

::: def 定义 6.2.1 · 视差（Disparity）与双目测距公式 {#def-embodied.2.6.2.1}
定义左右图像对应同名像素点的水平坐标差为**视差（Disparity, $d$）**：

$$
d \triangleq u_L - u_R = x_L - x_R \ge 0
$$

空间物体的三维绝对物理深度 $Z$ 由下式确定：

$$
Z = \frac{f \cdot b}{d}
$$

物体的空间三维坐标完全恢复为：

$$
X = \frac{(u_L - c_x) \cdot b}{d},\qquad Y = \frac{(v_L - c_y) \cdot b}{d},\qquad Z = \frac{f \cdot b}{d}
$$
:::

### 6.2.2 视差深度非线性敏感度与误差传播

通过对深度公式求微分，探究视差误差 $\delta d$（通常源于像素离散量化，大小约为 0.5 像素）对深度误差 $\delta Z$ 的放大效应：

$$
\delta Z = \left| \frac{\partial Z}{\partial d} \right| \delta d = \frac{f b}{d^2} \delta d = \frac{Z^2}{f b} \delta d
$$

核心物理规律在此暴露无遗：**双目相机的测距误差随距离呈二次方 $\mathcal{O}(Z^2)$ 剧烈放大！**
- 近距离（如 $Z = 1\,\mathrm{m}$）时，深度分辨率达到毫米级；
- 远距离（如 $Z = 15\,\mathrm{m}$）时，若基线较短（$b = 0.12\,\mathrm{m}$），微小的 0.5 像素匹配误差会导致超过 **1.5 米** 的深度跳变！
因此，室外远距离自动驾驶系统必须采用大基线双目或多线激光雷达作为补充。

### 6.2.3 半全局立体匹配（SGBM）能量泛函与一维动态规划代价聚合

为了从左右图像对中生成整幅图像的密集视差图，直接逐像素比较局部相关性（如灰度差绝对值和 SAD）会在弱纹理、反光或重复纹理区域产生大面积伪影。Hirschmüller 于 2008 年提出的**半全局立体匹配算法（Semi-Global Matching, SGM / SGBM）**通过定义全局能量泛函，成为了自动驾驶与机器人立体视觉的工业基准。

#### 1. 全局能量泛函定义
设全图视差图为 $D = \{d_p\}$。SGM 的目标是寻找一个使全图总能量最小的视差场分配：

$$
E(D) = \sum_{p} C(p, d_p) + \sum_{q \in \mathcal{N}_p} P_1 \cdot I\Big( |d_p - d_q| = 1 \Big) + \sum_{q \in \mathcal{N}_p} P_2 \cdot I\Big( |d_p - d_q| \gt 1 \Big)
$$

其中：
- $C(p, d_p)$ 为像素 $p$ 匹配到视差 $d_p$ 时的光度匹配代价。在工业立体匹配中，最鲁棒的匹配代价是 **Census 变换（Census Transform）**：
  1. 在以像素 $p$ 为中心的 $7 \times 7$ 局部窗口内，将每个邻域像素与中心像素灰度比较大小生成 48 位二进制位串；
  2. 若邻域灰度大于中心置 1，否则置 0；
  3. 两像素匹配代价直接计算 Census 位串的汉明距离。
  由于 Census 仅依赖像素相对大小关系，它对相机自动曝光变化或非均匀单调光照渐变具有 100% 的天然免疫力；
- $\mathcal{N}_p$ 为像素 $p$ 的 8 邻域或 16 邻域像素；
- $P_1$ 为惩罚小视差突变（相邻像素视差相差 1）的平滑参数，允许斜坡平面或曲面产生平缓的视差渐变；
- $P_2$ 为惩罚大视差突变（深度不连续跳变）的强惩罚参数（$P_2 \gt P_1$），防止在同一连续物体内部产生视差撕裂。

#### 2. 一维多路径动态规划聚合（Path Aggregation）
由于二维网格上的马尔可夫随机场（MRF）能量最小化是 NP-Hard 难题，SGM 将二维图切割分解为 $K = 8$ 或 $K = 16$ 条独立的**一维射线方向路径 $r$**，在每条一维路径上运行动态规划（DP）递推：

$$
L_r(p, d) = C(p, d) + \min\begin{cases}
L_r(p - r, d) \\
L_r(p - r, d - 1) + P_1 \\
L_r(p - r, d + 1) + P_1 \\
\min_{i} L_r(p - r, i) + P_2
\end{cases} - \min_{i} L_r(p - r, i)
$$

其中末尾减去 $\min_i L_r(p - r, i)$ 是一项极为精妙的**数值防溢出归一化操作**，保证了在长距离递推时代价值不会无限累加至浮点数饱和。

将所有方向的聚合代价值求和，最终视差由胜者为王（Winner-Takes-All, WTA）准则选出：

$$
S(p, d) = \sum_{r=1}^K L_r(p, d),\qquad d_p^* = \arg\min_d S(p, d)
$$

以下代码演示了一维水平路径上的动态规划代价聚合核心循环：

```python
def sgbm_1d_path_aggregation(cost_volume: np.ndarray, P1: float = 10.0, P2: float = 50.0):
    """一维水平向右路径 SGM 代价聚合。cost_volume 尺寸: (H, W, D_max)。"""
    H, W, D = cost_volume.shape
    L_r = np.zeros_like(cost_volume)

    # 初始第 0 列边界
    L_r[:, 0, :] = cost_volume[:, 0, :]

    for x in range(1, W):
        prev_L = L_r[:, x - 1, :]  # (H, D)
        min_prev = np.min(prev_L, axis=1, keepdims=True)

        for d in range(D):
            c_curr = cost_volume[:, x, d]
            v0 = prev_L[:, d]
            v1 = prev_L[:, d - 1] + P1 if d > 0 else np.full(H, 1e6)
            v2 = prev_L[:, d + 1] + P1 if d < D - 1 else np.full(H, 1e6)
            v3 = min_prev.flatten() + P2

            min_term = np.minimum(np.minimum(v0, v1), np.minimum(v2, v3))
            # 聚合代价值与数值防溢出
            L_r[:, x, d] = c_curr + min_term - min_prev.flatten()

    return L_r
```

## 6.3 张正友标定法：单应矩阵分解与内参闭式解推导 {#sec-embodied.2.6.3}

在 1998 年以前，相机标定通常需要极其昂贵、精密加工的三维空间三维标定架。微软研究院张正友博士提出的**平面棋盘格标定法（Zhang's Calibration Method）**，彻底革新了计算机视觉工业界：**仅需打印一张平面棋盘格贴在硬纸板上，手持相机从不同角度拍摄多张照片，即可高精度求解出相机的全部内参与畸变参数**。

### 6.3.1 平面单应性矩阵（Homography）推导

不失一般性，我们将标定世界坐标系建立在平面棋盘格所在的平面上，且令 $Z_w = 0$。棋盘格上的所有角点坐标简化为 $P_w = [X_w, Y_w, 0, 1]^T$。

将透视投影方程展开：

$$
Z_c \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = K \begin{bmatrix} r_1 & r_2 & r_3 & t \end{bmatrix} \begin{bmatrix} X_w \\ Y_w \\ 0 \\ 1 \end{bmatrix} = K \begin{bmatrix} r_1 & r_2 & t \end{bmatrix} \begin{bmatrix} X_w \\ Y_w \\ 1 \end{bmatrix}
$$

注意到旋转矩阵的第三列 $r_3$ 由于乘以 $Z_w = 0$ 被完全消去！
定义 $3 \times 3$ 单应矩阵（Homography Matrix）$H$：

$$
H = \begin{bmatrix} h_1 & h_2 & h_3 \end{bmatrix} = \lambda K \begin{bmatrix} r_1 & r_2 & t \end{bmatrix}
$$

其中 $\lambda$ 为尺度标量。平面上的角点 $(X_w, Y_w)$ 到像素 $(u, v)$ 的映射完全由单应矩阵决定：

$$
s \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = H \begin{bmatrix} X_w \\ Y_w \\ 1 \end{bmatrix}
$$

每个棋盘格角点提供 2 个独立的线性方程约束。单应矩阵具有 8 个独立自由度（归一化），因此只要在一张图像中检测到 **4 对以上不共线的角点**，即可通过直接线性变换（DLT）结合 SVD 分解唯一解出该图像对应的单应矩阵 $H$。

### 6.3.2 利用旋转正交约束解算内参矩阵 B

求解出每张图的 $H = [h_1, h_2, h_3]$ 后，利用旋转矩阵正交性：

$$
r_1 = \frac{1}{\lambda} K^{-1} h_1,\qquad r_2 = \frac{1}{\lambda} K^{-1} h_2
$$

由于旋转矩阵各列为互相垂直的正交单位向量：
1. **正交条件**：$r_1^T r_2 = 0 \implies h_1^T K^{-T} K^{-1} h_2 = 0$；
2. **等模长条件**：$\|r_1\| = \|r_2\| = 1 \implies h_1^T K^{-T} K^{-1} h_1 = h_2^T K^{-T} K^{-1} h_2$。

定义绝对二次曲面投影矩阵（内参对称矩阵）$B$：

$$
B \triangleq K^{-T} K^{-1} = \begin{bmatrix}
B_{11} & B_{12} & B_{13} \\
B_{12} & B_{22} & B_{23} \\
B_{13} & B_{23} & B_{33}
\end{bmatrix} \in \mathbb{R}^{3 \times 3}
$$

由于 $B$ 为对称矩阵，只有 6 个独立未知数，写成 6 维列向量：

$$
b = \begin{bmatrix} B_{11} & B_{12} & B_{22} & B_{13} & B_{23} & B_{33} \end{bmatrix}^T \in \mathbb{R}^6
$$

两项正交约束可以严格展开为关于向量 $b$ 的两个线性齐次方程：

$$
\begin{bmatrix} v_{12}^T \\ (v_{11} - v_{22})^T \end{bmatrix} b = 0
$$

其中 $v_{ij} \in \mathbb{R}^6$ 由单应矩阵的列元素 $h_i$ 与 $h_j$ 的乘积完全构成。

**结论**：每张棋盘格照片可以提供 2 个独立的线性方程约束。待求未知数 $b$ 共有 5 个自由度（尺度归一化后）。因此，**拍摄 $n \ge 3$ 张不同朝向的棋盘格照片，即可堆叠出 $2n \ge 6$ 个方程构建方程组 $V b = 0$**。

通过对超定矩阵 $V$ 进行 SVD 分解，取对应最小奇异值的右奇异向量即得出 $b$。由 $B$ 矩阵通过 Cholesky 分解逆解出内参矩阵 $K$：

$$
c_y = \frac{B_{12} B_{13} - B_{11} B_{23}}{B_{11} B_{22} - B_{12}^2}
$$

$$
\lambda = B_{33} - \frac{B_{13}^2 + c_y (B_{12} B_{13} - B_{11} B_{23})}{B_{11}}
$$

$$
f_x = \sqrt{\frac{\lambda}{B_{11}}},\qquad f_y = \sqrt{\frac{\lambda B_{11}}{B_{11} B_{22} - B_{12}^2}}
$$

$$
c_x = \frac{\gamma c_y}{f_y} - \frac{B_{13} f_x^2}{\lambda}
$$

解出内参后，外参直接代入闭式解：$r_1 = \lambda K^{-1} h_1, r_2 = \lambda K^{-1} h_2, r_3 = r_1 \times r_2, t = \lambda K^{-1} h_3$。最后以所有角点的重投影误差最小化为目标，调用 Levenberg-Marquardt 非线性优化联合微调所有内参、外参及多项式畸变系数 $(k_1, k_2, p_1, p_2)$。

以下 Python 类完整实现了张正友标定法的线性闭式方程构建与内参矩阵分解：

```python
import numpy as np


class ZhangCalibrationLinearSolver:
    """张正友标定法线性闭式求解器。"""

    @staticmethod
    def create_v_vector(h_i: np.ndarray, h_j: np.ndarray) -> np.ndarray:
        """从单应矩阵的两列 h_i, h_j 构建 6 维约束行向量 v_ij^T。"""
        return np.array([
            h_i[0] * h_j[0],
            h_i[0] * h_j[1] + h_i[1] * h_j[0],
            h_i[1] * h_j[1],
            h_i[2] * h_j[0] + h_i[0] * h_j[2],
            h_i[2] * h_j[1] + h_i[1] * h_j[2],
            h_i[2] * h_j[2]
        ], dtype=float)

    @classmethod
    def solve_intrinsics_from_homographies(cls, H_matrices: list) -> np.ndarray:
        """输入至少 3 个单应矩阵 H_k (3x3)，闭式解出相机内参矩阵 K。"""
        n = len(H_matrices)
        assert n >= 3, "张正友标定至少需要 3 张不同姿态的棋盘格单应矩阵"

        # 堆叠 2n x 6 矩阵 V
        V = np.zeros((2 * n, 6), dtype=float)
        for k in range(n):
            H = H_matrices[k]
            h1 = H[:, 0]
            h2 = H[:, 1]
            v12 = cls.create_v_vector(h1, h2)
            v11 = cls.create_v_vector(h1, h1)
            v22 = cls.create_v_vector(h2, h2)

            V[2 * k] = v12
            V[2 * k + 1] = v11 - v22

        # SVD 分解求解 V * b = 0
        _, _, Vt = np.linalg.svd(V)
        b = Vt[-1]

        # 构造 B 矩阵
        B11, B12, B22, B13, B23, B33 = b

        # 封闭公式恢复内参
        cy = (B12 * B13 - B11 * B23) / (B11 * B22 - B12**2)
        lam = B33 - (B13**2 + cy * (B12 * B13 - B11 * B23)) / B11
        fx = np.sqrt(abs(lam / B11))
        fy = np.sqrt(abs(lam * B11 / (B11 * B22 - B12**2)))
        cx = - (B13 * (fx**2)) / lam

        K = np.array([
            [fx, 0.0, cx],
            [0.0, fy, cy],
            [0.0, 0.0, 1.0]
        ], dtype=float)
        return K
```

## 6.4 特征提取：Harris 角点、FAST 与 ORB 二进制描述子 {#sec-embodied.2.6.4}

从原始图像中恢复相机运动，核心在于建立图像之间像素点的几何对应关系。在纹理均匀的墙壁或光滑曲面上，像素缺乏梯度辨识度；只有**角点（Corner / Keypoint）**具有强烈的全向几何约束。

### 6.4.1 Harris 角点准则与自相关矩阵

Harris 角点检测建立在局部自相关能量函数之上。设图像在微小窗口 $W$ 内平移 $(u, v)$，灰度平方差（SSD）为：

$$
E(u, v) = \sum_{(x, y) \in W} w(x, y) \Big[ I(x + u,\ y + v) - I(x, y) \Big]^2
$$

对图像做一阶泰勒展开 $I(x + u, y + v) \approx I(x, y) + I_x u + I_y v$，化简得到二次型矩阵形式：

$$
E(u, v) \approx \begin{bmatrix} u & v \end{bmatrix} M \begin{bmatrix} u \\ v \end{bmatrix}
$$

其中结构张量（Structure Tensor / 自相关矩阵）$M$ 定义为：

$$
M = \sum_{(x, y) \in W} w(x, y) \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}
$$

矩阵 $M$ 的两个特征值 $\lambda_1, \lambda_2$ 决定了局部像素梯度的椭球形态：
- 若 $\lambda_1 \approx 0, \lambda_2 \approx 0$：平坦区域，无特征；
- 若 $\lambda_1 \gg \lambda_2 \approx 0$：边缘（Edge），只在垂直边缘方向有梯度，沿边缘滑动产生孔径问题（Aperture Problem）；
- **若 $\lambda_1 \gt 0, \lambda_2 \gt 0$ 且均较大**：角点（Corner），全向均有剧烈灰度变化。

Harris 角点响应函数（无需显式特征值分解）：

$$
R = \det(M) - k \cdot (\mathrm{Tr}(M))^2 = \lambda_1 \lambda_2 - k (\lambda_1 + \lambda_2)^2,\qquad k \in [0.04, 0.06]
$$

### 6.4.2 FAST 快速角点检测（Features from Accelerated Segment Test）

在实时视觉 SLAM（要求帧率 $\ge 30\,\mathrm{Hz}$）中，逐像素计算图像梯度与矩阵自相关的 Harris/SIFT 算法算力开销过大。Rosten 等人提出了极速的 **FAST 角点算法**。

#### FAST-16 检测判定准则：
对于候选像素点 $p$，考察其周围半径为 3 像素、圆周长为 16 个像素的 Bresenham 圆周点集 $p_1 \sim p_{16}$。
若圆周上存在连续 $N$ 个像素（通常 $N = 9$ 或 $N = 12$），其灰度值 $I_i$ 均显著高于或显著低于中心像素灰度 $I_p$（超过对比度门限 $\epsilon$）：

$$
I_i \gt I_p + \epsilon\quad \text{或}\quad I_i \lt I_p - \epsilon
$$

则判定中心点 $p$ 为候选角点。

**极速剪枝加速机制（Fast Corner Pruning）**：
检测时无需遍历全部 16 个像素，先检查正交的四个关键点 $p_1, p_5, p_9, p_{13}$。仅当这 4 个点中**至少有 3 个点**同时满足变亮或变暗条件时，才继续检查其余像素；否则在 4 次访存操作后立即剔除该点。该策略直接剪枝过滤了全图 80% 以上的平坦像素。

### 6.4.3 ORB（Oriented FAST + Rotated BRIEF）特征系统

经典的 FAST 角点虽然极快，但存在两大致命缺陷：**不具备尺度不变性**，且**不具备旋转不变性**。Rublee 等人在 2011 年提出了 **ORB 特征算法**，通过极具工程智慧的方案彻底解决了这一问题。

#### 1. 尺度不变性：图像高斯金字塔（Image Pyramid）
在输入图像上构建多层降采样金字塔（如 8 层，缩放尺度因子 1.2）。在每一层金字塔上分别提取 FAST 角点，从而使同一物理尺度的物体特征在不同远近视距下都能被某一层金字塔捕获。

#### 2. 旋转不变性：灰度质心法（Intensity Centroid）推导
设角点局部邻域图像块 $B$ 的图像矩（Image Moments）定义为：

$$
m_{pq} = \sum_{x, y \in B} x^p y^q I(x, y)
$$

角点邻域的“灰度质心（Centroid）”坐标为：

$$
C = \left( \frac{m_{10}}{m_{00}},\ \frac{m_{01}}{m_{00}} \right)
$$

定义从几何中心 $O(0, 0)$ 指向灰度质心 $C$ 的向量作为该角点的**特征主方向（Orientation）**：

$$
\theta = \mathrm{atan2}(m_{01},\ m_{10})
$$

#### 3. 描述子：带旋转补偿的 Steered BRIEF（rBRIEF）
BRIEF 描述子通过在关键点邻域内随机选取 256 对点 $(p_i, q_i)$，比较其灰度大小输出一个 256 位（32 字节 uint8）的二进制比特串：

$$
\tau(p, x, y) = \begin{cases} 1, & I(p + x) \lt I(p + y) \\ 0, & \text{其他} \end{cases}
$$

为了使描述子在图像旋转时不失效，ORB 将 256 对采样点根据主方向 $\theta$ 进行二维刚体旋转变换：

$$
S_\theta = R_\theta \cdot S = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix} \begin{bmatrix} x_1 & \dots & x_{256} \\ y_1 & \dots & y_{256} \end{bmatrix}
$$

利用旋转后的点对矩阵生成描述子，使其具备完全的二维刚体旋转不变性。

以下 Python 类实现了 FAST 角点快速检测与灰度质心方向提取：

```python
import math
import numpy as np


class FastFeatureExtractor:
    """FAST-16 角点检测与灰度质心主方向提取器。"""

    # 半径为 3 的 16 个圆周像素相对坐标偏移 (dy, dx)
    CIRCLE_OFFSETS = [
        (-3, 0), (-3, 1), (-2, 2), (-1, 3),
        (0, 3), (1, 3), (2, 2), (3, 1),
        (3, 0), (3, -1), (2, -2), (1, -3),
        (0, -3), (-1, -3), (-2, -2), (-3, -1)
    ]

    def __init__(self, threshold: int = 20, patch_radius: int = 15):
        self.threshold = threshold
        self.patch_radius = patch_radius

    def detect_keypoints(self, image_gray: np.ndarray) -> list:
        """快速检测角点位置列表 [(y, x), ...]"""
        H, W = image_gray.shape
        keypoints = []
        t = self.threshold

        # 遍历图像中心内部像素
        for y in range(3, H - 3):
            for x in range(3, W - 3):
                Ip = int(image_gray[y, x])

                # 极速四点剪枝测试 (点 0, 4, 8, 12 对应 12点、3点、6点、9点方向)
                p0 = int(image_gray[y - 3, x])
                p4 = int(image_gray[y, x + 3])
                p8 = int(image_gray[y + 3, x])
                p12 = int(image_gray[y, x - 3])

                brighter = (p0 > Ip + t) + (p4 > Ip + t) + (p8 > Ip + t) + (p12 > Ip + t)
                darker = (p0 < Ip - t) + (p4 < Ip - t) + (p8 < Ip - t) + (p12 < Ip - t)

                if brighter < 3 and darker < 3:
                    continue

                # 完整 16 点环形圆周测试（检测是否有连续 9 个点亮或暗）
                circle_vals = [int(image_gray[y + dy, x + dx]) for dy, dx in self.CIRCLE_OFFSETS]
                # 复制一圈以处理跨 16-0 边界的连续段
                extended = circle_vals + circle_vals[:8]

                # 统计最长连续变亮/变暗长度
                max_bright = 0; curr_b = 0
                max_dark = 0; curr_d = 0
                for val in extended:
                    if val > Ip + t:
                        curr_b += 1; max_bright = max(max_bright, curr_b)
                    else:
                        curr_b = 0

                    if val < Ip - t:
                        curr_d += 1; max_dark = max(max_dark, curr_d)
                    else:
                        curr_d = 0

                if max_bright >= 9 or max_dark >= 9:
                    keypoints.append((y, x))

        return keypoints

    def compute_orientation(self, image_gray: np.ndarray, y: int, x: int) -> float:
        """通过图像局部矩求取灰度质心主方向 angle (rad)。"""
        r = self.patch_radius
        H, W = image_gray.shape
        y_min = max(y - r, 0); y_max = min(y + r + 1, H)
        x_min = max(x - r, 0); x_max = min(x + r + 1, W)

        patch = image_gray[y_min:y_max, x_min:x_max].astype(float)
        dy_coords, dx_coords = np.meshgrid(np.arange(y_min - y, y_max - y),
                                           np.arange(x_min - x, x_max - x), indexing="ij")

        # 图像矩 m10 与 m01
        m10 = float(np.sum(dx_coords * patch))
        m01 = float(np.sum(dy_coords * patch))

        return float(math.atan2(m01, m10))
```

## 6.5 特征匹配度量与 RANSAC 鲁棒单应性几何验证 {#sec-embodied.2.6.5}

在两帧连续图像间建立特征对应关系时，必须解决两个核心问题：**距离度量（Distance Metric）**与**误匹配过滤（Outlier Rejection）**。

### 6.5.1 汉明距离（Hamming Distance）与极速 POPCNT 指令

对于 SIFT/SURF 等浮点描述子（128 维 Float），两点之间的匹配需要计算昂贵的欧几里得距离，单次耗时涉及数百次浮点乘加运算。
而 ORB 描述子为 256 比特二进制串，其相似度度量为**汉明距离（Hamming Distance）**——即两个二进制序列中不同比特的个数：

$$
D_{\mathrm{Hamming}}(d_1, d_2) = \mathrm{popcount}(d_1 \oplus d_2)
$$

其中 $\oplus$ 为按位异或运算，$\mathrm{popcount}$ 为统计二进制中为 1 的位数。现代 x86 与 ARM CPU 原生提供了单周期硬件指令（如 Intel `POPCNT` 指令与 ARM `VCNT` NEON 指令）。计算一对特征的汉明距离仅需 **几纳秒**，匹配速度比浮点描述子快 **两个数量级**。

为了剔除模糊匹配，匹配时通常执行**劳氏比值检验（Lowe's Ratio Test）**：若最佳匹配汉明距离 $d_1$ 与次佳匹配汉明距离 $d_2$ 的比值 $d_1 / d_2 \gt 0.8$，说明环境存在相似对称纹理，该候选对直接被视作歧义点丢弃。

### 6.5.2 RANSAC 随机抽样一致算法数学推导

无论前端特征匹配多么严格，光照突变、动态遮挡与周期性重复纹理依然会产生 10%–40% 的错误假阳性匹配对（Outliers）。**RANSAC（Random Sample Consensus）**是消除外点的最强几何滤镜。

::: thm 定理 6.5.1 · RANSAC 抽样迭代次数理论下界公式 {#thm-embodied.2.6.5.1}
设全集匹配对中真实内点（Inliers）的比例为 $w \in (0, 1]$。计算某种几何模型（如求解单应矩阵 $H$ 需要 $p = 4$ 对点，求解基础矩阵 $F$ 需要 $p = 8$ 对点）所需的最少点数为 $p$。
为了以至少 $1 - \gamma$ 的置信概率（通常设定 $\gamma = 0.01$，即 99% 的置信度）保证至少有一次抽取的 $p$ 个样本全部为真实内点，所必需的**最小随机抽样迭代次数 $K$** 为：

$$
K = \frac{\ln(\gamma)}{\ln(1 - w^p)} = \frac{\ln(1 - P_{\text{success}})}{\ln(1 - w^p)}
$$
:::

::: proof 证明
在单次随机抽取中，$p$ 个点全部为内点的概率为 $w^p$。
因此，单次抽样至少包含一个错误外点的概率为 $1 - w^p$。
连续执行 $K$ 次独立抽样，所有 $K$ 次抽样全部失败（每次都至少抽到一个外点）的概率为：

$$
P_{\text{all\_fail}} = (1 - w^p)^K
$$

我们要求系统总失败率小于等于预设阈值 $\gamma$：

$$
(1 - w^p)^K \le \gamma
$$

两边取自然对数，由于 $1 - w^p \lt 1$，其对数为负数，不等号方向翻转：

$$
K \ln(1 - w^p) \le \ln\gamma \implies K \ge \frac{\ln\gamma}{\ln(1 - w^p)}
$$

证毕。
:::

#### 迭代次数数值分析表（设定 $p=4$，求解平面单应性）：
| 真实内点比例 $w$ | 99% 置信度所需迭代次数 $K$ | 99.9% 置信度所需迭代次数 $K$ |
|:--|--:|--:|
| **90%** ($w = 0.9$) | **5 次** | **8 次** |
| **70%** ($w = 0.7$) | **17 次** | **26 次** |
| **50%** ($w = 0.5$) | **72 次** | **106 次** |
| **30%** ($w = 0.3$) | **566 次** | **849 次** |

该表清晰地指导了工程调优：当环境特征质量极差（内点率降至 30%）时，若仍然沿用默认的 100 次 RANSAC 迭代，算法有高达 44% 的概率直接漏检正确几何模型！必须根据图像质量动态提升迭代上限。

### 6.5.3 归一化八点法（Normalized 8-Point Algorithm）与桑普森距离 RANSAC

在一般三维立体场景中，两视图特征匹配满足基础矩阵对极几何约束：

$$
x_2^T F x_1 = 0,\qquad F \in \mathbb{R}^{3 \times 3}
$$

直接使用未归一化的原始图像像素坐标（如 $u \approx 1000$）构建方程，矩阵 $A$ 的列范数会相差高达 $10^6$ 倍，导致 SVD 分解数值条件数极度恶化。Hartley 提出的**坐标归一化八点法**通过将图像坐标预先平移缩放到以原点为中心、平均距离为 $\sqrt{2}$ 的无量纲坐标，彻底攻克了条件数问题。

在 RANSAC 检验阶段，度量匹配点对 $(x_1, x_2)$ 偏离对极约束的一阶最佳距离并非代数残差 $|x_2^T F x_1|$，而是**桑普森一阶几何距离（Sampson Distance）**：

$$
d_{\mathrm{Sampson}}^2(x_1, x_2; F) = \frac{(x_2^T F x_1)^2}{(F x_1)_1^2 + (F x_1)_2^2 + (F^T x_2)_1^2 + (F^T x_2)_2^2}
$$

以下 Python 类实现了完整的归一化八点法估计器与带有桑普森距离门控的 RANSAC 求解管线：

```python
import numpy as np


class FundamentalMatrixRansac:
    """归一化八点法基础矩阵估计器（带 Sampson 几何误差 RANSAC）。"""

    @staticmethod
    def normalize_points(pts: np.ndarray):
        """Hartley 各向同性坐标归一化：均值为 0，平均到原点距离为 sqrt(2)。"""
        mean = np.mean(pts, axis=0)
        shifted = pts - mean
        scale = np.sqrt(2.0) / np.mean(np.hypot(shifted[:, 0], shifted[:, 1]))
        T = np.array([
            [scale, 0.0,   -scale * mean[0]],
            [0.0,   scale, -scale * mean[1]],
            [0.0,   0.0,    1.0]
        ], dtype=float)
        pts_homo = np.column_stack((pts, np.ones(len(pts))))
        pts_norm = (T @ pts_homo.T).T
        return pts_norm[:, :2], T

    @classmethod
    def solve_8point_fundamental(cls, pts1: np.ndarray, pts2: np.ndarray) -> np.ndarray:
        """从至少 8 对点闭式解出基础矩阵 F，并强制其秩为 2（奇异值截断）。"""
        p1_norm, T1 = cls.normalize_points(pts1)
        p2_norm, T2 = cls.normalize_points(pts2)

        N = len(pts1)
        # 构造系数矩阵 A (N x 9)
        u1, v1 = p1_norm[:, 0], p1_norm[:, 1]
        u2, v2 = p2_norm[:, 0], p2_norm[:, 1]
        A = np.column_stack([u2 * u1, u2 * v1, u2, v2 * u1, v2 * v1, v2, u1, v1, np.ones(N)])

        _, _, Vt = np.linalg.svd(A)
        F_norm = Vt[-1].reshape((3, 3))

        # 强制秩为 2 约束：det(F) = 0
        U, S, Vt_f = np.linalg.svd(F_norm)
        S[-1] = 0.0
        F_rank2 = U @ np.diag(S) @ Vt_f

        # 去归一化变换
        F = T2.T @ F_rank2 @ T1
        return F / (F[2, 2] if abs(F[2, 2]) > 1e-12 else 1.0)

    @classmethod
    def ransac_fundamental(cls, pts1: np.ndarray, pts2: np.ndarray,
                           max_iters: int = 500, thresh_px: float = 1.5):
        """RANSAC 迭代求解最佳基础矩阵并剔除外点。"""
        N = len(pts1)
        assert N >= 8, "估计基础矩阵至少需要 8 对特征匹配点"

        best_F = None
        best_inliers = []
        p1_h = np.column_stack((pts1, np.ones(N)))
        p2_h = np.column_stack((pts2, np.ones(N)))

        for _ in range(max_iters):
            sample_idx = np.random.choice(N, size=8, replace=False)
            F_cand = cls.solve_8point_fundamental(pts1[sample_idx], pts2[sample_idx])

            # 计算所有点的桑普森几何距离平方
            # Fx1 (N x 3), F_t_x2 (N x 3)
            Fx1 = (F_cand @ p1_h.T).T
            Ftx2 = (F_cand.T @ p2_h.T).T
            num = np.sum(p2_h * Fx1, axis=1) ** 2
            denom = Fx1[:, 0]**2 + Fx1[:, 1]**2 + Ftx2[:, 0]**2 + Ftx2[:, 1]**2
            sampson_dist = np.sqrt(num / np.maximum(denom, 1e-12))

            inliers = np.where(sampson_dist < thresh_px)[0]
            if len(inliers) > len(best_inliers):
                best_inliers = inliers
                best_F = F_cand

        return best_F, best_inliers
```

### 6.6.2 根因排查与工程多约束防御对策

事故根因在于：纯视觉特征点匹配是基于局部图像块外观的，**完全无法区分具有空间平移对称性的重复周期纹理**。

工业级视觉前端必须构建以下三层几何防御屏障：
1. **结合 IMU 先验预测的对极线搜索窗口限制（Guided Matching）**：利用高频 IMU 在该时间段积分得出的位姿变换初值 $R_{\text{prior}}, t_{\text{prior}}$，将匹配点的搜索范围强行限制在理论对极线周围 $\pm 3$ 像素的狭窄走廊内，直接剔除相邻周期图案的干扰；
2. **强制网格化均匀特征分散（Grid Bucket Feature Distribution）**：严禁在具有高频密集体毯纹理的地面局部聚集 90% 的特征点；将全图划分为 $8 \times 8$ 个均匀网格，限制每个网格最多提取 5 个特征点，强制保留远处天花板、立柱等无周期性静态特征；
3. **基于光流金字塔（Lucas-Kanade）的连续跟踪代替全局描述子硬匹配**（第 7 章详解）。

以下 Python 模块实现了工业级网格化特征均匀分散器与对极引导匹配线搜索限制：

```python
import numpy as np


class GridFeatureBucketFilter:
    """网格化特征均匀分散桶（防止特征过度扎堆于局部周期性纹理）。"""

    def __init__(self, width: int = 640, height: int = 480, grid_cols: int = 8, grid_rows: int = 6, max_per_cell: int = 5):
        self.W = width
        self.H = height
        self.cols = grid_cols
        self.rows = grid_rows
        self.max_k = max_per_cell
        self.cell_w = width / grid_cols
        self.cell_h = height / grid_rows

    def filter_keypoints(self, keypoints: list, scores: list) -> list:
        """根据网格容量限制与响应度进行空间非极大值抑制。"""
        # 创建空网格容器
        cells = {(r, c): [] for r in range(self.rows) for c in range(self.cols)}

        for kp, score in zip(keypoints, scores):
            y, x = kp
            c = int(min(max(x / self.cell_w, 0), self.cols - 1))
            r = int(min(max(y / self.cell_h, 0), self.rows - 1))
            cells[(r, c)].append((kp, score))

        retained = []
        for cell_kps in cells.values():
            if not cell_kps:
                continue
            # 按响应度从大到小排序，仅保留前 max_k 个
            cell_kps.sort(key=lambda item: item[1], reverse=True)
            for kp, _ in cell_kps[:self.max_k]:
                retained.append(kp)

        return retained


class EpipolarGuidedMatcher:
    """基于先验旋转平移的对极线引导匹配器。"""

    def __init__(self, K: np.ndarray, max_epipolar_dist_px: float = 3.0):
        self.K = K
        self.K_inv = np.linalg.inv(K)
        self.max_dist = max_epipolar_dist_px

    @staticmethod
    def skew(v):
        return np.array([[0, -v[2], v[1]], [v[2], 0, -v[0]], [-v[1], v[0], 0]], dtype=float)

    def filter_candidates_by_epipolar_line(self, pt1: np.ndarray, candidates_pt2: np.ndarray, R_c2_c1: np.ndarray, t_c2_c1: np.ndarray):
        """利用本质矩阵计算对极线，过滤偏离对极走廊的假匹配候选。"""
        # E = [t]_x * R
        E = self.skew(t_c2_c1) @ R_c2_c1
        # F = K^-T * E * K^-1
        F = self.K_inv.T @ E @ self.K_inv

        # 图像 2 中的对极线: l2 = F * x1 = [a, b, c]^T (ax + by + c = 0)
        p1_h = np.array([pt1[0], pt1[1], 1.0])
        l2 = F @ p1_h
        denom = math.hypot(l2[0], l2[1])
        if denom < 1e-8:
            return candidates_pt2

        # 批量计算候选点到对极线的点到直线距离: |a*u + b*v + c| / sqrt(a^2 + b^2)
        u2 = candidates_pt2[:, 0]
        v2 = candidates_pt2[:, 1]
        dists = np.abs(l2[0] * u2 + l2[1] * v2 + l2[2]) / denom

        valid_mask = dists < self.max_dist
        return candidates_pt2[valid_mask]
```
