如果说相机为机器人提供了观察世界纹理与颜色的“眼睛”，那么**激光雷达（LiDAR，Light Detection and Ranging）**则是为具身智能体量身打造的“终极三维空间量尺”。

与被动接收外界环境光照射的相机截然相反，激光雷达是一种**主动式发光探测传感器（Active Sensor）**。它在纳秒级时间内向空间发射数以百万计的不可见红外纳秒级窄脉冲激光束，并精密记录反射光子返回的时间差（Time of Flight, ToF）。这一主动发射机制赋予了激光雷达三大无与伦比的物理优势：
1. **完全免疫环境光照剧变**：在烈日直射、漆黑深夜、阴阳交界逆光或无纹理纯白墙壁前，激光测距精度毫无衰减；
2. **天然具备真实绝对物理尺度**：光速恒定 $c \approx 2.9979 \times 10^8\,\mathrm{m}/\mathrm{s}$，激光点云的坐标以毫米级精度直接对应真实物理距离，不存在任何单目尺度的模糊与漂移；
3. **全向大视场与远探测距离**：机械式雷达原生具备 $360^\circ$ 全景水平视场，测距半径可达 100 至 300 米，能够瞬间捕捉整个环境的三维结构骨架。

然而，原始点云只是离散、无序且在空间中高频抖动的三维点集合。如何对海量点云进行空间组织？如何在物体几何曲面上构建精准的刚体配准？当机器人快速运动时点云发生的剧烈扭曲如何消除？

本章深入探讨激光雷达感知与点云配准全栈技术：从底层**硬件去畸变**、**空间 Kd 树索引**，到核心配准算法**点到点/点到面 ICP**、**3D NDT 正态分布变换**，直至现代高性能紧耦合激光惯导里程计（**LOAM / Fast-LIO2**）。

## 8.1 激光雷达测距原理与运动畸变补偿（Deskewing） {#sec-embodied.2.8.1}

激光雷达根据光学扫描机制主要分为三大物理流派：
- **机械旋转式雷达（Mechanical LiDAR）**：通过电机驱动内部发射接收激光头做 $360^\circ$ 连续回转，形成 16、32、64 或 128 线水平环状扫描；
- **微机电固态雷达（MEMS Solid-State LiDAR）**：通过高频微振镜改变极小光束偏转角，具有视场集中（如 $120^\circ \times 25^\circ$）、体积小、寿命长的特点；
- **面阵闪光式雷达（Flash LiDAR）**：单次脉冲覆盖全视场，依靠高灵敏单光子雪崩二极管（SPAD）面阵直接成像，但探测距离较短。

### 8.1.1 飞行时间测距（ToF）与连续扫描机制

雷达向目标发射脉冲，并检测反射脉冲的往返时间差 $\Delta t$。光速记作 $c$，物理距离公式为：

$$
d = \frac{c \cdot \Delta t}{2}
$$

### 8.1.2 激光雷达能量方程与漫反射物理衰减特性

对于理想朗伯漫反射面，一个简化的激光测距链路预算可写成

$$
P_r \propto P_t \cdot \frac{A_r}{R^2} \cdot \eta_{\text{sys}} \cdot \eta_{\text{atm}} \cdot \rho \cos\alpha
$$

其中：
- $P_t$ 为激光器单脉冲发射峰值功率（通常为数十瓦特）；
- $A_r$ 为接收物镜的有效通光孔径面积；
- $R$ 为目标三维空间距离；
- $\eta_{\text{sys}}, \eta_{\text{atm}}$ 分别为光学系统透过率与大气衰减系数；
- $\rho \in [0, 1]$ 为目标物体的漫反射率（例如柏油路面约为 0.1，白色车道线约为 0.7）；
- $\alpha$ 为激光入射方向与目标表面局部法向量的夹角（入射角）。

注意其核心衰减规律：对于完全漫反射朗伯面（Lambertian Surface），接收光功率与**距离平方 $R^2$ 呈反比**，且与**入射角余弦 $\cos\alpha$ 成正比**。
当激光以极大掠射角（$\alpha \to 90^\circ$）射向路面，或射向深黑色吸光材料时，接收端信噪比急剧下降，点云在测距上会产生高达数十厘米的漂移甚至完全无法返回有效点（Dropout）。

::: def 定义 8.1.1 · 运动畸变（Motion Distortion / Skewing）物理现象 {#def-embodied.2.8.1.1}
与相机的全局快门（所有像素在同一微秒曝光）截然不同，机械旋转式激光雷达是以典型的“回转扫描（Rolling Scanning）”模式工作的。
雷达旋转一周采集一帧完整点云通常耗时 $\Delta T_{\text{scan}} = 100\,\mathrm{ms}$（对应 10 Hz 帧率）。在这一百毫秒内：
- 激光雷达的第一个激光点是在时刻 $t_{\text{start}}$ 采集的；
- 最后一个点是在时刻 $t_{\text{end}} = t_{\text{start}} + 100\,\mathrm{ms}$ 采集的。

若机器人在该时间段内以 $v = 20\,\mathrm{m}/\mathrm{s}$（72 km/h）高速前进，雷达起始点与终点在三维物理世界中已经向前位移了整整 **$2.0$ 米**！如果直接将这一帧点云当成同一时刻的静态几何快照，原本笔直平整的墙壁会发生高达数米的倾斜扭曲，矩形房间被拉扯成平行四边形。这种现象称为**点云运动畸变（Motion Distortion）**。
:::

### 8.1.3 基于高频 IMU / 里程计的线性与流形插值去畸变推导

消除运动畸变的核心目标是：**将一帧点云内所有点的时间戳 $t_i$，通过机器人运动估计，统一投影视线对齐到本帧激光扫描的特定基准时刻（通常取扫描起始时刻 $t_0$ 或终点时刻 $t_{\text{end}}$）**。

设点云中第 $i$ 个激光点 $p_i^{L(t_i)}$ 是在时刻 $t_i$、在激光雷达当时的瞬时坐标系 $\mathcal{F}_{L(t_i)}$ 下测得的。
利用高频 IMU 积分或轮速里程计，我们可以求出扫描周期内任意时刻雷达相对基准时刻的世界位姿变换 $T_{w, t_i} = [R_{w, t_i} \mid p_{w, t_i}]$。

#### 1. 李群流形插值位姿解算：
设整帧点云起始时刻位姿为 $T_0$，终点时刻位姿为 $T_1$。归一化时间比例系数定义为：

$$
s_i = \frac{t_i - t_0}{t_{\text{end}} - t_0} \in [0, 1]
$$

在时刻 $t_i$ 的雷达相对初始时刻的相对位姿 $T_{0, t_i} \in \mathrm{SE}(3)$ 通过对数映射做流形插值：

$$
T_{0, t_i} = \exp\Big( s_i \cdot \log(T_0^{-1} T_1) \Big)
$$

对于平移向量，亦可直接采用线性插值：$p_{0, t_i} = s_i \cdot p_{01}$；旋转部分采用四元数球面线性插值 $\mathbf{q}(t_i) = \mathrm{Slerp}(\mathbf{q}_0, \mathbf{q}_1; s_i)$。

#### 2. 点云坐标投影视线归一化：
空间点首先从瞬时雷达系映射到世界系，再从世界系统一投影视线回基准时刻坐标系：

$$
p_i^{\text{deskewed}} = T_0^{-1} \cdot T_{t_i} \cdot p_i^{L(t_i)} = T_{0, t_i} \cdot p_i^{L(t_i)}
$$

经过这一逐点插值坐标还原，被高速运动拉扯变形的点云被彻底复原为严格符合刚体静止几何的规整点云。

以下代码演示端点位姿插值的单帧去畸变；实际系统还须处理 IMU 积分、外参和时间同步，并对重复或乱序时间戳报错：

```python
import numpy as np
from scipy.spatial.transform import Rotation as R_scipy, Slerp


class PointCloudDeskewer:
    """将单帧点云投影到起始时刻雷达坐标系。"""

    @staticmethod
    def deskew_point_cloud(raw_points: np.ndarray,
                           timestamps: np.ndarray,
                           T_start_world: np.ndarray,
                           T_end_world: np.ndarray) -> np.ndarray:
        """根据扫描周期内的位姿插值，将所有激光点统一投影至起始时刻坐标系。
        
        raw_points: (N, 3), 原始激光雷达测量点坐标
        timestamps: (N,), 每个点的绝对测量时间戳 (s)
        T_start_world, T_end_world: 扫描起止时刻的世界位姿 SE(3) (4x4)
        """
        N = len(raw_points)
        if N == 0 or len(timestamps) != N or timestamps[-1] <= timestamps[0]:
            raise ValueError("需要非空、同长度且正扫描时长的输入")
        t0 = timestamps[0]
        t1 = timestamps[-1]
        dt_total = max(t1 - t0, 1e-6)

        # 计算世界到扫描起始坐标系的逆变换
        T_w_start_inv = np.linalg.inv(T_start_world)
        # 旋转与平移插值准备
        R_start = T_start_world[:3, :3]
        R_end = T_end_world[:3, :3]
        p_start = T_start_world[:3, 3]
        p_end = T_end_world[:3, 3]

        slerp = Slerp([t0, t1], R_scipy.from_matrix([R_start, R_end]))

        deskewed_points = np.empty_like(raw_points)

        for i in range(N):
            s = np.clip((timestamps[i] - t0) / dt_total, 0.0, 1.0)
            # 1. 插值出时刻 t_i 雷达在世界坐标系下的瞬时位姿
            # 平移线性插值
            p_ti = p_start + s * (p_end - p_start)
            # 在 SO(3) 上执行四元数球面插值，而不是线性插值旋转向量
            R_ti = slerp([t0 + s * dt_total]).as_matrix()[0]

            T_w_ti = np.eye(4)
            T_w_ti[:3, :3] = R_ti
            T_w_ti[:3, 3] = p_ti

            # 2. 变换矩阵: T_start_ti = T_start_w * T_w_ti
            T_start_ti = T_w_start_inv @ T_w_ti

            # 3. 投影至起始时刻基准坐标系
            p_homo = np.array([raw_points[i, 0], raw_points[i, 1], raw_points[i, 2], 1.0])
            p_deskewed = T_start_ti @ p_homo
            deskewed_points[i] = p_deskewed[:3]

        return deskewed_points
```

## 8.2 空间数据结构：体素滤波与 Kd-Tree 空间索引 {#sec-embodied.2.8.2}

单帧激光雷达输出的点云数量多达数万至数十万个点。直接对全量点云运行配准，计算复杂度为 $O(N^2)$，在实时嵌入式系统上是完全不可承受的。必须引入高效的**空间降采样**与**树状最近邻空间索引**。

### 8.2.1 体素网格质心降采样（Voxel Grid Filter）

体素降采样的物理目标是：**在空间中建立三维均匀离散栅格立方体（体素，Voxel），保持点云在空间中的密度均匀分布，降低冗余点数量**。

设三维体素的分辨率尺寸为 $(r_x, r_y, r_z)$。对于点云中的任意点 $p_i = [x_i, y_i, z_i]^T$，其所属体素的整数三维离散索引为：

$$
c_x = \left\lfloor \frac{x_i - x_{\min}}{r_x} \right\rfloor,\quad c_y = \left\lfloor \frac{y_i - y_{\min}}{r_y} \right\rfloor,\quad c_z = \left\lfloor \frac{z_i - z_{\min}}{r_z} \right\rfloor
$$

定义全局一维哈希键（Hash Key）：

$$
\mathrm{Key}(p_i) = c_x + c_y \cdot D_x + c_z \cdot (D_x D_y)
$$

遍历落入同一哈希体素的所有点集 $\mathcal{V}_k = \{p_1, \dots, p_m\}$，以其**物理质心（Centroid）**代替该体素，输出唯一点：

$$
p_{\text{voxel}} = \frac{1}{m} \sum_{j=1}^m p_j
$$

质心法比固定体素中心更贴近当前采样点的均值，但会平滑尖锐边缘；降采样率取决于场景与体素尺寸，不能固定宣称为 95%。

### 8.2.2 K-d 树（K-Dimensional Tree）最近邻检索机制

在点云配准中，最耗时的操作是：为源点云中的每个点 $p$，在目标点云中寻找空间欧几里得距离最近的点 $q$。
**K-d 树**在低维且分布适宜时，平衡树的平均最近邻搜索通常比 $O(N)$ 穷举快，常以约 $O(\log N)$ 描述；构树、退化分布和高维查询仍有开销，最坏情况可退化到 $O(N)$。

```text
【三维空间 K-d 树正交超平面切分层级】
  
  深度 0: 选取 X 坐标中位数划分垂直超平面 X = x_mid
          ┌────────────────────────────────────────┐
          │ 左子树 (X < x_mid)   │ 右子树 (X >= x_mid)│
          └──────────┬─────────────────────────────┘
                     ▼ 深度 1: 沿 Y 轴划分 Y = y_mid
          ┌──────────┴──────────┐
          ▼                     ▼
  深度 2: 沿 Z 轴划分 Z = z_mid ──▶ 递归循环循环: X -> Y -> Z -> X ...
```

#### 最近邻回溯剪枝准则（Backtracking Pruning）：
当搜索某测试点 $p$ 的最近邻时，算法顺着树结构一路向下直达叶子节点，得到当前的候选最小距离 $d_{\min}$。
在向上回溯遍历另一个分支时，计算**点 $p$ 到当前切分超平面的垂直代数距离 $|p_d - \text{split}_d|$**：
- 若 $|p_d - \text{split}_d| \ge d_{\min}$：说明以点 $p$ 为球心、半径为 $d_{\min}$ 的空间超球体**完全不与分割平面的另一侧相交**！算法直接跳过并剪枝整个对侧子树（包含数千个点！）；
- 只有当球体与分割平面相交时，才需要深入对侧子树回溯。

以下 Python 类完整实现了三维 K-d 树的中位数切分建树与超球剪枝最近邻搜索：

```python
class KDNode3D:
    def __init__(self, point: np.ndarray, index: int, axis: int, left=None, right=None):
        self.point = point
        self.index = index
        self.axis = axis
        self.left = left
        self.right = right


class KDTree3D:
    """无第三方依赖的三维空间 K-d 树实现。"""

    def __init__(self, points: np.ndarray):
        self.points = np.array(points, dtype=float)
        indices = np.arange(len(points))
        self.root = self._build_tree(indices, depth=0)

    def _build_tree(self, indices: np.ndarray, depth: int):
        if len(indices) == 0:
            return None
        axis = depth % 3
        # 沿当前主轴按坐标排序取中位数
        sorted_indices = indices[np.argsort(self.points[indices, axis])]
        mid = len(sorted_indices) // 2
        mid_idx = sorted_indices[mid]

        left_node = self._build_tree(sorted_indices[:mid], depth + 1)
        right_node = self._build_tree(sorted_indices[mid + 1:], depth + 1)

        return KDNode3D(self.points[mid_idx], mid_idx, axis, left_node, right_node)

    def query_nearest(self, query_pt: np.ndarray):
        """寻找距离 query_pt 最近的点坐标、原始索引与距离。"""
        best = {"dist_sq": float("inf"), "point": None, "index": -1}

        def _search(node):
            if node is None:
                return
            # 1. 计算当前节点距离
            d_sq = float(np.sum((query_pt - node.point) ** 2))
            if d_sq < best["dist_sq"]:
                best["dist_sq"] = d_sq
                best["point"] = node.point
                best["index"] = node.index

            # 2. 判断优先进入哪一侧子树
            axis = node.axis
            diff = query_pt[axis] - node.point[axis]
            first = node.left if diff < 0 else node.right
            second = node.right if diff < 0 else node.left

            _search(first)

            # 3. 超平面剪枝回溯检验
            # 若点到切分超平面的垂直距离平方小于当前最优距离平方，必须检查另一侧
            if (diff ** 2) < best["dist_sq"]:
                _search(second)

        _search(self.root)
        return best["point"], best["index"], math.sqrt(best["dist_sq"])
```

## 8.3 点到点 ICP 与点到面 ICP 配准数学推导 {#sec-embodied.2.8.3}

迭代最近点算法（Iterative Closest Point, ICP）是三维几何配准的绝对王者。根据误差残差构建维度的不同，ICP 分为经典的**点到点（Point-to-Point）**与现代主流的**点到面（Point-to-Plane）**两大流派。

### 8.3.1 点到点 ICP 的 Arun SVD 闭式解

在已知两点云严格一一对应关系时，求解最优刚体变换无需任何迭代，存在极为优美的解析闭式解。

设源点云为 $P = \{p_i\}_{i=1}^N$，目标对应点云为 $Q = \{q_i\}_{i=1}^N$。优化目标函数为最小化点对欧几里得距离残差平方和：

$$
\min_{R, t} J(R, t) = \sum_{i=1}^N \|R p_i + t - q_i\|_2^2
$$

::: thm 定理 8.3.1 · Arun SVD 奇异值分解闭式配准定理 {#thm-embodied.2.8.3.1}
计算两点集的几何质心：

$$
\bar{p} = \frac{1}{N} \sum_{i=1}^N p_i,\qquad \bar{q} = \frac{1}{N} \sum_{i=1}^N q_i
$$

构建去质心中心化点集：$p_i' = p_i - \bar{p}$，$q_i' = q_i - \bar{q}$。目标函数完美解耦为旋转与平移两部分：

$$
J = \sum_{i=1}^N \|R p_i' - q_i' + (R \bar{p} + t - \bar{q})\|_2^2 = \sum_{i=1}^N \|R p_i' - q_i'\|_2^2 + N \|R \bar{p} + t - \bar{q}\|_2^2
$$

后半项包含平移 $t$，只要令平移满足：

$$
t^* = \bar{q} - R^* \bar{p}
$$

该项恒等于零。前半项展开化简为最大化相关矩阵的迹：

$$
\sum_{i=1}^N \|R p_i' - q_i'\|^2 = \sum \|p_i'\|^2 + \sum \|q_i'\|^2 - 2 \mathrm{Tr}\left( R \sum_{i=1}^N p_i' q_i'^T \right)
$$

其中常数项与旋转矩阵无关。因此，最小化几何距离残差在数学上完全等价于最大化交叉散度乘积的迹：

$$
\max_{R \in \mathrm{SO}(3)} \mathrm{Tr}(R W),\qquad W \triangleq \sum_{i=1}^N p_i' q_i'^T
$$

根据柯西-施瓦茨不等式与矩阵正交极分解（Polar Decomposition）定理，对于任意对称正定矩阵 $S$ 与任意旋转矩阵 $R$，恒有 $\mathrm{Tr}(R S) \le \mathrm{Tr}(S)$。将 $W$ 奇异值分解为 $W = U \Sigma V^T$，利用迹的循环置换性质：

$$
\mathrm{Tr}(R W) = \mathrm{Tr}(R U \Sigma V^T) = \mathrm{Tr}(V^T R U \Sigma)
$$

由于 $V^T R U$ 仍为正交矩阵，要使与其对角非负矩阵 $\Sigma$ 的乘积之迹达到最大值，唯一条件是令正交矩阵 $V^T R U = I$！两边同乘 $V$ 并右乘 $U^T$，即以最严密的方式证明了最优旋转矩阵的解析闭式解必为 $R^* = V U^T$。

对矩阵 $W$ 执行奇异值分解 $W = U \Sigma V^T$。使 $\mathrm{Tr}(R W)$ 达到绝对最大值的最优旋转矩阵闭式解为：

$$
R^* = V U^T
$$

若出现物理反射镜像导致 $\det(R^*) = -1$（不属于 $\mathrm{SO}(3)$），强制翻转第三列正负号修正：

$$
R^* = V \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & \det(V U^T) \end{bmatrix} U^T
$$
:::

### 8.3.2 点到面 ICP（Point-to-Plane ICP）非线性高斯-牛顿推导

尽管点到点 ICP 公式优雅，但在实际激光点云配准中，**目标表面是连续的几何曲面，激光采样点并不会恰好落在完全相同的物理质点上**。点到点 ICP 强行约束切向距离，会导致收敛极其缓慢，甚至沿墙面发生严重滑动（Sliding）。

Chen 与 Medioni 提出了**点到面 ICP**：残差不再计算欧几里得空间距离，而是**将点到点的空间残差投影到目标平面的局部法向量 $n_i$ 上**！

::: def 定义 8.3.1 · 点到面投影残差方程 {#def-embodied.2.8.3.1}
设目标点 $q_i$ 处的局部单位表面法向量为 $n_i \in \mathbb{R}^3$（$\|n_i\| = 1$）。点到面几何残差为一维标量：

$$
r_i(T) = n_i^T \Big( R p_i + t - q_i \Big) \in \mathbb{R}
$$

优化目标函数为最小化加权标量残差平方和：

$$
\min_T \frac{1}{2} \sum_{i=1}^N w_i \Big( n_i^T (R p_i + t - q_i) \Big)^2
$$
:::

#### 1. 李代数左乘扰动雅可比推导：
设变换矩阵经受微小左乘摄动 $T \leftarrow \exp(\delta \xi^\wedge) T$，其中 $\delta \xi = [\delta \rho^T, \delta \phi^T]^T \in \mathfrak{se}(3)$。
记当前变换点为 $p_i' = R p_i + t$。一阶展开：

$$
\begin{aligned}
r_i(\delta \xi) &= n_i^T \Big( \exp(\delta \xi^\wedge) p_i' - q_i \Big) \\
&\approx n_i^T \Big( p_i' + \delta \rho - (p_i')^\wedge \delta \phi - q_i \Big) \\
&= n_i^T (p_i' - q_i) + n_i^T \delta \rho - n_i^T (p_i')^\wedge \delta \phi \\
&= r_i(0) + n_i^T \delta \rho + (p_i' \times n_i)^T \delta \phi
\end{aligned}
$$

对扰动矢量 $\delta \xi$ 求偏导，得到极具几何美感的 **$1 \times 6$ 雅可比矩阵行向量**：

$$
J_i = \frac{\partial r_i}{\partial \delta \xi} = \begin{bmatrix} n_i^T & (p_i' \times n_i)^T \end{bmatrix} \in \mathbb{R}^{1 \times 6}
$$

#### 2. 正规方程构建与阻尼求解：
构建 $6 \times 6$ 高斯-牛顿正规方程：

$$
H \Delta \xi = b
$$

$$
H = \sum_{i=1}^N w_i J_i^T J_i = \sum_{i=1}^N w_i \begin{bmatrix} n_i n_i^T & n_i (p_i' \times n_i)^T \\ (p_i' \times n_i) n_i^T & (p_i' \times n_i) (p_i' \times n_i)^T \end{bmatrix}
$$

$$
b = -\sum_{i=1}^N w_i J_i^T r_i = -\sum_{i=1}^N w_i \begin{bmatrix} n_i \\ p_i' \times n_i \end{bmatrix} r_i
$$

点到面 ICP 不约束目标切平面的滑动，因此在长廊与单平面场景中会出现不可观测自由度；它在合适初值和曲面几何下常比点到点 ICP 收敛更快，但没有普适的速度倍率或稳定性保证。

## 8.4 正态分布变换（3D NDT）：连续体素概率分布配准 {#sec-embodied.2.8.4}

ICP 算法虽然高精度，但其致命瓶颈在于：每一轮迭代都必须通过 Kd-tree 查询数万次最近邻点对，内存访存开销极其巨大。

Biber 等人提出了颠覆性的 **正态分布变换（Normal Distributions Transform, NDT）** 算法：**彻底抛弃逐点搜索对应关系，将目标点云空间栅格化为三维体素，每个体素用一个连续的多元正态高斯概率密度函数（PDF）来描述！**

### 8.4.1 体素局部连续高斯概率建模

将空间划分为网格尺寸为 $D$（如 1.0 米）的立体体素网格。对于落入某体素格内部的所有激光点集 $P_v = \{p_1, \dots, p_m\}$，计算局部质心与协方差矩阵：

$$
\mu_v = \frac{1}{m} \sum_{k=1}^m p_k,\qquad \Sigma_v = \frac{1}{m - 1} \sum_{k=1}^m (p_k - \mu_v)(p_k - \mu_v)^T
$$

该体素内部任意空间点 $x$ 属于该物体几何表面的概率密度函数为：

$$
p(x) = \frac{1}{\sqrt{(2\pi)^3 \det\Sigma_v}} \exp\left( -\frac{1}{2} (x - \mu_v)^T \Sigma_v^{-1} (x - \mu_v) \right)
$$

### 8.4.2 NDT 似然评分函数与解析梯度海森矩阵推导

为了防止远离中心的异常点对配准产生破坏性扰动，Biber 构造了一个对数极大似然的**负高斯加权评分函数（NDT Score Function）**：

$$
s(x) = -d_1 \exp\left( -\frac{d_2}{2} (x - \mu_v)^T \Sigma_v^{-1} (x - \mu_v) \right)
$$

其中常数 $d_1, d_2$ 保证在体素边界处的连续性。优化目标为最小化所有变换后点云的总评分：

$$
\min_T S(T) = \sum_{i=1}^N s(T p_i)
$$

对刚体位姿参数 $\xi \in \mathbb{R}^6$ 求梯度向量 $g$ 与海森矩阵 $H$（链式法则求导）：

$$
g = \frac{\partial S}{\partial \xi} = \sum_{i=1}^N \frac{\partial s}{\partial x_i'} \cdot \frac{\partial x_i'}{\partial \xi}
$$

$$
H \approx \sum_{i=1}^N \left( \frac{\partial x_i'}{\partial \xi} \right)^T \frac{\partial^2 s}{\partial x_i'^2} \left( \frac{\partial x_i'}{\partial \xi} \right)
$$

NDT 以体素分布评估源点，不必逐点查询最近邻；单体素评分在硬边界处未必连续，实际实现可评估邻近体素、采用平滑插值及线搜索。速度随分辨率、有效点数与实现而变，不能断言总比 ICP 快。

示例使用单体素高斯评分与近似曲率演示计算结构；没有边界插值、线搜索与拒绝步，因此**不是生产可用的 NDT 配准器**。实验 8.2 只验证平移评分，不验证该优化循环的收敛性：

```python
import numpy as np
from scipy.spatial.transform import Rotation as R_scipy


class NDTMatcher3D:
    """3D 正态分布变换（NDT）配准引擎。"""

    def __init__(self, voxel_size: float = 1.0, max_iters: int = 20, step_tol: float = 1e-4):
        self.voxel_size = voxel_size
        self.max_iters = max_iters
        self.step_tol = step_tol
        self.voxels = {}

    def build_target_map(self, target_points: np.ndarray):
        """将静态参考点云栅格化为体素正态分布均值与逆协方差。"""
        buckets = {}
        for p in target_points:
            key = tuple(np.floor(p / self.voxel_size).astype(int))
            buckets.setdefault(key, []).append(p)

        self.voxels = {}
        for key, pts in buckets.items():
            if len(pts) >= 6:
                pts_arr = np.array(pts)
                mu = np.mean(pts_arr, axis=0)
                cov = np.cov(pts_arr, rowvar=False) + 1e-4 * np.eye(3)
                self.voxels[key] = (mu, np.linalg.inv(cov))

    def align(self, source_points: np.ndarray, init_T: np.ndarray = None) -> tuple:
        """运行牛顿-拉夫逊梯度迭代优化配准。"""
        T_cur = np.eye(4) if init_T is None else init_T.copy()
        d1 = 1.0; d2 = 1.0  # 评分常数

        for it in range(self.max_iters):
            # 将源点变换至当前估计位姿
            pts_trans = (source_points @ T_cur[:3, :3].T) + T_cur[:3, 3]

            g = np.zeros(6, dtype=float)
            H = np.zeros((6, 6), dtype=float)
            score = 0.0

            for i in range(len(source_points)):
                p_t = pts_trans[i]
                key = tuple(np.floor(p_t / self.voxel_size).astype(int))
                if key not in self.voxels:
                    continue

                mu, inv_cov = self.voxels[key]
                diff = p_t - mu
                c = float(diff.T @ inv_cov @ diff)
                val = d1 * np.exp(-0.5 * d2 * c)
                score += val

                # 偏导项 \partial s / \partial p_t (3x1)
                ds_dp = -d1 * d2 * np.exp(-0.5 * d2 * c) * (inv_cov @ diff)

                # 点对李代数左乘扰动的偏导 J_p = [I, -p_t^\wedge] (3x6)
                p_skew = np.array([[0, -p_t[2], p_t[1]],
                                   [p_t[2], 0, -p_t[0]],
                                   [-p_t[1], p_t[0], 0]], dtype=float)
                J = np.hstack((np.eye(3), -p_skew))

                # 累加梯度与海森近似
                g += J.T @ ds_dp
                H += J.T @ (inv_cov * (d1 * d2 * np.exp(-0.5 * d2 * c))) @ J

            # H 是峰值附近负 Hessian 的近似；求最大值时沿正梯度方向走。
            delta_xi = np.linalg.solve(H + 1e-4 * np.eye(6), g)
            norm = np.linalg.norm(delta_xi)
            if norm > 0.1:
                delta_xi *= 0.1 / norm  # 简单信赖步限幅；真实实现还需验收新评分
            dt = delta_xi[:3]
            dR = R_scipy.from_rotvec(delta_xi[3:]).as_matrix()

            dT = np.eye(4)
            dT[:3, :3] = dR
            dT[:3, 3] = dt

            T_cur = dT @ T_cur

            if np.linalg.norm(delta_xi) < self.step_tol:
                break

        return T_cur, score
```

## 8.5 特征法激光里程计（LOAM）：线面几何特征分类提取 {#sec-embodied.2.8.5}

直接对稠密点云执行点到面配准依然消耗大量算力。CMU 机器人研究所张纪博士提出的 **LOAM（Lidar Odometry and Mapping）** 算法，霸榜国际 KITTI 榜单数年，确立了特征法激光里程计的行业标准。

### 8.5.1 点云局部曲率（Curvature）分类准则

LOAM 巧妙利用了多线机械式激光雷达以固定线束圆环扫描的物理特性。
设某根线束扫描序列上，点 $p_i$ 沿扫描顺序前后各取 $S = 5$ 个相邻连续点集。定义点 $p_i$ 的**局部粗糙度 / 曲率因子（Smoothness Metric, $c$）**：

$$
c = \frac{1}{|S| \cdot \|p_i\|} \left\| \sum_{j \in S, j \neq i} (p_i - p_j) \right\|
$$

::: def 定义 8.5.1 · LOAM 边缘角点与平面点特征分类 {#def-embodied.2.8.5.1}
根据曲率因子 $c$ 的绝对大小，点云被严密分类为两大几何原语：
1. **边缘角点（Edge Points / Sharp Points）**：
   $c$ 极大（显著高于阈值 $c_{\text{edge}}$）。物理上对应建筑物外墙拐角、树干边缘、电线杆轮廓。该点周围的几何向量呈现剧烈空间突变；
2. **平面点（Planar Points / Flat Points）**：
   $c$ 极小（显著低于阈值 $c_{\text{plane}}$）。物理上对应光滑路面、平整建筑物侧墙、大面积地面。该点周围的几何向量在局部切平面上相互抵消平衡。
:::

### 8.5.2 点到线距离与点到面距离几何残差

1. **边缘点到对应线特征残差**：
   在目标点云中寻找空间距离最近的两个边缘特征点 $A, B$（构成一条三维空间直线段）。源边缘点 $p_i'$ 到直线 $AB$ 的几何垂直距离由向量叉积模长严格给出：
   $$
   d_{\text{edge}} = \frac{\|(p_i' - A) \times (p_i' - B)\|}{\|A - B\|}
   $$

2. **平面点到对应面特征残差**：
   在目标点云中寻找三个不共线的平面特征点 $A, B, C$（构成一个局部空间三角面）。源平面点 $p_i'$ 到平面的几何垂直距离由混合积给出：
   $$
   d_{\text{plane}} = \frac{|(p_i' - A) \cdot ((A - B) \times (A - C))|}{\|(A - B) \times (A - C)\|}
   $$

通过将原始 10 万个原始点提炼为几百个高信噪比的边缘点与平面点，LOAM 实现了在低算力单板工控机上以 10Hz 甚至 20Hz 极速运行的高精度里程计。

以下 Python 类实现了单线扫描束上的 LOAM 局部曲率因子计算与线面特征分离提取：

```python
import numpy as np


class LOAMFeatureExtractor:
    """LOAM 点云线束局部曲率因子与边缘点/平面点提取器。"""

    def __init__(self, c_edge_thresh: float = 0.1, c_plane_thresh: float = 0.01, window_size: int = 5):
        self.c_edge = c_edge_thresh
        self.c_plane = c_plane_thresh
        self.W = window_size

    def extract_features_on_ring(self, ring_points: np.ndarray):
        """输入按扫描角度排序的单线激光点序列 (N, 3)。返回: (edge_pts, plane_pts)"""
        N = len(ring_points)
        w = self.W
        if N < 2 * w + 1:
            return np.empty((0, 3)), np.empty((0, 3))

        curvatures = np.zeros(N, dtype=float)

        # 遍历计算每个点的曲率因子 c = || \sum (p_i - p_j) || / (2W * ||p_i||)
        for i in range(w, N - w):
            p_i = ring_points[i]
            dist_i = np.linalg.norm(p_i)
            if dist_i < 0.2:
                continue

            diff_sum = np.zeros(3)
            for j in range(i - w, i + w + 1):
                if j == i:
                    continue
                diff_sum += (p_i - ring_points[j])

            curvatures[i] = np.linalg.norm(diff_sum) / (2.0 * w * dist_i)

        # 将点云均匀分为 6 个扇区分别提取，保证全向特征分布
        edge_pts, plane_pts = [], []
        sector_size = N // 6

        for s in range(6):
            start = s * sector_size
            end = (s + 1) * sector_size if s < 5 else N
            sector_indices = np.arange(start, end)
            # 过滤两端未计算曲率的边界
            valid = (sector_indices >= w) & (sector_indices < N - w)
            sector_indices = sector_indices[valid]
            if len(sector_indices) == 0:
                continue

            # 按曲率降序排序
            sorted_indices = sector_indices[np.argsort(curvatures[sector_indices])[::-1]]

            # 选取曲率最大的前 2 个点作为强边缘角点
            for idx in sorted_indices[:2]:
                if curvatures[idx] > self.c_edge:
                    edge_pts.append(ring_points[idx])

            # 选取曲率最小的后 4 个点作为强平面点
            for idx in sorted_indices[-4:]:
                if curvatures[idx] < self.c_plane:
                    plane_pts.append(ring_points[idx])

        return np.array(edge_pts), np.array(plane_pts)
```

## 8.6 紧耦合激光惯导里程计：Fast-LIO2 与 LIO-SAM 架构解析 {#sec-embodied.2.8.6}

在移动机器人高速机动、四足颠簸奔跑或穿过剧烈振动坑洼时，纯激光里程计极易因点云退化或剧烈抖动导致配准丢失。现代学术界与工业界全面迈入了**激光-惯导紧耦合里程计（LIO）时代**。

### 8.6.1 Fast-LIO2：迭代卡尔曼滤波（IEKF）与增量式 ikd-Tree

香港大学及其合作者提出的 **Fast-LIO2** 采用原始点云直接配准；以下是设计要点，具体运行频率须依赖数据集和硬件实测：
1. **直接法原始点配准**：完全取消 LOAM 的线面特征曲率提取，直接将降采样后的所有原始点云送入配准，极大地增强了在自然非结构化灌木、草地等弱特征环境中的生存能力；
2. **误差状态迭代卡尔曼滤波（IEKF）**：将每个激光点到局部平面的几何残差，作为 IEKF 的高维测量方程：
   $$
   z_j = r_j(\check{x}_k \oplus \delta x) = 0
   $$
   通过等价的状态维度信息形式避免对点数维度的观测协方差直接求逆；运行耗时随点数、地图与硬件而变化；
3. **增量式树结构（ikd-Tree）**：增量插入、删除标记与按需局部重构可避免逐帧全量重建；延迟和线程安全仍须在具体实现中验证。

### 8.6.2 LIO-SAM：基于因子图的多传感器松紧耦合优化

麻省理工学院 Tixiao Shan 开源的 **LIO-SAM（Tightly-coupled Lidar Inertial Odometry via Smoothing and Mapping）** 则代表了因子图优化流派的巅峰：
- 系统由 IMU 预积分因子、激光里程计点面因子、GPS 绝对先验因子与回环检测闭环因子联合编排；
- 引入关键帧与子地图（Submap）滑窗机制，在位姿图优化框架下保证全局地图一致性；
- 针对无人驾驶场景，天然支持多传感器在因子图层面的即插即用（Plug-and-Play）。

### 8.6.3 增量式 ikd-Tree 惰性重平衡（Lazy Rebalancing）机制解析

传统静态 K-d 树在处理动态建图时存在致命短板：每次新来一帧点云，必须将旧地图与新点云合并并全量重新递归建树，耗时随点云数量线性暴增至数百毫秒。

ikd-Tree（Incremental k-d Tree）通过引入**二叉平衡树惰性维护准则**，实现了微秒级的动态增删查改：
1. **单点增量插入与伪删除**：
   - 插入新点时，从根节点向下遍历直接插入叶子节点，单点插入耗时 $O(\log N)$；
   - 删除过时地图点（如机器人驶出该区域）时不立即释放物理节点，而是设置布尔标志位 `deleted = True`，该操作仅需 $O(1)$。
2. **$\alpha$-平衡判据（$\alpha$-Balanced Criterion）**：
   定义子树平衡因子 $\alpha_{\text{bal}} \in (0.5, 1.0)$（通常取 0.7）。对于任意节点 $V$，若其左子树或右子树的点数超过该节点总点数的 $\alpha_{\text{bal}}$ 倍：
   $$
    \max\Big( \mathrm{size}(V_{\text{left}}),\ \mathrm{size}(V_{\text{right}}) \Big) \gt \alpha_{\text{bal}} \cdot \mathrm{size}(V)
   $$
   说明该局部子树已经严重倾斜退化。此时算法仅对该局部子树进行扁平化（Flatten）并重新构建局部平衡二叉树，而**完全不触动整棵树的其他部分**！
3. **双线程惰性并行重平衡（Dual-Thread Lazy Rebuild）**：
   重构大型子树的任务被抛入后台独立工作线程执行；主线程在配准时继续使用旧子树检索，一旦后台构建完毕通过原子指针（Atomic Swap）无锁无感切换，确保了激光里程计主频永远不受重构卡顿的影响。

以下 Python 类实现了简化的 ikd-Tree 惰性平衡判据与局部子树重建检测器：

```python
class IncrementalKDSubtreeTracker:
    """ikd-Tree 增量式局部平衡监控与惰性重构决策器。"""

    def __init__(self, alpha_bal: float = 0.7):
        self.alpha = alpha_bal

    def check_needs_rebuild(self, size_left: int, size_right: int, deleted_count: int) -> bool:
        """根据 alpha 平衡准则与失效伪删除节点比例，判断当前节点是否必须重构。"""
        total_size = size_left + size_right + 1
        # 1. 结构倾斜判据
        max_sub = max(size_left, size_right)
        if max_sub > self.alpha * total_size:
            return True
        # 2. 伪删除冗余判据：若失效点超过局部节点的 25%，必须重构以释放空间
        if deleted_count > 0.25 * total_size:
            return True
        return False
```

## 8.7 Python 原生点到面 ICP 与点云退化检测实现 {#sec-embodied.2.8.7}

以下代码给出了无 PCL/Open3D 黑盒依赖的原生点到面 ICP 配准器与局部 PCA 法向量估计器：

```python
import math
import numpy as np
from scipy.spatial import cKDTree
from scipy.spatial.transform import Rotation as R_scipy


class PointToPlaneICP:
    """点到面 ICP 原生高斯-牛顿优化器与 Hessian 特征谱退化分析。"""

    def __init__(self, max_iters: int = 25, tolerance: float = 1e-4, max_corr_dist: float = 0.5):
        self.max_iters = max_iters
        self.tol = tolerance
        self.max_dist = max_corr_dist

    @staticmethod
    def estimate_surface_normals(points: np.ndarray, k_neighbors: int = 10) -> np.ndarray:
        """基于局部 k 近邻 PCA 协方差矩阵特征分解估计表面法向量。"""
        tree = cKDTree(points)
        normals = np.zeros_like(points)
        dists, indices = tree.query(points, k=k_neighbors)

        for i in range(len(points)):
            neighbors = points[indices[i]]
            # 局部协方差矩阵
            cov = np.cov(neighbors, rowvar=False)
            # 特征值分解：最小特征值对应的特征向量即为局部法向量
            eigvals, eigvecs = np.linalg.eigh(cov)
            n = eigvecs[:, 0]
            # 统一法向量朝向（如朝向原点）
            if np.dot(n, points[i]) > 0:
                n = -n
            normals[i] = n

        return normals

    def align(self, source_pts: np.ndarray, target_pts: np.ndarray, target_normals: np.ndarray,
              init_T: np.ndarray = None) -> tuple:
        """运行点到面 ICP 高斯-牛顿迭代。返回: (T_final, converged, min_eigenvalue, cond_number)"""
        tree = cKDTree(target_pts)
        T_cur = np.eye(4) if init_T is None else init_T.copy()

        converged = False
        final_min_eig = 0.0
        final_cond = 1.0

        for it in range(self.max_iters):
            # 将源点云变换到目标系
            s_trans = (source_pts @ T_cur[:3, :3].T) + T_cur[:3, 3]
            dists, indices = tree.query(s_trans)

            valid = dists < self.max_dist
            if np.sum(valid) < 10:
                break

            s_val = s_trans[valid]
            q_val = target_pts[indices[valid]]
            n_val = target_normals[indices[valid]]

            # 构建 6x6 正规方程 H * delta_xi = b
            H = np.zeros((6, 6), dtype=float)
            b = np.zeros(6, dtype=float)

            for i in range(len(s_val)):
                p = s_val[i]
                q = q_val[i]
                n = n_val[i]

                r = np.dot(n, p - q)
                # 雅可比 J = [n^T, (p x n)^T]
                cross = np.cross(p, n)
                J = np.concatenate((n, cross))

                H += np.outer(J, J)
                b += -J * r

            # 计算 Hessian 特征谱判别退化
            eigvals = np.linalg.eigvalsh(H)
            final_min_eig = float(eigvals[0])
            final_cond = float(eigvals[-1] / max(eigvals[0], 1e-12))

            # 阻尼高斯-牛顿求解
            delta_xi = np.linalg.solve(H + 1e-4 * np.eye(6), b)

            # 左乘流形摄动更新
            dt = delta_xi[:3]
            dR = R_scipy.from_rotvec(delta_xi[3:]).as_matrix()
            dT = np.eye(4)
            dT[:3, :3] = dR
            dT[:3, 3] = dt

            T_cur = dT @ T_cur

            if np.linalg.norm(delta_xi) < self.tol:
                converged = True
                break

        return T_cur, converged, final_min_eig, final_cond
```

### 8.8.2 根因与零空间投影保护机制

该反例的根因在于：**环境几何维度的欠约束直接导致了正规方程 Hessian 矩阵在特定方向上的不可逆性**。

工业级系统必须建立严密的**特征谱退化保护器（Degeneracy Guard）**：

```python
def solve_with_degeneration_protection(H: np.ndarray, b: np.ndarray, thresh_eig: float = 20.0):
    """分析 Hessian 特征空间，将退化非约束方向投影切断，仅在有效空间更新。"""
    eigvals, eigvecs = np.linalg.eigh(H)

    # 构造可观测空间投影矩阵
    V_safe = np.zeros_like(eigvecs)
    for col in range(len(eigvals)):
        if eigvals[col] >= thresh_eig:
            V_safe[:, col] = eigvecs[:, col]

    # 在无退化可观测子空间内执行伪逆更新
    # 彻底杜绝沿未约束方向（如走廊前进方向）产生虚假位移爆炸！
    H_inv_safe = V_safe @ np.diag([1.0 / max(ev, 1e-6) if ev >= thresh_eig else 0.0 for ev in eigvals]) @ V_safe.T
    delta_safe = H_inv_safe @ b
    return delta_safe


def simulate_corridor_degeneration():
    """仿真光滑长廊点云沿墙滑动退化与零空间投影对比。"""
    np.random.seed(42)

    # 模拟长廊点云：两侧墙面法向量全部集中在 Y 轴方向 [0, 1, 0]
    N = 200
    normals = np.zeros((N, 3))
    normals[:N//2] = np.array([0.0, 1.0, 0.0])   # 左墙
    normals[N//2:] = np.array([0.0, -1.0, 0.0])  # 右墙
    # 注入微小 1% 的随机法向量噪声
    normals += np.random.normal(0, 0.01, size=(N, 3))
    normals /= np.linalg.norm(normals, axis=1, keepdims=True)

    # 构造点到面 ICP 的平移部分 Hessian 矩阵 (3x3)
    H_trans = normals.T @ normals
    eigvals, eigvecs = np.linalg.eigh(H_trans)

    print("=== 长直走廊 Hessian 矩阵特征谱退化仿真 ===")
    print(f"Hessian 特征值谱: \lambda_1={eigvals[0]:.4f}, \lambda_2={eigvals[1]:.4f}, \lambda_3={eigvals[2]:.4f}")
    print(f"矩阵条件数:       {eigvals[-1] / max(eigvals[0], 1e-12):.2e} (已达严重病态级别)")
    print(f"未约束退化方向向量: {eigvecs[:, 0]} (严格指向走廊前进 X 轴)")

    # 模拟前进方向残差微小噪声输入
    b = np.array([0.05, 0.0, 0.0])  # X 轴微弱伪残差

    # 1. 传统无防御高斯-牛顿解算：直接求逆
    delta_naive = np.linalg.solve(H_trans + 1e-4 * np.eye(3), b)
    # 2. 零空间投影安全解算
    delta_safe = solve_with_degeneration_protection(H_trans, b, thresh_eig=10.0)

    print(f"传统直接求逆步长更新: \Delta x = {delta_naive[0]:.2f} m (虚假步长爆炸！)")
    print(f"零空间安全更新步长:   \Delta x = {delta_safe[0]:.2f} m (成功切断退化发散)")
    print("零空间安全投影成功将不可观测的退化自由度隔离，确保了走廊环境下的鲁棒运行。")
```

| 11 | 忽略雷达安装垂直倾角标定 | 车顶雷达存在 $0.5^\circ$ 的微小俯仰安装公差未标定 | 车辆直线前进时，全局点云地图随距离向下插入地底或翘向天空 | 静态平地采集地面点云，利用最小二乘平面拟合精确校正雷达安装俯仰角 |
| 12 | 错误使用固定距离作为最近邻阈值 | 在 50 米远处仍采用 0.3 米固定欧氏距离筛选对应点 | 远端激光线束间距天然稀疏，有效物理对应点被无脑错杀过滤 | 将最大对应距离设定为随测距距离 $d$ 线性放大的自适应动态阈值 |
