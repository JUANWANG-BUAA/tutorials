# 范围、边界与不重写的内容

为了保证本书的深度与专业性，我们对本书的讨论范围划定极其清晰的边界。

## 1. 本书专注的核心领地

1. **概率状态估计全系理论**：离散贝叶斯滤波、高斯线性卡尔曼滤波（KF）、扩展卡尔曼滤波（EKF）、误差状态卡尔曼滤波（ESKF）、无迹卡尔曼滤波（UKF）及序列重要性粒子滤波（MCL）；
2. **具身传感器物理建模与多源融合**：MEMS IMU 连续运动学、Allan 方差噪声建模、轮速计运动学与打滑动力学、GNSS 坐标投影（ECEF/ENU）与 RTK 差分融合；
3. **视觉感知与几何计算**：针孔相机与径向/切向畸变模型、张正友标定法原理、特征提取与描述（ORB/FAST）、对极几何（本质矩阵与单应性）、DLT 三角化、PnP（P3P/EPnP）与光流法；
4. **激光雷达几何感知与配准**：机械/固态 LiDAR 测量原理与运动去畸变、Kd 树空间索引、点到点 ICP、点到面 ICP、三维正态分布变换（3D NDT）、LOAM 线面特征配准与紧耦合 LIO（Fast-LIO2/LIO-SAM）；
5. **后端非线性优化与因子图**：李群 $\mathrm{SE}(3)$ 流形微积分、左/右扰动模型、Bundle Adjustment 稀疏消元与舒尔补边缘化、位姿图优化（Pose Graph）、Huber/Cauchy 鲁棒核函数与 iSAM2 增量平滑；
6. **环境表征与建图工程**：2D Bresenham 对数几率占据栅格、3D OctoMap 概率八叉树、连续表面 TSDF 截断符号距离场融合、点云地图体素降采样与语义地图投影；
7. **评测与鲁棒容错工程**：ATE/RPE 轨迹评测基准、Horn 绝对位姿对齐、几何退化条件数检测、重定位与绑架恢复、跨多会话地图拼接。

## 2. 本书明确不重写的内容

以下主题已有成熟基础著作或由本系列其他卷深入覆盖，本书绝不水篇幅重写基础教学，仅在必要处提供标准交叉引用：

- **基础线性代数与微积分**：矩阵乘法、特征值分解、一阶导数定义（读者可参考《矩阵论教程》与《数值分析教程》）；
- **机械臂正逆运动学与动力学基础**：DH 参数法、连杆动力学牛顿-欧拉方程（已在第一卷《机器人控制技术》详尽推导，本书仅在视觉伺服控制部分引用几何雅可比与末端变换）；
- **基础深度学习与卷积神经网络原理**：反向传播、SGD/Adam 优化器、ResNet/Transformer 骨干网络（读者可参考《深度学习导论》与邱锡鹏《神经网络与深度学习》）。
