# 具身感知：SLAM、状态估计与传感器融合 · 机器人卷 II

> **“感知不是给世界拍照，而是具身智能体为了在三维物理世界中采取正确行动，对环境与本体状态进行的最优概率推断。”**

欢迎阅读《具身感知：SLAM、状态估计与传感器融合》。本书是机器人学体系的**第二卷**（第一卷为《机器人控制技术》），专为具身智能、移动机器人与自主系统的工程师、研究人员及高年级学生打造。

## 本书定位与核心问题

在第一卷中，我们深入讨论了机械臂的刚体运动学、微分运动学与动力学控制。然而，所有先进控制算法都建立在一个根本前提之上：**机器人必须准确知道自身在空间中的位姿，以及周围环境的几何与语义结构**。

真实的物理世界充满不确定性：
1. **传感器存在固有噪声与延迟**：IMU 存在高斯白噪声与温度零偏漂移；轮速计在打滑路面剧烈打滑；相机在剧烈运动时产生运动模糊；激光雷达在无特征长廊中发生配准退化；
2. **状态维度高且强非线性**：空间刚体位姿属于特殊欧氏群 $\mathrm{SE}(3)$，不具备欧几里得线性空间的加法闭合性；
3. **长期运行下的误差累积**：开环航位推算必然随时间发散，必须依靠几何观测、回环检测与全局位姿图优化消除累积漂移。

本书旨在建立一套**从概率数学推导、李群李代数流形微积分、多传感器硬件建模，到可运行工程复现**的完整具身感知体系。工程代码统一用 Python + NumPy/SciPy，目的是让公式与实现逐行对应；迁移到 C++ 时，矩阵与流形运算可以一对一替换。

## 深度承诺与写作规范

本书恪守严谨的专业标准：
- **拒绝概括空话**：绝不写“SLAM 就是定位与建图”这类泛泛谈资，每章均给出完整的系统状态方程、观测模型、残差推导、雅可比解析式与信息矩阵；
- **真实可运行代码**：所有算法均提供独立、无第三方庞大框架绑定的可运行实验脚本（位于 `experiments/`）与模块化工程代码（位于 `projects/`）；
- **直面工程现实**：每章专门收录 12 条真实工程落地中常见的硬件、标定与算法“陷阱”，并提供排查手段与修复策略。
