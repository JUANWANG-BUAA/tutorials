## 每章的七个判据

1. **正文骨架**：每个内容节都有 `这一节回答` + `::: preview` + 小结 + `::: method 即时自测`；章末「母本对应」表不计入。末节本身就是「本章小结」时，视为已满足小结一项，不再要求嵌套 `### 小结`。
2. **套件**：`chNN-overview.md` 与 summary/recall/exercises/checklist/errata 五页齐，且已登记进 `SUMMARY.md`（未登记＝书里不存在）。
3. **末节收束**：原来的「本章出口检查」改成「本章小结」，逐项打勾交给 checklist 页，正文不重复挂表。
4. **三视角审读**：按 `72-章节审读表.md` 记 A 主线 / B 文段 / C 行文，无 0 分、关键项均分 ≥1.5、A1/B2/C1 必须为 2。
5. **门禁**：`check_loss` 不倒退、`check_book` 该章零报错、`check_numbering` 该章无断档、`check_suspect` 该章清零、`check_terms` 该章命中已处置。
6. **实测口径**：每条运行现场值标明机器；跑不了的写「未实测」并说明原因。「未实测」数量不是罪，**含糊的断言才是**。
7. **构建**：`PATH=/usr/bin:$PATH mdbook build .` 出现 `INFO HTML book written to`，随后 `check_html` 通过。
