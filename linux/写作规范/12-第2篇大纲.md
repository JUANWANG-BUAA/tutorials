# 第 2 篇 · Unix/Linux 系统编程（大纲）

**目标**：把 Kerrisk 的 64 章压成 19 章，覆盖「能写正确系统程序」所需的最小完整集；每章以 API 语义、失败边界、可观测证据为主。
**读者画像**：会 C，知道 `printf`/`malloc`，但没系统写过 `fork`/`epoll`/信号。
**统一要求**：每章 480–680 行；代码必须能编译；每章至少 1 个 `terminal` 验证、1 组 `errata`、1 组自测、1 张图/布局图；错误处理不省略；所有示例用 `-D_GNU_SOURCE -Wall -Wextra -Werror`。
