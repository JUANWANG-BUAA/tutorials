## 读原文的方法（避免上下文爆炸）

1. **先读目录**：`.work/source-toc/*.md`，确定目标章节页码。
2. **只抽目标页**：
   ```bash
   pdftotext -f 100 -l 112 -layout "PDF路径" -
   ```
   不要整本转换，不要一次贴 50 页。
3. **扫描版**（C、L、W）：
   - CSAPP 有完整 PDF 书签，先用 `csapp.md` 的章节页码；
   - 需要看具体页时，`pdftoppm -f N -l N -r 150 -png` 渲染，再 `.work/ocrbin page.png zh-Hans`；
   - 李治军目录已 OCR 在 `.work/ocr/os-test-008..012.png`；正文需要时同样渲染 + OCR。
4. **核对事实**：API 语义以 man-pages/POSIX 为准；内核行为以 Linux 6.8 源码为准；不要只信教材。
5. **不摘录**：读完后合上书，用自己的话写；例子自己设计。
