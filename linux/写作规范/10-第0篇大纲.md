# 第 0 篇 · 命令行与 Shell 工程（大纲）

**目标**：让读者从「会用几个命令」变成「能设计可复用、可测试、可运维的命令行工作流」。
**读者画像**：有 C 基础，用过 `ls/cd/grep`，但没系统学过权限、进程、磁盘、systemd。
**统一要求**：每章 380–520 行；至少 1 个 `terminal` 会话、2 个代码/命令块、1 组 `errata`、1 组自测；命令以 Ubuntu 24.04 为准，旧工具只在附录 A.1 出现。

---

## 0.1 Linux 世界观：内核、GNU、发行版与标准（ch01.md，420 行）

- **回答**：Linux 到底是什么？内核、GNU、发行版、POSIX 各是哪一层？为什么「Linux」严格说只是内核？
- **必讲**：内核职责与边界；GNU 工具链；发行版 = 内核 + libc + 包管理 + 默认配置；POSIX/LSB/FHS 的作用与局限；`uname`/`lsb_release`/`/etc/os-release` 怎么读；x86-64 与 ARM64 的差异只提与后续相关的部分。
- **母本**：鸟哥 0–1；shell-book 1；Kerrisk 1–2；Shotts 1。
- **图**：无（用一张 ASCII 分层图 + 表）。
- **注意**：不写发行版安装步骤；不站队 distro；systemd 只在 0.12 展开。

## 0.2 终端、Shell 与命令行工作流（ch02.md，460 行）

- **回答**：终端、tty、pty、Shell 是什么关系？一条命令从回车到输出经过什么？怎么高效编辑与复用命令？
- **必讲**：tty/pty/终端模拟器；login shell 与 non-login shell；`$PS1`；命令查找顺序（alias/function/builtin/`$PATH`）；`type`/`command -v`；历史展开 `!!`/`!$`/`Ctrl-R`；作业控制最小集（`&`、`fg`、`bg`、`Ctrl-Z`）；vim 生存指南（模式、移动、删除、复制、查找、替换、保存退出）；`tmux` 最小集（session/window/pane、detach/attach）。
- **母本**：鸟哥 4、9；Shotts 1–2、8、12；shell-book 2、10。
- **图**：`boot` 图不适用；用 ASCII 画「键盘 → pty master/slave → shell → 子进程」。
- **注意**：vim 只教够用的 30 个操作，不写成 vim 大全。

## 0.3 文件系统导航与文件操作（ch03.md，500 行）

- **回答**：Linux 目录树为什么这样组织？`ls -l` 的每一列是什么？硬链接、软链接、`rename`、`rm` 在 inode 层发生了什么？
- **必讲**：FHS（`/bin`→`/usr/bin` 合并、`/etc`、`/var`、`/proc`、`/sys`、`/dev`、`/run`）；路径与 `cwd`；`ls -li` 看 inode；`stat` 三组时间；硬链接 vs 软链接（跨文件系统、悬空链接、目录硬链接限制）；`cp -a`/`mv`/`rm -rf` 的边界；`find` 的 `-name/-type/-mtime/-size/-exec/-print0`；`xargs -0`；`tree`/`ncdu`。
- **母本**：鸟哥 5–6；Shotts 2–4；shell-book 3–4；Kerrisk 18。
- **图**：用 `pre class="tree"` 画目录树 + inode 链接示意。
- **注意**：`rm -rf` 的安全习惯（先 `ls`、用 `--`、避免变量为空）；不要教 `cd` 进符号链接后的 `pwd -P` 细节过多。

## 0.4 权限与安全模型（ch04.md，520 行）

- **回答**：`rwx` 之外还有哪些位？`umask` 怎么算？为什么 setuid 危险？ACL 与 capability 怎么替代它？
- **必讲**：mode 的 12 位（setuid/setgid/sticky）；目录的 `x` 与 `r` 的区别；`umask` 计算；`chmod` 符号/八进制；`chown`/`chgrp`；特殊位；ACL（`getfacl/setfacl`，mask）；capability（`getcap/setcap`，`cap_net_bind_service`）；`sudo` 的配置边界（`visudo`、`NOPASSWD` 风险）；`/etc/passwd`、`/etc/shadow`、`/etc/group` 字段。
- **母本**：鸟哥 5、13；Shotts 9；shell-book 7；Kerrisk 8–9、15–17。
- **图**：`pre class="layout"` 画 mode 位 + ACL 判定顺序。
- **注意**：setuid 只作为「历史与危险」讲；主线推荐 capability + systemd `User=`。

## 0.5 重定向、管道与文本流（ch05.md，480 行）

- **母本**：Shotts 6；shell-book 5、15；鸟哥 10。
- **图**：ASCII 画「三个 fd + 管道缓冲区 + 两个进程」。
- **注意**：必须解释 SIGPIPE 与退出码 141。

## 0.6 正则表达式与 grep/sed/awk（ch06.md，560 行）

- **回答**：BRE/ERE/PCRE 有什么区别？`grep -P` 什么时候用？sed 的 hold space 怎么理解？awk 的 `BEGIN/END` 与数组怎么用？
- **必讲**：元字符、字符类、锚点、量词、分组、反向引用；贪婪 vs 非贪婪（PCRE）；`grep -E/-F/-P/-r/-l/-o/-c/-A/-B/-C`；`sed -n 'p'`、`s///g`、地址范围、`-i` 备份、hold space 最小例；awk 字段 `$0/$1/NF/NR/FS/OFS`、模式-动作、数组、`BEGIN/END`、`printf`；三者选择判据。
- **母本**：鸟哥 11；shell-book 19–22；Shotts 19–21。

- **注意**：不要写成正则大全；每个工具给 5–8 个真实任务（日志统计、批量改名、CSV 抽取）。

## 0.7 Bash 编程基础（ch07.md，560 行）

- **回答**：变量、引号、展开、条件、循环的准确语义是什么？哪些写法在空格/通配符/空变量下会炸？
- **必讲**：变量与 `readonly`/`local`；引号三态（单/双/无）；参数展开 `${var:-default}`/`${var#prefix}`/`${var//a/b}`；命令替换 `$()`；算术 `$(( ))`；`test`/`[`/`[[` 的区别；`if/case/for/while/until`；`break/continue`；`select` 提一句；退出码与 `&&`/`||`；`set -euo pipefail` 的语义与例外。
- **母本**：鸟哥 10、12；Shotts 24–35；shell-book 11–13。
- **图**：无；用「引号对照表」。
- **注意**：所有示例用 `#!/usr/bin/env bash`；不教 `csh`；`[` 是命令、`[[` 是关键字必须讲清。

## 0.10 磁盘、文件系统、挂载与 LVM/RAID（ch10.md，620 行）
