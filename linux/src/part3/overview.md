# 第 3 篇 · Linux 内核

::: preview 这一篇在讲什么
系统调用在内核里怎么实现？`fork` 之后调度器怎样选下一个任务，`read` 怎样经过 VFS 与页缓存到达磁盘，缺页时内核怎样补页，`epoll_wait` 为什么能同时等一万个 fd？这一篇以奔跑吧/OSTEP 为主线、CSAPP 第 9 章与 Kerrisk 的用户态接口为底座，带你读关键路径，而不是背结构体名字。
:::

## 读完这一篇你会

- 编译/启动一个内核，用 QEMU + `printk`/`gdb` 做最小实验。
- 解释启动链路、中断/异常/系统调用的入口与返回。
- 读懂 `task_struct`、调度器（CFS/EEVDF/实时）、多核/NUMA 负载均衡。
- 解释物理页分配、虚拟内存/页表、slab/vmalloc、页回收/RMAP/KSM。
- 用 `mutex`/`spinlock`/RCU 解释内核并发，知道睡眠与原子上下文的边界。
- 读懂 VFS、ext4、块层、I/O 调度与设备驱动的基本路径。
- 用 `perf`/`ftrace`/`bpftrace`/`crash` 找证据，而不是猜。

## 怎么读这一篇

- **第一次读**：3.1–3.3 必须先动手（编译、QEMU、`printk`）；之后按 3.4–3.15 顺序。
- **只想排障**：3.15 + 3.5（调度）、3.7–3.10（内存）、3.13（I/O）；其余按需回查。
- **想读源码**：先有用户态证据（`strace`/`perf`），再按函数名跳转，不要从目录通读。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补页表/中断/进程，再回到对应小节。
