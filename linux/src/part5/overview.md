# 第 5 篇 · 云原生

::: preview 这一篇在讲什么
容器不是轻量虚拟机：它共享宿主机内核，用 namespace 改视图、cgroup 限资源、overlayfs 做镜像分层、OCI runtime 管生命周期。这一篇把「容器为什么能隔离、为什么不能换内核、镜像为什么分层、Kubernetes 的原语在说什么」讲清，并用一个最小容器运行时把概念落到代码。
:::

## 读完这一篇你会

- 解释容器与虚拟机的边界：共享内核、namespace、cgroup、rootfs。
- 用 `unshare`/`nsenter` 操作 namespace，解释 PID 1、挂载传播与用户命名空间。
- 用 cgroup v2 限制 CPU/内存/IO，读懂 `cpu.max`、`memory.max`、`pids.max`。
- 解释 overlayfs 的 lower/upper/work 与镜像分层、写时复制。
- 解释 OCI 镜像/运行时/生命周期（runc、containerd、CRI）。
- 解释 Kubernetes 的 Pod/Service/Deployment 原语与容器网络的基本模型。
- 写一个最小 `mycontainer`：namespace + cgroup + overlayfs + `exec`。
