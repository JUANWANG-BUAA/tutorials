## 4. 每周节奏

无论哪条路线，建议每周固定四件事：

1. **读**：2–3 章正文，先看「本章回答」与图，再读细节；
2. **做**：每章至少跑通一个实验，记录命令与输出；
3. **测**：章末出口检查 + 回忆卡，错题回到对应小节；
4. **写**：一页笔记，只写「路径 + 边界 + 一个反例」，不抄书。
