## 1. C 语言最小集

**大白话**：变量是放数据的盒子，指针是盒子的地址，结构体是把几个盒子捆在一起，函数是一段可复用的代码。C 程序要先编译成机器码，再由加载器装进内存运行。

**最小例子**：

```c
int x = 1;
int *p = &x;          /* p 保存 x 的地址 */
printf("%d\n", *p);   /* 通过地址读 x，输出 1 */
```

**为什么系统编程离不开指针**：系统调用要传缓冲区地址、长度和结构体指针；不理解地址，就看不懂 `read(fd, buf, n)` 里的 `buf` 是什么。

**展开**：[1.2 信息的表示与运算](part1/ch02.md)、[1.3 机器级程序](part1/ch03.md)、[1.7 链接、加载与库](part1/ch07.md)；Kerrisk 第 1–2 章。

## 2. 程序、进程与地址空间

**大白话**：程序是磁盘上的文件；进程是程序跑起来后的实例。每个进程都以为自己独占一整块内存（虚拟地址空间），内核用页表把它映射到真实的物理内存。

**最小例子**：

```bash
sleep 100 &     # 启动一个进程
ps -o pid,ppid,cmd -p $!   # 看它的 PID、父进程、命令
```

`fork()` 之后父子进程各有一份地址空间副本（写时复制），所以子进程改变量不影响父进程。

**展开**：[1.1 计算机系统漫游](part1/ch01.md)、[1.9 虚拟内存](part1/ch09.md)、[2.7 进程创建与终止](part2/ch07.md)；CSAPP 第 1、9 章，Kerrisk 第 6、24–27 章。

## 3. 文件、inode 与 fd

**大白话**：文件不只是一串字节，还有元数据（权限、大小、时间、数据块位置），这些元数据放在 inode 里；目录是「名字 → inode 号」的映射。fd 是进程内「打开文件表」的下标，表项指向一次打开。

**最小例子**：

```bash
ls -li /etc/hosts          # 第一列是 inode 号
cat /proc/self/fd/0        # 看当前进程的 fd 0 指向哪
```

同一个文件可以被打开多次，得到多个 fd，各自有独立偏移；`dup`/`fork` 出来的 fd 共享同一个「打开文件描述」，所以共享偏移。

**展开**：[0.3 文件系统导航与文件操作](part0/ch03.md)、[2.2 文件 I/O](part2/ch02.md)、[2.5 文件属性](part2/ch05.md)；Kerrisk 第 4–5、18 章，CSAPP 第 10 章。

## 4. 系统调用与 errno

**大白话**：用户态程序不能直接碰硬件；要读文件、发网络包、创建进程，必须通过系统调用请内核代劳。系统调用失败时通常返回 `-1`，具体原因放在 `errno` 里。

**最小例子**：

```c
int fd = open("/no/such/file", O_RDONLY);
if (fd == -1)
    perror("open");   /* 输出 open: No such file or directory */
```

`errno` 是线程局部变量；失败后要立刻读，别被下一条库函数覆盖。`syscall()` 是裸入口，glibc 的 `open()`/`read()` 是包装。

**展开**：[0.1.13 系统调用接口](part0/ch01.md#sec-0.1.13)、[2.1 系统编程基础](part2/ch01.md)；Kerrisk 第 2–3 章，CSAPP 第 8、10 章。

## 5. 并发：线程、锁与原子

**大白话**：线程是同一个进程里并发执行的执行流，共享地址空间；锁用来保证同一时间只有一个线程改共享数据；原子操作是不可被打断的一步操作。

**最小例子**：两个线程各把同一个计数器加 100 万次，不加锁的结果通常小于 200 万——因为 `n++` 不是一步。

**展开**：[1.12 并发编程](part1/ch12.md)、[2.12 线程](part2/ch12.md)、[2.13 线程同步](part2/ch13.md)、[3.11 内核并发与同步](part3/ch11.md)；CSAPP 第 12 章，Kerrisk 第 29–33 章。

## 6. 网络：IP、端口与 TCP

**大白话**：IP 地址找主机，端口找主机上的进程；TCP 在不可靠的 IP 上提供可靠、有序的字节流，靠三次握手建连、ACK/重传/窗口做可靠传输。

**最小例子**：

```bash
ss -lnt                 # 看本机在监听哪些 TCP 端口
curl -v https://example.com   # 看 DNS、TCP、TLS、HTTP 各阶段
```

**展开**：[1.11 网络编程与协议基础](part1/ch11.md)、[4.1 网络分层与报文之旅](part4/ch01.md)、[4.4–4.6 TCP](part4/ch04.md)、[2.16 套接字基础](part2/ch16.md)；CSAPP 第 11 章，谢希仁第 1–6 章。

## 7. 缓存与性能

**大白话**：缓存是把常用的数据放在离 CPU 更近的地方；性能不能只看一个数字，要区分延迟（一次操作多久）和吞吐（单位时间做多少）。

**最小例子**：顺序遍历一个大数组，通常比随机跳着访问快很多，因为缓存一次会装入相邻数据。

```bash
perf stat -e cache-misses,cache-references ./your_program
```

**展开**：[1.5 程序性能优化](part1/ch05.md)、[1.6 存储层次与缓存](part1/ch06.md)、[3.15 内核调试、观测与性能分析](part3/ch15.md)；CSAPP 第 5–6 章。

## 8. 命令行：管道、重定向与退出码

**大白话**：管道 `|` 把左边命令的 stdout 接到右边命令的 stdin；重定向 `>`/`<` 改变 fd 指向；退出码 0 表示成功，非 0 表示失败。

**最小例子**：

```bash
grep ERROR app.log | wc -l    # 统计错误行数
echo $?                       # 上一条管道的退出码（默认是最后一段的）
```

**展开**：[0.5 重定向、管道与文本流](part0/ch05.md)、[0.6 正则表达式与 grep/sed/awk](part0/ch06.md)。

## 9. 内核、发行版与版本

**大白话**：Linux 严格说是内核；你日常用的完整系统是发行版（内核 + C 库 + 用户态工具 + 包管理 + 默认配置）。`uname -r` 看内核，`/etc/os-release` 看发行版。

**最小例子**：

```bash
uname -r
cat /etc/os-release | head -3
```

**展开**：[0.1 Linux 世界观](part0/ch01.md)、[0.1.4 发行版](part0/ch01.md#sec-0.1.4)。

## 10. 怎么读 man page

**大白话**：man page 按区组织：`man 2` 是系统调用，`man 3` 是 C 库函数，`man 5` 是文件格式，`man 7` 是概览与约定。读错区，就会把 libc 行为当成内核行为。

**最小例子**：

```bash
man 2 read        # 内核视角：返回值、EINTR、短读
man 3 fread       # stdio 视角：缓冲、EOF、线程安全
man 7 signal      # 信号语义、默认动作、可捕获性
```

**展开**：[0.1.9 文档即证据](part0/ch01.md#sec-0.1.9)。
