# 0.11 软件包、编译、库与镜像 · 本章导航

::: preview 这一章在讲什么
为什么 `apt install` 了库，编译还是 `undefined symbol`？为什么同一个二进制在同事机器上能跑、到你这里就 `not found`？`.deb` 里到底装了什么，`apt` 怎样求解依赖，`soname` 和符号版本怎样决定 ABI？这一章从包、源码构建、静态/共享库、链接错误一路走到容器镜像与 `dpkg` 状态机，再用 `pkg-config`/`readelf`/`patchelf` 做对账。目标不是背命令，而是**遇到“装不上/链接不上/跑不起来”时知道查哪一层**。
:::

## 读完你会

- 拆开 `.deb` 看 control/data、依赖、维护者脚本与文件所有权。
- 配 apt 源、理解依赖求解与 pinning，知道 `apt install` 为什么选这个版本。
- 用 `prefix`/`DESTDIR` 做源码构建与暂存安装，不污染系统。
- 分清静态库、共享库、`soname`、`rpath`/`runpath` 与符号版本。
- 按顺序排查 `undefined reference`/`undefined symbol`/`not found`。
- 用 `pkg-config`/CMake 写最小工程，用 `readelf`/`ldd`/`objdump` 对账。
- 把用户态打包成容器镜像，解释镜像层与运行时依赖。
- 用 `dpkg` 状态机/维护者脚本/`debian/` 目录做一个最小 deb。

## 先修与预计学时

- 先修：读完 [0.10 磁盘、文件系统、挂载与 LVM/RAID](ch10.md)；会 `gcc`、`make`、`apt`。**不需要**学过链接器；ELF/soname 的白话解释在本章开头。
- 阅读：约 120–150 分钟；实验与打包：约 90 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.11.1–0.11.8 按顺序；每节先做「即时自测」，再去下一节。`gcc`/`ldd`/`readelf` 要自己在终端里试。
- **只想装包/排依赖**：0.11.1–0.11.2、0.11.9；先看 `apt-cache policy`/`apt install -s`。
- **想编译/链接**：0.11.3–0.11.6、0.11.10；先分清编译期/链接期/运行期。
- **想打包/做镜像**：0.11.7–0.11.8、0.11.14；先做最小 deb/镜像，再谈优化。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补链接/ELF/ABI，再回到对应小节。

- 应用/运维：**必读**（0.11.1–0.11.7；装包、依赖、镜像最常用）。
