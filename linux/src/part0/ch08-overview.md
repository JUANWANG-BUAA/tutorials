# 0.8 Bash 编程进阶与工程化 · 本章导航

::: preview 这一章在讲什么
从“能跑”到“可维护”，差的不是更多语法，而是工程纪律：函数怎样返回结果、数组怎样存列表、`trap` 怎样保证清理、临时文件怎样不冲突、并发怎样限流、参数怎样解析、日志怎样留证据。这一章用一个完整的 `backup.sh` 把这些串起来，再用第二遍看函数/数组/`trap` 的语义与 `flock`/`wait -n`/`getopt`/`shellcheck` 的边界。学完你能写出别人敢在生產上跑的脚本。
:::

## 读完你会

- 用三种返回通道写函数：退出码、stdout、nameref/全局变量。
- 用索引数组、关联数组与 `mapfile` 存列表/映射，知道稀疏数组的边界。
- 用 `trap` 在 `EXIT`/`ERR`/`INT`/`TERM` 时做清理，避免重复执行与退出码丢失。
- 用 `mktemp`、`flock` 做安全的临时文件与单实例锁。
- 用 `wait -n` 做后台任务限流，处理并发收尾。
- 用 `getopt`（外部）解析长选项，用 `getopts` 解析短选项。
- 写 `backup.sh`：参数、日志、锁、临时文件、错误处理、清理、退出码。
- 用 `shellcheck`、`set -x`、`PS4` 与 POSIX 边界做静态/动态检查。

## 先修与预计学时

- 先修：读完 [0.7 Bash 编程基础](ch07.md)；会写函数、条件、循环与 `set -euo pipefail`。**不需要**学过并发理论；锁与并发的白话解释在 0.8.4/0.8.11。
- 阅读：约 120–150 分钟；实验与脚本：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.8.1–0.8.7 按顺序；每节先做「即时自测」，再去下一节。`backup.sh` 要自己跑一遍。
- **只想写备份脚本**：0.8.1–0.8.7、0.8.16；先保证锁、临时文件、清理、退出码。
- **想写并发脚本**：0.8.4、0.8.11–0.8.12；先理解 `flock` 与 `wait -n` 的边界。
- **想读别人的脚本**：0.8.8–0.8.15；先看函数返回通道、数组、`trap` 与 `getopt`。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补函数/数组/信号/锁，再回到对应小节。
