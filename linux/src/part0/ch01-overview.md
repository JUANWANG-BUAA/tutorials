# 0.1 Linux 世界观 · 本章导航

::: preview 这一章在讲什么
你每天都在敲 `ls`、`apt`、`systemctl`，但很多「Linux 报错」其实不是内核报的。这一章先给你一张四层地图：内核、C 库、Shell、发行版各管什么；再带你追一条命令从按键到系统调用的路径。学完这张地图，后面每个排障问题都能先问一句「这是哪一层的事」。
:::

## 读完你会

- 从 `uname -a`、`/etc/os-release`、`getconf` 的输出里，分清内核、用户态和发行版。
- 画出「应用 → libc → 系统调用 → 内核 → 硬件」的分层图，说出内核不负责的三件事。
- 用 `strace` 把一条 `ls` 拆成 `execve`、`openat`、`getdents64`、`write` 几步，并指出每步是谁做的。
- 解释 POSIX 保证什么、FHS 约定什么、发行版策略决定什么，不再把三者混为一谈。
- 判断一个模块是内建还是可加载，画出从固件到 systemd 的五段启动链路。
- 解释 `syscall()` 与 `write()` 的返回值、`errno` 和 vDSO 差异。
- 用「可变性」判断一个目录该放配置、状态还是运行时数据。

## 先修与预计学时

- 先修：会 C 的变量、函数、指针；会用 `cd`、`ls`、`cat` 和管道。**不需要**学过操作系统、组成原理或计算机网络。
- 如果终端还不熟，先做[入学诊断](../entry-test.md)，再回来看[符号与命令约定](../notation.md)。
- 阅读：约 90–120 分钟；做完三个实验：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：按五个单元顺序读。每读完一节，先合上页面做该节的「即时自测」，再往下走。
- **只想排障**：先读 [0.1.16](ch01.md#sec-0.1.16) 的十个误判，再按问题回到对应小节；启动问题直接看 [0.1.12](ch01.md#sec-0.1.12)。
- **想深入**：读 [0.1.8](ch01.md#sec-0.1.8) 的 `strace` 拆解与 [0.1.13](ch01.md#sec-0.1.13) 的系统调用 ABI；这两节是后面第 1、2 篇的入口。
- **非科班补课**：这一章不要求你先懂页表、中断或文件系统。遇到这些词，先看本节的白话解释；还不懂就记下，第 1、2 篇会逐层展开。
