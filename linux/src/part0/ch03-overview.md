# 0.3 文件系统导航与文件操作 · 本章导航

::: preview 这一章在讲什么
你每天都在 `cd`、`ls`、`cp`、`rm`，但一旦遇到「文件明明删了磁盘还满」「`du` 和 `ls` 对不上」「`rm` 删不掉」「`find` 结果多了一堆」就容易卡住。这一章分两遍走：第一遍先让你会用目录树、链接、查找和批量操作；第二遍回到内核，用 inode、dentry、`stat` 字段、`renameat2` 与 `xattr` 解释「为什么是这样」。两遍之间不是重复，而是「先用对，再看懂」。
:::

## 读完你会

- 画出 FHS 目录树的用途分区，解释 usrmerge 后 `/bin` 为什么是链接。
- 逐列读 `ls -l` 与 `stat`，说出 inode、链接数、块数、时间字段各是什么。
- 解释硬链接与软链接的区别，知道 `cp`/`mv`/`rm` 在跨文件系统、符号链接、权限上的边界。
- 写出带优先级和动作的 `find` 表达式，用 `-print0` + `xargs -0` 安全处理带空格的文件名。
- 解释 `du` 与 `ls -l` 为什么对不上：稀疏文件、硬链接、块大小、已删除但仍打开的文件。
- 用 `strace` 看到 `openat`、`readlink`、`renameat2`、`unlink` 的真实调用。
- 用 `rsync`/`tar` 做可验证的复制与归档，知道 `--delete`、`-a`、`-H` 的风险。
- 写一个默认试运行、拒绝危险根目录的清理脚本。

## 先修与预计学时

- 先修：读完 [0.2 终端、Shell 与命令行工作流](ch02.md)；会用 `cd`、`ls`、`cp`、`mv`、`rm`、`find`。**不需要**学过文件系统；inode 与 dentry 的白话解释在本章开头。
- 阅读：约 120–150 分钟；实验与脚本：约 60 分钟；章末习题：约 60 分钟。

一句话主线：**先把目录树与路径走通（0.3.1–0.3.2），再用 `ls`/`stat` 看清文件、用链接与 `cp`/`mv`/`rm` 操作文件（0.3.3–0.3.5）；接着用 `find`/`xargs`/`du` 做批量与占用分析（0.3.6–0.3.9）。第一遍只要求会用。第二遍回到内核：路径 → dentry → inode → `stat` → `find` 表达式 → `xargs` NUL → `xattr` → 复制/归档 → 移动/删除的原子性（0.3.10–0.3.18）。最后用 `strace` 取证、三个脚本与陷阱清单收口（0.3.19–0.3.21）。**

## 怎么读

- **第一次读**：先读第一遍（0.3.1–0.3.9），每节做完「即时自测」；如果只想会用，到这里可以先去整理自己的目录。
- **要排障**：先读 [0.3.21](ch03.md#sec-0.3.21) 的本章小结，再按症状回到 [0.3.3](ch03.md#sec-0.3.3)（`ls -l`）、[0.3.13](ch03.md#sec-0.3.13)（inode/稀疏文件）、[0.3.14](ch03.md#sec-0.3.14)（find 表达式）；逐项打勾去 [学习目标自检表](ch03-checklist.md)。
- **要深入**：第二遍（0.3.10–0.3.18）配合 [0.3.19](ch03.md#sec-0.3.19) 的 `strace` 实验一起读。
- **非科班补课**：不需要先懂文件系统。先记住「目录是名字到 inode 的映射，inode 存元数据与数据块位置，dentry 是内核里的目录项缓存」；第二遍再展开。
