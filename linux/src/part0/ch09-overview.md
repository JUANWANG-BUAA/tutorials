# 0.9 进程、作业控制与信号 · 本章导航

::: preview 这一章在讲什么
`ps` 里那些 `S`/`R`/`D`/`Z` 是什么意思？`Ctrl-C` 到底发给了谁？为什么关掉终端后台任务会死？为什么容器里的 PID 1 不回收僵尸？这一章先把进程看清：五列、进程组、会话、控制终端、状态；再学会管：作业控制、信号、僵尸/孤儿、`nice`/亲和性/资源限制；最后看信号的处置、阻塞与排队，用脚本和实验把结论变成证据。
:::

## 读完你会

- 读 `ps` 的 PID/PPID/STAT/TTY/CMD 五列，解释 `S`/`R`/`D`/`Z`/`T` 等状态。
- 画出进程组、会话、控制终端的关系，解释 `Ctrl-C`/`Ctrl-Z`/`SIGHUP` 发给谁。
- 用 `jobs`/`fg`/`bg`/`disown`/`nohup`/`setsid` 管理前后台与断线。
- 用 `kill` 先 `TERM` 再 `KILL`，解释信号处置、阻塞、排队与 `sigprocmask`。
- 解释僵尸/孤儿、`wait`/`waitpid`、PID 1 的回收责任。
- 用 `nice`/`renice`/`taskset`/`ulimit`/cgroup 管理 CPU 与资源。
- 用 `ps`/`top`/`/proc` 定位进程树、身份与资源。
- 写进程巡检/信号转发/超时回收脚本，并用实验验证。

## 先修与预计学时

- 先修：读完 [0.8 Bash 编程进阶与工程化](ch08.md)；会 `ps`、`kill`、`&`。**不需要**学过操作系统；进程组/会话/信号的白话解释在本章开头。
- 阅读：约 100–130 分钟；实验与脚本：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.9.1–0.9.10 按顺序；每节先做「即时自测」，再去下一节。`ps`/`kill` 要自己在终端里试。
- **只想排障**：0.9.1、0.9.3、0.9.5–0.9.6、0.9.9、0.9.13；先看状态与进程树，再决定信号。
- **想写作业控制/守护进程**：0.9.2、0.9.4、0.9.6、0.9.10；配合 0.8 的 `trap`/`flock`。
- **想管资源**：0.9.8、0.9.14；`nice`/`taskset`/`ulimit`/cgroup 各管什么要分清。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补进程/信号/线程，再回到对应小节。
