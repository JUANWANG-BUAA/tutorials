# 0.7 闭卷回忆卡

这页不是摘要，而是一组**检索练习**。先只看问题，合上正文，开口说或落笔写；「看着熟」不算会。每张卡答完再展开核对。

建议在学完当天、隔天、第 3 天、第 7 天各做一次。每次只记三种结果：✓ 能完整写出；△ 有关键词但缺条件；× 完全想不起。下一轮只重做 △ 和 ×。

## A. 第一遍：先会用

### D1 · 脚本骨架

一个可靠脚本的开头通常有哪几行？`set -euo pipefail` 各是什么？shebang 为什么写 `#!/usr/bin/env bash`？

::: sol D1 核对

开头：`#!/usr/bin/env bash`、`set -euo pipefail`、可选的 `IFS=$'\n\t'`。`-e` 命令失败退出，`-u` 使用未定义变量报错，`-o pipefail` 管道任一段失败即失败。`env bash` 从 `PATH` 找 bash，避免写死 `/bin/bash`；macOS 自带 bash 3.2，`env` 更容易用到新版。
:::

### D2 · 变量与作用域

变量、环境变量、只读变量、局部变量各是什么？`export`、`readonly`、`local` 各做什么？

::: sol D2 核对

普通变量只在当前 Shell；`export` 后进入环境，子进程可见；`readonly` 禁止修改/删除；`local` 只在函数内有效（bash 扩展）。变量默认全局，函数里改全局变量要小心；`declare -p var` 看类型/值。环境变量用 `env`/`printenv` 看。
:::

### D3 · 引号三态

无引号、单引号、双引号各怎样处理变量、分词与通配？`"$@"` 与 `"$*"` 差在哪？

::: sol D3 核对

无引号：变量展开后会分词、通配；单引号：全字面，不展开；双引号：展开变量/命令替换，但不分词/不通配。`"$@"` 保留每个位置参数为独立参数；`"$*"` 用 `IFS` 合成一个字符串。路径、变量、命令替换默认都加双引号。
:::

### D4 · 参数展开

`${var:-default}`、`${var:=default}`、`${var:?msg}`、`${var:+alt}`、`${#var}`、`${var#prefix}`、`${var%suffix}`、`${var/old/new}` 各做什么？

::: sol D4 核对

`:-` 为空/未设时用默认值（不赋值）；`:=` 同时赋值；`:?` 为空/未设时报错退出；`:+` 有值时用 alt；`${#var}` 长度；`#` 去最短前缀，`##` 去最长；`%` 去最短后缀，`%%` 去最长；`/old/new` 替换第一个，`//old/new` 替换全部。它们不调用外部命令，比 `sed`/`cut` 快。
:::

### D5 · 命令替换与算术

`$(...)` 与 `` `...` `` 差在哪？`$((...))` 与 `((...))` 各做什么？算术里变量要不要 `$`？

::: sol D5 核对

`$(...)` 可嵌套、可读性好，优先用；反引号旧式、嵌套要转义。`$((...))` 展开为算术结果；`((...))` 作为命令执行，返回退出码（非零为真）。算术里变量名通常不用 `$`（`$((a+1))` 和 `$(( $a + 1 ))` 都可，但前者更清晰）；`((count++))` 可直接改变量。
:::

### D6 · 条件三套

`[`、`[[`、`(( ))` 各是什么？字符串/数字/文件测试各举一例。`[[ ]]` 比 `[` 强在哪？

::: sol D6 核对

`[` 是命令（`test`），`[[` 是 bash 关键字，`(( ))` 做算术。字符串：`[[ $a == b ]]`；数字：`(( a > b ))`；文件：`[[ -f $path ]]`。`[[ ]]` 支持 `&&`/`||`、模式/正则 `=~`、不做分词/通配，空变量更安全；`[` 需要小心引号和 `-a`/`-o`。
:::

## B. 第二遍：看展开与边界

### D7 · 分支与循环

`if`/`case`/`for`/`while`/`until`/`select` 各适合什么？`break`/`continue`/`return` 差在哪？

::: sol D7 核对

`if` 条件分支；`case` 多值匹配（字符串/模式）；`for` 遍历列表/数组；`while`/`until` 条件循环；`select` 生成菜单（bash）。`break` 退出循环，`continue` 下一轮，`return` 退出函数并返回状态码（0–255）。循环读文件用 `while IFS= read -r line`。
:::

### D8 · 退出码与 set -e

退出码 0/非 0 各表示什么？`set -e` 在哪些语境不生效？`pipefail`/`PIPESTATUS` 解决什么？

::: sol D8 核对

0 成功，非 0 失败（1 通用错误，2 用法错误，126/127 不可执行/找不到，130 Ctrl-C，141 SIGPIPE）。`set -e` 在 `if`/`while`/`until`/`&&`/`||`/`!`、管道（除非 `pipefail`）等语境有例外；函数/子 Shell 里也可能不按预期传播。`pipefail` 让管道任一段失败即失败；`PIPESTATUS` 保留每段状态，需立刻保存。
:::

### D9 · 展开顺序

一行命令执行前，bash 按什么顺序展开？为什么 `var='a b'; echo $var` 输出两个参数？

::: sol D9 核对

顺序：大括号展开 → 波浪号展开 → 参数/变量展开 → 命令替换 → 算术展开 → 分词 → 通配符展开 → 去引号。`$var` 未加引号，参数展开后经过分词，`a b` 变成两个参数；`"$var"` 保留一个。顺序记反会写出“看起来对、跑起来错”的脚本。
:::

### D10 · 位置参数与 getopts

`$0`、`$1`、`$#`、`$@`、`$*`、`shift` 各是什么？`getopts` 怎样解析 `-a -b value`？

::: sol D10 核对

`$0` 脚本名，`$1` 第一个参数，`$#` 参数个数，`$@` 所有参数（数组语义），`$*` 所有参数（合一个字符串），`shift` 左移参数。`getopts 'ab:' opt` 解析 `-a`（无参）与 `-b value`（有参），`OPTARG` 取值，`OPTIND` 位置；循环后 `shift $((OPTIND-1))` 处理剩余位置参数。长选项要手写 `case`。
:::

### D11 · trap

`trap 'cleanup' EXIT INT TERM` 各在什么时候执行？`ERR` trap 与 `set -e` 怎样配合？清理函数里要注意什么？

::: sol D11 核对

`EXIT` 在脚本退出时执行（正常/`exit`/信号捕获后）；`INT`/`TERM` 在收到 Ctrl-C/终止信号时执行；`ERR` 在命令失败时执行（受 `set -e` 例外影响）。清理函数先保存 `$?`、`trap -` 防递归、再删临时文件/恢复终端。不要假设 `ERR` 一定触发；关键清理放 `EXIT`。
:::

### D12 · 可移植性与静态体检

bash 专有语法有哪些？`#!/bin/sh` 与 `#!/usr/bin/env bash` 差在哪？没有 `shellcheck` 时用哪六步把一个脚本过一遍？

::: sol D12 核对

bash 专有：数组、`[[ ]]`、`(( ))`、`local`、`<<<`、`<()`、`&>`、`select`、`mapfile`、`${var//}` 等。`#!/bin/sh` 在 Debian/Ubuntu 是 dash，不支持 bash 扩展；要 bash 就写 `#!/usr/bin/env bash`。静态检查按 0.7.15 的六步走：`bash -n` 查语法、`PS4=… bash -x` 看每条命令的 argv 形状、`declare -p` 与 `printf '%q'`/`printf '[%s]'` 分清值本体与切出来的词、临时加 `set -u` 抓未设置、把 `rm`/`mv`/`>` 换成 `printf` 试运行、收尾打印一次 `argc=`。本书两台机器都没装 `shellcheck`（`command -v shellcheck` 都返回空），所以它不在必答项里；SC2086/SC2181 这类编号只是给同一批问题起了名字，规则表见 0.8.14，装了工具也替代不了运行测试。
:::
