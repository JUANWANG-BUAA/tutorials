# 0.6 正则表达式与 grep/sed/awk · 本章导航

::: preview 这一章在讲什么
正则不是一串要背的符号，而是把文本流变成「可筛选、可改写、可统计」的数据的工具。这一章分两遍走：第一遍先分清 BRE/ERE/PCRE 三种方言，用 grep 筛、sed 改、awk 算，知道三者怎么选；第二遍回到引擎与全表，看回溯、退出码、hold space、数组与浮点精度。学完你能把一坨日志变成一张报表，而不是一条条肉眼翻。
:::

## 读完你会

- 分清 BRE、ERE、PCRE 的元字符差异，写出锚点、字符类、量词、分组、反向引用。
- 用 `grep` 筛选/计数，读懂退出码 0/1/2，知道 `-F`/`-E`/`-P` 的边界。
- 用 `sed` 的「模式空间 + 地址 + 命令」执行模型做替换、删除、插入、分支与 hold space。
- 用 `awk` 的「记录/字段/规则」模型做统计、报表、数组与自定义函数。
- 在三者之间做选择：筛选用 grep，流编辑用 sed，结构化统计用 awk。
- 用 `sort`/`uniq`/`cut`/`tr`/`paste`/`join`/`diff` 补齐文本处理链。
- 解释正则引擎的回溯、贪婪/懒惰、locale 对匹配的影响，避免灾难性回溯。
- 用 `sed -i` 的 inode 行为、awk 浮点精度、`sed -n l` 的不可见字符排查真实问题。

## 先修与预计学时

- 先修：读完 [0.5 重定向、管道与文本流](ch05.md)；会用 `grep`、`sed`、`awk` 的基本命令。**不需要**学过编译原理；正则引擎的白话解释在 0.6.9。
- 阅读：约 120–150 分钟；实验与脚本：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.6.1–0.6.8 按顺序；每节先做「即时自测」，再去下一节。正则一定要在终端里试，不要只看。
- **只想筛日志**：0.6.1–0.6.3、0.6.8；先会用 `grep -E`/`-F`，再回来看引擎。
- **想批量改文件**：0.6.4–0.6.5、0.6.11–0.6.12；先用 `sed -n`/`-i.bak` 试运行。
- **想做报表**：0.6.6、0.6.13–0.6.15；先写 awk 的 `BEGIN/pattern/END` 骨架。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补管道/重定向，再回到对应小节。
