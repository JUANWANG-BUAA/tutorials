# 第 0 篇 · 命令行与 Shell 工程

::: preview 这一篇在讲什么
这一篇不是命令速查，而是把「你敲下的每个字如何变成内核动作」讲通。学完你不仅能写命令，还能解释一条命令经过哪几层、脚本为什么失败、服务为什么起不来、网络为什么超时；后面的计算机系统、系统编程、内核与网络，都从这张地图往下走。
:::

## 读完这一篇你会

- 画出「终端 → Shell → 系统调用 → 内核」的链路，分清内核、libc、发行版各管什么。
- 用文件、权限、重定向、管道、正则完成日常任务，知道每一步的边界与失败模式。
- 写带 `set -euo pipefail`、`trap`、日志与 `--dry-run` 的 Bash 脚本。
- 管理进程、作业、信号、磁盘、软件包、systemd 服务、日志与定时任务。
- 用 `ss`、`tcpdump`、`strace`、`perf` 等工具定位服务、网络与性能问题。
- 知道每一章在三条学习路线里是必读、可后补还是可跳过。

## 入口与出口

| 项 | 内容 |
|:--|:--|
| **入口** | 会用几条命令，但不成体系；遇到「命令找不到」「权限拒绝」「服务起不来」「网络超时」只能试错。 |
| **出口** | 能写带错误处理的脚本；能用证据定位文件、权限、进程、磁盘、服务、网络问题；能解释一条命令的完整路径。 |
| **不需要** | 不需要学过操作系统、组成原理或计算机网络；0.1 会把分层补上，后续篇再展开。 |

## 与后面篇的接口

- **0.1 / 0.3 / 0.4 / 0.5 → 第 1、2 篇**：分层、文件、权限、fd 表是 CSAPP 与 Kerrisk 的入口。
- **0.9 → 第 2、3 篇**：进程、信号、作业控制是系统编程与调度器的前置。
- **0.10 → 第 3 篇**：磁盘、文件系统、LVM/RAID 是 VFS 与块层的前置。
- **0.12 → 第 5 篇**：systemd、日志、服务管理是容器与云原生的运维基础。
- **0.13 → 第 4 篇**：网络配置、抓包、排障是协议栈与 socket 的入口。

## 怎么读这一篇

- **第一次读**：按 0.1 → 0.14 顺序读；每章先看章总览，再做每节「即时自测」。0.1–0.6 是地基，不要跳。
- **只想运维**：0.1–0.9、0.12–0.14；0.10 至少读磁盘与挂载，0.11 至少读 apt/dpkg。
- **想做系统编程**：0.1–0.9、0.13；0.10–0.12 可后补。
- **只想排障**：先看每章章末的「看到问题先选工具」与陷阱清单，再回到对应小节。
