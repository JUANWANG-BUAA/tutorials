# 0.5 重定向、管道与文本流 · 本章导航

::: preview 这一章在讲什么
`>`、`2>&1`、`|`、`tee` 看起来像“语法糖”，其实是在改进程的文件描述符表。这一章分两遍走：第一遍先让你会用，能写对重定向、管道、日志和缓冲；第二遍再回到内核，用 `dup2`、`PIPE_BUF`、`SIGPIPE` 解释“为什么必须这样写”。两遍之间不是重复，而是“先用起来，再看清底层”。
:::

## 读完你会

- 画出进程的 fd 表，解释 `2>&1 >file` 与 `>file 2>&1` 为什么结果相反。
- 用 here-doc、here-string、进程替换写配置、传输入，知道引号定界符的安全边界。
- 写对管道：取 `PIPESTATUS`、开 `pipefail`、处理 `SIGPIPE` 与退出码 141。
- 避免 `while read` 在管道里丢变量，知道进程替换、`lastpipe`、命令替换各自的生效条件。
- 用 `tee` 同时看输出和留日志，并保留上游退出码。
- 解释缓冲三模式、TTY 检测、`stdbuf` 的适用边界。
- 用 `dup2`、`O_CLOEXEC`、`/proc/PID/fd` 解释 fd 共享、fd 泄漏和 fd 耗尽。
- 在脚本里安全地备份/恢复 fd，处理 `INT`/`TERM` 清理。

## 先修与预计学时

- 先修：会 C 的变量、函数、指针；用过 `>`、`|`、`grep`。**不需要**学过操作系统；fd 的白话解释在本章开头。
- 如果文件操作还不熟，先看 [0.3 文件系统导航与文件操作](ch03.md)；如果权限还不熟，先看 [0.4 权限与安全模型](ch04.md)。
- 阅读：约 120–150 分钟；三个实验：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：先读第一遍（0.5.1–0.5.7），每节做完「即时自测」；如果只想“会用”，到这里可以先去写脚本，遇到 bug 再回第二遍。
- **要排障**：直接看 [0.5.18](ch05.md#sec-0.5.18) 的陷阱清单，再按症状回到对应小节；退出码问题看 [0.5.4](ch05.md#sec-0.5.4)、[0.5.11](ch05.md#sec-0.5.11)，缓冲问题看 [0.5.15](ch05.md#sec-0.5.15)。
- **要深入**：第二遍（0.5.8–0.5.15）配合 [0.5.16](ch05.md#sec-0.5.16) 的三个 `strace` 实验一起读；不要只背结论。
- **非科班补课**：这一章不需要你先懂内核的 `struct file`。先记住“fd 是进程内文件描述符表的下标，表项指向一次打开”，第二遍再展开。

## 路线标签与项目回链

- 应用/运维：**必读**（0.5.1–0.5.7、0.5.18；排障最常用）。
- 系统编程：**必读**（0.5.8–0.5.15；fd 与管道是系统编程基本功）。
- 内核/性能：**可后补**（0.5.11、0.5.16 提供 `SIGPIPE`/管道的证据）。
- 项目回链：项目 D1（`mysh`）的重定向与管道；A2（`myhttpd`）的日志包装；B1（`myredis`）的事件循环日志。
