# 0.6 闭卷回忆卡

这页不是摘要，而是一组**检索练习**。先只看问题，合上正文，开口说或落笔写；「看着熟」不算会。每张卡答完再展开核对。

建议在学完当天、隔天、第 3 天、第 7 天各做一次。每次只记三种结果：✓ 能完整写出；△ 有关键词但缺条件；× 完全想不起。下一轮只重做 △ 和 ×。

## A. 第一遍：先会用

### D1 · BRE、ERE、PCRE

BRE、ERE、PCRE 的元字符写法差在哪？各给一个 `+`、`{}`、`()` 的例子。

::: sol D1 核对

BRE：`+`、`{}`、`()` 默认是普通字符，要写成 `\+`、`\{m,n\}`、`\(...\)`；ERE 直接写 `+`、`{m,n}`、`(...)`；PCRE 在 ERE 基础上加 `\d`、`\w`、`\s`、环视、懒惰量词。`grep` 默认 BRE，`grep -E` 用 ERE，`grep -P` 用 PCRE（GNU）。不要把一个方言的写法直接塞进另一个方言。
:::

### D2 · 语法骨架

锚点、字符类、量词、分组、反向引用各是什么？`^`、`$`、`[^abc]`、`*`、`+`、`?`、`{2,4}`、`(...)`、`\1` 各做什么？

::: sol D2 核对

`^`/`$` 锚定行首/行尾；`[abc]` 匹配集合中任一字符，`[^abc]` 排除；`*` 0 次或多次，`+` 1 次或多次，`?` 0 或 1 次，`{2,4}` 2–4 次；`(...)` 分组并捕获，`\1` 反向引用第 1 个捕获组。贪婪量词默认尽量多匹配；PCRE 可用 `*?`/`+?` 懒惰。
:::

### D3 · grep

`grep` 的 `-E`/`-F`/`-P`/`-r`/`-n`/`-c`/`-v`/`-o`/`-q` 各做什么？退出码 0/1/2 分别表示什么？

::: sol D3 核对

`-E` ERE，`-F` 固定字符串（最快），`-P` PCRE（GNU），`-r` 递归，`-n` 行号，`-c` 计数，`-v` 反向匹配，`-o` 只输出匹配部分，`-q` 静默（只看退出码）。退出码：0 有匹配，1 无匹配，2 出错（文件不存在/正则错误）。脚本里不要把 1 当错误。
:::

### D4 · sed 执行模型

sed 的「模式空间 + 地址 + 命令」是什么？`-n`、`p`、`d`、`s///g`、`-i` 各做什么？

::: sol D4 核对

sed 逐行读入模式空间，按地址（行号/正则）选命令执行，默认输出模式空间。`-n` 关闭默认输出；`p` 打印；`d` 删除并开始下一轮；`s/old/new/g` 替换（`g` 全局）；`-i` 原地编辑（临时文件 + rename）。`sed -n '2,4p'` 只打印 2–4 行；`sed '/^#/d'` 删注释行。
:::

### D5 · hold space

hold space 是什么？`h/H/g/G/x` 各做什么？举一个「倒序输出」的思路。

::: sol D5 核对

hold space 是 sed 的第二个缓冲区，初始为空。`h` 用模式空间覆盖 hold；`H` 追加；`g` 用 hold 覆盖模式空间；`G` 追加；`x` 交换。倒序思路：`sed -n '1!G;h;$p'`——每行把 hold 追加到模式空间、再把模式空间存回 hold，最后打印，得到倒序。
:::

### D6 · awk 模型

awk 的记录、字段、`FS/OFS/RS/ORS`、`NR/FNR/NF`、`BEGIN/END` 各是什么？

::: sol D6 核对

每行是记录 `$0`；按 `FS` 切字段 `$1..$NF`；`OFS` 是输出字段分隔符；`RS`/`ORS` 是输入/输出记录分隔符；`NR` 是总记录号，`FNR` 是当前文件记录号，`NF` 是字段数。`BEGIN` 在读取前执行，`END` 在结束后执行；中间是 `pattern { action }`。`awk -F: '{print $1}' /etc/passwd` 取用户名。
:::

## B. 第二遍：看引擎与边界

### D7 · 三者怎么选

grep、sed、awk 各最适合什么任务？各给一个不该用它的例子。

::: sol D7 核对

grep 适合筛行/计数/找模式；sed 适合按行做替换/删除/插入/流编辑；awk 适合按字段做统计/报表/数组。反例：用 grep 做替换（应 sed）；用 sed 做列求和（应 awk）；用 awk 只筛行（grep 更直接）。选择标准是「数据形状」：行、流、字段。
:::

### D8 · 日志统计/批量改名

把「统计 access.log 里每个 IP 的 5xx 次数，按次数降序取前 10」拆成一条管道；批量改名要注意什么？

::: sol D8 核对

```bash
awk '$9 ~ /^5/ {c[$1]++} END {for (ip in c) print c[ip], ip}' access.log \
  | sort -rn | head -10
```

批量改名先 `-print`/`echo` 试运行；文件名可能带空格/换行，用 `-print0` + `read -d ''` 或 `xargs -0`；改名用 `mv -n` 防覆盖，先备份。不要用 `for f in $(ls)`，会按空白分词。
:::

### D9 · 正则引擎与回溯

为什么 `(a+)+b` 可能很慢？贪婪与懒惰量词差在哪？`grep -F` 为什么快？

::: sol D9 核对

回溯引擎在嵌套量词 + 失败匹配时会尝试大量组合，导致灾难性回溯；`(a+)+b` 在长串 `aaaa...` 上可能指数级。贪婪 `*`/`+` 尽量多匹配，懒惰 `*?`/`+?` 尽量少；引擎不同（DFA/回溯）行为不同。`grep -F` 用固定字符串匹配，不做正则回溯，通常最快；`LC_ALL=C` 也能减少 locale 开销。
:::

### D10 · 工具链

`sort`、`uniq`、`cut`、`tr`、`paste`、`join`、`diff` 各做什么？`uniq` 为什么通常要先 `sort`？

::: sol D10 核对

`sort` 排序（`-n` 数值、`-k` 键、`-u` 去重）；`uniq` 去重/计数（`-c`），只处理相邻重复行，所以先 `sort`；`cut` 取列（`-d` 分隔符、`-f` 字段）；`tr` 字符替换/删除/压缩；`paste` 按行合并文件；`join` 按共同键连接；`diff` 比较差异（`-u` 统一格式）。`sort | uniq -c` 是统计频次的标准组合。
:::

### D11 · locale 与匹配

`LC_ALL=C` 为什么通常更快？locale 会影响哪些行为？`[a-z]` 在 UTF-8 locale 下一定只匹配 26 个字母吗？

::: sol D11 核对

`LC_ALL=C` 用字节/ASCII 排序与字符类，通常比 UTF-8 locale 快，因为少了多字节处理与 collation。locale 影响排序、字符类、大小写、日期/数字格式。`[a-z]` 在 UTF-8 locale 下可能受 collation 影响，范围不一定是严格的 ASCII 26 个字母；需要严格字节范围时用 `LC_ALL=C`。
:::

### D12 · `sed -i` 与 awk 精度

`sed -i` 为什么改 inode、断硬链接？awk 的 `%d` 与 `%.2f` 各怎样舍入？金额为什么用整数分？

::: sol D12 核对

GNU sed `-i` 写临时文件再 rename，inode 变了，硬链接仍指向旧 inode；要保留 inode 用 `sed ... > tmp && cat tmp > file`。awk `%d` 向零截断（3.9→3，-3.9→-3），`%.2f` 按二进制浮点舍入，`1.005` 可能显示 `1.00`；金额用整数分避免浮点误差。`sed -n l` 可看 tab/行尾等不可见字符。
:::
