# 0.2 终端、Shell 与命令行工作流 · 本章导航

::: preview 这一章在讲什么
你每天打开的“终端窗口”并不是 Shell：它是一个终端模拟器，中间隔着内核的 pty 与行规程，Shell 只是跑在 pty slave 上的一个进程。这一章先把这条链路画清，再给你一套能持续用的工作台：历史、readline、作业控制、vim、tmux 和文档检索。学完你不仅知道“命令怎么敲”，还知道出问题时该重启窗口、改 `.bashrc`，还是去看程序日志。
:::

## 读完你会

- 画出「键盘 → 终端模拟器 → pty master → 行规程 → pty slave → Shell → 子进程」的链路，指出 `Ctrl-C`/`Ctrl-D` 是在哪一层被翻译的。
- 说出 bash 查找一条命令的五步顺序，解释 `alias` 为什么在脚本里不生效。
- 用登录/交互四象限解释 `ssh host cmd`、cron、`su -` 各读哪些启动文件。
- 用 `$PS1`、历史展开、`Ctrl-R`、readline 键位把日常编辑提速。
- 用 `jobs`/`fg`/`bg`/`disown`/`nohup`/tmux 管理前后台与断线恢复。
- 在服务器上安全地用 vim 改文件：模式、文本对象、宏、`:w !sudo tee %`。
- 用 tmux 脚本化一个可复现的布局，能 `send-keys`、`capture-pane`、`pipe-pane`。
- 按 `help → --help → man → info → /usr/share/doc` 的顺序查文档，不再一上来搜网页。

## 先修与预计学时

- 先修：读完 [0.1 Linux 世界观](ch01.md)；会用 `cd`、`ls`、`cat`、`grep`。**不需要**学过操作系统；tty/pty 的白话解释在本章开头。
- 阅读：约 90–120 分钟；键位与 tmux 练习：约 60 分钟；章末习题：约 45 分钟。

## 怎么读

- **第一次读**：按五个单元顺序读。每节先做「即时自测」，再去下一节；键位与 tmux 最好边读边开一个终端练。
- **只想提效**：先读 [0.2.5](ch02.md#sec-0.2.5)、[0.2.10](ch02.md#sec-0.2.10)、[0.2.11](ch02.md#sec-0.2.11)、[0.2.12](ch02.md#sec-0.2.12)；这四节对日常速度提升最大。
- **要排障**：先看 [0.2.14](ch02.md#sec-0.2.14) 的陷阱清单，再按症状回到 [0.2.1](ch02.md#sec-0.2.1)（终端链路）、[0.2.4](ch02.md#sec-0.2.4)（启动文件）、[0.2.9](ch02.md#sec-0.2.9)（行规程）。
- **非科班补课**：不需要先懂 `termios`。先记住“终端窗口是模拟器，pty 是内核里的一对虚拟设备，Shell 只是 pty slave 上的进程”；0.2.9 再展开 flag。
