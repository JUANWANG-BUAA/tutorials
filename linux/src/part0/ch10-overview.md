# 0.10 磁盘、文件系统、挂载与 LVM/RAID · 本章导航

::: preview 这一章在讲什么
`df` 说磁盘满了，`du` 却只算出几十 GB；`rm` 了 3 GB 日志，空间只降 200 MB；分区还有空间，却写不进去；扩容要不要停机？这一章先把块设备、文件系统、挂载看清，再学 LVM/RAID/swap/TRIM/配额与健康检查，最后回到分区表、`mkfs`、`fsck` 与块层证据。目标不是背命令，而是**每次动磁盘前都能说出设备名、挂载点、文件系统与回滚路径**。
:::

## 读完你会

- 用 `lsblk`/`findmnt`/`df` 画出「块设备 → 分区 → 文件系统 → 挂载点」。
- 解释 `df` 与 `du` 为什么对不上：块占用、稀疏文件、硬链接、deleted-but-open、保留块。
- 处理 inode 用尽、`/etc/fstab` 写错、挂载救援、只读根。
- 用 LVM 做在线扩容，用 `mdadm` 建/查 RAID，知道级别取舍。
- 管 swap、TRIM、磁盘配额与 SMART 健康。
- 读懂分区表/对齐、`mkfs`/挂载选项、`fsck`/超级块救援。
- 用 `strace`/`/proc`/`iostat`/`blktrace` 找块层证据，做两次回滚实验。
- 写磁盘巡检/扩容/健康检查脚本，默认 dry-run。

## 先修与预计学时

- 先修：读完 [0.9 进程、作业控制与信号](ch09.md)；会 `df`、`lsblk`、`mount`。**不需要**学过文件系统；块设备/inode/挂载的白话解释在本章开头。
- 阅读：约 120–150 分钟；实验：约 90 分钟（需要虚拟机 + 两块空盘）；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.10.1–0.10.8 按顺序；每节先做「即时自测」，再去下一节。涉及设备的命令先在虚拟机里跑。
- **只想排障**：0.10.1、0.10.3–0.10.5、0.10.15；先看 `df -hT`/`df -i`/`findmnt`/`lsblk`。
- **想扩容/做 RAID**：0.10.6–0.10.7、0.10.13；先在快照/空盘上练，确认回滚。
- **想读块层**：0.10.9–0.10.11、0.10.14；配合 `iostat`/`blktrace`/`/proc/diskstats`。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补 inode/挂载/块设备，再回到对应小节。

## 路线标签与项目回链

- 应用/运维：**必读**（整章；磁盘满、扩容、挂载、RAID 是高频）。
- 系统编程：**可后补**（0.10.1–0.10.5；文件系统/块层接口在需要时回看）。
- 内核/性能：**必读**（0.10.9–0.10.11、0.10.14；块层与 I/O 路径的前置）。
- 项目回链：项目 B2（`mydb`）的文件布局/`fsync`；C3（`mysniff`）的抓包落盘；A1（容器）的 overlay/卷。
