# 0.7 Bash 编程基础 · 本章导航

::: preview 这一章在讲什么
脚本不是把几条命令堆进文件。引号三态、展开顺序、退出码、`set -e` 的例外，决定了脚本在出错时是“安静地做错”还是“可靠地停下”。这一章分两遍走：第一遍先写能跑、能读、能退出的脚本；第二遍回到展开顺序、参数展开全表、三套条件与 `getopts`，把“为什么这样写”讲清。学完你能写带参数、日志、错误处理与 `--dry-run` 的脚本，而不是一堆只能在自己机器上跑的 alias。
:::

## 读完你会

- 写规范的脚本骨架：shebang、`set -euo pipefail`、`usage`、`main`、退出码。
- 分清变量、环境变量、只读变量、局部变量与作用域。
- 掌握引号三态（无引号、单引号、双引号）与分词、通配符、展开的关系。
- 用参数展开（`${var:-default}`、`${var#prefix}`、`${var%.suffix}` 等）做不调用外部命令的字符串处理。
- 用命令替换、算术展开、`test`/`[`/`[[` 写条件与分支。
- 写 `for`/`while`/`until`/`select`/`read` 循环，处理 `break`/`continue`/`return`。
- 用 `getopts`/`shift` 解析位置参数，用 `trap` 做清理与 `ERR` 处理。
- 解释 `set -e` 的例外、`pipefail`、`PIPESTATUS` 的价值，以及没有 `shellcheck` 时怎样手工体检一个脚本。

## 先修与预计学时

- 先修：读完 [0.5 重定向、管道与文本流](ch05.md)、[0.6 正则表达式与 grep/sed/awk](ch06.md)；会写简单命令。**不需要**学过编程语言理论；展开顺序的白话解释在 0.7.9。
- 阅读：约 120–150 分钟；实验与脚本：约 60 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：0.7.1–0.7.8 按顺序；每节先做「即时自测」，再去下一节。脚本要自己敲一遍。
- **只想写运维脚本**：0.7.1–0.7.8、0.7.13–0.7.14；先保证参数解析、错误处理、清理逻辑。
- **想读别人的脚本**：0.7.9–0.7.12；先看展开顺序与条件边界，再回看变量与循环。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补变量/引号/退出码，再回到对应小节。
