## 没达标怎么办

- **K 类卡住**：回到右列那一节的「小结」和「即时自测」，先只补一件事——把那个循环的 CPE 下界在纸上算一遍，再读改写手段。界算不出来时，改写手段就只是清单背诵。
- **S 类卡住**：在本机跑 C1、C2、C3（只需要 `cc`，macOS 与 Linux 都行），把真实输出贴进笔记；`perf` 与 `cachegrind` 跑不通不是你的代码问题，先看[勘误页](ch05-errata.md)的权限、事件名与安装情况，改在[Ubuntu 虚拟机](../env.md)里做。
- **A 类卡住**：做 B 组七题，强迫自己把答案写成「现象 → 五个候选里选一个 → 先测什么 → 怎么改 → 怎么验收」的链条；写不出「验收」那一环，就说明你还在猜。
- **只有 K1.5.12、K1.5.16 没达标**：这两行依赖工具（PMU 事件、Valgrind），可以带着「本机未实测」的标注先往前走，但别把正文里那两段示例输出当成自己的读数。
