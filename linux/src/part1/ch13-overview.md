# 1.13 操作系统导论 · 本章导航

::: preview 这一章在讲什么
前面六章把系统切成六个横截面：链接、进程、虚拟内存、I/O、网络、并发。这一章换一种切法——**虚拟化、并发、持久化**三件事，每件事都要回答「机制怎么做、策略选哪一个」。1.13.1–1.13.6 给地图与理论骨架，1.13.7–1.13.11 把骨架钉到结构体、位与日志协议上，并给出三个可跑的模拟器，1.13.12–1.13.16 用 50 章落点表、两个小内核、三个实验和十五条陷阱收口。它不教你新 API，它让你手里的 API 各就各位。

## 这一章回答什么

先记住三个词：**虚拟化**是「让每个进程以为自己独占一台机器」；**并发**是「多个执行流同时读写，还要保证正确」；**持久化**是「断电之后数据仍然在、而且自洽」。三件事各有自己的机制与策略：机制回答「怎么切换、怎么翻译、怎么原子、怎么落盘」，策略回答「切给谁、换哪一页、用哪个 I/O 顺序、什么时候回写」。

- **CPU 为什么够用**：程序数远多于核数，靠「受限直接执行 + 定时器中断 + 上下文保存」造出独占的幻觉。策略层是调度：周转时间与响应时间互相拉扯，FIFO 有护航效应，SJF/STCF 需要预知运行时间，RR/MLFQ 用时间片与优先级近似，彩票/步长/CFS 按权重分配。
- **内存为什么够用**：地址空间是假的，页表 + TLB + 缺页异常把虚拟地址翻译成物理地址；物理内存不够时把冷页换到 swap，换谁由页替换策略决定。分段、分页、交换是三步演进，外部碎片、页表开销、缺页代价是三次还债。
- **并发为什么难**：共享带来了吞吐，也带来了丢更新、顺序反转、死锁、活锁与饥饿。1.12 教你怎么写对，这一章补「为什么这样分类」：原子性违反、顺序违反、死锁、活锁、饥饿各有典型修法。
- **数据为什么丢不了**：持久化要同时回答「放在哪」和「崩了怎么办」。磁盘时间账（寻道 + 旋转 + 传输）、RAID 的容量与容错、文件系统的 inode 与位图，回答第一个问题；FSCK 与日志、`fsync` 与 `rename` 的边界，回答第二个问题。
- **模型与真实内核差多远**：OSTEP 是地图，Linux 是地形。CFS 在 6.6 之后换成 EEVDF，模型里的「固定时间片」「精确 LRU」在内核里都不存在；不知道差距，就会把教科书结论直接当排障依据。

这一章的定位是第 1 篇的收束：把 1.1–1.12 的六个切面折成一张「操作系统三件事」的总图，再交给第 2 篇的系统调用、第 3–5 篇的内核与云原生。

## 读完你会

- 在白纸上画出三大主题地图，每块写出机制与策略各两条，并指出缺页异常、page cache、自旋锁这三处跨越两块的地方。
- 对一组任务手算 FIFO、SJF、RR 的周转时间与响应时间（例如 A(0,10)、B(1,5)、C(2,2) 的平均周转分别是 13、12、11），说清哪个指标在什么负载下更重要。
- 写出 MLFQ 的五条规则，解释周期提升为什么不是可选项；说出 SQMS、MQMS、work stealing 各自的代价。
- 用 `segmentation → paging → swapping` 三段讲清内存虚拟化，说明分段的外部碎片、页表的空间开销、交换的 I/O 代价分别由什么机制偿还。
- 比较 OPT、LRU、FIFO、Clock，用「栈算法」解释 Belady 异常，并在模拟器里跑出 FIFO 从 3 个页框的 9 次缺页涨到 4 个页框的 10 次。
- 讲清磁盘一次随机 4 KiB 读为什么约 12 ms（约 83 IOPS），以及 RAID 0/1/5/6/10 的容量、容错与写代价。
- 画出 redo 日志的四个阶段，说出恢复的两条规则（有提交记录就重放、没有就丢弃），并指出 `fsync` 之后为什么还要 `fsync` 目录。
- 把 `task_struct` 的字段按生命周期分四组，说出 PTE 的 `P/RW/US/A/D` 各管什么，以及 aarch64 上这套位号为什么不成立。
- 说出李治军 8 个实践项目各自的关键结构与验收证据，指出 xv6 的 `proc.c`/`vm.c`/`log.c` 分别对应本章哪一节。
- 任给 OSTEP 一章，说出本书的落点与状态（已覆盖 / 合并 / 背景 / 淘汰）。

## 怎么读

- **第一次读**：按段走 1.13.1–1.13.5，再跳 1.13.9 与 1.13.10 的模拟器。1.13.1 与 1.13.7 是全章的两根梁：前者给地图，后者给「OSTEP 概念 → Linux 结构体」的对照。地图没画出来就读调度，最后只剩背名词。
- **正在排一个具体的故障**：先看[章末总结](ch13-summary.md)的「症状 → 机制 → 命令」表。CPU 分不匀看 1.13.2 与 1.13.9；内存越用越少、swap 在动看 1.13.3 与 1.13.10；文件名回退、断电后文件丢了看 1.13.11；容器里限额不生效看 1.13.15 与[勘误页](ch13-errata.md)的 cgroup 一节。

- **准备面试或课程考试**：1.13.2 的指标手算、1.13.10 的 Belady 异常、1.13.11 的两条恢复规则、1.13.8 的 PTE 位表是四处必答；把[习题集](ch13-exercises.md) A 组做完，再做 B 组。
- **怕数字搬家**：本章的模拟器输出只取决于代码，换机器不变；标「VM 实测」的读数来自本书虚拟机（见[勘误页](ch13-errata.md)）；`fio` 的随机/顺序倍数、RAID 重建时长、xv6/rCore 行数都按「形状示例」或「未实测」读。
