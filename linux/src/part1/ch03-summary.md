## 一条主线

这一章从“C 代码”走到“机器指令”：**先看寄存器/寻址/传送/条件码，再用 if/switch/循环/栈帧/数组结构体/objdump 读 C 的汇编，用 ARM64 对照；第二遍看机器码/参数/栈对齐/红区，用三个程序、两个实验、三架构×双语言验证，最后过 12 个陷阱。** 读汇编的固定问题：**数据在哪个寄存器/内存？控制流去哪？栈帧多大、谁保存？**

## 能否讲出这八句话

1. x86-64 参数用 `rdi/rsi/rdx/rcx/r8/r9`，返回 `rax`；`rbx/rbp/r12–r15` 是 callee-saved。
2. 寻址 `disp(base,index,scale)` = `disp + base + index*scale`；`lea` 算地址不访存。
3. `mov`/`add`/`sub`/`imul` 改 flags；`cmp`/`test` 只改 flags；`jcc` 按 ZF/SF/OF/CF 跳。
4. `if`/`switch`/循环都落成 `cmp/test` + `jcc`/跳转表。
5. `call` 压返回地址、跳目标；`ret` 弹返回地址；栈帧含保存的 rbp/局部变量/对齐。
6. 数组 `base + index*scale`；结构体按字段偏移/padding；联合体共享偏移。
7. ARM64 用 `x0–x7` 传参、`x0` 返回、`ldr/str`、`bl/ret`、NZCV。
8. 机器码变长（REX/ModRM/SIB/disp/imm）；ABI 规定参数/栈对齐/红区；读汇编先问数据/控制流/栈帧。
