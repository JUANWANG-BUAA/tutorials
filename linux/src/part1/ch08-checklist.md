# 1.8 学习目标自检表

这张表接管 [1.8.17 本章小结](ch08.md#sec-1.8.17)：左列是达标项，中列是「怎样算达标」，右列是正文依据与对应习题、回忆卡。正文那张七行表只给引子，逐项打勾看这一页。本章是两遍式，所以达标项也分层——**K 组考第一遍（会读会判），M 组考第二遍（会写会跑），S 组考取证，A 组考数字口径**。卡住时回到依据列重读那一段，不要从头再读整章。

**使用建议**：先做[习题集](ch08-exercises.md)的 A 组定位概念缺口，再用 B 组查「会不会落到证据」，最后跑 C 组。M 组的五行必须落笔写过程序并跑过一遍，口述不算达标。

## 没达标怎么办

- **K 组卡住（概念行）**：回到对应小节的「小结」与「即时自测」，先口头讲一句完整因果，例如「因为 exec 后旧 handler 的地址在新地址空间里没有意义，所以捕获的处置被重置」。这类问题不要靠多读几遍解决；讲不出因果就还没到线。
- **M 组卡住（动手行）**：只做三件事——把 [例 1.8-C1](ch08-exercises.md#ex-1.8-C1) 跑出 1792 与 15；把 [例 1.8-C2](ch08-exercises.md#ex-1.8-C2) 的僵尸数出来再清零；把 [例 1.8-C3](ch08-exercises.md#ex-1.8-C3) 的 2 秒差复现出来。三件事都过了，K5、K6、K8 自然就稳了。
- **S 组卡住（取证行）**：先确认环境边界，别在拿不到的东西上耗时间。macOS 没有 `strace` 与 `/proc`；Ubuntu 24.04 的默认加固会挡住 `dmesg`，也可能没有 `coredumpctl`。按 [例 1.8-C4](ch08-exercises.md#ex-1.8-C4) 的降级路径走 `journalctl -k` 与 `/proc`，并在结论里写明「未实测」。
- **B 组判断行卡住**：强迫自己写四段——「现象 → 机制 → 证据（命令与字段）→ 修法」。差得最远的通常是第三段：说不出看哪个字段，就等于没定位。
- **只有 A 组全对**：说明还停在第一遍。本章要求会写会跑，把 M 组与 S 组做完再来勾这一页。
