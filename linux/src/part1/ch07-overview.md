# 1.7 链接、加载与库 · 本章导航

::: preview 这一章在讲什么
你在 [1.1](ch01-overview.md) 里已经把 `hello.c` 走过一遍「预处理—编译—汇编—链接—加载」，知道可执行文件里有个 `puts@plt`，真正的 `puts` 在 `libc.so.6` 里。这一章不是重讲这个故事，而是把那条链摊开成规则和结构：链接器凭什么决定同名符号听谁的、指令里那四个零节填什么、`ld.so` 按什么顺序找库、GOT 表项在第一次调用时被改成什么。读完你应该能在遇到 `undefined reference`、`multiple definition`、`cannot open shared object file` 时不靠猜：先判断它发生在哪一层，再选那一条命令。
:::

## 读完你会

- 说出链接器四步（符号解析、合并节、重定位、布局）各自对应哪一类构建错误。
- 用 `readelf -S` 读节视图、用 `readelf -l` 读段视图，并解释 `.bss` 为什么不占文件空间。
- 判断两个同名符号谁赢，说明 GCC 10 起默认 `-fno-common` 把静默合并变成了链接错误。
- 讲清静态库为什么按命令行顺序扫描，什么时候必须用 `--start-group` 或 `--whole-archive`。
- 手算一次 PC 相对重定位，说清加数 `-4` 从哪里来——正文 1.7.4 算出的 `e8 eb fe ff ff` 要能自己推出来。
- 描述 `execve` 到 `_start` 之间内核与 `ld.so` 各做什么，`PT_INTERP` 归谁读。
- 画出 PLT 与 GOT 在首次调用和后续调用上的两条路径，说明 `-z now`、`-z relro` 各改了什么。
- 用 `LD_PRELOAD`、`-Wl,--wrap`、`dlopen` 三种手段替换或加载实现，并说出各自的边界。
- 不依赖 libelf 解析一个 ELF 的 ELF 头、节头与符号表，解释 `sh_link` 和 `st_shndx=65521` 这类字段。
- 在 Linux 免特权环境里复现并修好本章的五类典型错误。

## 先修与预计学时

- 先修：[1.1.13 静态链接、动态链接与 LD_PRELOAD](ch01.md#sec-1.1.13)、[1.1.18 重定位：链接器改的是哪几个字节](ch01.md#sec-1.1.18)、[1.1.19 动态链接的两次绑定](ch01.md#sec-1.1.19)（都在 [1.1 章总览](ch01-overview.md) 的路线里）。那三节已经把这条链走通一遍，本章是展开成可查的全规则，别当作第一次见面；如果你连「`.o` 里的 `call` 目标是 0」都没印象，先回 1.1.18。
- 另需：会用 `cc` 把两个 `.c` 编成一个程序；认识 `.o`、`.a`、`.so` 三种文件；知道虚拟地址与页对齐大概是怎么回事（[1.9.1 物理地址、虚拟地址与地址空间](ch09.md#sec-1.9.1) 扫一眼即可，不必先读完）。
- 阅读：约 150–180 分钟（17 节）；抄两个完整程序并跑通：约 90 分钟；章末习题：约 60 分钟。
- 环境：ELF、加载与打桩类实验要在 Linux 上做，[实验环境](../env.md) 里那台 Ubuntu 24.04 虚拟机工具齐全且不需要 root。macOS 侧是 Mach-O 加 llvm 工具链，没有 `readelf` 和 `ldd`，两套口径必须分开，见[勘误与版本注记](ch07-errata.md)第 1 节。

## 怎么读

- **第一次读**：按段顺序走 1.7.1–1.7.8，每节做完即时自测再往下。这一段的目标只有判读，不要求记住字段偏移和全部重定位类型。
- **手算这一处别跳过**：[1.7.4](ch07.md#sec-1.7.4) 的 `0x401141` 与 `A = -4`，在纸上重算一遍再往下走；1.7.11 的全部类型表都建立在这个直觉上。
- **正在排一个具体的构建错误**：先按[章末总结](ch07-summary.md)的「看到问题先选工具」定位层次，再跳到对应小节；`undefined reference` 与 `multiple definition` 都在第二遍那两节（1.7.3、1.7.10），运行期找不到库看 1.7.6。
- **要动手做实验**：[1.7.12](ch07.md#sec-1.7.12) 与 [1.7.13](ch07.md#sec-1.7.13) 的代码完整可编译，可以直接抄；做之前先读 [1.7.15](ch07.md#sec-1.7.15) 的实验顺序，免得对着空输出找 bug。
- **想理解自己写的库为什么被别人覆盖**：1.7.6、1.7.7、1.7.8、1.7.13 连着读，再看[习题集](ch07-exercises.md) B 组。
- **卡住时**：先回 [1.1.18](ch01.md#sec-1.1.18) 与 [1.1.19](ch01.md#sec-1.1.19) 确认你已经有的那部分，再回来；`execve` 与进程侧的接口留给 [1.8.3](ch08.md#sec-1.8.3) 和 [2.8.1](../part2/ch08.md#sec-2.8.1)。

## 路线标签与项目回链

- 应用/运维：**必读** [1.7.5](ch07.md#sec-1.7.5)、[1.7.6](ch07.md#sec-1.7.6)、[1.7.8](ch07.md#sec-1.7.8) 的取证顺序三节；其余可后补。「装好的程序一启动就报找不到 `.so`」几乎全在这三节里。

- 项目回链：D3 `mygit` 的前置章节就写着 1.7——读 `.o`、算偏移、按节找数据都用得上；A1 `mycontainer` 里「容器里报 `cannot open shared object file`」要靠 1.7.6 的搜索顺序定位；A2 `myhttpd`、C2 `myproxy` 打包部署时的 `rpath` 与 soname 属于 1.7.5–1.7.7；A3 `mybpf` 与 1.7.8 的打桩是同一目的的两种手段，边界见[习题集](ch07-exercises.md) A8。项目清单见[项目总览](../projects/overview.md)。
