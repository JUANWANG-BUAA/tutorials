## A. 第一遍：位与整数

### D1 · 位、字节、字与十六进制

位/字节/字/十六进制各是什么？LP64 与 ILP32 下 `long`/指针各几字节？

::: sol D1 核对

位（bit）0/1；字节（byte）8 位；字（word）是机器字长（指针宽度）；十六进制 4 位一组，方便看字节。LP64：`long`/指针 8 字节、`int` 4；ILP32：`long`/指针 4、`int` 4。用 `sizeof`/`getconf LONG_BIT` 确认。
:::

### D2 · 补码

补码怎样表示负数？`-x` 的位运算是什么？有符号范围为什么不对称？

::: sol D2 核对

补码：最高位权为 `-2^(w-1)`；`-x = ~x + 1`。w 位有符号范围 `[-2^(w-1), 2^(w-1)-1]`，负数比正数多一个（`INT_MIN` 没有正对应），所以 `-INT_MIN` 溢出。
:::

### D3 · 扩展、截断与转换

符号扩展与零扩展差在哪？截断会怎样？`int`→`unsigned` 的规则是什么？

::: sol D3 核对

符号扩展复制符号位（有符号→更宽），零扩展补 0（无符号）；截断保留低位、丢高位。`int`→`unsigned` 按模 `2^w` 重解释（负数变大正数）；`unsigned`→`int` 实现定义/回绕，避免依赖。混用会触发整数提升/转换，比较时特别危险。
:::

### D4 · 整数运算与溢出

有符号溢出与无符号溢出各是什么？移位有哪些 UB？`x & -x` 取出什么？

::: sol D4 核对

有符号溢出是 UB（编译器可假设不发生）；无符号按 `2^w` 回绕。移位：移位数负数/≥位宽是 UB；左移负数/溢出有符号是 UB；右移有符号是实现定义（算术/逻辑）。`x & -x` 取出最低位的 1（`x=0` 时为 0）。
:::

### D5 · 位运算与移位

`& | ^ ~` 各做什么？怎样用掩码取/置/清位？`>>` 对有符号数是什么？

::: sol D5 核对

`&` 与、`|` 或、`^` 异或、`~` 取反。取位 `x & mask`；置位 `x |= mask`；清位 `x &= ~mask`；翻转 `x ^= mask`。有符号右移通常算术（补符号位），但 C 标准是实现定义；要逻辑右移用无符号。
:::

## B. 第二遍：布局、浮点与语义

### D6 · 字节序、对齐与布局

小端/大端差在哪？为什么有 padding？`offsetof`/`sizeof` 各给什么？

::: sol D6 核对

小端低字节在低地址，大端高字节在低地址；网络字节序通常大端。对齐要求字段地址是 `alignof` 的倍数，编译器插 padding；`offsetof` 给字段偏移，`sizeof` 给总大小（含尾部 padding）。`repr(C)` 固定 C 布局；默认 Rust 布局可重排。
:::

### D7 · IEEE 754

float/double 的符号/指数/尾数各几位？偏置是多少？规格化/非规格化/NaN/Inf 怎样区分？

::: sol D7 核对

float：1/8/23，偏置 127；double：1/11/52，偏置 1023。指数全 0：非规格化（尾数无隐含 1）；指数全 1：尾数 0 是 Inf、非 0 是 NaN；其余规格化（隐含 1）。`-0.0` 符号位 1、指数/尾数 0。
:::

### D8 · 舍入、ULP 与比较

为什么 `0.1+0.2 != 0.3`？ULP 是什么？NaN 比较有什么特殊？

::: sol D8 核对

0.1/0.2/0.3 不能精确表示，加法舍入到最近可表示值，所以不等。ULP 是最小间距（随指数变化）；比较用容差/ULP，不用 `==`。NaN 与任何值（包括自己）比较都为假；`isnan` 判断；`-0.0 == 0.0` 为真但符号不同。
:::

### D9 · 手算

手算 `-5` 的 8 位补码、`0xF0` 的有符号值、`1<<31` 的结果、`INT_MAX+1` 的行为。

::: sol D9 核对

`-5`：5=`00000101`，取反 `11111010`，+1=`11111011`=0xFB。`0xF0` 有符号 8 位 = -16。`1<<31` 在 32 位 int 是 UB（有符号溢出）；用 `1u<<31`。`INT_MAX+1` 有符号 UB；无符号回绕。
:::

### D10 · 程序与实验

三个完整程序各验证什么？`gdb`/`objdump` 实验各看什么？

::: sol D10 核对

位操作工具箱（掩码/`x&-x`/popcount/swap）；浮点位模式分析器（符号/指数/尾数/ULP）；汇编字节序验证（内存字节）。UBSan 看溢出、`printf`/`offsetof`/DWARF 看转换与布局；`gdb` 在本机只到寄存器；`objdump`/`readelf` 看常量/浮点指令/布局。用证据验证，不靠猜。
:::

### D11 · 十二条陷阱

任选四个表示陷阱，说出“现象 → 原因 → 修复”。

::: sol D11 核对

示例：① 有符号溢出 UB——用无符号/检查；② `-1` 与 `UINT_MAX` 比较——统一类型；③ 移位 ≥ 位宽 UB——检查；④ `0.1+0.2` 不等——容差；⑤ NaN 比较——`isnan`；⑥ 结构体 padding——`offsetof`/`repr(C)`；⑦ 字节序——`htonl`/显式；⑧ `memcpy` 别名/对齐——`memcpy`/`alignas`。
:::

### D12 · C 与 Rust

C 的 UB/实现定义 vs Rust 的安全/checked 各是什么？FFI 为什么用 `repr(C)`？

::: sol D12 核对

C 有 UB（溢出/别名/越界）和实现定义（右移/`int` 宽度）；Rust 安全代码禁止 UB，`checked_*`/`wrapping_*`/`saturating_*` 明确语义。FFI 用 `repr(C)` 固定字段顺序/对齐，与 C 结构体一致；默认 Rust 布局可重排，不能跨 FFI。
:::
