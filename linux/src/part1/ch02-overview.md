# 1.2 信息的表示与运算 · 本章导航

::: preview 这一章在讲什么
`0xFFFFFFFF` 是 -1 还是 4294967295？为什么 `0.1 + 0.2 != 0.3`？`struct` 为什么有 padding？有符号溢出为什么是未定义行为？这一章用 CSAPP 第 2 章的路径，把位、字节、补码、整数运算、字节序、对齐、IEEE 754 逐层讲清；第二遍用三个完整程序、两个 `gdb`/`objdump` 实验、12 个陷阱与 C/Rust 对照验证。目标是**看到二进制/十六进制/浮点数字时，能说出它的表示、范围、边界与陷阱**。
:::

## 读完你会

- 读写位、字节、字、十六进制，知道字长与数据模型（LP64/ILP32）。
- 用补码表示有符号数，解释无符号/有符号转换、符号扩展、截断。
- 判断整数溢出、移位边界、`x & -x`、位运算技巧。
- 解释字节序、对齐、padding 与结构体布局，知道什么时候要 `repr(C)`。
- 读 IEEE 754 的符号/指数/尾数，解释非规格化、舍入、ULP、`0.1+0.2`。
- 手算进制/补码/移位/溢出，不依赖计算器。
- 用 `gdb` 看溢出/转换/布局，用 `objdump`/`readelf` 读常量/浮点指令。
- 对照 C 与 Rust 的表示语义，知道哪些是未定义行为。

## 先修与预计学时

- 先修：读完 [1.1 计算机系统漫游](ch01-overview.md)；会 C 的整数/浮点/结构体。**不需要**学过数字逻辑；补码/浮点的白话解释在本章开头。
- 阅读：约 120–150 分钟；实验与手算：约 90 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：1.2.1–1.2.9 按顺序；每节先做「即时自测」。手算题要动笔。
- **只想避开坑**：1.2.2–1.2.4、1.2.7–1.2.8、1.2.17；先看溢出/浮点/布局。
- **想读底层**：1.2.6、1.2.10–1.2.11、1.2.14–1.2.16；配合 `gdb`/`objdump`。
- **写 Rust/C 互操作**：1.2.18；先看 `repr(C)`/UB/对齐。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补二进制/补码/浮点，再回到对应小节。
