# 1.3 机器级程序：x86-64 汇编 · 本章导航

::: preview 这一章在讲什么
C 代码怎样变成寄存器、指令和栈帧？`call`/`ret` 到底做了什么？为什么 `-O0` 的汇编那么长？`if`/`switch`/循环在汇编里长什么样？数组/结构体的地址怎样算？这一章用 CSAPP 第 3 章的路径，从寄存器/寻址/传送/条件码走到控制流、栈帧、数据布局，再用 `objdump`/`gdb` 把机器码与源码对上；第二遍看机器码编码、参数/返回值规则、栈对齐/红区，并用 x86-64/ARM64/RISC-V × C/Rust 六种实现对照。目标是**看到汇编能说出“数据在哪、控制流去哪、栈帧多大”**。
:::

## 读完你会

- 说出 x86-64 的通用寄存器、调用约定与参数/返回值寄存器。
- 读操作数/寻址模式（`(%rdi)`、`8(%rsp)`、`(%rax,%rcx,4)`）。
- 读 `mov`/算术/逻辑/比较/跳转/`call`/`ret` 的语义。
- 把 `if`/`switch`/`while`/`for` 对应到条件码与跳转。
- 画出栈帧：返回地址、保存的寄存器、局部变量、对齐。
- 解释数组/结构体/联合体的地址计算与 padding。
- 用 `objdump -d`/`gdb` 逐条执行、看寄存器/栈/机器码。
- 对照 ARM64 的寄存器/调用/寻址，知道 ABI 差异。
- 读机器码编码、参数传递完整规则、红区/对齐。

## 先修与预计学时

- 先修：读完 [1.2 信息的表示与运算](ch02-overview.md)；会 C 的函数/指针/数组/结构体。**不需要**学过汇编；寄存器/栈帧的白话解释在本章开头。
- 阅读：约 120–150 分钟；实验与手写汇编：约 90 分钟；章末习题：约 60 分钟。

## 怎么读

- **第一次读**：1.3.1–1.3.9 按顺序；每节先做「即时自测」。`objdump`/`gdb` 要自己跑。
- **只想读汇编**：1.3.1–1.3.8；先建立寄存器/栈帧/控制流。
- **想写汇编/ABI**：1.3.10–1.3.17；先看参数/对齐/机器码。
- **想多架构**：1.3.9、1.3.15、1.3.18；对照 x86-64/ARM64/RISC-V。
- **卡住时**：先回[先修工具箱](../prerequisite.md)补 C/指针/栈，再回到对应小节。
