# 1.11 网络编程与协议基础 · 本章导航

::: preview 这一章在讲什么
两个进程隔着网络，凭什么能像读写文件一样交换字节？这一章把这个问题压成三件事：**连接凭什么唯一**（四元组，不是「一个 socket」）、**字节流在哪里断开**（TCP 不保留消息边界）、**连接什么时候算建立、什么时候算关闭**（三次握手、accept 队列、`TIME_WAIT`）。1.11.1–1.11.10 建立这三个模型，1.11.11–1.11.16 用四个程序和两个实验把它们跑出来，1.11.17–1.11.18 收口。
:::

## 这一章回答什么

三个词先记住：**socket** 是 fd 的一个特例，`read`/`write` 的返回值语义一条都不用改，变的是对端；**四元组**（源 IP:端口 + 目的 IP:端口 + 协议）唯一标识一条连接，监听 socket 只绑定本地一半；**MSS** 是一条 TCP 段能装的应用数据上限，以太网 MTU 1500 下 IPv4 是 1460、IPv6 是 1440。

- **连接凭什么唯一**：为什么 `accept` 要返回新 fd？为什么同一台机器能用 8080 同时服务上万条连接？监听 fd 与连接 fd 各自绑定了什么？
- **字节流在哪里断开**：`read` 为什么可能只拿到半条请求？长度前缀、分隔符、固定长度、关闭连接四种边界各适合什么？HTTP 的头与 body 又各用什么边界？
- **连接什么时候算建立、什么时候算关闭**：`listen` 的 backlog 限制的是哪个队列？`ss` 的 `Recv-Q`/`Send-Q` 在监听 socket 与连接 socket 上各是什么？`close` 之后对端为什么不一定立刻知道？
- **接口怎么选**：TCP 与 UDP 的边界差在哪？`SO_REUSEADDR`、`SO_REUSEPORT`、`SO_LINGER`、`TCP_NODELAY` 各改的是哪一段行为？fork、线程、epoll、io_uring 四种并发模型，瓶颈分别在哪？

## 读完你会

- 画出一次 HTTP 访问的封装与分用，标出每层首部、MTU 1500 与 MSS 1460/1440，并说清分片为什么会放大丢包代价。
- 解释四元组、监听 socket 与连接 socket 的区别，说清「对监听 fd 直接 `read`」为什么会失败。
- 用 `getaddrinfo` + `AF_UNSPEC` 写出协议无关的解析循环：客户端逐个候选 `connect`，服务器用 `AI_PASSIVE` + `node = NULL` 逐个 `bind`。
- 写出并跑通一个 fork 并发的 echo 服务器，处理 `EINTR`、`SIGCHLD` 回收、父子进程各自该关哪个 fd。
- 写出一个最小 HTTP 服务器与一个手写客户端，按 `\r\n\r\n` 切头、按 `Content-Length` 或 EOF 切 body。
- 解释 `listen` backlog、半连接队列/全连接队列、`ss` 的四个数字与 `TIME_WAIT`，并用 `SO_REUSEADDR` 修好「重启后 bind 失败」。
- 按可靠性、边界、延迟、首部开销在 TCP 与 UDP 之间给理由；说清 Nagle 与延迟 ACK 叠加出的 40 ms 停顿。
- 说清 epoll 边沿触发为什么必须配非阻塞 fd、为什么一次要读到 `EAGAIN`；知道写侧为什么要自己缓冲没发完的字节。
- 用 `ss`、`nstat`、`nc`、`curl`、`getent` 分层定位「连不上」「连上了没响应」「响应被截断」三类问题。

## 怎么读

- **第一次读**：按段走 1.11.1–1.11.7，每节做完「即时自测」再往下。1.11.3 与 1.11.6 是全章的脊梁：前者解释「连接是什么」，后者解释「字节从哪里断开」。这两节没读懂，后面的服务器只会变成抄代码。
- **正在排一个具体的故障**：先看[章末总结](ch11-summary.md)的「症状 → 机制 → 命令」表，再跳到对应小节。`bind: Address already in use` 看 1.11.9，`curl` 正常浏览器卡住看 1.11.10，连接慢而不是被拒看 1.11.3 与 1.11.16，IPv6 连不上看 1.11.8。
- **要动手**：1.11.4、1.11.5、1.11.12、1.11.13 的四个程序都能直接编译，建议按 echo → HTTP 服务器 → epoll echo → HTTP 客户端 的顺序跑；先跑通再看解释，否则分不清是代码问题还是协议理解问题。
- **准备做题或面试**：1.11.3 的四元组与 `TIME_WAIT`、1.11.6 的边界表、1.11.10 的 HTTP 四种边界、1.11.11 的 epoll 条件是四处必答；把[习题集](ch11-exercises.md) A 组做完，再做 B 组。
- **怕数字搬家**：本章的 `ss`/`nstat` 读数来自本书虚拟机（见[勘误与版本注记](ch11-errata.md)），1.11.15 的 `tcpdump` 输出与 1.11.16 的 500 连接 `strace` 统计是形状示例；哪些没测，统一记在勘误页的「本章未实测项」。
