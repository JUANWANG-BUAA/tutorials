# STYLE：行文禁忌清单

这份清单来自一次实测：ch11–ch13 三章里出现「不是……而是」48 处、「不是……，是」25 处、「正是」28 处、「这里」52 处。这些不是语法错误，是**腔调问题**——读起来像同一个人在同一个语气里连续说话，一段接一段地「揭示真相」，每一段都用同一个节拍收尾。

读者对此的形容是「AI 味」「短剧腔」。这份清单把那些具体句式固化下来，配合 `tools/check_style.py` 自动检查。

## 一、禁用/限用的句式

### 1. 「不是 A，而是 B」——每章限 4 处

这是最重的病灶。它的毛病不在意思，在**节奏**：它把句子强行切成两拍，一拍否定一拍肯定，读十遍就腻。

| 不要写 | 改成 |
|:--|:--|
| 这不是修辞，而是结构问题。 | 这是结构问题。前一句的比喻容易让人当修辞读。 |
| 问题不在 `c`，而在 `v`。 | 问题出在 `v` 那一头。 |
| 不是工人使用生产资料，而是生产资料使用工人。 | （原文引用，保留）工人不再使用生产资料；生产资料开始使用工人。 |

**保留的情形**：引文原文、原著自己就是这一句（如「不是工人使用生产资料，而是生产资料使用工人」）、以及确实需要并置两种读法的地方。

### 2. 「这正是……」——每章限 3 处

它几乎总是段落结尾的装饰性总结。删掉不影响信息。

| 不要写 | 改成 |
|:--|:--|
| 这正是「现代工具补原著做不到的功课」。 | 删掉整句，或：这件事原著做不到。（换成陈述，不加"正是"） |
| 这正是马克思在 597 页描述的结构。 | 597 页描述的是同一个结构。 |

### 3. 「值得注意的是」「更有意思的是」「耐人寻味的是」——禁用

这类插入语是空转。要么直接说事，要么删。

### 4. 「一句话：……」——每章限 2 处

用作小结时可以，但三章里出现 7 次就成了口头禅。

### 5. 「必须说清」「必须承认」「需要强调的是」——每章合计限 4 处

用多了像在自我辩护。真正需要交代边界时，直接陈述边界：「这个换算只能读作方向，不能读作数值。」

### 6. 「这里」「这一点」——每千字不超过 4 处

「这里有一个问题」「这一点很重要」——它们常是句子起手式的填充物，删掉后句子更紧。

### 7. 每段都以一个短句论断收尾——禁用

三章里大量段落是「……（论证）。**这就是 X。**」的结构。连续五段都这么收，读者会感到被反复拍肩膀。

改法：让段落停在事实或推导上，不追加论断句；论断只在真正需要落锤的地方出现，一章不超过三次。

## 二、更根本的问题：信息密度

AI 味的另一个来源不是句式，是**稀释**。同一件事说三遍、用比喻再说一遍、再总结一遍。判断标准：

> 删掉一句话，如果读者没少得到任何信息，这句话就不该存在。

具体的稀释手法：
- **预告 + 重述 + 总结**三段式（同一内容讲三次）
- 「换句话说」把刚说的话换个说法再说一遍
- 「这意味着」「也就是说」把推导结果口头重复一遍

## 三、该有的样子

对照《资本论》自己的写法（这是本书要模仿的文体基准）：

> 工人在生产劳动力日价值（如三先令）的工作日部分内，只是生产资本家已经支付的劳动力价值的等价物……因此，我把进行这种再生产的工作日部分称为必要劳动时间。

特征：
1. **句子长，从句多，信息密集**——不切成短促的排比。
2. **定义式陈述用「我把……称为……」**，不用「这就是……的本质」。
3. **不解释自己为什么重要**。说了就说了，读者自己判断。
4. **数字和条件从句承担论证**，不靠形容词加强（「极其」「完全」「彻底」）。

## 四、检查方式

```bash
python3 mlm/tools/check_style.py --book mlm/src/part2/ch13.md
```

脚本按每千字密度给出以下指标，超过阈值即报：

| 模式 | 阈值（每千字） | 说明 |
|:--|--:|:--|
| `不是……而是` / `不是……，是` | 0.3 | 对偶句 |
| `正是` | 0.3 | 口头禅 |
| `值得注意` / `更有意思` / `耐人寻味` | 0.1 | 禁用词 |
| `一句话` / `换句话说` | 0.15 | 重复表述 |
| `必须说清` / `必须承认` | 0.15 | 自我辩护 |
| `这里` / `这一点` | 0.5 | 填充 |

阈值是**每千字**，因为长章理应容纳更多内容，不能按绝对次数卡。
