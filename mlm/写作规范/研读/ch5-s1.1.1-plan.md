## 二、本节要回答的难点和与后文的分工

不能只重复「要从事实出发」「不要循环论证」。需要让读者亲手感到：**经济学已经把私有财产、工资—利润—地租、竞争写进公式，却仍未解释这些公式所依赖的关系如何产生、如何运动。**

本节难点四条：

1. **为何从私有财产出发仍未解释**  
   接受「私有财产存在」「工资与利润对立」是研究起点，不等于已经说明：劳动/资本/土地何以分离；为何「资本家的利益」能充当最终原因；竞争看起来像外部偶然，在多大程度上是必然过程的表现。难点在「把应当阐明的东西当做前提」。

2. **虚构原始状态问题**  
   用「远古某人勤、某人懒」或「一开始就有有产者与必须为其劳动的人」说明今天的分离，等于把待推论的关系假定为具有历史形式的事实。神学原罪类比说明的是**论证结构**的循环，不是宣布一切起源研究非法。史料可核查的起源研究仍可做；本节训练的是识别循环，不是禁史。

3. **竞争/垄断等运动联系**  
   把竞争与垄断、经营自由与同业公会、地产分割与大地产写成互斥、对立的学说，会把集中与垄断说成「额外干涉的偶然结果」。作者要求弄清：一种被当作正常起点的安排，如何在运行中产生改变它的结果。这是**解释任务**，不是本节已完成的通史证明。

4. **用自足教学题设训练「产量≠支配关系」**  
   两作坊同人数、同人均产量、不同出售决定权与所得用途决定权。数字只控制规模；已证的是「由产量不能唯一推出支配」；未证的是现实工厂都属于乙、或甲必然演变为乙。还必须能练「命名资本家获利愿望 ≠ 解释他何以有权组织他人劳动」。

**与后文分工**：1.1.1停在方法与提问链（前提/未解释/运动联系/拒绝虚构起源）；1.1.2才进入对象化何以成异己力量及「成正比」阅读边界；1.1.3双重生活资料；1.1.7才处理私有财产作为结果与相互作用。本节不抢讲异化四规定定义，不写私有财产起源史。

## 四、自足教学题设规范（虚构、非史实）

以下为**交给写手展开的虚构题设规范**，不是历史统计，也不是对现实工厂的因果识别。

### 基线：控制变量的两作坊

- 作坊甲、乙各10人；每人每月生产10件；月总产量均为100件。数字只固定规模，不代表任何历史调查。
- **必须相同（控制）**：人数、人均产量、总产量、产品种类、观察窗口（一个月）、必要生活资料的市场价格（若引入工资比较时）。
- **必须不同（待辨识）**：

| 条件 | 作坊甲 | 作坊乙 |
|:--|:--|:--|
| 产品出售决定 | 生产者共同决定 | 外部所有者决定 |
| 所得用途决定 | 生产者共同决定 | 所有者决定；生产者领约定工资 |
| （可选加强行）劳动条件取得 | 生产者共同支配工具与材料 | 工具与材料由所有者提供，无所有权则不能开工 |

- 固定甲乙劳动者初始「希望改善生活」的偏好相同，避免用「甲更勤奋/乙更懒」偷换支配差异。

### 必须能说明什么已证 / 未证

| 已证（逻辑不充分） | 未证（不得偷渡） |
|:--|:--|
| 由「产量=100件」不能唯一推出「生产者有处置权」 | 现实工厂都属于乙 |
| 同产量下，出售决定权与所得用途决定权可以系统不同 | 甲在历史上必然演变为乙，或乙必然演变为甲 |
| 「资本家希望获利」若不连结劳动条件支配与产品处置，不能解释为何按乙方式组织 | 开篇「贫困成反比」「垄断恢复」已由本表统计证实 |
| 若解释句删掉支配关系只留产量或愿望，则无法区分甲乙 | 本节已弄清货币制度与全部异化的本质联系 |

### 至少两项真正反例 + 删除检验

1. **反例A（产量改善且支配改善）**  
   若某题内产量上升，同时生产者共同决定出售与所得，且实际取得的生活资料不减少，则不能用「产量↑⇒工人必然更穷」解释该题。本节由此训练：开篇命题是待解释的关系概括，不是对本表的必然推论。

2. **反例B（有获利愿望无组织权）**  
   题内丙也「希望获利」，但无权决定工具材料由谁使用、无权出售产品、无权规定工资。则「因为想获利」不能解释为何生产按乙的方式运行；必须补「谁支配劳动条件与产品」。

3. **删除检验**  
   - 删除表中两行决定权，只留「各产100件」→无法回答生活能否改善、产品归谁。  
   - 删除「劳动条件由谁提供」，只留「所有者决定出售」→仍可讨论产品环节，但无法练U4「何以能组织他人劳动」的完整链；若写手要承载U4，不可删这一行或等价叙述。  
   - 删除「当前事实」记录，改成「远古已有有产者与无产者」的唯一前提→解释坍塌为U8所批循环；此时应能指出尚未展示分离如何形成与如何持续。

### 运动联系的微型追问（仍属虚构题设，非通史）

可在作坊题之外加**同一规则下的两期比较**（仍非史料）：乙式安排下，若干期后部分生产者因无法维持约定条件退出，工具与订单进一步集中到更少的决定者手中。题设只用于提问「若把集中说成与竞争无关的外来干涉，还缺什么说明」；**不得**写成已证明一切竞争必然垄断，不得附伪造的工业革命产量/工资序列。

## 五、五问及详答达标线

正文习题与解答须与最终题设逐项一致。每问给确定的已有结论，不能五问都以「需要更多资料」收尾；「还需资料」只能作为有范围结论之后的边界，不能代替结论。

1. **经济学从私有财产出发，为什么仍可能什么也没有解释？**  
   达标线：区分「承认事实作为起点」与「说明事实如何产生、规律如何从关系中出现」。点出把物质过程塞进抽象公式再当规律、以及把资本家利益当最终原因，都是把待阐明者当前提。确定结论：起点可以合法，解释尚未完成。

2. **两作坊产量同为100件，为什么仍不能判断生产者生活是否改善？**  
   达标线：列出至少出售决定权、所得用途/工资与价格、劳动条件由谁支配（及可选工时强度）。确定结论：同产量逻辑上推不出同支配；甲乙差异来自题内给定的决定权，不是来自产量数字本身。

3. **「因为资本家要获利」解释了什么、没解释什么？**  
   达标线：已解释——命名了受益者的愿望方向；未解释——他何以支配生产条件、生产者何以必须经他进入劳动、产品何以由其处置。对照反例B。确定结论：愿望≠组织权说明。

4. **把竞争与垄断写成互相排斥的「正常 vs 外来干涉」，会漏掉哪类问题？**  
   达标线：漏掉「被当作竞争的安排在运行中如何改变财产分布与劳动进入条件」。确定结论：作者在此提出的是必须追问运动联系，不是本节已证明某种唯一历史结局。若题内两期无集中，不能硬套「必然垄断」。

5. **「远古一开始就有有产者与必须为其劳动的人」这句话的论证毛病在哪里？怎样才算从当前事实出发？**  
   达标线：毛病是把应当推论的分离假定为已有历史形式的事实（原罪结构）。从当前事实出发=先确认现存工资/归属/竞争等关系，再分析其与劳动组织、产品、生活资料的连接；历史起源另用可核查材料。确定结论：该句未解释形成与持续；不是一切古史都无效。并写明一项会使循环指责不成立的材料方向（逐步可核查的取得史），但不伪造数据。
