## 一、卢森堡：《资本积累论》——资产已在，只需译回中文

### 1.1 你说对了，而且这份资产一直在库里

SOURCE-MAP §四把卢森堡列为 P0 缺口，说「`.work/lux2/acc.txt` 鉴定为**英文版**《资本积累论》
（Gutenberg #41405），只可对照、不可作引文源」。这个判断本身没错，但结论下早了：
**它不是「不可用」，而是「未译回中文」**。这本 17.8 万词的完整著作就在磁盘上，缺的只是中文本。

实检：

```
$ wc -c  .work/lux2/acc.txt
1117831
$ wc -w  .work/lux2/acc.txt
178063
$ grep -n "^_CHAPTER" .work/lux2/acc.txt | head
1051:_CHAPTER I_
1668:_CHAPTER II_
...
10775:_CHAPTER XX
```

（Gutenberg 版把各章标题排在文末的目录里，故行号跨度大。）

### 1.2 版本鉴定：确为 Luxemburg 原著，非他人代笔

```
$ grep -n "Author: Rosa Luxemburg" acc.txt
13:Author: Rosa Luxemburg
```

全书 20 章，可辨的论题包括：原始积累（primitive accumulation）与资本主义产生的
非暴力路径、帝国主义、殖民掠夺在积累中的地位、军国主义作为资本主义积累方式的
内生性。这一组问题正是你说的「政治经济问题分析」，也正是《资本积累论》的骨架。

**卢森堡的独特贡献（对照马克思《资本论》）**：马克思《资本论》第一卷从「原始积累」
起笔，论证资本主义的产生；卢森堡则论证**资本主义不能在纯粹的经济基础上自行产生**，
它必须通过摧毁非资本主义地区（殖民地、半殖民地）来强制作出原始积累。这是她对
政治经济学的原创性补充，也是马克思主义史上关于帝国主义与积累关系的经典论述。

### 1.3 但有两个不可回避的限制

**限制一：这是英译本，是 1916 年或 1920 年的英译，不是中文。**
CHAPTER-STANDARD §4 关于引文的规则在这里要区别对待：

- 若只做**内容引用**（「卢森堡在《资本积累论》中论证……」）并标英文版页码/章号，
  学术上可接受，但**必须注明是英译本**；
- 若要**直接引用中文译文**，必须先获得中文译本（或自行译出并标明译者）。
  本教程的引用规范（`bibliography.md`）要求中文正文引文与中文底本一致，
  因此**在拿到中文本前，3.8 一章的引文体例只能是「转述 + 标注英译本章节」**。

**限制二：原书没有印刷页码标记**（`grep -c "\[Pg" acc.txt` = 0）。
Gutenberg 版靠章节结构定位，所以引用只能标章号（如「第三章『非资本主义地区的破坏』」），
不能编造页码。

### 1.4 建议方案：不等补料，先做两件事

| 方案 | 内容 | 成本 | 效果 |
|:--|:--|:--|:--|
| A（推荐） | 标章号做**转述式引用**，明标英译本 | 立即可做 | 3.8 可立即动笔 |
| B | 从英文本自译所需段落，标「据英译本译」 | 中等 | 可引中文原句 |
| C | 用户开代理，从中文马克思主义文库下中文本 | 用户操作 | 最佳，但依赖用户 |

**建议 A+B 并行**：主体用 A（转述，标英译本章号），三到五处最关键的段落用 B
（自译，标「据英译本译，本书译」），并在 `bibliography.md` 中登记英文本版本信息。
这样 3.8 不必等补料即可开工。

### 1.5 3.8 章的定位需要改

现 SOURCE-MAP 3.8 写的是「卢森堡：群众罢工、自发与组织」，必读料指向
「群众罢党、组织问题、改良还是革命」——**这四本都是她的政论，不是《资本积累论》**。
按你的指正，3.8 的主体应当是《资本积累论》（政治经济学分析），政论作为补充/选读。
这需要改 SOURCE-MAP。

### 2.3 但库里有一件可用的东西：《共产主义ABC》

`txt/共产主义ABC (…).txt`（392 页 / 14 675 段 / 印刷页映射完整）是布哈林与普列奥布拉任斯基

```

  第一政书目： 亚·波格丹诺夫«经济学简明教程»… 尼·列宁«国家与革命»。
  弗·恩格斯«家庭、私有制和国家的起源»…
--- … pdf.202 printed.192

  苏维埃共和国的战争状态造成的。这种现象是由于…我们这里不是一般的无产阶级专政，
  而是军事无产阶级专政：共和国是一座武装起来的营垒。
```

**这是一个真实的补救通道**：1920 年列宁在世、著作刚出版两年时写的党纲读物，

### 3.3 三个必须交代的版本问题

**问题一：第六卷缺 1956-1957。** 目录实检 89 条，最早是 1958 年 1 月杭州会议。
**1956 年 4 月《论十大关系》正文、1957 年整风反右、1962 年整风三卷——全部不在库。**
《论十大关系》在第六卷只作为**他人讲话中的追述**出现：

```
$ python3 qp.py '论十大关系' 毛泽东选集第六卷 2
— pdf.96 printed.82 —
  一九五六年四月提出《论十大关系》，开始提出自己的建设路线，原则和苏联相同，
  但有我们的一套内容。《论十大关系》中，工业和农业，沿海和内地，中央和地方，
  国家、集体和个人，国防建设和经济建设，这五条是主要的。
```

这段话讲《论十大关系》**有五条主要关系**——但这是毛在别处追述时的概括，
不是《论十大关系》原文。**不能当作该文原文引用。**

**问题二：第六、七卷全是笔记体。** 目录条目形态：
「在杭州会议上的讲话」「插话」「批语」「谈话纪要」「提纲」「给某某的信」。
这意味着——

- 它们是**第一手记录稿**，史料价值极高；
- 但它们**不是论著**，没有经过论证结构的打磨；
- 引用时必须标明文体性质，否则读者会误以为是成文论述。

**问题三：1-4 合订本未建索引。** `txt/毛泽东选集1-4.txt`（9.5 MB，333 万字符）含
《矛盾论》《实践论》等，但不在 `pages.jsonl` 里，故 `qp.py` 检索不到。
不过**文本内嵌了印刷页码**，已定位：

```

实践论: 锚点@194309, 前邻页码=173
```

（均为「毛泽东选集」一至四卷的页码；与 1-5 合订本不是同一页码体系，**不可混用**。）
