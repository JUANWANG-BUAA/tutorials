# SOURCE-MAP：结构目标与章节—篇目映射总表

**地位**：本文是全书结构的**权威目标**。`src/SUMMARY.md` 在每篇落地重写时逐步向它对齐；两处不一致时，以重写进度为准、以本文为目标。

**为什么有这张表**：此前各章由 agent 自行判断"本章该读什么"，读什么全凭猜——这是内容被拆散、变甜品的直接原因之一。本表把"读什么"一次性定死，读手不许自选篇目；要改映射，先改本表并说明理由。

**讲解比目标**：精读章正文规模 ≈ 对应原著印刷页数 × 1800 字 × **0.3–0.5**。据此，资本论一卷第一篇第一章（印刷页 47–102，约 55 页）应得 3.0–5.0 万字——这正是现行 ch08 的 3.6 万字所在区间；全书对《资本论》的讲解比不得低于 0.25（现状 11%，不可接受）。

**检索命令**：见 `CHAPTER-STANDARD.md` §0。本表「语料」列写的是书名片段，直接作为 `qp.py` / `find.py` 的第二参数。
