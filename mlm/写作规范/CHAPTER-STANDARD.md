# 章节写作标准（全书通用）

这份标准是为了解决一个已量化的问题：**旧稿的每一节只有三段的容量**。

全书 383 节，节字符数中位数 813，79% 的节不足 1000 字；45 章里 **0 章达标**，算例表 0 个、练习 0 道、公式块只有 25 个。

症状是「每节随便讲讲就结束」。病根是写作单位选错了：旧稿把「介绍一个话题」当作一节，而教材的一节应当是「训练一项能力」。

**现状（2026-11-03）**：全书按原著结构制扩为 68 章目标（篇目映射见 `SOURCE-MAP.md`，那是"每章读什么"的权威来源，读手不得自选）；达标 3 章（ch08/09/10）。旧稿的另一半病根是**无源写作**——agent 不读原著、只凭记忆和旧稿覆写。本标准第 0 条和流水线分工就是为此立的。

## 0. 开工前必须通读原著

**不许先看旧稿，先读原著。** 顺序不能颠倒——先看旧稿，只会把旧稿的框架抄一遍。

每个子代理在动笔前必须完成一次有记录的研读：

1. 找出本章对应的原著篇目（马恩选集/文集、列宁选集、毛选、卢森堡、阿尔都塞等）。
2. 用检索工具定位原文，**通读整篇**，不是搜关键词看一句。
3. 交出一份阅读报告，包含：
   - 读了哪些篇目，各多少页/多少字符；
   - 本章可以依托的 8–15 段原文（每段：原文首句 + 印刷页码 + 用它讲什么）；
   - 原著里本章还没被用到的论证（这是补深度的主要来源）；
   - 原著中作者自己打的比方、举的算例、给的具体数字——这些优先写进正文。

**没有阅读报告，不许写正文。**

**报告入库**：研读报告写为 `mlm/写作规范/研读/chNN.md`，与正文**分开提交**——先落报告的 commit，再落正文的 commit。现有样例：`研读/ch08.md`、`ch09.md`、`ch10.md`。报告是下一任代理的既得材料，覆写者不得从零起步。

**流水线分工**（四个角色，防覆写自猜与偷懒）：

| 角色 | 数量 | 职责 | 禁止 |
|:--|:--|:--|:--|
| 读手 | 每章 1 | 按 SOURCE-MAP 通读必读篇目，产出研读报告入库 | 不写正文 |
| 架构手 | 主线代理 | 把报告拆成节组任务卡：每卡含节号、困惑、用哪几段摘录（带页码）、算例设计、锚点号 | 不替写手写正文 |

## 1. 一节必须回答的六件事

顺序不要调换：

1. **困惑**：先摆一个读者真会卡住的问题。不是「本节讲剩余价值率」，而是「同样 100 万资本，为什么纺纱厂和炼钢厂赚的钱不一样多？」
2. **材料**：原文、数据、图式。原文必须逐字引用，标印刷页码。
3. **推导**：一步一步推，中间不能跳。每一步说明「为什么可以走这一步」。
4. **算例**：一组具体数字，算到底，出表格。
5. **常见错**：读者最容易在哪一步想歪，想歪之后会得出什么错误结论。
6. **练习**：一道两三行能做完的小题，答案放 `::: sol` 盒。

前五步缺任何一步，这一节不算完成。第六步可隔节出现，但每章不少于 6 道。

## 2. 篇幅预算

| 章的类型 | 整章下限 | 单节下限 |
|:--|:--|:--|
| 精读章（资本论逐篇、原著精读型） | 30000 字 | 900 字 |
| 理论章（有公式/推导/图式） | 20000 字 | 900 字 |
| 历史与实践章（叙述+分析） | 15000 字 | 900 字 |
| 卷首/附录 | 不设下限 | 300 字 |

过渡节可以短，但必须标 `<!-- transition -->`，一章不超过 1 节。

篇幅的真正预算是**讲解比**：精读章按 SOURCE-MAP 的 0.3–0.5（原著印刷页 × 1800 字 × 比例）估算目标规模，上表只是绝对下限。逐篇精读时，正文规模不得低于该区间下限。

## 3. 算例的硬要求

- 必须有**具体数字**（不是字母），必须**算到底**（不是「可以算出」）。
- 至少一处用 Markdown 表格并排两种口径（如价值图式与生产价格图式）。
- 所有数字必须由脚本算出，脚本存 `.work/mlm-depth/verify_chNN.py`，输出与正文一致。**禁止手算。**
- 表格里要有单位和量纲；数字保留有效位要一致。

## 4. 引文的硬要求

- 只引能核对的原文。**禁止编造页码。**
- 核不到原文的，改成转述，不加引号、不标页码。
- 逐字引用；可用「……」省略中间，不许改词。
- 写完跑 `python3 .work/mlm-corpus/verify_cites.py`（v3，2026-11-04 起；旧版 verify_cites2.py 仍在但已废弃），未命中的逐条解释（篇名式引用 / OCR 偏移 / 语料未收）。

## 5. 禁止事项

- **禁止用「见第 X 章」把深度推走**。一章最多 2 处，且必须真的超出本章范围。
- **禁止用「本书的判断」代替推导**。一章不超过 2 处，只允许出现在真正的争议处。
- **禁止只列清单不解释**。五个特征、四种形式、三个层次——列完必须给一条把这些项串起来的机制。
- **禁止把原文当讲解**。引完原文必须拆解：它从哪一步推到哪一步，中间省略了什么。
- **禁止改动其他章的文件。**
- **禁止保留旧稿的节标题却只加几段话。** 要么重写，要么合并，要么删掉。

## 6. 技术约束（违反会导致构建失败）

- 锚点格式 `{#arg-mlm.17.3.1}`。**新增锚点不得与已有重名**；删除带锚点的内容时必须保留锚点或改掉全部 `[@锚点]` 引用，否则 `mathbook.py` 报「引用了不存在的锚点」。
- 动笔前先查引用：`grep -rn '@[a-z]*-mlm\.17\.' mlm/src --include=*.md`
- 盒子必须闭合：`::: arg 论证 17.3 · 标题 {#arg-mlm.17.3.1}` … `:::`。嵌套时先关内层。
- 公式里的 `<` `>` 写成 `\lt` `\gt`。
- `$$ … $$` 块前后空行。公式里不用中文标点。

## 7. 覆盖审计（信息量约束，2026-11-03 增补，与字数门并行）

字数门（§2）只防缩水，不保证讲全——一章灌水到 30000 字照样可以是甜品。真正的完成标准是：**原著的每个论证单元在本章都有落点**。2026-11-03 用户裁定：约束的根据是原文的信息量，不是字数。

**三态覆盖表**（写在研读报告末尾，随报告入库；正文 commit 前必须完成）：

对原著每一章（大篇可按原著章再拆）一行，标三态之一：

| 状态 | 含义 | 写法要求 |
|:--|:--|:--|
| 承载 | 本章呈现了该论证 | 落点写到节号；承载方式三选一：论证复述 / 数字复算 / 引文呈现 |
| 割舍 | 明确不承载 | 给一句理由（如「与卷一 ch7 重复，已在 2.6 证过」） |
| 缺 | 审读时未处置 | 验收时不允许存在 |

**门的阈值**（按原著印刷页加权）：
- 缺 = 0。
- 割舍 ≤ 30%；超过即判本章不达标，返回加厚，或提请 SOURCE-MAP 改映射/拆章。
- 原著每张算表：要么进正文并进验算脚本，要么列为割舍并给理由。

**讲解比复核（信号，不自动判死）**：承载页数 × 1800 × 0.3–0.5 应与本章字数同量级。明显偏低（如 300 页原著只写 3 万字，比 0.05）时，优先向 SOURCE-MAP 提请**拆章**而不是硬撑——宁可多一章，不要一章甜品；拆章仍走结构变更记录。
