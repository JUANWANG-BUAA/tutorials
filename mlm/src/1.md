## 7.1 一个先要澄清的问题：它是科学还是立场

先摆结论：**马克思主义同时是科学命题系统和政治立场，但它把这两者的关系本身当作一个理论问题来处理**。这不是骑墙，而是它区别于其他社会主义思潮的关键。

空想社会主义者也有立场——他们要消灭贫困——但他们给不出「为什么贫困必然被消灭」的机制。他们诉诸道德：这样做是正义的。傅立叶计算过，如果人人都做自己喜爱的工作，人类的生产能力可以提高到这样的程度，以至于贫困消失。这是一个关于**可能性**的论证，不是关于**必然性**的论证。它没有回答：既然这件事这么好，为什么统治阶级不干？他们有能力阻止，怎么办？

马克思的《资本论》第一卷序言说得很清楚，他要研究的是「资本主义生产方式以及和它相适应的生产关系和交换关系」的**运动规律**。这个提法有两层意思。第一，「规律」不是指宿命，而是指趋势：在给定的结构下，当事人各自追求自己的利益，会反复地产生某种整体后果，而这些后果又反过来改变当事人面对的条件。第二，「运动」意味着规律是有历史的：它在资本主义生产方式成立之前不存在，在这个生产方式消失之后也不再成立。

::: def 定义 0.1 · 运动规律 {#def-mlm.7.1.1}
一个**运动规律**是关于某个社会形态的、形如「若结构满足条件 C，则当事人行为的聚合后果倾向于 T」的命题。它有三个特征：

1. **结构性**：T 不是任何个人意图的结果，而是结构约束下行动聚合的产物；
2. **趋势性**：它给出的是方向与强度，不是精确数值；反作用因素可以延缓或暂时逆转它；
3. **历史性**：它的成立以该社会形态的存在为前提，不是普适的「人性规律」。
:::

这个定义把两种常见的误读同时排除了。一种把马克思主义读成「历史必然如此，我们等着就行」——这是把趋势读成了宿命；另一种读成「一切规律都是虚构，只有政治意志」——这是把历史性读成了任意性。第 7 章会专门处理这个问题。

## 7.2 三个来源与三个组成部分：一条链，不是三个抽屉

列宁在《马克思主义的三个来源和三个组成部分》里给出的经典表述是：马克思主义由德国古典哲学、英国古典政治经济学、法国和英国的空想社会主义三者的批判继承构成，相应地分为哲学、政治经济学、科学社会主义三个部分。

这个表述常被误读成三个并列的抽屉：哲学讲世界观，经济学讲剥削，社会主义讲理想。按抽屉理解，三部分之间没有推理关系，学生只能分别背诵。真正的结构是**一条链**：

<pre class="layout">
   德国古典哲学                 英国古典政治经济学             法国空想社会主义
   （黑格尔辩证法）              （斯密、李嘉图劳动价值论）      （圣西门、傅立叶、欧文）
        │                              │                            │
        │ 批判：辩证法合理内核          │ 批判：劳动价值论            │ 批判：只描述理想
        │ 剥离唯心主义外壳              │ 却不敢推出剩余价值          │ 不给实现机制
        ▼                              ▼                            ▼
   唯物辩证法 ────────► 政治经济学批判 ────────► 科学社会主义
   （怎样研究历史）        （资本主义怎样运动）      （为什么必然是它，而不只是它更好）
</pre>

这条链上每一步都是**被前一步逼出来的**。唯物辩证法要求从社会内部的矛盾解释社会变迁，于是必须研究社会最基本的实践——生产；研究生产就要研究生产的社會形式，于是进入政治经济学；政治经济学揭示了资本积累的内在矛盾，于是「这个社会为什么会灭亡」变成了一个可以用经济范畴回答的问题，而不是道德愿望。

这条链也解释了学习顺序。直接读《资本论》第一章的读者常常卡住，因为不知道为什么要从商品开始；直接读《共产党宣言》的读者会觉得很痛快但学不到方法，因为宣言是结论的浓缩，不是论证。本书按链的顺序组织：先方法，再经济学，再国家与革命，最后历史。

::: arg 论证 0.2 · 为什么必须从生产开始 {#arg-mlm.7.1.2}
**前提 1**：要解释一个社会的变迁，必须找到该社会内部可重复的、有结构的相互作用。（方法论要求，见第 4 章）

**前提 2**：在所有人类实践中，物质生产是唯一具有如下性质的活动：它必须持续进行，否则社会解体；它在进行中必然形成人与人之间的稳定关系；这些关系又反过来规定生产如何进行。

**前提 3**：其他实践（政治、法律、艺术、宗教）的持续性依赖于物质生产的持续性，反之不成立。

**结论**：解释社会变迁的理论必须以物质生产的组织方式为基础环节。

**可能的反驳**：宗教、政治也可以在长时间内稳定地塑造生产组织（例如禁欲伦理与资本主义兴起）。**回应**：这不构成反驳，而是要求把「基础」理解为**归根到底的决定**而非唯一原因；第 3 章会把这一限定写进定义。
:::

## 7.3 为什么今天还要读

有三种常见的「过时论」，值得逐一检查，因为它们各自的错误方式不同。

**第一种：工人阶级没有了。** 说这话的人通常指发达国家的传统产业工人比例下降。这是事实。但「工人阶级」在马克思的定义里不是「在工厂里干活的人」，而是「没有生产资料、因而必须出卖劳动力才能生活的人」。按这个定义，一个在写字楼里写代码、按月领薪、不拥有公司股份的雇员，与一个在纺织厂看机器的工人，在**生产关系中的位置**上是同一类。第 44 章会给出当代阶级分析的完整操作方案，包括如何用职业、雇佣关系、管理权限、资产持有四个维度做交叉分类，而不是靠「蓝领/白领」的外观。

**第二种：计划经济失败了，所以理论错了。** 这里有一个逻辑跳跃。理论预言的是「资本主义的内在矛盾会导致危机与制度变迁」，并给出一个关于替代方案的**原则性**描述（生产资料公有、按劳分配、计划调节）。它没有给出替代方案的详细工程图纸。「某种具体制度设计失败」与「资本主义的根本矛盾不存在」是两个不同的命题。更诚实的问法是：那次失败的原因，在多大程度上来自理论本身的缺陷，在多大程度上来自具体的制度设计、国际环境与信息条件？第 43 章会把这个问题拆成可讨论的几层。

**第三种：他的经验材料过时了。** 这一点部分成立。马克思写作时，英国是资本主义的典型，世界市场尚未形成今天的金融化格局，信用制度远没有今天复杂。但《资本论》第三卷对信用与虚拟资本的讨论，在 2008 年之后被大量重读，原因不是它预言了次贷危机，而是它给出了一个理解「金融资产的价格如何脱离 underlying 生产」的框架。第 18 章会展示这个框架的当代用法，也会指出它的限度。

::: intuition 一个类比：解剖学与病理学
把《资本论》想成解剖学：它画的是这个社会正常运转时的结构图。危机理论则是病理学：它说明这个结构在什么条件下会失灵。学解剖学不会让你预言某个人什么时候生病，但不学解剖学，你连病理报告都读不懂。很多「马克思主义过时了」的论断，其实是拿一份十九世纪的病理报告去对照二十一世纪的病人，然后宣布解剖学无效。
:::

## 7.4 本书的写法：把结论还原成论证

本书有一个刻意的选择：**尽量不写「某某指出」然后接一句结论**。每个重要结论都要经过三步：

1. **提出**：这个结论要解决什么问题？在它之前，人们怎么回答？
2. **论证**：它的前提是什么？从前提推到结论用了几步？哪一步最可疑？
3. **限定**：它在什么范围内成立？哪些反例可以修正它？

这个写法有一个副作用：读起来比语录体慢。但它是唯一能让读者在合上书之后**自己用**的写法。第 45 章会把这套流程变成一份可操作的写作模板。

::: errata 三个常见的入门误读
**误读一：「马克思主义是经济决定论」。** 经济因素归根到底起决定作用，不等于每个具体事件都由经济因素直接决定。恩格斯在 1890 年致布洛赫的信里明确说过，如果有人认为经济状况是唯一决定性的因素，那他就是把这个命题变成「毫无内容的、抽象的、荒诞无稽的空话」。

**误读二：「阶级是一个道德范畴」。** 在马克思的用法里，阶级首先是生产关系中的位置，其次才是意识与组织。有位置无意识是常态（「自在的阶级」），有意识无位置是例外。

**误读三：「辩证法就是正反合三段式」。** 黑格尔的三段式是唯心主义的外壳。马克思在《资本论》第二版跋里说自己「卖弄」了黑格尔的表述方式，但同时明确说自己是唯物主义者。把辩证法还原成「正—反—合」的公式，恰恰丢掉了它最核心的东西：矛盾的特殊性。
:::

## 7.5 本章要点

<div class="keypoints">
<span class="kp-title">本章要点</span>
<ol>
<li>马克思主义主张自己是一门科学，指的是它给出的是关于社会运动的结构性、趋势性、历史性命题，而不是道德命令。</li>
<li>三个组成部分不是三个抽屉，而是一条链：方法要求研究生产，生产研究逼出经济学，经济学论证了社会主义的历史必然性。</li>
<li>这条链决定了学习顺序：先方法，再经济学，再国家与革命，最后历史经验。</li>
<li>「工人阶级消失」「计划经济失败」「经验材料过时」三种过时论，各自混淆了不同层次的命题，需要分别拆解而非一并接受或一并拒绝。</li>
<li>本书的写法是把每个结论还原成「问题—论证—限定」三步，目的是让读者能自己用，而不是能复述。</li>
</ol>
