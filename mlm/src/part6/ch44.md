## 44.1 一个先要澄清的问题

「工人阶级消失了」——这话在 20 世纪后期很流行。

依据是：发达国家的制造业工人比例下降了，写字楼里的人比车间里的人多。

这个依据是真的，结论却是假的。因为它把两件事混成了一件：

- **职业结构的变化**：确实，制造业工人比例下降了；
- **阶级结构的变化**：工人阶级（没有生产资料、必须出卖劳动力的人）的比例，没有下降。

按马克思的定义，阶级不是由「干什么活」决定的，而是由**在生产关系中的位置**决定的（第 2 章）。一个在写字楼写代码的雇员，与一个在纺织厂看机器的工人，在「是否占有生产资料」「是否必须出卖劳动力」这两个关键点上是同一类。

::: def 定义 44.1 · 当代阶级分析的四个维度 {#def-mlm.44.1.1}
判断一个人的阶级位置，需要看四个维度（生产关系的定义见 [@def-mlm.2.1.2]）：

1. **雇佣关系**：是雇主（占有他人劳动）、自雇（自己劳动）、还是雇员（出卖劳动力）？
2. **管理权限**：是否对他人有支配权（招聘、解雇、考核）？权限多大？
3. **资产持有**：是否持有生产资料（企业股权、生产设备、土地）？是否持有金融资产（股票、债券、房产）？
4. **职业与技能**：从事什么职业？技能是否可替代？

四个维度交叉，可以区分出不同的阶级位置，而不是简单的「蓝领/白领」。
:::

## 44.2 四个维度的交叉

用四个维度交叉，可以得到一个粗略的分类表。

| 雇佣关系 | 管理权限 | 资产持有 | 阶级位置 |
|:--|:--|:--|:--|
| 雇主（大） | 高 | 大量生产资料 | 资本家 |
| 雇主（小） | 中 | 少量生产资料 | 小业主 |
| 自雇 | 无 | 自己劳动的工具 | 个体劳动者 |
| 雇员 | 高（高管） | 大量金融资产 | 高级经理（介于资本家与雇员之间） |
| 雇员 | 中（中层） | 少量金融资产 | 中间阶层 |
| 雇员 | 无 | 无 | 工人阶级 |

这个表的用处是：它把「中产阶级」拆开了。

- **高级经理**：他们不占有生产资料，但掌握管理权，收入高，持有大量金融资产。他们的位置接近资本家（「代理人」），但不是资本家。
- **中层管理者**：他们有一定的管理权，收入中等，持有少量金融资产。他们是「中间阶层」，在危机中容易向下流动。
- **普通白领**：他们没有管理权，不占有生产资料，靠工资生活。他们的阶级位置与蓝领工人相同，只是职业不同。

::: arg 论证 44.1 · 「中产阶级」是一个意识形态概念 {#arg-mlm.44.2.1}
**「中产阶级」话语的功能**：
- 它把社会分成「上层/中层/下层」，而不是「资产阶级/无产阶级」；
- 它暗示「大多数人是中层」，从而淡化阶级对立；
- 它把「向上流动」作为目标，而不是「改变结构」。

**为什么它在统计上站不住**：
- 前提 1：「中产阶级」通常按收入或职业定义（如年收入 10—50 万、白领职业）。
- 前提 2：按这个定义，「中产阶级」内部差异极大：一个年收入 15 万的普通白领，与一个年收入 45 万的企业中层，在阶级位置上完全不同。
- 结论：「中产阶级」是一个统计上的「中间收入群体」，不是一个阶级。

**本书的判断**：「中产阶级」话语有意识形态功能，但它也反映了一个真实的现象：**中间阶层的扩大**。这个扩大是真实的（管理、专业、服务岗位增加），但它的后果不是「阶级消失」，而是「阶级结构的复杂化」：中间阶层在繁荣时向上流动，在危机时向下流动，他们的政治态度是摇摆的。
:::

## 44.3 数据从哪里来

做阶级分析需要数据。可用的数据来源包括：

**来源一：收入与财富数据。** 国家统计局的家庭调查、税务数据、财富报告（如瑞士信贷的全球财富报告）。这些数据可以看收入份额、财富集中度。

**来源二：职业数据。** 人口普查的职业分类、劳动力调查。这些数据可以看职业结构的变化。

**来源三：企业数据。** 上市公司的股权结构、高管薪酬、员工人数。这些数据可以看资本集中度、高管与普通员工的收入差距。

**来源四：微观调查。** 学术机构的住户调查（如中国家庭追踪调查 CFPS）、访谈。

::: method 方法 44.1 · 一次小规模的阶级分析 {#method-mlm.44.3.1}
**步骤一：确定分析对象。** 例如「某城市的互联网从业者」。

**步骤二：按四个维度收集数据。**
- 雇佣关系：雇主/自雇/雇员的比例；
- 管理权限：是否有下属、是否有考核权；
- 资产持有：是否持有公司股权、房产、股票；
- 职业与技能：岗位类型、技能可替代性。

**步骤三：分类。** 按上面的表格，把样本分到不同的阶级位置。

**步骤四：分析趋势。** 与五年前、十年前比较：哪个阶级位置在扩大？哪个在缩小？收入差距如何变化？

**步骤五：检验假设。** 例如「平台化是否使更多雇员变成准自雇？」——用数据检验。

**注意**：这个分析是描述性的，不是规范性的。它告诉你「结构是什么」，不告诉你「应该怎么办」。
:::

## 44.4 一个当代的争论：程序员是工人阶级吗

这个问题看起来琐碎，但它涉及阶级分析的核心。

**「是」的论证**：
- 程序员不占有生产资料（代码、服务器归公司所有）；
- 程序员必须出卖劳动力（工资）；
- 程序员受管理（KPI、考核、加班）。

**「不是」的论证**：
- 程序员的技能稀缺，议价能力强；
- 程序员的收入高，持有股票期权；
- 程序员有「专业自主性」（可以选择技术方案）。

::: debate 论战 44.1 · 高技能劳动者是不是工人阶级 {#debate-mlm.44.4.1}
**传统定义**：只要不占有生产资料、靠工资生活，就是工人阶级。按这个定义，程序员是工人阶级。

**修正定义**：要考虑「技能垄断」与「议价能力」。高技能劳动者可以通过技能垄断获得较高工资，他们的利益与资本家更接近（都希望企业盈利）。

**本书的判断**：传统定义在理论上更严格，但它忽略了一个事实：**高技能劳动者的「技能」本身是一种资产**（人力资本）。这种资产不能继承、不能出售，但它可以带来租金（高工资）。

更准确的说法是：程序员是工人阶级，但他们是工人阶级中的**上层**（「工人贵族」的当代形态，第 29 章）。他们的利益是分裂的：作为劳动者，他们受剥削；作为技能持有者，他们从企业盈利中获益（股票期权）。

**这个分裂的政治后果**：高技能劳动者在劳资冲突中往往摇摆：他们可能支持工会（保护劳动条件），也可能反对（担心影响企业竞争力）。这不是「阶级觉悟低」，而是他们的位置本身是矛盾的。
:::

## 44.5 阶级分析的政治用途

阶级分析不是学术游戏，它有政治用途。

**用途一：识别支持者与反对者。** 革命时代，阶级分析用来确定「谁是敌人，谁是朋友」（第 33 章）。当代，阶级分析用来确定「谁支持改革，谁反对改革」。

**用途二：解释政治态度。** 为什么某些群体支持民族主义，某些群体支持全球化？阶级位置可以提供一个解释（但不是唯一解释）。

**用途三：设计政策。** 如果政策的目标是「共同富裕」，那么需要知道「谁在底层」「谁在中间」「谁在顶层」，以及政策如何影响不同阶层。

::: errata 关于阶级分析的三个误读
**误读一：「阶级分析就是划分敌人」。** 阶级分析是描述社会结构，不是给人贴政治标签。把阶级分析等同于「划成分」，是文革的教训（第 39 章）。

**误读二：「阶级分析已经过时」。** 阶级结构变了，但阶级分析的方法（看生产关系中的位置）仍然有效。过时的是「两个阶级对立」的简单模型，不是阶级分析本身。

**误读三：「阶级分析可以解释一切」。** 阶级是重要的，但不是唯一的。性别、民族、地域、代际，都是独立的社会结构。把它们全部还原为阶级，是「阶级还原论」，同样是一种简化。
:::
