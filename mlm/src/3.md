# 3 社会形态的告终

关系变成桎梏，社会革命的时代到来了，一种社会形态却还不灭亡。它所能够容纳的全部生产力没有发挥出来，它就决不灭亡。新的、更高的生产关系也不会抢先出现。新关系的物质存在条件先在旧社会的胎胞里成熟，成熟以前没有它的位置。

人类因此只提出自己能够解决的任务。解决任务的物质条件已经存在，或者至少正在生成，任务才产生。人们在法律和哲学里提出克服冲突的办法，也要等到这个时候。

大体说来，亚细亚的、古希腊罗马的、封建的和现代资产阶级的生产方式，可以看做经济的社会形态演进的几个时代。演进到资产阶级的生产关系，社会生产过程的对抗形式到了最后一个。这里的对抗，不是个人跟个人结下的私怨，而是从个人的社会生活条件中生长出来的对抗。

资产阶级社会的胎胞里，生产力还在发展，同时又创造着解决这种对抗的物质条件。对抗的形式到这里是最后一个，解决它的条件又长在这个社会自己里面，所以人类社会的史前时期就以这种社会形态告终。

> 无论哪一个社会形态，在它所能容纳的全部生产力发挥出来以前，是决不会灭亡的；而新的更高的生产关系，在它的物质存在条件在旧社会的胎胞里成熟以前，是决不会出现的。所以人类始终只提出自己能够解决的任务，因为只要仔细考察就可以发现，任务本身，只有在解决它的物质条件已经存在或者至少是在生成过程中的时候，才会产生。大体说来，亚细亚的、古希腊罗马的、封建的和现代资产阶级的生产方式可以看做是经济的社会形态演进的几个时代。资产阶级的生产关系是社会生产过程的最后一个对抗形式，这里所说的对抗，不是指个人的对抗，而是指从个人的社会生活条件中生长出来的对抗；但是，在资产阶级社会的胎胞里发展的生产力，同时又创造着解决这种对抗的物质条件。因此，人类社会的史前时期就以这种社会形态而告终。

（《马克思恩格斯选集》第2卷，第3页）
