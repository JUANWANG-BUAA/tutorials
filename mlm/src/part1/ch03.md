## 3.1 原文只有一句话，后世加了很多

「经济基础决定上层建筑」，这句话人人都能背。可马克思写它的时候，只用了一个比喻，写完就走了，去分析商品了。

他没有给「上层建筑」开清单，也没有说明「决定」是哪种决定。后世的全部争论——上层建筑包括什么、它能不能反过来决定基础、这个比喻还成不成立——都是在补这个省略。

补得好，理论就往前走一步；补得糟，就补成了经济决定论。

这个比喻的原始出处仍然是《〈政治经济学批判〉序言》：

> 这些生产关系的总和构成社会的经济结构，即有法律的和政治的上层建筑竖立其上并有一定的社会意识形式与之相适应的现实基础。
> ——《马克思恩格斯选集》第 2 卷，第 2 页

马克思用了一个建筑比喻（untersuchen 之上的 aufbau），然后就走了，去分析商品了。他没有为这个比喻写过一篇专门的说明，也没有给出「上层建筑」的清单。后世关于上层建筑的全部争论——包括「有没有上层建筑」「上层建筑包括什么」「它能不能决定基础」——都是在补救这个省略。

这一点很重要，因为它意味着：**不要把「经济基础决定上层建筑」当成马克思的一句现成结论来背，它是一个未完成的、需要被理论化的提纲**。谁把它讲得越具体，谁就越是在做理论工作而不是在复述。

::: def 定义 3.1 · 上层建筑 {#def-mlm.3.1.1}
**上层建筑**指建立在经济结构之上、并服务于经济结构再生产的制度化形式与观念形式的总和。它包括：

1. **政治法律层**：国家机器（军队、警察、法院、监狱、官僚机构）、法律体系、政党与政治组织；
2. **意识形态层**：宗教、教育、家庭、媒体、文化机构，以及在这些机构中被生产与传播的观念；
3. **社会意识形式**：哲学、艺术、道德、科学（科学的位置有争议，见 3.4 节）。

注意，这个清单本身是有争议的。马克思本人没有给过清单；列宁在《国家与革命》里主要讨论政治法律层；葛兰西加了「市民社会」；阿尔都塞把教育、教会、家庭、媒体单列为「意识形态国家机器」。清单的差异不是术语游戏，它反映了对「什么在维持这个社会」的不同判断。
:::

## 3.2 「决定」的三种强度

「决定」是全书最含混的词之一。它在不同文本里有三种强度，混用会导致完全不同的结论。

**强度一：因果决定（强）。** 经济结构的每一个变化，都在上层建筑中产生对应的、可预测的变化。这个读法会让历史变得机械：只要知道经济结构，就能算出法律条文。它显然是假的，恩格斯自己也反对。

**强度二：功能决定（中）。** 上层建筑的形式必须满足经济结构再生产的需要，否则它会被淘汰。这个读法不预测具体形式，只预测**哪些形式能存活**。它比较有解释力：为什么所有阶级社会都有某种形式的财产法、税收、常备军？因为不这样，剥削关系就无法稳定维持。

**强度三：约束决定（弱）。** 经济结构规定了上层建筑变动的**可行集**：哪些变化是可能的，哪些是不可能的。这个读法最弱，但也最稳妥。

::: arg 论证 3.1 · 为什么「功能决定」是最有用的读法 {#arg-mlm.3.2.1}
**前提 1**：一个社会形态要持续存在，其生产关系必须被不断再生产出来（生产资料要更新、劳动者要成长、服从关系要维持）。

**前提 2**：生产关系的再生产不能只靠暴力，因为暴力的成本太高且不稳定；它必须同时依靠习惯、法律、教育等机制。

**前提 3**：这些机制的具体形式可以多样（英国用习惯法加议会，法国用成文法加官僚制，美国用宪法加联邦制），但它们必须能完成再生产的功能。

**结论**：说「上层建筑由经济基础决定」，其可操作的内容是：**上层建筑必须满足再生产的功能要求；不满足的形式会在危机中被替换**。至于替换成哪一种，由历史条件、阶级斗争、偶然事件决定。

**这个论证的解释力边界**：它不能解释上层建筑的**细节**。为什么英国的议会是两院制而不是一院制？功能分析给不出答案，只有历史叙述能。
:::

## 3.3 相对独立性：四个可以观察的机制

上层建筑不只是被动反映经济。它有相对独立性，这不是一句补充，而是可以被观察的。

**机制一：路径依赖。** 制度一旦建立，就会产生自我维持的惯性。英国的法律体系保留了大量的封建形式（王权、贵族院、普通法），尽管英国早已是资本主义国家。这些形式不是资本主义经济的「必然反映」，而是历史遗留；它们与经济基础并存，有时还会拖累经济（例如贵族院对某些立法的阻挠）。

**机制二：内部逻辑。** 法律有自己的体系性要求：一旦承认「合同自由」，就必须处理违约、代理、善意第三人等一系列问题，这些问题由法学家在体系内部推演，不是每一条都由经济需求直接决定。哲学、艺术、科学也是这样，它们有各自的问题史。

**机制三：利益的独立化。** 上层建筑的从业者（官员、法官、教师、教士、知识分子）有自己的利益。他们不一定按照统治阶级的意愿行事，有时会形成独立的集团（例如法国大革命前的穿袍贵族，或现代的职业官僚）。

**机制四：反作用。** 上层建筑可以加速或延缓经济基础的变化。保护产权的法律可以促进投资；限制工时的法律可以提高劳动力质量，从而在长期提高生产力；而阻碍技术传播的专利制度、阻碍劳动力流动的户籍制度，则会延缓发展。

::: src 史料 3.1 · 恩格斯的两封书信 {#src-mlm.3.3.1}
恩格斯在 1890 年代的一系列书信里，反复纠正对历史唯物主义的庸俗化。除了致布洛赫的信（见 [@src-mlm.1.4.1]），还有 1894 年 1 月 25 日致瓦尔特·博尔吉乌斯的信，其中说：政治、法律、哲学、宗教、文学、艺术等等的发展是以经济发展为基础的，但它们又互相作用并对经济基础发生作用。这并不是说，经济状况自动发生作用，而是说，**人们自己创造自己的历史，但他们在既定的、制约着他们的环境中创造**。

这段话把两个层面分开了：经济是「环境」的一部分（约束），人是「创造者」（能动）。把两者合起来才是历史唯物主义。只要其中一半，就会得到宿命论或唯意志论。
:::

## 3.4 阿尔都塞的问题：比喻不能解释再生产

阿尔都塞在《论再生产》里对这个比喻提出了一个尖锐的质疑。他的问题不是「比喻对不对」，而是「比喻能不能解释它该解释的东西」。

建筑比喻说的是：基础支撑上层。但它没有回答：**上层建筑为什么会长久地维持基础**？如果上层建筑只是「竖立其上」，那么它随时可以倒塌，而基础不受影响。可是现实是：当上层建筑崩溃时（国家机器被打碎、学校体系被改造），基础也会动摇。这说明两者之间的关系比「支撑」更紧密。

阿尔都塞的替代方案是**再生产**。他的思路可以概括为三步：

**第一步：任何社会形态都必须再生产它的生产条件。** 这包括生产资料（机器、原料）与劳动力（会干活的人）。

**第二步：生产条件的再生产不能在生产过程内部完成。** 机器需要被生产出来，劳动者需要被培养出来；这两件事都需要生产过程之外的机构。培养劳动者需要学校、家庭；维持秩序需要国家机器。

**第三步：因此，上层建筑的功能是保证生产关系的再生产。** 学校不只是教知识，它还教「服从」「守时」「等级」；教会不只是提供信仰，它还提供对苦难的解释；国家机器不只是镇压，它还通过法律确认产权。

这个三步论证的价值在于：它把「基础—上层建筑」从**空间比喻**变成了**功能关系**。上层建筑不是「在上面」，而是「在再生产中起作用」。

::: def 定义 3.2 · 意识形态国家机器 {#def-mlm.3.4.1}
阿尔都塞把国家机器分为两类：

- **镇压性国家机器（Appareil répressif d'État, AE）**：政府、行政机关、军队、警察、法院、监狱。它以**暴力**（或暴力的威胁）为主要手段发挥功能，是单一的、公共的。
- **意识形态国家机器（Appareil idéologique d'État, AIE）**：宗教（教会系统）、教育（学校系统）、家庭、法律（在阿尔都塞的列举里，法律同时属于两类）、政治（政党系统）、工会、传播（报刊、广播、电视）、文化（文学、艺术、体育）。它以**意识形态**为主要手段发挥功能，是多样的、多数为私人的。

这个区分的要点：镇压性机器以暴力为主、意识形态为辅（警察也讲法律意识）；意识形态机器以意识形态为主、暴力为辅（学校也有惩罚，但主要靠说服与规训）。
:::

这里的引文位置需要说明。阿尔都塞这本书的中译本没有把印刷页码排进文本层，因此本书引用时给出**章次与节次**，而不是页码：

> 任何国家机器，无论是镇压性的，还是意识形态的，都既通过暴力也通过意识形态发挥功能，区别只在于两者所占的比重不同。
> ——阿尔都塞《论再生产》第六章（据吴子枫译本）

::: debate 论战 3.1 · 学校是上层建筑还是经济基础 {#debate-mlm.3.4.2}
**立场 A（上层建筑）**：学校不直接生产物质产品，它培养人，属于意识形态国家机器。阿尔都塞持此立场。

**立场 B（经济基础的一部分）**：教育劳动也是生产劳动（它生产劳动力这种特殊商品），教师也是雇佣劳动者，教育产业本身创造价值。按这个读法，学校既是上层建筑又是经济部门。

**本书的判断**：这不是二选一的问题，而是**同一对象在不同关系中的不同位置**。作为培养劳动者的机构，学校执行再生产的功能，属于上层建筑；作为雇佣教师、收取学费、创造增加值的部门，学校参与剩余价值的生产，属于经济结构。混淆两者会导致实践上的错误：只看到前者，就会把教育完全当作意识形态工具，忽略教师也是被剥削的劳动者；只看到后者，就会把教育市场化当作中性改革，忽略它在再生产阶级关系中的作用。
:::

## 3.4b 多元决定：为什么「决定」不等于「单向」的第二个答案

阿尔都塞还有一个概念，专门处理「上层建筑到底有多大力量」这个问题：**多元决定**（surdetermination，旧译「过度决定」）。

要点只有一句：**一个历史事件从来不是由单一矛盾单独决定的，而是由多个层次的矛盾「共同决定」，其中有一个是「归根到底」的决定性的。**

这句话听起来像折中，其实不是。它提出三个可检验的要求。

**要求一：分清层次。** 任何事件都要拆成经济、政治、意识形态几个层次，分别看各层次的矛盾状态。

**要求二：找出「决定性的那一个」。** 不是说所有层次平等，而是说在特定形势下，有一个层次起「归根到底」的作用——它划定其他层次发挥作用的空间。

**要求三：解释「不平衡」。** 各层次的发展速度不同，有的超前，有的滞后。事件的形态往往由这种不平衡决定，而不是由某一层次的单独状态决定。

::: arg 论证 3.1b · 用多元决定重看 1917 年 {#arg-mlm.3.4b.1}
**单一因素解释（经济决定）**：俄国资本主义落后，所以革命条件不成熟，十月革命是「早产」。

**单一因素解释（政治决定）**：列宁的判断与布尔什维克的组织，决定了革命成功。

**多元决定的解释**：

- **经济层**：俄国资本主义发展不充分，但集中度高（大工厂集中在彼得格勒），形成有组织的工人群体；
- **政治层**：沙皇制度依赖暴力、缺乏合法性的代议机构，战争使国家机器瓦解；
- **意识形态层**：农民的土地要求、士兵的厌战情绪、知识分子的革命传统；
- **国际层**：世界大战把俄国拖入危机，帝国主义链条在这里最薄。

**结论**：革命不是任何单一层次的产物，而是四层矛盾「汇合」的结果。其中经济层是「归根到底」的（它决定了工人为什么集中、农民为什么缺地），但革命的时机与形式由政治层与国际层决定。

**这个解释的好处**：它既不用「条件不成熟」否定革命，也不用「领袖意志」解释一切。它给了一个可以逐层检查的框架。
:::

::: errata 关于「多元决定」的两个误读
**误读一：「多元决定就是多因素论」。** 不是。多因素论把各因素并列，谁重谁轻看情况；多元决定坚持有一个「归根到底」的决定性层次（经济），只是反对把它理解为「唯一原因」。

**误读二：「多元决定否定了经济基础的决定作用」。** 不是。它改变的是「决定」的形式：从「经济直接产生政治」改成「经济划定空间、其他层次在其中起作用」。这个改动使理论能够解释「同样的经济基础，不同的政治形式」这个事实。
:::

## 3.5 一个完整的分析：义务教育制度

用上面的框架分析义务教育，看它能给出什么。

**功能问题**：为什么 19 世纪后期主要资本主义国家先后建立义务教育？

**常见答案一（人道主义）**：因为进步人士认识到教育的重要性。这是真实的一部分，但它不解释为什么恰恰在那个时间点、以那种形式（强制、免费、国家办）出现。

**常见答案二（经济需求）**：因为工业化需要识字、守时、服从的工人。这个答案有解释力。工厂制度需要能读懂操作手册、能按钟点上班、能接受等级指挥的劳动力；家庭与行会不能大规模提供这种劳动力；于是国家介入。

**上层建筑的视角补充**：义务教育同时完成了三件事——（1）生产技能（读写算）；（2）生产纪律（作息、考试、排队）；（3）生产认同（国旗、历史叙述、公民课）。第三件事不直接提高生产力，但它降低了镇压成本：一个认同现有秩序的人不需要警察时刻盯着。

**反作用**：义务教育一旦建立，就产生了自己的动力。教师职业的形成、教育理论的积累、家长对教育的期待，都超出了最初的「培养工人」目标。这就是相对独立性：制度会生长出它自己的利益与逻辑，反过来对经济提出要求（例如要求更多教育经费、更长学制）。

这个分析示范了怎么用「功能—机制—反作用」三层来理解一个制度，而不是简单地贴「上层建筑」的标签。

::: errata 关于上层建筑的四个常见错误
**错误一：「上层建筑只是统治阶级的工具」。** 这忽略了相对独立性与内部矛盾。法律体系内部有职业逻辑，官僚机构内部有派系，教会内部有神学争论。这些不是「工具」能概括的。

**错误二：「经济基础一变，上层建筑立刻变」。** 马克思用的是「或慢或快」（《序言》原文），说明两者有时间差。这个时间差是政治斗争的空间。

**错误三：「上层建筑没有独立的因果效力」。** 这会让历史变成经济自动机的展开。恩格斯明确说过，如果这样理解，「历史就变得非常容易」——而这恰恰是错的。

**错误四：「意识形态就是虚假意识」。** 阿尔都塞的用法比这复杂：意识形态是「个人与其真实生存条件的想象关系的再现」，它不一定是假的，而是一定被体验为真的。虚假意识只是它的一种可能形态。
:::

## 3.6 本章要点

<div class="keypoints">
<span class="kp-title">本章要点</span>
<ol>
<li>「基础—上层建筑」是马克思用过一次的建筑比喻，他没有给出清单与机制说明，后世的具体化都是理论工作。</li>
<li>「决定」有三种强度：因果决定（假）、功能决定（最有用）、约束决定（最稳妥）。本书主要用功能决定。</li>
<li>上层建筑有相对独立性，四个可观察机制是：路径依赖、内部逻辑、利益独立化、反作用。</li>
<li>阿尔都塞用「再生产」替代空间比喻：上层建筑的功能是保证生产关系的再生产，其中教育、家庭、教会、媒体是意识形态国家机器。</li>
<li>镇压性国家机器以暴力为主、意识形态为辅；意识形态国家机器以意识形态为主、暴力为辅。</li>
<li>同一对象可以在不同关系中处于不同位置（学校既是上层建筑又是经济部门），混淆会导致实践错误。</li>
<li>用「功能—机制—反作用」三层分析制度，比贴「上层建筑」标签更有解释力。</li>
</ol>
