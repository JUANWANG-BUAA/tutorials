# 5 异化劳动与人的本质：1844 年手稿

本章连续解读《马克思恩格斯选集》第一卷印刷49–63页所收《1844年经济学哲学手稿》节选［异化劳动和私有财产］。引文采用该选集的页码；它们是马克思的一手论证，经选集编校转录，不能当作独立统计调查。我们沿着原文的提问顺序，追踪生产出来的对象如何成为对生产者的支配，再由劳动活动追到人与人的财产关系。本章只据这一完整节选展开，不冒充整部手稿的通读成果。

## 1.1.1 从经济学前提追到生产关系

工厂生产得更多，工人的生活就一定会改善吗？这个问题至少包含两个判断：生产的物质成果有没有增加，以及生产者能否支配这些成果。前一个判断需要产量、质量和工时材料，后一个判断还需要工资、产品归属、生产资料控制权与生活资料价格。只知道产量增长，尚不能回答生活改善的问题。

马克思在选集第一卷49页写道：“国民经济学从私有财产的事实出发。”（一手论证，选集编校本）他紧接着批评经济学没有说明这个事实，而把财产运动放进抽象公式，再把公式当成规律。他接受工资、利润、地租、分工和竞争作为分析起点，却继续追问它们为什么以这种方式联系。接受一个现实关系存在，与宣布这个关系已获得解释，是两件不同的事。

::: arg 论证 5.1.1 · 起点与解释的区分 {#arg-mlm.5.1.1}

如果有人问为什么劳动者没有产品处置权，回答“因为产品归所有者”只是重述现行归属。分析还要说明，劳动者如何进入生产，为什么必须借用他人掌握的劳动条件，以及产品如何在生产结束后继续由另一方控制。经济学规律可以描述工资、竞争和利润的运动；异化劳动分析则从生产者的处境追问这些运动所依赖的关系。
:::

50页拒绝用虚构的原始状态解释现存关系。假设远古某人勤劳、另一人懒惰，再把今天的财产差别归结于那个故事，没有提供可核查的历史链条。马克思要求从当前国民经济事实出发。这仍然包括概念分析和论证，不能缩减为收集几个数字后直接归纳，也不能用“马克思只讲经验、黑格尔只讲纯思想”的对照代替对两位作者的阅读。本章没有通读黑格尔著作，因此不据这个选段裁定黑格尔全部异化理论。

::: method 方法 5.1.1 · 控制变量后再提问 {#method-mlm.5.1.1}

下面是教学假设，两家作坊各有10人，每人每月生产10件产品，总产量均为100件。这个数字只固定生产规模，不代表历史调查。

|条件|作坊甲|作坊乙|
|---|---|---|
|人数（人）|10|10|
|人均月产量（件）|10|10|
|月总产量（件）|100|100|
|产品出售决定|生产者共同决定|外部所有者决定|
|所得用途决定|生产者共同决定|所有者决定，生产者领约定工资|

相同产量不能消除表中两项控制权差异。反过来，仅凭共同决定这一项，也还不能断言甲已经具备一切自由条件；债务、市场依赖和内部权力仍需调查。
:::

::: arg 论证 5.1.2 · 假设模型的证据范围 {#arg-mlm.5.1.2}

模型所能证明的是逻辑上的不充分：由“产量100件”无法唯一推出“生产者有处置权”。模型不能证明现实工厂都属于乙，也不能证明某种历史制度必然由甲演变为乙。后一类判断需要超出本模型的材料。
:::

常见错误是把51页关于财富增多与工人贫穷的命题当成已经由本篇附表验证的普适定律。本节选没有提供对应的时间序列，也没有规定贫困的计量单位。写作者不能为它补一组自造的“英国工业革命调查”。我们能够沿着作者给出的分析路径追问工资与所有权，但历史工资的涨落须另找真实证据。


### 经济学的割裂如何构成解释困难

49–50页批评的对象还包括一种处理矛盾的方法：把竞争同垄断、经营自由同同业公会、地产分割同大地产分开，仿佛每一对现象只有互相排斥的性质。按照这种写法，竞争属于自由的正常秩序，垄断来自某种额外干涉；只要排除干涉，就仿佛可以保存竞争而不再追究竞争自身怎样改变财产分布。马克思要求考察这些关系的运动联系，即一种被当作起点的安排如何在运行中产生改变它的结果。

这并不等于已经凭一句话证明所有竞争都会通向同一种垄断。原文在这里提出的是解释要求：若把财产集中解释为竞争之外的偶然事件，研究者还需要回答，为什么这些事件能够反复发生、为什么同一制度容许某些竞争者积累而另一些退出。若只说退出者竞争失败，便还没有说明失败后生产条件和劳动者如何重新配置。分析须追踪活动与财产关系，不停在成功或失败的名称上。

50页的神学类比把这个困难讲得更清楚。用原罪解释恶的起源，先要求接受某件具有历史形式的事情，然后把需要解释的恶放进那件事情里。对应的经济学叙事可以是：为了说明劳动与财产为什么分离，先假定原始社会中已经有一群有产者和另一群必须替他们劳动的人。这个假定复述了要解释的分离，没有展示分离怎样形成。马克思批评的是论证中的预设和循环，不能据此推断所有关于过去的研究都无效；有史料支持、能够逐步核查的起源研究仍然可以进行。

从现存事实出发也有边界。观察到今天工资由雇主支付，只能确认这种支付关系；说明支付关系如何连接劳动组织、产品归属和生活资料，还要进一步分析；说明它如何在历史上出现，又是另一层任务。把这三层分开，可以防止将概念上的推导顺序写成事件发生的时间顺序。后文从异化劳动分析私有财产时，也应持续保留这个区分。


### 商品化、集中与分化为何放在开篇

49页开篇不仅列出工资、利润和地租，也列出劳动、资本、土地的分离。前一组是取得收入的不同形式，后一组指出这些形式所依赖的生产条件被分属不同位置。作者采用这些范畴，不是承认它们无需解释，而是要追问：为什么提供劳动的一方必须以工资取得生活资料，掌握其他生产条件的一方却能够凭借占有取得收益？仅把三种收入并列，尚未说明三种位置如何共同形成生产过程。

作者接着概括工人降低为商品、竞争中资本积累到少数人手中、垄断重新出现，以及社会分化为有产者和没有财产的工人。它们在开篇构成同一提问背景：生产扩展了财富，取得生产条件的位置却可能更加分离。竞争不是只改变售价，还可能改变谁能够继续掌握生产条件、谁必须依靠出卖劳动进入生产。原文提出这些联系，并不在这十五页里逐项提供统计证明；教材应呈现这串命题和相互关联，另把事实检验的任务保留下来。

50页以工资与资本利润的关系举例，指出经济学将资本家的利益作为最终原因。说某种安排存在“因为资本家希望获利”，命名了受益者的愿望，却没有说明他何以能够凭这个愿望组织他人的劳动。还要追问生产条件怎样由他支配、生产者怎样取得工作、产品怎样由他处置。这使开篇的收入分类进入关系分析，也使后面的商品化与财产集中不再只是几个相邻标签。

::: ex 练习 5.1 · 还缺什么材料

一家工厂宣布人均产量翻倍。能否据此判断工人生活改善？至少列出三项还需核实的材料。
:::
::: sol 解答 5.1

不能。至少还需实际工资及生活资料价格、工时与劳动强度、产品和生产条件的控制权。它们分别回答购买能力、劳动负担和支配关系的问题。
:::

::: ex 练习 5.1补 · 解释是否绕回了前提

有人说：“工人缺少生产资料，因为最早就有人拥有全部生产资料，所以现在工人只能接受工作条件。”这句话解释了什么，又有什么尚未解释？
:::
::: sol 解答 5.1补

它至多叙述了一个被假设的初始安排。它没有提供初始安排的证据，没有说明该安排如何形成，也没有展示它怎样持续到现在。若初始安排仅为解释当前分离而设，论证就绕回了自己的前提。可继续分别查明生产资料取得史、劳动者进入生产的条件及财产关系的再生产过程。
:::

## 1.1.2 对象化何以成为异己力量

生产者把一张桌子做出来，桌子离开他的双手，是否就发生了异化？若把一切外在对象都叫异化，劳动只要有所成果就会成为问题，人的创造能力本身也就失去积极意义。原文的区分比这个理解精确。

51页说：“劳动的现实化就是劳动的对象化。”（一手论证，选集编校本）劳动借材料和工具形成某个对象，使活动获得客观结果；桌子不再只是想象，而成为可使用的东西。这一层说明劳动如何实现。原文随后加上“在国民经济的实际状况中”的限定，才讲这种现实化如何表现为工人的非现实化、对象化如何表现为对象的丧失。限定不能删，否则就会把特定关系中的结果写成所有劳动的命运。

::: arg 论证 5.2.1 · 三个需要分别说明的环节 {#arg-mlm.5.2.1}

第一，劳动在对象中固定下来，形成产品；第二，生产者丧失对该产品的支配；第三，已经独立的产品及其财产形式又反过来制约生产者。第一步本身不能推出后两步。异化分析要解释的正是：劳动的客观成果为什么在一定关系中成为劳动者不能驾驭的力量。
:::

产品离开生产现场、拿到公共仓库存放，都不能单独证明第二步。共同保管与被他人独占在空间上可能相同，在权利上却不同。生产者也可以自愿将产品赠给他人；赠与和为取得生活资料而不得不进入他人指挥的生产活动，仍需区分。考察应落在取得生产条件、安排活动和处置成果的具体关系上。

::: thm 分析命题 5.2.1 · 物量不直接等于价值关系 {#thm-mlm.5.2.1}

同样工时生产更多件产品，首先表示物质生产率提高。要由此讨论价值总量、工资份额或剩余价值率，还需价格、社会必要劳动时间、原料和设备耗费等条件。本章不从产品件数直接计算剩余价值。
:::

::: ex 教学假设 5.2.1 · 增产与生活改善 {#ex-mlm.5.2.1}

假设同一组生产者在相同月工时下，产品从100件增为200件，月工资从100元增为120元，生活资料价格指数从100升为120。这个模型只测购买能力，价格指数是给定条件，不是生产率变化的自动结果。

|指标|原期|新期|
|---|---:|---:|
|月产量（件）|100|200|
|月工资（元）|100|120|
|生活资料价格指数|100|120|
|实际工资指数（工资÷价格指数×100）|100|100|

名义工资增长20%，实际工资没有改变；产量增长100%。这说明增产与实际工资改善没有一对一对应关系。模型没有给出售价和投入成本，因此不能据它计算利润，也不能判断剩余价值率升降。
:::

::: note 注 5.2.1 · 对“成正比”的阅读边界 {#note-mlm.5.2.1}

51页“物的世界的增值同人的世界的贬值成正比”是作者对矛盾关系的概括。本选段没有定义两项可比量，没有给出比例常数；将它改写成“产量翻倍，贫困深度必然翻倍”，会替原文增加一个未经证明的数学定律。
:::

产品成为力量，还涉及它能否转化为继续组织生产的条件。生产者创造机器，而机器归他人掌握；下一次取得工作时，他仍须服从机器所有者的条件。这样，过去活动的结果进入下一轮活动并形成约束。此处不是说每台机器都压迫人，而是说明同一机器在不同控制关系下可能承担不同作用。

::: arg 论证 5.2.2 · 感受不能替代关系调查 {#arg-mlm.5.2.2}

工作愉快可以与产品缺少支配权并存；独立劳动者也可能因技艺失败而痛苦。因此，“我喜欢工作”和“我讨厌工作”都不足以独立完成异化判断。感受是需要解释的材料，生产条件、活动组织和产品归属提供进一步判断的依据。
:::


### 宗教比方究竟说明哪一种独立化

51页把劳动者同产品的关系同人对上帝的奉献并置：人把越多力量归给一个独立存在，就越少把这些力量当作自身能够掌握的能力。这个比方承接的是劳动者把生命投入对象，而对象获得独立力量的分析。它帮助读者辨认一种关系形式：原本出自人的活动的东西，在人的经验中反而像不依赖人的力量。

两边的材料不能不加区分地交换。在宗教比方中，独立化涉及人的观念和精神力量；在劳动分析中，产品能够由别人实际占有，能够售出，能够转为下一轮劳动的材料和工具。经济关系的改变需要处理现实归属、取得条件和活动组织，不能由“工人意识到产品出自自己”自动完成。即使生产者完全明白某台机器是自己造的，只要他无权使用或处分它，明白来源就没有取消现实限制。

反过来说，宗教比方也不能证明所有宗教活动都等于经济剥夺。本节选没有逐项调查不同宗教的财产组织，更没有提供宗教经验与经济关系一一对应的证据。它借助熟悉的独立化图式说明产品关系，写作者只能在这个层次使用它。用它断言一切精神文化都属于异化，或断言只要消除宗教就能消除劳动异化，均超出当前论证。

还应区分对象的独立存在和对象的支配力量。桌子制作完成后可以比制作者活得更久，作品可以被陌生人阅读，工具可以供下一代使用。这些超出个人生命的结果，使劳动能够积累和传承，不能单凭其独立存在判为损失。需要解释的是，独立存在的成果如何在一定关系中使生产者丧失行动条件；“东西继续存在”同“东西的归属反过来制约我”不是同一判断。

如果甲把工具留给共同体，任何成员可按共同规则使用；乙把工具交出后，下一次使用却要接受所有者单方条件，两者都发生了对象离开个人的过程。然而甲的对象可能扩展共同活动，乙的对象可能形成新的依赖。比较不能只问对象还在不在手边，还应问谁能使用、谁能改变规则、拒绝条件会失去什么。这样才能把原文的宗教类比还原为一个可继续追查的问题，而非给对象或信念贴标签的办法。

### 产品增加与生产者处境怎样接到同一过程

51页说劳动不仅生产商品，还生产“作为商品的劳动自身和工人”（一手论证，选集编校本）。这并不是说工人在生物学上由工厂制造，而是把劳动者的社会处境纳入生产结果：他造出的产品归另一方，自己的生活资料仍须通过工资取得，下一轮又要作为出售劳动的主体进入生产。物品的形成与关系的延续在同一活动中实现，因此，商品化不能只按某次工资高低理解。

同页把工人投入对象的生命力量与对象独立化相连。力量投入对象，本来使人的能力获得现实成果；成果归另一方掌握，并作为原料、工具和资金返回生产时，却可以成为要求劳动者继续接受条件的力量。作者关于“生产越多”与对立力量加强的判断，依靠这些归属和支配条件。若把归属、使用权和组织方式省掉，只比较件数和工资，就失去了这一推导的中间部分。

因此，“成正比”的限定说明之后仍要回答正面问题：何种关系使对象世界的扩展与生产者对活动条件的依赖并行？本节的机器例子提供这条线索，下一节再从取得劳动对象与维持身体的双重条件展开。概念分析没有提供精确比例常数，却仍提出可以继续调查的机制，而非只给一个不可检验的形容词。

::: ex 练习 5.2 · 同一仓库

甲、乙共同制造桌子并决定暂存公共仓库。只因桌子不在两人手里，能否认定它成为异己力量？
:::
::: sol 解答 5.2

不能。还要查谁决定使用和处置、谁能取得下一次劳动条件，以及这种安排能否由生产者共同改变。空间分离不等于支配关系的丧失。
:::

::: ex 练习 5.2补 · 了解来源是否已足够

劳动者清楚自己制造了机器，却仍须获得所有者同意才能使用它。有人说“既然没有观念上的误认，就没有异化”，这个回答遗漏了什么？
:::
::: sol 解答 5.2补

它遗漏了现实的使用与支配关系。来源被理解，不能自动转成使用权。宗教类比帮助识别独立化的形式，机器的经济关系则需要另查财产安排、使用条件和活动规则。
:::

## 1.1.3 劳动条件与生存条件的双重依赖

为什么失去产品控制，会影响下一次劳动，而不只影响劳动结束后的分配？52页将自然界提供的生活资料分为两种含义：劳动得以活动的对象和材料，以及维持劳动者身体生存的资料。前者使劳动能够发生，后者使劳动者能够生活；不能只看产品被谁买走。

同页说：“没有自然界，没有感性的外部世界，工人什么也不能创造。”（一手论证，选集编校本）这句话先确定劳动对客观条件的依赖。再追问谁掌握这些条件，才能理解劳动者为什么必须通过特定关系才能工作。一个人有劳动能力，并不自动拥有可用的土地、原料、厂房或工具。失去这些对象，能力就不能仅凭愿望转成现实活动。

原文接着说明，工人在两个方面成为对象的奴隶：首先要取得工作，其次要取得生存资料。工作不仅是一个职位名称，而是进入生产所需客观条件的机会。生存资料也不是关于尊严的抽象说法，而是身体必须持续取得的食物、住处等。两者在雇佣关系中连接：为了取得维生资料，人要取得工作；为了继续工作，人又必须维持身体。

用教学假设看这种连接。甲乙各生产120部假设设备，每部售价5000元；假定原料等当期外购投入每部1000元，设备耗费当期共10000元，工资总额120000元。假设全部售出、没有税费利息和其他费用，只为避免把营业额直接当收益。

|当期账目|计算|金额（元）|
|---|---|---:|
|营业额|120×5000|600000|
|外购投入|120×1000|120000|
|设备耗费|给定|10000|
|工资总额|给定|120000|
|扣上述项目后余额|600000−120000−10000−120000|350000|

余额只是这个简化会计假设中的余额，不能直接命名为马克思意义的剩余价值，更不是“无偿创造的全部价值”。售价、成本和工资均属假设；该算例未讨论价值向价格的关系，也没有用它们证明真实设备制造业的利润。120部设备全部进入出售，不再另设两部自用和两部交换以造成去向不明。

数字能说明的是：在产品出售后，掌握350000元余额用途决定权的一方，可以安排下一轮购买材料和工具；没有这种权利的生产者则不能仅凭自己参与生产过，就直接调用这笔钱。把控制权条件换掉，同一账目还可以由生产者共同决定。因此账目本身不证明异化，账目与权利配置合看，才能表达原文追问的关系。

再设一个不涉及利润的条件表：每人每天维生需2单位食物、开展生产需10单位材料。两项都是假设需求。一个人有2单位食物却无权取得材料，可以生活一天但无法立即开展这项生产；有材料却没有食物，也无法无限持续劳动。这种区分帮助我们读懂双重生活资料，并不把全部失业和饥饿原因都归结为同一机制。

常见错误是拿设备售价同个别工资比较，因“工资买不起一部设备”就宣布完成论证。设备可能本来就是多人协作产品；价格还包含外购投入和其他条件。异化分析的重点在生产者如何取得劳动条件、如何参与活动、如何处置成果，购买能力只是其中一项。收入增加能缓解维生困难，仍须另外核查对劳动条件的支配是否改变。


### 两层丧失怎样发生在同一活动之中

52页的论证比“工人贫穷所以买不起东西”多了一层：劳动者通过劳动占有外部自然界，却可能在劳动对象与身体生活资料两个方面丧失它。这里“占有”首先说劳动怎样把材料纳入活动，并不预先保证成品在法律上归劳动者。木匠把木料加工成家具，是活动对对象的实际改变；家具被谁掌握，仍由这项活动所处关系决定。将两种含义混为一谈，就会误以为劳动者既然加工了木料，便已取得了能够自由处分的财产。

第一个丧失是劳动对象越来越不成为劳动者能够自主取得的劳动条件。他可以制作出更多工具，却不能据此自行开始下一次生产。工具、原料和场所集中在他人掌握之下时，生产规模扩大同个人对劳动条件依赖增强，可以同时发生。原文不是在抱怨劳动没有接触自然，而是在说明接触自然所必须经过的社会关系：谁可以使材料成为劳动对象，须以什么方式进入这个过程。

第二个丧失涉及维持身体的生活资料。劳动者的活动产生了可供生活使用的财富，但他取得生活资料的路径仍可能受制于工资、就业和交换条件。它同第一个丧失相互连接，因为失去工作会影响工资，失去维生资料又会损害继续工作的能力。把它们分开，是为了辨认关系的不同环节；把它们重新连接，则为了理解为什么某个局部改善尚不能自动取消整个依赖结构。

这个分析保留了自然条件的物质意义。食物不能由所有权称谓替代，材料不足也不会仅凭共同决定立即消失。面对灾害导致的减产，需要考察实际产出和分配规则；面对材料充足却不许使用的情况，则要考察进入条件。两种情况可能叠加，但若不分别调查，就会把自然短缺当成一切支配关系的原因，或把一切自然限制都说成社会制度造成。

假设共同体允许每个人使用工具，却没有足够粮食，它已改变某种使用权安排，仍未解决维生困难。另设有人每月获得足够补助，却无权参与生产安排，他的生存风险有所缓解，劳动条件的控制关系却需另议。这两个反例说明，“有饭吃”和“能掌握自己的活动条件”不能相互替代。承认两项改善各自有效，也有助于避免把原文误解成一切生活改善都没有意义。


### 宫殿与棚舍：成果对照所要说明的关系

53页写道：“劳动生产了宫殿，但是给工人生产了棚舍。”（一手论证，选集编校本。）作者以同一生产活动的不同去向具体化前面两层丧失：宏大的建筑成果存在，不意味着生产这些成果的人也能取得相应生活资料。这个对照首先要求追踪享用与占有关系，不能从宫殿的数量独自算出工人贫困多少，也不能据一句对照代替所有时代住房条件的调查。

同页还讨论机器代替手工劳动，却使一部分工人回到野蛮劳动，使另一部分工人变成机器。技术能力在社会层面扩大，与个人活动被压缩可以并存：工具怎样减轻某些任务，与谁安排剩下的任务、劳动者能否运用和发展能力，是相连而不同的问题。作者将智慧的生产与工人的愚钝并置，也在追问共同积累的知识为何未必作为个人能力的展开返回生产者。这些是原文的批判性论述，不能不经材料核实就改写成当代各行业的统计结论。

由此，原文转向工人与产品的直接关系，并把有产者对对象和生产的关系作为需要随后说明的结果。先考察生产者怎样形成并丧失成果，再追问谁取得成果，才能避免一开始就把所有者的权利作为无需解释的答案。这也为1.1.6的“归谁”问题准备了落点。

::: ex 练习 5.3 · 两个门槛

一名生产者有食物，却不能使用仓库里的原料。另一名生产者能进入车间，却拿不到维持次日生活的资料。两人分别卡在哪个条件？
:::
::: sol 解答 5.3

前者缺少作为劳动条件的生活资料，后者缺少维持身体的生活资料。两个门槛能够彼此影响，但概念上需要分别辨认。
:::

::: ex 练习 5.3补 · 自然限制与进入限制

仓库没有可用木料，与仓库木料充足却只准所有者指定的人使用，两种情况可以用同一个原因说明吗？
:::
::: sol 解答 5.3补

不能预先这样说明。前者首先涉及材料供给，后者首先涉及材料取得规则。还需查供给不足是否同分配和经营相连、进入规则是否受真实短缺制约。区分两层，是调查起点，不是认定它们永远互不相关。
:::

## 1.1.4 异化也在生产行为本身

产品属于别人，为什么还要继续追问生产过程？53页的转折是：“产品不过是活动、生产的总结。”（一手论证，选集编校本）劳动成果中表现出的关系，需要回到形成成果的活动中理解。如果只在最后分产品的时刻寻找问题，就会漏掉劳动如何被组织、谁决定劳动目的和节奏、生产者如何使用自身能力。

原文由此讨论劳动的外在性。劳动者在活动中否定自己，不能自由发挥体力与智力；劳动成为满足活动之外需要的手段；活动又属于别人。几个规定互相联系，不能只抽出“痛苦”当作定义。写作、攀登或体育训练也会痛苦，但参与者可能自主选择活动目的和组织方式。相反，一项工作可能有趣、有成就感，生产者仍缺少改变目的和控制成果的权利。

54页将活动归属说得直接：“他的活动属于别人，这种活动是他自身的丧失。”（一手论证，选集编校本）句中的“属于”把视线从个人心情引到关系。劳动者消耗的是自己的生命时间，活动所服从的目的和安排却由别人规定。由这层关系再看“不劳动时觉得舒畅”等描述，才能避免把作者的批判读成对一切辛苦工作的排斥。

下面用假设安排做对照。两组工作均8小时，其中必要协同活动6小时、可调整事项2小时；工资和劳动强度假定相同。甲的生产者共同决定2小时用于改进工具、学习或轮换；乙的2小时由管理者安排且生产者无调整权。

|工作日安排|甲|乙|
|---|---|---|
|总时长（小时）|8|8|
|必要协同活动（小时）|6|6|
|待安排部分（小时）|2|2|
|决定待安排部分的人|生产者共同决定|管理者决定|
|能否据此计算异化百分比|不能|不能|

6＋2＝8只检查时段完整。2÷8＝25%也只是时长份额，不能说甲“只有75%异化”、乙“100%异化”。异化不是这个选段已经定义的计量指标。共同决定也不等于每个人随时随意退出一切协作；共同活动仍需协调，只是协调规则怎样产生、能否共同修改，值得继续核查。

原文还用吃喝、生殖等动物机能同人的机能倒置的表述说明：本来具有自主创造可能的活动，被压缩为维持生活的手段；劳动者只能在劳动之外寻求自在。54页随即限定，吃喝生殖也是真正的人的机能；只有将它们从其他活动领域抽离、当作最后和唯一目的，才在这个论证中被叫作动物的机能。教材若只保留前半句，就会把对生活关系的批判误写成对身体需要的贬低。

常见错误还有将被迫理解为必须存在直接暴力。原文同时谈肉体强制或其他强制，要求我们考察劳动条件与生活资料的依赖。劳动者签过合同，并不自动回答他有多少可行选择；然而仅凭合同存在，也不能替代对具体选择条件的调查。另一个错误则反向夸大：只要活动能赚钱，就属于异化。报酬本身无法充分说明活动的归属和组织方式。



### 从强制的不同形式读回活动的归属

53–54页按几个相连层次描述劳动外在性：活动无法成为自身能力的展开；它仅作为满足劳动之外需要的手段；它不属于劳动者而属于别人。这种次序不能改写成一份心情测量表。如果只问工作时是否痛苦，就会把训练、修复或照护中自愿承担的艰难活动一并归入同一关系；如果只问是否领取报酬，又会漏掉劳动者能否参与决定活动目的。

“强制”还需区分直接命令、肉体暴力与生活条件形成的压力。直接暴力是可见的外部约束；缺少可替代的生活资料取得途径，也可能使人不得不接受既定劳动条件。两者不能简单等同：它们的制度形式、退出成本和可用救济不同。原文将肉体强制与其他强制并提，给我们提出考察这些条件的理由，却不容许跳过调查，声称凡签合同的人都处在完全相同的处境。

另一方面，没有强制也不等于活动没有必要性。共同体需要生产食物、维护设施、照护成员，个人不能把所有必要劳动随时取消。必要性首先来自生活再生产的要求；异化劳动分析进一步问，在这些必要任务中，活动怎样分配、谁决定规则、生产者能否共同调整。自愿协调下的不便与别人单方支配下的不便，可能在身体感觉上相似，但在社会关系上需要分别说明。

54页关于人的机能与动物机能的倒置，也不是将活动分成高贵的精神创造与低贱的身体生活。作者明确承认吃喝、生殖属于人的机能。倒置发生在另一层：人的活动原本具有把目的、方法和结果作为意识对象来处理的可能，却被压缩为取得下一次生存资料的手段；身体满足于是成为唯一可自在活动的领域。问题是生活的各个方面被切断，不能由此要求人放弃休息、食物和亲密关系来证明自己像人。

这还能帮助区分短期选择与稳定关系。一位研究者自愿暂时减少休闲完成项目，保留目的选择、方法修改和成果处置，并不因为阶段性把其他需要当手段，就自动落入原文讨论的全部规定。若劳动者长期没有可行选择，只能将自身活动交由他人安排以维生，则需要分析这种关系如何再生产。判断要考虑持续条件和可改变程度，不能把某一刻的选择抽离出来。

同样，活动得到认可、产品制作精良，都不必抹去支配关系。愉悦与痛苦可以在一项活动中并存；工资改善可以减轻生存压力；共同决定可能扩大自主空间。这些变化应分别记录，而不应被一个总标签吞没。下一节再从自由的有意识活动理解类生活时，才能在具体条件上继续推进，而非用“人应当快乐工作”的口号接替推导。


### 从活动的总结回到活动，以及第二个宗教比方

产品是活动的总结，意味着成品中呈现的关系应追溯到形成成品的活动。第53页的条件推理是：如果产品以外化形式同生产者对立，不能仅在分配终点解释它，而要考察生产本身怎样成为外化的活动。这个推理讨论稳定的生产关系，不是断言任何一次产品被盗都证明此前全部活动不自主；后者还需要盗窃发生的独立解释。

54页另外使用一个宗教比方：人的幻想、头脑和心灵的自主活动，可以在宗教中以异己活动的形式发生作用，不取决于个人；与之对应，工人自己的活动并非自主活动，而属于别人。它与51页“奉献越多、留给自身越少”的比方有所区别。前一个比方说明对象化力量独立对立，后一个说明活动本身不由活动者支配。二者分别接在产品与过程的不同论证环节，不能只用同一个“宗教比方”标签替代。

原文说外部强制停止，人便像逃避瘟疫那样逃避劳动；这是作者描述劳动外在性的一种表现。它需要同活动归属和生存依赖一道理解，不能单凭某次下班离开或休息愿望给劳动定性。依此读完54页的回顾，前两种异化可以并列如下：

|方面|直接考察的对象|所要解释的关系|
|:--|:--|:--|
|物的异化|劳动产品及外部对象|活动成果怎样独立并反过来支配生产者|
|自我异化|生产行为及个人生命活动|自己的体力智力怎样表现为不属于自己的活动|

它们分析同一生产过程的结果与活动，互相连接而不能简单合并。下一节由这两种规定进一步推出类生活的颠倒，才保留了原文从第一、第二规定走到第三规定的次序。

::: ex 练习 5.4.1 · 辛苦与外在性 {#ex-mlm.5.4.1}

一位创作者主动连续修改作品而十分疲惫；一位雇员工作轻松却不能决定工作目的。仅凭疲惫程度，能否比较两人的异化？
:::
::: sol 解答 5.4.1

不能。疲惫说明身体负担，还需调查活动目的、劳动安排与成果归属。辛苦并不排除自主，轻松也不保证自主。
:::

::: ex 练习 5.4.2 · 身体需要的限定 {#ex-mlm.5.4.2}

为什么不能用本节原文证明“吃喝都不属于人的生活”？
:::
::: sol 解答 5.4.2

原文明说这些也是真正的人的机能。批判针对它们被抽离、成为唯一终极目的时与自主活动之间的倒置关系，并非否定身体需要。
:::

::: ex 练习 5.4补 · 必要劳动与别人的目的

轮流处理共同体的必要清洁工作，与由某人单方决定他人的清洁任务，都可能辛苦。为什么不能只凭辛苦程度判成同一种关系？
:::
::: sol 解答 5.4补

辛苦说明负担，尚未说明规则如何形成。应比较成员是否参与分配、能否修改安排、退出有何后果、谁享有成果。共同决定不自动消除全部不平等，单方安排也需具体调查；但两者的组织形式不能被同一种感受代替。
:::

## 1.1.5 类生活怎样成为生存的手段

一个人能设计工具、讨论工序、设想尚未存在的产品，却只能把这些能力用于完成自己不能决定的任务。说这种活动受异化，并不等于说他失去了思考能力。读者容易把“人的本质相异化”理解为人变成了另一种动物；这种理解恰好会遗漏原文的推导条件：活动仍然有意识，能够改变活动目的的能力却被安排为维持生存的手段。

马克思写道：“一个种的整体特性、种的类特性就在于生命活动的性质，而自由的有意识的活动恰恰就是人的类特性。”（《马克思恩格斯选集》第一卷，第56页；一手论述，官方编订文本。）紧接着，他说异化劳动把关系颠倒，以致人“正因为是有意识的存在物，才把自己的生命活动，自己的本质变成仅仅维持自己生存的手段”（同页）。有意识这一条件在颠倒前后都保留着。因此，批判的对象是人的能力实现方式受到何种规定，不能写成工人的操作已经无意识、工人的生命已经不再具有人性。

推导从前面的两种关系接过来。产品不由生产者支配，生产活动服务于另一主体的目的；这样的活动仍然运用人的计划、协作、记忆和创造能力，但这些能力的直接用途被限定为取得继续生存所需的报酬。产品的丧失由此扩展为一种活动条件的丧失：生产者能够设想活动的其他用途，却不能把这些用途直接变成自己生产生活的目的。把这一关系称作类生活的异化，需要前面关于产品和活动归属的分析，单凭“工作很累”推不出来。

第55页还提出自然界作为人的“无机的身体”。这个比方所说的并不限于某一件消费品。人既要靠自然产品生活，也要以自然材料和工具进行活动；第52页已经区分劳动所需对象与维持身体所需资料，第55–56页把这两个方面放到人与自然的持续交互中。失去劳动对象的支配条件，会同时影响人怎样取得生活资料、怎样运用和发展自己的能力。因此，不能把类生活缩成下班后的文娱时间，也不能把它理解为只要参加集体活动便已恢复的归属感。

第57页借动物营巢与人的生产作对照，强调生产的范围、面对产品的方式以及对不同尺度的掌握。这是作者说明人的普遍活动能力的论证，不是一份比较动物行为学的测量报告。本章据它解释概念，不从中捏造蜜蜂每天工作多少小时，或给动物和工人打自主性分数。原文关于“按照美的规律来构造”的说明也承担实际作用：生产可以考虑对象的结构和形式，可以形成超出即时生存需要的目的；这些活动能力被降为单一生存手段，才构成这里所说的颠倒。


常见的另一种误读是把维持生存本身视为低贱。第54页明确承认吃、喝、生殖也是真正的人的机能；问题在于把这些机能从人的其他活动中抽离，成为最后和唯一目的。维持生命是人的活动条件，批判针对的是社会关系使它压缩并支配了能力展开的其他目的。劳动者养家谋生不因此失去尊严。


::: sol
提出方案已经表明他具有反思活动的能力。需要进一步调查谁决定生产目的、方案怎样形成、劳动者能否参与决定以及产品怎样支配。时间预算只说明活动机会分配，不能独自判断这些关系。
:::


### 自然界既是生活条件，也是活动对象

“无机的身体”这个用语容易引起两个相反的误解。一种把自然界看成人可以无限占有的外物，另一种把它理解成身体边界之外所有东西都已经归个人所有。第55–56页的论证不采取任何一种理解。它先从依赖关系说起：人只有持续摄取和加工自然产品才能生活，生产也只有在材料和工具的条件下才能进行。所谓身体的扩展说明生命不能自足，所依赖的条件超出生物身体；它没有因此建立个人对全部自然界的产权。

读者可以分别问两个问题。空气、食物与燃料怎样维持身体？这些东西在什么条件下成为可使用的劳动对象？前一问指出自然依赖，后一问引入生产活动。若再问谁能取得和决定这些对象的用途，就进入社会关系。三问逐层推进，不能把第一层的自然依赖直接当作第三层某种所有权必然成立的证明。一个人需要土地才能种植，不等于由需要本身即可推出土地归谁、取得何种权利及与他人怎样协作。

原文将科学和艺术的对象也放入人的精神的无机界。自然物并不只以可立即吃掉或使用的形式与人发生关系：人能够把它们作为认识、表达和构造的对象。所谓普遍性就在这种对象范围和活动方式的展开中。若只保留热量摄入和工资购买力，会漏掉人怎样理解、加工并形成对象的多重能力。反过来，若只说精神自由而不考察人能否取得材料、工具和维持生活的资料，也会把能力的实现同现实条件分开。

### 动物比较怎样参与推导

第57页承认动物也生产，随后用需要范围、产品关系和尺度来比较。作者没有把区分建立在“动物完全不活动、人类才活动”之上，而是强调人能够使活动本身成为对象。由此才能推出目的和手段的颠倒：只有能够设定和反思目的的活动，才会面临这种能力被固定用于外在目的的问题。若先断言工人已经没有意识，反而取消了颠倒所需要的前提。

因此，不宜把每次为吃饭而劳动都直接等同于类本质异化。做饭、种粮也可以包含计划、共同决定与对对象尺度的把握；某种不直接用于谋生的活动也可能受别人强制。区分不能只看活动名称，须看它在生活关系中的位置。动物比较在原文中帮助界定活动形式，读者据此提出的是分析问题；它不授权我们为现实劳动者排定生物等级，更不授权以“低于动物”为由贬损其人格。

### 对象化为什么也是对能力的现实确认

第57页在动物比较之后再推进一步：生产使人能够在自己创造的世界中直观自身。理解这句话，可以区分设想、实现和面对结果三个环节。制作者先设想一种工具的用途，把尚未出现的形式作为活动目的；随后借助材料和协作，使设想成为可使用的工具；最后在这个现实对象上检验自己能做什么、哪里需要改变。对象提供的阻力与效果，使能力得到修正，而不只停留在制作者关于自己的想象中。

原文把这种过程称为现实地使自身二重化。这里没有出现两个生物身体，也没有说人把一部分灵魂灌入物件；活动者仍是活动者，自己的能力却另外取得了对象形式。一个能使水流转动的装置，既是外在物，也使设计、加工与协作的能力变得可见。其他人可以使用、研究和继续改造它，因此这种确认超出一个人的内心满足。它成为可共同面对、可继续发展的现实活动条件。

由此，产品的丧失何以会成为类对象性的丧失，才有了中间环节。产品若只是工资以外的一份消费品，失去产品似乎只减少消费；但若产品同时包含能力的现实展开，并继续作为后续生产的条件，那么失去对它的支配也就限制了生产者借自己的成果继续展开活动的可能。工人仍能看到产品，仍可能为技艺自豪；这不等于能够决定产品怎样使用、技术怎样发展、下一轮活动按什么目的进行。对象仍显示人的能力，现实的使用和发展却作为另一方的权力面对生产者。这种分离接通了产品异化与类生活异化。

| 同一工具的三个层次 | 所问的问题 | 能回答什么 |
|:--|:--|:--|
| 设想 | 想使工具实现什么用途 | 活动能以自身目的为对象 |
| 实现 | 怎样让材料取得可用形式 | 能力获得现实的对象形式 |
| 继续使用和发展 | 谁能决定用途、改造和后续生产 | 对象化成果如何成为活动条件 |

对象化因此具有积极可能：人在改造对象时发展和认识自身。异化并不取消对象化的发生，而使这种实现所形成的力量转为生产者不能自主支配的条件。若把两者看成同义词，就无法说明为何原文一方面肯定改造对象世界，另一方面批判对象的丧失。若只以个人是否喜欢成品来判断，又会把现实的支配关系缩为自我感受。

动物比较中各项对照也围绕这个推导安排。直接需要与超出直接需要，说的是活动目的能否成为反思和改变的对象；片面与全面，说的是活动对象和方式的范围；按一个种的尺度与把握不同对象的尺度，说的是能否根据对象特性调整构造，而非任意把自己的愿望强加于材料。美的规律在此进一步说明生产不只追求即时可食用的结果。作者用这些对照说明类活动的普遍性；我们解释的是这条论证，不将十九世纪文本直接当作对今日全部动物研究的最终裁判。

原文说人是自然界的一部分，也使“无机的身体”免于成为支配一切自然物的授权。材料、工具和自然知识是人实现能力所依赖的条件，人对它们的活动仍发生在自然之内。所谓人与自然持续交互，也就包含自然的一部分同其他部分的联系。依赖关系提出维护和组织活动条件的问题，不能自行回答产权怎样分配，更不能推出可以无限耗用自然。


::: sol
工具的存在使设计和制作能力取得现实形式，因而生产者可以认识这种能力；用途与改造的决定权则属于另一层现实关系。看见成果不足以取得决定其后续使用的权利。两者的分离说明对象化已经发生，同时其成果仍可能作为异己条件面对生产者。
:::

## 1.1.6 产品属于谁：从人的异化到人与人的关系

如果产品已经不属于制造它的人，产品究竟归谁？这个追问使论证从工人与对象的关系，进入人与人的现实关系。第58页先写人同人相异化是前面几个方面的直接结果，再提出产品和活动到底属于谁的问题。这个顺序避免了把“异己力量”理解成物品自己具有的魔力。

“劳动和劳动产品所归属的那个异己的存在物，劳动为之服务和劳动产品供其享受的那个存在物，只能是人自身。”（《马克思恩格斯选集》第一卷，第59页；一手论述，官方编订文本。）作者此前提到为神建造神庙的例子；即使生产被叙述为奉献给神，现实中组织、支配和享用产品的关系仍须在人之间寻找。这个例子要求解释生产组织，不能据它断言所有宗教活动都有相同的经济制度。

第一步，产品不归工人意味着存在另一种占有关系。这里的“属于他人”不能仅凭产品被卖出就认定：独立生产者也会出售产品，关键要结合生产过程中已经存在的支配关系。第二步，活动不由工人支配，意味着另一主体能够要求他以一定方式活动。第三步，两种关系结合：工人在制造产品时，同时维持了另一主体支配生产和产品的条件。第60页于是说，通过外化劳动，工人还生产出站在劳动之外的人对劳动的关系。

“生产出一种关系”与“凭空创造一个人”不同。资本家可以在某次生产以前就已存在；生产行为把他的角色实现出来，使他继续作为产品占有者和劳动支配者存在。工人也在这一过程中继续依赖取得工作和生活资料。分析因此越过个人善恶，进入双方怎样通过同一生产过程维持各自位置的问题。

这不意味着所有雇员只能认识自己的工资、所有所有者都无法理解劳动者的处境。工人可以读账目、讨论分配、认识关系并采取行动；所有者也可能理解批判、改变管理和待遇。原文第58页谈在既定关系中观察他人的尺度，不足以推出个人永远不能反思这种尺度。否则，作者要求理解并改变关系的实践也将变得不可解释。制度位置带来的倾向，不能写成思维能力的绝对封锁。


常见错误是把关系异化缩成彼此冷漠。两人友善并不能单独证明生产支配关系已改变；两人争吵也不能单独证明异化成立。第59–60页的分析对象始终是产品的占有、活动的支配及这些关系的实现。态度、感受可以成为调查材料，但要解释它们同制度安排的联系。


::: sol
生活待遇和相处方式改善了，生产决定及产品处置的规则依题设保留。不能由友善直接推出关系已经改变，也不能由决定权集中推断工人完全没有认识和反思能力；应继续调查决策与分配的具体机制。
:::


### 同一生产过程中的两种实现方式

产品“离开工人”若只表示物理距离，并不能推出人与人的异化。产品可能暂存在共同仓库，也可能在生产者共同同意后运往远处。第59页所说的相异关系还包含另一主体作为产品主宰的条件。需要追问的是谁有权决定移动和用途、生产者是否能够改变安排，以及另一方怎样凭借这些权利要求生产者继续活动。把空间距离当作异化，会把正常保管、交换与支配关系混为一谈。

同样，“替他人做事”也不足以独立判定劳动的性质。互助生产、共同任务也包含为他人的活动。原文的论证将替他人活动同受支配、不属于自身的条件连接；恰是这一组合使活动成为异化关系。读者若从一句“属于别人”抽出普遍规则，便可能把任何合作都说成异化。合作中能否参与制定目的、能否改变规则以及产品如何支配，需要与活动服务谁一道考察。

不对称性由这些条件形成。工人在生产中实际耗费力量，使产品成为现实；站在劳动之外的人通过占有和支配取得产品的使用条件。生产是同一个过程，在双方却实现为不同位置。一方在交出产品的同时延续自己取得下一次工作的需要，另一方在取得产品的同时延续决定生产的条件。相互依赖因此不等于权利相等，也不等于双方承担的活动与损失相同。

### 关系批判怎样保留人的能动性

若把工人描述为只能看到工资、无法理解关系，说明中便出现矛盾：读者正在学习的理论为何能够被劳动者理解和运用？从制度位置讨论经验形成，可以解释某些问题更直接地进入个人生活，却不能给认知设定永远无法越过的边界。工资争议可以引出产品分配问题，工艺争议可以引出生产决定问题；同一种现实经验也可能经过不同讨论而形成不同认识。

这也说明友善与支配何以可以并存。改善待遇与听取意见可能改变关系的某些方面，不能预先宣布所有改进都无效；与此同时，若最终决定和撤回安排的权利仍集中在另一方，友善本身还不足以证明生产者取得共同支配。分析要给出改变发生在哪一环，并保留尚未改变的条件。这样既不把制度问题缩成品性，也不把具体改革抹成毫无差别的表象。

### 自身关系为何需要人的中介

说活动“不属于自己”，尚须指出这个否定怎样在现实中实现。生产者面对一件工具，工具本身不会签订契约、要求交货或者改变排班；这些要求通过有权决定活动的其他人及其组织程序实现。产品作为异己力量出现，也要经由占有、出售、扣留、配置等实际行动。自身力量变为支配自身的条件，并非只发生在心里；它必须在这些人与人的实践联系中取得现实形式。

第59页用宗教关系再次说明这种中介：对神的奉献也会通过世俗人与僧侣等现实人物的关系表现出来。这个比方帮助辨认中介，不能由此宣布每种宗教都采取同样的生产制度。对当前生产关系，调查应继续追问谁有权命令、凭什么要求交付、怎样执行，以及生产者是否能改变安排。找到这些中介，才说明异己力量怎样发生作用，而不仅是给它起名。

关系也会形成观察的尺度。领取工资的人可能首先按工时、报酬和生活需要判断活动；占有并组织生产的人可能首先按交付、成本和产品用途安排它。这里说明现实位置怎样使不同问题进入日常判断，不是说任何人都只能想到这些问题。劳动者可以由工时争议追到决定权，所有者也可以理解劳动者的批判。承认尺度的现实来源与承认反思尺度的能力，可以同时成立。

::: ex 教学算例 · 工资账目与关系判断 {#ex-mlm.5.6.1}
假设一个作坊有4名雇员，每人月工资均为5000元，工资总额为20000元。这里明确给的是全员同薪，不是中位工资。即使知道工资总额，仍不能直接推出他们的异化程度。

| 已知事项 | 可据此回答 | 仍需调查 |
|:--|:--|:--|
| 全员工资及人数 | 工资总额 | 谁决定生产计划 |
| 产品登记在企业名下 | 形式归属 | 谁决定用途和收益分配 |
| 工人参与工艺讨论 | 有参与渠道 | 讨论是否有约束力 |

工资表提供一种材料，产品和决策规则提供另两种材料。只有把它们连接起来，才能说明劳动者处在怎样的关系中。不能拿利润除人数，便宣布测得每个工人的全部贡献；共同生产中个体贡献的分解还需要额外假设。
:::


::: ex 练习 · 友善与支配 {#ex-mlm.5.6.2}
作坊主人改善食堂，雇员与他相处融洽，生产计划和产品处置仍由他单独决定。哪些方面改变了？哪些材料不足以判断？
:::

## 1.1.7 私有财产：分析的结果与再生产的条件

经济学把私有财产当作已知条件，异化劳动的分析却把它作为结果提出来。这是否循环论证？要回答，需要分别考察研究的出发点、概念分析的结果与关系在现实中的持续实现。

第49–50页批评国民经济学没有解释私有财产的事实，却把待解释的东西当作前提。马克思暂时采用这套前提，以便分析其中劳动的处境；第58–60页由工人的产品与活动归谁支配，提出非工人的占有关系。这说明私有财产不是一个完全外在于劳动的物件，而是特定劳动关系的物质表现。

“因此，私有财产是外化劳动即工人对自然界和对自身的外在关系的产物、结果和必然后果。”（《马克思恩格斯选集》第一卷，第60页；一手论述，官方编订文本。）这里先从既有经济事实形成外化劳动概念，再分析这一概念所包含的人与人的占有关系。论证不能简化为人先有异化的观念，随后发明财产制度；作者讨论的是实践的、现实的关系。

同页承认，从国民经济学得到的外化劳动概念本来表现为私有财产运动的结果，随后又写：“后来，这种关系就变成相互作用的关系。”该页末尾进一步说明私有财产既是外化劳动的产物，又是劳动借以外化的手段。两个方向的关系都有文本根据。不过，据此仍不能直接写出一部私有财产起源史，不能宣布某一朝代或某一次暴力事件就是闭环形成的精确时刻。

::: arg 论证 · 相互作用不等于完成了起源解释 {#arg-mlm.5.7.1}
已经建立的论证是：工人失去产品及活动的支配，包含他人取得支配的关系；已经形成的财产关系，又为这种劳动关系的继续实现提供条件。尚未建立的论证是：人类最初怎样进入这样的劳动关系。第62页明确把后一问题列为任务。因此，用“二者互为因果”直接终止起源问题，会把作者保留的问题掩盖掉。
:::


第60页借宗教观念作类比：神起初是人的理智迷误的结果，后来又参与相互作用。这个比方帮助读者理解“产生的结果转为活动条件”的结构，却不能代替对劳动和财产实际形成过程的研究。类比提供理解方向，研究仍需独立材料。


::: sol
表格描述既有企业关系下资金的一个周期变化，起源问题追问该企业及其财产关系如何形成。前者预设的期初资金、占有规则和雇佣关系，恰是后者需要解释的材料。
:::


### 从产品丧失到占有关系，中间不能省掉什么

从“产品不归我”到“私有财产是结果”之间，原文还有一层人际关系的说明。孤立地否定归属，只能说某个主体没有某种权利，尚未说出权利怎样组织。第58–60页进一步追问产品属于谁、活动为谁服务，把否定性的丧失转为另一方的占有和支配。私有财产因而作为两方面关系的表现出现，而非只是某一堆物品的名称。

这一分析也要求区分偶然失去物件与生产关系。某人的产品被洪水毁坏，产品同样不再供他使用，但洪水没有因此成为非工人的占有位置。若产品转入另一人手中，也仍须调查转入的方式：一次赠与、共同决定的分配和在既定支配下生产并交出产品，并非同一关系。原文选择的对象是工人及其生产在既有国民经济条件下的异化，不是为所有物品转移规定一个共同原因。

### 三种次序怎样相接

第一种是研究者认识对象的次序：暂从经济学接受的事实出发，形成并分析异化劳动概念。第二种是理论分析的次序：由活动和产品的异化，明确其中包含的非工人占有关系。第三种是实际发展的次序：这些关系怎样形成、如何延续、又如何改变。前两种次序帮助确定第三种应研究什么，却不能直接替第三种提供年代与事件。

这解释了为什么第60页能够写私有财产是后果，第62页仍能提出起源问题。若作者已经用一个完整的历史叙述说明劳动怎样异化，后一个任务便无须再列。把“后来”读成一个等待查明的过程标记，比把它读成已知年代更准确。它提示关系的发展，不给出该发展的一切中间环节。

两期资金模型也应放在这个位置理解。模型预设资金由某方支配、工资按既定规则支付、余额由控制者保留。这些条件决定计算能描述哪一种延续；计算本身并不证明条件从何而来。换成共同决定余额用途的规则，同一现金算术仍可能成立，关系含义却会改变。模型让读者看到算术约束与社会规则的区别；起源研究则要继续解释规则怎样产生，不能让余额增加替代它。

### 为什么经济学内部的矛盾还要追到劳动关系

第60–61页接着处理一个矛盾：国民经济学把劳动称为生产的真正灵魂，却把一切给予私有财产。前一句以劳动说明财富形成，后一句在现存占有关系中安排所得。若只把它们并列为作者言行不一，就还没有说明这种矛盾何以能够在同一现实中持续存在。工人实际进行生产，生产成果却进入非工人的占有和支配，这一关系使财富来源与成果控制发生分离。

原文提到蒲鲁东从矛盾中得出有利于劳动、不利于私有财产的结论，随后把表面矛盾还原为异化劳动同自身的矛盾。这里的意思不止是批评一种分配方案：若劳动已经以不属于生产者的活动形式进行，那么仅宣布“财富来自劳动”尚未改变这种活动形式。经济学的分裂表达有现实的关系基础，批判须进入劳动怎样进行及成果如何成为他人支配条件，不能只给财富的来源换一个更公正的赞美对象。

私有财产在最后、最高阶段显露其双重角色，也应沿这一关系理解：劳动不断形成被另一方支配的对象条件，而已有的对象条件又成为继续组织和支配劳动的手段。作者据此说结果同时成为实现外化的条件。这一解释指出应观察何种联系，并没有提供足以把每个历史阶段按年代排列的材料；它使起源与发展研究的问题更具体，不能替代那些研究。

## 1.1.8 工资增加与工资平等为何仍需追问劳动关系

如果工资提高，生活资料能够增加，为什么原文仍说这没有使劳动获得人的身份和尊严？难点在于两种判断使用不同标准：一项措施是否改善生活，与它是否改变劳动的目的和归属，不能互相替代。

第61页写：“强制提高工资……无非是给奴隶以较多工资，而且既不会使工人也不会使劳动获得人的身份和尊严。”（《马克思恩格斯选集》第一卷，第61页；一手论述，官方编订文本，省略插入语。）这个比喻批判的是只变更报酬而保留劳动从属关系的限度，不能把它当作雇佣劳动与法律上的人身奴隶制完全相同的证明，更不能推出争取工资改善毫无价值。


### 工资与私有财产的“同一”指什么

在讨论提高工资以前，第61页先把工资与私有财产联系起来。作者所分析的工资，是以劳动产品、劳动对象来偿付劳动本身的关系：活动为取得报酬而进行，生产者通过这种报酬重新取得生活条件，活动的产品却不由生产者自主处置。因而工资既使劳动者能够继续生活，也在这一关系中表现劳动服从于取得工资的目的。原文所谓劳动是工资的奴仆，批判的是这种目的与手段的安排，并不否认劳动者实际需要生活资料。

“同一”不能读成工资总额等于财产总额，也不能读成每笔工资在法律上都是不正当的占有。它说明的是两种关系表现之间的内在联系：一方作为非工人占有和支配生产条件，另一方以外在的生产活动取得报酬。工资在这种劳动关系中成为异化的结果，劳动的外化又形成私有财产的占有关系。若只将工资数额提高而保留这些条件，数额变动不足以独立证明关系已消失。

原文进一步将一方的衰亡与另一方的衰亡联系起来。这项判断所要求的改变，比取消工资的名称深得多。假如只是把工资改称津贴，而活动的目的、产品处置与生产条件仍按原规则组织，名称变化不能证明关系变化。同样，讨论不同的共同劳动分配方式，也不能只问是否还出现货币支付；应问支付怎样产生、生产者怎样参与决定、活动和成果是否仍作为外在力量面对他们。这个选段提出了检验关系的方向，没有详细制定未来所有分配办法。


::: sol
作者分析两种关系如何在异化劳动中相互联系，并未提出两个会计金额相等的公式。工资与资产的金额来自不同统计口径；比较它们不能代替对活动、报酬与财产支配的关系分析。
:::

随后作者讨论蒲鲁东所要求的工资平等：“这时社会就被理解为抽象的资本家。”（同页。）其论证条件是今天工人对自己劳动的关系被推广成一切人对劳动的关系。平等在这里改变的是劳动者彼此报酬的比较，并未自动回答谁支配劳动、劳动为何进行。故而，分析需要继续追问平等的具体内容。

::: arg 论证 · 报酬相等不决定活动关系 {#arg-mlm.5.8.1}
假设4名劳动者每人领取5000元，合计20000元。相等这个事实只说明四笔金额之间的关系。它同时容许多种决策安排：由一个外在所有者决定，或由劳动者参与制定。仅从四笔金额相等，不能逻辑推出其中任何一种安排。因此，工资平等本身不足以证明生产过程获得共同支配。
:::

| 收入是否提高 | 同口径工资记录 | 所有制名称 |
| 报酬是否相等 | 全员报酬和口径 | 平均工资一个数字 |
| 劳动者能否支配生产 | 规则与实际决策过程 | 四笔相等的工资 |
| 产品如何处置 | 处置程序与权利 | 自行打出的自由度分数 |

这些分析可提出研究现代组织的问题，但本选段没有苏联企业的调查数据，也没有讨论某一20世纪制度的具体机制。本章不能据“抽象的资本家”一句话宣布某国全部企业的性质，更不能称作者已经预见并证明了后来历史。要作那种判断，需要另行搜集治理、分配和劳动者参与的材料。

::: note 阅读边界 {#note-mlm.5.8.1}

:::

它回答四人报酬是否相等，遗漏他们怎样参与决定生产与产品处置。前一事实不能独立证明劳动关系已获得改变。
:::

:::


### “抽象的资本家”这一比方的条件

工资平等的讨论容易被误解为对平等本身的否定。第61页批评的条件更具体：今天工人对自己劳动的关系，被推广为一切人对劳动的关系。若原有关系使劳动只是换取工资的手段，单纯把这种处境平均化，并未使生产者改变活动的目的、内容和结果。平等回答谁拿得一样多，仍需另一套材料回答人以什么方式活动。

“抽象的资本家”因此不是给任何组织都能贴的名称。比方把社会当成与劳动者相对立的统一占有者，以说明原有关系可能在普遍化形式中保留。要将这个比方用于一个实际组织，必须证明相应的生产与支配条件；不能只看到国家所有、集中安排或工资相同，便宣布前提已经全部满足。原文批评提供了调查的提问方式，实证结论尚需组织规则与实际运行材料。

比较反例能够检验推导范围。假设两组劳动者领取相同报酬，一组不能改变工作安排，另一组共同制定并能修订安排；同薪没有抹去二者在决定方式上的差异。再假设同一组劳动者工资提高而决策权不变，收入与决策便发生不同方向的变化。两种比较都表明，不能把一种维度当作其他维度的充分代理。反过来，增加参与也不能自动证明收入或生活资料已经充足。

### 工人解放的普遍性为何仍是一个待论证主张

第61页提出工人解放包含普遍的人的解放，理由在于作者将其他奴役关系看作工人对生产关系的变形和后果。讲解应当呈现这个理由，而非仅把普遍性写作一句口号：若劳动者的活动与产品持续成为他人支配他的条件，那么改变这种关系涉及人的活动条件，而不只是一群人的报酬比较。由此，目标越过了工资数额，进入人与其现实生产能力的关系。

不过，从这一理论方向不能独立推出国家、法律或所有具体支配关系将在何时以何种方式消失。不同形式的关系有各自需要研究的材料。原文对普遍性的表述是一项强主张，教材应使读者看见它依赖什么前提、尚需哪些展开；若把没有出现的未来制度细则补作作者已经证明的结论，就失去精读的边界。工资提高既不等于完成这一解放，也不因此成为应被拒绝的现实改善。

### 从两个因素展开其他范畴，是怎样的研究计划

第61页末至62页初提出，还要借外化劳动与私有财产阐明买卖、竞争、资本、货币等范畴。这使本文的目标超出对工作感受或企业沟通的评论：作者希望说明这些经济范畴怎样表现同一现实关系的不同展开。以买卖为例，可以提出产品为何必须通过交易转入另一人手中、活动为何通过报酬与生活资料相接等问题；这些问题把现象重新接到活动与占有的关系上。

但一个提问方向还没有独立证明全部范畴。由“还要阐明”不能倒推出作者已经在这十五页中完成货币起源、竞争规律或资本运动的详细推导。本章呈现的是论证纲领及它依赖的两个因素；继续精读其他经济学文本时，仍须分别核实每一项的条件与论证。将范畴名词列出后便宣称全部得到解决，反而重复了开头所批评的把抽象公式当解释的做法。

### 两个未决任务与非工人方面的考察

一段理论解释到哪里才应停下来？本选段最后并没有把所有问题解决。第62页列出两个任务，第63页列出考察非工人方面的三条线索，随即结束。把结尾读完整，读者才能看见已经建立的解释与研究计划之间的边界。

这段选文的最后一句是“我们来进一步考察这三种关系”（《马克思恩格斯选集》第一卷，第63页；一手论述，官方编订文本）。它是一项继续考察的预告。选段到此结束，不能据此说作者已经在这些页里完成了全部进一步论证。
:::

第一个任务是从私有财产对真正人的和社会的财产的关系，规定作为异化劳动结果的私有财产的普遍本质。第二个任务则明确追问：“人是怎样使自己的劳动外化、异化的？”（同书第62页。）作者认为，把私有财产起源转为外化劳动与人类发展关系的问题，有助于推进研究。改写问题提供了研究方向，仍须具体说明过程；它不是一份已经列出年代、制度和证据的发生史。

::: def 区分分析结论与待研究问题 {#def-mlm.5.9.1}
分析结论重建目前关系所包含的各方面，例如工人失去产品与非工人取得支配同时存在。待研究问题追问这些关系怎样形成、怎样发展及怎样改变。两者相关，但一种关系在概念上可以分析，不意味着其实际历史已经由概念独立证明。
:::

作者随后回到关系的双方。第62页说明私有财产包含工人与劳动、产品、非工人的关系，也包含非工人与工人及工人产品的关系。前面主要从工人方面分析，现在要考察另一方。第63页的第一条指出，工人的外化活动在非工人方面表现为外化状态；第二条对照工人在生产中实践的态度与非工人理论的态度；第三条指出，非工人把工人对自己所做的不利之事施加于工人，却不把自己对工人所做的不利之事同样施于自身。这些条目提示同一关系的不对称性，不能用“两边都异化”抹平占有和受支配的差别。

第62页对改变提问方式给予很强的评价，认为新的提法本身已经包含问题的解决。这里应保留作者的积极判断：把私有财产起源从一件仿佛在人之外的东西，改问人的劳动怎样外化，确实改变了研究所追踪的对象，使占有关系能够同人的实际活动联系。不过，指出解决所在的关系，与提供全部发生过程的材料仍有区别。正文既要解释这个转换带来什么，也要读到紧随其后的进一步考察，不能用“尚未研究”抹掉作者自认为已经取得的概念成果。

### 非工人的三条规定怎样分别理解

第一条区分外化的活动与外化的状态。劳动者实际付出体力智力、组织自己的动作并交出结果；非工人取得的是由这种活动形成的占有和支配位置。双方并非一方有关系、另一方无关系，差别在于同一关系在一方作为正在进行的活动实现，在另一方作为可以据以支配活动及产品的处境实现。说双方都处于外化关系，并不把双方的实践位置拉平。

第二条区分生产中的实践态度与非工人方面的理论态度。这里的“理论”不表示非工人知识更高，也不等于他必定从事学术研究。工人直接以自己的活动同材料和产品发生关系；站在劳动之外的人不以同样的直接生产活动接近对象，而从与这种活动分离的位置对待劳动和产品。原文在此只列考察线索，没有继续说明所有中间机制；教材可以解释它所做的对照，不能补写成作者已经给出一套企业管理知识分类。

第三条明确不对称：工人在既定条件下把自身活动与产品置于他人支配，非工人则将这种不利条件施于工人，却不对自身实行同样的丧失。一个生产者无权决定产品用途，与一个占有者有权决定用途，是相接的两面，不能由两者都参与同一关系便说他们都失去同一种权力。因此，关系的普遍性与后果的非对称需要同时保留；这也是从工人方面转向非工人方面考察的实际意义。


::: sol
不能。生产者交出支配，另一方取得支配，正是这两种不同位置使同一关系现实成立。“共同处于”说明关系的相互关联，“同样受损”则是另一个需要证明而在题设中不成立的判断。
:::

::: arg 同一关系的双方不等于同样处境 {#arg-mlm.5.9.1}
若一方活动受另一方支配，双方共同存在于同一关系中，却有不同的实践位置。一方执行生产、交出产品，另一方占有并支配。由此可以说关系需要双方才能实现，不能说双方因此承受完全相同的损失、享有同样的权力。所谓关系分析，恰好要求保留这些差别。
:::

::: note 教学图式的限度 {#note-mlm.5.9.1}
把工人、非工人两个角色与劳动、产品、对方三个对象交叉，可得到六个考察格，可按两行、三列检查。这是整理材料的表格，不是原著提出的量化指标，也不表示六种关系彼此独立。
:::

| 角色 | 对劳动的关系 | 对产品的关系 | 对另一角色的关系 |
|:--|:--|:--|:--|
| 工人方面 | 实际进行活动 | 生产对象并失去支配 | 活动服务于他人 |
| 非工人方面 | 取得支配位置 | 取得占有位置 | 以既定关系支配劳动者 |

这个表格帮助读者重新排列第58–63页的论证。每一格都要回到材料说明，而不能用“资本家邪恶”“工人愚昧”这样的性格词充填。它也不支持给两种理论各打零分、满分，或宣称脚本证实了一种哲学理论优越。脚本核对的是计数和算术；理论解释是否充分，要看概念区分、论证和实际证据。

常见错误是用后一年的《关于费尔巴哈的提纲》第六条，直接替换1844年这一选段中的类存在论述。两段材料可以比较，比较时须交代年代、篇目和不同的提问。这里读的是1844年选段的结尾；本章保留它对私有财产的两个任务，以及转向非工人方面的未完考察，不把1845年的表述冒充其原句。


::: sol

:::


::: sol
可调查生产计划及工艺变更的决定程序，说明谁能改变活动内容；也可调查产品收益处置与再投入规则，说明谁能支配生产结果。这两种材料同工资记录结合，才能具体说明关系怎样实现。
:::

::: ex 教学算例 · 两个问题分别判断 {#ex-mlm.5.8.1}
设一人月工资由4000元提高至5000元，其他条件依题设保持不变。增幅为25%。如果生产目的、工作安排和产品处置规则保持不变，我们能判断工资收入提高，不能仅据收入变化宣布这些规则也改变。

| 比较事项 | 提高前 | 提高后 |
|:--|:--|:--|
| 工资（元/月） | 4000 | 5000 |
| 工资增幅 | — | 25% |
| 决策和产品规则 | 既定规则 | 题设保持 |
| 实际购买力 | 还需价格资料 | 还需价格资料 |

脚本能够核算25%，无法替人核定尊严和自由。若价格变化尚未交代，甚至购买力改善也不能由名义工资独立算出。
:::
