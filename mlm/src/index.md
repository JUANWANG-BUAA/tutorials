## 这本书要解决什么问题

学马克思主义最常见的失败，不是读不懂某句话，而是**读完之后不会用**。你会背「经济基础决定上层建筑」，但遇到一个具体的制度变迁，说不出到底哪一部分是基础、哪一部分是上层建筑、决定关系又凭什么成立。你知道「剩余价值」四个字，但拿到一份工资单和一张财务报表，算不出剩余价值率，也说不清它为什么必然伴随着周期性的危机。

原因通常不在智力，而在材料的组织方式。市面上的读物大致两类：一类是语录汇编，把结论抽出来排列，读者得到的是立场而不是方法；另一类是教科书式的原理罗列，每条原理配一段「意义」，读者得到的是考点而不是推理。两类都跳过了同一件事——**这些结论是怎么被论证出来的，它们的证据在哪里，它们的边界在哪里**。

这本书试图补上这一环。它的组织原则不是「谁说了什么」，而是「一个问题如何被提出、被什么证据推进、被哪些反驳修正、最后剩下什么仍然成立」。马克思、恩格斯、卢森堡、列宁、毛泽东、阿尔都塞在这个叙述里不是并列的六位作者，而是同一条论证链条上的不同环节。他们之间的分歧被保留下来，因为那些分歧本身就是理论的内容。

## 全书的结构

**前半部是纯粹理论。** 第一篇处理历史唯物主义与辩证法：社会存在如何决定意识，生产力与生产关系如何构成社会形态，经济基础与上层建筑的关系为什么不是建筑比喻的字面意思，辩证法的三条规律各自的适用范围，矛盾的特殊性为什么在方法论上比普遍性更重要。第二篇处理政治经济学批判：从商品的二重性出发，经价值形式、货币、剩余价值、积累、循环周转、再生产图式，到利润率下降、信用与地租。第三篇处理国家与革命：国家的起源、国家机器的两副面孔、打碎国家机器的必要性、无产阶级专政的内容与限度、民族问题、过渡时期。

**后半部是实践发展。** 第四篇讲工人运动本身的历史：第一国际的成立与分裂、巴黎公社的七十二天、第二国际从黄金时代到 1914 年的破产、俄国革命、围绕一国社会主义与不断革命的争论、共产国际与殖民地革命。第五篇讲中国革命：半殖民地半封建的判定、新民主主义的两步走、农村包围城市、人民民主专政、社会主义改造、两类矛盾学说、无产阶级专政下继续革命的理论、文化大革命的政治经济学与阶级分析，以及它的失败与理论遗产。

第六篇回到当代，并给出方法训练：平台与数据、社会主义与市场经济、阶级分析的当代用法、如何写一篇马克思主义的分析。

## 每一章的样子

每章开头有一个提要，说明**本章回答什么问题**、**读完能做什么**。正文里穿插六类语义盒子：

| 盒子 | 用途 |
|:--|:--|
| 定义 | 给概念下可操作的界定，而不是口号 |
| 论证 | 把推理拆成编号的前提与结论，便于检查 |
| 史料 | 引原文、数据、页码，便于回查 |
| 论战 | 呈现理论内部的分歧，不预设结论 |
| 直觉 | 用类比建立第一印象，并说明类比的失效处 |
| 勘误 | 列出常见误读及其来源 |

章末有「本章要点」，用五到八条把论证链收紧。

## 关于引文

所有引文都标明版本与页码，页码是**印刷页码**，不是 PDF 页码。本书主要使用的底本是：

- 《马克思恩格斯选集》第 1—4 卷，人民出版社（四卷本，书内页码）；
- 《马克思恩格斯文集》第 5—7 卷（《资本论》三卷），人民出版社；
- 《毛泽东选集》第 1—5 卷合订本与第 6、7 卷（润之赤旗版）；
- 罗莎·卢森堡《全集》第一卷；
- 路易·阿尔都塞《论再生产》，吴子枫译，西北大学出版社 2019 年版；
- 布哈林、普列奥布拉任斯基《共产主义ABC》，三联书店 1982 年版；
- 《文革史》（水陆洲）与《「四人帮」选集》（内部资料）。

其中第 6、7 卷毛选与《「四人帮」选集》是民间编纂或内部资料，版本可靠性低于人民出版社正式出版物。本书使用它们时会在「史料」盒里注明这一点：**引用它们是为了呈现当时的文本面貌，不是把它们当作权威版本**。凡涉及事实判断，尽量与正式出版物或档案性材料交叉。

## 怎么读

侧栏编号是**全书章号**（第 5、6、7、8…章）。正文小节里偶见 **1.1.x / 1.2.x / 1.3.x / 1.4.x**，那是第一篇的**逻辑编号**（SOURCE-MAP），与章号对照如下：

| 逻辑 | 全书章 | 主题 |
|:--|:--|:--|
| 1.1 | 第 5 章 | 异化劳动与人的本质 |
| 1.2 | 第 6 章 | 提纲与德意志意识形态 |
| 1.3 | 第 7 章 | 社会存在与社会意识 |
| 1.4 | 第 8 章 | 生产力与生产关系 |

如果按顺序读，先读卷首第 1—4 章（怎么读、方法论、文献学、路线），再进第一篇第 5—8 章打牢唯物史观；第 9 章起处理上层建筑比喻与辩证法。跳过第 7—8 章的条件与证据纪律，直接读历史部分，很容易把历史唯物主义读成口号或宿命论。

如果只想解决一个具体问题，可以走三条支线（章号以侧栏为准）：

- **想理解剥削怎么算**：第二篇第 26 → 30 → 31 → 33 → 35 → 36 章（商品、货币转化为资本、劳动过程、绝对/相对剩余价值、机器），配合书中公式与验算；
- **想理解国家与革命**：第三篇第 58 → 60 → 61 → 64 章，再读第四篇俄国革命相关章；
- **想理解中国**：第五篇中国革命各章（侧栏「第五篇」下）。

每章都可以单独读，但概念是逐层定义的，第一次出现的术语会给出锚点，后文用交叉引用指向它。
