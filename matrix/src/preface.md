# 先读这一页：怎样学，而不是怎样翻

这不是一本要求你从第一页顺序背到最后一页的「定义词典」。第一章真正要建立的是一条连续的推理链：**什么对象允许做线性运算 → 哪些部分仍保持线性 → 怎样用基压缩信息 → 怎样加入几何 → 怎样把向量唯一拆开。**定义是工具的使用说明，不是学习的终点。

第二章换了问题：第一章在一个空间**内部**做文章，第二章要把两个空间**连起来**——先备好映射的语言（[2.1](ch02/sec21.md)），再要求映射与线性运算相容（[2.2](ch02/sec22.md)），取定基把抽象映射落地成矩阵（[2.3](ch02/sec23.md)），再问「能不能挑一组基让矩阵最简单」——这引出特征值与特征向量（[2.4](ch02/sec24.md)），以及在保持度量不变的基变换下的正交、酉变换（[2.5](ch02/sec25.md)）。链条是：**映射 → 线性映射 → 矩阵 → 特征值 → 正交 / 酉变换**。读第二章前请先确认第一章的「基与坐标」（[1.3](ch01/sec13.md)）是真的懂了——2.3 通篇建立在那上面。

## 每个概念只问六个问题

读定义、定理和例题时，不要抄写原句。试着回答：

1. **它为了解决什么问题？**没有这个概念时，哪件事说不清？
2. **最小例子是什么？**尽量从一维、二维或 $2\times2$ 矩阵开始。
3. **最接近的反例是什么？**只破坏一个条件，看结论怎样失败。
4. **判定时先检查什么？**例如子空间先看零向量，内积先看 Hermite 再看正定。
5. **它与前后概念怎样连接？**例如「基」把线性表示变成唯一坐标，「直和」把和空间的表示变成唯一分解。
6. **我能否不用原句讲给别人？**能说清楚，才算从「识字」走到「理解」。

::: method 三遍阅读法

1. **第一遍只抓主线。**读每节开头的「先抓住一件事」、图和小结，先知道这一节为什么存在。
2. **第二遍攻克机制。**逐个读定义、证明和例题；每遇到公式，都说清「输入是什么、输出是什么、前提是什么」。
3. **第三遍闭卷输出。**做节末即时自测，再到[习题集](ch01/exercises.md)按「每节最小练习包」练。不会的地方只回看对应小节，不从头机械重读。

:::

## 怎样读证明

证明不是需要背诵的算式。先在纸上写出「已知」和「要证」，再给每一步标注它的作用：**使用定义、构造对象、套用定理、排除反例、完成存在性、完成唯一性**。如果某一行只能解释成「显然」，就追问它依赖哪条定义或恒等式。正文给出完整证明，是为了呈现论证结构，而不是增加背诵量。

如果你一离开答案就不知道第一行写什么，先用[证明怎么下笔：六种骨架](proof-workshop.md)练「只搭结构、不做细算」；写正文里的证明时，也先按这套骨架预测路线，再逐行补足细节。

## 怎样让定义和定理留在脑中

「看懂」只说明答案在眼前时能识别，不等于考试时能从空白纸上提取。复习体系分三层，各管一段：

1. **压缩**：先看[速查背记卡](memory-sheet.md)——它把每个定义、定理压成一句最小可背诵单元；背不下来时回正文核对。
2. **检索**：每学完一节，合上正文做[闭卷回忆卡](ch01/recall-cards.md)（[第一章](ch01/recall-cards.md) / [第二章](ch02/recall-cards.md) / [第三章](ch03/recall-cards.md)各一套）：先写定义的关键词、定理的前提与结论、证明的第一行，再展开核对。复习节奏见各页开头（当天 / 1 / 3 / 7 天，只重做标成 △ 和 × 的卡）；想做成 Anki 卡组见速查卡文末。
3. **应用**：做题与考前翻[解题工具箱](toolbox.md)——题型流程卡、二级结论（附前提与出处）、反例弹药、验算清单；第三章另把考试特化训练集中在[考场竞技场](ch03/arena.md)。
