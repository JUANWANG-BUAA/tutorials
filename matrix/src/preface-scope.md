# 范围声明与使用方法

本教程由第一章六节（七份）课件、**第二章的 2.1–2.5** 与**第三章的 3.1–3.2** 整理而成（2.1–2.2 另有第 3 周录播 2026-09-22 对照；2.3 只有官方课件，存于 `raw/decks/`；2.4–2.5 只有第 5 周录播 2026-10-08 的转录，课件尚未入库；3.1–3.2 只有官方课件 `3.1-相抵分解.pdf`、`3.2-满秩分解.pdf`，**均无录播**）。原课件提纲挈领但过于简略：部分定理只述不证、部分计算存在笔误、例题之间缺少衔接。本教程在不越出课程范围的前提下做三类工作：

| 做法 | 说明 |
|:--:|:--|
| **不丢内容** | 第一章七份课件、第二章 2.1–2.3 课件与第三章 3.1–3.2 课件的每一条定义、引理、定理、命题、注记、例题与思考题全部收录（2.4–2.5 依录播转录整理，暂无课件可对照，盒子自动编号），**保留原编号**（如「[@def-1.1.5]」「[@ex-1.4.6]」「[@def-2.1.11]」「[@thm-2.3.6]」「[@lem-3.1.1]」「[@thm-3.2.2]」），可与课件逐条对照。 |
| **补全与勘误** | 课件中省略的证明全部补出（如子空间判定定理、维数公式、正定 Hermite 矩阵与内积的等价性、三角不等式、正交分解定理、**逆映射唯一性、可逆 ⟺ 双射、单射判据、亏加秩定理**；2.3 的**存在唯一性、同构的充分性、矩阵与映射的不变量等式**；3.1–3.2 的**引理 3.1.1 存在性、左逆必要性、解方程组的结构、满秩分解中 $\operatorname{rank}C=r$、定理 3.2.2 与 $AXA=A\iff CXB=I_r$**）；第一章十五处公式、表述或概念边界问题已修正，详见[第一章勘误表](ch01/errata.md)；第二章课件留白、笔误与口述转写问题见[第二章勘误](ch02/errata.md)；第三章四条课件勘误（E3.1–E3.4：记号循环、次序不一致、「充分条件」实为充要条件）见[第三章勘误](ch03/errata.md)。 |
| **扩充例题与习题** | 新增例题以「[@ex-1.1.A] / [@ex-2.3.A]」等字母编号与原题区分；习题分 A（概念判断）、B（推理证明）、C（计算）三组，**全部附解答**（默认折叠，点击展开）。所有新题只使用本课程讲过的概念，不引入后续章节内容。 |

凡属**后续课程**才会严格证明的事实（如 Cayley–Hamilton 定理、正交投影与谱分解、相似对角化的完整判据），本教程只在必要的衔接处以「课程预告」虚线框或正文提示标注结论，不作展开——这是为了回答课件中明确提出的思考题，而不是增加新内容。**例外**：第二章的亏加秩定理（维数公式）课上只证了一半，本编按课堂的基扩充路线**补完**并明确标注「课堂证到一半、此处补完」，以便读者提前对照（[2.2.5](ch02/sec22.md#sec-2.2.5)）；2.3 的课件证明虽有省略与笔误，但均属本课程范围内，本编**直接补全并逐处标注**，不作预告处理。
