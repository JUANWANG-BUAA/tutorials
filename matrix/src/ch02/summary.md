## 一条主线

> **第一章给单个空间装上坐标（基与维数）；第二章把两个空间连起来。** 先备好映射的语言（2.1），再要求与线性运算相容（2.2）。线性映射的两个不变量——零空间与值域——由亏加秩定理定量：「$n$ 个自由度 $=$ $m$ 个被压死 $+$ $(n-m)$ 个传下去」。取定基之后，抽象映射落地为矩阵，而且这个对应是**一一对应且保持运算**（$L(V,W)\cong F^{m\times n}$，2.3）——于是抽象问题化为矩阵计算，而「换一组基」变成了「换一个相似 / 相抵的矩阵」。「挑一组让矩阵最简单的基」正是后面特征值理论的方向。

## 四句话带走

1. **线性映射 = 先算后映 = 先映后算**：可加性 + 齐次性，两条缺一不可；它必须保持原点不动，所以平移一般不是线性变换。
2. **单射判据是本章的枢纽**：$T$ 单射 ⟺ $N(T)=\{\boldsymbol{\theta}\}$ ⟺ 把无关组映成无关组；而「像相关 ⟹ 原相关」永远只有**单向**成立。
3. **亏加秩定理是维数守恒**：$\dim N(T)+\dim R(T)=\dim V$ 的证明用基扩充——「证维数、构造基，一定要用扩充的方式」（01:27:22 老师原话）。
4. **矩阵是映射的坐标版**：$A$ 的第 $j$ 列是 $T(\varepsilon_j)$ 的坐标——这句话既是**写**矩阵的算法，也是**读**矩阵的钥匙；它让 2.2 的一切（亏加秩、秩、零空间）原封不动搬到矩阵上（[@thm-2.3.6]）。

## 学完之后

按下面的顺序收尾：**先回忆、再自测、后反查、最后串一遍**。

1. **[闭卷回忆卡](recall-cards.md)**：先确认 12 张定义卡与 13 张定理卡能从空白纸上叫出来（定义关键词、定理前提与结论、证明第一行）。
2. **[综合自测卷](mock-exam.md)**：闭卷计时 90 分钟、100 分制，覆盖 2.1–2.5。不看分数，看**每道错题卡在哪一步**。
3. **[学习目标自检表](checklist.md)**：把失分点对到 K / S / A 目标，回到正文对应小节重读该节的「即时自测」。
4. **[习题集](exercises.md)**：只重做做过记号的题；B 组的证明题看自己能否**写出结构完整、每步有依据**的证明。
5. **[勘误与补注](errata.md)**：把「常见错误」逐条读一遍——能自己说清「正交矩阵特征值必为 $\pm1$」错在哪一步、复内积从第二变元提公因子为什么要取共轭，就算过关。
6. **[解题工具箱](../toolbox.md)**：把本章的流程卡（单侧逆、GS / 投影、特征值与对角化）与二级结论（单射判据、相似不变量、谱映射）过一遍，做几道题让流程上手。
7. **[第二章总览](overview.md)**：最后用一节一句话把「映射 → 线性映射 → 矩阵 → 特征值 → 正交 / 酉」串成一条线，能自己复述即算过关。
