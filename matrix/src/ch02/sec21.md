## 2.1.1 映射：术语与运算

「两个集合之间有对应」这句话要能检验，得先把它抽象成一个明确的对象——映射。一个映射由定义域、值域与对应法则三样东西共同确定，本节后面的每个概念，都在这三样之上做文章。

::: def 定义 2.1.1 · 映射 {#def-2.1.1}

设 $V,W$ 是**两个非空集合**。若存在 $V$ 到 $W$ 的对应法则 $f$，使得 $V$ 中每一个元素 $x$ 都有 $W$ 中一个**唯一确定**的元素 $y=f(x)$ 与之对应，则称 $f$ 是 $V$ 到 $W$ 的**映射**，记 $f:V\to W$。集合 $V$ 称为映射 $f$ 的**定义域**。

$y$ 称 $x$ 在 $f$ 下的**像**，$x$ 称 $y$ 的**原像**；当 $V$ 中元素改变时，$x$ 在 $f$ 下的像的**全体**作为 $W$ 的一个子集，称为 $f$ 的**值域**，记 $R(f)$。
:::

::: think 三个易错点（老师逐条强调，00:08:46–00:11:00）

1. **「唯一确定」是方向敏感的**：每个 $x$ 对**一个** $y$；反过来不要求——一个 $y$ 可以有多个原像；
2. **值域 $R(f)\subseteq W$，不必等于 $W$**：$R(f)=W$ 是额外的性质（满射）；
3. **定义域必须是整个 $V$**：不是「$V$ 的一部分能映」就行——所以判一个法则是不是映射，先问「是不是对每个 $x$ 都有像、像是否唯一」。
:::


映射的品质取决于三件事：不同的元素是否始终映到不同的像（单射）、值域能不能盖满整个 $W$（满射）、两者是否同时成立（双射）。这三个词在后续章节出现频率极高，定义的方向值得先看清楚。

::: def 定义 2.1.2 · 单射、满射与双射 {#def-2.1.2}

设 $V$ 和 $W$ 是两个非空集合，$f$ 是 $V$ 到 $W$ 的一个映射。

- 若对任意 $x_1,x_2\in V$，当 $x_1\neq x_2$ 时有 $f(x_1)\neq f(x_2)$，则称 $f$ 是 $V$ 到 $W$ 的**单映射**（简称**单射**）；
- 若对任意 $y\in W$ 都有一个元素 $x\in V$ 使得 $f(x)=y$（即 $R(f)=W$），则称 $f$ 是 $V$ 到 $W$ 的**满映射**（简称**满射**）；
- 若映射 $f$ 既是单射又是满射，则称 $f$ 是 $V$ 到 $W$ 的**一一映射**或**双射**（简称**双射**）。
:::


分清这三种性质之后，下一个问题是：两个映射在什么情况下算「同一个」？这个问题不先定下来，后面的复合与逆就无从谈唯一。

::: def 定义 2.1.3 · 映射相等 {#def-2.1.3}

设 $f_1$ 是集合 $V_1$ 到集合 $W_1$ 的一个映射，$f_2$ 是集合 $V_2$ 到集合 $W_2$ 的一个映射。若 $V_1=V_2$、$W_1=W_2$，**并且**对任意 $x\in V_1$ 有 $f_1(x)=f_2(x)$，则称映射 $f_1$ 和 $f_2$ **相等**，记为 $f_1=f_2$。
:::

相等定下来，映射之间就能谈运算了：只要第一个映射的终点恰好是第二个映射的起点，两个映射就可以首尾相接，接成一个新的映射。

::: def 定义 2.1.4 · 映射乘积（复合映射）{#def-2.1.4}

设 $V_1,V_2$ 和 $V_3$ 是三个非空集合，并设 $f_1$ 是 $V_1$ 到 $V_2$ 的一个映射，$f_2$ 是 $V_2$ 到 $V_3$ 的一个映射。由 $f_1$ 和 $f_2$ 确定的 $V_1$ 到 $V_3$ 的映射 $f_3:x\mapsto f_2(f_1(x))$，$x\in V_1$，称为映射 $f_1$ 和 $f_2$ 的**乘积**（又称**复合映射**），记为 $f_3=f_2\cdot f_1$，或简写为 $f_3=f_2f_1$。
:::

**顺序**（00:13:02 老师专门强调）：$f_2f_1$ 是**先作用 $f_1$、再作用 $f_2$**——「顺序不要写反。」


复合把两个映射接成一条链，但这条链只能单向走——作用之后还能不能原路返回？这就是逆映射要回答的问题。

::: def 定义 2.1.5 · 可逆映射 {#def-2.1.5}

设有映射 $f_1:V\to W$，若存在映射 $f_2:W\to V$ 使得

$$f_2\cdot f_1=I_V,\qquad f_1\cdot f_2=I_W$$

式中 $I_V:x\mapsto x$（$x\in V$）为 $V$ 上的**恒等映射**，$I_W$ 是 $W$ 上的恒等映射。则称 $f_2$ 为 $f_1$ 的**逆映射**，记为 $f_1^{-1}$；若映射 $f_1$ 有逆映射，则称 $f_1$ 为**可逆映射**。
:::

::: think 「$I_V$ 与 $I_W$ 不是同一个映射」（00:13:54）

$I_V:V\to V$ 与 $I_W:W\to W$ 都把元素映到自身，但**定义域不同**——按 [@def-2.1.3]，映射相等要求定义域一致，故 $I_V\neq I_W$。这类「看着一样、其实差在定义域」的例子是判断映射相等时最容易失分的地方。
:::

::: thm 定理 2.1.1 · 逆映射唯一 {#thm-2.1.1}

设映射 $f:V\to W$ 是可逆的，则 $f$ 的逆映射 $f^{-1}$ 是**唯一**的。
:::

::: proof 证明（课堂给出结论，此处补全）

设 $g_1,g_2$ 都是 $f$ 的逆。则

$$g_1=g_1\cdot I_W=g_1\cdot(f\cdot g_2)=(g_1\cdot f)\cdot g_2=I_V\cdot g_2=g_2$$

（用了复合的结合律与恒等映射的性质）。故逆映射唯一。∎
:::


::: thm 定理 2.1.2 · 可逆的判别 {#thm-2.1.2}

设映射 $f:V\to W$ 可逆的**充分必要条件**是 $f$ 是**双射**。此时还有复合的逆序公式：对可复合的 $f_1,f_2$，

$$(f_2\cdot f_1)^{-1}=f_1^{-1}\cdot f_2^{-1}.$$
:::

::: proof 证明（四条，课堂上给了大意，此处补全）

**单射 + 满射 ⟹ 逆存在**：定义 $g:W\to V$ 为「取原像」——由单射，原像唯一，故 $g$ 是良定义的映射；由满射，每个 $y\in W$ 都有原像，$g$ 的定义域是整个 $W$。于是 $g(f(x))=x$、$f(g(y))=y$，$g=f^{-1}$。

**逆存在 ⟹ 单射**：若 $f(x_1)=f(x_2)$，两边作用 $f^{-1}$ 得 $x_1=x_2$。

**逆存在 ⟹ 满射**：$\forall y\in W$，取 $x=f^{-1}(y)$，则 $f(x)=y$，故 $R(f)=W$。

**逆序公式**：记 $h=f_1^{-1}\cdot f_2^{-1}$（注意定义域衔接）。则

$$h\cdot(f_2\cdot f_1)=f_1^{-1}\cdot(f_2^{-1}\cdot f_2)\cdot f_1=f_1^{-1}\cdot I\cdot f_1=I_V,$$

同理 $(f_2\cdot f_1)\cdot h=I$。由 [@thm-2.1.1] 的唯一性得 $(f_2\cdot f_1)^{-1}=f_1^{-1}\cdot f_2^{-1}$。**顺序颠倒的直觉**：脱衣服要「先穿的后脱」。∎
:::

映射的语言到这里已经齐备：相等让「两个映射是同一个」这种说法有依据，复合把映射串起来，可逆则回答了「何时能撤销」。最后把出现得最多的一类映射单独命名——定义域与值域是同一个集合的映射。

::: def 定义 2.1.6 · 变换 {#def-2.1.6}

设 $V$ 是一个非空集合，$V$ 到**自身**的映射称为 $V$ 的**变换**；$V$ 到自身的双射称为 $V$ 的**一一变换**；若 $V$ 是有限集，$V$ 的一一变换称为 $V$ 的**置换**。
:::


::: think 「这个考试考过」（00:15:49）

老师原话：「变换这个概念之前好像还没介绍过，而且**考试考过**。」要点有三：① 「变换」= 定义域与值域**同一个**集合的特殊映射；② 「一一变换」= 变换 + 双射；③ 有限集的一一变换另有名字「**置换**」。后面「线性变换」（$W=V$ 的线性映射，[@def-2.2.1]）是本章第一个重点，判题时先看**是不是 $V\to V$**。
:::

### 2.1.1′ 应用：无穷集合的「大小」

定理 2.1.2 让双射与可逆画上了等号；双射还有第二个用处——它让「两个集合一样多」这句话对无穷集合也有了意义。「映射有一个**非常重要的作用**，就是判断两个无穷集合的大小」（00:16:10）。无穷集合不能靠「数个数」比大小（「无穷减无穷」没有意义），正确做法是**构造双射**。

::: def 定义 · 等势 {#def-2.1.A}

若存在双射 $f:A\to B$，则称 $A$ 与 $B$ **等势**（equipotent），记 $A\sim B$——即「两个集合的元素一样多」。
:::


::: ex 例 2.1.A（课件原文）· $\mathbb N\sim\mathbb Z$：给双射一个公式 {#ex-2.1.A}

定义函数 $f:\mathbb N\to\mathbb Z$ 如下：

$$f(n)=\begin{cases}\dfrac{n}{2}, & n\ \text{为偶数},\\[4pt] -\dfrac{n+1}{2}, & n\ \text{为奇数}.\end{cases}$$

课件逐项算出：$f(0)=0,\ f(1)=-1,\ f(2)=1,\ f(3)=-2,\ f(4)=2,\ f(5)=-3,\ f(6)=3,\dots$——恰把 $\mathbb Z$ 铺满：$0\leftrightarrow 0,\ 1\leftrightarrow-1,\ 2\leftrightarrow 1,\ 3\leftrightarrow-2,\ 4\leftrightarrow 2,\dots$，于是「自然数和整数之间建立了一一对应」。板书（19:35、23:44）用竖写的两短横 $\parallel$ 记这件事：$\mathbb N\parallel\mathbb Z\parallel\mathbb Q$。

$\mathbb N\sim\mathbb Z$ 的冲击：$\mathbb Z\supsetneq\mathbb N$（真子集），元素个数却相等——**「部分小于整体」在无穷集合上失效**，这正是不能用数数法比大小的原因。
:::

::: ex 例 2.1.B（新增）· 有理数可数 {#ex-2.1.B}

$\mathbb N\sim\mathbb Q$：把正有理数按「分子分母之和」分组排成方阵（$1/1$；$2/1,1/2$；$3/1,2/2,1/3$；……），按 $i+j$ 为常数分组、逐条斜着读（**对角线列举法**），跳过可约分数即可得到 $\mathbb N$ 到正有理数的双射；负数与 $0$ 再按 [@ex-2.1.A] 的交替法插入。结论：「前三个集合 $\mathbb N,\mathbb Z,\mathbb Q$ 的元素个数相等」（板书 23:44 与口述 00:19:44–00:20:12）。
:::

::: note 实数不可数（课件注「课后自行了解」，00:20:44–00:21:08）

老师课堂原话是「实数的元素个数多于有理数，因为实数里还包括无理数」——**这句话作为理由是不成立的**，恰好踩了本小节刚强调的坑：「包含关系」在无穷集合上**不**蕴含「元素更多」（回忆 $\mathbb Z\supsetneq\mathbb N$ 却 $\mathbb Z\sim\mathbb N$）。正确的理由需要**康托对角线法**：假设 $[0,1)$ 中全体实数可数，把它们逐个列出并写成小数展开 $x_i=0.x_{i1}x_{i2}x_{i3}\cdots$，再构造一个新数 $y=0.y_1y_2y_3\cdots$，其中 $y_i$ 与 $x_{ii}$ 不同，则 $y$ 与每个 $x_i$ 都不相等（第 $i$ 位就不同），矛盾。

**一个容易漏掉的补丁：**十进小数表示不唯一（$0.4999\cdots=0.5$），若构造时任取数字，可能恰好撞上同一个数的另一种写法而使论证失效。标准做法是**每位只从两个数字里挑**，例如规定「$x_{ii}\neq1$ 时取 $y_i=1$，否则取 $y_i=2$」——这样 $y$ 的展开既不会以全 $9$ 结尾，也就不会与任何 $x_i$ 的另一种表示重合。

**康托对角线法当堂未讲，留作课后自学**——这条留白是本节的钩子，不是考点。但请记住：**结论对，理由不能照抄课堂那句话**。
:::

## 2.1.2 多项式：带余除法与四个将来要用的对象

映射的预备到此完成，接下来补上第二件：多项式。在第一章里，多项式只是线性空间的一个例子（$P_n(x)$）；从本章起它要换个身份，当工具去刻画矩阵。

「这些都是我们以前学过的，不再细讲证明」（00:21:13），本节按课件要点清点工具箱。

::: def 定义 2.1.7 · 一元多项式 {#def-2.1.7}

设 $F$ 是数域，$n$ 是自然数，$\lambda$ 是一个文字（或符号），形式表达式

$$g(\lambda)=a_n\lambda^n+a_{n-1}\lambda^{n-1}+\cdots+a_1\lambda+a_0$$

其中 $a_i\in F$（$i=0,1,\cdots,n$），称为数域 $F$ 上的**一元多项式**。如果 $a_n\neq0$，则称 $a_n\lambda^n$ 为多项式的**首项**，$n$ 称为 $g(\lambda)$ 的**次数**，记为 $\deg(g(\lambda))=n$，$a_n$ 称为 $g(\lambda)$ 的首项系数。若 $a_n=1$，则称 $g(\lambda)$ 为**首 1 多项式**（首一多项式）。

**零多项式是唯一的例外。**所有系数全为 $0$ 的多项式 $g(\lambda)=0$ 称为**零多项式**，它**不定义次数**（也不谈首项与首项系数、不谈首一）——因为上面每一条都要求某个 $a_n\neq0$。这个例外不是吹毛求疵：[定理 2.1.3](#thm-2.1.3) 里余式 $q(\lambda)=0$ 是常见情形，友矩阵（[定义 2.1.11](#def-2.1.11)）的「首一」要求也只在非零多项式上才有意义。为便于陈述，下文凡写 $\deg g$ 都默认 $g\neq0$。
:::


工具箱的第一件是带余除法。它把「除不尽」的情形也纳入一套确定的算式，并强制余式的次数严格低于除式——后面反复要用的，正是这个「次数下降」。

::: thm 定理 2.1.3 · 带余除法 {#thm-2.1.3}

设 $g(\lambda)$ 和 $h(\lambda)$ 是数域 $F$ 上的多项式且 $h(\lambda)\neq0$，则存在**唯一**的多项式 $p(\lambda)$ 和 $q(\lambda)$ 使得

$$g(\lambda)=p(\lambda)h(\lambda)+q(\lambda),$$

式中 $q(\lambda)=0$ 或 $\deg(q(\lambda))<\deg(h(\lambda))$。
:::

余式为零是带余除法中一个特别干净的情形，值得单独命名。

::: def 定义 2.1.8 · 多项式整除 {#def-2.1.8}

设 $g(\lambda)$ 和 $h(\lambda)$ 是数域 $F$ 上的多项式，如果存在多项式 $p(\lambda)$ 使得 $g(\lambda)=p(\lambda)h(\lambda)$，则称多项式 $h(\lambda)$ **整除** $g(\lambda)$，记为 $h(\lambda)\mid g(\lambda)$；$h(\lambda)$ 是 $g(\lambda)$ 的**因式**，$g(\lambda)$ 是 $h(\lambda)$ 的**倍式**。
:::


::: note 为什么这一个定理撑起整个多项式理论

带余除法是多项式版的「除法算式」，它保证「余式次数严格下降」——辗转相除法求最大公因式、判定互素、乃至后面证明「$\lambda_0$ 是特征根 $\iff(\lambda-\lambda_0)\mid f(\lambda)$」全都依赖这个下降机制。**唯一性**同样重要：它让「余式」成为可计算的确定对象。
:::

整除把「因式」与「倍式」这两个词定了下来，接下来自然要问：两个多项式之间有没有共同的因式、共同的倍式？

::: def 定义 2.1.9 / 2.1.10 · 公因式与公倍式 {#def-2.1.9}

设 $g(\lambda)$ 和 $h(\lambda)$ 是数域 $F$ 上的多项式：

- 若多项式 $p(\lambda)$ 既是 $g(\lambda)$ 的因式、又是 $h(\lambda)$ 的因式，则称 $p(\lambda)$ 是 $g(\lambda)$ 与 $h(\lambda)$ 的**公因式**（定义 2.1.9）；
- 若多项式 $p(\lambda)$ 既是 $g(\lambda)$ 的倍式、又是 $h(\lambda)$ 的倍式，则称 $p(\lambda)$ 是 $g(\lambda)$ 与 $h(\lambda)$ 的**公倍式**（定义 2.1.10）。
:::

（**补注**：课件未展开「最大公因式 / 互素」的完整定义，但其后讨论矩阵与多项式的互素性、互素多项式矩阵时都要用到；标准定义与性质见 [勘误与补注](errata.md#errata-2.1) 的一处补注。）


工具箱的最后一件跨出了多项式：把一个多项式的系数整编成一个矩阵，多项式的问题从此可以交给矩阵来处理。

::: def 定义 2.1.11 · 友矩阵（伴侣矩阵）{#def-2.1.11}

设 $f(\lambda)$ 是数域 $F$ 上的首 1 多项式，其表达式为

$$f(\lambda)=\lambda^n+a_{n-1}\lambda^{n-1}+\cdots+a_1\lambda+a_0,$$

定义 $n$ 阶矩阵

$$A=\begin{bmatrix}0&1&0&\cdots&0\\ 0&0&1&\cdots&0\\ \vdots&\vdots&\vdots&\ddots&\vdots\\ 0&0&0&\cdots&1\\ -a_0&-a_1&-a_2&\cdots&-a_{n-1}\end{bmatrix}
\quad\text{或}\quad
A=\begin{bmatrix}0&0&\cdots&0&-a_0\\ 1&0&\cdots&0&-a_1\\ 0&1&\cdots&0&-a_2\\ \vdots&\vdots&&\vdots&\vdots\\ 0&0&\cdots&1&-a_{n-1}\end{bmatrix}$$

称为多项式 $f(\lambda)$ 的**友矩阵**（或**伴侣矩阵**）。$f(\lambda)$ 恰是 $A$ 的特征多项式。
:::


::: think 为什么这个矩阵出现在「预备知识」

友矩阵是「把多项式的全部系数信息打包成一个矩阵」的标准做法——它将多项式的因式分解信息**编码进矩阵的特征结构**。将来讨论特征值与特征向量（2.4）、矩阵相似与标准形时，它是主角：$f$ 不可约时友矩阵无重特征值（数域特征为 $0$ 时不可约多项式无重根），且 $f$ 的每个因式 $g$ 都对应一个 $A$ 的不变子空间 $\ker g(A)$（循环子空间）。现在只需认清两种形状（行形式 / 列形式，互为转置）、会写会认。
:::

## 2.1 小结与常见错误

- **一条主线**：映射的三要素（定义域、值域、法则）→ 单 / 满 / 双射 → 相等与复合（顺序！）→ 可逆（逆唯一 [@thm-2.1.1]；可逆 ⟺ 双射 [@thm-2.1.2]）→ 变换与置换 → 用双射量无穷集合（$\mathbb N\sim\mathbb Z\sim\mathbb Q$）→ 多项式：带余除法 [@thm-2.1.3]、整除 [@def-2.1.8]、公因式 / 公倍式、友矩阵 [@def-2.1.11]。
- **一个视角**：「等势」把「一样多」翻译成「存在双射」——**映射是计数概念的推广**。

::: think 常见错误清单 · 自查三条

1. 判「是不是映射」只看有没有对应、不查**唯一性**（如「取平方根」在 $\mathbb R$ 上不是映射）；
2. 复合与逆的顺序想当然——$f_2f_1$ 先作用 $f_1$；$(f_2f_1)^{-1}=f_1^{-1}f_2^{-1}$（先穿的后脱），与书写顺序相反；
3. 把「变换」当任意映射——它要求**定义域 = 值域**；「置换」还额外要求集合有限，这两个条件都要在。
:::

::: ex 即时自测（不看上文，3 分钟）{#ex-2.1.quiz}

1. 写出 [@ex-2.1.A] 的 $f(9)$、$f(10)$，并说明 $f$ 为何是双射。
2. 判断：若有两个映射 $g:W\to V$、$f:V\to W$ 满足 $f\cdot g=I_W$ 且 $g\cdot f=I_V$，是否一定有 $f$ 可逆？逆是谁？
3. 什么是首一多项式？友矩阵的两种形状差在什么位置？

::: sol 参考要点

1. $f(9)=-(9+1)/2=-5$，$f(10)=5$；偶数与奇数分别铺满 $\mathbb Z$ 的非负与非正部分，且不重叠。
2. 是；按 [@def-2.1.5]，$g$ 就是 $f$ 的逆映射（$g=f^{-1}$），由 [@thm-2.1.2] $f$ 是双射。
3. 首项系数为 1 的多项式；两种形状分别是「上次对角线为 1、**最后一行**为系数」与「次对角线为 1、**最后一列**为系数」，互为转置。
