## 一、课件留白处的一处补注：最大公因式与互素

课件给出定义 2.1.9（公因式）与定义 2.1.10（公倍式）后**未展开**「最大公因式 / 互素」的完整定义，但后续（若尔当标准形、多项式矩阵、$\lambda$-矩阵的初等因子）都以此为语言。补注如下（与第一章配套）——今后讨论「两多项式互素」「$f$ 与 $f'$ 互素 ⟺ $f$ 无重根」时直接引用。

::: note 补注 · 最大公因式与互素

设 $g,h\in F[\lambda]$ 不全为零。若 $d\in F[\lambda]$ 满足：

1. $d\mid g$、$d\mid h$（是公因式）；
2. $g,h$ 的**任一**公因式都整除 $d$（最大性，按整除关系而非「次数最大」）；

则称 $d$ 为 $g,h$ 的**最大公因式**，记 $d=(g,h)$。最大公因式在**相差非零常数倍**的意义下唯一（取首一者即唯一）；其存在性由辗转相除法给出，且存在 $u,v\in F[\lambda]$ 使

$$u(\lambda)g(\lambda)+v(\lambda)h(\lambda)=(g,h)\qquad(\text{Bezout 等式}).$$

当 $(g,h)=1$ 时称 $g,h$ **互素**——等价于 $\gcd$ 意义下无公共因式，也等价于存在 $u,v$ 使 $ug+vh=1$。
:::

## 五、2.3 课件的三处勘误与两处补注（无录播，逐页核对）

以下各条均**逐页核对课件原文**（《2.3 矩阵与同构》）后列出，正文相应位置已标注。编号沿用本页体例（E2.x）。

::: errata E2.1 · 「定理 2.3.6(2)」的证明省略了关键一句

课件对 $\dim R(T)=\dim R(A)=\operatorname{rank}A$ 的证明写道：「假设 $T(\varepsilon_1),\cdots,T(\varepsilon_r)$ 为 $R(T)$ 的一组基，易得 $A_1,\cdots,A_r$ 线性无关，且 $A_i$（$i=r+1,\cdots,n$）可由 $A_1,\cdots,A_r$ 线性表出。」其中 $A_i$ **未加说明**——按上下文它指「矩阵 $A$ 的第 $i$ 列」。漏掉这句（以及「取坐标是同构映射，故无关性可以平移」的论证），整个证明无从对照。

**本编处理**：在 [@thm-2.3.6] 的证明框中给出完整版本（含 $R(T)\to R(A)$ 的同构映射构造），并在正文以 errata 框标出此处，见 [2.3.5](sec23.md#sec-2.3.5)。
:::

::: errata E2.2 · 「例 2.3.5」默认了 $a_0\neq0$

课件写差分方程的 $k$ 取 $0,\pm1,\pm2,\cdots$，并断言「当 $x_0$ 给定，序列 $\{u_k\}$ 唯一确定」——**这句话默认了 $a_0\neq0$**（$a_0=0$ 时友矩阵奇异，反方向无法唯一还原）。

**本编处理**：完整说明与改正见 [@ex-2.3.5] 解答后紧随的勘误框，此处不重复；引用时补上「设 $a_0\neq0$」即可，只讨论正方向（$k\ge0$）则无此要求。
:::

::: errata E2.3 · 课件未给「例 2.3.3」的答案

课件仅提问「求 $T$ 在基 $\varepsilon_1,\cdots,\varepsilon_n$ 下的矩阵」，未给答案。**本编补**：$T$ 的矩阵恰是由 $\varepsilon$ 到 $\eta$ 的**过渡矩阵** $P$（[@ex-2.3.3]），这一步把「坐标不能直接搬用」的几何直觉（[2.2](sec22.md#sec-2.2.2)）变成了可计算的结论。
:::

::: note 补注 · 「整数集与偶数集同构」这句注记该怎么读

课件在定义 2.3.2 旁标注「整数集与偶数集同构」。**注意它说的是集合层面的等势**（$n\leftrightarrow2n$，[@def-2.1.A]），而不是线性空间的同构——后者还要求保持加法与数乘。正文已在 [@def-2.3.2] 后辨析：**同构 $=$ 等势 $+$ 保持线性运算**，判别依据是**维数相等**（[@thm-2.3.3]）而非元素个数。
:::

::: note 补注 · 相抵与相似的关系

课件注 1、注 2 分别给出相抵（$A\cong B$）与相似（$B=P^{-1}AP$），但未点明两者的关系（因为这需要 2.3.4 的矩阵语言与「秩」的完整理论）：

- **相似必相抵**：$B=P^{-1}AP$ 就是取 $Q=P$ 的相抵（同一组基的两侧也用同一个 $P$）；
- **相抵未必相似**：相抵允许两侧用不同的可逆矩阵（$B=P^{-1}AQ$，$P,Q$ 独立），且不要求同阶方阵——$2\times3$ 矩阵也谈相抵，但只有同阶方阵才谈相似；
- **对应到映射**：相抵 $=$ 同一个线性映射 + 出发 / 到达两组基**各自**换（甚至可以是同秩的另一个映射）；相似 $=$ 同一个线性变换（$V\to V$）+ 同一个空间的两组基。
:::
