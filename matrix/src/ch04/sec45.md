# 4.5 特征值估计

4.1–4.3 造好了一把尺子，量的是「大小」。这一节换一个被量的东西：**特征值**。

特征值当然可以算——解特征多项式 $\det(\lambda I-A)=0$。但 $n$ 阶矩阵的特征多项式是 $n$ 次多项式：$n=5$ 就没有求根公式，$n=100$ 更是只能数值近似。于是分析学的老办法又派上用场：**先不求出它，先说它在哪儿。**

这一节给三种「说它在哪儿」的工具，精度依次提高：

1. **谱半径与矩阵范数**（4.5.2）：$\rho(A)\le\|A\|$ 对任意矩阵范数成立；反过来，只要肯换一把「为 $A$ 定制」的范数，$\|A\|$ 可以压到 $\rho(A)+\varepsilon$。两个方向合起来说：**谱半径是全体矩阵范数在 $A$ 处取值的下确界**。
2. **显式界**（4.5.3）：把范数换成行和、列和、$F$-范数，立刻得到特征值模的三个上界；$F$-范数那一条还带等号条件——等号成立当且仅当 $A$ 正规。这一条把 4.2 的酉不变性和 3.5 的 Schur 引理接在一起。
3. **盖尔圆盘**（4.5.4–4.5.6）：把每一个特征值关进一个**具体位置已知的圆盘**，而且能数——k 个圆盘连成一片且与其余圆盘不相交，那片区域里就恰好有 k 个特征值。这是本节的主力工具，也是 4.6 判断「$A^k\to O$」的入口。

一句话概括：**4.5 把「特征值在哪」从求根问题变成几何问题。**

## 4.5.1 谱与谱半径：一个数概括全部特征值

::: def 定义 4.5.1 · 谱与谱半径（课件原文） {#def-4.5.1}

给定复方阵 $A\in\mathbb C^{n\times n}$，记

$$Sp(A)=\{\lambda\mid\lambda\ \text{是}\ A\ \text{的特征值}\},$$

则称 $Sp(A)$ 是矩阵 $A$ 的**谱**，称 $A$ 的特征值模的最大值

$$\rho(A)=\max_{\lambda\in Sp(A)}|\lambda|$$

为 $A$ 的**谱半径**。
:::

谱是一个**集合**，谱半径是它的**最大模**——把「$n$ 个复数散落在平面上」压成「一个非负数」。这个压缩丢了很多信息（位置、重数、几何重数全丢了），但留下的这一个数恰好控制住了一件最要紧的事：**$A$ 的幂会不会衰减**（[4.6](sec46.md#sec-4.6.3)）。

::: note 本编补注 · 谱半径的四条基本性质 {#note-4.5-basic}

四个练习里反复用到的等式与不等式，先摆在这里（都能从定义直接读出）：

1. $\rho(A)\ge0$，且 $\rho(A)=0$ **不推出** $A=O$——凡幂零矩阵都满足 $\rho(A)=0$（它的特征值全为 $0$）；
2. **相似不变**：$\rho(P^{-1}AP)=\rho(A)$，因为相似矩阵的特征值（连同重数）完全相同（[3.6](../ch03/sec36.md#sec-3.6.1)）；
3. **幂**：$\rho(A^k)=\rho(A)^k$。特征值是 $\lambda^k$，取模最大即得；
4. **取共轭**：$\rho(A^{\mathrm H})=\rho(A)$，因为 $A^{\mathrm H}$ 的特征值是 $A$ 的特征值的共轭。

第 1 条是下面那个「思考」的关键，也是 4.5.2 里两个定理之所以要「两个方向都说」的原因：$\rho$ 只看得见特征值，看不见 Jordan 块。
:::

::: ex 例 4.5.1（课件原文）· 谱半径的第一算 {#ex-4.5.1}

求 $A=\begin{bmatrix}1&0\\2&2i\end{bmatrix}$ 的谱半径 $\rho(A)$。

::: sol 解答（本编补中间步骤）

$A$ 是上三角阵（$\begin{bmatrix}1&0\\2&2i\end{bmatrix}$ 的下三角元为 $2$，上三角元为 $0$——注意这里「三角」看的是**非对角元是否全在一侧**）。

**按定义算**：$\det(\lambda I-A)=(\lambda-1)(\lambda-2i)$，故 $Sp(A)=\{1,\,2i\}$，$|1|=1$、$|2i|=2$，于是

$$\rho(A)=\max\{1,2\}=2 .$$

**用三角阵的快捷读法复核**：上三角阵的**对角元就是全部特征值**，不用解多项式——这是本章反复用的一招。∎
:::
:::

::: think 思考 · 矩阵的谱半径可以定义矩阵范数吗？（课件） {#think-4.5-rhomorphism}

**答案：不可以。** 谱半径连范数的第一条公理（正定性）都过不了，三角不等式也过不了。两个反例都只有 $2\times2$：

- **正定性失效**：取 $N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，则 $N\ne O$，但 $N$ 的特征值只有 $0$（重数 $2$），故 $\rho(N)=0$。范数要求「非零矩阵的范数严格大于零」，$\rho$ 违反了。
- **三角不等式失效**：取 $A=\begin{bmatrix}0&1\\0&0\end{bmatrix}$、$B=\begin{bmatrix}0&0\\1&0\end{bmatrix}$。两者都幂零，故 $\rho(A)=\rho(B)=0$；但 $A+B=\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 的特征值为 $\pm1$，$\rho(A+B)=1$。于是
  $$\rho(A+B)=1\gt0=\rho(A)+\rho(B) .$$

**为什么它会失败**：范数衡量的是「矩阵本身有多大」，谱半径只衡量「特征值有多远」。幂零矩阵「本身不小」（$N\ne O$），但它的全部特征值都挤在原点——$\rho$ 对这个差别完全无感。这正是 [4.5.2](#sec-4.5.2) 要处理的问题：**用范数给谱半径做上界，方向是对的；把等号当定义，方向就错了。**
:::

## 4.5.2 谱半径与矩阵范数：一个不等式、两个方向

先把 $\rho$ 与 $\|\cdot\|$ 放在一起算一遍，看看它们差多少。

::: ex 例 4.5.2（课件原文）· 谱半径与四个范数 {#ex-4.5.2}

求 $A=\begin{bmatrix}1&2\\2&2\end{bmatrix}$ 的谱半径 $\rho(A)$，以及 $\|A\|_1,\|A\|_\infty,\|A\|_2,\|A\|_F$。

::: sol 解答（课件给出答案，本编补中间步骤）

**特征值**：$\det(\lambda I-A)=(\lambda-1)(\lambda-2)-4=\lambda^2-3\lambda-2$，故

$$\lambda_{1,2}=\frac{3\pm\sqrt{9+8}}{2}=\frac{3\pm\sqrt{17}}{2}\approx3.5616,\ -0.5616,\qquad \rho(A)\approx3.5616 .$$

**列和**：$1+2=3$、$2+2=4$，故 $\|A\|_1=4$。

**行和**：$1+2=3$、$2+2=4$，故 $\|A\|_\infty=4$。

**Frobenius**：$\|A\|_F=\sqrt{1+4+4+4}=\sqrt{13}\approx3.606$。

**谱范数**：$A$ 实对称，故 $\|A\|_2=\rho(A)\approx3.5616$（[注](#note-4.5-normal) 的直接兑现）。

**答案**：$\rho(A)=3.5616$，$\|A\|_1=4$，$\|A\|_\infty=4$，$\|A\|_2=3.5616$，$\|A\|_F=3.605$。∎

**读法**：四个范数里，**谱范数恰好等于谱半径**（因为 $A$ 正规），其余三个都严格大于它。这不是巧合，而是 [定理 4.5.1](#thm-4.5.1) 的一个等式情形。
:::
:::

::: thm 定理 4.5.1（课件原文）· 谱半径不大于任一矩阵范数 {#thm-4.5.1}

复方阵的谱半径不大于它的任一矩阵范数，即对任意矩阵范数 $\|\cdot\|$，

$$\rho(A)\le\|A\| .$$
:::

::: proof 证明（课件原文，本编补「相容向量范数」这一句的作用）

设 $\lambda$ 是 $A$ 的任一特征值，$x\ne\boldsymbol0$ 是对应的特征向量，即 $Ax=\lambda x$。

**对于任意给定的矩阵范数，都存在与之相容的向量范数**（这正是 [定理 4.3.1](sec43.md#thm-4.3.1)），在该向量范数下把等式两边取范数：

$$|\lambda|\,\|x\|=\|\lambda x\|=\|Ax\|\le\|A\|\,\|x\| .$$

由 $x\ne\boldsymbol0$ 得 $\|x\|\gt0$，两边约去即得 $|\lambda|\le\|A\|$。对每个特征值都成立，故

$$\rho(A)=\max_\lambda|\lambda|\le\|A\| .\qquad\blacksquare$$

**证明的要点**：矩阵范数本身量不了向量，所以「$\|Ax\|\le\|A\|\|x\|$」这一步**必须借相容的向量范数**——与 [定理 4.3.6](sec43.md#thm-4.3.6) 的反证法是同一个技术动作。少了这一步，证明根本启动不了。
:::

::: note 注（课件原文）· 正规矩阵：$\rho(A)=\|A\|_2$ {#note-4.5-normal}

若 $A$ 是正规矩阵，则 $\rho(A)=\|A\|_2$。

**本编补证明**：由 [定理 4.2.3](sec42.md#thm-4.2.3) 的酉不变性，$\|A\|_2^2=\lambda_{\max}(A^{\mathrm H}A)=\rho(A^{\mathrm H}A)$。$A$ 正规时 $A^{\mathrm H}A=AA^{\mathrm H}$ 且可酉对角化：

$$A=U\operatorname{diag}(\lambda_1,\cdots,\lambda_n)U^{\mathrm H}\ \Longrightarrow\ A^{\mathrm H}A=U\operatorname{diag}(|\lambda_1|^2,\cdots,|\lambda_n|^2)U^{\mathrm H},$$

故 $\rho(A^{\mathrm H}A)=\max_i|\lambda_i|^2=\rho(A)^2$，开方即得 $\|A\|_2=\rho(A)$。

反过来，$\|A\|_2=\rho(A)$ 并不推出正规——[例 4.5.9](#ex-4.5.9) 的旋转阵就满足 $\|A\|_2=\rho(A)=1$ 而非正规。**等号是正规的必要条件，不是充分条件**。
:::

定理 4.5.1 说的是「$\rho\le$ 任何范数」。反过来问：能不能找一把范数，把 $\|A\|$ 压到离 $\rho(A)$ 任意近？答案是能——但要付代价：**这把范数是为 $A$ 定制的**。

::: thm 定理 4.5.2（课件原文）· 谱半径是范数的下确界 {#thm-4.5.2}

设 $A\in\mathbb C^{n\times n}$，任取正常数 $\varepsilon$，则必存在某个矩阵范数 $\|\cdot\|$ 使得

$$\|A\|\le\rho(A)+\varepsilon .$$
:::

::: proof 证明（课件原文，本编补「$\|\cdot\|_1$ 确实是矩阵范数」与 $Q$ 的具体计算）

存在可逆矩阵 $P$，使 $P^{-1}AP=J$ 为 Jordan 标准形（[3.8](../ch03/sec38b.md#thm-3.8.5j)）。记 $\Lambda$ 为 $J$ 的对角部分、$\tilde J=J-\Lambda$，则 $\tilde J$ 的元素只有 $0$ 或 $1$，且**只出现在超对角线上**。

对任意的 $\varepsilon\gt0$，令

$$Q=\operatorname{diag}(1,\ \varepsilon,\ \varepsilon^2,\ \cdots,\ \varepsilon^{n-1}),$$

取 $S=PQ$。由 $Q^{-1}\tilde JQ$ 的第 $(i,j)$ 元是 $\tilde j_{ij}\varepsilon^{j-i}$，而 $\tilde J$ 只在 $j=i+1$ 处非零，得

$$S^{-1}AS=Q^{-1}JQ=\Lambda+\varepsilon\tilde J .$$

定义

$$\|A\|_m=\|S^{-1}AS\|_1 .$$

**（1）它是矩阵范数**：$A\mapsto S^{-1}AS$ 是相似变换，$\|\cdot\|_1$ 是矩阵范数，故 $\|S^{-1}AS\|_1$ 满足四公理——这正是 [例 4.2.3](sec42.md#ex-4.2.3) 的「用相似造范数」，关键一步是 $S^{-1}ABS=(S^{-1}AS)(S^{-1}BS)$。

**（2）估计它**：$\Lambda+\varepsilon\tilde J$ 的第 $j$ 列元素是「对角元 $\lambda_j$」加上「至多一个 $\varepsilon$」，故列和不超过 $|\lambda_j|+\varepsilon\le\rho(A)+\varepsilon$，于是

$$\|A\|_m=\|\Lambda+\varepsilon\tilde J\|_1\le\rho(A)+\varepsilon .\qquad\blacksquare$$

**读法**：$\varepsilon$ 出现在**超对角线**上——Jordan 块越「长」，需要越小的 $\varepsilon$ 才能把它压下去。$A$ 可对角化时 $\tilde J=O$，直接取 $\|A\|_m=\|S^{-1}AS\|_1=\rho(A)$，$\varepsilon$ 可以取 $0$。
:::

::: note 注 1（课件原文）· 这把范数离不开 $A$ {#note-4.5-depends}

定理 4.5.2 中构造的矩阵范数与给定的矩阵 $A$ 有关。因此，当用矩阵 $A$ 构造的矩阵范数来计算矩阵 $B$（$B\ne A$）的范数时，不等式 $\|B\|\le\rho(B)+\varepsilon$ **不一定成立**。

**本编补一个具体反例**：取 $A=\operatorname{diag}(1,0)$，$\varepsilon=\tfrac12$。按证明的构造（$A$ 已是对角阵，$P=I$、$\tilde J=O$），$\|X\|_m=\|X\|_1$。对 $A$ 本身：$\|A\|_m=1=\rho(A)+\tfrac12$ 当然成立（甚至取 $\varepsilon=0$ 也成立）。但换 $B=\begin{bmatrix}0&1\\0&0\end{bmatrix}$：$\|B\|_m=\|B\|_1=1$，而 $\rho(B)=0$，于是 $\|B\|_m=1\gt\tfrac12=\rho(B)+\varepsilon$ ——**不等式失效**。

**所以「$\rho(A)=\inf\|\cdot\|$」这句话里的 $\inf$ 是对「$A$ 与范数的联合选择」取的**：对每个固定的 $A$，$\inf_{\|\cdot\|}\|A\|=\rho(A)$；但不能指望「同一把范数对所有矩阵都逼近各自的谱半径」。
:::

::: note 本编补注 · 两个不等式合起来是什么 {#note-4.5-inf}

把 [定理 4.5.1](#thm-4.5.1) 与 [定理 4.5.2](#thm-4.5.2) 并排放：

$$\rho(A)\le\|A\|\quad(\text{对一切矩阵范数}),\qquad \inf_{\|\cdot\|}\|A\|\le\rho(A)+\varepsilon\quad(\text{对一切}\ \varepsilon\gt0).$$

两式合起来就是

$$\boxed{\ \rho(A)=\inf_{\|\cdot\|\ \text{是矩阵范数}}\|A\|\ }$$

**谱半径是「所有矩阵范数在 $A$ 处读数」的下确界**。这个下确界**不一定取到**：如果 $A$ 不可对角化，任何矩阵范数都严格大于 $\rho(A)$（[例 4.5.A](#ex-4.5.A) 就是这种情形）。

用途：**证明收敛性时用上界（挑一把好算的范数），证明「不能再改进了」时用下确界。** 4.6 的 Abel 型定理（[定理 4.6.5](sec46.md#thm-4.6.5)）正是靠「$\rho(A)\lt r$ 时总存在范数使 $\|A\|\lt r$」这一步把矩阵幂级数化归成数值幂级数。
:::

::: ex 例 4.5.A（新增）· 定理 4.5.2 的构造跑一遍 {#ex-4.5.A}

设 $A=\begin{bmatrix}0.1&1\\0&0.1\end{bmatrix}$（一个 $2$ 阶 Jordan 块，与课件「超对角元为 $1$」的约定一致）。(a) 求 $\rho(A)$ 与 $\|A\|_\infty,\|A\|_1,\|A\|_F$；(b) 取 $\varepsilon=0.01$，按 [定理 4.5.2](#thm-4.5.2) 的构造写出 $S$ 与 $\|A\|_m$，验证 $\|A\|_m\le\rho(A)+\varepsilon$；(c) 说明为什么任何一个矩阵范数都**不能**等于 $\rho(A)$。

::: sol 解答

**(a)** $A$ 是上三角阵，对角元即特征值：$\lambda_1=\lambda_2=0.1$，故 $\rho(A)=0.1$。

行和：$0.1+1=1.1$、$0.1$，故 $\|A\|_\infty=1.1$；列和：$0.1$、$1+0.1=1.1$，故 $\|A\|_1=1.1$；$\|A\|_F=\sqrt{0.01+1+0.01}=\sqrt{1.02}\approx1.010$。

三个范数都远大于 $\rho(A)=0.1$——**这就是「$A$ 不可对角化」的代价**：超对角线上那个 $1$ 在任何「按行列求和」的范数里都跑不掉。

**(b)** $A$ 已经是 Jordan 形：$A=\Lambda+N$，其中 $\Lambda=\operatorname{diag}(0.1,0.1)$、$N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$。取 $P=I$，则 $\tilde J=N$。

**一个必须说清的乘法方向**：$Q^{-1}AQ$ 的第 $(i,j)$ 元是 $a_{ij}\cdot\dfrac{q_j}{q_i}$（左边乘 $Q^{-1}$ 除 $q_i$、右边乘 $Q$ 乘 $q_j$）。所以对**超对角**的 $(1,2)$ 元，乘的是 $\dfrac{q_2}{q_1}$——取 $q_2=\varepsilon$、$q_1=1$ 就把它压成 $\varepsilon$。这正是课件写的

$$Q=\operatorname{diag}(1,\ \varepsilon)=\operatorname{diag}(1,\ 0.01),\qquad S=PQ=Q .$$

代入：

$$S^{-1}AS=Q^{-1}AQ=\begin{bmatrix}0.1&1\cdot\dfrac{0.01}{1}\\0&0.1\end{bmatrix}=\begin{bmatrix}0.1&0.01\\0&0.1\end{bmatrix}.$$

列和：$0.1$、$0.01+0.1=0.11$，故 $\|A\|_m=\|S^{-1}AS\|_1=0.11=\rho(A)+\varepsilon$ ✓。一般地，若 $A$ 有 $s$ 阶 Jordan 块，取 $q_i=\varepsilon^{i-1}$，则第 $l$ 条超对角线的 $1$ 被压成 $\varepsilon^l$，所有非对角元都不超过 $\varepsilon$。

**$S$ 干了什么**：$\operatorname{diag}(1,0.01)$ 把第 $1$ 行缩小 $100$ 倍（等价地把第 $2$ 列放大 $100$ 倍），于是那个 $1$ 变成 $0.01$——**用尺度变换把超对角元压到可以忽略**。这正是 [注 3](#note-4.5-diag) 的 $DAD^{-1}$ 手法在 Jordan 形上的版本（那里 $DAD^{-1}$ 的 $(i,j)$ 元是 $a_{ij}d_i/d_j$，与本处的 $q_j/q_i$ 方向相反，因为一个是「相似」的两种写法）。

**(c)** 若某个矩阵范数满足 $\|A\|=\rho(A)=0.1$，则由乘法相容性 $\|A^k\|\le\|A\|^k=0.1^k$。但 $A=0.1I+N$（$N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，$N^2=O$），故

$$A^k=0.1^kI+k\cdot0.1^{k-1}N=\begin{bmatrix}0.1^k&k\cdot0.1^{k-1}\\0&0.1^k\end{bmatrix},$$

于是对每个 $k\ge1$，

$$\|A^k\|\ge\big|(A^k)_{12}\big|=k\cdot0.1^{k-1}=10k\cdot0.1^k\gt0.1^k=\|A\|^k ,$$

与 $\|A^k\|\le\|A\|^k$ **矛盾**（$k\ge1$ 时 $10k\gt1$）。所以**下确界严格取不到**：$\inf\|\cdot\|=0.1$，但每个矩阵范数的读数都 $\gt0.1$。∎

**这个矛盾为什么必然出现**：$A^k$ 里那个 $k\cdot0.1^{k-1}$ 是**多项式因子**乘指数因子。若 $\|A\|=\rho(A)$，相容性会把「多项式 × 指数」压成「纯指数」，两个增长速度不可能一致——**这就是 Jordan 块与范数不相容的定量表达**。$A$ 可对角化时多项式因子不出现（$N=O$），等号才可能取到。
:::
:::

## 4.5.3 特征值的显式界：不用求多项式

[定理 4.5.1](#thm-4.5.1) 把「特征值模」交给「矩阵范数」。范数是可算的，于是立刻得到三个不用解多项式的界。

::: thm 补充定理（课件原文）· 特征值模的三个上界 {#thm-4.5-extra}

设 $A=(a_{ij})\in\mathbb C^{n\times n}$ 的特征值为 $\lambda_1,\cdots,\lambda_n$，则

$$\text{(1)}\quad |\lambda_l|\le\max_{1\le j\le n}\sum_{i=1}^{n}|a_{ij}|=\|A\|_1,\qquad l=1,\cdots,n;$$

$$\text{(2)}\quad |\lambda_l|\le\max_{1\le i\le n}\sum_{j=1}^{n}|a_{ij}|=\|A\|_\infty,\qquad l=1,\cdots,n;$$

$$\text{(3)}\quad \sum_{l=1}^{n}|\lambda_l|^2\le\sum_{i,j=1}^{n}|a_{ij}|^2=\|A\|_F^2,$$

其中 (3) 的等号成立**当且仅当 $A$ 为正规矩阵**。
:::

::: proof 证明（课件只给两句提示，本编补全）

**(1)(2) 就是谱半径性质**：由 [定理 4.5.1](#thm-4.5.1) 与 [定理 4.3.3](sec43.md#thm-4.3.3)，

$$|\lambda_l|\le\rho(A)\le\|A\|_1=\max_j\sum_i|a_{ij}|,\qquad |\lambda_l|\le\rho(A)\le\|A\|_\infty=\max_i\sum_j|a_{ij}| .$$

两个都只是「$\rho\le$ 范数」加「范数公式」，一步到位。

**(3) 用 Schur 引理**。由 Schur 三角化（[定理 3.5.2](../ch03/sec35.md#thm-3.5.2)），存在酉矩阵 $U$ 使 $T=U^{\mathrm H}AU$ 为上三角，且 $T$ 的对角元恰是 $\lambda_1,\cdots,\lambda_n$。

- **左边**：$\sum_l|\lambda_l|^2=\sum_l|t_{ll}|^2$，即 $T$ 的**对角元平方和**；
- **右边**：$\|A\|_F=\|T\|_F$（[定理 4.2.3](sec42.md#thm-4.2.3) 的酉不变性），而 $\|T\|_F^2=\sum_{i\le j}|t_{ij}|^2$ 是**全部元素**（含上三角非对角元）的平方和。

故

$$\sum_l|\lambda_l|^2=\sum_{l}|t_{ll}|^2\le\sum_{i\le j}|t_{ij}|^2=\|A\|_F^2 .$$

**等号条件**：等号 $\iff$ 上三角部分除对角元外全为 $0$ $\iff$ $T$ 是对角阵 $\iff$ $A$ 可酉对角化 $\iff$ $A$ 正规（[定理 3.6.2](../ch03/sec36.md#thm-3.6.2)）。∎

**读法**：$F$-范数的平方是「全部能量的总和」，而特征值模的平方和只取「对角线上的那份」。**非对角元是浪费掉的能量**——正规矩阵一点不浪费，所以取等。
:::

课件接着给了一条「推广」，把复特征值的实部、虚部也框住。它的证明同样只用 Schur 引理，但要多一步「Hermite 部分的 Rayleigh 商」。

::: note 推广（课件原文）· 实部与虚部的界 {#note-4.5-realimag}

设 $A=(a_{ij})\in\mathbb C^{n\times n}$ 的特征值为 $\lambda_1,\cdots,\lambda_n$，则

$$\text{(1)}\quad |\operatorname{Re}\lambda_l|\le\frac12\big\|A+A^{\mathrm H}\big\|_{v\infty},\qquad \text{(2)}\quad |\operatorname{Im}\lambda_l|\le\frac12\big\|A-A^{\mathrm H}\big\|_{v\infty},\qquad l=1,\cdots,n,$$

其中 $\|A\|_{v\infty}=n\max\limits_{1\le i,j\le n}|a_{ij}|$。

**本编补证明**（课件只写「Schur 引理」三个字）：

记 $H=\tfrac12(A+A^{\mathrm H})$、$K=\tfrac12(A-A^{\mathrm H})$，则 $H$ 是 Hermite 阵、$K$ 是反 Hermite 阵，且 $A=H+K$。设 $Ax=\lambda x$、$x\ne\boldsymbol0$，左乘 $x^{\mathrm H}$：

$$\lambda\,x^{\mathrm H}x=x^{\mathrm H}Ax=x^{\mathrm H}Hx+x^{\mathrm H}Kx .$$

$x^{\mathrm H}Hx$ 是**实数**（$H$ 自伴），$x^{\mathrm H}Kx$ 是**纯虚数**（$K$ 反自伴），故把两边分成实部与虚部：

$$\operatorname{Re}\lambda=\frac{x^{\mathrm H}Hx}{x^{\mathrm H}x},\qquad \operatorname{Im}\lambda=\frac{x^{\mathrm H}Kx}{x^{\mathrm H}x} .$$

现在估 $|x^{\mathrm H}Hx|$。用齐次性归一化 $\|x\|_2=1$，则 $\|x\|_1\le\sqrt n\,\|x\|_2=\sqrt n$，于是

$$|x^{\mathrm H}Hx|=\Big|\sum_{i,j}h_{ij}x_i\overline{x_j}\Big|\le\max_{i,j}|h_{ij}|\sum_{i,j}|x_i||x_j|=\max_{i,j}|h_{ij}|\,\|x\|_1^2\le n\max_{i,j}|h_{ij}| .$$

代回并注意 $h_{ij}=\tfrac12\big(a_{ij}+\overline{a_{ji}}\big)$，即 $\max\limits_{i,j}|h_{ij}|=\tfrac12\max\limits_{i,j}\big|a_{ij}+\overline{a_{ji}}\big|$：

$$|\operatorname{Re}\lambda|\le n\cdot\frac12\max_{i,j}\big|a_{ij}+\overline{a_{ji}}\big|=\frac12\big\|A+A^{\mathrm H}\big\|_{v\infty} .$$

（最后一步用 $\|B\|_{v\infty}=n\max\limits_{i,j}|b_{ij}|$ 的定义，取 $B=A+A^{\mathrm H}$。）

对 $K$ 完全同理：$\max\limits_{i,j}|k_{ij}|=\tfrac12\max\limits_{i,j}\big|a_{ij}-\overline{a_{ji}}\big|$，故

$$|\operatorname{Im}\lambda|\le n\max_{i,j}|k_{ij}|=\frac12\big\|A-A^{\mathrm H}\big\|_{v\infty} .\qquad\blacksquare$$

**这两条界的第一个用途是「排除」**：$A$ 实对称时 $A-A^{\mathrm H}=O$，界退化为 $|\operatorname{Im}\lambda|\le0$，立刻得「实对称阵特征值全实」——与 [定理 3.6.2](../ch03/sec36.md#thm-3.6.2) 一致，但这里是用一条**不等式**直接逼出来的。
:::

::: ex 例 4.5.B（新增）· 三个界一起用 {#ex-4.5.B}

(a) 对 $A=\begin{bmatrix}1&2\\2&2\end{bmatrix}$ 验证 [补充定理](#thm-4.5-extra) 的 (3) 取等；(b) 对 $A=\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 验证 (3) 严格不等，并算出差多少；(c) 对 (b) 的 $A$ 验证 [推广](#note-4.5-realimag) 的两个界。

::: sol 解答

**(a)** $\lambda=\frac{3\pm\sqrt{17}}{2}$，$\sum|\lambda|^2=\frac{9+17+2\cdot3\sqrt{17}+9+17-2\cdot3\sqrt{17}}{4}=\frac{52}{4}=13$；而 $\|A\|_F^2=1+4+4+4=13$。**取等** ✓。原因：$A$ 实对称，正规。

**(b)** $\lambda_1=\lambda_2=1$，$\sum|\lambda|^2=2$；$\|A\|_F^2=1+1+1=3$。**严格不等**，差 $1$——正好是「超对角线上那个 $1$ 的平方」。$A$ 不正规（$AA^{\mathrm T}=\begin{bmatrix}2&1\\1&1\end{bmatrix}\ne\begin{bmatrix}1&1\\1&2\end{bmatrix}=A^{\mathrm T}A$），所以不取等。

**(c)** $A+A^{\mathrm H}=\begin{bmatrix}2&1\\1&2\end{bmatrix}$，$n\max|a_{ij}|=2\cdot2=4$，故界为 $|\operatorname{Re}\lambda|\le2$；实际 $|\operatorname{Re}\lambda|=1\le2$ ✓（松了一半）。$A-A^{\mathrm H}=\begin{bmatrix}0&1\\-1&0\end{bmatrix}$，$n\max|a_{ij}|=2$，界为 $|\operatorname{Im}\lambda|\le1$；实际 $|\operatorname{Im}\lambda|=0\le1$ ✓。

**要点**：这三条界都是**上界**，松是常态。它们真正的用途不是「求值」，而是「先排除某些情况」——比如界小于 $1$ 就立刻知道 $\rho(A)\lt1$（[例 4.6.9](sec46.md#ex-4.6.9) 就这么用）。∎
:::

## 4.5.4 盖尔圆盘：把特征值关进 n 个圆

前面的界只给「模有多大」，不给「在哪个方向」。盖尔圆盘（Gershgorin disk）把**位置**也管住了：每个特征值都落在某个圆盘里，而圆盘的圆心、半径都能从元素直接读出来。

::: def 定义 4.5.2 · 盖尔圆盘（课件原文） {#def-4.5.2}

设 $A=(a_{ij})\in\mathbb C^{n\times n}$，令

$$\delta_i=\sum_{j=1,\,j\ne i}^{n}|a_{ij}|,\qquad i=1,\cdots,n,$$

并定义

$$G_i=\big\{z\in\mathbb C\ \big|\ |z-a_{ii}|\le\delta_i\big\},\qquad i=1,\cdots,n,$$

即 $G_i$ 是复平面上以 $a_{ii}$ 为圆心、$\delta_i$ 为半径的**闭圆盘**，称之为矩阵 $A$ 的一个**盖尔圆盘**。
:::

读法：**第 $i$ 个圆盘的圆心是第 $i$ 个对角元，半径是第 $i$ 行「除去对角元」的绝对值之和**。注意是**行**——这一点与转置后的版本（[注 2](#note-4.5-transpose)）配合起来用。

::: ex 例 4.5.3（课件原文）· 三个圆盘 {#ex-4.5.3}

计算矩阵 $A=\begin{bmatrix}1&0.02&0.11\\0.01&i&0.14\\0.02&0.01&0.5\end{bmatrix}$ 的盖尔圆盘。

::: sol 解答（本编补）

对角线是 $1,\ i,\ 0.5$；每行「除去对角元」的绝对值之和：

$$\delta_1=0.02+0.11=0.13,\qquad \delta_2=0.01+0.14=0.15,\qquad \delta_3=0.02+0.01=0.03 .$$

故

$$G_1:\ |z-1|\le0.13,\qquad G_2:\ |z-i|\le0.15,\qquad G_3:\ |z-0.5|\le0.03 .$$

**三个圆盘两两不相交**（$|1-0.5|=0.5\gt0.13+0.03$；$|1-i|=\sqrt2\approx1.414\gt0.13+0.15$；$|i-0.5|=\sqrt{1.25}\approx1.118\gt0.15+0.03$）。由 [推论 4.5.3](#cor-4.5.3)，$A$ 的三个特征值互不相同，且各在一个孤立圆盘里——这正是「对角占优」的几何图像：对角元的模（$1,1,0.5$）远大于同行非对角元的和。

**数值核对**（`tools/verify_teaching_examples.py`）：$A$ 的特征值约为 $1.0045,\ 0.4961,\ -0.0007+0.9988i$，分别落在 $G_1$（$|z-1|\approx0.0045\le0.13$）、$G_3$（$|z-0.5|\approx0.0039\le0.03$）、$G_2$（$|z-i|\approx0.0014\le0.15$）内 ✓。∎
:::
:::

::: thm 定理 4.5.3（课件原文）· 盖尔圆盘定理 {#thm-4.5.3}

设 $A=(a_{ij})\in\mathbb C^{n\times n}$ 的 $n$ 个盖尔圆盘为 $G_1,\cdots,G_n$，则矩阵 $A$ 的任一特征值

$$\lambda\in\bigcup_{i=1}^{n}G_i .$$
:::

::: proof 证明（课件原文，本编补「为什么挑最大的那个分量」）

设 $\lambda$ 是 $A$ 的任一特征值，对应的特征向量为 $x=(x_1,\cdots,x_n)^{\mathrm T}\ne\boldsymbol0$，则对每个 $i$，

$$\sum_{j=1}^{n}a_{ij}x_j=\lambda x_i\ \Longrightarrow\ (a_{ii}-\lambda)x_i=\sum_{j\ne i}a_{ij}x_j .$$

取 $x_\sigma=\max\limits_{1\le i\le n}|x_i|$，显然 $x_\sigma\gt0$（$x\ne\boldsymbol0$）。在第 $\sigma$ 个方程上取模：

$$|a_{\sigma\sigma}-\lambda|\,|x_\sigma|=\Big|\sum_{j\ne\sigma}a_{\sigma j}x_j\Big|\le\sum_{j\ne\sigma}|a_{\sigma j}|\,|x_j|\le\Big(\sum_{j\ne\sigma}|a_{\sigma j}|\Big)|x_\sigma| .$$

两边除以 $|x_\sigma|\gt0$：

$$|a_{\sigma\sigma}-\lambda|\le\sum_{j\ne\sigma}|a_{\sigma j}|=\delta_\sigma ,$$

即 $\lambda\in G_\sigma$。由 $\lambda$ 的任意性，$\lambda\in\bigcup_iG_i$。∎

**证明的要点**：**挑「最大的分量」所在的方程**。这一挑同时干了两件事——分母 $|x_\sigma|$ 可以约掉，且每个 $|x_j|/|x_\sigma|\le1$ 使右端被 $\delta_\sigma$ 控住。换成任何别的分量都不行：分母变小，右端就会超出半径。

**这个技巧的名字**叫「主导分量法」；它与 [定理 4.3.6](sec43.md#thm-4.3.6) 的反证法、[定理 4.5.1](#thm-4.5.1) 的「借相容向量范数」是同一类动作：**都在向量层面制造一个可约去的正数**。
:::

::: ex 例 4.5.4（课件原文）· 行圆与列圆一起用 {#ex-4.5.4}

试估计矩阵

$$A=\begin{bmatrix}2&-1&-2&0\\-1&3&2i&0\\0&-i&10&i\\-2&0&0&6i\end{bmatrix}$$

的特征值分布。

::: sol 解答（本编补行圆盘，课件给列圆盘）

**行圆盘**（$A$ 本身，按行求和）：

$$G_1:\ |z-2|\le3,\qquad G_2:\ |z-3|\le3,\qquad G_3:\ |z-10|\le2,\qquad G_4:\ |z-6i|\le2 .$$

**列圆盘**（$A^{\mathrm T}$ 的盖尔圆，等价于按列求和、圆心不变）：

$$G_1':\ |z-2|\le3,\qquad G_2':\ |z-3|\le2,\qquad G_3':\ |z-10|\le4,\qquad G_4':\ |z-6i|\le1 .$$

（核对 $G_2'$：第 2 列是 $(-1,\,3,\,-i,\,0)^{\mathrm T}$，除对角元外 $|-1|+|-i|+0=2$。核对 $G_3'$：第 3 列是 $(-2,\,2i,\,10,\,0)^{\mathrm T}$，$|-2|+|2i|+0=4$。）

由 [定理 4.5.3](#thm-4.5.3)，$A$ 的 $4$ 个特征值都在 $\bigcup_iG_i$ 中；由 [注 2](#note-4.5-transpose)，它们也都在 $\bigcup_iG_i'$ 中。所以更精确的结论是

$$\lambda\in\Big(\bigcup_{i=1}^{4}G_i\Big)\cap\Big(\bigcup_{i=1}^{4}G_i'\Big).$$

**数值核对**：$Sp(A)\approx\{10.2545,\ 3.4556+0.1650i,\ 1.3489-0.1530i,\ -0.0590+5.9890i\}$（`verify_teaching_examples.py`）。逐个对圆盘：$10.2545$ 只在 $G_3\cap G_3'$ 里；$3.4556+0.1650i$ 与 $1.3489-0.1530i$ **同时**落在 $G_1\cap G_2$（也同在 $G_1'\cap G_2'$）——这两个圆盘本来就相交；$-0.0590+5.9890i$ 只在 $G_4\cap G_4'$ 里。四个点都在两个并集的交集中 ✓。∎

**读法**：行圆与列圆**圆心相同、半径不同**（半径分别是「行和」与「列和」）。两个并集取交，就把区域夹小了一圈——这是盖尔圆最便宜的用法：**多算一遍转置，白拿一个更小的区域**。
:::
:::

::: note 注 2（课件原文）· 转置的圆盘 {#note-4.5-transpose}

设 $A^{\mathrm T}$ 的盖尔圆为 $G_1',\cdots,G_n'$，则 $G_i$ 与 $G_i'$ 有相同的圆心。因此，矩阵 $A$ 的特征值必须满足

$$\lambda\in\Big(\bigcup_{i=1}^{n}G_i\Big)\cap\Big(\bigcup_{i=1}^{n}G_i'\Big).$$

**本编补两句**：(1) 为什么圆心相同——$A^{\mathrm T}$ 的对角元与 $A$ 的对角元逐个相同，而圆心就是对角元；(2) 为什么可以取交——[定理 4.5.3](#thm-4.5.3) 对 $A$ 与对 $A^{\mathrm T}$ 各成立一次，而 $A$ 与 $A^{\mathrm T}$ 的**特征值完全相同**（特征多项式相同），故同一个 $\lambda$ 必须同时落在两个并集里。
:::

::: think 思考 · $n$ 个特征值是否恰好落入它的 $n$ 个盖尔圆内？（课件） {#think-4.5-oneperdisk}

**答案：不是。** 课件用下面的 $2\times2$ 例子直接反驳。
:::

::: ex 例 4.5.5（课件原文）· 一个圆盘装两个，一个圆盘空着 {#ex-4.5.5}

考查矩阵 $A=\begin{bmatrix}0&-0.4\\0.9&1\end{bmatrix}$，其盖尔圆为

$$G_1:\ |z|\le0.4,\qquad G_2:\ |z-1|\le0.9 .$$


::: sol 解答（本编补完整计算）

**圆盘**：对角元 $0$、$1$；第 1 行除对角元 $|-0.4|=0.4$，第 2 行除对角元 $|0.9|=0.9$。故 $G_1$ 以原点为心、半径 $0.4$，$G_2$ 以 $1$ 为心、半径 $0.9$。

**特征值**：$\det(\lambda I-A)=\lambda(\lambda-1)+0.36=\lambda^2-\lambda+0.36$，故

$$\lambda_{1,2}=\frac{1\pm\sqrt{1-1.44}}{2}=\frac{1\pm\sqrt{0.44}\,i}{2}\approx0.5\pm0.3317i .$$

**核对位置**：$|\lambda|=\sqrt{0.25+0.1100}=\sqrt{0.36}=0.6\gt0.4$，故**两个特征值都不在 $G_1$ 里**；而 $|\lambda-1|=|{-0.5}\pm0.3317i|=\sqrt{0.25+0.11}=0.6\le0.9$，故**两个都在 $G_2$ 里**。

**结论**：并非每个盖尔圆内都恰好有一个特征值——$G_1$ 一个也没有，$G_2$ 里挤了两个。∎

**这是不是与 [定理 4.5.3](#thm-4.5.3) 矛盾？** 不矛盾。定理只保证「每个特征值落在**某个**圆盘里」，从不保证「每个圆盘里都有特征值」，更不保证「一个不多一个不少」。要让「一个不多一个不少」成立，必须加上**连通区域的分离条件**——那就是下面的 [定理 4.5.4](#thm-4.5.4)。

**顺便记住这个例子的数**：$\rho(A)=0.6$，两个圆盘半径分别是 $0.4$ 与 $0.9$，圆心在 $0$ 与 $1$。注意 $\rho(A)=0.6$ **大于**第 1 个半径 $0.4$——半径只是「圆心到特征值的偏移上界」，它本身不是范数，拿它和 $\rho$ 比大小没有意义。真正的矩阵范数是 $\|A\|_\infty=\max\{0.4+0,\ 0.9+1\}=1.9$、$\|A\|_1=\max\{0+0.9,\ 0.4+1\}=1.4$，而 $\rho(A)=0.6\le1.4\le1.9$ ✓，[定理 4.5.1](#thm-4.5.1) 安然无恙。**「圆盘半径」与「范数」是两个不同的对象，别混。**
:::
:::

::: thm 定理 4.5.4（课件原文）· 盖尔圆盘定理续：连通区域的计数 {#thm-4.5.4}

设 $A=(a_{ij})\in\mathbb C^{n\times n}$ 的 $n$ 个盖尔圆盘为 $G_1,\cdots,G_n$，若其中的 $k$ 个盖尔圆盘的并集形成一个**连通的区域**，且该区域与其余 $n-k$ 个圆盘**都不相交**，则此连通域内**恰有 $k$ 个特征值**。

特别地，孤立盖尔圆内有且仅有一个特征值。
:::

::: proof 证明（课件原文，本编补「特征值连续依赖 $\varepsilon$」的依据）

记 $D=\operatorname{diag}(a_{11},a_{22},\cdots,a_{nn})$，$B=A-D$（$B$ 就是「非对角部分」）。令

$$A(\varepsilon)=D+\varepsilon B,\qquad \varepsilon\in[0,1],$$

则 $A(0)=D$、$A(1)=A$。

**关键观察**：$A(\varepsilon)$ 与 $A$ 的**对角元相同**，故圆心相同；$A(\varepsilon)$ 的盖尔圆半径是 $A$ 的 $\varepsilon$ 倍（$\varepsilon\delta_i\le\delta_i$），故 $A(\varepsilon)$ 的每个盖尔圆都**位于** $A$ 的对应圆盘**内部**。

**第二步**：矩阵 $A(\varepsilon)$ 的特征根**连续地依赖于 $\varepsilon$**（本编补依据：$A(\varepsilon)$ 的元素是 $\varepsilon$ 的多项式，特征多项式的系数因而连续依赖 $\varepsilon$；而多项式的根连续依赖其系数——这是代数学基本定理的连续性推论，也可用 Rouché 定理直接证）。于是 $n$ 个特征值随 $\varepsilon$ 从 $0$ 走到 $1$ 时描出 $n$ 条**连续曲线**：

- 起点（$\varepsilon=0$）：$A(0)=D$ 的特征值就是 $n$ 个对角元 $a_{11},\cdots,a_{nn}$，**每个圆盘里恰好一个起点**（就在圆心上）；
- 终点（$\varepsilon=1$）：$A(1)=A$ 的特征值。

**第三步**：由 [定理 4.5.3](#thm-4.5.3)，对每个 $\varepsilon$，$A(\varepsilon)$ 的全部特征值都在 $\bigcup_iG_i$ 内（$A(\varepsilon)$ 的圆盘更小，当然也在里面）。所以这 $n$ 条曲线**不能跑出 $n$ 个圆盘的并集**。

**第四步**：设 $k$ 个圆盘的并集 $U$ 连通，且与其余圆盘不相交。$U$ 里有 $k$ 个起点（$k$ 个圆心），$U$ 外有 $n-k$ 个起点。曲线连续且不能跨出并集，而 $U$ 与外部之间**没有通道**（$U$ 与其余圆盘不相交，并集之外是空白），故：

- 从 $U$ 内出发的 $k$ 条曲线永远留在 $U$ 内；
- 从 $U$ 外出发的 $n-k$ 条曲线永远留在 $U$ 外。

于是 $U$ 内恰有 $k$ 条曲线的终点，即**恰有 $k$ 个特征值**（按代数重数计）。特别地取 $k=1$，孤立圆盘内恰有一个特征值。∎

**证明的要点**：「**连续形变 + 不能越界 = 计数不变**」。这是一个拓扑论证：不去解方程，而是让矩阵从「最好算的 $D$」连续变到「要研究的 $A$」，盯着特征值曲线看它们怎么跑。这条路子在矩阵分析里反复出现（[3.8](../ch03/sec38b.md#thm-3.8.5j) 的 Jordan 形、本章 4.6 的 Abel 定理都是同一思路）。
:::

## 4.5.5 推论：非奇异、可对角化、实特征值

定理 4.5.3 与 4.5.4 一放出去，四种常见判断立刻变成「看圆盘」。

::: cor 推论 4.5.1（课件原文）· 零不在并集里 ⟹ 非奇异 {#cor-4.5.1}

设矩阵 $A=(a_{ij})\in\mathbb C^{n\times n}$ 的 $n$ 个盖尔圆盘为 $G_1,\cdots,G_n$，若原点 $0\notin\bigcup_iG_i$，则矩阵 $A$ 为非奇异矩阵。
:::

::: proof 证明（本编补）

反设 $A$ 奇异，则 $0$ 是 $A$ 的特征值。由 [定理 4.5.3](#thm-4.5.3)，$0\in\bigcup_iG_i$，与假设矛盾。∎

**这就是「对角占优 ⟹ 可逆」的几何版本**：原点离每个圆心都超过半径，特征值就碰不到原点。
:::

::: cor 推论 4.5.2（课件原文）· 对角占优 ⟹ 非奇异 {#cor-4.5.2}

设矩阵 $A=(a_{ij})\in\mathbb C^{n\times n}$ 是**对角占优**矩阵，即对 $i=1,\cdots,n$ 有

$$|a_{ii}|\gt\sum_{j=1,\,j\ne i}^{n}|a_{ij}|\quad(\text{行对角占优}),\qquad\text{或}\qquad |a_{ii}|\gt\sum_{i=1,\,i\ne j}^{n}|a_{ij}|\quad(\text{列对角占优}),$$

则矩阵 $A$ 非奇异。
:::

::: proof 证明（本编补：两种占优各一句话）

**行对角占优**：条件恰是 $|a_{ii}|\gt\delta_i$，即**原点不在第 $i$ 个圆盘内**（圆心 $a_{ii}$ 到原点的距离大于半径）。对每个 $i$ 都成立，故 $0\notin\bigcup_iG_i$，由 [推论 4.5.1](#cor-4.5.1) 得 $A$ 非奇异。

**列对角占优**：对 $A^{\mathrm T}$ 用同一句话——$A^{\mathrm T}$ 行对角占优，故 $A^{\mathrm T}$ 非奇异，而 $\det A=\det A^{\mathrm T}\ne0$。∎

**注意课件这里的两个笔误**（见[勘误 E4.10](errata.md)）：(1)「对即 $i=1,\cdots,n$」多了一个「即」字；(2) 列占优的求和下标写成 $\sum_{i=1,i\ne j}^{n}$，与行占优的 $\sum_{j=1,j\ne i}^n$ 混用了同一个指标——正确的写法是「固定 $j$、对 $i\ne j$ 求和」。正文已按正确写法照录。
:::

::: cor 推论 4.5.3（课件原文）· 孤立圆 ⟹ 特征值互异、全分离 ⟹ 单纯 {#cor-4.5.3}

若复方阵 $A$ 有 $k$ 个孤立的盖尔圆，则它**至少有 $k$ 个互异**的特征值。特别地，若矩阵 $A$ 的所有盖尔圆两两互不相交，则 $A$ 是**单纯矩阵**。

**本编补一句**：$k$ 个孤立圆给出 $k$ 个互异特征值，但**不能**给出「$A$ 可对角化」——剩下 $n-k$ 个特征值仍可能带 Jordan 块。只有当 $k=n$（两两互不相交）时，$n$ 个特征值全部互异，$A$ 才一定是单纯的。
:::

::: proof 证明（本编补）

设 $G_{i_1},\cdots,G_{i_k}$ 是孤立圆盘（每个与其余所有圆盘不相交）。对每个孤立圆取 $k=1$ 用 [定理 4.5.4](#thm-4.5.4)：它里面恰有一个特征值。$k$ 个互不相交的圆盘各含一个，故至少 $k$ 个互异特征值。

$k=n$ 时，$n$ 个特征值两两互异，其几何重数与代数重数都是 $1$，由 [定理 3.6.1](../ch03/sec36.md#thm-3.6.1) 的五条等价刻画（第 $n$ 个互异特征值 $\Rightarrow$ 可对角化），$A$ 单纯。∎
:::

::: cor 推论 4.5.4（课件原文）· 实方阵：孤立圆给实特征值 {#cor-4.5.4}

若实方阵 $A$ 有 $k$ 个孤立的盖尔圆，则它**至少有 $k$ 个互异的实特征值**。特别地，若矩阵 $A$ 的所有盖尔圆两两互不相交，则它有至少 $n$ 个互异的实特征值。

**本编补一句**：这里的「$k$ 个孤立圆给 $k$ 个实特征值」比 [推论 4.5.3](#cor-4.5.3) 强，强在**实**。原因是实方阵的圆盘**关于实轴对称**（圆心 $a_{ii}$ 是实数、半径是实数），所以共轭配对的两个非实特征值必须落在同一组对称的圆盘里——孤立圆只能装实特征值。
:::

::: proof 证明（本编补）

设 $G_{i_0}$ 是孤立圆。由 [定理 4.5.4](#thm-4.5.4)，$G_{i_0}$ 内恰有一个特征值 $\lambda$。$A$ 实，故 $\overline\lambda$ 也是 $A$ 的特征值，且 $\overline\lambda$ 也落在 $G_{i_0}$ 内（$G_{i_0}$ 关于实轴对称，$\lambda\in G_{i_0}\Rightarrow\overline\lambda\in G_{i_0}$）。$G_{i_0}$ 里只有一个特征值（计重数），故 $\lambda=\overline\lambda$，即 $\lambda$ 是实数。对 $k$ 个孤立圆各做一次，得 $k$ 个互异实特征值。∎
:::

::: ex 例 4.5.6（课件原文）· 证明 $A$ 是单纯矩阵 {#ex-4.5.6}

证明 $n$ 阶矩阵 $A$ 是单纯矩阵，其中

$$A=\begin{bmatrix}2&\frac1n&\frac1n&\cdots&\frac1n\\[2pt]\frac1n&4&\frac1n&\cdots&\frac1n\\[2pt]\vdots&&\ddots&&\vdots\\[2pt]\frac1n&\frac1n&\frac1n&\cdots&2n\end{bmatrix},$$

即 $a_{ii}=2i$，$a_{ij}=\frac1n\ (i\ne j)$。

::: sol 解答（本编补）

**圆盘**：第 $i$ 个圆心是 $2i$，半径是「同行 $n-1$ 个非对角元之和」

$$\delta_i=(n-1)\cdot\frac1n=1-\frac1n\lt1 .$$

**相邻圆盘分离**：相邻圆心距离为 $2$，两个半径之和为 $2\big(1-\tfrac1n\big)=2-\tfrac2n\lt2$，故相邻圆盘不相交；不相邻的圆心距离更大（$\ge4$），更不可能相交。于是 $n$ 个圆盘**两两互不相交**。

**结论**：由 [推论 4.5.3](#cor-4.5.3)，$A$ 有 $n$ 个互异特征值，故 $A$ 是单纯矩阵。∎

**要点**：这个例子说明「对角元增长得足够快」就能保证可对角化——半径固定为 $1-\frac1n$，而圆心以 $2$ 的步长跑开，永远不会撞上。**圆盘法在这里代替了「解 $n$ 次方程」这件根本做不到的事。**
:::
:::

::: ex 例 4.5.7（课件原文）· 证明至少有两个实特征值 {#ex-4.5.7}

证明矩阵 $A$ 至少有两个实特征值，其中

$$A=\begin{bmatrix}9&1&-2&1\\0&8&1&1\\-1&0&4&0\\1&0&0&1\end{bmatrix}.$$

::: sol 解答（本编补：用「实系数多项式的根」补齐计数）

**圆盘**（全在实轴上，因为对角元都是实数）：

$$G_1:\ |z-9|\le4=[5,13],\quad G_2:\ |z-8|\le2=[6,10],\quad G_3:\ |z-4|\le1=[3,5],\quad G_4:\ |z-1|\le1=[0,2].$$

**第一步：至少有一个实特征值**。$G_4=[0,2]$ 与其余三个圆盘都不相交（$G_3$ 从 $3$ 开始）。由 [定理 4.5.4](#thm-4.5.4)，$G_4$ 内恰有一个特征值；由 [推论 4.5.4](#cor-4.5.4)，它是**实数**。故至少一个实特征值 $\lambda_1$。

**第二步：实特征值的个数是偶数**。$A$ 是实方阵，特征多项式是**实系数多项式**；实系数多项式的非实根必成**共轭对**出现（若 $\lambda$ 是根，则 $\overline\lambda$ 也是根，且重数相同）。$n=4$ 时，非实特征值的个数是偶数，故**实特征值（计重数）的个数与 $4$ 同奇偶，也是偶数**。

**结论**：实特征值个数是正偶数，故至少 $2$ 个。∎

**数值核对**：$Sp(A)\approx\{9.441,\ 8.067,\ 3.608,\ 0.884\}$——四个全是实数（`verify_teaching_examples.py`）。第一、二个在 $G_1\cup G_2$ 的连通区里，第三个在 $G_3$，第四个在 $G_4$。

**技巧总结**：单纯靠盖尔圆只能数出「$G_4$ 里有一个」，数不出第二个。补上「实系数多项式的根共轭配对」这条代数事实，才把 $1$ 抬到 $2$。**几何给位置，代数给奇偶**——两条一起用才能定量。
:::

## 4.5.6 把圆盘挪一挪：相似变换的调参

圆盘位置由「对角元 + 同行元素和」决定，都是**相似不变量吗**？不是——相似变换会改变非对角元，从而改变半径。于是有了本节最实用的一招：**主动挑一个相似变换，把想孤立的圆盘挤出去。**

::: note 注 3（课件原文）· 用 $DAD^{-1}$ 调整圆盘 {#note-4.5-diag}

在使用盖尔圆估计矩阵 $A$ 的特征值时，我们总希望获得更多的孤立圆，这时可采取如下方法：取合适的非零实数 $d_1,\cdots,d_n$，并令

$$D=\operatorname{diag}(d_1,\cdots,d_n),$$

则

$$B=DAD^{-1}=\Big(a_{ij}\frac{d_i}{d_j}\Big)_{n\times n},$$

显然，矩阵 $A$ 与 $B$ **相似**，它们具有相同的特征值。

**本编补：这个公式怎么来的**。$D^{-1}$ 的第 $j$ 列是 $\frac{1}{d_j}e_j$，故 $AD^{-1}$ 的第 $j$ 列是 $\frac1{d_j}$（$A$ 的第 $j$ 列）；再左乘 $D$（第 $i$ 行乘 $d_i$），得 $(DAD^{-1})_{ij}=\frac{d_i}{d_j}a_{ij}$。**对角元不变**（$i=j$ 时 $\frac{d_i}{d_i}=1$），所以圆心不动，只有半径变。
:::

::: note 注 3（续）（课件原文）· 怎么挑 $d_i$ {#note-4.5-diag2}

通常 $d_i$ 的选取办法为：

1. 若取 $d_i\lt1$、其余元素为 $1$，则第 $i$ 个盖尔圆 $G_i$ 会**缩小**，其余所有盖尔圆会**放大**；
2. 若取 $d_i\gt1$、其余元素为 $1$，则第 $i$ 个盖尔圆 $G_i$ 会**放大**，其余所有盖尔圆会**缩小**。

**本编补验算**：设 $d_i=t$、其余 $d_j=1$。

- $B$ 的第 $i$ 行：$b_{ij}=a_{ij}\frac{t}{1}=t\,a_{ij}\ (j\ne i)$，故第 $i$ 个圆盘半径变为 $t\,\delta_i$；
- $B$ 的第 $k$ 行（$k\ne i$）：$b_{ki}=a_{ki}\frac{1}{t}$（被 $t$ 除），$b_{kj}=a_{kj}\ (j\ne i,k)$，故第 $k$ 个圆盘半径变为 $\delta_k-|a_{ki}|+\frac{|a_{ki}|}{t}$。

于是 $t\lt1$ 时第 $i$ 个半径 $\times t$（缩小）、别的圆盘都多了一项被放大的 $|a_{ki}|/t$（放大）；$t\gt1$ 时反过来。**注 3 的直觉是「牺牲一个、孤立一个」**：想抓住第 $i$ 个特征值，就把它自己的圆盘放大成一块「领地」，同时把别人的圆盘挤小。
:::

::: ex 例 4.5.8（课件原文）· 用 $D$ 把三个圆盘分开 {#ex-4.5.8}

估计复方阵 $A=\begin{bmatrix}9&1&1\\1&i&1\\1&1&3\end{bmatrix}$ 的特征值分布范围。

::: sol 解答（本编补完整计算与比较）

**先看原位（$D=I$）**：$\delta_1=2,\ \delta_2=2,\ \delta_3=2$，故

$$G_1:\ |z-9|\le2,\qquad G_2:\ |z-i|\le2,\qquad G_3:\ |z-3|\le2 .$$

$G_1=[7,11]$ 与另两个都不相交（到 $i$ 的距离 $\sqrt{82}\approx9.06$，到 $3$ 的距离 $6$）；但 $G_2$（以 $i$ 为心、半径 $2$）与 $G_3$（$[1,5]$）**相交**（$|3-i|=\sqrt{10}\approx3.16\lt2+2$）。所以只能孤立 $G_1$，得到「一个特征值在 $[7,11]$」。

**试 $D=\operatorname{diag}(2,1,1)$**：$b_{ij}=a_{ij}\frac{d_i}{d_j}$，故第 $1$ 行乘 $2$、第 $1$ 列除 $2$：

$$B=\begin{bmatrix}9&2&2\\[2pt]\tfrac12&i&1\\[2pt]\tfrac12&1&3\end{bmatrix},\qquad G_1':\ |z-9|\le4,\quad G_2':\ |z-i|\le1.5,\quad G_3':\ |z-3|\le1.5 .$$

检查分离：$G_1'=[5,13]$，到 $G_2'$ 的距离 $|9-i|-4-1.5\approx9.06-5.5\gt0$ ✓；$G_2'$ 与 $G_3'$ 的距离 $|3-i|-(1.5+1.5)\approx3.16-3=0.16\gt0$ ✓；$G_1'$ 与 $G_3'$：$6-5.5=0.5\gt0$ ✓。**三个圆盘两两不相交**，故 $A$ 有三个互异特征值，分别落在 $[5,13]$、以 $i$ 为心半径 $1.5$ 的圆盘、$[1.5,4.5]$ 内。

**对照 $D=\operatorname{diag}(0.5,1,1)$**（课件给的另一种尝试）：$G_1''\colon|z-9|\le1$，而 $G_2''\colon|z-i|\le3$、$G_3''\colon|z-3|\le3$——$G_2''$ 与 $G_3''$ 距离 $3.16\lt6$，**合并成一片**，只剩 $G_1''$ 孤立。**孤立圆反而少了**。

**结论**：$d_1=2$ 优于 $d_1=0.5$。方向是注 3（续）的第 2 条：**放大第 $1$ 个圆盘、缩小其余，让 $G_1$ 独占一片，同时把 $G_2,G_3$ 压到互不相交。**

**数值核对**：$Sp(A)\approx\{9.3038+0.0151i,\ 3.0320+0.0563i,\ -0.3357+0.9285i\}$。第一个在 $G_1'$（心 $9$、半径 $4$）内，$|z-9|\approx0.304\le4$ ✓；第二个在 $G_3'$（心 $3$、半径 $1.5$）内，$|z-3|\approx0.065\le1.5$ ✓；第三个在 $G_2'$（心 $i$、半径 $1.5$）内，$|z-i|\approx0.343\le1.5$ ✓。∎

::: note 读图之后：三件事被你看见了 {#note-4.5-figread}

图里左半（$D=I$）与右半（$D=\operatorname{diag}(2,1,1)$）用的是**同一个矩阵 $A$**（[例 4.5.8](#ex-4.5.8)）、**同一组特征值**。差别只有三处，而这三处正好对应本节的三条结论：

1. **圆心一个没动**——圆心就是对角元 $a_{ii}$，而 $DAD^{-1}$ 的对角元不变（[注 3](#note-4.5-diag) 的 $(DAD^{-1})_{ii}=a_{ii}\cdot\frac{d_i}{d_i}=a_{ii}$）；
2. **半径变了**——第 $i$ 行整体乘 $d_i$、第 $i$ 列整体除以 $d_i$，半径从 $\delta_i$ 变成「按新元素的绝对值求和」；
3. **能断言的结论变强了**——从「1 个特征值在 $[7,11]$」升级到「3 个特征值互异」。这不是估得更准了（圆盘仍然只是**上界**），而是**分离条件被满足了**（[定理 4.5.4](#thm-4.5.4) 有了用武之地）。

::: ex 例 4.5.9（课件原文）· 圆盘法失效的样子 {#ex-4.5.9}

利用盖尔圆定理考察矩阵 $A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ 的特征值分布。

::: sol 解答（本编补：说明「为什么再怎么调也没用」）

**原位**：$\delta_1=\delta_2=1$，故

$$G_1:\ |z|\le1,\qquad G_2:\ |z|\le1 .$$

两个圆盘**完全重合**，都是单位圆盘。特征值是 $\pm i$，正好落在**边界**上。

**调参**：取 $D=\operatorname{diag}(k,1)$，则

$$B=DAD^{-1}=\begin{bmatrix}0&-k\\[2pt]\tfrac1k&0\end{bmatrix},\qquad G_1:\ |z|\le k,\quad G_2:\ |z|\le\tfrac1k .$$

两个圆盘**仍然同圆心**（都还是原点），只是半径一涨一落。$k=1$ 时最小（两个半径都是 $1$）；$k$ 取任何值，两个圆盘都**互相包含或相交**，永远无法分开。

**结论**：盖尔圆定理在这里给出 $\{\pm i\}\subset\{|z|\le1\}$——正确，但**什么也没排除**。这个矩阵满足 $\rho(A)=1$、$\|A\|_2=1$、特征值恰在单位圆上，是「谱半径顶到范数上界」的极端情形。

**数值核对**：$\lambda=\pm i$，$|\lambda|=1=\|A\|_2=\|A\|_1=\|A\|_\infty$ ✓。

**为什么值得记住这个例子**：它标出了盖尔圆的**盲区**——圆盘只看得见「对角元 + 同行非对角元之和」，看不见**结构**。$A$ 是旋转 $90^\circ$ 的正交阵，它的「大小」完全藏在非对角元里，而对角元全是 $0$，两个圆心因此重合。遇到这种矩阵，要么用 [4.5.2](#sec-4.5.2) 的范数界，要么直接算特征值——**盖尔圆不是万能的**，它只擅长「对角占优」那一类。∎
:::
:::

::: ex 例 4.5.C（新增）· 三种估法的精度比较 {#ex-4.5.C}

设 $A=\begin{bmatrix}4&1&0\\1&4&1\\0&1&4\end{bmatrix}$。(a) 算 $\rho(A)$ 与 $\|A\|_1,\|A\|_\infty,\|A\|_F$，用 [定理 4.5.1](#thm-4.5.1) 与 [补充定理](#thm-4.5-extra) 各给出一个上界；(b) 写出三个盖尔圆盘，判断它们是否孤立；(c) 比较三种估法的松紧。

::: sol 解答

**(a)** $A$ 实对称三对角，特征值 $4+2\cos\frac{k\pi}{4}\ (k=1,2,3)$，即 $4+\sqrt2\approx5.414$、$4$、$4-\sqrt2\approx2.586$，故 $\rho(A)=4+\sqrt2\approx5.414$。

$\|A\|_1=\|A\|_\infty=\max\{5,6,5\}=6$；$\|A\|_F^2=3\cdot4^2+4\cdot1^2=48+4=52$，故 $\|A\|_F=\sqrt{52}\approx7.211$。

界：$\rho\le\|A\|_1=\|A\|_\infty=6$；又 $\sum|\lambda|^2=(4+\sqrt2)^2+4^2+(4-\sqrt2)^2=(18+8\sqrt2)+16+(18-8\sqrt2)=52=\|A\|_F^2$，**取等**（$A$ 实对称，正规）。

**(b)** 三个圆心都是 $4$，半径 $\delta_1=1,\delta_2=2,\delta_3=1$，故

$$G_1=G_3=[3,5],\qquad G_2=[2,6].$$

$G_2$ 包含 $G_1,G_3$，三个圆盘**完全重叠**，一个孤立圆也没有。定理 4.5.3 只给出「三个特征值都在 $[2,6]$」，而这个结论**已经是最优的**（$5.414$ 与 $2.586$ 恰好落在端点附近）。

**(c)** 三种估法给出的上界：$\rho\le6$（行和 / 列和）、$\rho\le\sqrt{52}\approx7.211$（$F$-范数）、$\rho\in[2,6]$（盖尔圆）。

- $F$-范数**最松**：它把「全部能量」都算上，而特征值只用得上对角那份；
- 行和 / 列和给出 $6$，比真值 $5.414$ 高 $11\%$；
- 盖尔圆给出**区间** $[2,6]$，不仅给上界还给下界（这是范数界做不到的），且区间端点恰好夹住两个极端特征值。

**要点**：**要「一个数」用范数，要「区间」用盖尔圆，要「精确值」只能算特征多项式。** 三者的代价也依次上升。∎
:::
:::

## 4.5 小结与常见错误

- **一条主线**：**定义**（[谱与谱半径](#def-4.5.1)）$\Rightarrow$ **与范数的双向夹逼**（[$\rho\le\|A\|$](#thm-4.5.1)、[$\inf\|A\|=\rho$](#thm-4.5.2)）$\Rightarrow$ **三个显式界**（[行和、列和、$F$](#thm-4.5-extra)，[实部虚部](#note-4.5-realimag)）$\Rightarrow$ **圆盘**（[定义](#def-4.5.2)、[定理 4.5.3](#thm-4.5.3)、[定理 4.5.4](#thm-4.5.4)）$\Rightarrow$ **四条推论**（[非奇异](#cor-4.5.1)、[对角占优](#cor-4.5.2)、[互异](#cor-4.5.3)、[实特征值](#cor-4.5.4)）$\Rightarrow$ **相似调参**（[注 3](#note-4.5-diag)）。
- **一条对应**：**谱半径 $\leftrightarrow$ 最小的那把矩阵范数；盖尔圆 $\leftrightarrow$ 特征值的「领地」**。前者只给一个数，后者给一整块区域；前者对正规矩阵精确，后者对对角占优矩阵精确。

::: think 常见错误清单 · 自查五条

1. **把谱半径当矩阵范数**：$\rho$ 不满足正定性（幂零阵 $\rho=0$ 但 $A\ne O$）也不满足三角不等式（[思考](#think-4.5-rhomorphism) 的反例 $\rho(A+B)=1\gt0$）；
2. **把圆盘半径当范数**：$\delta_i=\sum_{j\ne i}|a_{ij}|$ 是**半径**，不是范数；[例 4.5.5](#ex-4.5.5) 里 $\rho(A)=0.6$ 比第 $1$ 个半径 $0.4$ 还大，看着像违反「$\rho\le$ 范数」——其实不矛盾：$0.4$ 根本不是范数，真正的范数是 $\|A\|_\infty=1.9$；
3. **以为每个圆盘里恰好一个特征值**：只有**孤立**（且与其余圆盘都不相交）的圆盘才有这个保证（[定理 4.5.4](#thm-4.5.4)）；一般情形见 [例 4.5.5](#ex-4.5.5)（一个装两个、一个空着）；
4. **忘记「行圆」用行和、「列圆」用列和**：圆心都是对角元，半径一个按行、一个按列（[例 4.5.4](#ex-4.5.4)）；两者取交才是完整结论；
5. **以为 $DAD^{-1}$ 会改变特征值**：$D$ 只改圆盘、不改谱（[注 3](#note-4.5-diag)）；调参的目标是「多几个孤立圆」，不是「换特征值」。
:::

::: ex 即时自测（不看上文，6 分钟）{#ex-4.5.quiz}

1. 写出谱与谱半径的定义；举一个 $\rho(A)=0$ 但 $A\ne O$ 的例子。
2. 证明 $\rho(A)\le\|A\|$，并指出哪一步必须借「相容的向量范数」。
3. 写出三个显式界；$F$-范数那条的等号条件是什么？
4. 写出盖尔圆盘的定义（圆心与半径各是什么）；叙述定理 4.5.4 的计数结论。
5. 为什么 $|a_{ii}|\gt\delta_i$ 能推出 $A$ 可逆？用一句几何话说明。
6. 已知 $A$ 的三个圆盘为 $[2,4]$、$[10,12]$、$[2.5,3.5]$，能断定什么？

::: sol 参考要点

1. $Sp(A)=\{\lambda\mid\lambda\text{ 是特征值}\}$，$\rho(A)=\max|\lambda|$；$A=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，$\rho=0$ 但 $A\ne O$（幂零）。
2. $Ax=\lambda x\Rightarrow|\lambda|\|x\|=\|Ax\|\le\|A\|\|x\|$；「$\|Ax\|\le\|A\|\|x\|$」这一步需要与矩阵范数相容的向量范数（[定理 4.3.1](sec43.md#thm-4.3.1)）。
3. $|\lambda|\le\|A\|_1$、$|\lambda|\le\|A\|_\infty$、$\sum|\lambda_l|^2\le\|A\|_F^2$；等号 $\iff A$ 正规。
4. 圆心 $a_{ii}$、半径 $\delta_i=\sum_{j\ne i}|a_{ij}|$；$k$ 个圆盘连成一片且与其余圆盘不相交 $\Rightarrow$ 该区域恰有 $k$ 个特征值，孤立圆恰有一个。
5. $|a_{ii}|\gt\delta_i$ 意味着第 $i$ 个圆盘不包含原点；若每个 $i$ 都这样，原点不在任何圆盘内，而所有特征值都在圆盘内，故 $0$ 不是特征值，$A$ 可逆。
6. 第三个圆盘 $[2.5,3.5]$ 与 $[2,4]$ 相交（$[2,4]$ 包含 $[2.5,3.5]$），故只有 $[10,12]$ 是孤立的：至少有一个特征值在 $[10,12]$ 内，且它是实的（实方阵时）。其余两个特征值都在 $[2,4]$ 内。
:::
