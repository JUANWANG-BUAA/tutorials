# 第四章 · 矩阵分析（4.1–4.3、4.5–4.6）

前三章一直在回答「结构」问题：空间长什么样（第一章）、映射怎么用矩阵表示（第二章）、矩阵能拆成什么（第三章）。这一章换一个问题，也是分析学最朴素的问题：**它有多大？**

一旦问出「多大」，一连串新问题就跟着来了：两个向量差多少？一个矩阵把向量最多放大几倍？矩阵稍微改一点，特征值会跑多远？$I-A$ 什么时候可逆、逆有多大？矩阵能不能取指数、能不能求导积分？——课件开篇把这一章的内容列成一张九格清单，正是这条线索的展开：

| 矩阵范数 | 矩阵函数 |
| 相容范数 | 函数矩阵 |
| 矩阵扰动分析 | 应用：主元分析法 |
| 特征值估计 | |

**本章已整理五节**，分两批入库：

- **第一批（4.1–4.3，度量地基）**：先把「长度」公理化（4.1），再让矩阵也有长度并把乘法算进去（4.2），最后要求矩阵的尺子与向量的尺子配套，从而得到算子范数、三个显式公式、Rayleigh 商与逆矩阵的扰动估计（4.3）；
- **第二批（4.5–4.6，从「量大小」走向「量位置」与「量极限」）**：4.5 不再问「特征值是多少」而问「它在哪里」——谱半径与范数的双向夹逼、三个显式界、盖尔圆盘与它的四条推论；4.6 把「逆矩阵」写成「无穷级数」，用谱半径判定矩阵幂级数的敛散，并以 Neumann 级数收尾。**这两节是 4.4 之后所有内容（矩阵函数、函数矩阵、主元分析）的技术前提**：没有 $\rho(A)\lt1\iff\sum A^m$ 收敛，就没有 $e^A$ 的定义。

## 一条主线

> **第四章给矩阵装上一把尺子，然后只用这把尺子做三件事：量大小、量放大、量误差。**
>
> - **4.1 造尺子**：长度不必来自内积。只要满足正定、齐次、三角不等式三条公理，就是范数；$p$-范数一族说明**同一空间可以有很多把尺子**，而有限维空间里任意两把尺子只差两个常数因子（等价）。
> - **4.2 给矩阵也配尺子**：矩阵拉直就是向量，所以先有三条公理的「矩阵的向量范数」；但矩阵还会相乘，于是加第四条**乘法相容性**，才叫矩阵范数。Frobenius 范数是最好算的一把，元素和范数也合格，而「最大元素」不合格（反例只有 $2\times2$）。
> - **4.3 让两把尺子配套**：$\|Ax\|_v\le\|A\|_m\|x\|_v$ 是「配套」的定义。给定矩阵范数一定能配出向量范数（$\|x\|_v=\|x\alpha^{\mathrm T}\|_m$）；给定向量范数一定能配出矩阵范数，而且配得**最紧**——诱导范数 $\|A\|=\max_{\|x\|=1}\|Ax\|$。三种常用向量范数诱导出三个可手算的公式：**列和、行和、谱**。
> - **4.3 后半**：算子范数的几何含义是「单位球被 $A$ 拉成的像离原点最远有多远」；把它用在 Hermite 矩阵上，就是 Rayleigh 商与 Courant–Fischer 极大极小定理；用在 $I-A$ 上，就是 $\|A\|\lt 1$ 时逆矩阵存在且逆的范数被 $1/(1-\|A\|)$ 控制——这是所有迭代法与扰动分析的起点。

> - **4.5 换一个问题：从「多大」到「在哪」**：特征值算不出来（$n$ 次方程无公式），就改问它在哪。谱半径 $\rho(A)$ 与任意矩阵范数**双向夹逼**——$\rho(A)\le\|A\|$ 恒成立，而只要肯为 $A$ 定制一把范数，$\|A\|$ 可以压到 $\rho(A)+\varepsilon$，所以 $\rho(A)=\inf\|\cdot\|$。换成行和 / 列和 / $F$-范数就得到三个可手算的界，其中 $F$-范数那条**取等 $\iff$ 正规**。要把握位置，就上**盖尔圆盘**：圆心是对角元、半径是同行非对角元之和，所有特征值落在这些圆盘的并集里；更进一步，$k$ 个圆盘连成一片且与其余不相交，那片区域里就**恰有 $k$ 个**特征值。调 $DAD^{-1}$ 不改特征值、只改圆盘，这是「把手边的圆盘挤开、多数几个」的标准手法。
> - **4.6 把逆写成级数**：矩阵级数的收敛完全由范数控制（$\sum\|A_k\|$ 收敛 $\Rightarrow$ 绝对收敛），而**幂级数**的敛散由 $\rho(A)$ 与收敛半径 $r$ 决定：$\rho(A)\lt r$ 绝对收敛、$\rho(A)\gt r$ 发散，边界要另算。两个端点情形是全部应用的来源——$r=\infty$ 时对**任意** $A$ 都收敛（这就是 $e^A$ 的定义依据）；$r=1$ 时给出 **Neumann 级数** $\sum_{m\ge0}A^m=(I-A)^{-1}\ (\rho(A)\lt1)$，把 4.3 的「$I-A$ 可逆」升级成「逆的显式表达式」。

**四把尺子的关系可以画成一条链**：

$$\underbrace{\text{向量范数}}_{\text{三条公理}}\ \Longrightarrow\ \underbrace{\text{矩阵的向量范数}}_{\text{拉直}}\ \Longrightarrow\ \underbrace{\text{矩阵范数}}_{\text{加乘法相容}}\ \Longrightarrow\ \underbrace{\text{诱导范数}}_{\text{与向量范数配套且最紧}}\ \Longrightarrow\ \underbrace{\text{列和 / 行和 / 谱}}_{\text{三个可手算的公式}}.$$

链的每一环都只加一个条件，所以**越往后越少、越往后越好用**：向量范数无穷多，矩阵范数已经少了一批（最大元素范数被淘汰），诱导范数更少（元素和范数、Frobenius 范数都不是诱导范数），而最右边只剩三个能写成分量的公式。

| $\lambda_n\le R(x)\le\lambda_1$（[注 4](sec43.md#note-4.3-rayleigh)） | [例 4.3.C](sec43.md#ex-4.3.C)：$2\times2$ 实对称阵 | 特征值是 Rayleigh 商的最大 / 最小值 |

| $\rho(A)\lt r\Rightarrow$ 绝对收敛（[定理 4.6.5](sec46.md#thm-4.6.5)） | [Abel 判别图版](sec46.md#fig-abel-anchor)：谱在圆内 / 圆上 / 圆外三种 | 只看最远的特征值，不看范数读数 |

## 与前后章的联系

- **向后看**：[1.4](../ch01/sec14.md) 的内积给出第一个范数 $\|x\|=\sqrt{(x,x)}$，[1.5](../ch01/sec15.md) 的长度与夹角是它的几何读法；本章把「长度」从内积里解放出来，只保留三条公理。第三章的 Schur 分解（[3.5](../ch03/sec35.md)）与谱分解（[3.7](../ch03/sec37.md)）在本章反复出场：谱范数 $\|A\|_2=\sqrt{\lambda_{\max}(A^{\mathrm H}A)}$ 就是 $A^{\mathrm H}A$ 的最大特征值开方，Courant–Fischer 定理则是谱分解的「变分版」；4.5 的「$F$-范数界取等 $\iff$ 正规」直接用的就是 3.5 的 Schur 引理，4.5.5 的「孤立圆 $\Rightarrow$ 单纯」用的则是 [3.6](../ch03/sec36.md#thm-3.6.1) 的五条判据，4.6.3 的 $A^k\to O$ 判据用的是 [3.8](../ch03/sec38b.md#thm-3.8.5j) 的 Jordan 标准形。
- **本章内部的一条链**：4.1–4.3 造尺子与配尺子 → 4.5 用尺子量「特征值在哪」（[定理 4.5.1](sec45.md#thm-4.5.1) 要 [定理 4.3.1](sec43.md#thm-4.3.1) 的相容向量范数；[定理 4.5.2](sec45.md#thm-4.5.2) 要 [例 4.2.3](sec42.md#ex-4.2.3) 的相似造范数）→ 4.6 用尺子量「级数收不收敛」（[定理 4.6.5](sec46.md#thm-4.6.5) 的核心一步就是 [定理 4.5.2](sec45.md#thm-4.5.2)）。**4.5 与 4.6 不是并列的两节，而是「4.5 造工具、4.6 用工具」**：Abel 型定理的证明里，没有 4.5.2 就迈不过去。
- **向前看**：4.7 及以后（矩阵函数、函数矩阵、主元分析）的入口就是本章的 [Neumann 级数](sec46.md#cor-4.6.5)——没有 $\rho(A)\lt1\iff\sum A^m$ 收敛且和为 $(I-A)^{-1}$，就没有 $e^A=\sum A^k/k!$ 的收敛保证（[推论 4.6.4](sec46.md#cor-4.6.4)），也就没有 $e^{At}$ 与线性系统的解。4.4 的矩阵扰动分析则把 4.5 的 Weyl 不等式（[定理 4.3.5](sec43.md#thm-4.3.5)）与本节的特征值界接上。
