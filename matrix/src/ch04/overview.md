# 第四章 · 矩阵分析（4.1–4.3）

前三章一直在回答「结构」问题：空间长什么样（第一章）、映射怎么用矩阵表示（第二章）、矩阵能拆成什么（第三章）。这一章换一个问题，也是分析学最朴素的问题：**它有多大？**

一旦问出「多大」，一连串新问题就跟着来了：两个向量差多少？一个矩阵把向量最多放大几倍？矩阵稍微改一点，特征值会跑多远？$I-A$ 什么时候可逆、逆有多大？矩阵能不能取指数、能不能求导积分？——课件开篇把这一章的内容列成一张九格清单，正是这条线索的展开：

| 左列 | 右列 |
|:--|:--|
| 向量范数 | 矩阵级数 |
| 矩阵范数 | 矩阵函数 |
| 相容范数 | 函数矩阵 |
| 矩阵扰动分析 | 应用：主元分析法 |
| 特征值估计 | |

**本编（第四章第一部分）只做前两行半：4.1 向量范数、4.2 矩阵范数、4.3 相容范数。** 这是整章的度量地基：先把「长度」公理化（4.1），再让矩阵也有长度并把乘法算进去（4.2），最后要求矩阵的尺子与向量的尺子配套，从而得到算子范数、三个显式公式、Rayleigh 商与逆矩阵的扰动估计（4.3）。4.4 及以后（矩阵级数、矩阵函数、函数矩阵、特征值估计、主元分析）待素材到位，按同一流程续写。

## 一条主线

> **第四章给矩阵装上一把尺子，然后只用这把尺子做三件事：量大小、量放大、量误差。**
>
> - **4.1 造尺子**：长度不必来自内积。只要满足正定、齐次、三角不等式三条公理，就是范数；$p$-范数一族说明**同一空间可以有很多把尺子**，而有限维空间里任意两把尺子只差两个常数因子（等价）。
> - **4.2 给矩阵也配尺子**：矩阵拉直就是向量，所以先有三条公理的「矩阵的向量范数」；但矩阵还会相乘，于是加第四条**乘法相容性**，才叫矩阵范数。Frobenius 范数是最好算的一把，元素和范数也合格，而「最大元素」不合格（反例只有 $2\times2$）。
> - **4.3 让两把尺子配套**：$\|Ax\|_v\le\|A\|_m\|x\|_v$ 是「配套」的定义。给定矩阵范数一定能配出向量范数（$\|x\|_v=\|x\alpha^{\mathrm T}\|_m$）；给定向量范数一定能配出矩阵范数，而且配得**最紧**——诱导范数 $\|A\|=\max_{\|x\|=1}\|Ax\|$。三种常用向量范数诱导出三个可手算的公式：**列和、行和、谱**。
> - **4.3 后半**：算子范数的几何含义是「单位球被 $A$ 拉成的像离原点最远有多远」；把它用在 Hermite 矩阵上，就是 Rayleigh 商与 Courant–Fischer 极大极小定理；用在 $I-A$ 上，就是 $\|A\|\lt 1$ 时逆矩阵存在且逆的范数被 $1/(1-\|A\|)$ 控制——这是所有迭代法与扰动分析的起点。

**四把尺子的关系可以画成一条链**：

$$\underbrace{\text{向量范数}}_{\text{三条公理}}\ \Longrightarrow\ \underbrace{\text{矩阵的向量范数}}_{\text{拉直}}\ \Longrightarrow\ \underbrace{\text{矩阵范数}}_{\text{加乘法相容}}\ \Longrightarrow\ \underbrace{\text{诱导范数}}_{\text{与向量范数配套且最紧}}\ \Longrightarrow\ \underbrace{\text{列和 / 行和 / 谱}}_{\text{三个可手算的公式}}.$$

链的每一环都只加一个条件，所以**越往后越少、越往后越好用**：向量范数无穷多，矩阵范数已经少了一批（最大元素范数被淘汰），诱导范数更少（元素和范数、Frobenius 范数都不是诱导范数），而最右边只剩三个能写成分量的公式。
