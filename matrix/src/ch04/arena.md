# 考场竞技场 · 第四章（4.1–4.6 特训）

第四章的考法与前三章不同：**它很少出“大证明”，更多是概念判断 + 小计算 + 一个套公式的估计**。老师在第 7 周课末说得很直白：第四章“比第三章还抽象，考试出题分数应该是最少的，但也是学习最难的”（10-22 01:30）。所以这里的策略不是“刷难题”，而是**把便宜分全部拿稳**：判断范数、手算四个范数、写对相容与逆的估计。

用法：先读[必考点清单](#arena4-must)，照着清单回正文补漏；然后关掉正文，按三轮计时赛走一遍；赛完按段位表复盘，错题送进[抢救室](#arena4-rescue)。

::: note 素材依据与诚实声明

本章五节 **只有课件、没有录播**（录像截止 2026-10-27，第四章尚未开讲），所以本页的考情依据只有两类：

- **B 级**：课堂原话中与本章直接联动的三条——第四章“分值最少、学习最难”（10-22 01:30）、第三章“分值最大”（10-13 00:26）、“复习按书不按 PPT”（10-13 01:29）。原话见[课堂口述与考点信号](../lecture-signals.md)。

## 二、第一轮 · 概念抢答（5 分钟 · 20 分）

规则：每题 2 分，只答“对 / 错”并给一句理由；只写对错不得分。

::: ex R1-1 · 范数与矩阵范数（10 连发）
1. $\|x\|=|x_1-x_2|$ 是 $\mathbb R^2$ 上的范数。
2. $\|x\|_\infty\le\|x\|_2\le\|x\|_1$。
3. $0\lt p\lt1$ 时 $\ell_p$ 是范数。
4. $\max|a_{ij}|$ 是矩阵范数。
5. $\sum\sum|a_{ij}|$ 是矩阵范数。
6. $\|\cdot\|_F$ 是诱导范数。
7. 任何矩阵范数都满足 $\|I\|=1$。
8. $\|A\|\lt1$ 时 $I-A$ 一定可逆。
9. $\|A\|_2\le\|A\|_F$ 对任意矩阵成立。
10. 相似变换可以改变谱半径。

::: sol 答案（每题 2 分：判断 1 分 + 理由 1 分）

1. **错**：正定性失效，$x=(1,1)\ne0$ 但 $\|x\|=0$。
2. **对**：这是 §4.1 的刻度表（[注](sec41.md#note-4.1-scale)）。
3. **错**：三角不等式失效，$x=(1,0),y=(0,1)$ 时 $2^{1/p}\gt2$。
4. **错**：不满足乘法相容（[反例](sec42.md#think-4.2-maxentry)）。
5. **对**：交叉项非负，$\|AB\|_{v1}\le\|A\|_{v1}\|B\|_{v1}$（[证明](sec42.md#think-4.2-sum)）。
6. **错**：$\|I_n\|_F=\sqrt n\ne1$（[注](sec43.md#note-4.3-hierarchy)）。
7. **错**：一般矩阵范数 $\|I\|\ge1$，$F$-范数是 $\sqrt n$（[注](sec43.md#note-4.3-identity)）。
8. **对**：[@thm-4.3.6]。
9. **对**：$\sigma_{\max}^2\le\sum\sigma_i^2$（[注](sec43.md#note-4.3-multi)）。
10. **错**：相似保持特征值，谱半径不变。
:::
:::

## 三、第二轮 · 计算擂台（25 分钟 · 45 分）

规则：每题 9 分；写出公式 3 分、代入 3 分、结果与验算 3 分。

::: ex R2-1 · 三个向量范数
设 $x=(2,-1,2)^{\mathrm T}$，求 $\|x\|_1,\|x\|_2,\|x\|_\infty$，并验证 $\|x\|_\infty\le\|x\|_2\le\|x\|_1$。

::: sol 答案
$5$；$3$；$2$。验证 $2\le3\le5$ ✓。
:::
:::

::: ex R2-2 · 四个矩阵范数
设 $A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，求 $\|A\|_1,\|A\|_\infty,\|A\|_F,\|A\|_2$，并验证 $\|A\|_2\le\|A\|_F$。

::: sol 答案
列和 $4,6$ ⇒ $\|A\|_1=6$；行和 $3,7$ ⇒ $\|A\|_\infty=7$；$\|A\|_F=\sqrt{30}$。

$A^{\mathrm T}A=\begin{bmatrix}10&14\\14&20\end{bmatrix}$，$\operatorname{tr}=30$、$\det=4$，$\lambda_{\max}=15+\sqrt{221}$，故 $\|A\|_2=\sqrt{15+\sqrt{221}}\approx5.465\le5.477=\sqrt{30}$ ✓。
:::
:::

::: ex R2-3 · 椭圆范数
设 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$。(a) 求上三角 $B$ 使 $A=B^{\mathrm T}B$；(b) 计算 $\|(1,0)\|_A$ 与 $\|(1,1)\|_A$；(c) 写出单位球的主轴与半轴长。

::: sol 答案
(a) $B=\begin{bmatrix}\sqrt2&\frac{1}{\sqrt2}\\0&\sqrt{\frac32}\end{bmatrix}$。
(b) $\sqrt2$；$\sqrt6$。
(c) 特征值 $3,1$，主轴沿 $(1,1)$、$(1,-1)$，半轴长 $1/\sqrt3$、$1$。
:::
:::

::: ex R2-4 · 等价常数取等
在 $\mathbb R^2$ 中取 $x=(1,1)^{\mathrm T}$，验证 $\|x\|_2\le\|x\|_1\le\sqrt2\|x\|_2$ 是否取等，并说明另一个不等式的取等向量。

::: sol 答案
$\|x\|_2=\sqrt2$、$\|x\|_1=2$，右端 $\sqrt2\cdot\sqrt2=2$ **取等**；左端 $\sqrt2\le2$ 严格。$\|x\|_\infty\le\|x\|_2$ 在 $x=(1,0)$ 取等。
:::
:::

::: ex R2-5 · 逆的界与 Neumann
设 $A=\begin{bmatrix}0&\frac13\\\frac13&0\end{bmatrix}$。(a) 验证 $\|A\|_\infty\lt1$；(b) 求 $(I-A)^{-1}$ 及其 $\infty$-范数；(c) 与 [@thm-4.3.6] 的界比较；(d) 用 $I+A$ 近似，算误差。

::: sol 答案
(a) $\|A\|_\infty=\frac13$。(b) $(I-A)^{-1}=\begin{bmatrix}\frac98&\frac38\\\frac38&\frac98\end{bmatrix}$，$\|\cdot\|_\infty=\frac32$。(c) 界 $\frac{1}{1-1/3}=\frac32$，取等。(d) 误差 $=\begin{bmatrix}\frac18&\frac1{24}\\\frac1{24}&\frac18\end{bmatrix}$，$\infty$-范数 $\frac16$；级数界 $\frac{1/9}{2/3}=\frac16$，也取等。
:::
:::

## 四、第三轮 · 证明对决（20 分钟 · 35 分）

规则：每题 12 / 12 / 11 分；按“思路 4 分 + 关键步骤 5 分 + 结论 3 分”给分。

::: ex R3-1 · 左乘可逆矩阵造范数（12 分）
设 $\|\cdot\|$ 是 $\mathbb C^n$ 上的范数，$P$ 可逆。证明 $\|x\|'=\|Px\|$ 是范数，并说明它是椭圆范数的来源。

::: sol 答案
正定：$\|Px\|=0\iff Px=0\iff x=0$；齐次：$\|P(kx)\|=|k|\|Px\|$；三角：$\|P(x+y)\|\le\|Px\|+\|Py\|$。

椭圆范数：$A$ 正定 Hermite ⇒ $A=B^{\mathrm H}B$，取 $P=B$、$\|\cdot\|=\|\cdot\|_2$ 即得 $\|x\|_A=\|Bx\|_2$。
:::
:::

::: ex R3-2 · 行和范数（12 分）
证明 $\|A\|_\infty=\max_i\sum_j|a_{ij}|$ 是 $\|\cdot\|_\infty$ 诱导的算子范数。

::: sol 答案
上界：$\|Ax\|_\infty=\max_i|\sum_j a_{ij}x_j|\le\max_i\sum_j|a_{ij}|\|x\|_\infty$。

取到：设第 $i_0$ 行取到最大，令 $x_j=|a_{i_0j}|/a_{i_0j}$（$a_{i_0j}\ne0$），否则 $x_j=1$，则 $\|x\|_\infty=1$ 且 $\|Ax\|_\infty=\sum_j|a_{i_0j}|$。上下界相等。
:::
:::

::: ex R3-3 · 逆矩阵定理（11 分）
设 $\|\cdot\|$ 是矩阵范数，$\|A\|\lt1$。证明 $I-A$ 可逆，且 $\|(I-A)^{-1}\|\le\|I\|/(1-\|A\|)$；指出哪一步必须用相容的向量范数。

::: sol 答案
反设 $(I-A)x=0$，$x\ne0$，则 $x=Ax$。取与 $\|\cdot\|$ 相容的向量范数（[@thm-4.3.1]），$\|x\|=\|Ax\|\le\|A\|\|x\|\lt\|x\|$，矛盾。

由 $(I-A)(I-A)^{-1}=I$ 得 $(I-A)^{-1}=I+A(I-A)^{-1}$，取范数移项即得界。

**关键步**：$\|Ax\|\le\|A\|\|x\|$ 必须借相容的向量范数——这是反证法能启动的前提。
:::
:::

## 五、第四轮 · 特征值与级数（20 分钟 · 30 分）

规则：每题 10 分；公式 3 分、关键一步 4 分、结论与边界判断 3 分。**这一轮的失分几乎全部来自「选错工具」**，不是算错。

::: ex R4-1 · 盖尔圆盘与调参（10 分）
设 $A=\begin{bmatrix}5&1&0\\0&4&2\\1&0&-2\end{bmatrix}$。(a) 写出三个盖尔圆盘，判断能孤立几个；(b) 想多孤立一个，取 $D=\operatorname{diag}(1,0.3,1)$ 重算，圆盘分开没有？(c) 说明为什么本例**怎么调都分不开**。

::: sol 答案

**(a)** 半径 $\delta_1=1$、$\delta_2=2$、$\delta_3=1$：

$$G_1=[4,6],\qquad G_2=[2,6],\qquad G_3=[-3,-1].$$

$G_1\subset G_2$（$[4,6]\subset[2,6]$），两者合成一片；$G_3$ 与它不相交 ⇒ **只孤立 1 个**（$[-3,-1]$ 内恰有一个特征值）。精确特征值约 $5.226,\ 3.726,\ -1.952$，与 $G_1\cup G_2=[2,6]$、$G_3=[-3,-1]$ 相符 ✓。

**(b)** $D=\operatorname{diag}(1,0.3,1)$：$b_{12}=1\cdot\frac{1}{0.3}=\frac{10}{3}$、$b_{23}=2\cdot\frac{0.3}{1}=0.6$、$b_{31}=1\cdot\frac{1}{1}=1$，故

$$G_1'=\Big[5-\tfrac{10}{3},\ 5+\tfrac{10}{3}\Big]=[1.67,8.33],\qquad G_2'=[3.4,4.6],\qquad G_3'=[-3,-1].$$

$G_2'$ 现在**被 $G_1'$ 完全包含**——孤立圆数量仍是 $1$，**没有变多**。

**(c)** 关键是一个**守恒量**。对任意 $D=\operatorname{diag}(d_1,d_2,d_3)$，

$$\delta_1'=\frac{d_1}{d_2}|a_{12}|,\qquad \delta_2'=\frac{d_2}{d_3}|a_{23}|,\qquad \delta_3'=\frac{d_3}{d_1}|a_{31}|,$$

三者相乘，$d_1,d_2,d_3$ **全部约掉**：

$$\delta_1'\delta_2'\delta_3'=|a_{12}a_{23}a_{31}|=1\cdot2\cdot1=2 .$$

**半径的乘积是相似不变量。** 于是不可能让三个半径同时变小：若想 $\delta_1'+\delta_2'\lt1$ 来分开前两个圆盘，则 $\delta_3'=\dfrac{2}{\delta_1'\delta_2'}$ 会大到 $\ge\dfrac{2}{0.25}=8$，$G_3'$ 反而胀成 $[-10,6]$ 把前面两个全吞掉。

**验证**：取 $d=(0.2,0.2,1)$（想让前两个都小）：$\delta_1'=1$、$\delta_2'=0.4$、$\delta_3'=\dfrac{2}{0.4}=5$，$G_3'=[-7,3]$ 与 $G_1'=[4,6]$ 不相交 ✓，但 $G_2'=[3.6,4.4]$ 与 $G_1'$ **仍相交**（$[4,4.4]$ 重叠），且 $G_3'$ 逼近 $G_2'$。全孤立无望。

**(c) 的结论**：$A$ 的非零结构是 $a_{12}\to a_{23}\to a_{31}\to a_{12}$ 一个**三元环**，环上元素乘积固定，所以三个半径的乘积固定。**圆盘能否分开，取决于「环上乘积」与「圆心间距」的对比**——把 $a_{12},a_{23},a_{31}$ 换成 $0.1,0.2,0.1$（乘积 $0.002$），三个圆盘立刻可以全部孤立。∎

**要点**：这是本竞技场里唯一一道「调参失败」的题，目的是让你记住：**$DAD^{-1}$ 不是万能的**。它只能重新分配半径，不能减少半径的乘积（在有向环上）；[例 4.5.9](sec45.md#ex-4.5.9) 是这个事实的极端情形（两个圆心重合，怎么调都不可能分开）。
:::
:::

::: ex R4-2 · 判幂级数（10 分）
判断 $\sum\limits_{m\ge1}\dfrac{A^m}{m}$ 的敛散性，$A=\begin{bmatrix}2&1\\0&2\end{bmatrix}$；再判断把 $c_m$ 换成 $1/2^m$ 之后的情形。

::: sol 答案

**第一个**：$A$ 上三角、对角元 $2,2$，故 $\rho(A)=2$。$c_m=1/m$ 的收敛半径 $r=1$。$\rho(A)=2\gt1=r$ ⇒ **发散**（[定理 4.6.5](sec46.md#thm-4.6.5)(2)）。

**核对**：$\frac{A^m}{m}$ 的对角元是 $\frac{2^m}{m}\to\infty$，通项不趋于零 ✓。

**第二个**：$c_m=2^{-m}$，$r=2$。$\rho(A)=2=r$ ⇒ **边界，Abel 定理失效**。逐元素算：写 $A=2I+N$、$N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，$A^m=2^mI+m2^{m-1}N$，故

$$\frac{A^m}{2^m}=I+\frac{m}{2}N=\begin{bmatrix}1&\frac m2\\0&1\end{bmatrix},$$

$(1,2)$ 元是 $\frac m2\to\infty$，通项不趋于零 ⇒ **发散**。

**要点**：两问都发散，但**理由不同**——第一问是 $\rho\gt r$（定理直接判），第二问是边界（定理失效，必须逐元素算）。**答对结论但说不出理由，就是没学会。**∎
:::
:::

::: ex R4-3 · Neumann 级数与误差（10 分）
设 $A=\begin{bmatrix}0&0.5\\0.5&0\end{bmatrix}$。(a) 用 Neumann 级数求 $(I-A)^{-1}$ 的精确值；(b) 前 $4$ 项近似的误差界是多少？

::: sol 答案

**(a)** $A^2=0.25I$，故 $A^{2l}=0.25^lI$、$A^{2l+1}=0.25^lA$，于是

$$\sum_{m\ge0}A^m=\sum_{l\ge0}0.25^l(I+A)=\frac{1}{1-0.25}(I+A)=\frac43\begin{bmatrix}1&0.5\\0.5&1\end{bmatrix}=\begin{bmatrix}\frac43&\frac23\\\frac23&\frac43\end{bmatrix}.$$

**(b)** $\|A\|_\infty=0.5\lt1$，前 $4$ 项（$N=3$）的误差界为 $\dfrac{0.5^4}{1-0.5}=0.125$；实际误差 $\|(I-A)^{-1}-S_3\|_\infty=0.125$，**恰好取等**。

**要点**：$0.5^4/0.5$ 这个界的分子是 $\|A\|^{N+1}$ 不是 $\|A\|^N$——**差一次方是常错点**。∎
:::
:::

**抢救室五句话**：

1. **先查正定性**：范数题的第一个反例，十有八九死在“非零向量长度为零”。
2. **先问哪把尺子**：$\|A\|_1$ 配 $\|x\|_1$，$\|A\|_\infty$ 配 $\|x\|_\infty$，$\|A\|_2$ 配 $\|x\|_2$——交叉使用必错。
3. **先看 $\|I\|$**：只有诱导范数才有 $\|I\|=1$；写逆的界时别把 $\|I\|$ 吞掉。
4. **先问「要数还是要判」**：数特征值用盖尔圆（孤立才准）；判收敛用 $\rho(A)$ 比 $r$（$\|A\|\lt1$ 只是充分条件）。
5. **先看边界**：$\rho(A)=r$ 时 Abel 定理一个字也用不上，**回定义逐元素算**——这是本章唯一「没有捷径」的地方。

::: note 赛后复盘（三问）
