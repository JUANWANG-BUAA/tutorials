# 考场竞技场 · 第四章（4.1–4.3 特训）

第四章的考法与前三章不同：**它很少出“大证明”，更多是概念判断 + 小计算 + 一个套公式的估计**。老师在第 7 周课末说得很直白：第四章“比第三章还抽象，考试出题分数应该是最少的，但也是学习最难的”（10-22 01:30）。所以这里的策略不是“刷难题”，而是**把便宜分全部拿稳**：判断范数、手算四个范数、写对相容与逆的估计。

用法：先读[必考点清单](#arena4-must)，照着清单回正文补漏；然后关掉正文，按三轮计时赛走一遍；赛完按段位表复盘，错题送进[抢救室](#arena4-rescue)。

::: note 素材依据与诚实声明

本章 4.1–4.3 **只有课件、没有录播**（录像截止 2026-10-27，第四章尚未开讲），所以本页的考情依据只有两类：

- **S 级**：课件小结页亲排的“基本概念 / 重要结论 / 重要计算”——4.1 的范数公理与等价、4.2 的四公理与 Frobenius、4.3 的相容与三个公式；
- **B 级**：课堂原话中与本章直接联动的三条——第四章“分值最少、学习最难”（10-22 01:30）、第三章“分值最大”（10-13 00:26）、“复习按书不按 PPT”（10-13 01:29）。原话见[课堂口述与考点信号](../lecture-signals.md)。

本页竞技题 R1–R3 全部为**新增**，不与[习题集](exercises.md)、[自测卷](mock-exam.md)重复；计算题均已回代验算（R2-2、R2-5 另用精确算术复核）。
:::

## 二、第一轮 · 概念抢答（5 分钟 · 20 分）

规则：每题 2 分，只答“对 / 错”并给一句理由；只写对错不得分。

::: ex R1-1 · 范数与矩阵范数（10 连发）
1. $\|x\|=|x_1-x_2|$ 是 $\mathbb R^2$ 上的范数。
2. $\|x\|_\infty\le\|x\|_2\le\|x\|_1$。
3. $0\lt p\lt1$ 时 $\ell_p$ 是范数。
4. $\max|a_{ij}|$ 是矩阵范数。
5. $\sum\sum|a_{ij}|$ 是矩阵范数。
6. $\|\cdot\|_F$ 是诱导范数。
7. 任何矩阵范数都满足 $\|I\|=1$。
8. $\|A\|\lt1$ 时 $I-A$ 一定可逆。
9. $\|A\|_2\le\|A\|_F$ 对任意矩阵成立。
10. 相似变换可以改变谱半径。

::: sol 答案（每题 2 分：判断 1 分 + 理由 1 分）

1. **错**：正定性失效，$x=(1,1)\ne0$ 但 $\|x\|=0$。
2. **对**：这是 §4.1 的刻度表（[注](sec41.md#note-4.1-scale)）。
3. **错**：三角不等式失效，$x=(1,0),y=(0,1)$ 时 $2^{1/p}\gt2$。
4. **错**：不满足乘法相容（[反例](sec42.md#think-4.2-maxentry)）。
5. **对**：交叉项非负，$\|AB\|_{v1}\le\|A\|_{v1}\|B\|_{v1}$（[证明](sec42.md#think-4.2-sum)）。
6. **错**：$\|I_n\|_F=\sqrt n\ne1$（[注](sec43.md#note-4.3-hierarchy)）。
7. **错**：一般矩阵范数 $\|I\|\ge1$，$F$-范数是 $\sqrt n$（[注](sec43.md#note-4.3-identity)）。
8. **对**：[@thm-4.3.6]。
9. **对**：$\sigma_{\max}^2\le\sum\sigma_i^2$（[注](sec43.md#note-4.3-multi)）。
10. **错**：相似保持特征值，谱半径不变。
:::
:::

## 三、第二轮 · 计算擂台（25 分钟 · 45 分）

规则：每题 9 分；写出公式 3 分、代入 3 分、结果与验算 3 分。

::: ex R2-1 · 三个向量范数
设 $x=(2,-1,2)^{\mathrm T}$，求 $\|x\|_1,\|x\|_2,\|x\|_\infty$，并验证 $\|x\|_\infty\le\|x\|_2\le\|x\|_1$。

::: sol 答案
$5$；$3$；$2$。验证 $2\le3\le5$ ✓。
:::
:::

::: ex R2-2 · 四个矩阵范数
设 $A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，求 $\|A\|_1,\|A\|_\infty,\|A\|_F,\|A\|_2$，并验证 $\|A\|_2\le\|A\|_F$。

::: sol 答案
列和 $4,6$ ⇒ $\|A\|_1=6$；行和 $3,7$ ⇒ $\|A\|_\infty=7$；$\|A\|_F=\sqrt{30}$。

$A^{\mathrm T}A=\begin{bmatrix}10&14\\14&20\end{bmatrix}$，$\operatorname{tr}=30$、$\det=4$，$\lambda_{\max}=15+\sqrt{221}$，故 $\|A\|_2=\sqrt{15+\sqrt{221}}\approx5.465\le5.477=\sqrt{30}$ ✓。
:::
:::

::: ex R2-3 · 椭圆范数
设 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$。(a) 求上三角 $B$ 使 $A=B^{\mathrm T}B$；(b) 计算 $\|(1,0)\|_A$ 与 $\|(1,1)\|_A$；(c) 写出单位球的主轴与半轴长。

::: sol 答案
(a) $B=\begin{bmatrix}\sqrt2&\frac{1}{\sqrt2}\\0&\sqrt{\frac32}\end{bmatrix}$。
(b) $\sqrt2$；$\sqrt6$。
(c) 特征值 $3,1$，主轴沿 $(1,1)$、$(1,-1)$，半轴长 $1/\sqrt3$、$1$。
:::
:::

::: ex R2-4 · 等价常数取等
在 $\mathbb R^2$ 中取 $x=(1,1)^{\mathrm T}$，验证 $\|x\|_2\le\|x\|_1\le\sqrt2\|x\|_2$ 是否取等，并说明另一个不等式的取等向量。

::: sol 答案
$\|x\|_2=\sqrt2$、$\|x\|_1=2$，右端 $\sqrt2\cdot\sqrt2=2$ **取等**；左端 $\sqrt2\le2$ 严格。$\|x\|_\infty\le\|x\|_2$ 在 $x=(1,0)$ 取等。
:::
:::

::: ex R2-5 · 逆的界与 Neumann
设 $A=\begin{bmatrix}0&\frac13\\\frac13&0\end{bmatrix}$。(a) 验证 $\|A\|_\infty\lt1$；(b) 求 $(I-A)^{-1}$ 及其 $\infty$-范数；(c) 与 [@thm-4.3.6] 的界比较；(d) 用 $I+A$ 近似，算误差。

::: sol 答案
(a) $\|A\|_\infty=\frac13$。(b) $(I-A)^{-1}=\begin{bmatrix}\frac98&\frac38\\\frac38&\frac98\end{bmatrix}$，$\|\cdot\|_\infty=\frac32$。(c) 界 $\frac{1}{1-1/3}=\frac32$，取等。(d) 误差 $=\begin{bmatrix}\frac18&\frac1{24}\\\frac1{24}&\frac18\end{bmatrix}$，$\infty$-范数 $\frac16$；级数界 $\frac{1/9}{2/3}=\frac16$，也取等。
:::
:::

## 四、第三轮 · 证明对决（20 分钟 · 35 分）

规则：每题 12 / 12 / 11 分；按“思路 4 分 + 关键步骤 5 分 + 结论 3 分”给分。

::: ex R3-1 · 左乘可逆矩阵造范数（12 分）
设 $\|\cdot\|$ 是 $\mathbb C^n$ 上的范数，$P$ 可逆。证明 $\|x\|'=\|Px\|$ 是范数，并说明它是椭圆范数的来源。

::: sol 答案
正定：$\|Px\|=0\iff Px=0\iff x=0$；齐次：$\|P(kx)\|=|k|\|Px\|$；三角：$\|P(x+y)\|\le\|Px\|+\|Py\|$。

椭圆范数：$A$ 正定 Hermite ⇒ $A=B^{\mathrm H}B$，取 $P=B$、$\|\cdot\|=\|\cdot\|_2$ 即得 $\|x\|_A=\|Bx\|_2$。
:::
:::

::: ex R3-2 · 行和范数（12 分）
证明 $\|A\|_\infty=\max_i\sum_j|a_{ij}|$ 是 $\|\cdot\|_\infty$ 诱导的算子范数。

::: sol 答案
上界：$\|Ax\|_\infty=\max_i|\sum_j a_{ij}x_j|\le\max_i\sum_j|a_{ij}|\|x\|_\infty$。

取到：设第 $i_0$ 行取到最大，令 $x_j=|a_{i_0j}|/a_{i_0j}$（$a_{i_0j}\ne0$），否则 $x_j=1$，则 $\|x\|_\infty=1$ 且 $\|Ax\|_\infty=\sum_j|a_{i_0j}|$。上下界相等。
:::
:::

::: ex R3-3 · 逆矩阵定理（11 分）
设 $\|\cdot\|$ 是矩阵范数，$\|A\|\lt1$。证明 $I-A$ 可逆，且 $\|(I-A)^{-1}\|\le\|I\|/(1-\|A\|)$；指出哪一步必须用相容的向量范数。

::: sol 答案
反设 $(I-A)x=0$，$x\ne0$，则 $x=Ax$。取与 $\|\cdot\|$ 相容的向量范数（[@thm-4.3.1]），$\|x\|=\|Ax\|\le\|A\|\|x\|\lt\|x\|$，矛盾。

由 $(I-A)(I-A)^{-1}=I$ 得 $(I-A)^{-1}=I+A(I-A)^{-1}$，取范数移项即得界。

**关键步**：$\|Ax\|\le\|A\|\|x\|$ 必须借相容的向量范数——这是反证法能启动的前提。
:::
:::

**抢救室三句话**：

1. **先查正定性**：范数题的第一个反例，十有八九死在“非零向量长度为零”。
2. **先问哪把尺子**：$\|A\|_1$ 配 $\|x\|_1$，$\|A\|_\infty$ 配 $\|x\|_\infty$，$\|A\|_2$ 配 $\|x\|_2$——交叉使用必错。
3. **先看 $\|I\|$**：只有诱导范数才有 $\|I\|=1$；写逆的界时别把 $\|I\|$ 吞掉。
