## A. 定义卡

### D1 · 向量范数的三条公理

写出定义 4.1.1 的三条公理；为什么「长度」只需要这三条，而不需要内积？

::: sol D1 核对

1. **正定**：$\|x\|\ge0$，等号 $\iff x=\boldsymbol\theta$；2. **齐次**：$\|kx\|=|k|\|x\|$；3. **三角**：$\|x+y\|\le\|x\|+\|y\|$（[@def-4.1.1]）。三条只用到加法与数乘，所以任何线性空间都能定义范数；内积只是**充分**条件（[思考](sec41.md#think-4.1-inner)）。反过来，内积多出来的是「角度」，范数没有。
:::

### D2 · 三个常用范数与 $p$-范数

写出 $\|x\|_1,\|x\|_2,\|x\|_\infty$ 与 $\|x\|_p$ 的公式；$p$ 在什么范围才合格？$p\to\infty$ 时发生什么？

::: sol D2 核对

$\|x\|_1=\sum|x_i|$，$\|x\|_2=\big(\sum|x_i|^2\big)^{1/2}$，$\|x\|_\infty=\max_i|x_i|$，$\|x\|_p=\big(\sum|x_i|^p\big)^{1/p}$（[@ex-4.1.1]、[@ex-4.1.3]）。合格范围 $1\le p\le\infty$；$0\lt p\lt1$ 时三角不等式失效（反例 $x=(1,0)$、$y=(0,1)$，$2^{1/p}\gt2$，[@note-4.1-p]）。$p\to\infty$ 时 $\|x\|_p\to\|x\|_\infty$（夹逼：$M\le\|x\|_p\le n^{1/p}M$）。
:::

### D3 · 椭圆（加权）范数

写出 $\|x\|_A$ 的定义与对 $A$ 的要求；证明它为什么是范数（一行）。

::: sol D3 核对

$\|x\|_A=\sqrt{x^{\mathrm H}Ax}$，要求 $A$ **正定 Hermite**（[@ex-4.1.4]）。取 $A=B^{\mathrm H}B$（Cholesky 或谱分解），则 $\|x\|_A=\|Bx\|_2$，三公理继承自 2-范数；正定性用「$B$ 可逆 $\Rightarrow$ $Bx=0$ 只有零解」。单位球是椭球，半轴长 $1/\sqrt{\lambda_i}$。
:::

### D4 · 范数等价

写出定义；两个方向的不等式各由什么保证？等价常数能否取正整数？

::: sol D4 核对

存在正数 $k_1,k_2$ 使 $k_1\|x\|_\beta\le\|x\|_\alpha\le k_2\|x\|_\beta$（[@def-4.1.2]）。上界**算**出来（$\|x\|\le M\|x\|_2$）；下界**紧**出来（单位球面有界闭，若 $\|x^{(k)}\|\to0$ 则与 $\|x^*\|_2=1$ 矛盾，[@thm-4.1.2]）。常数是**正数**不是正整数（$\sqrt n$ 就会出现，勘误 E4.4）。
:::

### D5 · 矩阵的向量范数 vs 矩阵范数

两者的公理差哪一条？各举一个「是前者不是后者」的例子。

::: sol D5 核对

矩阵的向量范数只要正定、齐次、三角（[@def-4.2.1]）；矩阵范数再加 **$\|AB\|\le\|A\|\|B\|$**（[@def-4.2.2]）。反例：$\max|a_{ij}|$ 是前者不是后者（$A=\begin{bmatrix}1&0\\1&1\end{bmatrix}$、$B=\begin{bmatrix}-1&0\\-1&1\end{bmatrix}$，$\|AB\|_\infty=2\gt1$，[@think-4.2-maxentry]）。合格的例子：元素和范数（[@think-4.2-sum]）与 Frobenius 范数（[@ex-4.2.2]）。
:::

### D6 · Frobenius 范数

写出三种等价写法；它为什么是矩阵范数（指出证明的关键不等式）？

::: sol D6 核对

$\|A\|_F=\big(\sum_{i,j}|a_{ij}|^2\big)^{1/2}=\sqrt{\operatorname{tr}(A^{\mathrm H}A)}=\sqrt{\sum_i\sigma_i^2}$（[@ex-4.2.2]、[@note-4.2-frobenius]）。乘法相容靠 $|c_{ij}|^2\le\big(\sum_k|a_{ik}|^2\big)\big(\sum_k|b_{kj}|^2\big)$（Cauchy–Schwarz），再对 $i,j$ 求和时**可分离**，得 $\|AB\|_F^2\le\|A\|_F^2\|B\|_F^2$。
:::

### D7 · 相容

写出定义；它与矩阵范数的乘法相容性有什么区别？

::: sol D7 核对

$\|Ax\|_v\le\|A\|_m\|x\|_v$（[@def-4.3.1]）。它管「矩阵乘向量」，乘法相容性 $\|AB\|\le\|A\|\|B\|$ 管「矩阵乘矩阵」；前者不能由后者自动推出，需要单独验证或构造。
:::

### D8 · 诱导范数（算子范数）

写出定义与等价定义；它为什么一定与给定的向量范数相容？

::: sol D8 核对

$\|A\|=\max_{\|x\|_v=1}\|Ax\|_v=\max_{x\ne0}\|Ax\|_v/\|x\|_v$（[@thm-4.3.2]、[@note-4.3-opdef]）。相容性：对 $x\ne0$ 取 $y=x/\|x\|_v$，$\|Ax\|_v=\|Ay\|_v\|x\|_v\le\|A\|\|x\|_v$。最大值存在靠「$\|Ax\|_v$ 连续 $+$ 单位球有界闭」（[@note-4.3-existence]）。
:::

## B. 定理卡

### T1 · 范数的连续性与等价性

叙述定理 4.1.1 与 4.1.2，并写出后者的证明主线（两个字概括每一步）。

::: sol T1 核对

定理 4.1.1：范数是坐标的连续函数，证 $\big|\|x\|-\|y\|\big|\le\|x-y\|\le M\|x-y\|_2$（[@thm-4.1.1]）。定理 4.1.2：有限维空间任意两范数等价；证明主线是**上界靠算、下界靠紧**（[@thm-4.1.2]）：先 $\|x\|\le M\|x\|_2$，再反证 $\|x\|\ge c\|x\|_2$，最后两两合成。
:::

### T2 · 范数等价的三条性质

写出自反、对称、传递，并说明对称性里常数怎么变。

::: sol T2 核对

自反：$k_1=k_2=1$（平凡）；对称：由 $k_1\|x\|_\beta\le\|x\|_\alpha\le k_2\|x\|_\beta$ 得 $\frac1{k_2}\|x\|_\alpha\le\|x\|_\beta\le\frac1{k_1}\|x\|_\alpha$；传递：常数相乘（[@prop-4.1.1]）。用途：换范数不换收敛（[$k_1$ 夹逼](sec41.md#note-4.1-convergence)）。
:::

### T3 · 矩阵向量范数的连续性与等价性

这两条为什么可以「直接搬」向量版本？

::: sol T3 核对

把 $A$ 拉直成 $\operatorname{vec}(A)\in\mathbb C^{mn}$，任何矩阵向量范数都是它的向量范数，于是定理 4.1.1 与 4.1.2 直接适用（[@thm-4.2.1]、[@thm-4.2.2]）。**注意**：这里只保证「向量层面」的连续与等价，没有管乘法。
:::

### T4 · Frobenius 范数是矩阵范数

不看书，写出四步证明；指出兼容性一步用了哪个不等式、最后一步为什么能拆。

::: sol T4 核对

正定、齐次、三角（逐项用 Minkowski）；相容：$|c_{ij}|^2\le\big(\sum_k|a_{ik}|^2\big)\big(\sum_k|b_{kj}|^2\big)$（Cauchy–Schwarz），求和后因被加项对 $i$、$j$ 可分离而拆成 $\|A\|_F^2\|B\|_F^2$（[@ex-4.2.2]）。
:::

### T5 · Frobenius 范数的三条性质

写出酉不变、按列 / 按行分块、$\|Ax\|_2\le\|A\|_F\|x\|_2$，并各给一句证明要点。

::: sol T5 核对

(1) $\|UAV\|_F^2=\operatorname{tr}(V^{\mathrm H}A^{\mathrm H}AV)=\operatorname{tr}(A^{\mathrm H}AVV^{\mathrm H})=\|A\|_F^2$（迹的循环）；(2) $\|A\|_F^2=\sum_j\|\beta_j\|_2^2$（逐列平方和）；(3) $Ax=\sum_jx_j\beta_j$，三角不等式 $+$ Cauchy–Schwarz（[@thm-4.2.3]）。酉不变性的用途：$F$-范数只依赖奇异值。
:::

### T6 · 相似造范数

陈述例 4.2.3 并证明乘法相容性；举一个「把范数调小」的数值例。

::: sol T6 核对

$\|A\|_m=\|P^{-1}AP\|$（$P$ 可逆）是矩阵范数（[@ex-4.2.3]）。关键在于 $P^{-1}ABP=(P^{-1}AP)(P^{-1}BP)$，中间插入 $PP^{-1}=I$。例：$A=\begin{bmatrix}1&10\\0&1\end{bmatrix}$，$\|A\|_\infty=11$；取 $P=\operatorname{diag}(10,1)$ 后 $\|P^{-1}AP\|_\infty=2$，而谱半径始终是 $1$（[@ex-4.2.C]）。
:::

### T7 · 矩阵范数必有相容的向量范数

写出构造与证明的四步；$\alpha$ 可以怎么取？

::: sol T7 核对

取 $\alpha\ne0$，定义 $\|x\|_v=\|x\alpha^{\mathrm T}\|_m$（[@thm-4.3.1]）：正定（$x\alpha^{\mathrm T}=O\iff x=0$）、齐次、三角、相容（$Ax\alpha^{\mathrm T}=A(x\alpha^{\mathrm T})$）。$\alpha$ 任取非零，所以这样的向量范数有无穷多个。**用途**：定理 4.3.6 的反证法必须借它。
:::

### T8 · 诱导范数定理

写出定理与四步证明（正定、齐次、三角、乘法相容、相容）；最大值为什么存在？

::: sol T8 核对

$\|A\|=\max_{\|x\|=1}\|Ax\|$（[@thm-4.3.2]）。正定：单位球面为零 $\Rightarrow$ 全空间为零 $\Rightarrow A=O$；齐次显然；三角：取到最大值的 $y$；乘法：$\|AB\|=\|A(z/\|z\|)\|\|z\|\le\|A\|\|B\|$；相容：$y=x/\|x\|$。存在性：连续函数在有界闭集上取最值（[@note-4.3-existence]）。
:::

### T9 · 三个显式公式

默写列和、行和、谱三个公式；各说出取到最大值的 $x$。

::: sol T9 核对

$\|A\|_1=\max_j\sum_i|a_{ij}|$，取 $x=e_{j_0}$；$\|A\|_\infty=\max_i\sum_j|a_{ij}|$，取 $x_j=|a_{i_0j}|/a_{i_0j}$（零元取 $1$）；$\|A\|_2=\sqrt{\lambda_{\max}(A^{\mathrm H}A)}=\sigma_{\max}$，取 $A^{\mathrm H}A$ 的最大特征向量（[@thm-4.3.3]）。口诀「1 列 $\infty$ 行」。
:::

### T10 · $\|A\|_2\le\|A\|_F$ 与等号

证明这个不等式；等号什么时候成立？

::: sol T10 核对

$\|A\|_2^2=\sigma_1^2$，$\|A\|_F^2=\sum_i\sigma_i^2$，故 $\|A\|_2\le\|A\|_F$；等号 $\iff$ 除 $\sigma_1$ 外全为零 $\iff\operatorname{rank}A\le1$（[@note-4.3-multi]）。例 4.3.2：$\sqrt{15}\lt\sqrt{23}$（秩 $3$）。
:::

### T11 · Rayleigh 商与 Courant–Fischer

写出 $R(x)$ 的上下界与极大极小定理；证明用了哪一句维数事实？

::: sol T11 核对

$\lambda_n\le R(x)\le\lambda_1$，$R=x^{\mathrm H}Ax/x^{\mathrm H}x$（[@note-4.3-rayleigh]）；$\lambda_1=\max R$、$\lambda_n=\min R$（[@cor-4.3.1]）。Courant–Fischer：$\lambda_i=\max_{V_i}\min_{V_i}R=\min_{V_{n-i+1}}\max_{V}R$（[@thm-4.3.4]）。证明用「两个子空间维数之和 $\gt n$，必非零相交」。
:::

### T12 · Weyl 扰动不等式

写出不等式；说明它由 Courant–Fischer 的哪一步推出。

::: sol T12 核对

$\lambda_i(A)+\lambda_n(E)\le\lambda_i(A+E)\le\lambda_i(A)+\lambda_1(E)$（[@thm-4.3.5]）。用 $R_{A+E}=R_A+R_E$ 与 $\lambda_n(E)\le R_E\le\lambda_1(E)$，把常数提出 $\min/\max$ 即得（[应用](sec43.md#app-4.3-weyl)）。
:::

## D. 4.5–4.6 的定义卡（续）

### D9 · 谱与谱半径

写出 $Sp(A)$ 与 $\rho(A)$ 的定义；举一个 $\rho(A)=0$ 但 $A\ne O$ 的矩阵；$\rho$ 为什么不能当范数？

::: sol D9 核对

$Sp(A)=\{\lambda:\lambda\ \text{是}\ A\ \text{的特征值}\}$，$\rho(A)=\max_{\lambda\in Sp(A)}|\lambda|$（[@def-4.5.1]）。反例 $N=\begin{bmatrix}0&1\\0&0\end{bmatrix}$：$Sp(N)=\{0\}$，$\rho=0$ 而 $N\ne O$。$\rho$ 不能当范数：正定性失效（幂零阵）、三角不等式也失效（$\rho(A+B)=1\gt0=\rho(A)+\rho(B)$，(a)(b) 见[思考](sec45.md#think-4.5-rhomorphism)）。基本性质：相似不变、$\rho(A^k)=\rho(A)^k$、$\rho(A^{\mathrm H})=\rho(A)$（[@note-4.5-basic]）。
:::

### D10 · 盖尔圆盘

写出圆心与半径；为什么半径按「行」算；转置之后圆心变不变？

::: sol D10 核对

圆心 $a_{ii}$、半径 $\delta_i=\sum_{j\ne i}|a_{ij}|$（[@def-4.5.2]）。按行算是因为[定理 4.5.3](sec45.md#thm-4.5.3) 的证明要挑「最大分量 $x_\sigma$」所在的方程——那是第 $\sigma$ **行**，右端被同行非对角元之和控住。转置后对角元不变，故**圆心不变**、半径改为列和，两个并集取交就得到更小的区域（[@note-4.5-transpose]）。
:::

### D11 · 向量序列与矩阵序列的收敛

三种收敛各是什么？为什么它们等价？**哪些量保证这种等价**？

::: sol D11 核对

按范数：$\lim\|\boldsymbol x_k-\boldsymbol x\|_\alpha=0$（[@def-4.6.1]）；按坐标：每个 $\xi_i^{(k)}\to\xi_i$（[@def-4.6.2]）；按元素：每个 $a_{ij}^{(k)}\to a_{ij}$（[@def-4.6.3]）。等价性靠 [定理 4.1.2](sec41.md#thm-4.1.2) 的**范数等价**——把坐标范数 $\|\cdot\|_\infty$ 夹在任意范数两侧（[@thm-4.6.1]、[@thm-4.6.2]）。**注意**：等价只在**有限维**成立；无限维里三种收敛可以不一致。
:::

### D12 · 矩阵级数与绝对收敛

写出矩阵级数收敛的定义；绝对收敛的定义；两者什么关系？

::: sol D12 核对

$S_N=\sum_{k\le N}A_k$ 收敛到 $S$ 即级数收敛（[@def-4.6.4]）；$mn$ 个数值级数 $\sum|a_{ij}^{(k)}|$ 都收敛即绝对收敛（[@def-4.6.5]）。关系：绝对收敛 $\Rightarrow$ 收敛，反之不然（[例 4.6.5](sec46.md#ex-4.6.5) 的交错调和级数）。**为什么要绝对**：重排、交换求和序、逐项求导都需要它（[@prop-4.6.3]、[@note-4.6-rearrange]）。判绝对收敛只需算一列正数 $\sum\|A_k\|$（[@thm-4.6.4]）。
:::

### D13 · 矩阵幂级数与收敛半径

写出矩阵幂级数的定义；数值幂级数的收敛半径是什么？

::: sol D13 核对

$\sum_{m\ge0}c_mA^m$，约定 $A^0=I$（[@def-4.6.6]）。收敛半径 $r$：$|z|\lt r$ 收敛、$|z|\gt r$ 发散的那个临界值（[@lem-4.6.1]）。**$r$ 只由 $c_m$ 决定，与 $A$ 无关**——这就是为什么 Abel 定理能把「$A$ 的信息」压缩成 $\rho(A)$ 一个数。
:::

## E. 4.5–4.6 的定理卡（续）

### T13 · 谱半径不大于任一矩阵范数

写出不等式与证明；哪一步必须借「相容向量范数」？

::: sol T13 核对

$\rho(A)\le\|A\|$（[@thm-4.5.1]）。证明：$Ax=\lambda x\Rightarrow|\lambda|\|x\|=\|Ax\|\le\|A\|\|x\|$，约去 $\|x\|\gt0$。「$\|Ax\|\le\|A\|\|x\|$」这一步必须有一个与 $\|A\|$ 相容的向量范数（[定理 4.3.1](sec43.md#thm-4.3.1)）——矩阵范数量不了向量。正规矩阵时 $\|A\|_2=\rho(A)$（[@note-4.5-normal]）。
:::

### T14 · 谱半径是范数读数的下确界

写出定理 4.5.2 与合起来的结论；下确界取得到吗？

::: sol T14 核对

任给 $\varepsilon\gt0$，存在矩阵范数使 $\|A\|\le\rho(A)+\varepsilon$（[@thm-4.5.2]）；与 T13 合起来 $\rho(A)=\inf\|\cdot\|$（[@note-4.5-inf]）。**不一定取到**：$A$ 不可对角化时任何范数都 $\gt\rho(A)$（[例 4.5.A](sec45.md#ex-4.5.A) 用 $\|A^k\|\le\|A\|^k$ 反证）。构造：$Q=\operatorname{diag}(1,\varepsilon,\cdots)$ 把 Jordan 块的超对角元压成 $\varepsilon$。
:::

### T15 · 三个显式界与等号

写出三个界；$F$ 那条的等号条件与证明工具？

::: sol T15 核对

$|\lambda_l|\le\|A\|_1$、$|\lambda_l|\le\|A\|_\infty$、$\sum|\lambda_l|^2\le\|A\|_F^2$（[@thm-4.5-extra]）。等号 $\iff$ $A$ **正规**（Schur 三角化后「上三角部分除对角元外为零」$\iff$ 可酉对角化）。前两条是「$\rho\le$ 范数」的直接兑现；第三条把「对角元平方和」与「全部元素平方和」比较（[例 4.5.B](sec45.md#ex-4.5.B)）。
:::

### T16 · 盖尔圆盘定理与计数

写出定理 4.5.3 与 4.5.4；后者证明的核心一句话是什么？

::: sol T16 核对

所有特征值在 $\bigcup_iG_i$ 内（[@thm-4.5.3]，证明用主导分量法）；$k$ 个圆盘连成一片且与其余不相交 $\Rightarrow$ 那里恰有 $k$ 个特征值（[@thm-4.5.4]）。后者证明核心：**连续形变 $+$ 不能越界 $=$ 计数不变**——让 $A(\varepsilon)=D+\varepsilon B$ 从 $D$ 变到 $A$，特征值描出 $n$ 条连续曲线，起点在各圆心、终点是 $A$ 的特征值，曲线跑不出并集。
:::

### T17 · 四条推论

能由盖尔圆直接得到哪四个结论？各用哪条定理？

::: sol T17 核对

(1) $0\notin\bigcup G_i\Rightarrow A$ 可逆（[@cor-4.5.1]，反证 $0$ 是特征值）；(2) 严格对角占优 $\Rightarrow$ 非奇异（[@cor-4.5.2]，原点不在任何圆盘内）；(3) $k$ 个孤立圆 $\Rightarrow$ 至少 $k$ 个互异特征值；全孤立 $\Rightarrow$ 单纯（[@cor-4.5.3]）；(4) 实方阵孤立圆 $\Rightarrow$ 实特征值（[@cor-4.5.4]，圆盘关于实轴对称）。**注意**：只有全孤立才给「可对角化」，$k\lt n$ 时剩下的仍可能带 Jordan 块。
:::

### T18 · $A^k\to O$ 的充要条件

写出判据与证明主线；$\|A\|\lt1$ 是什么条件？为什么两者不同？

::: sol T18 核对

$A^k\to O\iff\rho(A)\lt1$（[@thm-4.6.3]）。证明用 Jordan 形：$J_i^k$ 的元素是 $\binom{k}{l}\lambda_i^{k-l}$，**指数战胜多项式**，故只看 $|\lambda_i|$；$\rho\ge1$ 时对角元不趋于零。$\|A\|\lt1$ 只是**充分**条件（[@cor-4.6.2]）——反例 $\begin{bmatrix}0.1&0\\1&0.1\end{bmatrix}$ 的 $\|A\|_\infty=1.1$ 但 $\rho=0.1$（[@think-4.6-normnotboth]）。差别在于 $\|A\|$ 是「一步的放大」，$\rho$ 是「长期的增长率」。
:::

### T19 · Abel 型定理

写出两条结论；$\rho(A)=r$ 时怎么办？证明里最关键的一步是什么？

::: sol T19 核对

$\rho(A)\lt r\Rightarrow$ 绝对收敛；$\rho(A)\gt r\Rightarrow$ 发散（[@thm-4.6.5]）。$\rho(A)=r$ 时**定理失效**，回定义逐元素算（[@note-4.6-1]、[例 4.6.7](sec46.md#ex-4.6.7)）。证明里最关键的是 **$(\rho\lt r)$ 分支先用 [定理 4.5.2](sec45.md#thm-4.5.2) 换一把定制范数，把 $\|A\|$ 压进收敛圆内**，再用等比控制；$(\rho\gt r)$ 分支用「乘 $\boldsymbol x\boldsymbol x^{\mathrm H}$ 降维成标量级数」。
:::

### T20 · Neumann 级数与整函数

写出 Neumann 级数的条件、结论、和；它比 [定理 4.3.6](sec43.md#thm-4.3.6) 强在哪？$r=\infty$ 时得到什么？

::: sol T20 核对

$\rho(A)\lt1\iff\sum_{m\ge0}A^m$ 收敛，和为 $(I-A)^{-1}$（[@cor-4.6.5]）。比 [定理 4.3.6](sec43.md#thm-4.3.6) 强在：(1) 条件从「某范数 $\lt1$」放宽到「谱半径 $\lt1$」；(2) 把逆写成**显式级数**，可截断、可逐项运算。$r=\infty$ 时对任意 $A$ 收敛（[@cor-4.6.4]）——这就是 $e^A=\sum A^k/k!$ 的定义依据（[例 4.6.8](sec46.md#ex-4.6.8)）。
:::

### T21 · 逆的可交换性

证明 $(I-A)^{-1}A=A(I-A)^{-1}$；用级数证与用恒等式证分别说明什么？

::: sol T21 核对

由 $\rho(A)\lt1$，$(I-A)^{-1}=\sum_{m\ge0}A^m$ 是 $A$ 的多项式极限，故可交换（[@note-4.6-3]）。不用级数：由 $A=I-(I-A)$，

$$(I-A)^{-1}A=(I-A)^{-1}-I=A(I-A)^{-1}.$$

**两种证法的差别**：级数法说明「可展开成幂级数的矩阵都可交换」；恒等式法说明这个结论**与 $\rho(A)\lt1$ 无关**，只要 $I-A$ 可逆就成立。
:::
