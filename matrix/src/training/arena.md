## 一、快问快答

**规则**：遮住后半句，只看**考点**，15 秒内说出「一句话答案要点」。说不出立刻点「回读锚点」回去读那一节——不要在这里硬背。共 25 条，每题 1 分。

1. **线性空间 · 八条公理** → 加法四条「换、结、零、负」，数乘四条「两分配、一结合、一单位」；唯一**不能由其余七条推出**的是单位律 $1\boldsymbol{\alpha}=\boldsymbol{\alpha}$ → [1.1.4](../ch01/sec11.md#sec-1.1.4)

2. **子空间判定** → 固定顺序：先查**子集**、再看**零元**、最后验任意线性组合 $a\boldsymbol{x}+b\boldsymbol{y}\in W$（一次覆盖两种封闭性）→ [1.2.2](../ch01/sec12.md#sec-1.2.2)

3. **交、并、和** → 交与和一定是子空间，**并一般不是**（除非一个有包含关系）；「和」与「并」不要混 → [1.2.5](../ch01/sec12.md#sec-1.2.5)

4. **基与坐标** → 基＝无关**且**张成（无冗余＋够用，缺一不可）；坐标是**表示唯一的系数**，依赖基、不是向量的固有属性 → [1.3.3](../ch01/sec13.md#sec-1.3.3)、[1.3.5](../ch01/sec13.md#sec-1.3.5)

5. **过渡矩阵** → 「新基＝旧基 $\times P$」，$P$ 的第 $j$ 列是新基第 $j$ 个向量在**旧基**下的坐标；换基时矩阵贴着**旧**的一侧 → [1.3.7](../ch01/sec13.md#sec-1.3.7)

6. **维数公式** → $\dim(W_1+W_2)=\dim W_1+\dim W_2-\dim(W_1\cap W_2)$；用法的三步：各求秩 → 拼矩阵求和的秩 → 代公式 → [1.3.9](../ch01/sec13.md#sec-1.3.9)

7. **直和判定** → 四条等价，**最快的一眼是查交** $W_1\cap W_2=\{\boldsymbol{\theta}\}$；只给维数时才用「维数相加」判定 → [1.6.1](../ch01/sec16.md#sec-1.6.1)、[1.6.2](../ch01/sec16.md#sec-1.6.2)

8. **投影** → 投影依附**整个分解**：谈投影必须说清「沿哪个补空间」，同一个 $W_1$ 换补就换投影 → [1.6.3](../ch01/sec16.md#sec-1.6.3)

9. **内积（复空间）** → 共轭对称＋对**第一**变元线性；长度是 $\sqrt{\sum|x_i|^2}$（不是 $\sqrt{\sum x_i^2}$）；从第二变元提常数要取共轭 → [1.4.1](../ch01/sec14.md#sec-1.4.1)、[1.5.1](../ch01/sec15.md#sec-1.5.1)

10. **Cauchy–Schwarz 与勾股** → $|(\boldsymbol{x},\boldsymbol{y})|\le\|\boldsymbol{x}\|\|\boldsymbol{y}\|$，等号 ⟺ 线性相关；「正交 ⟹ 勾股」实复都对，**逆命题只在实空间成立** → [1.5.2](../ch01/sec15.md#sec-1.5.2)、[1.5.5](../ch01/sec15.md#sec-1.5.5)

11. **正交补与正交投影** → $W^{\perp}$ 由 $W$ 与内积**唯一确定**（一般补空间要挑，它不用挑）；正交投影＝垂直落下＋最近点；投影公式**只认正交基** → [1.6.6](../ch01/sec16.md#sec-1.6.6)、[1.6.7](../ch01/sec16.md#sec-1.6.7)

12. **核与像** → $N(T)\le V$、$R(T)\le W$（住哪个空间别写反）；亏加秩 $\dim N(T)+\dim R(T)=\dim V$ → [2.2.5](../ch02/sec22.md#sec-2.2.5)

13. **单射判据与维数陷阱** → $T$ 单射 ⟺ $N(T)=\{\boldsymbol{\theta}\}$（首选口径）；「单射 ⟹ 满射」必须先有 $\dim V=\dim W$ → [2.2.3](../ch02/sec22.md#sec-2.2.3)

14. **同构** → 双射**＋**保运算（等势不够）；同数域有限维下判据只看**维数相等** → [2.3.2](../ch02/sec23.md#sec-2.3.2)、[2.3.5](../ch02/sec23.md#sec-2.3.5)

15. **特征值与特征向量** → 「$T$ 与 $A$ 互相翻译」：矩阵的特征值就是变换的特征值，解出的特征向量是**坐标**，回答案前要**乘回基** → [2.4.1](../ch02/sec24.md#sec-2.4.1)

16. **迹与行列式当验算** → $\operatorname{tr}A=\sum\lambda_i$、$\det A=\prod\lambda_i$（含重数），两者都是相似不变量——求出特征值先核这两个数 → [2.4.2](../ch02/sec24.md#sec-2.4.2)

17. **两种重数与对角化** → $V_\lambda=N(A-\lambda I)$ **含零向量**（「特征向量全体」不含、也不是子空间）；恒有 $1\le$ 几何 $\le$ 代数，**处处取等 ⟺ 可对角化** → [2.4.3](../ch02/sec24.md#sec-2.4.3)

18. **不变子空间** → 「被 $T$ 映回自己」的子空间：特征向量张成的直线是最小的一档，$V_\lambda$ 亦然；它还在 $\ker g(A)$（$g$ 是 $f$ 的因式）处出场 → [2.4.3](../ch02/sec24.md#sec-2.4.3)、[2.1.2](../ch02/sec21.md#sec-2.1.2)

19. **正交／酉变换** → 四条等价：保内积 ⟺ 保长度 ⟺ 标准正交基映为标准正交基 ⟺ $A^{\mathrm H}A=I$；验「保长度」比验「保内积」省一遍计算 → [2.5.2](../ch02/sec25.md#sec-2.5.2)

20. **正交矩阵的特征值** → 只能保证 $|\lambda|=1$（**别写 $\pm1$**：旋转阵给 $\pm\mathrm i$）；Givens 旋转 $\det=+1$，Householder 反射 $\det=-1$、$H^2=I$ 且 $H^{\mathrm T}=H$ → [2.5.1](../ch02/sec25.md#sec-2.5.1)、[2.5.4](../ch02/sec25.md#sec-2.5.4)

21. **相抵** → $B=P^{-1}AQ$（两端各自换基）；同型相抵 ⟺ 同秩；**分解式不唯一、标准形由秩唯一决定** → [3.1.1](../ch03/sec31.md#sec-3.1.1)

22. **单侧逆与秩等式** → **行**满秩 ⟺ **右**逆，**列**满秩 ⟺ **左**逆（方向不能反）；$\operatorname{rank}A=\operatorname{rank}(A^{\mathrm H}A)=\operatorname{rank}(AA^{\mathrm H})$ → [3.1.3](../ch03/sec31.md#sec-3.1.3)、[3.1.4](../ch03/sec31.md#sec-3.1.4)

23. **满秩分解** → $A=BC$：$B$ **列**满秩（列是 $R(A)$ 的一组基）、$C$ **行**满秩（列是坐标）；不唯一的精确刻度是「两种分解差一个**可逆** $D$」 → [3.2.1](../ch03/sec32.md#sec-3.2.1)、[3.2.3](../ch03/sec32.md#sec-3.2.3)

24. **最小多项式** → $m_A$ 唯一、整除**一切**零化多项式（故 $m_A\mid f_A$）、与 $f_A$ **同根不计重数**；候选法**从低往高**试 → [3.5.4](../ch03/sec35.md#sec-3.5.4)

25. **QR 与两张保底牌** → $A=QR$ 的 $r_{kk}$ 是**残差**范数、正线下唯一；QR 迭代 $A_{k+1}=Q_k^{\mathrm H}A_kQ_k$ 是**酉相似**、模互异才收敛；复方阵总能酉相似于上三角，实阵要「特征值全实」 → [3.4.1](../ch03/sec34.md#sec-3.4.1)、[3.4.3](../ch03/sec34.md#sec-3.4.3)、[3.5.1](../ch03/sec35.md#sec-3.5.1)

## 二、推导现场

**规则**：下面 12 条是**必须能当场推出来**的结论。不要背证明，练「第一行＋三步结构」——每条只给「思路三步」，完整证明回正文。写完对照时只问一件事：**那三步我有没有真的走完**。

::: think 推导 1 · 维数公式 $\dim(W_1+W_2)=\dim W_1+\dim W_2-\dim(W_1\cap W_2)$ {#derive-dim-formula}

**思路三步**：① **从最公共的地方取基**——取 $W_1\cap W_2$ 的一组基 $\boldsymbol{u}_1,\cdots,\boldsymbol{u}_m$；② **双向扩充**——先把它扩充成 $W_1$ 的基（添 $\boldsymbol{v}_1,\cdots,\boldsymbol{v}_s$），再扩充成 $W_2$ 的基（添 $\boldsymbol{w}_1,\cdots,\boldsymbol{w}_t$）；③ **证明拼起来的 $m+s+t$ 个向量是 $W_1+W_2$ 的基**：张成显然；无关要「组合落在 $W_1$ 里 ⟹ 落在 $W_1\cap W_2$ 里 ⟹ 被 $\boldsymbol{u}$ 组的无关性吃掉」，最后数数 $(m+s)+(m+t)-m$。

**考场提醒**：只写「拼起来就是一组基」正是跳步高发处（[证明工坊 · 骨架六](../proof-workshop.md)）；数数之前，「张成」与「线性无关」两件事必须都落地。
:::

::: think 推导 2 · 直和判定：零元素表法唯一 ⟺ $W_1\cap W_2=\{\boldsymbol{\theta}\}$ {#derive-direct-sum}

**思路三步**：① **认出零元素的一般表法**——$\boldsymbol{\theta}=\boldsymbol{u}+(-\boldsymbol{u})$，其中 $\boldsymbol{u}\in W_1$、$-\boldsymbol{u}\in W_2$ 当且仅当 $\boldsymbol{u}\in W_1\cap W_2$；② **交非零 ⟹ 表法不唯一**——取非零 $\boldsymbol{u}\in W_1\cap W_2$，则 $\boldsymbol{\theta}=\boldsymbol{\theta}+\boldsymbol{\theta}=\boldsymbol{u}+(-\boldsymbol{u})$ 是两个不同表法；③ **交为零 ⟹ 唯一**——任何零表法都被迫取 $\boldsymbol{u}=\boldsymbol{\theta}$；再补一句「任意向量的两种拆法相减就是零表法」，把 (2) 推回 (1)。

**考场提醒**：这条就是[@thm-1.6.1] 的 (2)⟺(3)，也是「直和 ⇔ 交为零」的全部内容；(3)⟺(4) 那一环要用 [1.3.9](../ch01/sec13.md#sec-1.3.9) 的维数公式接起来。
:::

::: think 推导 3 · 幂等与投影：$A^2=A$ ⟹ $\mathbb{C}^n=R(A)\dotplus N(A)$ {#derive-idempotent}

**思路三步**：① **看两个子空间各自被 $A$ 如何作用**——$\boldsymbol{x}\in R(A)\Rightarrow A\boldsymbol{x}=\boldsymbol{x}$（因 $\boldsymbol{x}=A\boldsymbol{z}$、$A^2=A$），$\boldsymbol{x}\in R(I-A)\Rightarrow A\boldsymbol{x}=\boldsymbol{0}$；② **交为零**——取 $\boldsymbol{w}\in R(A)\cap R(I-A)$，则 $\boldsymbol{w}=A\boldsymbol{w}=\boldsymbol{0}$，由[@thm-1.6.1] (3) 得直和；③ **补满整个空间**——恒等式 $\boldsymbol{x}=A\boldsymbol{x}+(I-A)\boldsymbol{x}$ 把任意向量拆进 $R(A)$ 与 $R(I-A)$。

**再补一行（把 $A$ 认成投影）**：拆法唯一 ⟹ $\boldsymbol{x}\mapsto A\boldsymbol{x}$ 就是「沿 $R(I-A)$ 落到 $R(A)$」的投影；再加一行双向包含得 $N(A)=R(I-A)$，于是这副分解可以写成更常用的一张脸 $\mathbb{C}^n=R(A)\dotplus N(A)$。**顺手的推论**：特征值 $1$ 的个数 $=\operatorname{rank}A$，故 $\operatorname{tr}A=\operatorname{rank}A$。
:::

::: think 推导 4 · 特征子空间的直和性：不同特征值的特征向量组线性无关 {#derive-eig-independent}

**思路三步**：① **取一个最短的线性关系**——在诸特征向量中取个数最少的相关组 $c_1\boldsymbol{\xi}_1+\cdots+c_k\boldsymbol{\xi}_k=\boldsymbol{\theta}$（各 $c_i\neq0$），并盯住最后一个特征值 $\lambda_k$；② **相减消元**——两边作用 $T$ 得 $\sum c_i\lambda_i\boldsymbol{\xi}_i=\boldsymbol{\theta}$，减去 $\lambda_k$ 乘原式，得 $\sum_{i<k}c_i(\lambda_i-\lambda_k)\boldsymbol{\xi}_i=\boldsymbol{\theta}$，系数全非零（特征值互异）；③ **矛盾收尾**——这给出一个更短的非平凡关系，与「最少」矛盾。

**考场提醒**：等价说法是「不同特征值的特征子空间之和是直和」。第 ① 步的「取最少」是这条证明的心脏；直接归纳容易在「$k$ 与 $k-1$ 之间」含糊过去。
:::

::: think 推导 5 · 亏加秩定理 $\dim N(T)+\dim R(T)=\dim V$ {#derive-rank-nullity}

**思路三步**：① **从核取基再扩充**——取 $N(T)$ 的基 $\boldsymbol{h}_1,\cdots,\boldsymbol{h}_m$，由基扩充定理添成 $V$ 的基 $\boldsymbol{h}_1,\cdots,\boldsymbol{h}_m,\boldsymbol{h}_{m+1},\cdots,\boldsymbol{h}_n$；② **量出值域由后 $n-m$ 个像张成**——任取 $\boldsymbol{x}=\sum k_i\boldsymbol{h}_i$，作用 $T$ 后前 $m$ 项消失，故 $R(T)=\operatorname{span}\{T(\boldsymbol{h}_{m+1}),\cdots,T(\boldsymbol{h}_n)\}$；③ **证这 $n-m$ 个像无关**——若其组合为零，则该组合属于 $N(T)$、可由前 $m$ 个基向量表出；与 $\boldsymbol{h}$ 组的无关性联立，逼出系数全为零。

**考场提醒**：第 ③ 步必须「回到核的基再收尾」（[@thm-2.2.5] 的评分要点）。它与「同维时单射 ⟺ 满射」是两个结论，后者要额外假设 $\dim V=\dim W$。
:::

::: think 推导 6 · 秩等式 $\operatorname{rank}(A)=\operatorname{rank}(A^{\mathrm H}A)$ {#derive-rank-transpose}

**思路三步**：① **先证 $N(A)=N(A^{\mathrm H}A)$**：由 $A\boldsymbol{x}=\boldsymbol{0}$ 两边左乘 $A^{\mathrm H}$ 得 $A^{\mathrm H}A\boldsymbol{x}=\boldsymbol{0}$，即 $N(A)\subseteq N(A^{\mathrm H}A)$；② **反方向用内积正定性**——由 $A^{\mathrm H}A\boldsymbol{x}=\boldsymbol{0}$ 左乘 $\boldsymbol{x}^{\mathrm H}$，得 $\|A\boldsymbol{x}\|^2=(A\boldsymbol{x},A\boldsymbol{x})=0$，正定性逼 $A\boldsymbol{x}=\boldsymbol{0}$；③ **换成维数**——两个矩阵零空间相同，由 $\dim N+\operatorname{rank}=$ 列数 得秩相等。

**考场提醒**：三步里真正花力气的是第 ② 步的**正定性**（[@prop-3.1.1]）。这也解释了为什么它不能平移到任意数域，也不能把 $A^{\mathrm H}A$ 换成 $A^2$（[3.1.4](../ch03/sec31.md#sec-3.1.4) 的补注）。
:::

::: think 推导 7 · 满秩分解的不唯一刻画：两种分解差一个可逆因子 {#derive-full-rank-d}

**思路三步**：① **两个列空间相同**——由 $A=B_1C_1$、$C_1$ 行满秩（作为映射满射）得 $R(B_1)=R(A)$；同理 $R(B_2)=R(A)$，故 $R(B_1)=R(B_2)$；② **过渡矩阵出场**——$B_1$、$B_2$ 的列是同一个 $r$ 维子空间的两组基，由过渡矩阵的存在唯一性，存在**可逆** $D$ 使 $B_1=B_2D$；③ **$C$ 随之被决定**——由 $B_2C_2=B_1C_1=B_2DC_1$ 得 $B_2(C_2-DC_1)=O$，用 $B_2$ 列无关（表示唯一）逼出 $C_2=DC_1$，即 $C_1=D^{-1}C_2$。

**考场提醒**：结论是「**一个**分解即生成全部」——任取可逆 $D$ 都能造出一族新分解；写「不唯一」时若漏掉「$D$ 可逆」，等于把结论写成了「随便」。
:::

::: think 推导 8 · 正交／酉变换四条等价的一条最短循环 {#derive-orth-equiv}

**思路三步**：① **$A^{\mathrm H}A=I$ ⟹ 保内积**——$(A\boldsymbol{x},A\boldsymbol{y})=\boldsymbol{y}^{\mathrm H}A^{\mathrm H}A\boldsymbol{x}=\boldsymbol{y}^{\mathrm H}\boldsymbol{x}=(\boldsymbol{x},\boldsymbol{y})$；② **保内积 ⟹ 保长度**——在 $\boldsymbol{y}=\boldsymbol{x}$ 处取值即得 $\|A\boldsymbol{x}\|^2=\|\boldsymbol{x}\|^2$；③ **保长度 ⟹ 标准正交基映为标准正交基 ⟹ $A^{\mathrm H}A=I$**——取标准正交基 $\boldsymbol{e}_j$，保长度给出每一列都是单位向量，再用极化（在**复**空间要用 $\boldsymbol{q}_i+t\boldsymbol{q}_j$ 把虚部也钉死）恢复内积，得 $(A\boldsymbol{e}_i,A\boldsymbol{e}_j)=\delta_{ij}$，把这两式按列读出来就是 $A^{\mathrm H}A=I$。

**考场提醒**：循环闭合即可（[证明工坊 · 骨架五](../proof-workshop.md)），但复空间那一步不能省——实空间里「保长度」用点积展开就够，复空间必须走极化。
:::

::: think 推导 9 · QR 的读法：Gram–Schmidt 就是算法 {#derive-qr-read}

**思路三步**：① **把两族向量写成基的关系**——GS 的「张成不变」给出 $(\boldsymbol{a}_1,\cdots,\boldsymbol{a}_n)=(\boldsymbol{z}_1,\cdots,\boldsymbol{z}_n)R$，即 $R$ 正是「$\boldsymbol{z}$ 基到 $\boldsymbol{a}$ 基」的**过渡矩阵**；② **逐列读出元素**——第 $k$ 列两边与 $\boldsymbol{z}_i$（$i<k$）作内积，正交性把和式砍成一项：$r_{ik}=(\boldsymbol{a}_k,\boldsymbol{z}_i)$；对角元来自残差 $\boldsymbol{y}_k=\boldsymbol{a}_k-\sum_{i<k}(\boldsymbol{a}_k,\boldsymbol{z}_i)\boldsymbol{z}_i$，故 $r_{kk}=\|\boldsymbol{y}_k\|$；③ **补上「列满秩 ⟹ 正线唯一」**——列无关保证各残差非零、$R$ 对角非零；把每列的符号用对角酉阵吸收即得 $R$ 正线，[@thm-3.4.1] 的唯一性随之成立。

**考场提醒**：$r_{kk}$ 是**残差**范数（不是 $\|\boldsymbol{a}_k\|$），这是本节最高频的失分点；写完必须回代 $QR=A$。
:::

::: think 推导 10 · Schur 型的存在性：复方阵总能酉相似于上三角 {#derive-schur}

**A 路线（直接构造，自包含）**：① **起手用一个单位特征向量**——取 $A\boldsymbol{u}_1=\lambda_1\boldsymbol{u}_1$、$\|\boldsymbol{u}_1\|=1$，扩充为标准正交基、拼成酉阵 $U_1$，第一列立刻干净：$U_1^{\mathrm H}AU_1=\begin{bmatrix}\lambda_1&\boldsymbol{\beta}\\ \boldsymbol{0}&A_1\end{bmatrix}$；② **对 $n-1$ 阶块归纳**——设 $A_1=V\Lambda_1V^{\mathrm H}$；③ **拼装**——$U=U_1\operatorname{diag}(1,V)$ 仍是酉阵，且 $U^{\mathrm H}AU=\begin{bmatrix}\lambda_1&*\\ \boldsymbol{0}&\Lambda_1\end{bmatrix}$ 上三角。

**B 路线（借力再升级）**：先用「相似于上三角」（[@thm-3.5.1]，对阶数归纳）拿到 $P^{-1}AP=\Lambda$；再对 $P$ 作 QR 分解 $P=UR$，代入得 $U^{\mathrm H}AU=R\Lambda R^{-1}$——**上三角阵对乘法和求逆封闭**，于是也是上三角。

**考场提醒**：A 路线自包含、不必先写另一个定理的骨架，考场更稳；两条都练过才有得选（第三章竞技场把两条路线分开计分）。
:::

::: think 推导 11 · Hamilton–Cayley：$f_A(A)=O$ {#derive-hamilton-cayley}

**思路三步**：① **先在上三角情形下手**——由 Schur 型不妨设 $A$ 上三角、对角元为 $\lambda_1,\cdots,\lambda_n$，于是 $f_A(\lambda)=\prod_{k}(\lambda-\lambda_k)$；② **按次序乘因子、逐列清零**——左乘 $(\Lambda-\lambda_1I)$ 先把第 $1$ 列打成零；再乘 $(\Lambda-\lambda_2I)$，第 $2$ 列也被打掉（关键是「上三角乘以 $(\Lambda-\lambda_kI)$ 只影响前 $k$ 列」这一句，它把**次序**钉死）；③ **$n$ 个因子乘完即 $O$**，再对一般 $A$ 用相似（或酉相似）把结论搬回去。

**考场提醒**：最常见的伪证是「对角元全为零 ⟹ 矩阵为零」——$\begin{bmatrix}0&1\\0&0\end{bmatrix}$ 就是反例；必须真的写出「逐列清零」这一步。
:::

::: think 推导 12 · 正交投影为什么是最近点 {#derive-nearest}

**思路三步**：① **残差垂直**——设 $\boldsymbol{y}=\operatorname{Proj}_W\boldsymbol{x}$，则 $\boldsymbol{x}-\boldsymbol{y}\perp W$（正交补的定义）；② **对任意 $\boldsymbol{w}\in W$ 做勾股分解**——$\boldsymbol{x}-\boldsymbol{w}=(\boldsymbol{x}-\boldsymbol{y})+(\boldsymbol{y}-\boldsymbol{w})$，两项正交（第一项 $\perp W$、第二项 $\in W$），故 $\|\boldsymbol{x}-\boldsymbol{w}\|^2=\|\boldsymbol{x}-\boldsymbol{y}\|^2+\|\boldsymbol{y}-\boldsymbol{w}\|^2\ge\|\boldsymbol{x}-\boldsymbol{y}\|^2$；③ **等号条件**——取等当且仅当 $\boldsymbol{w}=\boldsymbol{y}$，即 $\boldsymbol{y}$ 是 $W$ 中**唯一**的最近点。

**考场提醒**：第 ② 步只用到「正交 ⟹ 勾股」这一个方向，正好在复空间也够用；不要把「勾股 ⟺ 正交」的逆命题写进去。
:::

## 三、工程与判断

**规则**：这一节问的不是「会不会算」，而是「**该用哪件工具、为什么用、代价是什么**」。每条先自己答，再看要点。共 10 条。

1. **三副「换基权」怎么挑？** 相抵 $B=P^{-1}AQ$、相似 $B=P^{-1}AP$、合同 $B=P^{\mathrm H}AP$ 都是「换基」，但保的东西不同：**相抵只保秩**（适合解方程组、判秩、造单侧逆）；**相似保特征值、迹、行列式**（适合特征值问题，换基不改变变换本身）；**合同保内积与正定性**（适合度量矩阵、二次型、能量）。挑错的直接后果是：用相抵去读特征值（信息已经丢了），或用相似去化长方阵（根本没定义）。

2. **为什么「能用酉就不用一般可逆」？** 酉（正交）变换保长度 $\|Q\boldsymbol{x}\|=\|\boldsymbol{x}\|$，因此**不放大误差**：用它做 QR、Schur、QR 算法时，中间量的大小与输入同一量级；而一般可逆的相似 $P^{-1}AP$ 会把误差按 $P$、$P^{-1}$ 的规模放大——这正是「能用酉就不用一般可逆」这条原则的工程含义。

3. **「秩」为什么不能只看消元结果是否恰好为零？** 精确算术里秩是整数、不会中途改变；浮点下「恰好为零」几乎不发生，真正要看的是**有没有可以被舍掉的极小主元 / 极小谱值**——要定一个**阈值**，得到的量叫「数值秩」。本册 3.1–3.5 给的判秩工具（消元、$\operatorname{rank}A=\operatorname{rank}(A^{\mathrm H}A)$、满秩分解）都是精确口径；直接搬进浮点要小心：$A^{\mathrm H}A$ 会把误差放大，所以工程实现宁可对 $A$ 本身做直接正交化（QR / Schur），或用奇异值谱阈值判秩（3.6 及以后的内容，本册只点到为止）。

4. **手算还是迭代？** 手算题给你小矩阵、整齐的数字，用特征多项式 $f_A$ 配合迹 / 行列式核对最快；矩阵一大、或因式分解不出来，手算就彻底失效——这时才轮到 QR 算法：它不展开特征多项式，只用一次次 QR 分解把特征值挤上对角线，代价是**迭代**（要指定轮数，还要满足「模互异」这个收敛前提）。

5. **相似与相抵在计算中的差别，落到一句话**：相抵允许**两端各自**换基，所以只留「秩」这一件信息——化简之后你只能回答「解的结构」；相似是**同一空间**换基（$Q=P$），变换本身没变，所以动态系统 $\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k$ 的表现、幂 $A^m$ 的特征值全部照旧。**要特征值，只能用相似，不能只做相抵。**

6. **最小多项式为什么是「最省的账本」？** 降次时除以 $m_A$ 比除以 $f_A$ 得到更低的余式（[@thm-3.5.5]：$m_A$ 整除一切零化多项式），$g(A)$、$A^m$ 的计算量更小；再配合谱映射（[@cor-3.5.1]）——幂、逆、多项式的特征值一步到位，不必重算特征多项式。

7. **Givens 和 Householder 该选谁？** Givens 一次只清**一个**分量（只动两个坐标），适合稀疏矩阵与并行；Householder 一次清**一整列**（动用全部坐标），适合稠密矩阵一次成型。判据很简单：**要清的零是「少数」还是「一大片」**；两者都正交、都不放大误差，差别只在工作量的分布。

8. **「正线」这种约定值得较真吗？** 值得。没有它，满秩方阵的 QR 分解有 $2^n$ 种（实情形）；有了它，答案唯一、可以与别人的结果逐位对照、可以写成程序里的断言。第三章七条勘误里符号与方向占了大头（[勘误与补注](../ch03/errata.md)）——**统一约定就是统一验算式**，而验算式是考场上最便宜的保险。

9. **什么时候该用满秩分解，而不是相抵？** 相抵把矩阵压成 $\Gamma$，但两侧的可逆矩阵把**列之间的关系**揉没了；满秩分解 $A=BC$ 保留「$B$ 的列是 $R(A)$ 的基、$C$ 的列是坐标」这副结构，于是 $R(A)$、$N(A)$、列与列的线性关系都能**直接读出来**，还能顺势写出 $AXA=A$ 的一个解。要研究「列空间与列关系」就选满秩分解；只想知道「秩是多少、方程有没有解」相抵就够。

10. **为什么「最小多项式」在工程里比「特征多项式」常用？** 因为它是**程度量**：$m_A$ 把「这个矩阵离可对角化还有多远」记成了一笔最省的账（重数能省则省），于是任何要算 $g(A)$、$A^m$、$A^{-1}$ 的地方，除以 $m_A$ 都最省；而 $f_A$ 只在求特征值、做迹 / 行列式核对时才需要展开全部重数。
