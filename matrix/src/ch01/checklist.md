# 学习目标自检表

逐条对照。**本表是三件事的映射**：左列给出目标的**简写标签**（完整「能……」表述见[学习目标](../preface-objectives.md)），中列是**自检口径**，右列是「正文依据 + 对应习题」。若某行卡壳，回到所指小节重读再做习题。

**使用建议：**先做[入学诊断自测](../entry-test.md)与[综合自测卷](mock-exam.md)，用失分点定位下面若干行，再回到「依据」列的正文小节重读、做「依据与习题」列的题。不要从头到尾机械地逐行打钩。目标的具体练法见[解题工具箱](../toolbox.md)的流程卡（GS / 投影 / 验算清单），记忆检验走[速查背记卡](../memory-sheet.md)与[闭卷回忆卡](recall-cards.md)。
