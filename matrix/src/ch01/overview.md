# 第一章 · 线性空间引论

本教程依据本课程六次课的课件整理扩充而成，覆盖线性空间、线性子空间、基与坐标、内积空间、向量长度与夹角、直和与投影六节。

## 六节各问一个问题

| 节 | 核心问题 |
|:--|:--|
| [1.1 线性空间](sec11.md) | 什么集合上能做线性运算？ |
| [1.2 线性子空间](sec12.md) | 大空间中哪些部分自成空间？ |
| [1.3 基与坐标](sec13.md) | 怎样给空间装「坐标系」并数出「刻度数」？ |
| [1.4 内积空间](sec14.md) | 怎样在线性空间里定义长度、夹角与正交？ |
| [1.5 向量长度与夹角](sec15.md) | 有了内积，怎样量出长度、夹角与垂直？ |
| [1.6 直和与投影](sec16.md) | 和空间何时拆法唯一？分量怎么算？ |

每节的**关键结论**与**典型陷阱**见[章末总结的「六节一览」](summary.md#六节一览)——本页只负责「先知道每节在问什么」，不重复结论清单。

## 一条主线

六节一环扣一环：**先规定规则（1.1），再找封闭的部分（1.2），用基把信息压成坐标（1.3），加入几何（1.4），提炼出长度、夹角与正交（1.5），最后研究拆法唯一的和与投影（1.6）。**

带结构图、逐环展开的完整版本见[全章知识地图](../preface-map.md)。
