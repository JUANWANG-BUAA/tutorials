## 六层结构，一条主线

每一层只记一句话，六句连起来就是全章：

1. **线性空间 = 加群 + 数域上的数乘**——八条公理是全部规则的来源。
2. **子空间由封闭性判定**——交、和与 $\operatorname{span}$ 是基本构造；$N(A)$ 与 $R(A)$ 把方程组放进空间语言。
3. **基 = 无关的生成组**——它给向量唯一坐标；过渡矩阵处理换基，维数公式计算子空间的规模。
4. **内积 = 线性结构上的几何**——复空间里必须照顾共轭；固定基后内积等价于一个正定 Hermite 的度量矩阵，换基只改变矩阵表示、不改变几何本身。
5. **长度、夹角、正交是内积的直接产物**——Cauchy–Schwarz 是全部几何不等式的源头（注意夹角只对**实**空间有定义），Gram–Schmidt 把任意基掰成正交基，标准正交基下度量矩阵坍缩为 $I$。
6. **拆法唯一的和是直和**——直和分解给出投影；正交补让投影变成「垂直落下」的法定运算且是最近点；GS 的换基关系整理成正线上三角（QR 雏形）；幂等矩阵与 $N(A)\oplus R(A^{\mathrm H})$ 把这些分解装进矩阵等式。

## 看到题目，先选工具

本表按**题型**给出第一动作；若要按「触发词 → 定理名」反查，见[速查背记卡 B 表](../memory-sheet.md)——本表面向做题，那张表面向回忆定理。

| 题目在问 | 第一动作 | 为什么 |
|:--|:--|:--|
| 某集合是不是线性空间 | 先确认运算；若是新运算，找零元、负元并验八条 | 不能借用通常运算的公理 |
| 某子集是不是子空间 | 先看是否为子集、是否含零向量，再验任意线性组合 | 零向量能最快否定；线性组合条件一次覆盖两种封闭性 |
| $A\boldsymbol{x}=\boldsymbol{b}$ 是否可解 | 判断 $\boldsymbol{b}\in R(A)$ | 列空间就是所有可能的输出 |
| 向量组是否无关、能否作基 | 拼列矩阵求秩；基还要同时检查张成 | 「无冗余」与「够用」缺一不可 |
| 求换基后的坐标 | 先写「新基 = 旧基 × $P$」，再用「旧坐标 = $P$ × 新坐标」 | 先固定方向，避免把 $P$ 和 $P^{-1}$ 用反 |
| 一个公式是不是内积 | 先查共轭对称/Hermite，再查正定 | 前者保证交换自洽，后者排除非零向量长度为零 |
| 做 Gram–Schmidt | 依次减去在**已经正交化**方向上的全部成分 | 被减方向必须是 $\boldsymbol y_i$，不是原始 $\boldsymbol x_i$ |
| $W_1+W_2$ 是否为直和 | 优先求 $W_1\cap W_2$；只交于零即可 | 比逐个证明分解唯一更短 |
| 求投影 | 先写清目标子空间和沿哪个补空间，再解唯一分解 | 投影由整个直和分解决定，不只由目标空间决定 |
| 求 $W^{\perp}$ | 设「与 $W$ 的基正交」得线性方程组，解出补空间的基；核维数 $n-\dim W$ | $W$ 的每个基向量给一个齐次方程 |
| 求正交投影 | 基正交 → 命题 1.6.1 公式；不正交 → 先 GS 或解 Gram 方程组；$W^{\perp}$ 好求 → 先投补再相减 | 投影公式只认**正交**基（勘误 E12） |

## 学完之后

按下面的顺序收尾：**先自测、再反查、最后串一遍**。

1. **[闭卷回忆卡](recall-cards.md)**：先确认关键定义、定理和证明入口能从空白纸上叫出来。
2. **[综合自测卷](mock-exam.md)**：闭卷计时 90 分钟、100 分制。不看分数，看**每道错题卡在哪一步**。
3. **[学习目标自检表](checklist.md)**：把失分点对到 25 条学习目标，回到正文对应小节重读该节的「即时自测」。
4. **[习题集](exercises.md)**：只重做做过记号的题；B 组的证明题要看自己能否**写出结构完整、每步有依据**的证明（对应目标 A1.5）。
5. **[勘误表](errata.md)**：读一遍 E1–E15 的发现过程；能独立发现这类问题，说明已具备复核他人论证的能力。
6. **[全章知识地图](../preface-map.md)**：最后用一张图把「空间 → 子空间 → 基 → 内积 → 度量 → 直和」串成一条线，能自己复述即算过关。
