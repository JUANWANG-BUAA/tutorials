# 证明怎么下笔：六种骨架

「看证明时觉得合理，自己写时一片空白」，通常不是没有理解每一行，而是没有记住**证明的入口和结构**。证明不从完整答案开始，而从四行草稿开始：

| 草稿栏 | 要写什么 |
|:--|:--|
| **已知** | 题目给了哪些定义条件？把形容词翻译成公式 |
| **要证** | 结论按定义等价于什么？是包含、相等、唯一，还是恒正？ |
| **桥梁** | 哪个对象同时接触已知与结论？需要构造谁？ |
| **收口** | 最后凭哪条定义或定理宣布完成？ |

::: method 下笔前的 30 秒

先不要算。圈出命题中的关键词：**子空间、唯一、线性无关、维数、内积、直和**。每个词都对应一种固定骨架。把定义展开，通常第一行就出现了。

:::

## 骨架一：证明「是子空间」

**触发词：**解集、满足某个齐次条件的矩阵/函数集合、$\operatorname{span}$。

**第一行：**「先验证 $W\subseteq V$ 且 $\boldsymbol{\theta}\in W$。任取 $\boldsymbol x,\boldsymbol y\in W$ 与 $a,b\in F$……」

接下来只做一件事：把 $a\boldsymbol x+b\boldsymbol y$ 代回定义条件，证明结果仍满足条件。最后写：「由子空间判定定理，$W$ 是 $V$ 的子空间。」

若要判定「不是」，优先依次试：不是子集 → 不含零向量 → 数乘不封闭 → 加法不封闭。否定命题只需一个反例。

## 骨架二：证明「表示唯一」

**触发词：**坐标唯一、分解唯一、解唯一、投影唯一。

**第一行：**「假设同一对象有两种表示……」

把两式相减，得到一个等于零的式子；再用「基线性无关」「零元素表法唯一」或「交集只有零向量」迫使对应分量相等。

$$
\text{两种表示}
\Longrightarrow \text{相减得到零表示}
\Longrightarrow \text{各系数/分量为零}
\Longrightarrow \text{两种表示相同}.
$$

## 骨架三：证明「线性无关」

**触发词：**一组向量是基、正交组、扩充后的向量组。

**第一行：**「设 $c_1\boldsymbol v_1+\cdots+c_n\boldsymbol v_n=\boldsymbol{\theta}$。」

目标不是直接说「显然无关」，而是逐步迫使 $c_1=\cdots=c_n=0$。常用工具有三种：比较坐标、与某个向量作内积、把等式两边放进两个子空间并进入交空间。

## 骨架四：证明「两个集合相等」

**触发词：**$U=W$、$N(A)=R(I-A)$、某个和空间等于整个空间。

**第一行：**「分别证明 $U\subseteq W$ 与 $W\subseteq U$。」

每个方向都从「任取」开始：任取 $\boldsymbol x\in U$，利用 $U$ 的定义推出它满足 $W$ 的定义。不要只证明一个方向；「维数相同」也不能单独替代包含关系，除非已知二者是有限维子空间且已有一个包含。

## 骨架五：证明「若干命题等价」

**触发词：**「以下命题等价」「充要条件」。

先画最短箭头，不必证明所有两两方向。例如三个命题可走循环

$$ (1)\Longrightarrow(2)\Longrightarrow(3)\Longrightarrow(1), $$

四个命题也可以证明 $(1)\Leftrightarrow(2)$、$(2)\Leftrightarrow(3)$、$(3)\Leftrightarrow(4)$。动笔前把箭头写在纸上，每完成一个方向就打勾。

## 骨架六：证明「维数公式或不等式」

**触发词：**$\dim$、基的个数、和空间与交空间。

**第一动作：**选一组最能避免重复计数的基。对 $W_1+W_2$，先从公共部分 $W_1\cap W_2$ 取基，再分别向 $W_1$、$W_2$ 扩充。

构造出候选向量组后必须完成两件事：

1. 证明它**张成**目标空间；
2. 证明它**线性无关**。

最后才能数向量个数。只写「拼起来就是一组基」通常正是证明跳步发生的地方。

## 内积不等式的特殊入口

看到 $|(\boldsymbol x,\boldsymbol y)|$、长度或最小残差时，尝试构造一个必非负的量：

$$0\leq\|\boldsymbol x-\lambda\boldsymbol y\|^2.$$

然后选择 $\lambda$ 消掉交叉项或让残差正交。这里的关键不是背展开式，而是记住：**「不等式从非负量来，最佳系数从正交残差来。」**

## 三个常见「断笔点」

| 卡住的位置 | 自问 | 修复动作 |
|:--|:--|:--|
| 不知道第一行 | 结论里的关键词对应哪个定义？ | 把定义完整写开 |
| 推到一半不知道为何构造某对象 | 这个对象要同时属于哪两个集合，或让哪个量变成零？ | 在式子旁写构造目的 |
| 算完不知道是否证完 | 最后一句应引用哪条定义/定理？ | 明写「由……可知……」 |

::: method 一页练习

不看正文，只写证明骨架，不做细节计算：

1. $N(A)$ 是子空间；
2. 基下的坐标唯一；
3. 两两正交的非零向量组线性无关；
4. $A^2=A$ 时 $N(A)=R(I-A)$；
5. $W_1\dotplus W_2$ 等价于 $W_1\cap W_2=\{\boldsymbol{\theta}\}$。

如果五题都能在一分钟内写出第一行，再回正文补细节。第一行写不出时，优先复习本页对应骨架，而不是背完整答案。

:::
