# 第九章来源核读与纠偏（原创归纳）

## 方法与范围

- 本章涉及的时钟门控、休眠模式转换、WFI/WFE 语义以及电源管理寄存器映射，严格映射自经典母本与厂商官方硬件手册：
  1. 《TI Stellaris LM3S6965 Microcontroller》：物理页 90–91、183–186、214–233、709。
  2. 《ARMv7-M Architecture Ref Manual》：Chapter B3.2.11 (System Control Register)。
  3. 《The RISC-V Privileged Architecture》：Chapter 3.1 & 3.3。
  4. 《ARM64体系结构编程与实践》：第 16 章 16.1 节（物理页 265–267）。
- 抽取的文本在本地忽略目录 `.qa/edge/sources/ch09/`，不发布母本原页或复制其插图与代码。
- 以下记录各单元在正文中的技术落实与边界说明。

## 验证与限制边界

- 实验一为主机 C11 仿真，通过 ASan/UBSan 监控，量化验证 3.3V/1.8V/1.1V 多工作点的 DVFS 二次方能耗收益、600 µs PLL 重新锁相下的唤醒损益平衡时间（682 µs），以及 Tickless 相比 1 ms 周期性滴答的断崖式节能效果（消除 91.8% 空转能耗）。
- 实验二为 QEMU Cortex-M3 与 RV32IM 虚拟目标机固件，实际配置 `SCB->SCR`、外设时钟门控与 `mtimecmp` 定时器唤醒，完成 64 次休眠唤醒状态机流转，并通过破坏性变异测试捕获非法配置。
- 本轮未连接物理电流采样仪或真实电池，所有能耗与时间数据均明确标示为数学模型或目标机仿真。
- 来源清单库继续保持未全部逐节录入的真实状态，不宣称“缺口 0”。
