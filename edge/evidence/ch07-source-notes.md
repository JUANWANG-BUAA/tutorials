## TI 原始器件手册

- 文档：**Stellaris LM3S6965 Microcontroller**，Texas Instruments，页脚日期 **July 15, 2014**。
- 官方地址：<https://www.ti.com/lit/ds/symlink/lm3s6965.pdf>。
- 实际 PDF：761 物理页；SHA-256 `c3bfe9f1bcfb128f6a940aeb27805ce7ad7806ed412210b1f32367b24249f0a1`。
- 最初下载在约 3.37MB 处超时，随后 Range 续传完整并成功解析。未把半份 PDF 当作已读来源。
- 实际核读重点页：395（十位 ADC 能力）、397（序列/FIFO 表）、402（初始化前提）、406–409（RIS/IM/ISC/overflow）、424–425（FIFO 读副作用和状态）、430（SS3 END/IE）。其余抽取页只作定位或部分阅读。
- 物理第 397 页另渲染直接核看，确认 SS3 深度为 **1**，SS0 为 **8**，不是每个序列器都相同。

落实与限制：

1. §11.3.1，397：结果保存在 32 位 FIFO 读值低 10 位；读取弹出。正文据此区分寄存器宽度和转换分辨率。
2. §11.4 起始，402：硬件 ADC 要求 PLL 与受支持晶振。当前 QEMU 镜像没有完整配置这一板级链路，不能直接称为实体可烧录采样驱动。
3. Register 2–5，406–409：ISR 一次读结果，ISC 直接写 1 确认；不使用读改写误清其他事件。
4. Register 13–20，424–425：读取结果前检查 EMPTY，真实 FIFO 溢出服务预算按器件深度而非模型数组计算。
5. Register 26，430：SS3 只有一个条目，END0 必须保持置位；IE0=1 使完成产生事件，因此本例 SSCTL3=6。
6. 当前实验不验证硬件转换建立时间、温度、参考稳定、模拟管脚、PLL、真实溢出恢复和实际采样周期。

## QEMU 实现核读

作为模型能力线索，另下载并核读公开源码：

- `hw/arm/stellaris.c`：<https://gitlab.com/qemu-project/qemu/-/raw/master/hw/arm/stellaris.c>，SHA-256 `66fae838e0d04a6df7da968846c7255c7e305ddd0279b3226372e047ebd07d3e`。
- `hw/timer/stellaris-gptm.c`：<https://gitlab.com/qemu-project/qemu/-/raw/master/hw/timer/stellaris-gptm.c>，SHA-256 `7d632c176102ffabd107a0b14afd5e6aef6262febcc3eaebc6660a67f95a5cc0`。
- 实际运行二进制为 QEMU 11.1.2；未声称上述 master 文件与安装包逐提交完全相同。选择分支由实际正向和变异行为另行验证。
- Github raw 首次请求超时，换官方 GitLab 托管成功；没有重复轮询无效来源。

已核实线索：

- ADC 的 PSSI 写路径记录未实现，不产生软件启动转换。
- timer 触发条件匹配时才生成样本，样本由内部 noise 状态决定，不来自外部电压。
- 四个序列器在模型中使用 16 项内部数组，与实体 SS3 单项深度不一致。
- ADC 第四路中断连接到 NVIC 外部号 17。
- GPTM 的 TAOTE 位触发 ADC 输入事件。

本轮目标成功证明 MMIO、触发、中断和所选确认路径得到执行。
不证明模拟精度、物理 FIFO 抗溢出、器件时序或实体有效位数。
