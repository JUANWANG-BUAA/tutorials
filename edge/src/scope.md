## 0.1 核心攻防范围：三层计算体系

本书的重心全面聚焦于**架构、汇编、实时内核与外设交互**，形成垂直穿透的硬核系统全景：

```text

+-----------------------------------------------------------------------------------+
| 1. 计算架构与汇编：                                                               |
|    - ARM: ARMv7-M (Cortex-M4/M7), ARMv8-A (AArch64), Thumb-2 汇编, NVIC, SysTick |
|    - RISC-V: RV32I / RV64GC, M/S/U 特权模式, CSR 寄存器, CLINT, PLIC, PMP, RVV    |
```

## 0.2 严格排除与不展开的内容

为了确保篇幅的高度紧凑与技术穿透力，本书对以下邻近领域做出严格排除，绝不漫无目的地稀释注意力：

| 邻近领域 | 本书排除的具体内容 | 为什么排除与替代方案 |
|:--|:--|:--|
| **Linux 内核内部实现** | Linux VFS 虚拟文件系统、页缓存、通用网络协议栈内部实现 | 本书只在第 1 章探讨 Linux 与 MCU 在实时性、特权切换上的边界，内核细节请参考《Linux 系统与内核》 |
| **纯数字电路与 IC 制造** | 半导体 PN 结制造工艺、硅片光刻、CMOS 版图绘制、标准单元库布局布线 | 系统与固件工程师只需将芯片视为确定的黑盒，关注其寄存器、总线时序与电气引脚规范 |
| **纯模拟电路与器件物理** | 晶体管小信号微变等效模型、场效应管内部势垒物理推导 | 本书只关注外围传感器的输入阻抗、信号幅度范围与 ADC 采样保持电容的充电常数 |

## 0.3 跨架构对照准则

在探讨每一个技术命题时，本书均遵循“概念模型 $\rightarrow$ 寄存器位域 $\rightarrow$ 汇编落地 $\rightarrow$ 时序验证”的四步闭环：
1. **概念模型**：明确硬件机制所解决的本质冲突（如竞态、延迟、抖动、一致性）。
2. **寄存器位域**：展示实际硬件中各个控制位与状态位的物理定义与设置准则。
3. **汇编落地**：针对 ARM（Thumb-2/AArch64）、RISC-V 与 x86 给出手写的高性能汇编代码段。
4. **时序验证**：给出具体的执行周期消耗、总线占用时序或示波器/逻辑分析仪波形。
