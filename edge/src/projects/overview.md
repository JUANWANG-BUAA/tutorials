## 0.1 两个项目，两种确定性考验

本书设计的两大综合项目代表了现代边缘嵌入式工程中最具挑战性的两个核心场景：

| 维度 | 项目一：工业 CAN 节点 + RTOS + 边缘推理 | 项目二：多通道高速 DAQ + 零拷贝 DMA + 自愈系统 |
|:--|:--|:--|
| **核心工程目标** | 在硬实时多任务环境下，保证 CAN 报文收发、高频采样与 INT8 神经网络故障诊断的协同执行 | 在极高总线吞吐量下，实现微秒级零拷贝乒乓 DMA 采集、低功耗休眠与看门狗故障自愈 |
| **源码目录** | `projects/edge-rtos-infer/` | `projects/edge-daq-monitor/` |
| **硬件/靶机环境** | QEMU ARM Cortex-M / RISC-V Virt + Linux SocketCAN `vcan0` | QEMU / 裸机定时器联动多通道 DMA 仿真器 + 独立看门狗 |
| **核心实时性指标** | CAN 报文端到端处理延迟 $\le 500\,\mu\text{s}$，诊断推理耗时 $\le 2\,\text{ms}$，丢帧率 0% | 采样率 $1\,\text{MSPS}$ 下 DMA 双缓冲切换抖动 $\le 50\,\text{ns}$，看门狗超时恢复 $\le 10\,\text{ms}$ |
| **验证命令** | `bash projects/edge-rtos-infer/run_tests.sh` | `bash projects/edge-daq-monitor/run_tests.sh` |

## 0.2 项目一：工业边缘诊断节点总体架构

项目一构建了一套工业机器人协作关节或智能电机的边缘状态诊断终端：

```text
+----------------------------------------------------------------------------------------------------+
|                                    项 目 一 系 统 软 件 架 构                                      |
+----------------------------------------------------------------------------------------------------+
|  [任务 1: 传感器采样 (Priority 2)]       [任务 2: 边缘诊断推理 (Priority 3)]                       |
|   - 高频 ADC 数据读取 (1kHz)             - 滑动窗口特征提取 (定点 FFT / 时域特征)                  |
|   - 定点 FIR 低通滤波 (Q15 格式)         - INT8 量化轻量级神经网络推理 (振动故障分类)              |
|   - 写入共享传感器无锁环形队列           - 故障状态输出与警报触发                                  |
+-----------------------------------+----------------------------------------------------------------+
|  [任务 3: CAN 通信调度 (Priority 1)]                                                               |
|   - 接收总线控制命令与参数配置 (CAN ID 0x100)                                                      |
|   - 上报关节实时状态与诊断结果 (CAN ID 0x200, 周期 10ms)                                           |
|   - 突发故障高优先级异步主动告警帧 (CAN ID 0x050)                                                  |
+----------------------------------------------------------------------------------------------------+
|  [自研轻量级抢占式 RTOS 内核 (Cortex-M / RISC-V)]                                                  |
|   - 基于 PendSV / mscratch 的无锁汇编上下文切换                                                     |
|   - 基于硬件前导零指令 (CLZ) 的 $O(1)$ 优先级位图调度器                                           |
|   - 临界区保护：优先级天花板互斥锁与事件标志组                                                     |
+----------------------------------------------------------------------------------------------------+
```

## 0.3 项目二：高速数据采集与自愈小系统总体架构

项目二构建了一套针对高速瞬态信号采集的极高可靠性边缘测控系统：

```text
+----------------------------------------------------------------------------------------------------+
|                                    项 目 二 系 统 软 件 架 构                                      |
+----------------------------------------------------------------------------------------------------+
|  [数据流管道：零拷贝双缓冲 DMA 引擎]                                                              |
|   - 硬件定时器 TRGO 触发多通道 ADC 同步采样 (1 MSPS)                                              |
|   - DMA 循环模式：Half-Transfer (HT) 与 Transfer-Complete (TC) 中断交替通知                        |
|   - 零拷贝读写指针分离，避免总线竞态与 Cache 一致性颠簸                                            |
+----------------------------------------------------------------------------------------------------+
|  [高可靠性自愈与安全监控子系统]                                                                    |
|   - 硬件独立看门狗 (IWDG) 监控主采集状态机                                                         |
|   - 窗口看门狗 (WWDG) 监控高频 DMA 中断刷新率，防止中断风暴或过早喂狗                             |
|   - HardFault 崩溃黑匣子：在 RAM 保留区持久化寄存器现场与栈回溯，软复位后自动上报                  |
|   - 动态电源域切换：采集突发结束后自动通过 WFI 进入低功耗 Sleep/Stop 模式，待机功耗降低 90%        |
+----------------------------------------------------------------------------------------------------+
```
