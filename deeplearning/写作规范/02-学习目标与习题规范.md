# 《深度学习导论》学习目标与习题设计规范

## 一、设计基准

- 采用 **Bloom 认知分类法**（记忆 / 理解 / 应用 / 分析 / 评价 / 创造）与**逆向教学设计**（先定目标与证据，再设计内容）。
- **每条目标可观察、可测量、可考核**；高层级目标（分析、评价、创造）占比不低于 50%。
- 与《数值分析》《矩阵论》《机器人控制技术》三本共用同一套目标体系：K（知识）/ S（技能）/ A（判断与素养）三组。

## 二、每条目标的五要素（缺一不可）

1. **编号**：`K1.3`（讲号.序号）、`S2.4`、`A9.2`。
2. **行为动词**：可观察、可测量（见第五节动词表）。
3. **学习内容**：指向具体概念、算法、结构或工程实践。
4. **达标标准**：可验证的量化或可观察判据（"能写出…并说明…"、"给定…能算出…"、"在…条件下能定位…"）。
5. **认知层级**：标注 Bloom 层级（记忆 / 理解 / 应用 / 分析 / 评价 / 创造）。

示例：

> **S1.3（应用／分析）** 能对一个给定前向结构逐层写出张量形状与参数量：给定 `(B=32, 3, 224, 224)` 输入与三层网络配置，在不运行代码的前提下写出每层输出形状与总参数量，误差为零。

## 三、行为动词规范

禁止单独使用「了解、熟悉、掌握、理解、知道」——若使用「掌握」，其后必须紧跟达标标准。

| 层级 | 可用动词 |
|:--|:--|
| 记忆 | 定义、列出、写出、复述 |
| 理解 | 解释、说明、区分、归纳、举例、翻译成形状 |
| 应用 | 实现、计算、推导、编程、执行、调试 |
| 分析 | 推导、证明、分析、诊断、比较、拆解、定位 |
| 评价 | 评估、判断、选择、批判、检验、取舍 |
| 创造 | 设计、构建、开发、提出、综合、训练 |

## 四、每讲目标的分组与数量

每讲 **6–10 条**，三组分类输出，并给出**先修目标编号**（保证目标链条连贯）：

| 组 | 指向 | 例 |
|:--|:--|:--|
| **K（知识）** | 概念、结构与结论：能说清什么是什么、解决了什么问题 | K2.2 能写出注意力机制中 Q/K/V 的语义与形状，并解释 $\sqrt{d_k}$ 的作用 |
| **S（技能）** | 推导、实现、实验：能算、能写、能跑 | S2.5 能实现缩放点积注意力并验证形状与因果掩码的正确性 |
| **A（判断）** | 诊断、选择、批判、迁移：能做工程决策并说明理由 | A4.2 能判断一个生成任务该选 VAEGAN扩散流匹配中的哪一个，并给出代价与失败的判据 |

## 五、目标与考核的映射（硬性）

1. 每条目标**至少对应一种**考核方式：概念题 / 推导题 / 编程题 / 实验报告 / 开放设计题 / 项目提案。
2. `checklist.md` 中每条目标必须给出**依据（小节锚点或盒子锚点）+ 对应习题编号**。
3. 目标以学生为行为主体（"能……"），不写"本讲介绍……"。
4. 不得编造课程标准编号、评估工具名称或文献。

## 六、习题设计规范（A / B / C / D 四组）

| 组 | 类型 | 数量 | 要求 |
|:--|:--|:--|:--|
| **A** | 概念判断题 | 6–8 | 每题要么判断对错并给一句话理由/反例，要么解释一组易混概念。答案必须给「为什么错」而不只是「对/错」 |
| **B** | 推导与证明 | 5–6 | 从定义出发的可跟读推导；给关键步骤，不给「略」；涉及形状变化的必须先写形状 |
| **C** | 编程实现 | 5–6 | 依赖最少（numpy / torch 即可）；**每题给验收标准**（可运行的判据，如"loss 单调下降 20 步内"、"输出形状断言通过"、"与参考实现误差 < 1e-5"） |
| **D** | 开放设计 | 3–4 | 真实场景的取舍题：给约束（数据量、算力、延迟、合规），要求给出方案 + 理由 + 失败判据 + 验证计划 |

**答案与提示**：全部题目附答案或提示，折叠（`::: sol`）呈现；难度递进（A < B < C < D）；习题不得与 `mock-exam.md` 重复（自测卷题目**绝大多数为新增**，如确有重复必须说明理由）。

## 七、自测卷与回忆卡

1. **`mock-exam.md`**：闭卷计时（建议用时写清）、满分 100、分四部分（概念判断 / 填空简答 / 推导计算 / 开放论述）；
   文末给**评分标准**（每题给分点）与**漏点定位表**（错哪题 → 回哪节）。
2. **`recall-cards.md`**：按「定义卡 / 结论卡 / 公式卡 / 陷阱卡」四组；只写问题，答案用 `::: sol` 折叠；
   每张卡末尾给「评估标记」（✓ 能完整写出 / △ 有关键词但缺条件 / × 完全想不起）与间隔复习建议（当天 / 隔天 / 第 3 天 / 第 7 天）。
