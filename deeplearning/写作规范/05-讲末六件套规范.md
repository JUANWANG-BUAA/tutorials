# 讲末六件套规范（可复制骨架）

每讲正文之后固定有六个页面。本文件给出**结构、质量门槛与自查命令**。骨架可直接复制。

## 零、总则

| 页面 | 篇幅 | 唯一职责 | 判定「合格」的硬指标 |
|:--|:--|:--|:--|
| `summary.md` | 40–80 行 | 把整讲压成可复习的骨架 | 节一览表覆盖全部节；有「一条主线」与「三句话带走」 |
| `errata.md` | 40–100 行 | 对照母本讲义的补注与时效说明 | 四节齐全；至少 5 条术语/译误条目 |
| `exercises.md` | 200–400 行 | A/B/C/D 四组练习 | 四组齐全；**每题都有答案或提示且用 `::: sol` 折叠**；C 组每题有验收标准 |
| `checklist.md` | 30–60 行 | 学习目标自检 | 覆盖该讲全部 K/S/A 目标；每条给「依据 + 对应习题」 |
| `recall-cards.md` | 150–250 行 | 闭卷检索练习 | 四组卡片（定义/结论/公式/陷阱）；问题在前、答案折叠 |
| `mock-exam.md` | 200–350 行 | 闭卷计时自测 | 四部分 + 满分 100；有评分标准表与漏点定位表 |

**通用纪律**：① 盒子**平铺闭合**（先关内层再关外层）；② 跨页引用用相对路径（同讲内写 `sec24.md`，跨讲写 `../lec02/sec24.md`，跨层写 `../labs/lab1.md`）；③ 来源必须真实，不确定标「需核实」；④ 不自造新知识点——所有内容必须能在该讲正文中找到依据。

## 七、提交前自查（逐条过）

1. **盒子配平**：跑下面的命令，必须输出「全部配平」。

```bash
cd /Users/juanwang/Desktop/tutorials/deeplearning && python3 - <<'PY'
import re, os
open_re = re.compile(r'^:::+\s*[A-Za-z]'); close_re = re.compile(r'^:::+\s*$')
bad=[]
for root,_,fs in os.walk('src'):
    for f in sorted(fs):
        if not f.endswith('.md'): continue
        p=os.path.join(root,f); depth=0; fence=False
        for line in open(p,encoding='utf-8'):
            s=line.rstrip('\n').strip()
            if s.startswith('```'): fence=not fence; continue
            if fence: continue
            if open_re.match(s): depth+=1
            elif close_re.match(s): depth-=1
        if depth!=0: bad.append((os.path.relpath(p,'src'),depth))
print('全部配平' if not bad else bad)
PY
```

2. **链接可达**：所有相对路径指向**真实存在**的文件（同讲内文件此时应已齐备；跨讲引用要等到全部讲完成，**若目标尚未创建，改用文字指代**，避免留断链）。
3. **答案折叠**：`exercises.md` 与 `mock-exam.md` 的每个答案都在 `::: sol` 内。
4. **目标闭环**：`checklist.md` 的每条目标都有「依据 + 习题」两列非空。
5. **无自造知识**：所有题目的答案都能在该讲正文定位。
