## 一、盒子（语义盒）速查

语法：`::: 类型[优先级] 标题 {#锚点}` … `:::`；`proof` / `sol` 会渲染为可折叠块。

| 类型 | 用途 | 默认优先级 | 备注 |
|:--|:--|:--|:--|
| `def` | 定义（概念、符号、结构） | core | 必记骨架；标题写全编号 |
| `thm` / `prop` / `cor` / `lem` | 定理族（关键结论） | core | 编号共享同一序列 |
| `ex` | 例题（含形状推演、手算、反例） | main | 解答用嵌套 `::: proof` |
| `intuition` | 直觉（白话解释「这条在讲什么」） | main | 每个定义/定理后**必须**紧跟 |
| `method` | 方法、流程、清单、复盘 | main | 也用于「即时自测」 |
| `think` | 思考题、辨析、开放讨论 | main | 「为什么不是另一种做法」 |
| `note` | 边注、补充说明、延伸阅读 | main | 不参与编号 |
| `errata` | 陷阱、勘误、常见误解 | main | 每节 3–5 条、每讲末尾必看 |
| `preview` | 课程预告、下一讲引子 | skip | 第一遍可跳 |
| `proof`（嵌套） | 推导与证明 | skip | 第一遍可跳，二刷补 |
| `sol`（嵌套） | 习题/自测的答案与提示 | main | 折叠 |

优先级标记写在类型后：`::: thm[skip] …`（`core` / `main` / `skip`）。

**嵌套规则**：`ex`、`thm`、`method` 内可嵌 `proof` / `sol`；**不要**在 `proof` 里再嵌盒子。
**标题约定**：`::: def 定义 2.4.1 · 缩放点积注意力 {#def-2.4.1}`——编号手工写全，` · ` 分隔编号与名称。

## 四、锚点与交叉引用

- 盒子锚点：`{#def-2.4.1}`、`{#ex-2.4.A}`、`{#thm-2.4.2}`、`{#method-2.4.1}`（method 也可编号引用）
- 小节锚点：`### 2.4.3 复杂度 {#sec-2.4.3}`
- 引用盒子：`[@def-2.4.1]`；引用小节：`[2.4.3](sec24.md#sec-2.4.3)`；跨讲引用：`[第 9 讲 9.5](../lec09/sec95.md)`
- 同页引用小节：`[1.2 节](#12-多层感知机与通用逼近)`（H2 自动锚点是「小写标题去符号」）

## 五、自检清单（提交前逐条过）

1. 每个 `def` / `thm` 后有 `intuition`；每个关键结论有 `proof` 或明确标注「结论性陈述，推导见 §X」。
2. 每个盒子标题带**全编号**与**唯一锚点**；锚点无重复（构建时会报错）。
3. 节标题编号与讲号一致（第 7 讲无 1.x）。
4. 所有外链是**真实存在**的论文/仓库/课程（宁缺勿造）；不确定的标「需核实」。
5. 每节有 `errata` 或 `think` 陷阱框；每节有「即时自测」。
6. 涉及结构的段落有形状或参数量表；至少一处张量形状推演。
7. 讲末六件套齐全，`checklist` 覆盖全部学习目标，`exercises` 四组齐全且答案折叠。
8. 页面内不出现裸 HTML 卡片替代语义盒；不破坏既有锚点。
9. 公式用 `$…$` / `$$…$$`（KaTeX 构建期渲染）；行内公式避免使用 `~` 与裸 `>` 造成 Markdown 误解析。
10. 全文用简体中文，术语首次出现给英文原名（如「注意力机制（attention）」）。
