# 《深度学习导论》定制教程 · 写作规范

> 本文件是本书的**内容宪法**：结构、页面类型、编号、引用与来源纪律都以此为准。
> 与《数值分析》《矩阵论》《机器人控制技术》三本共用同一套**组织方式与行为方式**：
> 「讲（章）→ 节 → 讲末脚手架（总结 / 勘误 / 习题 / 自检 / 回忆卡 / 自测卷）」+
> 全局层（学前准备 / 复习 / 特训 / 查阅 / 附录）。任何新增页面都必须落进这套骨架。

## 一、对标基准

### 1. 母本：MIT 6.S191《Introduction to Deep Learning》

- 官网 `introtodeeplearning.com`；软件实验（Lab）仓库 `github.com/aamini/introtodeeplearning`。
- 母本特征：**单讲信息密度极高、以「讲」为单位组织、以软件实验为落点**；先修假设为微积分与线性代数，Python 经验非必需。
- 本教程与母本的关系：**以讲次主题与实验题目为骨架**，补齐母本省略的推导与中间步骤，并把散落的名词整理成可通读的叙述线；
  **不逐字翻译讲义，不虚构讲义中不存在的内容**。母本讲次、Lab 题目、评分要素属于「课程事实」，引用时必须注明来自哪个版本的公开材料。

### 3. 必须补齐的现代内容（相对母本与旧版讲义）

母本更新极快，但**课堂时间只够给结论**；以下内容属于「课程点到、教程必须展开」的一类，逐讲归位：

1. **架构与序列**：位置编码族（RoPE / ALiBi / 相对位置）、GQA / MQA、SwiGLU、RMSNorm、Pre-LN；
   状态空间模型（S4 → Mamba / Mamba-2）、线性注意力、MoE 与专家并行；长上下文与 FlashAttention 家族、KV cache 压缩。
2. **生成建模**：扩散 → 潜空间扩散（LDM）→ DiT → 一致性模型 → 整流流 / 流匹配（Flow Matching）；
   VQ-VAE / VQGAN / FSQ；自回归图像生成（VAR）；视频生成（Sora 类与开源实现）；GAN 的现状与对抗蒸馏。
3. **对齐与推理**：RLHF 全流程 → DPO / KTO / ORPO / SimPO → GRPO 与 RLAIF；奖励模型与 reward hacking；
   推理模型与测试时计算（o1/o3 类、DeepSeek-R1 的 GRPO + 蒸馏）；LoRA / QLoRA / DoRA 与量化部署。
4. **多模态与智能体**：CLIP 式对比学习、BLIP-2 / LLaVA / Qwen-VL 的三段式训练范式；语音与音频大模型；
   VLA（RT-1 / RT-2 / OpenVLA / π0 / Diffusion Policy）；世界模型；Agent 框架（ReAct / Toolformer / function calling / MCP）。
5. **高效训练工程**：ZeRO-1/2/3 与 FSDP / FSDP2；张量并行与序列并行；流水线并行（GPipe / 1F1B / zero-bubble）；
   3D–5D 并行；BF16 / FP8 与 loss scaling；激活重计算；通信重叠；checkpoint 与容错。
6. **可信 AI**：对抗攻击与鲁棒训练；机制可解释性（稀疏自编码器 / 激活引导 / circuits）；幻觉、watermark、
   越狱与防御、机器遗忘；监管框架（欧盟 AI Act 等）**只作事实性概述**。
7. **AI for Science**：AlphaFold2/3、ESMFold、蛋白质语言模型；等变网络与机器学习势函数（MACE / NequIP）；
   天气与气候大模型（GraphCast / Pangu-Weather / FourCastNet）；神经算子（FNO / DeepONet）与可微分仿真的边界。
8. **评估与可复现**：主流基准（MMLU / GPQA / SWE-bench / Arena 类）与**污染、刷榜、评测有效性的争议**；
   浮现能力的度量争议；实验管理（种子、版本、日志）与可复现清单。

### 4. 必须弱化或删除

1. **只给结论不给条件**的写法：凡「效果好 / 更强 / 更快」必须给出**条件与量级**（在什么数据、什么规模、什么代价）。
2. **以传闻充当事实**：如「涌现能力」「模型会思考」一类表述，必须区分**观测到的指标现象**与**机制解释**。
3. **过时的默认实践**：Sigmoid 隐藏层、无归一化的深层网络、Adam 全程不调学习率、全参数微调解决一切等，改了要说明「为什么现在不这么做」。
4. **与母本范围冲突的编造**：不得虚构课程讲次、Lab 任务、评分规则、论文编号与实验结果。

### 5. 必须保留的现有优点（本书的既有资产）

1. **语义盒子体系**：`def / thm / prop / ex / proof / intuition / method / think / note / errata / preview`——
   定义与定理是复习骨架、直觉框建手感、证明框可跳、陷阱框必看。**新增内容必须继续用这套盒子。**
2. **「10 分钟复习版」**：每讲页首的必记结论表 + 「最该记住的 N 个判断」。
3. **学习简报**（`lesson-brief`）：先修 / 目标 / 学完标准，三栏固定。
4. **形状推演传统**：凡涉及结构，给张量形状与参数量表（`shape-table`）。
5. **插图传统**：`figure-svg` 手绘 SVG（含 `title/desc` 无障碍描述与图注），不引用来源不明的图片。
6. **推导完整**：反向传播、注意力、ELBO、扩散目标、策略梯度、PPO 裁剪等关键公式给出可跟读推导。

## 三、页面类型与固定结构

### 1. 讲导览 `overview.md`（每讲一页，120–200 行）

1. **讲首导语**（600–1000 字）：这一讲要解决的真实问题、它在九讲主线中的位置、与母本讲次的对应关系。
2. **节一览表**：列 | 核心问题 | 关键结论 | 典型陷阱（对齐其他书的「三节一览」）。
3. **本讲地图**：一条 ASCII 或文字流程图，标出节与节之间的依赖。
4. **学习简报变化**：本讲新增的概念清单（先修 / 目标 / 学完标准仍用 `lesson-brief` HTML 块）。
5. **与实验 / 项目的关系**：指向 Lab 与项目选题。
6. `::: method 怎么用这一讲`：读法建议（哪些框可跳、哪些必读、打卡路径）。

### 2. 节页 `secXY.md`（每节 250–450 行，核心正文）

固定节奏，不跳步：

1. **动机段**：这一节要回答什么问题，为什么不能用上一节的方法。（2–4 段）
2. **定义 → 直觉 → 关键结论 → 推导**：每个定义/定理后**必须**紧跟一个 `intuition` 框；关键公式给 `proof`（可折叠，第一遍可跳）。
3. **例题与形状推演**：至少 1 个 `ex` 例题（带 `proof` 解答）；涉及结构必给形状/参数量表。
4. **代码与工程细节**：框架接口级示例（PyTorch 优先，TensorFlow 仅在母本 Lab 需要时出现），给关键行注释。
5. **陷阱与勘误**：`errata` 或 `think` 框列出本节最常见的 3–5 条误解。
6. **即时自测**：`::: method 即时自测 · X.Y` 给出 2–4 道口答题（答案折叠在 `sol`）。
7. **延伸阅读**：`::: note[skip] 延伸阅读` 指向**真实存在**的论文 / 开源项目 / 课程章（给可核查的标识：arXiv 编号或仓库名）。
8. **节末小结**：3–5 行，回收本节结论并指出下一节的动机。

### 3. 讲末六件套

| 页面 | 内容要求 | 篇幅 |
|:--|:--|:--|
| `summary.md` | 节一览表（关键结论 + 典型陷阱）+ 一条主线（加粗引文）+ 三句话带走 + 与后续讲次的连接 | 40–80 行 |
| `errata.md` | ① 对照母本讲义的**补注**（母本省略、本教程补齐的推导与背景）；② **术语与常见译误**（如 Attention 的 QKV 译名、Embedding 与 Embedding layer 的区别）；③ **时效补注**（母本录播年代 vs 当前工程实践，如框架 API、默认超参、数据集）；④ 更正清单（本教程自身的错误修订记录） | 40–100 行 |
| `exercises.md` | A 概念（6–8 题）／B 推导证明（5–6 题）／C 编程实现（5–6 题，给验收标准）／D 开放设计（3–4 题）；**每题附答案或提示**，折叠呈现 | 200–400 行 |
| `checklist.md` | 打勾清单：目标编号 → 依据小节/盒子 → 对应习题 | 30–60 行 |
| `recall-cards.md` | 定义卡 / 结论卡 / 公式卡 / 陷阱卡，四组；**问题在前、答案折叠在后**；文末给「导出到 Anki」说明 | 150–250 行 |
| `mock-exam.md` | 闭卷计时自测卷：概念判断 / 填空简答 / 推导计算 / 开放论述；满分 100，附评分标准与漏点定位表 | 200–350 行 |

### 4. 全局层页面

- `toolbox.md`：**工程工具箱**——环境与依赖、张量形状调试、训练不收敛排查树、显存估算公式、实验管理（种子/日志/版本）、常用命令与清单。
- `memory-sheet.md`：**速查背记卡**——每个讲次压成「最小可背诵单元」（一句话 + 一个公式 + 一个陷阱），供考前与面试前快速过一遍。
- `review/contrast-cards.md`：**易混对照卡**——SGD/Momentum/Adam、BN/LN/RMSNorm、L1/L2、VAE/GAN/扩散、on-policy/off-policy、DP/TP/PP、LoRA/全参微调等成对概念。
- `reading.md`：**延伸阅读地图**——分类列出课程网站、教材、论文、开源项目、数据集与评测、可视化教学资源；每条注明「读什么 / 何时读」。
- `training/arena.md`：**面试与答辩竞技场**——高频问题三轮计时特训（基础 → 架构 → 训练工程 → 项目答辩）。
- `training/exam-sprint.md`：**综合自测卷**（100 分制，覆盖九讲），带计时器锚点与评分标准。
- `appendix/roadmap.md`：从课程到研究选题的路线；`appendix/resources.md`：开源项目与工具地图；`appendix/derivations.md`：补充推导（可选专题）。

## 四、编号、锚点与交叉引用（硬性）

1. **节标题**：`## 2.4 从压缩瓶颈到注意力`——讲号.节号 + 空格 + 标题。
2. **盒子编号**：`::: def 定义 2.4.1 · 缩放点积注意力 {#def-2.4.1}`——
   `{#type-讲.节.序号}`，序号从 1 开始；补充型例题用字母：`{#ex-2.4.A}`。
   盒子标题**必须写全编号**（不依赖自动编号），保证跨页引用稳定。
3. **页内小节锚点**：`### 2.4.3 自注意力的复杂度 {#sec-2.4.3}`（需要被 checklist 引用时才加）。
4. **交叉引用**：`[@def-2.4.1]` 或 `[2.4](sec24.md#sec-2.4.3)`；本教程内一律用相对路径 `.md`（构建后由预处理器改写）。
5. **不要**手写 `{#def-1-1}` 这类旧式短锚点；新增内容一律用点号形式。（历史文件迁移时同步更新引用。）
6. **节编号必须与讲号一致**：第 5 讲的节是 5.1、5.2…，第 7 讲是 7.1、7.2…（旧版存在的 1.x 编号错误必须修正）。

## 五、来源与诚实纪律

1. **可核查性**：引用论文给标题 + 年份（有 arXiv 编号更好）；引用开源项目给仓库名与用途；引用课程材料给「官网 / 讲义 / Lab 编号」。
2. **量级要用条件说话**：「参数量 7B 的模型用 Adam 混合精度训练，优化器状态约 $16N$ 字节 ≈ 112 GB」——给出算式。
3. **区分三类陈述**：① 课程/论文事实（可溯源）；② 工程惯例（注明「社区默认做法」）；③ 本教程的推理（可用「本书认为 / 建议」）。
4. **不确定就标注**：无法核实的数字标「需核实」，不写「研究表明」这类无主语的句子。
5. **时效**：涉及库 API、模型版本、榜单数量级，标注年份或版本区间（如「截至 2025 年」）。

## 六、禁止事项

1. 不得虚构论文、仓库、课程讲次、实验数据与 API。**宁缺勿造。**
2. 不得把传闻当结论（「某某模型已经具备通用推理」这类判断必须给出评测口径与反例空间）。
3. 不得符号冲突：全书统一 $\boldsymbol{x}$（向量）、$A$（矩阵）、$\theta$（参数）、$\eta$（学习率）、$\mathcal L$（损失）。
4. 不得跳过直觉直接甩公式；不得用「显然」「易得」「读者自证」掩盖关键步骤。
5. 不得引入与现有盒子体系冲突的排版（禁止裸 HTML 卡片替代语义盒子；`lesson-brief`、`chapter-cover`、`study-paths`、`index-cards` 只在卷首层使用）。
6. 不得破坏既有锚点与链接策略（跨页引用必须用相对路径 + 锚点）。
7. 不得让页面失去「可跳读性」：每个长页都要有页内小标题层级（H2 → H3），且每节开头给出「这节解决什么」。
