# 范围与目标

这是一本**面向研究生的深度学习入门教程**，依据 MIT 6.S191《Introduction to Deep Learning》的九讲主题与三个软件实验整理、扩充而成。它不逐字翻译讲义，而是按「**一个范式、四条支线**」重新组织：

- **一个范式**：任何深度网络都可以拆成「定义结构 → 定义损失 → 用梯度下降最小化」这三步（[第 1 讲](lectures/lec01/overview.md)）。后面每一讲都是这个范式的实例，只是把「结构」换成更适合某种数据的形状。
- **四条支线**：**序列**（[第 2 讲](lectures/lec02/overview.md) RNN → 注意力 → Transformer）、**视觉**（[第 3 讲](lectures/lec03/overview.md) 卷积 → 检测/分割 → 视觉基础模型）、**生成**（[第 4 讲](lectures/lec04/overview.md) VAE → GAN → 扩散 → 流匹配）、**决策**（[第 5 讲](lectures/lec05/overview.md) 强化学习 → 偏好优化）。它们共享同一套训练语言（损失、梯度、正则、泛化）。
- **三个收束**：规模（[第 9 讲](lectures/lec09/overview.md)）、价值（[第 7 讲](lectures/lec07/overview.md)）与应用（[第 8 讲](lectures/lec08/overview.md)）——它们不引入新范式，而是回答「这套范式推到极致会发生什么」。

## 本教程解决什么问题

公开课的讲义「提纲挈领、信息密度极高」，但通读时会遇到三个典型障碍，本教程逐一处理：

1. **概念之间缺少衔接**——讲义一页给出十个名词，却不说明它们的关系。本教程每讲先给一张**讲导览**（节一览表 + 本讲地图）与**学习简报**（先修 / 目标 / 学完标准），正文按「动机 → 定义 → 关键结论 → 直觉 → 陷阱」的固定节奏推进，名词出现即解释它相对于前一节的增量。
2. **公式只有结论、没有推导**——凡关键公式（反向传播、注意力、ELBO、扩散目标、策略梯度、PPO 裁剪、DPO）都给出**可跟读的推导**，并附一句白话直觉；只看结论的读者可直接跳过推导框。最完整的推导另收在[附录 C](appendix/derivations.md)。
3. **代码与理论脱节**——三个 Lab 给出**逐行讲解**：数据长什么样、张量形状怎么变、损失为什么这么写、训练不收敛时先查什么；另有[工程工具箱](toolbox.md)把工程细节（显存账、排查树、实验管理）集中成可查的手册。

## 本书的组织方式（怎么读最快）

全书由**五种页面**构成，各司其职：

| 层 | 页面 | 干什么 |
|:--|:--|:--|
| **学** | 讲导览（overview）+ 节页（secNN） | 建立概念与推导：从这里读第一遍 |
| **查** | 讲末脚手架：总结 / 勘误 / 教科书式习题 | 学完一讲后巩固；遇到疑问回查 |
| **记** | [公式与结论卡](review/formula-cards.md) / [速查背记卡](memory-sheet.md) / [易混对照卡](review/contrast-cards.md) / 各讲回忆卡 | 考前与面试前把骨架压到最短 |
| **练** | [三个 Lab](labs/lab1.md) + [项目提案指南](exercises/project.md) | 动手跑通完整流程 |
| **输出** | [面试与答辩竞技场](training/arena.md) + [综合自测卷](training/exam-sprint.md) | 把「知道」练成「讲得出、做得对」 |

每讲的**固定结构**：讲导览 → 若干节（动机 → 定义 → 直觉 → 推导 → 例题 → 代码 → 陷阱 → 即时自测）→ 讲末六件套（总结、勘误、习题、自检表、回忆卡、自测卷）。**这个结构在九讲里完全一致**，因此你可以只学一遍「怎么读」，就能用同样的节奏推进九讲。

## 三层阅读结构

正文用统一的**语义盒子**区分内容性质，读者可以按需分层：

| 盒子 | 含义 | 第一遍怎么处理 |
|:--|:--|:--|
| **定义 / 定理**（蓝 / 紫） | 必记骨架：概念的精确定义与关键结论 | **必读**，是复习时的骨架 |
| **直觉**（蓝绿） | 一句白话解释「这条定义/定理在讲什么、为什么需要它」 | 先读，建立手感 |
| **方法 / 例题**（青 / 绿） | 怎么用、算一遍 | 跟着算，建立熟练度 |
| **证明 / 推导**（灰，可折叠） | 关键公式的完整推导 | **第一遍可跳**，二刷再补 |
| **陷阱 / 勘误**（红） | 常见误解与易错点 | 每节末尾必看 |

## 与母本（MIT 6.S191）的关系

- **骨架一致**：九讲的主题顺序、核心结论、三个实验的题目与课程一致；本教程的作用是把它们**读薄、串起来、补齐推导**。
- **明确扩展**：凡母本未展开或近年才出现的内容（状态空间模型、MoE、流匹配、测试时计算、VLA、机制可解释性、FP8 与 FSDP2 等），本教程以「**拓展**」标注，并给出可核查的来源；不确定处标「需核实」，**不编造**。
- **权威源仍在课程**：官网、讲义 PDF、Lab Notebook 与录播是权威源；术语一律保留英文对照（见[符号与缩略语表](preface-notation.md)与[术语索引](review/glossary.md)）。

- **零基础**：卷首 → [先修工具箱](prerequisite.md) → [入学诊断](entry-test.md) → 按 1–9 讲顺序通读，每讲配一个 Lab。
- **有基础、赶时间**：只读每讲页首的**「10 分钟复习版」**与[公式速查卡](review/formula-cards.md)，跳过全部证明框。
- **为课程项目做准备**：重点读 [第 1、2、4、9 讲](lectures/lec01/overview.md)与[项目提案指南](exercises/project.md)，选题多落在「序列/生成 + 高效训练」的组合上。
- **要动手做工程**：从[工程工具箱](toolbox.md)与[最小必读路径 · 路线 5](review/study-paths.md)进入。
- **要输出（面试/答辩）**：[面试与答辩竞技场](training/arena.md)三轮特训。
