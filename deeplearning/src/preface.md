# 范围与目标

这是一本**面向研究生的深度学习入门教程**，依据 MIT 6.S191《Introduction to Deep Learning》的九讲主题与三个软件实验整理、扩充而成。它不逐字翻译讲义，而是按「**一个范式、四条支线**」重新组织：

- **一个范式**：任何深度网络都可以拆成「定义结构 → 定义损失 → 用梯度下降最小化」这三步（[第 1 讲](lectures/lec01.md)）。后面每一讲都是这个范式的实例，只是把「结构」换成更适合某种数据的形状。
- **四条支线**：**序列**（[第 2 讲](lectures/lec02.md) RNN → 注意力 → Transformer）、**视觉**（[第 3 讲](lectures/lec03.md) 卷积 → 检测/分割）、**生成**（[第 4 讲](lectures/lec04.md) VAE → GAN → 扩散）、**决策**（[第 5 讲](lectures/lec05.md) 强化学习）。它们共享同一套训练语言（损失、梯度、正则、泛化）。

## 本教程解决什么问题

公开课的讲义「提纲挈领、信息密度极高」，但通读时会遇到三个典型障碍，本教程逐一处理：

1. **概念之间缺少衔接**——讲义一页给出十个名词，却不说明它们的关系。本教程每讲先给一张**学习简报**（先修 / 目标 / 学完标准），正文按「动机 → 定义 → 关键结论 → 直觉 → 陷阱」的固定节奏推进，名词出现即解释它相对于前一节的增量。
2. **公式只有结论、没有推导**——凡关键公式（反向传播、注意力、ELBO、扩散目标、策略梯度、PPO 裁剪）都给出**可跟读的推导**，并附一句白话直觉；只看结论的读者可直接跳过推导框。
3. **代码与理论脱节**——三个 Lab 给出**逐行讲解**：数据长什么样、张量形状怎么变、损失为什么这么写、训练不收敛时先查什么。

## 三层阅读结构

正文用统一的**语义盒子**区分内容性质，读者可以按需分层：

| 盒子 | 含义 | 第一遍怎么处理 |
|:--|:--|:--|
| **定义 / 定理**（蓝 / 紫） | 必记骨架：概念的精确定义与关键结论 | **必读**，是复习时的骨架 |
| **直觉**（蓝绿） | 一句白话解释「这条定义/定理在讲什么、为什么需要它」 | 先读，建立手感 |
| **方法 / 例题**（青 / 绿） | 怎么用、算一遍 | 跟着算，建立熟练度 |
| **证明 / 推导**（灰，可折叠） | 关键公式的完整推导 | **第一遍可跳**，二刷再补 |
| **陷阱 / 勘误**（红） | 常见误解与易错点 | 每讲末尾必看 |

## 学习路径

- **零基础**：卷首 → [先修工具箱](prerequisite.md) → [入学诊断](entry-test.md) → 按 1–9 讲顺序通读，每讲配一个 Lab。
- **有基础、赶时间**：只读每讲页首的**「10 分钟复习版」**与[公式速查卡](review/formula-cards.md)，跳过全部证明框。
- **为课程项目做准备**：重点读 [第 1、2、4、9 讲](lectures/lec01.md)与[项目提案指南](exercises/project.md)，因为选题多落在「序列/生成 + 高效训练」的组合上。
