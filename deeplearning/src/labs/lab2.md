## 2. 基线：一个会报 logits 的 CNN

官方结构是若干带批归一化的卷积层，再接两个全连接层，输出一个 logit。训练用的是带 logits 的二元交叉熵，评估时再过 sigmoid。下面是同一接口的最小写法，层数按你的笔记本填。

```python
import torch
from torch import nn

class FaceCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Flatten(),
            nn.LazyLinear(1),   # 形状随输入分辨率变，第一次前向才实例化
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)   # [B]，未过 sigmoid

loss_fn = nn.BCEWithLogitsLoss()
# loss = loss_fn(model(x), y.float())
```

`BCEWithLogitsLoss` 合并 sigmoid 和交叉熵，采用更稳定的计算方式。单独计算 sigmoid 后再用 `BCELoss` 时，极端 logits 可能先被浮点精度舍入到 0 或 1；训练宜直接使用 logits 版本。评估时用 `torch.inference_mode()`，并先 `model.eval()`，否则批归一化仍按训练批次更新统计量。

```python
model.eval()
with torch.inference_mode():
    logits = model(x)
    pred = (logits.sigmoid() >= 0.5).to(y.dtype)
    acc = (pred == y).float().mean()
```

这里的 `0.5` 只演示 logit → 概率 → 决策的接口。正式对照使用第 8.1 节从验证集确定并冻结的共同阈值；两模型不能各自按测试表现选阈值。

`LazyLinear` 是现行 PyTorch 的写法。若你的版本没有它，就先用假输入跑一次，把 `Flatten` 之后的长度写死。不要使用已经不存在的 `Variable`。

## 3. 总准确率为什么会掩盖失败

::: ex 思考题 · 四档里有一档崩了 {#lab2-q1}
测试集四档人数相等。三档准确率是 $0.96$，一档是 $0.60$。总准确率是多少？只报总准确率时，你会做出什么错误的上线决定？

::: proof 参考结论
总准确率是 $(3\times0.96+0.60)/4=0.87$。它看起来「还能用」，但有一档只有六成。人脸是否被系统承认，在这一档上已经和抛硬币差不多。第 7 讲要求的是**最差子群**，不是平均。笔记本的提交也是按四档分开报，而不是一个数。
:::
:::

发现差距之后，笔记本讨论的一种简单修正方法是：给训练集的所有样本标上子群标签，再补齐样本少的那一档。这样做成本高，而且可能不知道该标哪一个潜在因素（肤色、配饰、光照、年龄会缠在一起）。DB-VAE 转而按学到的潜变量的稀有程度重采样；这些潜变量不保证与人为定义的属性一一对应。

## 4. DB-VAE 在算什么

这一节接[第 4 讲的变分自编码器](../lectures/lec04/sec43.md)。编码器给出 $\mu$ 和 $\log\sigma$，采样必须走重参数化，否则梯度断掉：

$$z=\mu+\sigma\odot\epsilon,\qquad \epsilon\sim\mathcal N(0,I).$$

损失仍是两项：重建项，加上把 $q(z\mid x)$ 拉向标准正态的 KL 项。官方函数签名里给了一个示例默认值 `kl_weight=0.0005`，损失本体仍需填写。这个默认值不是普遍最优的超参。人脸和非人脸的损失形式不一样：非人脸不需要重建出一张脸，具体分支以笔记本正文为准，不要把两类样本都放进同一个重建项。

DB-VAE 通过改变采样来去偏，不是把分类损失写得更复杂。编码器把人脸映射到潜变量后，先估计这些潜变量在训练集上的直方图；落在稀有区间里的脸，下一批被抽到的概率更高。分类器因此更常看见原先很少的属性组合。潜变量是模型自己学的，**不是**你标好的「肤色」轴，也可能表示光照或背景。所以重采样之后必须回到第 3 节的四档测试集上重新报告准确率：总准确率上升、最差一档不变，就不算去偏成功。

::: errata 三件不要做的事
1. 不要在测试集上估计哪些区间需要重采样。重采样分布只能来自训练批次，否则就用测试信息调整了训练采样。
2. 不要把 DB-VAE 读成「公平已经解决」。它缓解的是**训练分布里少见的潜在因素**，不保证换一个数据集、换一种摄像条件仍然成立。第 7 讲的公平度量彼此还可能不相容。
3. 不要为了做这个实验去收集或公开可识别的人脸。用课程提供的缓存数据；报告里放曲线和四档数字，不放能认出某人的图片。
:::

## 5. 排错清单

1. **logits 和概率用混**：`BCEWithLogitsLoss` 吃 logits；阈值 $0.5$ 要打在 sigmoid 之后。
2. **忘了 `eval()`**：批归一化在小批量评估时会把准确率打乱，四档差距可能是统计噪声。
3. **标签类型**：`y` 必须是浮点 0/1。整型标签进 `BCEWithLogitsLoss` 会直接报错或悄悄算错。
4. **KL 权重过大**：编码分布可能过度接近标准正态，输入信息难以通过潜变量保留；需要结合重建、分类和潜变量统计检查，不能仅凭权重大小断言塌缩。
5. **只看训练准确率**：CelebA 上很高，不代表四档测试集上均衡。两个数都要报。

### 8.1 分组错误率：同一阈值下比较两种模型

这一节是本书的测量扩展，不声称官方笔记本已经提供以下全部标签或划分。要检验的假设是：**在相同留出样本、共同冻结阈值和预先约定的训练预算下，DB-VAE 降低固定分组集合的最差正类 FNR，且总体准确率的下降不超过事先约定的容忍量。** 例如可在实验计划中取容忍量 $\epsilon=0.01$（本书建议，不是课程标准）。主要效应记为

$$\Delta_{\rm worst}=\max_{g\in G}\mathrm{FNR}_{g,\rm DBVAE}-\max_{g\in G}\mathrm{FNR}_{g,\rm CNN},\qquad
\Delta_{\rm acc}=\mathrm{Acc}_{\rm DBVAE}-\mathrm{Acc}_{\rm CNN}.$$

$G$ 必须在打开测试预测前按标注清单固定；不因某组结果难看而删组。两模型最差组可以不同。报告每组差值，不能只比较两次各挑出来的「最好改进组」。若配对区间的 $\Delta_{\rm worst}$ 上界小于 0，且 $\Delta_{\rm acc}$ 下界不小于 $-\epsilon$，才把这一运行的证据记为支持假设；区间跨界是证据不足，不是证明无效。这个判据不证明所有组同时改善，也不证明一般意义的公平。

这里的 $G$ 只包含预先定义且测试清单中确有正例的组；零正例组保留计数，但不能参与正类最差值。工具输出 `worst_FNR_groups` 后，须与冻结的分组清单逐项核对：若预期组消失，先查导出/数据覆盖，不能把缩小后的集合当原假设通过。分组名称相同但定义或标注来源不同，也不能直接合并。

**先建立划分，再训练。** 保存不可变清单：匿名 `sample_id`、来源、文件摘要、类别、标签来源、split，以及在确有元数据时的人物或来源簇 ID。去掉精确重复，按事先设定的近重复检索规则审查；有可信人物映射时按人物划分，相关帧按来源场景划分。没有人物元数据时可按来源簇/图像划分并检查重复，但必须写「未验证身份互斥」，图像不重叠不能替代人物独立。不得用识别人脸来补齐缺失 ID。若官方训练缓存没有验证集，从训练部分划出固定验证集；不要动官方测试集做调参。保留原始官方对照和本书重划分对照的区别，不把两种协议混为一张表。

训练、潜变量直方图和重采样仅使用训练部分。固定两模型输入预处理、数据划分、优化步数或所选预算口径、检查点选择规则，并记录 DB-VAE 额外解码器/直方图开销。先用同一预算训练基线和完整 DB-VAE；若要把变化归因于采样而非架构，另做同一 DB-VAE 的均匀采样对照。至少预先约定多个训练种子（例如 3 个），逐种子保留全部结果；样本 bootstrap 不涵盖重训练波动，不能选最好的一次代替跨种子报告。

**共同阈值只能在验证集选择。** 一种可复现规则：遍历事先固定的阈值网格 `0.01, 0.02, …, 0.99`，最大化两模型在同一验证集上的平均准确率；并列时取最接近 0.5 的值，再并列取较小值。记录验证类别比例；仅有人脸的验证集不能约束误报代价，应明确该阈值只对正类覆盖有解释力，不能声称得到完整二分类工作点。共同概率阈值也不保证两模型校准相同。模型、预处理、阈值、分组及变换参数全部冻结后，才对测试清单推理一次，禁止按测试结果换阈值或挑样本。

**分母决定能回答什么。** 每模型、每组和总计都报 $N,N_+,N_-$、TP、TN、FP、FN，以及准确率 $(TP+TN)/N$、正类 FNR = FN / $(FN+TP)$、FPR = FP / $(FP+TN)$。分母为零用 `null` /「未定义」，不能填 0。四档若只含人脸，就只能测分组漏检；分组 FPR 需要事先存在且适用于非人脸的合法分组语义，不能把非人脸硬贴进肤色/性别档。若有独立留出的有标签非人脸，可算总体 FPR，但不能复制这些负例到四档中伪造分组 FPR。没有留出负例，则总体准确率也只代表当前正类混合物。总体按清单样本加权，不等同于四档宏平均，更不代表部署人群比例。

**固定协变量队列，而不是看图后讲故事。** 若数据已有可信的光照/遮挡标注，在训练前定义如「原标注遮挡=1」的队列，记录标注规范、缺失率、与四档的交叉样本数。无此标注时，不从潜变量或预测错误反推「暗光组」。可另做受控压力测试：在划分后，给每张留出图像生成同样的固定变换，例如 `[0,1]` 像素乘以 0.5，或中央宽高各占图像 20% 的黑色矩形遮挡；固定库、像素范围、顺序与坐标取整规则。验证部分可用于选择变换强度，测试强度随后冻结；测试原图及其所有变体不得进入训练/验证，两个模型必须使用完全相同变体。每个变换单独出表，原图/变体共享重采样簇；不要把变体当独立新增人物。该实验只测指定变换下的敏感性，不能称为真实低光摄像头、自然遮挡或真实域迁移性能。来源/设备变化只能在有来源标注及独立留出来源时研究；否则写明未检验 OOD。

**预测接口。** 从冻结检查点在 `eval()` + `inference_mode()` 下，对同一份完整测试清单导出宽表 `sample_id,unit_id,group,label,baseline_score,dbvae_score`。两列分数都必须是 sigmoid 后的概率；每行是一张图的配对预测，而不是各模型选取的成功样本。`unit_id` 是 bootstrap 的独立簇：有可信人物/来源簇时用匿名簇 ID，没有时只能用 `sample_id` 并承认图像独立假设可能低估不确定性。缺失分组用空字符串，工具保留为 `__unknown__`，计入总体、单独报数，但不冒充第五个人群组；缺失率与缺失机制也应讨论。保留所有合法样本，记录任何排除和失败推理，不得悄悄取两个成功列表的交集。

`tools/lab2_compare.py` 使用 Python 3.11+ 标准库，无需 GPU。它拒绝重复 ID、缺失任一模型分数和非法概率；不自动推断标签、不训练、不选择阈值。输入配对结构防止两模型错位，但工具不能从 CSV 证明图像来源、标签真实性或没有测试泄漏，仍需保存清单与导出日志。阈值记录 JSON 必含 `split="validation"`、数值 `threshold`、`validation_manifest`、`selection_rule`、`baseline_checkpoint`、`dbvae_checkpoint`；后四项写真实文件/规则及哈希，勿把测试记录改名冒充验证记录。

真实预测分析命令为 `python3 tools/lab2_compare.py predictions-test.csv --threshold-record frozen-validation.json --bootstrap 2000 --seed 191 > report-test.json`；每个训练种子、每个压力测试队列分别运行，不能混合成伪独立样本。输出包含各模型计数/分母/准确率/FNR/FPR，各组与总体的 `DB-VAE − CNN` 配对差值，以及固定有正例分组集合的最差 FNR 差值。合成例中 B 的负类分母为零，FPR 必为 `null`；A 的正负类分母均为 40；总体仍含空组 20 条，不能因缺失标签删掉。

工具按 `unit_id` 有放回抽取同样数量的簇；每次两模型一起重采样，计算差值的百分位 95% 区间，默认 2,000 次。输出 `units`、`valid_replicates` 和 `requested_replicates`；若某次重采样缺少某项分母，对应区间整体为 `null`，不悄悄只用有利的有效重复。样本或独立簇很少时，即使区间退化也不能解释为确定无误；单簇不提供总体推断。最差 FNR 的区间在每次重采样重新取固定集合的最大值，小组极少时尤其不稳定。区间是固定检查点下的样本不确定性，不包含标签误差、未知人物相关性或训练随机性；多组区间不是同时置信保证。报告跨种子的方向一致性、预算与限制，不只提交显著项。

人脸图片、原始身份映射、可回溯路径及可识别特征不进入 CSV 或公开报告；匿名 ID 也不等于彻底匿名，应限制清单访问、记录保存期限并遵守来源许可。提交汇总计数、分组覆盖、协议与代码；小组极小且可能暴露个人属性时，公开版合并/抑制细粒度表，受控环境保留完整审计结果，不以公开披露要求推动额外采集。

### 8.2 可选挑战：从分类到框匹配

这是独立的目标检测扩展，不是官方笔记本必做。可使用 [WIDER FACE](http://shuoyang1213.me/WIDERFACE/) 按其下载说明取得图片和人脸框标注，并遵守数据许可；也可只用自己有明确授权的图片，自行标框。不要采集陌生人的人脸或上传可识别图片、标注和预测；确认许可、用途和存储要求，报告优先放汇总数字。先按人物或来源场景划分，避免同一人、相似帧或近重复图跨训练、验证、测试；检测器、窗口大小、置信度阈值和 NMS 均只在训练/验证集确定，最后冻结后评估测试集。

把来源标注转换为统一格式：每行 `image_id,x1,y1,x2,y2`，预测再加一列 `score`；坐标以原图左上角为原点，向右为 x、向下为 y，单位为像素，采用半开区间 `[x1,x2) × [y1,y2)`，且 `0 ≤ x1 < x2 ≤ 图宽`、`0 ≤ y1 < y2 ≤ 图高`。来源若用 `(x,y,w,h)`，转成 `(x,y,x+w,y+h)`；缩放或裁剪图片时同步转换框并裁剪到图像边界。无框的图也要列入评估清单，不能只评估有标注的图片。

例如同一图的真值框 `(0,0,10,10)`、预测框 `(5,0,15,10)`，交集面积为 `5×10=50` 像素²，并集为 `100+100-50=150` 像素²，IoU 为 `1/3`；以 0.5 为阈值时不匹配。对每张图将预测按分数降序排列，每个预测只与尚未匹配的真值中 IoU 最大者匹配，IoU 至少为 0.5 才计一个 TP；其余预测计 FP，最后未匹配真值计 FN。每个真值最多匹配一次；无预测或无真值时分别产生 FN 或 FP，两者均无则均为零。固定并说明分数相同时的排序规则，例如按输入行序。报告总 TP、FP、FN，精确率 `TP/(TP+FP)` 和召回率 `TP/(TP+FN)`；分母为零时报告未定义。比较滑动窗口分类器与一个预先选定的检测基线，保持测试图片、标注和匹配规则一致；说明遮挡、小脸、框标注误差与推理成本的限制。不要把单一阈值的精确率当作 mAP。

### 8.3 可选挑战：用 t-SNE 检查潜变量

可视化能帮助提出问题，不能证明模型有偏或公平。先冻结基线与 DB-VAE，在同一批按身份和来源独立划分的样本上，以评估模式提取特征：例如基线分类器倒数第二层和 DB-VAE 编码器的均值 `μ`，记录各自维度。分别只用训练特征拟合标准化参数，再用相同参数变换对应的验证或测试特征；不要用测试特征拟合标准化、PCA 或模型。若特征维度高，可在训练特征上拟合 PCA 降维，再变换待画样本；记录维度和预处理。基线与 DB-VAE 特征空间不同，分别拟合预处理，不直接比较两张图的坐标尺度。

从同一评估集按预先约定规则抽取相同样本，记录每组样本数、抽样种子和上限（例如总计最多 2,000 条，以实际资源为准）；少数群体不足时如实报告，避免按标签挑选看起来有差异的点。对标准化（及可选 PCA）后的特征运行 t-SNE，固定并记录 `random_state`、perplexity 和库版本，perplexity 必须小于实际样本数；以多个种子重复，并在资源允许时比较不同 perplexity。样本过少时减少 perplexity 或不画，不凭空补样本。可用标签或错误类型着色，但不展示可识别图片。

提交样本选择、预处理、参数、不同种子的图及分组错误率对照，说明抽样和小组样本量的限制。t-SNE 坐标方向、跨簇距离和簇的形状对参数与随机初始化敏感；分离或重叠不等于存在或不存在偏差，也不能代替独立测试集的 FPR/FNR。
