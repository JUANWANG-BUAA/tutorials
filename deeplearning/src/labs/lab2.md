## 1. 从分类到检测

分类回答「这张图是什么」，检测回答「图里**哪里有**什么」。第 3 讲的 CNN 给出**一张图的整体标签**；检测要给出**一组框 + 类**：$\{(x,y,w,h,\text{score})\}_i$。

两条主流路线（第 3 讲 3.6）：

| 路线 | 做法 | 代表 | 特点 |
|:--|:--|:--|:--|
| 两阶段 | 先产生候选区域，再对每个区域分类 + 回归框 | R-CNN 系列 | 精度高、速度较慢 |
| 单阶段 | 直接在网格上预测框与类 | YOLO 类 | 速度快、适合实时 |
| 滑动窗口（本 Lab 起点） | 用固定大小的窗口在图上逐位置扫 | 经典方法 | 直观，能看清感受野与步幅的作用 |

## 2. 用滑动窗口理解检测

最朴素的检测器：拿一个小 CNN（输入如 $32\times32$），在图上以固定**步幅**滑动，每个窗口输出"有人脸 / 没人脸"。这正好把[第 3 讲](../lectures/lec03.md)的**感受野**和**步幅**用上了。

::: intuition 滑动窗口为什么慢，又为什么值得先理解
在每个位置都跑一次 CNN，计算重复且昂贵。但这个笨办法把检测的**本质**摊开了：检测 = 在**位置**和**尺度**上搜索"分类器认为这里有个目标吗"。理解了它，再看 YOLO 的"一次前向在特征图上密集预测"，就知道它只是把搜索**共享**了——卷积本身已经在所有位置滑动，何必再手动循环。
:::

**多尺度**：人脸大小不一，窗口也需多尺度——图像金字塔或特征金字塔（在不同下采样层级上检测）。这正是「池化带来的一定平移不变性」（第 3 讲 3.3）在检测里的用途。

## 3. 数据管线

检测数据是「图 + 一组框」，比分类多两步：

1. **读入与归一化**：像素缩放到 $[0,1]$ 或标准化。
2. **框的坐标变换**：标注常给 $(x_1,y_1,x_2,y_2)$，模型常预测 $(c_x,c_y,w,h)$ 加偏移——**训练时需要在这两种表示间转换**（这是检测最容易出 bug 的地方）。
3. **匹配正负样本**：对滑动窗口版本，窗口与某个人脸框的 IoU 超过阈值记为正，低于另一阈值记为负（背景）。

::: note IoU：检测的"重叠度"
$\mathrm{IoU}=\dfrac{\text{交集面积}}{\text{并集面积}}$。它同时用作**正负样本的匹配准则**与**评价指标**。IoU 越大，预测框与真值框越重合；一般 $\mathrm{IoU}\gt0.5$ 视为命中。
:::

## 4. 训练与评估

- **损失**：分类用交叉熵（第 1 讲 1.4），框回归用平滑 L1 或 IoU 类损失。
- **评估**：不要只看准确率（背景远多于人脸，全判背景也能"高准确率"）。用 **Precision / Recall** 与 **mAP**（各类别 Precision–Recall 曲线下面积的平均），NMS（非极大值抑制）去掉重叠的重复框。

::: ex 思考题 · 为什么准确率会骗人 {#lab2-q1}
一个检测集里 99% 的窗口是背景。若模型全部判为背景，准确率是多少？为什么这个数字没有意义？

::: proof 参考结论
准确率 $\approx99\%$——但它**一个人脸都框不出来**（召回率 = 0）。类别极不平衡时准确率是坏指标，必须看 Precision / Recall 或 mAP。
:::
:::

## 5. 对抗样本：人眼看不出，模型却错

在输入上加一个**人眼几乎不可察**的小扰动 $\boldsymbol\delta$，使模型出错：

$$\boldsymbol x_{\text{adv}}=\boldsymbol x+\boldsymbol\delta,\qquad
\boldsymbol\delta=\varepsilon\cdot\mathrm{sign}\bigl(\nabla_{\boldsymbol x}\mathcal L(\boldsymbol x,y)\bigr).$$

这就是 **FGSM**（快速梯度符号法）：沿**让损失上升**的方向推一小步。它和训练用的是**同一个梯度**（第 1 讲的反向传播），只是这次求的是**对输入**的梯度，而不是对参数。

::: intuition 对抗样本说明了什么
它说明模型的决策**不等于**人的决策：模型的"人脸"是特征空间里一个高维区域，沿某些方向挪一点点就跨过边界，而这些方向对人不敏感。这既是安全风险（攻击），也是理解模型（它的边界长什么样）的工具。第 3 讲 3.7 讨论的伦理问题在这里变成可实验的对象。
:::

## 6. 隐私与偏见（讨论题）

- **偏见**：若训练数据里某种肤色/性别的样本偏少，检测器对该群体的召回率会系统性偏低。列出如何在**数据集层面**发现这一点。
- **隐私**：人脸是可识别身份的生物特征。讨论：这类系统在部署时应当有哪些**默认约束**（数据留存、用途限制、知情同意）？（参见[第 7 讲](../lectures/lec07.md)三条法则。）

## 7. 排错清单

1. **框坐标用错表示**（像素 vs 归一化、中点+宽高 vs 两角）——检测最常见的 bug；
2. **正负样本比例**：负样本过多会让模型全判背景，需要采样/加权；
3. **NMS 阈值**：太小→漏框，太大→重复框；
4. **图像与标注不同步**：增强（翻转/裁剪）时必须**同等地**变换框；
5. **评估集泄漏**：别用训练里见过的图评估。

## 8. 提交与自检

- 一张带检测框的可视化结果；
- 一份 Precision / Recall（或 mAP）报告；
- 一个对抗样本演示：原图 + 扰动放大图 + 误判结果。

**自检**：能说清「卷积共享」如何把滑动窗口变高效；能解释 IoU、NMS、mAP 各自解决什么问题；能演示一个对抗样本并说明它为何"欺骗"了模型。
