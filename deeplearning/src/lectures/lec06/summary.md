# 第 6 讲总结 · 新前沿

> 本页把[导览](overview.md)与 [6.1](sec61.md)–[6.7](sec67.md) 压成一张可复习的骨架。用法：先只看「核心问题」列做自问，答不全再读「关键结论」列，最后回到「典型陷阱」列校核。

| **[6.1 大语言模型：从自监督预训练到对齐](sec61.md)** | 把 Transformer 放到极致地大、喂进海量文本，为什么能学出语言能力？ | 预测下一个 token 的交叉熵**字面上就是压缩码长**（[命题 6.1.1](sec61.md#prop-6.1.1)）；三段式流程各移动什么（[方法 6.1.1](sec61.md#method-6.1.1)）；KV cache 显存 $=2BLn_{\text{layer}}n_{\text{kv}}d_hb$，10 万 token 单会话约 **33 GB**（[定义 6.1.5](sec61.md#def-6.1.5)） | 跨 tokenizer 比较 PPL；不 mask 指令损失；把「对齐顺带激发能力」当定论 |

| **[6.6 智能体与世界模型](sec66.md)** | 怎样让模型持续行动？它真的在「规划」吗？ | ReAct 的关键是 **Observation 不由模型生成**（[定义 6.6.1](sec66.md#def-6.6.1)）；schema 设计决定工具调用成败，**不可逆操作必须隔离并确认**（[例 6.6.1](sec66.md#ex-6.6.1)）；同源反思**放大**偏差；rollout 受复合误差限制（单步 2% → 5 步 / 25 步，[例 6.6.2](sec66.md#ex-6.6.2)） | 把框架当能力；以为反思能自我纠错；把生成视频当可靠仿真 |
| **[6.7 评估、不确定性与可信部署](sec67.md)** | 怎么别被骗？怎样把分数变成可上线的决策？ | 四类基准**失效方向不同**，选型至少覆盖三类（[方法 6.7.1](sec67.md#method-6.7.1)）；污染三路径且「无污染」**无法被证明**（[定义 6.7.1](sec67.md#def-6.7.1)）；配对比较比平均分差可靠（[例 6.7.3](sec67.md#ex-6.7.3)）；模型系统性过度自信 → 弃答阈值是**业务决策**（[例 6.7.4](sec67.md#ex-6.7.4)）；四道闸门（[方法 6.7.4](sec67.md#method-6.7.4)） | 用单榜第一名选型；把「没主动放测试集」当作无污染；按均值而非 P95 估成本；回滚只切模型不管提示与配置 |

> **一条主线**：因为「好的概率预测 = 好的压缩 = 好的理解」把**扩大规模**变成一件值得下注的事（6.1），所以必须回答「参数与数据怎么配」——缩放律给出经验配比，也顺带暴露了「涌现」这类**读法问题**（6.2）；既然扩规模既有天花板又有争议，就转向**不改参数**的另一条路：提示与思维链，并把「多花推理算力」变成正式技术路线，但它的边界是**可验证面**（6.3）；同一套「用算力换质量」的思路向外长出能看图听声的多模态模型（6.4）、把符号接成动作的 VLA（6.5），以及会在环境里持续行动的智能体与在内部想象的世界模型（6.6）；而系统越贴近真实使用，**评测与部署纪律**就越成为决定成败的那一环（6.7）。

## 三句话带走

1. **本讲的数字几乎都能自己复算，本讲的主张都必须带条件。** 交叉熵就是压缩码长；$D\approx20N$ 只是某组拟合下的量级锚点；视觉 token 数随分辨率**平方**增长；动作分块把 $6.7$ Hz 恢复到 $50$ Hz；单步 2% 的误差只够规划 5–25 步。**把这些算式记牢，比背任何产品规格都耐用**（[勘误页第三节](errata.md#三时效补注版本时点快照纪律)）。
2. **三处争议必须并列两方、不站队**：能力涌现是真突变还是度量假象（[6.2.4](sec62.md#sec-6.2.4)）、视频模型算不算世界模拟器（[6.6.8](sec66.md#sec-6.6.8)）、评测污染与刷榜（[6.7.2](sec67.md#sec-6.7.2)）。要学的不只是两方说了什么，而是**怎样的实验能分辨它们**。
3. **从「分数」到「决策」要过四道闸门**：匹配性 → 污染 → 稳定性 → 可用性（[方法 6.7.4](sec67.md#method-6.7.4)）。任何「某模型更好」的主张，只要有一道过不去，它就只是一个**待验证的观测**。
