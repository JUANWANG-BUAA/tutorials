## A. 定义卡

**A1.** 写出自监督语言建模的分解式与训练目标，并说明「自监督」在**数据层面**意味着什么。
::: sol
$p_\theta(\boldsymbol x)=\prod_{t=1}^{T}p_\theta(x_t\mid x_{\lt t})$，训练目标为平均负对数似然 $\mathcal L(\theta)=-\frac1T\sum_t\log p_\theta(x_t\mid x_{\lt t})$（即词表上的交叉熵）。**「自监督」指监督信号来自数据本身**：第 $t$ 个位置的标签就是文本中真实出现的第 $t$ 个 token，因此任何网页 / 书籍 / 代码 / 对话都能变成样本，**不需要人工标注**（[定义 6.1.1](sec61.md#def-6.1.1)）。（✓ / △ / ×）
:::

**A2.** 写出困惑度的定义，并说明它与「平均每 token 花多少比特」的关系。
::: sol
$\mathrm{PPL}=\exp\bigl(-\frac1T\sum_t\log p_\theta(x_t\mid x_{\lt t})\bigr)=e^{\mathcal L}$：读作「模型每一步平均在多少个等可能的 token 之间犹豫」（$1$ 是完全确定、$V$ 是均匀乱猜）。由[命题 6.1.1](sec61.md#prop-6.1.1)，$\mathrm{PPL}=2^{H_2(q)}$，**底‑2 对数就是每 token 的比特数**；$\mathcal L=0.693$ nat $\Rightarrow \mathrm{PPL}\approx2$、每 token 约 1 比特（[定义 6.1.2](sec61.md#def-6.1.2)）。（✓ / △ / ×）
:::

**A3.** 什么是字节级 BPE？它为什么不存在未登录词（UNK）？编码时为什么可能切分不同？
::: sol
从 256 个 UTF-8 字节出发，反复执行贪心合并 $(a,b)^\star=\arg\max \mathrm{count}_\mathcal C(ab)$ 直到词表达目标规模（现代 LLM 常取 $V\in[3\times10^4,2\times10^5]$）。**字节级**意味着词表建立在字节上，**任意字符串都可编码**，故无 UNK。编码时按学到的合并规则顺序**贪心**切分，不再全局最优，因此**同一文本在不同实现下可能切分不同**（[定义 6.1.4](sec61.md#def-6.1.4)）。（✓ / △ / ×）
:::

**A4.** 写出 KV cache 的显存公式并逐个解释符号；再说出两种压低它的手段。
::: sol
$\text{bytes}=2\,B\,L\,n_{\text{layer}}\,n_{\text{kv}}\,d_h\,b$：系数 $2$ 是 K 与 V，$B$ 批大小、$L$ 序列长度、$b$ 每元素字节数。**随 $L$ 线性增长**（而算长上下文的代价随 $L$ 平方增长）。手段：GQA/MQA 降 $n_{\text{kv}}$、分页 cache + 前缀缓存复用、KV 量化、滑窗 / sink token、把长文档改为检索（[定义 6.1.5](sec61.md#def-6.1.5)）。（✓ / △ / ×）
:::

**A5.** 写出缩放律的常见拟合形式，解释 $L_\infty$；并回答「它到底是不是理论」。
::: sol
$L(N,D)\approx L_\infty+\bigl(\frac{N_c}{N}\bigr)^{\alpha_N}+\bigl(\frac{D_c}{D}\bigr)^{\alpha_D}$。$L_\infty$ 是**不可约损失**：即使 $N,D\to\infty$，损失也不会低于数据本身的熵（自然语言的固有不确定性）。它是**经验拟合**、不是推导：指数与常数随架构、优化器、数据分布变化，MoE / 合成数据等都会移动指数——**记趋势，不背数字**（[定义 6.2.1](sec62.md#def-6.2.1)）。（✓ / △ / ×）
:::

**A6.** 什么是数据墙与合成数据？合成数据在什么条件下可能带来净收益？
::: sol
**数据墙**：按计算最优配比扩张时，所需高质量自然文本量将超出可获得存量（各类估算差异很大，**引用必须注明口径**）。**合成数据**：用模型自身或更强模型生成训练数据。**净收益的条件是「有外部信息注入 + 有验证器」**——真实数据锚点（改写已有文档）、可执行检查（跑测试）、检索核对事实；此时它扮演**形态转换器**。无筛选地递归自产自收则放大偏差、塌缩多样性（[定义 6.2.2](sec62.md#def-6.2.2)）。（✓ / △ / ×）
:::

**A7.** 什么是上下文学习（ICL）？它与监督微调在「学习发生在哪里」上的差别是什么？
::: sol
ICL 不更新任何参数，只在输入前缀里给出 $k$ 个示范，让模型在**一次前向**中依据前缀改变行为（$k=0$ 为零样本、$k$ 不大为少样本）；形式上是 $\arg\max_y p_\theta(y\mid\text{前缀})$。**差别**：ICL 的「学习」发生在**前向条件化**里（权重冻结，本质是定位并调用预训练已装的子程序），微调发生在**参数更新**里。因此 ICL **不能凭空创造**预训练里没有的知识（[定义 6.3.1](sec63.md#def-6.3.1)）。（✓ / △ / ×）
:::

**A8.** 什么是自洽性（self-consistency）？它把「什么事件」替换成了「什么事件」？
::: sol
对同一问题**采样 $k$ 条带温度的完整推理路径**，对最终答案做统计取出现次数最多者：$\hat y=\arg\max_a\sum_i\mathbf 1[y^{(i)}=a]$。它把「一条长链一路正确」（要求极高、容错极差）替换为「多条链中多数落到同一答案」（多数表决）。**前提是错误在链之间不相关**；且只对有确定答案的任务成立（[定义 6.3.3](sec63.md#def-6.3.3)）。（✓ / △ / ×）
:::

**A9.** 写出 CLIP 式对比损失的单向形式；说明批大小为什么是这类方法的「核心算力」。
::: sol
$\mathcal L_{i\to t}=-\log\frac{\exp(\mathrm{sim}(\boldsymbol u_i,\boldsymbol w_i)/\tau)}{\sum_{j=1}^{B}\exp(\mathrm{sim}(\boldsymbol u_i,\boldsymbol w_j)/\tau)}$，再对称做一遍 $t\to i$（两者相加除以 2）；$\tau$ 是可学习温度。把 $B$ 个配对排成 $B\times B$ 相似度矩阵，**对角线是正例、其余全是负例**，因此 $B$ 越大负例越多、任务越难、表征越好——有效批大小可用负例缓存与跨卡交换扩大（[定义 6.4.1](sec64.md#def-6.4.1)）。（✓ / △ / ×）
:::

**A10.** 什么是 VLA 与动作分块（action chunking）？为什么分块是**必需**的？
::: sol
**VLA** 以视觉观测与语言指令为输入，直接输出低层动作（常是一段动作块 $a_{t:t+H}$），站在大模型语义骨干上。**动作分块**：一次前向输出 $H$ 步动作，执行时按控制频率依次下发。**必需性来自频率算术**：单步闭环下两次决策至少间隔一次前向时间（$0.15$ s $\Rightarrow 6.7$ Hz），远低于控制回路要求的 50 Hz；分块后执行侧仍是 50 Hz、等效控制频率恢复，代价是块间**接缝**（[定义 6.5.1](sec65.md#def-6.5.1)、[例 6.5.1](sec65.md#ex-6.5.1)）。（✓ / △ / ×）
:::

## B. 结论卡

**B1.** 三段式流水线的三个阶段各自「移动什么」？为什么跳过 SFT 直接做偏好对齐几乎不成立？
::: sol
预训练学**全部人类文本的概率分布**（含「怎么流畅地说错话」）；SFT 教**照做**（只对回答 token 算损失）；偏好对齐**移动概率质量**（把有用且守规的抬上去、把有害或敷衍的压下去），改的是**倾向**而非注入知识。跳过 SFT 不成立，是因为 DPO 类方法的**参考模型默认是 SFT 后的模型**——没有它就没有可锚定的起点（[方法 6.1.1](sec61.md#method-6.1.1)、[6.1.2](sec61.md#sec-6.1.2)）。（✓ / △ / ×）
:::

**B2.** 分词器通过哪三条通道影响成本与可用性？为什么「改词表」是真实收益而不是营销？
::: sol
① **成本**：按 token 计费、注意力按 token 平方增长（同一段中文在不同分词器下 token 数可相差近一倍）；② **有效长度**：窗口**按 token 计**，所以「容量」随语言不同而不同；③ **多语言公平**：英文主导的词表使稀有语言要更多 token 表达同一意思，等于被收更高费用、拿更短窗口。因此改词表能降低服务成本、扩大有效窗口、改善小语种可用性**而不改模型能力**——但它**不改变推理速度**（参数量与每 token 计算量未变）（[6.1.3](sec61.md#sec-6.1.3)）。（✓ / △ / ×）
:::

**B3.** 为什么「先调数据、再调架构」是更稳的顺序？
::: sol
① 架构改动的影响是**全局的**（要重训才能验证），数据改动的验证成本低（小规模消融可先看方向）；② 历史经验显示数据侧的收益常常更大（质量过滤与去重通常比换架构微调的一次性收益更大）；③ 更关键的是**数据问题会伪装成架构问题**——「模型学不会多步推理」可能只是训练集里没有足够的分布中样例，「代码能力差」可能只是代码占比太低或去重过度。**先诊断数据，再改模型**（[6.2.5](sec62.md#sec-6.2.5)）。（✓ / △ / ×）
:::

**B4.** Kaplan（2020）与 Chinchilla（2022）各给什么建议？差别来自什么方法差异？之后为什么又被「再修改」？
::: sol
Kaplan：固定算力下**大部分算力应投入参数**，数据可相对少（$N^\star\propto C^{0.73}$）；Chinchilla：**参数与数据等比例扩张**，此前的模型普遍参数过大、数据不足（$N^\star\propto D^\star\propto C^{0.5}$，等价于 $D\approx20N$）。**方法差异**：Chinchilla 在**同一批学习率调度下把每个点训到近乎收敛**再比较，而 Kaplan 未把所有训练跑到各自的损失平台。**再次修改**的原因：① 目标函数变了（工业界最小化**总拥有成本**而非训练损失，多花训练算力换更小模型更划算）；② 数据管线进步改变了最优点；③ 评测导向——下游表现并不与训练损失严格共变（[方法 6.2.1](sec62.md#method-6.2.1)、[6.2.2](sec62.md#sec-6.2.2)）。（✓ / △ / ×）
:::

**B5.** 测试时计算的三条形态各把算力花在哪个维度？各自适用什么任务？
::: sol
① **长思维链**——花在**序列长度**（自回归解码步数），适合单题深推理、形式化推导；② **多采样投票**——花在**采样条数 $k$**，适合有确定答案且 $p\gt0.5$ 的任务；③ **搜索 + 验证器重排**——花在**验证器调用次数 + 搜索宽度**，适合可分步验证的结构化任务。共同点是「用推理期算力换准确率」，区别是维度不同；第 ③ 条的命门是**要有可靠验证器**（没有它就退回不可靠的自我打分）（[定义 6.3.4](sec63.md#def-6.3.4)、[6.3.3](sec63.md#sec-6.3.3)）。（✓ / △ / ×）
:::

**B6.** RLVR 的突破处与天花板各是什么？为什么长 CoT 蒸馏是「能力搬运」而不是「能力创造」？
::: sol
**突破**：奖励来自**可判定的检验**（答案比对、测试用例、形式化检查器），$r\in\{0,1\}$ 或分段值，不需要训练奖励模型——大规模 RL 第一次有了稳定目标。**天花板**：**能验证什么就能学什么**，可验证面之外的能力不涨；且存在**奖励可钻性**（规格博弈：写死期望值、跳过边界用例）。**蒸馏**用强模型的推理轨迹 + 普通 SFT 把小模型教会，不需要 RL、不需要验证器，工程上便宜稳定，但**学生的上限由教师水平与轨迹数据量共同决定**——它没有产生新能力，且会让小模型继承教师的「啰嗦」（评估时必须同时报平均 token 消耗）（[定义 6.3.6](sec63.md#def-6.3.6)、[6.3.5](sec63.md#sec-6.3.5)）。（✓ / △ / ×）
:::

**B7.** 为什么说「连接器便宜、视觉 token 贵」？分辨率与压缩率各决定什么？
::: sol
连接器往往只是一个 MLP 或一组查询向量（336² 图、$d_v=1024\to d=4096$ 时约 $4.2$ M 参数，仅 7B 的 $0.06\%$ 量级）；视觉 token 才是大头：336² 一张图 $=576$ 个 token，是文本提示的 2.9 倍，提到 1008² 就到 $5184$。**分辨率**决定「看得到多细」，**压缩率**决定「细粒度信息能带进 LLM 多少」——编码器看清楚了却在压缩时扔掉，等于没看清。所以「换个更强编码器」不一定提升 VLM，先要找到瓶颈在哪一侧（[例 6.4.2](sec64.md#ex-6.4.2)、[6.4.3](sec64.md#sec-6.4.3)）。（✓ / △ / ×）
:::

**B8.** VLA 的四重错配是什么？两条动作生成路线各自的取舍是什么？
::: sol
四重错配：**输出空间**（词表离散分布 vs 连续有量纲多自由度向量）、**速度**（控制回路 10–100 Hz vs 模型前向 100 ms 量级）、**时间尺度**（一个语义步骤 = 数百个控制步）、**错误代价**（物理动作不可撤销）。两条路线：**动作离散化**（RT-1 → RT-2 → OpenVLA）换来语义迁移与指令泛化，代价是**精度上限 + 序列长度**；**连续生成**（Diffusion Policy → π0 流匹配）换来**多峰动作分布**与精细操作，代价是**采样步数**与实时性。粗动作（导航）用离散更划算，精细操作（插拔、装配）用连续更合适（[6.5.2](sec65.md#sec-6.5.2)、[方法 6.5.3](sec65.md#method-6.5.3)）。（✓ / △ / ×）
:::

**B9.** 执行式判定（SWE-bench 类）为什么比静态问答更难刷分？它仍有哪些漏洞？
::: sol
**更难**：判定依赖**真实执行**——补丁必须让仓库的隐藏测试通过，你没法「记住」一个补丁能否通过，因为那取决于真实代码库状态；造假成本高。**仍有的漏洞**：① **测试覆盖不足**时可写「让测试通过但不修根因」的补丁（规格博弈）；② 任务来自**公开仓库**，题目与修复可能已出现在训练数据里（污染）；③ 环境依赖使分数不稳、可复现性成本极高。所以判据应落到**任务是否真的完成**，而不是「测试是否通过」（[6.6.6](sec66.md#sec-6.6.6)）。（✓ / △ / ×）
:::

**B10.** 部署五件事里哪两步回报最高？各自的「唯一纪律」是什么？
::: sol
**缓存**与**分流**。缓存同时改善成本（不重复计算）、首 token 延迟（跳过 prefill）与吞吐（共享前缀可批处理），唯一实现纪律是**顺序**：稳定内容放前面、易变内容放后面（把用户问题放在系统提示之前会让命中率掉到接近零）。分流把请求按难度分层（规则 / 小模型先判 / 置信度阈值），只把难例送进大模型或长思维链——与「按难度分配测试时算力」是同一策略，只是决策点放到了系统层（[6.7.5](sec67.md#sec-6.7.5)）。（✓ / △ / ×）
:::

## C. 公式卡

**C1.** 自回归分解与训练目标。
::: sol
$p_\theta(\boldsymbol x)=\prod_{t=1}^{T}p_\theta(x_t\mid x_{\lt t})$，$\mathcal L(\theta)=-\frac1T\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{\lt t})$（词表 softmax + 交叉熵）。SFT 版本只累加回答位置：$\mathcal L_{\mathrm{SFT}}=-\frac1{|\mathcal A|}\sum_{t\in\mathcal A}\log p_\theta(y_t\mid\text{指令},y_{\lt t})$（[定义 6.1.1](sec61.md#def-6.1.1)、[定义 6.1.3](sec61.md#def-6.1.3)）。（✓ / △ / ×）
:::

**C2.** 压缩码长与困惑度。
::: sol
$\mathbb E_p[-\log_2 q]=H(p)+D_{\mathrm{KL}}(p\lVert q)\ \text{比特}$（$q$ 为模型、$p$ 为真实分布；$D_{\mathrm{KL}}\ge0$，$q=p$ 取等）；$\mathrm{PPL}=e^{\mathcal L}=2^{H_2(q)}$（[命题 6.1.1](sec61.md#prop-6.1.1)）。（✓ / △ / ×）
:::

**C3.** KV cache 与注意力代价。
::: sol
$\text{bytes}=2\,B\,L\,n_{\text{layer}}\,n_{\text{kv}}\,d_h\,b$（随 $L$ 线性）；注意力计算量每层 $\mathcal O(L^2d)$（随 $L$ 平方）。10 万 token、80 层、$n_{\text{kv}}=8$、$d_h=128$、BF16、$B=1$ $\Rightarrow\approx33$ GB（[定义 6.1.5](sec61.md#def-6.1.5)）。（✓ / △ / ×）
:::

**C4.** 缩放律与算力交换。
::: sol
$L(N,D)\approx L_\infty+(N_c/N)^{\alpha_N}+(D_c/D)^{\alpha_D}$；$C\approx6ND$（前向 $2ND$ + 反向 $4ND$）；$D\approx20N$；代入后 $C\approx120N^2$ 可反解：$N=\sqrt{C/120}$、$D=20N$。例：$C=2.4\times10^{22}\Rightarrow N\approx14.1$B、$D\approx283$B（[定义 6.2.1](sec62.md#def-6.2.1)、[例 6.2.2](sec62.md#ex-6.2.2)）。（✓ / △ / ×）
:::

**C5.** 乘积效应与多数投票。
::: sol
多步全对：$\mathrm{Acc}=p^{k}$（$p$ 平滑上升也会造出台阶）。多数投票（$k$ 条链、至少 $\lfloor k/2\rfloor+1$ 条正确）：$P=\sum_{j\gt k/2}\binom{k}{j}p^{j}(1-p)^{k-j}$；$p=0.4,k=5\Rightarrow0.317\lt0.4$（投票更差），$p=0.6\Rightarrow0.683$（[例 6.2.3](sec62.md#ex-6.2.3)、[例 6.3.2](sec63.md#ex-6.3.2)）。（✓ / △ / ×）
:::

**C6.** GRPO 的优势估计。
::: sol
$\hat A_i=\dfrac{r_i-\operatorname{mean}(r_1,\dots,r_G)}{\operatorname{std}(r_1,\dots,r_G)}$，$i=1,\dots,G$；其余仍是带裁剪的重要性采样目标并保留对参考模型的 KL 惩罚。**省掉的是与策略同规模的价值网络（critic）**，代价是用一组采样来估计基线（[定义 6.3.6](sec63.md#def-6.3.6)）。（✓ / △ / ×）
:::

**C7.** 视觉 token 与连接器参数量。
::: sol
$N_v=\dfrac{H}{p}\times\dfrac{W}{p}$（$p$ 为 patch 边长）：$336^2/p{=}14\Rightarrow576$；$672^2\Rightarrow2304$；$1008^2\Rightarrow5184$（随边长**平方**增长）。单层线性连接器参数量 $=d_v\times d$（$1024\times4096\approx4.19$ M）（[例 6.4.2](sec64.md#ex-6.4.2)）。（✓ / △ / ×）
:::

**C8.** 流匹配动作生成。
::: sol
$\boldsymbol a_t=(1-t)\boldsymbol\varepsilon+t\boldsymbol a$，$\mathcal L=\mathbb E_{t,\boldsymbol\varepsilon}\lVert v_\theta(\boldsymbol a_t,\boldsymbol o_t,\ell,t)-(\boldsymbol a-\boldsymbol\varepsilon)\rVert^2$，采样时解 ODE 从 $t=0$ 积到 $t=1$。它用多步生成过程表示**多峰**动作分布，避免单峰（高斯）策略把双峰最优解平均成「撞向障碍」（[定义 6.5.2](sec65.md#def-6.5.2)）。（✓ / △ / ×）
:::

**C9.** 世界模型的复合误差。
::: sol
独立随机误差：$e_H\approx\epsilon\sqrt H$；系统性偏差：$e_H\approx\epsilon H$。$\epsilon=0.02$、容差 $10\%$ 时分别给出 $5$ 步与 $25$ 步；$\epsilon=0.005$ 时给出 $20$ 步与 $400$ 步。**任何「可规划 $H$ 步」都必须连带报告误差模型**（[例 6.6.2](sec66.md#ex-6.6.2)）。（✓ / △ / ×）
:::

**C10.** 校准与选择性预测。
::: sol
$\mathrm{ECE}=\sum_{b}\frac{n_b}{n}\bigl|\mathrm{acc}(b)-\mathrm{conf}(b)\bigr|$（按置信度分箱、样本数加权）；**风险—覆盖曲线**：阈值 $\tau$ 越高 → 覆盖率越低、作答子集错误率越低。正文例：三箱（$40/100/60$、conf $0.60/0.80/0.95$、acc $0.45/0.72/0.90$）$\Rightarrow\mathrm{ECE}=0.085$；$\tau=0.9$ 时覆盖 $30\%$、错误率 $10\%$；$\tau=0.7$ 时覆盖 $80\%$、错误率 $21.25\%$（[定义 6.7.3](sec67.md#def-6.7.3)、[例 6.7.4](sec67.md#ex-6.7.4)）。（✓ / △ / ×）
:::

## D. 陷阱卡（每题给一两个错误说法，请指出错在哪）

**D1.** 「我们的 PPL 更低，所以模型更强」；「在提示里放几个示范，模型就学会了这个新任务」。
::: sol
两处都错。① PPL 只在**同一 tokenizer、同一去重程度**下可比，且重复数据可人为压低它（$2.0\to1.33$）——跨分词器比较要改用每字节比特数（BPB）（[6.1.1](sec61.md#sec-6.1.1)、[例 6.1.1](sec61.md#ex-6.1.1)）。② 上下文学习**不改参数**：它是把预训练已有的子程序**调出来**（条件化 / 检索），不是监督学习；对词表外的新概念没有任何通道（[定义 6.3.1](sec63.md#def-6.3.1)）。（✓ / △ / ×）
:::

**D2.** 「缩放律是理论，所以可以外推点值」；「涌现被证明是度量假象，所以扩大规模没有意义」。
::: sol
两处都错。① 缩放律是**经验拟合**：常数与指数随架构、数据、优化器变化，旧曲线不能搬；能外推的只有**趋势**（[6.2.1](sec62.md#sec-6.2.1)）。② 反向过度解读：度量论证说明的是**曲线形状可以由不连续度量产生**，不是「规模无用」；规模依然平滑提升底层能力，被证伪的只是最激进的机制主张（[6.2.4](sec62.md#sec-6.2.4)）。（✓ / △ / ×）
:::

**D3.** 「CoT 的输出就是模型的思考过程，可以拿来做审计」；「推理 token 越多，答案越准」。
::: sol
两处都错。① CoT **不保证忠实**：模型可能先「倾向」某答案、再组织理由；审计要靠**外部信号**（[6.3.2](sec63.md#sec-6.3.2)）。② 长度与正确率**不单调**：超纲题只会产出更长的错误论证（且更不易察觉），已会做的题无增益，成本线性以上（[6.3.6](sec63.md#sec-6.3.6)）。（✓ / △ / ×）
:::

**D4.** 「自洽性总是更好，采样越多越准」；「训练奖励涨到 0.95 就说明可以上线了」。
::: sol
两处都错。① $p\lt0.5$ 时多数投票**劣于**单链（$0.317\lt0.4$）；错误相关时收益被吃掉甚至转负（$0.683\to0.478$）；$k$ 越大收益递减（[例 6.3.2](sec63.md#ex-6.3.2)）。② 训练奖励是**代理**：奖励上升而真实质量先升后降是结构性现象（奖励模型是有损压缩）；必须看**独立于奖励模型**的评测，并把优化强度当超参（[定义 6.3.7](sec63.md#def-6.3.7)）。（✓ / △ / ×）
:::

**D5.** 「多模态模型说得出图里的细节，说明它真的看见了」；「换个更强的视觉编码器就能提升 VLM」。
::: sol
两处都错。① 它对齐的是**表示**，可能大量依赖**文本先验与共现统计**；细粒度空间关系、计数、小字、罕见组合上常出错，幻觉的四个来源（语言先验、信息损失、数据偏差、解码目标）里有两个与「看见」无关（[6.4.6](sec64.md#sec-6.4.6)）。② 若**压缩率**过高，编码器看清的细节传不进 LLM——先判断瓶颈在「看不清」还是「没传进去」（[6.4.3](sec64.md#sec-6.4.3)）。（✓ / △ / ×）
:::

**D6.** 「动作 token 化只是换输出格式，不影响精度」；「仿真足够真就不需要真机数据」。
::: sol
两处都错。① 分箱给动作精度设了**不可逾越的上限**，且按维度依次预测引入顺序依赖（[6.5.2](sec65.md#sec-6.5.2)）。② 模仿学习对**动力学失配**极其敏感，域随机化能缓解但不能消除；仿真应作为**放大器**而非替代品（[6.5.5](sec65.md#sec-6.5.5)）。（✓ / △ / ×）
:::

**D7.** 「换一个更强的框架，智能体就能做更多事」；「让它反思刚才的错误，它就能自我纠正」。
::: sol
两处都错。① 框架解决的是**管道**（重试、超时、并发、可观测性），不解决**能力**；要问「我缺的是能力还是管道」（[6.6.5](sec66.md#sec-6.6.5)）。② 同源自评（评价者=被评价者）会**放大**偏差，给错误结论盖「已验证」的章；只有当依据来自**模型之外**（测试、检索、人工确认）时反思才有修正力（[6.6.4](sec66.md#sec-6.6.4)）。（✓ / △ / ×）
:::

**D8.** 「测试集没被主动放进训练数据，所以没有污染」；「用公开榜单的第一名最稳」。
::: sol
两处都错。① 污染的主要来源是**近似泄漏、间接泄漏与输出回流**，都不需要「主动放入」；「无污染」**无法被证明**，只能降低风险（[6.7.2](sec67.md#sec-6.7.2)）。② 榜单排名会因提示格式、few-shot 数、采样策略剧烈变化，且被刷榜的概率最高；**在自己任务上的小规模对照实验比榜单可靠**（[6.7.2 的误读 3](sec67.md#sec-6.7.2)）。（✓ / △ / ×）
:::
