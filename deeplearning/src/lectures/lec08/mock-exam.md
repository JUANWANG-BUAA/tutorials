## 第一部分 · 概念判断（10 题 × 3 分 = 30 分）

**1.** 「科学任务的标签可以自动生成，因此不必担心标签质量。」（[定义 8.1.1](sec81.md#def-8.1.1)、[8.1.3 思考框](sec81.md#think-8.1.1)）

::: sol
**错。** 自动标签**继承生成器误差**：DFT 泛函误差、仿真近似、离散误差都会写进训练数据，构成精度上限；若用同一套生成器「自证」，误差会被静默固化。所以「可验证答案」这一特点的用处是**能算**，而不是**算得准**——验证必须来自独立来源（实验、观测、更高精度计算）。**给分**：判断 1 分 + 「继承生成器误差 / 独立来源」2 分。
:::

**2.** 「不变与等变只是同一件事的两种说法，模型学到近似的对称性就够了。」（[定义 8.1.2](sec81.md#def-8.1.2)、[例 8.2.3](sec82.md#ex-8.2.3)）

::: sol
**错。** 两者描述**不同输出类型**的变换规律：标量输出不变（$f(Rx+t)=f(x)$）、向量输出等变（$f(Rx+t)=Rf(x)$），不能互换。而「近似对称性」的问题在于等价朝向是**连续无穷多**的：模型只能学出一个以数据分布为条件的近似等变映射，在分布外立刻退化——把对称性写进结构才是真正解决。**给分**：判断 1 分 + 定义区分 1 分 + 「连续无穷多 / 分布外退化」1 分。
:::

**3.** 「两个位点的互信息为零，说明它们不可能在空间上接触。」（[定理 8.2.1](sec82.md#thm-8.2.1)、[定义 8.2.2](sec82.md#def-8.2.2)）

::: sol
**对，但注意方向性。** $\mathrm{MI}=0$ 当且仅当两位点统计独立；真正接触的位点若能维持结构稳定就必须协同变化，故会留下非零相关——所以「零互信息 ⇒ 不接触」成立。**反过来不成立**：$\mathrm{MI}\gt0$ 推不出接触（链式构造 $X_k=X_i$、$X_j=X_k$ 下 $\mathrm{MI}(i,j)=1$ bit 而 $i,j$ 无直接作用）。**给分**：判断 1 分 + 「$\mathrm{MI}=0$ ⟺ 独立」1 分 + 指出单向性 1 分。
:::

**4.** 「FAPE 与『全局叠合后的 RMSD』都消除了整体位姿的影响，所以二者可以互换。」（[定义 8.2.4](sec82.md#def-8.2.4)）

::: sol
**错。** 二者对**局部几何**的敏感性完全不同：全局叠合只消掉整体位姿，仍会把局部错误平均掉（局部误差被稀释约出错比例的平方根）；FAPE 在**每个残基的局部框架**里分别度量，使每个邻域的几何都被单独检查。可互换的说法在「域内扭转 30°」这类局部错误上直接失效。**给分**：判断 1 分 + 「局部错误被平均」2 分。
:::

**5.** 「局部能量分解让势函数的计算量与体系大小无关。」（[定义 8.3.2](sec83.md#def-8.3.2)、[方法 8.3.2](sec83.md#method-8.3.2)）

::: sol
**错，混淆了两个对象。** 与体系大小**无关**的是「每个原子局部环境的评价标准」（同一套参数适用于 $N=10$ 与 $N=10^{5}$）；计算量本身是**近似线性**的 $O(Nk)$（每原子聚合截断半径内 $k$ 个邻居），不是常数。对照 DFT 的高阶增长与每构型重新自洽迭代，这才是数量级差异的来源。**给分**：判断 1 分 + 「线性而非无关」1 分 + 「与 DFT 对比」1 分。
:::

**6.** 「PINN 的残差损失降到很低，就可以判定解是对的。」（[8.4.2 直觉框](sec84.md#sec-8.4.2)、[方法 8.4.4](sec84.md#method-8.4.4)）

::: sol
**错。** 残差是在**采样点**上算的：采样覆盖不足、权重失衡、或解在采样点之间剧烈变化时，损失可以很低而解很错；而且「残差小」不保证离散守恒。验收必须同时报告：残差相对量级、**边界与初条件满足度**、以及与低精度参照解 / 守恒量的对照。**给分**：判断 1 分 + 「只在采样点上」1 分 + 三类验收量 1 分。
:::

**7.** 「神经算子学的是算子本身，所以换分辨率时必然仍可用——这是它的自动属性。」（[定义 8.4.2](sec84.md#def-8.4.2)、[方法 8.4.4](sec84.md#method-8.4.4)）

::: sol
**错。** 「离散无关」是需要**验证的主张**，不是自动属性。参数量与分辨率无关只是**必要条件**；充分条件是在训练分辨率之外的网格上测相对 $L^2$ 误差（含上采样、下采样 / 不规则采样、分布外参数与高频成分），并对含激波 / 间断的解单列——那时有限的 $k_{\max}$ 截断是结构性失效。**给分**：判断 1 分 + 「需验证 + 必要条件」1 分 + 「高频 / 间断单列」1 分。
:::

**8.** 「数据驱动预报的主要困难是训练数据不够，多喂几年再分析数据就能解决外推问题。」（[定义 8.5.2](sec85.md#def-8.5.2)、[8.5.5 思考框](sec85.md#think-8.5.1)）

::: sol
**错。** 困难至少有三层：① **训练—推理分布差异**（暴露偏差，与数据量无关）；② **多步误差累积**（放大率由动力学决定，混沌系统有可预报性上限）；③ **气候非平稳**（训练分布本身在漂移，历史再分析覆盖的是一个正在移动的分布，数据再多也不覆盖未来气候态）。**给分**：判断 1 分 + 任两条机制 2 分。
:::

**9.** 「ACC 是尺度不变的，整体偏弱 20% 的预报也能拿到满分，所以 ACC 不可用。」（[定义 8.5.3](sec85.md#def-8.5.3)、[例 8.5.3](sec85.md#ex-8.5.3)）

::: sol
**错，结论下反了。** ACC 的尺度不变性是**特性而非缺陷**：它衡量「异常的空间形态是否一致」，适合诊断形势；幅度误差由 RMSE 捕捉（$1.2o$ 的预报 ACC $=1.000$ 而 RMSE 几乎差一倍）。正确做法是**两者并列**，并写明业务关心形态还是幅度，而不是弃用其中之一。**给分**：判断 1 分 + 两种指标的分工 2 分。
:::

**10.** 「外推三判据里，分布外判据最强，因为它最难做。」（[定义 8.6.2](sec86.md#def-8.6.2)、[方法 8.6.1](sec86.md#method-8.6.1)）

::: sol
**错。** 三条判据中**干预判据最强**（它直接检验模型抓到的是因果机制还是统计相关），代价是必须做真正的干预（实验或受控仿真）；而分布外判据**最便宜**（通常只是改变切分维度），因此执行顺序建议是先 ① 再 ②，最后 ③。**给分**：判断 1 分 + 指出干预最强 1 分 + 执行顺序 / 成本 1 分。
:::

## 第二部分 · 填空与简答（5 题 × 4 分 = 20 分）

**11.** 填空：取 $N=384$、MSA 深度 $s=256$、$c_m=128$、$c_z=64$、bf16（2 字节），写出四组元素的**元素数与显存**：MSA 表示 \_\_\_ 元素 / \_\_\_ MB；配对表示 \_\_\_ 元素 / \_\_\_ MB；行注意力（$N\times N\times s$）\_\_\_ MB；列注意力（$N\times s\times s$）\_\_\_ MB。并指出 $N$ 翻倍时哪一项涨得最快。（[例 8.2.2](sec82.md#ex-8.2.2)）

::: sol
MSA 表示 $384\times256\times128=12{,}582{,}912$ 元素 ≈ $25.2$ MB；配对表示 $384\times384\times64=9{,}437{,}184$ ≈ $18.9$ MB；行注意力 $384\times384\times256=37{,}748{,}736$ ≈ $75.5$ MB；列注意力 $384\times256^2=25{,}165{,}824$ ≈ $50.3$ MB（均已乘 2 字节）。增长律：MSA 表示 $\propto Ns$、行注意力与配对表示 $\propto N^2$、列注意力 $\propto Ns^2$——**$N$ 翻倍时 $N^2$ 与 $Ns^2$ 类项涨得最快**（长链瓶颈是 $N^2$，深 MSA 瓶颈是 $s^2$）。
:::

**12.** 简答：数据驱动预报为什么常输入**两个时刻**？它能缓解什么、**不能**解决什么？（[定义 8.5.1](sec85.md#def-8.5.1)、[即时自测 8.5](sec85.md#method-8.5.6)）

::: sol
推进映射写成 $f_\theta:(\boldsymbol s_{t-\Delta},\boldsymbol s_t)\mapsto\boldsymbol s_{t+\Delta}$：单帧静态场里「正在加深的低压」与「正在减弱的低压」看起来一样，两帧之差给出**趋势 / 运动方向**信息。**能缓解**方向不清；**不能解决**误差累积与暴露偏差——那些要靠 rollout 训练、噪声注入、多步长模型组合与集合化（[方法 8.5.4](sec85.md#method-8.5.4)）。
:::

**13.** 简答：写出一维热方程 $u_t=\alpha u_{xx}$ 的 PINN 残差损失，说明其中的二阶导从哪来，并给出一个残差恒为零的函数族。（[定义 8.4.3](sec84.md#def-8.4.3)、[例 8.4.2](sec84.md#ex-8.4.2)）

::: sol
$\mathcal L_{\text{res}}=\frac1N\sum_k\bigl(\partial_tu_\theta(x_k,t_k)-\alpha\,\partial_x^2u_\theta(x_k,t_k)\bigr)^2$。两个导数**全部由对网络输入 $(x,t)$ 的自动微分给出**：$\partial_t$ 是一次 `grad`，$\partial_x^2$ 是对 $x$ 连求两次（嵌套 `grad` 或高阶函数），不需要任何差商。精确解族：$u=e^{-\alpha k^2t}\sin(kx)$ 对任意 $k$ 成立（高频衰减更快）；例如 $u=e^{-2\alpha t}\sin(\sqrt2x)$ 的残差为零。
:::

**14.** 填空与简答：设 DFT 单点 $120$ 秒、势函数单次前向 $2\times10^{-3}$ 秒、训练需要 $2\times10^{4}$ 个 DFT 标签、训练机时 $2\times10^{4}$ 秒。写出「划算判决」的不等式，并给出**调用次数的门槛**；再判断「只跑 $10^{3}$ 步 MD」该不该训势函数。（[例 8.3.2](sec83.md#ex-8.3.2)）

::: sol
判决式：$C_{\text{DFT}}\cdot N_{\text{调用}}\ \text{vs}\ C_{\text{标签}}\cdot N_{\text{标签}}+C_{\text{训练}}+C_{\text{势}}\cdot N_{\text{调用}}$。代入：标签成本 $=2\times10^{4}\times120=2.4\times10^{6}$ 秒，加训练机时 $2\times10^{4}$ 秒，门槛 $\approx2.42\times10^{6}$ 秒。令 $120N\gt2.42\times10^{6}+0.002N$ 得 $N\gtrsim2.0\times10^{4}$：**调用次数超过约两万次才划算**。只跑 $10^{3}$ 步 MD 时 DFT 直接算约 $1.2\times10^{5}$ 秒（约 1.4 天），远低于训练门槛——**此时训势函数是浪费**；反之在百万级筛选里训练成本被摊薄到可忽略。
:::

**15.** 简答：写出外推能力的三条判据，指出哪一条最难获得证据并说明原因。（[定义 8.6.2](sec86.md#def-8.6.2)）

::: sol
① **分布外**（推到训练覆盖之外的同类型对象：新体系 / 新区域 / 更极端气候态）；② **尺度**（更大体系、更长时、更细 / 更粗分辨率）；③ **干预**（主动改一个变量后预测后果）。**最难的是 ③**：它要求真正的干预（实验或受控仿真），而天文、气候、地球演化等领域根本无法对系统做受控实验；替代方案（自然实验、准实验设计、结构因果模型的条件独立检验）都需要额外假设，可信度依次下降。
:::

## 第三部分 · 推导与计算（3 题 × 10 分 = 30 分）

**16.** （10 分）设误差按 $e_{k+1}=g\,e_k+\delta_k$ 传播，步长 $\Delta=6$ 小时。(1) 写出 $e_k$ 与翻倍步数 $k^\star$；(2) 取 $g=1.03$ 与 $g=1.01$（$\delta=0$）分别求 $k^\star$ 与天数；(3) 说明 $\delta\gt0$、$g\lt1$ 时的稳态及其随 $g\to1^-$ 的变化；(4) 讨论：为什么「翻倍时间延长约 3 倍」不能直接宣传为「可用预报时效延长 3 倍」？（[例 8.5.1](sec85.md#ex-8.5.1)、[定义 8.5.2](sec85.md#def-8.5.2)）

::: sol
**(1)** $e_k=g^ke_0$；$k^\star=\dfrac{\ln2}{\ln g}$（$g\gt1$）。
**(2)** $g=1.03$：$k^\star=\dfrac{0.6931}{0.02956}\approx23.4$ 步 → $23.4\times6=140$ h $\approx5.9$ 天。$g=1.01$：$k^\star=\dfrac{0.6931}{0.00995}\approx69.7$ 步 → $69.7\times6=418$ h $\approx17.4$ 天。
**(3)** 通解 $e_k=g^ke_0+\delta\dfrac{1-g^k}{1-g}$，$g\lt1$ 时稳态 $e_\infty=\dfrac{\delta}{1-g}$：误差不再指数增长，但**停在非零水平**，且 $g\to1^-$ 时该水平发散（$g=0.98$ 时 $50\delta$，$g=0.9$ 时 $10\delta$）——耗散越弱，稳态误差越大。
**(4)** 三点：① 翻倍时间描述的是**已有误差的传播**，它给出的是「误差何时翻倍」的标尺，而业务关心的是误差**何时越过一个绝对阈值**（相对于气候态变率），两者不是线性关系；② 模型改进通常同时改变单步误差 $\delta_k$ 与放大率 $g$，必须**分开报告**；③ $g$ 是玩具放大率，真实误差增长随变量、尺度与天气形势变化（**需核实**），且误差不增长还可能是过度平滑的假象。
**给分**：公式 2 分 + 两组代入 3 分 + 通解与稳态 3 分 + 讨论 2 分。
:::

**17.** （10 分）(1) 从 $E=\sum_iE_i(\mathcal N_i)$ 出发，推导消息传递的开销为 $O(LNk)$ 并说明它与体系大小无关的理由；(2) 论证「平移不变自动成立」；(3) 给出这条假设的两个代价并各配一条检查动作；(4) 某平台计划调用 $5\times10^{4}$ 个体系的单点，$C_{\text{DFT}}=10^{2}$ 秒、$C_{\text{势}}=10^{-3}$ 秒、$N_{\text{标签}}=5\times10^{4}$、训练机时 $10^{4}$ 秒——求门槛与结论。（[定义 8.3.2](sec83.md#def-8.3.2)、[方法 8.3.2](sec83.md#method-8.3.2)）

::: sol
**(1)** 每原子只依赖截断半径 $r_c$ 内的邻居（平均 $k$ 个）；一轮消息传递对每原子聚合 $k$ 个邻居 → $O(Nk)$，$L$ 轮 → $O(LNk)$。$L$ 与 $k$ 由模型与 $r_c$ 决定，**与 $N$ 无关**，故算力随原子数近似线性（对照 DFT：自洽场迭代、通常随电子数高阶增长、每个构型都要重算）。「与体系大小无关」说的是**局部环境的评价标准不变**，不是计算量不变。
**(2)** $\mathcal N_i$ 只由「邻居与相对位置」构成，整体平移不改变任何局部环境，故平移不变无需额外约束即自动成立（对比：旋转等变需要在网络结构里显式实现）。
**(3)** ① **长程相互作用被截断忽略**（静电、色散、电荷转移）→ 检查：对带电 / 极性体系单独验证，必要时显式加长程项；② **近邻集合与解离极限**（数据集中在平衡构型附近时断键 / 过渡态势垒不可信）→ 检查：用含反应路径的数据训练并对势垒专门验证，在目标体系上用 DFT 抽查点核对。
**(4)** 门槛 $=5\times10^{4}\times10^{2}+10^{4}=5.01\times10^{6}$ 秒；判决 $100N\gt5.01\times10^{6}+0.001N$ 得 $N\gtrsim5\times10^{4}$。计划调用恰好 $5\times10^{4}$ 个单点，**处在门槛附近**：结论是「勉强划算，但没有余量」——应把「调用次数会随平台使用持续增长」当作前提，同时把训练数据的覆盖范围写进适用域声明，否则省下来的算力会被外推误差吃掉。
**给分**：复杂度推导与「无关」辨析 4 分 + 平移不变论证 1 分 + 两个代价与检查 3 分 + 代入与结论 2 分。
:::

**18.** （10 分）(1) 写出中心差分梯度校验的两项误差与总误差量级；(2) 取 $M=\lvert f'''\rvert=10$、$\varepsilon=2.2\times10^{-16}$，求 $h^\star$ 与最低误差，并说明最优处两项的比例；(3) 若数值噪声使**有效** $\varepsilon_{\text{eff}}=10^{-8}$，求新的 $h^\star$ 与可达精度，并说明为什么此时的梯度校验容差必须放宽；(4) 说明这条检查为什么必须在可微分仿真里「先跑」。（[例 8.4.4](sec84.md#ex-8.4.4)）

::: sol
**(1)** $E(h)\approx\dfrac{Mh^2}{6}+\dfrac{\varepsilon}{h}$：第一项是差分公式的截断误差，第二项是函数值舍入误差被 $2h$ 放大的结果。
**(2)** 令 $\frac{Mh}{3}=\frac{\varepsilon}{h^2}$ 得 $h^{\star3}=\frac{3\varepsilon}{M}=\frac{6.6\times10^{-16}}{10}=6.6\times10^{-17}$，故
$$h^\star\approx4.0\times10^{-6},\qquad E(h^\star)=\frac{Mh^{\star2}}{6}+\frac{\varepsilon}{h^\star}\approx2.7\times10^{-11}+5.4\times10^{-11}\approx8.2\times10^{-11}.$$
最优处截断项 $=\frac{\varepsilon}{2h^\star}$，**恰为舍入项的一半**（这就是系数 3 的来源）。
**(3)** $\varepsilon_{\text{eff}}=10^{-8}$ 时 $h^{\star3}=\frac{3\times10^{-8}}{10}=3\times10^{-9}\Rightarrow h^\star\approx1.4\times10^{-3}$，$E(h^\star)\approx\frac{10\times(1.4\times10^{-3})^2}{6}+\frac{10^{-8}}{1.4\times10^{-3}}\approx3.5\times10^{-6}+7\times10^{-6}\approx1.0\times10^{-5}$。**可达精度从 $10^{-11}$ 掉到 $10^{-5}$**（量级从 $\varepsilon^{2/3}$ 变到 $(10^{-8})^{2/3}\approx4.6\times10^{-6}$），所以容差必须跟着数值噪声走：此时合理门槛是相对误差 $10^{-4}$ 量级，死守 $10^{-6}$ 只会把「噪声」误判成「链路错误」。
**(4)** 它**不需要真值、成本极低**，却能在花掉大量算力之前暴露梯度链路错误（不可微点、参数未参与计算图、实现错误）；在可微分仿真里这是唯一的「梯度可信度体检」（[方法 8.4.3](sec84.md#method-8.4.3)）。
**给分**：误差两项 2 分 + $h^\star$ 与最低误差 3 分 + 比例关系 1 分 + 噪声变体与容差结论 3 分 + 「先跑」理由 1 分。
:::

## 第四部分 · 开放题（2 题 × 10 分 = 20 分）

**19.** （10 分）场景：你拿到一份 $10^{5}$ 条「候选晶体结构」清单（含预测形成能与来源模型置信度），DFT 预算 500 个单点，湿实验预算 3 个样品。请设计筛选与验证方案，并回答：**「新」这个词在你的方案里如何定义**？请给出两方证据（不站队）并说明你的判据选择。（[方法 8.3.3](sec83.md#method-8.3.3)、[例 8.3.3](sec83.md#ex-8.3.3)、[思考 8.3.1](sec83.md#think-8.3.1)）

::: sol
**方案（四步）**：① **重算稳定性判据**——不信任清单自带的数，用**同一版本数据库与凸包定义**重算形成能与相对凸包高度，记录数据库版本与计算日期；② **新颖性核查**——结构相似性（原子环境指纹类描述符 + 阈值）与成分相似性同时检索现有数据库，对高相似度候选标为「已知结构的变体」而非「新材料」；③ **动力学与有限温度检验**——对通过前两步的候选跑有限温度 MD（先用 DFT 抽查确认所用势函数在该化学空间内可信，否则等于用模型检验模型）；④ **可合成性与排序**——合成可达性评分 + 类似反应路线检索，把候选分成「有先例路径 / 需新路线 / 目前无路径」，输出**带失败判据的推荐清单**。
**判据选择**：「新」＝**在给定的相似度阈值、成分容差与数据库版本下未被收录**。因此必须**报告「在若干阈值下分别有多少条通过」**，而不是只报一个数字——阈值收紧会否掉真正的新结构，放宽会把畸变当成新发现；同时把「热力学稳定」「动力学稳定」「可合成」三者分开表述。
**两方证据**：支持方主张流程可复现（生成 → 筛选 → DFT 验证）、规模远超人工枚举、覆盖大量未被实验探索的成分与原型；质疑方主张「新」依赖比对口径、大规模搜索常产已知原型的畸变 / 超胞变体、热力学稳定 ≠ 可合成、被复核的只是先验筛选后的子集。**我的判据**：把这类工作的价值定位在「把搜索规模推进一个数量级 + 给出可复现流程」，而「发现多少新材料」必然依赖判据与验证覆盖。
**失败判据**：① 换一个合理阈值后通过数变化超过一个数量级 ⇒ 结论不可报告为「发现」；② 500 个 DFT 复核里高置信度分段的误差不显著优于低置信度分段 ⇒ 不确定性估计失效；③ 3 个样品的表征结果与预测的排序不一致 ⇒ 退回「候选生成器」定位。
**验证计划**：先用 500 个 DFT 预算做**分层抽样复核**（按置信度分层，检查误差校准）→ 用 3 个样品优先验证「有先例合成路径」的候选 → 把失败样本与阈值敏感性一并写进报告。
**给分**：四步方案 4 分 + 「新」的判据明确且阈值敏感 2 分 + 两方证据并列 2 分 + 失败判据与验证计划 2 分。
:::

**20.** （10 分）场景：某团队声称「用 AI 从观测数据里发现了一个新的守恒量（或一条新的控制关系）」。请设计一套检验方案，写出**外推三判据**的具体测试、所需的**验证器强度**、最可能出现的**两类伪发现**、以及验证预算的分配原则；最后写出「AI 是在发现还是在高效插值」两方主张的**可检验推论**。（与[习题集 D4](exercises.md) 同域但不同题：那题比较三类产出，本题针对一个物理声明。）（[定义 8.6.2](sec86.md#def-8.6.2)、[例 8.6.2](sec86.md#ex-8.6.2)、[方法 8.6.2](sec86.md#method-8.6.2)）

::: sol
**五步验证流水线（从零成本到需要实验逐级加码）**：① **量纲与极限**（免新数据）：等式两边量纲一致；已知极限（浓度 / 温度趋零、对称性）下是否退化为公认结果；② **独立数据**：换另一批独立采集 / 不同实验条件的复算，检查项结构不变、系数落在置信区间内；③ **分布外与尺度**：更高 / 更低温度区、更宽参数范围、不同体系；误差应随外推距离温和上升（数量级跳变 ⇒ 缺乏外推结构）；④ **干预**：主动改动被认定为关键的那个变量（加添加剂、改压力、施加外场），先预测再实测，**方向一致**是最低要求；⑤ **与既有理论对话**：写出「这个结论在什么条件下必然失效」的可证伪预测并设计反例实验。
**三判据的具体测试**：分布外＝按体系 / 时间 / 空间切分（而非随机切分）；尺度＝更大体系、更长时、更细分辨率下重测；干预＝受控实验或受控仿真（替换参数 / 边界、施加外场），比较排序能力（如 Spearman）是否保持。
**验证器强度**：物理声明属「拟合 + 物理检查」级（阶梯第 3 级），**没有任何形式化检查器能替代实验**；硬验证器（可执行复算、形式化证明）在这类声明上不可得，所以最终判决只能是实验与独立观测。
**两类伪发现**：① **判据产物**——「新」依赖相似度阈值 / 数据库版本 / 预处理口径，换一个合理阈值就消失；② **目标错设**——评分器（拟合误差 + 复杂度）写错目标时，搜索会高效地找到「在错误目标上很强」的表达式（与第 7 讲的奖励错设同构），例如只用拟合优度而漏掉量纲与极限检查。
**验证预算分配原则**：验证器越软，留给独立数据与干预实验的预算越多；第 ① 步不过关就不必花实验预算；把验证当作流程的一部分而不是发现之后的意外支出。
**两方主张的可检验推论**：若「高效插值」一方正确，推论是**把评分器换成人类无法事先定义的评价标准时这类系统会失效**；若「新的理解载体」一方正确，推论是**模型表征应能预测人类尚未写出公式的现象，且预测能被实验证实**。两条推论都可用同一套框架检验，所以**不必先站队即可推进研究**；在证据出现前按验证器强度决定信任级别、按[决策表](sec86.md#method-8.6.4)决定输出用途。
**给分**：五步流水线与三判据映射 4 分 + 验证器强度判断 2 分 + 两类伪发现 2 分 + 两方推论与预算原则 2 分。
:::
