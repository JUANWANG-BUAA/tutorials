## 节一览

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[8.1 为什么科学适合深度学习](sec81.md)** | 科学数据的什么特点决定了它的方法？三类任务怎么分？ | 主要矛盾是**标签稀缺而非数据稀缺**；三特点 = 结构化先验 / 可验证答案 / 海量弱标注（[定义 8.1.1](sec81.md#def-8.1.1)）；三类任务 = 预测（死在分布外）/ 反演（死在约束）/ 发现（死在验证）（[定义 8.1.3](sec81.md#def-8.1.3)）；把梯度成本从 $2d$ 次前向压到约 $3\sim4$ 次前向，是「科学也能用梯度」的前提（[例 8.1.2](sec81.md#ex-8.1.2)） | 把「科学 AI」当成「把大模型套到物理上」；以为数据够多就不需要归纳偏置；把「能反传」当成「梯度可信」 |
| **[8.2 蛋白质与分子结构预测](sec82.md)** | 序列里的什么信息能定出三维结构？端到端方法的关键部件是什么？ | 共进化（同源序列协同突变）携带**接触**信息，是端到端方法的**信息源**；但两两互信息分不开「直接接触」与「经由第三位点的传递」（[定理 8.2.1](sec82.md#thm-8.2.1)）；四个部件 = MSA 与配对表示 / Evoformer 式迭代 / 等变结构模块 / FAPE（[方法 8.2.1](sec82.md#method-8.2.1)）；等变管整体位姿、FAPE 管局部几何；RMSD / GDT-TS / lDDT 各管一段、不可互替（[定义 8.2.5](sec82.md#def-8.2.5)） | 以为「折叠问题已解决」；把 pLDDT 当功能正确性的证据；用静态单点结构讨论动态构象与复合物 |
| **[8.3 分子与材料设计](sec83.md)** | 机器学习势函数凭什么快数个数量级？快到哪里就不能信？ | 快的两层来源 = **局部能量分解** $E=\sum_iE_i$（代价降到 $O(Nk)$ 的近似线性）+ **一次前向替代一次自洽场求解**（[定义 8.3.2](sec83.md#def-8.3.2)、[例 8.3.2](sec83.md#ex-8.3.2)）；力必须由 $F=-\nabla E$ 导出，否则破坏保守性（[例 8.3.1](sec83.md#ex-8.3.1)）；能力上限 = 训练分布覆盖，**适用域声明是交付物**（[方法 8.3.2](sec83.md#method-8.3.2)）；GNoME 的「新」是**对判据敏感的结论**（[思考 8.3.1](sec83.md#think-8.3.1)）；生成式设计三关 = 有效性 / 可合成性 / 稳定性（[定义 8.3.3](sec83.md#def-8.3.3)） | 拿势函数去跑未覆盖的元素与极端构型；把「生成得像分子」当成「能合成」；把候选数量当成已验证的新材料数 |
| **[8.4 偏微分方程与仿真加速](sec84.md)** | 四类做法各在学什么？PINN 的边界在哪？ | 代理模型学「某参数下的解」、降阶模型学低维子空间、神经算子学**算子本身**（FNO 频域截断 / DeepONet 分支-主干，[定义 8.4.2](sec84.md#def-8.4.2)）、PINN 把方程残差写进损失（[定义 8.4.3](sec84.md#def-8.4.3)）；PINN 在**反问题与稀疏数据**上有效、在**正向高精度**上常不敌成熟求解器，机制是损失项梯度病态与 NTK 特征值不平衡（[方法 8.4.2](sec84.md#method-8.4.2)）；可微分仿真的梯度必须先做数值校验（$h^\star\sim\varepsilon^{1/3}$，[例 8.4.4](sec84.md#ex-8.4.4)） | 以为 PINN 是「不要数据的通用求解器」；以为「残差下降 = 解对了」；把「加速」与「可微」混成一件事 |
| **[8.5 气候与地球科学](sec85.md)** | 数据驱动预报与数值模式是什么关系？多步预报为什么会崩？ | 传统管线四段 = 资料同化 / 动力核心 / 物理参数化 / 集合与后处理（[方法 8.5.1](sec85.md#method-8.5.1)），参数化是混合路线最自然的落点；与物理模式的关系分**替代 / 混合 / 加速**（[方法 8.5.3](sec85.md#method-8.5.3)）；核心困难是**多步误差累积**与**训练—推理分布差异**（$e_{k+1}\approx J_{\mathcal F}e_k+\delta_k$，[定义 8.5.2](sec85.md#def-8.5.2)）；评测必须写清口径、RMSE 与 ACC 并列（[例 8.5.3](sec85.md#ex-8.5.3)） | 把「秒级出报」当成「预报更准」；用单步误差代替多步表现；用平均指标掩盖极端事件与长时效 |
| **[8.6 科学发现的范式：拟合与理解](sec86.md)** | 能预测就等于掌握机制吗？AI 在工作流里站哪个位置？ | 「理解」分三层：预测性 / 机制性 / 可干预性（[定义 8.6.1](sec86.md#def-8.6.1)）；**外推三判据** = 分布外 / 尺度 / 干预（[定义 8.6.2](sec86.md#def-8.6.2)）；AI 辅助发现 = 搜索 + 验证器，验证器硬度决定产出能否被接受为发现（[方法 8.6.2](sec86.md#method-8.6.2)）；AI 强在生成与筛选、弱在**结论判定**（[方法 8.6.4](sec86.md#method-8.6.4)） | 把榜上分数当外推证据；把 AI 提出的表达式当定律；用同一个模型（或同一批数据）验证自己的输出 |

> **一条主线**：因为科学的每一次试错都贵得离谱（[8.1](sec81.md) 的三特点 → 标签稀缺），所以要把「实验试错」换成**可微分推断**；这需要两把钥匙——**把先验写进结构**（对称性 → 8.2 的等变与 FAPE、局部性 → 8.3 的局部能量分解、几何一致性与方程 → 8.4 的算子与残差损失、守恒 → 8.5 的三类关系）与**把过程变可微**（端到端结构预测、$F=-\nabla E$、可微分仿真、把方程写进损失）。但梯度只在它被验证过的范围内可信（势函数的适用域、PINN 的软约束、仿真器的不可微点），所以六节最终都收在同一个问题上：**它在哪个范围内可信、我用哪条独立证据证明它没有越界**（[8.6](sec86.md) 的外推三判据 + 决策表）。

## 三句话带走

1. **免费标签不是无代价标签。** 结构、物理与方程确实能造标签（[方法 8.1.1](sec81.md#method-8.1.1) 的三张配方），但误差会从标注者转移到生成器：DFT 的泛函误差、仿真的近似、数值格式的离散误差都会进训练数据——所以验证必须来自**独立来源**（实验 / 观测 / 更高精度计算）。
2. **先验是外推的唯一凭据。** 等变网络在新朝向下自动正确、局部能量分解对更大体系自动成立、守恒约束不让误差在守恒方向累积；反过来，只有大数据而没有物理先验的模型，外推行为完全由数据覆盖决定——**分布内无敌，分布外没有理由正确**。
3. **把「形成候选」与「判定结论」分开。** 模型强在生成与筛选，判定需要外部世界的反馈（实验、观测、形式证明）。分布内筛选可以当计算器，分布外只能当假设生成器，安全 / 健康 / 环境决策必须回到实验与专业评审（[方法 8.6.4](sec86.md#method-8.6.4)）。
