# 8.5 气候与地球科学

地球系统是典型的「高维 + 昂贵 + 缺标签」：状态向量动辄上亿（三维大气 / 海洋网格，含温度、风场、湿度、位势等多层变量），传统数值天气预报（numerical weather prediction, NWP）要靠超算运行；而卫星、雷达、探空与**再分析**（reanalysis，把观测与模式融合生成的连续历史场）又提供了海量历史数据，天然适合数据驱动方法。

近年的公开工作（GraphCast、Pangu-Weather、FourCastNet、Aurora 一类）表明：用图神经网络或 Transformer 在再分析数据上训练，可以在**推理速度**上比传统数值模式快几个数量级（秒级出报 vs 分钟到小时级），同时在若干中短期指标上达到与业务模式可比的水平（**具体指标与对照口径以各篇原始论文与官方评测为准，需核实**）。这是 AI for Science 目前最成功的落地方向之一。

但这一节的写法必须避开两个陷阱：一是把「快」当成「准」，二是把「平均误差好看」当成「预报有用」。真实的气象预报业务关心的是**多步 rollout 的误差累积**、**极端事件**、**与业务模式的同口径对照**，以及**训练分布之外的气候外推**。这一节按「传统管线 → 数据驱动模型 → 误差累积与分布差异 → 评测口径 → 外推挑战」推进，并把每一项都落到可检查的指标上。

## 传统数值预报管线

### 8.5.1 从观测到预报：四段管线与各自的代价 {#sec-8.5.1}

::: method 传统数值预报管线的四段（数据驱动方法可以从哪一段切进来） {#method-8.5.1}
| 段 | 做什么 | 为什么贵 | 数据驱动可切入的位置 |
|:--|:--|:--|:--|
| **① 观测与资料同化**（data assimilation） | 把分布不均、带噪、不同时刻的观测融合成一个**物理一致的初始状态**（分析场） | 需要求解一个巨大的变分优化问题（如四维变分），每次分析都要跑多次模式 | 用网络做快速同化 / 用网络订正观测偏差（混合路线） |
| **② 动力核心**（dynamical core） | 在网格上离散求解大气运动方程（预报方程），做时间积分 | 高分辨率下时间步长受稳定性限制，算力随分辨率急剧增长 | 用**代理模型**替换部分算子（加速），或用数据驱动模型整体替代（替代） |
| **③ 物理参数化**（parameterization） | 表达网格无法解析的过程：辐射、对流、云微物理、边界层湍流 | 参数化是**经验物理**，含大量近似与调参；也是模式误差的主要来源 | 用网络学参数化（学习子网格闭合），是混合路线最成熟的位置 |
| **④ 集合与后处理** | 用多个扰动初始场 / 多模式做集合预报，刻画不确定性；再做统计后处理 | 每个成员都要跑一整条管线，成本乘以成员数 | 用一次性前向生成大量成员（数据驱动模型推理便宜，见 [8.5.3](#sec-8.5.3)） |

**关键提醒**：这条管线不是「物理 vs 学习」的二选一。**第 ① 与第 ③ 段本身就是「用可用的物理经验近似未知过程」，与机器学习做的事情性质相同**——区别只在于参数化用解析形式与经验系数，机器学习用可训练函数。
:::

::: intuition 为什么「物理参数化」是理解混合路线的钥匙
一个分辨率 $0.25^\circ$ 的全球模式，其网格单元约 $25\ \text{km}$ 见方，而雷暴单体的尺度只有几公里、云滴更小。**这些过程无法被网格解析**，只能「用一个公式近似它对大尺度的影响」——这就是参数化。它的形式来自物理推理（例如对流上升、辐射传输），但其中的系数往往靠经验或拟合调定。

由此有两点直接推论：

1. **参数化是模式误差的主要来源之一**，因为它是「用粗网格变量近似细网格过程」，本质上是一个**从大尺度量到次网格效应的映射**——这正是监督学习擅长的形式（数据里的小尺度过程可以通过高分辨率模拟或观测统计得到）。
2. **混合（hybrid）路线最自然的落点就是参数化**：保留动力核心的物理守恒与可解释性，用网络替换或订正参数化方案，这就是「物理模式 + 学习成分」的典型形态（[@method-8.5.2]）。
:::

## 数据驱动模型

### 8.5.2 四个代表模型和它们与物理的关系 {#sec-8.5.2}

::: def 定义 8.5.1 · 数据驱动预报的任务形式 {#def-8.5.1}
把大气状态写成场 $\boldsymbol s_t$（多个变量 × 多个气压层 × 经纬网格），预报任务是学一个**推进映射**
$$f_\theta:\ (\boldsymbol s_{t-\Delta},\ \boldsymbol s_{t})\ \mapsto\ \boldsymbol s_{t+\Delta},$$
然后用它**自回归**（autoregressive）地推进多步：
$$\hat{\boldsymbol s}_{t+k\Delta}=f_\theta^{k}\bigl(\boldsymbol s_{t-\Delta},\boldsymbol s_t\bigr),$$
其中 $k$ 步 rollout 意味着把 $f_\theta$ 反复调用 $k$ 次。训练目标通常是**预报误差的加权平方 / 绝对误差**（在再分析数据上），例如
$$\mathcal L(\theta)=\sum_{k}\sum_{\text{变量 }v}\sum_{\text{层 }l}w_{v,l}\,\bigl\lVert \hat{\boldsymbol s}^{(v,l)}_{t+k\Delta}-\boldsymbol s^{(v,l)}_{t+k\Delta}\bigr\rVert ,$$
权重 $w_{v,l}$ 反映各变量 / 层的重要性与尺度差异（**具体权重设计随工作而异**）。

**两个工程要点**：① 输入用**两个时刻**（$t$ 与 $t-\Delta$）而不是单帧，等于给网络一个「趋势」信息，弥补纯静态输入无法判断运动方向的问题；② 输出与输入同形状，因此可以立即喂回自己继续推——这正是误差累积的来源（[8.5.3](#sec-8.5.3)）。
:::

::: method 四个公开代表模型的做法对照 {#method-8.5.2}
| 模型 | 架构要点 | 训练数据 | 主要主张 |
|:--|:--|:--|:--|
| **GraphCast**（2023，*Science*；预印本 arXiv:2212.12794） | 图神经网络，把经纬网格建成多分辨率图；输入两个时刻，输出 6 小时后的全场 | 再分析数据（ERA5 类） | 在多项中短期指标上达到或超过同期业务模式（**以原文与官方评测为准，需核实**） |
| **Pangu-Weather**（2023，*Nature*；预印本 arXiv:2211.02556） | 三维 Earth-specific Transformer；为不同预报时效训练专用模型（不同步长的模型组合使用） | 再分析数据 | 用较大的时间步长减少自回归步数，从而降低累积误差 |
| **FourCastNet**（2022，arXiv:2202.11214） | 自适应傅里叶神经算子（AFNO），把 [8.4](sec84.md) 的谱方法思路搬到预报 | 再分析数据 | 高分辨率、快速集合预报 |
| **Aurora**（2025，*Nature*；预印本 arXiv:2405.13063） | 三维 Swin Transformer 大模型，**大规模预训练 + 针对任务微调**（含开放权重） | 多来源（大气、海浪、空气质量等） | 「基础模型 + 微调」范式在多种地球系统任务上复用 |

**共同点**：都以再分析数据为主要训练源；都做自回归多步预报；都采用「场到场」的映射（形状保持不变），因此可以直接接在传统同化的输出上（初始场来自[@method-8.5.1] 的第 ① 段）。
:::

::: intuition 为什么地球网格对图网络与 Transformer 友好
三个性质让这套数据「对现代架构友好」：

1. **规则、稠密的网格**：经纬网格是规则的（可用卷积 / 窗口注意力），转化到图之后每个节点邻居数可控；
2. **强局部性与近似平移不变**：大气演化以局地平流与波动传播为主，远距离影响通过中间区域逐步传递——这与卷积 / 局部注意力的归纳偏置高度匹配（[第 3 讲](../lec03/sec33.md) 的平移不变思想在这里再次成立）；
3. **场量之间的物理耦合是稳定的**：温度、风、湿度、位势之间的约束关系在时间与空间上都相当规律，网络可以从数据中学到（这比图像生成容易，因为映射的「物理文法」固定）。

**但请注意**：地球网格的一个技术细节会带来麻烦——**极点附近经纬网格严重收敛**（同样经度间隔对应的实际距离趋近于零）。图网络与窗口注意力在这类非均匀采样下需要专门处理（如多分辨率图、球面网格或特殊卷积核），这是这类模型工程上不可忽略的一环。
:::

::: method 数据驱动模型与物理模式的三类关系 {#method-8.5.3}
不要用「替代 vs 不被替代」的二分法讨论，实际有三种关系：

| 关系 | 做什么 | 优点 | 代价与风险 | 例子（公开方向） |
|:--|:--|:--|:--|:--|
| **替代**（emulation / replacement） | 用数据驱动模型整体替换「同化之后到预报」的全链路 | 推理极快、可大量生成集合成员；不依赖业务模式的代码栈 | 失去物理模式的守恒保证；外推与极端事件风险高；难以给出「为什么」的物理解释 | GraphCast / Pangu-Weather 类端到端预报 |
| **混合**（hybrid） | 保留物理动力核心，用网络嵌在参数化 / 订正 / 同化环节 | 保留守恒与可解释的骨架，只用学习补足已知弱点 | 接口与训练更复杂；需要证明「学到的订正」在新气候态下仍成立 | 学参数化、学习偏差订正（模式输出统计后处理） |
| **加速**（acceleration） | 用网络代理管线中的某个昂贵算子（如辐射传输、化学） | 精度可测（局部算子比对容易）、风险受限（不改变整体骨架） | 加速幅度受限于被替换算子占比（阿姆达尔定律式的约束） | 用网络替代辐射 / 参数化的部分计算 |

**判断建议**：从**加速**开始（风险最小、收益可测），进入**混合**（需要更强的验证能力），只有在有充分的分布外与极端事件证据时才考虑**替代**——因为替代意味着把整条物理守则链交给一个纯数据模型。
:::

### 8.5.3 多步误差累积与训练—推理分布差异 {#sec-8.5.3}

::: def 定义 8.5.2 · 自回归 rollout 与暴露偏差 {#def-8.5.2}
**训练时的输入**若用**真值**（$\boldsymbol s_{t-\Delta},\boldsymbol s_t$ 都来自数据），叫 teacher forcing；**推理时**必须用模型自己的输出当输入（$\hat{\boldsymbol s}_{t+k\Delta}$），这条链就是 **rollout**。

两者的差别带来**暴露偏差**（exposure bias）：模型在训练时从未见过「含自己误差的输入」，而在推理时每一步的输入都带着累积误差，**输入分布随步数逐渐偏离训练分布**（这是一个典型的分布偏移 / train-test mismatch 问题）。

**误差累积**：记 $e_k=\hat{\boldsymbol s}_{t+k\Delta}-\boldsymbol s_{t+k\Delta}$，一阶传播为
$$e_{k+1}\approx J_{\mathcal F}\,e_{k}+\delta_k,$$
其中 $J_{\mathcal F}$ 是单步映射的雅可比矩阵、$\delta_k$ 是模型自身的单步误差。若 $\lVert J_{\mathcal F}\rVert\gt1$（误差放大方向），误差被逐步放大；若 $\lt1$，误差被衰减。
:::

::: intuition 为什么「喂真值训练、喂自己推理」是根本困难
把这件事想成一条「自我实现的回路」：

- 训练时，模型看到的是**干净的**（真值）历史，它的任务只是「从干净历史推下一步」，这比真实任务容易得多；
- 推理时，模型看到的是**带瑕疵的**历史（自己造的），而且瑕疵会**改变输入的统计性质**（例如过度平滑、能量偏少、小尺度结构缺失）。网络对这些「不自然」的输入没有训练经验，于是产生的误差往往**比训练误差更具系统性**（典型表现：预报随步数增加变得过于平滑、极端值被抹平）。

**这解释了数据驱动预报最常见的失效形态**：平均误差看起来温和，但**方差（极值）系统性偏小**、**小尺度结构被过度平滑**。对业务而言这恰恰是最要命的部分，因为预报的价值大量集中在极端事件上（[8.5.4](#sec-8.5.4) 的尾部讨论）。
:::

::: method 缓解误差累积的五种做法（公开工作中常见的组合） {#method-8.5.4}
| 做法 | 机制 | 代价 | 注意点 |
|:--|:--|:--|:--|
| **多步 / rollout 训练** | 训练时也展开 $k$ 步、用自身预测当输入，直接优化多步误差 | 训练显存与时间随 $k$ 增长；梯度穿过自身预测易不稳（可截断） | 训练目标要与评测口径一致（评测看 5 天就不该只训 1 步） |
| **噪声注入** | 训练时往真值输入里加噪声，制造「不完美历史」 | 引入额外超参（噪声量级） | 噪声的统计应与模型的误差分布可比（不然反而失真） |
| **双时刻输入** | 输入 $t-\Delta$ 与 $t$ 两帧，提供趋势信息 | 无额外代价（多一路输入） | 只能缓解「方向不清」，不能解决累积问题 |
| **多模型 / 多步长组合** | 为不同预报时效训练不同模型，用大时间步减少 rollout 次数 | 训练与维护成本上升 | 不同步长模型之间要**保持一致**，否则衔接处不连续 |
| **集合化** | 用多个扰动输入 / 随机模型生成成员，输出分布而非单点 | 推理成本 × 成员数（但相对数值模式仍便宜） | 集合的**离散度校准**要检验（过小 → 低估风险） |

**共同目标只有一个**：让推理时见到的输入分布，尽量接近训练时见到的分布。**这也是 [8.6](sec86.md) 的外推三判据在预报任务上的具体化身。**
:::

::: ex 例 8.5.1 · 手算误差放大与「误差翻倍时间」 {#ex-8.5.1}
设某预报模型的单步误差按一阶线性模型放大，放大因子 $\lVert J_{\mathcal F}\rVert=g$ 为常数、单步新增误差为 0（只看已有误差如何传播），初始误差 $e_0$。

1. 写出 $k$ 步后的误差 $e_k$；
2. 取 $g=1.05$、步长 $\Delta=6$ 小时，求误差翻倍所需步数与对应的预报时效；
3. 取 $g=0.98$ 重复计算，并说明两种情形的实践含义（提示：这是「玩具放大率」，真实大气的误差增长随变量、尺度与天气形势变化，**具体数值需核实**）。

::: proof 解
**① 递推求解。** 由 $e_{k+1}=g\,e_k$ 直接得
$$e_k=g^{k}\,e_0 .$$

**② $g=1.05$ 的情形。** 令 $g^k=2$，得
$$k^\star=\frac{\ln 2}{\ln 1.05}\approx\frac{0.6931}{0.04879}\approx14.2\ \text{步}.$$
对应预报时效 $14.2\times6\ \text{h}\approx85\ \text{h}\approx3.5$ 天。也就是**误差大约每 3.5 天翻一倍**。参照：大气运动的可预报性上限通常被概括为两周左右（**该量级的具体数字随变量与尺度差异很大，需核实**），因此这个玩具放大率给出的「翻倍时间」与业务经验在同一量级，说明模型抓住了正确的机制。

**③ $g=0.98$ 的情形。**
$$k^\star=\frac{\ln 2}{\ln 0.98}=\frac{0.6931}{-0.02020}\approx-34\ (\text{无解}) .$$
因为 $g\lt1$ 时 $e_k=g^ke_0$ 单调**衰减**：误差会以半衰期 $k_{1/2}=\ln 0.5/\ln 0.98\approx34$ 步（约 8.5 天）衰减到一半，永远不会翻倍。

**④ 实践含义。** 两种情形的差别不是「模型好坏」，而是**动力学性质**：

- $g\gt1$（误差放大）：预报存在**可预报性上限**——无论模型多准，超过某个时效后误差会增长到与气候态变率同量级，此时预报不再提供信息。所以**「延长预报时效」这件事本身有物理上限**，模型改进只能推迟到达上限的时间（例如把 $g$ 从 $1.05$ 降到 $1.02$，翻倍时间从 3.5 天拉到约 8.75 天：$0.6931/0.0198\approx35.0$ 步，每步 6 小时，$35\times6/24=8.75$ 天）。
- $g\lt1$（误差衰减）：系统在该尺度上是耗散 / 稳定的，误差自然被抹掉。**如果观测到「误差不增长」，先确认它不是因为模型过度平滑**（把预报都变成气候平均，误差自然不会增长，但这样的预报毫无价值）。$\blacksquare$
:::
:::

::: ex 例 8.5.2 · 诊断训练—推理分布差异 {#ex-8.5.2}
某数据驱动预报模型报告单步（6 小时）RMSE 很低，但业务试用后被指出「5 天后预报过于平滑、极端值偏小」。请设计一个三步诊断实验，区分下列三种可能原因：① 训练不足 / 模型容量不够；② **暴露偏差**（推理输入分布偏移）；③ 损失函数与评测口径不一致（如只训单步、权重偏向平均误差）。

::: proof 解
**第 ① 步：把误差分解到不同步数与不同统计量上。** 对同一批初始场，同时测：
- **逐时效 RMSE**（1、3、5、7、10 天）——看误差随步数的增长曲线（[@ex-8.5.1] 的放大率）；
- **方差 / 极值指标**：预报场的方差与观测（分析场）方差之比、分位数（如第 99 百分位）对比、以及**功率谱**（小尺度能量是否被抹掉）。
判据：若 1 天误差已偏高 → 更可能是 ①；若 1 天尚可但方差随步数迅速收缩、谱在小尺度系统性偏低 → 指向 ② 或 ③。

**第 ② 步：teacher forcing 与 free running 对照（关键实验）。** 用同一批初始场跑两个模式：
- **A：teacher forcing 推理**——每一步都把**真值**喂回输入（只推一步，然后重置输入）；
- **B：free running 推理**——正常 rollout，喂自己的输出。

若 A 的误差显著低于 B（差距随步数扩大），就**直接证明**了暴露偏差的存在（②）。若 A 与 B 都差，则问题在模型本身或训练目标（①③）。

**第 ③ 步：一致性检查（损失 vs 评测）。** 检查训练损失的形式：若训练只在单步上做**平均误差**最小化，则模型的「最优策略」本来就是给出条件均值——**条件均值必然是平滑的、极值偏小的**（这是统计事实，不是 bug）。此时应当：
- 把训练目标改为**多步 rollout 损失**（与评测时效一致）；
- 引入**分布型损失**或对抗 / 扩散式建模（在需要刻画极值与不确定性时）；
- 或至少报告「均值型指标 + 分布型指标」两套，不以 RMSE 单独作为验收。

**结论判定表**：

| 观察 | 最可能原因 | 处置 |
|:--|:--|:--|
| A 与 B 都差、1 天误差已高 | ① 训练不足 / 容量不够 | 加数据、加容量、检查数据质量与预处理 |
| A 明显优于 B、差距随步数扩大 | ② 暴露偏差 | rollout 训练、噪声注入、双时刻输入（[@method-8.5.4]） |
| A 与 B 接近，但方差与极值系统性偏低 | ③ 损失与口径不一致 | 改多步损失、引入分布型目标、双口径报告 |

**注意这三类原因可以叠加**，诊断的意义在于**确定优先级**，而不是找唯一元凶。$\blacksquare$
:::

### 8.5.4 评测口径：RMSE、ACC 与业务对照 {#sec-8.5.4}

::: def 定义 8.5.3 · RMSE 与异常相关系数 {#def-8.5.3}
**RMSE（加权均方根误差）**：把预报 $f_i$ 与真值（通常是分析场）$o_i$ 在各格点 / 变量 / 层次上逐点比较，带面积或质量权重 $w_i$：
$$\mathrm{RMSE}=\sqrt{\frac{\sum_i w_i\,(f_i-o_i)^2}{\sum_i w_i}} .$$

**ACC（异常相关系数，anomaly correlation coefficient）**：先减去**气候态**（该地点、该日期、该层次的气候平均值 $\bar c_i$）得到「异常」，再算预报异常与分析异常的相关系数：
$$\mathrm{ACC}=\frac{\sum_i w_i\,(f_i-\bar c_i)\,(o_i-\bar c_i)}{\sqrt{\sum_i w_i\,(f_i-\bar c_i)^2}\ \sqrt{\sum_i w_i\,(o_i-\bar c_i)^2}} .$$
**两点必须记住**：① ACC 是**尺度不变量**——把整个预报场乘一个常数，ACC 不变；② RMSE 是尺度敏感的——它同时惩罚「方向错」与「幅度错」。
:::

::: intuition RMSE 与 ACC 各自在说什么
把预报误差分成两类：**位置 / 形态误差**（把脊线放错地方）与**幅度误差**（强度偏弱 20%）。

- **ACC 只对前者敏感**：它衡量「异常的空间形态是否一致」。一个预报只要形态对，即使整体偏弱一半，ACC 仍可以很高。
- **RMSE 对两者都敏感**：强度偏差直接进入分母。所以 RMSE 是「业务上更贴近后果」的指标（风场偏弱 20% 对发电、航运调度影响巨大），而 ACC 更多用于**诊断模式是否抓住形势**。

**业务报告惯例**是并列给出两者（以及不同预报时效上的曲线），并且**必须说明对照对象**：同一个模型与「气候态」对照、与「持续性预报（persistence）」对照、与「业务模式」对照，会得到完全不同的结论。与业务模式对照时，通行做法是**在同一初始场（同一分析场）、同一预报时效、同一变量与层次、同一评分定义**下比较（本节把这条写成硬性要求）。
:::

::: ex 例 8.5.3 · 手算一次 ACC 与 RMSE，看清两者的分歧 {#ex-8.5.3}
考虑一个极简的 4 格点、单变量、单层次的情形（气候态取全 0，简化为「异常即原值」）：

- 分析 / 真值异常：$o=(2,\ 1,\ -1,\ 0)$
- 预报 A：$f_A=(1.8,\ 0.9,\ -1.1,\ 0.1)$（形态接近、幅度略小）
- 预报 B：$f_B=(2.4,\ 1.2,\ -1.2,\ 0.0)$（形态完全一致但幅度放大 20%，即 $f_B=1.2\,o$）

等权（$w_i=1$），请分别计算 ACC 与 RMSE，并解释结果的实践含义。

::: proof 解
**基本量。** $\sum_i o_i^2=4+1+1+0=6$，$\sqrt{\sum o_i^2}=\sqrt6\approx2.449$。

**预报 A。**
$$\sum_i o_if_{A,i}=(2)(1.8)+(1)(0.9)+(-1)(-1.1)+(0)(0.1)=3.6+0.9+1.1=5.6,$$
$$\sum_i f_{A,i}^2=1.8^2+0.9^2+1.1^2+0.1^2=3.24+0.81+1.21+0.01=5.27,\qquad \sqrt{5.27}\approx2.296,$$
$$\mathrm{ACC}_A=\frac{5.6}{2.449\times2.296}=\frac{5.6}{5.623}\approx0.996 .$$
误差平方和：$(2-1.8)^2+(1-0.9)^2+(-1+1.1)^2+(0-0.1)^2=0.04+0.01+0.01+0.01=0.07$，
$$\mathrm{RMSE}_A=\sqrt{0.07/4}=\sqrt{0.0175}\approx0.13 .$$

**预报 B（$f_B=1.2\,o$）。**
$$\sum_i o_if_{B,i}=1.2\sum_i o_i^2=1.2\times6=7.2,\qquad \sqrt{\sum_i f_{B,i}^2}=\sqrt{1.44\times6}=1.2\sqrt6\approx2.939,$$
$$\mathrm{ACC}_B=\frac{7.2}{2.449\times2.939}=\frac{7.2}{7.197}\approx1.000 .$$
误差平方和：$(0.4)^2+(0.2)^2+(0.2)^2+0^2=0.16+0.04+0.04=0.24$，
$$\mathrm{RMSE}_B=\sqrt{0.24/4}=\sqrt{0.06}\approx0.245 .$$

**结果与含义。** B 的 ACC **更完美**（1.000 > 0.996），但 RMSE **几乎差一倍**（0.245 vs 0.130）：

| 预报 | ACC | RMSE | 读法 |
|:--|:--|:--|:--|
| A | 0.996 | 0.13 | 形态略偏、幅度接近真值 → 日常使用更可靠 |
| B | 1.000 | 0.25 | 形态完美、幅度放大 20% → 「形势对但强度错」 |

**结论**：单看 ACC 会得出「B 更好」的错误结论；单看 RMSE 会忽略「形态是否抓对」。**两个指标必须并列，并且要写明业务关心的到底是形态还是幅度。** 这也是为什么这一节反复强调「评测口径要写清」——指标不是中立的，它内嵌了对「什么算好」的定义。$\blacksquare$
:::
:::

::: method 指标 → 衡量什么 → 会怎么骗人（评测清单） {#method-8.5.5}
| 指标 / 做法 | 衡量什么 | 会怎么骗人 | 必须配什么 |
|:--|:--|:--|:--|
| **RMSE**（同层次 / 变量 / 时效） | 幅度 + 形态的综合误差 | 被大尺度、大振幅变量主导；对稀疏但重要的极端区域不敏感 | 分层 / 分变量报告；与 ACC 并列 |
| **ACC** | 异常的空间形态一致性 | 尺度不变 → 强度系统性偏弱也能得高分；对局地细节不敏感 | 一起报告偏差（bias）与方差比 |
| **单步误差** | 一步预测精度 | 与多步表现可以几乎无关（[@ex-8.5.2]） | 逐时效误差曲线 + 多步 rollout 指标 |
| **平均指标** | 整体表现 | 掩盖尾部：极端事件可能极差而平均值良好 | 极端事件专项指标（见下） |
| **极端事件指标** | 尾部与灾害相关表现 | 样本极少 → 方差大、结论不稳；阈值选择影响结论 | 明确事件定义（阈值 / 区域 / 时段）、给样本数与置信区间 |
| **集合离散度** | 不确定性刻画是否合理 | 离散度过小 → 低估风险；过大 → 预报无用 | 可靠性图 / 排序直方图 + 覆盖率检验 |
| **与业务模式对照** | 相对水平 | 初始场、口径、时效、版本不同 → 不可比 | 同初始场、同口径、同期、注明模式版本 |

**一句话**：**没有「哪个指标最好」，只有「这套指标是否覆盖了你关心的后果」。** 气象预报的后果集中在**极端事件**与**长时效**，因此这两块必须单列指标，不能藏在平均值里。
:::

### 8.5.5 外推挑战：非平稳气候、极端事件与下尺度 {#sec-8.5.5}

::: think 为什么气候外推比天气预报更难 {#think-8.5.1}
天气预报在形式上是「外推未来」，但它有一个隐含的稳定条件：**统计规律与物理常数在预报时效内近似不变**（几周内温室气体浓度、海温格局的缓慢变化可以当常数）。气候问题没有这个条件：

- **训练分布本身在漂移**：温室气体浓度、冰盖范围、海温格局在几十年尺度上持续变化，训练数据（历史再分析）覆盖的是**一个正在移动的分布**。一个在历史气候上表现良好的模型，可能在未来气候态上失效——这不是模型「过拟合」，而是任务本身非平稳。
- **没有可对照的「真值未来」**：要评估模型在 2050 年气候上的表现，要么等，要么用**气候模式模拟**产生的未来场景作为代理真值（但那些模拟本身有模型误差）。
- **极端事件是尾部**：最需要准确的部分（热浪、极端降水、强台风）在训练数据中出现次数最少，统计上最难学好（[8.6](sec86.md) 的外推判据正是为这类问题准备的）。

**可操作的做法**：① 用「过去某个时段训练、后续时段测试」的**时间外推**协议而不是随机切分（这条是气候 ML 的常规要求）；② 明确报告模型在**统计变化趋势**上的表现（例如预测的全球平均升温趋势是否正确）；③ 把「模型输出的未来场景」当作**条件于假设的推演**，其可信度取决于它是否复现了已知物理约束（守恒、能量平衡）。
:::

::: intuition 下尺度：与超分辨率同源，但更苛刻
**下尺度**（downscaling）把粗网格预报（如 $25\ \text{km}$）细化到局地尺度（如 $1\ \text{km}$），思想上与 [第 3 讲](../lec03/overview.md) 的超分辨率同源：都是从低分辨率输入生成高分辨率细节。但它比图像超分辨率苛刻，原因有二：

1. **极值主导价值**：图像超分辨率错一点纹理无伤大雅；下尺度如果抹平了局地暴雨的峰值，预报就失去了主要价值。而**极值恰恰是训练数据里最少的部分**（这是典型的长尾问题）。
2. **一致性要求**：细化后的场必须与粗网格场**物理一致**（质量、能量、水汽收支不能凭空改变），否则下游的水文、能源模型会得到自相矛盾的输入。纯图像式的超分辨率损失（像素级 L1/L2 或对抗损失）**不保证**这一点。

因此下尺度任务的评测必须包含：极值指标（分位数、超阈值频率）、收支一致性检查、以及**在未参与训练的地形 / 气候区**上的泛化测试（这条与气候非平稳是同一种担忧）。
:::

::: errata 本节的六个常见误解
1. **「秒级出报 = 预报更准」**：推理速度与预报精度是两件事。数据驱动模型的优势首先在**速度与集合规模**（一次前向很便宜，可生成大量成员）；精度必须在**同一初始场、同一口径**下与业务模式逐时效对照（[@method-8.5.5]）。
2. **「平均 RMSE 更好就说明模型更好」**：平均值会掩盖尾部。极端事件、爆发性系统、快速加强的台风恰恰是最有价值也最容易失败的部分，必须单列指标与样本计数。
3. **「单步误差小就等于多步可用」**：训练—推理分布差异（[@def-8.5.2]）会让多步表现显著劣于单步；评测必须做 rollout（[@ex-8.5.2] 的第 ② 步）。
4. **「数据驱动模型学到的是物理定律」**：它学到的是**在训练分布内的统计映射**。地图、场量与耦合关系可能被很好地拟合，但这不等于掌握了动力学机制（[8.6](sec86.md) 会给出三条区分判据）。在气候非平稳的场景下，这个区别有实际后果。
5. **「有了 AI 就不需要资料同化」**：初始场的质量决定预报上限，而同化是把**不规则、带噪、异步**观测变成物理一致初值的过程。目前数据驱动模型多数直接消费同化产物（分析场），因此同化仍是管线中最关键的一环（[@method-8.5.1] 第 ① 段）。
6. **「集合预报只是多跑几次」**：集合的意义在于**校准的不确定性**（离散度与误差匹配）。若成员之间几乎相同（离散度过小），或成员差异与真实误差不匹配，集合就会系统性低估风险——这比单点预报的误导性更强，因为它看起来「有不确定性」。
:::

::: method 即时自测 · 8.5 {#method-8.5.6}
**Q1** 写出数据驱动预报的推进映射与 $k$ 步 rollout 的定义，并说明为什么训练时通常输入**两个时刻**而不是一帧。

**Q2** 误差放大因子 $g=1.02$、步长 6 小时，误差翻倍需要多少步、对应多少天？把它与 $g=1.05$ 的情形（[@ex-8.5.1]）比较，说明「把 $g$ 从 1.05 降到 1.02」在业务上意味着什么。

**Q3** 某模型报告「与业务模式相比，全球平均 RMSE 低 5%」。请写出三条你必须追问的问题，把「它真的更好」与「口径造出的好看」区分开。

::: sol 参考要点
**Q1** 推进映射：$f_\theta:(\boldsymbol s_{t-\Delta},\boldsymbol s_t)\mapsto\boldsymbol s_{t+\Delta}$；$k$ 步 rollout：$\hat{\boldsymbol s}_{t+k\Delta}=f_\theta^{k}(\boldsymbol s_{t-\Delta},\boldsymbol s_t)$（把 $f_\theta$ 反复应用 $k$ 次，每一步的输入从前一步的输出取）。输入两帧是为了提供**趋势 / 运动方向**信息：单帧静态场里「正在加深的低压」与「正在减弱的低压」看起来无法区分，而两帧之差给出了这一信息（这属于工程惯例，具体做法随工作而异）。

**Q2** $k^\star=\ln 2/\ln 1.02\approx0.6931/0.01980\approx35.0$ 步，$35\times6\ \text{h}=210\ \text{h}\approx8.75$ 天。对比 $g=1.05$ 时约 3.5 天。含义：**误差翻倍时间延长了约 2.5 倍**，等价于「在同样的误差容限下多获得若干天可用预报」——这是业务上非常有价值的改进（但要注意：该放大率是**玩具模型**，真实误差增长与变量、尺度、天气形势有关，且模型改进往往同时改变单步误差 $\delta_k$，两者需要分开报告）。

**Q3** ① **对照口径**：与业务模式是否用**同一初始场（分析场）**、同一预报时效、同一变量与层次、同一评分定义、同一版本？不同版本的 IFS / 模式升级会显著改变数字。② **时空范围与分层**：是「全球平均」还是分区域 / 分纬度带 / 分气压层？全球平均的改善常常由数据密集、变率小的区域主导；对流活跃区、极区、以及**高影响天气区**的表现需要单列。③ **尾部与多步**：极端事件的专项指标如何？逐时效（1/3/5/7/10 天）曲线是否单调占优，还是仅在个别时效上领先？有没有做**时间外推**（不同年份训练 / 测试）而非随机切分？**若三问都能给出同口径证据，才有资格说「更好」。**
:::

**本节小结**：传统数值预报是一条四段管线——**资料同化、动力核心、物理参数化、集合与后处理**（[@method-8.5.1]），其中参数化是「用近似物理表达次网格过程」，也正是混合路线最自然的落点。数据驱动模型（GraphCast / Pangu-Weather / FourCastNet / Aurora）学的是**场到场的推进映射**（[@def-8.5.1]），与物理模式的关系分**替代、混合、加速**三类（[@method-8.5.3]），判断应从风险最小的加速起步。核心困难是**多步误差累积与训练—推理分布差异**（[@def-8.5.2]），缓解手段共有五个（[@method-8.5.4]）；评测必须写清口径，**RMSE 与 ACC 并列**且单列极端事件（[@ex-8.5.3]、[@method-8.5.5]）。最后，气候外推比天气预报更难，因为**训练分布本身在漂移**——这正好把话题交给下一节：能预测，到底等不等于掌握机制？
