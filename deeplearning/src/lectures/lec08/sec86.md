# 8.6 科学发现的范式：拟合与理解

前面五节各自解决一类问题，但它们共享同一条缝：**纯数据驱动的模型擅长在训练分布内插值，而科学往往关心分布外的行为**。当模型在一个新的材料体系、更极端的温度、更长的预报时效上给出预测时，它到底是在「应用规律」，还是在「外推一个拟合」？这个问题不回答，前面所有漂亮指标都无法转化为科学结论。

这一节要把这条缝讲成三件可操作的事。**第一**，区分三种不同强度的「理解」——能预测、能说出机制、能预测干预后果，它们各自需要什么证据。**第二**，给出**外推能力的三条判据**（分布外、尺度、干预），这是本讲最可迁移的一套检验方法：任何「模型发现了规律」的声明，都可以用这三条来体检。**第三**，看 AI 在「发现」这件事上实际能做到什么——符号回归、程序搜索、数学证明三条路线的共同点是「搜索 + 可验证评分」，而验证器的强度直接决定了产出可能是发现、也可能只是拟合技巧。最后把结论压成一张决策表：**什么时候可以把模型当计算器用，什么时候必须回到实验。**

## 能预测 ≠ 掌握机制

### 8.6.1 三种不同强度的「理解」 {#sec-8.6.1}

::: def 定义 8.6.1 · 预测性、机制性、可干预性 {#def-8.6.1}
对一个科学对象（体系、过程、现象），「理解」可以分三个强度层次，**每一层都需要不同的证据**：

| 层次 | 主张 | 需要什么证据 | 典型失败模式 |
|:--|:--|:--|:--|
| **① 预测性** | 「在给定条件下我能预测输出」 | 在独立测试集上误差达标；测试分布与使用分布一致 | 分布一变就失效；预测好但说不清依赖什么 |
| **② 机制性** | 「我能说出**因果结构 / 控制关系**：哪个量通过什么方式影响哪个量」 | 可写出方程 / 交互结构；能解释已知极限与量纲；能证伪（能说出「什么样的情况下这个机制会失效」） | 把统计相关当机制；机制只在数据范围内成立 |
| **③ 可干预性** | 「我还能预测**干预**的后果：如果我改动系统的一部分（而不只是观察变化），会发生什么」 | 对**主动干预**的实验预测正确；反事实推断有依据 | 混淆「相关」与「干预」；在干预条件下失效 |

形式化地看，③ 关心的是**干预分布** $p(y\mid \mathrm{do}(x=x'))$，而 ①② 往往只涉及**观测分布** $p(y\mid x=x')$。两者在存在混杂因素时**不相等**——这正是「预测很准但不能用来做决策」的数学根源。
:::

::: intuition 三个层次的区别，用三个例子看清
- **潮汐表**：几百年前的航海者用表格预测潮汐，精度足以导航——这是①（预测性理解），但表格不解释「为什么潮汐与月相相关」。
- **牛顿引力**：既能预测位置（①），又给出机制（②：力与距离平方成反比），还能预测干预（③：如果我在某处放一个额外质量，轨道会怎么变）。
- **现代气象预报**：在时效内预测很准（①），也能说明主导机制（②：斜压不稳定、急流、水汽输送），但在③（干预）上**几乎没有证据**——我们无法也不该对大气做受控实验。所以在气候问题上，「模型预测未来」与「我们理解气候系统」之间有真实距离。

**教学要点**：日常讨论里「模型懂了」常被用来指①，这与①②③的科学含义混在一起就成了大部分争论的来源。**在写结论时先声明你说的是哪一层。**
:::

::: think 混杂与「不许干预」的领域：科学里的因果难题 {#think-8.6.1}
有些领域天然缺③的证据：天文学、气候、地球演化、流行病学（部分）、人体实验。这些领域的常见应对是：

- **自然实验 / 准实验**：寻找「自然发生的干预」（火山喷发对气候的影响、政策变动对流行病传播的影响），把观测数据当成近似干预；
- **结构因果模型与图模型**：把假设写成有向图，再检验数据是否支持该结构（哪些条件独立应成立）；
- **能替代干预的代理指标**：在某些生物医学场景中，用机制明确的中介变量（如药物靶点结合率）代替直接的临床干预。

**机器学习在这些场景里的角色是双重的**：一方面它可以更精确地估计条件关系（提高①），另一方面若不显式引入干预假设，它**不会自动给出③**。因此「模型学到的因果结构」这个说法必须附带证据说明：是来自随机化实验、准实验设计，还是仅来自观测数据的条件独立性检验（三者的可信度依次下降）。**这条纪律在 [第 7 讲](../lec07/sec74.md) 讨论「模型被用于真实决策」时同样成立。**
:::

## 外推：检验「是否真懂」的试金石

### 8.6.2 外推能力的三条判据 {#sec-8.6.2}

::: def 定义 8.6.2 · 外推能力的三条判据 {#def-8.6.2}
判断一个模型是否只是「记住了数据」，看它在下面三类**训练分布之外**的考验中的表现。三条判据互相独立，缺一条都不足以支撑「掌握了机制」的主张：

1. **分布外（out-of-distribution, OOD）**：把模型推到训练数据覆盖范围之外的同类型对象上——新的材料体系、新的地理区域、更极端的气候态、未出现过的分子骨架。**检验的是「内插能力之外的泛化」。**
2. **尺度外推（scale extrapolation）**：改变系统的规模、时长或分辨率——更大的体系、更长的模拟时间、更细的网格、更远的预报时效。**检验的是「规律是否具有尺度不变的形式」。**
3. **干预外推（interventional extrapolation）**：在系统中主动改动一个变量（或施加一个此前未出现的条件），看模型对后果的预测是否仍成立。**检验的是「模型抓到的是因果机制还是统计相关」。**

**判据 3 是最强的一条，也是最常被跳过的一条**：它需要真实的干预（实验 / 受控仿真），而不只是「另一批观测」。这也是为什么 [@def-8.6.1] 的③最难获得证据。
:::

::: method 三条判据的实验设计与读法 {#method-8.6.1}
| 判据 | 具体实验设计 | 通过意味着什么 | 失败的典型形态 |
|:--|:--|:--|:--|
| **① OOD** | 按**结构 / 时间 / 空间**切分而非随机切分：新材料体系留出、未来年份测试、未参与训练的地理区域（气候 ML 的常规要求） | 模型学到了可迁移的模式，而不只是训练样本的邻域 | 随机切分分数很高、切分一换就崩——典型的「靠邻近样本」 |
| **② 尺度** | 训练小体系 / 短时 / 粗网格，测试大体系 / 长时 / 细网格；报告各尺度下的误差曲线 | 规律形式与尺度无关（例如势函数的局部性、算子的离散无关性） | 误差随尺度单调恶化到不可用；守恒量漂移随步数线性累积（[8.4](sec84.md)） |
| **③ 干预** | 主动施加已知干预：改变一个条件做实验、在仿真里替换一个参数 / 边界、施加一个外场 | 模型可用于设计与决策（可预测干预后果） | 干预后误差跳变；或预测「过度平滑」（把干预效应平均掉，见 [8.5](sec85.md) 的暴露偏差） |

**执行顺序建议**：先 ①（成本最低，通常是数据切分方式的改变），再 ②（需要构造不同规模的测试），最后 ③（需要实验或受控仿真）。**三条都过不去的模型不等于没用**——它可能仍是一个合格的筛选器（[8.6.4](#sec-8.6.4) 的决策表）；但它的**结论不能外推**。
:::

::: ex 8.6.1 · 给一个「催化剂活性预测模型」设计外推体检 {#ex-8.6.1}
某团队训练了一个模型，输入为催化剂表面结构与反应条件，输出为活性 / 选择性（数据来自公开实验数据库 + DFT 计算）。模型在随机切分的测试集上 $R^2\gt0.9$。请按 [@def-8.6.2] 的三条判据设计三组测试，并写明每组测试的**判据（通过 / 失败的分界）**与你会如何解释结果。

::: proof 解
**判据 ① OOD 测试（切分方式改变）。** 把随机切分换成**按化学空间切分**：例如把所有含某类金属（如某族过渡金属）或某类载体（氧化物 / 碳基）的样本留作测试集；再保留一个「按发表年份切分」的测试集（未来数据）。判据：若 OOD 误差显著高于随机切分（例如 $R^2$ 从 0.9 掉到 0.5 以下），说明模型主要依赖「邻近样本相似性」；若能保持可用水平（例如 $R^2\gt0.7$），说明它抓到了跨体系的可迁移特征。**解释**：随机切分下的高分不能作为「可用于新体系筛选」的证据。

**判据 ② 尺度测试。** 构造三种：① 反应条件外推（把温度 / 压力推到训练区间之外，如更高温区）；② 规模变化（从单晶表面模型扩展到含缺陷 / 台阶的真实表面），检查模型是否能处理更复杂的活性位点；③ 时间尺度（若模型与动力学相关，检查更长时间 / 更低速率的条件）。判据：误差随外推距离单调恶化的速率应当**可接受且可预测**（例如外推 10% 区间误差上升不超过某陪数）；若在刚超出训练区间处就出现数量级跳变，说明模型缺乏外推结构。**解释**：这类失败在催化中很常见，因为活性对局部配位环境极度敏感（[8.3](sec83.md) 的势函数可信边界同款问题）。

**判据 ③ 干预测试。** 这一条需要真正的干预：① **实验侧**：对若干候选表面做**受控修饰**（掺杂、缺陷引入、不同覆盖度），先让模型预测、再实测，比较预测与观测的差值；② **计算侧**：在 DFT 中替换关键参数或施加电场 / 应变，做「受控仿真干预」，比较模型预测与高精度计算。判据：模型的**排序能力**（哪个候选更好）在干预后仍保持（例如 Spearman 相关 $>0.6$），且不出现系统性方向错误（把更差的预测得更好）。**解释**：排序能力在筛选场景中往往比绝对精度更重要；但若排序在干预后反转，模型就不能用于设计决策。

**总结**：三组测试各自回答不同问题——① 能不能用在新体系；② 能不能用在极端条件与更大规模；③ 能不能用来做干预式设计。**只有同时报告三者的结果（含失败的那一条），「$R^2\gt0.9$」这个数字才有科学含义**；否则它只是对「这批数据被拟合得不错」的陈述。$\blacksquare$
:::
:::

::: intuition 为什么归纳偏置决定能不能外推
外推能力不是凭空产生的，它来自模型**结构里写死了什么**（[8.1](sec81.md) 的结构化先验）：

- 一个**等变**网络把「旋转平移下物理量如何变换」写进结构，于是它在新朝向下自动正确（[8.2](sec82.md)）；
- 一个**局部能量分解**的势函数把「相互作用随距离衰减」写进结构，于是它对更大体系自动成立（[8.3](sec83.md)）；
- 一个**守恒律约束**写进损失或结构，误差就不会在守恒方向累积（[8.4](sec84.md)）；
- 反过来，一个只有大数据、没有任何物理先验的模型，其外推行为**完全由数据覆盖决定**：在覆盖内插值无敌，在覆盖外没有理由正确。

**这就是本讲反复出现的那条主线的最终形态**：把先验写进模型，不是为了让指标更好看，而是为了**在数据之外仍有理由相信它**。
:::

## AI 辅助理论：搜索与验证器

### 8.6.3 符号回归、程序搜索与数学证明 {#sec-8.6.3}

::: def 定义 8.6.3 · 符号回归与稀疏回归 {#def-8.6.3}
**符号回归**（symbolic regression）直接在**表达式空间**里搜索，目标是找出既是紧凑形式、又能拟合数据的函数。它的评分通常写成「拟合优度 + 复杂度惩罚」：
$$\hat f=\arg\min_{f\in\mathcal F}\ \underbrace{\frac1N\sum_{i=1}^{N}\bigl(f(\boldsymbol x_i)-y_i\bigr)^2}_{\text{拟合误差}}\ +\ \lambda\,\underbrace{\Omega(f)}_{\text{复杂度（项数 / 深度 / 量纲一致性）}} .$$

**稀疏回归**（sparse identification）是它的一个重要特例：先构造一个候选函数的字典矩阵 $\Theta(\boldsymbol x)$（如常数项、各变量及其乘积、三角函数等），再要求系数向量 $\Xi$ **尽量稀疏**：
$$\min_{\Xi}\ \bigl\lVert \dot{\boldsymbol x}-\Theta(\boldsymbol x)\,\Xi\bigr\rVert_2^2\ +\ \lambda\lVert\Xi\rVert_1 .$$
$\ell_1$ 惩罚会把大多数系数压到零，留下的少数非零项就是「被数据支持的方程」。（这类方法的代表是稀疏辨识非线性动力学的工作，见延伸阅读。）

**为什么必须稀疏**：不稀疏的解总能拟合数据（项数足够多时拟合误差可以任意小），但它把噪声也当成了规律，且**无法外推**。稀疏性同时买到三件事：**可读**（人能审视）、**可外推**（项少 → 结构简单 → 在数据外更可能成立）、**可证伪**（能明确指出哪一项在什么极限下应当消失）。
:::

::: intuition 为什么「找到公式」比「拟合得准」更难也更有价值
考虑两个模型：一个深度网络把观测误差压到极低，一个两三项的公式误差略大。在科学语境里，后者往往更有价值，因为它**可以拿去和已知理论对话**：它的项是否对应已知的量？它在量纲上是否成立？它在某些极限下（如温度趋零、浓度趋零）是否退化为公认结果？

这就是符号回归的**验收标准比回归任务更苛刻**的原因——它不仅要「预测准」，还要过下面四道检查：

| 检查 | 问什么 | 不过关的表现 |
|:--|:--|:--|
| **量纲一致** | 等式两边的量纲是否匹配（含常数项） | 出现「长度 + 能量」这种无意义组合 |
| **极限行为** | 已知极限（趋零 / 趋无穷 / 对称性）下是否退化正确 | 在物理上必须为零处给出非零值 |
| **独立数据** | 换一批独立采集的数据（或不同实验条件）是否仍成立 | 系数大幅变动、甚至项的结构变化 |
| **可干预预测** | 用它预测一次干预实验的结果（[@def-8.6.2]） | 干预后符号方向都错 |

**注意**：这四道检查全部**不需要**机器学习——它们是科学界检验任何假设的常规手段。**AI 改变的是「候选从哪里来」，不是「候选怎么被验收」。**
:::

::: method AI 辅助发现的三条路线及其验证器 {#method-8.6.2}
| 路线 | 搜索对象 | 监督信号 / 验证器 | 代表工作（引用按期刊 / 官方页面） | 可验证性等级 |
|:--|:--|:--|:--|:--|
| **符号回归** | 表达式（公式） | 拟合误差 + 复杂度 + 量纲 / 极限检查 | Schmidt & Lipson（2009，*Science*）；稀疏辨识（2016，*PNAS*）；结合深度学习的符号模型（2020，NeurIPS） | 中（可解释、可人工审查；但「公式成立」需独立数据） |
| **程序搜索** | 计算机程序（算法 / 构造） | **可执行的评分函数**：跑一遍就有客观分数 | FunSearch（2024，*Nature*；**无 arXiv**）——用语言模型变异程序、用自动评估器筛选 | 高（分数可复算、结果可复现） |
| **数学证明** | 证明步骤 / 辅助构造 | **符号演绎引擎 + 形式化检查器**（如 Lean / Isabelle 一类系统） | AlphaGeometry（2024，*Nature*；arXiv:2401.04088）；AlphaProof 与 AlphaEvolve 为 DeepMind 官方博客 / 技术报告（2024 / 2025，**无 arXiv**） | 最高（形式化证明可由机器逐行核对） |

**共同结构**：**「生成候选 + 验证候选」的闭环**。三条路线的差别集中在一点：**验证器有多硬**。
:::

::: intuition 验证器的强度决定「发现」的可信度
把验证器强度排成一条阶梯，越靠上越不需要人类主观判断：

1. **可执行复算**（程序搜索）：给出代码与输入，任何人都能重跑并得到同样的分数。**最强的一类客观性。**
2. **形式化证明检查**（数学证明）：结论是机器逐行核对的定理，不存在「读者觉得对」的空间；剩下的人类判断只在于「这个定理是否重要」。
3. **拟合 + 物理检查**（符号回归）：公式能拟合数据、量纲与极限合理，但**是否真的成立需要新的独立数据与干预实验**——验证器较软。
4. **人类偏好 / 主观评审**（通用文本任务）：最软，且难以防止「看起来合理」。

**这条阶梯解释了 AI 在数学与算法发现上比在「物理学发现」上更容易给出可被接受的成果**：不是因为前者更难，而是因为**验证器更硬**——数学有形式化检查，程序有可执行评分，而「物理规律」的最终验证只能靠实验（这也正是本讲开头那句诚实声明的由来）。

**反过来，这条阶梯也给出了使用建议**：当你想让 AI 参与发现时，**先问「验证器是什么」**。如果没有硬验证器，那么无论产出的文本多么漂亮，都只能算「假设生成」，必须补上实验验证环节（[8.6.4](#sec-8.6.4)）。
:::

::: ex 8.6.2 · 设计一条「发现的验证流水线」 {#ex-8.6.2}
你所在的小组用符号回归从一批实验数据里得到了一个描述「反应速率随温度与浓度变化」的三项公式。请设计一条五步验证流水线，把「可能是发现」与「拟合技巧」区分开，并给每一步一个可执行的判据。

::: proof 解
**第 ① 步：量纲与物理合理性（无需新数据，最便宜）。** 检查等式两边量纲一致；检查已知极限：浓度趋零时速率应趋零（若公式给出非零截距，则这一项必须能用背景 / 催化自身贡献解释）；温度依赖是否与已知的活化能形式相容（例如取对数后是否近似线性）。**判据**：量纲完全一致；至少两个已知极限行为正确；任何偏离都要有物理解释。

**第 ② 步：独立数据复现（同分布，新样本）。** 用**另一批独立采集**的数据（不同批次、不同仪器或不同实验室条件）复算，检查系数是否稳定。**判据**：项的结构不变（不出现新项或丢项），系数变化在置信区间内（例如相对变化 $<20\%$）。

**第 ③ 步：分布外与尺度测试（[@def-8.6.2]）。** 在更高 / 更低温度区、更宽浓度范围、以及（若可能）不同催化剂体系上测试。**判据**：外推区域的相对误差随外推距离温和上升（无数量级跳变）；若在高浓度区出现系统性高估，检查是否遗漏了饱和 / 抑制项。

**第 ④ 步：干预实验（[@def-8.6.2]，最强）。** 主动改变公式中「被认定为关键」的那个变量（例如加入一个已知会改变局部环境的添加剂、或改变压力以影响覆盖度），先预测再实测。**判据**：预测与观测的**方向一致**（增加该变量使速率上升还是下降），且定量误差在可接受范围（例如相对误差 $<30\%$，具体阈值随体系而定）；若方向都错，则公式的因果结构有问题。

**第 ⑤ 步：与既有理论对话（可证伪性）。** 写出「这个公式在什么条件下必然失效」的具体预测，并设计一个能证伪它的实验。**判据**：能写出可执行的反例测试；若连「什么条件下会失效」都说不出来，那么这条公式只能算拟合式，不能升级为机制主张。

**总结**：五步从「零成本检查」到「需要实验」逐级加码，**如果第 ① 步就不过关，没必要花实验预算**；反之，若第 ④ 步也通过，那么这条公式具备了②（机制性）级别的证据，可以作为进一步研究的起点——**但仍不能算作③（完整可干预性）的证据**，因为干预测试只覆盖了有限的干预类型。$\blacksquare$
:::
:::

## AI 在科学工作流中的位置

### 8.6.4 假设生成 vs 结论判定 {#sec-8.6.4}

::: method 科学工作流的分工表（AI 强在哪、弱在哪） {#method-8.6.3}
| 工作流环节 | AI 的强项 | AI 的弱项（需要人 / 实验） | 证据要求 |
|:--|:--|:--|:--|
| **假设生成** | 在高维空间中大规模提出候选（结构、成分、公式、程序）；跨文献关联线索 | 判断「哪些假设值得追」需要领域判断与价值排序 | 候选清单 + 可复算的评分 |
| **实验设计** | 主动学习挑样本（[8.3](sec83.md)）、贝叶斯优化选条件 | 涉及安全、成本、可执行性的约束需要人定 | 采集函数与预算约束的显式化 |
| **数据分析** | 从大规模观测 / 仿真中提取模式、去噪、反演 | 系统性偏差的识别（仪器效应、采样偏差）常需领域知识 | 交叉验证 + 独立方法对照 |
| **机制推断** | 符号回归提候选式；因果图检验条件独立 | 把统计相关升级为因果机制（需要干预或准实验设计） | 外推三判据（[@def-8.6.2]） |
| **结论判定** | 快速复核计算、找反例（形式化检查） | **不能由模型自己宣布成立**：需要实验 / 观测 / 形式证明 | 硬验证器（[@method-8.6.2]） |
| **传播与复现** | 生成可执行代码、文档、复现脚本 | 对结论负责的署名与责任归属（[第 7 讲](../lec07/sec74.md)） | 代码 + 数据 + 随机种子 |

**一句话**：AI 在**生成**与**筛选**上强，在**判定**上弱。这个分工不是技术限制的托词，而是因为**判定需要外部世界的反馈**（实验、观测、形式证明），而模型内部没有外部世界。
:::

::: method 决策表：什么时候能当计算器、什么时候必须验证 {#method-8.6.4}
这张表是本讲所有内容的操作化总结。**判断依据只有两条：训练分布是否覆盖使用场景，以及错的代价能否承受。**

| 使用场景 | 能否当计算器 | 必须做什么 | 依据 |
|:--|:--|:--|:--|
| 在**已验证的物理模型**区间内做快速筛选（代理模型 / 势函数） | ✅ 可以 | 声明适用域；对少量样本做高精度抽查；监控漂移（守恒、分布） | [8.3](sec83.md) 可信边界清单；[8.4](sec84.md) 三类评测 |
| 在训练分布内做**排序**（虚拟筛选、候选优先级） | ✅ 可以（但只用于排序） | 报告排序指标（而非绝对精度）；保留实验抽查预算 | [@ex-8.6.1] 判据③的排序口径 |
| 外推到**新的化学空间 / 更极端条件 / 更长时效** | ⚠️ 只能当假设生成器 | 用外推三判据体检；把输出当候选项，逐项独立复核 | [@def-8.6.2] |
| 声称发现了**新规律 / 新机制** | ❌ 不能 | 独立数据 + 干预实验；说明可证伪条件 | [@ex-8.6.2] 五步 |
| 用于**安全 / 健康 / 环境决策** | ❌ 不能 | 实验验证 + 专业评审 + 责任链（含申诉与回退路径） | [第 7 讲](../lec07/sec76.md) 的可验证需求写法 |
| 生成**候选假设 / 候选材料 / 候选证明** | ✅ 正是它擅长的 | 用硬验证器过滤（可执行评分 / 形式检查 / 实验） | [@method-8.6.2] 的验证器阶梯 |

**两条使用纪律**（比任何技术细节都重要）：

1. **写清适用域**：每个模型交付时都要说明「它在什么范围内可信、由什么证据支持、在哪里失效」。**没有适用域声明的模型输出，不能进入决策链。**
2. **把验证预算算进收益**：若一个模型能把候选从百万级压到十个，那么节省的成本必须留出一部分给验证（DFT 抽查、实验复现）。**把验证当作流程的一部分，而不是发现之后的意外支出。**
:::

::: think 两方主张：AI 是在「发现」还是在「高效插值」 {#think-8.6.2}
这场争论的分歧可以用**可检验主张**的形式摆出来，避免退化为立场之争：

**「高效插值」一方的主张**：目前的模型在本质上是高维函数逼近器，其「发现」都可以归约为「在人类给定的表示空间中搜索 + 用人类给定的评分器筛选」；搜索空间的构造、评分器的定义、候选的最终解释都由人完成，因此它是**工具效率的提升**，不是科学理解方式的改变。**可检验的推论**：若把评分器换成人类无法事先定义的（真正新的）评价标准，这类系统就会失效。

**「新的理解载体」一方的主张**：科学理解本身一直在借助外部表征（微积分、张量、相图、数值模式）；模型提供的**高维、非符号化的表征**是一种新的表征方式，它能捕捉符号公式难以表达的关系（如复杂分子环境、湍流统计），并且可以与符号层互译（如用符号回归从网络里提取近似规律）。**可检验的推论**：模型表征应当能**预测人类尚未写出公式的现象**，并且其预测能被实验证实。

**两条推论分别可以通过实验检验**，也都还没有最终答案（**这一点需要明确标注为开放问题**）。本教程的立场是操作性的：**在证据出现之前，按验证器强度决定信任级别**（[@method-8.6.2]），并按[@method-8.6.4] 的决策表决定模型输出的用途——这与争论的最终结果无关，无论哪方正确，这套纪律都成立。
:::

::: errata 本节的六个常见误解
1. **「测试集分数高 = 模型懂了」**：测试集分数属于[@def-8.6.1] 的①，且仅在测试分布与使用分布一致时有意义。要谈「懂」必须过外推三判据（[@def-8.6.2]）。
2. **「外推就是把测试集换难一点」**：随机切分下的「难例子」仍是同分布；真正的 OOD 需要改变**切分维度**（新体系、未来时段、新区域）。这是最容易自我欺骗的一步。
3. **「符号回归得到公式就是发现了规律」**：公式要先过量纲、极限、独立数据、干预四道检查（[@ex-8.6.2]）。不稀疏、无量纲一致性、在极限下不退化正确的公式，只是拟合式。
4. **「AI 证明了定理，所以它理解了数学」**：形式化证明由机器逐行核对，可信度确实最高，但它证明的是**命题成立**，不自动等于「发现了重要的数学」。重要性的判断仍需人类同行评估（这是价值判断，不是计算问题）。
5. **「模型可以自己判定自己的发现」**：判定需要外部世界的反馈。用同一个模型（或同一批数据）去验证自己的输出，是典型的自我确认循环（[8.3](sec83.md) 主动学习中同样要避免的陷阱）。
6. **「有了硬验证器就不需要人」**：验证器只能验证**它被设计来验证的东西**。程序搜索的评分器若写错了目标，系统会高效地优化出一个「在错误目标上很强」的解（这与 [第 7 讲](../lec07/sec72.md) 的奖励错设同构）。**验证器的定义权、以及「验证什么才算重要」的判断，仍在人这一侧。**
:::

::: method 即时自测 · 8.6 {#method-8.6.5}
**Q1** 用 [@def-8.6.1] 的三个层次，判断下列说法各属于哪一层：①「这个模型能预测新合金的硬度，误差在 10% 内」；②「我们知道硬度主要由位错滑移阻力决定，而该阻力随溶质浓度非线性上升」；③「若把溶质浓度提高到 X，硬度会上升 Y」。

**Q2** 写出外推能力的三条判据，并说明哪一条最难获得证据、为什么。

**Q3** 一个团队用语言模型搜索出了一个新的排序算法，并用自动评测确认它在标准数据集上更快。请判断这条路线的**验证器强度**属于哪一级，并写出两条你仍要追问的问题。

::: sol 参考要点
**Q1** ① **预测性**（第一层）：只涉及「在给定条件下预测输出」，且需要检查测试分布是否与使用分布一致（若是新合金体系，则还要过 OOD 判据）。② **机制性**（第二层）：给出了因果结构（溶质浓度 → 位错滑移阻力 → 硬度）与形式（非线性上升），这类主张需要能说明极限行为与证伪条件。③ **可干预性**（第三层）：它预测的是**干预**（主动提高浓度）的后果，属于最强的层次；要注意它成立的前提是②的机制正确，且干预范围内没有被忽略的机制（如过饱和度上限导致的反转）。

**Q2** 三条判据：① **分布外**（新体系 / 新区域 / 未来时段）；② **尺度外推**（更大体系、更长时、更细 / 更粗分辨率）；③ **干预外推**（主动改动一个变量后预测后果）。**最难的是 ③**，因为它要求**真正的干预**（实验或受控仿真），而在天文、气候、地球演化等领域根本不可能对系统做受控实验；替代方案（自然实验、准实验设计、结构因果模型检验）都需要额外的假设，可信度依次下降。

**Q3** 属于**「可执行复算」级**（[@method-8.6.2] 阶梯的第 1 级）：评分由程序运行产生，任何人可复算，因此客观性最强，比符号回归的「拟合 + 物理检查」更硬。仍要追问：① **评分器是否覆盖了真实需求**——「在标准数据集上更快」是否包含最坏情况、内存 / 稳定性、边界输入与并发场景？（评分器写不好就会高效地优化出错误目标下的强解，[@errata-8.6.1] 同款风险。）② **是否与已知最优比较、以及是否只是已知算法的重发现**——需要与文献中的算法（含理论下界 / 上界）对照，判断这是**新发现**还是**重新发现**（后者同样有价值，但陈述要准确）。**这两个问题都指向同一件事：验证器的强度只保证「在被定义的目标上正确」，不保证「这个目标就是我们要的」。**
:::
:::

::: errata 一条边界声明（与 [导览](overview.md) 的诚实声明对应） {#errata-8.6.1}
本节讨论「发现」时反复使用「验证器」这个词，需要一条补充说明：**验证器的作用是排除错误，不是确认全部真理**。

- 通过形式化检查的定理，只保证了「在该形式系统内可证」，不保证公理系统与真实世界的对应关系；
- 通过实验验证的公式，只在其被测试的条件范围内获得支持（这正是一切科学结论的常态）；
- 通过自动评分的程序，只在评分函数覆盖的性能维度上被确认。
:::

**本节小结**：「理解」分三层——**能预测、能说出机制、能预测干预后果**（[@def-8.6.1]），每一层需要不同的证据，把三层混为一谈是大多数争论的来源。检验「是否真懂」靠**外推三判据**：分布外、尺度、干预（[@def-8.6.2]），其中干预判据最强也最难获得。AI 在「发现」上的三条路线——**符号回归、程序搜索、数学证明**——共享「生成候选 + 验证候选」的结构，而**验证器的硬度**（可执行复算 > 形式化检查 > 拟合加物理检查 > 主观评审）决定了产出能否被接受为发现（[@method-8.6.2]）。工作流上，AI 在**生成与筛选**强、在**结论判定**弱，因为判定需要外部世界的反馈；[@method-8.6.4] 的决策表把这条分工落成可执行的规则：**分布内筛选可以当计算器，分布外只能当假设生成器，安全相关决策必须回到实验与专业评审。**

**与全讲的连接**：本讲把深度学习的对象从人造数据换成了自然，方法上的两把钥匙始终是**把先验写进结构**（对称性、守恒、局部性、方程）与**把过程变可微**（端到端结构预测、可微分仿真、残差损失）；而验收标准始终是**独立的实验与专业验证**。要把这些研究级模型真正训起来——结构预测的 $N^2$ 项、预报模型的多步训练、材料平台的百万级筛选——需要的是 [第 9 讲](../lec09/overview.md) 的大规模并行与工程能力：**科学模型的规模，正是并行训练技术的下一个战场。**
