## 每讲固定结构

每讲都按同一套节奏组织，便于跳读：

1. **学习简报**（先修 / 目标 / 学完标准）；
2. **10 分钟复习版**（全讲必记结论）；
3. **正文**，按「动机 → 定义 → 关键结论 → 直觉 → 推导/例题」推进；
4. **本讲陷阱**（常见误解清单）；
5. **本讲小结**（三句话带走 + 与后续的连接）。

> 读法：第一遍读「直觉」建立手感，**跳过所有折叠的证明框**；二刷再逐行补推导。每讲末尾的「陷阱」务必看——考试与实战里出错最多的就是那几条。
