# 第 6 讲 · 新前沿

> 前五讲已经集齐了所有零件：[第 2 讲](lec02.md)的 **Transformer** 提供序列骨干，[第 4 讲](lec04.md)的**生成模型**给出采样框架，[第 5 讲](lec05.md)的**强化学习**提供对齐工具。本讲把它们组装成今天最受关注的系统——**大语言模型、多模态模型、具身智能体**。我们按「预训练 → 对齐 → 提示与推理 → 多模态 → 具身与智能体 → 评估」的顺序走一遍，并在**每一处不确定的地方明确标出「尚存争议 / 证据有限」**：这一讲比前五讲更贴近正在进行的研究，许多结论仍是**经验性的、会随证据修正的**。读完你应当对「规模带来能力」这件事既知道它有多有用，也知道它被夸大的地方在哪里。

::: method[core] 10 分钟复习版 · 第 6 讲

**一句话**：大语言模型 = **自监督预训练**（预测下一个 token，从海量文本里自学）+ **指令微调与偏好对齐**（从「续写器」变成「有用且守规的助手」）+ **提示与推理**（把任务当作前缀来调用已有能力）；把同一套骨干接到图像、动作与环境上，就长出**多模态、具身智能体与世界模型**——而它们的**评估**远比看起来难。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **语言模型** | 一个大的 Transformer，对 $p_\theta(x_t\mid x_{<t})$ 建模；输出层是覆盖词表的 softmax |
| **自监督预训练** | 标签就是下一个 token，损失为交叉熵 $\mathcal L=-\dfrac1T\sum_t\log p_\theta(x_t\mid x_{<t})$；**无需人工标注** |
| **为什么有效** | 要压低困惑度，模型被迫隐式学到语法、事实、风格乃至部分推理；「压缩即理解」是一种**解释，尚存争议** |
| **缩放律** | 损失随**参数 $N$、数据 $D$、算力 $C$** 大致按幂律下降；三条轴要**同向扩展**，只堆参数收益会饱和 |
| **能力涌现** | 「跨过某规模阈值能力突变」的说法**尚存争议**：一部分「突变」可能是**度量不连续**造成的假象 |
| **指令微调** | 在「指令-回答」数据上做监督微调（SFT），把只会续写的模型变成会听指令的助手 |
| **偏好对齐** | 用人类偏好优化行为（RLHF / DPO，见 [第 5 讲](lec05.md)）；主要改**行为与偏好**，是否「新增能力」**证据有限** |
| **上下文学习** | 不改参数，只在输入前缀里给几个示例，模型在前向中就切换行为——「**任务即前缀**」 |
| **零 / 少样本提示** | 不给示例（zero-shot）或给几个示例（few-shot）；能力来自预训练，提示只是**条件化**，不创造新知识 |
| **思维链（CoT）** | 让模型先输出中间步骤再给答案；对多步推理有效，但**「写出」未必等于「真实计算」**（未必忠实） |
| **多模态对齐** | 对比学习把图像与文本压进**同一表示空间**（CLIP 风格），支持零样本分类与图文检索 |
| **生成式统一** | 把图像 / 音频 / 动作离散成 token，与文本拼进同一自回归序列，用同一个 next-token 目标训练 |
| **VLA** | 视觉 + 语言 → 低层动作；用**示教轨迹**做模仿学习，动作可当 token 预测，也可当扩散生成的目标 |
| **智能体** | 「观察 → 思考 → 行动（含**工具调用**）→ 再观察」闭环，与 [第 5 讲](lec05.md)的 MDP 同构 |
| **世界模型** | 在内部预测 $p(s_{t+1}\mid s_t,a_t)$ 并在「想象」里规划；**复合误差**是它的主要风险 |
| **评估的局限** | 基准会**饱和、被污染（训练泄漏）、被 Goodhart**；「刷榜」不等于「有用」 |
| **幻觉** | 流畅但无据或错误；根因是模型优化「**似然的连贯**」而非「**事实为真**」，需检索接地、验证与弃答 |

**最该记住的四个判断**：① 大模型是「**自监督预训练 + 指令微调 + 偏好对齐**」三段的产物，缺一段都不成立；② 缩放律是**三条轴同时扩**的经验规律，而不是「参数越大越强」的单一承诺；③ 提示与 CoT 只**调用已有能力**，不能凭空创造预训练里没有的知识；④ 看到任何「涌现 / 超越人类 / 刷榜第一」的说法，先问三件事——**基准有没有被污染、度量连不连续、分布与真实使用是否一致**。

:::

## 6.1 大语言模型：从自监督预训练到对齐

[第 2 讲](lec02.md)已经把 Transformer 讲清楚了：一堆自注意力块，喂进一段 token 序列，输出每个位置上的下一个 token 分布。**大语言模型**（Large Language Model, LLM）做的就是把这个结构**放到极致地大、并喂进海量文本**，然后只做一件极其简单的事：**预测下一个 token**。

::: def 定义 6.1 · 自监督预训练（next-token prediction） {#def-6-1}
给定一段文本 $\boldsymbol x=(x_1,\dots,x_T)$（每个 $x_t$ 是一个 token），模型参数化条件分布 $p_\theta(x_t\mid x_{<t})$。训练目标是**平均负对数似然**（即[第 1 讲](lec01.md)的交叉熵，词表上做 softmax）：

$$\mathcal L(\theta)=-\frac1T\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).$$

关键在于**监督信号来自数据本身**：第 $t$ 个位置的标签就是文本里真实出现的第 $t$ 个 token。因此不需要任何人工标注，任意一段网页、书籍、代码都能变成训练样本——这正是「**自监督**（self-supervised）」的含义。
:::

::: intuition 预测下一个 token 为什么能学到这么多
「下一个词预测」听起来太简单，凭什么能学出语法、事实、甚至解题？一个直观是：要**稳定压低**整段文本的困惑度，模型不能只记表层的词频，它必须隐式地学到「谁和谁共现」「什么事实为真」「什么推理成立」——否则在长尾和大跨度依赖上就会付代价。用一句话概括这条路线的信念：**好的概率预测 = 好的压缩 = 好的理解**。但要诚实：这只是**一种解释**，模型内部到底「学到」了什么、有没有类似人类的语义结构，**仍是开放问题，证据有限**。
:::

预训练只给你一个**极度擅长续写**的模型，但它不天然会「回答问题、遵守格式、拒绝有害请求」。要把它变成助手，还要两步后训练——这一步在 [第 5 讲](lec05.md)已经埋过伏笔（RLHF）。

::: def 定义 6.2 · 指令微调与偏好对齐 {#def-6-2}
**指令微调（instruction tuning / SFT）**：在「指令 + 期望回答」的成对数据上做普通的监督微调（还是 [第 1 讲](lec01.md)的交叉熵，只是数据换成对话格式），让模型学会「**听到指令就照做**」。

**偏好对齐（alignment）**：在 SFT 之后，用人类（或 AI）对多个回答的**偏好排序**继续优化——RLHF 用奖励模型 + RL，DPO 直接对偏好做优化（见 [第 5 讲](lec05.md)），目标是让模型更倾向于**有用、诚实、无害**的输出。
:::

::: intuition 预训练学「分布」，对齐学「偏好分布里的哪一块」
可以把预训练想成把全部人类文本的**概率分布**都学到（其中当然也包含「怎么流畅地说错话」）。对齐不改变模型会什么，而是**移动它的概率质量**：把「有用且守规」的回答抬上去、把「有害或敷衍」的回答压下去。一个常见但**证据有限**的说法是「对齐只是让模型更愿意表现，而不是教它新知识」——它大体符合直觉，但「对齐能否顺带激发出预训练里已有、却未显露的能力」**仍存争议**，不必当作定论。
:::

### 缩放律与「能力涌现」：两条经验规律，一条要谨慎

预训练和后训练都吃规模，于是自然会问：**规模变大，效果怎么变？**

::: def 定义 6.3 · 缩放律（scaling law，经验关系） {#def-6-3}
大量实验给出的**经验规律**是：模型的测试损失随**参数量 $N$、训练数据量 $D$、训练算力 $C$** 的增大而按**幂律**平滑下降。一个常被引用的定性形式为

$$L(N,D)\ \approx\ L_\infty+\Bigl(\frac{N_c}{N}\Bigr)^{\alpha_N}+\Bigl(\frac{D_c}{D}\Bigr)^{\alpha_D},$$

即「无限规模下的不可约损失 $L_\infty$」加上两个随规模衰减的项。它的实践含义是：**三条轴要同向扩展**——只把参数堆大而数据不够，收益很快饱和（这正是「参数量并非唯一旋钮」的经验依据）。
:::

补一句边界：上式里的指数、常数、以及「足够大时是否仍成立」，都**依赖具体数据与设置**，不同研究给出的数值并不一致。**请记住趋势，不要背数字**——缩放律是**经验拟合**，不是像物理定律那样先验成立的东西。

比缩放律更出名、也更需要谨慎的是「**能力涌现**（emergent abilities）」：有观察报告称，当规模跨过某个量级，某些能力（如多步算术、符号推理）看起来**突然从「接近零」跳到「不错」**。

::: think 「能力涌现」要打几个问号
「涌现」的诱人叙事是「规模够大就必然获得新能力」。但必须意识到：

- **度量会骗人**：如果指标是**不连续**的（例如「整道题全对才算分」），那么底层能力**平滑**上升也会被显示成**台阶式突变**。换一个连续指标（如部分得分、逐 token 准确率），「突变」往往变回「斜坡」——这是对「涌现」叙事最主要的挑战，**相关争论尚存争议**。
- **阈值不稳健**：所谓「临界规模」对模型、数据、提示与评测细节都敏感，换个设置就移动。
- **能力是任务特定的**：同一个模型在某些任务上「涌现」，在另一些上却平滑甚至退化。

所以正确的态度是：**把「涌现」当作一组待解释的观测，而不是一条自然定律**。它可以指导「值得继续扩规模」的直觉，但不该被读成「只要够大，什么能力都会自动到来」。
:::

## 6.2 提示与推理：把任务当作前缀

后训练之后，我们**不再改参数**，只用它的前向能力做任务——这就是**提示**（prompting）的世界。

::: def 定义 6.4 · 上下文学习（in-context learning） {#def-6-4}
不更新任何参数，只在输入里给出若干「示范」，让模型在**一次前向**中依据这段前缀改变行为：给 $k$ 个示例 $(x^{(1)},y^{(1)}),\dots,(x^{(k)},y^{(k)})$，再拼上测试输入 $x^{\text{test}}$，模型直接续写出 $y^{\text{test}}$：

$$\underbrace{(x^{(1)},y^{(1)}),\dots,(x^{(k)},y^{(k)})}_{\text{示范（权重冻结，只在前缀里）}},\ \ x^{\text{test}}\ \Longrightarrow\ \ \hat y^{\text{test}}.$$

$k=0$ 就是**零样本**（zero-shot）提示，$k$ 不大就是**少样本**（few-shot）提示。整个过程**没有梯度、没有参数更新**——「学习」发生在前向的条件化里。
:::

::: intuition 大模型为什么能「举一反三」
关键是：预训练见过**海量、多样的「任务格式」**（问答、翻译、写代码、分步解题……）。当你在前缀里摆出几个示范，你其实是在**指定**「现在要做的是哪一类任务」——相当于在模型已经学到的一大堆子程序里**定位**一个，然后让它接着跑。

所以「举一反三」更像**条件化 / 检索**，而不是监督学习意义上的**学习**：能力是预训练**已经装进去的**，提示只负责**把它调出来**。这也解释了两件事：① 提示对**明确、常见**的任务格式最有效；② 它**不能凭空创造**预训练里没有的知识。至于内部机制（例如是否存在专门识别「示范-测试」对应模式的回路），已有一些研究线索，但**尚无公认结论，证据有限**。
:::

最有力的一种提示技巧是**思维链**（Chain-of-Thought, CoT）。

::: method 思维链提示（Chain-of-Thought, CoT） {#method-6-1}
**做法**：不要求模型直接给答案，而是**先输出中间推理步骤，再给最终答案**。

- **少样本 CoT**：示范里就把「步骤 + 答案」写全，让模型模仿这种格式。
- **零样本 CoT**：只在指令后加一句「**请一步一步思考**」，也能显著改变输出结构。

**为什么可能有效**（几点解释，非定论）：① 把难题拆成**多个较简单的局部步骤**，每步更容易；② 生成中间 token 等于给后续计算提供**更多算力与中间结果**（自回归模型没有「草稿纸」，CoT 就是给它草稿纸）；③ 与预训练里「解题过程」这类文本的格式对齐。

**边界要记住**：CoT 主要帮**多步推理**类任务，对纯记忆 / 检索类帮助有限；更重要的是——模型**写出来的步骤未必是它真实的内部计算过程**，即推理**未必「忠实」**（见下文 6.7 本讲陷阱）。把 CoT 当作「模型的真实心路」是一个常见的过度解读。
:::

::: ex 例 6.1（把一个分类任务改写成前缀） {#ex-6-1}
任务：判断一段影评是**正面**还是**负面**。不用任何微调，只用上下文学习完成它。

::: proof 解
**零样本**：把任务写成一条指令，直接让模型续写：

```text
判断下面这段影评是「正面」还是「负面」，只回答一个词。
影评：这部电影节奏拖沓，但配乐极好，我勉强看到结尾。
情感：
```

模型在前缀条件下对词表做 softmax，「正面」「负面」两个 token 的**条件概率**被比较，取大的那个即可。

**少样本**：在前面再放两条带答案的示范，让「任务 = 读前缀并补全」这件事对模型**更明确**：

```text
影评：剧情紧凑，演技在线。            情感：正面
影评：逻辑混乱，看到一半就想离场。    情感：负面
影评：这部电影节奏拖沓，但配乐极好，我勉强看到结尾。
情感：
```

**为什么这就「算」一个任务**：模型本来只在做「$p_\theta(\text{下一个 token}\mid\text{前缀})$」，而上面两段把「分类」翻译成了「**给定前缀，续写标签**」。所以严格地说，模型**没有学会**情感分类这个新任务——它只是被前缀**条件化**到了一个它预训练时见过的「评价-标签」模式上。这也说明少样本提示的**上限由预训练决定**。
:::

:::

## 6.3 多模态：把图像与文本放进同一个空间

语言模型活在离散 token 里，而图像、音频是连续的。**多模态**的两条主要路线：

**路线一：对齐**。学一个**共享的表示空间**，让描述同一件事的图像和文本靠得近。

::: def 定义 6.5 · 视觉-语言对比对齐（CLIP 风格） {#def-6-5}
分别用图像编码器 $f$ 与文本编码器 $g$ 把一批配对的 $(v_i,t_i)$ 映射到同一空间，得到 $\boldsymbol v_i=f(v_i)$、$\boldsymbol t_i=g(t_i)$。用 **InfoNCE 式对比损失**，对每个样本把「配对」当正例、批内其他文本当负例：

$$\mathcal L_{i\to t}=-\log\frac{\exp\bigl(\mathrm{sim}(\boldsymbol v_i,\boldsymbol t_i)/\tau\bigr)}{\sum_{j=1}^{B}\exp\bigl(\mathrm{sim}(\boldsymbol v_i,\boldsymbol t_j)/\tau\bigr)},\qquad \mathrm{sim}(\boldsymbol a,\boldsymbol b)=\frac{\boldsymbol a^{\mathrm T}\boldsymbol b}{\lVert\boldsymbol a\rVert\,\lVert\boldsymbol b\rVert},$$

再对称地做一遍 $t\to i$（即 $i$ 方向的「文本找图像」），两者相加。$\tau$ 是温度，控制分布的尖锐程度。**对齐之后**，分类可以做成「把类别名当文本查询」的零样本匹配：哪句描述与图像最像，就预测哪一类。
:::

**路线二：统一**。不再满足于「对齐两个空间」，而是让**同一个生成模型处理所有模态**——把图像切块、音频切帧、机器人动作切段，都**离散成 token**，与文本 token 拼进**同一条自回归序列**，用**同一个** $p_\theta(\text{下一个 token}\mid\text{前缀})$ 目标训练。

::: note 「统一」背后要打的一个问号
「把所有模态变成同一种 token 语言」在工程上确实优雅，它让 [第 2 讲](lec02.md)的 Transformer 与 [第 4 讲](lec04.md)的自回归生成**一次复用到底**。但要说清一个边界：**「用同一套架构训练」不等于「真的学到了统一的表示」**。视觉 token 与文本 token 是否在内部被同等、同质地处理，还是仍然**拼装、仍以文本为主干**，**尚存争议**。这是当前多模态研究的一块开放地带，看到「统一多模态」这类表述时，值得追问它统一到的**是接口，还是表示**。
:::

## 6.4 具身智能与 VLA：把语义接到低层控制

多模态让模型「看懂」，但要它**动手**，还要把高层的语义理解接到机器人**低层控制**上。

::: def 定义 6.6 · 视觉-语言-动作模型（Vision-Language-Action, VLA） {#def-6-6}
VLA 模型以**视觉观测**与**语言指令**为输入，直接输出**低层动作**（关节角、末端位姿，常是一段动作序列 $a_{t:t+H}$）：

$$\bigl(\text{图像帧},\ \text{语言指令}\bigr)\ \longrightarrow\ \bigl(\text{动作序列}\bigr).$$

它站在大模型的**语义骨干**之上，因此能泛化到**新的指令措辞**（「把红杯子放到左边」vs「把左边的杯子和红色那个换个位置」）；同时它要在**闭环控制**里实时、稳定地产生动作。
:::

VLA 的训练数据与目标，正好把 [第 5 讲](lec05.md)的**模仿学习**搬了过来。

::: intuition VLA 为什么是「大模型 + 模仿学习」
- **数据从哪来**：主要靠**示教轨迹**——人类遥控或穿戴设备操作机器人，录下「观测 → 动作」序列。这是**模仿学习 / 行为克隆**的经典数据形态。
- **目标是什么**：本质是「看着示范，学会在类似状态下模仿出类似动作」。动作可以像语言 token 一样**离散化后做交叉熵**，也可以像 [第 4 讲](lec04.md)里的扩散模型那样**把动作序列当作待生成的目标**（扩散策略天然能表达「同一状态有几种合理做法」的**多模态**动作）。
- **为什么接大模型**：大模型的骨干带来**语义与泛化**；模仿数据带来**技能与控制**。前者回答「**做什么**」，后者回答「**怎么动**」。

**三个诚实提醒**：① 示教数据**昂贵且分布窄**，真实世界的长尾覆盖极难；② 闭环里**误差会累积**，一步偏一点，之后越偏越远；③ 安全与实时性是硬约束——把语言模型的「自信」带进物理动作里，代价可能是撞坏东西或伤到人。（这三条也正是它比纯文本任务更难的原因。）
:::

## 6.5 智能体与世界模型：从「感知」到「决策」

再往前一步：让模型不只输出一次回答，而是**在环境里持续行动**。

::: def 定义 6.7 · 世界模型（world model） {#def-6-7}
**世界模型**指学习环境演化的模型，典型形式是学习状态转移 $p(s_{t+1}\mid s_t,a_t)$（或直接在**潜空间**里预测下一时刻的表示）。拥有它之后，智能体可以**不真动手**，而在内部「**想象**」若干步、用模型做**规划**（planning）再选动作——这正是 [第 5 讲](lec05.md)里 **model-based RL** 的核心：先用模型想象、再决策，以**提高样本效率**。

代价是**复合误差**：想象的每一步都带一点偏差，rollout（前向模拟展开）越长，偏差被放大得越厉害，想象轨迹可能越走越偏离真实后果。
:::

::: note 工具调用：把模型接上「模型之外的能力」
纯参数模型的知识**冻结**在训练时点、算术与检索都靠不住。**工具调用**（tool use）让它请求外部能力——搜索、计算器、代码执行、数据库查询、调用别的 API。此时系统从「输入一次、输出一次」变成**闭环**：

```text
观察（问题 / 环境反馈） → 思考（决定下一步） → 行动（回答 / 调工具 / 操作环境） → 再观察 → ...
```

这与 [第 5 讲](lec05.md)的**智能体-环境交互循环**是**同一个结构**。差别在于：它的「动作空间」既包含对用户说话，也包含调用工具、乃至驱动物理设备——**智能体 = 大模型 + 工具 + 记忆 + 循环**，是这一讲所有零件的一次总装。
:::

::: think 别把「想象」当成仿真，也别把「看起来会规划」当成「真的会规划」
世界模型与智能体最容易被过度解读。三条冷静提醒：① 内部 rollout **不是可信仿真**——[第 4 讲](lec04.md)的生成式想象越流畅，越可能「一本正经地编造」；② **幻觉在规划里被放大**：一个错误的前提会让后续所有步骤连锁作废，而且还会被巧妙地自圆其说；③ 「输出看起来像在一步步规划」**不等于**系统内部真在做可验证的搜索——这与 6.2 里 CoT 未必忠实的顾虑是**同一个问题**。看到「会规划、会反思、会自我修正」这类措辞，先问**能不能验证它的中间结论**。
:::

::: preview 从「能力」到「安全」：与后续两讲的接缝
本讲把大模型从「文本续写」推到了「**有实际副作用**的智能体」：它开始调用工具、驱动机器人、在环境里改变世界。这立刻引出两个后续主题——

- **[第 7 讲](lec07.md)** 追问「**怎样让系统可控、可信、符合人类价值**」：对齐、可解释、公平、滥用与监管。本讲里「偏好对齐只改行为、不改知识」的结论，是理解第 7 讲「对齐能做什么、不能做什么」的起点。
- **[第 9 讲](lec09.md)** 处理「**这么大规模怎么训得动**」：数据 / 张量 / 流水线并行、混合精度、显存切分。本讲提到的预训练、长上下文与大规模 rollout，全都落在第 9 讲的工程约束里。

一句话：**本讲讲「能做什么」，第 7 讲管「该不该、稳不稳」，第 9 讲解决「怎么让它跑得动」**。
:::

## 6.6 评估与不确定性：为什么「刷榜」不等于「有用」

前面每一节都在说「模型很强」，这一节专门说**怎么别被骗**。这是全讲最该带走的工程直觉。

::: think 基准的三种失效方式
一个**基准**（benchmark）是被测能力的**代理**。代理一旦被当作目标去优化，就不再是好度量（**Goodhart 定律**）。大模型评测里三种典型失效：

- **饱和**：顶尖模型在某基准上早已刷满，分数再高也**区分不出**能力差异，基准失去信息量。
- **数据污染（泄漏）**：评测题或近似题**混进了训练数据**，模型是「**背过答案**」而非「会做」。这让分数**系统性虚高**，是当前最棘手的问题之一——**污染程度往往难以确知，证据有限**。
- **被优化（过拟合基准）**：一旦某基准成为目标，各方就会针对它调模型 / 调提示，分数上涨而**真实分布外的能力未必提升**。

结论：**单个基准的数字，既不构成能力的上限，也不构成能力的下限**。看分数先问：它测的是哪个切片？有没有污染？和真实用途的分布一致吗？
:::

::: note 幻觉（hallucination）与不确定性
**幻觉**指模型生成**流畅、自信，但事实错误或无据**的内容。它常被误当成「纯 bug」，其实有结构性根源：

- 模型训练时优化的是**「像不像真话」（似然的连贯）**，而不是**「是不是真话」（事实为真）**。一个说得越顺的错误，恰恰越符合它被优化的方向。
- 模型通常**不知道自己不知道**——它的输出分布里几乎没有「弃答」的选项，于是会**过度自信**地编一个。
- 对策方向（都不是银弹）：**检索接地**（让答案有外部证据可依）、**可靠性与置信度校准**、允许**明确弃答**、以及把关键结论交给**外部验证器**去核对。**注意**：规模变大能减轻但不能消除幻觉；把它当成**概率系统的固有倾向**来设计防护，而不是指望某次升级一劳永逸修好。
:::

## 6.7 本讲陷阱

::: errata 常见误解清单
1. **把「能力涌现」当成必然**：所谓「规模一到、能力自动到来」的叙事，**尚存争议**。许多「突变」可能是**不连续的度量**造成的错觉，换成连续指标就变回平滑上升。把「涌现」当现象去研究可以，当成「只要够大万能」的承诺则错。
2. **以为「提示工程能解决一切」**：提示（含 CoT、少样本）只**调用**预训练已有的能力，**不能创造**模型里没有的知识或推理回路。任务对模型**真陌生**时，再好的提示也补不出能力——那需要微调、检索或换模型。
3. **以为「多模态模型真的『看见』了」**：它对齐的是**表示**，可能大量依赖**文本先验与共现统计**，而非像素级的真实感知。在**细粒度空间关系、计数、小字、罕见组合**上，多模态模型常出错——「能对着一张图聊得头头是道」不等于「真的看清了那张图」。**证据有限**之处要留余地。
4. **把 CoT 的输出当成模型的「真实心路」**：模型写出的推理步骤**未必忠实**于它实际的内部计算，有时答案是先定的、理由后编的。CoT 提高**表现**，但不保证**可解释性**。
5. **把基准分数当作能力的上限或下限**：分数受**饱和、数据污染、针对基准的过拟合**三重影响（见上文）。「刷榜第一」在真实用途上可能平平，「榜上不高」也可能很好用。
6. **把幻觉当纯 bug、以为攒够算力就能根除**：它是「优化似然而非事实」的**结构性倾向**，要靠**检索接地、校准、弃答、外部验证**去压制，而非指望规模一升就消失。
7. **把「参数量大」等同于「更好 / 更安全」**：缩放律是**参数、数据、算力同向扩展**的**经验规律**，参数只是三条轴之一；能力、成本、安全与对齐质量**都不是同一个旋钮**能调的。
8. **把世界模型的「想象」当作可靠仿真**：内部 rollout 有**复合误差**，越推越偏；把「看起来会规划」当成「真的会规划」，是把 [第 4 讲](lec04.md)式的「流畅生成」误当成了「可靠推理」。
:::

## 6.8 本讲小结

**三句话带走**：

1. 大语言模型是**三段合成**：**自监督预训练**（预测下一个 token，从海量文本里自学）给出底座，**指令微调 + 偏好对齐**（SFT / RLHF / DPO，接 [第 5 讲](lec05.md)）把它变成有用的助手；而**提示 / 少样本 / 思维链**只是**条件化**已有能力，**不创造**新知识。
2. 规模的作用是**经验的、要谨慎解读的**：损失按**参数 / 数据 / 算力三条轴**平滑下降（**缩放律**），但「**能力涌现**」的叙事**尚存争议**——度量方式足以把「斜坡」伪装成「台阶」。把「规模」当有用直觉可以，当「必然规律」则错。
3. 同样的骨干接上别的模态与环境，就长出**多模态**（图-文对齐、生成式统一）、**VLA 与具身智能**（把语义接到低层控制，用示教做模仿学习）、**智能体与世界模型**（工具调用、内部规划）；而它们的**评估**极难——**基准会污染与饱和，「刷榜」不等于「有用」，幻觉是结构性倾向**。

**与后续的连接**：本讲是全书的**汇合点**——[第 2 讲](lec02.md)的 Transformer 是骨干，[第 4 讲](lec04.md)的生成模型既做多模态生成也做扩散策略，[第 5 讲](lec05.md)的 RL/RLHF 与模仿学习是训练工具。往后看：本讲把模型推到了「**有实际副作用**」的智能体，于是 **[第 7 讲](lec07.md)** 顺理成章地追问**安全、对齐、可信与滥用**——「怎么让系统可控、符合人类价值」；而要把这一讲的预训练、长上下文与大规模训练**真正跑起来**，则落到 **[第 9 讲](lec09.md)** 的**并行与显存切分**上。[Lab 3](../labs/lab3.md) 微调大语言模型的流程（加载预训练模型 → LoRA 微调 → 评估生成），正是本讲「预训练 + 后训练」的最小工程化身。
