# 第 8 讲 · AI for Science

> 前七讲把深度学习用在**人类自己制造的数据**上：图像、文本、语音、序列、决策轨迹。这一讲换个对象——**自然本身**。科学数据有三个特点：**维度高**（分子的构象空间、气候的状态空间）、**实验贵**（一次湿实验、一轮密度泛函计算可能要很久）、**几乎没有标签却有海量结构数据**（数据库里躺着大量序列、结构、卫星影像，只是没人为它们标注「答案」）。但科学也回赠深度学习一件独有的礼物：**物理规律本身就是免费的监督信号**。于是本讲的核心思想只有一句话——把「昂贵的实验试错」变成「**可微分的推断**」：用网络拟合高维映射，用自动微分把物理仿真变成可以端到端优化的模块。读完你应明白，AI for Science 不是「把深度学习套到物理上」，而是**把先验（对称性、守恒、方程）和梯度请进科学流程**。

**一句话**：科学问题的红利是「**结构化的无标注数据 + 物理先验**」；用好它的两把钥匙是**把先验写进结构**（对称性、等变性、守恒）与**把过程变可微**（自动微分穿透网络与仿真），于是「昂贵的实验试错」被替换成「**可微分的端到端推断与优化**」。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **科学数据三特点** | 高维、实验昂贵、大量**无标注**结构数据（序列 / 结构 / 影像） |
| **核心思想** | 把「实验试错」变成「**可微分推断**」：网络拟合高维映射，自动微分把仿真变成可优化模块 |
| **两类任务** | **前向**（结构 / 条件 → 性质，预测）；**逆向**（性质 → 结构，设计）；逆向常**多解欠定** |

| **不变 / 等变** | 不变 $f(R\boldsymbol x+\boldsymbol t)=f(\boldsymbol x)$（标量，如能量）；等变 $f(R\boldsymbol x+\boldsymbol t)=R f(\boldsymbol x)$（向量，如力） |
| **几何深度学习** | 把对称性写进网络 → 省参数、省样本、更易外推 |
| **生成式设计** | 扩散 / 生成模型在分子空间采样新结构；**条件生成** = 按目标性质生成 |
| **虚拟筛选** | 用**代理模型**快速近似昂贵 DFT / 实验，给分子库打分排序 |
| **逆向设计三路** | 条件生成 / 贝叶斯优化 / 可微分目标优化 |
| **神经算子** | 学**函数到函数**的解算子，与离散网格无关（FNO、DeepONet 类） |
| **PINN** | 把 PDE 残差放进损失：$\mathcal L=\mathcal L_{\text{data}}+\lambda_r\mathcal L_{\text{res}}+\lambda_b\mathcal L_{\text{bc}}$；导数由**自动微分**给出 |

## 1.1 为什么科学适合深度学习

科学是深度学习最「反常识」的一块应用：这里的数据不是人产生的，而是**自然**产生的。这既带来困难，也带来别处没有的机会。

- **高维**：一个蛋白质有成千上万个原子，构象空间大到无法枚举；气候的状态向量可以包含上亿个格点。传统方法要在这类空间里搜索，很快撞上「维数灾难」。
- **实验昂贵**：做一次湿实验、跑一轮高精度量子化学、架一次风洞，代价都是时间与金钱。**能做的实验次数，远少于想探索的候选数**。
- **大量未标注的结构数据**：数据库里堆着海量的序列、结构、卫星观测，它们的**结构本身就是信息**，只是没人给它们贴「正确答案」的标签。

正因为如此，科学问题的形态非常适合「**学习一个从高维输入到目标量的映射**」。这里有两类最基本的任务，值得先定义清楚。

::: def 定义 8.1 · 科学机器学习的两类基本任务 {#def-8-1}
把科学问题写成「映射学习」后，绝大多数任务落进两个方向：

- **前向问题（预测）**：给定结构或条件 $\boldsymbol x$（分子构型、材料成分、初始场），预测可观测的性质 $y$（能量、稳定性、未来状态），即学习映射 $f_\theta:\boldsymbol x\mapsto y$。
- **逆向问题（设计）**：给定目标性质 $y^\star$，反过来求满足它的结构 $\boldsymbol x^\star$，即采样 $\boldsymbol x\sim p_\theta(\boldsymbol x\mid y^\star)$，或解 $\boldsymbol x^\star=\arg\max_{\boldsymbol x}y(\boldsymbol x)$。

两者像「求值」与「求反函数」：前向问题通常有明确的物理定义，适合**监督回归**；逆向问题往往**多解、欠定**（许多分子能给出同一种性质），因此更需要**生成模型**与**优化**，而不是单点回归。
:::

::: intuition 为什么"可微分"是这一讲的关键词
科学流程里最贵的环节是**实验试错**：造一批候选、测一批、再根据结果猜下一批。这套流程本质是**没有梯度的黑箱搜索**——你只拿到「好 / 坏」，拿不到「往哪个方向改会更好」。

深度学习带来两层杠杆：其一，网络本身可微，**自动微分**能把「输出对输入的敏感度」精确算出来；其二，如果连**仿真器**都写得可微（见 [1.4](#14-偏微分方程与仿真加速)），梯度就能**穿过整个物理过程**，一路回传到「设计参数」上。于是「盲目试错」变成「**沿梯度下降的端到端优化**」——这就是「把实验试错变成可微分推断」的确切含义。
:::

::: think 科学为什么天生就有海量"无标注数据"
监督学习缺的从来不是数据，是**标签**。科学的妙处在于：大量数据**自带结构**，标签可以从结构里免费造出来。

- 蛋白质数据库里存的是**真实的原子坐标**，而序列数据库里的氨基酸序列**远多于**有实验结构的；
- 分子可以由量子化学算出能量与受力，等于给每个结构配了一个「物理老师」；
- 再加上**对称性、守恒律、控制方程**这些先验，可以在没有人工标注的情况下构造自监督目标（如「预测被遮住的原子环境」「让方程残差最小」）。

所以在科学里，**物理自监督 + 预训练**往往比在少量标注数据上死磕更划算。这就是本讲反复出现的第一个主题：**把先验请进来**。
:::

## 1.2 蛋白质与分子结构预测

蛋白质是生命的机器，功能几乎完全由**三维结构**决定。一个被广泛接受的经验事实是：氨基酸**序列**在很大程度上决定了折叠后的**结构**。于是「序列 → 结构」成了一个巨大的映射学习问题——序列的种类数不胜数，而有实验解析结构的只是极小一部分。这正是 [@def-8-1] 里的**前向问题**。

### 从共进化到端到端

传统的结构预测靠两样东西：**同源模板**（找一个已知结构的相似蛋白照着搭）与**接触图**（判断哪些残基在空间里挨着）。接触图的信息从哪来？从**进化**来：把同一蛋白家族的大量同源序列对齐成**多序列比对**（MSA），如果两个位置**总是成对地一起突变**（共进化），它们很可能在三维空间中**相邻**——因为一处变了、另一处也得跟着变，才能维持结构稳定。这条「**共进化 → 空间接触**」的因果链是几十年积累的共识，也是端到端方法的信息来源。

::: method AlphaFold 类方法的公开思路（定性） {#method-8-1}
公开的端到端结构预测方法，可以把思路概括成一条「**把共进化信息直接喂进注意力网络**」的流水线：

1. **建立两类表示**：从 MSA 与（若有）模板中，抽出每个残基的**序列表示**，以及刻画「残基 $i$ 与残基 $j$ 之间关系」的**成对表示**（pair representation）。
2. **迭代传递信息**：用**注意力机制**在两类表示之间反复搬运信息——既在残基对之间传播「谁和谁相邻、取向如何」，也让序列表示与成对表示互相更新。每迭代一轮，网络对**整体几何**的把握就更精细一层。
3. **端到端输出结构**：最终由这些表示直接回归每个原子的坐标（也有公开工作改用**扩散模型**逐步去噪生成坐标）。
4. **用已知结构监督**：训练信号就是数据库中真实解析出的坐标，损失衡量预测结构与真值的**几何差异**。

**要点**：这是一条**端到端**的路子——不再手工拼「先算接触图、再拼结构」，而是让网络从共进化模式里自己学出几何。关键构件是**对残基对的注意力**与**迭代精修**，而不是某条神奇的公式。（本教程不引用具体评测分数与准确率，请把注意力放在**方法的结构**上。）
:::

### 为什么分子需要等变网络

分子的物理量天生带着**对称性**：把整个分子在空间里平移或旋转一下，它的**能量不变**；而受力、原子坐标这类**向量**则会跟着一起转。这不是巧合，是空间本身的几何性质。若把这个性质**写进网络结构**，就相当于免费给模型装了「旋转平移等价」的常识。

::: def 定义 8.2 · 不变性与等变性 {#def-8-2}
设 $R$ 是旋转矩阵、$\boldsymbol t$ 是平移向量，对输入（如原子坐标集合）做整体变换 $\boldsymbol x\mapsto R\boldsymbol x+\boldsymbol t$：

- **不变（invariant）**：输出是标量（如能量），整体变换后**不变**，
$$f(R\boldsymbol x+\boldsymbol t)=f(\boldsymbol x).$$
- **等变（equivariant）**：输出是向量 / 张量（如受力、坐标），整体变换后**跟着一起变**，
$$f(R\boldsymbol x+\boldsymbol t)=R\,f(\boldsymbol x).$$

把 $R\boldsymbol x+\boldsymbol t$ 换成更一般的对称群元素（分子的原子置换、晶格的平移），定义完全类似。**不变可以看成等变在「输出为标量」时的特例**——标量「跟着转」与「不变」是同一件事。
:::

::: intuition 对称性为什么直接省样本、省参数
假设模型不知道「转 90 度的分子还是同一个分子」。那它得**从数据里把这件事重新学一遍**：看见一个构象、再看它转过的版本、再转 45 度……无数**等价样本**被当成不同样本去记。把等变性写进网络，等于**预先告诉它这些样本是一回事**。

好处是双重的：**参数被对称性约束住**（许多本来要学的自由度直接消掉），**样本效率更高**（不必靠数据穷举所有朝向）。这与[第 3 讲](lec03.md)用卷积把「平移不变」写进网络是同一个道理——**归纳偏置与任务的对称性匹配，是深度学习最可靠的红利**。几何深度学习（等变网络）在分子与材料上奏效，根子就在这里。
:::

::: ex 例 8.1（为什么整体旋转不改变分子能量） {#ex-8-1}
设某个量只由原子两两距离决定，$E(\boldsymbol x_1,\dots,\boldsymbol x_n)=g\bigl(\{\lVert\boldsymbol x_i-\boldsymbol x_j\rVert\}_{i\lt j}\bigr)$。证明 $E$ 对任意整体旋转 $R$ 与平移 $\boldsymbol t$ 不变。

::: proof 解
整体变换后，第 $i,j$ 个原子的新坐标为 $R\boldsymbol x_i+\boldsymbol t$ 与 $R\boldsymbol x_j+\boldsymbol t$，二者之差为
$$(R\boldsymbol x_i+\boldsymbol t)-(R\boldsymbol x_j+\boldsymbol t)=R(\boldsymbol x_i-\boldsymbol x_j).$$
旋转是正交变换，**保长度**：$\lVert R(\boldsymbol x_i-\boldsymbol x_j)\rVert=\lVert\boldsymbol x_i-\boldsymbol x_j\rVert$。故所有两两距离都不变，而 $E$ 只是这些距离的函数，于是 $E(R\boldsymbol x+\boldsymbol t)=E(\boldsymbol x)$。$\blacksquare$

**结论**：只要把网络设计成**只吃相对几何**（两两距离、相对坐标、键角等），平移旋转不变 / 等变就是**结构性保证**，而不是靠数据硬学出来的。这正是 [@def-8-2] 的等变思想在分子上落地的方式。
:::
:::

## 1.3 分子与材料设计

设计新分子、新材料，本质上是在一个**天文数字大小**的空间里找满足性能要求的点。传统做法是先合成再测（慢），或先算性质再筛（准但贵）。深度学习提供两条互补的路：**预测**（把性质算快）与**生成**（把候选造出来）。

先看预测侧的**虚拟筛选**：训练一个**代理模型**去近似昂贵的性质计算（如量子化学、分子动力学），就能对数以百万计的候选做快速打分排序，把宝贵的实验预算集中到最有希望的少数分子上。再看生成侧：用生成模型直接在分子空间里**采样新结构**——这就是 [@def-8-1] 的**逆向问题**。

::: method 逆向设计的三条路径 {#method-8-2}
给定目标性质 $y^\star$，怎么找到结构 $\boldsymbol x^\star$？三条常见路径：

- **条件生成**：训练一个生成模型 $p_\theta(\boldsymbol x\mid y)$（扩散模型、流模型、VAE 等），做条件采样即得一批候选。优点是一次给出一批**多样的**候选；难点是保证**化学有效性**与**可合成性**。
- **贝叶斯优化 / 主动学习**：把昂贵实验看作黑箱，用代理模型估计「哪些候选最有希望」，再用采集函数挑下一个去算——用最少的实验逼近最优，天然适合「实验预算有限」的科学场景。
- **可微分目标优化**：若性质模型（或物理仿真）**可微**，就直接对 $\boldsymbol x$ 做梯度上升 $\boldsymbol x\leftarrow\boldsymbol x+\eta\nabla_{\boldsymbol x}y(\boldsymbol x)$，端到端地「把结构推向想要的性能」。
:::

::: intuition 筛选与生成：两种"找分子"的方式
**筛选**是「先有库、再挑宝」：枚举或检索已知分子库，用**代理模型**打分，留下高分候选。它的天花板是**库的覆盖范围**——库里没有的好分子，你永远找不到。

**生成**是「按需造候选」：直接从数据里学出分子分布，再**采样**出新结构。它能跳出已知库，代价是要为「有效性、可合成性、稳定性」额外把关。实务上两者常配合：**生成**负责开疆，**筛选**负责收敛。
:::

::: think 生成分子的"好看"与"能用"
一个生成模型可以产出「看起来像真分子」的样本，却可能**根本合不出来**、或合成出来立刻分解。所以评价分子生成不能只看「像不像」，至少还要过三道关——**化学有效性**（价键规则成立）、**可合成性**（有可行的合成路线）、**目标性能**（真的满足设计需求）。这与[第 4 讲](lec04.md)的生成模型评价一脉相承，只是这里多了一层**物理与化学的硬约束**。把约束写进生成过程（可微的可合成性打分、物理有效性投影），往往比事后过滤更有效。
:::

## 1.4 偏微分方程与仿真加速

科学里最贵的东西之一是**数值仿真**：流体、结构、电磁、量子……归结为解**偏微分方程**（PDE）。传统数值方法（有限差分 / 有限元）精度可信，但每次改参数都要重算一遍，在需要反复迭代优化的场合吃不消。深度学习在这里分担两类工作：**加速单次求解**，以及**让求解过程可微、可优化**。

### 代理模型与神经算子

最朴素的做法是**代理模型**：训练一个网络，输入参数、输出近似解，把一次昂贵的仿真压缩成一次前向。但普通网络常常**绑死在一种离散网格**上——换了分辨率就得重训。更本质的做法是学习**解算子**：PDE 的解本身是一个「从输入函数（初值、边界、系数）到输出函数（解）」的映射。

::: def 定义 8.3 · 神经算子 {#def-8-3}
设 PDE 的解算子把输入函数 $a(\cdot)$ 映到解函数 $u(\cdot)$，即 $\mathcal G:a\mapsto u$。**神经算子**用参数化映射 $\mathcal G_\theta$ 去逼近这个**函数到函数**的映射，并希望它**与离散方式无关**（discretization-invariant）：
$$\mathcal G_\theta:a(\cdot)\mapsto u(\cdot),\qquad \mathcal G_\theta[a]\approx u\ \text{（在函数意义下接近）}.$$

两类公开代表：**傅里叶神经算子（FNO）**在频域里做线性变换（用快速傅里叶变换得到全局感受野）；**DeepONet**用两路网络（branch 编码输入函数、trunk 编码查询点）组合出解在任意点的取值。
:::

::: intuition 神经算子为什么"跟网格无关"
普通卷积网络把空间切成固定格子，学到的是「第 5 行第 7 列」这种**坐标相关**的模式。神经算子的目标是学「**作用在函数上的算符**」：输入换成另一个分辨率、另一套采样点，输出的**函数**还是同一个（只是被采样得更粗 / 更密）。这听起来抽象，其实是科学里最自然的要求——**物理规律不依赖于你用多细的网格去算它**。这一性质让神经算子既能跨分辨率泛化，也更容易与不同来源的观测对接。
:::

### 可微分仿真

比「快速预测解」更进一步的是：让整个**仿真过程可微**。数值求解器往往就是一堆可微运算的迭代；只要把这些运算写成自动微分能穿透的形式，梯度就能**从仿真的输出回传到它的输入参数**。

::: method 可微分仿真：把仿真器变成"一层网络" {#method-8-3}
把物理仿真器（分子动力学、流体、刚体 / 柔性体等）当做一个（近似）可微模块 $\boldsymbol y=\mathrm{Sim}(\boldsymbol\theta)$，其中 $\boldsymbol\theta$ 是**设计参数**（几何形状、材料、控制量）。于是

$$\nabla_{\boldsymbol\theta}\mathcal J(\boldsymbol\theta)=\frac{\partial\mathcal J}{\partial\boldsymbol y}\cdot\frac{\partial\boldsymbol y}{\partial\boldsymbol\theta},\qquad \boldsymbol\theta\leftarrow\boldsymbol\theta-\eta\,\nabla_{\boldsymbol\theta}\mathcal J .$$

关键在于 $\partial\boldsymbol y/\partial\boldsymbol\theta$ 由**穿过仿真器的反向传播**给出，而不是用有限差分去逐个扰动参数试。这样，「改设计」就不再是黑箱搜索，而是一个**有梯度的端到端问题**——可以塞进任何基于梯度的优化器里，和[第 1 讲](lec01.md)的反向传播是同一套机制。
:::

::: intuition 加速仿真 vs 可微分仿真：目标不同
两者常被混为一谈，其实关心的东西不同。

- **加速（代理 / 神经算子）**：目标是**又快又准地预测**解，用在「需要反复调用仿真」的场合（集合预报、参数扫描）。
- **可微**：目标是**能得到可靠的梯度**，用在「要优化设计 / 控制」的场合——哪怕仿真慢一点，只要梯度准，优化就能一步到位。

一个既快又可微的仿真器最理想，但往往要在**精度、稳定、可微**之间权衡取舍。
:::

### 物理信息网络（PINN）

还有一条路是把方程直接当损失：不用等仿真数据，让网络去满足 PDE 本身。

::: def 定义 8.4 · 物理信息神经网络（PINN） {#def-8-4}
设 PDE 写作 $\mathcal N[u](\boldsymbol x,t)=0$（$\mathcal N$ 是含空间 / 时间导数的算子），并带初始条件与边界条件。用网络 $u_\theta(\boldsymbol x,t)$ 逼近解，**把方程残差作为损失的一项**：
$$\mathcal L(\theta)=\underbrace{\mathcal L_{\text{data}}}_{\text{观测拟合}}+\lambda_r\underbrace{\frac1N\sum_{k}\bigl\lVert\mathcal N[u_\theta](\boldsymbol x_k,t_k)\bigr\rVert^2}_{\text{PDE 残差}}+\lambda_b\,\mathcal L_{\text{bc}} ,$$
其中残差项里的导数 $\partial_t u_\theta,\ \partial_x u_\theta,\dots$ 全部由**自动微分**给出（对网络输入求导），采样点 $(\boldsymbol x_k,t_k)$ 可在区域内随机取。$\lambda_r,\lambda_b$ 平衡各项。
:::

::: intuition PINN 的"软约束"是什么意思
传统数值方法把 PDE 离散化后**硬性**求解；PINN 则把「遵守方程」变成一条**要尽量降低的损失**——违反方程就罚分。好处是**几乎不需要网格**，且天然能融合稀疏观测；代价是**约束是软的**：权重 $\lambda$ 没调好，网络可能为了拟合数据而牺牲方程，或为了满足方程而偏离观测。

它与代理模型是两种哲学：**代理模型把数据当老师**（只学观测到的输入-输出），**PINN 把方程当老师**（用物理定律约束函数形状）。实践中常两者兼用——数据给方向、方程防跑偏。
:::

::: ex 例 8.2（热方程的 PINN 残差） {#ex-8-2}
一维热方程 $u_t=\alpha\,u_{xx}$（$\alpha\gt0$ 为热扩散系数）。写出用网络 $u_\theta(x,t)$ 表示时的 PDE 残差损失。

::: proof 解
把方程移项即得残差：
$$r_\theta(x,t)=\frac{\partial u_\theta}{\partial t}-\alpha\,\frac{\partial^2 u_\theta}{\partial x^2} .$$
若 $u_\theta$ 精确满足方程则 $r_\theta\equiv0$。PDE 残差损失就是采样点上残差平方的均值：
$$\mathcal L_{\text{res}}=\frac1N\sum_{k=1}^{N}\Bigl(\frac{\partial u_\theta}{\partial t}(x_k,t_k)-\alpha\,\frac{\partial^2 u_\theta}{\partial x^2}(x_k,t_k)\Bigr)^2 .$$
两个导数都由**自动微分**对输入 $x,t$ 求得（$\partial^2/\partial x^2$ 就是求两次导），无需网格差商。$\blacksquare$

**要点**：PINN 的「物理」不在网络结构里，而在**损失里**；网络本身仍是一个普通 MLP，这正是它实现简单、易与现有观测融合的原因。
:::
:::

::: think 可微分仿真的承诺与代价
承诺很诱人：把「设计」变成一个**梯度优化问题**，理论上比无梯度搜索高效得多。但有一个常被忽视的前提——**仿真得真的可微**。现实里的仿真器充满**不连续**：碰撞接触、相变、激波、离散的求解分支、`if` 判断……这些地方梯度要么**不存在**、要么只是**次梯度 / 有偏估计**，直接反传可能给出误导性的方向。

所以实务上要清醒：可微分仿真给的是**近似梯度**，用之前得验证它与数值扰动是否一致；在强不连续处，往往还得退回无梯度方法或引入可微的松弛。**「能反传」不等于「梯度可信」**。
:::

## 1.5 气候与地球科学

地球系统是典型的「高维 + 昂贵 + 缺标签」：状态向量动辄上亿（三维大气 / 海洋网格），传统数值天气预报需要巨大的超算；而卫星、雷达、**再分析**（reanalysis）又提供了**海量的历史观测场**，天然适合数据驱动。近年的公开工作（如 **GraphCast、Pangu-Weather、FourCastNet** 一类）表明，用**图神经网络 / Transformer**在历史再分析数据上训练，能在**推理速度**上显著快于传统数值模式，同时达到有竞争力的预报精度。（本教程不给具体误差数字。）

- **学习目标**：从历史状态预测未来状态（$\boldsymbol s_t\to\boldsymbol s_{t+\Delta}$），或一次前向直接预测多步。
- **为什么适合 AI**：地球网格是规则的、时空自相关的，图 / 卷积 / 注意力都能利用**局部性**与近似的**平移不变**；再分析数据量大且连续。
- **难点**：**守恒与稳定**（质量、能量不能凭空增减，误差会随步数累积）、**极端事件**（稀有但最要紧）、以及下面要说的**外推**。

::: intuition 为什么天气预报只能是概率的
大气是**混沌系统**：初始场里一点微小的误差会被指数放大（这正是「蝴蝶效应」的数学含义），因此**确定性的长期预报存在可预报性上限**。既然如此，与其给一个看起来很确定的错误数字，不如给出**分布**——用**集合预报**（多个略有差异的初始场各自演化）刻画不确定性。

深度学习在这里有天然优势：一次前向很便宜，因而可以**轻松跑几十上百个集合成员**；生成式 / 概率式的预测模型（输出分布而非单点）也直接契合这个需求。**预报的正确形式是概率，不是某个确定值。**
:::

::: think 气候外推为什么比天气更难
天气预报表面上是「外推未来」，但气候系统在几十年的尺度上是**非平稳**的：温室气体、海温、冰盖在缓慢改变，训练数据的分布**本身就在漂移**。一个在历史气候上表现很好的模型，可能在**它没见过的未来气候态**上失效。

此外，**下尺度**（downscaling，把粗网格预报细化到局地）在思想上与[第 3 讲](lec03.md)的超分辨率同源，但它对局地极值尤其敏感，而极值恰恰是训练数据里最少的那部分。于是气候 AI 的核心难题不是「拟合历史」，而是**能不能外推到训练分布之外**——这恰好引出下一节的哲学问题：**「拟合数据」与「理解机制」的区别**。
:::

## 1.6 科学发现的范式：拟合与理解

前面几节其实一直在同一条缝上做文章：**纯数据驱动**的模型擅长在**训练分布内**插值，而科学往往关心**分布外**的行为。这就逼我们回头看一个更根本的问题——模型到底学到了**相关**，还是**机制**？

- **数据驱动模型**：目标是**拟合观测**，$y\approx f_\theta(x)$。预测准，但可能只抓住了**统计相关**——换了环境就崩。
- **机制模型**：目标是**写出规律**（方程、守恒律、对称性），可解释、可外推，但往往需要简化假设、参数难定。
- **融合**：把两者接起来——用物理约束 / 等变结构把机制塞进网络（本讲反复出现的手法），或用网络去**补**机制模型算不准的部分（混合 / 残差建模），再或者用**可微分仿真**把机制与梯度连起来。

::: think "拟合 ≠ 理解"：外推是试金石
一个模型能在**它训练过的分布**上做到极高精度，说明不了它「懂」这个系统——它可能只是把观测**记住了**。真正区分这两者的实验是**外推**：把模型推到**训练分布之外**（更极端的温度、没见过的尺度、全新的材料），再问它是否仍然遵守物理。

**归纳偏置决定能不能外推**：把对称性、守恒律、方程残差这类**不随环境改变**的约束写进模型，就是在替外推「上保险」。反过来，一个只有大数据、没有任何物理先验的模型，往往在插值上无敌、在外推上一败涂地。所以在科学里，**「预测准」是必要条件，不是充分条件**——你还得能说清它凭什么准、又会在哪里失效。
:::

::: preview 与后续的连接
本讲把深度学习的「对象」从人类数据换成了**自然**，靠的是两把钥匙：**结构化的先验**（共进化的接触信息、旋转平移的等变性、PDE 残差）与**可微分**（端到端结构预测、可微分仿真、PINN）。这两条线会在后续汇合：[第 9 讲](lec09.md)讲**规模**——当模型与数据都要放大到超算级别，怎么用并行与通信把它们训起来，正是本讲这些科学大模型（气候、材料、结构）的工程底座；本讲的**等变网络**与**生成式设计**，则分别是[第 3 讲](lec03.md)几何先验与[第 4 讲](lec04.md)生成模型的科学延伸。回头再看[第 1 讲](lec01.md)的「结构 + 损失 + 梯度下降」，你会发现本讲做的，只是**把物理写进了结构、把方程写进了损失**。
:::

## 1.7 本讲陷阱

::: errata 常见误解清单
1. **「能预测」就当成「能解释」**：模型把观测拟合得很好，只能说明它在**训练分布内**抓住了相关；这既不等价于发现了机制，也不保证它在**新条件下**还成立。区分二者要靠外推实验，而不是训练 / 测试精度。
2. **「外推」当成「插值」**：在训练数据覆盖范围内的漂亮分数，与分布外的表现是两回事。科学最关心的恰恰是**分布外**（新材料、极端气候、更长时间），别拿榜上分数代替外推证据。
3. **物理约束只是「装饰」**：把 $\mathcal L_{\text{res}}$ 加上去不等于模型就守物理。$\lambda$ 没调好，网络会**一边拟合数据一边违反方程**；物理约束是**软**的，需要验证残差、检查守恒，而不是加一项就完事。
4. **对称性 / 归纳偏置可以不要、靠数据堆**：忽略等变性，等于让模型从零学「旋转平移的分子是一回事」。有对称性的任务**应把对称性写进结构**；纯堆数据既浪费样本，也更难外推。
5. **可微分仿真的梯度就是真梯度**：接触、相变、激波、离散分支处梯度**不存在或有偏**，反传得到的是**近似 / 次梯度**。用之前务必与数值扰动对一遍，别把误导性方向当真。
6. **生成分子只看「像不像」**：生成的样本可能化学上无效、合不出来、或一合成就分解。评价必须同时过**有效性、可合成性、目标性能**三关。
7. **把单点确定性预测当结论**：科学预测（尤其天气 / 气候）本质带不确定性，混沌系统更是如此。只给确定性输出、不给分布 / 集合，容易**低估风险**——极端事件往往藏在尾部。
8. **拿测试集当真实验**：模型在历史数据上的测试分数，不等于它在**真实实验 / 真实未来**里的表现。数据的**分布漂移**（气候在变、新体系没被覆盖）会让「测得好」与「用得好」之间留一道鸿沟。
:::

## 1.8 本讲小结

**三句话带走**：

1. AI for Science 的核心是把**实验试错**变成**可微分推断**：用网络拟合高维映射，用自动微分把仿真与物理方程变成**可优化**的模块。
2. 两把钥匙反复出现——**结构化的先验**（共进化的接触信息、旋转平移的等变性、PDE 残差）与**可微分**（端到端结构预测、可微分仿真、PINN）；它们分别解决**样本效率**与**优化效率**。
3. 科学里的好模型不止要**拟合数据**，更要**能外推、守物理**：把对称性、守恒、方程写进模型，是用**归纳偏置**为外推上保险；**「拟合 ≠ 理解」，外推是试金石**。

**与后续的连接**：本讲把[第 1 讲](lec01.md)的「结构 + 损失 + 梯度下降」原样搬到了科学问题上——只是把**物理**写进了结构，把**方程**写进了损失。等变网络接的是[第 3 讲](lec03.md)的几何先验与卷积的对称性思想；分子生成接的是[第 4 讲](lec04.md)的扩散 / 生成模型；而要把这些研究级大模型（结构预测、气候预报、材料设计）真正训起来，靠的是[第 9 讲](lec09.md)的**大规模并行与通信**——科学模型的规模，正是并行训练技术的下一个战场。
