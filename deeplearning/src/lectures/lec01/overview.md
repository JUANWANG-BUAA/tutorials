# 第 1 讲导览 · 深度学习导论

## 这一讲要解决的真实问题

训练一个深度学习模型，最常见的失败不是「模型不够大」，而是**四个环节中有一个没接上**：结构、损失、梯度、泛化。结构决定了模型能表达什么函数；损失决定了「什么叫好」；梯度决定了参数能不能朝好的方向移动；泛化决定了训练集上的好成绩能不能带到没见过的数据上。这四件事在今天被框架封装成了三行代码（`model(x)`、`loss.backward()`、`opt.step()`），封装得太好，以至于出错时绝大多数人不知道从哪一环查起。第 1 讲的全部目的，就是把这四环拆开、逐环写清楚——后面的八讲都只是在「结构」这一环上换形状。

母本 MIT 6.S191 的第一讲讲次（Lecture 1: Introduction to Deep Learning）在一节课里从感知机讲到反向传播，重点是**建立直觉**，把推导、初始化、归一化层、优化器细节都留给学生自己补。本教程与它的关系是：**沿用它的骨架与术语，把课堂上省略的中间步骤补齐**，并把母本录播年代之后成为默认实践的东西（AdamW、RMSNorm、SwiGLU、大批量训练的线性缩放规则、双下降现象）归位到相应小节。凡是超出母本范围的内容，本教程会明确标注那是「工程惯例」还是「本教程的推理」。母本配套的 Lab（`github.com/aamini/introtodeeplearning`）对应的入门实验，本书组织为 [Lab 1](../../labs/lab1.md)。

## 七节一览

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[1.1 从神经元到感知机](sec11.md)** | 一个神经元的数学形式与能力边界是什么？ | 神经元 = 加权求和 + 偏置 + 非线性；单层的天花板是**线性可分**，XOR 是最小反例 | 以为「换更光滑的激活」就能让单层变强——能力没变，变的只是可训练性 |
| **[1.2 多层感知机与通用逼近](sec12.md)** | 把单元堆成层之后，表达能力涨在哪、涨到什么程度？ | 前向是逐层「线性 + 非线性」；通用逼近只保证**存在**，不保证宽度可寻、可训练、样本高效 | 把通用逼近定理当作「随便建个大网络就能逼近任何函数」的工程保证 |
| **[1.3 激活函数：非线性从哪来](sec13.md)** | 为什么隐藏层不能用 Sigmoid？现代默认用什么？ | 梯度要**连乘**每层导数；Sigmoid 导数上限 $\tfrac14$ 是深层不可训的直接原因；ReLU 族不饱和但有死亡问题；现代大模型默认 SwiGLU + RMSNorm | 输出层也用 ReLU 族；把 ReLU 的「稀疏」当成普遍优点；以为 GELU / SiLU 一定比 ReLU 好 |
| **[1.4 损失函数：把任务翻译成优化目标](sec14.md)** | 损失从哪来？为什么分类不用 MSE？ | 损失是负对数似然；不同的输出分布导出不同的损失；交叉熵在「错误且自信」时惩罚最陡 | 网络里加了 `Softmax` 又用 `CrossEntropyLoss`（做了两次）；回归数据有离群点时仍用 MSE |
| **[1.5 梯度下降与反向传播](sec15.md)** | 上百万参数的梯度怎么在有限时间里全算出来？ | 反向传播 = 链式法则 + **中间结果复用**，代价从 $O(\text{参数量})$ 次前向降到 $O(1)$ 次前向 + $O(1)$ 次反向 | 把反向传播当成「另一种数学」；忘了清空梯度（累加）；没做梯度检查就相信实现 |
| **[1.6 优化器：从 SGD 到 AdamW](sec16.md)** | 为什么需要动量、自适应学习率和解耦权重衰减？ | 优化器改的是**方向与每参数步长**；AdamW 修正了 Adam 把 L2 正则一起自适应缩放的错误 | 以为换了 Adam 就不用调学习率；学习率与批大小只改一个；梯度没裁剪就开混合精度 |
| **[1.7 泛化、正则化与归一化](sec17.md)** | 训练集上对了，为什么测试集上错？ | 泛化误差 = 近似误差 + 估计误差；正则化是**能力预算的再分配**；归一化层改变的是优化条件数而不只是「稳定数值」；深度时代还有双下降 | 用验证集调参又用验证集报结果（数据泄漏）；把 BatchNorm 用在变长序列或小批量上 |

## 本讲的主线与「一条主线」

> **一条主线**：任何深度网络的训练都可以拆成「**定义结构 → 定义损失 → 用梯度下降最小化损失**」三步；反向传播只是链式法则在计算图上的高效实现，而泛化是这三步之外、由数据与正则化共同决定的第四条约束。

| 步骤 | 本讲对应节 | 出错时的典型症状 |
|:--|:--|:--|
| 定义结构 | [1.2](sec12.md)、[1.3](sec13.md) | 形状报错、深层训练不动、单元大量死亡 |
| 定义损失 | [1.4](sec14.md) | 收敛慢、概率过度自信、少数类被忽略 |
| 最小化损失 | [1.5](sec15.md)、[1.6](sec16.md) | 损失不降 / 发散 / 震荡、梯度范数爆炸 |
| 带得走吗 | [1.7](sec17.md) | 训练好、验证差；离线好、线上差 |
