**一句话**：生成建模就是学一个分布 $p(\boldsymbol x)$ 并**从它采样**；四副骨架各用一招逼近它——AE 只会重建（潜空间无结构）→ VAE 用「重建 − KL」把潜空间变成可采样空间（靠**重参数化**训练）→ GAN 用对抗博弈换锐利样本（但脆弱、会坍塌）→ 扩散用**多步去噪回归**换稳定与高质量（代价是采样慢）。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **判别 vs 生成** | 判别学 $p(y\mid\boldsymbol x)$（给标签）；生成学 $p(\boldsymbol x)$（密度 + 采样） |
| **生成三问** | ① 能给出 $p(\boldsymbol x)$ 吗 ② 能从 $p(\boldsymbol x)$ 采样吗 ③ 潜表示可用吗 |
| **能重建 ≠ 能采样** | 自编码器只在训练点附近定义了解码器；潜空间没有概率结构，从先验采样得到的是噪声/垃圾 |
| **自编码器** | 编码 $z=f_\phi(\boldsymbol x)$ + 解码 $\hat{\boldsymbol x}=g_\theta(z)$，损失 $\lVert\boldsymbol x-\hat{\boldsymbol x}\rVert^2$；为压缩而生，不为生成 |
| **VAE 先验/后验** | 先验 $p(z)=\mathcal N(0,I)$；近似后验 $q_\phi(z\mid\boldsymbol x)=\mathcal N\bigl(\mu_\phi(\boldsymbol x),\operatorname{diag}(\sigma_\phi^2(\boldsymbol x))\bigr)$ |
| **ELBO** | $\mathcal L_{\mathrm{ELBO}}=\mathbb E_{q}\bigl[\log p_\theta(\boldsymbol x\mid z)\bigr]-\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p(z)\bigr)$，是 $\log p(\boldsymbol x)$ 的下界；缺口恰为 $\mathrm{KL}(q_\phi(z\mid\boldsymbol x)\|p_\theta(z\mid\boldsymbol x))\ge0$ |
| **重参数化** | $z=\mu+\sigma\odot\varepsilon,\ \varepsilon\sim\mathcal N(0,I)$：把随机性移出 $\phi$ 的求导路径，使采样可导、梯度方差低 |
| **KL 闭式** | $\mathrm{KL}\bigl(\mathcal N(\mu,\operatorname{diag}(\sigma^2))\,\|\,\mathcal N(0,I)\bigr)=\frac12\sum_j\bigl(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2\bigr)$ |
| **VAE 损失** | $-\mathrm{ELBO}$ = 重建项（高斯解码器下等价于 MSE，二值像素用 BCE）+ KL 正则；$\beta$ 可调两项权重 |
| **GAN 目标** | $\min_G\max_D\ \mathbb E_{\boldsymbol x}\bigl[\log D(\boldsymbol x)\bigr]+\mathbb E_{z}\bigl[\log\bigl(1-D(G(z))\bigr)\bigr]$ |
| **最优 D 与 JS** | $D^\star=\dfrac{p_{\text{data}}}{p_{\text{data}}+p_g}$，代回得 $V(D^\star,G)=-\log4+2\,\mathrm{JSD}\bigl(p_{\text{data}}\,\|\,p_g\bigr)$ |
| **GAN 的坑** | 鞍点博弈 → 训练震荡、梯度消失、**模式坍塌**；无显式似然，评估靠代理指标 |
| **扩散前向** | $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon$，其中 $\bar\alpha_t=\prod_{s\le t}(1-\beta_s)$ |
| **扩散训练** | 预测所加噪声的 MSE：$\mathbb E_{t,x_0,\varepsilon}\bigl[\lVert\varepsilon-\varepsilon_\theta(x_t,t)\rVert^2\bigr]$ |
| **扩散采样** | 从 $x_T\sim\mathcal N(0,I)$ 起逐步去噪 $T$ 次；稳、质量高、可控，但**慢**（$T$ 次前向） |
| **取舍四轴** | 似然 · 质量 · 稳定性 · 采样代价：VAE（有 / 偏糊 / 稳 / 快）、GAN（无 / 锐 / 脆 / 快）、扩散（有 / 高 / 稳 / 慢） |

**最该记住的四个判断**：① 生成模型的终极标准是「能不能从学到的分布里**采样**」，而不只是「能不能重建」；② VAE 是三件套——**先验 $p(z)$** 定采样起点、**ELBO** 定优化目标、**重参数化**让目标可导，缺一不可；③ GAN 的锐利来自**对抗**，脆弱也来自对抗：鞍点没有稳定的收敛保证，模式坍塌是结构性问题而非调参疏漏；④ 扩散把「生成」拆成「多步去噪回归」，用**采样次数**换稳定与质量，是当前图像、视频、机器人动作生成的主流选择。

:::

## 4.1 生成建模要做什么

前三讲的模型都是**判别式**的：学一个从输入到标签的映射，回答「这个 $\boldsymbol x$ 是哪一类」。生成式模型问的是另一个问题：**这批数据本身的分布长什么样**？

::: def 定义 4.1 · 判别模型与生成模型 {#def-4-1}
**判别模型**（discriminative）直接学条件分布 $p(y\mid\boldsymbol x)$ 或决策边界，只关心「给定输入该输出什么标签」。

**生成模型**（generative）则学数据自身的分布 $p(\boldsymbol x)$（或联合分布 $p(\boldsymbol x,y)$），它要满足两件事：

1. **密度估计**：对任意 $\boldsymbol x$ 能给出 $p(\boldsymbol x)$（或它的下界 / 相对分数）；
2. **采样**：能从 $p(\boldsymbol x)$ 中抽出**没见过**的新样本 $\boldsymbol x\sim p(\boldsymbol x)$。
:::

判别模型能做的事很直接：分类、回归。生成模型则打开了另外三扇门——**采样**（造新样本、数据增强、超分辨率）、**密度估计**（检测离群点、给样本打「是否真实」的分数）、**潜表示**（把高维数据压到低维、可编辑、可控生成）。本讲的主线是前两件事，落脚点在**采样**。

这里最容易混淆的一步是先分清：**「能重建」和「能采样」根本不是一回事**。

::: intuition 「能重建」为什么远不等于「能采样」
一个自编码器把训练图压成潜码 $z$、再解回来，重建得几乎一模一样——看上去「学会了这批数据」。但它的潜空间是**训练时被迫学出来的一个坐标系**，并没有任何概率含义：
- 哪些 $z$ 是「合法」的？训练里出现过的那些，它们在潜空间里可能挤成几个孤立的团；
- 两个团**中间**的区域呢？解码器从没在那里被训练过，输出纯粹是外推，往往是无意义的糊团；
- 干脆**随机**取一个 $z$（比如从 $\mathcal N(0,I)$ 采）呢？它大概率落在这些团之外的「荒原」上，解码出垃圾。

所以「重建好」只证明模型记住了**怎么把见过的点压回来**，完全不保证能够在潜空间里「无中生有」地采样。要能采样，就必须让**整个潜空间都有明确的概率含义**——这正是下一节 VAE 要修的问题。
:::

## 4.2 自编码器：压缩，不是生成

**自编码器**（Autoencoder, AE）是生成模型一族里最简单的骨架，也是理解后面所有模型的起点。

::: def 定义 4.2 · 自编码器（autoencoder） {#def-4-2}
自编码器由两部分组成：**编码器**把数据压成低维潜码，**解码器**再把它还原回数据空间。
$$z=f_\phi(\boldsymbol x)\ \ (\text{编码}),\qquad \hat{\boldsymbol x}=g_\theta(z)\ \ (\text{解码}).$$
训练只用一个**重建损失**，让输出逼近输入：
$$\mathcal L_{\mathrm{AE}}=\mathbb E_{\boldsymbol x}\bigl[\lVert\boldsymbol x-g_\theta(f_\phi(\boldsymbol x))\rVert^2\bigr].$$
（连续像素用 MSE，二值像素可换成逐像素交叉熵。）
:::

直觉上，AE 是一个**有损压缩器**：如果潜维远小于数据维，网络只能保留数据最主要的成分，重建过程本身迫使它学出紧凑的表示。它的价值在于**表示学习**（降维、去噪、特征提取），而不是生成。

那它为什么当不了生成模型？把问题拆开看，缺的是「一个关于 $z$ 的**先验分布**」。

::: intuition 潜空间为什么必须「有分布」
生成的标准流程应该是两步：先从潜空间里**按某个分布采一个 $z$**，再解码成样本。AE 只定义了第一步的**反向**——给定 $\boldsymbol x$ 去找 $z$；它从未声明「$z$ 服从什么分布」。于是：
- **无分布可采**：采样要求 $z\sim$ 某个已知分布，AE 给不出；
- **空间不连续、无结构**：编码器是一个高度非线性的映射，训练点附近的潜码分布稀疏且不规则，团与团之间是空的；解码器在这些空洞上的行为无约束；
- **对潜码大小极其敏感**：不正常的 $z$（哪怕只是几个坐标偏一点）就会产生荒谬的输出。

一句话：AE 学到的是一张**只在对数据有效的窄带上成立的编码—解码表**，而不是一个覆盖整个潜空间的概率模型。要让「先验采样 → 解码」这条链路成立，就得**强迫潜空间整体服从一个简单分布**——把它「填满、变连续」。
:::

## 4.3 变分自编码器：把潜空间变成可采样的空间

**变分自编码器**（Variational Autoencoder, VAE）的修补思路很直接：给潜空间**指定一个先验**，再强迫编码结果贴近它。这样整个潜空间都有定义，我们就能从先验里随便采点、解码出新样本。

::: def 定义 4.3 · 变分自编码器与 ELBO {#def-4-3}
VAE 给潜变量指定一个**简单先验**，并让编码器输出一个**分布**而不是一个点：

- **先验**：$p(z)=\mathcal N(0,I)$；
- **近似后验（编码器）**：$q_\phi(z\mid\boldsymbol x)=\mathcal N\bigl(\mu_\phi(\boldsymbol x),\operatorname{diag}(\sigma_\phi^2(\boldsymbol x))\bigr)$；
- **似然（解码器）**：$p_\theta(\boldsymbol x\mid z)$，常取高斯 $\mathcal N\bigl(g_\theta(z),\sigma^2I\bigr)$ 或 Bernoulli。

我们要最大化数据的对数似然 $\log p_\theta(\boldsymbol x)=\log\int p_\theta(\boldsymbol x\mid z)\,p(z)\,dz$，但这个积分对任意网络不可解。VAE 转而最大化它的**证据下界**（Evidence Lower BOund, ELBO）
$$\mathcal L_{\mathrm{ELBO}}=\underbrace{\mathbb E_{q_\phi(z\mid\boldsymbol x)}\bigl[\log p_\theta(\boldsymbol x\mid z)\bigr]}_{\text{重建项}}-\underbrace{\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p(z)\bigr)}_{\text{正则项}} .$$
训练目标是最大化 $\mathcal L_{\mathrm{ELBO}}$，等价于最小化 $\mathcal L_{\mathrm{VAE}}=-\mathcal L_{\mathrm{ELBO}}$。
:::

读者现在可能有两个立刻要问的问题：ELBO 是怎么冒出来的？为什么是它？下面补上推导。

::: thm 定理 4.1 · ELBO 是 log 似然的下界 {#thm-4-1}
对任意分布 $q_\phi(z\mid\boldsymbol x)$（不必是真后验），有
$$\log p_\theta(\boldsymbol x)\ \ge\ \mathcal L_{\mathrm{ELBO}}=\mathbb E_{q_\phi(z\mid\boldsymbol x)}\bigl[\log p_\theta(\boldsymbol x\mid z)\bigr]-\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p(z)\bigr),$$
且缺口恰为近似后验与真后验的距离：
$$\log p_\theta(\boldsymbol x)-\mathcal L_{\mathrm{ELBO}}=\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p_\theta(z\mid\boldsymbol x)\bigr)\ \ge\ 0 .$$
:::

::: proof 推导（从 log 似然到 ELBO）
目标不可直接算，因为要对全部潜变量积分：
$$\log p_\theta(\boldsymbol x)=\log\int p_\theta(\boldsymbol x\mid z)\,p(z)\,dz .$$
乘除同一个 $q_\phi(z\mid\boldsymbol x)$（把积分写成对它求期望），再用 Jensen 不等式把 $\log$ 移进期望：
$$\log p_\theta(\boldsymbol x)=\log\mathbb E_{q_\phi(z\mid\boldsymbol x)}\!\left[\frac{p_\theta(\boldsymbol x\mid z)\,p(z)}{q_\phi(z\mid\boldsymbol x)}\right]\ \ge\ \mathbb E_{q_\phi(z\mid\boldsymbol x)}\!\left[\log\frac{p_\theta(\boldsymbol x\mid z)\,p(z)}{q_\phi(z\mid\boldsymbol x)}\right].$$
把右边按 $\log(ab)=\log a+\log b$ 拆开，第二项正好凑出一个 KL：
$$\mathbb E_q\bigl[\log p_\theta(\boldsymbol x\mid z)\bigr]+\mathbb E_q\!\left[\log\frac{p(z)}{q_\phi(z\mid\boldsymbol x)}\right]=\underbrace{\mathbb E_q\bigl[\log p_\theta(\boldsymbol x\mid z)\bigr]}_{\text{重建项}}-\underbrace{\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p(z)\bigr)}_{\text{正则项}} .$$
**缺口为什么是那个 KL**：由 $\log p_\theta(\boldsymbol x)=\mathbb E_q[\log p_\theta(\boldsymbol x)]$ 且 $p_\theta(\boldsymbol x)=\dfrac{p_\theta(\boldsymbol x,z)}{p_\theta(z\mid\boldsymbol x)}$，有
$$\log p_\theta(\boldsymbol x)=\mathbb E_q\!\left[\log\frac{p_\theta(\boldsymbol x,z)}{q_\phi(z\mid\boldsymbol x)}\right]+\mathbb E_q\!\left[\log\frac{q_\phi(z\mid\boldsymbol x)}{p_\theta(z\mid\boldsymbol x)}\right]=\mathcal L_{\mathrm{ELBO}}+\mathrm{KL}\bigl(q_\phi(z\mid\boldsymbol x)\,\|\,p_\theta(z\mid\boldsymbol x)\bigr).$$
Jensen 取等号的条件正是 $q_\phi(z\mid\boldsymbol x)=p_\theta(z\mid\boldsymbol x)$：**近似后验越贴近真后验，下界越紧**。$\blacksquare$
:::

现在两个具体障碍要跨过去才能真的训练：期望里含「从 $q_\phi$ 中采样」这一步，怎么对 $\phi$ 求导？KL 项又怎么算？

::: method 重参数化技巧（reparameterization trick） {#method-4-1}
**障碍**：重建项是 $\mathbb E_{z\sim q_\phi(z\mid\boldsymbol x)}[\cdot]$，求梯度时要面对
$$\nabla_\phi\,\mathbb E_{z\sim q_\phi(z\mid\boldsymbol x)}\bigl[f(z)\bigr],$$
而被求期望的**分布本身依赖 $\phi$**，「采样」这一步在计算图上是个不可导的断点。用 REINFORCE 型的对数导数估计 $\mathbb E_q\bigl[f(z)\nabla_\phi\log q_\phi(z\mid\boldsymbol x)\bigr]$ 虽然无偏，但方差极大，训练慢到不可用。

**解法**：把随机性**搬出**求导路径。把采样写成「一份与 $\phi$ 无关的噪声」经确定性变换：
$$z=\mu_\phi(\boldsymbol x)+\sigma_\phi(\boldsymbol x)\odot\varepsilon,\qquad \varepsilon\sim\mathcal N(0,I).$$
于是期望变成对 $\varepsilon$ 的期望，$\phi$ 只出现在确定性路径上，梯度可以直接穿过去：
$$\nabla_\phi\,\mathbb E_{z\sim q_\phi}\bigl[f(z)\bigr]=\mathbb E_{\varepsilon\sim\mathcal N(0,I)}\bigl[\nabla_z f(z)\cdot\nabla_\phi\bigl(\mu_\phi(\boldsymbol x)+\sigma_\phi(\boldsymbol x)\odot\varepsilon\bigr)\bigr].$$
采样节点现在就是一个「加一份独立高斯噪声」的可微运算，普通反向传播即可。**这是 VAE 能端到端训练的关键**，而且几乎不增加计算成本。

**为什么这就等于「采样可导」**：$\varepsilon$ 的分布不依赖任何参数，参数 $\phi$ 的影响全部通过 $\mu_\phi,\sigma_\phi$ 这两个确定性函数注入。改变 $\phi$ 只是把同一份噪声「平移伸缩」，梯度自然可算。
:::

::: prop 命题 4.1 · 先验与对角高斯后验的 KL 闭式 {#prop-4-1}
当 $p(z)=\mathcal N(0,I)$、$q_\phi(z\mid\boldsymbol x)=\mathcal N(\mu,\operatorname{diag}(\sigma^2))$ 时，KL 项有闭式解，逐维求和即可：
$$\mathrm{KL}\bigl(\mathcal N(\mu,\operatorname{diag}(\sigma^2))\,\|\,\mathcal N(0,I)\bigr)=\frac12\sum_{j=1}^{d}\Bigl(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2\Bigr).$$
:::

KL 有闭式这一点至关重要：**正则项不需要采样、不需要 Monte Carlo**，可以直接算；只有重建项需要采样（用 [@method-4-1] 让它可以求导）。于是 VAE 的一步训练就是「采一个 $\varepsilon$ → 前向解码 → 算 $\lVert\boldsymbol x-\hat{\boldsymbol x}\rVert^2$ → 加上闭式 KL → 反向传播」，干净利落。

::: ex 例 4.1 · 手算一个样本的 VAE 损失 {#ex-4-1}
设潜维 $d=2$，某样本编码得到 $\mu=(1.0,\,-0.5)$、$\sigma=(0.5,\,2.0)$；解码的平均重建误差为 $\lVert\boldsymbol x-g_\theta(z)\rVert^2=0.36$（取 $\sigma_x^2=1$ 的高斯解码器）。求这一样本的 $-\mathrm{ELBO}$。

::: proof 解
**KL 项**（用 [@prop-4-1]）。先算 $\sum_j\mu_j^2=1^2+(-0.5)^2=1.25$。再算 $\sum_j\sigma_j^2=0.25+4=4.25$。对数项 $\sum_j\log\sigma_j^2=\log(0.25\cdot4)=\log1=0$。于是
$$\mathrm{KL}=\frac12\bigl(1.25+4.25-2-0\bigr)=\frac12\times3.5=1.75 .$$
**重建项**。固定方差 $\sigma_x^2=1$ 时，$-\log p_\theta(\boldsymbol x\mid z)=\frac12\lVert\boldsymbol x-g_\theta(z)\rVert^2+\text{const}=\frac12\times0.36=0.18$（忽略与 $\theta,\phi$ 无关的常数）。

**合计**：$-\mathrm{ELBO}=0.18+1.75=1.93$。可见这一个样本上 **KL 正则占了大头**——网络被推着把 $\mu$ 拉向 $0$、$\sigma$ 拉向 $1$。若把 $\sigma$ 压小（想重建更准），KL 会因 $-\log\sigma_j^2$ 增大而变贵；这就是 VAE「重建准度 vs 潜空间规整」的张力。
:::

:::

::: intuition VAE 的潜空间为什么「连续、可插值」
KL 项 $\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2)$ 是一个**双向的力**：$\mu_j^2$ 把每个样本的均值拉向原点，而 $\sigma_j^2-1-\log\sigma_j^2$ 在 $\sigma_j^2=1$ 处取最小值 $0$，把方差推向 $1$。结果是近似后验被压成一个个**互相重叠**的团，共同铺满 $\mathcal N(0,I)$ 的支撑。

于是潜空间里**没有空洞**：任意一个从先验采出的 $z$ 都落在某个样本的团附近，解码器在那里被训练过，输出合理。也正因相邻的 $z$ 解码相似，我们可以做**插值**——在两个潜码之间线性走一遍，解码结果平滑地从一张图过渡到另一张（线性插值的中间态解释性最强，是 VAE 的招牌演示）。
:::

::: think KL 项到底是「正则」还是「负担」
从优化角度看，KL 项在惩罚「编码出的后验偏离先验」，逼潜空间规整，作用类似 L2 正则：它压低了纯重建的性能，却换来了可采样性。若给它的权重乘上系数 $\beta$（$\beta$-VAE），$\beta$ 大 → 潜表示更解耦、更规整，但重建更糊；$\beta$ 小 → 重建更准，潜空间却逐渐退化成普通 AE 的样子、不再像先验。$\beta$ 因此是一个**刻意的权衡旋钮**，不是越大越好。
:::

## 4.4 生成对抗网络：用博弈换锐利

VAE 靠一个显式的似然目标工作，代价是样本偏模糊。**生成对抗网络**（Generative Adversarial Network, GAN）换了一条路：**不写似然，直接让「造假者」和「鉴定者」互相较劲**。

::: def 定义 4.4 · GAN 的极小极大目标 {#def-4-4}
GAN 有两个网络：**生成器** $G(z;\theta_g)$ 把噪声 $z\sim p_z$ 映射成样本（$p_z$ 常取 $\mathcal N(0,I)$），其诱导的分布记作 $p_g$；**判别器** $D(\boldsymbol x;\theta_d)\in(0,1)$ 输出「$\boldsymbol x$ 是真实数据的概率」。二者玩一个**极小极大博弈**：
$$\min_G\max_D\ V(D,G)=\mathbb E_{\boldsymbol x\sim p_{\text{data}}}\bigl[\log D(\boldsymbol x)\bigr]+\mathbb E_{z\sim p_z}\bigl[\log\bigl(1-D(G(z))\bigr)\bigr].$$
:::

这个目标要分开读：$D$ 想**最大化** $V$——让真实样本的 $D$ 趋近 $1$、生成样本的 $D$ 趋近 $0$；$G$ 想**最小化** $V$——让 $D(G(z))$ 趋近 $1$，也就是把假的做得让 $D$ 认不出来。二者目标相反，构成一场零和博弈。

关键问题是：这场博弈的最优点是什么？

::: thm 定理 4.2 · 最优判别器与 JS 散度 {#thm-4-2}
固定 $G$，使 $V(D,G)$ 最大的判别器为
$$D^\star(\boldsymbol x)=\frac{p_{\text{data}}(\boldsymbol x)}{p_{\text{data}}(\boldsymbol x)+p_g(\boldsymbol x)} .$$
代回 $V$，得
$$V(D^\star,G)=-\log4+2\,\mathrm{JSD}\bigl(p_{\text{data}}\,\|\,p_g\bigr),$$
其中 $\mathrm{JSD}$ 是**对称化的 KL 散度**：$\mathrm{JSD}(p\|q)=\tfrac12\mathrm{KL}(p\|m)+\tfrac12\mathrm{KL}(q\|m)$，$m=\tfrac12(p+q)$，取值在 $[0,\log2]$。因此当 $D$ 被训到最优时，$\min_G\max_D V$ 等价于**最小化数据分布与生成分布之间的 JS 散度**。
:::

::: proof 推导（最优 $D$ 与 JS 散度）
固定 $G$ 后，$p_g$ 固定，$V$ 是一个关于函数 $D(\cdot)$ 的泛函：
$$V(D)=\int\Bigl[p_{\text{data}}(\boldsymbol x)\log D(\boldsymbol x)+p_g(\boldsymbol x)\log\bigl(1-D(\boldsymbol x)\bigr)\Bigr]d\boldsymbol x .$$
被积函数只在每个 $\boldsymbol x$ 处单独依赖 $D(\boldsymbol x)$，可以**逐点**最大化。令 $a=p_{\text{data}}(\boldsymbol x)$、$b=p_g(\boldsymbol x)$，对 $a\log D+b\log(1-D)$ 关于 $D$ 求导并置零：
$$\frac{a}{D}-\frac{b}{1-D}=0\ \Longrightarrow\ D^\star(\boldsymbol x)=\frac{a}{a+b}=\frac{p_{\text{data}}(\boldsymbol x)}{p_{\text{data}}(\boldsymbol x)+p_g(\boldsymbol x)} .$$
把 $D^\star$ 代回，令 $m=\tfrac12(p_{\text{data}}+p_g)$，则 $p_{\text{data}}+p_g=2m$，有
$$V(D^\star,G)=\int\Bigl[p_{\text{data}}\log\frac{p_{\text{data}}}{m}+p_g\log\frac{p_g}{m}\Bigr]d\boldsymbol x-\log2\int(p_{\text{data}}+p_g)d\boldsymbol x=2\,\mathrm{JSD}(p_{\text{data}}\|p_g)-\log4 .$$
（两个分布都积分为 $1$，故末项为 $\log2\cdot2=\log4$；括号内积分恰为 $2\,\mathrm{JSD}$。）$\blacksquare$
:::

这个结论漂亮，却也**同时点明了 GAN 的病根**。

::: intuition GAN 为什么天生脆弱
最优判别器与 JS 散度的联系看着优雅，但 JS 散度有两个致命性质，它们在训练早期几乎必然出现：
- **支撑不重叠时梯度消失**：真实分布 $p_{\text{data}}$ 与生成分布 $p_g$ 在初始化时几乎必然落在低维流形上、彼此不重叠，此时 $\mathrm{JSD}$ 恒为 $\log2$（常数），对 $G$ 的梯度为零——**生成器一开始拿不到任何方向**；
- **判别器太强会断信号**：$D$ 一旦接近最优，$D(G(z))\approx0$，生成器原始损失 $\log(1-D(G(z)))$ 的梯度趋零，$G$ 学不动。

三条回避手段（工程上已成标配）：① 生成器改用**非饱和损失** $\max_G\mathbb E_z[\log D(G(z))]$，它在 $D(G(z))\to0$ 时梯度依然有力；② 限制判别器更新频率/容量，或加**梯度惩罚**、**谱归一化**压住它的 Lipschitz 常数；③ 用 WGAN 的 Wasserstein 距离替代 JS，让不重叠时也有梯度。

还有一个更顽固的失效模式——**模式坍塌**（mode collapse）：生成器发现「只要反复输出那几个足以骗过当前判别器的样本就够了」，于是把整个 $z$ 空间坍缩到少数几个模式上，样本多样性崩溃。它是**博弈结构**的产物：$G$ 与 $D$ 都在动，不存在一个「$G$ 停在最优」的收敛保证，最优解是一个**鞍点**而非极小点。
:::

::: think 判别器一定要训到最优吗
不需要，也**不应该**。定理 4.2 说的是「$D$ 最优时 $G$ 等价于在最小化 JS 散度」，但训练是交替的：若每步都把 $D$ 训到最优，$G$ 反而困在梯度消失区。实践中的平衡是——让 $D$ 强到能提供有区分度的信号，又弱到让 $G$ 有可用的梯度。这个「既不能太强也不能太弱」的窗口很窄，正是 GAN 调参痛苦的来源（两网学习率比、更新次数比都围绕它调）。
:::

## 4.5 扩散模型：把生成拆成多步去噪

GAN 用博弈换锐利，换来的是不稳定；VAE 用似然换稳定，换来的是模糊。**扩散模型**（diffusion model）给出第三条路：**不要一次从噪声跳到样本，而是把它拆成几百上千步「稍微去一点噪声」的小任务**。

::: def 定义 4.5 · 前向加噪与反向去噪 {#def-4-5}
**前向加噪**（不学参数，纯固定过程）：在 $T$ 步内逐步往数据里注入高斯噪声，
$$q(x_t\mid x_{t-1})=\mathcal N\Bigl(\sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\Bigr),$$
其中 $\{\beta_t\in(0,1)\}$ 是**噪声调度**（noise schedule）。记 $\alpha_t=1-\beta_t$、$\bar\alpha_t=\prod_{s=1}^{t}\alpha_s$，则任意一步都能一步到位地写出：
$$q(x_t\mid x_0)=\mathcal N\bigl(\sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\bigr)\ \Longleftrightarrow\ x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon,\quad \varepsilon\sim\mathcal N(0,I).$$
当 $T$ 足够大、$\bar\alpha_T\to0$ 时，$x_T$ 已近似纯高斯噪声。**反向去噪**（要学参数）：让网络逐步把 $x_t$ 还原成 $x_{t-1}$，
$$p_\theta(x_{t-1}\mid x_t)=\mathcal N\bigl(\mu_\theta(x_t,t),\ \Sigma_\theta(x_t,t)\bigr).$$
:::

训练目标看起来吓人（要对上百步的变分下界做优化），但化简之后**核心就是一个预测噪声的回归任务**。

::: thm 定理 4.3 · 扩散的简化训练目标（去噪回归） {#thm-4-3}
从 $t\sim\mathcal U\{1,\dots,T\}$、$x_0\sim p_{\text{data}}$、$\varepsilon\sim\mathcal N(0,I)$、$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon$ 中采样，最小化
$$\mathcal L=\mathbb E_{t,\,x_0,\,\varepsilon}\Bigl[\bigl\lVert\varepsilon-\varepsilon_\theta(x_t,t)\bigr\rVert^2\Bigr].$$
也就是说：**给网络看「加过噪的图」和「当前是第几步 $t$」，让它把当初加进去的那份噪声 $\varepsilon$ 猜出来**。（这就是 DDPM 的简化目标；完整的变分下界与它只差一个跟 $t$ 有关的权重。）
:::

::: method 采样：从纯噪声迭代去噪
训练好 $\varepsilon_\theta$ 后，采样就是一个**固定步数的迭代**：先从纯噪声出发 $x_T\sim\mathcal N(0,I)$，然后对 $t=T,\dots,1$ 依次
$$x_{t-1}=\frac{1}{\sqrt{\alpha_t}}\Bigl(x_t-\frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon_\theta(x_t,t)\Bigr)+\sigma_t\,z,\qquad z\sim\mathcal N(0,I)\ (t>1),\quad z=0\ (t=1).$$
每一步都做两件事：用网络**估计当前噪声并减掉一部分**（把样本往高密度区推），再**注入一点点新噪声**（$\sigma_t$ 项；$t=1$ 时不再加，避免最后一步破坏细节）。跑完 $T$ 步就得到一张样本。

**条件生成**很自然地接进来：把条件 $c$（文本、类别、动作）作为额外输入喂给网络 $\varepsilon_\theta(x_t,t,c)$，推理时用**无分类器引导**（classifier-free guidance）放大条件的作用：
$$\tilde\varepsilon_\theta(x_t,t,c)=\varepsilon_\theta(x_t,t,\varnothing)+w\bigl(\varepsilon_\theta(x_t,t,c)-\varepsilon_\theta(x_t,t,\varnothing)\bigr),$$
$w$ 越大越贴合条件（更「听话」），过大则多样性下降、画面过饱和——又是一个可调的取舍旋钮。
:::

::: intuition 扩散为什么既稳又高质量
一句话：**它用一个有明确答案的回归任务，替代了 GAN 那个没有稳定收敛保证的对抗博弈。**
- **训练稳**：每一步的监督信号是「我们亲手加进去的那份噪声 $\varepsilon$」——已知、无歧义。没有两个网络互相追赶，不会模式坍塌，损失曲线通常平滑、实验可复现；
- **质量高**：网络只被要求做「局部去一点噪声」这种小改动，等价于逐步逼近数据分布的**分数** $\nabla_x\log p_t(x)$（去噪方向正比于分数方向），比「从纯噪声一步生成样本」容易得多。把难任务拆成许多简单任务，是它质量的来源；
- **可控性强**：条件只须作为额外输入注入，配合无分类器引导即可精确控制生成方向；这是文本到图像、可控编辑大规模落地的直接原因；
- **代价是慢**：采样要跑 $T$ 次网络前向。**DDIM**、蒸馏、少步采样器能把 $T$ 压到个位数到几十步，代价是质量略降——扩散的每一步加速都是一次「质量 vs 速度」的交易。
:::

::: ex 例 4.2 · 手算一次加噪系数 {#ex-4-2}
给定一个极简调度 $T=4$、$\beta_1=\beta_2=\beta_3=\beta_4=0.1$，求 $t=4$ 时 $x_4$ 中信号与噪声各占多少权重。

::: proof 解
$\alpha_t=1-\beta_t=0.9$（每步相同），故
$$\bar\alpha_1=0.9,\quad \bar\alpha_2=0.81,\quad \bar\alpha_3=0.729,\quad \bar\alpha_4=0.6561 .$$
代入 $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon$，$t=4$ 时
$$\sqrt{0.6561}=0.81,\qquad \sqrt{1-0.6561}=\sqrt{0.3439}\approx0.586 .$$
即 $x_4=0.81\,x_0+0.586\,\varepsilon$：原始信号权重掉到 $0.81$，噪声权重升到约 $0.586$。随 $t$ 增大，$\bar\alpha_t$ 单调下降，信号被越来越厚的噪声淹没——这正是「$T$ 步后趋近纯噪声」的机制。$\blacksquare$
:::

## 4.6 应用谱系与取舍

四副骨架解决的是同一个问题（学 $p(\boldsymbol x)$ 并采样），但**在哪一根轴上妥协**各不相同。把取舍浓缩成一张表：

| 模型 | 显式似然 | 样本质量 | 训练稳定性 | 采样代价 | 主要风险 |
|:--|:--|:--|:--|:--|:--|
| **VAE** | 有下界（ELBO） | 偏模糊 / 平滑 | 高（重建 + KL 的回归） | 低（一次前向） | 高斯解码器 + 重建损失导致欠锐；潜维与 $\beta$ 需权衡 |
| **GAN** | 无（只有相对判别） | 锐利 | 低（鞍点博弈） | 低（一次前向） | 模式坍塌、训练震荡、梯度消失、评估困难 |
| **扩散** | 有（可写出变分下界） | 高且多样 | 高（逐步去噪回归） | 高（$T$ 次前向） | 采样慢，对噪声调度与数值细节敏感 |

怎么读这张表——**四个轴就是四句话**：

- **似然**：VAE 与扩散都优化一个可写的下界，因此能比较「谁对数据拟合得更好」；GAN 只有相对判别，没有可比的对数似然，评估必须借助代理指标（区分度、多样性等）。
- **质量**：GAN 与扩散能产出锐利细节；VAE 因为高斯解码器 + 重建平均，天生偏糊——它想「同时照顾多个可能模式」，结果画出一个平均的影子。
- **稳定性**：VAE 与扩散本质上是回归任务，训练曲线平滑、可复现；GAN 是零和博弈，能否收敛依赖精细的平衡。
- **采样代价**：VAE 与 GAN 一次前向出样本；扩散要迭代 $T$ 次，这是它最大的、也是唯一的结构性短板。

::: note 应用谱系：从图像到机器人动作
- **图像**：扩散是当前文本到图像与图像编辑的主流（在 VAE 潜空间里跑扩散还能大幅省算力）；GAN 仍在实时风格迁移、超分等「要一次前向」的场景活跃；VAE 大量退居**表示学习与压缩**的部件。
- **视频 / 音频 / 3D**：扩散把「时间维」或「视角维」当作额外的条件维度来处理，是视频与音频生成的主干方法。
- **机器人动作生成**：**扩散策略**（diffusion policy）把「动作」当成待生成的数据——以观测为条件，用扩散模型直接生成一段**动作序列（chunk）**。它相对「输出单峰高斯」的策略的优势很直接：人类演示里的动作常常是**多模态**的（同一状态有几种合理做法），而扩散天然能表达多模态分布，不会把几种模式平均成一个歪掉的「均值动作」。
- **与决策的合流**：扩散还能直接充当强化学习的**策略**，把本讲的生成能力接到 [第 5 讲](lec05.md) 的决策问题上。
- **别忘了自回归生成**：语言模型也是生成模型——学的是 $p(\text{token}_1,\dots,\text{token}_N)$，只是把它拆成 $p(\text{token}_t\mid\text{token}_{<t})$ 的连乘逐个生成（见 [第 2 讲](lec02.md)）。本讲讲的是「一次生成整个样本」的路线，自回归是另一条平行路线，二者在后续章节会合流。
:::

## 4.7 本讲陷阱

::: errata 常见误解清单
1. **「VAE 的重建损失用 MSE 就等于对数似然」**：只有当解码器取**固定方差的高斯** $p_\theta(\boldsymbol x\mid z)=\mathcal N\bigl(g_\theta(z),\sigma^2 I\bigr)$ 时，$-\log p_\theta(\boldsymbol x\mid z)$ 才等于 $\frac{1}{2\sigma^2}\lVert\boldsymbol x-g_\theta(z)\rVert^2$ 加一个与参数无关的常数；而且整个目标是 **ELBO（下界）**，不是 $\log p(\boldsymbol x)$ 本身。二值/离散像素应改用 Bernoulli 解码器 + 交叉熵（BCE）。
2. **「GAN 训不好就是代码 bug」**：极小极大博弈本身就是鞍点问题，可能震荡或发散。先按「非饱和损失 → 谱归一化 / 梯度惩罚 → 调两网学习率与更新次数比 → 减小 $D$ 容量」排查，再把矛头指向代码。
3. **「扩散模型采样一步到位」**：DDPM 需要上百到上千步迭代去噪，单步从纯噪声直接预测样本不可行。想加速要用 DDIM、蒸馏或潜空间扩散，而不是「一步生成」。
4. **把自编码器当生成模型**：普通 AE 的潜空间没有概率结构，从 $\mathcal N(0,I)$ 采一个 $z$ 再解码只会得到无意义的输出——「能重建」不等于「能采样」。
5. **采样时从后验而不是先验取 $z$**：生成阶段必须从**先验** $p(z)=\mathcal N(0,I)$ 采样；拿编码器对某张真实图的后验去解码，那是在做**重建**，不是生成。
6. **只保留 ELBO 的重建项、丢掉 KL**：这样 VAE 退化成普通 AE，潜空间重新变得无结构、不可采样。KL 项正是把后验拉向先验、让潜空间连续的那一项，不能省。
7. **把 VAE 的模糊都归咎于「模型不够大」**：模糊来自高斯解码器 + 重建损失对多个模式的**平均**效应，以及 $\beta$ 过小带来的强正则；加大网络往往无效，通常要调 $\beta$、换更锐利的解码器或改损失。
8. **扩散训练与采样用了不同的噪声调度或数值范围**：$\beta_t$、$\bar\alpha_t$ 与像素归一化（例如归到 $[-1,1]$）必须**训练与推理一致**，否则加噪/去噪的统计对不上，采样结果直接崩坏。
:::

## 4.8 本讲小结

**三句话带走**：

1. **生成建模的目标是学会 $p(\boldsymbol x)$ 并能从中采样**，与判别模型「学 $p(y\mid\boldsymbol x)$」是两条不同的路；「能重建」远不等于「能采样」——这条界线贯穿全讲。
2. 四副骨架各有一招：**AE** 只有重建、没有分布；**VAE** 用 ELBO = 重建 − KL 把潜空间变成可采样的连续空间（靠**重参数化**才使采样可导）；**GAN** 用对抗博弈逼出锐利样本，但代价是脆弱与**模式坍塌**；**扩散**把生成拆成多步**去噪回归**，稳、质量高、可控，代价是采样慢。
3. 取舍就看四个轴：**似然**（VAE / 扩散有，GAN 没有）· **质量**（GAN / 扩散锐利，VAE 偏模糊）· **稳定性**（VAE / 扩散稳，GAN 脆）· **采样代价**（VAE / GAN 一次前向，扩散 $T$ 步）。

**与后续的连接**：本讲把「预测」换成了「采样」，但用的仍是 [第 1 讲](lec01.md) 那套「结构 + 损失 + 梯度下降」的范式，只是损失从交叉熵 / MSE 换成了 ELBO、对抗目标或去噪 MSE。往后看：[第 2 讲](lec02.md) 的序列建模与注意力，其实就是**自回归生成模型**的另一条路线（把 $p(\boldsymbol x)$ 拆成条件概率连乘），与扩散的「一次生成整个样本」互补；[第 5 讲](lec05.md) 强化学习里，本讲的生成模型可以直接当**策略**（扩散策略）来生成动作；[Lab 1](../labs/lab1.md) 的音乐生成是自回归生成的入门实践，而 [Lab 3](../labs/lab3.md) 微调大语言模型，则是把本讲的生成思想用到文本这一模态上。
