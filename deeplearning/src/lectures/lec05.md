# 第 5 讲 · 深度强化学习

> 前四讲学的是「有标签」的问题：给定输入与正确答案，最小化损失。但很多任务没有答案可抄——下棋只有输赢，机器人只有「走稳了没有」，推荐系统只看到用户点没点。本讲把范式从**监督**切换到**试错**：智能体与环境交互，只拿到一个标量**奖励**。我们从 MDP 与贝尔曼方程讲起，沿两条线展开——**值方法**（Q-learning → DQN）与**策略方法**（策略梯度 → Actor-Critic → PPO），最后落到离线 RL 与 RLHF——后者正是[第 6 讲](lec06.md)、[第 7 讲](lec07.md)里大模型对齐的默认工具。读完本讲你会明白：为什么 RL 是「没有标签时怎么学」的答案，以及为什么它比监督学习难得多。

::: method[core] 10 分钟复习版 · 第 5 讲

**一句话**：强化学习把「有标签的监督」换成「**与环境交互、从奖励信号里试错**」；它的两条主干是**学价值再取贪心动作**（Q-learning / DQN）与**直接对策略求梯度**（策略梯度 / Actor-Critic / PPO），稳定化的关键分别是**经验回放 + 目标网络**与**基线降方差 + 裁剪限幅**。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **交互循环** | 观察 $s$ → 动作 $a$ → 奖励 $r$ 与新状态 $s'$；**没有标签，只有奖励** |
| **MDP** | 五元组 $(\mathcal S,\mathcal A,P,R,\gamma)$；**马尔可夫性**：未来只依赖当前 $(s,a)$ |
| **策略** | $\pi(a\vert s)$：状态到动作（分布）的映射，就是要学的东西 |
| **回报** | $G_t=\sum_{k\ge0}\gamma^{k}r_{t+k+1}$；$\gamma$ 控制视野，有效期约 $\frac1{1-\gamma}$ |
| **值函数** | $V^\pi(s)=\mathbb E_\pi[G_t\vert s_t=s]$，$Q^\pi(s,a)=\mathbb E_\pi[G_t\vert s_t=s,a_t=a]$ |
| **两函数关系** | $V^\pi(s)=\sum_a\pi(a\vert s)\,Q^\pi(s,a)$ |
| **贝尔曼（期望）** | $V^\pi(s)=\sum_a\pi(a\vert s)\bigl[r(s,a)+\gamma\sum_{s'}P(s'\vert s,a)V^\pi(s')\bigr]$ |
| **贝尔曼（最优）** | 把 $\sum_a\pi(a\vert s)$ 换成 $\max_a$，即得 $V^\ast$、$Q^\ast$ |
| **Q-learning** | $Q\leftarrow Q+\alpha\bigl[r+\gamma\max_{a'}Q(s',a')-Q\bigr]$；off-policy、自举 |
| **DQN** | 用 $Q_\theta$ 逼近；**经验回放**打散样本相关、**目标网络**冻结目标；$\varepsilon$-greedy 探索 |
| **Double DQN** | 选动作与评估动作分开，缓解 $\max$ 带来的**过高估计** |
| **策略梯度** | $\nabla_\theta J=\mathbb E\bigl[\sum_t\nabla_\theta\log\pi_\theta(a_t\vert s_t)\,Q^\pi(s_t,a_t)\bigr]$：好动作抬概率、坏动作压概率 |
| **REINFORCE** | 用 $G_t$ 代替 $Q^\pi$，无偏但**高方差** |
| **基线/优势** | 减去 $b(s)$ 不改变期望；优势 $A=Q-V$ 是最常用形式 |
| **Actor-Critic** | Actor 学 $\pi_\theta$，Critic 学 $V_\phi$，用 Critic 估计优势 → 低方差 |
| **PPO** | 裁剪目标 $\min\bigl(\rho\hat A,\ \mathrm{clip}(\rho,1-\varepsilon,1+\varepsilon)\hat A\bigr)$；限制单批更新幅度，稳定通用 |
| **离线 RL** | 只有固定数据集、不能交互；难点是分布偏移导致的过高估计 |
| **RLHF** | 偏好数据 → 奖励模型 → 用 RL 优化策略并加 KL 约束；大模型对齐的默认流程 |

**最该记住的四个判断**：① 有标签用监督，**只有奖励用 RL**；② 动作离散、能估价值 → **值方法（DQN）**，动作连续或需要随机策略 → **策略方法（PPO）**；③ 训练不稳先查两件事——**目标稳不稳**（目标网络）、**样本相关不相关**（回放）；④ **奖励是你写的、不是你要的**，上线前盯实际行为，防奖励黑客。

## 1.1 为什么需要 RL

监督学习假定每个输入都配一个「正确答案」。但大量决策问题里根本不存在这样的标签：下棋时没有哪一步被标注为「对」，只有最终输赢；机器人迈步时也没有老师告诉你「这一脚该迈多大」。这类问题中我们唯一能得到的，是一串**奖励**（reward）信号——它常常还很**稀疏**（大部分时刻为 0）、很**延迟**（赢了才见到 +1）。

::: def 定义 5.1 · 智能体-环境交互循环 {#def-5-1}
在离散时间步 $t=0,1,2,\dots$ 上，**智能体**（agent）与环境（environment）交替交互：智能体观察到状态 $s_t\in\mathcal S$，依据策略选择动作 $a_t\in\mathcal A$；环境接收动作后给出即时**奖励** $r_{t+1}\in\mathbb R$ 与**下一状态** $s_{t+1}$。如此往复，得到一条轨迹
$$\tau=(s_0,a_0,r_1,s_1,a_1,r_2,s_2,\dots).$$
与监督学习的关键差别：**没有任何标签告诉智能体哪个动作是对的**，它只能从实际经验到的奖励里反推。
:::

与监督学习相比，RL 的困难集中在这三点：

- **没有标签，只有奖励**：奖励是标量、可正可负，且**只评价结果**，不告诉你「哪里做错了」。
- **数据不是独立同分布**：训练数据由智能体自己的动作产生，策略一变，未来遇到的分布也随之漂移（[第 1 讲](lec01.md)里「样本 i.i.d.」的假设在这里完全失效）。
- **信用分配（credit assignment）困难**：赢了这一局，是开局那步妙手，还是对手失误？奖励要**跨越很长时间**才能摊到具体动作上。

::: intuition 探索与利用的根本张力
你走进一家餐厅，是点最熟悉的那道菜（**利用** exploitation，把已知的好东西吃满），还是试试没吃过的（**探索** exploration，可能发现更好的，也可能踩雷）？这两者**天然对立**：永远利用，就会困在已知的次优解里；永远探索，就永远在浪费时间试错。

这正是 RL 区别于任何监督问题的核心——**信息只能靠采样获得，而采样会消耗机会**。工程上的经典折中是 $\varepsilon$-greedy：以概率 $1-\varepsilon$ 选当前最优动作，以概率 $\varepsilon$ 随机探索，并让 $\varepsilon$ 随训练衰减（先摸清环境，再收敛到最优）。更精细的算法（UCB、Thompson 采样、熵正则）都在同一张力上做文章。
:::

::: think 为什么「多臂老虎机」是 RL 的最小模型
去掉状态、只留一个动作重复 $n$ 次的选择问题，就是**多臂老虎机**（multi-armed bandit）。它没有「延迟奖励」也没有「状态转移」，剩下的唯一难题就是**探索与利用**。所以看到 bandit 类算法时，要意识到它剥离的正是 RL 最纯粹的那一层矛盾；而完整的 RL 又额外背上了「延迟」与「非平稳数据」两个包袱。
:::

## 1.2 马尔可夫决策过程与值函数

要让「试错」变成可以推导的数学，需要给环境一个形式化描述：**马尔可夫决策过程**（Markov Decision Process, MDP）。

::: def 定义 5.2 · 马尔可夫决策过程 {#def-5-2}
一个 MDP 由五元组 $(\mathcal S,\mathcal A,P,R,\gamma)$ 给出：

- $\mathcal S$：**状态空间**；$\mathcal A$：**动作空间**。
- $P(s'\vert s,a)=\Pr\{s_{t+1}=s'\mid s_t=s,\ a_t=a\}$：**转移概率**。
- $R$：**奖励函数**，常用 $r(s,a)=\mathbb E[r_{t+1}\mid s_t=s,a_t=a]$（也可写成 $r(s,a,s')$）。
- $\gamma\in[0,1)$：**折扣因子**。

**马尔可夫性**：未来只依赖当前的状态与动作，与更早的历史无关，
$$P(s_{t+1}\mid s_t,a_t,\dots)=P(s_{t+1}\mid s_t,a_t).$$
因此 $(s_t,a_t)$ 是关于未来的一切**充分统计量**——记住当前状态就够了，不必回放整段历史。

**策略** $\pi(a\vert s)$ 是从状态到动作分布的映射（确定性策略是它的特例）。**折扣回报**从 $t$ 时刻起累计未来奖励，
$$G_t=\sum_{k=0}^{\infty}\gamma^{k}r_{t+k+1}.$$
:::

给定策略 $\pi$，我们关心两件事：站在某个状态好不好（**状态值函数**），以及站在那里做某个动作好不好（**动作值函数**）。

::: def 定义 5.3 · 值函数与动作值函数 {#def-5-3}
$$\underbrace{V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]}_{\text{状态值}},\qquad
\underbrace{Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a]}_{\text{动作值}}.$$
两者关系为 $V^\pi(s)=\sum_a\pi(a\vert s)\,Q^\pi(s,a)$：状态值就是「按策略加权平均」后的动作值。$Q^\pi$ 比 $V^\pi$ 多承载了「某动作一旦选定」的信息，因此更适合直接用于选择动作。
:::

把 $G_t$ 按「当前奖励 + 折扣的未来」递归展开，就得到 RL 的中心方程。

::: thm 定理 5.1 · 贝尔曼方程 {#thm-5-1}
**期望贝尔曼方程**（对固定策略 $\pi$）：
$$V^\pi(s)=\sum_{a}\pi(a\vert s)\Bigl[r(s,a)+\gamma\sum_{s'}P(s'\vert s,a)\,V^\pi(s')\Bigr],$$
$$Q^\pi(s,a)=r(s,a)+\gamma\sum_{s'}P(s'\vert s,a)\sum_{a'}\pi(a'\vert s')\,Q^\pi(s',a').$$
**最优贝尔曼方程**（对最优策略，把对动作的期望换成取最大）：
$$V^\ast(s)=\max_{a}\Bigl[r(s,a)+\gamma\sum_{s'}P(s'\vert s,a)\,V^\ast(s')\Bigr],\qquad
Q^\ast(s,a)=r(s,a)+\gamma\sum_{s'}P(s'\vert s,a)\max_{a'}Q^\ast(s',a').$$

::: proof 推导（期望贝尔曼方程）
由 $G_t=r_{t+1}+\gamma G_{t+1}$（自我递归），对两边取条件期望：
$$V^\pi(s)=\mathbb E_\pi[r_{t+1}+\gamma G_{t+1}\mid s_t=s]
=\sum_a\pi(a\vert s)\Bigl[r(s,a)+\gamma\,\mathbb E_\pi[G_{t+1}\mid s_t=s,a_t=a]\Bigr].$$
再用全期望公式与马尔可夫性，把内层期望写成 $\sum_{s'}P(s'\vert s,a)\,\mathbb E_\pi[G_{t+1}\mid s_{t+1}=s']=\sum_{s'}P(s'\vert s,a)V^\pi(s')$，代入即得第一式。对 $Q^\pi$ 同理展开 $r_{t+1}$ 后再对 $s'$ 与 $a'$ 求和，得到第二式。最优版只需注意：一旦拥有 $V^\ast$ 或 $Q^\ast$，最优动作就是在每一步取 $\arg\max$，故期望被 $\max$ 取代。$\blacksquare$
:::

:::

::: ex 例 5.1（折扣回报怎么算） {#ex-5-1}
某轨迹长度为 3，奖励 $r_1=r_2=r_3=1$，折扣 $\gamma=0.9$。求从 $t=0$ 出发的回报 $G_0$，并说明为什么要打折。

::: proof 解
**直接求和**：$G_0=\gamma^{0}r_1+\gamma^{1}r_2+\gamma^{2}r_3=1+0.9+0.81=2.71$。
**递归验证**：$G_1=1+0.9=1.9$，于是 $G_0=r_1+\gamma G_1=1+0.9\times1.9=2.71$，与上式一致——这正是贝尔曼方程「当前奖励 + 折扣的未来」的来源。

**为什么要折扣**：若 $\gamma=1$ 且奖励持续为 1、时域无穷，$G_0=1+1+1+\cdots$ **发散**，值函数失去定义；只要 $\gamma\lt1$ 就收敛，且等效视野约为 $\frac1{1-\gamma}$（对 $\gamma=0.9$ 约为 10 步）。折扣同时表达一种偏好：**眼前的奖励比遥远的奖励更值钱**，也降低了估计的方差。
:::

## 1.3 值方法：Q-learning 与 DQN

如果环境完全已知（$P$、$R$ 都给定），解贝尔曼最优方程就是一个动态规划问题。但真实环境里 $P$ 未知，智能体只能靠**采样**估计它。**时序差分（TD）**学习是这里的主力：用「实际走一步得到的结果」去修正当前估计，一步一更新，不必等整条轨迹结束。

::: def 定义 5.4 · Q-learning 更新 {#def-5-4}
以状态-动作值 $Q(s,a)$ 为表，每走一步就更新一次：
$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\underbrace{\Bigl[\underbrace{r_{t+1}+\gamma\max_{a'}Q(s_{t+1},a')}_{\text{TD 目标}}-Q(s_t,a_t)\Bigr]}_{\text{TD 误差 }\delta_t},$$
其中 $\alpha\in(0,1]$ 是学习率。它有三个关键词：

- **自举（bootstrapping）**：目标里用的是**当前**对 $Q(s_{t+1},\cdot)$ 的估计，而不是等真值。
- **off-policy**：行为策略（带探索的 $\varepsilon$-greedy）与目标策略（$\max$ 贪心）分离，因此可以用任意来源的经验去逼近 **最优** $Q^\ast$。
- **收敛条件**：表格形式下，只要每个 $(s,a)$ 被访问无穷多次、且步长满足 Robbins–Monro 条件（$\sum\alpha=\infty$、$\sum\alpha^2\lt\infty$），$Q$ 会收敛到 $Q^\ast$。
:::

但从图像、语言这类**高维状态**出发，一张 $Q$ 表根本存不下（状态可能是像素级连续量）。于是用神经网络逼近，这就是 **DQN**（Deep Q-Network）。可惜「直接用神经网络 + Q-learning」会剧烈震荡甚至发散，原因有二：相邻时序的样本高度**相关**，且目标会随参数更新而**移动**。DQN 的两个技巧正是针对这两点的解药。

::: method DQN 的两大稳定技巧 {#method-5-1}
**技巧一 · 经验回放（experience replay）**：把每条转移 $(s,a,r,s')$ 存入回放池 $\mathcal D$，训练时从中**随机采样**一个 mini-batch。

- 打破相邻轨迹的**时序相关**，让梯度更接近 i.i.d. 假设；
- 同一条经验能被**反复使用**，样本效率远高于用一次就丢的在线更新；
- 不同策略产生的旧数据混在一起，也天然满足 off-policy 的复用需求。

**技巧二 · 目标网络（target network）**：复制一份参数 $\theta^-$ 专门用来算 TD 目标，它**每隔 $C$ 步才与在线网络同步**（或做缓慢 Polyak 平均）：

$$\mathcal L(\theta)=\mathbb E_{(s,a,r,s')\sim\mathcal D}\Bigl[\bigl(r+\gamma\max_{a'}Q_{\theta^-}(s',a')-Q_\theta(s,a)\bigr)^2\Bigr].$$

目标里的 $\theta^-$ 在若干步内**冻结不动**，相当于把「移动靶」钉住一段时间，回归问题才稳定。**注意**：只有 $Q_\theta(s,a)$ 侧要反传梯度，$\theta^-$ 侧视为常数。

**探索**：用 $\varepsilon$-greedy 选动作——以概率 $\varepsilon$ 均匀随机、否则取 $\arg\max_a Q_\theta(s,a)$，并让 $\varepsilon$ 从 ~1.0 衰减到一个小值（如 0.05）。
:::

::: think 为什么 RL 的样本不是 i.i.d.，以及回放为什么「合法」
监督学习可以打乱数据集，是因为各样本本来就近乎独立。RL 不同：$s_{t+1}$ 由 $(s_t,a_t)$ 决定，相邻样本几乎必然强相关，直接拿它们连续更新会像反复端详同一张图——梯度被同一段轨迹主导，容易灾难性遗忘其他状态。回放池把不同时刻、不同策略的经历混合后随机抽样，等于人为地把「非平稳、相关的数据流」改造成「近似平稳的样本集合」。

它之所以**合法**，是因为 Q-learning 本身 off-policy：目标里对 $s'$ 取 $\max$，不依赖产生这条数据的那个策略。换成纯 on-policy 方法（如 REINFORCE）就不能这样随意复用旧数据了（见 [1.8 本讲陷阱](#18-本讲陷阱)）。
:::

::: intuition 取 max 为什么会让 DQN「过于乐观」
TD 目标里有一个 $\max_{a'}$。无论 $Q$ 的估计噪声是正是负，**取最大值**都会倾向挑到那些被**偶然高估**的动作，于是目标被系统性地抬高，$Q$ 值整体虚高。修正思路是**把「选动作」和「评估动作」拆开**：**Double DQN** 用在线网络 $\theta$ 选出最优动作，却用目标网络 $\theta^-$ 去评估它的价值，
$$y=r+\gamma\,Q_{\theta^-}\bigl(s',\ \arg\max_{a'}Q_\theta(s',a')\bigr).$$
这样一次噪声很难同时骗过两个网络，过高估计显著缓解。这里只需记住结论：**单网络取 $\max$ 会乐观，双网络分工可纠偏**。
:::

## 1.4 策略方法：策略梯度与 REINFORCE

值方法的思路是「先学 $Q$，再隐式地由 $\arg\max$ 得到策略」。它有两处不便：连续动作空间里 $\max_a Q(s,a)$ 不是一个查表操作，而是一个内层优化；而有些任务（如石头剪刀布）最优策略本身就是**随机**的，硬取 $\arg\max$ 反而不对。**策略方法**直接参数化策略 $\pi_\theta(a\vert s)$（例如网络输出离散动作的 softmax 概率，或高斯分布的均值方差），直接优化它。

目标很自然：最大化从初始状态出发的期望回报
$$J(\theta)=\mathbb E_{\tau\sim\pi_\theta}[G_0]=V^{\pi_\theta}(s_0).$$

::: thm 定理 5.2 · 策略梯度定理 {#thm-5-2}
对任意可微的 $\pi_\theta$，
$$\nabla_\theta J(\theta)=\mathbb E_{\pi_\theta}\Bigl[\sum_{t\ge0}\nabla_\theta\log\pi_\theta(a_t\vert s_t)\;Q^{\pi_\theta}(s_t,a_t)\Bigr].$$

::: proof 推导（对数导数技巧）
关键在于一个恒等式：$\nabla_\theta\pi_\theta(a\vert s)=\pi_\theta(a\vert s)\,\nabla_\theta\log\pi_\theta(a\vert s)$。于是对「概率 × 回报」求导时，
$$\nabla_\theta\mathbb E_{\pi_\theta}[f]=\nabla_\theta\sum_\tau p_\theta(\tau)f(\tau)=\sum_\tau p_\theta(\tau)\nabla_\theta\log p_\theta(\tau)\,f(\tau)=\mathbb E_{\pi_\theta}\bigl[f\,\nabla_\theta\log p_\theta(\tau)\bigr].$$
轨迹概率可分解为 $p_\theta(\tau)=p(s_0)\prod_t\pi_\theta(a_t\vert s_t)P(s_{t+1}\vert s_t,a_t)$，其中**转移项 $P$ 与 $\theta$ 无关**，取对数求导后全部消失，只剩 $\sum_t\nabla_\theta\log\pi_\theta(a_t\vert s_t)$。再注意到时刻 $t$ 的动作只影响**之后**的奖励，其期望即 $Q^{\pi_\theta}(s_t,a_t)$，合并即得定理。$\blacksquare$
:::

:::

这个定理的**直观极其好记**：$\nabla_\theta\log\pi_\theta(a_t\vert s_t)$ 是「想让动作 $a_t$ 出现得更频繁」的方向，它被 $Q^{\pi_\theta}$ **加权**。

::: intuition 好动作抬概率，坏动作压概率
把更新写成梯度上升 $\theta\leftarrow\theta+\eta\nabla_\theta J$：

- 若某动作的 $Q$ 为**正**，梯度把它**推高**的权重为正 → 该动作出现的概率上升；
- 若某动作的 $Q$ 为**负**（比平均还差），负号使该方向被**抑制** → 该动作概率下降。

所以策略梯度本质上是一句朴素的话：**「多做一些回报高的动作，少做一些回报低的动作」**。它不需要 $Q$ 表的 $\max$，天然适用于连续动作与随机策略——代价是它把整局**结果**归因给每一步，信噪比很差。
:::

::: method REINFORCE（蒙特卡洛策略梯度） {#method-5-2}
用一条完整轨迹里的**实际回报** $G_t$ 作为 $Q^{\pi}(s_t,a_t)$ 的无偏估计，即得最简单的策略梯度算法：

$$\nabla_\theta J(\theta)\approx\sum_{t=0}^{T-1}\nabla_\theta\log\pi_\theta(a_t\vert s_t)\,G_t,\qquad \theta\leftarrow\theta+\eta\,\nabla_\theta J(\theta).$$

```text
for episode = 1..M:
    用 π_θ 采样一条完整轨迹 τ = (s_0,a_0,r_1,...,s_{T-1})
    从后往前算回报 G_t = r_{t+1} + γ r_{t+2} + ...
    ∇J ← Σ_t ∇_θ log π_θ(a_t|s_t) · G_t
    θ ← θ + η · ∇J
```

**优点**：无偏、实现简单、无需值函数。**缺点**：$G_t$ 是单条轨迹的**噪声样本**，方差极大；且必须**等整局结束**才能更新，样本效率低。下一小节的两把钥匙——基线与 Critic——就是为了治这个病。
:::

::: method 基线：减去一个与动作无关的参考值 {#method-5-3}
对任意只依赖状态 $b(s)$，都有 $\mathbb E_{\pi}[\nabla_\theta\log\pi_\theta(a\vert s)\,b(s)]=0$（因为 $\sum_a\nabla_\theta\pi_\theta(a\vert s)=\nabla_\theta 1=0$）。所以

$$\nabla_\theta J=\mathbb E\Bigl[\sum_t\nabla_\theta\log\pi_\theta(a_t\vert s_t)\,\bigl(Q^{\pi}(s_t,a_t)-b(s_t)\bigr)\Bigr]$$

**仍是无偏的**，却把「和哪个数比」从 0 换成了一个合理的参照。取 $b=V^{\pi}(s)$ 时，括号内就是**优势函数**

$$A^{\pi}(s,a)=Q^{\pi}(s,a)-V^{\pi}(s),$$

它回答的是「**这个动作比在该状态下的平均水平好多少**」。好动作优势为正、坏动作为负，信号被归一化，方差大幅下降——这是策略梯度能真正可用的一步。
:::

## 1.5 Actor-Critic 与 PPO

基线的选择决定了方差与偏差的取舍：用整局回报 $G_t$ 无偏但方差大；用一个**学出来的**值函数则方差小、但引入了偏差。把「学策略」和「学价值」分成两个网络、互相喂饭，就是 **Actor-Critic**。

- **Actor**：策略网络 $\pi_\theta(a\vert s)$，负责「演」，按策略梯度更新。
- **Critic**：值网络 $V_\phi(s)$，负责「评」，用 TD 学习拟合真实回报，并向 Actor 提供优势估计。

最常用的优势估计是**一步 TD 残差**：
$$\hat A_t=r_{t+1}+\gamma V_\phi(s_{t+1})-V_\phi(s_t),$$
它既有 Critic 的低方差，又只需走一步就能更新（不必等整局结束）。实践中还常用 **GAE**（广义优势估计）：把多步 TD 残差做指数加权平均，通过参数 $\lambda$ 在「低方差高偏差」与「高方差低偏差」之间连续插值——记住它是「TD 残差的多步混合」即可。

朴素 Actor-Critic 的一个隐患是**步长难控**：策略梯度对步长很敏感，走大步会把策略一步推坏，而策略一坏、后续采样全废，很难恢复。**PPO**（Proximal Policy Optimization）用一个极简的**裁剪**机制解决了它，成为今天的默认算法。

::: def 定义 5.5 · PPO 的裁剪目标 {#def-5-5}
设 $\pi_{\theta_{\text{old}}}$ 是采样时用的策略，$\hat A_t$ 是优势估计，定义**概率比**
$$\rho_t(\theta)=\frac{\pi_\theta(a_t\vert s_t)}{\pi_{\theta_{\text{old}}}(a_t\vert s_t)}.$$
PPO 最大化的是**裁剪替代目标**
$$L^{\mathrm{CLIP}}(\theta)=\mathbb E_t\Bigl[\min\Bigl(\rho_t(\theta)\hat A_t,\ \ \mathrm{clip}\bigl(\rho_t(\theta),\,1-\varepsilon,\,1+\varepsilon\bigr)\hat A_t\Bigr)\Bigr],$$
其中 $\varepsilon$ 是超参数（常取 0.1~0.2）。目标是**下限** $\min$，意味着只有当「按比例缩放的优势」落在 $[1-\varepsilon,1+\varepsilon]$ 内时才会被真正奖励，超出部分被**截断**。
:::

::: intuition 裁剪到底裁掉了什么
$\rho_t$ 衡量新策略相对老策略「偏爱这个动作的程度变了多少」：$\rho_t=1$ 表示没变，$\rho_t=5$ 表示把这个动作的概率抬到了 5 倍。

- 当 $\hat A_t\gt0$（好动作）：目标希望 $\rho_t$ 越大越好，但被 $\min$ 与 $\mathrm{clip}$ 卡在 $1+\varepsilon$——**抬到一定程度就够了，再抬不给额外收益**。
- 当 $\hat A_t\lt0$（坏动作）：目标希望 $\rho_t$ 越小越好，但被卡在 $1-\varepsilon$——**压低到一定程度也不再多要**。

于是在两种情形下，越过裁剪区间的更新都**拿不到梯度**（梯度为 0），策略不会因为一个 batch 的噪声被一步推飞。这正是它替代 TRPO 的原因：**同样的「别走太远」的约束，却只需一阶梯度、实现简单、对超参数鲁棒**。

**它也是「近似 on-policy」的**：$\rho_t$ 是重要性采样比，修正了「用老策略数据估计新策略目标」的偏差，因此**同一批数据可以重复做几个 epoch 的梯度上升**，样本效率比 REINFORCE 高不少；但数据仍来自 $\pi_{\theta_{\text{old}}}$，跑完这几轮后必须**重新采样**。实际实现里除了裁剪目标，还会加价值损失（Critic 回归回报）与**熵奖励**（鼓励探索、防过早收敛）。
:::

## 1.6 前沿：离线 RL 与 RLHF

### 离线 RL：连交互都不许有

前面的方法都假定智能体可以**在线**试错、随时采集新数据。但医疗、金融、推荐、工业控制这些场景里，一次错误的探索代价高昂甚至不可逆——我们往往只有一份**早已录好的固定数据集**。这类问题叫**离线 RL**（offline RL，也叫 batch RL）。

难点是**分布偏移**：学到的策略想去尝试**数据集里没出现过**的 $(s,a)$，而 $Q$ 对它们只能靠自举**外推**，极易给出虚高的估计；策略越激进，越是往这些「没数据、估值虚高」的区域钻，形成恶性循环。主要对策是**保守地估计价值**（对数据外的动作施加惩罚）或**约束策略不偏离行为策略太远**。要点记一条即可：**离线 RL 的核心矛盾是「不能交互」，一切技巧都为了压制数据分布外的过高估计**。

### RLHF：把「人类偏好」变成奖励

前面提到，RL 需要一个奖励函数 $r$。可对于「什么样的回答更好」这种任务，没人能写出精确的数值奖励。**RLHF**（Reinforcement Learning from Human Feedback）的思路是：**先用人来定义奖励，再用 RL 去优化**。

::: method RLHF 四步流程 {#method-5-4}
1. **得到初始策略**：预训练 + 监督微调（SFT），得到参考模型 $\pi_{\text{ref}}$。
2. **收集偏好数据**：对同一个输入 $x$（如一个 prompt），让模型给出两个回答，请人类标注哪个更好，得到成对比较 $y_w\succ y_l$（$w$ 为 preferred）。
3. **训练奖励模型** $r_\phi$：用 **Bradley–Terry** 模型把「偏好概率」写成奖励差的 sigmoid，
$$\Pr(y_w\succ y_l)=\sigma\bigl(r_\phi(x,y_w)-r_\phi(x,y_l)\bigr),$$
用交叉熵（即最大化偏好数据的似然）训练 $r_\phi$。
4. **用 RL 对齐策略**：把 $r_\phi$ 当作环境奖励，用 RL（实践中大多是 PPO）优化语言模型，同时用一个 **KL 惩罚**把它约束在 $\pi_{\text{ref}}$ 附近：
$$\max_\theta\ \mathbb E_{x,\,y\sim\pi_\theta}\bigl[r_\phi(x,y)\bigr]\;-\;\beta\,\mathrm{KL}\bigl(\pi_\theta(\cdot\vert x)\,\Vert\,\pi_{\text{ref}}(\cdot\vert x)\bigr).$$
:::

::: note 为什么 RLHF 必须加 KL 惩罚
奖励模型 $r_\phi$ 只是对人类偏好的**代理**，它在训练数据分布外并不可靠。如果只最大化 $r_\phi$，策略会找到奖励模型的**漏洞**：产出人类其实不喜欢的文本，却拿到很高分——这就是「**奖励黑客**」在语言模型上的实例。KL 项把策略拴在 $\pi_{\text{ref}}$ 附近，等价于限制「探索范围」，既防止跑偏，也保住语言本身的流畅与多样性。**权衡**：$\beta$ 太大则学不动、几乎等于不训练，太小则会被奖励模型带偏。
:::

::: preview RLHF 与后续两讲的关系
RLHF 是「用 RL 驯服大模型」的范式，也是本讲与后续内容的**接缝**：[第 6 讲](lec06.md)讲规模为什么会带来能力、大模型如何训练；[第 7 讲](lec07.md)继续追问「怎样让系统可控、可信、符合人类价值」——对齐、可控性与安全，本质上都是在改进「奖励该由谁定义、如何定义」。把这一节记住，第 6、7 讲里的对齐部分就有了骨架。

相关的延伸：用**AI 反馈**（RLAIF）替代人标、用**直接偏好优化**（DPO）跳过显式奖励模型、把 RLHF 推向**多模态**与**工具/智能体**场景——它们共享同一套「偏好 → 目标 → 优化」的骨架。
:::

## 1.7 示例：一个简单环境的训练循环

下面是一个 **DQN 风格**的最小训练循环，刻意把前面所有概念标出来。读的时候请对照：哪一步在**收集非平稳数据**、哪一步在处理**样本相关**、哪一步在处理**移动目标**、哪一步在**探索**。

::: method 训练循环（伪代码） {#method-5-5}
```text
初始化：在线网络 Q_θ、目标网络 Q_{θ⁻} ← Q_θ、回放池 D、探索率 ε ← 1.0
for episode = 1 .. M:                    # 一个 episode 是一条完整轨迹
    s ← env.reset()
    while s 不是终止状态:
        # (1) 探索：ε-greedy 选动作
        a ← 以概率 ε 均匀随机；否则 argmax_a Q_θ(s, a)
        # (2) 与环境交互 —— 这一步在改变未来数据的分布（非 i.i.d. 的来源）
        s', r, done ← env.step(a)
        D.add((s, a, r, s', done))       # 存入回放池，旧经验可反复使用
        # (3) 从池中随机采样 mini-batch —— 打破时序相关（经验回放）
        batch ← D.sample(B)
        # (4) 用冻结的目标网络构造 TD 目标 —— 钉住“移动靶”（目标网络）
        y ← r + γ · (1 - done) · max_{a'} Q_{θ⁻}(s', a')
        L ← mean( (y - Q_θ(s, a))² )      # 只对 θ 求梯度，θ⁻ 视为常数
        θ ← θ - η · ∇_θ L                 # 反向传播（第 1 讲）
        s ← s'
    # (5) 周期性同步目标网络、衰减探索率
    每 C 步:  θ⁻ ← θ
    ε ← max(ε_min, ε · decay)
```

**评估与汇报**（RL 里最容易被忽视的一步）：在训练期间定期用**确定性策略**（$\arg\max Q$ 或 $\varepsilon=0$）跑若干局，记录**平均回报与标准差**，并跨多个随机种子重复。RL 结果对种子极其敏感，单条曲线不足以下结论（见[本讲陷阱](#18-本讲陷阱)）。

**变体**：把 (1)(4) 换成「用当前策略采样一批轨迹 → 用 Critic 估优势 → 优化 PPO 裁剪目标」，就得到一个 **PPO 循环**；连续动作空间下把 $\max_a Q$ 换成策略采样，就得到 policy-based 的写法。
:::

## 1.8 本讲陷阱

::: errata 常见误解清单
1. **奖励设计错误 → 奖励黑客（reward hacking）**：智能体优化的是**你写的奖励**，不是**你想要的意图**。经典教训是「奖励移动速度」的策略学会了原地绕圈刷分、「奖励把船划快」反而迟迟不到终点。对策：奖励要绑定真实目标、辅以约束与惩罚、并且**盯着策略的实际行为**验收，而不是只看回报曲线。
2. **on-policy 与 off-policy 混淆**：Q-learning / DQN 是 **off-policy**，可以用回放池里的旧数据；REINFORCE 是 on-policy，PPO 是「近似 on-policy」（靠重要性比率在同一批数据上多跑几个 epoch，但之后必须重新采样）。把旧策略数据硬塞给 on-policy 方法、又不做重要性修正，会引入未校正的分布偏移。
3. **把 DQN 直接搬到连续动作空间**：$y=r+\gamma\max_{a'}Q(s',a')$ 中的 $\max$ 在连续动作上是一个**内层优化**，逐点枚举不可行。连续控制应改用策略方法（PPO 直接参数化高斯策略），或让一个 Actor 网络直接给出 $\arg\max$（如 DDPG）。
4. **折扣因子乱设或忘了折扣**：无限时域下 $\gamma=1$ 使回报发散、值函数无定义；$\gamma\to1$ 也会把有效视野拉得极长、令估计方差暴涨。$\gamma$ 是**超参数**，要和任务的时间尺度匹配。
5. **把 RL 当监督学习喂数据**：轨迹样本高度相关且分布随策略漂移。直接拿一小段连续轨迹反复更新，会让网络只拟合局部经验、灾难性遗忘其他状态。回放、打乱、基线、GAE 都是在替你「制造 i.i.d. 的假象」。
6. **只看平均回报、不看种子与方差**：RL 对随机种子极度敏感，同一算法换个种子可能一个学会、一个不学。报告必须给**多 seed 的均值与波动**，必要时画出各条曲线。
7. **目标网络忘记同步或忘记冻结**：DQN 的稳定来自「目标在若干步内不动」。若每步都同步 $\theta^-\leftarrow\theta$，就等于每步追一个移动靶，训练极易发散。
8. **忽视样本效率与稳定性的权衡**：off-policy 方法（DQN）样本效率高但难调；on-policy（PPO）稳定但吃样本。先问清算力与在线交互预算，再选算法——不要拿一个方法去硬套所有场景。
:::

## 1.9 本讲小结

**三句话带走**：

1. RL 把「有标签的监督」换成「**与环境交互、从奖励信号里试错**」；它独有的两个难题是**延迟的信用分配**与**探索-利用的张力**，MDP 与贝尔曼方程是描述它们的通用语言。
2. 两条主干殊途同归：**值方法**（Q-learning → DQN）先学 $Q$ 再取贪心动作，靠**经验回放 + 目标网络**稳住训练；**策略方法**（策略梯度 → Actor-Critic → PPO）直接对 $\pi_\theta$ 求梯度，靠**基线/优势**降方差、靠**裁剪**限制步幅。Actor-Critic 把两者合流，PPO 则是今天最稳、最通用的默认算法。
3. 前沿把 RL 推向两个极端：**离线 RL** 应对「不能交互，只有固定数据」，**RLHF** 应对「奖励写不出来，只用人类偏好代替」——后者正是大模型对齐的默认手段。

**与后续的连接**：本讲把「结构 + 损失 + 梯度下降」的范式换成了「**策略 + 回报 + 试错**」，但底层仍是[第 1 讲](lec01.md)的反向传播在驱动。**RLHF** 直接接到[第 6 讲](lec06.md)（规模为何带来能力、大模型怎么训）与[第 7 讲](lec07.md)（对齐、可控与安全）；用 RL 做科学发现与控制题会出现在[第 8 讲](lec08.md)；而大规模策略/价值网络的并行训练，则落到[第 9 讲](lec09.md)的切分与通信上。[Lab 3](../labs/lab3.md) 微调大语言模型的流程里，SFT 之后的偏好优化环节就是本讲 RLHF 的工程化身。
