# 第 3 讲导览 · 深度计算机视觉

## 这一讲要解决的真实问题

把一张图喂给第 1 讲的 MLP，会发生什么？$224\times224\times3$ 的图像展平后有 $150{,}528$ 个数，接一层 $1000$ 维隐层就是约 **1.5 亿个参数**；更糟的是，展平把二维的像素网格拉成一维向量，「谁挨着谁」这个信息只以「下标差」的形式隐式保留，网络必须为**每个位置**单独学一遍同样的图案。这就是**参数爆炸**与**无视空间结构**这两宗罪。

卷积的答案是把「图像该长什么样」这个先验**写进结构**：**局部连接**（每个输出只与一个小邻域相连）、**权值共享**（同一个核在全图滑动）、以及由此推得的**平移等变**。这三条合称卷积的**归纳偏置**，它们把参数量压到与图像尺寸无关（下降三到四个数量级），也让「学会一个图案」不必再重复几百遍。代价是：当这个先验不成立时（比如位置本身携带语义），卷积会吃亏——**归纳偏置是条件性的工具，不是免费的午餐**。

本讲的叙述线是一条**障碍升级链**：

1. **卷积怎么算**（3.2–3.3）：把「核在图上滑动」写成精确公式，把尺寸、参数量、感受野、池化、归一化逐项算清。这一部分的目标是让你获得**不依赖代码的形状推演能力**——它决定了你排错的速度。
2. **怎么堆**（3.4）：AlexNet 证明了深度 CNN 可训（靠的是一整套**配方**），VGG 用「小核堆叠 + 结构规整」把**深度**变成可研究的变量，ResNet 遇到并解决了**退化问题**（更深反而训练误差更高——不是过拟合），手段是**残差连接**：它让恒等映射变便宜、让梯度有一条直通的路。
3. **能不能不用卷积**（3.5）：ViT 把图像切成 patch 当 token 序列，用注意力替代卷积。它成功了，但带着两个条件——**需要大量数据**（弱先验换大假设空间），以及**计算量随分辨率快速上升**。Swin 用窗口注意力与层次化找回效率与多尺度输出；ConvNeXt 用一次控制变量实验说明「卷积 vs 注意力」的胜负**很大程度取决于训练配方与微观设计**。
4. **怎么不用标签也训好**（3.6）：迁移学习是工程默认起点（**先冻结、再逐步解冻**）；自监督预训练把监督信号换成数据自身的结构——对比学习（InfoNCE / SimCLR / MoCo）、自蒸馏（BYOL / DINO）、掩码建模（MAE / BEiT）三条路线各有取舍。
5. **怎么做到「一个模型解决一类问题」**（3.7–3.8）：检测与分割把输出从「一个标签」变成「一个集合 / 一张稠密标签图」，于是 IoU、NMS、AP 成为必须掌握的语言；DETR 用集合预测去掉锚框与 NMS；SAM 把分割变成**提示式**的通用后端。3.8 节把视觉接到语言上：CLIP 的对齐、BLIP-2 / LLaVA 的连接器与指令微调、扩散模型的定制（ControlNet / LoRA）。
6. **代价是什么**（3.9–3.10）：数据集偏见会被**放大**，对抗样本说明「人看不出异常」不等于「模型不会判错」，深伪让「真实」本身变得可疑。3.10 节把这些落到 Lab 2：滑动窗口人脸检测、IoU 匹配、NMS、对抗实验与隐私讨论。

**在九讲主线中的位置**：第 1 讲给了通用范式（结构 + 损失 + 梯度下降 + 泛化），第 2 讲把「结构」这一环换成序列与注意力。本讲把这两条线**合到图像上**：3.2–3.4 是「结构」在空间维度上的展开，3.5 是第 2 讲的注意力反过来改造视觉，3.6–3.8 是「预训练 + 迁移」这套方法论在视觉里的完整形态，3.9 对应第 7 讲的治理视角。**与母本 MIT 6.S191 的关系**：本讲以母本 Lecture 3（Deep Computer Vision）的主题与配套 Lab（人脸检测）为骨架，把课堂上只给结论的部分（输出尺寸与感受野的推导、残差连接的梯度结构、ViT 的复杂度、检测评估口径）补齐；3.5 / 3.6 / 3.7 / 3.8 中标注为「教材外拓展」的新增部分，属于母本录播年代之后成为主流的内容，已按规范给出论文标题与编号。

| **[3.3 池化与归一化](sec33.md)** | 池化到底提供了什么？BN 为什么训练/推理不一致？ | 池化的不变性**很弱**，主要价值是降分辨率扩视野；BN 训练用批统计、推理用运行统计，与 batch size 强耦合；卷积 Dropout 必须按**通道**丢弃 | 推理忘了 `model.eval()`（单样本时统计退化）；小 batch 硬用 BN；逐元素 Dropout 用在特征图上 |
| **[3.4 经典骨干演进](sec34.md)** | 三代网络的贡献是什么？为什么会「更深更差」？ | AlexNet 是一套**可训配方**（且 95% 参数在全连接层）；VGG 用 $3\times3$ 堆叠换感受野与非线性；**退化不是过拟合**，残差 $y=F(x)+x$ 给出恒等直通项 $I$ | 把退化当过拟合（加正则无效）；以为残差只是「防梯度消失」；忽略「中间激活更多」带来的显存代价 |
| **[3.5 现代视觉架构](sec35.md)** | 不用卷积行不行？代价是什么？ | ViT 用 patchify + 注意力；**常规分辨率下 MLP 占计算量约 64%，注意力矩阵只占 4%**；弱先验需要更多数据；Swin 用窗口 + 层次化换线性复杂度；MAE 让预训练脱离标签 | 以为 ViT 算力与 ResNet 相近（ViT-B/16 约 17.6 GMACs，是 ResNet-50 的 4.3 倍）；以为 ViT 没有归纳偏置；把 ConvNeXt 的结论读成「卷积更好」 |
| **[3.6 迁移与自监督](sec36.md)** | 为什么不能从零训练？没标签怎么办？ | 迁移是默认起点：**先冻结、再逐步解冻**，骨干学习率小一个量级；InfoNCE 等价于在表示空间做 $2N-1$ 类分类；MoCo 用队列解耦 batch；BYOL / DINO 去负样本但**机制解释有争议** | 预处理与骨干不匹配；一上来就全网络微调；把「不用负样本也不崩塌」当成已确立的定理 |
| **[3.7 检测、分割与视觉基础模型](sec37.md)** | 输出为什么不能只看准确率？ | 类不平衡下准确率无信息量；IoU 是匹配与评估的共同基础；NMS 是弥补「训练未去重」的手段；AP 必须说清口径（VOC 11 点 vs COCO 101 点 + 10 个 IoU 阈值）；DETR 用集合预测消掉锚框与 NMS，代价是收敛慢 | 用准确率评估检测；混淆 AP 与 mAP；以为 NMS 是必需步骤；把 SAM 当分类器（它不给语义标签） |
| **[3.8 多模态视觉](sec38.md)** | 图像怎么接到语言上？ | CLIP 用 4 亿图文对的对称 InfoNCE 做对齐，从而支持零样本分类；VLM 三段式（对齐 / 指令微调 / 偏好优化）；视觉 token 数量直接决定上下文预算；ControlNet 管「怎么摆」、LoRA 管「长什么样」 | 以为 CLIP 会生成文本；以为视觉幻觉是「没看清」（实为语言先验压过视觉证据）；跨论文直接比较 VQA 数字 |
| **[3.9 伦理与安全](sec39.md)** | 强能力的代价是什么？ | 数据集偏见会被**放大**（反馈回路）；必须做**分群评估**；对抗样本说明人不可察觉的输入也能翻车；鲁棒性是**相对攻击预算**的陈述；有些场景**不该用**视觉模型 | 用总体准确率掩盖子群失败；把对抗样本归因于过拟合；把检测器当作深伪的唯一防线 |
| **[3.10 Lab 2 导读](sec310.md)** | 怎么把零件装成能跑的检测系统？ | 滑动窗口 = 在位置与尺度上搜索（并用它体会「重复计算」的动机）；正负样本匹配与**忽略区**；「先过拟合 10 个样本」是最有效的调试手段 | 框坐标顺序错（不报错但框乱飞）；增强只改图不改框；NMS 条件方向写反；多尺度推理忘记还原坐标 |

## 常见提问（本讲最常被问到的五件事）

::: method 五个高频疑问
**Q：卷积到底要不要「翻转核」？**
不要。框架实现的是**互相关**（[命题 3.2.1](sec32.md#prop-3.2.1)）。但手推反向传播、做核合并、对接信号处理公式时必须显式处理翻转——这是两套约定，别混用。

**Q：为什么现代架构越来越少用池化？**
因为池化提供的不变性比通常认为的**弱得多、且不连续**（[例 3.3.1](sec33.md#ex-3.3.1)），它的真实价值是降分辨率与扩感受野；而这两件事用**步幅卷积**做更灵活（可学），代价是算力。真正带来不变性的是大感受野、全局聚合与数据增强。

**Q：ViT 是不是已经取代 CNN 了？**
不是。ViT 的弱先验在**数据充足**时是优势，在中小数据上是劣势；ConvNeXt 的控制变量实验说明「卷积 vs 注意力」的差距**很大程度来自训练配方与微观设计**。选型要按数据量、延迟、部署工具链、是否需要多尺度输出判断（[3.5.5](sec35.md#sec-3.5.5)）。

**Q：为什么检测任务不能看准确率？**
因为背景位置的占比可能是 $99.9\%$ 以上，「全判背景」就能拿到极高准确率却零召回（[例 3.7.1](sec37.md#ex-3.7.1)）。要看 precision / recall / AP / mIoU，并且**分别报告漏检与误检**。

**Q：既然有预训练权重，为什么还要学这些推导？**
因为**推理与排错需要形状、算力与精度的量级感**：显存为什么爆、为什么换了分辨率就报错、为什么这个改动理论上更快实测更慢、为什么换了个骨干精度掉了——这些问题都不是「加载权重 + 微调」能回答的。预训练解决的是「从哪开始」，本讲的公式解决的是「为什么」与「哪里出问题」。
:::

## 与实验和项目的关系

- **[Lab 2 · 人脸检测系统](../../labs/lab2.md)**：本讲的落点。它把 3.1–3.9 的内容装成一台机器——滑动窗口检测器（3.7）、IoU 与 NMS（3.7.2）、训练与正则（3.3、3.4）、对抗样本（3.9.3）、分群评估与隐私（3.9）。**3.10 节是它的理论导读**，逐条把原理对应到实现。
- **与 Lab 1 / Lab 3 的连接**：本讲的骨干（3.4、3.5）是 Lab 3 里视觉—语言模型的前端；本讲的自监督（3.6）与第 4 讲的生成建模共享「用无标签数据训练表示」的思路。
- **期末项目**：如果项目涉及图像（分类、检测、分割、生成、多模态），决策顺序应当是——先读 3.6 的实操清单选预训练骨干与迁移策略，再读 3.7 确定任务的输出结构与评估口径，最后读 3.9 写出**使用边界**（哪些情况下不应部署）。**一个合格的视觉项目报告必须包含分群评估与失败模式分析。**
