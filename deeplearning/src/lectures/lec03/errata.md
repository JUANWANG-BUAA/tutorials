## 一、对照母本讲义的补注

母本 **MIT 6.S191 · Lecture 3（Deep Computer Vision）** 在一节课里从「为什么需要卷积」讲到检测与分割，定位是**建立视觉任务的全局直觉**，配套 Lab 做滑动窗口人脸检测。推导、复杂度拆解、评估口径与治理议题大多留给学生自己补。本教程沿用它的骨架与术语，逐节补齐被省略的中间步骤。

读母本时容易出现三种落差，先在这里说清：

1. **「课堂上说显然」的步骤，考试与面试会要求写出来**——输出尺寸公式的取整来源、感受野递推、残差梯度的展开、InfoNCE 的梯度，本教程都写进 `proof` 折叠框，第一遍可跳，第二遍必须能复现。

3. **「录播年代之后成为主流」的内容**——ViT / Swin / ConvNeXt / MAE、SAM、CLIP 之后的 VLM 与扩散定制、自监督的落地清单，[3.5](sec35.md)–[3.8](sec38.md) 已按《教材写作规范》标注为「教材外拓展」并给出论文标题与编号。

## 二、术语与常见译误

这一节的用法：**当你在「同一个词指向两件事」上卡住时来查**。以下九条都是本讲内部就构成实际困惑的对比。

| 术语 | 常见误用／误译 | 正确理解 |
|:--|:--|:--|
| **padding（填充）vs zero padding（零填充）** | 把两者当同一件事，于是「填充会引入边界偏差」这类话说不清是机制问题还是取值问题 | **填充**指在四周补 $p$ 圈元素、控制输出尺寸的操作（[定义 3.2.2](sec32.md#def-3.2.2)）；**零填充**只是其中最常用的一种取值约定（补 $0$）。框架里的 `padding=1` 是前者，补什么由实现决定——换取值（如镜像填充）会改变边缘像素的统计，但尺寸公式 (3.2) 不变 |
| **stride（步幅）vs step（步长）** | 把「步幅」与优化器的「步长 / 学习率」混用，于是「$s=2$ 相当于下采样」被误读成「学习率减半」 | **步幅**是核每次移动的距离，只影响几何（输出尺寸、跳距）与算力（[定义 3.2.2](sec32.md#def-3.2.2)、[命题 3.2.4](sec32.md#prop-3.2.4)）；「步长」在本教程中专指优化器的更新幅度 $\eta$，与卷积无关。写作时用「步幅 / stride」避免歧义 |
| **pooling（池化）vs subsampling（下采样 / 子采样）** | 把池化等同于「降分辨率」，认为降分辨率就一定要用池化 | **池化**是三种降采样方式之一，另两种是**步幅卷积**（可学、有参数）与**重排 / 稀疏采样**（无参数、信息无损）（[定义 3.3.2](sec33.md#def-3.3.2)）。决定分辨率与感受野的是**步幅的累乘**，不是「池化」这个名字（[例 3.3.2](sec33.md#ex-3.3.2)）。历史上还有 subsampling 一词指 LeNet 时代的无参数下采样，与今天的池化不完全同义 |
| **BN 的「批」到底指什么** | 以为「批」是「一批图片」或「一个 batch 的样本」，于是算不清统计范围 | BN 的统计量是**每个通道独立**、在**该批全部样本的 $B\times H\times W$ 个元素**上算的（[定义 3.3.3](sec33.md#def-3.3.3)）——「批」既不跨通道也不跨位置，但**跨样本**。这一个「跨谁不跨谁」就解释了为什么它依赖 batch size、为什么推理要用运行统计量、以及为什么小批量场景改用 GroupNorm（[定义 3.3.4](sec33.md#def-3.3.4)） |
| **等价（equivariance）vs 不变（invariance）** | 说「卷积具有平移不变性」，或在讲数据增强时把两者混着用 | **等变**：输入平移 $\Delta$，输出特征图跟着平移 $\Delta$——卷积自带的性质（[命题 3.1.1](sec31.md#prop-3.1.1)）。**不变**：物体在哪都给出同一个标签——分类要的性质，靠池化 / 全局池化 / 大感受野逐步换来（[3.3.1](sec33.md#sec-3.3.1)），且实际网络的不变性只是局部的 |
| **感受野（receptive field）vs 跳距（jump）** | 只记感受野，于是说不清「这一层相当于原图上的多大核」 | 感受野答「看多大」，跳距答「隔多远一个采样点」，两者共同决定特征图相当于原图的什么分辨率（[定义 3.2.4](sec32.md#def-3.2.4)）。把某层的核换算到第 $l$ 层要乘 $j_l$（即用 $k\cdot j_l$），分割的定位精度上限就是 $j_L$ |
| **转置卷积（transposed conv）vs 反卷积（deconvolution）** | 当成卷积的逆运算，或以为它能「恢复下采样丢掉的信息」 | 它是**与卷积梯度同形**的线性映射 $A^{\mathrm T}$，不是逆（卷积矩阵几乎总是奇异的，[定义 3.2.6](sec32.md#def-3.2.6)）。零插值 $+$ 大步幅还会留下棋盘格伪影；要保边界精度靠**跳连 / 高分辨率特征**，不靠上采样算子（[3.7.4](sec37.md#sec-3.7.4)） |
| **AP vs mAP（以及 COCO 的「AP」）** | 把三个不同的平均混成一个词，导致数字不可比 | 三件事要分清：**单类别单阈值**（AP）、**跨类别平均**（常写作 mAP）、**跨 IoU 阈值平均**（COCO 口径下官方写作 "AP"，已是 $0.50{:}0.05{:}0.95$ 十个阈值的均值）（[方法 3.7.1](sec37.md#method-3.7.1)）。报告时必须写清是哪几件（[3.7.2](sec37.md#sec-3.7.2)） |
| **GAP（全局平均池化）vs 展平（flatten）** | 以为 GAP 只是「另一种池化层」，或以为二者可互换 | GAP 把每个通道的整张图聚成一个数，直接得到长度 $C_{out}$ 的向量：参数量骤降、可按通道可视化类激活、可接受任意输入尺寸——代价是**彻底丢掉空间信息**，因此只适合分类；展平则保留全部位置信息但把一个巨大矩阵塞给分类头（[3.3.1](sec33.md#sec-3.3.1)、[例 3.4.1](sec34.md#ex-3.4.1)） |

## 三、时效补注

母本录播年代与当前工程默认之间存在若干处「已经换了默认答案」的差异。以下按「主题 / 母本年代的做法 / 截至 2025 年的工程默认 / 本教程的处理」列出；**涉及具体版本与比例的条目均标注为社区惯例，采用前应结合你自己的配置验证**。

| 主题 | 母本年代（约 2018–2020 录播口径） | 当前工程默认（截至 2025） | 本教程的写法 |
|:--|:--|:--|:--|
| Dropout 在 CNN 中的位置 | 讲「Dropout 防过拟合」，常配在全连接层或按元素丢弃 | ResNet / ConvNeXt 等主要靠**数据增强 + 权重衰减 + BN**，骨干内**不用 Dropout**；要用也是**通道级**（`Dropout2d`），出现在分类头之前或小数据任务里 | [定义 3.3.5](sec33.md#def-3.3.5) 与[算法 3.3.1](sec33.md#sec-3.3.4) 明确「掩码必须作用在语义上有意义的单位上」，并给出 $p=0.1\sim0.3$ 的典型区间 |
| 分类头 | AlexNet / VGG 用「展平 + 三层大全连接」 | **GAP + 一个小线性层**（甚至只留一层）；参数效率提升的主要来源就是把大 FC 换掉 | [3.3.1](sec33.md#sec-3.3.1) 给 GAP 的三重收益与一条代价；[例 3.4.1](sec34.md#ex-3.4.1)、[例 3.4.2](sec34.md#ex-3.4.2) 用参数分布把「为什么必须换」算给读者看 |
| 骨干选型 | ResNet 系列为绝对默认 | **按数据量 / 延迟 / 工具链 / 是否需要多尺度**四分法选型：ViT 系（数据足）、Swin（多尺度）、ConvNeXt（纯卷积但现代化）、深度可分离系（移动端） | [3.5.5](sec35.md#sec-3.5.5) 的三层区分（架构 / 实现 / 工程）与 [3.6.5](sec36.md#sec-3.6.5) 的决策顺序 |
| 预训练来源 | ImageNet-1k 监督预训练 | **自监督优先**（DINOv2 / MAE 系）> CLIP 系（涉及图文）> ImageNet 监督；领域接近的目标域更重要 | [3.6.5](sec36.md#sec-3.6.5) 第 2 步给出这个优先顺序，并要求记录来源与版本 |
| 归一化层 | BatchNorm 为图像任务默认 | 大 batch 分类仍用 BN；**检测 / 分割 / 视频 / 小批量一律改用 GroupNorm**；Transformer 用 LN | [定义 3.3.4](sec33.md#def-3.3.4) 用「统计范围」统一视角把四者排在一张表里，并在 [3.6](sec36.md#sec-3.6.2) 指出领域偏移时 BN 的运行统计量本身是误差源 |
| 「先训分类再迁移」 | 迁移主要等于「载入 ImageNet 权重再微调」 | **两阶段**（先冻结只训头、再小学习率解冻）+ 分层学习率；小数据下冻结骨干的 BN 也要切 `eval()` | [定义 3.6.1](sec36.md#def-3.6.1)、[方法 3.6.1](sec36.md#method-3.6.1) 与 [例 3.6.1](sec36.md#ex-3.6.1) 的成本对比 |
| 检测范式 | 锚框 $+$ NMS 是标配 | **DETR 系集合预测**（无锚框、无 NMS）在增长，但经典锚框路线仍是主流生产方案；SAM 一类提示式模型把分割变成可复用后端 | [3.7.3](sec37.md#sec-3.7.3)–[3.7.6](sec37.md#sec-3.7.6) 把两条路线与代价讲清，并写明 DETR 的两条代价（收敛慢、小目标弱） |
| 生成与定制 | 生成模型与视觉识别基本分开讲 | **扩散主干 $+$ ControlNet（空间条件）/ LoRA（主体与风格）** 成为定制接口的标准组合 | [3.8.3](sec38.md#sec-3.8.3)：ControlNet 管「怎么摆」、LoRA 管「长什么样」，两者正交可叠加 |
| 「ViT 是否取代 CNN」 | 尚无此讨论 | 结论是**条件性的**：ConvNeXt 的控制变量实验说明配方与微观设计贡献很大 | [3.5.5](sec35.md#sec-3.5.5) 与本节第一部分的三条落差提醒 |
| 隐私与合规 | 主要作为讨论题 | **分群评估、拒答机制、人在回路、可追溯日志、数据最小化**成为交付物的一部分 | [3.9.5](sec39.md#sec-3.9.5) 的「最小合规包」与 [3.10.6](sec310.md#sec-3.10.6) 的三个可执行实验 |

**一条通用提醒**：本讲涉及的具体数字（如 MAE 的 $75\%$ 掩码、DeiT 的 $81.8\%/83.4\%$、队列长度 $65{,}536$、CONV 系模型的参数量）都来自**特定配置与特定实现口径**。正文对不确定处已标注「需核实」；引用到自己的项目前，请以所使用框架版本与模型公开配置为准。

**为什么这些默认会变**：它们大多不是数学结论，而是「在当时的硬件、数据规模与框架能力下性价比最高的选择」。硬件（BF16 / 量化）、数据规模（十亿级图文对、十亿级掩码）与框架（FlashAttention 类 IO 感知算子、分布式归一化）任一项变化，默认答案就可能改写。**因此本页的价值在于记录「变化发生过」，而不是把 2025 年的默认当成永久正确。**
