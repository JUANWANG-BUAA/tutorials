# 第 1 讲 · 深度学习导论

> 本讲建立全书唯一的**范式**：任何深度网络都可以拆成「**定义结构 → 定义损失 → 用梯度下降最小化损失**」三步。我们从单个神经元讲起，堆到多层感知机（MLP），写出损失与梯度下降的更新式，把**反向传播**一步步推导出来，最后交代过拟合与正则化。读完这一讲，后面八讲都只是「把结构换成更适合某种数据的形状」。

<div><span class="brief-label">TARGET</span><strong>本讲要建立</strong><p>神经元与感知机；MLP 的前向传播；激活函数的作用与选择；交叉熵与 MSE 损失；SGD / Momentum / Adam；反向传播的推导；过拟合与正则化（Dropout / 权重衰减 / 早停）。</p></div>

::: method[core] 10 分钟复习版 · 第 1 讲

**一句话**：深度网络 = **结构**（多层「线性变换 + 非线性激活」）+ **损失**（衡量预测与真值的差距）+ **梯度下降**（沿损失下降方向更新参数）；反向传播只是链式法则的高效实现。

**必记结论**

| 内容 | 要点 |
|:--|:--|
| **神经元** | $z=\sum_i w_ix_i+b=\boldsymbol w^{\mathrm T}\boldsymbol x+b$，输出 $a=\phi(z)$；$\boldsymbol w$ 是权，$b$ 是偏置，$\phi$ 是激活函数 |
| **感知机** | 无隐藏层、$\phi$ 为阶跃：只能划分**线性可分**的数据（异或问题无解） |
| **MLP 前向** | $\boldsymbol z^{(l)}=\boldsymbol a^{(l-1)}W^{(l)}+\boldsymbol b^{(l)}$，$\boldsymbol a^{(l)}=\phi(\boldsymbol z^{(l)})$；$\boldsymbol a^{(0)}=\boldsymbol x$ |
| **通用逼近** | 足够宽（或够深）的 MLP 可在紧集上任意逼近连续函数——这是「一切都能用 MLP 试」的理论底气 |
| **激活函数** | Sigmoid / tanh 深层易**饱和**（梯度消失）；ReLU 及其变体（GELU / SiLU）是默认选择 |
| **损失·分类** | Softmax + **交叉熵** $\mathcal L=-\sum_c y_c\log\hat y_c$ |
| **损失·回归** | **均方误差** $\mathcal L=\frac1N\sum_i(\hat y_i-y_i)^2$ |
| **梯度下降** | $\theta\leftarrow\theta-\eta\nabla_\theta\mathcal L$；SGD 用**小批量**梯度估计真梯度 |
| **反向传播** | 定义误差信号 $\boldsymbol\delta^{(l)}=\partial\mathcal L/\partial\boldsymbol z^{(l)}$，则 $\nabla_{W^{(l)}}=\boldsymbol a^{(l-1)\mathrm T}\boldsymbol\delta^{(l)}$，$\boldsymbol\delta^{(l)}=(\boldsymbol\delta^{(l+1)}W^{(l+1)\mathrm T})\odot\phi'(\boldsymbol z^{(l)})$ |
| **优化器** | Momentum 累积方向抑制震荡；Adam ≈ 动量 + 每参数自适应学习率；$\eta$ 仍是最关键超参数 |
| **过拟合** | 训练误差降、验证误差升；对策：Dropout、权重衰减（L2）、早停、数据增强、减小模型 |
| **偏置-方差** | 高偏置=欠拟合（模型太弱），高方差=过拟合（模型太强/数据太少） |

**最该记住的四个判断**：① 输出层用不用 softmax、配什么损失，取决于任务是**分类还是回归**；② 深层网络**不用 Sigmoid** 做隐藏层激活；③ 反向传播**不是**新数学，就是链式法则，只是复用中间结果把复杂度从指数降到线性；④ 训练/验证曲线**同时**看，才能判断是过拟合还是学习率不对。

:::

## 1.1 从神经元到感知机

深度学习的原子单元是**神经元**：把输入按权重加权求和，加偏置，再过一次非线性函数。

::: def 定义 1.1 · 神经元（neuron） {#def-1-1}
给定输入 $\boldsymbol x\in\mathbb R^n$、权 $\boldsymbol w\in\mathbb R^n$、偏置 $b\in\mathbb R$ 和激活函数 $\phi$，神经元的输出为

$$z=\sum_{i=1}^{n}w_ix_i+b=\boldsymbol w^{\mathrm T}\boldsymbol x+b,\qquad a=\phi(z).$$
:::

单个神经元能干什么？如果 $\phi$ 取**阶跃函数**（$z\ge0$ 输出 $1$，否则 $0$），它就等价于一个**线性分类器**：$z=0$ 是一条超平面，把空间切成两半。这就是最早的**感知机**（perceptron）。

::: intuition 为什么"线性"是个硬伤
超平面只能切出「一刀两半」。像**异或（XOR）**这样的问题，正例在对角、负例在另一对角，任何一条直线都分不开——感知机的天花板就在这里。出路不是把一刀切得更花哨，而是**先变换、再切**：叠一层神经元，让新空间里原本纠缠的点变得线性可分。这正是「深度」的起点。
:::

::: ex 例 1.1（XOR 为什么解不了） {#ex-1-1}
证明单个感知机无法实现 XOR。设输入 $(x_1,x_2)\in\{0,1\}^2$，标签 $y=x_1\oplus x_2$（$0,1$ 相同为 $0$，不同为 $1$）。

::: proof 解
只需判断四个点是否线性可分。要求同时满足

$$w_1\cdot0+w_2\cdot0+b<0,\quad w_1\cdot1+w_2\cdot1+b<0,\quad w_1\cdot1+b\ge0,\quad w_2\cdot1+b\ge0.$$

前两式给出 $b<0$ 且 $w_1+w_2+b<0$；后两式相加给出 $w_1+w_2+2b\ge0$。由 $b<0$ 有 $w_1+w_2+2b<w_1+w_2+b<0$，与 $\ge0$ 矛盾。故无解。（等价地说：$y=x_1\oplus x_2$ 不是线性可分函数。）
:::

:::

解法：引入**隐藏层**。用两个神经元分别表示 $x_1\ \text{AND}\ (\text{not }x_2)$ 与 $(\text{not }x_1)\ \text{AND}\ x_2$，再让输出神经元做一次 OR——两层非线性叠加后，XOR 变得可分。这提示了 MLP 的一般形式。

## 1.2 多层感知机与通用逼近

把神经元一层层摞起来就是**多层感知机**（Multi-Layer Perceptron, MLP）。约定 $\boldsymbol a^{(0)}=\boldsymbol x$ 为输入，第 $l$ 层（$l=1,\dots,L$）为

$$\boldsymbol z^{(l)}=\boldsymbol a^{(l-1)}W^{(l)}+\boldsymbol b^{(l)},\qquad \boldsymbol a^{(l)}=\phi\bigl(\boldsymbol z^{(l)}\bigr).$$

这里 $W^{(l)}\in\mathbb R^{d_{l-1}\times d_l}$，$\boldsymbol b^{(l)}\in\mathbb R^{d_l}$；$\boldsymbol z^{(l)}$ 叫**预激活**，$\boldsymbol a^{(l)}$ 叫**激活**。最后一层的激活即为预测 $\hat{\boldsymbol y}=\boldsymbol a^{(L)}$。

::: intuition "线性变换 + 非线性"为什么缺一不可
如果去掉 $\phi$，两层线性网络 $W^{(2)}(W^{(1)}\boldsymbol x)=\underbrace{W^{(2)}W^{(1)}}_{W'}\boldsymbol x$ 仍是一个线性变换——叠多少层都白搭。**非线性是深度的意义所在**：它让每一层能重新弯曲空间，把复杂函数拆成一段段局部线性的拼接。
:::

::: thm 定理 1.1 · 通用逼近（universal approximation，陈述） {#thm-1-1}
设 $\phi$ 为非常数、有界、单调递增的连续函数（如 Sigmoid），$K\subset\mathbb R^n$ 为紧集，$f:K\to\mathbb R$ 连续。则对任意 $\varepsilon\gt0$，存在有限宽的单隐藏层网络 $g$，使 $\sup_{\boldsymbol x\in K}\lvert f(\boldsymbol x)-g(\boldsymbol x)\rvert\lt\varepsilon$。
:::

**定理的含义与边界**：它保证「**存在**一个够宽的网络能逼近任意连续函数」，但**不告诉你**这个网络有多宽、要多少数据、能不能训出来。工程上真正的架构选择（CNN / RNN / Transformer）解决的是「**用更少参数、更多归纳偏置**把同样的事情做得更好」，通用逼近只是理论下限。

::: ex 例 1.2（一层网络前向的形状推演） {#ex-1-2}
输入一个 mini-batch 的 $\boldsymbol X\in\mathbb R^{32\times784}$（32 张 $28\times28$ 灰度图展平）。层：`Linear(784,128) → ReLU → Linear(128,10)`。逐层写出形状。

::: proof 解
设批大小 $B=32$。

| 步骤 | 运算 | 输出形状 |
|:--|:--|:--|
| 输入 | — | $32\times784$ |
| Linear(784,128) | $\boldsymbol XW_1+\boldsymbol b_1$，$W_1\in\mathbb R^{784\times128}$ | $32\times128$ |
| ReLU | 逐元素 $\max(0,\cdot)$ | $32\times128$ |
| Linear(128,10) | $\cdots W_2$，$W_2\in\mathbb R^{128\times10}$ | $32\times10$ |

参数量 $=784\times128+128+128\times10+10=101{,}770$。**批维 $32$ 全程不变**——这是「批优先」约定的直接结果。
:::

## 1.3 激活函数：为什么不用 Sigmoid 做隐藏层

激活函数提供非线性，但选错会让深层网络**训不动**。

| 激活 | 公式 | 优点 | 缺点 |
|:--|:--|:--|:--|
| Sigmoid | $\sigma(z)=\dfrac{1}{1+e^{-z}}$ | 输出 $(0,1)$，可解释为概率 | 两端**饱和**，导数趋 $0$ → 梯度消失；输出非零均值 |
| tanh | $\dfrac{e^{z}-e^{-z}}{e^{z}+e^{-z}}$ | 零均值 | 同样两端饱和 |
| **ReLU** | $\max(0,z)$ | 正区间导数为 $1$，**不饱和**、计算便宜、稀疏 | 负区间梯度为 $0$（神经元可能「死亡」） |
| GELU / SiLU | 平滑版 ReLU | 大模型中表现更好 | 略贵 |

::: intuition 梯度消失的一句话
反向传播时梯度要**连乘**每层的导数。Sigmoid 的导数最大只有 $0.25$，十层连乘就是 $0.25^{10}\approx10^{-6}$——信号还没传到第一层就没了。ReLU 在正区间导数为 $1$，连乘不衰减，这才让几十上百层的网络可训练（配合 [第 3 讲](lec03.md)的残差连接，还能再深）。

## 1.4 损失函数：分类用交叉熵，回归用均方误差

**损失**度量预测与真值的差距，是训练的唯一目标。两种最常用的损失：

::: def 定义 1.2 · 交叉熵与均方误差 {#def-1-2}
**分类**（$C$ 类，真值为 one-hot $\boldsymbol y$，网络输出 logits $\boldsymbol z$）：先 softmax 得 $\hat y_c=\dfrac{e^{z_c}}{\sum_{c'}e^{z_{c'}}}$，再用**交叉熵**

$$\mathcal L_{\mathrm{CE}}=-\sum_{c=1}^{C}y_c\log\hat y_c .$$

**回归**（预测 $\hat y$、真值 $y$）：用**均方误差**

$$\mathcal L_{\mathrm{MSE}}=\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2 .$$
:::

::: intuition 交叉熵到底在惩罚什么
one-hot 时它退化为 $\mathcal L=-\log\hat y_{y}$：**只惩罚正确类别的预测概率**。预测概率 $\hat y_y\to1$ 时损失 $\to0$；预测成 $0.1$ 时损失 $\approx2.3$，而且越接近 $0$ 惩罚越陡（对数发散）。这逼着模型把正确类别的概率顶上去，而不是「差不多就行」。相比 MSE，交叉熵配 softmax 的梯度更干净（见 [1.5](lec01.md) 的推导），这是分类任务的标准搭配。
:::

::: think 为什么分类不直接用 MSE
MSE + softmax 的梯度里含一个 $\hat y(1-\hat y)$ 因子，输出饱和时梯度同样消失，学习会变慢；而且 MSE 对「概率误差」的惩罚是平方级、不够陡，无法强力推动正确类别。交叉熵直接对**似然**做最大似然估计，是最小 KL 散度意义下的正确目标。（回归任务没有「类别概率」，MSE 才是自然的。）
:::

## 1.5 梯度下降与反向传播

训练就是最小化损失：$\theta^\star=\arg\min_\theta\mathcal L(\theta)$。

::: def 定义 1.3 · 梯度下降与 SGD {#def-1-3}
**全批梯度下降**：用整个数据集的梯度更新
$$\theta\leftarrow\theta-\eta\,\nabla_\theta\mathcal L(\theta).$$
**随机梯度下降（SGD）**：用**单个样本或小批量** $\mathcal B$ 上的梯度作无偏估计
$$\theta\leftarrow\theta-\eta\,\nabla_\theta\mathcal L_{\mathcal B}(\theta),\qquad \mathbb E_{\mathcal B}\bigl[\nabla_\theta\mathcal L_{\mathcal B}\bigr]=\nabla_\theta\mathcal L .$$
:::

::: intuition 小批量为什么反而更好
全批梯度精确但每次要扫全数据，代价大且容易陷进尖锐的局部极小；小批量梯度带噪声，**噪声本身是好事**——它帮助参数跳出尖锐极小，找到更平坦、泛化更好的解，还顺带让批内并行（GPU）发挥效用。批大小是可调超参数，常见 $32\sim512$。
:::

### 反向传播：链式法则的高效实现

要更新参数，就要知道 $\partial\mathcal L/\partial W^{(l)}$ 对**每一层**的值。逐参数数值求导是 $O(\text{参数量})$ 次前向，不可行；反向传播利用链式法则**复用中间结果**，一次前向 + 一次反向即可得到全部梯度。

定义第 $l$ 层的**误差信号** $\boldsymbol\delta^{(l)}\triangleq\partial\mathcal L/\partial\boldsymbol z^{(l)}$（$B\times d_l$ 的矩阵）。可以证明（见下）：

::: thm 定理 1.2 · 反向传播递推 {#thm-1-2}
设损失 $\mathcal L$ 对输出层激活的梯度为 $\partial\mathcal L/\partial\boldsymbol a^{(L)}$，则

$$\underbrace{\boldsymbol\delta^{(L)}=\frac{\partial\mathcal L}{\partial\boldsymbol a^{(L)}}\odot\phi'\bigl(\boldsymbol z^{(L)}\bigr)}_{\text{输出层}},\qquad
\underbrace{\boldsymbol\delta^{(l)}=\bigl(\boldsymbol\delta^{(l+1)}W^{(l+1)\mathrm T}\bigr)\odot\phi'\bigl(\boldsymbol z^{(l)}\bigr)}_{\text{逐层回传}}\ (l=L-1,\dots,1),$$

$$\frac{\partial\mathcal L}{\partial W^{(l)}}=\boldsymbol a^{(l-1)\mathrm T}\boldsymbol\delta^{(l)},\qquad
\frac{\partial\mathcal L}{\partial\boldsymbol b^{(l)}}=\sum_{\text{批}}\boldsymbol\delta^{(l)} .$$

::: proof 推导（两层网络、单样本，逐步展开）
取一个两层网络 $\boldsymbol a^{(0)}=\boldsymbol x$，$\boldsymbol z^{(1)}=\boldsymbol xW^{(1)}+\boldsymbol b^{(1)}$，$\boldsymbol a^{(1)}=\phi(\boldsymbol z^{(1)})$，$\boldsymbol z^{(2)}=\boldsymbol a^{(1)}W^{(2)}+\boldsymbol b^{(2)}$，$\hat{\boldsymbol y}=\mathrm{softmax}(\boldsymbol z^{(2)})$，$\mathcal L=-\sum_c y_c\log\hat y_c$。

**第一步：输出层。** Softmax + 交叉熵有一个漂亮的结果：$\dfrac{\partial\mathcal L}{\partial\boldsymbol z^{(2)}}=\hat{\boldsymbol y}-\boldsymbol y$。于是 $\boldsymbol\delta^{(2)}=\hat{\boldsymbol y}-\boldsymbol y$（这正是把 softmax 与交叉熵配对的原因——导数干净得可以直接背）。

**第二步：回传到第 1 层。** 由链式法则，$\mathcal L$ 经 $\boldsymbol z^{(2)}$ 依赖 $\boldsymbol a^{(1)}$：
$$\frac{\partial\mathcal L}{\partial\boldsymbol a^{(1)}}=\frac{\partial\mathcal L}{\partial\boldsymbol z^{(2)}}\frac{\partial\boldsymbol z^{(2)}}{\partial\boldsymbol a^{(1)}}=\boldsymbol\delta^{(2)}W^{(2)\mathrm T}.$$
再过激活：$\boldsymbol\delta^{(1)}=\dfrac{\partial\mathcal L}{\partial\boldsymbol a^{(1)}}\odot\phi'(\boldsymbol z^{(1)})=\bigl(\boldsymbol\delta^{(2)}W^{(2)\mathrm T}\bigr)\odot\phi'(\boldsymbol z^{(1)})$。

**第三步：参数的梯度。** 因 $\boldsymbol z^{(1)}=\boldsymbol xW^{(1)}+\boldsymbol b^{(1)}$，有 $\dfrac{\partial\mathcal L}{\partial W^{(1)}}=\boldsymbol x^{\mathrm T}\boldsymbol\delta^{(1)}$，$\dfrac{\partial\mathcal L}{\partial\boldsymbol b^{(1)}}=\boldsymbol\delta^{(1)}$。推广到批与任意层即得定理。$\blacksquare$
:::

:::

::: intuition 反向传播"复用了什么"
关键是 $\boldsymbol\delta^{(l)}$ 只依赖 $\boldsymbol\delta^{(l+1)}$——**同一份误差信号被本层两个用途共享**（一是继续往上传，二是算本层参数梯度）。于是求全部梯度的代价只是「一次前向 + 一次反向」，与层数成**线性**关系，而不是对每个参数单独求导。深度学习能训起来，靠的就是这条 $O(\text{层数})$ 的捷径。
:::

::: method 亲手跑一遍：纯 numpy 的两层网络与反向传播（本编已验证运行）

下面这段代码**只用 numpy、不依赖任何框架**，把本节的三件事——前向、损失、反向——逐行落实在一个线性不可分的 XOR 型数据集上。四步注释对应[例 1.2](#12-多层感知机与通用逼近) 的形状推演与[定理 1.2](#15-梯度下降与反向传播) 的递推。

```python
import numpy as np
rng = np.random.default_rng(0)

N, D, H, C = 64, 2, 32, 2                # 样本数 / 输入维 / 隐藏维 / 类别数
X = rng.normal(0, 1, (N, D))             # 两维特征
y = (X[:, 0] * X[:, 1] > 0).astype(int)  # XOR 型标签——线性不可分（例 1.1）

W1, b1 = rng.normal(0, 0.5, (D, H)), np.zeros(H)
W2, b2 = rng.normal(0, 0.5, (H, C)), np.zeros(C)
eta = 0.1                                # 学习率

for step in range(2000):
    # ① 前向：z1 (N,H) → ReLU → z2 (N,C) → softmax
    z1 = X @ W1 + b1
    a1 = np.maximum(0, z1)
    z2 = a1 @ W2 + b2
    z2 -= z2.max(axis=1, keepdims=True)  # 数值稳定：先减行最大值
    p = np.exp(z2); p /= p.sum(axis=1, keepdims=True)
    # ② 损失：交叉熵（对 batch 取均值）
    L = -np.log(p[np.arange(N), y]).mean()
    # ③ 反向：softmax+CE 对 logits 的梯度 = p − y（定理 1.2 第一步）
    d2 = p.copy(); d2[np.arange(N), y] -= 1; d2 /= N
    gW2, gb2 = a1.T @ d2, d2.sum(0)      # ∂L/∂W2 = a1ᵀ δ2
    da1 = d2 @ W2.T                      # δ 回传
    dz1 = da1 * (z1 > 0)                 # ReLU 导数：0/1 掩码
    gW1, gb1 = X.T @ dz1, dz1.sum(0)
    # ④ 更新
    W1 -= eta * gW1; b1 -= eta * gb1; W2 -= eta * gW2; b2 -= eta * gb2
    if step % 400 == 0:
        acc = (p.argmax(1) == y).mean()
        print(f"step {step:5d}  loss {L:.4f}  acc {acc:.2%}")
```

实测输出（`numpy` 2.x，随机种子 0）：loss 从 $1.09$ 单调降到 $0.03$，400 步即达 **100%** 准确率——这正是[例 1.1](#11-从神经元到感知机) 里单层感知机**无解**的 XOR 问题，加一个隐藏层后迎刃而解。建议动手改两处再跑：把 `np.maximum(0, z1)` 换成恒等映射（去掉非线性，看它退化回线性分类器）；把 `eta` 调大 10 倍（看损失发散）。

:::

::: method 训练循环（伪代码）
```text
初始化 θ
重复若干 epoch：
  打乱训练集，切成若干 mini-batch
  对每个 batch (X, y)：
    前向：ŷ = f(X; θ)             # 得到预测
    算损失：L = loss(ŷ, y)
    反向：∇ = backprop(L, θ)      # 定理 1.2

  每个 epoch 末在验证集上评估，记录 train / val 损失
```

## 1.6 优化器：从 SGD 到 Adam

朴素 SGD 方向抖动、对学习率敏感。两种常见的改进：

- **Momentum（动量）**：累积历史梯度方向 $v_t=\beta v_{t-1}+\nabla_\theta\mathcal L$，用 $v_t$ 更新。沿一致方向加速、在震荡方向抵消，像小球滚下山带着惯性。
- **Adam**：同时维护梯度的一阶矩（动量）与二阶矩（梯度平方的滑动平均），对每个参数做自适应缩放。对学习率不敏感、收敛快，是默认首选。

$$\text{Momentum: }\theta\leftarrow\theta-\eta v_t;\qquad
\text{Adam: }m_t=\beta_1m_{t-1}+(1-\beta_1)g,\ \ v_t=\beta_2v_{t-1}+(1-\beta_2)g^2,\ \ \theta\leftarrow\theta-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}.$$

::: think 学习率才是"真正的超参数"
优化器换来换去，效果常常不如把 $\eta$ 调对。经验做法：先用 Adam 配 $\eta=3\times10^{-4}\sim10^{-3}$，观察前几百步的损失曲线——**发散就降 10 倍，下降太慢就升 3 倍**；再用学习率预热 + 余弦退火这类调度提升最终效果。
:::

## 1.7 过拟合、欠拟合与正则化

模型在训练集上很好、在验证集上差，叫**过拟合**；两边都差，叫**欠拟合**。

| 现象 | 训练误差 | 验证误差 | 原因（偏置-方差） | 对策 |
|:--|:--|:--|:--|:--|
| 欠拟合 | 高 | 高 | **高偏置**：模型太弱 / 训得不够 | 加宽加深、训练更久、减正则、换更好特征 |
| 过拟合 | 低 | 高 | **高方差**：模型太强 / 数据太少 | **Dropout**、权重衰减、早停、数据增强、减小模型 |

常用正则化手段：

- **Dropout**：训练时以概率 $p$ 随机把神经元输出置零，逼网络不依赖任何单个神经元，等价于集成大量子网络；推理时关闭并按比例缩放。
- **权重衰减（L2）**：在损失里加 $\lambda\lVert W\rVert_2^2$，抑制参数过大。
- **早停（early stopping）**：验证损失不再下降就停，是最省事的正则。
- **数据增强**：图像翻转/裁剪、文本回译等，人工扩大数据多样性。

::: intuition Dropout 为什么有用
一个神经元不能总指望某个同伴一定在场，于是每个神经元都得学出**独立有用**的特征，网络的表示变得冗余而稳健——这正是「集成多个子网络」的效果近似。它同时也是「高方差」最直接的解药。
:::

## 1.8 本讲陷阱

::: errata 常见误解清单
1. **把「层数多」等同于「能力强」**：深而窄 vs 宽而浅各有所长，关键是与数据先验匹配（图像配卷积、序列配注意力），盲目堆层只会更难训。
2. **隐藏层用 Sigmoid / tanh**：深层网络的梯度会消失。**隐藏层默认 ReLU 族**；Sigmoid 只用在需要 $(0,1)$ 输出的地方（如二分类输出层、门控）。
3. **softmax 与损失用错**：分类输出层配 softmax + 交叉熵（框架里常把 softmax 融进 `CrossEntropyLoss`，此时**网络不要再加 softmax**，否则做两次）；回归用线性输出 + MSE。
4. **拿验证集调参、又用验证集报最终结果**：会造成信息泄漏与过于乐观的结论。调参用验证集，最终指标用**测试集**。
5. **只盯训练损失**：训练损失降不降、验证损失跟不跟，两者要一起看才能诊断。
6. **忘了小批量里的批维**：前向形状写错多半是批维没对齐（见[例 1.2](#12-多层感知机与通用逼近)）。
7. **学习率与批大小一起动**：增大批大小通常要相应增大学习率；只改一个常导致「不收敛」的错觉。
:::

## 1.9 本讲小结

**三句话带走**：

1. 一切深度网络都是「**结构 + 损失 + 梯度下降**」，第 2–9 讲都是这个范式换结构。
2. **非线性激活**让深度有意义，**反向传播**让深度可训练（链式法则的线性时间实现），**交叉熵/ MSE** 让分类/回归各有正确目标。
3. 训练的日常是**诊断**：同时看训练与验证曲线，按「数据 → 损失 → 学习率 → 初始化 → 正则」的顺序找病因。
