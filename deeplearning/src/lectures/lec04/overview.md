## 这一讲要解决的真实问题

前三讲的模型都在回答同一个问题：**给定 $\boldsymbol x$，预测 $y$**。分类、回归、序列标注、目标检测，学的都是条件分布 $p(y\mid\boldsymbol x)$。这一讲把方向掉转 180°——**只给数据，不给标签**，让模型学数据自身的分布 $p(\boldsymbol x)$，并且能从中**采样**出训练集里没有、却又像真的图像、音频、动作序列与离散符号。

这件事为什么难？因为「像不像」没有一个像交叉熵那样现成的、逐样本可算的损失。三类做法由此分岔：**显式似然**路线（自回归、流、VAE、扩散）写下一个目标函数（或它的下界）去最大化；**隐式**路线（GAN）不写似然，用「能否骗过判别器」当信号；**得分—能量**路线（score-based / EBM）只学密度函数的梯度或相对高度。本讲按「密度能不能算 → 采样能不能快 → 训练稳不稳」三根轴，把这条谱系走一遍。

第二件难事是**代价**。生成建模里没有免费午餐：能量化的取舍至少有四个轴——似然、样本质量与多样性、训练稳定性、采样代价。VAE 一次前向出样本但偏糊；GAN 锐利却脆弱且会模式坍塌；扩散稳定、质量高、可控，但要迭代几十到上千步；自回归似然完备可算，却必须一个一个 token 串行生成。这一讲的每一节都在回答「某一根轴上你放弃了什么、换来了什么」。

第三件难事是**评价**。FID / IS 这类代理指标有明确的方法论缺陷（见 [4.1](sec41.md)），但工业界又离不开它们。本教程的处理方式是：把指标的定义、它真正度量的东西、以及它无法度量的东西分别写清楚，并给出「人类偏好评估」的位置。

| **[4.1 生成建模要做什么](sec41.md)** | 生成模型的定义、分类学与评价困境是什么？ | 生成 = 密度（或相对分数）+ 采样；谱系分三支：显式似然（AR / 流 / VAE / 扩散）、隐式（GAN）、得分—能量 | 把「似然高」当成「样本好」——两者在多模态数据上系统性错位 |
| **[4.2 自编码器：压缩，不是生成](sec42.md)** | 能重建，为什么不能当生成模型？ | AE 学的是「数据窄带上的编码—解码表」，潜空间无先验、团间是空洞，随机采的 $z$ 落在低密度区 | 用「重建损失很低」当生成能力强弱的证据 |
| **[4.3 变分自编码器：把潜空间变成可采样的空间](sec43.md)** | 怎样让潜空间「可采样」？ | 三件套缺一不可：先验 $p(z)=\mathcal N(0,I)$ 定采样起点、ELBO 定目标、重参数化让采样可导；KL 有闭式 | 采样时用后验而不是先验取 $z$（那是在做重建）；丢掉 KL 项把 VAE 退化回 AE |
| **[4.4 生成对抗网络：用博弈换锐利](sec44.md)** | 无似然的生成靠什么信号？ | 最优判别器 $D^\star=p_{\text{data}}/(p_{\text{data}}+p_g)$ 把博弈化成最小化 JS 散度；支撑不重叠时 JS 是常数→梯度消失 | 以为 GAN 训不好都是代码 bug；把模式坍塌当成调参问题 |
| **[4.5 扩散模型：把生成拆成多步去噪](sec45.md)** | 怎样用「回归」替代「博弈」，换来稳定与质量？ | 前向闭式 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\varepsilon$；训练就是预测所加噪声；DDIM 提供确定性少步采样；CFG 用两个条件分支的差放大引导 | 训练与采样的噪声调度 / 归一化范围不一致，导致采样直接崩坏 |
| **[4.6 潜空间扩散与整流流](sec46.md)** | 像素空间扩散贵在哪里？直线搬运为什么更省步数？ | LDM 把扩散搬到 VAE 潜空间（两阶段训练）；DiT 用 Transformer + adaLN-Zero 替换 U-Net；整流流回归直线速度场，配合重流化把轨迹拉直；一致性模型学「任意时刻 → 原图」的一步映射 | 以为「少步」等于「一步」；忽略潜空间编码器本身带来的重建误差上限 |
| **[4.7 离散与自回归生成：VQ 家族与视觉自回归](sec47.md)** | 连续潜空间之外，离散 token 路线怎么工作？ | VQ-VAE 用量化和直通估计量拿到离散代码；FSQ 用标量量化绕开代码本学习；VAR 把光栅扫描换成 next-scale prediction；掩码扩散语言模型是文本上的离散去噪 | 把代码本利用率低当成「容量不够」；以为自回归只能光栅扫描 |
| **[4.8 应用谱系与取舍](sec48.md)** | 面对真实任务，怎么选、怎么改、怎么标？ | 四轴取舍表 + 决策表；定制与编辑（ControlNet / LoRA / inpainting）是「条件注入」问题；水印与溯源是部署的必要件 | 拿单一 FID 数字做全量对比；忽略数据授权与溯源要求 |

## 四类骨架的取舍速查（本讲的「一张总表」）

这张表是本讲**唯一一个值得背下来的东西**。八节内容都可以从它出发推导：每一节是在某一根轴上做取舍。

| 模型 | 显式似然 | 样本质量 | 训练稳定性 | 采样代价 | 可控性 | 潜空间结构 |
|:--|:--|:--|:--|:--|:--|:--|
| **AE**（[4.2](sec42.md)） | 无 | —（不能生成） | 高（纯回归） | — | — | 无概率结构（不可采样） |
| **VAE**（[4.3](sec43.md)） | 有下界（ELBO） | 偏模糊 / 平滑 | 高（重建 + KL 的回归） | 低（一次前向） | 中（条件 VAE / 潜空间编辑） | 由 KL 拉成连续、可插值的空间 |
| **GAN**（[4.4](sec44.md)） | 无（只有相对判别） | 锐利 | 低（鞍点博弈） | 低（一次前向） | 中（条件注入容易） | 隐式，无密度 |
| **扩散**（[4.5](sec45.md)） | 有（可写出变分下界） | 高且多样 | 高（逐步去噪回归） | 高（$T$ 次前向） | **高**（CFG / ControlNet / inpainting） | 时间步本身充当分层潜变量 |
| **潜空间扩散**（[4.6](sec46.md)） | 有（同上） | 高（有解码器上限） | 高 | 中（步数 × 小分辨率） | 高 | 两层：VAE 潜空间 + 时间步 |
| **流匹配 / 整流流**（[4.6](sec46.md)） | 有（连续时间视角） | 高 | 高 | **低～中**（路径直 → 少步） | 高 | 连续时间轨迹 |
| **离散 AR / VQ 家族**（[4.7](sec47.md)） | **可精确算**（连乘） | 中～高 | 高 | 高（逐 token 串行） | 中 | 有限码本（离散） |

**四个轴就是四句话**：似然决定「能不能比较谁拟合得更好」；质量与多样性决定「产出能不能用」；稳定性决定「训练要花多少人天」；采样代价决定「能不能做成实时产品」。**没有一根轴可以同时最优**——这正是本讲要反复强调的工程现实。

## 三句话带走

1. **生成建模的目标是学会 $p(\boldsymbol x)$ 并能从中采样**，与判别模型「学 $p(y\mid\boldsymbol x)$」是两条不同的路；「能重建」远不等于「能采样」——这条界线贯穿全讲（[4.2](sec42.md) 给出它最锋利的版本）。
2. **四类骨架各有一招**：AE 只有重建、没有分布；VAE 用 ELBO $=$ 重建 $-$ KL 把潜空间变成可采样的连续空间（靠**重参数化**才使采样可导）；GAN 用对抗博弈逼出锐利样本，代价是脆弱与**模式坍塌**；扩散把生成拆成多步**去噪回归**，稳、质量高、可控，代价是采样慢——而 4.6 的整套工程就是围绕这一个代价展开的。
3. **取舍就看四个轴**：似然（VAE / 扩散 / 流有，GAN 没有）· 质量与多样性（GAN / 扩散锐利，VAE 偏糊）· 稳定性（VAE / 扩散 / 流稳，GAN 脆）· 采样代价（VAE / GAN 一次前向，扩散 $T$ 步，离散 AR 串行）。4.7 补上第五条判断：**离散表示把生成变成分类，因此天生能表达多模态；连续回归天生产生平均化。**

- [第 2 讲](../lec02/overview.md)的序列建模与注意力，其实就是**自回归生成模型**的另一条路线（把 $p(\boldsymbol x)$ 拆成条件概率连乘），与扩散的「一次生成整个样本」互补；[4.6](sec46.md) 的 DiT 直接把 Transformer 当生成主干，两讲在这里会合。
- [第 5 讲](../lec05/overview.md)强化学习里，本讲的生成模型可以直接当**策略**（扩散策略 / 流匹配策略）。[4.8](sec48.md) 的选型表里有一条专门讲这个场景，以及它为什么天然适合多模态动作分布。
- [第 6 讲](../lec06/overview.md)的离散扩散语言模型与 [4.7](sec47.md) 是同一套机制在文本上的应用；[第 9 讲](../lec09/overview.md)的 LoRA / QLoRA 与 [4.8.2](sec48.md#sec-4.8.2) 的图像 LoRA 共用同一个低秩增量的思想。
- [Lab 1](../../labs/lab1.md) 的音乐生成是自回归生成的入门实践，[Lab 3](../../labs/lab3.md) 微调大语言模型则是把本讲的生成思想用到文本模态上。
