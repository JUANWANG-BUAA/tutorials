## 二、术语与常见译误

这一节的用法：**当你在「同一个词指向两件事」上卡住时来查**。以下七条都在本讲内部构成实际困惑，不是泛泛的词汇表。

| 术语 | 常见误用／误译 | 正确理解 |
|:--|:--|:--|
| **隐状态（hidden state）vs 细胞状态（cell state）** | 把两者当成同一个向量的两个名字；或把框架返回的 `c_n` 理解成「另一种 output」 | $\boldsymbol c_t$ 是 LSTM 内部的**长期记忆**，不对外输出；$\boldsymbol h_t=\boldsymbol o_t\odot\tanh(\boldsymbol c_t)$ 是把记忆「读出来」的部分，供输出层与下一步门控使用（[定义 2.3.1](sec23.md#def-2.3.1)）。两者的雅可比不同：$\partial\boldsymbol c_t/\partial\boldsymbol c_{t-1}=\operatorname{diag}(\boldsymbol f_t)$ 是加法通道，而读出路径每次都被 $\boldsymbol o_t$ 与 $\tanh'$ 打折（[定理 2.3.1](sec23.md#thm-2.3.1)）。GRU 没有独立的 $\boldsymbol c$ |
| **query / key / value 的中文** | 译成「问题 / 钥匙 / 数值」；也常把 key 与「键值对」里的键混为一谈 | 查询（query）、键（key）、值（value）：**想找什么 / 每个位置挂出的匹配标签 / 真正被取走的内容**（[定义 2.4.4](sec24.md#def-2.4.4)）。$K$ 只参与打分、不参与聚合——**键指路、值交货**；把 $V$ 换成随机数，输出立刻变随机 |
| **位置编码（position encoding）vs 位置嵌入（position embedding）vs 词嵌入（word embedding）** | 三者混称，进而在「能不能把学习式换成 RoPE」上判断错 | 正弦式与学习式都是**嵌入加性**：加到词嵌入上，与词义共享同一份 $d$ 维预算，学习式还有硬上限 $L_{\max}$（[定义 2.6.1](sec26.md#def-2.6.1)、[定义 2.6.2](sec26.md#def-2.6.2)）；RoPE 是**QK 乘性**：旋转 $\boldsymbol q,\boldsymbol k$ 本身，$\boldsymbol v$ 与残差主干不动（[定义 2.6.3](sec26.md#def-2.6.3)）；ALiBi / T5 分桶是**分数加性**：加在 logits 上（[定义 2.6.4](sec26.md#def-2.6.4)）。三类可替换性完全不同——换注入方式通常必须重训 |
| **KV cache 里的 K 与 V** | 当成「键值对缓存」的泛指；或以为缓存里也存 $\boldsymbol Q$ | 缓存的就是注意力的**键与值** $\boldsymbol K_{1:t},\boldsymbol V_{1:t}$，每步只新算 $\boldsymbol Q_t$（[定义 2.5.4](sec25.md#def-2.5.4)）；缓存量的头数是**键值头数** $n_{kv}$（MHA 时 $n_{kv}=H$，GQA / MQA 时小于 $H$）（[方法 2.5.3](sec25.md#method-2.5.3)） |
| **序列长度（sequence length）vs 上下文窗口（context window）** | 把训练长度、位置表长度、部署可用窗口当成同一个数 | $T$ 是张量的时间维；学习式位置表只有 $L_{\max}$ 行，越界即「无参数可用」（[定义 2.6.2](sec26.md#def-2.6.2)）；上下文窗口是**部署时真正可用的长度**，同时受位置外推能力与 KV cache 显存限制（[2.6.6](sec26.md#sec-2.6.6)）。三个数字经常互不相等，报告时必须写清是哪一个 |
| **注意力权重（weight）vs 贡献（contribution）** | 读成「$P_{ij}=0.9$ ⇒ 位置 $j$ 最重要」，并用它当解释证据 | 输出是 $\boldsymbol P\boldsymbol V$：权重只决定**取多少**，取到的内容由 $\boldsymbol V$ 的行决定；且 softmax 权重之和恒为 1，一个位置上升必然压低其他位置（[2.4.7](sec24.md#sec-2.4.7)）。权重是有用的调试信号，不是解释证据 |
| **复杂度里的 $O(T^2)$ 指什么** | 把 $T^2$ 当成「总开销」而不区分对象与阶段 | $O(T^2)$ 指**分数 / 权重矩阵的规模**（$B\cdot H\cdot T^2$，与 $d$ 无关）；时间开销是 $O(T^2d)$；KV cache 只是 $O(T)$ 但常数大，是**推理**时的主要消费者。三者的缓解手段不同（[2.4.6](sec24.md#sec-2.4.6)、[方法 2.6.1](sec26.md#method-2.6.1)） |

## 三、时效补注

母本录播年代与当前工程默认之间存在若干处「已经换了默认答案」的差异。涉及版本与比例的条目均标注为**社区惯例**，采用前请结合自己的配置验证。

| 主题 | 母本年代（约 2018–2020 录播口径） | 当前工程默认（截至 2025） | 本教程的写法 |
|:--|:--|:--|:--|
| 序列主干 | 以 RNN → LSTM → 注意力为线索，Transformer 作为「最新一代」引入 | 注意力（Transformer）已是**默认主干**，decoder-only 收敛为通用接口 | 保留三代线索作为因果链（[2.2](sec22.md)–[2.5](sec25.md)），但把 [2.5](sec25.md) 的工程件与 [2.6](sec26.md) 的位置编码写全 |
| 位置编码 | 正弦式与学习式，一句话带过 | **RoPE** 是开源模型默认；ALiBi / T5 分桶作为「短训长测」备选；扩窗常配位置插值 / 频率缩放一类的后处理 | [2.6.1](sec26.md#sec-2.6.1)–[2.6.5](sec26.md#sec-2.6.5) 按「注入位置」分三类系统化；扩窗细节标**需核实**（随框架与实现变化） |
| 归一化与块布局 | Post-LN（原始 Transformer 布局） | **Pre-LN + RMSNorm** 几乎是默认；FFN 常用 SwiGLU 门控变体 | [定理 2.5.2](sec25.md#thm-2.5.2) 给 Pre / Post-LN 的梯度尺度差别与各自代价（收尾归一化、warmup） |
| 注意力实现 | 朴素实现：物化 $T\times T$ 权重矩阵 | **FlashAttention / SDPA** 成为默认后端：精确、FLOPs 不变、省中间显存与带宽 | [定理 2.6.4](sec26.md#thm-2.6.4) 给在线 softmax 的等价性证明，明确「不是近似」 |
| 推理显存 | 基本不提 KV cache | KV cache 是长上下文推理的**主项**；GQA / MQA、KV 量化、滑窗与淘汰是常规压缩手段 | [方法 2.5.3](sec25.md#method-2.5.3) 给显存账与三档对照，[方法 2.6.2](sec26.md#method-2.6.2) 给手段与代价 |
| 替代架构（近年增量） | 不覆盖 | **SSM**（S4 → Mamba → Mamba-2）、**线性注意力 / RWKV**、**混合架构**（按比例交错注意力与线性层）、**MoE** 稀疏专家 | [2.7](sec27.md) 标注「教材外拓展」：考试不要求背公式，但要求说清**代价与适用条件** |
| 生成与采样 | 贪心 / 束搜索 + 温度 | 温度 / top-k / **top-p** 是默认组合，采样参数按任务与风格调 | [2.8.5](sec28.md#sec-2.8.5) 把「改分布形状」与「改支撑集」分成两件事，并给 [例 2.8.1](sec28.md#ex-2.8.1) 的手算 |

**一条通用提醒**：本讲的所有具体数字（$3.1\times10^{23}$、$n^\star$、$20{,}608$、$7.09$M、$4$ GiB、$64$ GiB、$0.55$ TFLOP 等）都来自**正文给定配置**。引用到自己的项目前，请按 [方法 2.5.3](sec25.md#method-2.5.3) 与 [方法 2.6.1](sec26.md#method-2.6.1) 的公式重算，并以所用框架版本的实现为准。

**为什么默认会变**：这些默认大多不是数学结论，而是「在当时硬件、数据规模与框架能力下性价比最高的选择」。硬件（BF16 / FP8）、训练规模（多卡到上万卡）、框架（融合算子、并行策略）任一项变化，默认答案就可能改写。**本页的价值在于记录「变化发生过」，而不是把 2025 年的默认当成永久正确。**
