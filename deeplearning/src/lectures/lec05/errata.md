# 第 5 讲 · 勘误与补注

> 用途：说明本讲与母本讲义的差异、容易踩的译名坑、录播年代与 2023–2025 实践之间的时效落差，以及本教程自身的更正记录。
> 阅读顺序建议：先看第二节（术语），因为这一讲的混淆绝大多数来自词；再看第三节（时效），最后按需查第一节与第四节。

## 一、对照母本讲义的补注

母本把 RL 放在与监督/无监督并列的位置上，用「交互循环 → 值方法 → 策略方法 → 对齐应用」的骨架把一整讲铺完；它的目标是让你**认出**这些算法与它们的适用位置，而不是让你从头推导。本教程沿用同一骨架，但把每一处「母本只给结论」的地方补齐——逐条如下：

| 母本的处理 | 母本省略了什么 | 本教程补在哪里 |
|:--|:--|:--|
| 交互循环用一张图带过；奖励「稀疏且延迟」只作口头描述 | 稀疏程度的**量级**论证（成功率 $2^{-H}$）、三种「奖励—动作」关系（即时稠密 / 延迟稠密 / 延迟稀疏） | [5.1.3](sec51.md) 与其中的 `think` 框 |
| 讲探索「用 $\varepsilon$-greedy」 | 探索税可以**精确算出来**：$\Delta=\varepsilon(\mu^\ast-\bar\mu)$，以及「常数 $\varepsilon$ 永远拿不到满分」的推论 | [定理 5.1.1](sec51.md#thm-5.1.1) 与紧随的推导、`intuition` |
| 写 MDP 五元组与贝尔曼方程 | 期望方程的**完整推导**、矩阵形式与 $(I-\gamma P^\pi)^{-1}$ 的代价、最优算子的**压缩性**与唯一性 | [定理 5.2.1](sec52.md#thm-5.2.1)、[定理 5.2.2](sec52.md#thm-5.2.2) 的推导；可对照[附录 C.9](../../appendix/derivations.md) |
| 给 Q-learning 更新式，说「它会收敛」 | 收敛的**前提**（充分访问 + Robbins–Monro 步长条件）与随机近似骨架；SARSA 与它的**同一条转移对照算例** | [定义 5.3.2](sec53.md#def-5.3.2) 与[例 5.3.1](sec53.md#ex-5.3.1)（5.3 vs 3.95） |
| 说 DQN 用「回放 + 目标网络」 | 两个技巧各治**哪个病**的对照，以及 $\max$ 造成的过高估计**量级估算** $\sigma\sqrt{2\ln N}$ | [方法 5.3.1](sec53.md#method-5.3.1)、[定理 5.3.2](sec53.md#thm-5.3.2) 与[例 5.3.2](sec53.md#ex-5.3.2) |
| 给策略梯度定理的结论式 | 按轨迹展开的**四步推导**、因果性（回报-to-go）的证明、基线无偏性的一行引理 | [定理 5.4.1](sec54.md#thm-5.4.1)、[定理 5.4.2](sec54.md#thm-5.4.2)、[定理 5.4.3](sec54.md#thm-5.4.3)；[附录 C.10](../../appendix/derivations.md) |
| 讲 PPO「用 clip 代替 KL」，配一张目标函数示意图 | **分四象限的梯度分析**（哪两个象限归零、哪两个「拉回」）、裁剪目标是无裁剪目标的**保守下界**、PPO 的三项目标与诊断指标表 | [定义 5.5.2](sec55.md#def-5.5.2) 后的推导与[例 5.5.2](sec55.md#ex-5.5.2)、[方法 5.5.3](sec55.md#method-5.5.3)、[方法 5.5.4](sec55.md#method-5.5.4) |
| 提 RLHF 三步与「用偏好训奖励模型」 | Bradley–Terry 的**建模假设与其危险**（单维标量、$\sigma$ 饱和、冲突偏好被平均掉）；DPO 的**三步推导**与 $Z(x)$ 抵消这一关键 | [定义 5.6.2](sec56.md#def-5.6.2) 与其 `intuition`、[定理 5.6.2](sec56.md#thm-5.6.2) 的推导；[附录 C.13](../../appendix/derivations.md) |
| 讲训练与调参经验 | 四类失败模式的**症状—根因—处方**诊断表、多种子 + 多回合 + 回报分布的评估协议与**置信区间算例** | [方法 5.7.4](sec57.md#method-5.7.4)、[方法 5.7.5](sec57.md#method-5.7.5)、[例 5.7.1](sec57.md#ex-5.7.1) |

一句话概括：**母本给你「哪条路通向哪里」，本教程补上「这条路为什么通、代价多少、什么时候断」。**

## 二、术语与常见译误

| 术语 | 常见误用 / 误译 | 正确理解 |
|:--|:--|:--|
| **reward（奖励）与 return（回报）** | 把两者都译成「收益」，于是「最大化收益」这句话既可能指最大化即时 $r$ 也可能指最大化 $G_t$ | 奖励 $r_{t+1}$ 是**单步标量**，回报 $G_t=\sum_{k\ge0}\gamma^{k}r_{t+k+1}$ 是**折扣累积量**；RL 的目标是后者（[定义 5.2.3](sec52.md#def-5.2.3)）。混用会直接导出一个错误结论：「奖励大的动作多做」——奖励不在动作上，它只评价结果 |
| **policy（策略）与 actor（演员网络）** | 把 actor 与 policy 当同义词，于是觉得「Actor–Critic 里有两个策略」 | 策略是**数学对象** $\pi(a\mid s)$（状态到动作分布的映射）；actor 是**实现它的那组参数** $\pi_\theta$。Critic 里没有策略，只有值函数 $V_\phi$（[定义 5.2.2](sec52.md#def-5.2.2)、[方法 5.5.1](sec55.md#method-5.5.1)） |
| **critic（评论家）与 value function（值函数）** | 把「Critic 就是 $Q$ 网络」 | Critic 是**角色名**（负责评、向 actor 提供优势），值函数是**它拟合的对象**。值方法里那个网络拟合的是 $Q$，Actor–Critic 里拟合的通常是 $V$——**差别就在于决策交给谁**：值方法靠 $\arg\max_a Q$，Actor–Critic 靠策略网络，所以只需 $V$（[命题 5.2.1](sec52.md#prop-5.2.1) 后 `intuition`） |
| **on-policy 与 off-policy 的判据** | 用「有没有用 $\max$」「更新频率」当判据，或者笼统地说「Q-learning 是 off-policy 所以用旧数据没问题」 | 判据只有一条：**产生数据的行为策略**与**被评估/改进的目标策略**是不是同一个。SARSA 用行为策略实际选出的 $a'$ ⇒ on-policy；Q-learning 用 $\max$，学的是**与数据来源无关**的目标（最优 $Q^\ast$）⇒ off-policy（[定义 5.3.2](sec53.md#def-5.3.2)）。**反例预警**：「off-policy」不等于「可以不探索」——充分访问仍是收敛前提；PPO 则是**近似 on-policy**：靠 $\rho$ 修正后只能多跑几个 epoch |
| **RLHF 与 DPO 的关系** | 说「DPO 是 RLHF 的近似」或「DPO 也是 RLHF 的一种」 | 在「KL 正则目标 + Bradley–Terry 偏好模型」这套假设下两者**等价**（[定理 5.6.2](sec56.md#thm-5.6.2)），真正近似的地方只有一处——假设最优解落在参数化策略族内。工程差别在**失败模式**：RLHF 容易被奖励模型的漏洞带偏，DPO 没有奖励模型这层缓冲，标注噪声直接进策略梯度（[5.6.9](sec56.md) 的 `think`） |
| **advantage 与 TD error** | 把 $A(s,a)$ 与 $\delta_t$ 当成一回事，或以为 $A=Q-V$ 是「一步」的量 | $\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$ 是**一步残差**；$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$ 是**多步**的「比平均好多少」（[定义 5.5.1](sec55.md#def-5.5.1)）。两者的桥正是 GAE：当 $V=V^\pi$ 时 $A^\pi(s_t,a_t)=\mathbb E[\sum_{l\ge0}\gamma^l\delta_{t+l}]$，一步 TD 残差只是它的 $\lambda=0$ 特例（[定理 5.5.1](sec55.md#thm-5.5.1)） |
| **贝尔曼「期望」方程与「最优」方程** | 说「贝尔曼方程用来求最优值」 | 期望方程评的是**给定策略**的值 $V^\pi$，是**线性**方程组、有唯一解；最优方程才给 $V^\ast$，把 $\sum_a\pi(a\mid s)$ 换成 $\max_a$ 后变成**非线性**不动点（[定理 5.2.2](sec52.md#thm-5.2.2)）。混用的后果是「以为在评估、实际在改进」的策略退化 |

## 三、时效补注（2023–2025 的实践落差）

母本录播年代的 RL 叙事以 **DQN（Atari）与策略梯度（连续控制）**为主，对齐只作为「应用展望」出现。以 2023–2025 年的实践看，重心已经明显移动，读正文时请按下表换算：

| 主题 | 母本年代的说法 | 2023–2025 的实践 | 本讲对应处 |
|:--|:--|:--|:--|
| **主战场** | 游戏与控制（Atari / MuJoCo / 机器人） | **语言模型对齐与推理模型**：偏好优化、可验证奖励、推理期搜索成为主线 | [5.6](sec56.md) 全节 |
| **奖励从哪来** | 环境内建的游戏得分 | **偏好模型（RLHF）或程序判定的 0/1（RLVR）**；「奖励设计」变成数据工程 | [5.6.3](sec56.md)、[5.6.7](sec56.md) |
| **默认算法** | DQN 家族为主，PPO 用于连续控制 | **PPO 仍是 RLHF 的默认执行器，但离线侧 DPO 家族已分流**；推理任务上 GRPO 类（去 Critic）成为主力 | [5.6.5](sec56.md)、[5.6.6](sec56.md)、[方法 5.6.6](sec56.md#method-5.6.6) |
| **「算力换什么」** | 换样本（与环境交互次数） | 换**采样与评判**：每组多采样（GRPO 的 $G$）、推理期多次采样再投票/搜索（test-time scaling） | [5.6.6](sec56.md)、[5.7](sec57.md) |
| **稳定化手段** | 回放池 + 目标网络；KL 惩罚 | 回放与目标网络仍是值方法标配；策略侧更多靠 **KL 早停 / 裁剪比例 / 优势归一化**的仪表盘式监控 | [方法 5.5.4](sec55.md#method-5.5.4) |
| **评估文化** | 报最优种子 / 单条曲线 | **多种子 + 多回合 + 报分布**已是硬要求；单点数字不构成证据 | [方法 5.7.5](sec57.md#method-5.7.5)、[例 5.7.1](sec57.md#ex-5.7.1) |
| **环境接口** | `gym` 的 `reset() -> obs`、`step() -> 四元组` | **Gymnasium** 的 `reset() -> (obs, info)`、`step() -> 五元组`（`terminated`/`truncated` 必须区分） | [5.4.7](sec54.md) 的 `note`、[5.7.1](sec57.md#method-5.7.1) |

两个必须跟着更新的工程习惯：① **奖励尺度与学习率要一起定**——奖励整体乘一个大常数不改变信噪比，等价于把有效学习率乘同倍数（[5.4.7 即时自测 Q4](sec54.md)）；② **终止与截断必须分开处理**，否则靠近时间上限的状态值被系统性低估（[方法 5.7.1](sec57.md#method-5.7.1)）。
