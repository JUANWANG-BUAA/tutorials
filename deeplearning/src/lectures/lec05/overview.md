## 这一讲要解决的真实问题

前四讲的模型都在同一个范式里工作：**有标签，最大化似然或最小化误差**。分类有正确类别、检测有框的坐标、生成有「这张图属于数据分布」的对数似然。这一讲把范式整体换掉：**没有标签，只有一个标量奖励**。下棋时没有哪一步被标注为「对」，只有最后输赢；机器人迈步时没有老师告诉你「这一脚该迈多大」；推荐系统也只看到用户点没点。我们能拿到的，是**一串既稀疏又延迟的奖励**——大部分时刻为 0，赢了才见到 +1。

这件事在数学上难在三个地方，而它们互相纠缠。第一是**信用分配**（credit assignment）：这一局赢了，是开局那步妙手还是对手失误？奖励必须跨越很长时间才能摊到具体动作上。第二是**数据不独立同分布**：训练数据由智能体自己的动作产生，策略一变，未来遇到的分布随之漂移——第 1 讲里「样本 i.i.d.」这条几乎被所有理论结论依赖的假设，在这里彻底失效。第三是**探索与利用的张力**：信息只能靠采样获得，而采样会消耗机会，永远利用会困在次优解里，永远探索则永远在浪费时间。

要给「试错」找到可以推导的语言，我们需要把环境形式化：**马尔可夫决策过程**（Markov Decision Process, MDP）。它的价值在于把「未来只依赖当前状态与动作」写成一个可验证的条件，从而让「值」满足一个**自洽的递归方程**——贝尔曼方程。整讲的两条主干都从这一个方程分岔：**值方法**（Q-learning → DQN）先把方程右边的未知量学出来，再由 $\arg\max$ 隐式地得到策略；**策略方法**（策略梯度 → Actor–Critic → PPO）则跳过值函数这一层中间商，直接对策略求梯度，把「回报」当成加权系数去调整动作概率。

第三条线是本讲真正的现代意义所在：**当奖励写不出来时怎么办**。对「什么样的回答更好」这种任务，没人能写出精确的数值奖励函数，但人可以**比较**两个回答哪个更好。把偏好变成奖励、再用 RL 优化策略，就是 **RLHF**（Reinforcement Learning from Human Feedback）；而 **DPO**（Direct Preference Optimization）进一步证明：那一步「先训奖励模型、再跑 RL」可以被数学上等价地折叠成一个**分类式损失**，直接作用在偏好对上。今天几乎所有大模型的对齐配方——RLHF、DPO/IPO/KTO/ORPO/SimPO、推理模型里的 GRPO 与可验证奖励——都是这一讲内容的不同化身。读完本讲，你会明白为什么 RL 是「没有标签时怎么学」的答案，也会明白为什么它比监督学习难得多、贵得多、也更容易被自己的目标函数欺骗。

## 七节一览

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[5.1 为什么需要强化学习](sec51.md)** | 没有标签时，「学习」还剩下什么？ | RL = 交互循环 + 标量奖励 + 最大化折扣回报；独有的两个难题是延迟信用分配与探索—利用张力；有标签就用监督，只有奖励才用 RL | 把「有奖励」当成「有标签」；拿 RL 硬套其实可以监督求解的问题 |
| **[5.2 马尔可夫决策过程与值函数](sec52.md)** | 怎样把试错写成可推导的数学？ | MDP 五元组 + 马尔可夫性使 $(s_t,a_t)$ 成为未来的充分统计量；$V^\pi,Q^\pi$ 满足贝尔曼期望方程；最优方程把期望换成 $\max$，是唯一的非线性不动点 | 以为 $\gamma=1$ 无害（无限时域下回报发散、值函数无定义）；把 $V$ 与 $Q$ 混用（只有 $Q$ 能直接拿来选动作） |
| **[5.3 值方法：Q-learning 与 DQN](sec53.md)** | 不知道 $P,R$ 时怎么估价值？ | TD 学习用「走一步的实际结果」修正估计；Q-learning 是 off-policy 自举，表格下满足充分访问 + Robbins–Monro 条件即收敛；DQN 用**经验回放**打破相关、用**目标网络**钉住移动靶 | 每步都同步目标网络（等于永远追移动靶）；忘记 `done` 掩码，把终止状态的自举算进去 |
| **[5.4 策略梯度与 REINFORCE](sec54.md)** | 能不能不学 $Q$，直接优化策略？ | 策略梯度定理：$\nabla_\theta J=\mathbb E[\nabla_\theta\log\pi_\theta\,Q^\pi]$；用 $G_t$ 替代 $Q^\pi$ 得无偏但高方差的 REINFORCE；减去只依赖状态的基线不改变期望却能大幅降方差 | 把策略梯度当成监督学习的「加权最大似然」却忘了样本来自当前策略（on-policy）；用旧策略数据不做重要性修正 |
| **[5.5 Actor–Critic 与 PPO](sec55.md)** | 怎样既降方差又不引入大偏差？ | Actor 学策略、Critic 学值；优势 $A=Q-V$ 是「比平均好多少」；GAE 用 $\gamma\lambda$ 把单步 TD 与蒙特卡洛连成一条连续的旋钮；PPO 的裁剪目标在 $\rho$ 越界后**梯度归零**，用一阶实现替代了 TRPO 的二阶 KL 约束 | 以为裁剪对所有越界情形都生效（只在 $A\gt0$ 且 $\rho\gt1+\varepsilon$、或 $A\lt0$ 且 $\rho\lt1-\varepsilon$ 时归零）；把 PPO 当成纯 on-policy 而重复使用同一批数据太多轮 |
| **[5.6 离线 RL、RLHF 与偏好优化](sec56.md)** | 不能交互、甚至写不出奖励时怎么办？ | 离线 RL 的核心矛盾是分布偏移导致的外推过高估计（CQL / IQL 用保守估计或避免查询数据外动作）；RLHF 三步 = SFT → Bradley–Terry 奖励模型 → RL + KL 约束；DPO 用「KL 正则目标的闭式最优解」把奖励反解出来，于是偏好对齐退化成一个分类损失；GRPO 用组内相对优势替掉 Critic | 只看代理奖励上涨就宣布对齐成功（reward hacking / Goodhart）；把 DPO 当「更小的 RLHF」而忽略它对偏好数据偏差毫无缓冲 |
| **[5.7 训练循环示例与调试](sec57.md)** | 把上面所有零件装起来，怎么判断它真的在学？ | 一个最小环境 + 两个训练循环（DQN / PPO）逐行讲解；四类高频失败模式（奖励设计、探索不足、目标更新过快、方差爆炸）各有可测量的诊断信号；评估必须多种子、多回合、看回报分布而不是单条曲线 | 报告单一种子的最优曲线；评估时仍在用 $\varepsilon$-greedy 采样而不说明；把「回报没涨」直接归因于算法而跳过奖励与尺度检查 |

## 10 分钟复习版 · 必记结论

::: method[core] 10 分钟复习版 · 第 5 讲

**一句话**：强化学习把「有标签的监督」换成「**与环境交互、从奖励信号里试错**」；它的两条主干是**学价值再取贪心动作**（Q-learning / DQN）与**直接对策略求梯度**（策略梯度 / Actor–Critic / PPO），稳定化的关键分别是**经验回放 + 目标网络**与**基线降方差 + 裁剪限幅**。

| 内容 | 要点 |
|:--|:--|
| **交互循环** | 观察 $s$ → 动作 $a$ → 奖励 $r$ 与新状态 $s'$；**没有标签，只有奖励** |
| **MDP** | 五元组 $(\mathcal S,\mathcal A,P,R,\gamma)$；**马尔可夫性**：未来只依赖当前 $(s,a)$ |
| **策略** | $\pi(a\mid s)$：状态到动作分布的映射，就是要学的东西 |
| **回报** | $G_t=\sum_{k\ge0}\gamma^{k}r_{t+k+1}$；$\gamma$ 控制视野，有效期约 $\frac{1}{1-\gamma}$ |
| **值函数** | $V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]$，$Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a]$ |
| **两者关系** | $V^\pi(s)=\sum_a\pi(a\mid s)\,Q^\pi(s,a)$ |
| **贝尔曼（期望）** | $V^\pi(s)=\sum_a\pi(a\mid s)\bigl[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')\bigr]$ |
| **贝尔曼（最优）** | 把 $\sum_a\pi(a\mid s)$ 换成 $\max_a$，即得 $V^\ast$、$Q^\ast$ |
| **Q-learning** | $Q\leftarrow Q+\alpha\bigl[r+\gamma\max_{a'}Q(s',a')-Q\bigr]$；off-policy、自举 |
| **DQN** | 用 $Q_\theta$ 逼近；**经验回放**打散样本相关、**目标网络**冻结目标；$\varepsilon$-greedy 探索 |
| **Double DQN** | 选动作与评估动作分开，缓解 $\max$ 带来的**过高估计** |
| **策略梯度** | $\nabla_\theta J=\mathbb E\bigl[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,Q^\pi(s_t,a_t)\bigr]$：好动作抬概率、坏动作压概率 |
| **REINFORCE** | 用 $G_t$ 代替 $Q^\pi$，无偏但**高方差** |
| **基线 / 优势** | 减去 $b(s)$ 不改变期望；优势 $A=Q-V$ 是最常用形式 |
| **Actor–Critic** | Actor 学 $\pi_\theta$，Critic 学 $V_\phi$，用 Critic 估计优势 → 低方差 |
| **PPO** | 裁剪目标 $\min\bigl(\rho\hat A,\ \mathrm{clip}(\rho,1-\varepsilon,1+\varepsilon)\hat A\bigr)$，$\varepsilon$ 常取 0.1–0.2；限制单批更新幅度，稳定通用 |
| **离线 RL** | 只有固定数据集、不能交互；难点是分布偏移导致的过高估计 |
| **RLHF / DPO** | 偏好数据 → 奖励模型 → RL + KL 约束；DPO 用闭式最优解把奖励反解掉，直接做偏好分类 |

**最该记住的四个判断**：① 有标签用监督，**只有奖励用 RL**；② 动作离散、能查表估价值 → **值方法（DQN）**，动作连续或需要随机策略 → **策略方法（PPO）**；③ 训练不稳先查两件事——**目标稳不稳**（目标网络）、**样本相关不相关**（回放）；④ **奖励是你写的、不是你要的**，上线前盯实际行为，防奖励黑客。
