## 节一览

| 节 | 核心问题 | 关键结论 | 典型陷阱 |
|:--|:--|:--|:--|
| **[5.1 为什么需要强化学习](sec51.md)** | 没有标签时，「学习」还剩下什么？ | 三分法的分界线是**信号粒度**（轨迹级 vs 逐样本）与**数据所有权**（分布由策略决定）；三个独有困难＝信用分配、非平稳、探索—利用；常数 $\varepsilon$ 的探索税 $\Delta=\varepsilon(\mu^\ast-\bar\mu)$ 可精算 | 把「有奖励」当「有标签」；拿 RL 硬套本可监督求解的问题；把 $\varepsilon$ 当无关紧要的超参数 |
| **[5.2 MDP 与值函数](sec52.md)** | 怎样把试错写成可推导的数学？ | 五元组 $(\mathcal S,\mathcal A,P,R,\gamma)$ + 马尔可夫性使 $(s_t,a_t)$ 成为未来的**充分统计量**；期望方程是**线性**方程组、最优方程是**非线性**不动点（$\mathcal T$ 为 $\gamma$-压缩 ⇒ 唯一解）；值迭代轮数 $O(\log(1/\varepsilon)/\log(1/\gamma))$ | 以为 $\gamma=1$ 无害；把 $V$ 与 $Q$ 混用（只有 $Q$ 能直接选动作）；把「策略迭代 vs 值迭代」当成两个不同答案 |
| **[5.3 值方法：Q-learning 与 DQN](sec53.md)** | 不知道 $P,R$ 时怎么估价值？ | TD 用「走一步的实际结果」修正估计（自举 + 在线 + 低方差）；Q-learning 是 off-policy 自举，表格下需**充分访问 + Robbins–Monro**；DQN 的两个技巧分别治「样本相关」与「目标在动」；$\max$ 的过高估计量级 $\sigma\sqrt{2\ln N}$（$N=10,\sigma=1$ 时 **2.15**） | 每步都同步目标网络；忘掉 `done` 掩码；把 Q 值膨胀当「学得好」 |
| **[5.4 策略梯度与 REINFORCE](sec54.md)** | 能不能不学 $Q$，直接优化策略？ | 对数导数技巧把「对分布的导数」变成可采样期望，且**环境动力学从梯度里消失**；定理一句话即「**好动作抬概率、坏动作压概率**」；因果性（用 $G_t$）与**任意只依赖状态的基线**都不改变期望、只降方差 | 忘了数据必须来自当前策略（on-policy）；以为基线是启发式会引入偏差；把奖励乘以大常数以为能学更快 |
| **[5.5 Actor–Critic 与 PPO](sec55.md)** | 怎样既降方差又不引入大偏差？ | 优势 $A=Q-V$ 是 Actor 与 Critic 的接口；GAE 用 $(\gamma\lambda)^l$ 把单步 TD 与蒙特卡洛连成**一根旋钮**；PPO 裁剪目标越界时**只有两个象限梯度归零**、另两个象限仍「拉回区间」；$\varepsilon$ 常取 0.1–0.2 | 以为裁剪对所有越界情形都生效；把 $\rho$ 的裁剪当成对概率的硬截断；把 PPO 当纯 on-policy 而重复用同一批数据过多轮 |
| **[5.6 离线 RL、RLHF 与偏好优化](sec56.md)** | 不能交互、甚至写不出奖励时怎么办？ | 离线 RL 的敌人是分布偏移：单步误差被 $1/(1-\gamma)$ 放大（$\gamma=0.99$ ⇒ **100 倍**），CQL 压低数据外 $Q$、IQL 干脆不查询；RLHF 三步＝SFT → Bradley–Terry 奖励模型 → RL + KL；**DPO 用闭式最优解把奖励反解掉**，$Z(x)$ 在差值中精确抵消，对齐退化成分类损失；GRPO 用组内相对优势替掉 Critic | 只看代理奖励上涨就宣布对齐成功；把 DPO 当「更小的 RLHF」而忽略它对标注噪声无缓冲；以为离线 RL 的失败是数据量问题 |
| **[5.7 训练循环示例与调试](sec57.md)** | 把零件装起来，怎么判断它真的在学？ | DQN 循环 ＝ 回放池 + 目标网络 + `done` 掩码 + $\varepsilon$ 衰减；PPO 循环 ＝ rollout → GAE → 优势归一化 → 多 epoch 裁剪更新 → 诊断量；四类失败模式（奖励设计、探索不足、目标更新过快、方差爆炸）**都不报错**；评估必须**多种子 + 多回合 + 报分布** | 报告单一种子的最优曲线；把训练指标当验收指标；回报没涨就先调学习率（顺序应是先奖励、再评估协议、再探索） |

> **一条主线**：因为很多决策问题**没有标签、只有标量奖励**（[5.1](sec51.md)），所以要把交互形式化成 MDP，用折扣回报让「值」满足一个自洽的递归方程（[5.2](sec52.md)）；因为真实环境里 $P$ 与 $R$ 拿不到，所以只能**采样**——学 $Q$ 再取贪心（[5.3](sec53.md) 的值方法），或者**直接对策略求梯度**（[5.4](sec54.md) 的策略方法）；因为前者的高方差与后者的高偏差都不能单独忍受，所以把基线升级成 Critic、用 GAE 把偏差—方差做成旋钮、再用 PPO 裁剪替你限幅（[5.5](sec55.md)）；而这些机器最终服务于两个更现实的约束——**不能交互**（离线 RL 的外推误差）与**写不出奖励**（RLHF / DPO / GRPO 把人类偏好或可验证信号变成学习信号，[5.6](sec56.md)）；最后，因为 RL 的失败**看起来像成功**，所以必须把训练接对并建立多种子评估协议，才谈得上「它真的在学」（[5.7](sec57.md)）。

## 三句话带走

1. **RL 把「有标签的监督」换成「与环境交互、从奖励信号里试错」**；它独有的两个难题是**延迟的信用分配**与**探索—利用的张力**，MDP 与贝尔曼方程是描述它们的通用语言——「奖励是你写的，不是你要的」。
2. **两条主干殊途同归**：值方法（Q-learning → DQN）先学 $Q$ 再取贪心动作，靠**经验回放 + 目标网络**稳住训练；策略方法（策略梯度 → Actor–Critic → PPO）直接对 $\pi_\theta$ 求梯度，靠**基线/优势**降方差、靠**裁剪**限制步幅；Actor–Critic 让两者合流，PPO 是今天最通用、最稳的默认算法。
3. **前沿把 RL 推向两个极端**：离线 RL 应对「不能交互，只有固定数据」（误差被 $1/(1-\gamma)$ 放大），RLHF / DPO / GRPO 应对「奖励写不出来，用人类偏好或可验证信号代替」——后者正是大模型对齐的默认手段；而**所有路线的共同瓶颈是数据与评估，不是算法**。
