# 学习目标（K / S / A）

本书的学习目标按 **K（知识）/ S（技能）/ A（判断与素养）** 三类列出，格式为「**编号 · 可观察的行为 · 达标判据 · 认知层级**」。

**怎么用**：把它当成一张**能力对账表**——读完一讲，逐条自问能否做到；做不到的那条，按最后一列回到对应小节或习题。每讲的[自检表](lectures/lec01/checklist.md)把这套目标拆成可打勾的清单。

**约定**：编号形如 `K2.3`（第 2 讲 · 第 3 条知识目标）；认知层级用 Bloom 分类（记忆 / 理解 / 应用 / 分析 / 评价 / 创造）；每条目标都对应至少一种考核方式（概念题 / 推导题 / 编程题 / 实验报告 / 开放设计 / 项目提案）。

## 综合目标（读完本书应能做到）

- **说清一个范式**：拿到任意一个新模型，能把它拆成「结构 + 损失 + 优化」三部分，并指出创新发生在哪一步。
- **算清一次前向与一次显存**：给定输入形状与模型配置，能推演每层形状、参数量与训练显存（这是排错与规划的第一技能）。
- **查清一次不收敛**：拿到训练曲线，能按「数据 → 损失 → 学习率 → 初始化 → 正则 → 数值稳定性」的顺序定位问题，且每步都有可证伪的判据。
- **做一次取舍**：在给定约束（数据量、算力、延迟、合规）下给出方案，并说明**失败判据**与验证计划。
- **写清一份提案**：按官方七要素写出可落地的课程项目提案（见[项目指南](exercises/project.md)），并通过[答辩五问](training/arena.md#arena-defense)。
