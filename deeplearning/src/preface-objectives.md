# 学习目标（K / S / A）

本书的学习目标按 **K（知识）/ S（技能）/ A（态度与判断）** 三类列出，并对到具体讲次与盒子。读者可把它当成一张**能力对账表**：读完一讲，逐条自问能否做到。

## 按讲次的学习目标

| 讲 | K · 你能说清 | S · 你能做到 | A · 你应有的判断 |
|:--|:--|:--|:--|
| [1](../lectures/lec01.md) | 神经元、MLP、激活函数、损失、梯度下降、反向传播、过拟合 | 手写一层前向 + 反向；为给定任务选损失与激活 | 明白「架构没有免费的午餐」，结构要配数据先验 |
| [2](../lectures/lec02.md) | RNN 的隐状态递推与梯度消失、门控、自注意力、Transformer | 推导注意力的形状变化；解释位置编码为何必要 | 警惕「序列越长越该用 RNN」——注意力的取舍在复杂度 |
| [3](../lectures/lec03.md) | 卷积的局部性/权值共享、感受野、池化、残差、检测与分割 | 算一层卷积的输出尺寸与参数量；做迁移学习 | 认识到数据集偏见会被模型放大 |
| [4](../lectures/lec04.md) | 自编码器 / VAE / GAN / 扩散模型的构成与目标函数 | 写 VAE 的 ELBO 与重参数化；写扩散的噪声预测损失 | 分得清「能重建」与「能采样」是两件事 |
| [5](../lectures/lec05.md) | MDP、回报、值函数、策略梯度、Actor–Critic、PPO | 解释 DQN 的经验回放与目标网络；写出策略梯度 | 知道 on-policy / off-policy 与探索-利用的根本张力 |
| [6](../lectures/lec06.md) | 大模型、缩放律、思维链、多模态、具身智能、世界模型 | 说明一个 VLA 系统的数据与训练流程 | 对「涌现能力」的传闻保持审慎 |
| [7](../lectures/lec07.md) | 对齐、可解释、公平、滥用、监管 | 为一个模型列出三类风险与缓解手段 | 把安全当成设计约束，而非事后补丁 |
| [8](../lectures/lec08.md) | AlphaFold 类方法、可微分仿真、AI 辅助科学发现 | 说清「把试错变成可微分推断」的含义 | 区分「拟合数据」与「理解机制」 |
| [9](../lectures/lec09.md) | 数据/张量/流水线并行、混合精度、梯度累积、ZeRO/FSDP | 为受限显存选一套切分与优化策略 | 认识到瓶颈常在通信与内存，而非纯算力 |

## 综合目标（读完本书应能做到）

- **说清一个范式**：拿到任意一个新模型，能把它拆成「结构 + 损失 + 优化」三部分并指出创新点在哪一步。
- **算清一次前向**：给定输入形状，能推演每一层的输出形状与参数量（这是排错的第一技能）。
- **查清一次不收敛**：拿到训练曲线，能按「数据 → 损失 → 学习率 → 初始化 → 正则」的顺序定位问题。
- **写清一份提案**：能按官方七要素写出一份可落地的课程项目提案（见[项目指南](../exercises/project.md)）。
