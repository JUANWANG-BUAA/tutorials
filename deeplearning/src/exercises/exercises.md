# 九讲习题集（附提示）

每题给**提示**而非完整答案——先自己想，再看提示。按讲次分组，难度递进：概念题 → 推导题 → 设计题。

## 第 1 讲 · 基础

**1-1（概念）** 一个两层 MLP 去掉激活函数后等价于什么？为什么？

**1-2（推导）** 设二分类，网络输出单个 logit $z$，用**二元**交叉熵 $\mathcal L=-[y\log\sigma(z)+(1-y)\log(1-\sigma(z))]$。证明 $\dfrac{\partial\mathcal L}{\partial z}=\sigma(z)-y$。

::: sol 提示
把 $\sigma'(z)=\sigma(z)(1-\sigma(z))$ 代入链式法则，合并同类项即可。
:::

**1-3（推导）** 给定批 $\boldsymbol X\in\mathbb R^{B\times D}$、权重 $W\in\mathbb R^{D\times K}$，写出 $\boldsymbol Z=\boldsymbol XW$ 的 $\partial\mathcal L/\partial W$。

::: sol 提示
结果是 $\boldsymbol X^{\mathrm T}\dfrac{\partial\mathcal L}{\partial\boldsymbol Z}$，形状为 $D\times K$。核对形状永远是推导的第一步。
:::

**1-4（设计）** 一个样本量 500、特征 30 维、明显线性可分的任务，你选多复杂的模型？为什么？

::: sol 提示
从**最简**模型（逻辑回归）开始，建立基线；再逐步加复杂度并观察验证集。高方差的风险大于高偏置的风险。
:::

## 第 2 讲 · 序列

**2-1（概念）** RNN 为什么难捕捉长程依赖？注意力如何绕开？

**2-2（推导）** 写出 Scaled Dot-Product Attention 的输出形状：输入 $Q\in\mathbb R^{B\times T_q\times d_k}$、$K\in\mathbb R^{B\times T_k\times d_k}$、$V\in\mathbb R^{B\times T_k\times d_v}$。

::: sol 提示
$QK^{\mathrm T}$ 形状 $B\times T_q\times T_k$；softmax 沿最后一维；乘 $V$ 得 $B\times T_q\times d_v$。
:::

**2-3（思考）** 为什么注意力要除以 $\sqrt{d_k}$？

::: sol 提示
$q\cdot k$ 的方差随 $d_k$ 线性增长，若不平移，softmax 会进入饱和区、梯度趋零。
:::

**2-4（设计）** 一段语音识别任务，序列很长（>1000 帧）。你会直接用全注意力吗？给出一个权衡方案。

::: sol 提示
全注意力复杂度 $O(T^2)$，长序列下不可行。考虑局部/稀疏注意力、下采样、或 CNN 前置降长。
:::

## 第 3 讲 · 视觉

**3-1（计算）** 输入 $224\times224\times3$，一层 $7\times7$ 卷积、64 个输出通道、步幅 2、填充 3。求输出尺寸与本层参数量。

::: sol 提示
输出 $=\lfloor(224-7+6)/2\rfloor+1$；参数量 $=7\times7\times3\times64+64$。
:::

**3-2（概念）** 残差连接为什么能让极深的网络可训练？从梯度角度解释。

::: sol 提示
$\partial\boldsymbol y/\partial\boldsymbol x=I+\partial\mathcal F/\partial\boldsymbol x$，多了个恒等项，梯度可"直通"。
:::

**3-3（概念）** 检测任务为什么不能只看准确率？

**3-4（设计）** 只有 1000 张标注图，要做一个 10 类分类。给出方案。

::: sol 提示
迁移学习：加载 ImageNet 预训练骨干，冻结大部分层，只微调最后几层；配合数据增强。
:::

## 第 4 讲 · 生成

**4-1（推导）** 写出 VAE 的 ELBO，并指出哪一项是重建、哪一项是正则。

**4-2（概念）** 为什么普通自编码器不能直接当生成模型？

::: sol 提示
潜空间没有先验约束，随意采样的 $z$ 可能落在训练没覆盖的区域，解码出无意义结果。
:::

**4-3（推导）** 写出扩散模型的训练损失，并说明网络学的是什么。

::: sol 提示
$\mathcal L=\mathbb E[\lVert\varepsilon-\varepsilon_\theta(\boldsymbol x_t,t)\rVert^2]$；学的是在 $t$ 时刻注入的噪声。
:::

## 第 6–9 讲 · 前沿与规模

**6-1（判断）** "模型变大就一定更强"——你怎么看？

::: sol 提示
缩放律给的是**期望趋势**，但受数据质量、训练策略、评估方式影响；"涌现"的度量方式本身有争议。
:::

**7-1（分析）** 给定一个监控摄像头人脸识别系统，列出三类风险与缓和手段。

**8-1（概念）** "把科学试错变成可微分推断"是什么意思？举一个例子。

**9-1（计算）** 一个 7B 参数的模型用 Adam 混合精度训练，优化器状态约需多少显存？单卡 80GB 放得下吗？

::: sol 提示
用 $16N$ 字节估算：$16\times7\times10^9=112$ GB，已超单卡——所以需要 ZeRO/FSDP 分片。
:::

**9-2（设计）** 你有 8 张 40GB 卡，要训一个单卡放不下的模型。给出并行策略。

::: sol 提示
先用数据并行扩批；单层太大加张量并行；层数太多加流水线并行；三者可组合（3D 并行）。
:::
