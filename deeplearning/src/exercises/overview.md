# 练习与项目总览

这一页回答一个问题：**「我该做哪些题、按什么顺序做、做到什么程度算过关」**。九讲的练习入口、四个 Lab、期末项目与自测卷都从这里出发。

## 一、练习在哪里

| 类型 | 位置 | 题量 | 形态 |
|:--|:--|:--|:--|
| **每讲习题集** | 各讲 `exercises.md`（如 [1. 习题集](../lectures/lec01/exercises.md)） | 每讲 24 题 | A 概念 → B 推导 → C 编程 → D 开放，**答案全部折叠** |
| **每讲自测卷** | 各讲 `mock-exam.md` | 每讲 20 题 / 100 分 | 闭卷计时，含评分标准与漏点定位 |
| **回忆卡** | 各讲 `recall-cards.md` | 每讲 33–45 张 | 遮住答案自测，可导出 Anki |
| **四个 Lab** | [Lab 1](../labs/lab1.md) · [Lab 2](../labs/lab2.md) · [Lab 3](../labs/lab3.md) | 3 个 | 端到端跑通，给验收标准 |
| **综合自测卷** | [考场冲刺 · 综合自测卷](../training/exam-sprint.md) | 20 题 / 100 分 | 跨九讲，闭卷 90 分钟 |
| **限时口述** | [必考点竞技场](../training/arena.md) | 约 30 条 | 快问快答 + 推导现场 + 工程判断 |
| **期末项目** | [期末项目提案指南](project.md) | 1 个 | 八周排期模板 + 评估设计模板 |

## 二、四组习题的定位（A / B / C / D）

| 组 | 考什么 | 建议用时 | 过关判据 |
|:--|:--|:--|:--|
| **A · 概念判断** | 是否真懂定义与边界 | 3–5 分钟/题 | 能说出「为什么错」，而不是只判对错 |
| **B · 推导证明** | 能不能自己推出来 | 15–25 分钟/题 | 盖上答案能从空白纸写出关键步骤 |
| **C · 编程实现** | 会不会落到代码 | 30–60 分钟/题 | **达到该题给出的验收标准**（形状断言 / 误差阈值 / 单调性） |
| **D · 开放设计** | 能不能做工程决策 | 30–45 分钟/题 | 交出「方案 + 理由 + 失败判据 + 验证计划」四件 |

::: note 关于答案
C 组与 D 组给的是**参考实现与评分要点**，不是唯一解。做不出来先看提示，再看答案，最后**合上答案重做一遍**——这一步不能省。
:::

## 三、三种使用节奏

### 1. 跟课节奏（每讲一次）
读完一讲的节页 → 做该讲的 [checklist](../lectures/lec01/checklist.md) 自检 → 做习题集 A、B 组 → 上机做 C 组 → 周末做该讲的 [mock-exam](../lectures/lec01/mock-exam.md) 并评分。

### 2. 复习节奏（考前一周）
先做 [考场冲刺卷](../training/exam-sprint.md) 找漏点 → 按漏点定位表回读对应节 → 用[回忆卡](../review/formula-cards.md)与[易混对照卡](../review/contrast-cards.md)做检索练习 → 再做一遍冲刺卷。

### 3. 项目节奏（第 5 讲之后）
选题（见 [附录 A · 选题路线](../appendix/roadmap.md)）→ 按 [项目提案指南](project.md) 的八周排期推进 → 每周用 Lab 的验收标准自检 → 结题按「评估设计模板」交出对照组与消融。

## 四、做不出来时怎么办

| 症状 | 先做什么 | 再做什么 |
|:--|:--|:--|
| 概念题拿不准 | 回该节找 `def` 定义框 | 看该讲的[易混对照卡](../review/contrast-cards.md) |
| 推导卡住 | 看答案的**第一步**就停 | 自己往下推，卡住再看下一步 |
| 代码跑不通 | 用该讲的形状推演表核对张量 | 看[工程工具箱](../toolbox.md)的不收敛排查树 |
| 结果是数字不对 | 换成手算的小规模例子复现 | 对照[附录 C 的推导](../appendix/derivations.md) |
| 完全没思路 | 先做 A 组把概念补齐 | 该讲的[节页导览](../lectures/lec01/overview.md)重读一遍 |

## 五、自检：练习是否到位

- [ ] 每讲的 A、B 组能在**不看答案**的情况下做完
- [ ] C 组每题都**跑通并通过验收标准**（不是「看起来对」）
- [ ] D 组至少认真写过 3 题的四件套
- [ ] 至少做完两个 Lab，且能解释每个超参为什么这么取
- [ ] 综合自测卷得分 ≥ 80，且漏点定位表里的项都补过
- [ ] 有一个能讲 15 分钟的期末项目（含基线对照与消融）

六条里达到 4 条，本课程的「练」这一环就算闭环。
