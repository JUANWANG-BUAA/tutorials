# 入学诊断自测

用 15 分钟做这张卷子，**目的是决定你从哪里开始**：是直接通读，还是先补数学、先补编程，或直接跳到你真正关心的那一讲。

**做法**：闭卷、不看资料、每题 30–60 秒；不会的题**直接跳过**（跳过比猜更有信息量）。

## 一、数学与张量（5 题）

**M1.** 设 $A\in\mathbb R^{3\times4}$、$B\in\mathbb R^{4\times2}$，$AB$ 的形状是？$A^{\mathrm T}B$ 呢？

**M2.** 写出链式法则：若 $y=f(u)$、$u=g(x)$，则 $\dfrac{dy}{dx}=$？

**M3.** 一个标量函数 $f(\boldsymbol x)$ 在 $\boldsymbol x_0$ 处的梯度 $\nabla f(\boldsymbol x_0)$ 的**几何含义**是什么？

**M4.** 设随机变量 $X$ 取 0 与 1 的概率各为 $1/2$，$\mathbb E[X]$ 与 $\mathrm{Var}(X)$ 分别是多少？

**M5.** 张量形状 $32\times784$ 与矩阵 $784\times128$ 做矩阵乘，结果是？这一运算里「32」代表什么？

## 二、编程与工程直觉（3 题）

**P1.** 在 PyTorch 里，一行代码完成「把 `x` 从 CPU 搬到 GPU 并把 dtype 变成 bfloat16」：`x = ______`。

**P2.** 训练脚本出现报错 `Expected all tensors to be on the same device`，你的第一反应是查什么？

**P3.** 你有一个训练损失曲线：训练损失持续下降、验证损失第 5 轮后开始上升。用一句话说出最可能的现象和一个对策。

## 三、深度学习概念（7 题）

**D1.** 一个十层网络如果把所有激活函数都去掉，它等价于什么？

**D2.** 交叉熵和均方误差各自适合什么任务？为什么分类一般不直接用 MSE？

**D3.** 反向传播为什么比「逐参数数值求导」快得多？

**D4.** 卷积层比全连接层省参数的根本原因是什么（两条）？

**D5.** 自注意力里为什么要除以 $\sqrt{d_k}$？

**D6.** VAE 的损失里为什么要有一项 KL 散度？去掉它会怎样？

**D7.** 「显存 16N 字节」这条经验公式里的 $N$ 是什么？它适用于什么配置？

---

## 答案与解析

::: sol 第一部分 · 数学与张量
**M1.** $AB\in\mathbb R^{3\times2}$；$A^{\mathrm T}\in\mathbb R^{4\times3}$，故 $A^{\mathrm T}B$ **不可乘**（$3\ne4$）。→ 形状规则是本书的第一基本功。

**M2.** $\dfrac{dy}{dx}=\dfrac{dy}{du}\cdot\dfrac{du}{dx}$。→ 反向传播就是它在计算图上的系统化应用（[1.5](lectures/lec01/sec15.md)）。

**M3.** 梯度指向 $f$ **增长最快**的方向，其模长是该方向的方向导数。→ 所以梯度下降走负梯度方向（[1.5](lectures/lec01/sec15.md)）。

**M4.** $\mathbb E[X]=1/2$；$\mathrm{Var}(X)=\mathbb E[X^2]-(\mathbb E[X])^2=1/2-1/4=1/4$。→ 方差与期望是理解批大小、梯度噪声的基础。

**M5.** 结果是 $32\times128$；「32」是**批大小**（batch size），本书约定批维恒定在第 0 位（[1.1](lectures/lec01/sec11.md#method-1.1.1)）。
:::

::: sol 第二部分 · 编程与工程直觉
**P1.** `x = x.to("cuda", dtype=torch.bfloat16)`（或 `x.to(device=..., dtype=...)`）。

**P2.** 先查「模型参数/缓冲区与输入是否在同一设备」，以及是否有**手写的常量张量**没跟着搬（例如 mask、位置索引）。→ [工具箱](toolbox.md)第一节。

**P3.** 最可能是**过拟合**；一个对策是加正则（Dropout / 权重衰减）或早停。→ 但先别急着下结论，完整诊断顺序见[工具箱](toolbox.md#flow-debug)与[1.7](lectures/lec01/sec17.md)。
:::

::: sol 第三部分 · 深度学习概念
**D1.** 等价于**一个线性变换**（多层矩阵相乘仍是一个矩阵）。→ 非线性才是深度的意义（[1.2](lectures/lec01/sec12.md)）。

**D2.** 交叉熵配 softmax 用于分类，MSE 用于回归。分类不用 MSE 的原因：MSE + softmax 的梯度含 $\hat y(1-\hat y)$ 因子，**预测饱和时梯度消失**，学习变慢。→ [1.4](lectures/lec01/sec14.md)。

**D3.** 反向传播复用中间结果：一次前向 + 一次反向即可得到**全部**参数的梯度（代价与参数量成线性）；数值求导每个参数都要独立扰动一次前向。→ [1.5](lectures/lec01/sec15.md)。

**D4.** ① **局部连接**（每个输出只连感受野内的输入）；② **权值共享**（同一个核在空间所有位置复用）。→ 因此参数量与输入分辨率无关（[3.1](lectures/lec03/sec31.md)）。

**D5.** 点积的方差随 $d_k$ 线性增长，不缩放会让 softmax 进入饱和区、梯度趋零。→ 严格论证见[附录 C.3](appendix/derivations.md)。

**D6.** KL 项把近似后验拉向先验，使潜空间**可采样**；去掉它（或权重过小）退化成普通自编码器，任采样的 $z$ 会落在训练未覆盖区域、解码出无意义结果；权重过大则**后验坍塌**。→ [4.3](lectures/lec04/sec43.md)。

**D7.** $N$ 是**参数量**；该口径对应「混合精度训练 + Adam 系优化器 + 保留 fp32 主权重」（参数 $2N$ + 梯度 $2N$ + 优化器状态 $8N$ + 主权重 $4N$ = $16N$ 字节）。换 8-bit 优化器约降到 $10N$。→ [9.1](lectures/lec09/sec91.md)、[工具箱](toolbox.md)。
:::
