# 范围声明与使用方法

## 内容来源与边界

本教程**覆盖 MIT 6.S191 的九讲主题与三个实验**，整理方式遵循四条纪律：

- **以公开课程内容为骨架**：九讲的顺序、覆盖范围、核心结论与课程一致；三个 Lab 的题目与课程一致（音乐生成、人脸检测、大语言模型微调）。
- **在不越出课程范围的前提下做三类工作**：(1) 补齐讲义省略的推导与中间步骤；(2) 为每个概念补一句白话直觉；(3) 把散落在多页的名词整理成前后衔接的叙述线。
- **明确标注「拓展」**：2023 年之后才成为默认实践的内容（状态空间模型、MoE、流匹配、测试时计算、VLA、机制可解释性、FP8/FSDP2 等）一律标为「拓展」或「前沿」，并给出可核查来源。
- **不编造**：不虚构论文编号、实验数据与库函数签名。凡涉及具体数值（注意力复杂度、参数量、显存账）均给出**可复算的依据**；无法核实处标「需核实」。

> **时效说明**：母本课程更新极快，讲义与录播之间存在版本差异。本教程以「**概念不随时间失效**」为取舍标准：会随版本变化的细节（具体榜单分数、模型版本号、库 API 形状）尽量给**口径与判据**而不是给数字；必须给数字时注明时点。

> **与课程的关系**：本教程是**学习辅助**，不是课程的替代。课程官网、讲义 PDF、实验 Notebook 与录播视频是权威源；本教程补充推导并整理它们之间的联系。原文术语一律保留英文对照（见[符号与缩略语表](preface-notation.md)与[术语索引](review/glossary.md)）。

## 三层阅读结构

全书内容按性质分层，读者可跳读（盒子类型见[范围与目标](preface.md)）：

- **必读层**：定义、定理、每讲页首的「10 分钟复习版」、每节的「陷阱清单」；
- **主体层**：动机叙述、例题、方法步骤、直觉解释、代码；
- **可跳层**：证明与推导框、拓展与前沿展望——第一遍可以跳过，第二遍再回来逐行读。

## 怎么用这本书

1. **预习**：读某讲页首的「10 分钟复习版」；缺什么先用[先修工具箱](prerequisite.md)补什么。
2. **精读**：顺着节页走，遇到折叠的「推导」先跳过，遇到「直觉」一定要读。
3. **动手**：读完对应讲次后做配套 Lab；Lab 里的「排错清单」列出训练不收敛时最可能的五个原因。
4. **复习**：只看[公式速查卡](review/formula-cards.md)、[速查背记卡](memory-sheet.md)与每讲的「必记结论」表；考前按[最小必读路径](review/study-paths.md)走一遍。
5. **自检**：做每讲的[自检表](lectures/lec01/checklist.md)与[综合自测卷](training/exam-sprint.md)，把「以为会」的地方暴露出来。
6. **产出**：课程唯一计分产出是**项目提案**，写作方法见[项目提案指南](exercises/project.md)；答辩训练见[竞技场](training/arena.md)。

### 链接与阅读辅助

正文中的书内链接可以直接打开。用鼠标悬停或键盘聚焦部分链接时，会显示目标页面的原文摘录；按 `Esc` 关闭预览，点击链接仍会跳转。触屏上直接点链接即可。

在同一标签页普通点击正文中的书内页面或页内锚点，或从术语卡片打开定义后，目标页面会出现「返回阅读位置」，可回到跳转前的位置；连续跳转也可以逐次返回。该功能只在当前标签页的会话存储可用时生效，不记录带检索参数的地址或新标签页操作；浏览器原有的前进、后退仍可使用。

部分术语带有虚线：悬停、键盘聚焦或触屏点击可查看释义，再用卡片里的「看定义」打开正文。术语数据在完整构建时生成；仅运行 `mdbook serve` 的预览不包含这项功能，不影响正文阅读。

## 记号约定

- 向量用粗体小写 $\boldsymbol{x}$，矩阵用大写 $A$，标量用斜体 $x$；张量沿用框架习惯（如 $B\times T\times C$ 表示批 × 序列长 × 通道数）。
- 损失一律记 $\mathcal L$，参数记 $\theta$，学习率记 $\eta$，梯度记 $\nabla_\theta\mathcal L$。
- 第 $l$ 层的权记 $W^{(l)}$、偏置记 $\boldsymbol b^{(l)}$、激活记 $\boldsymbol h^{(l)}$ 或 $\boldsymbol a^{(l)}$。
- 上下标遵循「先层后元素」：$W^{(l)}_{ij}$ 表示第 $l$ 层权矩阵的第 $(i,j)$ 元。
- **形状记号**：$\boldsymbol X\in\mathbb R^{B\times n}$ 表示「批优先」的张量；批维统一写在第 0 位，且在前向过程中保持不变。
- **复杂度记号**：$T$ 为序列长度、$L$ 为层数、$d$ 为模型维度（$d_{\text{model}}$）、$d_k$ 为单头键维度（$d/h$）、$N$ 为参数量、$B$ 为批大小。
- **显存记账**：一律以字节为单位写清口径（例如「混合精度 + Adam 系」的静态开销 $\approx16N$ 字节）。

## 勘误反馈：页面入口与提交材料

发现公式、代码、链接或课程对应关系有疑问时，可先查该讲的“勘误与补注”，例如[第 1 讲勘误页](lectures/lec01/errata.md)。已有记录也可能仍待核实；反馈时请区分“可复现的错误”和“需要进一步核对的疑问”。

本书 `book.toml` 配置的仓库是 `JUANWANG-BUAA/tutorials`，教材位于其中的 `deeplearning/` 目录。可用以下两条路径反馈：

- **提交 issue**：登录 GitHub 后打开[新建勘误 issue](https://github.com/JUANWANG-BUAA/tutorials/issues/new)，在标题中注明“deeplearning + 讲次/页面 + 问题摘要”；提交前可在[现有 issues](https://github.com/JUANWANG-BUAA/tutorials/issues)中查找相同问题。
- **提交具体修改**：使用页面右上角“编辑此页”，进入对应源文件的 GitHub 编辑页。以本页为例，入口为[编辑范围说明](https://github.com/JUANWANG-BUAA/tutorials/edit/main/deeplearning/src/preface-scope.md)。没有直接写入权限时，可按 GitHub 的界面提示通过 fork/分支提出 pull request；这不是直接修改已发布页面。

为让其他读者能定位和复算，请在 issue 或 pull request 中提供：

1. **页面**：浏览器地址及源文件路径，例如 `deeplearning/src/lectures/lec01/sec14.md`。
2. **位置**：小节号、例题/定理编号或标题，附原句、公式或代码片段；有锚点时给出带锚点的页面链接。
3. **复现或推导**：说明预期结果与实际结果。公式问题写出假设和中间步骤；代码问题给出最小输入、运行命令、完整错误信息或实际输出；来源问题给出原文链接及页码/版本。不要只写“答案不对”。
4. **版本**：本地阅读请给出所用 commit SHA；在线阅读请给出访问日期、页面地址，以及能确认的源码 commit。若无法确认发布页对应的提交，请明确写“发布版本未知”，不要猜。代码问题另列 Python、框架、相关依赖版本及硬件/精度等影响复现的条件。

例如，反馈一条交叉熵计算疑问时，应同时贴出 logits、标签、是否先做 softmax、损失的 reduction 设置及逐步计算，而不只给最终小数。公开提交前请移除访问令牌、个人信息和未获授权的数据。

以上是读者主动提交反馈的入口，不表示页面会自动收集阅读记录，也不承诺有人受理或在特定时间完成修订。是否提交成功，以 GitHub 返回的 issue 或 pull request 页面为准。
