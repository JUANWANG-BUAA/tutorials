# 先修工具箱：数学、张量与自动微分

这一页只讲**读本书真要用到**的最小先修，不展开完整课程。每条给「要什么、为什么、一句话怎么用」。

## 1. 线性代数：够用就好

| 概念 | 你需要会 | 在书里用在哪 |
|:--|:--|:--|
| 矩阵乘法 | 形状匹配规则：$(m\times k)(k\times n)=m\times n$ | 每一层前向 |
| 转置 | $(AB)^{\mathrm T}=B^{\mathrm T}A^{\mathrm T}$ | 反向传播 |
| 内积与范数 | $\boldsymbol x^{\mathrm T}\boldsymbol y$、$\lVert\boldsymbol x\rVert_2$ | 注意力、损失、归一化 |
| 特征值（了解） | $Av=\lambda v$ 的含义 | 谱理论、PCA 直觉 |
| 奇异值（了解） | $A=U\Sigma V^{\mathrm T}$ 的几何意义 | 低秩、LoRA |

::: intuition 形状是你的安全带
深度学习里 90% 的报错是**形状不匹配**。养成习惯：写每一层前先在心里写出输入输出的形状；报错时先打印 `x.shape`，而不是盯着数值。本书每讲都会显式推演形状（见[例 1.2](../lectures/lec01.md)）。
:::

## 2. 微积分：链式法则是全部

- **偏导** $\partial f/\partial x_i$：固定其他变量，对 $x_i$ 求导。
- **梯度** $\nabla_{\boldsymbol x}f$：把偏导堆成向量，指向上升最快的方向。
- **链式法则**：$\dfrac{d}{dx}f(g(x))=f'(g(x))\,g'(x)$——**反向传播就是它的批量实现**（[第 1 讲](../lectures/lec01.md)）。
- **Jacobian（了解）**：向量对向量的导数，形状是矩阵；梯度反传做的是「Jacobian 转置 × 上游梯度」。

::: note "逐元素"相乘为什么到处都是
激活函数（ReLU、Sigmoid）是**逐元素**作用的，所以它的导数也逐元素地乘在误差信号上：$\boldsymbol\delta\odot\phi'(\boldsymbol z)$。那个 $\odot$（Hadamard 积）就是「同一位置的数相乘」。
:::

## 3. 概率：期望、似然、高斯

| 概念 | 一句话 |
|:--|:--|
| 期望 $\mathbb E[X]$ | 随机变量的平均取值；损失常写成期望（在数据分布上平均） |
| 极大似然 | 选让观测数据概率最大的参数；交叉熵与 MSE 都可由它导出 |
| 高斯 $\mathcal N(\mu,\sigma^2)$ | 钟形分布；VAE 的先验与后验、扩散的噪声都用它 |
| KL 散度（了解） | 两个分布"有多不像"，非负；VAE 的正则项 |

::: intuition 为什么损失总写成期望
训练是在**有限数据**上最小化**期望损失**的经验近似——小批量梯度是真实梯度（整个数据分布上的期望）的**无偏估计**。这就是为什么小批量能代替全批（[第 1 讲 1.5](../lectures/lec01.md)）。
:::

## 4. 张量与形状约定

本书与主流框架一致，采用**批优先**（PyTorch 风格）：

| 数据 | 形状 | 例 |
|:--|:--|:--|
| 全连接输入 | $(B, D)$ | $32\times784$ |
| 序列 | $(B, T, D)$ | 32 句话、每句 20 词、每词 128 维 |
| 图像（NCHW） | $(B, C, H, W)$ | 32 张 3 通道 $32\times32$ |
| 注意力打分 | $(B, H, T, T)$ | $H$ 为头数 |

::: think 维度顺序没有"正确"答案，只有"一致"
框架间 NCHW 与 NHWC 之争只是约定。真正的纪律是：**同一本书、同一个项目里保持一致**，并在每个张量传过边界（进模型、进损失）时都确认一次形状。
:::

## 5. 自动微分：为什么不用手写反向传播

现代框架用**计算图 + 反向模式自动微分**：前向时记录运算图，反向时按链式法则从输出往回走，自动算出每个参数的梯度。

```python
import torch
x = torch.tensor([1.0, 2.0], requires_grad=True)
y = (x ** 2).sum()          # 前向：y = x1² + x2²
y.backward()                # 反向：自动求 dy/dx
print(x.grad)               # tensor([2., 4.]) → 即 2x
```

::: intuition 自动微分 = 反向传播的自动化
手推反向传播（[定理 1.2](../lectures/lec01.md)）让你**理解**它在做什么；自动微分让你**不必手推**。二者不矛盾：读懂推导是为了在梯度异常（NaN、消失、爆炸）时知道从哪儿查，日常训练交给框架。
:::
