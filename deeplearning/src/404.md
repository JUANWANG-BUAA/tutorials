## 如果你是从书内链接跳过来的

这说明教程内部有一处断链。四本教程共用一套链接纪律：正文链接一律写成**相对路径 + 锚点**（如 `../lec02/sec24.md#sec-2.4.3`）。
本页出现，说明这条路径没被覆盖（例如外部站点、旧版地址，或某次重构后的遗留链接）。**把来源页面的地址记下来**即可。

> 从 2026-10 的重构起，九讲正文由「一讲一页」改为「讲目录 + 节页」（`lectures/lecNN/secNN.md`），
> 旧的 `lectures/lec01.html` 一类地址不再存在——请从[九讲导览](lectures/overview.md)重新进入。

<script>
/*
 * GitHub Pages 会把 404.html 的内容返回给任意路径，浏览器地址栏仍停在那个
 * 路径上，所以本页里的相对链接会被解析到错误的目录（站点还部署在 /<repo>/ 子
 * 路径下，用根绝对路径同样不行）。这里从页面自己的样式表 URL 反推站点根，
 * 再把正文里的相对链接改写成根绝对链接。脚本不可用时退化为普通相对链接。
 */
(function () {
  var sheet = document.querySelector('link[rel="stylesheet"][href*="css/variables-"]');
  var main = document.querySelector("main");
  if (!sheet || !main) return;
  var root = sheet.href.replace(/css\/variables-[^/]*$/, "");
  main.querySelectorAll("a[href]").forEach(function (a) {
    var href = a.getAttribute("href");
    if (!href || /^([a-z][a-z0-9+.-]*:|\/|#)/i.test(href)) return;
    a.setAttribute("href", root + href);
  });
})();
</script>
