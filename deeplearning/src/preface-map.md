# 全书知识地图

这张图是全书唯一的**全局导航**：先看清九讲的关系，再决定从哪一讲切入。

## 一张图：一个范式，四条支线

```
                  ┌─────────────────────────────────────────┐
                  │  第 1 讲 · 深度学习导论（范式）           │
                  │  结构 → 损失 → 梯度下降 → 反向传播        │
                  └───────────────┬─────────────────────────┘
                                  │  这个范式套到不同数据上……
        ┌──────────────┬──────────┼──────────┬──────────────┐
        ▼              ▼          ▼          ▼              ▼
   ┌─────────┐   ┌─────────┐ ┌─────────┐ ┌─────────┐  ┌──────────┐
   │ 第 2 讲  │   │ 第 3 讲  │ │ 第 4 讲  │ │ 第 5 讲  │  │ 第 6–9 讲 │
   │ 序列     │   │ 视觉     │ │ 生成     │ │ 决策     │  │ 前沿/科学 │
   │ RNN→注意 │   │ 卷积→检测 │ │ VAE→扩散 │ │ RL→PPO  │  │ 并行/对齐 │
   └─────────┘   └─────────┘ └─────────┘ └─────────┘  └──────────┘
```

**读法**：第 1 讲是地基，其余八讲都是它的实例。第 2 讲把「结构」换成能处理**变长有序数据**的形状；第 3 讲换成能利用**空间局部性**的形状；第 4 讲把「预测」换成「**采样**」；第 5 讲把「有标签的监督」换成「**与环境交互的试错**」。第 6–9 讲不引入新的范式，而是把这套范式推到**规模**（大模型、并行训练）、**价值**（安全对齐）与**应用**（AI for Science）的层面。

## 概念依赖：这些概念后面反复用

- **反向传播**（[1.5](../lectures/lec01.md)）：第 2–9 讲所有目标函数都靠它求梯度。
- **注意力**（[2.4](../lectures/lec02.md)）：Transformer 是 LLM、VLA、扩散骨干的共同底座，[第 6、9 讲](../lectures/lec06.md)全部建立在它之上。
- **重参数化技巧**（[4.2](../lectures/lec04.md)）：VAE 与扩散模型都用它把随机性「推」到可导的位置。
- **参数高效微调 LoRA**（[9.4](../lectures/lec09.md)）：[Lab 3](../labs/lab3.md) 的实战方法，也是项目里「小算力撬动大模型」的默认手段。
- **缩放律与并行**（[6.1](../lectures/lec06.md)、[9.1](../lectures/lec09.md)）：理解「为什么是这些模型胜出」的两把钥匙。

## 三条推荐路线

| 路线 | 顺序 | 适合 |
|:--|:--|:--|
| **通读线** | 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9 | 第一次系统学习 |
| **视觉/生成线** | 1 → 3 → 4 →（Lab 2） | 做视觉或生成课题 |
| **序列/大模型线** | 1 → 2 → 6 → 9 →（Lab 1、Lab 3） | 做序列、LLM 或机器人课题 |

> 每讲页首都有一张**学习简报**（先修 / 目标 / 学完标准）与一个**「10 分钟复习版」**盒子；赶时间时只读后者，即可拿到该讲的骨架。
