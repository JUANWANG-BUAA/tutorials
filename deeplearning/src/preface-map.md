# 全书知识地图

这张图是全书唯一的**全局导航**：先看清九讲的关系，再决定从哪一讲切入。

## 一张图：一个范式，四条支线，三个收束

```text
                  ┌──────────────────────────────────────────────────┐
                  │  第 1 讲 · 深度学习导论（范式）                    │
                  │  结构 → 损失 → 梯度下降 → 反向传播                 │
                  └───────────────┬──────────────────────────────────┘
                                  │  这个范式套到不同数据上……
        ┌──────────────┬──────────┼──────────┬──────────────────────┐
        ▼              ▼          ▼          ▼                      ▼
   ┌─────────┐   ┌─────────┐ ┌─────────┐ ┌─────────┐          ┌──────────┐
   │ 第 2 讲  │   │ 第 3 讲  │ │ 第 4 讲  │ │ 第 5 讲  │          │ 第 6 讲   │
   │ 序列     │   │ 视觉     │ │ 生成     │ │ 决策     │          │ 新前沿    │
   │ 注意力   │   │ 卷积     │ │ 扩散/流  │ │ RL/偏好  │          │ 大模型    │
   └────┬────┘   └────┬────┘ └────┬────┘ └────┬────┘          └─────┬────┘
        │             │           │           │                    │
        └─────────────┴─────┬─────┴───────────┘                    │
                            │  四条支线共享同一套训练语言            │
                            ▼                                       ▼
                  ┌───────────────────┐              ┌───────────────────────┐
                  │ 第 9 讲 · 规模     │              │ 第 7 讲 · 价值/责任    │
                  │ 切分与通信         │              │ 可控·可信·公平         │
                  └─────────┬─────────┘              └──────────┬────────────┘
                            │                                    │
                            └────────────┬───────────────────────┘
                                         ▼
                              ┌───────────────────────┐
                              │ 第 8 讲 · 应用：科学   │
                              │ 拟合 vs 理解           │
                              └───────────────────────┘
```

**读法**：第 1 讲是地基，第 2–5 讲是四条支线——都是「同一个范式换结构」：第 2 讲把「结构」换成能处理**变长有序数据**的形状；第 3 讲换成能利用**空间局部性**的形状；第 4 讲把「预测」换成「**采样**」；第 5 讲把「有标签的监督」换成「**与环境交互的试错**」。第 6–9 讲不引入新范式，而是把这套范式推到**规模**（[6](lectures/lec06/overview.md)、[9](lectures/lec09/overview.md)）、**价值**（[7](lectures/lec07/overview.md)）与**应用**（[8](lectures/lec08/overview.md)）的层面。

| [9](lectures/lec09/overview.md) | 模型放不下时，切分与通信是核心 | 怎么在有限显存里训大模型？ |

### 2. 三个「反复出现的判断」

1. **「代价换什么」**：$O(T^2)$ 换精度（注意力）、步数换质量（扩散）、显存换通信（ZeRO/TP/PP）、能力换风险（更大的模型）。
2. **「先小后大」**：先用单样本过拟合验证通路（[工具箱](toolbox.md)），再放大；先小模型验证方法（[9.7](lectures/lec09/sec97.md)），再上并行。
3. **「并列证据，不站队」**：涌现能力之争（[6.2](lectures/lec06/sec62.md)）、世界模型之辩（[6.6](lectures/lec06/sec66.md)）、PINN 边界（[8.4](lectures/lec08/sec84.md)）——教材给证据与判据，不给口号。

## 四条推荐路线

| 路线 | 顺序 | 适合 |
|:--|:--|:--|
| **通读线** | 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9 | 第一次系统学习 |
| **视觉/生成线** | 1 → 3 → 4 →（Lab 2） | 做视觉或生成课题 |
| **序列/大模型线** | 1 → 2 → 6 → 9 →（Lab 1、Lab 3） | 做序列、LLM 或机器人课题 |
| **工程落地线** | [工具箱](toolbox.md) → 1（只补形状与训练） → 3.6 或 2.2 → 9.5 → Lab 3 | 已有编程基础、目标是「跑起来」 |

> 每讲页首都有一张**学习简报**（先修 / 目标 / 学完标准）与一个**「10 分钟复习版」**盒子；赶时间时只读后者，即可拿到该讲的骨架。
