# 面试与答辩竞技场

面试与答辩考的**不是「你学过什么」，而是「你能不能在压力下把一件事讲清楚」**：给 60 秒要你区分两个概念，给 5 分钟要你在白板上推一个公式，给 10 分钟要你在约束下做一个工程决策。这三种能力训练方式完全不同——这一页把它们做成三轮计时赛。

用法：先读[必考点清单](#arena-must)照着补漏，然后**关掉正文**，进入三轮赛制（自带计时与记分牌），赛后按[段位表](#arena-rank)复盘，错题送进[抢救室](#arena-rescue)。

::: note 素材依据与诚实声明（本页的「必考」从哪来）

本页题目的分级依据有三类，逐条标注、不含臆测：

- **S 级（课程核心）**：九讲正文里给出完整推导的结论——它们必被追问，因为**能推导的东西最容易被验证**。
- **A 级（工程高频）**：真实工程与面试中反复出现的判断点（显存账、并行选择、训练不收敛、对齐方案取舍）。
- **B 级（前沿常识）**：2023–2025 年的默认实践（RoPE/GQA/FlashAttention/MoE/DPO/GRPO/量化），只需讲清「解决什么问题、代价是什么」。

全部题目与答案要点为**本教程编写**，不代表任何机构的真实面试题库。涉及论文的，以论文原文为准。
:::

## 二、三轮赛制

<a id="arena-rounds"></a>

::: method 第一轮 · 60 秒速答（每个概念 60 秒，共 20 题）{#arena-round1}

**规则**：抽题 → 计时 60 秒 → **开口讲**（录音或讲给同伴）→ 对照答案要点自评。只写不算。

**评分**：① 说出定义（1 分）；② 说出「解决什么问题」（1 分）；③ 说出一个条件或代价（1 分）。**满分 3 分，低于 2 分算不过。**

| # | 题目 | 答案要点（自评用） |
|:--|:--|:--|
| 1 | 为什么深层网络不用 Sigmoid 做隐藏层激活？ | 导数上界 0.25，连乘导致梯度指数衰减；ReLU 正区间导数为 1 |
| 2 | 交叉熵为什么比 MSE 更适合分类？ | 配 softmax 时梯度是 $\hat y-y$，不随饱和消失；MSE 含 $\hat y(1-\hat y)$ 因子 |
| 3 | Adam 与 AdamW 的差别？ | AdamW 把权重衰减从梯度中解耦，不参与自适应缩放，泛化更好 |
| 4 | BN 与 LN 的关键差别？ | 归一化维度不同（批 vs 特征）；BN 依赖批统计且在推理时用滑动统计 |
| 5 | 为什么注意力要除以 $\sqrt{d_k}$？ | 点积方差随 $d_k$ 线性增长 → softmax 饱和 → 梯度消失 |
| 6 | 位置编码为什么必要？ | 自注意力对置换等变，无序信息；位置必须显式注入 |
| 7 | KV cache 是什么？占多少显存？ | 缓存历史 K/V 避免重算；约为 $2\!\cdot\!L\!\cdot\!H_{kv}\!\cdot\!d\!\cdot\!T\!\cdot\!B\!\cdot\!\text{字节}$ |
| 8 | 为什么 LLM 推理常是 memory-bound？ | 每步只算一个 token，算力用不满，瓶颈在权重与 KV 的读取带宽 |
| 9 | 残差连接为何让深层可训？ | 梯度含恒等项 $I+\partial\mathcal F/\partial x$，可直接回传 |
| 10 | Dropout 为什么有效？ | 阻止共适应，近似集成子网络；推理期关闭（Inverted dropout 训练期已缩放） |
| 11 | VAE 的 ELBO 两项各是什么？ | 重建项（期望对数似然）+ 正则项（KL 到先验） |
| 12 | GAN 为什么会模式坍塌？ | 判别器主导 → 生成器只覆盖少数模式；对策：WGAN、谱归一化、mini-batch 判别 |
| 13 | 扩散的采样为什么慢？ | 需 T 步串行去噪；加速：DDIM、蒸馏、一致性、流匹配 |
| 14 | DQN 的经验回放与目标网络各解决什么？ | 打破样本时序相关；稳定 TD 目标避免「追着自己跑」 |
| 15 | on-policy 与 off-policy 的差别？ | 更新用的数据是否来自当前策略；影响样本效率与稳定性 |
| 16 | RLHF 的奖励模型怎么训？ | Bradley-Terry 偏好模型：$\sigma(r(y_w)-r(y_l))$ 做二分类 |
| 17 | reward hacking 是什么？ | 代理奖励上升但真实目标变差（Goodhart 效应），需 KL 约束与多指标监控 |
| 18 | LoRA 为什么有效？ | 微调增量近似低秩；冻结基座只训 $BA$，显存与存储都省 |
| 19 | ZeRO 三个阶段分片什么？ | 优化器状态 → 梯度 → 参数；通信量递增、显存递减 |
| 20 | 什么是指令微调？ | 用「指令—回答」对做监督微调，让模型学会遵循任务格式 |

## 三、项目答辩特训（课程产出是提案，不是考试）

6.S191 一类的课程以**项目提案**作为唯一计分产出，答辩考的正是「你的问题值不值得做、你的方案能不能落地」。答辩用**五问**逼出名堂：

::: method 答辩五问（每个问题 90 秒，超时即失分）{#arena-defense}
1. **问题**：你要解决的具体问题是什么？**它的成功判据是什么**（可测量）？
2. **为什么现在**：已有工作做到哪一步了？你做与不做的差别在哪（最小可验证增量）？
3. **怎么做**：技术路线的三段式（数据 → 方法 → 评估）；最不确定的一环是哪一步？
4. **代价**：算力/数据/时间预算各是多少？**预算减半砍哪一刀**？
5. **失败预案**：什么结果会让你判定「此路不通」？届时你的 Plan B 是什么？

**常见失分点**：① 只讲「我要用 Transformer」不讲为什么非它不可；② 没有基线（无基线的提升不可信）；③ 评估口径含糊（「效果好」不是判据）；④ 数据来源与合规一句带过；⑤ 没有失败预案。**五个里中三个，答辩就算没过。**
:::

## 五、抢救室（高频错点复盘）

::: errata 十个最常讲错的地方
1. **把 softmax 说成「归一化的输出层激活」而忘了它融在损失里**：框架的 `CrossEntropyLoss` 已含 softmax，网络输出层不要再加。
2. **把 BN 说成「归一化到标准正态」**：它是「减均值除标准差 + 可学习仿射」，仿射才是表达能力来源。
3. **把注意力复杂度说成 $O(T^2d)$ 而忘记显存 $O(T^2)$**：训练时的中间矩阵才是显存杀手。
4. **把扩散的 $T$ 步说成「必须串行所以无法加速」**：DDIM/一致性/流匹配都在解耦这个约束。
5. **把 DPO 说成「不需要偏好数据」**：DPO 恰恰需要**成对**偏好数据，省的是奖励模型与在线采样。
6. **把 off-policy 说成「更不稳定所以不好」**：样本效率高是它的核心价值，代价才是稳定性。
7. **把 ZeRO-3 说成「一定更快」**：它省显存但通信量最大，小集群上常常更慢。
8. **把 TP 与 PP 的取舍说反**：TP 通信密集（层内）、气泡小；PP 气泡明显但通信少；选谁取决于**单层能否放下**。
9. **把缩放律当成「越大越好」**：Chinchilla 的结论是**给定算力**下的最优配比，不是无限堆参数。
10. **把基准分数当能力**：污染、提示敏感、解码策略都会显著改变分数（[6.7](../lectures/lec06/sec67.md)）。
:::
