## 案例1：GRPO的组内归一化优势估计

### 插入位置
`src/lectures/lec06/sec63.md`，在"推理模型与策略优化"小节讨论GRPO时

### 完整内容

:::ex 例 6.3.1 · GRPO的优势估计：为什么不需要critic {#ex-6.3.1}
**背景**：PPO需要训练值函数 $V(s)$ 来估计优势 $A=Q-V$，DeepSeek-R1用**组内归一化**（group-relative policy optimization）替代critic，显存和样本效率都提升。

**问题**：给定4条采样轨迹（数学题答案），奖励 $r=[0.2, 0.8, 0.5, 0.6]$（1=完全正确，0=完全错误），对比GRPO和PPO的优势估计。

::::proof 解

**GRPO的做法（组内归一化）**：

(1) 算均值与标准差：
$$\bar r = \frac{0.2+0.8+0.5+0.6}{4}=0.525$$

方差（样本方差，除以 $n-1=3$）：
$$s^2=\frac{(0.2-0.525)^2+(0.8-0.525)^2+(0.5-0.525)^2+(0.6-0.525)^2}{3}$$
$$=\frac{0.105625+0.075625+0.000625+0.005625}{3}=0.0625$$

$$s=\sqrt{0.0625}=0.25$$

(2) 归一化优势：
$$A_i^{\text{GRPO}}=\frac{r_i-\bar r}{s}$$

$$A^{\text{GRPO}}=\begin{bmatrix}
\frac{0.2-0.525}{0.25}\\
\frac{0.8-0.525}{0.25}\\
\frac{0.5-0.525}{0.25}\\
\frac{0.6-0.525}{0.25}
\end{bmatrix}=\begin{bmatrix}-1.30\\1.10\\-0.10\\0.30\end{bmatrix}$$

**PPO的做法（用critic估计值函数）**：

假设critic预测所有状态的值 $V=0.5$（学习后的平均估计），则：
$$A_i^{\text{PPO}}=r_i-V=\begin{bmatrix}0.2-0.5\\0.8-0.5\\0.5-0.5\\0.6-0.5\end{bmatrix}=\begin{bmatrix}-0.3\\0.3\\0\\0.1\end{bmatrix}$$

**对比（关键差异）**：

| 轨迹 | 奖励 $r$ | GRPO优势 | PPO优势 | 解读 |
|------|---------|---------|---------|------|
| 1 | 0.2 | **-1.30** | -0.3 | GRPO强烈压制"最差的" |
| 2 | 0.8 | **+1.10** | +0.3 | GRPO强烈奖励"最好的" |
| 3 | 0.5 | -0.10 | 0 | 接近均值，两者都接近0 |
| 4 | 0.6 | +0.30 | +0.1 | 略好于均值 |

**GRPO的对比度**：$1.10-(-1.30)=2.40$  
**PPO的对比度**：$0.3-(-0.3)=0.6$

GRPO把"做对"和"做错"的轨迹拉开了 **4倍**（2.40 vs 0.6）。

**为什么GRPO有效**：

1. **可验证任务**：数学题、代码题的奖励是**二值的**（对/错）或**稀疏的**（只有最终答案有奖励）。组内归一化强制拉开对比度，不需要critic去学"差不多对"的细粒度值。

2. **节省显存**：PPO需要训练critic网络（与policy同等大小），GRPO只需存储一组轨迹的奖励（$O(k)$ 浮点数）。

3. **代价**：需要每组采样**足够多**轨迹（$k\geq 4$），否则标准差不稳定。当 $k=2$ 时，任何两个不同奖励都会被归一化成 $\pm 1$，丢失真实差距。

**验证（极端情况）**：

若4条轨迹的奖励全部相同 $r=[0.5, 0.5, 0.5, 0.5]$：
- 标准差 $s=0$（除以0，数值不稳定）
- 实现中需要加 $\epsilon=10^{-8}$ 避免除零：$s=\max(s, \epsilon)$

此时GRPO的梯度为0（所有优势相同），模型不更新——这符合直觉（无法区分好坏时，不应该学习）。$\blacksquare$
::::
:::

## 案例2：Mamba的选择性SSM（4-token手算）

### 插入位置
`src/lectures/lec02/sec27.md`，在讨论Mamba机制时

### 完整内容

:::ex 例 2.7.A · 选择性SSM的状态更新：输入依赖 vs 固定 {#ex-2.7.A}
**对比目标**：S4（固定转移矩阵 $A$）vs Mamba（输入依赖的 $\bar A_t$）

**场景**：4个token序列 $x=[1, 0, 1, -1]$，用1维状态 $h\in\mathbb R$ 累积信息。

**S4的做法（固定 $A$）**：
$$h_{t+1}=A\cdot h_t + B\cdot x_t,\quad A=0.9\text{（固定衰减系数）},\quad B=0.5$$

逐步更新：
- $t=0$: $h_0=0$（初始）
- $t=1$: $h_1=0.9\times0 + 0.5\times1=0.5$
- $t=2$: $h_2=0.9\times0.5 + 0.5\times0=0.45$
- $t=3$: $h_3=0.9\times0.45 + 0.5\times1=0.905$
- $t=4$: $h_4=0.9\times0.905 + 0.5\times(-1)=0.3145$

**问题**：$h_4$ 里包含了 $x_1=1$ 的信息，经过4步衰减到 $0.5\times0.9^3\approx0.36$。如果 $x_1$ 是**重要token**（如句子主语），衰减太快会丢失信息。

**Mamba的做法（输入依赖的 $\bar A_t$）**：
$$\bar A_t=\exp(\Delta_t\cdot A),\quad \Delta_t=\text{softplus}(W_\Delta x_t)$$

简化：$W_\Delta=[2, -1, 2, -3]$（学到的投影），$A=-1$（固定对数域系数）。

计算 $\Delta_t$：
$$\Delta_t=\ln(1+\exp(W_\Delta x_t))$$

- $t=1$: $W_\Delta x_1=2\times1=2$, $\Delta_1=\ln(1+e^2)\approx2.13$
- $t=2$: $W_\Delta x_2=-1\times0=0$, $\Delta_2=\ln(2)\approx0.69$
- $t=3$: $W_\Delta x_3=2\times1=2$, $\Delta_3\approx2.13$
- $t=4$: $W_\Delta x_4=-3\times(-1)=3$, $\Delta_4\approx3.05$

转换为 $\bar A_t$：
$$\bar A_t=\exp(\Delta_t\cdot A)=\exp(-\Delta_t)$$

- $\bar A_1=e^{-2.13}\approx0.12$（快速衰减，$x_1$ 是重要token，记住它）
- $\bar A_2=e^{-0.69}\approx0.50$（中等衰减）
- $\bar A_3=e^{-2.13}\approx0.12$
- $\bar A_4=e^{-3.05}\approx0.05$（极快衰减）

**选择性状态更新**（简化 $B=1$）：
$$h_{t+1}=\bar A_t\cdot h_t + \bar B_t\cdot x_t$$

- $h_1=0.12\times0 + 1\times1=1.0$
- $h_2=0.50\times1.0 + 1\times0=0.50$
- $h_3=0.12\times0.50 + 1\times1=1.06$
- $h_4=0.05\times1.06 + 1\times(-1)=-0.95$

**对比S4**：
- S4的 $h_4=0.31$（均匀衰减，所有历史信息混在一起）
- Mamba的 $h_4=-0.95$（$x_4=-1$ 的信号强，覆盖了衰减的历史）

**核心差异**：
- S4: $A$ 固定 → 所有token以相同速率衰减 → **无法区分重要性**
- Mamba: $\bar A_t$ 依赖 $x_t$ → 重要token用小 $\bar A$ 保持（衰减慢），无关token用大 $\bar A$ 快速遗忘

**为什么需要"选择性"**：
- 自然语言中，**并非所有token同等重要**（"the"可以快速遗忘，"Einstein"需要记住）
- 固定 $A$ 无法做这种区分，必须靠注意力机制（$O(T^2)$ 复杂度）
- 选择性SSM用 $O(T)$ 复杂度实现类似效果

$\blacksquare$
::::
:::

**代码验证**（可选）：

```python
import numpy as np

def s4_update(x, A=0.9, B=0.5):
    h = [0.0]
    for xt in x:
        h.append(A * h[-1] + B * xt)
    return np.array(h[1:])

def mamba_update(x, W_delta, A_log=-1.0):
    delta = np.log(1 + np.exp(W_delta * x))  # softplus
    A_bar = np.exp(delta * A_log)
    h = [0.0]
    for i, xt in enumerate(x):
        h.append(A_bar[i] * h[-1] + xt)
    return np.array(h[1:])

x = np.array([1, 0, 1, -1])
W_delta = np.array([2, -1, 2, -3])

print("S4 states:", s4_update(x))
print("Mamba states:", mamba_update(x, W_delta))
```

## 案例3：测试时计算的算力分配

### 插入位置
`src/lectures/lec06/sec63.md`，在"测试时计算"（test-time compute）小节

### 完整内容

:::ex 例 6.3.C · 固定算力预算下的最优采样分配 {#ex-6.3.C}
**场景**：3道数学题，难度不同。总算力预算：**20次前向传播**（forward pass），每题可以采样多次然后majority vote。

**问题分布**：
- 题1（简单）：单次正确率 $p_1=0.8$
- 题2（中等）：单次正确率 $p_2=0.5$
- 题3（困难）：单次正确率 $p_3=0.2$

**策略对比**：

**策略A（均匀分配）**：每题采样 $20/3\approx6$ 次（向下取整），取多数投票

多数投票正确率（$k$ 次采样中至少 $\lceil k/2\rceil$ 次正确）：
$$P_{\text{correct}}(k, p)=\sum_{j=\lceil k/2\rceil}^{k}\binom{k}{j}p^j(1-p)^{k-j}$$

计算：
- 题1（$k=6, p=0.8$）：$P_1=\binom{6}{3}0.8^3\cdot0.2^3 + \cdots + \binom{6}{6}0.8^6 \approx 0.983$
- 题2（$k=6, p=0.5$）：$P_2\approx 0.656$（硬币投掷，6次中至少3次正面）
- 题3（$k=6, p=0.2$）：$P_3\approx 0.099$

期望得分（3题均分）：
$$E_A=\frac{0.983+0.656+0.099}{3}\approx 0.579$$

**策略B（算力向高收益题倾斜）**：
- 题1：采样2次（已经很准，边际收益小）
- 题2：采样10次（中等准确率，收益大）
- 题3：采样8次（虽然难,但多采样能提升）

计算：
- 题1（$k=2, p=0.8$）：至少1次正确 $=1-(1-0.8)^2=0.96$
- 题2（$k=10, p=0.5$）：至少6次正确 $\approx 0.828$
- 题3（$k=8, p=0.2$）：至少5次正确 $\approx 0.056$（仍然很低）

期望得分：
$$E_B=\frac{0.96+0.828+0.056}{3}\approx 0.615$$

**策略C（放弃最难题，集中火力）**：
- 题1：采样1次（$p=0.8$，够了）
- 题2：采样19次（all-in）
- 题3：采样0次（放弃，得分0）

计算：
- 题1：$P_1=0.8$
- 题2（$k=19, p=0.5$）：至少10次正确 $\approx 0.999$
- 题3：$P_3=0$

期望得分：
$$E_C=\frac{0.8+0.999+0}{3}\approx 0.600$$

**对比汇总**：

| 策略 | 题1分配 | 题2分配 | 题3分配 | 期望得分 | 策略描述 |
|------|--------|--------|--------|---------|---------|
| A（均匀） | 6 | 6 | 6 | **0.579** | 公平但低效 |
| **B（倾斜）** | 2 | 10 | 8 | **0.615** | 最优 |
| C（放弃难题） | 1 | 19 | 0 | 0.600 | 极端策略 |

**结论**：
1. **边际收益递减**：题1从单次0.8→2次0.96，只提升0.16；题2从单次0.5→10次0.828，提升0.328
2. **最优分配**：给"中等难度+高边际收益"的题更多算力
3. **放弃策略**：当某题单次正确率<0.1时,多次采样收益极低（$p=0.2$, $k=8$ 只得0.056），不如把算力给其他题

**与o1/DeepSeek-R1的对比**：
- o1用强化学习训练"算力分配策略"（何时多采样、何时early stop）
- 这个例子是**静态已知 $p$** 的情况；实际中需要**在线估计** $p$（如前几次采样的一致性）

$\blacksquare$
::::
:::

**Python实现**（可选）：

```python
from scipy.stats import binom

def majority_vote_accuracy(k, p):
    """k次采样，单次正确率p，majority vote的正确率"""
    threshold = (k + 1) // 2  # 至少要对几次
    return 1 - binom.cdf(threshold - 1, k, p)

# 策略B
p_vals = [0.8, 0.5, 0.2]
k_vals = [2, 10, 8]

scores = [majority_vote_accuracy(k, p) for k, p in zip(k_vals, p_vals)]
print(f"策略B期望得分: {sum(scores) / 3:.3f}")
print(f"各题得分: {scores}")

# 网格搜索最优分配（暴力枚举）
best_score = 0
best_alloc = None
for k1 in range(1, 20):
    for k2 in range(1, 20 - k1):
        k3 = 20 - k1 - k2
        scores = [majority_vote_accuracy(k, p) 
                  for k, p in zip([k1, k2, k3], p_vals)]
        score = sum(scores) / 3
        if score > best_score:
            best_score = score
            best_alloc = (k1, k2, k3)

print(f"最优分配: {best_alloc}, 期望得分: {best_score:.3f}")
```
